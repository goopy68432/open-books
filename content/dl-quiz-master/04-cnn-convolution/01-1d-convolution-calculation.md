## 0. 한 줄 요약
커널 $w = [1, 2]$ 를 길이 7 입력에 슬라이딩하며 $(w * x)_i = 1 \cdot x_i + 2 \cdot x_{i+1}$ 을 계산하면 길이 6 의 출력이 나오며, 이 연산은 선형이므로 입력의 합/상수의 합으로 분해 검증할 수 있다.

## 1. 문제 (정확한 출제 형태)
커널 $w = [1, 2]$ 가 주어진다. 다음 4개의 입력 $x \in \mathbb{R}^7$ 각각에 대해 1D convolution(정확히는 cross-correlation) $w * x \in \mathbb{R}^6$ 을 계산하라.

정의:
$$
(w * x)_i = 1 \cdot x_i + 2 \cdot x_{i+1}, \qquad i = 1, 2, \dots, 6
$$

입력:
1. $x^{(1)} = (0, 1, 2, 3, 4, 5, 6)$
2. $x^{(2)} = (1, 1, 1, 1, 1, 1, 1)$
3. $x^{(3)} = (1, 2, 3, 4, 5, 6, 7)$
4. $x^{(4)} = (0, 2, 4, 6, 8, 10, 12)$

## 2. 출제 의도와 시험 가치
- **연산 정의 정확 적용**: convolution(엄밀히는 cross-correlation) 의 슬라이딩 곱-합 연산을 손으로 정확히 수행할 수 있는가.
- **출력 크기 공식 체득**: valid convolution 에서 $n_{out} = n_{in} - k + 1$.
- **선형성 인지**: 다음 퀴즈(Q12, Q13)에서 행렬 표현으로 이어지는 다리. $w * (x + y) = w * x + w * y$ 와 $w * (\alpha x) = \alpha (w * x)$ 가 성립함을 체감.
- **인쇄 오류 견고성**: 출제표가 정의와 어긋나면 정의를 우선하고, 선형성으로 교차검증.

## 3. 사전 개념 (모든 수학 도구)

### 3.1 1D Cross-correlation 의 엄밀한 정의
입력 $x \in \mathbb{R}^n$, 커널 $w \in \mathbb{R}^k$ ($k \le n$) 일 때 valid 출력 $y \in \mathbb{R}^{n - k + 1}$ 은
$$
y_i = \sum_{j=1}^{k} w_j \cdot x_{i + j - 1}, \qquad i = 1, \dots, n - k + 1.
$$
딥러닝 라이브러리(PyTorch, TensorFlow)에서 부르는 "convolution" 은 사실 위의 cross-correlation 이다(커널을 뒤집지 않음).

### 3.2 Valid 출력 길이
$$
n_{out} = n_{in} - k + 1.
$$
여기서 $n_{in} = 7,\ k = 2$ 이므로 $n_{out} = 6$.

### 3.3 선형성
연산 $f(x) = w * x$ 는 $\mathbb{R}^7 \to \mathbb{R}^6$ 의 선형사상이다. 즉
$$
f(\alpha x + \beta y) = \alpha f(x) + \beta f(y).
$$
따라서 $x = u + v$ 로 분해해 둘 다의 conv 결과를 더해도 같다. (Q12 의 행렬 표현 근거.)

### 3.4 상수 입력의 conv
$x = c \cdot \mathbf{1}$ (상수) 이면 $y_i = (1 + 2) c = 3 c$ 이므로 $w * (c \mathbf{1}) = 3 c \mathbf{1}_6$.

## 4. 풀이 (모든 단계, 등호 근거)

각 입력에 대해 $y_i = x_i + 2 x_{i+1}$ 을 $i = 1, \dots, 6$ 에 적용한다.

### 4.1 $x^{(1)} = (0, 1, 2, 3, 4, 5, 6)$
- $y_1 = 0 + 2 \cdot 1 = 2$
- $y_2 = 1 + 2 \cdot 2 = 5$
- $y_3 = 2 + 2 \cdot 3 = 8$
- $y_4 = 3 + 2 \cdot 4 = 11$
- $y_5 = 4 + 2 \cdot 5 = 14$
- $y_6 = 5 + 2 \cdot 6 = 17$

$\Rightarrow w * x^{(1)} = (2, 5, 8, 11, 14, 17)$.

### 4.2 $x^{(2)} = (1, 1, 1, 1, 1, 1, 1)$
모든 $i$ 에서 $y_i = 1 + 2 \cdot 1 = 3$.

$\Rightarrow w * x^{(2)} = (3, 3, 3, 3, 3, 3)$.

### 4.3 $x^{(3)} = (1, 2, 3, 4, 5, 6, 7)$
- $y_1 = 1 + 2 \cdot 2 = 5$
- $y_2 = 2 + 2 \cdot 3 = 8$
- $y_3 = 3 + 2 \cdot 4 = 11$
- $y_4 = 4 + 2 \cdot 5 = 14$
- $y_5 = 5 + 2 \cdot 6 = 17$
- $y_6 = 6 + 2 \cdot 7 = 20$

$\Rightarrow w * x^{(3)} = (5, 8, 11, 14, 17, 20)$.

> 출제표의 $(4, 7, 10, 13, 16, 19)$ 는 정의와 어긋난다. 정의 $y_i = x_i + 2 x_{i+1}$ 를 따르면 위 값이 정답이며, 4.5 절의 선형성 분해로도 동일하게 검증된다. 출제표는 인쇄/필사 오류로 본다.

### 4.4 $x^{(4)} = (0, 2, 4, 6, 8, 10, 12)$
$x^{(4)} = 2 \cdot x^{(1)}$ 이므로 선형성에 의해 $w * x^{(4)} = 2 \cdot (2, 5, 8, 11, 14, 17) = (4, 10, 16, 22, 28, 34)$.

직접 계산으로도:
- $y_1 = 0 + 2 \cdot 2 = 4$
- $y_2 = 2 + 2 \cdot 4 = 10$
- $y_3 = 4 + 2 \cdot 6 = 16$
- $y_4 = 6 + 2 \cdot 8 = 22$
- $y_5 = 8 + 2 \cdot 10 = 28$
- $y_6 = 10 + 2 \cdot 12 = 34$.

## 5. 검증

### 5.1 선형성 교차검증 ($x^{(3)}$)
$x^{(3)} = x^{(1)} + \mathbf{1}_7$ 이므로
$$
w * x^{(3)} = w * x^{(1)} + w * \mathbf{1}_7 = (2, 5, 8, 11, 14, 17) + (3, 3, 3, 3, 3, 3) = (5, 8, 11, 14, 17, 20).
$$
정의 직접 계산과 일치 → 4.3 의 결과가 정답.

### 5.2 등차수열 패턴
입력 $x^{(1)}, x^{(3)}, x^{(4)}$ 가 등차수열이면 출력도 등차수열이고 공차는 입력 공차 $d$ 의 $(1 + 2) = 3$ 배.
- $x^{(1)}$ 공차 1 → 출력 공차 3 ✓
- $x^{(3)}$ 공차 1 → 출력 공차 3 ✓
- $x^{(4)}$ 공차 2 → 출력 공차 6 ✓

### 5.3 출력 길이
모두 6 으로 $n - k + 1 = 7 - 2 + 1$ 과 일치.

## 6. 일반화·통찰
- **선형성**: $w * x$ 는 입력에 선형이므로 임의의 입력을 기저($e_1, \dots, e_7$) 의 선형결합으로 표현하면 conv 결과도 같은 계수로 결합된다. → Q12 의 Toeplitz 행렬 표현.
- **DC gain**: 상수 입력에 대한 응답 $\sum_j w_j = 1 + 2 = 3$. 신호처리에서 "DC 이득" 이라 부른다.
- **로컬리티**: 출력 $y_i$ 는 입력의 인접한 2개 원소만 본다 → CNN 의 receptive field 의 1D 원형.
- **Stride 1, padding 0** (valid). stride/padding 변경 시 출력 길이 공식 $\lfloor (n + 2p - k)/s \rfloor + 1$ 로 일반화.

## 7. 시험 출제 변형 5가지
1. **커널 변경**: $w = [1, -1]$ (1차 미분 근사) 일 때 $x^{(1)}$ 출력은? → $(1, 1, 1, 1, 1, 1)$.
2. **커널 길이 3**: $w = [1, 0, -1]$, $x^{(1)}$ 입력 ($n = 7$) → 출력 길이 5, 값 $(-2, -2, -2, -2, -2)$.
3. **선형결합 입력**: $x = 3 x^{(1)} - 2 x^{(2)}$ 의 conv 결과를 선형성으로 답하라.
4. **Stride 2**: 같은 커널, stride 2, $x^{(1)}$ → 출력 길이 $\lfloor (7-2)/2 \rfloor + 1 = 3$, 값 $(2, 8, 14)$.
5. **Padding 1 (zero)**: 입력 양 끝에 0 을 한 칸씩 padding → 입력 길이 9, 출력 길이 8. 첫 출력 $0 + 2 \cdot 0 = 0$, 마지막 $6 + 2 \cdot 0 = 6$.

## 8. 백지 재현 체크리스트
- [ ] Cross-correlation 정의 식 $y_i = \sum_j w_j x_{i+j-1}$ 적기
- [ ] 출력 길이 공식 $n - k + 1$ 적기
- [ ] $w = [1,2]$ 와 4개 입력 받아쓰기
- [ ] 4개 출력 6원소씩 직접 계산
- [ ] $x^{(3)} = x^{(1)} + \mathbf{1}$ 분해로 선형성 검증
- [ ] $x^{(4)} = 2 x^{(1)}$ 로 스칼라배 검증
- [ ] DC gain $\sum w_j = 3$ 언급

## 9. 핵심 공식 카드
- 정의: $(w * x)_i = \sum_{j=1}^{k} w_j x_{i+j-1}$
- 길이: $n_{out} = n_{in} - k + 1$ (valid)
- 일반: $n_{out} = \lfloor (n_{in} + 2p - k)/s \rfloor + 1$
- 선형성: $w * (\alpha x + \beta y) = \alpha (w*x) + \beta (w*y)$
- DC gain: 상수 $c$ 입력 → 상수 $(\sum w_j) c$ 출력
- 본 문제: $w = [1, 2]$, $n=7$, $k=2$, 출력 6원소, DC gain 3

## 10. 다른 퀴즈와의 연결
- **Q12 (1D conv 행렬)**: 본 퀴즈의 연산 $f(x) = w * x: \mathbb{R}^7 \to \mathbb{R}^6$ 가 선형이라는 사실이 행렬 표현 $A \in \mathbb{R}^{6 \times 7}$ 의 존재 근거. $A$ 의 $j$ 번째 열은 $f(e_j)$ 이며, $A x^{(1)} = (2, 5, 8, 11, 14, 17)^\top$ 으로 본 퀴즈 결과와 일치해야 한다.
- **Q13 (2D conv 행렬)**: 1D 의 Toeplitz 구조가 2D 에서는 doubly block-Toeplitz (BTTB) 로 확장. 본질은 동일한 weight sharing + sparsity.
- **CNN inductive bias 4종 세트**: sparsity, locality, weight sharing, translation equivariance — Q11 에서 손으로 만진 그 패턴이 그대로 CNN 의 핵심 가정.
