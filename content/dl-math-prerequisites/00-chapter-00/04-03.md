# 3단계: 고등 - 미적분 입문

> **이 단계의 목표**: 극한, 미분의 개념을 이해하고, 기본적인 미분 공식을 사용할 수 있다.
> 퀴즈에서 $\frac{\partial p}{\partial z}$의 $\partial$(편미분 기호)를 이해하기 위한 기초를 다진다.

---

## 3.1 극한 (Limit)

### 왜 알아야 하는가?

미분은 극한으로 정의된다. 극한을 모르면 미분을 제대로 이해할 수 없다.

### 무엇을 알아야 하는가?

#### 극한의 직관적 이해

"x가 어떤 값에 **한없이 가까이** 갈 때, f(x)는 어떤 값에 **다가가는가**?"

$$\lim_{x \to 2} (3x + 1) = 7$$

x가 2에 가까워지면, $3x + 1$은 7에 가까워진다.

#### 왜 "가까이 간다"고 하는가?

바로 그 값을 넣으면 되지 않나? 대부분은 그렇다. 하지만 아래처럼 직접 대입이 안 되는 경우가 있다:

$$\lim_{h \to 0} \frac{(x+h)^2 - x^2}{h}$$

$h = 0$을 직접 넣으면 $\frac{0}{0}$이 되어 계산 불가! 하지만 정리하면:

$$= \lim_{h \to 0} \frac{x^2 + 2xh + h^2 - x^2}{h} = \lim_{h \to 0} \frac{2xh + h^2}{h} = \lim_{h \to 0} (2x + h) = 2x$$

이것이 바로 $x^2$의 미분이다!

---

## 3.2 미분 (Derivative) - 변화율

### 왜 알아야 하는가?

퀴즈의 $\frac{\partial p}{\partial z}$는 "$z$가 변할 때 $p$가 얼마나 변하는가"를 묻는 것이다. 이것이 미분이다.

### 배경: 기울기와 변화율

#### 직선의 기울기

두 점 $(x_1, y_1)$과 $(x_2, y_2)$를 지나는 직선의 기울기:

$$\text{기울기} = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x} = \frac{\text{y의 변화량}}{\text{x의 변화량}}$$

예시: (1, 2)와 (3, 8)을 지나는 직선의 기울기:

$$\frac{8 - 2}{3 - 1} = \frac{6}{2} = 3$$

x가 1 증가하면 y는 3 증가한다.

#### 곡선의 기울기 → 미분

곡선 $y = x^2$ 위의 한 점에서의 기울기는?

두 점 사이의 기울기를 구한 뒤, 두 점의 간격을 0에 가깝게 줄인다:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

이것이 **미분의 정의**이다.

### 미분의 의미

> **"x가 아주 조금 변할 때, y는 얼마나 변하는가?"**

미분값이 크면 → 급격히 변함 (가파른 경사)
미분값이 0이면 → 변화 없음 (평평한 곳)
미분값이 음수면 → 감소하고 있음

---

## 3.3 미분의 표기법

### 다양한 표기법

같은 것을 여러 방식으로 쓴다:

| 표기법 | 읽는 법 | 설명 |
|--------|---------|------|
| $f'(x)$ | "f 프라임 x" | 라그랑주 표기법 |
| $\frac{dy}{dx}$ | "dx분의 dy" | 라이프니츠 표기법 |
| $\frac{df}{dx}$ | "dx분의 df" | 같은 의미 |
| $\frac{d}{dx}f(x)$ | "dx분의 d, f(x)에 적용" | 미분 연산자 형태 |

**중요**: $\frac{dy}{dx}$는 분수처럼 생겼지만, **하나의 기호**이다. "y를 x로 미분한 것"이라는 뜻이다.

---

## 3.4 기본 미분 공식

### 반드시 외워야 할 공식들

| 함수 $f(x)$ | 도함수 $f'(x)$ | 이름 |
|-------------|----------------|------|
| $c$ (상수) | $0$ | 상수의 미분 |
| $x$ | $1$ | |
| $x^n$ | $nx^{n-1}$ | 거듭제곱의 미분 |
| $e^x$ | $e^x$ | **지수함수의 미분 ← 매우 중요!** |
| $\ln(x)$ | $\frac{1}{x}$ | 로그함수의 미분 |
| $cf(x)$ | $cf'(x)$ | 상수배의 미분 |

### $e^x$의 미분이 왜 중요한가?

$$\frac{d}{dx} e^x = e^x$$

**자기 자신이 그대로 나온다!** 이것이 $e$가 특별한 이유이며, 소프트맥스에서 $\exp$를 사용하는 이유 중 하나이다. 미분이 깔끔하게 나온다.

---

## 3.5 미분 법칙 (Rules of Differentiation)

### 합의 법칙 (Sum Rule)

$$(f + g)' = f' + g'$$

예시: $(x^2 + 3x)' = 2x + 3$

### 곱의 법칙 (Product Rule)

$$(fg)' = f'g + fg'$$

예시: $(x \cdot e^x)' = 1 \cdot e^x + x \cdot e^x = e^x(1 + x)$

### **몫의 법칙 (Quotient Rule) ← 소프트맥스 미분의 핵심!**

$$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$$

> **매우 중요!** 소프트맥스는 분수 형태이므로, 미분할 때 반드시 몫의 법칙을 사용한다.

예시: $\left(\frac{x^2}{x+1}\right)' = \frac{2x(x+1) - x^2 \cdot 1}{(x+1)^2} = \frac{x^2 + 2x}{(x+1)^2}$

**몫의 법칙 외우는 법**:
```
(분자)' × 분모 - 분자 × (분모)'
─────────────────────────────
          (분모)²
```

### 연쇄 법칙 (Chain Rule) ← 딥러닝의 핵심!

합성함수의 미분:

$$\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)$$

예시: $\frac{d}{dx} e^{3x} = e^{3x} \cdot 3 = 3e^{3x}$

> 딥러닝의 **역전파(backpropagation)** 알고리즘이 바로 연쇄법칙의 연속 적용이다!

---

## 3.6 중요한 미분 예제: $e^{f(x)}$의 미분

연쇄법칙에 의해:

$$\frac{d}{dx} e^{f(x)} = e^{f(x)} \cdot f'(x)$$

**예시들**:

$$\frac{d}{dx} e^{2x} = 2e^{2x}$$

$$\frac{d}{dx} e^{x^2} = 2x \cdot e^{x^2}$$

$$\frac{d}{dx} e^{z_i} = e^{z_i} \cdot \frac{dz_i}{dx}$$

---

## 3.7 편미분 맛보기

### 왜 미리 알아야 하는가?

퀴즈의 $\frac{\partial p}{\partial z}$에서 $\partial$ 기호가 바로 편미분이다.

### 편미분이란?

변수가 여러 개인 함수에서, **한 변수만 변화시키고 나머지는 고정**시킨 채 미분하는 것.

$$f(x, y) = x^2 + 3xy + y^2$$

**x에 대한 편미분** (y는 상수 취급):

$$\frac{\partial f}{\partial x} = 2x + 3y$$

**y에 대한 편미분** (x는 상수 취급):

$$\frac{\partial f}{\partial y} = 3x + 2y$$

### 표기법의 차이

| 기호 | 의미 |
|------|------|
| $\frac{d}{dx}$ | 변수가 하나인 **일반 미분** |
| $\frac{\partial}{\partial x}$ | 변수가 여러 개인 **편미분** |

$\partial$는 "d의 곱슬머리 버전"이라고 생각하면 된다. "partial"이라고 읽는다.

---

## 3.8 이 단계에서 꼭 기억할 것

| 개념 | 소프트맥스 퀴즈에서의 역할 |
|------|--------------------------|
| 미분 = 변화율 | $\frac{\partial p}{\partial z}$는 z가 변할 때 p의 변화율 |
| $e^x$의 미분 = $e^x$ | 소프트맥스 미분이 깔끔해지는 이유 |
| 몫의 법칙 | 소프트맥스(분수)를 미분할 때 사용 |
| 편미분 ($\partial$) | 여러 변수 중 하나에 대해서만 미분 |
| 연쇄법칙 | 딥러닝 역전파의 수학적 기초 |

## 연습 문제

1. $f(x) = e^{3x}$를 미분하시오.

2. 몫의 법칙으로 $\frac{e^x}{e^x + 1}$을 미분하시오.

3. $f(x, y) = e^x + e^y$에서 $\frac{\partial f}{\partial x}$를 구하시오.

### 정답

1. $f'(x) = 3e^{3x}$ (연쇄법칙)

2. $\frac{e^x(e^x + 1) - e^x \cdot e^x}{(e^x + 1)^2} = \frac{e^{2x} + e^x - e^{2x}}{(e^x + 1)^2} = \frac{e^x}{(e^x + 1)^2}$

3. $\frac{\partial f}{\partial x} = e^x$ ($e^y$는 x에 대해 상수이므로 미분하면 0)
