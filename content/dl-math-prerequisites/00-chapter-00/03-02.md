# 2단계: 중등 - 대수와 함수

> **이 단계의 목표**: 변수, 함수, 지수, 시그마(Σ) 표기법을 이해한다.
> 소프트맥스 수식을 "읽을 수 있는" 수준이 된다.

---

## 2.1 변수 (Variable)

### 왜 알아야 하는가?

소프트맥스 수식에서 $z$, $p$, $i$, $k$, $C$ 등은 모두 변수이다. 변수를 이해하지 못하면 수식 자체를 읽을 수 없다.

### 무엇을 알아야 하는가?

**변수**란 특정 값을 대신하는 **이름표(기호)** 이다.

```
"사과의 개수"를 x라고 하자.
x = 5 이면 사과가 5개라는 뜻이다.
```

#### 변수의 종류 (소프트맥스에서)

| 변수 | 의미 | 역할 |
|------|------|------|
| $z$ | 입력 벡터 | 신경망의 출력값들 |
| $p$ | 출력 벡터 | 확률로 변환된 값들 |
| $z_i$ | z의 i번째 원소 | 특정 클래스의 점수 |
| $p_i$ | p의 i번째 원소 | 특정 클래스의 확률 |
| $C$ | 클래스의 총 개수 | 상수 (고정된 수) |
| $i, k$ | 인덱스(번호) | 몇 번째인지를 나타냄 |

### 첨자(subscript)의 의미

$z_i$에서 아래 작은 글씨 $i$는 **"z의 i번째 원소"** 를 의미한다.

$$z = [z_1, z_2, z_3, \ldots, z_C]$$

예를 들어 $C = 3$이고 $z = [2.0, 1.0, 0.5]$이면:
- $z_1 = 2.0$
- $z_2 = 1.0$
- $z_3 = 0.5$

---

## 2.2 함수 (Function)

### 왜 알아야 하는가?

소프트맥스($p_i$)는 **함수**이다. 입력($z$)을 넣으면 출력($p$)이 나온다.

### 무엇을 알아야 하는가?

#### 함수의 기본 개념

**함수**란 입력을 받아서 하나의 출력을 돌려주는 **규칙**이다.

```
입력(x) ──→ [규칙 f] ──→ 출력 f(x)
```

$$f(x) = 2x + 3$$

- $f(1) = 2(1) + 3 = 5$
- $f(4) = 2(4) + 3 = 11$

#### 함수의 표기법

| 표기 | 의미 |
|------|------|
| $f(x)$ | x를 입력받는 함수 f |
| $f(x) = x^2$ | f의 규칙은 "x를 제곱하는 것" |
| $y = f(x)$ | y는 f(x)의 결과값 |

#### 여러 변수를 가진 함수

함수는 여러 입력을 받을 수 있다:

$$g(x, y) = x + y$$

- $g(3, 5) = 3 + 5 = 8$

**소프트맥스에서**: $p_i$는 $z_1, z_2, \ldots, z_C$ **모두**에 의존하는 함수이다. (분모에 전부 들어가므로!)

---

## 2.3 거듭제곱과 지수 (Exponent)

### 왜 알아야 하는가?

소프트맥스에서 $\exp(z_i)$는 지수함수이다. 지수의 개념 없이는 이해 불가능하다.

### 무엇을 알아야 하는가?

#### 거듭제곱의 기본

$$a^n = \underbrace{a \times a \times \cdots \times a}_{n\text{번}}$$

- $2^3 = 2 \times 2 \times 2 = 8$
- $5^2 = 5 \times 5 = 25$
- $a^1 = a$
- $a^0 = 1$ (어떤 수든 0제곱은 1)

#### 지수법칙

| 법칙 | 공식 | 예시 |
|------|------|------|
| 곱셈 | $a^m \times a^n = a^{m+n}$ | $2^3 \times 2^2 = 2^5 = 32$ |
| 나눗셈 | $\frac{a^m}{a^n} = a^{m-n}$ | $\frac{2^5}{2^3} = 2^2 = 4$ |
| 거듭제곱의 거듭제곱 | $(a^m)^n = a^{mn}$ | $(2^3)^2 = 2^6 = 64$ |

## 2.4 자연상수 e와 지수함수 exp

### 왜 알아야 하는가?

소프트맥스의 핵심 재료가 $\exp(x) = e^x$이다.

### 자연상수 e란?

$$e \approx 2.71828\ldots$$

$e$는 $\pi$처럼 특별한 상수이다. 무한히 이어지는 소수이며, 수학과 자연현상에서 매우 자주 등장한다.

#### e의 직관적 이해

은행에 100만원을 넣고 연이율 100%로 복리를 적용한다고 하자:

| 복리 횟수 | 계산 | 결과 |
|-----------|------|------|
| 1번 (연1회) | $(1 + 1)^1$ | 2 |
| 2번 (반기) | $(1 + 1/2)^2$ | 2.25 |
| 12번 (월) | $(1 + 1/12)^{12}$ | 2.613... |
| 365번 (일) | $(1 + 1/365)^{365}$ | 2.7146... |
| ∞번 (연속) | $\lim_{n \to \infty}(1 + 1/n)^n$ | **2.71828... = e** |

복리를 무한히 자주 적용하면 수렴하는 값이 바로 $e$이다!

### 지수함수 exp(x)

$$\exp(x) = e^x$$

$\exp$는 "$e$를 $x$제곱한다"는 뜻이다.

| x | $\exp(x) = e^x$ | 근사값 |
|---|------------------|--------|
| 0 | $e^0$ | 1 |
| 1 | $e^1$ | 2.718 |
| 2 | $e^2$ | 7.389 |
| -1 | $e^{-1}$ | 0.368 |
| -2 | $e^{-2}$ | 0.135 |

**핵심 성질**:
- $\exp(x) > 0$ : **항상 양수!** (음수가 될 수 없다)
- $x$가 클수록 $\exp(x)$도 매우 빠르게 커진다
- $\exp(a) \times \exp(b) = \exp(a + b)$

#### 왜 소프트맥스에서 exp를 사용하는가?

1. **양수 보장**: 확률은 음수가 될 수 없으므로, exp로 감싸서 항상 양수로 만든다
2. **차이 증폭**: 큰 값은 더 크게, 작은 값은 더 작게 만들어 "확신있는" 확률 분포를 만든다
3. **수학적 편의**: 미분이 깔끔하게 나온다 ($\frac{d}{dx}e^x = e^x$)

## 2.5 시그마(Σ) 표기법 - 합의 기호

### 왜 알아야 하는가?

소프트맥스 분모의 $\sum_{k=1}^{C} \exp(z_k)$를 읽으려면 Σ를 알아야 한다.

### 무엇을 알아야 하는가?

#### Σ의 구조

$$\sum_{k=1}^{C} f(k) = f(1) + f(2) + f(3) + \cdots + f(C)$$

```
  C          ← 끝 번호 (어디까지 더할지)
  Σ f(k)     ← f(k)를 반복해서 더한다
 k=1         ← 시작 번호 (어디서부터 더할지)
```

#### 구체적 예시

$$\sum_{k=1}^{4} k = 1 + 2 + 3 + 4 = 10$$

$$\sum_{k=1}^{3} k^2 = 1^2 + 2^2 + 3^2 = 1 + 4 + 9 = 14$$

#### 소프트맥스에서의 Σ

$C = 3$이고 $z = [2.0, 1.0, 0.5]$일 때:

$$\sum_{k=1}^{3} \exp(z_k) = \exp(2.0) + \exp(1.0) + \exp(0.5)$$

$$= 7.389 + 2.718 + 1.649 = 11.756$$

이것이 소프트맥스의 **분모**가 된다.

---

## 2.6 소프트맥스 수식 읽기 연습

이제 소프트맥스 수식을 한 글자씩 읽어보자:

$$p_i = \frac{\exp(z_i)}{\sum_{k=1}^{C} \exp(z_k)}$$

**한국어로 읽기**:

> "p의 i번째 값은, e의 z_i 제곱을, k가 1부터 C까지일 때 e의 z_k 제곱을 모두 더한 것으로 나눈 값이다."

**더 쉽게**:

> "i번째 확률 = i번째의 exp 값 ÷ 모든 exp 값의 합"

### 구체적 계산 예시

$z = [2.0, 1.0, 0.5]$ (C = 3)

**Step 1**: 각각에 exp 적용

| i | $z_i$ | $\exp(z_i)$ |
|---|-------|-------------|
| 1 | 2.0 | 7.389 |
| 2 | 1.0 | 2.718 |
| 3 | 0.5 | 1.649 |

**Step 2**: 합계 계산 (분모)

$$\sum_{k=1}^{3} \exp(z_k) = 7.389 + 2.718 + 1.649 = 11.756$$

**Step 3**: 각 확률 계산

| i | $p_i = \frac{\exp(z_i)}{11.756}$ | 결과 |
|---|----------------------------------|------|
| 1 | 7.389 / 11.756 | 0.629 (62.9%) |
| 2 | 2.718 / 11.756 | 0.231 (23.1%) |
| 3 | 1.649 / 11.756 | 0.140 (14.0%) |

**검증**: $0.629 + 0.231 + 0.140 = 1.000$ ✓ (합이 1!)

## 2.7 집합 표기법 맛보기

### $\mathbb{R}$이란?

수식에 $z, p \in \mathbb{R}^C$라는 표현이 나온다.

- $\mathbb{R}$: **실수(Real number)** 전체의 집합. 정수, 분수, 소수, 무리수 등 모든 수.
- $\in$: "~에 속한다" (belongs to)
- $\mathbb{R}^C$: C개의 실수로 이루어진 벡터 (나중에 배움)

$z \in \mathbb{R}^C$는 "z는 C개의 실수로 이루어진 벡터이다"라는 뜻이다.

## 연습 문제

1. $\sum_{i=1}^{5} i$를 계산하시오.

2. $\sum_{k=1}^{3} 2^k$를 계산하시오.

3. $z = [1, 2, 3]$일 때, $\exp(z_2)$의 근사값을 구하시오. ($e \approx 2.718$)

4. $z = [1, 0, -1]$일 때, 소프트맥스 $p_1, p_2, p_3$를 계산하시오.

### 정답

1. $1 + 2 + 3 + 4 + 5 = 15$

2. $2^1 + 2^2 + 2^3 = 2 + 4 + 8 = 14$

3. $\exp(z_2) = \exp(2) = e^2 \approx 7.389$

4. $\exp(1) \approx 2.718$, $\exp(0) = 1$, $\exp(-1) \approx 0.368$
   - 합 = $2.718 + 1 + 0.368 = 4.086$
   - $p_1 = 2.718/4.086 \approx 0.665$
   - $p_2 = 1/4.086 \approx 0.245$
   - $p_3 = 0.368/4.086 \approx 0.090$
