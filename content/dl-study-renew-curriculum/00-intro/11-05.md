## 1.1 학습 프레임워크 (E, T, P) 완전 정복

### Tom Mitchell의 정의 다시 보기

> "A computer program is said to **learn** from **experience E** with respect to some class of **tasks T** and **performance measure P**, if its performance at tasks in T, as measured by P, improves with experience E."

이 정의를 하나씩 풀어보자.

#### Experience (E) — 경험 = 데이터

데이터는 학습의 원료다. 데이터의 **양**, **질**, **다양성** 모두 중요하다.

```
데이터의 세 가지 측면:

1. 양 (Quantity): 데이터가 많을수록 일반적으로 성능이 좋아진다
   - 하지만 무한히 많다고 무한히 좋아지지는 않는다 (수확 체감 법칙)

2. 질 (Quality): 노이즈가 많거나 라벨이 틀리면 학습이 오히려 나빠진다
   - "Garbage in, garbage out"

3. 다양성 (Diversity): 편향된 데이터 → 편향된 모델
   - 예: 밝은 피부 사진만으로 학습한 얼굴 인식 → 어두운 피부에서 성능 저하
```

#### Task (T) — 과제의 분류 체계

본 자료에서 다룬 분류/회귀 외에도, 실제로 다양한 과제 유형이 존재한다.

| 과제 유형 | 입력 | 출력 | 핵심 특징 |
|-----------|------|------|-----------|
| 이진 분류 | x | {0, 1} | 두 클래스 중 하나 |
| 다중 분류 | x | {1, 2, ..., C} | C개 클래스 중 하나 |
| 다중 라벨 분류 | x | {0,1}^C | 여러 라벨 동시에 가능 |
| 회귀 | x | 실수 | 연속적인 값 예측 |
| 순위 매기기 | x쌍 | 순서 | 검색 엔진, 추천 시스템 |
| 구조 예측 | x | 구조체 | 문장 파싱, 단백질 구조 |

#### Performance (P) — 성능 측정의 다양한 방법

```
분류 문제의 성능 지표:

                    실제 양성        실제 음성
예측 양성          TP (참양성)     FP (거짓양성) ← "없는데 있다고 한 것"
예측 음성          FN (거짓음성)   TN (참음성)

정확도 (Accuracy)  = (TP + TN) / 전체
정밀도 (Precision) = TP / (TP + FP)  → "양성이라고 한 것 중 진짜 양성"
재현율 (Recall)    = TP / (TP + FN)  → "진짜 양성 중 얼마나 찾았나"
F1 Score          = 2 × (Precision × Recall) / (Precision + Recall)
```

**왜 정확도만으로는 부족한가?**

```
예: 암 진단 (환자 1000명 중 10명이 실제 암)

모델 A: "모두 정상이다"라고 예측
→ 정확도 = 990/1000 = 99%  (높아 보이지만...)
→ 재현율 = 0/10 = 0%       (암 환자를 한 명도 못 찾음!)

모델 B: 실제로 학습한 모델
→ 정확도 = 95%
→ 재현율 = 80%              (암 환자 10명 중 8명 발견)

→ 모델 B가 실제로 훨씬 유용하다!
```

> **딥러닝과의 연결**: 딥러닝에서도 동일한 성능 지표를 사용한다. 특히 객체 탐지에서는 mAP (mean Average Precision), 생성 모델에서는 FID (Frechet Inception Distance) 같은 특화된 지표를 사용한다.

## 1.2 손실 함수 (Loss Function)의 직관

### 손실 함수란 무엇인가?

손실 함수는 **"모델의 예측이 정답과 얼마나 다른지"를 숫자로 표현하는 함수**다.

```
비유: 양궁 선수가 과녁을 쏜다고 하자.

  과녁 중심 = 정답 (y)
  화살이 꽂힌 곳 = 예측 (ŷ)
  과녁 중심과 화살 사이의 거리 = 손실 (L)

좋은 선수 = 손실이 작은 모델
```

### 회귀용 손실 함수 비교

#### (1) MSE (Mean Squared Error) — 평균 제곱 오차

$$L_{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

```
직관: 오차를 제곱해서 평균 낸다.

특징:
- 큰 오차에 "벌점"을 크게 준다 (제곱이니까)
- 미분이 깔끔하다 → 최적화에 유리
- 이상치(outlier)에 민감하다

예: 정답 = [3, 5, 7], 예측 = [2.5, 5.5, 6]
   오차 = [0.5, -0.5, 1]
   제곱 = [0.25, 0.25, 1.0]
   MSE = (0.25 + 0.25 + 1.0) / 3 = 0.5
```

#### (2) MAE (Mean Absolute Error) — 평균 절대 오차

$$L_{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$$

```
직관: 오차의 절댓값을 평균 낸다.

특징:
- 모든 오차에 동일한 비중을 준다
- 이상치에 더 강건하다 (robust)
- 0에서 미분 불가능 → 최적화가 살짝 까다로움

같은 예: |오차| = [0.5, 0.5, 1.0]
   MAE = (0.5 + 0.5 + 1.0) / 3 = 0.667
```

#### (3) Huber Loss — MSE와 MAE의 절충

$$L_\delta(a) = \begin{cases} \frac{1}{2}a^2 & |a| \leq \delta \\ \delta(|a| - \frac{1}{2}\delta) & |a| > \delta \end{cases}$$

```
직관: 작은 오차에는 MSE처럼 (부드럽게),
     큰 오차에는 MAE처럼 (이상치에 강건하게)

→ "두 마리 토끼를 잡는" 손실 함수
```

#### 시각적 비교

```
손실
 │
 │    ╱ MAE (V자 모양)
 │   ╱
 │  ╱  ╱── MSE (U자 모양, 더 가파르게 올라감)
 │ ╱  ╱
 │╱ ╱     Huber (가운데는 MSE, 양쪽은 MAE)
 │╱
 ┼──────── 오차
```

### 분류용 손실 함수

#### (1) 크로스 엔트로피 (Cross-Entropy Loss)

$$L_{CE} = -\sum_{i=1}^{n} \left[ y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i) \right]$$

```
직관: 정답이 1인데 예측이 0에 가까울수록 → 벌점이 폭발적으로 커진다

  정답 y=1일 때:
    예측 ŷ=0.9 → 손실 = -log(0.9) ≈ 0.105  (작음 ← 좋은 예측)
    예측 ŷ=0.5 → 손실 = -log(0.5) ≈ 0.693  (중간)
    예측 ŷ=0.1 → 손실 = -log(0.1) ≈ 2.303  (큼 ← 나쁜 예측)
    예측 ŷ=0.01 → 손실 = -log(0.01) ≈ 4.605 (매우 큼!)

→ "확신하면서 틀리면" 엄청난 벌점을 받는다
```

> **딥러닝과의 연결**: 신경망의 마지막 층에 softmax를 붙이고 크로스 엔트로피를 손실 함수로 사용하는 것이 분류 문제의 표준 패턴이다. PyTorch에서는 `nn.CrossEntropyLoss()`가 softmax + 크로스 엔트로피를 한 번에 처리한다.

#### (2) 힌지 손실 (Hinge Loss)

$$L_{hinge} = \max(0, 1 - y \cdot \hat{y})$$

```
직관: 올바르게 분류했고, 마진(여유)도 충분하면 손실 = 0
     마진이 부족하거나 틀리면 손실이 선형적으로 증가

→ SVM(서포트 벡터 머신)에서 사용하는 손실 함수
→ "단순히 맞추는 것"이 아니라 "여유 있게 맞추는 것"을 강제한다
```

### 손실 함수 선택 가이드

```
문제 유형        추천 손실 함수          이유
─────────────────────────────────────────────────
회귀             MSE                   깔끔한 수학적 성질
회귀 (이상치 多) Huber 또는 MAE         이상치에 강건
이진 분류         Binary Cross-Entropy  확률적 해석 가능
다중 분류         Categorical CE        softmax와 자연스러운 조합
순위 문제         Contrastive / Triplet  임베딩 학습에 적합
```

## 1.3 선형 회귀 Step-by-Step

### Step 1: 문제 설정

```
목표: 데이터 {(x₁,y₁), ..., (xₙ,yₙ)}이 주어졌을 때,
      ŷ = wx + b 형태의 직선을 찾아서 y를 예측하자.

w: 기울기 (weight, 가중치)
b: y절편 (bias, 편향)
```

### Step 2: 손실 함수 정의

$$L(w, b) = \frac{1}{2n} \sum_{i=1}^n (y_i - wx_i - b)^2$$

왜 $\frac{1}{2}$을 곱하는가? → 미분할 때 제곱의 2가 내려오면서 상쇄되어 식이 깔끔해지기 때문이다.

### Step 3: 경사하강법으로 풀기

```
반복 알고리즘:
  1. w, b를 아무 값으로 초기화 (예: w=0, b=0)
  2. 반복:
     a. 기울기(gradient) 계산:
        ∂L/∂w = -(1/n) Σ xᵢ(yᵢ - wxᵢ - b)
        ∂L/∂b = -(1/n) Σ (yᵢ - wxᵢ - b)

     b. 파라미터 업데이트:
        w ← w - η × (∂L/∂w)
        b ← b - η × (∂L/∂b)

        여기서 η = 학습률 (learning rate)

     c. 손실이 충분히 작아지면 멈춤
```

### Step 4: 닫힌 형태의 해 (Closed-form Solution)

행렬 표현을 사용하면 한 번에 최적해를 구할 수 있다.

$$\hat{w} = (X^\top X)^{-1} X^\top y$$

```
왜 이 공식이 나오는가? (직관적 이해)

L(w) = ||y - Xw||²  → 이것을 w에 대해 미분하고 0으로 놓으면:
∂L/∂w = -2X^T(y - Xw) = 0
X^T Xw = X^T y
w = (X^T X)^{-1} X^T y  ← 정규방정식 (Normal Equation)
```

**경사하강법 vs 정규방정식 비교:**

| 항목 | 경사하강법 | 정규방정식 |
|------|-----------|-----------|
| 특징 개수 d가 클 때 | 여전히 작동 | $O(d^3)$으로 매우 느림 |
| 데이터 n이 클 때 | SGD로 효율적 | 전체 데이터 필요 |
| 하이퍼파라미터 | 학습률 η 설정 필요 | 없음 |
| 범용성 | 어떤 미분가능 손실에도 적용 | MSE에만 적용 |

> **딥러닝과의 연결**: 딥러닝에서는 정규방정식을 사용할 수 없다 (비선형 모델이므로). 따라서 항상 경사하강법 (SGD, Adam 등)을 사용한다. 선형 회귀에서 경사하강법을 연습하는 것이 딥러닝의 학습 알고리즘을 이해하는 첫걸음이다.

## 1.4 로지스틱 회귀 Step-by-Step

### Step 1: "분류에 직선을 쓸 수 없을까?"

```
문제: y ∈ {0, 1}인데, 선형 함수 wx + b는 -∞ ~ +∞ 범위다.

해결: 시그모이드 함수로 출력을 [0, 1]로 압축!

σ(z) = 1 / (1 + e^{-z})

  z = -∞ → σ ≈ 0
  z = 0  → σ = 0.5
  z = +∞ → σ ≈ 1

그래프:
  1 ─────────────────╮
                    ╱
  0.5 ─────────╱
              ╱
  0 ─╰──────────────────
     -∞        0        +∞
```

### Step 2: 모델 정의

$$P(y=1|x) = \sigma(w^\top x + b) = \frac{1}{1 + e^{-(w^\top x + b)}}$$

"입력 x가 주어졌을 때, 클래스 1에 속할 확률"을 출력한다.

### Step 3: 왜 크로스 엔트로피 손실을 쓰는가?

```
최대 우도 추정 (Maximum Likelihood Estimation) 관점:

각 데이터의 확률:
  y=1일 때: P(y|x) = σ(w^T x)
  y=0일 때: P(y|x) = 1 - σ(w^T x)

한 줄로: P(y|x) = σ(w^T x)^y · (1 - σ(w^T x))^{1-y}

전체 데이터의 우도:
  L = Π P(yᵢ|xᵢ)

로그 우도:
  log L = Σ [yᵢ log σᵢ + (1-yᵢ) log(1-σᵢ)]

최대화 → 부호 뒤집으면 → 크로스 엔트로피 최소화!
```

### Step 4: 경사하강법 적용

$$\frac{\partial L}{\partial w} = \frac{1}{n} \sum_{i=1}^n (\sigma(w^\top x_i) - y_i) x_i$$

```
놀라운 사실: MSE의 기울기와 형태가 거의 동일하다!

선형 회귀:     ∂L/∂w = (1/n) Σ (ŷᵢ - yᵢ) xᵢ    (ŷ = wx + b)
로지스틱 회귀: ∂L/∂w = (1/n) Σ (σᵢ - yᵢ) xᵢ    (σ = sigmoid(wx + b))

차이점: 예측값에 시그모이드가 적용되었을 뿐이다!
```

> **딥러닝과의 연결**: 로지스틱 회귀는 활성화 함수가 시그모이드인 **1층짜리 신경망**과 동일하다. 즉, 딥러닝의 가장 기본적인 빌딩 블록이 바로 로지스틱 회귀다.

## 1.5 입문 레벨 연습문제

**문제 1.** MSE, MAE, Huber 손실 함수가 있다. 데이터에 이상치가 많은 경우 어떤 손실 함수를 선택해야 하는지 설명하고, 그 이유를 "큰 오차에 대한 벌점 크기" 관점에서 서술하라.

<details>
<summary>풀이 보기</summary>

MAE 또는 Huber 손실을 선택해야 한다.

- MSE: 오차를 제곱하므로, 이상치의 큰 오차가 제곱되어 전체 손실을 지배한다. 모델이 이상치에 "끌려가는" 현상이 발생한다.
- MAE: 오차를 절댓값으로 처리하므로, 이상치의 영향이 선형적이다. MSE보다 강건하다.
- Huber: 작은 오차에는 MSE, 큰 오차에는 MAE처럼 동작하여, 정상 데이터에서는 MSE의 장점을 유지하면서 이상치에는 강건하다.

</details>

**문제 2.** 로지스틱 회귀에서 $w^\top x + b = 0$인 점들이 **결정 경계(decision boundary)**가 되는 이유를 시그모이드 함수의 성질로 설명하라.

<details>
<summary>풀이 보기</summary>

$\sigma(0) = \frac{1}{1 + e^0} = \frac{1}{2} = 0.5$

즉 $w^\top x + b = 0$인 점에서 $P(y=1|x) = 0.5$이다. 이 값보다 크면 양성, 작으면 음성으로 분류하므로, 이 경계선이 클래스를 나누는 결정 경계가 된다.

기하학적으로 $w^\top x + b = 0$은 $d$차원 공간의 초평면(hyperplane)이며, 법선 벡터가 $w$인 평면이다.

</details>

**문제 3.** 크로스 엔트로피 손실에서, 정답이 $y=1$인데 모델이 $\hat{y}=0.01$로 예측한 경우와 $\hat{y}=0.5$로 예측한 경우의 손실을 각각 계산하라. 이를 통해 크로스 엔트로피의 "확신하면서 틀릴 때 큰 벌점" 성질을 확인하라.

<details>
<summary>풀이 보기</summary>

$L = -[y \log \hat{y} + (1-y)\log(1-\hat{y})]$

$y=1$일 때: $L = -\log \hat{y}$

- $\hat{y} = 0.5$: $L = -\log(0.5) = \log 2 \approx 0.693$
- $\hat{y} = 0.01$: $L = -\log(0.01) = \log 100 \approx 4.605$

$\hat{y} = 0.01$의 손실이 약 **6.6배** 크다. 모델이 "1%만 양성일 거다"라고 확신하면서 틀린 경우, 단순히 반반인 경우보다 훨씬 큰 벌점을 받는다.

</details>

## 2.1 정규화 이론 (Regularization)

### 왜 정규화가 필요한가?

```
과적합(Overfitting)의 문제:

  학습 데이터: ● ● ●  ●  ●
  과적합 모델: ~~●~~●~~●~~●~~●~~  (모든 점을 완벽히 지나감)
  좋은 모델:   ─────●──●──●──●──  (추세를 잡되, 노이즈는 무시)

과적합 = "교과서를 통째로 외우고, 시험 문제는 못 푸는 학생"
정규화 = "외우지 말고 이해해라"라는 제약 조건
```

### L1 정규화 (Lasso)

$$L_{Lasso} = \frac{1}{2n} \|y - Xw\|^2 + \lambda \sum_{j=1}^d |w_j|$$

```
특징:
- 가중치의 절댓값 합을 벌점으로 추가
- 덜 중요한 특징의 가중치를 정확히 0으로 만든다 → "자동 특징 선택"
- 해가 희소(sparse)해진다

비유: "불필요한 짐을 완전히 버리는 여행자"
     → 꼭 필요한 것만 가방에 넣는다
```

**왜 L1은 희소해를 만드는가?**

```
기하학적 직관:

  L1 제약 조건의 모양: 마름모 (다이아몬드)
  MSE 등고선: 동심원

      w₂
       │  ◇
       │ ◇ ◇
  ─────◇───◇─── w₁    ← L1 제약이 축 위의 꼭짓점에서 만남
       │ ◇ ◇        → 한 좌표가 정확히 0이 되기 쉽다
       │  ◇

  L2 제약 조건의 모양: 원
      w₂
       │  ○
       │○   ○
  ─────○─────○── w₁   ← L2 제약은 어디서든 만남
       │○   ○       → 정확히 0이 되기 어렵다
       │  ○
```

### L2 정규화 (Ridge)

$$L_{Ridge} = \frac{1}{2n} \|y - Xw\|^2 + \lambda \sum_{j=1}^d w_j^2$$

```
특징:
- 가중치의 제곱합을 벌점으로 추가
- 가중치를 0 "근처로" 줄이지만, 정확히 0으로 만들지는 않는다
- 모든 특징을 골고루 작게 만든다

비유: "모든 짐의 무게를 줄이는 여행자"
     → 버리지는 않되, 가벼운 버전으로 교체한다
```

### Elastic Net (L1 + L2 결합)

$$L_{EN} = \frac{1}{2n} \|y - Xw\|^2 + \lambda_1 \sum |w_j| + \lambda_2 \sum w_j^2$$

```
L1의 장점 (특징 선택) + L2의 장점 (안정성)을 동시에 취한다.
실전에서 특징이 많고 상관관계가 높을 때 자주 사용된다.
```

> **딥러닝과의 연결**:
> - L2 정규화는 딥러닝에서 **Weight Decay**라는 이름으로 거의 항상 사용된다 (PyTorch: `optimizer = Adam(params, weight_decay=1e-4)`)
> - 딥러닝에서는 이 외에도 **Dropout**, **Batch Normalization**, **Data Augmentation**, **Early Stopping** 등 다양한 정규화 기법을 사용한다. 이들은 모두 과적합을 방지한다는 같은 목적을 가진다.

## 2.2 교차 검증 (Cross-Validation)

### 왜 필요한가?

```
문제: 모델이 학습 데이터에서 잘 작동하는지는 알 수 있다.
     하지만 "새로운 데이터"에서 잘 작동할지 어떻게 알 수 있나?

답: 데이터를 "훈련용"과 "검증용"으로 나눈다!
```

### K-Fold Cross-Validation

```
데이터를 K개의 조각(fold)으로 나눈다. (보통 K=5 또는 K=10)

Round 1: [검증][학습][학습][학습][학습]  → 성능₁
Round 2: [학습][검증][학습][학습][학습]  → 성능₂
Round 3: [학습][학습][검증][학습][학습]  → 성능₃
Round 4: [학습][학습][학습][검증][학습]  → 성능₄
Round 5: [학습][학습][학습][학습][검증]  → 성능₅

최종 성능 = (성능₁ + 성능₂ + ... + 성능₅) / 5

장점: 모든 데이터가 한 번씩은 검증에 사용된다
     → 성능 추정의 분산이 줄어든다
```

### 하이퍼파라미터 튜닝에 활용

```
정규화 강도 λ를 선택해야 한다고 하자.

λ 후보: [0.001, 0.01, 0.1, 1, 10]

각 λ에 대해 K-fold CV를 수행:
  λ=0.001 → 평균 검증 손실 = 3.2
  λ=0.01  → 평균 검증 손실 = 2.1
  λ=0.1   → 평균 검증 손실 = 1.5  ← 최소!
  λ=1     → 평균 검증 손실 = 1.8
  λ=10    → 평균 검증 손실 = 4.5

→ λ=0.1을 선택한다
```

> **딥러닝과의 연결**: 딥러닝에서는 학습 비용이 크기 때문에 K-fold CV를 전부 수행하기 어렵다. 대신 **단일 검증 세트(validation set)**를 사용하거나, 학습 곡선(learning curve)을 모니터링하며 **early stopping**을 적용하는 것이 일반적이다.

## 2.3 특징 공학 (Feature Engineering)

### 왜 특징이 중요한가?

```
"데이터와 특징이 머신러닝의 한계를 결정하고,
 모델과 알고리즘은 그 한계에 얼마나 근접하는지를 결정한다."
 — Pedro Domingos
```

### 주요 기법

#### (1) 다항 특징 (Polynomial Features)

```
원래 특징: x
다항 특징: x, x², x³, ...

원래 특징: x₁, x₂
다항 특징: x₁, x₂, x₁², x₁x₂, x₂², x₁³, ...

→ 선형 모델로도 비선형 관계를 학습할 수 있다!

예: y = w₁x + w₂x² + w₃x³ + b
   이것은 x에 대해 비선형이지만, w에 대해서는 여전히 선형이다!
   → 정규방정식으로 풀 수 있다
```

#### (2) 특징 스케일링 (Feature Scaling)

```
문제: 키(cm)와 연봉(만원)이 같은 모델에 들어간다면?
     키: 150~190 범위
     연봉: 2000~10000 범위

  → 연봉의 스케일이 크므로, 경사하강법이 지그재그로 움직인다

해결법:
  표준화 (Standardization): z = (x - μ) / σ  → 평균 0, 분산 1
  정규화 (Normalization):   z = (x - min) / (max - min)  → [0, 1] 범위
```

#### (3) 원-핫 인코딩 (One-Hot Encoding)

```
범주형 데이터: 색상 = {빨강, 초록, 파랑}

숫자로 바꾸기 (나쁜 방법): 빨강=1, 초록=2, 파랑=3
  → "초록은 빨강의 2배"라는 잘못된 관계를 모델이 학습할 수 있다

원-핫 인코딩 (좋은 방법):
  빨강 = [1, 0, 0]
  초록 = [0, 1, 0]
  파랑 = [0, 0, 1]
  → 각 범주가 독립적인 차원으로 표현된다
```

> **딥러닝과의 연결**: 딥러닝의 핵심 강점은 **자동 특징 추출(automatic feature extraction)**이다. 전통적 ML에서 사람이 설계해야 했던 특징을 신경망이 데이터로부터 스스로 학습한다. 하지만 입력 데이터의 전처리(스케일링, 정규화)는 딥러닝에서도 여전히 중요하다.

## 2.4 커널 방법과 SVM (Support Vector Machine)

### 커널 트릭 (Kernel Trick)

```
문제: 데이터가 선형으로 분리 불가능하다

   ● ● ○ ● ●
   ● ○ ○ ○ ●
   ● ● ○ ● ●

직선으로는 ○와 ●을 나눌 수 없다!

해결: 고차원으로 보낸다 (feature mapping φ)

원래 공간: (x₁, x₂)
변환 공간: (x₁, x₂, x₁² + x₂²)  → 3차원에서는 평면으로 분리 가능!

핵심: 변환을 직접 계산하지 않고, 커널 함수 K(x, x')로 내적만 계산한다
     → 계산 비용을 크게 줄인다
```

### 대표적인 커널 함수

| 커널 | 수식 | 특징 |
|------|------|------|
| 선형 (Linear) | $K(x, x') = x^\top x'$ | 변환 없음, 선형 분류 |
| 다항 (Polynomial) | $K(x, x') = (x^\top x' + c)^d$ | 차수 d의 다항 변환 |
| RBF (가우시안) | $K(x, x') = \exp(-\gamma \|x-x'\|^2)$ | 무한 차원 변환, 가장 범용적 |

### SVM의 핵심 아이디어

```
목표: 두 클래스를 나누는 초평면 중에서 "마진이 최대인 것"을 찾는다

  ●        |  마진  |        ○
  ●      ● |───────| ○      ○
  ●        |       |        ○
           결정경계

마진(margin) = 결정 경계에서 가장 가까운 데이터 점까지의 거리 × 2

서포트 벡터(Support Vector) = 결정 경계에 가장 가까운 데이터 점들
  → 이 점들만 결정 경계를 결정한다 (나머지는 영향 없음)
```

### SVM의 수학적 정식화

$$\min_{w,b} \frac{1}{2} \|w\|^2 \quad \text{s.t.} \quad y_i(w^\top x_i + b) \geq 1, \; \forall i$$

```
해석:
- ||w||²를 최소화 = 마진을 최대화 (마진 = 2/||w||)
- 제약 조건: 모든 데이터가 마진 바깥에 있어야 한다

소프트 마진 SVM (오분류 허용):
min (1/2)||w||² + C Σ ξᵢ
s.t. yᵢ(w^T xᵢ + b) ≥ 1 - ξᵢ, ξᵢ ≥ 0

C가 크면: 오분류 벌점이 커서 마진이 좁아짐 → 과적합 위험
C가 작으면: 오분류를 많이 허용 → 과소적합 위험
```

> **딥러닝과의 연결**:
> - SVM의 힌지 손실은 딥러닝의 **contrastive loss**, **triplet loss** 등의 기초가 된다.
> - 커널 트릭의 "고차원 변환"이라는 아이디어는 신경망의 **은닉층(hidden layer)**이 수행하는 비선형 변환과 동일한 역할이다. 다만 신경망은 변환 자체를 데이터에서 학습한다는 점이 다르다.
> - Attention 메커니즘의 $QK^\top$도 일종의 커널 함수로 해석할 수 있다.

## 2.5 중급 레벨 연습문제

**문제 1.** L1과 L2 정규화의 기하학적 차이를 설명하고, L1이 왜 희소해를 만드는지 서술하라. "마름모의 꼭짓점"이라는 직관을 수식과 연결하여 설명하라.

<details>
<summary>풀이 보기</summary>

L1 정규화의 제약 조건 $\sum |w_j| \leq t$는 $d$차원 공간에서 **초마름모(cross-polytope)** 형태이다. 2차원에서는 마름모, 3차원에서는 팔면체다.

MSE의 등고선(동심원/타원)과 이 마름모가 만나는 점은 높은 확률로 **마름모의 꼭짓점**이다. 꼭짓점은 좌표축 위에 있으므로, 적어도 하나의 좌표가 정확히 0이 된다.

반면 L2 제약 $\sum w_j^2 \leq t$는 초구(hypersphere)이다. 등고선과 구가 만나는 점이 좌표축 위에 올 확률은 매우 낮으므로, 가중치가 정확히 0이 되기 어렵다.

</details>

**문제 2.** 5-fold Cross-Validation을 사용하여 Ridge 회귀의 $\lambda$를 선택하는 절차를 단계별로 서술하라. 학습 데이터 100개, $\lambda$ 후보가 5개일 때 총 몇 번의 모델 학습이 필요한가?

<details>
<summary>풀이 보기</summary>

절차:
1. 데이터 100개를 5개의 fold (각 20개)로 나눈다
2. 각 $\lambda$ 후보에 대해:
   - 5번 반복: fold 하나를 검증, 나머지 4개로 학습 → 검증 손실 기록
   - 5개 검증 손실의 평균을 해당 $\lambda$의 CV 점수로 기록
3. CV 점수가 가장 낮은 $\lambda$를 선택
4. 선택된 $\lambda$로 전체 100개 데이터를 사용하여 최종 모델 학습

총 학습 횟수: $\lambda$ 후보 5개 × fold 5개 = **25번** + 최종 1번 = **26번**

</details>

**문제 3.** RBF 커널 $K(x, x') = \exp(-\gamma\|x-x'\|^2)$에서 $\gamma$의 역할을 설명하라. $\gamma$가 매우 크거나 작으면 모델이 어떻게 변하는가?

<details>
<summary>풀이 보기</summary>

$\gamma$는 커널의 "폭"을 결정한다.

- $\gamma$가 **크면**: 커널이 좁아진다. 가까운 점들끼리만 영향을 주고받는다. 각 서포트 벡터 주변에 좁은 "섬"이 생기므로 결정 경계가 매우 복잡해진다 → **과적합** 위험.

- $\gamma$가 **작으면**: 커널이 넓어진다. 먼 점들끼리도 서로 비슷하게 취급한다. 결정 경계가 매우 부드러워지므로 → **과소적합** 위험.

$\gamma$의 역할은 "한 데이터 포인트가 얼마나 먼 곳까지 영향을 미칠 수 있는가"를 결정하는 것이다.

</details>

## 3.1 VC 차원 (Vapnik-Chervonenkis Dimension)

### 직관: "모델의 표현력을 측정하는 숫자"

```
질문: "이 모델이 얼마나 복잡한 패턴을 학습할 수 있는가?"

VC 차원은 이 질문에 대한 수학적으로 엄밀한 답이다.
```

### 산산조각(Shattering)의 개념

$n$개의 점이 있을 때, 각 점에 +1 또는 -1을 부여하는 모든 가능한 라벨링은 $2^n$가지다.

가설 클래스 $\mathcal{H}$가 $n$개의 점을 **산산조각(shatter)**한다는 것은 가능한 $2^n$가지 라벨링 모두를 $\mathcal{H}$의 어떤 가설로 정확히 분류할 수 있다는 뜻이다.

$$\text{VC}(\mathcal{H}) = \max\{n : \mathcal{H}\text{가 크기 }n\text{인 점 집합을 shatter할 수 있다}\}$$

### 예제: 2차원 선형 분류기의 VC 차원

```
2차원 평면에서 직선으로 분류하는 경우:

3개의 점: 모든 2³ = 8가지 라벨링을 직선으로 분류 가능
   ● ○     ○ ●     ● ●     ○ ○    ...
    ●       ●       ○       ●
   (가능)   (가능)   (가능)   (가능)

4개의 점: XOR 패턴은 직선으로 분류 불가
   ● ○
   ○ ●
   → 어떤 직선으로도 ●과 ○를 완벽히 분리할 수 없다

따라서 VC(2차원 선형 분류기) = 3 = d+1 (d는 입력 차원)
```

### 일반적인 VC 차원

| 가설 클래스 | VC 차원 |
|------------|---------|
| $d$차원 선형 분류기 | $d + 1$ |
| $k$차 다항식 분류기 | $\binom{d+k}{k}$ |
| $k$-최근접 이웃 (1-NN) | $\infty$ |
| 유한 가설 클래스 $|\mathcal{H}|$ | $\leq \log_2|\mathcal{H}|$ |

### VC 부등식 (VC Bound)

$$P\left[\sup_{h \in \mathcal{H}} |R(h) - \hat{R}(h)| > \epsilon\right] \leq 4 \cdot \Pi_{\mathcal{H}}(2n) \cdot e^{-n\epsilon^2/8}$$

여기서:
- $R(h)$: 진짜 위험 (true risk, 일반화 오차)
- $\hat{R}(h)$: 경험적 위험 (empirical risk, 학습 데이터에서의 오차)
- $\Pi_{\mathcal{H}}(n)$: 성장함수 (growth function)
- $n$: 데이터 수

```
해석 (직관적):

  일반화 오차 ≤ 학습 오차 + √(VC차원 / 데이터 수)

  → VC 차원이 클수록 (복잡한 모델) → 일반화 오차가 커진다
  → 데이터가 많을수록 → 일반화 오차가 줄어든다
  → 이것이 "모델 복잡도 vs 데이터 양"의 트레이드오프의 이론적 근거다
```

> **딥러닝과의 연결**: 딥러닝의 VC 차원은 파라미터 수에 비례하여 매우 크다. 이론적으로는 과적합이 심각해야 하지만, 실제로는 잘 일반화된다. 이 "미스터리"는 현대 딥러닝 이론의 핵심 연구 주제이며, double descent 현상, implicit regularization 등으로 설명이 시도되고 있다.

## 3.2 Rademacher 복잡도 (Rademacher Complexity)

### VC 차원의 한계

VC 차원은 "최악의 경우"만 본다 (shatter 가능한 최대 점 수). 하지만 실제 데이터 분포를 반영하지 못한다. Rademacher 복잡도는 **데이터 분포에 의존하는** 더 정교한 복잡도 측정이다.

### 정의

$$\mathfrak{R}_n(\mathcal{H}) = \mathbb{E}_{x, \sigma}\left[\sup_{h \in \mathcal{H}} \frac{1}{n} \sum_{i=1}^n \sigma_i h(x_i)\right]$$

여기서 $\sigma_i$는 $\{+1, -1\}$에서 균등하게 뽑은 **Rademacher 변수**(무작위 부호)이다.

```
직관:

σᵢ = 무작위 노이즈 라벨 (+1 또는 -1을 동전 던지기로 결정)

Rademacher 복잡도 = "가설 클래스 H가 순수한 노이즈에 얼마나 잘 맞출 수 있는가"

만약 H가 매우 복잡하다면 → 노이즈에도 잘 맞출 수 있다 → 복잡도가 높다
만약 H가 단순하다면 → 노이즈에 맞추기 어렵다 → 복잡도가 낮다

→ "쓸데없는 패턴도 학습할 수 있는 능력"을 측정하는 것이다
```

### Rademacher 복잡도 기반 일반화 바운드

확률 $1 - \delta$ 이상으로:

$$R(h) \leq \hat{R}(h) + 2\mathfrak{R}_n(\mathcal{H}) + \sqrt{\frac{\ln(1/\delta)}{2n}}$$

```
해석:
  일반화 오차 ≤ 학습 오차 + 2 × Rademacher 복잡도 + 신뢰 항

VC 바운드보다 더 타이트(tight)한 경우가 많다:
- 데이터 분포를 반영하므로
- 실제 학습에 사용되는 데이터에 맞춤화된 바운드
```

### VC 차원과 Rademacher 복잡도의 관계

$$\mathfrak{R}_n(\mathcal{H}) \leq \sqrt{\frac{2 \cdot \text{VC}(\mathcal{H}) \cdot \ln(en / \text{VC}(\mathcal{H}))}{n}}$$

즉, VC 차원이 Rademacher 복잡도의 상한을 결정하지만, Rademacher 복잡도는 더 정밀한 정보를 제공한다.

## 3.3 PAC 학습 (Probably Approximately Correct Learning)

### PAC 프레임워크

Leslie Valiant (1984)이 제안한 계산 학습 이론의 기본 프레임워크이다.

```
핵심 질문: "학습이 성공한다"는 것을 수학적으로 어떻게 정의할 수 있는가?

답: "높은 확률로(Probably), 거의 정확한(Approximately Correct) 가설을 찾을 수 있다"

형식적 정의:
  가설 클래스 H가 PAC 학습 가능(PAC learnable)하다 ⟺
  임의의 ε > 0 (오차 허용치)과 δ > 0 (실패 확률)에 대해,
  poly(1/ε, 1/δ, d) 개의 샘플만 있으면,
  확률 1-δ 이상으로 R(h) ≤ ε인 h를 찾을 수 있다.
```

### PAC 학습의 기본 정리

**유한 가설 클래스의 경우:**

$n \geq \frac{1}{\epsilon}\left(\ln|\mathcal{H}| + \ln\frac{1}{\delta}\right)$ 개의 샘플이면 PAC 학습 가능

```
해석:
- |H|가 크면 (가설이 많으면) → 더 많은 데이터가 필요
- ε이 작으면 (더 정확하게 학습하려면) → 더 많은 데이터가 필요
- δ가 작으면 (더 확실하게 보장하려면) → 더 많은 데이터가 필요

놀라운 점: 필요한 데이터 수가 |H|의 "로그"에만 비례한다!
→ 가설 공간이 기하급수적으로 커도, 데이터는 선형적으로만 더 필요하다
```

### PAC 학습의 기본 정리 (무한 가설 클래스)

**VC 차원을 이용한 확장:**

가설 클래스 $\mathcal{H}$가 PAC 학습 가능 $\Leftrightarrow$ VC$(\mathcal{H}) < \infty$

필요한 샘플 수:

$$n = O\left(\frac{d_{VC} + \ln(1/\delta)}{\epsilon^2}\right)$$

여기서 $d_{VC} = \text{VC}(\mathcal{H})$

```
이것이 통계학습이론의 "기본 정리(Fundamental Theorem)"이다:

  PAC 학습 가능
  ⟺ VC 차원이 유한
  ⟺ 균등 수렴(uniform convergence)이 성립
  ⟺ ERM(경험적 위험 최소화)이 일관적(consistent)
```

## 3.4 PAC-Bayes 바운드

### 동기: 사전 지식을 활용하자

기존 PAC 바운드는 가설 클래스 전체에 대한 "최악의 경우" 바운드다. PAC-Bayes는 **사전 분포(prior)**와 **사후 분포(posterior)**를 사용하여 더 타이트한 바운드를 제공한다.

### PAC-Bayes 정리 (McAllester, 1999)

확률 $1 - \delta$ 이상으로, 모든 사후 분포 $Q$에 대해:

$$\mathbb{E}_{h \sim Q}[R(h)] \leq \mathbb{E}_{h \sim Q}[\hat{R}(h)] + \sqrt{\frac{\text{KL}(Q \| P) + \ln(n/\delta)}{2(n-1)}}$$

여기서:
- $P$: 사전 분포 (학습 전에 정한, 데이터에 독립적인 분포)
- $Q$: 사후 분포 (학습 후의 가설 분포)
- $\text{KL}(Q \| P)$: KL 발산 (두 분포의 차이)

```
직관:

  일반화 오차 ≤ 학습 오차 + √(사전/사후 분포의 차이 / 데이터 수)

핵심 통찰:
- 학습 결과(Q)가 사전 지식(P)에서 크게 벗어나지 않으면 → 바운드가 타이트
- "사전 지식이 정확할수록 더 적은 데이터로 학습 가능하다"는 직관과 일치
- 정규화의 이론적 근거를 제공한다:
  L2 정규화 ≈ 가우시안 사전 분포를 가정한 것
```

> **딥러닝과의 연결**:
> - PAC-Bayes 바운드는 딥러닝의 일반화를 설명하는 유력한 이론적 도구 중 하나다.
> - Weight decay (L2 정규화)가 효과적인 이유를 PAC-Bayes 관점에서 설명할 수 있다: 가중치를 0 근처(사전 분포)에 가깝게 유지함으로써 KL 발산을 줄이고, 일반화 바운드를 타이트하게 만든다.
> - 최근 연구에서는 PAC-Bayes 바운드를 직접 최적화하는 학습 알고리즘도 제안되고 있다.

## 3.5 No Free Lunch 정리 (공짜 점심 정리)

### 정리의 내용

> "모든 가능한 문제에 대해 평균적으로, 모든 학습 알고리즘은 동등한 성능을 가진다."

— Wolpert & Macready (1997)

```
형식적 진술:
  모든 목표 함수의 균등 분포 하에서,
  어떤 두 학습 알고리즘 A₁, A₂에 대해:

  E_f[R(A₁)] = E_f[R(A₂)]

  즉, "모든 문제에서 항상 최고인 알고리즘은 존재하지 않는다"
```

### 무엇을 의미하는가?

```
잘못된 해석 (흔한 오해):
  "그러면 어떤 알고리즘을 쓰든 상관없는 거 아닌가?"
  → 아니다!

올바른 해석:
  1. "모든 문제"에서 최고인 알고리즘은 없다
  2. 하지만 "특정 문제 도메인"에서는 어떤 알고리즘이 더 좋을 수 있다
  3. 따라서 "문제에 대한 가정(inductive bias)"이 필수적이다

실전적 의미:
  - 문제의 구조를 이해하고, 그에 맞는 모델을 선택해야 한다
  - "만능 알고리즘"은 존재하지 않는다
  - 도메인 지식이 중요한 이유가 바로 여기에 있다
```

### Inductive Bias (귀납 편향)

```
학습 알고리즘이 가지는 "사전 가정"을 귀납 편향이라고 한다.

예시:
  - 선형 회귀: "데이터가 선형 관계를 따른다"
  - SVM: "마진이 큰 분류기가 좋다"
  - KNN: "가까운 점은 같은 클래스일 것이다"
  - CNN: "이미지의 패턴은 위치에 무관하다" (translation invariance)
  - Transformer: "먼 거리의 토큰도 직접 참조할 수 있다" (전역 어텐션)

No Free Lunch 정리가 말하는 것:
  "좋은 귀납 편향을 선택하는 것이 학습의 핵심이다"
```

> **딥러닝과의 연결**:
> - CNN의 합성곱은 "지역적 패턴이 중요하다"는 귀납 편향이다 → 이미지에서 강력하다.
> - Transformer의 어텐션은 "장거리 의존성이 중요하다"는 귀납 편향이다 → 언어에서 강력하다.
> - 최근의 Foundation Model (GPT, BERT 등)은 대규모 데이터로 사전 학습하여, 문제 특화 귀납 편향 없이도 범용적으로 잘 작동한다. 이는 NFL 정리와 모순되지 않는다: "모든 가능한 문제"가 아니라 "현실에서 발생하는 문제"에 집중하기 때문이다.

## 3.7 고급 레벨 연습문제

**문제 1.** 3차원 선형 분류기($w^\top x + b = 0$으로 분류)의 VC 차원이 4임을 보여라. (힌트: 4개의 점을 shatter할 수 있음을 보이고, 어떤 5개의 점도 shatter할 수 없음을 논증하라)

<details>
<summary>풀이 보기</summary>

**VC ≥ 4 (4개의 점을 shatter 가능):**

$d$차원 선형 분류기의 VC 차원은 $d+1$이다. 이를 보이기 위해 "일반적 위치(general position)"에 있는 4개의 점을 사용한다.

$x_1 = (1,0,0)$, $x_2 = (0,1,0)$, $x_3 = (0,0,1)$, 원점에 가까운 $x_0 = (0,0,0)$

이 4개의 점에 대한 $2^4 = 16$가지 라벨링 각각에 대해, $w \in \mathbb{R}^3$과 $b \in \mathbb{R}$를 적절히 선택하면 $\text{sign}(w^\top x_i + b)$로 해당 라벨링을 실현할 수 있다.

**VC ≤ 4 (5개의 점은 shatter 불가):**

Radon의 정리에 의해, $\mathbb{R}^d$에서 $d+2$개의 점은 항상 두 집합으로 나뉘어 그 볼록 껍질(convex hull)이 교차한다. 볼록 껍질이 교차하는 두 집합을 초평면으로 분리할 수 없으므로, 해당 라벨링은 실현 불가능하다.

따라서 VC(3차원 선형 분류기) = 3 + 1 = 4.

</details>

**문제 2.** PAC-Bayes 바운드에서 사전 분포 $P$를 $\mathcal{N}(0, \sigma^2 I)$로, 사후 분포 $Q$를 $\mathcal{N}(w^*, \sigma'^2 I)$로 놓았을 때, $\text{KL}(Q \| P)$를 계산하라. 이것이 L2 정규화와 어떻게 연결되는지 설명하라.

<details>
<summary>풀이 보기</summary>

두 다변량 가우시안 간의 KL 발산:

$$\text{KL}(\mathcal{N}(\mu_1, \Sigma_1) \| \mathcal{N}(\mu_2, \Sigma_2)) = \frac{1}{2}\left[\text{tr}(\Sigma_2^{-1}\Sigma_1) + (\mu_2-\mu_1)^\top \Sigma_2^{-1}(\mu_2-\mu_1) - d + \ln\frac{|\Sigma_2|}{|\Sigma_1|}\right]$$

$P = \mathcal{N}(0, \sigma^2 I)$, $Q = \mathcal{N}(w^*, \sigma'^2 I)$를 대입하면:

$$\text{KL}(Q \| P) = \frac{d}{2}\left(\frac{\sigma'^2}{\sigma^2} - 1 - \ln\frac{\sigma'^2}{\sigma^2}\right) + \frac{\|w^*\|^2}{2\sigma^2}$$

$\sigma' = \sigma$이면 (사전/사후의 분산이 같으면):

$$\text{KL}(Q \| P) = \frac{\|w^*\|^2}{2\sigma^2}$$

이것은 $w^*$의 L2 노름의 제곱에 비례한다! 즉 PAC-Bayes 바운드를 최소화하는 것은 학습 오차를 줄이면서 동시에 $\|w\|^2$을 줄이는 것 — 이것이 바로 L2 정규화 (Ridge 회귀, Weight Decay)의 구조와 동일하다.

**결론**: L2 정규화는 "사전 분포가 원점 중심 가우시안"이라는 베이즈적 가정 하에서 PAC-Bayes 바운드를 최적화하는 것과 동등하다.

</details>

**문제 3.** No Free Lunch 정리가 성립함에도 불구하고, 딥러닝이 다양한 과제에서 잘 작동하는 이유를 "현실 세계 데이터의 구조"와 "귀납 편향"의 관점에서 논하라.

<details>
<summary>풀이 보기</summary>

NFL 정리는 **모든 가능한 목표 함수의 균등 분포** 하에서 성립한다. 하지만 현실 세계는 이런 극단적 상황이 아니다.

1. **현실 데이터의 구조**: 자연에서 발생하는 데이터는 무작위가 아니다. 이미지는 지역적 상관관계를 가지고, 언어는 문법적 구조를 따르며, 물리 시스템은 미분방정식을 따른다. 이러한 구조는 "모든 가능한 함수" 중 극히 일부에 해당한다.

2. **딥러닝의 귀납 편향**:
   - 계층적 표현 학습: 저수준 특징 → 고수준 개념으로의 구성적 구조
   - 매끄러운 함수 선호: SGD가 자연스럽게 매끄러운 결정 경계를 찾는 경향
   - 암묵적 정규화: SGD의 노이즈, 배치 정규화 등이 과적합을 억제

3. **전이 학습과 사전 학습**: 대규모 데이터로 사전 학습된 모델은 "자연의 일반적 패턴"을 이미 인코딩하고 있으므로, 새로운 문제에서도 적은 데이터로 잘 작동한다.

핵심: NFL 정리는 "어떤 사전 가정도 없이는 학습이 불가능하다"는 점을 강조하며, 딥러닝은 현실 데이터의 구조와 잘 맞는 귀납 편향을 가지고 있기 때문에 성공적이다.
