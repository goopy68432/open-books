## 1. 집합 — "분류의 출발점"

### 1.1 집합은 왜 배우는가?

딥러닝에서 가장 먼저 하는 일은 **데이터를 분류**하는 것이다. "고양이 사진의 집합", "강아지 사진의 집합"처럼 데이터를 그룹으로 나누는 행위 자체가 집합이다.

- 학습 데이터 전체 = 하나의 큰 집합
- 각 클래스(고양이, 강아지, 새) = 부분집합
- "이 사진은 고양이인가?" = 원소가 특정 부분집합에 속하는가? (∈)

### 1.2 집합 연산의 실생활 예시

| 연산 | 일상 비유 | 딥러닝 비유 |
|------|-----------|-------------|
| 합집합 A ∪ B | A반 학생 + B반 학생 전체 | 학습 데이터 + 검증 데이터 합치기 |
| 교집합 A ∩ B | A반이면서 동시에 축구부인 학생 | 두 모델이 모두 "고양이"로 예측한 이미지 |
| 차집합 A \ B | A반 학생 중 축구부가 아닌 학생 | 전체 데이터에서 이상치(outlier) 제거 |
| 여집합 Aᶜ | 전교생 중 A반이 아닌 학생 | "고양이가 아닌" 모든 것 |

### 1.3 카테시안 곱 — "데이터 쌍 만들기"

카테시안 곱을 가장 쉽게 이해하는 방법은 **엑셀 표**를 떠올리는 것이다.

```
행(입력): {이미지1, 이미지2, 이미지3}
열(라벨): {고양이, 강아지}

가능한 모든 조합:
┌────────┬────────┬────────┐
│        │ 고양이  │ 강아지  │
├────────┼────────┼────────┤
│ 이미지1 │ (1,고) │ (1,강) │
│ 이미지2 │ (2,고) │ (2,강) │
│ 이미지3 │ (3,고) │ (3,강) │
└────────┴────────┴────────┘

이 표 전체 = 입력 집합 × 라벨 집합 (카테시안 곱)
실제 정답 데이터 = 이 표의 일부분 (부분집합)
```

**핵심 통찰**: 머신러닝의 지도학습(supervised learning) 데이터셋은 **입력 공간 X와 출력 공간 Y의 카테시안 곱 X × Y의 부분집합**이다.

## 2. 함수 — "기계의 작동 원리"

### 2.1 함수를 왜 배우는가?

**신경망 = 아주 복잡한 함수**이다. 이 한 문장이 딥러닝의 핵심이다.

```
                ┌──────────────┐
고양이 이미지 ─→│  신경망 f(x)  │─→ "고양이" (확률 0.95)
                └──────────────┘

f: 이미지 공간 → 라벨 공간
```

함수의 세 가지 핵심 질문:
1. **입력은 무엇인가?** (정의역) → 이미지, 텍스트, 숫자 등
2. **출력은 무엇인가?** (공역) → 분류 라벨, 예측 숫자 등
3. **어떤 규칙으로 변환하는가?** → 가중치와 활성화 함수로 결정

### 2.2 함수가 아닌 것 — 왜 중요한가?

신경망이 "함수"여야 하는 이유: **같은 입력에 항상 같은 출력**을 내야 예측 가능하기 때문이다.

```
좋은 모델 (함수):
  같은 고양이 사진 → 항상 "고양이" 예측   ✓

나쁜 모델 (함수 아님):
  같은 고양이 사진 → 어떤 때는 "고양이", 어떤 때는 "자동차"   ✗
```

> 참고: 실제로는 dropout 같은 확률적 요소가 있지만, 이는 학습 시에만 사용하고 추론(inference) 시에는 결정적(deterministic) 함수로 동작한다.

### 2.3 지시 함수 — "채점기"

지시 함수는 **Yes/No 판정기**이다. 딥러닝에서 모델이 맞았는지 틀렸는지 세는 가장 기본적인 도구이다.

```
시험 채점 과정:

문제1: 정답=A, 내답=A → 1(맞음) = 1점
문제2: 정답=B, 내답=C → 1(맞음) = 0점
문제3: 정답=C, 내답=C → 1(맞음) = 1점
문제4: 정답=A, 내답=B → 1(맞음) = 0점

정확도 = (1+0+1+0) / 4 = 50%
```

## 3. 스칼라와 벡터 — "숫자 하나 vs 숫자 묶음"

### 3.1 직관적 비교

```
스칼라: 체온계 → "36.5도"  (숫자 하나)
벡터:  혈액검사 → [백혈구 5200, 적혈구 480만, 혈소판 25만]  (숫자 여러 개)
```

| 구분 | 스칼라 | 벡터 |
|------|--------|------|
| 정보량 | 1개의 숫자 | n개의 숫자 |
| 방향 | 없음 | 있음 |
| 예시 | 온도, 무게, 점수 | 좌표, 속도, 성적표 |
| 딥러닝 예시 | 학습률, 손실값 | 입력 데이터, 가중치 벡터 |

### 3.2 벡터 연산을 그림으로 이해하기

**벡터 덧셈 = 이동의 연결**

```
v = [3, 1]: 오른쪽 3, 위로 1
w = [1, 2]: 오른쪽 1, 위로 2

v + w = [4, 3]: 오른쪽 4, 위로 3

    3 ·─────────────→ · (4, 3)
      ↑              ╱ ↑
      │ w           ╱  │
      │            ╱   │ w
      · ─────────→·    │
    (0,0)   v    (3,1)
```

**스칼라 곱 = 늘리기/줄이기**

```
v = [2, 1]
2v = [4, 2]   ← 같은 방향으로 2배 길어짐
-v = [-2, -1] ← 반대 방향으로 뒤집힘
0.5v = [1, 0.5] ← 같은 방향으로 반으로 줄어듦
```

### 3.3 내적(Dot Product)을 직관적으로 이해하기

**내적 = "두 벡터가 얼마나 같은 방향을 가리키는가"**

```
같은 방향 (내적 > 0):     반대 방향 (내적 < 0):    수직 (내적 = 0):
  →  →                      →  ←                     →
                                                      ↑
"취향이 비슷해!"           "취향이 정반대야!"        "완전히 다른 관심사!"
```

실생활 예시 — 영화 추천:

```
사용자A 취향 벡터: [액션=5, 로맨스=1, 공포=3]
사용자B 취향 벡터: [액션=4, 로맨스=2, 공포=4]
사용자C 취향 벡터: [액션=1, 로맨스=5, 공포=1]

A·B = 5×4 + 1×2 + 3×4 = 20+2+12 = 34  ← 높음! (취향 비슷)
A·C = 5×1 + 1×5 + 3×1 = 5+5+3 = 13   ← 낮음 (취향 다름)

→ 사용자 A에게 B가 좋아한 영화를 추천!
```

> 목표: 정의를 정확히 이해하고, 딥러닝과의 연결을 증명 수준에서 파악하기

## 1. 집합론 심화

### 1.1 무한 집합과 가산/비가산

딥러닝에서 다루는 데이터 공간의 크기를 이해하려면 무한 집합의 개념이 필요하다.

| 집합 | 기호 | 가산성 | 크기 |
|------|------|--------|------|
| 자연수 | ℕ = {1, 2, 3, ...} | 가산 무한 | ℵ₀ |
| 정수 | ℤ = {..., -1, 0, 1, ...} | 가산 무한 | ℵ₀ |
| 유리수 | ℚ | 가산 무한 | ℵ₀ |
| 실수 | ℝ | **비가산 무한** | 2^ℵ₀ |

**왜 중요한가?**
- 딥러닝의 입력 공간 ℝⁿ은 비가산 무한이다
- 학습 데이터는 유한개 → 무한한 공간을 유한한 데이터로 학습하는 것이 딥러닝의 근본 과제
- 이것이 **일반화(generalization)** 문제의 수학적 근원이다

### 1.2 멱집합 (Power Set)

> 집합 A의 **멱집합** P(A)는 A의 모든 부분집합의 집합이다.
> |P(A)| = 2^|A|

```
A = {1, 2, 3}
P(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}
|P(A)| = 2³ = 8
```

**딥러닝 연결**: 특성(feature) n개가 있을 때, 가능한 특성 조합의 수는 2ⁿ개이다. 이것이 **특성 선택(feature selection)** 이 NP-hard 문제인 이유이다.

### 1.3 카테시안 곱의 일반화 — 고차원 데이터

n번의 카테시안 곱으로 고차원 공간을 정의한다:

```
ℝ¹ = ℝ                    ← 수직선 (1차원)
ℝ² = ℝ × ℝ               ← 평면 (2차원)
ℝ³ = ℝ × ℝ × ℝ           ← 공간 (3차원)
ℝⁿ = ℝ × ℝ × ... × ℝ     ← n차원 공간
     └─── n번 ──────┘
```

**실전 예시**:
- MNIST 이미지 (28×28 픽셀) → ℝ⁷⁸⁴의 한 점
- RGB 컬러 이미지 (224×224×3) → ℝ¹⁵⁰⁵²⁸의 한 점
- GPT의 토큰 임베딩 → ℝ¹²²⁸⁸의 한 점 (GPT-4 기준)

## 2. 함수의 분류 체계

### 2.1 단사(Injective), 전사(Surjective), 전단사(Bijective)

```
단사 (일대일):                전사 (위에의):              전단사 (일대일 대응):
A     B                     A     B                     A     B
1 ──→ a                     1 ──→ a                     1 ──→ a
2 ──→ b                     2 ──┐                       2 ──→ b
3 ──→ c                     3 ──┘ b                     3 ──→ c
      d (빈 곳 있음)              c (빈 곳 없음)

서로 다른 입력 →               공역의 모든 원소에             단사 + 전사
서로 다른 출력                 대응되는 입력 존재             = 역함수 존재!
```

| 성질 | 정의 | 딥러닝 의미 |
|------|------|-------------|
| 단사(Injective) | f(a)=f(b) → a=b | 정보 손실 없음 |
| 전사(Surjective) | ∀b∈B, ∃a: f(a)=b | 출력 공간 전체 커버 |
| 전단사(Bijective) | 단사 + 전사 | **역함수가 존재** |

### 2.2 역함수와 딥러닝

전단사 함수만이 역함수를 가진다. 이것이 **생성 모델** 설계의 핵심 제약이다.

```
Normalizing Flows (정규화 흐름):

잡음 z ~ N(0, I)  ──[f₁]──→ ──[f₂]──→ ... ──[fₖ]──→  이미지 x

각 fᵢ가 전단사(bijective) 함수!
→ 역함수 fᵢ⁻¹가 존재
→ x에서 z로 되돌아갈 수 있음
→ 정확한 확률 밀도 계산 가능 (변수 변환 공식)
```

**변수 변환 공식** (전단사 함수가 필요한 이유):
```
p(x) = p(z) × |det(∂z/∂x)|

여기서 z = f⁻¹(x)이며, 역함수 f⁻¹가 존재해야 이 공식을 쓸 수 있다.
```

### 2.3 합성 함수 — 심층 신경망의 수학적 표현

> (g ∘ f)(x) = g(f(x))

**심층 신경망 = 함수의 합성**

```
입력 x
  → f₁(x) = σ(W₁x + b₁)           ← 1층
  → f₂(f₁(x)) = σ(W₂f₁(x) + b₂)  ← 2층
  → f₃(f₂(f₁(x)))                  ← 3층

전체 신경망 = f₃ ∘ f₂ ∘ f₁

여기서:
  Wᵢ = 가중치 행렬
  bᵢ = 편향 벡터
  σ  = 활성화 함수 (ReLU, sigmoid 등)
```

### 2.4 지시 함수의 확장 — 손실 함수로의 진화

**문제: 0-1 Loss는 미분 불가능**

```
0-1 Loss: L = 1(예측 ≠ 정답)

이 함수의 그래프:

L │  1 ──────       ──────
  │         │      │
  │         │ 0    │
  └─────────┴──────┴──────→ 예측값
            정답

문제점: 꺾이는 점에서 미분이 안 됨 → 경사하강법 사용 불가!
```

**해결: 대리 손실 함수 (Surrogate Loss)**

0-1 Loss를 미분 가능한 함수로 대체한다:

| 대리 손실 | 수식 | 특징 |
|-----------|------|------|
| Cross-Entropy | -Σ yᵢ log(ŷᵢ) | 분류 문제의 표준 손실 |
| Hinge Loss | max(0, 1 - y·ŷ) | SVM에서 사용 |
| MSE | (1/n)Σ(yᵢ - ŷᵢ)² | 회귀 문제의 표준 손실 |

**Cross-Entropy에서의 지시 함수 역할**:

```
다중 클래스 분류의 Cross-Entropy:

L = -Σⱼ 1(정답=j) × log(P(클래스=j))

여기서 1(정답=j)는 one-hot 인코딩을 생성하는 지시 함수이다:

정답이 "고양이"(클래스 2)일 때:
  1(정답=1) = 0  (강아지)
  1(정답=2) = 1  (고양이) ← 이것만 살아남음
  1(정답=3) = 0  (새)

→ L = -log(P(고양이))  ← 고양이일 확률이 높을수록 손실이 작아짐
```

## 3. 벡터 공간의 엄밀한 구조

### 3.1 벡터 공간의 공리 (8가지)

벡터 공간 V는 덧셈과 스칼라 곱에 대해 다음 8가지 공리를 만족해야 한다:

**덧셈에 대한 4가지 공리:**

| # | 공리 | 수식 | 의미 |
|---|------|------|------|
| 1 | 교환법칙 | u + v = v + u | 순서 바꿔도 같다 |
| 2 | 결합법칙 | (u + v) + w = u + (v + w) | 묶는 순서 무관 |
| 3 | 영벡터 존재 | ∃**0**: v + **0** = v | 더해도 변하지 않는 원소 |
| 4 | 역원 존재 | ∃(-v): v + (-v) = **0** | 빼면 0이 되는 원소 |

**스칼라 곱에 대한 4가지 공리:**

| # | 공리 | 수식 | 의미 |
|---|------|------|------|
| 5 | 스칼라 결합법칙 | a(bv) = (ab)v | 스칼라 곱의 순서 무관 |
| 6 | 분배법칙 1 | a(u + v) = au + av | 벡터 합에 대해 분배 |
| 7 | 분배법칙 2 | (a + b)v = av + bv | 스칼라 합에 대해 분배 |
| 8 | 항등원 | 1·v = v | 1을 곱하면 그대로 |

### 3.2 노름의 종류 — L1, L2, L∞

교재에서 배운 L2 노름 외에도 여러 노름이 있다:

```
v = [3, -4] 일 때:

L1 노름 (맨해튼 거리):
  ‖v‖₁ = |3| + |-4| = 7
  → 격자 도로를 따라 가는 거리

L2 노름 (유클리드 거리):
  ‖v‖₂ = √(3² + 4²) = 5
  → 직선 거리 (가장 흔히 사용)

L∞ 노름 (최대값 노름):
  ‖v‖∞ = max(|3|, |-4|) = 4
  → 가장 큰 성분의 절대값

Lp 노름 (일반화):
  ‖v‖ₚ = (Σ|vᵢ|ᵖ)^(1/p)
```

**시각적 비교** — "노름이 1인 점들의 집합" (단위 원):

```
  L1 (마름모)      L2 (원)        L∞ (정사각형)
      ◇              ○               □
     ╱ ╲            ╱   ╲          ┌─────┐
    ╱   ╲          │     │         │     │
   ◇     ◇        ○     ○        │     │
    ╲   ╱          │     │         │     │
     ╲ ╱            ╲   ╱          └─────┘
      ◇              ○
```

### 3.3 노름과 딥러닝 정규화

| 노름 | 정규화 이름 | 효과 | 수식 |
|------|------------|------|------|
| L1 | Lasso | 가중치를 **0으로** 만듦 (희소성) | λΣ\|wᵢ\| |
| L2 | Ridge / Weight Decay | 가중치를 **작게** 만듦 | λΣwᵢ² |
| L1+L2 | Elastic Net | 둘의 장점 결합 | λ₁Σ\|wᵢ\| + λ₂Σwᵢ² |

```
L1 정규화 효과:          L2 정규화 효과:
w = [0.5, 0, 0, 0.3]    w = [0.2, 0.1, 0.15, 0.1]
→ 많은 가중치가 0!       → 모든 가중치가 작아짐
→ 특성 선택 효과          → 과적합 방지
```

### 3.4 코사인 유사도 — 내적의 정규화

> cos(θ) = ⟨v, w⟩ / (‖v‖ · ‖w‖)

내적을 두 벡터의 노름으로 나누면 **-1 ~ 1 범위의 유사도** 를 얻는다.

```
cos(θ) = 1    → 완전히 같은 방향
cos(θ) = 0    → 수직 (무관)
cos(θ) = -1   → 완전히 반대 방향
```

**단어 임베딩에서의 활용** (Word2Vec, GloVe):

```
"왕" 벡터:   v_king   = [0.8, 0.2, 0.9, ...]
"여왕" 벡터: v_queen  = [0.75, 0.7, 0.85, ...]
"남자" 벡터: v_man    = [0.9, 0.1, 0.2, ...]
"여자" 벡터: v_woman  = [0.85, 0.6, 0.15, ...]

유명한 관계:
  v_king - v_man + v_woman ≈ v_queen

코사인 유사도:
  cos(v_king, v_queen) ≈ 0.85  (높은 유사도)
  cos(v_king, v_car)   ≈ 0.05  (낮은 유사도)
```

### 3.5 직교의 응용 — PCA와 차원 축소

**PCA(주성분 분석)**: 데이터를 직교하는 축으로 분해하여 가장 정보가 많은 축만 남기는 기법.

```
원본 데이터 (2D):             PCA 후 (1D):
  y                            PC1 방향
  │    · ·  · ·               ─────────────→
  │  ·  · ·  ·                 (분산이 가장 큰 방향으로 투영)
  │ ·  ·  ·
  └────────────→ x

PC1 ⊥ PC2 (두 주성분은 항상 직교)
→ 각 주성분이 독립적인 정보를 담는다
```

## 4. 유클리드 공간 계층 구조 심화

### 4.1 각 공간 간의 관계 증명

```
내적 공간 ⊂ 노름 공간 ⊂ 거리 공간
```

**내적 → 노름**: ‖v‖ := √⟨v, v⟩ 로 노름을 유도

**노름 → 거리**: d(v, w) := ‖v - w‖ 로 거리를 유도

**역방향은 성립하지 않는다**:
- 모든 거리 공간이 노름 공간인 것은 아니다
- 모든 노름 공간이 내적 공간인 것은 아니다

**판별법 — 평행사변형 법칙**:

노름 공간이 내적 공간이 되려면 평행사변형 법칙을 만족해야 한다:

```
‖u + v‖² + ‖u - v‖² = 2(‖u‖² + ‖v‖²)

L2 노름: 만족 ✓ → 내적 공간
L1 노름: 불만족 ✗ → 내적 공간이 아님
L∞ 노름: 불만족 ✗ → 내적 공간이 아님
```

### 4.2 완비성과 힐베르트 공간

```
내적 공간 + 완비성 = 힐베르트 공간 (Hilbert Space)
노름 공간 + 완비성 = 바나흐 공간 (Banach Space)

완비성: "수열의 극한이 항상 같은 공간 안에 존재"
```

| 공간 | 예시 | 완비? |
|------|------|-------|
| ℝⁿ (유클리드 공간) | [1, 2, 3] ∈ ℝ³ | ✓ 힐베르트 공간 |
| ℓ² (제곱합 수렴 수열) | [1, 1/2, 1/4, ...] | ✓ 힐베르트 공간 |
| 유리수 ℚ | 1, 1.4, 1.41, ... → √2 ∉ ℚ | ✗ 불완비 |

## 1. 집합론의 고급 응용

### 1.1 데이터 매니폴드 가설 (Manifold Hypothesis)

현실의 고차원 데이터는 실제로는 **저차원 매니폴드(다양체)** 위에 놓여 있다는 가설이다.

```
ℝ⁷⁸⁴ (28×28 이미지 공간)

이 공간의 거의 모든 점은 "의미 있는 이미지"가 아니다.
실제 손글씨 이미지는 이 거대한 공간의 아주 작은 부분집합,
약 10~20차원 정도의 매니폴드 위에 존재한다.

고차원 공간 ℝ⁷⁸⁴
  ┌─────────────────────────────┐
  │                             │
  │      ╭─── 실제 이미지들 ───╮ │
  │     ╱   (저차원 매니폴드)    ╲│
  │    ╱                          ╲
  │   ╲                          ╱│
  │    ╲                        ╱ │
  │     ╰──────────────────────╯  │
  │                             │
  └─────────────────────────────┘
```

**딥러닝 연결**:
- 오토인코더(Autoencoder)는 이 매니폴드의 좌표계를 학습한다
- GAN은 저차원 잡음 공간에서 매니폴드 위의 점으로 매핑하는 함수를 학습한다
- VAE는 매니폴드의 확률적 구조까지 학습한다

### 1.2 측도론과 확률 공간

고급 확률론에서 집합론은 **측도 공간** (Ω, F, P)으로 확장된다:

```
Ω = 표본 공간 (모든 가능한 결과의 집합)
F = σ-대수 (사건의 집합, Ω의 부분집합들의 모임)
P = 확률 측도 (F 위의 함수, P: F → [0, 1])
```

딥러닝에서의 적용:
- **확률적 경사하강법(SGD)**: 미니배치 선택이 확률 공간 위의 확률 변수
- **생성 모델**: 잠재 공간의 확률 분포를 데이터 공간으로 변환
- **베이지안 딥러닝**: 가중치 자체가 확률 분포

## 2. 함수의 고급 이론

### 2.1 범함수 (Functional)와 변분법

> 범함수: 함수를 입력으로 받아 스칼라를 출력하는 "함수의 함수"

```
일반 함수:  f: ℝ → ℝ         (숫자 → 숫자)
범함수:    J: {함수} → ℝ      (함수 → 숫자)

딥러닝 예시:
  손실 함수 L(f) = (1/N) Σ (f(xᵢ) - yᵢ)²

  여기서 f는 신경망 함수이고, L은 f를 입력받아 스칼라(손실값)를 출력하는 범함수이다.
```

**변분법의 핵심 질문**: "L(f)를 최소화하는 최적의 함수 f*는 무엇인가?"

→ 이것이 바로 딥러닝 학습의 수학적 형식화이다:

```
f* = argmin_f L(f) = argmin_f (1/N) Σ (f(xᵢ) - yᵢ)²
```

### 2.2 리프시츠 연속 함수와 학습 안정성

> f가 **리프시츠 연속**이라 함은: ∃K > 0 s.t. |f(x) - f(y)| ≤ K·‖x - y‖

"입력의 작은 변화가 출력의 큰 변화를 만들지 않는다"

```
리프시츠 상수 K가 작으면:
  입력이 조금 변해도 출력이 조금만 변함 → 안정적

리프시츠 상수 K가 크면:
  입력이 조금 변해도 출력이 급격히 변함 → 불안정
```

**딥러닝 적용**:
- **Spectral Normalization**: 각 층의 리프시츠 상수를 1로 제한 → GAN 학습 안정화
- **Gradient Clipping**: 그래디언트의 노름이 임계값을 넘으면 잘라냄 → 폭발적 그래디언트 방지
- **WGAN (Wasserstein GAN)**: 판별자를 리프시츠 함수로 제한하여 학습 안정성 확보

```
Gradient Clipping 구현 개념:

if ‖∇L‖ > threshold:
    ∇L ← threshold × (∇L / ‖∇L‖)   ← 방향은 유지, 크기만 줄임

이것은 그래디언트 벡터를 단위 벡터로 정규화한 후
threshold를 곱하는 것과 같다!
(교재의 "정규화" 개념이 여기서 사용된다)
```

### 2.3 활성화 함수 — 함수의 합성이 비선형성을 만든다

**왜 비선형 활성화 함수가 필요한가?**

선형 함수의 합성은 여전히 선형이다:

```
f₁(x) = W₁x  (선형)
f₂(x) = W₂x  (선형)

f₂(f₁(x)) = W₂(W₁x) = (W₂W₁)x  ← 여전히 선형!

아무리 층을 깊게 쌓아도 하나의 선형 변환과 같다.
→ XOR 같은 간단한 문제도 풀 수 없다.
```

활성화 함수를 추가하면:

```
f₁(x) = σ(W₁x + b₁)  (비선형!)
f₂(x) = σ(W₂x + b₂)  (비선형!)

f₂(f₁(x)) ≠ (어떤 단일 선형 변환)
→ 임의의 복잡한 함수를 근사할 수 있다 (만능 근사 정리)
```

**주요 활성화 함수와 수학적 성질**:

| 함수 | 정의 | 미분 | 특징 |
|------|------|------|------|
| ReLU | max(0, x) | 1(x>0) ← **지시함수!** | 가장 많이 사용, 계산 빠름 |
| Sigmoid | 1/(1+e⁻ˣ) | σ(x)(1-σ(x)) | 출력이 (0,1), 확률 해석 |
| tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 1-tanh²(x) | 출력이 (-1,1), 중심 대칭 |
| GELU | x·Φ(x) | Φ(x)+x·φ(x) | 트랜스포머에서 사용 |

> 주목: **ReLU의 미분이 바로 지시 함수 1(x>0)** 이다! 교재에서 배운 지시 함수가 여기서 직접 등장한다.

## 3. 벡터의 고급 이론

### 3.1 텐서 — 벡터의 일반화

스칼라, 벡터, 행렬은 모두 **텐서(tensor)** 의 특수한 경우이다:

```
텐서 계층:

0차 텐서 = 스칼라     예: 3.14
1차 텐서 = 벡터       예: [1, 2, 3]
2차 텐서 = 행렬       예: [[1,2],[3,4]]
3차 텐서 = 큐브       예: RGB 이미지 [높이 × 너비 × 채널]
4차 텐서 = 배치       예: [배치크기 × 높이 × 너비 × 채널]
```

**PyTorch/TensorFlow에서**:

```python
import torch

scalar = torch.tensor(3.14)           # 0차: 스칼라
vector = torch.tensor([1, 2, 3])      # 1차: 벡터
matrix = torch.tensor([[1,2],[3,4]])   # 2차: 행렬
image  = torch.randn(3, 224, 224)     # 3차: RGB 이미지
batch  = torch.randn(32, 3, 224, 224) # 4차: 배치 이미지
```

### 3.2 내적의 일반화 — 어텐션 메커니즘

트랜스포머의 **Self-Attention**은 내적을 핵심으로 사용한다:

```
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) V

여기서:
  Q = Query 행렬 (질문)
  K = Key 행렬 (열쇠)
  V = Value 행렬 (값)
  dₖ = Key 차원 (스케일링 인자)

QKᵀ의 (i,j) 원소 = ⟨qᵢ, kⱼ⟩ = i번째 쿼리와 j번째 키의 내적
→ 내적이 클수록 "관련성이 높다"
→ softmax로 확률로 변환
→ 관련성이 높은 값(V)에 더 많은 가중치
```

**Scaled Dot-Product**: √dₖ로 나누는 이유

```
dₖ가 크면 내적 값이 커짐 (각 성분의 곱의 합이므로)
→ softmax가 하나의 값에 집중 (vanishing gradient)
→ √dₖ로 나눠서 분산을 1로 유지
```

### 3.3 직교 초기화와 학습 안정성

가중치 행렬을 직교 행렬로 초기화하면 학습이 안정적이다:

```
직교 행렬 W의 성질:
  WᵀW = WWᵀ = I (단위 행렬)

이것이 의미하는 것:
  ‖Wx‖ = ‖x‖  (벡터의 크기가 보존됨!)

층을 지날 때마다:
  직교 초기화: ‖x‖ → ‖Wx‖ = ‖x‖ → ‖W²x‖ = ‖x‖  (안정적)
  랜덤 초기화: ‖x‖ → ‖Wx‖ → 폭발 또는 소멸 가능    (불안정)
```

### 3.4 거리의 일반화 — 다양한 거리 함수

| 거리 함수 | 수식 | 용도 |
|-----------|------|------|
| 유클리드 거리 (L2) | √Σ(vᵢ-wᵢ)² | KNN, 클러스터링 |
| 맨해튼 거리 (L1) | Σ\|vᵢ-wᵢ\| | 희소 데이터 |
| 코사인 거리 | 1 - cos(v,w) | 텍스트 유사도 |
| 마할라노비스 거리 | √((v-w)ᵀS⁻¹(v-w)) | 공분산 고려 |
| Wasserstein 거리 | inf E[‖X-Y‖] | WGAN |
| KL 다이버전스 | Σ p(x)log(p(x)/q(x)) | VAE (엄밀히 거리 아님) |

**Wasserstein 거리와 WGAN**:

```
기존 GAN: JS 다이버전스 사용 → 학습 불안정
WGAN: Wasserstein 거리 사용 → 학습 안정화

Wasserstein 거리 (Earth Mover's Distance):
"한 분포를 다른 분포로 변환하는 데 필요한 최소 이동량"

비유: 모래더미 p를 모래더미 q 모양으로 만들기 위해
옮겨야 하는 모래의 총량 × 이동 거리
```

### 고급 레벨

**Q3.** 2차원 공간에서 ReLU 활성화 함수 σ(x) = max(0, x)를 성분별로 적용하는 함수 f(v) = σ(Wv)가 있다. W = [[1, -1], [1, 1]]일 때:
- (a) 입력 v = [2, 1]ᵀ에 대한 출력을 구하시오.
- (b) 입력 v = [-1, -2]ᵀ에 대한 출력을 구하시오.
- (c) 이 함수가 단사(injective)인지 논하시오.

<details>
<summary>풀이</summary>

**(a)**
Wv = [[1,-1],[1,1]] × [2,1]ᵀ = [2-1, 2+1]ᵀ = [1, 3]ᵀ
σ([1, 3]ᵀ) = [max(0,1), max(0,3)]ᵀ = **[1, 3]ᵀ**

**(b)**
Wv = [[1,-1],[1,1]] × [-1,-2]ᵀ = [-1+2, -1-2]ᵀ = [1, -3]ᵀ
σ([1, -3]ᵀ) = [max(0,1), max(0,-3)]ᵀ = **[1, 0]ᵀ**

**(c)** 단사가 아니다. 반례: v₁ = [0, -1]ᵀ, v₂ = [0, -2]ᵀ
- Wv₁ = [0+1, 0-1]ᵀ = [1, -1]ᵀ → σ = [1, 0]ᵀ
- Wv₂ = [0+2, 0-2]ᵀ = [2, -2]ᵀ → σ = [2, 0]ᵀ

다른 반례: ReLU는 음수를 모두 0으로 만들므로, Wv의 음수 성분이 다르더라도 같은 출력을 낼 수 있다. 예를 들어 Wv₁ = [0, -1]ᵀ과 Wv₂ = [0, -5]ᵀ는 모두 σ → [0, 0]ᵀ이 되어 서로 다른 입력이 같은 출력을 만든다. 따라서 **단사가 아니다**. ReLU의 정보 손실 특성이 이를 야기한다.

</details>
