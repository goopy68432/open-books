# 1. 입문 (Beginner)

> 목표: 선형대수의 핵심 개념을 직관적으로 이해하고, 딥러닝에서 왜 필요한지 감을 잡는다.

## 1.1 벡터와 행렬: 직관적 이해

### 벡터란 무엇인가?

벡터를 이해하는 세 가지 관점이 있다:

1. **물리학적 관점**: 방향과 크기를 가진 화살표. 2D 평면에서 오른쪽으로 3, 위로 4 이동하면 `[3, 4]` 벡터.
2. **컴퓨터과학적 관점**: 숫자의 나열(리스트). 집 가격을 예측할 때 `[면적, 방 수, 층수]` = `[85, 3, 5]`.
3. **수학적 관점**: 덧셈과 스칼라 곱이 정의된 추상적 객체.

**딥러닝에서의 의미**: 신경망의 모든 데이터는 벡터로 표현된다. 이미지 한 장(28x28 픽셀)은 784차원 벡터, 단어 하나는 수백 차원의 임베딩 벡터로 변환된다.

### 행렬이란 무엇인가?

행렬은 숫자를 직사각형으로 배열한 것이지만, 더 중요한 것은 **변환(transformation)**으로 보는 관점이다.

**비유**: 행렬은 "공간을 변형하는 기계"다.
- 2x2 행렬은 2D 평면을 찌그러뜨리거나, 회전시키거나, 뒤집는 변환을 나타낸다.
- 행렬에 벡터를 곱하면(`Ax`), 벡터가 변환된 공간에서의 새 위치로 이동한다.

```
예시: 회전 행렬
[cos(θ)  -sin(θ)] [x]   [x cos(θ) - y sin(θ)]
[sin(θ)   cos(θ)] [y] = [x sin(θ) + y cos(θ)]

→ 벡터 (x, y)를 θ만큼 반시계 방향으로 회전
```

**딥러닝에서의 의미**: 신경망의 각 층(layer)은 본질적으로 행렬 곱셈 + 비선형 활성화 함수다.

```
출력 = 활성화함수(W * 입력 + b)
       ↑ 이 W가 바로 가중치 행렬
```

### 행렬 곱셈의 직관

행렬 곱셈 `AB`는 "변환 B를 먼저 적용하고, 변환 A를 그 다음에 적용한 것"과 같다.

**비유**: 포토샵 필터를 순서대로 적용하는 것. 먼저 흑백 필터(B)를 적용하고, 그 다음 블러 필터(A)를 적용하면, 결과는 `AB`라는 하나의 합성 필터와 같다.

**핵심 성질**:
- `AB ≠ BA` (교환법칙 성립하지 않음) → 필터 적용 순서가 중요한 것과 같다
- `(AB)C = A(BC)` (결합법칙 성립) → 어떤 순서로 묶어 계산해도 결과는 같다

## 1.2 고유값과 고유벡터: 직관적 이해

### 핵심 비유: "흔들리지 않는 방향"

행렬이 공간을 변형시킬 때, 대부분의 벡터는 방향이 바뀐다. 하지만 특별한 벡터들은 **방향은 그대로** 유지된 채 크기만 변한다. 이것이 고유벡터(eigenvector)이고, 크기가 변하는 비율이 고유값(eigenvalue)이다.

```
A * v = λ * v

A: 변환 행렬
v: 고유벡터 (방향이 변하지 않는 특별한 벡터)
λ: 고유값 (크기가 변하는 비율)
```

**일상적 비유**:
- 문을 밀 때, 경첩 축 방향의 힘은 방향이 바뀌지 않는다 → 고유벡터
- 고무줄을 한 방향으로만 당기면, 그 방향의 벡터는 방향이 유지되고 길이만 늘어난다 → 고유값은 늘어난 비율

### 고유값의 의미

| 고유값 λ | 의미 |
|----------|------|
| λ > 1 | 해당 방향으로 늘어남 (확대) |
| 0 < λ < 1 | 해당 방향으로 줄어듦 (축소) |
| λ = 1 | 해당 방향은 변화 없음 |
| λ = 0 | 해당 방향으로 찌그러져서 사라짐 |
| λ < 0 | 해당 방향이 뒤집힘 |

### 딥러닝에서의 의미

- **PCA (주성분 분석)**: 데이터의 공분산 행렬의 고유벡터 = 데이터가 가장 많이 퍼진 방향, 고유값 = 그 방향의 분산 크기
- **가중치 초기화**: 신경망 가중치 행렬의 고유값이 1에 가까워야 기울기 소실/폭발 문제가 줄어든다
- **학습 안정성**: 손실 함수의 헤시안(Hessian) 행렬 고유값으로 학습의 수렴 속도를 판단할 수 있다

## 1.3 SVD (특이값 분해): 직관적 이해

### 핵심 비유: "어떤 변환이든 3단계로 분해할 수 있다"

SVD는 임의의 행렬 `A`를 세 단계의 단순한 변환으로 분해한다:

```
A = U * Σ * V^T

V^T : 1단계 - 회전 (입력 공간에서의 회전)
Σ   : 2단계 - 스케일링 (각 축 방향으로 늘이거나 줄이기)
U   : 3단계 - 회전 (출력 공간에서의 회전)
```

**비유**: 피자 반죽 만들기
1. 반죽을 적절한 방향으로 놓고 (V^T: 회전)
2. 밀대로 한 방향으로 밀어 늘린다 (Σ: 스케일링)
3. 완성된 반죽을 원하는 방향으로 돌린다 (U: 회전)

### 특이값(Singular Values)의 의미

Σ 행렬의 대각선 원소가 특이값이며, 항상 양수이고 큰 순서대로 정렬된다.

- **큰 특이값**: 데이터에서 중요한 패턴/방향
- **작은 특이값**: 노이즈이거나 덜 중요한 정보

### 이미지 압축 예시

1000x1000 이미지를 SVD로 분해하면:
- 원본: 1,000,000개의 숫자 저장 필요
- 상위 50개 특이값만 사용: 1000x50 + 50 + 50x1000 = 100,050개 → **약 10배 압축**
- 눈으로 보기에는 거의 차이가 없다!

### 딥러닝에서의 의미

- **차원 축소**: 고차원 데이터를 저차원으로 압축하여 학습 효율 향상
- **노이즈 제거**: 작은 특이값을 제거하면 노이즈가 줄어든다
- **추천 시스템**: Netflix, YouTube 등의 추천 알고리즘의 핵심 수학

## 1.4 입문 수준 연습 문제

### 문제 1: 행렬-벡터 곱의 기하학적 해석
다음 행렬이 벡터 `[1, 0]`과 `[0, 1]`에 어떤 변환을 수행하는지 기하학적으로 설명하라.
```
A = [2  0]
    [0  3]
```

<details>
<summary>풀이</summary>

- `A * [1, 0]^T = [2, 0]^T`: x축 방향으로 2배 확대
- `A * [0, 1]^T = [0, 3]^T`: y축 방향으로 3배 확대
- 이 행렬은 x축으로 2배, y축으로 3배 늘이는 스케일링 변환이다.
- 고유벡터는 `[1,0]`과 `[0,1]`, 고유값은 2와 3이다.
</details>

### 문제 2: 고유값 직관
2x2 행렬의 고유값이 λ₁=5, λ₂=0.1 일 때, 이 행렬을 100번 반복 적용(A^100)하면 어떤 일이 일어나는지 직관적으로 설명하라.

<details>
<summary>풀이</summary>

- λ₁=5 방향: 5^100 ≈ 10^70 배로 폭발적 확대
- λ₂=0.1 방향: 0.1^100 = 10^(-100)으로 거의 0
- 결과적으로 모든 벡터가 λ₁에 대응하는 고유벡터 방향으로 쏠린다.
- **딥러닝 연결**: 이것이 바로 RNN에서 기울기 폭발/소실이 발생하는 원리이다!
</details>

### 문제 3: SVD 직관
100x100 이미지 행렬의 SVD에서 특이값이 [100, 50, 10, 1, 0.5, 0.01, ...] 일 때, 상위 3개 특이값만 유지하면 원본 정보의 대략 몇 %를 보존하는가?

<details>
<summary>풀이</summary>

- 정보 보존률 ≈ (100² + 50² + 10²) / (100² + 50² + 10² + 1² + 0.5² + 0.01² + ...)
- ≈ (10000 + 2500 + 100) / (10000 + 2500 + 100 + 1 + 0.25 + ...) ≈ 12600 / 12601.25 ≈ 99.99%
- 상위 3개만으로도 거의 모든 정보를 보존할 수 있다.
- 저장 비용: 100x3 + 3 + 3x100 = 603개 숫자 (원본 10,000개 대비 약 6%)
</details>

# 2. 중급 (Intermediate)

> 목표: 수학적 정의와 증명을 이해하고, 실제 계산 방법을 익히며, 딥러닝 알고리즘의 내부를 파악한다.

## 2.1 행렬 분해의 수학적 기초

### 고유값 분해 (Eigendecomposition)

**정의**: n x n 정방행렬 A가 n개의 선형 독립인 고유벡터를 가질 때:

```
A = QΛQ⁻¹

Q: 고유벡터를 열(column)로 배치한 행렬
Λ: 고유값을 대각선에 놓은 대각 행렬
Q⁻¹: Q의 역행렬
```

**대칭 행렬의 특수한 성질** (딥러닝에서 자주 등장):
- 대칭 행렬 `A = A^T`이면 모든 고유값이 실수이다.
- 고유벡터들이 서로 직교한다: `Q^T = Q⁻¹` (직교 행렬)
- 따라서: `A = QΛQ^T` (스펙트럴 분해)

**증명 스케치** (대칭 행렬의 고유값이 실수임):
```
Av = λv 에서 양변에 v의 켤레 전치를 곱하면:
v̄ᵀAv = λ(v̄ᵀv)

A가 대칭이면 v̄ᵀAv는 실수 (증명 가능)
v̄ᵀv = ||v||² > 0 이므로
λ = v̄ᵀAv / ||v||² 는 실수
```

### SVD의 수학적 정의

**정리**: 임의의 m x n 행렬 A에 대해 다음 분해가 항상 존재한다:

```
A = UΣV^T

U: m x m 직교 행렬 (A*A^T의 고유벡터 = 좌특이벡터)
Σ: m x n 대각 행렬 (특이값 σ₁ ≥ σ₂ ≥ ... ≥ 0)
V: n x n 직교 행렬 (A^T*A의 고유벡터 = 우특이벡터)
```

**고유값 분해와의 관계**:
```
A^T * A = (UΣV^T)^T * (UΣV^T) = VΣ^TU^T * UΣV^T = V(Σ^TΣ)V^T
→ A^T*A의 고유값 = σᵢ² (특이값의 제곱)
→ A^T*A의 고유벡터 = V의 열벡터

A * A^T = UΣV^T * (UΣV^T)^T = UΣV^T * VΣ^TU^T = U(ΣΣ^T)U^T
→ A*A^T의 고유값 = σᵢ² (같은 값)
→ A*A^T의 고유벡터 = U의 열벡터
```

**핵심 통찰**: SVD는 고유값 분해를 비정방 행렬(직사각형 행렬)로 일반화한 것이다.

### 절단된 SVD (Truncated SVD)

상위 k개의 특이값만 유지하는 근사:

```
A ≈ A_k = U_k * Σ_k * V_k^T

U_k: m x k (상위 k개 좌특이벡터)
Σ_k: k x k (상위 k개 특이값)
V_k: n x k (상위 k개 우특이벡터)
```

**Eckart-Young 정리**: 랭크-k 근사 중 `A_k`가 Frobenius 노름 의미에서 최적(가장 가까운) 근사이다.

```
||A - A_k||_F = √(σ_{k+1}² + σ_{k+2}² + ... + σ_r²)
```

이것은 SVD를 이용한 차원 축소가 이론적으로 최선임을 보장한다.

## 2.2 행렬의 노름과 조건수

### 행렬 노름

| 노름 | 정의 | 의미 |
|------|------|------|
| Frobenius 노름 | `||A||_F = √(Σᵢⱼ aᵢⱼ²)` | 모든 원소의 제곱합의 제곱근 |
| Spectral 노름 (L2) | `||A||_2 = σ_max` | 최대 특이값 |
| Nuclear 노름 | `||A||_* = Σᵢ σᵢ` | 모든 특이값의 합 |

**딥러닝 연결**:
- Frobenius 노름: 가중치 감쇠(weight decay) 정규화에서 `||W||_F²`를 최소화
- Spectral 노름: Spectral Normalization에서 판별자의 립시츠 상수를 제한
- Nuclear 노름: 저랭크(low-rank) 제약 조건의 볼록 완화(convex relaxation)

### 조건수 (Condition Number)

```
κ(A) = σ_max / σ_min = ||A|| * ||A⁻¹||
```

- κ ≈ 1: 잘 조건화된(well-conditioned) 행렬 → 수치적으로 안정
- κ >> 1: 나쁘게 조건화된(ill-conditioned) 행렬 → 작은 입력 변화에 큰 출력 변화

**딥러닝에서의 의미**: 가중치 행렬의 조건수가 크면 학습이 불안정해진다. Batch Normalization, Layer Normalization 등은 간접적으로 조건수를 줄이는 효과가 있다.

## 2.3 PCA의 수학적 유도

### 단계별 유도

1. **데이터 중심화**: 평균을 빼서 중심이 원점이 되도록 한다.
   ```
   X_centered = X - mean(X)
   ```

2. **공분산 행렬 계산**:
   ```
   C = (1/n) * X_centered^T * X_centered
   ```

3. **고유값 분해**:
   ```
   C = QΛQ^T
   ```
   - Q의 열벡터: 주성분 (데이터가 가장 많이 분산된 방향)
   - Λ의 대각 원소: 각 주성분 방향의 분산

4. **차원 축소**: 상위 k개 주성분만 선택
   ```
   X_reduced = X_centered * Q_k    (n x d → n x k)
   ```

5. **SVD를 이용한 효율적 PCA**:
   ```
   X_centered = UΣV^T 에서
   주성분 = V의 열벡터
   분산 = σᵢ² / n
   투영된 데이터 = UΣ (상위 k열만 선택)
   ```
   → 공분산 행렬을 명시적으로 계산하지 않아도 SVD로 직접 PCA를 수행할 수 있다.

### PCA와 오토인코더의 관계

선형 활성화 함수를 가진 1층 오토인코더는 PCA와 동일한 해를 학습한다:
```
인코더: z = W_enc * x  (d차원 → k차원)
디코더: x̂ = W_dec * z  (k차원 → d차원)
손실: ||x - x̂||²

→ 최적해에서 W_enc의 행들은 상위 k개 주성분의 부분공간을 span한다.
```

비선형 활성화 함수를 사용하면 비선형 차원 축소가 가능하며, 이것이 딥 오토인코더의 핵심 아이디어이다.

## 2.4 행렬 미적분 기초

### Jacobian 행렬

벡터 함수 `f: R^n → R^m`의 야코비안:

```
J = [∂fᵢ/∂xⱼ]    (m x n 행렬)

J[i,j] = ∂f_i / ∂x_j
```

**딥러닝에서의 의미**: 역전파(backpropagation)는 본질적으로 야코비안의 연쇄 곱셈이다.

```
∂L/∂x = (∂L/∂y) * (∂y/∂x) = (∂L/∂y) * J

여기서 J = ∂y/∂x 는 해당 층의 야코비안
```

### Hessian 행렬

스칼라 함수 `f: R^n → R`의 헤시안:

```
H = [∂²f/∂xᵢ∂xⱼ]    (n x n 대칭 행렬)
```

**딥러닝에서의 의미**:
- H의 고유값이 모두 양수 → 극소점 (local minimum)
- 양수와 음수가 혼재 → 안장점 (saddle point)
- 고차원 신경망에서는 안장점이 극소점보다 압도적으로 많다

# 3. 고급 (Advanced)

> 목표: 최신 딥러닝 연구에서 사용되는 선형대수적 도구를 이해하고, 논문을 읽을 수 있는 수준에 도달한다.

## 3.1 텐서와 텐서 분해

### 텐서란?

- 스칼라: 0차 텐서
- 벡터: 1차 텐서
- 행렬: 2차 텐서
- 3차 이상: 고차 텐서

딥러닝에서의 텐서 예시:
```
배치 이미지: (batch_size, channels, height, width) → 4차 텐서
트랜스포머 어텐션: (batch, heads, seq_len, d_k) → 4차 텐서
비디오 데이터: (batch, time, channels, height, width) → 5차 텐서
```

### 텐서 분해 (Tensor Decomposition)

행렬의 SVD를 고차 텐서로 확장한 것:

**CP 분해 (CANDECOMP/PARAFAC)**:
```
T ≈ Σᵢ λᵢ * (aᵢ ⊗ bᵢ ⊗ cᵢ)

3차 텐서를 랭크-1 텐서들의 합으로 분해
```

**Tucker 분해**:
```
T ≈ G ×₁ A ×₂ B ×₃ C

G: 코어 텐서 (작은 크기)
A, B, C: 각 모드의 팩터 행렬
```

**딥러닝 응용**:
- 신경망 가중치 텐서의 압축 (모델 경량화)
- 텐서 분해를 이용한 합성곱 층 가속
- 텐서 네트워크와 양자 컴퓨팅 영감의 신경망 아키텍처

## 3.2 LoRA: 저랭크 적응의 수학적 기반

### 핵심 아이디어

대규모 사전학습 모델의 가중치 행렬 `W₀`를 미세조정할 때, 가중치 변화 `ΔW`가 저랭크(low-rank)라는 가설에 기반한다:

```
W = W₀ + ΔW = W₀ + BA

W₀: d x d 사전학습 가중치 (고정, frozen)
B:  d x r 행렬 (학습 가능)
A:  r x d 행렬 (학습 가능)
r << d (랭크가 매우 작음, 보통 r = 4~64)
```

### SVD와의 연결

ΔW의 SVD를 생각하면:
```
ΔW = UΣV^T

상위 r개 특이값만 유지하면:
ΔW ≈ U_r * Σ_r * V_r^T

이것은 B = U_r * √Σ_r, A = √Σ_r * V_r^T 로 분해한 것과 동일
```

### 최신 변형 (2025)

| 방법 | 핵심 아이디어 |
|------|-------------|
| **LoRA+** | A와 B에 서로 다른 학습률 적용. 이론적 분석에 기반. |
| **LoRA-XS** | 극소 파라미터(r x r 행렬만 학습). SVD 초기화 활용. |
| **CL-LoRA** | 연속 학습(continual learning)을 위한 LoRA. 이전 작업의 특이 부분공간을 보존. |
| **GOAT** | SVD 구조 사전지식 + Mixture-of-Experts를 결합한 적응형 프레임워크. |
| **LoRA-PT** | 텐서 SVD(t-SVD)를 활용하여 3차 텐서로 확장. |

### 수학적 통찰

LoRA가 작동하는 이유에 대한 최신 연구 결과:
- 가중치 업데이트의 **크기(magnitude)**가 수렴을 결정하는 핵심 요인이다
- 저랭크 구조는 본질적으로 업데이트 크기의 상한을 제한한다
- 스펙트럴(SVD 기반) 초기화는 업데이트 크기를 증폭시켜 효과적이지만, 크기 중심(magnitude-driven) 초기화도 동등한 성능을 달성한다

## 3.3 스펙트럴 정규화와 립시츠 연속성

### 립시츠 연속 조건

함수 f가 K-립시츠 연속이란:
```
||f(x₁) - f(x₂)|| ≤ K * ||x₁ - x₂||    (모든 x₁, x₂에 대해)
```

선형 변환 `f(x) = Wx`의 립시츠 상수 = `||W||₂ = σ_max(W)` (최대 특이값)

### Spectral Normalization

GAN(생성적 적대 신경망)의 판별자(discriminator) 안정화:

```
W_SN = W / σ_max(W)

→ 정규화된 가중치의 spectral norm = 1
→ 각 층이 1-립시츠 → 전체 네트워크도 1-립시츠
```

**멱급수 반복(Power Iteration)**으로 σ_max를 효율적으로 근사:
```
반복:
  v ← W^T * u / ||W^T * u||
  u ← W * v / ||W * v||

σ_max ≈ u^T * W * v
```

한 번의 반복만으로도 실용적으로 충분한 근사를 제공한다.

## 3.4 손실 함수 곡면의 기하학

### 헤시안의 스펙트럼 분석

딥러닝 손실 함수 `L(θ)`의 헤시안 `H = ∇²L(θ)`는 수백만 차원이지만, 그 고유값 분포가 학습 동역학을 결정한다:

```
헤시안 스펙트럼의 특징적 구조:
- 소수의 큰 고유값 (날카로운 방향, sharp directions)
- 대부분의 고유값 ≈ 0 (평평한 방향, flat directions)
- 일부 음수 고유값 (안장점 방향)
```

**일반화와의 관계**:
- 날카로운 극소점 (큰 고유값): 일반화 성능이 나쁜 경향
- 평평한 극소점 (작은 고유값): 일반화 성능이 좋은 경향
- SAM(Sharpness-Aware Minimization)은 이 원리를 최적화 알고리즘에 반영

### Fisher 정보 행렬

```
F = E[∇log p(y|x,θ) * ∇log p(y|x,θ)^T]
```

- 자연 경사법(Natural Gradient)에서 사용
- 파라미터 공간의 리만 기하학적 구조를 반영
- K-FAC (Kronecker-Factored Approximate Curvature)은 Fisher 행렬을 크로네커 곱으로 근사하여 효율적 2차 최적화를 구현

## 3.5 어텐션 메커니즘의 선형대수적 해석

### Self-Attention의 행렬 표현

```
Attention(Q, K, V) = softmax(QK^T / √d_k) * V

Q = X * W_Q    (n x d_k)
K = X * W_K    (n x d_k)
V = X * W_V    (n x d_v)
```

**선형대수적 해석**:
- `QK^T`: n x n 유사도 행렬 (모든 토큰 쌍의 관련성)
- `softmax(...)`: 행 단위 정규화 → 가중치 행렬로 변환
- `softmax(...) * V`: 가중 평균 → 각 토큰이 다른 토큰들의 정보를 취합

### 저랭크 어텐션 근사

어텐션 행렬 `softmax(QK^T/√d_k)`는 n x n 크기로 시퀀스 길이에 대해 O(n²) 복잡도를 가진다.

**Linformer**: `QK^T`를 저랭크로 근사
```
Attention ≈ softmax(Q * (E * K)^T / √d_k) * (F * V)

E, F: k x n 투영 행렬 (k << n)
→ O(nk) 복잡도
```

**Linear Attention**: softmax를 제거하고 커널 트릭 적용
```
Attention(Q, K, V) = φ(Q) * (φ(K)^T * V)

결합법칙을 이용하여 φ(K)^T * V를 먼저 계산 → O(nd²) 복잡도
```

## 3.6 무작위 행렬 이론과 신경망 초기화

### Marchenko-Pastur 법칙

무작위 행렬 `X` (m x n, 각 원소 i.i.d., 평균 0, 분산 σ²)의 `(1/n)XX^T`의 고유값 분포:

```
γ = m/n (종횡비)

고유값 범위: [σ²(1 - √γ)², σ²(1 + √γ)²]
```

**딥러닝에서의 의미**:
- Xavier/He 초기화의 이론적 근거
- 학습 전 무작위 가중치의 특이값 분포 예측
- 학습된 가중치의 특이값이 이 분포에서 벗어난 정도 = 모델이 학습한 정보의 양

### Edge of Chaos 이론

깊은 신경망이 학습 가능하려면 입력 신호가 층을 통과할 때 폭발하거나 소멸하지 않아야 한다:

```
가중치 행렬의 특이값 분포가 1 근처에 집중되어야 함
→ 직교 초기화 (Orthogonal Initialization)
→ 가중치 행렬 W를 직교 행렬로 초기화하면 모든 특이값 = 1
```

## 3.7 고급 수준 연습 문제

### 문제 1: LoRA 파라미터 효율성 분석
GPT-2 (d_model = 768)의 어텐션 층 가중치 W_Q, W_K, W_V, W_O를 LoRA (r=8)로 미세조정할 때:
1. 원본 파라미터 수와 LoRA 파라미터 수를 비교하라.
2. 랭크 r의 선택이 표현력에 미치는 영향을 SVD 관점에서 분석하라.

<details>
<summary>풀이</summary>

1. 파라미터 수 비교:
   - 원본: 4 x (768 x 768) = 2,359,296개
   - LoRA: 4 x (768 x 8 + 8 x 768) = 4 x 12,288 = 49,152개
   - 비율: 49,152 / 2,359,296 ≈ 2.08% → **약 48배 절약**

2. SVD 관점 분석:
   - ΔW의 랭크가 r=8로 제한됨 → 특이값 8개만 학습 가능
   - W₀의 고유 차원이 768이므로, r=8은 768차원 공간의 약 1%만 수정
   - 이것이 작동하는 이유: 사전학습된 모델의 미세조정에서 필요한 변화가 실제로 저랭크 부분공간에 집중되어 있기 때문 (intrinsic dimensionality가 낮음)
   - r이 너무 작으면: 표현력 부족 → 과소적합
   - r이 너무 크면: 파라미터 효율성 저하, 과적합 위험 증가
</details>

### 문제 2: Spectral Normalization 증명
가중치 행렬 W에 spectral normalization을 적용한 `W_SN = W / σ_max(W)`이 정확히 1-립시츠임을 증명하라.

<details>
<summary>풀이</summary>

증명:
```
||W_SN * x||₂ = ||W * x / σ_max(W)||₂
              = ||W * x||₂ / σ_max(W)
              ≤ (σ_max(W) * ||x||₂) / σ_max(W)    (spectral norm의 정의)
              = ||x||₂

따라서: ||W_SN * x₁ - W_SN * x₂||₂ = ||W_SN * (x₁ - x₂)||₂ ≤ ||x₁ - x₂||₂

이는 W_SN이 1-립시츠 연속임을 의미한다.

등호 조건: x = v₁ (최대 특이값에 대응하는 우특이벡터)일 때 등호 성립.
```
</details>

### 문제 3: 어텐션의 저랭크 성질
Self-attention에서 `QK^T`가 저랭크인 이유를 `Q = XW_Q`, `K = XW_K`의 관계로 설명하고, 이것이 Linear Attention의 이론적 근거가 되는 이유를 서술하라.

<details>
<summary>풀이</summary>

1. `QK^T = (XW_Q)(XW_K)^T = X * W_Q * W_K^T * X^T`
   - W_Q, W_K: d x d_k 행렬 (d_k << d가 일반적)
   - W_Q * W_K^T: d x d 행렬이지만 랭크 ≤ d_k
   - 따라서 QK^T의 랭크 ≤ min(n, d_k)

2. d_k = 64 (일반적)이고 n = 1024 (시퀀스 길이)이면:
   - 1024 x 1024 어텐션 행렬의 유효 랭크는 최대 64
   - 대부분의 정보가 소수의 특이벡터에 집중

3. Linear Attention과의 연결:
   - QK^T가 저랭크이므로, n x n 어텐션 행렬을 명시적으로 구성하지 않아도 됨
   - φ(Q) * φ(K)^T로 근사하고, 결합법칙을 적용하면:
     `φ(Q) * (φ(K)^T * V)` → d_k x d_v 크기의 중간 행렬만 필요
   - 복잡도: O(n * d_k * d_v) → 시퀀스 길이에 대해 선형!
</details>
