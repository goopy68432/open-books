## 1.1 핵심 용어 사전 (Glossary)

### 수학 기초 용어

| 용어 | 한 줄 정의 | 5살 설명 |
|------|-----------|---------|
| 벡터 (Vector) | 크기와 방향을 가진 숫자들의 나열 | 화살표. 어디로 얼마나 갈지 알려주는 것 |
| 행렬 (Matrix) | 숫자들을 사각형으로 배열한 것 | 숫자 표. 여러 개의 화살표를 한꺼번에 적은 것 |
| 내적 (Dot Product) | 두 벡터가 얼마나 같은 방향인지 측정 | 두 화살표가 같은 쪽을 가리키면 큰 수, 반대면 음수 |
| 노름 (Norm) | 벡터의 길이 | 화살표가 얼마나 긴지 |
| 고유값 (Eigenvalue) | 행렬이 특정 방향을 늘리거나 줄이는 비율 | 거울이 키를 몇 배로 보여주는지 |
| Rank | 행렬이 실제로 표현할 수 있는 "독립적인 방향"의 수 | 로봇팔이 움직일 수 있는 방향 수 |
| 미분 (Derivative) | 함수가 변하는 속도 | 언덕의 기울기. 가파를수록 빨리 내려감 |
| Gradient | 다변수 함수에서 가장 가파르게 올라가는 방향 | 산에서 가장 빠르게 정상으로 가는 방향 |
| Hessian | 기울기가 변하는 속도 (2차 미분) | 언덕이 얼마나 울퉁불퉁한지 |

### 확률/통계 용어

| 용어 | 한 줄 정의 | 5살 설명 |
|------|-----------|---------|
| 확률 (Probability) | 어떤 일이 일어날 가능성을 0~1로 표현 | 주사위 6 나올 확률 = 1/6 |
| 기댓값 (Expectation) | 평균적으로 기대되는 결과 | 주사위 많이 던지면 평균 3.5 나옴 |
| 분산 (Variance) | 결과가 평균에서 얼마나 퍼져있는지 | 성적이 들쭉날쭉한 정도 |
| 베이즈 정리 | 새 증거를 보고 믿음을 업데이트하는 규칙 | "비 올 확률 30%" → 구름 봄 → "60%로 수정" |
| MLE | 관찰된 데이터가 가장 그럴듯한 파라미터를 찾는 것 | 동전 7/10 앞면 → "앞면 확률 70%가 가장 그럴듯" |
| KL Divergence | 두 확률분포가 얼마나 다른지 측정 | 두 주머니 속 구슬 색깔 비율이 얼마나 다른지 |

### 머신러닝 용어

| 용어 | 한 줄 정의 | 5살 설명 |
|------|-----------|---------|
| 모델 (Model) | 입력을 넣으면 예측을 내놓는 함수 | "이 사진에 뭐가 있어?" 물으면 대답하는 로봇 |
| 학습 (Training) | 데이터로부터 좋은 모델을 찾는 과정 | 오답노트 만들면서 시험공부하는 것 |
| 손실 함수 (Loss) | 모델이 얼마나 틀렸는지 측정하는 점수 | 시험에서 감점당한 점수 |
| 과적합 (Overfitting) | 훈련 데이터를 "외워버린" 상태 | 기출만 외워서 새 문제 못 푸는 것 |
| 과소적합 (Underfitting) | 모델이 너무 단순해서 패턴을 못 잡는 상태 | 공부를 너무 안 해서 기출도 못 푸는 것 |
| 정규화 (Regularization) | 과적합을 막는 기법 | "너무 외우지 마" 하고 제한 두는 것 |
| 일반화 (Generalization) | 새로운 데이터에서도 잘 작동하는 능력 | 처음 보는 문제도 잘 푸는 능력 |

### 딥러닝 용어

| 용어 | 한 줄 정의 | 5살 설명 |
|------|-----------|---------|
| 신경망 (Neural Network) | 여러 층의 선형변환+비선형함수 합성 | 레고 블록처럼 쌓아올린 함수 기계 |
| 역전파 (Backpropagation) | 출력에서 입력 방향으로 gradient를 전파하는 알고리즘 | "정답은 이건데 넌 이걸 출력했어" → 각 부품에게 "네 잘못 몇 %야" 알려주기 |
| 활성화 함수 | 비선형성을 추가하는 함수 (ReLU, Sigmoid 등) | 직선만으로는 곡선을 그릴 수 없으니 구부러뜨리는 장치 |
| CNN | 이미지의 지역 패턴을 인식하는 신경망 | 돋보기로 이미지의 작은 부분을 하나씩 살펴보는 것 |
| RNN | 순서가 있는 데이터를 처리하는 신경망 | 이전에 읽은 단어를 기억하면서 다음 단어를 읽는 것 |
| Transformer | Attention으로 모든 위치를 한번에 보는 신경망 | 시험 문제 전체를 한눈에 보고 중요한 부분에 집중하는 것 |
| Attention | "어디에 집중할지" 동적으로 결정하는 메커니즘 | 선생님이 "여기 중요해!" 하고 밑줄 그어주는 것 |
| VAE | 데이터의 숨은 구조를 찾아 새로운 데이터를 생성 | "고양이 사진 특징 파악" → "새 고양이 사진 그리기" |
| Diffusion | 노이즈를 점점 제거하여 데이터를 생성 | 흐릿한 사진을 조금씩 선명하게 만드는 것 |

## 1.2 기본 공식 카드

### 카드 1: 선형대수 필수 공식

```
┌─────────────────────────────────────────────┐
│  내적:  v · w = Σ vᵢwᵢ                      │
│  노름:  ‖v‖ = √(v · v)                      │
│  전치:  (AB)ᵀ = BᵀAᵀ                        │
│  행렬곱: C = AB → cᵢⱼ = Σₖ aᵢₖbₖⱼ          │
│  고유값: Av = λv → det(A - λI) = 0          │
│  Rank-Nullity: rank(A) + null(A) = n        │
└─────────────────────────────────────────────┘
```

### 카드 2: 미분 필수 공식

```
┌─────────────────────────────────────────────┐
│  Chain Rule:  d/dx f(g(x)) = f'(g(x))·g'(x)│
│  Product:     (fg)' = f'g + fg'             │
│  ∇(Wx) = W                                  │
│  ∇(xᵀAx) = (A+Aᵀ)x  [대칭이면 2Ax]         │
│  Softmax+CE gradient: p - eᵧ  ← 반드시 암기!│
│  ReLU gradient: 0 or 1 (단순 스위치)         │
└─────────────────────────────────────────────┘
```

### 카드 3: 확률 필수 공식

```
┌─────────────────────────────────────────────┐
│  Bayes:  P(H|E) = P(E|H)P(H) / P(E)       │
│  기댓값:  E[X] = Σ x·p(x)                   │
│  분산:   Var(X) = E[X²] - (E[X])²           │
│  엔트로피: H(p) = -Σ p(x)log p(x)           │
│  교차 엔트로피: H(p,q) = -Σ p(x)log q(x)    │
│  KL: D(p‖q) = Σ p(x)log(p(x)/q(x)) ≥ 0    │
└─────────────────────────────────────────────┘
```

### 카드 4: 딥러닝 핵심 공식

```
┌─────────────────────────────────────────────┐
│  GD:   θ_{t+1} = θ_t - η∇L(θ_t)            │
│  SGD:  미니배치로 gradient 추정 (불편추정)     │
│  Adam: 1차+2차 모멘트 + 편향보정              │
│  CNN출력: H_out = ⌊(H+2p-k)/s⌋ + 1          │
│  Attention: softmax(QKᵀ/√dₖ)V               │
│  ELBO: E[log p(x|z)] - KL(q(z|x)‖p(z))     │
└─────────────────────────────────────────────┘
```

## 1.3 개념 맵 (Concept Maps)

### 전체 과목 흐름도

```
수학 기초 (도구)
  ├── 선형대수 (벡터, 행렬, SVD)
  │     └── 행렬 연산 → 신경망의 선형 변환
  ├── 미적분 (gradient, chain rule)
  │     └── 최적화 → 역전파
  └── 확률/통계 (분포, 베이즈)
        └── 손실함수 유도 → 생성모델

머신러닝 기초 (개념)
  ├── 지도학습: 입력→출력 함수 학습
  ├── ERM: 경험적 위험 최소화
  └── Bias-Variance 트레이드오프

딥러닝 (실전)
  ├── 신경망: 합성함수 + 역전파
  ├── CNN: 이미지 (지역성, 등변성)
  ├── RNN → Transformer: 시퀀스 (attention)
  └── 생성모델: VAE, GAN, Diffusion
```

### "왜 이것을 배우는가?" 연결고리

```
왜 선형대수?
  → 신경망 = 행렬곱의 반복 → W 이해 = 모델 이해

왜 미적분?
  → 학습 = gradient descent → gradient = 미분

왜 확률?
  → 손실함수 = NLL → CE도 MSE도 확률에서 유도
  → 생성모델 = 확률분포 학습

왜 최적화?
  → SGD, Adam = 학습 알고리즘
  → softmax = 라그랑주 승수법으로 유도

왜 학습이론?
  → 과적합은 왜 일어나는가?
  → 딥러닝은 왜 일반화가 잘 되는가? (미해결!)
```

## 1.4 주제별 "5살에게 설명하기"

### 역전파 (Backpropagation)

> **5살 설명**: 공장에서 불량품이 나왔어. 사장님이 "누구 잘못이야?" 물어봐. 마지막 직원부터 거꾸로 추적해. "네가 고무 잘못 끼워서 30% 잘못", "네가 나사 빠뜨려서 70% 잘못". 이렇게 각 직원(=파라미터)의 잘못 비율(=gradient)을 정하면, 다음엔 각자 자기 실수를 고칠 수 있어.

### CNN (합성곱 신경망)

> **5살 설명**: 아주 큰 그림이 있어. 돋보기(=필터)로 작은 부분만 봐. "여기 직선 있네", "여기 동그라미 있네". 돋보기를 그림 전체에 움직이면서 본 결과를 정리해. 첫 번째 돋보기들은 선과 점을 찾고, 나중 돋보기들은 눈, 코, 입을 찾고, 마지막에는 "이건 고양이야!"라고 판단해.

### Transformer와 Attention

> **5살 설명**: 책을 읽는데 모르는 단어가 나왔어. "이 단어가 무슨 뜻이지?" 하고 앞뒤 문장을 전부 한꺼번에 살펴봐. 관련 있는 단어에는 노란 형광펜을 진하게 칠하고, 관련 없는 단어는 무시해. 이렇게 "어디를 집중해서 볼지" 스스로 정하는 게 Attention이야.

### VAE (변분 오토인코더)

> **5살 설명**: 고양이 사진을 줄여서 "특징 메모"로 만들어(인코더). 메모에는 "털 색깔: 주황, 눈 크기: 큼, 표정: 졸림" 같은 게 써있어. 그 메모만 보고 다시 고양이 사진을 그려(디코더). 메모를 살짝 바꾸면("표정: 놀람") 다른 고양이가 그려져!

### Diffusion Model

> **5살 설명**: 예쁜 그림에 모래를 조금씩 뿌려서 완전 뿌옇게 만들어(forward process). 그 다음, 뿌연 사진에서 모래를 조금씩 털어내는 방법을 배워(reverse process). 아무 모래(=노이즈)에서 시작해서 모래를 털어내면... 새로운 예쁜 그림이 나타나!

## 2.1 비교표 모음

### 옵티마이저 비교표

| 항목 | SGD | Momentum | RMSprop | Adam | AdamW |
|------|-----|----------|---------|------|-------|
| 업데이트 규칙 | $\theta - \eta g$ | $\theta - \eta m$ | $\theta - \eta g/\sqrt{s}$ | $\theta - \eta \hat{m}/\sqrt{\hat{s}}$ | Adam + decoupled WD |
| 1차 모멘트 | X | O ($\beta$) | X | O ($\beta_1$) | O |
| 2차 모멘트 | X | X | O ($\beta_2$) | O ($\beta_2$) | O |
| 편향 보정 | - | - | - | O | O |
| 적응적 LR | X | X | O (차원별) | O (차원별) | O |
| 장점 | 단순, 일반화 좋음 | 진동 감소, 가속 | sparse 데이터에 강함 | 빠른 수렴, 범용 | WD 분리 → 일반화↑ |
| 단점 | 느린 수렴, 조건수 민감 | 하이퍼파라미터 1개 추가 | non-convex에서 불안정 | 일반화 때때로 SGD보다 나쁨 | 하이퍼파라미터 많음 |
| 기본 하이퍼파라미터 | $\eta$ | $\eta, \beta=0.9$ | $\eta, \beta_2=0.999$ | $\eta, \beta_1=0.9, \beta_2=0.999$ | + $\lambda$ (WD) |
| 언제 사용? | CV 마지막 fine-tuning | CV 일반 학습 | RNN, 불안정한 gradient | NLP, 대부분의 경우 | Transformer 학습 |

### 손실함수 비교표

| 손실함수 | 수식 | 확률적 해석 | 사용 상황 | gradient |
|---------|------|-----------|----------|----------|
| MSE | $\frac{1}{2}\|y-\hat{y}\|^2$ | 가우시안 NLL | 회귀 | $\hat{y} - y$ |
| CE (이진) | $-[y\log p + (1-y)\log(1-p)]$ | 베르누이 NLL | 이진 분류 | $p - y$ |
| CE (다중) | $-\sum_c y_c \log p_c$ | 카테고리컬 NLL | 다중 분류 | $p - e_y$ |
| Hinge | $\max(0, 1-y\hat{y})$ | - | SVM / 마진 분류 | 조건부 |
| KL Div | $\sum p\log(p/q)$ | 분포 거리 | VAE 정합 항 | - |
| Focal Loss | $-(1-p_t)^\gamma \log p_t$ | - | 클래스 불균형 | - |

> **핵심 통찰**: MSE와 CE는 모두 **음의 로그 우도(NLL)**의 특수한 경우이다.
> - 가우시안 가정 → NLL = MSE (상수 차이)
> - 베르누이/카테고리컬 가정 → NLL = CE

### 아키텍처 비교표

| 항목 | MLP | CNN | RNN/LSTM | Transformer |
|------|-----|-----|----------|-------------|
| 입력 구조 | 1D 벡터 | 2D/3D 격자 | 시퀀스 | 시퀀스/집합 |
| 핵심 연산 | 행렬곱 | 합성곱 | 순환 연결 | Self-Attention |
| 파라미터 공유 | 없음 | 공간적 (필터) | 시간적 (동일 가중치) | 없음 (head별) |
| 귀납적 편향 | 없음 | 지역성, 이동 등변성 | 시간적 순서 | 없음 (데이터로 학습) |
| 장거리 의존성 | 깊이에 의존 | 수용 영역에 의존 | 이론적 O, 실제 어려움 | 직접 연결 (O(1)) |
| 병렬화 | O | O | X (순차적) | O |
| 복잡도 | $O(d^2)$ | $O(k^2 \cdot c^2)$ | $O(T \cdot d^2)$ | $O(T^2 \cdot d)$ |
| 대표 응용 | 테이블 데이터 | 이미지 | 음성, 번역(구) | NLP, 비전, 범용 |

### 활성화 함수 비교표

| 함수 | 수식 | 범위 | 장점 | 단점 |
|------|------|------|------|------|
| Sigmoid | $1/(1+e^{-x})$ | $(0, 1)$ | 확률 해석 | gradient 소실, 중심 ≠ 0 |
| Tanh | $(e^x-e^{-x})/(e^x+e^{-x})$ | $(-1, 1)$ | 중심 = 0 | gradient 소실 |
| ReLU | $\max(0, x)$ | $[0, \infty)$ | 빠른 계산, 소실 완화 | Dead neuron (음수 영역) |
| Leaky ReLU | $\max(\alpha x, x)$ | $(-\infty, \infty)$ | Dead neuron 방지 | 하이퍼파라미터 $\alpha$ |
| GELU | $x \cdot \Phi(x)$ | $\approx(-0.17, \infty)$ | 부드러움, Transformer 표준 | 계산 비용 약간 높음 |
| Softmax | $e^{z_i}/\sum e^{z_j}$ | $(0,1)$, 합=1 | 확률 분포 출력 | 출력 간 의존성 |

### 정규화 기법 비교표

| 기법 | 적용 위치 | 효과 | 학습/추론 차이 |
|------|----------|------|--------------|
| L2 정규화 (Weight Decay) | 손실함수에 $\lambda\|w\|^2$ 추가 | 가중치 크기 제한 | 없음 |

## 2.2 시험 빈출 패턴과 풀이 전략

### 패턴 A: "이 상황에서 어떤 문제가 발생하며, 해결책은?"

**예시 1**: "깊은 신경망에서 sigmoid 활성화를 사용할 때 발생하는 문제와 해결책"
- **문제**: Gradient vanishing. sigmoid의 최대 gradient는 0.25. $L$층이면 gradient ≤ $0.25^L$ → 급격히 감소
- **해결**: ReLU 사용 (양수 영역 gradient = 1), Residual Connection, BatchNorm
- **풀이 포인트**: "왜" 발생하는지 수식으로 보여주고 → "어떻게" 해결하는지 구체적 방법 제시

**예시 2**: "학습률이 너무 크면/작으면 어떻게 되는가?"
- **너무 크면**: 발산. 2차 함수에서 수렴 조건: $\eta < 2/\lambda_{\max}(H)$
- **너무 작으면**: 수렴 매우 느림. local minima/saddle point에 갇힘
- **해결**: Learning rate scheduler, Adam (적응적), warm-up

**예시 3**: "CNN에서 pooling을 제거하면 어떤 영향이 있는가?"
- 수용 영역(receptive field)이 줄어듦
- 이동 불변성 약화
- 계산 비용 증가 (feature map 크기 유지)
- 대안: stride > 1인 convolution으로 대체 가능 (strided conv)

### 패턴 B: "수식을 유도하시오"

**빈출 유도 1**: Softmax가 최대 엔트로피에서 나오는 과정

```
1. 라그랑지안: L = -Σ p(x)log p(x) + λ₀(Σp-1) + Σλᵢ(Σp·fᵢ-cᵢ)
2. ∂L/∂p(x) = 0 → -log p(x) - 1 + λ₀ + Σλᵢfᵢ(x) = 0
3. p(x) = exp(Σλᵢfᵢ(x)) / Z  ← Gibbs/Boltzmann 분포
4. 분류 문제에서 fᵢ(x) = 1(x=i)로 놓으면 → softmax!
```

**빈출 유도 2**: Bias-Variance Decomposition

```
E[(h-f)²] = E[(h-μ+μ-f)²]
           = E[(h-μ)²] + 2·E[h-μ]·(μ-f) + (μ-f)²
                                    ↑ =0
           = Var[h] + Bias²
```

**빈출 유도 3**: ELBO

```
log p(x) = log ∫ p(x,z) dz
         = log E_{q(z|x)} [p(x,z)/q(z|x)]
         ≥ E_q [log p(x,z)/q(z|x)]          ← Jensen (log는 오목)
         = E_q[log p(x|z)] - KL(q‖p(z))     ← ELBO
```

### 패턴 C: "계산하시오" (Forward/Backward Pass)

**시험 접근법**:
1. **Forward**: 입력부터 순서대로, 모든 중간값을 기록 (나중에 backward에서 필요)
2. **Backward**: 출력→입력 역순, chain rule 적용
3. **검증**: gradient의 shape이 파라미터의 shape과 일치하는지 확인

**자주 틀리는 포인트**:
- $\partial L/\partial W = (\partial L/\partial z) \cdot x^\top$에서 전치를 빼먹음
- ReLU에서 $z \leq 0$인 부분의 gradient를 0으로 안 만듦
- Softmax+CE gradient를 $p - e_y$로 바로 쓰지 않고 길게 유도하다 실수

### 패턴 D: "비교/설명하시오" (서술형)

**템플릿**:

```
① 정의를 간결하게 쓴다 (수식 포함)
② 핵심 차이점을 2~3개 나열한다
③ 언제 어떤 것을 쓰는지 실용적 가이드라인 제시
④ (가능하면) 수식/예시로 뒷받침
```

**예시**: "GD와 SGD의 차이를 설명하시오"

> ① GD: $\theta_{t+1} = \theta_t - \eta \nabla L_S(\theta)$ (전체 데이터). SGD: 미니배치 $B$로 gradient 추정.
> ② 차이: (1) 계산 비용 O(n) vs O(b), (2) gradient 정확도 (정확 vs 불편 추정), (3) 일반화 (SGD가 flat minima 유도)
> ③ 실전: 거의 항상 SGD(미니배치) 사용. GD는 데이터가 매우 적을 때만.
> ④ SGD의 확률적 잡음: $\text{Var}[\nabla L_B] = \sigma^2/b$ → 배치 크기가 커지면 잡음 감소

## 2.3 유도 연습 문제

### 연습 1: Cross-Entropy Loss의 gradient 유도

**문제**: $L = -\log p_y$, $p_i = e^{z_i}/\sum_j e^{z_j}$ (softmax)일 때, $\partial L/\partial z_i$를 유도하시오.

**풀이**:
$$\frac{\partial L}{\partial z_i} = -\frac{\partial \log p_y}{\partial z_i} = -\frac{1}{p_y} \frac{\partial p_y}{\partial z_i}$$

Softmax의 미분:
$$\frac{\partial p_y}{\partial z_i} = \begin{cases} p_y(1-p_y) & i = y \\ -p_y p_i & i \neq y \end{cases}$$

따라서:
$$\frac{\partial L}{\partial z_i} = \begin{cases} -\frac{1}{p_y} \cdot p_y(1-p_y) = -(1-p_y) = p_y - 1 & i = y \\ -\frac{1}{p_y} \cdot (-p_y p_i) = p_i & i \neq y \end{cases}$$

벡터로: $\nabla_z L = p - e_y$ (예측 확률벡터 - 정답 원핫벡터)

### 연습 2: L2 정규화 = MAP with Gaussian Prior

**문제**: 가우시안 사전분포 $p(w) = \mathcal{N}(0, \sigma^2 I)$ 하에서 MAP 추정이 L2 정규화된 ERM과 동일함을 보이시오.

**풀이**:
$$\hat{w}_{MAP} = \arg\max_w \log p(D|w) + \log p(w)$$
$$= \arg\max_w \left[\sum_i \log p(y_i|x_i, w) - \frac{\|w\|^2}{2\sigma^2}\right]$$
$$= \arg\min_w \left[-\sum_i \log p(y_i|x_i, w) + \frac{1}{2\sigma^2}\|w\|^2\right]$$
$$= \arg\min_w \left[L_S(w) + \lambda\|w\|^2\right] \quad (\lambda = 1/(2\sigma^2))$$

→ L2 정규화된 ERM과 동일! $\sigma$가 작을수록(사전 믿음이 강할수록) 정규화가 강해짐.

### 연습 3: $\sqrt{d_k}$ 스케일링의 필요성

**문제**: $q, k \in \mathbb{R}^{d_k}$의 각 원소가 i.i.d. 평균 0, 분산 1일 때, $q^\top k$의 분산이 $d_k$임을 보이시오.

**풀이**:
$$q^\top k = \sum_{j=1}^{d_k} q_j k_j$$
각 $q_j k_j$는 독립이고, $\mathbb{E}[q_j k_j] = 0$, $\text{Var}(q_j k_j) = \mathbb{E}[q_j^2 k_j^2] = \mathbb{E}[q_j^2]\mathbb{E}[k_j^2] = 1$

$$\text{Var}(q^\top k) = \sum_{j=1}^{d_k} \text{Var}(q_j k_j) = d_k$$

→ $d_k$가 크면 내적의 분산이 커져 softmax 입력이 극단적 → gradient 소실
→ $\sqrt{d_k}$로 나누면 분산을 1로 정규화

### 2-Layer MLP + Backprop (NumPy 스타일)

```python
# Forward Pass
def forward(x, W1, b1, W2, b2):
    z1 = W1 @ x + b1           # 선형변환 1
    a1 = relu(z1)               # 활성화
    z2 = W2 @ a1 + b2           # 선형변환 2
    probs = softmax(z2)         # 출력 확률
    return z1, a1, z2, probs

# Loss
def cross_entropy(probs, y):
    return -log(probs[y])

# Backward Pass
def backward(x, z1, a1, z2, probs, y, W1, W2):
    # 출력층 gradient
    dz2 = probs.copy()
    dz2[y] -= 1                 # p - e_y

    # W2, b2 gradient
    dW2 = dz2 @ a1.T            # (out x 1)(1 x hidden) = (out x hidden)
    db2 = dz2

    # 은닉층으로 전파
    da1 = W2.T @ dz2
    dz1 = da1 * (z1 > 0)        # ReLU gradient

    # W1, b1 gradient
    dW1 = dz1 @ x.T
    db1 = dz1

    return dW1, db1, dW2, db2

# SGD 업데이트
def sgd_step(params, grads, lr):
    for p, g in zip(params, grads):
        p -= lr * g
```

### Self-Attention 구현

```python
def self_attention(X, Wq, Wk, Wv, dk):
    """
    X: (seq_len, d_model) - 입력 시퀀스
    Wq, Wk, Wv: (d_model, dk) - 투영 행렬
    """
    Q = X @ Wq                  # (seq_len, dk)
    K = X @ Wk                  # (seq_len, dk)
    V = X @ Wv                  # (seq_len, dk)

    scores = Q @ K.T            # (seq_len, seq_len)
    scores = scores / sqrt(dk)  # 스케일링
    attn = softmax(scores, axis=-1)  # 행별 softmax
    output = attn @ V           # (seq_len, dk)
    return output, attn

def multi_head_attention(X, heads):
    """heads: list of (Wq, Wk, Wv) tuples"""
    head_outputs = [self_attention(X, Wq, Wk, Wv, dk)
                    for Wq, Wk, Wv in heads]
    concat = concatenate([h[0] for h in head_outputs], axis=-1)
    return concat @ Wo          # 최종 투영
```

### Adam 옵티마이저

```python
def adam(params, grads, m, s, t, lr=0.001, b1=0.9, b2=0.999, eps=1e-8):
    """
    m: 1차 모멘트 (gradient의 이동평균)
    s: 2차 모멘트 (gradient 제곱의 이동평균)
    t: 현재 스텝 (편향 보정용)
    """
    for i in range(len(params)):
        m[i] = b1 * m[i] + (1 - b1) * grads[i]         # 1차 모멘트 갱신
        s[i] = b2 * s[i] + (1 - b2) * grads[i]**2       # 2차 모멘트 갱신
        m_hat = m[i] / (1 - b1**t)                       # 편향 보정
        s_hat = s[i] / (1 - b2**t)
        params[i] -= lr * m_hat / (sqrt(s_hat) + eps)    # 파라미터 갱신
```

### VAE 학습 루프

```python
def vae_loss(x, encoder, decoder):
    # 인코더: 잠재 변수의 평균과 로그분산 출력
    mu, log_var = encoder(x)

    # Reparameterization Trick
    eps = random_normal(shape=mu.shape)
    z = mu + exp(0.5 * log_var) * eps    # z ~ N(mu, sigma^2)

    # 디코더: 잠재 변수로부터 복원
    x_recon = decoder(z)

    # 복원 손실 (NLL)
    recon_loss = -sum(x * log(x_recon) + (1-x) * log(1-x_recon))

    # KL 손실: KL(q(z|x) || N(0,I))
    kl_loss = -0.5 * sum(1 + log_var - mu**2 - exp(log_var))

    return recon_loss + kl_loss          # -ELBO 최소화
```

## 3.1 증명 기반 문제

### 증명 1: 보편 근사 정리 (Universal Approximation Theorem)의 한계

**정리**: 충분히 넓은 1-hidden-layer 신경망은 임의의 연속함수를 임의 정밀도로 근사할 수 있다.

**시험에서 물을 수 있는 포인트**:
1. **존재성 정리일 뿐**: "근사할 수 있다"는 것이지, "학습으로 찾을 수 있다"는 아님
2. **폭 vs 깊이 트레이드오프**: 깊이 $L$이면 폭 $O(\text{poly}(d))$로 충분하지만, $L=1$이면 지수적 폭 필요 가능
3. **ReLU의 경우**: 폭 $d+1$의 단층 ReLU 네트워크는 $\mathbb{R}^d$의 모든 볼록 함수를 표현 가능 (PWL 근사)

**비판적 사고 문제**: "보편 근사 정리가 있는데 왜 깊은 신경망을 쓰는가?"
- 답: 얕은 네트워크는 지수적 폭이 필요할 수 있음 (exponential width)
- 깊은 네트워크는 compositional structure를 활용하여 효율적 표현
- SGD가 깊은 네트워크의 좋은 해를 잘 찾는 경험적 관찰

### 증명 2: SGD의 수렴 보장 (볼록, smooth 함수)

**정리**: $f$가 $\beta$-smooth이고 볼록이면, $\eta = 1/\beta$로 설정한 GD는 $T$번 반복 후:

$$f(x_T) - f(x^*) \leq \frac{\beta \|x_0 - x^*\|^2}{2T}$$

**증명 스케치**:
1. Smoothness: $f(y) \leq f(x) + \nabla f(x)^\top(y-x) + \frac{\beta}{2}\|y-x\|^2$
2. $y = x - \frac{1}{\beta}\nabla f(x)$를 대입하면: $f(y) \leq f(x) - \frac{1}{2\beta}\|\nabla f(x)\|^2$
3. 볼록성: $f(x^*) \geq f(x) + \nabla f(x)^\top(x^* - x)$
4. 두 부등식 결합 → 텔레스코핑 합 → $O(1/T)$ 수렴

**시험 포인트**: "볼록이 아닌(non-convex) 딥러닝에서 SGD가 잘 되는 이유"
- 모든 local minima가 global에 가깝다는 경험적/이론적 관찰
- Loss landscape가 실제로는 "거의 볼록"에 가깝다는 주장
- 과다파라미터화(overparameterization)가 최적화를 쉽게 만듦

### 증명 3: Double Descent 현상

**현상**: 전통적 U자형 bias-variance 곡선과 달리, 모델 복잡도를 보간 임계점(interpolation threshold) 이상으로 키우면 테스트 오차가 다시 감소

**이론적 설명**:
1. 보간 임계점: 모델 파라미터 수 $p \approx n$ (데이터 수)
2. $p < n$: 클래식 underfitting→overfitting
3. $p \approx n$: 오차 극대 (노이즈까지 완벽히 맞추려는 "최소 노름 솔루션"이 불안정)
4. $p \gg n$: 무한히 많은 보간 해 중 SGD가 암묵적으로 "좋은 해" (최소 노름, flat) 선택

**시험 질문**: "Double descent가 bias-variance decomposition을 부정하는가?"
- 아니다. Bias-Variance는 여전히 성립. $p \gg n$에서 분산이 다시 감소하는 것.
- 핵심: 보간하는 함수들의 "복잡성"은 모두 같지 않음. SGD는 단순한 보간 함수 선택.

### 증명 4: Attention은 커널 회귀의 특수한 형태

**관찰**: $\text{Attention}(Q, K, V) = \text{softmax}(QK^\top/\sqrt{d_k})V$

이것은 Nadaraya-Watson 커널 회귀로 해석 가능:
$$\hat{f}(q) = \sum_i \frac{K(q, k_i)}{\sum_j K(q, k_j)} v_i$$

여기서 $K(q, k) = \exp(q^\top k / \sqrt{d_k})$ (softmax 커널)

**의미**: Attention은 key-value 쌍을 "학습된 비모수 회귀"로 검색하는 것
- Linear attention: $K(q,k) = \phi(q)^\top\phi(k)$ → $O(Td^2)$로 감소
- 이 관점은 Transformer의 표현력과 한계를 이해하는 데 유용

```
1단계: 제목 + 초록 + 결론 (5분)
  → "이 논문이 뭘 하는지" 한 문장으로 정리

2단계: 그림 + 표 + 실험 결과 (10분)
  → 핵심 수식과 아키텍처 파악

3단계: 방법론(Method) 정독 (30분)
  → 수식 유도 따라가기, 직접 계산해보기

4단계: 비판적 읽기 (10분)
  → "이 논문의 가정은?" "한계는?" "다른 접근은?"
```

## 3.4 챕터 간 연결 (Cross-Chapter Connections)

### 연결 1: 선형대수 ↔ 딥러닝

| 선형대수 개념 | 딥러닝에서의 등장 |
|-------------|-----------------|
| 행렬곱 | 선형 레이어 $z = Wx + b$ |
| SVD | 가중치 행렬 분석, 저랭크 근사 (모델 압축) |
| 고유값/벡터 | Hessian 분석 (수렴 속도, flat minima) |
| Rank | 표현력 제한 (bottleneck layer) |
| 조건수 $\kappa$ | 학습률 선택, 수렴 속도: $\rho = (\kappa-1)/(\kappa+1)$ |
| 직교 행렬 | 가중치 초기화 (orthogonal init) |
| PSD | Hessian이 PSD → 볼록 → 수렴 보장 |

### 연결 2: 확률 ↔ 손실함수 ↔ 생성모델

```
확률 모델 가정           → NLL 유도         → 손실함수
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
y ~ N(f(x), σ²)         → -log N(y|f,σ²)   → MSE
y ~ Bernoulli(σ(f(x)))  → -log Ber(y|p)     → Binary CE
y ~ Categorical(softmax) → -log Cat(y|p)    → Categorical CE
p(x) via latent z       → -ELBO             → VAE Loss
score ∇log p(x)         → denoising obj     → Diffusion Loss
```

> **핵심 통찰**: 거의 모든 딥러닝 손실함수는 확률적 가정에서 자연스럽게 유도된다. 손실함수를 "외우는" 것이 아니라 "유도할 수 있어야" 한다.

### 연결 3: 최적화 ↔ 일반화

```
최적화 이론                          일반화 이론
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
GD는 loss를 줄임         ↔    하지만 train loss만 줄이면 과적합
SGD의 확률적 잡음         ↔    flat minima로 유도 → 좋은 일반화
작은 배치 → 높은 잡음     ↔    더 나은 일반화 (경험적)
학습률과 배치크기 비율     ↔    "effective temperature" = η/b
라그랑주 승수법            ↔    정규화 (제약 최적화로 해석)
early stopping            ↔    암묵적 정규화 (반복 횟수 제한)
```

### 연결 4: CNN의 등변성 ↔ 수학적 대칭

```
합성곱의 수학적 성질:
- 등변성: f(S_τ(x)) = S_τ(f(x))   ← 이동(translation)에 대해
- CNN = 이동 대칭을 가정에 인코딩한 모델
- 풀링 추가 → 근사적 이동 불변성

일반화:
- 대칭 그룹 → 등변 신경망 (Group Equivariant CNN)
- 회전 등변: e2cnn
- 순열 등변: GNN (Graph Neural Network)
- 결론: 귀납적 편향 = 데이터의 대칭 구조를 모델에 반영
```

## 3.5 에지 케이스와 반례

### 에지 케이스 1: ReLU의 Dead Neuron 문제

**상황**: ReLU의 입력이 항상 음수가 되면 gradient = 0 → 영원히 학습 안 됨
- **발생 조건**: 학습률이 너무 크거나, 나쁜 초기화
- **대책**: Leaky ReLU, He 초기화, Batch Normalization
- **반례**: "ReLU가 항상 sigmoid보다 좋다" → X. 출력 레이어에서 확률이 필요하면 sigmoid/softmax 사용

### 에지 케이스 2: Batch Normalization의 배치 크기 의존성

**상황**: 배치 크기가 매우 작으면 (예: 1) 배치 통계가 불안정
- **문제**: $\mu_B$와 $\sigma_B^2$의 추정이 매우 불정확
- **대책**: Layer Normalization (Transformer에서 선호), Group Normalization
- **반례**: "BN은 항상 학습을 개선한다" → X. 작은 배치나 RNN에서는 오히려 해로움

### 에지 케이스 3: Adam이 SGD보다 일반화가 나쁜 경우

**상황**: Adam은 수렴이 빠르지만, 특정 상황에서 SGD+Momentum보다 테스트 성능이 낮음
- **원인**: Adam이 sharp minima에 수렴하는 경향 (적응적 학습률이 탐색 범위를 줄임)
- **해결**: AdamW (decoupled weight decay), SGD로 fine-tuning
- **반례**: "Adam이 항상 최고의 옵티마이저다" → X. CV 분야에서는 SGD+Momentum이 종종 우월

### 에지 케이스 4: 과다파라미터화의 역설

**상황**: 파라미터 수 >> 데이터 수인데도 과적합이 안 일어남
- **전통 이론**: VC 차원이 크면 일반화 오차 크다
- **현실**: 수십억 파라미터 모델이 잘 일반화
- **설명**: (1) SGD의 암묵적 정규화, (2) flat minima 선호, (3) 실제 유효 파라미터 수는 적음
- **반례**: "파라미터가 많으면 반드시 과적합" → X. Double Descent 참조

### 에지 케이스 5: Transformer의 위치 정보 문제

**상황**: Self-Attention은 순서를 모름 (순열 등변)
- **문제**: "고양이가 개를 쫓는다" ≠ "개가 고양이를 쫓는다" 구분 불가 (PE 없이)
- **해결**: Sinusoidal PE, Learned PE, Rotary PE (RoPE)
- **반례**: "Transformer는 RNN의 상위호환이다" → 주의 필요. 길이 외삽(length extrapolation)에서 RNN이 유리할 수 있음

### 에지 케이스 6: VAE의 Posterior Collapse

**상황**: KL 항이 0으로 가면서 인코더가 사전분포와 같아지고, 디코더가 z를 무시
- **원인**: 디코더가 너무 강력하면 z 없이도 잘 복원 → KL을 0으로 만드는 게 손실 최소화에 유리
- **해결**: KL annealing (처음에 KL 가중치 작게 시작), Free-bits, δ-VAE
- **시험 포인트**: ELBO의 두 항 (복원 + KL) 사이의 트레이드오프 이해

## 3.6 심화 서술형 예상 문제

### Q1: "딥러닝에서 일반화가 잘 되는 이유를 전통적 학습이론과 비교하여 설명하시오"

**모범 답안 구조**:

```
1. 전통적 학습이론 (VC 차원, Rademacher 복잡도)
   - 일반화 bound: L_P(h) ≤ L_S(h) + O(√(d/n))
   - d = 모델 복잡도, n = 데이터 수
   - 딥러닝: d >> n인데도 일반화 → 전통 bound가 vacuous (비어있음)

2. 왜 전통 이론이 실패하는가?
   - 모든 가설을 동일하게 취급 (SGD가 특정 해를 선호한다는 것을 반영 못함)
   - 최악의 경우(worst-case) 분석

3. 현대적 설명들
   - 암묵적 정규화: SGD가 최소 노름 해, flat minima를 선호
   - PAC-Bayes bound: 사후분포의 "복잡도"로 측정 → tighter bound
   - 압축 기반 이론: 네트워크를 압축할 수 있으면 일반화가 좋음
   - Neural Tangent Kernel: 과다파라미터화 → 커널 회귀처럼 동작

4. 미해결 문제
   - 정확한 일반화 bound는 아직 없음
   - 왜 SGD가 flat minima를 찾는지 완전한 이론 없음
   - Double Descent 현상의 완전한 이해
```

### Q2: "Transformer가 RNN을 대체하게 된 기술적 이유를 시간복잡도, 장거리 의존성, 병렬화 관점에서 분석하시오"

**핵심 논점**:

| 관점 | RNN | Transformer | 결론 |
|------|-----|-------------|------|
| 시간복잡도 | $O(T \cdot d^2)$ 순차 | $O(T^2 \cdot d)$ 병렬 | 짧은 시퀀스에선 Transformer 유리, 긴 시퀀스는 트레이드오프 |
| 장거리 의존성 | gradient가 $T$번 곱해짐 → vanishing | 직접 연결 $O(1)$ | Transformer 압도적 우위 |
| 병렬화 | $h_t$가 $h_{t-1}$에 의존 → 불가 | 모든 위치 동시 계산 → GPU 활용 | Transformer 압도적 우위 |
| 메모리 | $O(d)$ 은닉 상태 | $O(T^2)$ attention map | RNN 유리 (긴 시퀀스) |
| 학습 안정성 | BPTT → gradient exploding/vanishing | LayerNorm + Residual → 안정 | Transformer 유리 |

# 흔한 실수와 오해 (Common Mistakes & Misconceptions)

---

## 수학 관련 실수

| 번호 | 실수 | 올바른 이해 |
|------|------|-----------|
| 1 | $(AB)^\top = A^\top B^\top$ | $(AB)^\top = B^\top A^\top$ (순서 반전!) |
| 2 | $\nabla_W L$의 shape을 모름 | gradient shape = 파라미터 shape (항상 동일) |
| 3 | chain rule에서 Jacobian 방향 혼동 | $\partial L/\partial x = (\partial z/\partial x)^\top \partial L/\partial z$ (VJP 방향) |
| 4 | "det=0이면 역행렬 없다"만 외우고 rank와 연결 못함 | det=0 ↔ rank < n ↔ 영공간 비자명 ↔ 고유값 0 포함 (전부 동치) |
| 5 | 볼록 함수에서 극소 = 최소를 비볼록에 적용 | 비볼록에서는 극소점이 여럿, 안장점도 존재 |

## 딥러닝 관련 실수

| 번호 | 실수 | 올바른 이해 |
|------|------|-----------|
| 1 | "더 깊으면 항상 좋다" | 깊으면 gradient vanishing/exploding, 학습 어려움 (ResNet이 해결) |
| 2 | "학습률을 키우면 빨리 수렴" | 너무 크면 발산. 수렴 조건: $\eta < 2/\lambda_{\max}$ |
| 3 | "dropout은 추론 때도 적용" | 추론 때는 꺼야 함 (deterministic). 대신 가중치 스케일링 |
| 4 | "BN의 mean/var는 학습 파라미터" | 아니다. running 통계이며 gradient로 학습하지 않음. $\gamma, \beta$만 학습 |
| 5 | "Adam이면 learning rate 안 중요" | 틀림. 초기 lr 선택이 여전히 중요. 기본값이 항상 최적은 아님 |
| 6 | "파라미터 수 = 모델 복잡도" | 유효 파라미터 수 ≠ 총 파라미터 수. 정규화로 유효 복잡도 감소 |
| 7 | "Softmax+CE의 gradient를 길게 유도" | $p - e_y$로 바로 써야 함. 시간 절약! |
| 8 | "Attention의 Q, K, V가 뭔지 혼동" | Q=질문, K=색인, V=내용. 유사도(QK) 기반으로 V를 가중합 |
| 9 | "Transformer에 위치 정보가 자동으로 있다" | 없다! Self-Attention은 순열 등변 → PE 필수 |
| 10 | "VAE = Autoencoder" | 다르다. VAE는 확률적 잠재 변수 모델 (생성 모델), AE는 결정적 압축 |

## 확률/통계 관련 실수

| 번호 | 실수 | 올바른 이해 |
|------|------|-----------|
| 1 | $P(A \mid B) = P(B \mid A)$로 혼동 | 베이즈 정리로 변환 필요. 일반적으로 같지 않음 |
| 2 | KL divergence가 대칭이라고 생각 | $D_{KL}(p\|q) \neq D_{KL}(q\|p)$. 비대칭! (거리가 아닌 divergence) |
| 3 | MLE의 $\hat{\sigma}^2 = \frac{1}{n}\sum(x_i-\bar{x})^2$가 불편추정 | 편향 추정. 불편추정은 $\frac{1}{n-1}$. MLE ≠ 불편추정 |
| 4 | "엔트로피가 클수록 좋다/나쁘다" | 맥락 의존. 엔트로피 = 불확실성. 고엔트로피 = 균일 분포 (정보 없음) |

# 주제별 빠른 참조 공식집 (Quick Reference)

---

## 선형대수 공식

$$\text{내적: } \langle v, w \rangle = v^\top w = \|v\|\|w\|\cos\theta$$
$$\text{SVD: } A = U\Sigma V^\top, \quad A_k = \sum_{i=1}^k \sigma_i u_i v_i^\top$$
$$\text{PSD 판정: } v^\top Av \geq 0 \;\forall v \iff \lambda_i \geq 0 \;\forall i$$
$$\text{조건수: } \kappa(A) = \frac{\lambda_{\max}}{\lambda_{\min}} = \frac{\sigma_{\max}}{\sigma_{\min}}$$

## 미적분/최적화 공식

$$\text{Taylor: } f(x+\delta) \approx f(x) + \nabla f^\top \delta + \frac{1}{2}\delta^\top H \delta$$
$$\text{GD 수렴 (강볼록): } f(x_t) - f^* \leq \left(\frac{\kappa-1}{\kappa+1}\right)^{2t}(f(x_0)-f^*)$$
$$\text{Lagrangian: } \mathcal{L}(x,\lambda) = f(x) + \sum_i \lambda_i g_i(x)$$
$$\text{Jensen: 볼록 } f \Rightarrow f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$$

## 확률/정보이론 공식

$$\text{전체 확률: } P(A) = \sum_i P(A|B_i)P(B_i)$$
$$\text{가우시안: } p(x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$
$$H(p) = -\sum p\log p, \quad H(p,q) = H(p) + D_{KL}(p\|q)$$

## 신경망/역전파 공식

$$\text{Forward: } z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}, \quad a^{(l)} = \sigma(z^{(l)})$$
$$\text{Backward: } \delta^{(l)} = (W^{(l+1)\top}\delta^{(l+1)}) \odot \sigma'(z^{(l)})$$
$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} \cdot a^{(l-1)\top}, \quad \frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}$$

## CNN 공식

$$H_{out} = \left\lfloor\frac{H_{in} + 2p - k}{s}\right\rfloor + 1$$
$$\text{파라미터: } c_{out} \times (c_{in} \times k^2 + 1)$$
$$\text{FLOPs: } H_{out} \times W_{out} \times c_{out} \times c_{in} \times k^2$$

## Transformer 공식

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
$$\text{MHA}(X) = \text{Concat}(\text{head}_1,...,\text{head}_h)W^O$$
$$\text{FFN}(x) = \max(0, xW_1+b_1)W_2+b_2$$
$$\text{파라미터 (1블록): } 4d^2 + 2d \cdot d_{ff} + d_{ff} + d + 4d$$

## 생성모델 공식

$$\text{ELBO: } \mathbb{E}_q[\log p(x|z)] - D_{KL}(q(z|x)\|p(z))$$
$$\text{Reparam: } z = \mu + \sigma \odot \varepsilon, \quad \varepsilon \sim \mathcal{N}(0,I)$$
$$\text{Diffusion forward: } q(x_t|x_0) = \mathcal{N}(\sqrt{\bar{\alpha}_t}x_0, (1-\bar{\alpha}_t)I)$$
$$\text{Diffusion loss: } \|\varepsilon - \varepsilon_\theta(x_t, t)\|^2$$

# 최종 체크리스트

## 반드시 외워야 할 것 (시험장에서 바로 써야 함)

- [ ] Softmax+CE gradient = $p - e_y$
- [ ] CNN 출력 크기 = $\lfloor(H+2p-k)/s\rfloor + 1$
- [ ] Attention = $\text{softmax}(QK^\top/\sqrt{d_k})V$
- [ ] ELBO = $\mathbb{E}_q[\log p(x|z)] - D_{KL}(q\|p(z))$
- [ ] Bias-Variance = $\mathbb{E}[(h-f)^2] = \text{Var}[h] + \text{Bias}^2$
- [ ] GD 수렴 조건: $\eta < 2/\lambda_{\max}(H)$
- [ ] Adam 기본값: $\beta_1=0.9, \beta_2=0.999, \varepsilon=10^{-8}$
- [ ] 역전파: $\partial L/\partial W = (\partial L/\partial z) \cdot x^\top$
- [ ] 파라미터 수: Linear=$d_{in} \times d_{out} + d_{out}$, Conv=$c_{out} \times c_{in} \times k^2 + c_{out}$

## 반드시 이해해야 할 것 (서술형 대비)

- [ ] SGD가 flat minima를 유도하는 이유 (확률적 잡음 → sharp minima 탈출)
- [ ] CNN의 귀납적 편향: 지역성 + 이동 등변성
- [ ] Transformer가 RNN을 대체한 이유 (병렬화 + 장거리 의존성)
- [ ] VAE의 ELBO가 왜 하한인지 (Jensen 부등식 또는 KL ≥ 0)
- [ ] Diffusion의 forward/reverse process와 denoising loss의 직관
- [ ] Double Descent 현상의 직관적 설명
- [ ] 과적합 vs 과소적합의 진단과 해결
