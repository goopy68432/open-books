## 1. 집합 (Set)

### 1.1 집합이란?

#### 일상 비유

서랍 안에 물건을 넣는다고 생각하자. 서랍에는 **서로 다른 물건**만 들어갈 수 있고, 물건의 **순서는 상관없다**. 연필, 지우개, 자가 들어있는 서랍이든 자, 지우개, 연필이 들어있는 서랍이든 **같은 서랍**이다.

#### 정식 정의

> **집합(Set)**: 서로 다른 객체(object)들의 **순서 없는** 모임

- 집합을 이루는 각각의 객체를 **원소(element)** 라고 부른다.
- 집합은 보통 대문자 알파벳(A, B, S, ...)으로, 원소는 소문자(a, b, x, ...)로 표기한다.

#### 원소 표기

| 기호 | 의미 | 읽는 법 |
|------|------|---------|
| a ∈ A | a는 집합 A의 원소이다 | "a는 A에 속한다" |
| a ∉ A | a는 집합 A의 원소가 아니다 | "a는 A에 속하지 않는다" |

#### 구체적 예시

```
A = {1, 2, 3}

- 1 ∈ A   (1은 A에 속한다)  ✓
- 5 ∉ A   (5는 A에 속하지 않는다)  ✓
- {1, 2, 3} = {3, 1, 2}  (순서 무관)  ✓
- {1, 1, 2, 3} = {1, 2, 3}  (중복 원소는 하나로 취급)  ✓
```

#### 집합의 표현 방법

**1) 원소나열법** (직접 나열)
```
A = {1, 2, 3, 4, 5}
```

**2) 조건제시법** (조건으로 서술)
```
A = {x : x는 자연수이고, x ≤ 5}
```
여기서 콜론 `:` 은 "~인 것 중에서" 또는 "such that"으로 읽는다.

### 1.2 카테시안 곱 (Cartesian Product)

#### 일상 비유

카페 메뉴판을 떠올려보자. 음료 종류가 {아메리카노, 라떼}이고, 사이즈가 {S, L}이면, 주문 가능한 조합은:

```
(아메리카노, S), (아메리카노, L), (라떼, S), (라떼, L)
```

이렇게 **두 집합에서 하나씩 골라 순서쌍을 만드는 모든 조합**이 카테시안 곱이다.

#### 정식 정의

> A와 B가 집합일 때, **카테시안 곱(Cartesian Product)** 은 다음과 같이 정의된다:
>
> **A x B := {(a, b) : a ∈ A, b ∈ B}**

`:=` 는 "~로 정의한다"는 뜻이다.

#### 구체적 예시

```
A = {1, 2},  B = {x, y, z}

A x B = {(1,x), (1,y), (1,z), (2,x), (2,y), (2,z)}
```

- |A| = 2, |B| = 3이면 → |A x B| = 2 x 3 = **6개**
- 일반적으로 |A x B| = |A| x |B|

**주의**: 순서쌍이므로 (1, x) ≠ (x, 1) 이다. 집합은 순서가 없지만 순서쌍은 순서가 **있다**.

#### 딥러닝에서 왜 중요한가?

- 딥러닝에서 데이터는 **입력 공간 X**와 **출력 공간 Y**로 나뉜다.
- 학습 데이터 한 쌍 (x, y)는 카테시안 곱 X x Y의 원소이다.
  - 예: 이미지 분류에서 (고양이 이미지, "고양이" 라벨)
- 이렇게 수학적으로 표현해야 모델을 정의하고 분석할 수 있다.

#### 시험에 자주 나오는 유형

- "A = {1, 2, 3}, B = {a, b}일 때 A x B의 원소 수를 구하시오." → **6개**
- "A x B와 B x A는 같은가?" → **다르다** (순서쌍의 순서가 다르므로)
- "ℝ x ℝ = ℝ²는 무엇을 의미하는가?" → **2차원 좌표 평면의 모든 점의 집합**

## 2. 함수 (Function)

### 2.1 함수란?

#### 일상 비유

자판기를 생각하자. 버튼(입력)을 누르면 **반드시 하나의** 음료(출력)가 나온다.
- 버튼 A → 콜라
- 버튼 B → 사이다
- 버튼 C → 콜라 (다른 버튼이 같은 결과를 낼 수 있다)

하지만 **하나의 버튼을 눌렀는데 콜라가 나올 수도 있고 사이다가 나올 수도 있는** 자판기는 "함수"가 아니다. 하나의 입력에 반드시 **정확히 하나의** 출력이 대응되어야 한다.

#### 정식 정의

> **함수(Function)**: 집합 A의 **각 원소**에 집합 B의 원소를 **정확히 하나** 대응시키는 규칙
>
> **f: A → B,  a ↦ f(a)**

- **f: A → B** — "f는 A에서 B로의 함수이다"
- **a ↦ f(a)** — "a를 f(a)로 보낸다" (↦ 는 "~에 대응한다"로 읽는다)
- A를 **정의역(domain)**, B를 **공역(codomain)** 이라 한다.
- {f(a) : a ∈ A}를 **치역(range/image)** 이라 하며, 치역 ⊆ 공역이다.

#### 구체적 예시

```
A = {1, 2, 3},  B = {a, b, c, d}

f: A → B 를 다음과 같이 정의:
  f(1) = a
  f(2) = a
  f(3) = d

이것은 함수인가?  ✓ (A의 모든 원소에 B의 원소가 정확히 하나씩 대응)
```

**함수가 아닌 예**:
```
g(1) = a, g(1) = b   ← 하나의 입력에 두 개의 출력 → 함수 아님! ✗
g(1) = a, g(3) = b   ← g(2)가 정의 안 됨 → 함수 아님! ✗
```

#### 딥러닝에서 왜 중요한가?

- **신경망 자체가 하나의 함수**이다: f(이미지) = "고양이"
- 입력(이미지, 텍스트, 숫자 등)을 받아서 출력(분류, 예측값)을 내놓는 것
- 딥러닝 = "좋은 함수 f를 데이터로부터 자동으로 찾아내는 과정"

### 2.2 일대일 함수 (Injective / One-to-One Function)

#### 일상 비유

학교에서 사물함을 배정한다. **일대일 함수**는 "한 사물함에 한 학생만 배정"하는 것이다.
- 학생 A → 사물함 1, 학생 B → 사물함 2 ✓ (일대일)
- 학생 A → 사물함 1, 학생 B → 사물함 1 ✗ (일대일 아님)

#### 정식 정의

> f: A → B가 **일대일 함수(injective)** 라 함은:
>
> **a ≠ a'  →  f(a) ≠ f(a')**
>
> 동치 표현 (대우): f(a) = f(a')  →  a = a'

"서로 다른 입력은 반드시 서로 다른 출력을 낸다."

#### 구체적 예시

```
f: {1, 2, 3} → {a, b, c, d}

일대일인 예:
  f(1) = a, f(2) = c, f(3) = d   ✓  (모든 출력이 다름)

일대일 아닌 예:
  f(1) = a, f(2) = a, f(3) = d   ✗  (f(1) = f(2) = a인데 1 ≠ 2)
```

#### 딥러닝에서 왜 중요한가?

- 역전파(backpropagation) 등에서 함수가 일대일인지에 따라 역함수의 존재 여부가 달라진다.
- Flow-based 생성모델(예: Normalizing Flows)에서는 일대일 함수(가역 함수)를 핵심적으로 사용한다.

### 2.3 지시 함수 (Indicator Function)

#### 일상 비유

시험에서 "맞으면 1점, 틀리면 0점"을 매기는 채점 방식과 똑같다.

#### 정식 정의

> **지시 함수(Indicator Function)** **1**(p):
>
> **1**(p) = 1  (p가 참일 때)
> **1**(p) = 0  (p가 거짓일 때)

여기서 p는 참/거짓으로 판별할 수 있는 명제(조건)이다.

#### 구체적 예시

```
"x가 짝수인가?"라는 조건에 대해:

1(2는 짝수) = 1   ✓
1(3은 짝수) = 0   ✓
1(100은 짝수) = 1  ✓
```

좀 더 실용적인 예:
```
x = 7일 때,

1(x > 5) = 1    (7 > 5는 참)
1(x < 3) = 0    (7 < 3은 거짓)
1(x == 7) = 1   (7 == 7은 참)
```

#### 딥러닝에서 왜 중요한가?

- **손실 함수(loss function)** 에서 핵심적으로 사용된다.
- 분류 정확도: Accuracy = (1/N) Σ **1**(예측값 == 정답)
  - 맞춘 개수를 세는 것이 바로 지시 함수의 합!
- 0-1 loss: L = **1**(예측 ≠ 정답)

#### 시험에 자주 나오는 유형

- "1(3 > 2) + 1(1 > 5) + 1(4 = 4)의 값은?" → 1 + 0 + 1 = **2**
- "지시 함수를 이용해 분류 정확도를 수식으로 표현하시오"

## 3. 스칼라 (Scalar)

### 3.1 스칼라란?

#### 일상 비유

체중계에 올라가면 "65.3 kg"이라는 **하나의 숫자**가 나온다. 이처럼 **방향 없이 크기만 있는 하나의 수**가 스칼라이다. 온도 23.5도, 시험 점수 85점, 키 172.3cm — 모두 스칼라다.

이와 대비되는 것이 벡터인데, 벡터는 "동쪽으로 5km"처럼 **크기와 방향**을 함께 가진다. 스칼라는 크기만 있다.

#### 정식 정의

> **스칼라(Scalar)**: 실수 집합 ℝ에 속하는 하나의 수
>
> **s ∈ ℝ**

- ℝ (실수 집합): 정수, 유리수, 무리수를 모두 포함하는 수의 집합
  - 예: -3, 0, 0.5, √2, π, 100 모두 ℝ의 원소

#### 스칼라의 연산

| 연산 | 기호 | 예시 |
|------|------|------|
| 덧셈 | + | 3 + 5 = 8 |
| 뺄셈 | - | 7 - 2 = 5 |
| 곱셈 | x 또는 · | 4 x 3 = 12 |
| 나눗셈 | ÷ 또는 / | 10 / 2 = 5 |

#### 곱셈의 역원

> 0이 아닌 스칼라 s에 대해, **곱셈의 역원**은 1/s이다.
>
> s x (1/s) = 1

```
s = 5  →  역원 = 1/5  →  5 x (1/5) = 1  ✓
s = -3 →  역원 = -1/3 →  (-3) x (-1/3) = 1  ✓
s = 0  →  역원 없음! (0으로는 나눌 수 없다)
```

#### 딥러닝에서 왜 중요한가?

- **학습률(learning rate)** 이 대표적인 스칼라: α = 0.001
- **가중치(weight)** 하나하나가 스칼라
- **손실 값(loss)** 도 스칼라: 모델이 얼마나 틀렸는지를 하나의 숫자로 나타냄

## 4. 벡터 (Vector)

### 4.1 벡터란?

#### 일상 비유

**장보기 리스트**를 생각하자:

```
[사과 3개, 바나나 2개, 우유 1개]
```

이것은 숫자 3개를 **순서대로** 나열한 것이다. 순서가 중요하다 — [3, 2, 1]에서 첫 번째는 사과, 두 번째는 바나나, 세 번째는 우유를 의미하기 때문이다.

또 다른 비유: 학생의 **성적표**
```
[국어 85점, 수학 92점, 영어 78점] = [85, 92, 78]
```

이렇게 **여러 숫자를 순서대로 묶어놓은 것**이 벡터이다.

#### 정식 정의

> **벡터(Vector)**: 실수의 **순서 있는** 나열
>
> **v = [v₁, v₂, ..., vₙ]ᵀ ∈ ℝⁿ**

- vᵢ: 벡터 v의 i번째 **성분(component)**
- n: 벡터의 **차원(dimension)** — 성분의 개수
- ᵀ: 전치(transpose) 기호 — 세로(열) 벡터임을 표시
- ℝⁿ: n차원 실수 벡터 공간 (= ℝ x ℝ x ... x ℝ, n번 카테시안 곱)

#### 구체적 예시

```
v = [3, -1, 4]ᵀ ∈ ℝ³

- v₁ = 3  (첫 번째 성분)
- v₂ = -1 (두 번째 성분)
- v₃ = 4  (세 번째 성분)
- 차원: 3차원

열 벡터로 쓰면:
    ┌  3 ┐
v = │ -1 │
    └  4 ┘
```

#### 딥러닝에서 왜 중요한가?

- **입력 데이터**가 벡터이다: 이미지의 픽셀 값들, 단어의 임베딩 등
- 예: 28x28 흑백 이미지 → 784차원 벡터 [p₁, p₂, ..., p₇₈₄]ᵀ
- 신경망의 각 층은 벡터를 입력받아 벡터를 출력한다

---

### 4.2 벡터 연산

#### 벡터 덧셈

같은 차원의 벡터끼리 **같은 위치의 성분을 더한다**.

```
v = [1, 3, 5]ᵀ
w = [2, -1, 4]ᵀ

v + w = [1+2, 3+(-1), 5+4]ᵀ = [3, 2, 9]ᵀ
```

비유: 나의 장보기 리스트 [사과 3, 바나나 2] + 동생의 리스트 [사과 1, 바나나 5] = 합계 [사과 4, 바나나 7]

#### 스칼라 곱 (Scalar Multiplication)

벡터의 **모든 성분에 같은 스칼라를 곱한다**.

```
s = 3
v = [2, -1, 4]ᵀ

sv = 3 x [2, -1, 4]ᵀ = [6, -3, 12]ᵀ
```

비유: 장보기 리스트를 3배로 → [사과 2, 바나나 1] x 3 = [사과 6, 바나나 3]

#### 주의사항

```
차원이 다른 벡터끼리는 더할 수 없다!

[1, 2]ᵀ + [3, 4, 5]ᵀ = ???  ← 불가능! (2차원 + 3차원)
```

### 4.3 유클리드 공간의 계층 구조

벡터 공간에는 여러 "레벨"이 있다. 위로 갈수록 더 풍부한 구조를 가진다.

```
내적 공간 (Inner Product Space)     ← 가장 풍부: 각도 측정 가능
    ⊂
노름 공간 (Normed Space)            ← 길이 측정 가능
    ⊂
벡터 공간 (Vector Space)            ← 덧셈, 스칼라곱 가능
    ⊂
거리 공간 (Metric Space)            ← 거리 측정 가능
```

비유로 이해하기:

| 공간 | 비유 | 할 수 있는 것 |
|------|------|--------------|
| 거리 공간 | 거리만 알 수 있는 GPS | "A와 B는 5km 떨어져 있다" |
| 벡터 공간 | 이동 가능한 지도 | "동쪽 3 + 북쪽 4 = 이동 벡터" |
| 노름 공간 | 자(ruler)가 있는 지도 | "이 벡터의 길이는 5이다" |
| 내적 공간 | 각도기도 있는 지도 | "두 벡터 사이 각도는 60도이다" |

**포함 관계 (⊂)의 의미**: 내적 공간이면 자동으로 노름 공간이고, 노름 공간이면 자동으로 벡터 공간이다. 위의 구조가 아래의 구조를 포함한다.

#### 딥러닝에서 왜 중요한가?

- 딥러닝에서 다루는 ℝⁿ은 **내적 공간**이다 (가장 풍부한 구조).
- 따라서 벡터의 길이, 거리, 각도를 **모두** 계산할 수 있다.
- 이 세 가지 도구로 "유사도 측정", "오차 계산", "직교 분해" 등 핵심 연산을 수행한다.

### 4.4 내적 (Inner Product / Dot Product)

#### 일상 비유

두 학생이 각 과목에 투자한 시간과 각 과목의 점수 가중치가 있다고 하자:

```
투자 시간: [3시간(국어), 5시간(수학), 2시간(영어)]
가중치:    [2점/시간, 3점/시간, 4점/시간]

총점 = 3x2 + 5x3 + 2x4 = 6 + 15 + 8 = 29점
```

이 "같은 위치끼리 곱해서 전부 더하는 것"이 내적이다.

#### 정식 정의

> 두 벡터 v, w ∈ ℝⁿ에 대해 **내적(inner product)** 은:
>
> **⟨v, w⟩ = v₁w₁ + v₂w₂ + ... + vₙwₙ**

- 결과는 **스칼라** (하나의 숫자)이다!
- 두 벡터를 넣으면 숫자 하나가 나온다.

#### 구체적 예시

```
v = [1, 2, 3]ᵀ
w = [4, -1, 2]ᵀ

⟨v, w⟩ = (1)(4) + (2)(-1) + (3)(2)
       = 4 + (-2) + 6
       = 8
```

#### 내적의 성질

| 성질 | 수식 | 의미 |
|------|------|------|
| 교환법칙 | ⟨v, w⟩ = ⟨w, v⟩ | 순서 바꿔도 같다 |
| 선형성 | ⟨av + bu, w⟩ = a⟨v, w⟩ + b⟨u, w⟩ | 분배법칙 성립 |
| 양정치성 | ⟨v, v⟩ ≥ 0, 등호는 v = 0일 때만 | 자기 자신과의 내적은 항상 0 이상 |

#### 딥러닝에서 왜 중요한가?

- **신경망의 뉴런 하나가 하는 일이 바로 내적**이다!
  - 뉴런 = ⟨가중치, 입력⟩ + 편향 = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
- **코사인 유사도**: 두 벡터가 얼마나 비슷한 방향인지 = 내적 기반
- 추천 시스템: 사용자 벡터와 아이템 벡터의 내적 = 선호도 점수

---

### 4.5 노름 (Norm) — 벡터의 길이

#### 일상 비유

집에서 학교까지의 **직선 거리**를 구하는 것과 같다. 동쪽으로 3km, 북쪽으로 4km 가야 한다면 직선 거리는 √(3² + 4²) = √25 = 5km이다. (피타고라스 정리!)

#### 정식 정의

> 벡터 v ∈ ℝⁿ의 **(L2) 노름**은:
>
> **‖v‖ = √⟨v, v⟩ = √(v₁² + v₂² + ... + vₙ²)**

- ‖v‖ 기호는 "v의 노름" 또는 "v의 크기"로 읽는다.
- 내적으로 정의된다는 것에 주목 → 내적 공간이면 자동으로 노름이 정의됨

#### 구체적 예시

```
v = [3, 4]ᵀ

‖v‖ = √(3² + 4²) = √(9 + 16) = √25 = 5
```

```
w = [1, -2, 2]ᵀ

‖w‖ = √(1² + (-2)² + 2²) = √(1 + 4 + 4) = √9 = 3
```

#### 노름의 성질

| 성질 | 수식 | 의미 |
|------|------|------|
| 비음수성 | ‖v‖ ≥ 0 | 길이는 0 이상 |
| 영벡터 | ‖v‖ = 0 ⟺ v = 0 | 길이가 0인 벡터는 영벡터뿐 |
| 스칼라곱 | ‖sv‖ = |s| · ‖v‖ | 3배 늘리면 길이도 3배 |
| 삼각부등식 | ‖v + w‖ ≤ ‖v‖ + ‖w‖ | 두 변의 합 ≥ 나머지 한 변 |

#### 단위 벡터 (Unit Vector)

노름이 1인 벡터를 **단위 벡터**라 한다.

임의의 벡터 v를 단위 벡터로 만들기 (**정규화, normalization**):

```
v̂ = v / ‖v‖

예: v = [3, 4]ᵀ → v̂ = [3/5, 4/5]ᵀ
    ‖v̂‖ = √((3/5)² + (4/5)²) = √(9/25 + 16/25) = √(25/25) = 1  ✓
```

#### 딥러닝에서 왜 중요한가?

- **그래디언트의 노름**: 학습이 안정적인지 판단하는 지표 (gradient clipping)
- **정규화(normalization)**: 입력 데이터를 단위 벡터로 만들면 학습이 빨라진다
- **가중치 감쇠(weight decay)**: ‖w‖²을 손실에 더해 가중치가 너무 커지는 것을 방지

---

### 4.6 거리 (Metric / Distance)

#### 일상 비유

두 사람 사이의 **물리적 거리**를 재는 것이다. A가 (1, 2)에 있고 B가 (4, 6)에 있으면, A에서 B까지의 거리를 계산할 수 있다.

#### 정식 정의

> 두 벡터 v, w ∈ ℝⁿ 사이의 **(유클리드) 거리**는:
>
> **d(v, w) = ‖v - w‖ = √((v₁-w₁)² + (v₂-w₂)² + ... + (vₙ-wₙ)²)**

핵심: 거리 = 차이 벡터의 노름

#### 구체적 예시

```
v = [1, 2]ᵀ,  w = [4, 6]ᵀ

v - w = [1-4, 2-6]ᵀ = [-3, -4]ᵀ

d(v, w) = ‖v - w‖ = √((-3)² + (-4)²) = √(9 + 16) = √25 = 5
```

#### 거리의 성질

| 성질 | 수식 | 의미 |
|------|------|------|
| 비음수성 | d(v, w) ≥ 0 | 거리는 0 이상 |
| 동치 | d(v, w) = 0 ⟺ v = w | 거리 0이면 같은 점 |
| 대칭성 | d(v, w) = d(w, v) | A→B 거리 = B→A 거리 |
| 삼각부등식 | d(v, u) ≤ d(v, w) + d(w, u) | 직선이 가장 짧다 |

#### 딥러닝에서 왜 중요한가?

- **손실 함수의 핵심**: MSE Loss ∝ d(예측, 정답)² → 예측과 정답 사이 거리를 줄이는 것이 학습!
- **K-최근접 이웃(KNN)**: 거리가 가까운 k개의 데이터를 찾아 분류
- **임베딩 공간**: 의미가 비슷한 단어는 거리가 가까움 ("왕" - "남자" + "여자" ≈ "여왕")

---

### 4.7 직교 (Orthogonality)

#### 일상 비유

십자 교차로를 생각하자. 동서 방향 도로와 남북 방향 도로는 **90도로 만난다**. 이렇게 두 방향이 완전히 독립적(서로 영향을 주지 않는)일 때 "직교한다"고 말한다.

#### 정식 정의

> 두 벡터 v, w가 **직교(orthogonal)** 한다:
>
> **v ⊥ w  ⟺  ⟨v, w⟩ = 0**

"내적이 0이면 직교한다."

#### 구체적 예시

```
v = [1, 0]ᵀ  (→ 동쪽 방향)
w = [0, 1]ᵀ  (↑ 북쪽 방향)

⟨v, w⟩ = (1)(0) + (0)(1) = 0  → v ⊥ w ✓
```

```
v = [1, 2]ᵀ
w = [2, -1]ᵀ

⟨v, w⟩ = (1)(2) + (2)(-1) = 2 - 2 = 0  → v ⊥ w ✓
```

```
v = [1, 1]ᵀ
w = [1, 2]ᵀ

⟨v, w⟩ = (1)(1) + (1)(2) = 1 + 2 = 3 ≠ 0  → v ⊥ w ✗ (직교 아님)
```

#### 딥러닝에서 왜 중요한가?

- **직교 = 독립적 정보**: 직교하는 특성(feature)들은 서로 중복 없이 다른 정보를 담는다
- **PCA(주성분 분석)**: 데이터를 직교하는 축들로 분해하여 차원 축소
- **직교 초기화(orthogonal initialization)**: 가중치를 직교 행렬로 초기화하면 학습 안정성 향상

---

### 4.8 개념 간 관계 요약

```
내적(inner product)
  │
  ├── 자기 자신과 내적 → 노름²(norm²)
  │     │
  │     └── 차이 벡터의 노름 → 거리(metric)
  │
  └── 내적이 0인지 확인 → 직교(orthogonality)
```

**핵심**: 내적 하나만 알면 노름, 거리, 직교가 **전부** 정의된다!

```
                    ⟨v, w⟩ (내적)
                   /       \
           ⟨v, v⟩            = 0 ?
             ↓                 ↓
         ‖v‖ = √⟨v,v⟩     v ⊥ w (직교)
             ↓
      d(v,w) = ‖v-w‖ (거리)
```

**(iii)** 함수 ✗ — f(2)가 정의되지 않았다. 정의역의 모든 원소에 대해 값이 있어야 한다.

**(iv)** 함수 ✗ — f(1) = a이면서 f(1) = b이다. 하나의 입력에 두 개의 출력은 불가능하다.

### 문제 4: 지시 함수

다음을 계산하시오.

**(a)** **1**(7 > 3) + **1**(2 > 5) + **1**(4 = 4)

**(b)** 예측값이 [고양이, 개, 고양이, 새], 정답이 [고양이, 고양이, 고양이, 새]일 때, 지시 함수를 이용하여 정확도(Accuracy)를 구하시오.

<details>
<summary>풀이 보기</summary>

**(a)**
- 1(7 > 3) = 1 (참)
- 1(2 > 5) = 0 (거짓)
- 1(4 = 4) = 1 (참)
- 합: 1 + 0 + 1 = **2**

**(b)**
```
Accuracy = (1/N) Σ 1(예측ᵢ = 정답ᵢ)
         = (1/4) [1(고양이=고양이) + 1(개=고양이) + 1(고양이=고양이) + 1(새=새)]
         = (1/4) [1 + 0 + 1 + 1]
         = (1/4)(3)
         = 3/4 = 0.75 = 75%
```

</details>

### 문제 10: 개념 서술형

**(a)** 딥러닝에서 내적이 어떻게 사용되는지 한 문장으로 설명하시오.

**(b)** 유클리드 공간의 계층 구조(내적 공간 ⊂ 노름 공간 ⊂ 벡터 공간 ⊂ 거리 공간)에서, 내적이 정의되면 노름이 자동으로 정의되는 이유를 설명하시오.

**(c)** 지시 함수를 이용하여 분류 모델의 정확도 공식을 쓰시오.

<details>
<summary>풀이 보기</summary>

**(a)** 신경망의 각 뉴런은 입력 벡터와 가중치 벡터의 내적을 계산한 후 활성화 함수를 적용하는 구조로 작동한다.

**(b)** 노름은 ‖v‖ = √⟨v, v⟩로 정의된다. 즉, 내적이 있으면 벡터 자기 자신과의 내적을 통해 노름을 구할 수 있으므로 노름이 자동으로 정의된다.

**(c)** Accuracy = (1/N) Σᵢ₌₁ᴺ **1**(ŷᵢ = yᵢ)

여기서 N은 전체 데이터 수, ŷᵢ는 모델의 예측값, yᵢ는 정답이다.

</details>

```
┌─────────────────────────────────────────────────────────┐
│                    빠른 복습 카드                         │
├─────────────────────────────────────────────────────────┤
│ 카테시안 곱  │ A x B = {(a,b) : a ∈ A, b ∈ B}          │
│ 함수        │ f: A → B, 각 a에 정확히 하나의 f(a)       │
│ 일대일      │ a ≠ a' → f(a) ≠ f(a')                    │
│ 지시 함수   │ 1(참) = 1, 1(거짓) = 0                   │
│ 내적        │ ⟨v,w⟩ = Σ vᵢwᵢ  (→ 스칼라)              │
│ 노름        │ ‖v‖ = √⟨v,v⟩  (→ 스칼라, 길이)          │

│ 직교        │ v ⊥ w ⟺ ⟨v,w⟩ = 0                      │
│ 정규화      │ v̂ = v / ‖v‖  (단위벡터 만들기)            │
│ 관계        │ 내적 → 노름 → 거리  /  내적 → 직교       │
└─────────────────────────────────────────────────────────┘
```
