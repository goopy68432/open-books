## 1.1 전이학습 직관

### 피아노에서 기타로: 전이학습의 본질

전이학습은 우리가 일상에서 자연스럽게 하는 일이다.

**비유**: 피아노를 10년 동안 배운 사람이 기타를 새로 시작한다고 하자.

| 피아노에서 이미 배운 것 (전이 가능) | 기타에서 새로 배워야 하는 것 |
|------|------|
| 음계, 화음 구조 이해 | 기타 코드 잡는 손 모양 |
| 리듬감과 박자 감각 | 피크 사용법, 스트럼 패턴 |
| 악보 읽는 능력 | 기타 타브 악보 |
| 음악적 표현력 | 기타 특유의 주법 (벤딩, 슬라이드) |

이 사람은 음악을 전혀 모르는 초보자보다 **훨씬 빠르게** 기타를 배운다. 기초적인 음악 지식이 악기 간에 **전이(transfer)** 되기 때문이다.

딥러닝에서도 동일한 원리가 적용된다:

```
[대규모 데이터로 학습한 모델]  ──전이──▶  [내 소규모 데이터에 적용]
     (ImageNet 1400만 장)                    (의료 X-ray 500장)

피아노 10년 경력              ──전이──▶   기타 초보
```

### 왜 전이학습이 효과적인가?

신경망의 초반 레이어는 **범용적 특징**(edge, texture, color 등)을 학습한다. 이 특징은 거의 모든 시각 과제에서 유용하다. 마치 피아노에서 배운 음계 지식이 어떤 악기를 배우든 도움이 되는 것과 같다.

후반 레이어만 새 과제에 맞게 조정하면, 소량의 데이터로도 높은 성능을 얻을 수 있다.

### 본 교재와의 연결

본 교재 1.1절의 "일상적 비유"와 동일한 맥락이다. 본 교재에서 설명하는 "ImageNet 사전학습 = 초등학교 교육" 비유를 떠올려 보자. 입문 단계에서는 이 직관을 확실히 잡는 것이 중요하다.

## 1.2 Fine-Tuning 기초

### Fine-Tuning이란?

Fine-tuning은 사전학습된 모델을 내 데이터에 맞게 **미세 조정**하는 과정이다.

**비유**: 기성복을 사서 내 몸에 맞게 수선하는 것.

- 옷 전체를 새로 만들지 않는다 (처음부터 학습하지 않는다)
- 허리, 소매 길이만 조절한다 (일부 레이어만 재학습한다)
- 원래 옷의 디자인과 원단은 그대로 활용한다 (사전학습 가중치 활용)

### 3가지 전략

```
전략 1: Feature Extraction (특징 추출만)
┌──────────────────────────────────┐
│ 사전학습된 레이어 (모두 고정 🔒)    │
├──────────────────────────────────┤
│ 새로운 분류기 레이어 (학습 🔓)     │
└──────────────────────────────────┘
→ 데이터가 매우 적을 때 (수백 장)

전략 2: Partial Fine-Tuning (부분 조정)
┌──────────────────────────────────┐
│ 초반 레이어 (고정 🔒)              │
├──────────────────────────────────┤
│ 후반 레이어 (학습 🔓)              │
├──────────────────────────────────┤
│ 새로운 분류기 레이어 (학습 🔓)     │
└──────────────────────────────────┘
→ 데이터가 중간 수준일 때 (수천 장)

전략 3: Full Fine-Tuning (전체 조정)
┌──────────────────────────────────┐
│ 모든 레이어 (학습 🔓)              │
│ (낮은 learning rate 사용)          │
├──────────────────────────────────┤
│ 새로운 분류기 레이어 (학습 🔓)     │
└──────────────────────────────────┘
→ 데이터가 충분할 때 (수만 장 이상)
```

### 핵심 팁

- **Learning Rate**: Fine-tuning 시에는 사전학습 때보다 **훨씬 작은 learning rate**를 사용한다 (보통 10~100배 작게). 이미 좋은 위치에 있는 가중치를 크게 바꾸면 기존 지식이 파괴된다.
- **Layer-wise Learning Rate**: 초반 레이어는 더 작은 lr, 후반 레이어는 더 큰 lr을 적용하기도 한다.

## 1.3 오토인코더 개념

### 오토인코더란?

입력 데이터를 **압축했다가 다시 복원**하는 신경망이다.

**비유**: 여행 가방 싸기

```
원본 옷 10벌           →  압축해서 가방에 넣기  →  꺼내서 다시 펼치기
(입력 x)                  (인코더 → 잠재벡터 z)    (디코더 → 복원 x̂)
```

- 가방이 작을수록 (잠재 공간 차원이 작을수록) 압축이 더 어렵다
- 잘 압축하려면 옷의 **핵심 특징**(소재, 크기, 접는 방식)을 파악해야 한다
- 신경망도 마찬가지: 핵심 특징을 추출하는 법을 **스스로** 학습한다

```
입력 x  ──▶  인코더(압축)  ──▶  잠재벡터 z  ──▶  디코더(복원)  ──▶  출력 x̂
  │                                                                    │
  └──────────────── 손실 = ‖x - x̂‖² (차이를 최소화) ─────────────────┘
```

### 오토인코더의 활용

| 활용 분야 | 설명 |
|-----------|------|
| 차원 축소 | PCA처럼 데이터를 저차원으로 압축하되, 비선형 관계도 포착 |
| 노이즈 제거 | 노이즈가 있는 입력을 넣고 깨끗한 출력을 복원하도록 학습 |
| 이상 탐지 | 정상 데이터만 학습 → 비정상 데이터는 복원 오류가 큼 |
| 생성모델의 기초 | VAE, Diffusion Model 등의 기반 구조 |

### 본 교재와의 연결

본 교재 4절(VAE)에서 오토인코더를 확장한 모델을 다룬다. 입문 단계에서는 "압축과 복원"이라는 기본 개념을 확실히 이해하는 것이 우선이다.

## 1.4 GAN 기본 아이디어

### GAN이란?

**G**enerative **A**dversarial **N**etwork — 두 신경망이 **경쟁**하며 학습하는 생성 모델.

**비유**: 위조지폐범 vs 경찰

```
위조지폐범 (Generator)              경찰 (Discriminator)
  "진짜처럼 보이는                     "이게 진짜인지
   가짜를 만들자"                       가짜인지 판별하자"
        │                                    │
        ▼                                    ▼
   가짜 이미지 생성  ──────▶  진짜/가짜 판별
        ▲                         │
        │                         │
        └── 판별 결과로 더 잘 속이도록 개선 ──┘
```

- **Generator (G)**: 랜덤 노이즈 z를 입력받아 가짜 이미지를 생성
- **Discriminator (D)**: 이미지를 보고 진짜(1)인지 가짜(0)인지 판별

둘이 경쟁하다 보면:
- G는 점점 더 진짜 같은 이미지를 만들게 되고
- D는 점점 더 정교하게 판별하게 되며
- 결국 G가 만든 이미지가 진짜와 구분이 안 될 정도가 된다

### GAN이 혁신적인 이유

기존 생성모델(오토인코더 등)은 복원 오류를 직접 최소화하기 때문에, 결과물이 흐릿(blurry)하게 되기 쉽다. GAN은 "진짜처럼 보이는가?"라는 **판별기의 판단**을 기준으로 학습하기 때문에, **훨씬 선명하고 현실적인** 이미지를 생성한다.

### 입문자를 위한 핵심 정리

| 생성모델 | 핵심 아이디어 | 장점 | 단점 |
|----------|-------------|------|------|
| 오토인코더 | 압축 → 복원 | 간단, 안정적 학습 | 흐릿한 결과 |
| GAN | 생성자 vs 판별자 경쟁 | 선명한 결과 | 학습 불안정 |
| VAE | 확률적 압축 → 복원 | 다양한 결과 | 흐릿한 경향 |
| Diffusion | 노이즈 추가 → 제거 | 고품질 + 다양성 | 느린 생성 |

## 2.1 도메인 적응 (Domain Adaptation)

### 문제 정의

전이학습의 핵심 도전과제: **소스 도메인**에서 학습한 모델을 **타겟 도메인**에 적용할 때, 두 도메인의 데이터 분포가 다르면 성능이 떨어진다.

```
소스 도메인 (p_S)              타겟 도메인 (p_T)
  실제 사진으로 학습             스케치 이미지에 적용
  ┌───────────┐                ┌───────────┐
  │  📷 실사   │  ──적용──▶   │  ✏️ 스케치  │
  │  말 사진   │  성능 하락!   │  말 그림    │
  └───────────┘                └───────────┘
```

### 도메인 적응의 3가지 유형

| 유형 | 타겟 도메인 라벨 | 대표 기법 |
|------|---------------|----------|
| **Supervised** | 소량의 라벨 존재 | Fine-tuning, Few-shot learning |
| **Semi-supervised** | 극소량 라벨 + 대량 비라벨 | Pseudo-labeling, Mean Teacher |
| **Unsupervised** | 라벨 없음 | Domain Adversarial Training, MMD |

### 핵심 기법: Domain Adversarial Neural Network (DANN)

GAN의 아이디어를 도메인 적응에 적용한 기법이다.

```
입력 x  ──▶  특징 추출기 (Feature Extractor)
                    │
              ┌─────┴─────┐
              ▼           ▼
         분류기         도메인 판별기
      (Label Predictor)  (Domain Classifier)
       "고양이인가?"      "소스인가? 타겟인가?"
              │                 │
         분류 손실 ↓        도메인 손실 ↑ (Gradient Reversal!)
```

핵심 아이디어: 특징 추출기가 **도메인 판별기를 속이도록** 학습한다 (Gradient Reversal Layer). 이렇게 하면 소스와 타겟 도메인에서 **구분이 안 되는 특징**을 추출하게 된다.

목표 함수:

```
min_{θ_f, θ_y} max_{θ_d}  L_class(θ_f, θ_y) - λ · L_domain(θ_f, θ_d)
```

- `L_class`: 분류 손실 (소스 도메인에서 라벨 맞추기)
- `L_domain`: 도메인 판별 손실 (어느 도메인인지 맞추기)
- λ: 도메인 적응 강도 제어

### 기타 핵심 기법

**Maximum Mean Discrepancy (MMD)**: 두 분포 사이의 거리를 커널 함수로 측정

```
MMD²(p, q) = E[k(x,x')] - 2E[k(x,y)] + E[k(y,y')]
              x,x'~p        x~p,y~q     y,y'~q
```

두 도메인의 특징 분포를 가깝게 만들도록 학습한다.

## 2.2 자기지도 사전학습 (BERT, SimCLR, CLIP)

자기지도학습(Self-Supervised Learning, SSL)은 **라벨 없는 데이터**에서 유용한 표현을 학습하는 방법이다. 데이터 자체에서 "가짜 라벨"(pseudo-label)을 만들어 학습한다.

### 2.2.1 BERT: 빈칸 채우기로 언어 이해하기

```
입력:  "오늘 날씨가 [MASK] 좋다"
목표:  [MASK] = "정말"을 예측
```

**Masked Language Modeling (MLM)**:
- 입력 토큰의 15%를 무작위로 마스킹
- 모델이 마스킹된 토큰을 예측
- 양방향 문맥(앞뒤 단어 모두)을 활용

**Next Sentence Prediction (NSP)**:
- 두 문장이 연속된 문장인지 예측
- 문장 간 관계 이해 학습

BERT는 이 두 가지 사전학습 과제로 대량의 비라벨 텍스트에서 언어 표현을 학습하고, 이후 다양한 NLP 과제에 fine-tuning 한다.

### 2.2.2 SimCLR: 같은 이미지의 다른 뷰를 가까이

SimCLR는 시각 표현의 자기지도학습에서 대표적인 대조학습(Contrastive Learning) 프레임워크이다.

```
         원본 이미지 x
           /     \
     augment_1   augment_2
        ↓           ↓
       x_i         x_j       ← 양성 쌍(positive pair)
        ↓           ↓
    인코더 f     인코더 f     ← 같은 가중치 공유
        ↓           ↓
       h_i         h_j
        ↓           ↓
   프로젝터 g   프로젝터 g    ← MLP 헤드
        ↓           ↓
       z_i         z_j
        ↓           ↓
    NT-Xent Loss (대조 손실)
```

**NT-Xent Loss (Normalized Temperature-scaled Cross-Entropy)**:

```
ℓ(i,j) = -log [ exp(sim(z_i, z_j)/τ) / Σ_{k≠i} exp(sim(z_i, z_k)/τ) ]
```

- `sim(u,v) = u·v / (‖u‖·‖v‖)`: 코사인 유사도
- `τ`: 온도(temperature) 하이퍼파라미터
- 분자: 양성 쌍의 유사도를 높이고
- 분모: 음성 쌍(batch 내 다른 모든 이미지)과의 유사도를 낮춘다

**SimCLR의 핵심 발견**:
1. **데이터 증강 조합이 중요**: random crop + color jitter의 조합이 가장 효과적
2. **프로젝션 헤드의 역할**: 비선형 프로젝션 헤드 g(·)가 표현 품질을 크게 향상
3. **큰 배치 크기**: 대조학습은 배치가 클수록 (음성 샘플이 많을수록) 효과적

### 2.2.3 CLIP: 이미지와 텍스트를 같은 공간으로

CLIP (Contrastive Language-Image Pre-training)은 이미지와 텍스트를 **동일한 임베딩 공간**에 매핑한다.

```
      이미지                    텍스트
   ┌─────────┐            ┌──────────────┐
   │  🐕 사진 │            │"a photo of   │
   │         │            │ a dog"        │
   └────┬────┘            └──────┬───────┘
        ▼                        ▼
  이미지 인코더              텍스트 인코더
   (ViT/ResNet)              (Transformer)
        ▼                        ▼
       I_i                      T_j
        └────── 코사인 유사도 ──────┘

목표: 매칭되는 (이미지, 텍스트) 쌍의 유사도 ↑
      매칭되지 않는 쌍의 유사도 ↓
```

**CLIP의 혁신**:
- 4억 개의 (이미지, 텍스트) 쌍으로 학습
- Zero-shot 분류 가능: 학습 시 본 적 없는 클래스도 텍스트 설명만으로 분류
- 다양한 시각 과제에 범용적으로 전이 가능

### 자기지도학습의 3대 패러다임 비교

| 패러다임 | 대표 모델 | 핵심 아이디어 | 도메인 |
|---------|----------|-------------|--------|
| 마스킹 예측 | BERT, MAE | 일부를 가리고 예측 | NLP, Vision |
| 대조학습 | SimCLR, MoCo | 같은 것은 가까이, 다른 것은 멀리 | Vision |
| 멀티모달 대조 | CLIP, ALIGN | 이미지-텍스트 쌍의 대조학습 | Vision + NLP |

## 2.3 VAE와 Reparameterization Trick

### VAE의 핵심: 확률적 인코딩

일반 오토인코더는 입력을 하나의 **고정된 점(point)** 으로 인코딩한다. VAE는 입력을 **확률 분포(distribution)** 로 인코딩한다.

```
일반 오토인코더:  x → z (하나의 점)
VAE:              x → (μ, σ²) (평균과 분산 → 정규분포)
                      그 분포에서 z를 샘플링
```

### 왜 분포로 인코딩하는가?

하나의 점으로 인코딩하면, 잠재 공간에 "빈 구멍"이 생긴다. 그 빈 곳에서 z를 샘플링하면 의미 없는 결과가 생성된다. 분포로 인코딩하면 잠재 공간이 **연속적이고 채워진** 상태가 되어, 어디서 샘플링해도 의미 있는 결과를 생성할 수 있다.

### Reparameterization Trick

**문제**: z ~ N(μ, σ²)에서 샘플링하는 연산은 **미분이 불가능**하다. 따라서 역전파로 μ, σ를 학습할 수 없다.

**해결**: 샘플링을 결정적 연산으로 바꾼다.

```
원래: z = sample(N(μ, σ²))         ← 확률적, 미분 불가
변환: ε ~ N(0, 1)                   ← 고정된 분포에서 샘플링 (학습 불필요)
      z = μ + σ · ε                 ← 결정적 연산, 미분 가능!
```

```
         ε ~ N(0,1)
            │
            ▼
x → 인코더 → μ, σ → z = μ + σ·ε → 디코더 → x̂
         ↑                              │
         └── 역전파 가능! ──────────────┘
```

이제 ε은 상수처럼 취급되므로, z에 대한 μ, σ의 그래디언트를 계산할 수 있다:

```
∂z/∂μ = 1
∂z/∂σ = ε
```

### VAE 손실 함수

```
L_VAE = E_q[log p(x|z)]  -  KL(q(z|x) ‖ p(z))
        ─────────────────    ─────────────────────
         복원 손실              정규화 항
      (디코더가 잘 복원하는가?)   (잠재 분포가 N(0,1)에 가까운가?)
```

KL 발산 항의 닫힌 형태 (closed-form):

```
KL(N(μ, σ²) ‖ N(0, 1)) = -½ Σ_j (1 + log(σ_j²) - μ_j² - σ_j²)
```

### 본 교재와의 연결

본 교재 4절에서 VAE의 ELBO 유도를 자세히 다룬다. 여기서는 Reparameterization Trick의 **직관적 이해**에 집중했다.

## 2.4 GAN 학습 역학 (Training Dynamics)

### Min-Max 게임

GAN의 목표 함수:

```
min_G max_D  V(D, G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]
```

| 항 | D의 관점 | G의 관점 |
|----|---------|---------|
| E[log D(x)] | 진짜를 진짜라고 하고 싶음 (↑) | D가 관여, G 무관 |
| E[log(1-D(G(z)))] | 가짜를 가짜라고 하고 싶음 (↑) | 가짜를 진짜라고 속이고 싶음 (↓) |

### 학습의 어려움

**1. 모드 붕괴 (Mode Collapse)**

Generator가 다양한 샘플을 만들지 않고, 소수의 "안전한" 샘플만 반복 생성하는 현상.

```
실제 분포: 🐕 🐈 🐦 🐟 (다양한 동물)
모드 붕괴:  🐕 🐕 🐕 🐕 (강아지만 생성)
```

**2. 학습 불안정성**

D가 너무 강하면 → G에게 유용한 그래디언트가 전달되지 않음 (vanishing gradient)
D가 너무 약하면 → G가 제대로 학습하지 못함

**3. 평가의 어려움**

생성 품질을 측정할 표준적인 손실 함수가 없음. D의 손실이 줄어든다고 G가 좋아지는 것은 아님.

### 안정화 기법들

| 기법 | 핵심 아이디어 |
|------|-------------|
| **WGAN** | Wasserstein distance 사용 → 더 안정적인 그래디언트 |
| **Spectral Normalization** | D의 가중치를 정규화하여 Lipschitz 조건 만족 |
| **Progressive Growing** | 저해상도 → 고해상도로 점진적 학습 (ProGAN) |
| **StyleGAN** | 스타일 기반 생성으로 고품질 이미지 생성 |

## 2.5 조건부 생성 (Conditional Generation)

### 아이디어

무작위 생성이 아니라, **조건을 지정**하여 원하는 것을 생성한다.

```
무조건부: z ──▶ G ──▶ 무작위 이미지
조건부:   z + 조건 c ──▶ G ──▶ 조건에 맞는 이미지
```

### 조건 종류

| 조건 유형 | 예시 | 대표 모델 |
|----------|------|----------|
| 클래스 라벨 | "고양이" → 고양이 이미지 생성 | Conditional GAN, Class-conditional Diffusion |
| 텍스트 | "해변의 일몰" → 해당 이미지 | DALL-E, Stable Diffusion |
| 이미지 | 스케치 → 실사 이미지 | Pix2Pix, ControlNet |
| 다른 모달리티 | 텍스트 → 음성, 음악 → 동영상 | 다양한 모달리티 변환 모델 |

### Conditional GAN (cGAN)

```
min_G max_D  V(D, G) = E_{x,y}[log D(x|y)] + E_{z,y}[log(1 - D(G(z|y)|y))]
```

여기서 y는 조건 정보 (e.g., 클래스 라벨). G와 D 모두 y를 추가 입력으로 받는다.

### Conditional VAE (CVAE)

```
L_CVAE = E_q[log p(x|z,c)]  -  KL(q(z|x,c) ‖ p(z|c))
```

인코더와 디코더 모두 조건 c를 입력으로 받는다.

## 3.1 확산 모델 (Diffusion Models)

### 3.1.1 DDPM (Denoising Diffusion Probabilistic Models)

확산 모델의 핵심 아이디어는 놀랍도록 단순하다: **노이즈를 점진적으로 추가하는 과정을 역전시키는 것을 학습한다.**

#### Forward Process (노이즈 추가)

깨끗한 이미지 x₀에 T 스텝에 걸쳐 가우시안 노이즈를 점진적으로 추가한다:

```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t)·x_{t-1}, β_t·I)
```

- β_t: 노이즈 스케줄 (보통 β₁=10⁻⁴ ~ β_T=0.02로 선형 증가)
- T 스텝 후 x_T ≈ N(0, I) (순수 가우시안 노이즈)

**핵심 트릭**: 임의의 시점 t에서의 x_t를 x₀로부터 직접 계산 가능:

```
α_t = 1 - β_t
ᾱ_t = Π_{s=1}^{t} α_s   (누적 곱)

q(x_t | x_0) = N(x_t; √ᾱ_t · x_0, (1-ᾱ_t)·I)

즉, x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε,   ε ~ N(0, I)
```

이 덕분에 학습 시 매 스텝을 순차적으로 거칠 필요 없이, 임의의 t를 직접 샘플링할 수 있다.

#### Reverse Process (노이즈 제거)

신경망 ε_θ가 x_t에서 추가된 노이즈 ε을 **예측**한다:

```
p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t), σ_t²·I)

μ_θ(x_t, t) = 1/√α_t · (x_t - β_t/√(1-ᾱ_t) · ε_θ(x_t, t))
```

#### 학습 목표 (Training Objective)

놀랍도록 단순한 손실 함수:

```
L_simple = E_{t, x_0, ε} [ ‖ε - ε_θ(x_t, t)‖² ]
```

1. 학습 이미지 x₀를 선택
2. 랜덤 시간 t ~ Uniform(1, T)를 선택
3. 랜덤 노이즈 ε ~ N(0, I)를 생성
4. x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε 계산
5. 신경망이 ε_θ(x_t, t)를 예측
6. MSE 손실 ‖ε - ε_θ‖² 최소화

### 3.1.2 Score Matching과의 연결

**Score function**: ∇_x log p(x) — 데이터 로그 확률의 그래디언트

```
Score 예측:    s_θ(x_t, t) ≈ ∇_{x_t} log p_t(x_t)
노이즈 예측:   ε_θ(x_t, t) ≈ ε

관계:  s_θ(x_t, t) = -ε_θ(x_t, t) / √(1-ᾱ_t)
```

즉, 노이즈를 예측하는 것과 score를 예측하는 것은 **수학적으로 동치**이다.

### 3.1.3 SDE 통합 프레임워크 (Song et al.)

DDPM과 Score-based 모델을 통합하는 프레임워크: **확률미분방정식(SDE)**

```
Forward SDE:   dx = f(x,t)dt + g(t)dw
Reverse SDE:   dx = [f(x,t) - g(t)²∇_x log p_t(x)]dt + g(t)dw̄
```

DDPM은 이 SDE의 **이산화(discretization)** 에 해당한다.

### 3.1.4 DDIM: 빠른 샘플링

DDPM의 단점: 1000 스텝의 순차 샘플링 → 느림

DDIM (Denoising Diffusion Implicit Models)의 해결책:
- **결정론적(deterministic)** 샘플링 → 스텝 건너뛰기 가능
- 1000 스텝 → 20~50 스텝으로 감소, 품질 손실 최소

## 3.2 Flow Matching

### 기본 개념

Flow Matching은 확산 모델의 대안으로 등장한 생성 모델 패러다임이다. 핵심 아이디어: **노이즈 분포에서 데이터 분포로의 확률 흐름(flow)을 직접 학습**한다.

```
노이즈 z ~ N(0,I)  ───flow───▶  데이터 x ~ p_data
         t=0                          t=1
```

### Continuous Normalizing Flows (CNF)

ODE(상미분방정식)로 정의된 흐름:

```
dx/dt = v_θ(x, t)     (velocity field)
```

이 ODE를 t=0에서 t=1까지 적분하면 노이즈 → 데이터 변환.

### Flow Matching 목표

시뮬레이션 없이(simulation-free) 벡터 필드를 학습한다:

```
L_FM = E_{t, x_0, x_1} ‖v_θ(x_t, t) - u_t(x_t | x_1)‖²
```

- `x_t = (1-t)·x_0 + t·x_1`: 노이즈에서 데이터로의 선형 보간
- `u_t(x_t | x_1) = x_1 - x_0`: 조건부 벡터 필드 (목표 방향)

이 손실은 확산 모델의 denoising score matching과 유사하지만, **더 단순하고 일반적**이다.

### 확산 모델과의 관계

| 비교 항목 | Diffusion Model | Flow Matching |
|----------|----------------|---------------|
| 수학적 프레임워크 | SDE | ODE |
| 학습 대상 | 노이즈 ε 또는 score | velocity field v |
| 노이즈 경로 | 고정된 확산 과정 | 유연한 경로 설계 |
| 샘플링 | SDE/ODE solver | ODE solver |
| 확장성 | 비유클리드 공간 어려움 | 매니폴드, 이산 공간 확장 용이 |

### 최근 적용

## 3.3 Consistency Models

### 동기

확산/Flow 모델의 최대 약점: **생성 시 수십~수백 스텝의 순차 연산 필요**. Consistency Model은 **한 스텝(one-step)** 으로 생성하는 것을 목표로 한다.

### 핵심 아이디어: Self-Consistency 속성

확산 과정의 ODE 궤적(trajectory) 위의 **모든 점이 같은 시작점으로 매핑**되어야 한다는 제약.

```
ODE 궤적:  x_T → x_{t₂} → x_{t₁} → x_0

Consistency 함수 f_θ의 조건:
f_θ(x_t, t) = f_θ(x_{t'}, t')   ∀ t, t' ∈ [0, T]
                                  (같은 궤적 위에 있다면)
```

즉, 궤적 위 어디에서 시작하든 같은 x₀를 예측해야 한다.

### 학습 방법

**Consistency Distillation**: 사전학습된 확산 모델에서 증류

```
L_CD = E[ d(f_θ(x_{t_{n+1}}, t_{n+1}), f_θ⁻(x̂_{t_n}, t_n)) ]
```

여기서 x̂_{t_n}은 확산 모델의 ODE solver로 한 스텝 업데이트한 결과.

**Consistency Training**: 확산 모델 없이 직접 학습 (독립적)

### Consistency Models Made Easy (ICLR 2025)

최근 연구에서 consistency 학습을 더 단순하고 안정적으로 만드는 기법이 제안되었다. 확산 모델에 비해 1~2 스텝 생성으로도 경쟁력 있는 품질을 달성한다.

### 참고 자료

- [Consistency Models Made Easy (ICLR 2025)](https://proceedings.iclr.cc/paper_files/paper/2025/file/bb166dd4de5dba363bf1023eb956a826-Paper-Conference.pdf)

## 3.4 Foundation Models과 멀티모달 학습

### Foundation Model이란?

대규모 비라벨 데이터로 사전학습되어, 다양한 다운스트림 과제에 적응(adapt)할 수 있는 모델.

```
Foundation Model의 패러다임:

대규모 데이터  ──사전학습──▶  Foundation Model  ──적응──▶  다양한 과제
(인터넷 텍스트,                  (GPT, BERT,               (분류, 생성,
 이미지-텍스트 쌍,                CLIP, DALL-E)              번역, 추론...)
 코드, 동영상...)
```

### CLIP: 비전-언어 Foundation Model

CLIP의 핵심 구조 (이전 2.2.3절 참조)를 더 깊이 살펴본다.

**대조학습 목표 (InfoNCE)**:

배치 내 N개의 (이미지, 텍스트) 쌍이 주어졌을 때:

```
L_CLIP = -1/N Σ_i [log(exp(I_i·T_i/τ) / Σ_j exp(I_i·T_j/τ))
                  + log(exp(T_i·I_i/τ) / Σ_j exp(T_i·I_j/τ))]
```

대각선 원소(매칭 쌍)의 유사도를 최대화하고, 비대각선 원소(비매칭 쌍)를 최소화한다.

**Zero-shot Transfer**:
- 테스트 시, 각 클래스명을 "a photo of a {class}"로 템플릿화
- 텍스트 인코더로 각 클래스의 임베딩 생성
- 이미지와 각 클래스 텍스트의 코사인 유사도로 분류
- 학습 중 본 적 없는 클래스도 분류 가능

### DALL-E 계열: 텍스트로부터 이미지 생성

```
DALL-E 발전 과정:
DALL-E (2021) → DALL-E 2 (2022) → DALL-E 3 (2023)
  dVAE + 자귀회귀    CLIP + Diffusion      향상된 프롬프트 이해
```

**DALL-E 2 구조**:

```
텍스트 "a corgi playing in snow"
        ↓
  CLIP 텍스트 인코더
        ↓

        ↓

        ↓

        ↓

        ↓
```

## 3.5 RLHF (Reinforcement Learning from Human Feedback)

### 왜 RLHF가 필요한가?

대규모 언어모델(LLM)은 사전학습만으로는 "좋은 답변"이 무엇인지 모른다. 인터넷 텍스트에는 유해하거나 잘못된 정보도 포함되어 있기 때문이다.

```
사전학습된 LLM의 문제점:
- 유해한 내용 생성 가능
- 질문에 대한 거부 의사 표현 불가
- 도움이 되는 응답과 해로운 응답을 구분 못 함
- 사실과 허구를 혼동 (hallucination)
```

### RLHF 3단계 파이프라인

```
단계 1: Supervised Fine-Tuning (SFT)
  사전학습 LLM ──(인간이 작성한 양질의 응답으로 학습)──▶ SFT 모델

단계 2: Reward Model 학습
  사람이 여러 응답에 대해 선호도 순위 매기기
  (응답 A > 응답 B > 응답 C)
  이 데이터로 Reward Model을 학습

  R_θ(prompt, response) → 스칼라 점수

단계 3: PPO로 정책 최적화
  SFT 모델을 Reward Model의 점수를 극대화하도록 RL 학습

  max_π  E_{x~D, y~π(·|x)} [R_θ(x, y)] - β·KL(π ‖ π_SFT)
                                            ─────────────────
                                            원래 모델에서 너무
                                            벗어나지 않도록 제약
```

### 수학적 구조

**Reward Model 학습** (Bradley-Terry 모델):

```
P(y_w ≻ y_l | x) = σ(R_θ(x, y_w) - R_θ(x, y_l))

L_RM = -E_{(x, y_w, y_l)} [log σ(R_θ(x, y_w) - R_θ(x, y_l))]
```

- y_w: 인간이 선호한 응답 (winner)
- y_l: 덜 선호한 응답 (loser)
- σ: 시그모이드 함수

**PPO 목표 함수**:

```
L_PPO = E_t [min(r_t(θ)·Â_t, clip(r_t(θ), 1-ε, 1+ε)·Â_t)]
```

여기서 r_t(θ) = π_θ(a_t|s_t) / π_old(a_t|s_t)

### DPO: RLHF의 간소화

Direct Preference Optimization (DPO)는 Reward Model을 별도로 학습하지 않고, 선호도 데이터에서 직접 정책을 학습한다:

```
L_DPO = -E_{(x,y_w,y_l)} [log σ(β(log π_θ(y_w|x)/π_ref(y_w|x)
                                  - log π_θ(y_l|x)/π_ref(y_l|x)))]
```

이론적으로 RLHF와 동치이지만, 구현이 훨씬 간단하다.

## 3.6 에너지 기반 모델 (Energy-Based Models)

### 핵심 아이디어

데이터 분포를 **에너지 함수**로 정의한다:

```
p_θ(x) = exp(-E_θ(x)) / Z_θ

Z_θ = ∫ exp(-E_θ(x)) dx   (분배함수, partition function)
```

- 낮은 에너지 → 높은 확률 (데이터가 있을 법한 곳)
- 높은 에너지 → 낮은 확률 (데이터가 없을 법한 곳)

### EBM의 도전 과제

**분배함수 Z_θ가 계산 불가능(intractable)하다**. 이것이 EBM의 핵심 어려움.

해결 방법들:
1. **Contrastive Divergence (CD)**: MCMC로 Z_θ를 근사
2. **Score Matching**: Z_θ를 우회하여 score ∇_x log p(x)만 학습
3. **Noise Contrastive Estimation (NCE)**: 노이즈 분포와의 대조로 학습

### Score Matching과 확산 모델의 연결

```
EBM의 score: ∇_x log p_θ(x) = -∇_x E_θ(x)
                               (에너지의 그래디언트 = score)
                               (Z_θ가 사라짐!)

→ Score Matching으로 score를 직접 학습
→ 다양한 노이즈 수준에서 학습 (Denoising Score Matching)
→ DDPM과 수학적으로 동치
```

이것이 바로 확산 모델의 또 다른 관점이다.

### 샘플링: Langevin Dynamics

학습된 score를 이용한 반복적 샘플링:

```
x_{k+1} = x_k + (η/2)·∇_x log p(x_k) + √η · z_k,    z_k ~ N(0, I)
```

- 첫째 항: score 방향으로 이동 (고확률 영역으로)
- 둘째 항: 확률적 노이즈 (다양성 보장)

### 본 교재와의 연결

본 교재 5절(Energy-Based Model)에서 다루는 내용의 심화이다. 에너지 함수, 분배함수, Langevin Dynamics의 수학적 연결을 이해하면, 확산 모델의 이론적 기반을 더 깊이 파악할 수 있다.
