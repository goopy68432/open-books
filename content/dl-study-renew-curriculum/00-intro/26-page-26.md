### Day 6: 베이지안 추론 + MLE/MAP
**시간**: 3시간 ⭐ **가장 중요한 세션**

#### 학습 내용
| 순서 | 토픽 | 핵심 질문 |
|------|------|----------|
| 1 | 베이지안 관점 | 확률 = 가설에 대한 "믿음의 정도" |
| 2 | Prior → Data → Posterior | Belief Update = 학습 |
| 3 | 베이즈 정리 유도 | P(H\|E) = P(E\|H)·P(H) / P(E) |
| 4 | Likelihood의 의미 | "이 파라미터가 맞다면 데이터가 얼마나 그럴듯한가" |
| 5 | MLE | Prior 무시 → Likelihood만 최대화 |
| 6 | MAP | Posterior 최대화 ∝ Likelihood × Prior |
| 7 | MLE vs MAP 비교 | 데이터 양에 따른 트레이드오프 |

#### ⭐ 킬러 유도 체인 (반드시 손으로 직접 써볼 것)

```
Step 1: 데이터가 i.i.d.라 가정
    → "왜?" → 결합확률을 곱으로 분해하기 위해

Step 2: Likelihood = Π P(xᵢ|θ)
    → "왜 곱?" → i.i.d.이므로

Step 3: Log-Likelihood = Σ log P(xᵢ|θ)
    → "왜 log?" → 곱 → 합, 미분 편리

Step 4: ∂/∂θ [Log-Likelihood] = 0
    → "왜 미분=0?" → 극값 후보 찾기

Step 5: θ* 도출
    → "왜 상수 버리나?" → θ와 무관하므로 최적화에 영향 없음
```

### Day 7: Loss 유도 + 정보이론 + 모델 비교
**시간**: 3시간 ⭐ **두 번째로 중요한 세션**

#### Part A: Gaussian → MSE 유도

```
Gaussian Likelihood: P(y|x,θ) = (1/√2πσ²) exp(-(y-ŷ)²/2σ²)
    ↓ i.i.d. → 곱
    ↓ log → 합
    ↓ negative
NLL = Σ (yᵢ-ŷᵢ)²/2σ² + const
    ↓ 상수 제거
∴ NLL 최소화 ≡ MSE 최소화
```

**핵심 통찰**: MSE를 쓴다는 것 = 노이즈가 Gaussian이라 가정하는 것

#### Part B: Bernoulli → Cross Entropy 유도

```
Bernoulli Likelihood: P(y|x,θ) = ŷʸ(1-ŷ)¹⁻ʸ
    ↓ log
    ↓ negative
NLL = -[y log ŷ + (1-y) log(1-ŷ)]
    ↓
= Binary Cross Entropy
```

**핵심 통찰**: Cross Entropy를 쓴다는 것 = 출력이 Bernoulli라 가정하는 것

#### Part C: 정보이론

| 개념 | 공식 | 직관 | 핵심 질문 |
|------|------|------|----------|
| Entropy H(P) | -Σ P log P | 불확실성의 양 | 동전이 공정할 때 왜 entropy 최대? |
| Cross Entropy H(P,Q) | -Σ P log Q | Q로 P를 설명하는 비용 | 왜 Loss로 쓰이나? |
| KL Divergence D(P‖Q) | Σ P log(P/Q) | 두 분포의 "거리" | 왜 비대칭인가? |
| 관계 | H(P,Q) = H(P) + D(P‖Q) | | CE 최소화 ≈ KL 최소화 (H(P)는 상수) |

#### Part D: 모델 비교

| 모델 | Inductive Bias | Expressivity | 데이터 요구량 |
|------|---------------|-------------|-------------|
| Linear | 강함 (직선만) | 낮음 | 적어도 OK |
| Neural Network | 중간 | 높음 | 많이 필요 |
| CNN | 이미지 특화 (지역성) | 높음 (이미지) | 중간 |
| Transformer | 약함 (거의 없음) | 매우 높음 | 대량 필요 |

**핵심 연결**: MAP의 Prior ↔ 모델의 Inductive Bias
- 강한 Prior = 강한 가정 = 적은 데이터로 학습 가능
- 약한 Prior = 적은 가정 = 많은 데이터 필요

| 5 | 활성화 함수와 Firing | 생물학적 뉴런의 수학적 추상화 |

#### Softmax 미분의 구조
```
∂softmax(z)ᵢ/∂zⱼ = softmax(z)ᵢ · (δᵢⱼ - softmax(z)ⱼ)

  i = j: sᵢ(1 - sᵢ)    ← 자기 자신에 대한 변화율
  i ≠ j: -sᵢ · sⱼ      ← 다른 클래스에 대한 변화율 (음수 = 경쟁)
```

### Day 9: 킬러 유도 체인 반복 + 통합 연습
**시간**: 2~3시간

#### 반복 연습 (보지 않고 처음부터 직접 쓰기)

**연습 1**: MLE 유도 체인
```
i.i.d. 가정 → Likelihood 곱 → Log → 미분=0 → θ* 도출
(각 단계마다 "왜?"를 쓸 것)
```

**연습 2**: Gaussian → MSE
```
Gaussian Likelihood → Log → Negative → 상수 제거 → MSE
```

**연습 3**: Bernoulli → Cross Entropy
```
Bernoulli Likelihood → Log → Negative → Binary CE
```

**연습 4**: MAP → Regularization 연결
```
MAP = argmax P(θ|D) ∝ P(D|θ)·P(θ)
→ Log → Log-Likelihood + Log-Prior
→ Gaussian Prior → L2 norm
→ ∴ L2 Regularization = Gaussian Prior를 가정한 MAP
```

#### 통합 연습: 개념 연결 맵 그려보기
종이에 직접 그리기:
- 선형대수 → 미분 → 확률 → 추정 → Loss → 모델 선택
- 각 화살표에 "왜 연결되는가" 한 줄씩
