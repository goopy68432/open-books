## 1. 학습(Learning)의 프레임워크

### 1.1 핵심 개념: "기계가 배운다"는 게 뭘까?

#### 일상적 비유

학교에서 시험 공부를 한다고 생각해보자.

- **경험(E)**: 교과서와 문제집 (= 데이터)
- **과제(T)**: 시험에서 좋은 점수 받기 (= 예측/분류)
- **성능 측정(P)**: 시험 점수 (= 손실 함수)

기계학습도 똑같다. 컴퓨터에게 **데이터(경험)**를 주고, **특정 과제**를 수행하게 하며, **성능이 얼마나 좋은지** 측정한다.

> **한 줄 정의**: 머신러닝이란 데이터로부터 표현/특징/패턴을 학습하는 것이다.

### 1.2 Task (T): 어떤 종류의 과제가 있을까?

| 과제 | 일상 비유 | 입력 → 출력 | 예시 |
|------|----------|------------|------|
| **분류 (Classification)** | 사진을 보고 "고양이인지 개인지" 맞추기 | 이미지 → 라벨 | 스팸 메일 분류, 질병 진단 |
| **회귀 (Regression)** | 키를 보고 몸무게를 예측하기 | 숫자 → 숫자 | 주택 가격 예측, 온도 예측 |
| **탐지 (Detection)** | 사진에서 사람 위치 찾기 | 이미지 → 경계 상자 | 자율주행 보행자 탐지 |
| **분할 (Segmentation)** | 사진의 각 픽셀이 무엇인지 색칠하기 | 이미지 → 픽셀별 라벨 | 의료 영상 분석 |
| **번역 (Translation)** | 영어를 한국어로 바꾸기 | 문장 → 문장 | Google 번역, 이미지 캡셔닝 |
| **생성 (Generation)** | 그림 그리기, 글쓰기 | 조건 → 새로운 데이터 | ChatGPT, DALL-E |
| **정책 (Policy)** | 게임에서 다음 행동 결정하기 | 상태 → 행동 | 바둑 AI, 로봇 제어 |

### 1.3 학습의 세 가지 종류

#### (1) 지도학습 (Supervised Learning) - "정답지가 있는 공부"

```
[비유] 수학 문제집에 풀이와 정답이 있다.
       문제(x)를 보고 정답(y)을 맞추는 연습을 한다.

데이터: S = {(x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)}
                ↑입력     ↑정답(라벨)

예시:
  x = [키: 170cm, 나이: 25세] → y = 몸무게: 65kg  (회귀)
  x = [이메일 내용]            → y = 스팸/정상      (분류)
```

**핵심 표기법 설명:**
- $x \in \mathcal{X}$: 입력 데이터 (feature, 특징). 예: 키, 나이 같은 숫자들의 모음
- $y \in \mathcal{Y}$: 정답 라벨 (label, 타깃)
- $X \in \mathbb{R}^{n \times d}$: 설계 행렬. $n$개의 데이터가 각각 $d$개의 특징을 가짐

여기서 $\mathbb{R}^{n \times d}$가 어렵게 보일 수 있다. 그냥 "세로 $n$줄, 가로 $d$줄인 숫자 표"라고 생각하면 된다.

```
예: 학생 3명의 키와 나이 데이터 (n=3, d=2)

     [키]  [나이]
X = | 170    25 |   ← 학생1
    | 165    22 |   ← 학생2
    | 180    30 |   ← 학생3
```

**분류 vs 회귀:**
- **분류**: $\mathcal{Y} = \{1, 2, \ldots, C\}$ → 정답이 "몇 번째 그룹인지" (이산적)
- **회귀**: $\mathcal{Y} = \mathbb{R}$ → 정답이 아무 숫자나 가능 (연속적)

**목표**: 입력 $x$에서 출력 $y$로 가는 함수 $h$를 학습한다.

$$h: \mathcal{X} \to \mathcal{Y}$$

> "함수 $h$"가 어렵다면 그냥 **"변환기"**라고 생각하자. 입력을 넣으면 출력이 나오는 기계이다.

#### (2) 비지도학습 (Unsupervised Learning) - "정답 없이 스스로 패턴 찾기"

```
[비유] 외국의 과일 가게에서 처음 보는 과일들이 있다.
       이름은 모르지만, 색깔/크기/모양으로 비슷한 것끼리 분류할 수 있다.

데이터: S = {x₁, x₂, ..., xₙ}  ← 정답(y)이 없다!
```

**과제 종류:**
- **생성**: 데이터와 비슷한 새로운 데이터 만들기 (예: AI 그림)
- **밀도 추정/클러스터링**: 비슷한 데이터끼리 묶기
- **표현 학습**: 데이터의 핵심 특징을 추출하기

> **수식 관점**: 비지도학습은 $p(x)$를 모델링하고, 지도학습은 $p(y|x)$를 모델링한다.

#### (3) 강화학습 (Reinforcement Learning) - "시행착오로 배우기"

```
[비유] 미로에서 출구를 찾는 쥐.
       막다른 길에 가면 벌점(-1), 출구에 도착하면 보상(+100).
       반복하면서 최적 경로를 배운다.

상태(state) → 행동(action) → 보상(reward) → 새 상태 → ...
```

### 1.4 딥러닝과의 연결

딥러닝은 머신러닝의 한 종류이다. 함수 $h$를 **신경망(neural network)**으로 표현하는 것이다.

```
전통 머신러닝:  x → [간단한 수식] → y
딥러닝:        x → [층1] → [층2] → ... → [층N] → y
                     ↑ 여러 층을 쌓아서 복잡한 패턴을 학습
```

뒤에서 배울 선형 회귀는 "뉴런 1개짜리 신경망"이고, 로지스틱 회귀는 "시그모이드를 씌운 뉴런 1개"이다. 이것이 딥러닝의 기본 단위가 된다.

<details>

## 2. 손실 함수 (Loss Function)

### 2.1 핵심 개념: "얼마나 틀렸는지" 재는 점수

#### 일상적 비유

양궁 선수가 과녁을 맞추려고 한다.

- **과녁 중심** = 정답 $y$
- **화살이 꽂힌 위치** = 예측값 $\hat{y}$ (y-hat이라고 읽는다)
- **과녁 중심에서의 거리** = 손실 (loss)

손실이 **작을수록 좋다**. 0이면 정확히 맞춘 것이다.

> **손실 함수** $\ell(y, \hat{y})$: 정답 $y$와 예측값 $\hat{y}$ 사이의 "거리"를 재는 함수

### 2.2 회귀의 손실 함수: L2 Loss (제곱 오차)

#### 수식

$$\ell(y, \hat{y}) = (y - \hat{y})^2 = \|y - \hat{y}\|^2$$

#### 왜 "제곱"을 하는가?

```
[숫자 예시]

정답: y = 5

예측1: y_hat = 3  → 오차 = 5 - 3 = +2
예측2: y_hat = 7  → 오차 = 5 - 7 = -2

그냥 더하면:  (+2) + (-2) = 0  ← 오차가 없다고 착각!
제곱해서 더하면: (+2)² + (-2)² = 4 + 4 = 8  ← 올바른 오차 합산
```

제곱하면 **양수든 음수든 모두 양수가 되어서** 상쇄되지 않는다.

#### 시각화 (텍스트)

```
손실
 |
 |        *
 |       * *
 |      *   *
 |     *     *
 |    *       *
 |   *         *
 |  *           *
 | *             *
 +---+---+---+---+---→ (y - y_hat)
  -2  -1   0   1   2

 → 포물선 모양: 오차가 커질수록 손실이 급격히 증가
 → 정답(오차=0)에서 최솟값
```

### 2.3 분류의 손실 함수: Cross-Entropy Loss (교차 엔트로피)

#### 일상적 비유

일기예보에서 "내일 비 올 확률 90%"라고 했는데 **실제로 비가 왔다면** → 좋은 예측 (낮은 손실)
"내일 비 올 확률 10%"라고 했는데 **실제로 비가 왔다면** → 나쁜 예측 (높은 손실)

확률이 **정답에 가까울수록** 손실이 낮다.

#### 수식

$$\ell(y, h(x)) = -\log h_y(x) = -\log p(y|x)$$

여기서:
- $h(x) = [h_1(x), h_2(x), \ldots, h_C(x)]$: 모델이 예측한 각 클래스의 확률
- $h_y(x)$: 정답 클래스 $y$에 대한 예측 확률
- $-\log$: "로그를 씌운 다음 부호를 뒤집는" 연산

#### $-\log$가 왜 좋은 손실 함수인가?

$-\log$의 동작을 표로 보자:

| 정답에 대한 예측 확률 $p$ | $-\log(p)$ (손실) | 해석 |
|:---:|:---:|:---|
| 1.0 | 0 | 100% 확신하고 맞춤 → 손실 0 (완벽!) |
| 0.9 | 0.105 | 90% 확신 → 아주 낮은 손실 |
| 0.5 | 0.693 | 반반 → 중간 손실 |
| 0.1 | 2.303 | 10%만 확신 → 높은 손실 |
| 0.01 | 4.605 | 1% 확신 → 매우 높은 손실 |

```
손실
 |
5|*
 |
4|  *
 |
3|    *
 |
2|       *
 |
1|            *
 |                  *
0+-----+-----+-----+---→ 예측 확률 p
 0    0.25   0.5   1.0

→ 확률이 0에 가까울수록 손실이 폭발적으로 증가
→ "확신 있게 틀리면 큰 벌점"이라는 직관
```

#### 숫자 예시

고양이/개/새 3클래스 분류에서, 정답이 "고양이"(클래스 1)일 때:

```
모델 A의 예측: [고양이: 0.7, 개: 0.2, 새: 0.1]
→ 손실 = -log(0.7) = 0.357  ← 낮은 손실 (좋은 예측)

모델 B의 예측: [고양이: 0.1, 개: 0.6, 새: 0.3]
→ 손실 = -log(0.1) = 2.303  ← 높은 손실 (나쁜 예측)
```

### 2.4 경험적 위험 (Empirical Risk)

#### 일상적 비유

한 문제만 잘 맞추면 시험을 잘 본 것인가? 아니다. **전체 문제의 평균 점수**를 봐야 한다.

마찬가지로, 한 데이터만이 아니라 **모든 훈련 데이터에 대한 평균 손실**을 봐야 한다.

#### 수식

$$L_S(h) = \frac{1}{n}\sum_{i=1}^{n} \ell(y_i, h(x_i))$$

**읽는 법:** "$L_S(h)$는 모든 $n$개 데이터에 대해 손실 $\ell$을 계산한 뒤 평균을 낸 것이다."

- $S$: 훈련 데이터셋 (Sample의 S)
- $n$: 데이터 개수
- $\sum_{i=1}^{n}$: "$i=1$부터 $n$까지 전부 더한다"는 뜻
- $\frac{1}{n}$: 합계를 $n$으로 나눈다 (= 평균)

#### 숫자 예시

3개 데이터에 대한 제곱 오차:

```
데이터1: 정답 y₁=5, 예측 h(x₁)=4  → ℓ = (5-4)² = 1
데이터2: 정답 y₂=3, 예측 h(x₂)=5  → ℓ = (3-5)² = 4
데이터3: 정답 y₃=7, 예측 h(x₃)=6  → ℓ = (7-6)² = 1

경험적 위험 = (1 + 4 + 1) / 3 = 2.0
```

### 2.5 모집단 위험 (Population Risk)

#### 일상적 비유

시험 문제를 다 맞춰도, **처음 보는 문제**를 잘 풀어야 진짜 실력이 있는 것이다.

- **경험적 위험**: 교과서 문제의 평균 점수 (훈련 데이터 성능)
- **모집단 위험**: 세상 모든 문제의 평균 점수 (진짜 성능)

#### 수식

$$L_P(h) = \mathbb{E}_{(x,y) \sim P}[\ell(y, h(x))]$$

**읽는 법:** "데이터 분포 $P$에서 $(x, y)$를 뽑았을 때, 손실의 기대값(평균)."

- $\mathbb{E}$: "기대값" = 평균이라고 생각하면 된다
- $(x,y) \sim P$: "데이터가 분포 $P$를 따른다"
- 즉, **아직 보지 못한 데이터 포함** 전체에 대한 평균 손실

> **핵심 차이:**
> - $L_S(h)$: 가지고 있는 데이터 $n$개에 대한 평균 → 계산할 수 있다
> - $L_P(h)$: 모든 가능한 데이터에 대한 평균 → 직접 계산할 수 없다 (데이터가 무한하니까)
>
> 우리가 실제로 줄이는 것은 $L_S(h)$이지만, 진짜 원하는 것은 $L_P(h)$를 줄이는 것이다.
> 이 차이가 **과적합(overfitting)** 문제의 핵심이다.

### 2.6 NLL: 모든 손실 함수의 통합

#### 핵심 통찰

Cross-Entropy와 MSE는 전혀 다른 것 같지만, 사실 둘 다 **같은 원리**에서 나온다.

그 원리는 **NLL (Negative Log-Likelihood, 음의 로그우도)**이다.

```
가정: "데이터에 가우시안(정규분포) 노이즈가 있다"
  → NLL을 계산하면 → MSE 손실이 나온다!

가정: "데이터가 카테고리 분포를 따른다"
  → NLL을 계산하면 → Cross-Entropy 손실이 나온다!
```

| 분포 가정 | NLL → 변환 결과 | 사용 상황 |
|-----------|----------------|----------|
| 가우시안 (정규분포) | MSE (평균 제곱 오차) | 회귀 |
| 카테고리 분포 | Cross-Entropy | 분류 |
| 베르누이 분포 | Binary Cross-Entropy | 이진 분류 |

> **"분포 가정 + MLE = 손실 함수"** 이것이 딥러닝에서 손실 함수를 설계하는 핵심 원리이다.

### 2.7 딥러닝과의 연결

- 딥러닝에서 모델을 학습시킬 때 **항상** 손실 함수를 정의하고 이를 최소화한다
- 분류 문제 (이미지 인식 등)에는 Cross-Entropy를 사용
- 회귀 문제 (예측 등)에는 MSE를 사용
- GAN, Diffusion 등 생성 모델도 각자의 손실 함수를 가진다
- **경험적 위험을 최소화하되 모집단 위험과의 차이(과적합)를 줄이는 것**이 딥러닝의 핵심 과제

## 3. 선형 회귀 (Linear Regression)

### 3.1 핵심 개념: "데이터에 가장 잘 맞는 직선 찾기"

#### 일상적 비유

아이스크림 가게 사장님이 기온과 아이스크림 판매량의 관계를 알고 싶다.

```
기온(x)  | 15도 | 20도 | 25도 | 30도 | 35도
판매량(y) | 100  | 150  | 200  | 280  | 350

그래프에 점을 찍으면:

판매량
350 |                              *
300 |                    *
250 |
200 |              *
150 |       *
100 | *
    +-----+-----+-----+-----+-----→ 기온
      15   20    25    30    35

→ 이 점들 사이에 "가장 잘 맞는 직선"을 그으면
  "기온 28도일 때 판매량이 얼마일까?"를 예측할 수 있다
```

이 "가장 잘 맞는 직선"을 수학적으로 찾는 것이 **선형 회귀**이다.

### 3.2 모델: $y = Xw + \varepsilon$

#### 단계별 설명

**1단계: 직선의 방정식**

중학교에서 배운 직선의 방정식을 기억하는가?

$$y = ax + b$$

여기서 $a$는 기울기, $b$는 y절편이다.

머신러닝에서는 이렇게 쓴다:

$$f_w(x) = w_1 x + w_0$$

- $w_1$: 가중치 (weight) = 기울기
- $w_0$: 편향 (bias) = y절편
- $f_w(x)$: "가중치 $w$로 결정되는 함수에 $x$를 넣은 값"

**2단계: 여러 특징이 있을 때**

입력이 하나가 아니라 여러 개일 수 있다 (키, 나이, 운동량 → 몸무게).

$$f_w(x) = w_1 x_1 + w_2 x_2 + \cdots + w_d x_d + w_0$$

이것을 벡터 형태로 쓰면:

$$f_w(x) = x^\top w$$

> **$x^\top w$란?** 두 벡터의 "내적"이다. 각 원소끼리 곱해서 더한 것이다.
>
> 예: $x = [3, 2]$, $w = [4, 5]$ → $x^\top w = 3 \times 4 + 2 \times 5 = 22$

**편향 흡수 트릭**: $x$에 1을 추가하고 $w$에 $w_0$를 추가하면, 편향을 따로 쓰지 않아도 된다.

```
x = [x₁, x₂, 1],  w = [w₁, w₂, w₀]
x^T w = w₁x₁ + w₂x₂ + w₀  ← 편향이 자동으로 포함됨!
```

**3단계: 여러 데이터를 한꺼번에 (행렬 표현)**

데이터 $n$개를 한꺼번에 쓰면:

$$f_w(X) = Xw$$

여기서 $X$는 설계 행렬:

$$X = \begin{bmatrix} x_1^\top \\ x_2^\top \\ \vdots \\ x_n^\top \end{bmatrix} \in \mathbb{R}^{n \times p}$$

```
예: 3명의 학생, 2개의 특징 (키, 나이) + 편향

         [키]  [나이] [1]        [w₁]
X =    | 170    25    1 |    w = | w₂ |
       | 165    22    1 |        | w₀ |
       | 180    30    1 |

Xw =  | 170w₁ + 25w₂ + w₀ |   ← 학생1의 예측값
       | 165w₁ + 22w₂ + w₀ |   ← 학생2의 예측값
       | 180w₁ + 30w₂ + w₀ |   ← 학생3의 예측값
```

**4단계: 오차(노이즈) 추가**

현실에서는 완벽한 직선 관계가 없다. 약간의 오차가 있다:

$$y = Xw + \varepsilon$$

- $\varepsilon$ (입실론): 오차. 예측에서 벗어난 정도
- 가우시안 노이즈 가정: $\varepsilon \sim \mathcal{N}(0, \sigma^2)$ → "오차가 평균 0인 정규분포를 따른다"

### 3.3 최소제곱법: 가장 잘 맞는 $w$ 찾기

#### 일상적 비유

과녁에 화살 10개를 쐈다. "가장 잘 쏜 조준점"은 어디인가? 모든 화살까지의 거리의 제곱합이 최소가 되는 점이다.

#### 수식 전개 (단계별)

**목표**: 예측값 $Xw$와 실제값 $y$의 차이를 최소화하는 $w$를 찾자.

$$\hat{w} = \arg\min_w \|y - Xw\|^2$$

> $\arg\min_w$는 "이 식을 최소로 만드는 $w$의 값"이라는 뜻이다.
> $\|\cdot\|^2$는 "벡터의 길이의 제곱" = "각 원소의 제곱을 다 더한 것"이다.

**전개:**

$$L_S(w) = \frac{1}{2}\|Xw - y\|^2$$

> 앞에 $\frac{1}{2}$을 붙이는 이유: 미분할 때 $2$와 상쇄되어 계산이 깔끔해진다. 최솟값의 위치는 바뀌지 않는다.

$$= \frac{1}{2}(Xw - y)^\top(Xw - y)$$

$$= \frac{1}{2}(w^\top X^\top X w - 2y^\top X w + y^\top y)$$

> 이 전개가 어렵다면, $(a-b)^2 = a^2 - 2ab + b^2$의 행렬 버전이라고 생각하면 된다.

### 3.4 정규방정식: $X^\top X w = X^\top y$

#### 유도 (미분을 0으로 놓기)

**아이디어**: 손실 함수의 "기울기(미분)"가 0인 점이 최솟값이다.

고등학교에서 $f(x) = x^2$의 최솟값을 찾을 때 $f'(x) = 2x = 0$으로 놓은 것과 같은 원리이다.

$$\nabla_w L_S(w) = X^\top X w - X^\top y = 0$$

> $\nabla_w$는 "$w$에 대한 기울기(그래디언트)"를 뜻한다.

이것을 정리하면:

$$\boxed{X^\top X \hat{w} = X^\top y}$$

이것이 **정규방정식 (Normal Equation)**이다.

#### 왜 $X^\top X w = X^\top y$인가? (직관적 설명)

$Xw = y$를 풀고 싶지만, 데이터가 완벽한 직선 위에 있지 않으므로 정확히 풀 수 없다. 그래서 양변에 $X^\top$를 곱해서 **"가능한 한 가장 가까운 답"**을 구한다.

```
[기하학적 해석]

y는 n차원 공간에 있는 벡터.
Xw는 X의 열들이 만드는 부분공간 안의 벡터.

정규방정식의 해 = y를 부분공간에 "수직 투영"한 것.

       y (실제)
      /|
     / |
    /  | ← 이 수직 거리를 최소화
   /   |
  +----+-------
  Xw_hat (최적 예측)
  (X의 열공간)
```

### 3.5 해 (Solution)

#### Case 1: Full Rank일 때 ($\text{rank}(X) = p$)

**의미**: 데이터 수 $n$이 특징 수 $p$보다 많거나 같고, 특징들이 서로 독립적일 때.

$$\hat{w} = (X^\top X)^{-1} X^\top y$$

> $(X^\top X)^{-1}$: "$X^\top X$라는 행렬의 역행렬". 나눗셈의 행렬 버전이다.
> 마치 $ax = b$에서 $x = a^{-1}b = b/a$인 것과 같다.

**유일한 해가 존재한다.**

#### Case 2: Underdetermined일 때 ($n < p$, 데이터보다 특징이 많을 때)

**의미**: 방정식보다 미지수가 많아서 답이 무한히 많다.

$$\hat{w} = X^+ y \quad \text{(최소 노름 해)}$$

여기서 $X^+$는 **무어-펜로즈 유사역행렬 (pseudo-inverse)**이다.

> **비유**: 빚을 갚는 방법이 여러 가지 있을 때, "가장 적은 돈으로 갚는 방법"을 고르는 것.
> 무한히 많은 해 중에서 $\|w\|$ (가중치의 크기)가 가장 작은 것을 고른다.

### 3.6 숫자 예시: 처음부터 끝까지

**문제**: 3개의 데이터 $(1, 2), (2, 4), (3, 5)$에서 $y = w_1 x + w_0$을 적합하라.

**1단계: 설계 행렬과 타깃 벡터 만들기**

$$X = \begin{bmatrix} 1 & 1 \\ 2 & 1 \\ 3 & 1 \end{bmatrix}, \quad y = \begin{bmatrix} 2 \\ 4 \\ 5 \end{bmatrix}$$

> 첫 번째 열은 $x$ 값, 두 번째 열은 편향을 위한 1

**2단계: $X^\top X$ 계산**

$$X^\top X = \begin{bmatrix} 1 & 2 & 3 \\ 1 & 1 & 1 \end{bmatrix} \begin{bmatrix} 1 & 1 \\ 2 & 1 \\ 3 & 1 \end{bmatrix} = \begin{bmatrix} 1 \cdot 1 + 2 \cdot 2 + 3 \cdot 3 & 1 \cdot 1 + 2 \cdot 1 + 3 \cdot 1 \\ 1 \cdot 1 + 1 \cdot 2 + 1 \cdot 3 & 1 \cdot 1 + 1 \cdot 1 + 1 \cdot 1 \end{bmatrix} = \begin{bmatrix} 14 & 6 \\ 6 & 3 \end{bmatrix}$$

**3단계: $X^\top y$ 계산**

$$X^\top y = \begin{bmatrix} 1 & 2 & 3 \\ 1 & 1 & 1 \end{bmatrix} \begin{bmatrix} 2 \\ 4 \\ 5 \end{bmatrix} = \begin{bmatrix} 1 \cdot 2 + 2 \cdot 4 + 3 \cdot 5 \\ 1 \cdot 2 + 1 \cdot 4 + 1 \cdot 5 \end{bmatrix} = \begin{bmatrix} 25 \\ 11 \end{bmatrix}$$

**4단계: $(X^\top X)^{-1}$ 계산**

2x2 행렬 $\begin{bmatrix} a & b \\ c & d \end{bmatrix}$의 역행렬은 $\frac{1}{ad-bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}$이다.

$$ad - bc = 14 \times 3 - 6 \times 6 = 42 - 36 = 6$$

$$(X^\top X)^{-1} = \frac{1}{6}\begin{bmatrix} 3 & -6 \\ -6 & 14 \end{bmatrix}$$

**5단계: 해 계산**

$$\hat{w} = (X^\top X)^{-1} X^\top y = \frac{1}{6}\begin{bmatrix} 3 & -6 \\ -6 & 14 \end{bmatrix}\begin{bmatrix} 25 \\ 11 \end{bmatrix} = \frac{1}{6}\begin{bmatrix} 75 - 66 \\ -150 + 154 \end{bmatrix} = \frac{1}{6}\begin{bmatrix} 9 \\ 4 \end{bmatrix} = \begin{bmatrix} 1.5 \\ 0.667 \end{bmatrix}$$

**결과**: $y \approx 1.5x + 0.667$

**검증:**
```
x=1: 1.5(1) + 0.667 = 2.167  (실제: 2)
x=2: 1.5(2) + 0.667 = 3.667  (실제: 4)
x=3: 1.5(3) + 0.667 = 5.167  (실제: 5)

  y
5 |        * ---- (직선)
4 |     *--
3 |   --
2 | *-
1 |
  +--+--+--→ x
     1  2  3

*: 실제 데이터  ---: 적합된 직선
```

### 3.7 릿지 회귀 (Ridge Regression) - 과적합 방지

#### 일상적 비유

학생이 시험 공부를 너무 열심히 해서 문제와 답을 통째로 외워버렸다. 교과서 문제는 100점이지만 새로운 문제는 전혀 못 푼다. 이것이 **과적합(overfitting)**이다.

릿지 회귀는 "너무 극단적으로 외우지 마!"라는 제한을 거는 것이다.

#### 수식

$$L_S(w; \lambda) = \underbrace{\frac{1}{2}\|Xw - y\|^2}_{\text{데이터 적합}} + \underbrace{\frac{\lambda}{2}\|w\|^2}_{\text{정규화 (제한)}}$$

- 첫 번째 항: 데이터를 얼마나 잘 맞추는가
- 두 번째 항: 가중치 $w$가 너무 크지 않게 제한
- $\lambda$ (람다): 두 항의 균형을 조절하는 값
  - $\lambda = 0$: 제한 없음 → 일반 선형 회귀 (과적합 위험)
  - $\lambda$ 큼: 강한 제한 → 가중치가 0에 가까워짐 (과소적합 위험)

#### 해

$$\hat{w}_\lambda = (X^\top X + \lambda I)^{-1} X^\top y$$

> **장점**: $\lambda I$를 더하면 $X^\top X + \lambda I$가 **항상 역행렬이 존재**한다.
> 일반 선형 회귀에서 $X^\top X$의 역행렬이 없을 수 있는 문제를 해결한다.

### 3.8 딥러닝과의 연결

- 선형 회귀 = **뉴런 1개짜리 신경망** (활성화 함수 없음)
- 정규방정식은 작은 데이터에서 사용, 딥러닝에서는 **경사 하강법**으로 $w$를 반복 업데이트
- 릿지 회귀의 $\lambda\|w\|^2$ 항은 딥러닝의 **weight decay** 정규화와 동일
- 커널 릿지 회귀를 무한 뉴런으로 확장하면 **Neural Tangent Kernel(NTK)**이 된다

### 3.9 연습문제

**문제 5.** 다음 데이터에 대해 정규방정식으로 선형 회귀의 해를 구하라: $(0, 1), (1, 3), (2, 5)$

<details>
<summary>풀이 보기</summary>

$$X = \begin{bmatrix} 0 & 1 \\ 1 & 1 \\ 2 & 1 \end{bmatrix}, \quad y = \begin{bmatrix} 1 \\ 3 \\ 5 \end{bmatrix}$$

$$X^\top X = \begin{bmatrix} 0+1+4 & 0+1+2 \\ 0+1+2 & 1+1+1 \end{bmatrix} = \begin{bmatrix} 5 & 3 \\ 3 & 3 \end{bmatrix}$$

$$X^\top y = \begin{bmatrix} 0+3+10 \\ 1+3+5 \end{bmatrix} = \begin{bmatrix} 13 \\ 9 \end{bmatrix}$$

$$\det = 5 \times 3 - 3 \times 3 = 15 - 9 = 6$$

$$(X^\top X)^{-1} = \frac{1}{6}\begin{bmatrix} 3 & -3 \\ -3 & 5 \end{bmatrix}$$

$$\hat{w} = \frac{1}{6}\begin{bmatrix} 3 & -3 \\ -3 & 5 \end{bmatrix}\begin{bmatrix} 13 \\ 9 \end{bmatrix} = \frac{1}{6}\begin{bmatrix} 39-27 \\ -39+45 \end{bmatrix} = \frac{1}{6}\begin{bmatrix} 12 \\ 6 \end{bmatrix} = \begin{bmatrix} 2 \\ 1 \end{bmatrix}$$

결과: $y = 2x + 1$

검증: $x=0 \to 1$, $x=1 \to 3$, $x=2 \to 5$ → 모든 점을 완벽히 지나간다!

이 경우 데이터가 실제로 완벽한 직선 위에 있기 때문이다.

</details>

**문제 6.** 릿지 회귀에서 $\lambda$를 매우 크게 하면 $\hat{w}$는 어떻게 되는가? 직관적으로 설명하라.

<details>
<summary>풀이 보기</summary>

$$\hat{w}_\lambda = (X^\top X + \lambda I)^{-1} X^\top y$$

$\lambda \to \infty$이면, $\lambda I$가 $X^\top X$를 압도한다:

$$(X^\top X + \lambda I)^{-1} \approx (\lambda I)^{-1} = \frac{1}{\lambda} I$$

$$\hat{w}_\lambda \approx \frac{1}{\lambda} X^\top y \to 0$$

즉, $\lambda$가 매우 크면 **모든 가중치가 0에 수렴**한다. 모델이 아무것도 학습하지 않는 **과소적합** 상태가 된다.

직관적으로: "공부하지 마!"라는 제한을 너무 강하게 걸면, 아무것도 배우지 못하는 것과 같다.

</details>

## 4. 분류 (Classification)

### 4.1 핵심 개념: "어떤 그룹에 속하는지 맞추기"

#### 일상적 비유

과일 자동 분류기를 만든다고 하자.

```
색깔: 빨강, 크기: 큼  → 사과
색깔: 노랑, 크기: 중  → 바나나  (길쭉함은 일단 무시)
색깔: 주황, 크기: 중  → 오렌지
```

이렇게 특징(색깔, 크기)을 보고 어떤 그룹(사과, 바나나, 오렌지)인지 맞추는 것이 분류이다.

### 4.2 이진 분류 (Binary Classification)

가장 간단한 경우: **두 그룹** 중 하나를 고르는 것.

```
예: 이 이메일은 [스팸 / 정상] 중 어느 쪽인가?

특징(x):                    정답(y):
- 단어 수: 50               0 (정상)
- 느낌표 수: 15              1 (스팸)
- 링크 수: 3
- "무료" 단어 포함: 예
```

**결정 경계 (Decision Boundary)**: 두 그룹을 나누는 선(또는 면)

```
  특징2
   |    스팸(y=1)
   |   * * *
   |  * * *  *
   |  --------  ← 결정 경계 (이 선 위쪽이면 스팸)
   |      * *
   |    *   *
   |  정상(y=0)
   +---------------→ 특징1
```

### 4.3 베이즈 최적 분류기 (Bayes Optimal Classifier)

#### 일상적 비유

경험 많은 의사가 환자의 증상을 보고 진단을 내린다. 오랜 경험(= 모든 데이터 분포를 아는 것)을 바탕으로 "이 증상이면 감기일 확률 80%, 독감일 확률 20%"라고 판단하고, **가장 확률이 높은 질병**을 진단한다.

이것이 이론적으로 **가장 좋은** 분류기이다.

#### 수식

$$f(x) = \arg\max_{k \in \{1, \ldots, C\}} p(y = k \mid x)$$

**읽는 법**: "입력 $x$가 주어졌을 때, $p(y=k|x)$가 가장 큰 클래스 $k$를 고른다."

> $p(y=k|x)$는 "입력이 $x$일 때 클래스가 $k$일 확률"이다.

#### 베이즈 정리 사용

$$p(y=k \mid x) \propto p(x \mid y=k) \cdot p(y=k)$$

| 기호 | 이름 | 일상 비유 |
|:---:|:---:|:---|
| $p(y=k \mid x)$ | 사후확률 (posterior) | 증상을 본 후 진단 확률 |
| $p(x \mid y=k)$ | 우도 (likelihood) | 감기 환자가 이런 증상을 보일 확률 |
| $p(y=k)$ | 사전확률 (prior) | 겨울에 감기 걸릴 일반적 확률 |

> $\propto$는 "비례한다"는 뜻이다. 정확한 값은 아니지만 비교는 할 수 있다.

#### 숫자 예시

스팸 분류: "무료 쿠폰"이라는 단어가 포함된 이메일이 왔다.

```
사전확률: p(스팸) = 0.3,  p(정상) = 0.7
우도:    p("무료 쿠폰" | 스팸) = 0.8
         p("무료 쿠폰" | 정상) = 0.1

사후확률 (비정규화):
  p(스팸|"무료 쿠폰") ∝ 0.8 × 0.3 = 0.24
  p(정상|"무료 쿠폰") ∝ 0.1 × 0.7 = 0.07

정규화:
  p(스팸|"무료 쿠폰") = 0.24 / (0.24 + 0.07) = 0.774
  p(정상|"무료 쿠폰") = 0.07 / (0.24 + 0.07) = 0.226

→ 0.774 > 0.226이므로 "스팸"으로 분류!
```

### 4.4 LDA (Linear Discriminant Analysis, 선형 판별 분석)

#### 핵심 아이디어

각 클래스의 데이터가 **가우시안(정규분포)** 모양으로 분포한다고 가정한다.

```
[비유: 두 개의 종 모양]

         클래스 1              클래스 2
         (고양이)              (개)

키 분포:     ___                   ___
           /   \               /    \
          /     \             /      \
    -----/-------\-----------/--------\-----
                        ↑
                   결정 경계
                   (여기서 나눈다)
```

#### 가우시안 가정

$$p(x \mid y=k) = \mathcal{N}(\mu_k, \Sigma)$$

각 기호의 의미:

| 기호 | 의미 | 비유 |
|:---:|:---|:---|
| $\mathcal{N}$ | 정규분포 (종 모양 곡선) | 종 모양 분포를 따른다 |
| $\mu_k$ (뮤) | 클래스 $k$의 평균 (중심) | 종의 꼭대기 위치 |
| $\Sigma$ (시그마) | 공분산 행렬 (퍼진 정도) | 종이 얼마나 넓게 퍼져 있는가 |

> **공분산 행렬**이란? 데이터가 각 방향으로 얼마나 퍼져 있는지를 나타내는 표이다.
>
> 예: 키와 몸무게의 공분산 행렬 = $\begin{bmatrix} \text{키의 분산} & \text{키-몸무게 상관} \\ \text{키-몸무게 상관} & \text{몸무게의 분산} \end{bmatrix}$

#### LDA의 핵심: 공유 공분산 → 선형 결정 경계

**LDA 가정**: 모든 클래스가 **같은 공분산** $\Sigma$를 공유한다.

이 가정 덕분에 결정 경계가 **직선(또는 초평면)**이 된다!

$$F(x) = \text{sign}(a^\top x - b)$$

여기서:

$$a = \Sigma^{-1}(\mu_1 - \mu_2)$$

- $\mu_1 - \mu_2$: 두 클래스 중심의 차이
- $\Sigma^{-1}$: 퍼진 정도를 보정해주는 역할

> **직관**: 두 클래스의 중심을 잇는 방향으로 데이터를 투영하되, 퍼진 정도를 고려하여 보정한다.

#### 숫자 예시

두 클래스의 데이터 (2차원):

```
클래스 1: 평균 μ₁ = [1, 2]
클래스 2: 평균 μ₂ = [3, 4]
공유 공분산: Σ = [[1, 0], [0, 1]]  (단위 행렬 = 각 방향으로 동일하게 퍼짐)

μ₁ - μ₂ = [1-3, 2-4] = [-2, -2]
Σ⁻¹ = [[1, 0], [0, 1]]  (단위 행렬의 역행렬은 자기 자신)

a = Σ⁻¹(μ₁ - μ₂) = [-2, -2]

결정 경계: -2x₁ - 2x₂ = b  →  x₁ + x₂ = 상수

즉, x₁ + x₂ = 5 인 직선이 결정 경계가 된다.
(두 평균의 중점 [2, 3]을 지나는 직선)
```

```
  x₂
5 |            * *  (클래스 2)
4 |       *  * *
3 |     /          결정 경계: x₁+x₂=5
2 | * * /
1 | * /
  +---+---+---+---→ x₁
  1   2   3   4
```

#### QDA: 공분산이 다를 때 → 이차 결정 경계

클래스마다 공분산이 다르면 ($\Sigma_1 \neq \Sigma_2$), 결정 경계가 직선이 아니라 **곡선(이차)**이 된다.

```
LDA (같은 공분산):         QDA (다른 공분산):

  * * * | o o o           * * *  )  o o o
  * * * | o o o           * *  )   o o o
  * * * | o o o           * * )   o o o
    직선 경계               곡선 경계
```

$$\text{LLR}(x) = \frac{1}{2}(x - \mu_1)^\top \Sigma_1^{-1}(x - \mu_1) - \frac{1}{2}(x - \mu_2)^\top \Sigma_2^{-1}(x - \mu_2) + \ln\frac{|\Sigma_2|}{|\Sigma_1|}$$

> 이 수식이 복잡해 보이지만, 핵심은 "각 클래스 중심까지의 거리를 (퍼진 정도로 보정하여) 비교한다"는 것이다.

### 4.5 Fisher 선형 판별식

#### 일상적 비유

교실에서 남학생과 여학생을 키 한 가지 특징으로 구분하려 한다. 단순히 평균 차이만 보면 안 된다. 키의 분포가 많이 겹치면 구분이 어렵기 때문이다.

**Fisher의 아이디어**: "클래스 간 차이는 크게, 클래스 내 퍼짐은 작게" 하는 방향을 찾자.

#### 수식

$$S = \frac{\sigma_{\text{between}}^2}{\sigma_{\text{within}}^2} = \frac{(w^\top \mu_1 - w^\top \mu_2)^2}{w^\top \Sigma_1 w + w^\top \Sigma_2 w}$$

- 분자: 두 클래스 중심 사이의 거리 (클수록 좋다)
- 분모: 각 클래스 내부의 퍼짐 (작을수록 좋다)
- $S$를 **최대화**하는 $w$를 찾는다

최적 해: $w^* \propto \Sigma^{-1}(\mu_1 - \mu_2)$

> LDA와 같은 결과! Fisher 판별식은 LDA를 다른 각도에서 유도한 것이다.

### 4.6 딥러닝과의 연결

- LDA/QDA는 **특징을 사람이 설계**해야 한다 (예: 키, 나이 등을 직접 선택)
- 딥러닝은 **특징을 자동으로 학습**한다 (CNN이 이미지에서 특징을 추출)
- 하지만 마지막 층에서의 분류는 여전히 소프트맥스 + Cross-Entropy → 로지스틱 회귀와 본질적으로 같다
- LDA의 "선형 결정 경계" 개념은 신경망의 각 뉴런에서 반복적으로 나타난다

### 4.7 연습문제

**문제 7.** 베이즈 분류기에서 다음 데이터로 새로운 점 $x$를 분류하라.

- $p(y=A) = 0.6$, $p(y=B) = 0.4$
- $p(x|y=A) = 0.2$, $p(x|y=B) = 0.5$

<details>
<summary>풀이 보기</summary>

$$p(y=A|x) \propto p(x|y=A) \cdot p(y=A) = 0.2 \times 0.6 = 0.12$$

$$p(y=B|x) \propto p(x|y=B) \cdot p(y=B) = 0.5 \times 0.4 = 0.20$$

정규화:

$$p(y=A|x) = \frac{0.12}{0.12 + 0.20} = \frac{0.12}{0.32} = 0.375$$

$$p(y=B|x) = \frac{0.20}{0.32} = 0.625$$

$0.625 > 0.375$이므로 **클래스 B**로 분류한다.

사전확률은 A가 높았지만(0.6), 우도가 B가 훨씬 높아서(0.5 vs 0.2) 결론이 뒤집혔다.

</details>

**문제 8.** LDA에서 공분산 행렬이 같으면 왜 결정 경계가 직선이 되는가? 직관적으로 설명하라.

<details>
<summary>풀이 보기</summary>

가우시안의 로그를 취하면 $x$에 대한 **이차식**이 나온다.

두 클래스의 로그 확률 차이를 계산할 때:
- 공분산이 같으면 ($\Sigma_1 = \Sigma_2$), 이차 항 $x^\top \Sigma^{-1} x$가 **상쇄**된다
- 남는 것은 $x$에 대한 **일차식** → 직선

공분산이 다르면 이차 항이 상쇄되지 않아 **곡선(이차 곡면)**이 된다.

비유: 두 개의 동일한 크기의 원(같은 공분산)의 경계는 직선이지만, 크기가 다른 원(다른 공분산)의 경계는 곡선이다.

</details>

## 5. 로지스틱 회귀 (Logistic Regression)

### 5.1 핵심 개념: "확률을 출력하는 분류기"

#### 일상적 비유

의사가 환자에게 "당신은 당뇨입니다" (0 또는 1)라고만 말하면 불안하다. "당뇨일 확률이 75%입니다"라고 말해주면 더 유용하다.

로지스틱 회귀는 **"이 데이터가 클래스 1에 속할 확률이 몇 %인지"**를 출력한다.

> 이름에 "회귀"가 들어있지만 **실제로는 분류 모델**이다!

### 5.2 시그모이드 함수: $\sigma(z) = \frac{1}{1+e^{-z}}$

#### 왜 시그모이드가 필요한가?

선형 회귀의 출력은 $-\infty$부터 $+\infty$까지 아무 숫자나 될 수 있다. 그런데 확률은 **반드시 0과 1 사이**여야 한다.

시그모이드 함수가 이 변환을 해준다.

```
[시그모이드 함수의 모양 - S자 커브]

 1.0 |                    --------
     |                 --/
     |               -/
 0.5 |             -/       ← z=0일 때 정확히 0.5
     |           -/
     |         /-
 0.0 | --------
     +----+----+----+----→ z
     -4   -2    0    2    4

→ z가 크면 (양수) → 1에 가까워짐
→ z가 작으면 (음수) → 0에 가까워짐
→ z = 0이면 정확히 0.5
```

#### 숫자 예시

| $z$ | $e^{-z}$ | $1 + e^{-z}$ | $\sigma(z) = \frac{1}{1+e^{-z}}$ | 해석 |
|:---:|:---:|:---:|:---:|:---|
| -3 | 20.09 | 21.09 | 0.047 | 거의 0 (클래스 0) |
| -1 | 2.72 | 3.72 | 0.269 | 클래스 0 쪽 |
| 0 | 1 | 2 | 0.500 | 반반 |
| 1 | 0.37 | 1.37 | 0.731 | 클래스 1 쪽 |
| 3 | 0.05 | 1.05 | 0.953 | 거의 1 (클래스 1) |

> **$e$란?** 자연 상수로 약 2.718이다. $e^{-z}$는 "2.718의 $-z$제곱"이다.

### 5.3 로지스틱 회귀 모델

$$P(y=1 \mid x) = \sigma(w^\top x) = \frac{1}{1 + e^{-w^\top x}}$$

**작동 원리:**

```
1단계: 선형 결합 계산
  z = w^T x = w₁x₁ + w₂x₂ + ... + w₀
  (= 특징들의 가중 합)

2단계: 시그모이드로 확률 변환
  p = σ(z) = 1/(1+e^{-z})
  (= 0~1 사이의 확률)

3단계: 결정
  p > 0.5이면 → 클래스 1
  p ≤ 0.5이면 → 클래스 0
```

#### 숫자 예시

스팸 분류: 가중치 $w = [0.5, 0.3, -1.0]$, 편향은 $w$에 포함

입력 $x = [\text{느낌표 수}=4, \text{링크 수}=2, 1]$ (마지막 1은 편향용)

```
1단계: z = w^T x = 0.5(4) + 0.3(2) + (-1.0)(1) = 2.0 + 0.6 - 1.0 = 1.6

2단계: p = σ(1.6) = 1/(1+e^{-1.6}) = 1/(1+0.202) = 1/1.202 = 0.832

3단계: 0.832 > 0.5 → 스팸으로 분류! (확률 83.2%)
```

### 5.4 손실 함수: Binary Cross-Entropy (BCE)

#### 유도 과정 (MLE에서)

**MLE (Maximum Likelihood Estimation, 최대우도추정)**이란?

"주어진 데이터가 나올 확률을 최대화하는 파라미터를 찾는다."

```
[비유]
동전을 10번 던져서 앞면이 7번 나왔다.
"이 동전의 앞면 확률은 얼마일까?"
→ MLE: 관측 결과가 가장 그럴듯하게 설명되는 값 = 0.7
```

**로지스틱 회귀의 우도:**

데이터 $(x_i, y_i)$ 한 개에 대해:

$$p(y_i \mid x_i; w) = \begin{cases} \sigma(w^\top x_i) & \text{if } y_i = 1 \\ 1 - \sigma(w^\top x_i) & \text{if } y_i = 0 \end{cases}$$

이것을 한 줄로 쓰면:

$$p(y_i \mid x_i; w) = \sigma(w^\top x_i)^{y_i} \cdot (1 - \sigma(w^\top x_i))^{1-y_i}$$

> 이 트릭이 헷갈리면 대입해서 확인해보자:
> - $y_i = 1$이면: $\sigma^1 \cdot (1-\sigma)^0 = \sigma$ (첫 번째 항만 남는다)
> - $y_i = 0$이면: $\sigma^0 \cdot (1-\sigma)^1 = 1-\sigma$ (두 번째 항만 남는다)

**모든 데이터의 로그우도:**

$$\log p(y \mid X; w) = \sum_i \left[y_i \log \sigma(w^\top x_i) + (1-y_i)\log(1 - \sigma(w^\top x_i))\right]$$

**음의 로그우도 = 손실 함수:**

$$\boxed{L_S(w) = -\sum_i \left[y_i \log \sigma(w^\top x_i) + (1-y_i)\log(1 - \sigma(w^\top x_i))\right]}$$

이것이 **Binary Cross-Entropy (BCE)** 손실이다.

#### 숫자 예시

$w^\top x_i = 2$이고 실제 $y_i = 1$일 때:

```
σ(2) = 1/(1+e⁻²) ≈ 0.881

BCE = -[1·log(0.881) + 0·log(1-0.881)]
    = -log(0.881)
    ≈ 0.127  ← 낮은 손실 (좋은 예측: 88% 확률로 맞췄으니까)
```

$w^\top x_i = -1$이고 실제 $y_i = 1$일 때:

```
σ(-1) = 1/(1+e¹) ≈ 0.269

BCE = -log(0.269)
    ≈ 1.312  ← 높은 손실 (나쁜 예측: 27%밖에 안 맞췄으니까)
```

### 5.5 선형 회귀와의 핵심 차이

| | 선형 회귀 | 로지스틱 회귀 |
|---|:---:|:---:|
| **출력** | 연속값 ($-\infty$ ~ $+\infty$) | 확률 (0 ~ 1) |
| **용도** | 회귀 (숫자 예측) | 분류 (그룹 분류) |
| **손실 함수** | MSE | Cross-Entropy |
| **활성화 함수** | 없음 (항등 함수) | 시그모이드 |
| **닫힌 해** | **있음** (정규방정식) | **없음** (경사 하강법 필요) |
| **분포 가정** | 가우시안 노이즈 | 베르누이 분포 |

### 5.6 다중 클래스: 소프트맥스 (Softmax)

#### 시그모이드의 일반화

시그모이드는 2개 클래스에만 쓸 수 있다. 3개 이상의 클래스에는 **소프트맥스**를 쓴다.

$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}$$

**읽는 법**: "각 클래스의 점수를 $e$의 지수로 변환한 뒤, 전체 합으로 나누어 확률로 만든다."

#### 숫자 예시

3클래스 분류. 모델이 계산한 점수(logit): $z = [2.0, 1.0, 0.1]$

```
1단계: e^z 계산
  e^2.0 = 7.389
  e^1.0 = 2.718
  e^0.1 = 1.105
  합계 = 11.212

2단계: 확률 계산
  p₁ = 7.389 / 11.212 = 0.659  (65.9%)
  p₂ = 2.718 / 11.212 = 0.242  (24.2%)
  p₃ = 1.105 / 11.212 = 0.099  (9.9%)

확인: 0.659 + 0.242 + 0.099 = 1.000 ✓ (확률의 합 = 1)

→ 클래스 1로 분류! (확률 65.9%)
```

> **소프트맥스의 성질:**
> - 모든 출력이 0과 1 사이
> - 모든 출력의 합이 정확히 1
> - 가장 큰 입력이 가장 높은 확률을 받음
> - 차이가 클수록 확률 차이가 극대화됨

### 5.7 딥러닝과의 연결

- 딥러닝 분류 모델의 **마지막 층**은 항상 로지스틱 회귀(이진) 또는 소프트맥스 회귀(다중)이다
- 예: ImageNet 분류 → 마지막에 1000개 클래스에 대한 소프트맥스
- 로지스틱 회귀 = "뉴런 1개 + 시그모이드" → 이것을 쌓으면 딥러닝이 된다
- **비선형 로지스틱 회귀**: $\sigma(\phi(x)^\top w)$에서 $\phi(x)$를 신경망으로 학습하면 → 딥러닝!

```
선형 로지스틱 회귀:    x → [w^T x] → [σ] → 확률
                         (선형)

비선형 로지스틱 회귀:  x → [신경망 φ(x)] → [w^T φ(x)] → [σ] → 확률
                         (특징 학습)      (선형 분류)

딥러닝:               x → [층1] → [층2] → ... → [softmax] → 확률
                        ↑ 이 전체가 φ(x)를 학습하는 것
```

### 5.8 연습문제

**문제 9.** $\sigma(z) = \frac{1}{1+e^{-z}}$에서 $\sigma(0)$, $\sigma(100)$, $\sigma(-100)$의 값을 구하고 그 의미를 설명하라.

<details>
<summary>풀이 보기</summary>

$$\sigma(0) = \frac{1}{1+e^0} = \frac{1}{1+1} = 0.5$$

→ 정확히 반반. 어느 쪽인지 전혀 모르는 상태.

$$\sigma(100) = \frac{1}{1+e^{-100}} \approx \frac{1}{1+0} = 1.0$$

→ 거의 확실히 클래스 1. $e^{-100}$은 거의 0이다.

$$\sigma(-100) = \frac{1}{1+e^{100}} \approx \frac{1}{\infty} = 0.0$$

→ 거의 확실히 클래스 0. $e^{100}$은 매우 큰 수이다.

**의미**: 시그모이드는 아무리 큰 값이 들어와도 0~1 사이로 "눌러준다(squash)". 이것이 확률로 해석 가능한 이유이다.

</details>

**문제 10.** 소프트맥스에 $z = [1, 1, 1]$을 넣으면 어떤 결과가 나오는가? 왜 그런가?

<details>
<summary>풀이 보기</summary>

$$e^1 = e^1 = e^1 = 2.718$$

$$\text{softmax}([1,1,1]) = \left[\frac{2.718}{3 \times 2.718},\ \frac{2.718}{3 \times 2.718},\ \frac{2.718}{3 \times 2.718}\right] = \left[\frac{1}{3},\ \frac{1}{3},\ \frac{1}{3}\right]$$

모든 클래스의 확률이 동일하게 $\frac{1}{3}$이 된다.

**이유**: 입력 점수가 모두 같으면, 모든 클래스가 동일한 확률을 가져야 한다. 소프트맥스가 이 직관을 정확히 반영한다.

</details>

**문제 11.** 다음 빈칸을 채우시오.

| 분포 가정 | NLL 최소화 = | 사용 상황 |

| 카테고리 | (b) | 다중 분류 |
| 베르누이 | (c) | 이진 분류 |

<details>
<summary>풀이 보기</summary>

- (a) **MSE (Mean Squared Error)** 최소화
- (b) **Cross-Entropy** 최소화
- (c) **Binary Cross-Entropy** 최소화

핵심: "분포 가정 + MLE = 손실 함수". 가정하는 분포에 따라 손실 함수가 자동으로 결정된다.

</details>

**문제 12.** 경험적 위험을 완벽하게 최소화하면 (= 훈련 데이터 손실 = 0), 좋은 모델인가?

<details>
<summary>풀이 보기</summary>

**반드시 그렇지는 않다.** 오히려 **과적합(overfitting)** 의 위험이 있다.

- 경험적 위험 $L_S(h) = 0$: 훈련 데이터를 완벽히 외운 것
- 모집단 위험 $L_P(h)$: 새로운 데이터에 대한 성능은 나쁠 수 있음

이것이 릿지 회귀 같은 **정규화**가 필요한 이유이다. 훈련 데이터를 "적당히" 맞추면서, 모델을 과도하게 복잡하게 만들지 않는 균형이 중요하다.

</details>

### 계산 문제

**문제 13.** 선형 회귀에서 데이터가 $(1, 1), (2, 2), (3, 3)$일 때:
- (a) 정규방정식의 해를 구하라
- (b) 릿지 회귀 ($\lambda = 6$)의 해를 구하고 (a)와 비교하라

<details>
<summary>풀이 보기</summary>

**(a) 정규방정식의 해:**

$$X = \begin{bmatrix} 1 & 1 \\ 2 & 1 \\ 3 & 1 \end{bmatrix}, \quad y = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}$$

$$X^\top X = \begin{bmatrix} 14 & 6 \\ 6 & 3 \end{bmatrix}, \quad X^\top y = \begin{bmatrix} 14 \\ 6 \end{bmatrix}$$

$$\det = 42 - 36 = 6$$

$$\hat{w} = \frac{1}{6}\begin{bmatrix} 3 & -6 \\ -6 & 14 \end{bmatrix}\begin{bmatrix} 14 \\ 6 \end{bmatrix} = \frac{1}{6}\begin{bmatrix} 42-36 \\ -84+84 \end{bmatrix} = \frac{1}{6}\begin{bmatrix} 6 \\ 0 \end{bmatrix} = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$$

결과: $y = 1 \cdot x + 0 = x$ (완벽한 직선!)

**(b) 릿지 회귀 ($\lambda = 6$):**

$$X^\top X + 6I = \begin{bmatrix} 14 & 6 \\ 6 & 3 \end{bmatrix} + \begin{bmatrix} 6 & 0 \\ 0 & 6 \end{bmatrix} = \begin{bmatrix} 20 & 6 \\ 6 & 9 \end{bmatrix}$$

$$\det = 180 - 36 = 144$$

$$(X^\top X + 6I)^{-1} = \frac{1}{144}\begin{bmatrix} 9 & -6 \\ -6 & 20 \end{bmatrix}$$

$$\hat{w}_\lambda = \frac{1}{144}\begin{bmatrix} 9 & -6 \\ -6 & 20 \end{bmatrix}\begin{bmatrix} 14 \\ 6 \end{bmatrix} = \frac{1}{144}\begin{bmatrix} 126-36 \\ -84+120 \end{bmatrix} = \frac{1}{144}\begin{bmatrix} 90 \\ 36 \end{bmatrix} = \begin{bmatrix} 0.625 \\ 0.25 \end{bmatrix}$$

결과: $y = 0.625x + 0.25$

**비교:**
- (a) $y = x$: 기울기 1, 절편 0 → 데이터를 완벽히 맞춤
- (b) $y = 0.625x + 0.25$: 기울기가 줄고 절편이 생김 → 가중치가 0 쪽으로 당겨짐 (정규화 효과!)

정규화($\lambda$)가 가중치를 "줄이는" 역할을 한다는 것을 숫자로 확인할 수 있다.

</details>

### 서술 문제

**문제 14.** "선형 회귀는 뉴런 1개, 로지스틱 회귀는 뉴런 1개 + 시그모이드"라는 말의 의미를 설명하고, 이것이 어떻게 딥러닝으로 확장되는지 서술하라.

<details>
<summary>풀이 보기</summary>

**선형 회귀** = $f(x) = w^\top x$
- 입력 $x$에 가중치 $w$를 곱하고 더한다 (선형 결합)
- 이것은 신경망의 뉴런 1개가 하는 일과 정확히 같다
- 활성화 함수 없이 출력을 바로 내보낸다

**로지스틱 회귀** = $f(x) = \sigma(w^\top x)$
- 선형 결합 후 시그모이드 함수를 씌운다
- 뉴런 1개 + 시그모이드 활성화 함수

**딥러닝으로의 확장:**
1. 뉴런을 **여러 개** 배치 → 한 층 (layer)
2. 층을 **여러 개** 쌓기 → 깊은 신경망 (deep network)
3. 각 층에서: 선형 결합 → 비선형 활성화 → 다음 층에 전달
4. 마지막 층: 소프트맥스 (분류) 또는 그대로 출력 (회귀)

```
[뉴런 1개]          [딥러닝]
x → w^Tx → σ       x → [W₁x] → [ReLU] → [W₂] → [ReLU] → ... → [softmax]
 (로지스틱 회귀)        (선형)   (비선형)  (선형)  (비선형)      (분류)
```

핵심 통찰: 딥러닝은 선형 회귀/로지스틱 회귀라는 **기본 단위의 반복적 조합**이다. 기초를 이해하면 딥러닝의 구조가 자연스럽게 이해된다.

</details>

## 핵심 수식 요약

| 개념 | 수식 | 설명 |
|------|------|------|
| **경험적 위험** | $L_S(h) = \frac{1}{n}\sum_i \ell(y_i, h(x_i))$ | 훈련 데이터 평균 손실 |
| **모집단 위험** | $L_P(h) = \mathbb{E}[\ell(y, h(x))]$ | 전체 데이터 기대 손실 |
| **MSE** | $\frac{1}{n}\sum_i (y_i - h(x_i))^2$ | 회귀 손실 |
| **Cross-Entropy** | $-\sum_i \log h_{y_i}(x_i)$ | 분류 손실 |
| **선형 회귀 모델** | $f_w(x) = x^\top w$ | 선형 예측 |
| **정규방정식** | $X^\top X \hat{w} = X^\top y$ | 최적 가중치 조건 |
| **정규방정식 해** | $\hat{w} = (X^\top X)^{-1} X^\top y$ | full rank일 때 |
| **릿지 회귀 해** | $\hat{w}_\lambda = (X^\top X + \lambda I)^{-1} X^\top y$ | 정규화된 해 |
| **시그모이드** | $\sigma(z) = \frac{1}{1+e^{-z}}$ | 확률 변환 |
| **로지스틱 회귀** | $P(y=1|x) = \sigma(w^\top x)$ | 이진 분류 확률 |
| **소프트맥스** | $\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$ | 다중 분류 확률 |
| **BCE 손실** | $-\sum_i [y_i \log \sigma + (1-y_i)\log(1-\sigma)]$ | 이진 분류 손실 |
| **LDA 결정 경계** | $a = \Sigma^{-1}(\mu_1 - \mu_2)$ | 선형 판별 방향 |
| **베이즈 분류기** | $f(x) = \arg\max_k p(y=k|x)$ | 이론적 최적 분류 |
