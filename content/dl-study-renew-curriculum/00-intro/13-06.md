## 1. 입문 (Beginner)

### 1.1 퍼셉트론 (Perceptron)

#### 핵심 개념

퍼셉트론은 생물학적 뉴런을 모방한 가장 단순한 인공 신경망 단위이다.

```
입력(x) → [가중합: z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b] → [활성화 함수: f(z)] → 출력(y)
```

**구성 요소:**
- **입력 (Inputs, x):** 외부에서 들어오는 신호 (예: 이미지 픽셀, 텍스트 임베딩)
- **가중치 (Weights, w):** 각 입력의 중요도를 결정하는 학습 가능한 파라미터
- **편향 (Bias, b):** 활성화 함수의 임계값을 조절하는 파라미터
- **활성화 함수 (Activation Function):** 비선형성을 도입하여 복잡한 패턴 학습을 가능하게 함

**직관적 이해:**
- 퍼셉트론은 "예/아니오" 결정을 내리는 의사결정자이다
- 가중치는 각 증거(입력)에 대한 신뢰도를 나타냄
- 편향은 "기본적으로 얼마나 쉽게 활성화되는가"를 결정

**한계:**
- 단일 퍼셉트론은 **선형 분리 가능한** 문제만 풀 수 있다
- XOR 문제를 풀 수 없다 (Minsky & Papert, 1969)

### 1.2 다층 신경망 (Multi-Layer Networks)

#### 핵심 개념

단일 퍼셉트론의 한계를 극복하기 위해 여러 층을 쌓은 구조이다.

```
입력층          은닉층(들)         출력층
[x₁] ──┐    ┌── [h₁] ──┐    ┌── [y₁]
[x₂] ──┼────┼── [h₂] ──┼────┼── [y₂]
[x₃] ──┘    └── [h₃] ──┘    └── [y₃]
```

**층(Layer)의 역할:**
| 층 | 역할 | 비유 |
|---|---|---|
| 입력층 (Input Layer) | 원본 데이터를 받아들임 | 눈으로 보는 것 |
| 은닉층 (Hidden Layer) | 특징을 추출하고 변환 | 뇌에서 정보를 처리하는 것 |
| 출력층 (Output Layer) | 최종 예측/결정을 출력 | 판단을 내리는 것 |

**다층 신경망의 핵심 직관:**
- 각 은닉층은 **데이터를 새로운 표현 공간으로 변환**한다
- 첫 번째 은닉층: 단순한 특징 감지 (예: 이미지의 가장자리)
- 중간 은닉층: 복합 특징 조합 (예: 눈, 코 모양)
- 깊은 은닉층: 추상적 개념 형성 (예: 얼굴 인식)
- 층이 깊어질수록 점점 더 **추상적인 특징**을 학습한다

**만능 근사 정리 (Universal Approximation Theorem):**
- 충분히 넓은 은닉층 하나만 있으면 이론적으로 임의의 연속 함수를 근사할 수 있다
- 그러나 실제로는 깊은 네트워크가 같은 표현력을 훨씬 적은 파라미터로 달성

### 1.3 활성화 함수 시각적 가이드

#### 핵심 개념

활성화 함수는 신경망에 **비선형성**을 도입하는 수학적 함수이다. 활성화 함수가 없으면 아무리 많은 층을 쌓아도 결국 하나의 선형 변환과 동일하다.

#### 주요 활성화 함수 비교

| 함수 | 수식 | 출력 범위 | 장점 | 단점 |
|------|------|-----------|------|------|
| **Sigmoid** | σ(x) = 1/(1+e⁻ˣ) | (0, 1) | 확률 해석 가능 | 기울기 소실, 비대칭 |
| **Tanh** | tanh(x) | (-1, 1) | 영점 중심 | 기울기 소실 |
| **ReLU** | max(0, x) | [0, +inf) | 계산 효율, 기울기 소실 완화 | Dead neuron 문제 |
| **Leaky ReLU** | max(αx, x) | (-inf, +inf) | Dead neuron 해결 | α 하이퍼파라미터 |
| **Swish** | x * σ(x) | (-0.28, +inf) | 매끄러운 곡선, 깊은 네트워크에 유리 | 계산 비용 증가 |
| **GELU** | x * Φ(x) | ≈(-0.17, +inf) | Transformer에서 표준 | 계산 비용 |
| **Mish** | x * tanh(softplus(x)) | ≈(-0.31, +inf) | 매끄러움, 음수 허용 | 계산 비용 |

**활성화 함수 시각적 형태:**

```
Sigmoid:          ReLU:             Swish:
    ___               /                 /
   /             ____/             ___/
  /             /                _/
 /             /                /
              |               \/
```

**선택 가이드:**
- **기본 선택:** ReLU (대부분의 CNN, 피드포워드 네트워크)
- **NLP / Transformer:** GELU
- **깊은 네트워크:** Swish 또는 Mish
- **출력층 (분류):** Sigmoid(이진) 또는 Softmax(다중 클래스)
- **출력층 (회귀):** 활성화 없음 (선형)

### 1.4 경사 하강법과 역전파 직관

#### 경사 하강법 (Gradient Descent)

**직관적 이해 - 산 내려오기 비유:**
1. 안개 낀 산꼭대기에서 시작 (랜덤 초기화)
2. 발밑의 경사를 느낀다 (기울기/그래디언트 계산)
3. 가장 가파른 내리막 방향으로 한 발 내딛는다 (파라미터 업데이트)
4. 골짜기(최솟값)에 도달할 때까지 반복

**수식:**
```
θ_new = θ_old - η * ∂L/∂θ

여기서:
  θ = 파라미터 (가중치, 편향)
  η = 학습률 (보폭 크기)
  ∂L/∂θ = 손실 함수의 기울기
```

**학습률(η)의 역할:**
- 너무 크면: 최솟값을 건너뛰어 발산
- 너무 작으면: 수렴이 매우 느리거나 지역 최솟값에 갇힘
- 적절하면: 효율적으로 최솟값에 수렴

#### 역전파 (Backpropagation)

역전파는 **연쇄 법칙(chain rule)**을 체계적으로 적용하여 모든 파라미터에 대한 기울기를 효율적으로 계산하는 알고리즘이다.

**2단계 프로세스:**

```
1단계: 순전파 (Forward Pass)
   입력 → 은닉층 → 출력 → 손실 계산
   (왼쪽에서 오른쪽으로 데이터 흐름)

2단계: 역전파 (Backward Pass)
   손실 → 출력층 기울기 → 은닉층 기울기 → 입력층 기울기
   (오른쪽에서 왼쪽으로 오차 신호 전파)
```

**연쇄 법칙 핵심 아이디어:**
```
∂L/∂w₁ = ∂L/∂y * ∂y/∂h * ∂h/∂w₁

"최종 손실에 대한 w₁의 영향" =
  "손실에 대한 출력의 영향" ×
  "출력에 대한 은닉값의 영향" ×
  "은닉값에 대한 w₁의 영향"
```

**역전파의 효율성:**
- 나이브하게 각 가중치에 대한 기울기를 개별 계산하면 O(W²) (W: 가중치 수)
- 역전파는 중간 기울기를 재사용하여 O(W)로 계산 (한 번의 역방향 패스)

## 2. 중급 (Intermediate)

### 2.1 계산 그래프 (Computational Graphs)

#### 핵심 개념

계산 그래프는 수학적 연산을 **방향성 비순환 그래프(DAG)**로 표현한 것이다. 간선(edge)은 값(스칼라, 벡터, 텐서)을 나타내고, 노드(node)는 함수(연산)를 나타낸다.

**예시: f(x, y, z) = (x + y) * z**
```
x ──→ [+] ──→ q ──→ [×] ──→ f
y ──↗                z ──↗
```

**순전파(Forward Pass):**
```
x = 2, y = 3, z = -4
q = x + y = 5
f = q * z = -20
```

**역전파(Backward Pass):**
```
∂f/∂f = 1
∂f/∂z = q = 5
∂f/∂q = z = -4
∂f/∂x = ∂f/∂q * ∂q/∂x = -4 * 1 = -4
∂f/∂y = ∂f/∂q * ∂q/∂y = -4 * 1 = -4
```

**계산 그래프의 장점:**
1. **모듈성:** 각 노드는 로컬 기울기만 알면 된다
2. **효율성:** 중간 기울기를 캐싱하여 재계산 방지
3. **자동화:** 프레임워크가 자동으로 그래프를 구축하고 기울기를 계산

**분기(fan-out)와 합류(fan-in) 규칙:**
- 하나의 변수가 여러 연산에 사용될 때: 역전파 시 **기울기를 합산**
- 이는 다변수 미적분의 전미분(total derivative) 개념과 일치

### 2.2 자동 미분 (Automatic Differentiation)

#### 핵심 개념

자동 미분(AD)은 컴퓨터 프로그램으로 표현된 함수의 편미분을 **정확하게(기계 정밀도)** 계산하는 기법이다.

**세 가지 미분 방식 비교:**

| 방식 | 정확도 | 속도 | 설명 |
|------|--------|------|------|
| 수치 미분 | 근사값 (오차 있음) | 느림 O(n) | (f(x+h) - f(x-h)) / 2h |
| 기호 미분 | 정확 | 표현식 폭발 가능 | 수학 공식을 기호적으로 미분 |
| **자동 미분** | **정확 (기계 정밀도)** | **효율적** | 연쇄 법칙을 기본 연산에 반복 적용 |

**두 가지 모드:**

**순방향 모드 (Forward Mode AD):**
```
입력 → ... → 출력 (순전파와 같은 방향으로 미분 전파)
- 입력 1개, 출력 N개일 때 효율적
- 한 번에 하나의 입력 변수에 대한 기울기를 모든 중간값에서 계산
- 야코비안의 한 열을 한 번에 계산
```

**역방향 모드 (Reverse Mode AD = 역전파):**
```
출력 → ... → 입력 (역방향으로 미분 전파)
- 입력 N개, 출력 1개(손실 함수)일 때 효율적
- 한 번에 하나의 출력에 대한 모든 입력의 기울기를 계산
- 야코비안의 한 행을 한 번에 계산
- 딥러닝에서 사용하는 방식 (손실 = 스칼라 출력 1개)
```

**PyTorch의 자동 미분 시스템 (torch.autograd):**
```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = torch.tensor(3.0, requires_grad=True)

# 순전파: 계산 그래프가 자동으로 구축됨
z = x**2 + 3*x*y + y**2  # z = 4 + 18 + 9 = 31

# 역전파: 모든 기울기를 자동 계산
z.backward()

print(x.grad)  # ∂z/∂x = 2x + 3y = 4 + 9 = 13
print(y.grad)  # ∂z/∂y = 3x + 2y = 6 + 6 = 12
```

### 2.3 가중치 초기화 (Weight Initialization)

#### 핵심 개념

가중치 초기화는 학습의 성패를 좌우하는 중요한 요소이다. 잘못된 초기화는 **기울기 소실(vanishing gradient)** 또는 **기울기 폭발(exploding gradient)**을 유발한다.

**나쁜 초기화의 결과:**
```
모두 0으로 초기화 → 대칭성 문제 (모든 뉴런이 동일하게 학습)
너무 큰 값        → 기울기 폭발, 활성화 포화
너무 작은 값      → 기울기 소실, 학습 정체
```

#### Xavier 초기화 (Glorot, 2010)

**목표:** 각 층의 출력 분산을 입력 분산과 동일하게 유지

```
W ~ N(0, σ²)  여기서  σ² = 2 / (n_in + n_out)
또는
W ~ U(-a, a)  여기서  a = √(6 / (n_in + n_out))

n_in:  입력 뉴런 수
n_out: 출력 뉴런 수
```

- **적합한 활성화 함수:** Sigmoid, Tanh (대칭적이고 원점 근처에서 선형)
- **핵심 아이디어:** 순전파와 역전파 모두에서 분산이 유지되도록 입출력 크기의 평균을 사용

#### He 초기화 (Kaiming, 2015)

**목표:** ReLU 계열 활성화 함수에서 분산 유지

```
W ~ N(0, σ²)  여기서  σ² = 2 / n_in
```

- **적합한 활성화 함수:** ReLU, Leaky ReLU, PReLU
- **핵심 아이디어:** ReLU는 음수 입력을 0으로 만들어 분산을 절반으로 줄이므로, 2배를 보상

#### 최신 초기화 기법

| 기법 | 특징 | 사용 사례 |
|------|------|-----------|
| **ZerO 초기화** | Hadamard 변환 활용, 완전 결정론적 | 배치 정규화 없는 극심하게 깊은 네트워크 |
| **FixUp 초기화** | 잔차 연결의 분산 스케일링 문제 해결 | 정규화 없이 깊은 ResNet 안정 학습 |
| **LSUV** | Layer-Sequential Unit-Variance | 각 층의 출력 분산을 실험적으로 1로 맞춤 |

**PyTorch 구현:**
```python
import torch.nn as nn

# Xavier 초기화
nn.init.xavier_uniform_(layer.weight)
nn.init.xavier_normal_(layer.weight)

# He 초기화
nn.init.kaiming_uniform_(layer.weight, nonlinearity='relu')
nn.init.kaiming_normal_(layer.weight, nonlinearity='relu')
```

### 2.4 배치 정규화 (Batch Normalization)

#### 핵심 개념

배치 정규화(BatchNorm, Ioffe & Szegedy, 2015)는 각 층의 입력을 미니배치 단위로 정규화하여 학습을 안정화하고 가속하는 기법이다.

**알고리즘:**
```
미니배치 B = {x₁, x₂, ..., xₘ}에 대해:

1. 미니배치 평균:    μ_B = (1/m) Σ xᵢ
2. 미니배치 분산:    σ²_B = (1/m) Σ (xᵢ - μ_B)²
3. 정규화:          x̂ᵢ = (xᵢ - μ_B) / √(σ²_B + ε)
4. 스케일 & 시프트:  yᵢ = γ * x̂ᵢ + β    (γ, β는 학습 가능)
```

**배치 정규화의 효과:**
| 효과 | 설명 |
|------|------|
| 학습 가속 | 더 큰 학습률 사용 가능 |
| 초기화 민감도 감소 | 나쁜 초기화에도 학습 가능 |
| 정규화 효과 | 약간의 드롭아웃 효과 (배치 내 노이즈) |
| 기울기 흐름 개선 | 내부 공변량 이동(Internal Covariate Shift) 완화 |

**배치 정규화의 위치:**
```
일반적:  Linear → BatchNorm → Activation → Dropout
또는:    Linear → Activation → BatchNorm → Dropout  (논쟁 중)
```

**주의사항:**
- 배치 크기가 너무 작으면 통계가 불안정 → Layer Normalization 사용 고려
- 추론(inference) 시에는 학습 중 축적한 이동 평균/분산 사용
- Transformer 등 시퀀스 모델에서는 **Layer Normalization**이 표준

**변형:**
| 기법 | 정규화 축 | 주 사용처 |
|------|-----------|-----------|
| Batch Norm | 배치 축 (N) | CNN |
| Layer Norm | 특징 축 (C, H, W) | Transformer, RNN |
| Instance Norm | 각 샘플의 채널별 (H, W) | 스타일 전이 |
| Group Norm | 채널 그룹별 | 작은 배치, 검출 |

### 2.5 스킵 연결 (Skip Connections / Residual Connections)

#### 핵심 개념

스킵 연결(He et al., 2015, ResNet)은 한 층의 입력을 몇 층을 건너뛴 출력에 직접 더하는 구조이다.

```
x ──────────────────────────┐
│                            │
↓                            │ (identity shortcut)
[Conv → BN → ReLU → Conv → BN] → [+] → ReLU → 출력
         F(x)                    x + F(x)
```

**핵심 수식:**
```
y = F(x) + x    (잔차 학습)

네트워크가 학습하는 것: F(x) = y - x (잔차, residual)
```

**왜 효과적인가:**

1. **기울기 고속도로 (Gradient Highway):**
   ```
   ∂L/∂x = ∂L/∂y * (∂F(x)/∂x + 1)

   "+1" 항 덕분에 기울기가 층을 건너뛰어 직접 전달됨
   → 수백 층에서도 기울기 소실 문제 크게 완화
   ```

2. **항등 함수 학습 용이:**
   - F(x) = 0을 학습하면 y = x (항등 함수)
   - 불필요한 층은 자연스럽게 "꺼질" 수 있음
   - 최적 깊이를 네트워크가 스스로 결정

3. **손실 표면 평활화:**
   - 스킵 연결은 손실 표면을 극적으로 볼록(convex)하게 만들어 최적화를 용이하게 함

**변형:**
| 유형 | 수식 | 예시 아키텍처 |
|------|------|---------------|
| 덧셈 (Additive) | y = F(x) + x | ResNet |
| 연결 (Concatenation) | y = [F(x); x] | DenseNet |
| 게이트 (Gated) | y = T(x)*F(x) + (1-T(x))*x | Highway Network |

### 3.1 신경 접선 커널 (Neural Tangent Kernel, NTK)

#### 핵심 개념

NTK(Jacot et al., 2018)는 신경망의 학습 동역학을 **커널 방법(kernel method)**의 관점에서 분석하는 이론적 프레임워크이다.

**핵심 아이디어:**
- 무한 너비(infinite-width) 극한에서 신경망은 **가우시안 과정(Gaussian Process)**과 동일
- 초기화된 충분히 넓은 심층 신경망을 무한소 학습률로 경사 하강법으로 학습시키면, 이는 **NTK라는 결정론적 커널**을 사용한 커널 회귀와 동일

**NTK 정의:**
```
K(x, x') = ⟨∇_θ f(x; θ), ∇_θ f(x'; θ)⟩

여기서:
  f(x; θ): 파라미터 θ를 가진 신경망의 출력
  ∇_θ f:   파라미터에 대한 기울기
  K:       두 입력 x, x' 사이의 커널 값
```

**학습 동역학:**
```
무한 너비에서 NTK는 학습 중 일정(frozen)하게 유지됨

f_t(x) - y = exp(-η K t) (f_0(x) - y)

→ 학습은 커널 K에 의해 결정되는 선형 동역학을 따름
→ 전역 최솟값으로의 수렴이 보장됨
```

**이론적 의의:**
| 질문 | NTK의 답 |
|------|----------|
| 과적합에도 일반화하는 이유? | 커널의 고유값 구조가 암묵적 정규화 제공 |
| 깊은 네트워크가 수렴하는 이유? | NTK의 양정치성(positive definiteness) |
| 너비가 중요한 이유? | 넓을수록 NTK가 안정 → 학습 예측 가능 |

**한계와 비판:**
- 무한 너비 신경망은 **특징 학습(feature learning)**을 하지 못함
- 실제 유한 너비 네트워크의 성능을 완전히 설명하지 못함
- "lazy training" 체제에서만 유효: 파라미터가 초기값 근처에서 거의 변하지 않음
- 최근 **μP (Maximal Update Parameterization)** 등 유한 너비에서의 특징 학습을 설명하는 이론이 발전 중

**참고 자료:**
- [원논문: Neural Tangent Kernel (Jacot et al., 2018)](https://arxiv.org/abs/1806.07572)
- [Lil'Log - Some Math behind NTK](https://lilianweng.github.io/posts/2022-09-08-ntk/)
- [CMU ML Blog - Ultra-Wide Deep Nets and NTK](https://blog.ml.cmu.edu/2019/10/03/ultra-wide-deep-nets-and-the-neural-tangent-kernel-ntk/)

### 3.2 손실 표면 기하학 (Loss Landscape Geometry)

#### 핵심 개념

신경망 학습은 고도로 비볼록(non-convex)한 손실 함수의 최솟값을 찾는 과정이다. 손실 표면의 기하학적 구조는 학습의 성공 여부를 크게 좌우한다.

**손실 표면의 핵심 구조:**
```
        날카로운 극솟값            평탄한 극솟값
         (Sharp)                  (Flat)
           /\                    ___________
          /  \                  /           \
         /    \                /             \
        /      \              /               \
       /        \            /                 \

   → 일반화 나쁨              → 일반화 좋음
   (작은 섭동에 민감)         (견고한 해)
```

**주요 발견 (Li et al., 2018 - Visualizing the Loss Landscape):**

1. **네트워크 깊이와 손실 표면:**
   - 얕은 네트워크: 매끄럽고 넓은 볼록 영역
   - 깊은 네트워크: 혼란스럽고(chaotic) 고도로 비볼록 → 학습 어려움

2. **스킵 연결의 효과:**
   - 스킵 연결은 손실 표면의 극적인 "볼록화(convexification)"를 유발
   - ResNet-56의 손실 표면은 ResNet-56-noshort보다 훨씬 매끄러움

3. **날카로운 vs 평탄한 극솟값:**
   - 평탄한 극솟값(flat minima)은 더 나은 일반화 성능과 상관
   - 큰 배치 크기 → 날카로운 극솟값으로 수렴 경향
   - 작은 배치 크기 → 확률적 노이즈가 평탄한 극솟값으로 유도

**시각화 기법:**
| 기법 | 설명 |
|------|------|
| 1D 단면 (Linear Interpolation) | 두 가중치 사이를 보간하며 손실 플롯 |
| 2D 단면 (Random Directions) | 랜덤 방향 2개를 잡아 2D 등고선/3D 표면 생성 |
| **필터 정규화 (Filter Normalization)** | 방향 벡터를 필터 단위로 정규화하여 공정한 비교 가능 |

**안장점(Saddle Points) 문제:**
```
고차원 공간에서 극솟값보다 안장점이 기하급수적으로 많음
→ 실제로 SGD가 갇히는 것은 극솟값보다 안장점이나 평탄 영역

안장점 탈출 메커니즘:
- SGD의 확률적 노이즈가 안장점 탈출에 도움
- 모멘텀이 평탄 영역을 빠르게 통과하도록 가속
```

**참고 자료:**
- [Visualizing the Loss Landscape of Neural Nets (Li et al., 2018)](https://arxiv.org/abs/1712.09913)
- [Loss Landscape 시각화 코드 (GitHub)](https://github.com/tomgoldstein/loss-landscape)
- [인터랙티브 손실 표면 탐색기](https://losslandscape.com/)
- [J. Tucker의 Loss Landscape 시각적 탐색](https://jtuckerk.github.io/loss_landscape.html)

### 3.3 복권 가설 (Lottery Ticket Hypothesis)

#### 핵심 개념

복권 가설(Frankle & Carlin, 2019)은 밀집 네트워크 내에 **"당첨 티켓"**이라 불리는 희소 부분 네트워크가 존재하며, 이 부분 네트워크만으로도 원래 네트워크와 동등한 성능을 달성할 수 있다는 가설이다.

**가설 진술:**
> 밀집(dense), 무작위 초기화된 피드포워드 네트워크는 부분 네트워크("당첨 티켓")를 포함하며, 이 부분 네트워크는 독립적으로 학습될 때 비슷한 반복 횟수 내에 원래 네트워크와 비교 가능한 테스트 정확도에 도달한다.

**핵심 메커니즘 - 반복적 가지치기 (Iterative Pruning):**
```
1. 밀집 네트워크를 무작위 초기화 (가중치 θ₀ 저장)
2. 네트워크를 수렴까지 학습
3. 크기가 가장 작은 가중치 p%를 가지치기 (마스크 m 생성)
4. 남은 가중치를 원래 초기값 θ₀로 재초기화
5. 마스크된 네트워크 m ⊙ θ₀를 재학습
6. 2-5 반복하여 점진적으로 희소화
```

**주요 발견:**
- MNIST, CIFAR-10에서 원래 크기의 **10-20%** 이하인 당첨 티켓을 일관되게 발견
- 이 크기 이상에서는 당첨 티켓이 원래 네트워크보다 **빠르게 학습**하고 **더 높은 정확도** 달성
- 초기화가 핵심: 무작위 재초기화(랜덤 티켓)는 성능 저하

**이론적 의의:**
| 함의 | 설명 |
|------|------|
| 과파라미터화의 이유 | 넓은 네트워크 = 더 많은 "복권 티켓" → 당첨 확률 증가 |
| 모델 압축 | 학습 후 90%+ 가중치 제거 가능 |
| 초기화의 중요성 | "초기화 복권에 당첨"된 연결이 학습 성공을 결정 |
| 효율적 학습 | 처음부터 희소 네트워크로 학습 가능성 시사 |

**확장 연구:**
- **Rewinding (되감기):** 초기값 대신 학습 초반(k번째 반복)의 가중치로 되돌려도 효과적
- **BERT에서의 복권 티켓:** MLM 과제에서 40-90% 희소도의 당첨 티켓 발견
- **"Super Tickets":** 여러 과제에 동시에 효과적인 부분 네트워크
- **학습 없는 가지치기:** 초기화 시점에서 당첨 티켓을 식별하는 연구

**참고 자료:**

### 3.4 2차 최적화 (Second-Order Optimization)

#### 핵심 개념

1차 최적화(SGD, Adam 등)가 기울기(1차 도함수)만 사용하는 반면, 2차 최적화는 **헤시안(Hessian, 2차 도함수 행렬)**을 추가로 활용하여 더 정보가 풍부한 업데이트를 수행한다.

**1차 vs 2차 비교:**
```
1차 (SGD):     θ ← θ - η ∇L(θ)
2차 (뉴턴법):  θ ← θ - H⁻¹ ∇L(θ)

H = 헤시안 행렬 = ∂²L / ∂θᵢ∂θⱼ  (N×N 행렬, N=파라미터 수)
```

**2차 최적화의 장점:**
- 곡률(curvature) 정보를 활용하여 **파라미터별 적응적 학습률** 효과
- 좁은 골짜기(ill-conditioned landscape)에서 1차 방법보다 효율적
- 이론적으로 2차(quadratic) 수렴 속도

**2차 최적화의 근본적 도전:**
| 문제 | 설명 |
|------|------|
| 메모리 | 헤시안 H는 N×N → N=10⁸이면 10¹⁶개 원소 |
| 계산 비용 | 헤시안 역행렬 O(N³) |
| 비볼록성 | 헤시안이 음의 고유값을 가질 수 있음 → 업데이트 방향 불안정 |

**실용적 근사 기법:**

| 기법 | 핵심 아이디어 | 복잡도 |
|------|--------------|--------|
| **L-BFGS** | 최근 m개 기울기로 헤시안 역행렬을 근사 | O(mN) |
| **Conjugate Gradient** | 헤시안-벡터 곱(Hv)만으로 뉴턴 방향 근사 | O(kN), k=반복 수 |
| **K-FAC** | 크로네커 분해로 피셔 정보 행렬 근사 | O(N) 근사 |
| **Natural Gradient** | 피셔 정보 행렬로 파라미터 공간의 곡률 반영 | O(N²) → K-FAC으로 근사 |
| **Shampoo** | 구조화된 크로네커 곱 근사 | O(N^{3/2}) |

**K-FAC (Kronecker-Factored Approximate Curvature):**
```
피셔 정보 행렬 F ≈ A ⊗ G

A: 입력 활성화의 공분산
G: 출력 기울기의 공분산

→ 블록 대각 + 크로네커 분해로 효율적 역행렬 계산
→ 분산 학습에서 대규모 배치 크기와 결합하여 학습 가속
```

**헤시안의 스펙트럼 분석:**
- 신경망의 헤시안은 대부분의 고유값이 0 근처 → 저차원 부분공간에서 유효한 곡률
- 소수의 큰 고유값이 학습 동역학을 지배
- 이 구조를 활용하면 효율적인 2차 근사 가능

### 3.5 정보 병목 이론 (Information Bottleneck Theory)

#### 핵심 개념

정보 병목(IB) 이론(Tishby et al., 2000; Tishby & Zaslavsky, 2015)은 심층 학습을 **정보 이론적 관점**에서 분석하는 프레임워크이다.

**기본 원리:**
```
입력 X → 표현 Z(은닉층) → 출력 Y

목표: I(Z; Y)를 최대화하면서 I(X; Z)를 최소화

여기서 I(A; B)는 상호 정보량 (mutual information)
```

**직관적 이해:**
```
정보 병목 = "필요한 정보만 남기고 나머지는 버려라"

X (원본 이미지)     →  Z (특징 표현)      →  Y (고양이/개)
[모든 픽셀 정보]       [핵심 특징만 보존]     [분류에 필요한 정보]
I(X; Z) 최소화          ↕                   I(Z; Y) 최대화
(압축)              정보 병목               (관련성)
```

**IB 라그랑지안:**
```
L_IB = I(X; Z) - β I(Z; Y)

β: 압축과 관련성 사이의 트레이드오프 파라미터
β → 0: 최대 압축 (Z에 정보가 거의 없음)
β → ∞: 최대 관련성 (Z가 Y에 대한 모든 정보 보존)
```

**Tishby의 심층 학습 해석 (2015, 2017):**

1. **정보 평면 (Information Plane):**
   - 각 층의 I(X; T)와 I(T; Y)를 추적 (T = 층의 표현)
   - 학습은 정보 평면에서의 궤적으로 시각화

2. **두 단계 학습 가설:**
   ```
   1단계 (적합, Fitting):     I(T; Y) 증가, I(X; T) 증가
   → 라벨에 대한 정보를 빠르게 획득

   2단계 (압축, Compression): I(T; Y) 유지, I(X; T) 감소
   → 불필요한 입력 정보를 제거 → 일반화 능력 향상
   ```

3. **일반화 경계:**
   ```
   일반화 오차 ≤ O(2^{I(X;T)} / n)

   → 정보 병목을 조절하면 일반화 오차를 직접 제어 가능
   → 파라미터 수, VC 차원 등 기존 경계보다 tight할 수 있음
   ```

**논쟁과 비판 (Saxe et al., 2018):**

| Tishby의 주장 | 반론 |
|---------------|------|
| 학습에 적합 → 압축의 두 단계가 존재 | 활성화 함수에 의존적 (ReLU에서는 압축 단계 불명확) |
| 압축이 일반화의 원인 | 압축 없이도 일반화 가능 |
| SGD의 확률성이 압축을 유도 | 배치 GD에서도 일반화 가능 |

**최신 발전 (Kawaguchi et al., 2023):**
- 정보 병목이 도움이 되는 **정확한 조건**을 수학적으로 규명
- 모든 상황에서 유효한 것은 아니지만, 특정 조건하에서 일반화 경계를 개선
- 정보 병목의 이점은 데이터 분포와 모델 구조에 의존

**참고 자료:**

### 3.8 딥러닝 수업과의 연결

- NTK 이론은 **과파라미터화된 네트워크의 일반화** 현상을 설명하는 핵심 프레임워크

- 2차 최적화는 **대규모 분산 학습**에서 큰 배치 크기를 효과적으로 활용하는 핵심 기술
- 정보 병목 이론은 **표현 학습, VAE, 정보 이론적 정규화**의 이론적 기반
