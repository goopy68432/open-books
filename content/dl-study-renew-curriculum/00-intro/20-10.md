## 1. 전이학습 (Transfer Learning)

### 1.1 전이학습이란?

#### 일상적 비유

> 피아노를 잘 치는 사람이 기타를 배우면, 처음부터 시작하는 사람보다 훨씬 빨리 배운다.
> 왜? 음악의 기본 원리(리듬, 화음, 악보 읽기)를 이미 알고 있기 때문이다.
>
> 전이학습도 똑같다. **한 과업에서 배운 지식을 다른 과업에 재활용**하는 것이다.

딥러닝에서 전이학습이 중요한 이유는 단순하다. **데이터가 부족한 상황이 너무 많기 때문이다.** 의료 영상을 분류하고 싶은데, 전문가가 라벨링한 X-ray 이미지가 500장밖에 없다고 하자. 이 500장만으로 수백만 개의 가중치를 가진 신경망을 처음부터 학습하면 과적합이 발생한다.

해결책: ImageNet(1400만 장)으로 먼저 학습한 모델을 가져와서, X-ray 데이터에 맞게 **살짝만 조정**한다. 이것이 전이학습이다.

---

### 1.2 Supervised Pre-training: ImageNet으로 ConvNet 사전학습

#### 일상적 비유

> 초등학교에서 한글, 수학, 과학 등 **범용적인 기초**를 배운다. 이 기초가 있어야 나중에
> 의사가 되든, 변호사가 되든, 프로그래머가 되든 각 분야의 전문 지식을 빨리 익힐 수 있다.
>
> ImageNet 사전학습 = 초등학교 교육. 특정 과업 학습 = 전문 분야 진학.

#### 어떻게 작동하는가?

**1단계: 사전학습 (Pre-training)**

ImageNet이라는 거대한 이미지 데이터셋(1000개 클래스, 1400만 장)으로 ConvNet을 학습한다.

```
입력 이미지 → [Conv층1] → [Conv층2] → ... → [Conv층N] → [FC층] → 1000개 클래스 분류
                  ↑                                           ↑
            저수준 특징 학습                            고수준 특징 학습
            (엣지, 텍스처)                           (물체 부분, 전체)
```

이 과정에서 CNN의 각 층은 다음과 같은 **범용적인 시각 특징**을 학습한다:

| 층 깊이 | 학습하는 특징 | 비유 |
|---------|-------------|------|
| 얕은 층 (앞쪽) | 엣지, 색상, 텍스처 | 선 긋기, 색칠하기 |
| 중간 층 | 패턴, 부분 형태 | 눈, 코, 바퀴 같은 부품 인식 |
| 깊은 층 (뒤쪽) | 물체 전체, 장면 | "이건 강아지", "이건 자동차" |

**2단계: 전이 (Transfer)**

사전학습된 모델에서 **마지막 분류 층(FC층)을 제거**하고, 새로운 과업에 맞는 분류 층을 붙인다.

```
사전학습된 모델 (ImageNet 1000 클래스)
입력 → [Conv층들 - 그대로 유지] → [FC층: 1000 클래스] ← 이것을 제거

전이학습 후 (예: X-ray 질병 분류 3 클래스)
입력 → [Conv층들 - 그대로 유지 or 미세조정] → [새 FC층: 3 클래스] ← 새로 추가
```

#### 딥러닝에서의 의미

- 사전학습된 Conv층의 가중치에는 "시각의 기본 문법"이 담겨 있다
- 이 기본 문법은 어떤 이미지 과업에서든 유용하다 (엣지, 텍스처, 패턴 등은 보편적)
- 따라서 소량의 데이터로도 높은 성능을 달성할 수 있다

### 1.3 Unsupervised Pre-training (자기지도 사전학습)

#### 일상적 비유

> ImageNet 사전학습은 "정답이 있는 교과서"로 공부한 것이다.
> 그런데 세상에는 정답 없이도 배울 수 있는 것이 훨씬 많다.
>
> 아기가 세상을 배우는 방식을 생각해보자. 아무도 "저건 의자야"라고 매번 알려주지 않지만,
> 아기는 수만 번 보고 만지면서 세상의 구조를 스스로 파악한다.
> 이것이 **자기지도 사전학습**이다.

지도 사전학습(supervised pre-training)의 한계:

1. **라벨링 비용**: ImageNet 1400만 장에 라벨을 다는 데 엄청난 인력과 비용이 든다
2. **라벨 편향**: 사람이 정한 1000개 카테고리가 모든 시각 지식을 담지 못한다
3. **확장성**: 인터넷에는 라벨 없는 이미지가 수십억 장 있지만 활용하지 못한다

자기지도 사전학습은 라벨 없이도 데이터 자체에서 학습 신호를 만들어낸다. 이에 대해서는 [2장](#2-자기지도학습-self-supervised-learning)에서 자세히 다룬다.

---

### 1.4 왜 전이학습이 효과적인가?

#### 세 가지 핵심 이유

**이유 1: 저수준 특징의 보편성**

CNN 앞쪽 층이 학습하는 특징(엣지, 텍스처, 색상 패턴)은 거의 모든 시각 과업에서 동일하게 유용하다. 강아지를 인식하든, X-ray를 분석하든, "선"과 "면"이라는 기본 요소는 같다.

**이유 2: 데이터 효율성**

처음부터 학습하면 수백만 장이 필요한 것을, 전이학습은 수백~수천 장으로 가능하게 한다. 이미 학습된 가중치가 좋은 **출발점**이 되기 때문이다.

**이유 3: 정규화 효과**

사전학습된 가중치는 "자연 이미지의 통계적 규칙성"을 반영하고 있다. 이것이 일종의 **정규화(regularization)** 역할을 하여 과적합을 방지한다.

### 1.5 Fine-tuning vs Feature Extraction

전이학습을 적용하는 두 가지 전략이 있다.

#### Feature Extraction (특징 추출기로 사용)

```
사전학습 모델의 Conv층들 → 가중치 고정 (학습 안 함) → 새 FC층만 학습
```

| 항목 | 설명 |
|------|------|
| 비유 | 이미 완성된 망원경으로 다른 별을 관측하는 것. 망원경은 그대로, 관측 대상만 바꿈 |
| 언제 사용? | 새 데이터가 매우 적을 때 (수십~수백 장) |
| 장점 | 빠르고, 과적합 위험이 낮음 |
| 단점 | 원래 과업과 매우 다른 도메인에서는 성능 한계 |

#### Fine-tuning (미세조정)

```
사전학습 모델 전체 → 작은 학습률로 전체 가중치 업데이트 → 새 과업에 맞게 조정
```

| 항목 | 설명 |
|------|------|
| 비유 | 기존 망원경의 렌즈를 살짝 조정해서 더 잘 보이게 만드는 것 |
| 언제 사용? | 새 데이터가 어느 정도 있을 때 (수천 장 이상) |
| 장점 | 새 도메인에 더 잘 적응 |
| 단점 | 학습률이 너무 크면 사전학습 지식이 파괴됨 (catastrophic forgetting) |

#### 실전 가이드: 어떤 전략을 선택할까?

```
                    새 데이터가 많다
                    ┌───────────────────────┐
                    │                       │
새 도메인이 ←───── Feature Extraction ─────→ Fine-tuning 전체
원래와 비슷하다     (뒷부분 층만 학습)         (전체 층 학습,
                                              작은 학습률)
                    │                       │
                    │                       │
새 도메인이 ←───── Feature Extraction ─────→ Fine-tuning 뒷부분만
원래와 다르다       (Conv 출력을 새 모델       (앞쪽은 고정,
                    입력으로 사용)              뒤쪽만 학습)
                    └───────────────────────┘
                    새 데이터가 적다
```

#### Adapter: 제3의 전략

최근에는 **Adapter**라는 방법도 널리 사용된다. 사전학습 모델의 가중치는 완전히 고정하고, **아주 작은 추가 모듈**만 삽입하여 학습한다.

```
기존: 입력 → [사전학습 층] → 출력
                    ↓
Adapter: 입력 → [사전학습 층 (고정)] → [작은 Adapter 모듈 (학습)] → 출력
```

장점: 모델 하나로 여러 과업에 대응 가능. 각 과업마다 Adapter만 교체하면 된다.

<details>
<summary>풀이 보기</summary>

## 2. 자기지도학습 (Self-Supervised Learning)

### 2.1 왜 자기지도학습이 필요한가?

#### 일상적 비유

> Yann LeCun(딥러닝의 거장)은 이렇게 비유했다:
>
> - **자기지도학습** = 케이크 본체 (가장 큰 부분)
> - **지도학습** = 아이싱 (케이크 위의 크림)
> - **강화학습** = 체리 (위에 올리는 장식)
>
> 인간의 뇌에는 약 100조(10^14)개의 신경 연결이 있고, 수명은 약 10억(10^9)초이다.
> 이 연결을 모두 채우려면 초당 10만(10^5)비트의 정보가 필요하다.
> 이 정보는 누군가가 알려주는 "정답"에서 오는 것이 아니라,
> **세상을 관찰하면서 스스로 파악**하는 것이다.

핵심 문제: 인터넷에는 라벨 없는 데이터가 수십억 개 있지만, 라벨이 달린 데이터는 극소수이다.

| 데이터 종류 | 양 | 비용 |
|------------|---|------|
| 라벨 없는 이미지 (인터넷) | 수십억 장 | 거의 무료 |
| 라벨 있는 이미지 (ImageNet) | 1400만 장 | 수백만 달러, 수년 소요 |

자기지도학습은 이 **라벨 없는 거대한 데이터**에서 스스로 학습 신호를 만들어, **범용적인 표현(representation)**을 학습하는 방법이다.

---

### 2.2 라벨 없는 데이터 활용: 세 가지 접근법

#### 접근법 1: 대입 과제 (Imputation Tasks)

> **비유**: 시험에서 빈칸 채우기 문제. 문장의 일부를 가리고 맞추려면 전체 맥락을 이해해야 한다.

이미지의 일부를 가리고 복원하기 (MAE), 문장의 단어를 가리고 맞추기 (BERT).

#### 접근법 2: 프록시 과제 (Pretext Tasks)

> **비유**: 그림 퍼즐 맞추기. 조각의 위치를 맞추려면 그림 전체를 이해해야 한다.

이미지를 회전시키고 "몇 도 돌렸는지" 맞추기, 이미지 조각의 상대 위치 맞추기.

#### 접근법 3: 대조 학습 (Contrastive Learning) -- 가장 중요!

> **비유**: 짝꿍 찾기 게임. 같은 사진의 두 변형은 "같다!", 다른 사진은 "다르다!"

이것이 이 장의 핵심이다. 아래에서 자세히 다룬다.

---

### 2.3 Contrastive Learning (대조 학습) 기본 개념

#### 일상적 비유

> 학교에서 얼굴 인식 출석 시스템을 만든다고 하자.
>
> 같은 학생의 사진 두 장 (하나는 안경 쓴 것, 하나는 모자 쓴 것)을 보여주고
> "이 둘은 같은 사람이야!"라고 가르친다.
> 다른 학생의 사진은 "이건 다른 사람이야!"라고 가르친다.
>
> 이렇게 하면, 모델은 안경이나 모자 같은 **표면적 변화에 흔들리지 않고**,
> 얼굴의 **본질적 특징**을 파악하게 된다.

#### 핵심 아이디어 (3줄 요약)

1. 같은 데이터의 다른 변형(augmentation)은 **표현 공간에서 가까워야** 한다
2. 다른 데이터는 **표현 공간에서 멀어야** 한다
3. 이 과정에서 모델은 데이터의 **본질적 특징**만 추출하는 법을 배운다

#### 딥러닝에서의 의미

대조 학습으로 학습한 인코더는 **범용 특징 추출기**가 된다. 이 인코더 위에 작은 분류 층을 붙이면, 적은 라벨 데이터만으로도 다양한 과업(분류, 검출, 분할 등)을 수행할 수 있다.

---

### 2.4 BarlowTwins: 교차상관 행렬을 이용한 자기지도학습

#### 일상적 비유

> 팀 프로젝트를 상상해보자. 좋은 팀의 조건은 두 가지다:
>
> 1. **팀원들이 같은 결론에 도달해야 한다** (일관성)
> 2. **각 팀원이 서로 다른 역할을 맡아야 한다** (중복 제거)
>
> 5명이 모두 같은 일만 하면 비효율적이다.
> 5명이 각자 다른 역할을 하면서, 최종 결론은 같아야 최고의 팀이다.
>
> BarlowTwins는 이 원리를 표현 학습에 적용한 것이다.

#### 단계별 설명

BarlowTwins의 전체 과정을 하나씩 따라가 보자.

**[Step 1] 같은 이미지에서 두 개의 뷰(view) 생성**

원본 이미지 하나에 서로 다른 데이터 증강(augmentation)을 적용한다.

$$x = t(x_0), \quad x' = t'(x_0)$$

여기서:
- $x_0$: 원본 이미지
- $t, t'$: 서로 다른 랜덤 증강 (자르기, 색상 변경, 흐리게 하기 등)
- $x, x'$: 같은 이미지의 두 가지 변형

> **비유**: 같은 강아지 사진을 하나는 밝게, 하나는 잘라서 만든다.
> 둘 다 "같은 강아지"라는 본질은 변하지 않는다.

**[Step 2] 인코더로 표현(representation) 추출**

각 뷰를 신경망(인코더)에 통과시켜 특징 벡터를 얻는다.

$$r = r(x), \quad r' = r(x')$$

여기서:
- $r(\cdot)$: 신경망 인코더 (예: ResNet)
- $r, r'$: 각각 D차원 벡터 (표현)

> **비유**: 두 장의 사진을 각각 "설명문"으로 요약한 것. 같은 강아지니까 비슷한 설명이 나와야 한다.

**[Step 3] 정규화 (Normalize)**

배치 내에서 각 차원의 평균을 0, 표준편차를 1로 맞춘다.

$$\bar{r} = \frac{r - \mu(r)}{\sigma(r)}$$

> **무슨 뜻인가?**
>
> $r$이 5차원 벡터 [100, 0.5, -30, 7, 200]이라고 하자.
> 각 차원의 숫자 크기가 제각각이면 비교가 어렵다.
> 정규화하면 모든 차원이 비슷한 범위(-1 ~ 1 정도)로 맞춰진다.
>
> **비유**: 시험 점수를 과목마다 다른 만점(수학 100점, 체육 50점)으로 비교하면 불공정하다.
> 표준점수(z-score)로 변환하면 공정하게 비교할 수 있다. 정규화가 바로 이것이다.

$\mu(r)$는 배치 내 모든 샘플에서 $r$의 평균, $\sigma(r)$는 표준편차이다.

**[Step 4] 교차상관 행렬 (Cross-Correlation Matrix) 계산**

정규화된 두 표현의 교차상관 행렬을 계산한다.

$$C = \frac{\bar{r}^\top \bar{r}'}{N} \in \mathbb{R}^{D \times D}$$

여기서:
- $N$: 배치 크기 (한 번에 처리하는 이미지 수)
- $D$: 표현의 차원 수
- $C$: D x D 크기의 행렬

> **이 행렬이 무엇을 의미하는가?**
>
> $C_{ij}$는 "첫 번째 뷰의 i번째 특징"과 "두 번째 뷰의 j번째 특징"이 얼마나 상관있는지를 나타낸다.
>
> - $C_{ii}$ (대각선 원소): 같은 번호의 특징 간 상관관계. **1에 가까울수록 좋다.**
>   → "두 뷰에서 같은 특징이 일관되게 추출된다"는 뜻
>
> - $C_{ij}$ ($i \neq j$, 비대각선 원소): 다른 번호의 특징 간 상관관계. **0에 가까울수록 좋다.**
>   → "서로 다른 특징이 중복 없이 독립적이다"는 뜻
>
> **비유**: 5명의 팀원이 각자 보고서를 쓴다. 같은 번호의 항목(예: 팀원1의 "시장분석" vs 팀원2의 "시장분석")은 같은 결론이어야 하고(대각선 = 1), 다른 번호의 항목(예: 팀원1의 "시장분석" vs 팀원2의 "기술분석")은 겹치지 않아야 한다(비대각선 = 0).

**[Step 5] 손실 함수 (Loss Function)**

$$\mathcal{L} = \underbrace{\sum_i (1 - C_{ii})^2}_{\text{invariance term (불변성 항)}} + \lambda \underbrace{\sum_i \sum_{j \neq i} C_{ij}^2}_{\text{redundancy reduction term (중복 제거 항)}}$$

이 수식을 한 조각씩 뜯어보자.

**첫 번째 항: 불변성 (Invariance)**

$$\sum_i (1 - C_{ii})^2$$

- $C_{ii}$는 같은 번호 특징의 상관관계이다
- $(1 - C_{ii})^2$: $C_{ii}$가 1과 다를수록 큰 값 (페널티)
- 이 항을 최소화하면 모든 대각선 원소가 1에 가까워진다
- 의미: **"같은 이미지의 두 뷰는 같은 표현을 만들어라!"**

> **비유**: 수학 시험을 두 번 봤는데, 같은 문제에 대해 다른 답을 쓰면 감점. 일관성이 중요하다.

**두 번째 항: 중복 제거 (Redundancy Reduction)**

$$\lambda \sum_i \sum_{j \neq i} C_{ij}^2$$

- $C_{ij}$ ($i \neq j$)는 서로 다른 특징 간의 상관관계이다
- $C_{ij}^2$: 0이 아닌 상관관계가 있을수록 큰 값 (페널티)
- 이 항을 최소화하면 모든 비대각선 원소가 0에 가까워진다
- 의미: **"각 특징 차원은 서로 다른 독립적인 정보를 담아라!"**
- $\lambda$: 두 항의 중요도를 조절하는 가중치

> **비유**: 팀원 5명이 모두 "시장분석"만 하면 비효율적이다. 한 명은 시장분석, 한 명은 기술분석, 한 명은 재무분석... 각자 다른 역할을 맡아야 한다.

**특수한 경우: $\lambda = 1$일 때**

$$\mathcal{L} = \|C - I\|_F^2$$

> **이것은 무엇인가?**
>
> $I$는 단위행렬(대각선이 1, 나머지가 0인 행렬)이다.
> $\|C - I\|_F^2$는 **프로베니우스 노름의 제곱**이다.
>
> 프로베니우스 노름이란? 행렬의 모든 원소를 제곱해서 더한 것의 제곱근이다.
> 즉, $\|C - I\|_F^2 = \sum_i \sum_j (C_{ij} - I_{ij})^2$
>
> 대각선에서는 $(C_{ii} - 1)^2$, 비대각선에서는 $(C_{ij} - 0)^2 = C_{ij}^2$이 된다.
> 이것은 위의 두 항을 하나로 합친 것과 정확히 같다!
>
> **한 줄 요약**: 교차상관 행렬 $C$를 단위행렬 $I$에 최대한 가깝게 만들어라.

#### 왜 BarlowTwins가 특별한가?

SimCLR 같은 다른 대조 학습 방법은 **부정 샘플(negative sample)**이 필요하다. 즉, "이 두 이미지는 다르다"라는 정보도 주어야 한다. 이를 위해 큰 배치 크기가 필요하고, 계산 비용이 높다.

BarlowTwins는 **부정 샘플이 필요 없다!** 교차상관 행렬의 비대각선 원소를 0으로 만드는 것 자체가 표현의 붕괴(collapse)를 방지하기 때문이다.

> **표현 붕괴란?** 모든 입력에 대해 같은 표현을 출력하는 것. 예를 들어 모든 이미지에 대해
> [1, 1, 1, 1, 1]을 출력하면 불변성 항은 완벽하지만, 완전히 쓸모없는 표현이다.
> 중복 제거 항이 이를 방지한다.

### 2.5 연습문제

**문제 1**: BarlowTwins의 손실 함수에서 invariance term만 있고 redundancy reduction term이 없다면 어떤 문제가 발생하는가?

<details>
<summary>풀이 보기</summary>

**답**: **표현 붕괴(representation collapse)**가 발생한다.

모든 입력에 대해 동일한 상수 벡터를 출력하면, 두 뷰의 표현이 항상 같으므로 invariance term은 0이 된다. 이렇게 되면 손실이 최소가 되지만, 표현에는 아무 의미 있는 정보가 담기지 않는다.

Redundancy reduction term은 각 차원이 서로 다른 정보를 담도록 강제함으로써, 이런 사소한 해(trivial solution)를 방지한다.

</details>

**문제 2**: 교차상관 행렬 $C$가 다음과 같을 때, 각각의 상태를 해석하시오.

(a) $C = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$ (단위행렬)

(b) $C = \begin{pmatrix} 0.3 & 0.8 \\ 0.7 & 0.4 \end{pmatrix}$

(c) $C = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix}$

<details>
<summary>풀이 보기</summary>

**(a)** 이상적인 상태. 대각선이 1이므로 두 뷰의 같은 차원 특징이 완벽히 일치하고, 비대각선이 0이므로 서로 다른 차원이 독립적이다. 손실 = 0.

**(b)** 나쁜 상태. 대각선이 1이 아니므로 두 뷰의 표현이 일관되지 않고(불변성 부족), 비대각선이 0이 아니므로 차원 간 중복 정보가 있다(중복 제거 부족).

**(c)** 매우 나쁜 상태 (붕괴). 모든 원소가 1이면, 모든 차원이 완전히 같은 정보를 담고 있다. 즉, D차원 벡터인데 사실상 1차원 정보만 담는 것과 같다. Redundancy reduction term이 이를 방지한다.

</details>

**문제 3**: BarlowTwins에서 왜 정규화(normalize)가 필요한가?

<details>
<summary>풀이 보기</summary>

**답**: 정규화 없이 교차상관을 계산하면, 표현의 크기(scale)에 따라 상관관계 값이 왜곡된다.

예를 들어, 한 차원의 값이 [1000, 2000, 3000]이고 다른 차원이 [0.1, 0.2, 0.3]이면, 큰 값을 가진 차원이 교차상관 행렬을 지배하게 된다.

정규화하면 모든 차원이 평균 0, 표준편차 1이 되어 공정한 비교가 가능해진다. 이는 통계학에서 **피어슨 상관계수**를 계산하는 것과 같은 원리이다.

</details>

## 3. 생성모델 개요 (Generative Models)

### 3.1 판별 모델 vs 생성 모델

#### 일상적 비유

> **판별 모델**: 미술 감정사. 그림을 보고 "이건 모네 작품이다", "이건 피카소 작품이다"라고
> **구별**할 수 있지만, 직접 그림을 그리지는 못한다.
>
> **생성 모델**: 화가. 모네의 작품을 많이 보고 나면, 모네 **스타일의 새로운 그림을 직접 그릴** 수 있다.

수학적으로:

| | 판별 모델 | 생성 모델 |
|--|-----------|-----------|
| 학습 대상 | $p(y \mid x)$ (입력이 주어졌을 때 라벨의 확률) | $p(x)$ 또는 $p(x, y)$ (데이터 자체의 확률 분포) |
| 할 수 있는 것 | 분류, 예측 | 새로운 데이터 생성, 분류도 가능 |
| 예시 | CNN 분류기, SVM | VAE, GAN, Diffusion Model |

#### 딥러닝에서의 의미

생성 모델은 데이터의 **확률 분포 전체**를 학습한다. 이것이 왜 중요한가?

1. **새로운 데이터 생성**: 학습한 분포에서 샘플링하면 현실적인 새 데이터가 나온다
2. **데이터 이해**: 분포를 아는 것은 데이터의 구조를 깊이 이해하는 것이다
3. **비지도 학습**: 라벨 없이도 데이터의 패턴을 학습할 수 있다

---

### 3.2 생성 모델의 종류 한눈에 보기

```
생성 모델
├── VAE (Variational Autoencoder)
│   → 데이터를 압축(인코딩)했다가 복원(디코딩)
│
├── GAN (Generative Adversarial Network)
│   → 위조범(생성자) vs 경찰(판별자)의 대결
│
├── Normalizing Flow
│   → 단순한 분포를 가역 변환으로 복잡한 분포로 변환
│
├── EBM (Energy-Based Model)
│   → 에너지가 낮은 곳 = 확률 높은 곳
│
├── Auto-Regressive Model
│   → 한 토큰씩 순서대로 생성 (GPT 방식)
│
└── Diffusion Model
    → 노이즈를 점진적으로 추가/제거
```

이 가이드에서는 **VAE**와 **EBM**을 집중적으로 다룬다.

### 3.3 공통 학습 목표: 최대우도추정 (MLE)

모든 생성 모델의 공통 목표는 같다:

$$\max_\theta \mathbb{E}_{x \sim p_S}[\log p_\theta(x)]$$

> **이 수식이 말하는 것 (비유)**:
>
> 내가 만든 모델($p_\theta$)이 실제 데이터($x$)를 "당연하다"고 생각할 확률을 최대화하라.
>
> 예를 들어, 강아지 사진을 많이 보여주면, 모델이 "강아지 사진이 나올 확률은 높고,
> 의미 없는 노이즈 이미지가 나올 확률은 낮다"고 판단하도록 학습한다.

수식을 한 조각씩 뜯어보면:

| 기호 | 의미 | 비유 |
|------|------|------|
| $\theta$ | 모델의 가중치 (파라미터) | 화가의 기술 수준 |
| $p_\theta(x)$ | 모델이 데이터 $x$에 부여하는 확률 | "이 그림이 나올 가능성이 얼마나 되는가?" |
| $p_S$ | 실제 데이터의 분포 | 실제 세상에 있는 그림들의 모음 |
| $\mathbb{E}[\cdot]$ | 기대값 (평균) | 모든 데이터에 대해 평균적으로 |
| $\log$ | 로그 함수 | 곱셈을 덧셈으로 바꿔 계산 편의 제공 |
| $\max_\theta$ | $\theta$를 조정해서 최대화 | 화가의 기술을 발전시켜 최고의 결과를 만들기 |

## 4. VAE (Variational Autoencoder)

### 4.1 VAE의 핵심 아이디어

#### 일상적 비유

> VAE는 **우편 시스템**과 비슷하다.
>
> **인코더 (보내는 쪽)**: 큰 택배 상자(이미지)를 작은 우편함(잠재 공간)에 넣을 수 있도록 압축한다.
> 하지만 완벽히 같은 크기로 압축하는 것이 아니라, "대략 이 범위에 있다"고 표현한다.
> (확률적 인코딩)
>
> **디코더 (받는 쪽)**: 작은 우편함에서 정보를 꺼내 원래의 택배 상자를 복원한다.
>
> **핵심**: 우편함(잠재 공간)의 배치가 깔끔하면(정규분포를 따르면),
> 아무 위치에서나 정보를 꺼내도 그럴듯한 택배(이미지)가 나온다.
> → 이것이 바로 **새로운 이미지 생성**이다!

---

### 4.2 Forward Process: 데이터 x에서 잠재 변수 z로

#### 단계별 설명

**목표**: 입력 이미지 $x$를 저차원 잠재 변수 $z$로 인코딩한다.

**Step 1**: 인코더 신경망이 입력 $x$에서 **두 가지 값**을 출력한다.

$$\mu_\phi(x): \text{잠재 변수의 평균}$$
$$\sigma_\phi(x): \text{잠재 변수의 표준편차 (불확실성)}$$

> **왜 하나가 아니라 두 개를 출력하는가?**
>
> 비유: "서울 어딘가에 있어"보다 "서울역 근처(평균)에 있는데, 반경 500m 이내(표준편차)야"가
> 더 정확한 위치 정보이다. 평균은 **가장 가능성 높은 위치**, 표준편차는 **불확실성의 정도**이다.

**Step 2**: 이 두 값을 사용해 잠재 변수 $z$를 **샘플링**한다.

$$z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I)$$

이 수식을 한 조각씩 분해하면:

| 부분 | 의미 | 비유 |
|------|------|------|
| $\varepsilon \sim \mathcal{N}(0, I)$ | 표준정규분포에서 랜덤 숫자를 뽑음 | 주사위를 던짐 |
| $\sigma_\phi(x) \odot \varepsilon$ | 랜덤 숫자에 불확실성 크기를 곱함 | 주사위 결과에 "흔들림 정도"를 반영 |
| $\mu_\phi(x) + \ldots$ | 평균 위치에 흔들림을 더함 | 중심점 근처 어딘가에 착지 |
| $\odot$ | 원소별 곱셈 | 각 차원마다 독립적으로 흔들림 적용 |

> **Reparameterization Trick이란?**
>
> 위의 $z = \mu + \sigma \odot \varepsilon$ 공식이 바로 reparameterization trick이다.
>
> 왜 필요한가? 신경망 학습(역전파)은 "미분 가능한 연산"으로만 이루어져야 한다.
> "확률분포에서 샘플링"은 랜덤이라 미분할 수 없다.
>
> 해결: 랜덤성을 $\varepsilon$이라는 외부 변수로 분리하면,
> $z$는 $\mu$와 $\sigma$의 **결정적(deterministic) 함수**가 되어 미분 가능해진다!
>
> **비유**: "주사위를 던져서 나온 숫자"는 제어할 수 없지만,
> "미리 던져둔 주사위 결과에 내가 원하는 연산을 적용"하면 제어 가능하다.

---

### 4.3 Reverse Process: 잠재 변수 z에서 데이터 x로

**목표**: 잠재 변수 $z$에서 원본 데이터 $x$를 복원한다.

$$\hat{x} = \text{Decoder}_\theta(z)$$

디코더 신경망이 $z$를 입력받아 원본과 비슷한 이미지를 출력한다.

학습 목표: $p_\theta(x \mid z)$를 최대화, 즉 "잠재 변수 $z$가 주어졌을 때 원본 $x$가 나올 확률"을 최대화한다.

> **비유**: 우체부가 우편번호(z)만 보고 원래 택배(x)를 정확히 재현하는 것.
> 우편번호 체계가 좋을수록(좋은 잠재 공간) 재현이 정확해진다.

---

### 4.4 MLE와 ELBO: VAE의 학습 목표

#### 이상적인 목표: MLE

우리가 정말 원하는 것:

$$\max_\theta \mathbb{E}[\log p_\theta(x)]$$

"모델이 실제 데이터 $x$에 높은 확률을 부여하도록 학습하라."

#### 문제: 직접 계산이 불가능하다

$p_\theta(x)$를 계산하려면 모든 가능한 $z$에 대해 적분해야 한다:

$$p_\theta(x) = \int p_\theta(x \mid z) \cdot p(z) \, dz$$

> **비유**: "서울에서 부산까지 갈 수 있는 모든 경로의 확률을 다 더하라"
> → 경로가 무한히 많으므로 불가능!

#### 해결: ELBO (Evidence Lower Bound)

직접 계산 대신, **하한(lower bound)**을 최대화한다.

$$\log p_\theta(x) \geq \text{ELBO}(x; \theta, \phi)$$

> **비유**: 시험 점수의 정확한 값은 모르지만, "최소한 80점 이상"이라는 것은 알 수 있다.
> 이 "최소 80점"을 최대한 높이면, 실제 점수도 높아진다.

#### ELBO를 풀어쓰면:

$$\text{ELBO}(x; \theta, \phi) = \underbrace{\mathbb{E}_{z \sim q_\phi(\cdot|x)}[\log p_\theta(x|z)]}_{\text{복원 항 (Reconstruction)}} - \underbrace{\text{KL}(q_\phi(z|x) \| p(z))}_{\text{정규화 항 (Consistency)}}$$

각 항의 의미:

**복원 항: $\mathbb{E}_{z \sim q_\phi(\cdot|x)}[\log p_\theta(x|z)]$**

- "인코더가 만든 $z$로부터 디코더가 원본 $x$를 잘 복원하는가?"
- 이 값이 클수록 복원이 정확하다
- 실전에서는 $-\|x - \hat{x}\|^2$ (원본과 복원의 차이)로 근사

> **비유**: 압축-해제 후 원본과 얼마나 비슷한가? 손실 압축의 품질.

**정규화 항: $\text{KL}(q_\phi(z|x) \| p(z))$**

- "인코더 출력의 분포 $q_\phi(z|x)$가 표준정규분포 $p(z) = \mathcal{N}(0, I)$과 얼마나 다른가?"
- 이 값이 작을수록 잠재 공간이 깔끔하게 정리된다
- KL divergence는 항상 0 이상이고, 두 분포가 같을 때 0이다

> **비유**: 우편번호 체계가 체계적인가? 1번 근처에 2번이 있고, 멀리 떨어진 곳에 3번이 있는 깔끔한 배치 vs 번호가 마구잡이인 혼란스러운 배치. 깔끔할수록 새로운 우편번호를 만들어도 의미 있는 택배가 나온다.

**최종 학습 목표 (-ELBO를 최소화):**

$$\min_{\theta, \phi} \underbrace{\mathbb{E}_{z \sim q_\phi(\cdot|x)}[-\log p_\theta(x|z)]}_{\text{복원 오차를 줄여라}} + \underbrace{\text{KL}(q_\phi(z|x) \| p(z))}_{\text{잠재 공간을 정규화하라}}$$

---

### 4.5 VAE vs Diffusion Model 간단 비교

| 항목 | VAE | Diffusion Model |
|------|-----|-----------------|
| Forward 과정 | $x \to z$ (인코더, **학습 대상**) | $x \to z_T$ (노이즈 추가, **고정**) |
| Reverse 과정 | $z \to x$ (디코더, **학습 대상**) | $z_T \to x$ (노이즈 제거, **학습 대상**) |
| 잠재 변수 | 한 번에 압축 | 점진적으로 단계별 변환 |
| 생성 품질 | 흐릿한 경향 | 매우 선명 |
| 생성 속도 | 빠름 (한 번에 생성) | 느림 (수백 스텝 필요) |
| 비유 | 택배 압축-해제 | 조각상 만들기 (돌을 한 겹씩 깎음) |

> **Diffusion Model 직관**: 깨끗한 이미지에 노이즈를 한 겹씩 추가하면 결국 완전한 잡음이 된다
> (forward). 이 과정을 거꾸로 학습하면, 잡음에서 시작해서 한 겹씩 노이즈를 제거하여
> 깨끗한 이미지를 만들 수 있다 (reverse). 즉, Diffusion Model은 **계층적 VAE**의 일종이다.

### 4.6 연습문제

**문제 1**: VAE에서 reparameterization trick이 왜 필요한지, "샘플링은 미분 불가능하다"는 관점에서 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**: 신경망 학습(역전파)에는 모든 연산이 미분 가능해야 한다. 그러나 "확률분포에서 샘플 뽑기"는 랜덤한 과정이므로 미분할 수 없다.

Reparameterization trick은 이 문제를 해결한다:
- 원래: $z \sim \mathcal{N}(\mu_\phi(x), \sigma_\phi(x)^2)$ → 랜덤 과정, 미분 불가
- 변환: $z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon$, $\varepsilon \sim \mathcal{N}(0, I)$

변환 후에 $z$는 $\mu$와 $\sigma$의 **결정적 함수**가 되고, 랜덤성은 외부 변수 $\varepsilon$으로 분리된다. $\varepsilon$은 $\phi$와 무관하므로, $\phi$에 대한 미분이 $\mu$와 $\sigma$를 통해 깔끔하게 전달된다.

</details>

**문제 2**: ELBO의 두 항(복원 항, 정규화 항)이 서로 **상충(trade-off)** 관계임을 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**:
- **복원 항**을 최대화하려면: 인코더가 입력의 세부 정보를 최대한 보존하는 $z$를 만들어야 한다. 이를 위해 $z$의 분포가 입력마다 매우 다르고 정교해져야 한다.
- **정규화 항(KL)**을 최소화하려면: 인코더 출력이 표준정규분포에 가까워야 한다. 이는 모든 입력에 대해 비슷한 분포를 출력하라는 것이다.

이 둘은 상충한다:
- 복원에 집중하면 → 잠재 공간이 불규칙해져 새로운 데이터 생성이 어려워진다
- 정규화에 집중하면 → 모든 입력이 비슷한 $z$로 인코딩되어 복원 품질이 떨어진다 (흐릿한 이미지)

최적의 VAE는 이 두 목표 사이의 균형점을 찾는다.

</details>

**문제 3**: VAE의 ELBO를 구성하는 두 항을 적고, 각각의 직관적 의미를 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**:

$$\text{ELBO} = \underbrace{\mathbb{E}_{z \sim q_\phi(\cdot|x)}[\log p_\theta(x|z)]}_{\text{복원 항}} - \underbrace{\text{KL}(q_\phi(z|x) \| p(z))}_{\text{정규화 항}}$$

- **복원 항**: "잠재 변수 $z$로부터 원본 $x$를 얼마나 잘 복원하는가?" → 크면 클수록 좋다. 실전에서는 원본과 복원 이미지의 MSE(평균제곱오차)로 측정.

- **정규화 항 (KL divergence)**: "인코더 출력 분포가 표준정규분포에 얼마나 가까운가?" → 작으면 작을수록 좋다. 잠재 공간이 깔끔하게 정리되어, 임의의 $z$를 넣어도 의미 있는 이미지가 생성된다.

ELBO를 최대화하면 (또는 -ELBO를 최소화하면) 두 목표의 균형을 찾는다.

</details>

## 5. Energy-Based Model (EBM)

### 5.1 EBM의 핵심 아이디어

#### 일상적 비유

> **에너지 지도**를 상상해보자.
>
> 산과 골짜기가 있는 지형도를 그린다.
> - **골짜기** (에너지가 낮은 곳) = 데이터가 자주 나타나는 곳 = 확률이 높은 곳
> - **산꼭대기** (에너지가 높은 곳) = 데이터가 거의 없는 곳 = 확률이 낮은 곳
>
> 물은 항상 높은 곳에서 낮은 곳으로 흐른다.
> 마찬가지로, 데이터는 에너지가 낮은 곳에 모인다.
>
> EBM의 목표: 실제 데이터가 모여 있는 곳에 골짜기를 만들고,
> 데이터가 없는 곳에 산을 만드는 **에너지 지형**을 학습하는 것이다.

---

### 5.2 에너지 함수와 확률 분포

#### 수식

$$p_\theta(x) = \frac{\exp(-E_\theta(x))}{Z_\theta}$$

이 수식을 한 조각씩 분해하면:

| 부분 | 의미 | 비유 |
|------|------|------|
| $E_\theta(x)$ | 에너지 함수. 데이터 $x$에 대한 에너지 값 | 지형도에서 $x$ 위치의 높이 |
| $\exp(-E_\theta(x))$ | 에너지가 낮으면 큰 값, 높으면 작은 값 | 골짜기일수록 물이 많이 고임 |
| $Z_\theta$ | 정규화 상수 (partition function) | 전체 물의 양으로 나눠서 비율(확률)로 만듦 |
| $p_\theta(x)$ | 데이터 $x$의 확률 | $x$ 위치에 물이 얼마나 고여 있는가의 비율 |

$$Z_\theta = \int \exp(-E_\theta(x)) \, dx$$

> **핵심 관계**: 에너지가 낮을수록 → $\exp(-E)$가 클수록 → 확률이 높다.
>
> 이것은 물리학의 **볼츠만 분포**와 같은 원리이다.
> 물리에서도 입자는 에너지가 낮은 상태에 있을 확률이 높다.

#### 에너지 함수의 구현

$E_\theta(x)$는 신경망으로 모델링한다:

```
입력 x (예: 이미지) → [신경망] → 스칼라 값 E(x) (에너지)
```

이 신경망의 가중치 $\theta$를 학습하여, 올바른 에너지 지형을 만드는 것이 목표이다.

---

### 5.3 EBM의 학습: 에너지 내리기 & 올리기

#### 학습 규칙

$$-\nabla_\theta \ell(\theta) = -\underbrace{\mathbb{E}_{x \sim p_D}[\nabla_\theta E_\theta(x)]}_{\text{실제 데이터의 에너지 기울기}} + \underbrace{\mathbb{E}_{x \sim p_M}[\nabla_\theta E_\theta(x)]}_{\text{모델 샘플의 에너지 기울기}}$$

여기서:
- $p_D$: 실제 데이터 분포 (학습 데이터에서 나온 샘플)
- $p_M$: 모델이 현재 생각하는 분포 (모델에서 생성한 샘플)
- $\nabla_\theta$: 가중치 $\theta$에 대한 기울기

#### 수식의 직관적 해석

이 수식은 두 가지를 동시에 한다:

**첫 번째 항: $-\mathbb{E}_{x \sim p_D}[\nabla_\theta E_\theta(x)]$**

- 실제 데이터 포인트의 에너지를 **낮추는** 방향으로 가중치를 업데이트
- "진짜 데이터가 있는 곳에 골짜기를 파라!"

**두 번째 항: $+\mathbb{E}_{x \sim p_M}[\nabla_\theta E_\theta(x)]$**

- 모델이 생성한 포인트의 에너지를 **높이는** 방향으로 가중치를 업데이트
- "모델이 잘못 생각하는 곳에 산을 세워라!"

> **비유: Push-Pull 동역학**
>
> 상상해보자. 지형도 위에 빨간 점(실제 데이터)과 파란 점(모델 생성 데이터)이 있다.
>
> - **Pull (당기기)**: 빨간 점이 있는 곳의 지형을 아래로 누른다 → 골짜기 생성
> - **Push (밀기)**: 파란 점이 있는 곳의 지형을 위로 밀어 올린다 → 산 생성
>
> 이 과정을 반복하면:
> 빨간 점(실제 데이터) 주변에만 깊은 골짜기가 형성되고,
> 나머지 공간은 높은 산이 된다.
> → 모델의 에너지 지형이 실제 데이터 분포를 정확히 반영하게 된다!

#### 유도 과정 (왜 이 수식이 나오는가?)

MLE 목표에서 출발한다:

$$\ell(\theta) = \mathbb{E}_{x \sim p_D}[\log p_\theta(x)]$$

$\log p_\theta(x) = -E_\theta(x) - \log Z_\theta$를 대입하면:

$$\nabla_\theta \ell(\theta) = -\mathbb{E}_{x \sim p_D}[\nabla_\theta E_\theta(x)] - \nabla_\theta \log Z_\theta$$

핵심: $\nabla_\theta \log Z_\theta$를 계산하면:

$$\nabla_\theta \log Z_\theta = \frac{1}{Z_\theta} \nabla_\theta \int \exp(-E_\theta(x)) dx = -\mathbb{E}_{x \sim p_\theta}[\nabla_\theta E_\theta(x)]$$

> **이 유도가 말하는 것**: 정규화 상수 $Z_\theta$의 기울기는 모델 분포에서의 에너지 기울기 기대값과 같다. 직접 $Z_\theta$를 계산할 필요 없이, 모델에서 샘플을 뽑아 근사할 수 있다!

따라서:

$$\nabla_\theta \ell(\theta) = -\mathbb{E}_{x \sim p_D}[\nabla_\theta E_\theta(x)] + \mathbb{E}_{x \sim p_\theta}[\nabla_\theta E_\theta(x)]$$

---

### 5.4 Contrastive Divergence: 실전 학습 방법

#### 문제: 모델에서 샘플링이 어렵다

위 학습 규칙의 두 번째 항 $\mathbb{E}_{x \sim p_\theta}[\nabla_\theta E_\theta(x)]$을 계산하려면 모델 분포 $p_\theta(x)$에서 샘플을 뽑아야 한다. 그런데 $p_\theta(x) = \frac{\exp(-E_\theta(x))}{Z_\theta}$에서 직접 샘플링하기는 어렵다 ($Z_\theta$를 모르기 때문).

#### 해결: Langevin MCMC

에너지 함수의 기울기를 따라 "언덕을 내려가면서" 샘플을 생성한다:

$$x_{t+1} = x_t + \lambda \nabla_x \log p_\theta(x_t) + \sigma \varepsilon_t, \quad \varepsilon_t \sim \mathcal{N}(0, I)$$

$\nabla_x \log p_\theta(x) = -\nabla_x E_\theta(x)$이므로:

$$x_{t+1} = x_t - \lambda \nabla_x E_\theta(x_t) + \sigma \varepsilon_t$$

> **비유**: 안개 낀 산에서 골짜기를 찾는 것.
>
> 1. 현재 위치에서 **경사를 느껴본다** ($-\nabla_x E$: 에너지가 낮아지는 방향)
> 2. 그 방향으로 **한 걸음 내려간다** ($\lambda$: 걸음 크기)
> 3. 약간의 **랜덤한 방향**으로도 움직인다 ($\sigma \varepsilon_t$: 탐색)
> 4. 이 과정을 반복하면 결국 골짜기(에너지가 낮은 곳)에 도착한다
>
> 랜덤 움직임이 있는 이유: 지역 최소점(작은 웅덩이)에 빠지지 않고 전역 최소점(가장 깊은 골짜기)을 찾기 위해서다.

#### Contrastive Divergence (CD)

실전에서는 위의 MCMC를 무한히 돌리지 않고, **k번만** 돌린 후 나온 샘플을 사용한다 (CD-k).

```
학습 1 스텝:
1. 학습 데이터에서 실제 데이터 x 가져오기
2. 랜덤 노이즈에서 시작하여 Langevin MCMC를 k번 돌려 모델 샘플 x' 얻기
3. 가중치 업데이트:
   θ ← θ - η × (∇E(x, θ)) + η × (∇E(x', θ))
   = "실제 데이터의 에너지 낮추기" + "모델 샘플의 에너지 높이기"
```

### 5.5 연습문제

**문제 1**: EBM에서 에너지가 낮은 것이 확률이 높은 것과 같다는 관계를 수식으로 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**: EBM의 확률 분포는 다음과 같다:

$$p_\theta(x) = \frac{\exp(-E_\theta(x))}{Z_\theta}$$

$\exp(-E)$는 $E$가 감소하면 증가하는 함수이다:
- $E = 0$ → $\exp(0) = 1$
- $E = 1$ → $\exp(-1) \approx 0.37$
- $E = 5$ → $\exp(-5) \approx 0.007$
- $E = -2$ → $\exp(2) \approx 7.39$

따라서 에너지가 낮을수록 $\exp(-E)$가 크고, 정규화 상수 $Z_\theta$로 나누면 확률도 높아진다.

</details>

**문제 2**: EBM 학습에서 "실제 데이터의 에너지를 낮추고, 모델 생성 데이터의 에너지를 높인다"는 것이 직관적으로 왜 올바른 학습 방향인지 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**: 모델의 목표는 실제 데이터 분포 $p_D(x)$를 정확히 근사하는 것이다.

- **실제 데이터의 에너지를 낮추면**: 실제로 존재하는 데이터에 높은 확률을 부여한다. 이는 "있어야 할 곳에 확률 질량을 배치"하는 것이다.

- **모델 생성 데이터의 에너지를 높이면**: 모델이 현재 높은 확률을 부여하고 있지만 실제로는 데이터가 없는 곳의 확률을 줄인다. 이는 "잘못 배치된 확률 질량을 제거"하는 것이다.

이 두 과정을 반복하면, 모델의 확률 분포가 점점 실제 데이터 분포에 가까워진다. 이는 마치 지형을 조각하여 "실제 데이터가 있는 곳에만 골짜기가 있는 정확한 에너지 지형"을 만드는 것과 같다.

</details>

**문제 3**: EBM에서 정규화 상수 $Z_\theta = \int \exp(-E_\theta(x)) dx$를 직접 계산할 수 없는 이유는 무엇이며, 이를 어떻게 우회하는가?

<details>
<summary>풀이 보기</summary>

**답**:

**직접 계산이 불가능한 이유**: $x$가 고차원(예: 256x256 이미지 = 약 20만 차원)이면, 모든 가능한 $x$에 대해 적분하는 것은 계산적으로 불가능하다. 차원이 늘어날수록 적분해야 할 공간이 기하급수적으로 커진다.

**우회 방법**: 학습 시 $Z_\theta$를 직접 계산하지 않아도 된다. 핵심 관찰:

$$\nabla_\theta \log Z_\theta = -\mathbb{E}_{x \sim p_\theta}[\nabla_\theta E_\theta(x)]$$

즉, $Z_\theta$의 기울기는 모델 분포에서 뽑은 샘플의 에너지 기울기 기대값으로 대체할 수 있다. 모델 분포에서의 샘플링은 Langevin MCMC로 근사한다. 이렇게 하면 $Z_\theta$ 자체를 계산하지 않고도 가중치를 업데이트할 수 있다.

</details>

**문제 4**: Langevin MCMC 업데이트 식에서 노이즈 항 $\sigma \varepsilon_t$의 역할을 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**: 노이즈 항은 두 가지 역할을 한다:

1. **탐색 (Exploration)**: 기울기만 따라 내려가면 가장 가까운 지역 최소점에 빠질 수 있다. 랜덤 노이즈가 있으면 지역 최소점에서 탈출하여 더 좋은 전역 최소점을 탐색할 수 있다.

2. **이론적 보장**: 노이즈 크기를 $\sigma = \sqrt{2\lambda}$로 설정하면, 충분한 스텝 후에 샘플이 목표 분포 $p_\theta(x)$에 정확히 수렴한다는 것이 수학적으로 보장된다. 노이즈 없이 기울기만 따르면 에너지의 최소점에만 도달하지, 분포 전체를 탐색하지는 못한다.

비유: 안개 낀 산에서 나침반(기울기)만 따르면 가장 가까운 웅덩이에 빠진다. 가끔 랜덤한 방향으로도 걸으면(노이즈), 더 깊은 골짜기를 발견할 기회가 생긴다.

</details>

## 6. 종합 연습문제

**문제 1**: 전이학습, 자기지도학습, 생성모델의 관계를 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**: 이 세 개념은 밀접하게 연결되어 있다:

1. **전이학습**은 "한 과업에서 배운 지식을 다른 과업에 활용"하는 전략이다.

2. **자기지도학습**은 전이학습의 **사전학습 방법** 중 하나이다. 기존에는 ImageNet의 지도 학습으로 사전학습했지만, 자기지도학습은 라벨 없는 데이터로 사전학습한다. 이렇게 학습한 인코더를 다양한 downstream 과업에 전이한다.

3. **생성모델(VAE 등)**도 넓은 의미에서 비지도/자기지도 사전학습에 활용될 수 있다. VAE의 인코더가 학습한 잠재 표현은 데이터의 의미 있는 특징을 담고 있으므로, downstream 과업에 전이 가능하다.

흐름: 자기지도학습/생성모델로 **사전학습** → 전이학습으로 새 과업에 **적용**

</details>

**문제 2**: BarlowTwins의 손실 함수와 SimCLR의 손실 함수를 비교하고, BarlowTwins가 negative 샘플 없이도 학습할 수 있는 이유를 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**:

**SimCLR**: N-pair loss (InfoNCE) 사용. 같은 이미지의 두 변형(positive pair)의 유사도를 높이고, 배치 내 다른 이미지(negative)와의 유사도를 낮춘다. Negative 샘플이 많을수록 성능이 좋으므로 큰 배치 크기가 필요하다.

**BarlowTwins**: 교차상관 행렬을 단위행렬에 가깝게 만든다. Negative 샘플을 명시적으로 사용하지 않는다.

**BarlowTwins가 negative 없이도 작동하는 이유**:

SimCLR에서 negative 샘플의 역할은 "표현 붕괴 방지"이다 (모든 입력에 같은 표현을 내면 안 됨). BarlowTwins에서는 **redundancy reduction term** ($\sum_{i \neq j} C_{ij}^2$)이 이 역할을 대신한다. 각 차원이 서로 다른 정보를 담도록 강제하면, 상수 벡터로의 붕괴가 자동으로 방지된다.

</details>

**문제 3**: VAE와 EBM의 학습 방식의 근본적 차이를 설명하시오.

<details>
<summary>풀이 보기</summary>

**답**:

**VAE**: ELBO(하한)를 최대화한다. $\log p(x)$를 직접 계산할 수 없으므로, 인코더-디코더 구조를 도입하여 계산 가능한 하한을 대신 최적화한다. 핵심은 "잠재 변수 $z$를 경유"하는 것이다.

**EBM**: 에너지 함수를 직접 정의하고, 정규화 상수 $Z_\theta$의 기울기를 MCMC 샘플링으로 근사한다. 핵심은 "실제 데이터의 에너지는 낮추고, 모델 샘플의 에너지는 높이는" push-pull 동역학이다.

| 비교 | VAE | EBM |
|------|-----|-----|
| 핵심 구조 | 인코더 + 디코더 | 에너지 함수 하나 |
| 학습 목표 | ELBO 최대화 | MLE (push-pull) |
| 생성 방법 | $z \sim \mathcal{N}(0,I) \to$ 디코더 통과 | Langevin MCMC로 에너지 지형 탐색 |
| 장점 | 빠른 생성, 잠재 공간 해석 가능 | 유연한 에너지 함수, 이론적 우아함 |
| 단점 | 흐릿한 생성 | 느린 샘플링, 학습 불안정 |

</details>

**문제 4**: 다음 상황에서 어떤 접근법이 가장 적절한지 고르고 이유를 설명하시오.

(a) 의료 영상 데이터 100장으로 폐렴 분류기를 만들고 싶다.
(b) 1억 장의 라벨 없는 인터넷 이미지로 범용 이미지 인코더를 만들고 싶다.
(c) 학습 데이터와 비슷한 스타일의 새로운 이미지를 생성하고 싶다.

<details>
<summary>풀이 보기</summary>

**(a) 전이학습 (Feature Extraction)**

이유: 100장은 매우 적으므로, ImageNet이나 자기지도학습으로 사전학습된 모델을 가져와서 Feature Extraction 방식으로 마지막 층만 학습하는 것이 최선이다. Fine-tuning도 가능하지만 과적합 위험이 높다.

**(b) 자기지도학습 (예: BarlowTwins, SimCLR)**

이유: 1억 장에 모두 라벨을 다는 것은 비현실적이다. 자기지도학습은 라벨 없이도 대규모 데이터에서 범용 표현을 학습할 수 있다. 학습된 인코더는 다양한 downstream 과업에 전이 가능하다.

**(c) 생성모델 (VAE, GAN, 또는 Diffusion Model)**

이유: 새로운 이미지를 "생성"해야 하므로 생성모델이 필요하다. 분류나 특징 추출이 목적이 아니라 데이터 분포 자체를 학습하여 샘플링해야 한다. 고품질 이미지가 필요하면 Diffusion Model, 빠른 생성이 필요하면 GAN, 잠재 공간 탐색이 필요하면 VAE를 선택한다.

</details>

## 7. 핵심 수식 요약표

시험 직전에 이 표만 보고 빠르게 복습하자.

### 전이학습

| 개념 | 핵심 | 비유 |
|------|------|------|
| Pre-training | 대규모 데이터로 범용 특징 학습 | 초등학교 교육 |
| Fine-tuning | 사전학습 모델 전체를 작은 학습률로 조정 | 렌즈 미세 조정 |
| Feature Extraction | 사전학습 층 고정, 마지막 층만 학습 | 완성된 망원경으로 다른 별 관측 |
| Adapter | 사전학습 모델에 작은 모듈만 추가 학습 | 어댑터 끼우기 |

### BarlowTwins

| 단계 | 수식 | 의미 |
|------|------|------|
| 뷰 생성 | $x = t(x_0),\ x' = t'(x_0)$ | 같은 이미지의 두 변형 |
| 인코딩 | $r = r(x),\ r' = r(x')$ | 특징 벡터 추출 |
| 정규화 | $\bar{r} = (r - \mu) / \sigma$ | 크기를 맞춤 |
| 교차상관 | $C = \bar{r}^\top \bar{r}' / N$ | 두 표현 간 상관 행렬 |
| 손실 | $\sum_i(1-C_{ii})^2 + \lambda\sum_{i \neq j}C_{ij}^2$ | 단위행렬에 가깝게 |
| $\lambda=1$ | $\|C - I\|_F^2$ | 동일한 의미의 간결한 표현 |

### VAE

| 단계 | 수식 | 의미 |
|------|------|------|
| 인코딩 | $z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon$ | 확률적 압축 |
| 디코딩 | $\hat{x} = \text{Dec}_\theta(z)$ | 복원 |
| ELBO | $\mathbb{E}[\log p_\theta(x\|z)] - \text{KL}(q_\phi(z\|x) \| p(z))$ | 복원 + 정규화 |

### EBM

| 단계 | 수식 | 의미 |
|------|------|------|
| 확률 분포 | $p_\theta(x) = \exp(-E_\theta(x)) / Z_\theta$ | 낮은 에너지 = 높은 확률 |
| 학습 규칙 | $-\mathbb{E}_{p_D}[\nabla E] + \mathbb{E}_{p_M}[\nabla E]$ | 실제↓ 모델↑ |
| 샘플링 | $x_{t+1} = x_t - \lambda \nabla_x E + \sigma\varepsilon_t$ | Langevin MCMC |
