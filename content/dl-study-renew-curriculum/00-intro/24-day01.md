# Day 1: 벡터와 행렬 — 처음부터 완벽하게

> **전제**: 수학은 중1 수준. 수업은 한 번도 안 들었음.
> **목표**: "벡터가 뭐고, 행렬이 뭐고, 왜 딥러닝에 필요한지" 확실히 이해
> **소요**: 약 3시간 (쉬면서)

---

## Part 0: 왜 이걸 배워야 하는가?

딥러닝(인공지능)은 결국 이런 거다:

```
데이터가 들어온다 → 뭔가 계산한다 → 답이 나온다
    (사진)        (신경망)        (고양이!)
```

이 "뭔가 계산한다"의 정체가 **행렬 곱셈**이다.
그리고 데이터를 표현하는 방법이 **벡터**다.

즉:
- **벡터** = 데이터를 숫자로 표현하는 방법
- **행렬** = 데이터를 변환하는 도구
- **행렬 × 벡터** = 입력 데이터를 출력으로 바꾸는 것 = **신경망의 한 층**

이게 오늘의 전부다. 하나씩 가자.

---

## Part 1: 숫자 하나 vs 숫자 여러 개

### 1.1 스칼라 (Scalar) — 숫자 하나

중학교에서 다루는 건 대부분 **숫자 하나**다.

```
온도: 25도
키: 170cm
시험 점수: 85점
```

이렇게 **하나의 값**으로 표현되는 것을 **스칼라(scalar)**라고 부른다.

> **스칼라** = 그냥 숫자 하나. 크기만 있고, 방향은 없다.

### 1.2 그런데 현실은 숫자 하나로 부족하다

네비게이션을 생각해보자. "집에서 학교까지"를 설명하려면:

```
❌ "500미터"  → 어느 방향으로 500미터? 알 수 없음
✅ "동쪽으로 300미터, 북쪽으로 400미터"  → 정확함!
```

숫자가 **두 개** 필요하다. 이것이 **벡터**의 시작이다.

---

## Part 2: 벡터 (Vector) — 숫자를 묶어놓은 것

### 2.1 벡터란?

> **벡터** = 숫자 여러 개를 **순서대로** 묶어놓은 것

```
v = [300, 400]     ← 2차원 벡터 (숫자 2개)
w = [1, 2, 3]      ← 3차원 벡터 (숫자 3개)
x = [170, 65, 20]  ← 3차원 벡터 (키, 몸무게, 나이)
```

벡터 안의 각 숫자를 **성분** 또는 **원소(element)**라고 부른다.

### 2.2 왜 "벡터"라고 따로 이름을 붙이나?

그냥 "숫자 묶음"이랑 뭐가 다르냐고?
벡터는 **더하기**와 **곱하기** 같은 연산이 정의되어 있다. 그래서 특별하다.

### 2.3 벡터의 표기법

수학/딥러닝에서 벡터는 **세로로** 쓰는 게 기본이다:

```
    [ 300 ]
v = [ 400 ]     ← 이것을 "컬럼 벡터(column vector)"라고 부른다
```

가로로 쓰면:

```
v = [300, 400]  ← 이것을 "로우 벡터(row vector)"라고 부른다
```

> **약속**: 딥러닝에서 벡터를 그냥 쓰면 **컬럼 벡터**(세로)가 기본이다.
> 가로로 쓰고 싶으면 vᵀ 라고 쓴다 (T는 "Transpose", 뒤집기).

왜 세로가 기본이냐? 나중에 행렬과 곱할 때 계산이 자연스럽기 때문이다.
지금은 "세로가 기본이구나" 정도만 기억하면 된다.

### 2.4 벡터의 차원

벡터에 숫자가 몇 개 들어있느냐 = **차원(dimension)**

```
[3, 4]           → 2차원 (2D) — 평면 위의 점/방향
[1, 2, 3]        → 3차원 (3D) — 3D 공간의 점/방향
[170, 65, 20, 85] → 4차원 — 사람의 (키, 몸무게, 나이, 점수)
```

> **핵심**: 딥러닝에서는 수백~수만 차원의 벡터를 다룬다!
> 이미지 28×28 = 784개 픽셀 → 784차원 벡터

### 2.5 현실 데이터를 벡터로 바꾸기

| 현실 데이터 | 벡터 표현 | 차원 |
|-----------|----------|------|
| 학생 (키, 몸무게) | [170, 65] | 2 |
| RGB 색상 (빨, 초, 파) | [255, 128, 0] | 3 |
| 흑백 사진 28×28 | [p₁, p₂, ..., p₇₈₄] | 784 |
| 단어 "고양이" | [0.2, -0.5, 0.8, ...] | 300 (Word2Vec) |

> **딥러닝의 첫 번째 원칙**: 모든 것을 숫자(벡터)로 바꾼다.

## Part 3: 벡터의 연산

### 3.1 벡터 덧셈 — 그냥 같은 위치끼리 더하기

```
[1, 2, 3] + [4, 5, 6] = [1+4, 2+5, 3+6] = [5, 7, 9]
```

직관: 동쪽 3m 이동 후 → 동쪽 2m 더 이동 = 동쪽 5m

> **규칙**: 같은 차원의 벡터끼리만 더할 수 있다.
> [1, 2] + [3, 4, 5] = ❌ 불가능!

### 3.2 스칼라 곱 — 벡터를 늘이거나 줄이기

숫자(스칼라) 하나를 벡터의 모든 성분에 곱한다:

```
3 × [1, 2, 3] = [3, 6, 9]     ← 3배로 늘림
0.5 × [4, 6] = [2, 3]         ← 절반으로 줄임
-1 × [1, 2] = [-1, -2]        ← 방향 반전
```

직관: "동쪽 3m"을 2배 하면 → "동쪽 6m" (같은 방향, 더 멀리)

### 3.3 내적 (Inner Product, Dot Product) ⭐ 매우 중요!

내적은 **두 벡터의 유사도**를 하나의 숫자로 알려준다.

#### 계산 방법: 같은 위치끼리 곱해서 전부 더하기

```
[1, 2, 3] · [4, 5, 6] = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

> **내적의 결과는 스칼라(숫자 하나)다!**

#### 왜 "유사도"인가?

두 벡터가 같은 방향이면 → 내적이 **큰 양수**
두 벡터가 수직이면 → 내적이 **0**
두 벡터가 반대 방향이면 → 내적이 **큰 음수**

```
같은 방향: [1, 0] · [1, 0] = 1    (최대)
수직:     [1, 0] · [0, 1] = 0    (무관)
반대:     [1, 0] · [-1, 0] = -1   (최소)
```

> **딥러닝 연결**: Attention 메커니즘에서 "이 단어가 저 단어와 얼마나 관련 있는가?"를
> 계산하는 핵심 연산이 바로 내적이다!

#### 내적의 표기

```
a · b       (점을 찍어서 "dot product")
aᵀb         (a를 가로로 뒤집어서 곱하기 — 나중에 행렬로 확장할 때 이렇게 씀)
⟨a, b⟩      (꺾쇠 괄호)
```

세 가지 다 같은 뜻이다. 딥러닝에서는 **aᵀb** 표기를 가장 많이 쓴다.

### 3.4 외적 (Outer Product) — 벡터를 행렬로!

외적은 내적의 반대 방향이다:

```
내적: 벡터 × 벡터 → 스칼라 (숫자 하나)
외적: 벡터 × 벡터 → 행렬 (숫자 격자)
```

계산: 첫 벡터를 세로로, 둘째 벡터를 가로로 놓고 모든 조합을 곱한다.

```
    [ 1 ]                    [ 1×4  1×5 ]   [ 4  5 ]
a = [ 2 ],  b = [4, 5]  →   [ 2×4  2×5 ] = [ 8  10]
    [ 3 ]                    [ 3×4  3×5 ]   [12  15]
```

표기: **abᵀ** (a를 세로로, b를 가로로)

> 외적의 결과는 **행렬**이다! (3×1 벡터와 1×2 벡터의 외적 → 3×2 행렬)

### 3.5 내적 vs 외적 정리

| | 내적 (Inner/Dot) | 외적 (Outer) |
|---|---|---|
| 표기 | aᵀb | abᵀ |
| 입력 | 같은 차원의 벡터 두 개 | 아무 차원 벡터 두 개 |
| 결과 | **스칼라** (숫자 하나) | **행렬** |
| 의미 | 유사도 측정 | 모든 조합의 곱 |
| 딥러닝 | Attention 점수 | 가중치 업데이트 |

## Part 4: 행렬 (Matrix) — 숫자를 격자로 배열한 것

### 4.1 행렬이란?

> **행렬** = 숫자를 직사각형(격자) 모양으로 배열한 것

```
A = [ 1  2  3 ]     ← 2행 3열 = "2×3 행렬"
    [ 4  5  6 ]
```

- **행(row)** = 가로 줄 (1행: [1,2,3], 2행: [4,5,6])
- **열(column)** = 세로 줄 (1열: [1,4], 2열: [2,5], 3열: [3,6])

#### 표기

```
A ∈ ℝᵐˣⁿ    (= "A는 m행 n열짜리 실수 행렬이다")

ℝ = 실수(Real number)
m×n = m행 n열
```

#### 특별한 행렬들

```
정방행렬 (Square Matrix): 행과 열이 같은 수
[ 1  2 ]
[ 3  4 ]     ← 2×2 정방행렬

단위행렬 (Identity Matrix): 대각선이 1, 나머지 0
[ 1  0 ]
[ 0  1 ]     ← 곱해도 원래 벡터가 그대로 나옴 (곱하기 1과 같은 역할)
```

### 4.2 행렬 곱셈 — 가장 중요한 연산

#### 방법: "행 × 열의 내적"

A(2×3) × B(3×2) = C(2×2) 를 계산해보자:

```
A = [ 1  2  3 ]     B = [ 7   8 ]
    [ 4  5  6 ]         [ 9  10 ]
                        [11  12 ]
```

결과 C의 각 칸 = A의 해당 행과 B의 해당 열의 **내적**

```
C₁₁ = A의 1행 · B의 1열 = [1,2,3] · [7,9,11] = 1×7 + 2×9 + 3×11 = 7+18+33 = 58
C₁₂ = A의 1행 · B의 2열 = [1,2,3] · [8,10,12] = 8+20+36 = 64
C₂₁ = A의 2행 · B의 1열 = [4,5,6] · [7,9,11] = 28+45+66 = 139
C₂₂ = A의 2행 · B의 2열 = [4,5,6] · [8,10,12] = 32+50+72 = 154

C = [ 58   64 ]
    [139  154 ]
```

#### 곱셈이 가능한 조건

> A(m×**k**) × B(**k**×n) = C(m×n)
>
> A의 **열 수**와 B의 **행 수**가 같아야 곱할 수 있다!

```
(2×3) × (3×2) = (2×2)  ✅   ← 3이 맞으니까 OK
(2×3) × (2×3) = ???     ❌   ← 3 ≠ 2 이므로 불가능!
```

#### 행렬 곱셈의 순서가 중요하다!

```
A × B ≠ B × A    (일반적으로!)
```

숫자의 곱셈은 3 × 5 = 5 × 3 이지만, **행렬 곱셈은 순서를 바꾸면 결과가 다르다!**
심지어 한쪽은 곱셈이 가능하고 다른 쪽은 불가능할 수도 있다.

### 4.3 행렬 × 벡터 — 신경망의 핵심 연산

```
A = [ 1  2 ]     x = [ 3 ]
    [ 3  4 ]         [ 5 ]

Ax = [ 1×3 + 2×5 ] = [ 13 ]
     [ 3×3 + 4×5 ]   [ 29 ]
```

> 2차원 벡터 [3, 5]가 행렬 A를 통과하면 → 새로운 2차원 벡터 [13, 29]가 된다.

이것이 **신경망의 한 층이 하는 일**이다!

```
입력 벡터 x → [행렬 곱셈: Wx] → [편향 더하기: +b] → [활성화 함수] → 출력 벡터 y
```

## Part 5: 행렬 = 선형변환 ⭐ 핵심 관점 전환

### 5.1 행렬은 "숫자표"가 아니라 "변환 기계"다

이것이 이 수업에서 가장 중요한 관점 전환이다.

행렬을 보면 보통 "숫자가 네모로 배열된 것"이라고 생각한다.
하지만 **진짜 의미**는:

> **행렬 = 벡터를 받아서 다른 벡터로 바꿔주는 기계(함수)**

```
입력 벡터 x → [ 행렬 A ] → 출력 벡터 Ax

[3, 5] → [ 1 2 ] → [13, 29]
          [ 3 4 ]
```

### 5.2 어떤 변환을 하는가?

2×2 행렬의 예:

```
회전 (45도):       [ 0.7  -0.7 ]
                   [ 0.7   0.7 ]

확대 (2배):        [ 2  0 ]
                   [ 0  2 ]

반사 (y축 대칭):    [-1  0 ]
                   [ 0  1 ]

기울이기 (shear):   [ 1  1 ]
                   [ 0  1 ]
```

각각의 행렬은 벡터(화살표)를 회전시키거나, 늘리거나, 뒤집거나, 기울인다.

### 5.3 "선형"변환이란?

"선형"이란 두 가지 규칙을 지키는 변환이다:

```
규칙 1: A(x + y) = Ax + Ay     (더한 걸 변환 = 변환한 걸 더하기)
규칙 2: A(cx) = c(Ax)          (늘린 걸 변환 = 변환한 걸 늘리기)
```

직관적으로: **직선은 직선으로, 원점은 원점으로** 유지하는 변환이다.
격자 무늬 종이를 잡아당기되 찢거나 구기지 않는 것과 같다.

### 5.4 왜 "행렬 = 변환"이라는 관점이 중요한가?

시험에서 나올 수 있는 핵심 질문이다:

> **"행렬을 데이터의 배열이 아니라 변환으로 봐야 하는 이유는?"**

**답**:
1. 신경망의 각 층은 **입력을 변환하는 행렬**이다.
2. 딥러닝 = 좋은 변환 행렬(가중치)을 찾는 과정이다.
3. 행렬을 "변환"으로 보면, "이 변환이 데이터에 무엇을 하는가?"라는
   질문을 할 수 있고, 고유벡터/고유값/SVD 같은 도구로 답할 수 있다.
4. 행렬을 "숫자 격자"로만 보면, 그냥 계산만 하게 되고
   "왜 이렇게 되는가?"를 이해할 수 없다.

### 5.5 행렬 곱셈의 계산 비용 — O(n³)

A(n×n) × B(n×n)을 계산하려면:
- 결과 행렬의 각 칸: 내적 1번 = 곱셈 n번 + 덧셈 (n-1)번
- 결과 행렬의 칸 수: n×n = n² 개

```
총 곱셈 횟수 ≈ n × n × n = n³
```

> **O(n³)** = "n이 커질수록 계산량이 n의 세제곱으로 늘어난다"

| n | n³ | 체감 |
|---|-----|------|
| 10 | 1,000 | 순식간 |
| 100 | 1,000,000 | 1초 |
| 1,000 | 1,000,000,000 | 느려짐 |
| 10,000 | 1조 | 매우 느림 |

**역행렬(inverse matrix)도 O(n³)**이라서 비싸다.
→ 딥러닝에서 역행렬을 직접 구하는 대신 다른 방법(gradient descent)을 쓰는 이유!

## Part 6: 요약 & 확인

### 오늘 배운 것 한 줄 정리

| 개념 | 한 줄 정의 | 딥러닝 연결 |
|------|----------|-----------|
| 스칼라 | 숫자 하나 | Loss 값 (손실 하나) |
| 벡터 | 숫자 여러 개의 순서 있는 묶음 | 데이터 = 벡터 |
| 내적 | 같은 위치끼리 곱해서 합 → 스칼라 | Attention 유사도 |
| 외적 | 모든 조합 곱 → 행렬 | 가중치 업데이트 |
| 행렬 | 숫자의 직사각형 배열 | 신경망의 가중치 |
| 행렬 곱셈 | 행×열의 내적 반복 | 신경망 forward pass |
| 행렬 = 변환 | 벡터를 다른 벡터로 바꾸는 기계 | 각 층 = 변환 |
| O(n³) | 행렬 곱의 계산 비용 | 왜 효율적 알고리즘이 필요한가 |

### 확인 질문 (직접 써보기)

답을 머리 속으로만 생각하지 말고, **실제로 글로 써보자**:

1. **"내적이 뭐고 왜 쓰는가?"**
   (힌트: 계산 방법 + 결과의 의미)

2. **"행렬을 데이터의 배열이 아니라 변환으로 봐야 하는 이유는?"**
   (힌트: 신경망과 연결)

3. **"[1,2,3] · [4,5,6] = ?"**
   (직접 계산)
