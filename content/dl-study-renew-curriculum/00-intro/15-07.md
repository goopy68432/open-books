## 1.1 Bias-Variance 직관적 이해

### 개념 설명

모든 예측 모델의 오차는 세 가지 성분으로 분해된다:

```
총 오차 = Bias² + Variance + 줄일 수 없는 노이즈(Irreducible Error)
```

| 구성 요소 | 의미 | 비유 |
|-----------|------|------|
| **Bias (편향)** | 모델이 체계적으로 정답에서 벗어나는 정도 | 항상 왼쪽으로 기울어진 저울 |
| **Variance (분산)** | 훈련 데이터가 바뀔 때 예측이 흔들리는 정도 | 바람에 흔들리는 화살 |
| **Irreducible Error** | 데이터 자체의 노이즈로, 어떤 모델도 제거 불가 | 과녁 자체가 미세하게 흔들림 |

### 직관적 그림: 모델 복잡도와 오차의 관계 (전통적 관점)

```
  오차
  │
  │ ╲                          ╱
  │   ╲  Total Error         ╱
  │     ╲                  ╱
  │       ╲______________╱   ← 최적점 (sweet spot)
  │         ╲          ╱
  │    Bias²  ╲      ╱  Variance
  │            ╲   ╱
  │             ╲╱
  │
  └──────────────────────────────── 모델 복잡도
     단순                      복잡
```

- **모델이 너무 단순하면**: Bias가 크다 (과소적합, Underfitting)
- **모델이 너무 복잡하면**: Variance가 크다 (과적합, Overfitting)
- **최적점**: Bias와 Variance의 합이 최소인 지점

### 핵심 포인트

딥러닝에서는 이 전통적 U자 곡선이 반드시 성립하지 않는다. 파라미터 수가 매우 많은 과매개변수화(overparameterized) 모델에서는 Bias와 Variance가 동시에 줄어드는 현상이 관찰된다. 이 "이상한" 현상은 중급 단계의 Double Descent에서 다룬다.

## 1.2 과적합(Overfitting)과 과소적합(Underfitting) 시각적 예시

### 개념 설명

```
  과소적합 (Underfitting)       적절한 적합 (Good Fit)       과적합 (Overfitting)
  High Bias, Low Variance      Low Bias, Low Variance       Low Bias, High Variance

       ·  ·                         ·  ·                         ·  ·
    ·        ·                   ·    ··  ·                   ·    ··  ·
  ─────────────  (직선)        ·  ╱╲  ╱╲  ·   (적절한 곡선)   ·╱╲╱╲╱╲╱╲·  (지나친 곡선)
  ·        ·                  · ╱  ╲╱  ╲ ·                  모든 점을 관통
    ·  ·                       ╱        ╲
```

| 상태 | 훈련 오차 | 검증 오차 | 진단 방법 |
|------|-----------|-----------|-----------|
| 과소적합 | 높음 | 높음 | 모델 용량 부족, 특성 부족 |
| 적절한 적합 | 낮음 | 낮음 (훈련과 비슷) | 이상적 상태 |
| 과적합 | 매우 낮음 | 높음 (훈련보다 훨씬 높음) | 훈련-검증 오차 간 큰 격차 |

### 학습 곡선(Learning Curve)으로 진단하기

```
  오차                              오차
  │                                 │
  │ ──── 검증 오차                  │  ──── 검증 오차
  │                                 │ ╱
  │ ──── 훈련 오차                  │╱          ← 큰 격차!
  │                                 │
  │  (둘 다 높고 수렴)              │  ──── 훈련 오차 (매우 낮음)
  │                                 │
  └──── Epoch ────→                 └──── Epoch ────→
    과소적합 (High Bias)              과적합 (High Variance)
```

## 1.3 기본 정규화 기법: L1과 L2

### L2 정규화 (Ridge / Weight Decay)

**핵심 아이디어**: 손실 함수에 가중치의 제곱합을 페널티로 추가한다.

```
L_total = L_original + λ · Σ(w_i²)
```

- **효과**: 모든 가중치를 균일하게 작게 만든다 (하지만 정확히 0으로 만들지는 않음)
- **비유**: "모든 팀원이 골고루 일하게 하되, 아무도 너무 많은 일을 맡지 않게 한다"
- **기하학적 의미**: 가중치 공간에서 원(구) 형태의 제약 조건

```
  w2
  │    ╭─╮
  │   ╱   ╲   ← L2 제약: ||w||² ≤ c (원 형태)
  │  │  ●  │      가중치가 이 원 안에 있도록 제한
  │   ╲   ╱
  │    ╰─╯
  └──────────── w1
```

### L1 정규화 (Lasso)

**핵심 아이디어**: 손실 함수에 가중치의 절댓값 합을 페널티로 추가한다.

```
L_total = L_original + λ · Σ|w_i|
```

- **효과**: 일부 가중치를 정확히 0으로 만든다 (희소성, Sparsity)
- **비유**: "불필요한 팀원은 아예 프로젝트에서 빼버린다"
- **기하학적 의미**: 가중치 공간에서 다이아몬드(마름모) 형태의 제약 조건

```
  w2
  │      ╱╲
  │    ╱    ╲   ← L1 제약: |w1|+|w2| ≤ c (다이아몬드)
  │  ╱   ●   ╲     꼭짓점에서 만나면 w1=0 또는 w2=0
  │    ╲    ╱
  │      ╲╱
  └──────────── w1
```

### L1 vs L2 비교표

| 특성 | L1 (Lasso) | L2 (Ridge) |
|------|-----------|-----------|
| 페널티 항 | Σ\|w_i\| | Σw_i² |
| 가중치 효과 | 일부를 0으로 (희소 해) | 모두 작게 (0에 가까이) |
| 특성 선택 | 자동으로 수행 | 수행하지 않음 |
| 제약 형태 | 다이아몬드 | 원 |
| 딥러닝에서 사용 | 드물게 사용 | Weight Decay로 매우 널리 사용 |

### PyTorch에서의 구현

```python
# L2 정규화 (Weight Decay) - 가장 흔한 방법
optimizer = torch.optim.Adam(model.parameters(), lr=0.001, weight_decay=1e-4)

# L1 정규화 - 수동 구현 필요
l1_lambda = 1e-5
l1_norm = sum(p.abs().sum() for p in model.parameters())
loss = criterion(output, target) + l1_lambda * l1_norm
```

## 1.4 Early Stopping (조기 종료)

### 개념 설명

훈련을 일찍 멈추는 것도 정규화의 한 형태이다.

```
  오차
  │
  │ ╲
  │   ╲  검증 오차
  │    ╲_____╱╱╱╱╱   ← 검증 오차가 다시 올라가기 시작
  │          │
  │          │ ← 여기서 멈춤! (Early Stopping Point)
  │          │
  │          ╲______  훈련 오차 (계속 감소)
  │
  └──────────────────── Epoch
```

**왜 정규화인가?**
- 훈련을 오래 할수록 모델이 훈련 데이터에 과적합됨
- 조기 종료는 모델의 "유효 복잡도"를 제한하는 효과
- L2 정규화와 수학적으로 유사한 효과를 가짐 (특히 선형 모델에서)

### 구현 시 핵심 요소

```python
# Early Stopping의 핵심 구성 요소
patience = 10          # 검증 손실이 개선되지 않는 epoch 허용 횟수
best_val_loss = float('inf')
counter = 0

for epoch in range(max_epochs):
    train_loss = train_one_epoch(model, train_loader)
    val_loss = evaluate(model, val_loader)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        counter = 0
        torch.save(model.state_dict(), 'best_model.pt')  # 최고 모델 저장
    else:
        counter += 1
        if counter >= patience:
            print(f"Early stopping at epoch {epoch}")
            break

# 최고 성능 모델 복원
model.load_state_dict(torch.load('best_model.pt'))
```

### 문제 3: Early Stopping

### 딥러닝과의 연결

| 입문 개념 | 딥러닝에서의 의미 |
|-----------|-------------------|
| High Bias | 네트워크가 너무 얕거나 좁음, 학습률이 너무 낮음, 훈련 epoch 부족 |
| High Variance | 네트워크가 너무 크거나, 훈련 데이터가 부족하거나, 정규화 없음 |
| L2/Weight Decay | Adam, SGD 등 옵티마이저의 `weight_decay` 파라미터 |
| Early Stopping | 거의 모든 딥러닝 훈련에서 기본적으로 사용 |

## 2.1 Dropout: 이론과 실제

### 핵심 아이디어

Dropout은 훈련 중 각 미니배치마다 뉴런을 확률 p로 무작위 비활성화하는 기법이다.

```
    훈련 시 (dropout rate = 0.5)          추론 시 (전체 네트워크)

     O ─── O ─── O                        O ─── O ─── O
     │     ╳     │   ← 비활성화           │     │     │
     O ─── O ─── O                        O ─── O ─── O
     │     │     ╳   ← 비활성화           │     │     │
     O ─── O ─── O                        O ─── O ─── O

   매번 다른 "서브네트워크"가            모든 가중치를 (1-p)로 스케일링
   훈련에 참여                           (inverted dropout은 훈련 시 1/p로 스케일)
```

### 왜 작동하는가? - 세 가지 관점

#### 관점 1: 앙상블 학습

Dropout은 지수적으로 많은 서브네트워크의 앙상블을 근사한다.

- n개 뉴런이 있으면 2^n개의 가능한 서브네트워크가 존재
- 매 미니배치마다 다른 서브네트워크를 훈련
- 추론 시 모든 서브네트워크의 예측을 (가중) 평균하는 것과 유사

#### 관점 2: Co-adaptation 방지

- 특정 뉴런이 다른 뉴런에 지나치게 의존하는 것을 방지
- 각 뉴런이 독립적으로 유용한 특성을 학습하도록 유도
- 결과적으로 더 robust한 특성 표현을 학습

#### 관점 3: 노이즈 주입

- 훈련 데이터에 곱셈 노이즈(multiplicative noise)를 주입하는 것과 동치
- 이는 데이터 증강의 한 형태로 볼 수 있음

### 실전 가이드

```python
import torch.nn as nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 512)
        self.dropout1 = nn.Dropout(p=0.5)    # 은닉층: 보통 0.5
        self.fc2 = nn.Linear(512, 256)
        self.dropout2 = nn.Dropout(p=0.5)
        self.fc3 = nn.Linear(256, 10)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        x = self.dropout1(x)                # 훈련 시에만 활성화
        x = F.relu(self.fc2(x))
        x = self.dropout2(x)
        x = self.fc3(x)                     # 출력층에는 dropout 안 함!
        return x

# 중요: 추론 시 반드시 eval 모드
model.eval()   # dropout 비활성화
model.train()  # dropout 활성화
```

### Dropout 사용 가이드라인

| 상황 | 권장 dropout rate |
|------|-------------------|
| 입력층 | 0.1 ~ 0.2 (또는 사용 안 함) |
| 은닉층 (FC) | 0.3 ~ 0.5 |
| CNN 합성곱층 | 보통 사용 안 함 (대신 Spatial Dropout 사용) |
| Transformer | Attention dropout 0.1, Residual dropout 0.1 |
| 데이터가 적을 때 | 더 높은 비율 (0.5~0.7) |
| 데이터가 많을 때 | 낮은 비율 (0.1~0.3) 또는 사용 안 함 |

## 2.2 데이터 증강 전략 (Data Augmentation)

### 개념 설명

데이터 증강은 기존 데이터를 변형하여 훈련 데이터의 다양성을 높이는 기법이다. 이는 모델이 불변적(invariant) 특성을 학습하도록 돕는, 가장 효과적인 정규화 방법 중 하나이다.

### 이미지 데이터 증강

```
  원본 이미지        좌우 반전          회전              색상 변환
  ┌─────────┐      ┌─────────┐      ┌─────────┐      ┌─────────┐
  │  🐱     │      │     🐱  │      │    🐱   │      │  🐱     │
  │         │  →   │         │  →   │   ╱     │  →   │ (밝기↑) │
  │         │      │         │      │  ╱      │      │         │
  └─────────┘      └─────────┘      └─────────┘      └─────────┘
```

### 주요 기법 분류

| 카테고리 | 기법 | 설명 |
|---------|------|------|
| **기하학적** | 회전, 반전, 크롭, 리사이즈 | 위치/방향에 대한 불변성 학습 |
| **색상** | 밝기, 대비, 채도, 색조 변환 | 조명 조건에 대한 강건성 |
| **노이즈** | 가우시안 노이즈, 블러 | 노이즈에 대한 강건성 |
| **삭제** | Cutout, Random Erasing | 부분 가림(occlusion)에 대한 강건성 |
| **혼합** | Mixup, CutMix | 두 이미지를 혼합하여 새 샘플 생성 |
| **자동화** | AutoAugment, RandAugment | 최적 증강 정책을 자동 탐색 |

### Mixup과 CutMix

```
Mixup: 두 이미지를 픽셀 단위로 혼합
  λ=0.3:  0.3 × 🐱 + 0.7 × 🐶 = 흐릿한 혼합 이미지
  라벨:   [0.3, 0.7]  (고양이 0.3, 개 0.7)

CutMix: 한 이미지의 일부를 다른 이미지로 대체
  ┌──────────┐     ┌──────────┐     ┌──────────┐
  │  🐱      │  +  │  🐶      │  =  │  🐱 ┌──┐│
  │          │     │          │     │     │🐶││
  │          │     │          │     │     └──┘│
  └──────────┘     └──────────┘     └──────────┘

```

## 2.3 학습률 스케줄 (Learning Rate Schedules)

### 왜 학습률 스케줄이 필요한가?

학습률(lr)은 최적화 과정에서 가장 중요한 하이퍼파라미터이다.

```
  큰 학습률:                    작은 학습률:                   적응적 학습률:
  빠르지만 불안정               안정적이지만 느림               빠르고 안정적

  ╱╲    ╱╲                      ╲                              ╲
 ╱  ╲  ╱  ╲   ← 발산 위험      ╲                              ╲
╱    ╲╱    ╲                      ╲                              ╲___
                                    ╲_______________              최솟값에 수렴
       최솟값을 건너뜀                느리게 수렴
```

### 주요 스케줄 비교

```
  lr
  │
  │ ████                           ← Step Decay: 일정 epoch마다 lr을 감소
  │     ████
  │         ████
  │             ████
  │
  │ ╲                              ← Cosine Annealing: 코사인 곡선으로 부드럽게 감소
  │   ╲
  │     ╲___
  │          ╲
  │            ╲___
  │
  │       ╱╲                       ← Warmup + Decay: 초반에 lr을 점진적 증가 후 감소
  │     ╱    ╲____
  │   ╱            ╲____
  │ ╱                    ╲____
  │
  └──────────────────────────── Epoch
```

| 스케줄 | 장점 | 단점 | 주요 사용처 |
|--------|------|------|------------|
| Step Decay | 구현 간단 | 급격한 변화 | 기본 CNN 훈련 |
| Cosine Annealing | 부드러운 감소, Warm Restart 가능 | 하이퍼파라미터 선택 필요 | 현대 딥러닝 전반 |
| Linear Warmup + Decay | 초기 불안정성 해결 | 복잡한 설정 | Transformer, 대규모 모델 |
| OneCycleLR | 빠른 수렴, super-convergence | 올바른 max_lr 설정 필요 | 빠른 훈련이 필요한 경우 |
| ReduceOnPlateau | 자동 적응 | 반응이 느릴 수 있음 | 수렴 시점 예측 어려울 때 |

### PyTorch 구현

```python
# Cosine Annealing with Warm Restart
scheduler = torch.optim.lr_scheduler.CosineAnnealingWarmRestarts(
    optimizer, T_0=10, T_mult=2
)

# Linear Warmup + Cosine Decay (Transformer에서 많이 사용)
from torch.optim.lr_scheduler import LambdaLR

def lr_lambda(current_step):
    warmup_steps = 1000
    if current_step < warmup_steps:
        return current_step / warmup_steps  # Linear warmup
    else:
        # Cosine decay
        progress = (current_step - warmup_steps) / (total_steps - warmup_steps)
        return 0.5 * (1 + math.cos(math.pi * progress))

scheduler = LambdaLR(optimizer, lr_lambda)
```

## 2.4 배치 크기의 효과 (Batch Size Effects)

### 큰 배치 vs 작은 배치

배치 크기는 단순한 하드웨어 제약이 아니라, 일반화 성능에 직접적인 영향을 미친다.

```
  Loss Landscape 비유:

  작은 배치 (e.g., 32):                큰 배치 (e.g., 4096):
  노이즈가 많은 그래디언트              깨끗한 그래디언트

       ╱╲     ╱╲                              ╱╲     ╱╲
  ────╱  ╲───╱  ╲────                   ────╱  ╲───╱  ╲────
      ↓                                              ↓
   넓고 평평한 최솟값에 도달             좁고 날카로운 최솟값에 갇힘
   → 일반화 성능이 좋음                 → 일반화 성능이 나쁠 수 있음
```

### 핵심 관찰

| 특성 | 작은 배치 | 큰 배치 |
|------|-----------|---------|
| 그래디언트 노이즈 | 높음 (암묵적 정규화) | 낮음 |
| 수렴 속도 (epoch당) | 느림 | 빠름 |
| 일반화 성능 | 보통 더 좋음 | 추가 기법 없이는 나쁠 수 있음 |
| GPU 활용 | 비효율적 | 효율적 |
| 메모리 사용 | 적음 | 많음 |
| 도달하는 최솟값 | 넓고 평평함 | 좁고 날카로울 수 있음 |

### 큰 배치 훈련을 위한 해결책

- **Linear Scaling Rule**: 배치 크기를 k배 늘리면 학습률도 k배 늘림
- **Warmup**: 큰 학습률로 바로 시작하면 불안정하므로 점진적 증가
- **LARS/LAMB**: 레이어별로 적응적 학습률 적용
- **Gradient Accumulation**: 메모리 제약 시 작은 배치로 그래디언트를 누적

```python
# Gradient Accumulation 예시 (실효 배치 크기 = batch_size × accumulation_steps)
accumulation_steps = 4
optimizer.zero_grad()

for i, (inputs, targets) in enumerate(train_loader):
    outputs = model(inputs)
    loss = criterion(outputs, targets) / accumulation_steps  # 정규화
    loss.backward()

    if (i + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

## 2.5 Double Descent 현상

### 전통적 관점 vs 현대적 관점

전통적 통계학에서는 모델 복잡도를 늘리면 어느 시점부터 과적합으로 테스트 오차가 증가한다고 가르친다 (U자 곡선). 그러나 현대 딥러닝에서는 **Double Descent**라는 놀라운 현상이 관찰된다.

```
  테스트 오차
  │
  │ ╲                   ╱╲
  │   ╲    전통적      ╱  ╲
  │    ╲   U자 곡선  ╱    ╲
  │     ╲_________╱        ╲
  │                          ╲
  │                           ╲________   ← 두 번째 하강!
  │                                        (interpolation 이후)
  │
  │         │                 │
  │    과소매개변수화    보간 임계점     과매개변수화
  │    (전통적 영역)    (critical     (현대 딥러닝 영역)
  │                     regime)
  └──────────────────────────────────── 모델 파라미터 수
```

### 세 가지 형태의 Double Descent

#### 1. Model-wise Double Descent
- 모델 크기(파라미터 수)를 늘리면 테스트 오차가 두 번 하강
- 보간 임계점(interpolation threshold): 모델이 훈련 데이터를 "간신히" 완벽 적합할 수 있는 크기
- 이 임계점 부근에서 테스트 오차가 최대 (과적합 피크)

#### 2. Epoch-wise Double Descent
- 고정된 모델에서 훈련 epoch을 늘리면 테스트 오차가 감소 → 증가 → 다시 감소
- 충분히 오래 훈련하면 과적합을 "넘어서" 다시 좋아짐

#### 3. Sample-wise Double Descent
- 더 많은 데이터가 오히려 성능을 **악화**시킬 수 있는 놀라운 현상
- 모델이 보간 임계점 근처에 있을 때, 데이터를 추가하면 임계점이 이동하여 성능 저하

### 왜 발생하는가?

보간 임계점에서는 모델이 훈련 데이터를 "간신히" 완벽 적합해야 하므로, 모델의 모든 용량이 훈련 데이터를 외우는 데 소진된다. 하지만 과매개변수화 영역에서는 여유 용량이 충분하여, 모델이 데이터를 적합하면서도 "단순한" 해를 찾을 수 있다.

```
보간 임계점:     모델 용량 ≈ 데이터 크기
                 → 모든 용량이 암기에 소진
                 → 일반화할 여유 없음

과매개변수화:    모델 용량 >> 데이터 크기
                 → 데이터를 적합하고도 여유 있음
                 → 여러 가능한 해 중 "단순한" 해를 선택
                 → SGD의 암묵적 정규화가 단순한 해로 유도
```

## 3.1 PAC-Bayes 일반화 한계 (Generalization Bounds)

### 배경: 왜 일반화 이론이 필요한가?

딥러닝의 가장 큰 이론적 미스터리: 과매개변수화된 신경망이 훈련 데이터를 완벽히 암기할 수 있는 용량을 가지면서도 새로운 데이터에 잘 일반화한다. 전통적 학습 이론(VC 차원, Rademacher 복잡도)으로는 이를 설명할 수 없다.

### PAC-Bayes 프레임워크

PAC-Bayes는 모델의 가중치를 확률분포로 모델링하여 일반화 한계를 유도한다.

**핵심 정리 (McAllester's PAC-Bayes Bound)**:

```
확률 ≥ 1-δ 로, 다음이 성립:

E_Q[L_true(h)] ≤ E_Q[L_train(h)] + √[ (KL(Q || P) + ln(n/δ)) / (2n) ]

여기서:
- Q: 사후 분포 (학습된 가중치 분포)
- P: 사전 분포 (학습 전 선택, 예: 초기화 분포)
- KL(Q || P): Q와 P 사이의 KL 발산
- L_true: 실제 손실, L_train: 훈련 손실
- n: 훈련 샘플 수
```

### 직관적 의미

```
일반화 갭 ≤ f(모델의 "복잡도")

여기서 "복잡도" = KL(학습 후 분포 || 학습 전 분포)
             = 학습 과정에서 얼마나 많이 변했는가
```

- **KL 발산이 작다** = 가중치가 초기화에서 크게 벗어나지 않았다 = 단순한 해
- **KL 발산이 크다** = 가중치가 매우 특수한 값으로 이동했다 = 복잡한 해

### 평평한 최솟값과의 연결

PAC-Bayes 한계는 **평평한 최솟값(flat minima)**이 일반화가 좋은 이유를 설명한다:

```
  날카로운 최솟값:                  평평한 최솟값:
  가중치를 조금만 바꿔도             가중치를 좀 바꿔도
  손실이 크게 변함                   손실이 크게 변하지 않음

      ╱│╲                              ╱────────╲
     ╱ │ ╲                            ╱          ╲
    ╱  │  ╲                          ╱            ╲
   ╱   ↓   ╲                       ╱       ↓       ╲
       w*                                  w*
  → 가중치 섭동 시                 → 가중치 섭동 시
    손실 급증                        손실 안정
  → KL 발산이 커야 이 점에         → KL 발산이 작아도
    도달 가능                        도달 가능
  → PAC-Bayes bound 느슨           → PAC-Bayes bound 타이트
```

### 최근 연구 성과

- PAC-Bayes 압축 한계: 네트워크 압축성과 일반화의 직접적 연결 (NeurIPS 2022)
- 비공허(non-vacuous) 한계: 실제 딥러닝 모델에 대해 의미 있는 일반화 한계 도출 성공

## 3.2 Neural Tangent Kernel (NTK) 레짐

### 핵심 개념

NTK는 무한 너비(infinite-width) 신경망의 훈련 동역학을 커널 방법으로 정확히 기술할 수 있게 해주는 이론적 도구이다.

### NTK의 정의

신경망 f(x; θ)에서 NTK는 다음과 같이 정의된다:

```
K(x, x') = ⟨∇_θ f(x; θ), ∇_θ f(x'; θ)⟩

= Σ_i (∂f(x;θ)/∂θ_i) · (∂f(x';θ)/∂θ_i)
```

즉, 두 입력에 대한 네트워크 출력의 파라미터 그래디언트 내적이다.

### NTK 레짐의 핵심 결과

```
무한 너비 극한에서:

1. NTK가 초기화 시 결정론적 커널로 수렴
2. 훈련 중 NTK가 변하지 않음 (고정 커널)
3. 그래디언트 디센트 → 커널 회귀와 동치
4. 전역 최솟값으로의 수렴이 보장됨
```

### 한계와 현실

```
  이론 (NTK 레짐)              현실 (유한 너비)
  ─────────────                ──────────────
  커널이 고정됨                 커널이 학습 중 변함
  특성 학습 없음                특성 학습이 핵심!
  선형화된 동역학               비선형 동역학
  너비 → ∞                     유한 너비

  → NTK 레짐은 실제 성공적인      → "Rich regime" 또는
    신경망을 설명하지 못함          "feature learning regime"이
                                    실제 신경망의 작동 방식
```

### NTK vs Rich Regime

| 특성 | NTK (Lazy) Regime | Rich (Feature Learning) Regime |
|------|-------------------|-------------------------------|
| 너비 | 매우 큼 (→∞) | 유한 |
| 파라미터 변화 | 초기화에서 거의 변하지 않음 | 크게 변함 |
| 특성 학습 | 없음 (랜덤 특성 사용) | 있음 (데이터에 적응) |
| 수렴 보장 | 이론적으로 보장 | 보장 없지만 실제로 작동 |
| 성능 | 커널 방법 수준 | 커널 방법 초과 (현대 딥러닝) |

## 3.3 암묵적 정규화 (Implicit Regularization)

### 핵심 질문

명시적 정규화(L2, dropout 등) 없이도 SGD로 훈련한 과매개변수화 신경망이 왜 일반화하는가?

### SGD의 암묵적 편향

SGD는 단순히 손실을 최소화하는 것이 아니라, 특정 종류의 해를 "선호"한다.

```
  과매개변수화 모델의 해 공간:

  ┌─────────────────────────────────┐
  │                                 │
  │    ★ 날카로운 최솟값            │
  │         (높은 복잡도)           │
  │                                 │
  │              ★ 날카로운 최솟값  │
  │                                 │
  │  ◉◉◉◉◉◉◉◉◉◉                    │
  │  ◉ 넓고 평평한 최솟값 ◉        │  ← SGD가 여기로 수렴!
  │  ◉◉◉◉◉◉◉◉◉◉                    │
  │                                 │
  │    ★ 날카로운 최솟값            │
  │                                 │
  └─────────────────────────────────┘
  모든 ★과 ◉는 훈련 손실이 0인 점
  SGD의 확률적 노이즈가 평평한 영역으로 유도
```

### 암묵적 정규화의 세 가지 메커니즘

#### 1. 그래디언트 노이즈에 의한 정규화

SGD의 미니배치 노이즈가 날카로운 최솟값에서 탈출하게 한다.

```
Implicit Gradient Regularization (IGR):

유효 손실 ≈ L_train + (η/4) · ||∇L||²

                                ↑
                    학습률 × 그래디언트 크기의 제곱
                    → 경사가 급한 곳에 페널티
                    → 평평한 곳을 선호
```

#### 2. 초기화에 가까운 해 선택

그래디언트 디센트는 초기화 점에서 가장 가까운 해를 찾는 경향이 있다.

- 선형 모델: 최소 노름 해로 수렴함이 증명됨
- 신경망: 유사한 경향이 경험적으로 관찰됨

#### 3. 저주파 편향 (Spectral Bias)

신경망은 고주파 성분보다 저주파 성분을 먼저 학습한다.

```
학습 순서:
  1단계: 부드러운 패턴 학습 (일반화 가능한 특성)
  2단계: 세밀한 패턴 학습 (데이터 특유의 패턴)
  3단계: 노이즈 학습 (과적합 시작)

  → Early Stopping이 효과적인 이론적 근거!
```

## 3.4 Sharpness-Aware Minimization (SAM)

### 핵심 아이디어

SAM은 손실 값이 낮은 점을 찾는 것이 아니라, 주변 전체가 낮은 "평평한" 영역을 찾는다.

### 수학적 정의

```
SAM의 목적 함수:

min_w  max_{||ε||≤ρ}  L(w + ε)

해석: "최악의 섭동 ε을 적용해도 손실이 낮은 가중치 w를 찾아라"

일반 SGD: min_w L(w)            → 한 점에서의 손실만 최소화
SAM:      min_w max_ε L(w + ε)  → 주변 영역 전체에서의 최대 손실을 최소화
```

### 시각적 비교

```
  SGD가 찾은 최솟값:                SAM이 찾은 최솟값:

        ╱╲                              ╱──────────╲
       ╱  ╲                            ╱            ╲
      ╱    ╲                          ╱              ╲
     ╱  ↓   ╲                       ╱       ↓         ╲
         w*                                 w*

  "여기는 손실이 낮지만,           "여기는 주변 전체가 낮으므로,
   조금만 벗어나면 급증"            조금 벗어나도 안정적"

  → 훈련 데이터에서만 좋음          → 테스트 데이터에서도 좋음
  → 일반화 성능 낮음               → 일반화 성능 높음
```

### SAM의 2단계 업데이트

```
Step 1: 현재 가중치 w에서 최악의 섭동 방향 계산
        ε* = ρ · ∇L(w) / ||∇L(w)||

Step 2: 섭동된 위치에서의 그래디언트로 가중치 업데이트
        w ← w - η · ∇L(w + ε*)

→ Forward-Backward를 2번 해야 하므로 훈련 시간이 약 2배
```

### PyTorch 구현 (간략화)

```python
# SAM 옵티마이저 사용 예시 (davda54/sam 구현 기반)
from sam import SAM

base_optimizer = torch.optim.SGD
optimizer = SAM(model.parameters(), base_optimizer, lr=0.1, momentum=0.9, rho=0.05)

# 훈련 루프
for inputs, targets in train_loader:
    # 1단계: 최악의 섭동 계산
    loss = criterion(model(inputs), targets)
    loss.backward()
    optimizer.first_step(zero_grad=True)

    # 2단계: 섭동된 위치에서 실제 업데이트
    criterion(model(inputs), targets).backward()
    optimizer.second_step(zero_grad=True)
```

### SAM의 변형

| 변형 | 설명 |
|------|------|
| ASAM (Adaptive SAM) | 파라미터 스케일에 따라 섭동 크기를 적응적으로 조절 |
| GSAM | 그래디언트와 섭동 방향의 관계를 고려 |
| LookSAM | 주기적으로만 SAM 업데이트를 수행하여 비용 절감 |
| Friendly SAM | 더 안정적인 수렴을 위한 변형 |

## 3.5 Lottery Ticket Hypothesis (복권 가설)

### 핵심 주장

> "무작위 초기화된 밀집(dense) 네트워크 안에는, 독립적으로 훈련했을 때 원래 네트워크와 비슷한 정확도를 비슷한 반복 횟수 안에 달성하는 희소(sparse) 서브네트워크('당첨 복권')가 존재한다."
> -- Frankle & Carlin, ICLR 2019

### 시각적 설명

```
  원래 네트워크 (100% 파라미터)        당첨 복권 (10-20% 파라미터)

  O ─── O ─── O ─── O                O ─── O       O
  │ ╲ ╱ │ ╲ ╱ │ ╲ ╱ │                │       ╲     │
  O ─── O ─── O ─── O                O       O ─── O
  │ ╲ ╱ │ ╲ ╱ │ ╲ ╱ │                  ╲   ╱ │
  O ─── O ─── O ─── O                    O   O ─── O

  정확도: 95%                         정확도: 95% (동일!)
  훈련 시간: T                        훈련 시간: ≈ T
  파라미터: N                         파라미터: 0.1N ~ 0.2N

  핵심: 서브네트워크의 "구조"만이 아니라
       "초기 가중치 값"도 같아야 작동!
```

### 당첨 복권 찾기: Iterative Magnitude Pruning (IMP)

```
1. 무작위 초기화 θ₀로 밀집 네트워크 생성
2. 네트워크를 T epoch 동안 훈련 → θ_T
3. 크기가 가장 작은 가중치 p%를 가지치기(pruning)
4. 남은 가중치를 θ₀의 값으로 재초기화 ← 핵심!
5. 2-4를 원하는 희소성에 도달할 때까지 반복
```

### 핵심 발견

| 발견 | 내용 |
|------|------|
| 희소성 | MNIST/CIFAR에서 원래 크기의 10-20%로도 동등한 성능 |
| 초기화의 중요성 | 같은 구조라도 무작위 재초기화하면 성능 저하 → "당첨" 초기값이 핵심 |
| 대규모에서의 수정 | 큰 네트워크에서는 θ₀ 대신 초기 몇 epoch 훈련 후의 θ_k로 재초기화 (Late Rewinding) |
| Transformer에도 적용 | BERT에서도 40-90%의 가중치를 제거해도 성능 유지 가능 |

### 딥러닝에의 함의

- **효율적 추론**: 희소 네트워크로 연산량 절감
- **모델 이해**: 왜 과매개변수화가 필요한가에 대한 통찰 (탐색 공간을 넓히기 위해)
- **Neural Architecture Search**: 큰 네트워크에서 좋은 구조를 찾는 것

## 3.6 Grokking (지연된 일반화) 현상

### 정의

Grokking은 모델이 훈련 데이터를 완벽히 암기(memorization)한 **한참 후에** 갑자기 일반화 성능이 급격히 향상되는 현상이다.

```
  정확도
  │
  │ ████████████████████████████████  훈련 정확도 (일찍 100%에 도달)
  │
  │
  │                            ╱████  테스트 정확도
  │                          ╱
  │                        ╱         ← 갑작스러운 일반화!
  │ ______________________╱             (phase transition)
  │
  │         │                  │
  │    암기 단계           일반화 단계
  │   (memorization)      (generalization)
  └──────────────────────────────────── 훈련 스텝
              (매우 긴 훈련 필요)
```

### 일반적 학습 vs Grokking

```
일반적 학습:                       Grokking:

  훈련 정확도 ↑                     훈련 정확도 ↑
  테스트 정확도 ↑                   테스트 정확도 ─── (정체)
  → 동시에 개선                     → 한참 후에 갑자기 ↑↑↑
```

### 발생 조건과 촉진 요인

| 요인 | 설명 |
|------|------|
| **작은 데이터셋** | 모델 용량 대비 데이터가 적을 때 (경계 지점) |
| **알고리즘적 데이터** | 모듈러 연산, 그룹 연산 등 구조가 있는 데이터 |
| **높은 Weight Decay** | 정규화가 암기에서 일반화로의 전환을 촉진 |
| **높은 학습률** | 가중치 공간 탐색을 촉진 |
| **오래 훈련** | 일반화까지 도달하려면 통상적 훈련 시간의 수십~수백 배 필요 |

### 왜 발생하는가? - 두 가지 메커니즘의 경쟁

```
  모델 내부에서 두 가지 해결 전략이 경쟁:

  "빠른" 전략 (암기):              "느린" 전략 (일반화):
  ─────────────────                ──────────────────
  각 입력-출력 쌍을                 데이터의 구조/패턴을
  개별적으로 암기                   발견하고 활용

  → 빠르게 학습됨                  → 느리게 학습됨
  → 훈련에서만 작동                → 테스트에서도 작동
  → 가중치 노름이 큼               → 가중치 노름이 작음

  Weight Decay가 점차 암기 전략의 가중치를 감소시키고,
  일반화 전략이 우세해지는 "상전이(phase transition)"가 발생
```

### 최근 연구 결과

- **Deep Networks Always Grok** (ICML 2024): 일반적인 딥러닝 환경(CNN on CIFAR-10 등)에서도 Grokking이 발생할 수 있음을 발견
- **Grokking과 Double Descent의 연결**: 두 현상 모두 "지연된 일반화"의 다른 표현으로 볼 수 있음
- **Grokking Explained**: 훈련 데이터와 테스트 데이터 분포 차이가 핵심 요인
