## 1. 수학 공식 총정리

### 1.1 벡터/행렬 핵심 공식

| 공식 | 수식 |
|------|------|
| 내적 | $\langle v, w \rangle = v^\top w = \sum_i v_i w_i$ |
| 노름 | $\|v\| = \sqrt{v^\top v}$ |
| 거리 | $d(v,w) = \|v-w\|$, $\|v-w\|^2 = \|v\|^2 + \|w\|^2 - 2v^\top w$ |
| 전치 | $(AB)^\top = B^\top A^\top$ |
| 행렬곱 원소 | $c_{ij} = \sum_k a_{ik} b_{kj}$, 차원: $(m \times n)(n \times p) = m \times p$ |
| Rank-Nullity | $n = \text{rank}(A) + \text{null}(A)$ ($A \in \mathbb{R}^{m \times n}$) |
| Rank 성질 | $\text{rank}(A) \leq \min(m,n)$, $\text{rank}(A) = \text{rank}(A^\top)$ |
| Rank 부등식 | $\text{rank}(AB) \leq \min(\text{rank}(A), \text{rank}(B))$ |
| 선형대수 기본정리 | $\mathbb{R}^n = \mathcal{N}(A) \oplus \mathcal{R}(A^\top)$, $\mathcal{N}(A) \perp \mathcal{R}(A^\top)$ |

**가역행렬 동치 조건 (TFAE)**: $A \in \mathbb{R}^{n \times n}$에 대해 다음은 모두 동치:
- $A^{-1}$ 존재 $\Leftrightarrow$ $\text{rank}(A) = n$ $\Leftrightarrow$ $\ker(A) = \{0\}$ $\Leftrightarrow$ $\det(A) \neq 0$ $\Leftrightarrow$ 모든 고유값 $\neq 0$

### 1.2 고유값/SVD 핵심 성질

| 항목 | 내용 |
|------|------|
| 고유값 정의 | $Av = \lambda v$ ($v \neq 0$) |
| 특성방정식 | $\det(A - \lambda I) = 0$ |
| 고유값 분해 | $A = U\Lambda U^\top$ (대칭 행렬, $U$는 직교) |
| SVD | $A = U\Sigma V^\top$ ($U$: $m \times m$ 직교, $\Sigma$: $m \times n$ 대각, $V$: $n \times n$ 직교) |
| 저랭크 근사 | $A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^\top$ (Eckart-Young 정리: Frobenius 최적) |
| 직교행렬 | $U^\top U = I$, 노름 보존: $\|Ux\| = \|x\|$ |
| PSD | $v^\top Av \geq 0$, 모든 고유값 $\geq 0$. $BB^\top$는 항상 PSD |
| PD | $v^\top Av > 0$, 모든 고유값 $> 0$. PD이면 가역 |

### 1.3 미분 공식

| 공식 | 수식 |
|------|------|
| Chain Rule | $\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)$ |
| Product Rule | $(fg)' = f'g + fg'$ |
| 다변수 Chain Rule | $\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial x}$ (Jacobian의 곱) |
| Gradient | $\nabla f = \left[\frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_n}\right]^\top$ |
| Jacobian | $J_{ij} = \frac{\partial f_i}{\partial x_j}$, $J \in \mathbb{R}^{m \times n}$ |
| Hessian | $H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$, 대칭 행렬 |
| $\nabla_x (Wx)$ | $= W$ |
| $\nabla_x (x^\top A x)$ | $= (A + A^\top)x$ (대칭이면 $= 2Ax$) |
| $\nabla_W (a^\top W x)$ | $= x a^\top$ |

**역전파 핵심 미분**:

| 연산 | $\partial L / \partial z$ |
|------|--------------------------|
| Softmax + CE ($L = -\log p_y$) | $p - e_y$ (예측 확률 - 정답 원핫) |
| MSE ($L = \frac{1}{2}\|z - z_0\|^2$) | $z - z_0$ |
| ReLU | $\text{diag}(\mathbf{1}(z > 0))$ |
| 선형 $z = Wx$ | $\partial z / \partial x = W$, $\partial z / \partial W = x$ |

### 1.4 확률 공식

| 공식 | 수식 |
|------|------|
| 베이즈 정리 | $P(H \mid E) = \frac{P(E \mid H) \cdot P(H)}{P(E)}$ |
| 조건부 확률 | $P(E \mid F) = \frac{P(E \cap F)}{P(F)}$ |
| 독립 | $P(E \cap F) = P(E) \cdot P(F)$ |
| 기댓값 (이산) | $\mathbb{E}[X] = \sum_x x \cdot p(x)$ |
| 기댓값 (연속) | $\mathbb{E}[X] = \int x \cdot p(x) dx$ |
| 분산 | $\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ |
| 대수의 법칙 (LLN) | $\bar{X}_n \to \mu$ as $n \to \infty$ |
| 중심극한정리 (CLT) | $\sqrt{n}(\bar{X}_n - \mu) \to \mathcal{N}(0, \sigma^2)$ |
| MLE (베르누이) | $\hat{\theta} = k/n$ |
| MLE (정규) | $\hat{\mu} = \bar{x}$, $\hat{\sigma}^2 = \frac{1}{n}\sum(x_i - \bar{x})^2$ (편향) |

**정보이론 핵심**:

| 양 | 수식 |
|----|------|
| 엔트로피 | $H(p) = -\sum_x p(x) \log p(x)$ |
| 교차 엔트로피 | $H(p, q) = -\sum_x p(x) \log q(x)$ |
| KL Divergence | $D_{\text{KL}}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = H(p,q) - H(p) \geq 0$ |

## 2. 핵심 개념 한 줄 정리

### 선형대수
| 용어 | 정의 |
|------|------|
| 선형변환 | $L(av+bu) = aL(v)+bL(u)$를 만족하는 함수, 행렬로 표현 가능 |
| Rank | 행렬의 열(또는 행)이 생성하는 공간의 차원 |
| 영공간 (Kernel) | $Av = 0$을 만족하는 모든 $v$의 집합 |
| 고유벡터 | 행렬 $A$에 의해 방향이 변하지 않고 스케일만 변하는 벡터 |
| SVD | 임의의 행렬을 "회전 $\to$ 스케일링 $\to$ 회전"으로 분해 |
| PSD/PD | 이차형식 $v^\top Av$가 항상 $\geq 0$ / $> 0$인 대칭 행렬 |
| 조건수 | $\kappa(A) = \lambda_{\max}/\lambda_{\min}$, 수치 안정성과 수렴 속도 결정 |

### 최적화
| 용어 | 정의 |
|------|------|
| 볼록 함수 | $f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda) f(y)$ |
| 강볼록 | 볼록 + $\nabla^2 f \succeq mI$ ($m > 0$): 유일한 최솟값 보장 |
| 임계점 | $\nabla f(x) = 0$인 점 (극값의 필요조건) |
| 안장점 | 임계점이지만 극값이 아닌 점 (Hessian 부호 혼합) |
| 라그랑주 승수법 | 제약 $g(x)=0$ 하에서 최적점은 $\nabla f = -\lambda \nabla g$ |
| KKT 조건 | 부등식 제약 포함 최적화의 필요조건 (정류성 + 실행가능성 + 상보 이완성) |
| Jensen 부등식 | 볼록 $f$에 대해 $f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$ |

### 확률/통계
| 용어 | 정의 |
|------|------|
| 사전 확률 (Prior) | 데이터 관측 전 가설에 대한 믿음 $P(H)$ |
| 우도 (Likelihood) | 가설 하에서 데이터 관측 확률 $P(E \mid H)$ |
| 사후 확률 (Posterior) | 데이터 관측 후 업데이트된 믿음 $P(H \mid E)$ |
| MLE | 우도를 최대화하는 파라미터 추정: $\arg\max_\theta \prod P(x_i \mid \theta)$ |
| MAP | 사후확률 최대화: MLE + 사전분포 = 정규화된 ERM |
| NLL | 음의 로그우도: CE와 MSE는 모두 NLL의 특수한 경우 |

### 머신러닝 기초
| 용어 | 정의 |
|------|------|
| ERM | 경험적 위험 $L_S(h) = \frac{1}{n}\sum \ell(y_i, h(x_i))$을 최소화 |
| 모집단 위험 | 전체 분포에 대한 기대 손실 $L_\mathcal{P}(h) = \mathbb{E}[\ell(y, h(x))]$ |
| 일반화 오차 | $L_\mathcal{P}(h_S) = \text{근사 오차} + \text{추정 오차}$ |
| 근사 오차 | 가설 공간의 표현력 부족에 의한 오차 ($|\mathcal{H}| \uparrow$이면 $\downarrow$) |
| 추정 오차 | 유한 데이터에 의한 오차 ($|\mathcal{H}| \uparrow$이면 $\uparrow$, $n \uparrow$이면 $\downarrow$) |

### 딥러닝
| 용어 | 정의 |
|------|------|
| 신경망 | $f = f_L \circ f_{L-1} \circ \cdots \circ f_1$, 선형변환 + 비선형 활성화의 반복 합성 |
| 역전파 | 역방향 모드 자동미분: chain rule로 모든 파라미터의 gradient를 한 번에 계산 |
| 활성화 함수 | 비선형성 도입 (ReLU, Sigmoid, Tanh 등) |
| 보편 근사 정리 | 충분히 넓은 1-hidden-layer NN은 임의의 연속함수를 근사 가능 (존재성 정리) |
| 귀납적 편향 | 학습 알고리즘이 가정하는 구조적 사전지식 (CNN: 지역성, RNN: 시간적 구조) |
| Batch Normalization | 레이어 입력을 정규화하여 학습 안정화 |
| Dropout | 학습 시 뉴런을 확률적으로 비활성화하여 정규화 |
| 이중 하강 (Double Descent) | 모델 복잡도를 계속 키우면 오차가 U자형이 아닌 두 번째 하강 발생 |
| Flat Minima | 평평한 극소점은 일반화 성능이 좋다 (SGD가 암묵적으로 유도) |

### CNN
| 용어 | 정의 |
|------|------|
| 합성곱 | 필터가 입력 위를 슬라이딩하며 내적 계산: 지역성 + 가중치 공유 |
| 등변성 | 입력이 이동하면 출력도 같은 만큼 이동: $f(S_\tau(x)) = S_\tau(f(x))$ |
| 수용 영역 | 출력 한 픽셀이 참조하는 입력 영역의 크기 |
| 풀링 | 공간 해상도를 줄여 이동 불변성과 계산 효율 확보 |
| $1 \times 1$ 합성곱 | 공간 유지, 채널 간 선형 결합 (Network-in-Network) |

### Transformer/Attention
| 용어 | 정의 |
|------|------|
| Attention | Query-Key 유사도로 Value를 가중 합산하는 미분 가능한 soft dictionary lookup |
| Scaled Dot-Product | $\text{Attention}(Q,K,V) = \text{softmax}(QK^\top/\sqrt{d_k})V$ |
| Multi-Head Attention | 여러 head가 서로 다른 부분공간에서 attention 수행 후 결합 |
| Positional Encoding | Transformer에 위치 정보를 주입 (순서 정보가 없으므로) |
| Self-Attention | Q, K, V가 모두 같은 시퀀스에서 유래 |
| Cross-Attention | Q는 디코더에서, K/V는 인코더에서 유래 |
| Causal Masking | 미래 토큰을 참조하지 못하게 마스킹 (GPT 등 자기회귀 모델) |

### 생성모델
| 용어 | 정의 |
|------|------|
| VAE | ELBO를 최대화하여 잠재 변수 모델을 학습하는 생성 모델 |
| ELBO | $\log p(x) \geq \mathbb{E}_q[-\log p(x|z)] - D_{\text{KL}}(q(z|x) \| p(z))$의 하한 |

## 3. 알고리즘 총정리

### 3.1 Gradient Descent (GD)

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L(\theta_t)$$

- 전체 데이터로 gradient 계산: 한 스텝 비용 $O(n)$
- 수렴 조건 (2차 함수): $\eta < 2/\lambda_{\max}(H)$
- 볼록 + smooth: $O(1/t)$ sublinear 수렴
- 강볼록 + smooth: $O(\rho^t)$ linear 수렴, $\rho = 1 - m/\beta$

### 3.2 SGD (Stochastic Gradient Descent)

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta L_B(\theta_t)$$

- 미니배치 $B$ ($|B| = b$)로 gradient 추정: 불편 추정 ($\mathbb{E}[\nabla L_B] = \nabla L_S$)
- 한 스텝 비용 $O(b) \ll O(n)$
- 확률적 잡음이 sharp minima 탈출, flat minima 유도 (암묵적 정규화)
- Robbins-Monro 조건: $\sum \eta_t = \infty$, $\sum \eta_t^2 < \infty$

### 3.3 Momentum / Adam

```
[Heavy Ball Momentum]
  m_t = beta * m_{t-1} + grad_t
  theta_{t+1} = theta_t - eta * m_t

[Adam]
  m_t = beta1 * m_{t-1} + (1-beta1) * g_t          # 1차 모멘트
  s_t = beta2 * s_{t-1} + (1-beta2) * g_t^2         # 2차 모멘트
  m_hat = m_t / (1 - beta1^t)                        # 편향 보정
  s_hat = s_t / (1 - beta2^t)
  theta_{t+1} = theta_t - eta * m_hat / (sqrt(s_hat) + eps)
  기본값: beta1=0.9, beta2=0.999, eps=1e-8
```

### 3.4 Backpropagation 절차

```
[Forward Pass]
1. z_1 = W_1 x + b_1
2. x_1 = sigma(z_1)          # 활성화 함수 적용
3. z_2 = W_2 x_1 + b_2
4. x_2 = sigma(z_2)
5. L = loss(x_2, y)

[Backward Pass] (VJP chain)
5. dL/dx_2 = dloss/dx_2                    # 손실 미분
4. dL/dz_2 = dL/dx_2 * sigma'(z_2)         # 활성화 미분
3. dL/dW_2 = dL/dz_2 * x_1^T              # 가중치 미분
   dL/dx_1 = W_2^T * dL/dz_2              # 입력으로 전파
2. dL/dz_1 = dL/dx_1 * sigma'(z_1)
1. dL/dW_1 = dL/dz_1 * x^T
```

시간 복잡도: 순전파와 같은 차수 $O(Ln^2)$

### 3.5 Convolution 계산

**출력 크기 공식**:

$$H_{out} = \left\lfloor\frac{H_{in} + 2p - k}{s}\right\rfloor + 1$$

- $k$: 커널 크기, $s$: 스트라이드, $p$: 패딩

**파라미터 수**: $c_{out} \times c_{in} \times k^2 + c_{out}$ (바이어스 포함)

**계산 예시** (1D, $k=3$, $s=1$, $p=0$):
```
입력: [1, 2, 3, 4, 5]    필터: [1, 0, -1]
출력[0] = 1*1 + 2*0 + 3*(-1) = -2
출력[1] = 2*1 + 3*0 + 4*(-1) = -2
출력[2] = 3*1 + 4*0 + 5*(-1) = -2
출력: [-2, -2, -2]    크기: (5+0-3)/1 + 1 = 3
```

### 3.6 Attention 계산

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$

**단계별 계산** ($d_k = 2$, 시퀀스 길이 $N = 3$):
```
1. Score 계산:  S = QK^T              # (N x d_k)(d_k x N) = N x N
2. Scaling:     S = S / sqrt(d_k)      # 분산을 1로 정규화
3. Softmax:     A = softmax(S, dim=-1) # 행별로 softmax -> attention weights
4. 가중합:      Output = AV            # (N x N)(N x d_v) = N x d_v
```

**$\sqrt{d_k}$ 스케일링 이유**: $q, k$ 각 원소가 평균 0, 분산 1이면 내적의 분산이 $d_k$. 스케일링 없으면 softmax가 one-hot에 가까워져 gradient 소실.

**Multi-Head**: $\text{head}_i = \text{Attention}(XW_i^Q, XW_i^K, XW_i^V)$, $\text{MHA}(X) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O$

### 3.7 Transformer Forward Pass

```
[Encoder (한 블록)]
1. x = x + MHA(LayerNorm(x))          # Self-Attention + Residual
2. x = x + FFN(LayerNorm(x))          # Feed-Forward + Residual
   FFN(x) = W_2 * ReLU(W_1 * x + b_1) + b_2

[Decoder (한 블록)]
1. x = x + MaskedMHA(LayerNorm(x))    # Causal Self-Attention
2. x = x + CrossMHA(LayerNorm(x), enc) # Cross-Attention (Q=dec, K/V=enc)
3. x = x + FFN(LayerNorm(x))

[전체 흐름]
입력 토큰 -> 임베딩 + Positional Encoding -> N x Encoder -> 인코더 출력
출력 토큰 -> 임베딩 + Positional Encoding -> N x Decoder -> Linear -> Softmax
```

원 논문: $d=512$, $h=8$, $d_k=d_v=64$, $N=6$ (블록 수), $d_{ff}=2048$

## 4. 시험 빈출 유형별 풀이 전략

### 4.1 "미분을 구하시오" 유형

**전략**: 합성함수 → chain rule 적용, 행렬 미분은 차원 먼저 확인

```
풀이 순서:
1. 계산 그래프를 그린다 (입력 -> 중간변수 -> 출력)
2. 각 노드 간의 Jacobian을 구한다
3. chain rule로 곱한다: dL/dx = dL/dz * dz/dx
4. 차원을 검증한다: (1 x m) * (m x n) = (1 x n)
```

**자주 나오는 패턴**:
- $\frac{\partial}{\partial W}(Wx) = x^\top$ (스칼라 L에 대해)
- Softmax + CE: $\partial L / \partial z = p - e_y$ (외우기!)
- ReLU: 0 or 1 (단순 게이트)

### 4.2 "행렬의 rank를 구하시오" 유형

**전략**: 행 사다리꼴로 변환 → 영이 아닌 행의 수 = rank

```
풀이 순서:
1. 가우스 소거법으로 행 사다리꼴(REF)로 변환
2. 영이 아닌 행의 수 = rank
3. null(A) = n - rank(A) (Rank-Nullity)
4. 검증: rank <= min(m, n)
```

**빠른 판단법**:
- 2x2: $\det \neq 0$이면 rank = 2
- 열(또는 행)이 서로 상수배이면 rank = 1
- $AB$의 rank $\leq \min(\text{rank}(A), \text{rank}(B))$

### 4.3 "확률을 계산하시오" 유형

**전략**: 문제를 사건과 조건으로 분해 → 적절한 공식 적용

```
풀이 순서:
1. 주어진 것/구할 것을 P(?) 형태로 정리
2. 조건부 확률이면 베이즈 정리 적용:
   P(H|E) = P(E|H)P(H) / P(E)
3. P(E) = sum_H P(E|H)P(H) (전체 확률 법칙)
4. 독립성 활용 가능 여부 확인
```

### 4.4 "Forward pass를 계산하시오" 유형

**전략**: 레이어별로 순서대로 계산, 중간 결과를 모두 기록

```
풀이 순서:
1. 입력 x에 W_1 곱하고 b_1 더하기: z_1 = W_1 x + b_1
2. 활성화 함수 적용: x_1 = sigma(z_1)
3. 다음 레이어 반복
4. 최종 출력에 softmax (분류) 또는 그대로 (회귀)
5. 손실 계산

주의사항:
- 행렬 곱 차원 체크 (m x n)(n x 1) = (m x 1)
- softmax: p_i = exp(z_i) / sum_j exp(z_j)
- ReLU: max(0, z)
```

### 4.5 "Backpropagation으로 gradient를 구하시오" 유형

**전략**: forward pass의 역순으로, 각 변수에 대해 chain rule 적용

```
풀이 순서:
1. Forward pass를 먼저 수행하고 모든 중간값 기록
2. 출력에서 시작: dL/d(출력) 계산
3. 역순으로 각 레이어에서:
   - 활성화 미분: dL/dz = dL/dx * sigma'(z)
   - 가중치 미분: dL/dW = (dL/dz) * x_prev^T
   - 입력 미분:   dL/dx_prev = W^T * (dL/dz)
4. 차원 검증 (gradient와 파라미터의 shape 일치해야 함)
```

### 4.6 "이 모델의 파라미터 수를 구하시오" 유형

**전략**: 각 레이어별 파라미터 수를 합산

| 레이어 | 파라미터 수 |
|--------|-----------|
| Linear $(d_{in} \to d_{out})$ | $d_{in} \times d_{out} + d_{out}$ |
| Conv2d $(c_{in}, c_{out}, k)$ | $c_{out} \times c_{in} \times k^2 + c_{out}$ |
| MHA ($d, h$) | $4 \times d^2$ ($W^Q, W^K, W^V, W^O$ 각각 $d \times d$) |
| FFN ($d, d_{ff}$) | $d \times d_{ff} + d_{ff} + d_{ff} \times d + d$ |
| LayerNorm ($d$) | $2d$ ($\gamma, \beta$) |
| Embedding ($V, d$) | $V \times d$ |
| BatchNorm ($c$) | $2c$ ($\gamma, \beta$) + $2c$ (running mean/var, 학습 안 함) |

**Transformer 블록 파라미터 예시** ($d=512, h=8, d_{ff}=2048$):
- MHA: $4 \times 512^2 = 1,048,576$
- FFN: $512 \times 2048 + 2048 + 2048 \times 512 + 512 = 2,099,712$
- LayerNorm x2: $2 \times 2 \times 512 = 2,048$
- 블록 합계: 약 3.15M

## 5. 자주 나오는 증명/유도

### 5.1 Softmax가 엔트로피 최대화에서 나오는 과정

**문제**: 기댓값 제약 $\mathbb{E}_p[f_i(x)] = c_i$ ($i=1,\ldots,m$) 하에서 엔트로피 $H(p) = -\sum_x p(x) \log p(x)$를 최대화하라.

**풀이**:
1. 라그랑지안 구성:
$$\mathcal{L} = -\sum_x p(x)\log p(x) + \lambda_0\left(\sum_x p(x) - 1\right) + \sum_i \lambda_i\left(\sum_x p(x)f_i(x) - c_i\right)$$

2. $\partial \mathcal{L}/\partial p(x) = 0$:
$$-\log p(x) - 1 + \lambda_0 + \sum_i \lambda_i f_i(x) = 0$$

3. 정리하면:
$$p(x) = \exp\left(\lambda_0 - 1 + \sum_i \lambda_i f_i(x)\right) = \frac{\exp\left(\sum_i \lambda_i f_i(x)\right)}{Z}$$

4. $f_i(x) = \mathbf{1}(x = i)$ (분류 문제)이면 **softmax 함수**:
$$p(i) = \frac{\exp(\lambda_i)}{\sum_j \exp(\lambda_j)}$$

### 5.2 Rank-Nullity 정리

**정리**: $A \in \mathbb{R}^{m \times n}$에 대해 $\text{rank}(A) + \text{null}(A) = n$

**증명 핵심**:
1. $\mathcal{R}(A^\top) \perp \mathcal{N}(A)$: $v \in \mathcal{N}(A)$이면 $Av = 0$이므로, $A^\top$의 임의 열 $A^\top y$에 대해 $(A^\top y)^\top v = y^\top (Av) = 0$
2. $\mathcal{R}(A^\top)$와 $\mathcal{N}(A)$는 서로 직교 보공간: $\mathbb{R}^n = \mathcal{R}(A^\top) \oplus \mathcal{N}(A)$
3. 따라서 $\dim(\mathcal{R}(A^\top)) + \dim(\mathcal{N}(A)) = n$
4. $\text{rank}(A) = \text{rank}(A^\top) = \dim(\mathcal{R}(A^\top))$이므로 완료

### 5.3 Bias-Variance Decomposition

**정리**: $\mathbb{E}_S[(h_S(x) - f(x))^2] = \text{Var}_S[h_S(x)] + \text{Bias}^2$

**증명**:
$$\mathbb{E}_S[(h_S - f)^2] = \mathbb{E}_S[(h_S - \mu + \mu - f)^2]$$
$$= \mathbb{E}_S[(h_S - \mu)^2] + 2\underbrace{\mathbb{E}_S[h_S - \mu]}_{=0}(\mu - f) + (\mu - f)^2$$
$$= \underbrace{\text{Var}_S[h_S]}_{\text{분산}} + \underbrace{(\mu - f)^2}_{\text{편향}^2}$$

여기서 $\mu = \mathbb{E}_S[h_S]$ (다양한 훈련세트에 대한 평균 모델).

### 5.4 ELBO 유도

**목표**: $\log p(x)$의 tractable한 하한 유도

$$\log p(x) = \log \int p(x, z) dz = \log \mathbb{E}_{q(z|x)}\left[\frac{p(x, z)}{q(z|x)}\right]$$

Jensen 부등식 ($\log$는 오목) 적용:

$$\geq \mathbb{E}_{q(z|x)}\left[\log \frac{p(x, z)}{q(z|x)}\right] = \underbrace{\mathbb{E}_q[\log p(x|z)]}_{\text{복원 항}} - \underbrace{D_{\text{KL}}(q(z|x) \| p(z))}_{\text{정합 항}} = \text{ELBO}$$

**등호 조건**: $q(z|x) = p(z|x)$ (변분 사후분포 = 실제 사후분포)

**다른 유도** (직접 분해):
$$\log p(x) = \text{ELBO} + D_{\text{KL}}(q(z|x) \| p(z|x)) \geq \text{ELBO}$$

KL divergence $\geq 0$이므로 하한이 성립.

## 6. 헷갈리기 쉬운 개념 비교표

### 6.1 GD vs SGD

| 항목 | GD | SGD |
|------|-----|-----|
| Gradient 계산 | 전체 데이터 ($n$개) | 미니배치 ($b$개) |

### 6.2 Training Error vs Test Error vs Generalization Error

| 항목 | 수식 | 의미 |
|------|------|------|

### 문제 3. 편미분과 Gradient [미적분]

**풀이**:
$$\frac{\partial f}{\partial x} = 2xy + 3y^2 + 2 \Big|_{(1,2)} = 4 + 12 + 2 = 18$$
$$\frac{\partial f}{\partial y} = x^2 + 6xy \Big|_{(1,2)} = 1 + 12 = 13$$

**$\nabla f(1, 2) = [18, 13]^\top$**

### 문제 4. Chain Rule 적용 [역전파]

$z = Wx$ ($W \in \mathbb{R}^{2 \times 3}$, $x \in \mathbb{R}^3$), $a = \text{ReLU}(z)$, $L = \sum_i a_i$일 때,

$W = \begin{pmatrix} 1 & -1 & 2 \\ 0 & 3 & -1 \end{pmatrix}$, $x = [1, 0, -1]^\top$에서 $\frac{\partial L}{\partial x}$를 구하시오.

**풀이**:
1. $z = Wx = [1 \cdot 1 + (-1) \cdot 0 + 2 \cdot (-1),\; 0 \cdot 1 + 3 \cdot 0 + (-1)(-1)]^\top = [-1, 1]^\top$
2. $a = \text{ReLU}(z) = [0, 1]^\top$
3. $\frac{\partial L}{\partial a} = [1, 1]^\top$
4. $\frac{\partial L}{\partial z} = \frac{\partial L}{\partial a} \odot \mathbf{1}(z > 0) = [1, 1] \odot [0, 1] = [0, 1]^\top$
5. $\frac{\partial L}{\partial x} = W^\top \frac{\partial L}{\partial z} = \begin{pmatrix} 1 & 0 \\ -1 & 3 \\ 2 & -1 \end{pmatrix} \begin{pmatrix} 0 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 3 \\ -1 \end{pmatrix}$

**$\frac{\partial L}{\partial x} = [0, 3, -1]^\top$**

### 문제 7. 베이즈 정리 [확률]

**풀이**:

$$= \frac{0.0099}{0.0099 + 0.0495} = \frac{0.0099}{0.0594} \approx \mathbf{16.7\%}$$

핵심 교훈: 유병률(prior)이 낮으면 양성이어도 실제 확률은 낮다.

### 문제 11. Attention Score 계산 [Transformer]

$Q = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$, $K = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$, $V = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$ (각 행이 토큰), $d_k = 2$일 때, Attention 출력을 구하시오.

**풀이**:
1. $QK^\top = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}\begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$

2. $\frac{QK^\top}{\sqrt{2}} = \begin{pmatrix} 0.707 & 0 \\ 0.707 & 0.707 \end{pmatrix}$

3. Softmax (행별):
   - 행1: $[e^{0.707}, e^0] / (e^{0.707}+1) = [2.028, 1]/3.028 \approx [0.670, 0.330]$
   - 행2: $[e^{0.707}, e^{0.707}] / 2e^{0.707} = [0.5, 0.5]$

4. $\text{Output} = AV = \begin{pmatrix} 0.670 & 0.330 \\ 0.5 & 0.5 \end{pmatrix}\begin{pmatrix} 1 \\ 2 \end{pmatrix} = \begin{pmatrix} 1.330 \\ 1.5 \end{pmatrix}$

### 문제 12. Gradient Descent 한 스텝 [최적화]

$L(\theta) = \theta^2 + 4\theta + 4$, 초기값 $\theta_0 = 3$, $\eta = 0.1$일 때, $\theta_1$은?

**풀이**:
$$\nabla L(\theta_0) = 2\theta_0 + 4 = 2(3) + 4 = 10$$
$$\theta_1 = \theta_0 - \eta \nabla L = 3 - 0.1 \times 10 = \mathbf{2.0}$$

참고: 최적해는 $\theta^* = -2$ ($\nabla L = 0$에서).

### 문제 14. Bias-Variance [학습이론]

### 문제 15. KL Divergence 계산 [정보이론]

$p = [0.5, 0.5]$, $q = [0.9, 0.1]$일 때, $D_{\text{KL}}(p \| q)$는?

**풀이**:
$$D_{\text{KL}}(p \| q) = 0.5 \log\frac{0.5}{0.9} + 0.5 \log\frac{0.5}{0.1}$$
$$= 0.5 \times (-0.588) + 0.5 \times 1.609 = -0.294 + 0.805 \approx \mathbf{0.511}$$

(자연로그 기준)

### 문제 16. SVD와 저랭크 근사 [선형대수]

### 문제 17. 볼록 함수 판정 [최적화]
