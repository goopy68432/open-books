## 1. 미분 기초

### 1.1 도함수란 무엇인가? -- 기울기와 변화율

#### 일상적 비유

자동차의 속도계를 생각해보자. 자동차가 달리고 있을 때, 속도계는 "지금 이 순간 얼마나 빠르게 달리고 있는가"를 보여준다. 이것이 바로 **도함수(derivative)**의 핵심 아이디어이다.

- 위치가 시간에 따라 변하는 함수라면, 도함수는 **속도**(변화율)이다
- 은행 잔고가 시간에 따라 변하는 함수라면, 도함수는 **이자가 붙는 속도**이다
- 산의 높이가 위치에 따라 변하는 함수라면, 도함수는 **경사(기울기)**이다

#### 수식 설명

함수 $f(x)$가 있을 때, 도함수 $f'(x)$는 다음과 같이 정의된다:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

한 줄씩 읽어보자:

- $f(x+h)$: 현재 위치 $x$에서 아주 조금($h$만큼) 이동한 곳의 함수값
- $f(x+h) - f(x)$: 함수값이 **얼마나 변했는지** (변화량)
- $\frac{f(x+h) - f(x)}{h}$: 변화량을 이동 거리로 나눈 것 = **변화율**
- $\lim_{h \to 0}$: $h$를 0에 가깝게 줄인 극한 = **순간** 변화율

#### 구체적 계산 예시

$f(x) = x^2$의 도함수를 구해보자.

$$f'(x) = \lim_{h \to 0} \frac{(x+h)^2 - x^2}{h}$$

1단계: $(x+h)^2$을 전개한다.

$$(x+h)^2 = x^2 + 2xh + h^2$$

2단계: 분자를 계산한다.

$$(x^2 + 2xh + h^2) - x^2 = 2xh + h^2$$

3단계: $h$로 나눈다.

$$\frac{2xh + h^2}{h} = 2x + h$$

4단계: $h \to 0$으로 보낸다.

$$f'(x) = 2x$$

**의미**: $f(x) = x^2$에서 $x = 3$일 때, 기울기는 $f'(3) = 6$이다. 즉, $x$가 3 근처에서 1만큼 증가하면 $f$는 대략 6만큼 증가한다.

#### 딥러닝에서의 활용

딥러닝에서 도함수는 **손실 함수의 기울기**를 의미한다. 손실이 "얼마나 틀렸는가"라면, 도함수는 "가중치를 조금 바꾸면 틀린 정도가 얼마나 변하는가"를 알려준다. 이 정보로 가중치를 **손실이 줄어드는 방향**으로 업데이트한다.

$$\theta_{\text{new}} = \theta_{\text{old}} - \alpha \cdot f'(\theta_{\text{old}})$$

여기서 $\alpha$는 학습률(learning rate)이다.

### 1.2 기본 미분 공식

#### 일상적 비유

미분 공식은 마치 "구구단"과 같다. 매번 정의($\lim$)로 계산하면 너무 느리니까, 자주 쓰는 패턴을 외워두는 것이다.

#### 수식 설명

| 함수 $f(x)$ | 도함수 $f'(x)$ | 읽는 법 |
|---|---|---|
| $x^n$ | $nx^{n-1}$ | "지수를 앞으로 내리고, 지수를 1 줄인다" |
| $e^x$ | $e^x$ | "자기 자신이 도함수" (이것이 $e$가 특별한 이유!) |
| $\ln x$ | $\frac{1}{x}$ | "$x$분의 1" |
| $\sin x$ | $\cos x$ | — |
| $\cos x$ | $-\sin x$ | — |

추가 규칙:

| 규칙 | 공식 |
|---|---|
| 상수배 | $(cf)' = cf'$ |
| 합 | $(f + g)' = f' + g'$ |
| 곱 (Product Rule) | $(fg)' = f'g + fg'$ |
| 합성함수 (Chain Rule) | $(f \circ g)' = f'(g(x)) \cdot g'(x)$ |

#### 구체적 계산 예시

**예시 1**: $f(x) = 3x^4$

$$f'(x) = 3 \cdot 4x^3 = 12x^3$$

**예시 2**: $f(x) = e^{2x}$ (합성함수 -- Chain Rule 사용)

바깥 함수: $e^u$, 안쪽 함수: $u = 2x$

$$f'(x) = e^{2x} \cdot 2 = 2e^{2x}$$

**예시 3**: $f(x) = \ln(x^2 + 1)$

바깥 함수: $\ln u$, 안쪽 함수: $u = x^2 + 1$

$$f'(x) = \frac{1}{x^2 + 1} \cdot 2x = \frac{2x}{x^2 + 1}$$

#### 딥러닝에서의 활용

- $e^x$의 미분: **softmax** 함수의 역전파 계산에 핵심
- $\ln x$의 미분: **cross-entropy 손실 함수**의 역전파에 사용
- $x^n$의 미분: **가중치 감쇠(weight decay)** 정규화항 $\|\theta\|^2$의 기울기 계산

### 1.3 편미분 (Partial Derivative)

#### 일상적 비유

오디오 믹서를 상상해보자. 여러 개의 슬라이더(음량, 저음, 고음, 에코 등)가 있다. **편미분**은 "다른 슬라이더는 고정한 채, 하나의 슬라이더만 살짝 움직이면 소리가 얼마나 변하는가?"를 측정하는 것이다.

#### 수식 설명

$f(x, y)$처럼 변수가 여러 개인 함수에서:

$$\frac{\partial f}{\partial x} = \lim_{h \to 0} \frac{f(x+h, y) - f(x, y)}{h}$$

- $\frac{\partial}{\partial x}$: "$y$는 상수로 취급하고, $x$에 대해서만 미분한다"는 뜻
- 기호 $\partial$("라운드 디"라고 읽음)는 편미분을 나타내는 기호

#### 구체적 계산 예시

$f(x, y) = x^2 y + 3xy^2 + 5$에서:

**$x$에 대한 편미분** ($y$는 상수 취급):

$$\frac{\partial f}{\partial x} = 2xy + 3y^2$$

- $x^2 y$: $y$는 상수이므로 $x^2$만 미분 $\to 2xy$
- $3xy^2$: $y^2$는 상수이므로 $x$만 미분 $\to 3y^2$
- $5$: 상수이므로 $\to 0$

**$y$에 대한 편미분** ($x$는 상수 취급):

$$\frac{\partial f}{\partial y} = x^2 + 6xy$$

**검증**: $x = 1, y = 2$에서:

- $\frac{\partial f}{\partial x}\bigg|_{(1,2)} = 2(1)(2) + 3(4) = 4 + 12 = 16$
- 이는 "$y = 2$로 고정한 채 $x$를 1에서 살짝 늘리면, $f$가 약 16만큼 증가한다"는 뜻

#### 딥러닝에서의 활용

신경망의 손실 함수 $L(\theta_1, \theta_2, \ldots, \theta_n)$은 수백만 개의 가중치에 대한 함수이다. 각 가중치를 업데이트하려면 **각 가중치에 대한 편미분**이 필요하다:

$$\theta_i \leftarrow \theta_i - \alpha \frac{\partial L}{\partial \theta_i}$$

이것이 **역전파(backpropagation)**의 핵심이다.

## 2. 행렬 미적분 (Matrix Calculus)

### 2.1 스칼라를 벡터로 미분: Gradient ($\nabla f$)

#### 일상적 비유

등산을 하고 있다고 상상하자. 발밑 지형이 함수 $f(x, y)$ (동서 좌표 $x$, 남북 좌표 $y$에 대한 높이)라면:

- 편미분 $\frac{\partial f}{\partial x}$: 동쪽으로 갈 때 경사가 얼마나 되는지
- 편미분 $\frac{\partial f}{\partial y}$: 북쪽으로 갈 때 경사가 얼마나 되는지
- **그래디언트** $\nabla f$: 이 두 정보를 합쳐서 만든 "**가장 가파르게 올라가는 방향**을 가리키는 화살표(벡터)"

경사 하강법(gradient descent)은 이 화살표의 **반대 방향**으로 걸어 내려가는 것이다.

#### 수식 설명

스칼라 함수 $f: \mathbb{R}^n \to \mathbb{R}$ (입력: 벡터, 출력: 숫자 하나)에 대해:

**미분(행벡터 -- numerator layout 규약)**:

$$\frac{\partial f}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial f}{\partial x_1} & \frac{\partial f}{\partial x_2} & \cdots & \frac{\partial f}{\partial x_n} \end{bmatrix} \in \mathbb{R}^{1 \times n}$$

**그래디언트(열벡터 -- 전치)**:

$$\nabla_\mathbf{x} f = \left(\frac{\partial f}{\partial \mathbf{x}}\right)^\top = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \frac{\partial f}{\partial x_2} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix} \in \mathbb{R}^n$$

> **주의**: 수업에서는 **numerator layout** 규약을 사용한다. 스칼라를 벡터로 미분하면 **행벡터**가 나온다. 그래디언트는 이것의 전치(열벡터)이다.

#### 구체적 계산 예시

$f(\mathbf{x}) = x_1^2 + 3x_1 x_2 + x_2^2$에서:

$$\frac{\partial f}{\partial \mathbf{x}} = \begin{bmatrix} 2x_1 + 3x_2 & 3x_1 + 2x_2 \end{bmatrix}$$

$$\nabla f = \begin{bmatrix} 2x_1 + 3x_2 \\ 3x_1 + 2x_2 \end{bmatrix}$$

$\mathbf{x} = [1, 2]^\top$에서: $\nabla f = [2 + 6, 3 + 4]^\top = [8, 7]^\top$

이 벡터는 $(1, 2)$에서 $f$가 **가장 빠르게 증가하는 방향**을 가리킨다.

#### 자주 쓰는 벡터 미적분 공식 (암기 필수!)

| 함수 | 미분 $\frac{\partial}{\partial \mathbf{x}}$ | 비고 |
|---|---|---|
| $\mathbf{a}^\top \mathbf{x}$ | $\mathbf{a}^\top$ | 선형 함수의 미분 |
| $A\mathbf{x}$ | $A$ | 행렬-벡터 곱의 야코비안 |
| $\mathbf{x}^\top A\mathbf{x}$ | $\mathbf{x}^\top(A + A^\top)$ | 2차 형식의 미분 |
| $\mathbf{x}^\top S\mathbf{x}$ ($S$ 대칭) | $2\mathbf{x}^\top S$ | $A = A^\top$이면 단순화 |
| $\|\mathbf{x}\|^2 = \mathbf{x}^\top \mathbf{x}$ | $2\mathbf{x}^\top$ | $S = I$인 특수 경우 |

#### 딥러닝에서의 활용

경사 하강법(SGD)의 업데이트 규칙:

$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} - \alpha \nabla_{\boldsymbol{\theta}} L$$

모든 가중치를 한 번에 업데이트할 수 있는 것은, 그래디언트가 "각 가중치에 대한 편미분을 모아놓은 벡터"이기 때문이다.

### 2.2 벡터를 벡터로 미분: Jacobian

#### 일상적 비유

비디오 게임에서 조이스틱을 움직이면 캐릭터가 화면에서 움직인다고 하자. 조이스틱에는 2개의 축(좌우, 상하)이 있고, 캐릭터 위치도 2차원(화면 x, 화면 y)이다.

**야코비안(Jacobian)**은 "조이스틱의 각 축을 살짝 움직일 때, 캐릭터의 각 좌표가 얼마나 변하는지"를 표로 정리한 것이다.

#### 수식 설명

함수 $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ (입력: $n$차원 벡터, 출력: $m$차원 벡터)에 대해:

$$J = \frac{\partial \mathbf{f}}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2} & \cdots & \frac{\partial f_2}{\partial x_n} \\ \vdots & \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \frac{\partial f_m}{\partial x_2} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix} \in \mathbb{R}^{m \times n}$$

- $(i, j)$ 원소: $j$번째 입력이 살짝 변할 때 $i$번째 출력이 얼마나 변하는지
- **각 행**: 하나의 출력 성분에 대한 그래디언트(행벡터)
- **각 열**: 하나의 입력 성분이 모든 출력에 미치는 영향

#### 구체적 계산 예시

$\mathbf{f}(x_1, x_2) = \begin{bmatrix} x_1^2 + x_2 \\ x_1 x_2 \end{bmatrix}$의 야코비안:

$$J = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} \\ \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2} \end{bmatrix} = \begin{bmatrix} 2x_1 & 1 \\ x_2 & x_1 \end{bmatrix}$$

$(x_1, x_2) = (3, 2)$에서:

$$J = \begin{bmatrix} 6 & 1 \\ 2 & 3 \end{bmatrix}$$

**해석**: $x_1$을 3에서 3.01로 바꾸면 ($\Delta x_1 = 0.01$):
- $f_1$은 약 $6 \times 0.01 = 0.06$ 증가
- $f_2$는 약 $2 \times 0.01 = 0.02$ 증가

#### 핵심 예시: 소프트맥스의 야코비안

$p_i = \frac{\exp(z_i)}{\sum_k \exp(z_k)}$일 때:

$$\frac{\partial p_i}{\partial z_j} = \begin{cases} p_i(1 - p_i) & \text{if } i = j \\ -p_i p_j & \text{if } i \neq j \end{cases}$$

행렬로 쓰면:

$$\frac{\partial \mathbf{p}}{\partial \mathbf{z}} = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top$$

#### 딥러닝에서의 활용

신경망의 각 레이어는 벡터를 벡터로 변환하는 함수이다. **역전파**에서 각 레이어의 야코비안을 곱해가며 그래디언트를 전파한다. 야코비안의 곱이 너무 커지면 **gradient explosion**, 너무 작아지면 **gradient vanishing**이 발생한다.

### 2.3 Chain Rule (연쇄 법칙)

#### 일상적 비유

도미노를 생각하자. 첫 번째 도미노가 두 번째를 쓰러뜨리고, 두 번째가 세 번째를 쓰러뜨린다. "첫 번째 도미노를 얼마나 세게 밀면 세 번째가 얼마나 세게 쓰러지는가?"는 **각 단계의 영향을 곱**하면 된다.

신경망에서: 입력 $\to$ 은닉층1 $\to$ 은닉층2 $\to$ 출력 $\to$ 손실

각 단계의 "영향"(야코비안)을 거꾸로 곱해가는 것이 **역전파(backpropagation)**이다.

#### 수식 설명

$\mathbb{R}^{d(x)} \xrightarrow{g} \mathbb{R}^{d(y)} \xrightarrow{f} \mathbb{R}^{d(z)}$일 때:

$$\frac{\partial (f \circ g)(\mathbf{x})}{\partial \mathbf{x}} = \left.\frac{\partial f(\mathbf{y})}{\partial \mathbf{y}}\right|_{\mathbf{y} = g(\mathbf{x})} \cdot \frac{\partial g(\mathbf{x})}{\partial \mathbf{x}}$$

행렬 크기를 맞춰보자:

$$\underbrace{\frac{\partial (f \circ g)}{\partial \mathbf{x}}}_{d(z) \times d(x)} = \underbrace{\frac{\partial f}{\partial \mathbf{y}}}_{d(z) \times d(y)} \cdot \underbrace{\frac{\partial g}{\partial \mathbf{x}}}_{d(y) \times d(x)}$$

**핵심**: 행렬 곱의 크기가 자연스럽게 맞아야 한다. $d(z) \times d(y)$와 $d(y) \times d(x)$를 곱하면 $d(z) \times d(x)$가 된다.

#### 구체적 계산 예시

$g(x) = 3x + 1$, $f(y) = y^2$일 때 $(f \circ g)(x) = (3x+1)^2$의 도함수:

Chain Rule 적용:

$$\frac{d(f \circ g)}{dx} = \frac{df}{dy}\bigg|_{y=3x+1} \cdot \frac{dg}{dx} = 2y \bigg|_{y=3x+1} \cdot 3 = 2(3x+1) \cdot 3 = 6(3x+1)$$

검증: $(3x+1)^2 = 9x^2 + 6x + 1$이므로 도함수는 $18x + 6 = 6(3x+1)$. 일치한다!

**다변수 예시**: $\mathbf{y} = A\mathbf{x}$, $L = \|\mathbf{y}\|^2$일 때 $\frac{\partial L}{\partial \mathbf{x}}$:

$$\frac{\partial L}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{y}} \cdot \frac{\partial \mathbf{y}}{\partial \mathbf{x}} = 2\mathbf{y}^\top \cdot A = 2(A\mathbf{x})^\top A = 2\mathbf{x}^\top A^\top A$$

#### 딥러닝에서의 활용

역전파 알고리즘의 전체 과정이 Chain Rule이다:

$$\frac{\partial L}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{h}_3} \cdot \frac{\partial \mathbf{h}_3}{\partial \mathbf{h}_2} \cdot \frac{\partial \mathbf{h}_2}{\partial \mathbf{h}_1} \cdot \frac{\partial \mathbf{h}_1}{\partial \mathbf{x}}$$

출력에서 입력 방향으로 야코비안을 순차적으로 곱한다.

---

### 2.4 Product Rule (곱 법칙)

#### 일상적 비유

직사각형의 넓이 = 가로 $\times$ 세로이다. 가로와 세로가 동시에 변할 때 넓이의 변화는?

"가로가 변한 만큼 $\times$ 원래 세로" + "원래 가로 $\times$ 세로가 변한 만큼"

#### 수식 설명

**스칼라 함수끼리의 곱** ($f, g: \mathbb{R}^{d(x)} \to \mathbb{R}$):

$$\frac{\partial [f(\mathbf{x}) \cdot g(\mathbf{x})]}{\partial \mathbf{x}} = g(\mathbf{x}) \frac{\partial f(\mathbf{x})}{\partial \mathbf{x}} + f(\mathbf{x}) \frac{\partial g(\mathbf{x})}{\partial \mathbf{x}}$$

**벡터 함수의 내적** ($f, g: \mathbb{R}^{d(x)} \to \mathbb{R}^{d(y)}$):

$$\frac{\partial [f(\mathbf{x})^\top g(\mathbf{x})]}{\partial \mathbf{x}} = g(\mathbf{x})^\top \frac{\partial f(\mathbf{x})}{\partial \mathbf{x}} + f(\mathbf{x})^\top \frac{\partial g(\mathbf{x})}{\partial \mathbf{x}}$$

#### 구체적 계산 예시

$h(x) = x^2 \cdot e^x$의 도함수:

$$h'(x) = (x^2)' \cdot e^x + x^2 \cdot (e^x)' = 2x \cdot e^x + x^2 \cdot e^x = (2x + x^2)e^x$$

---

### 2.5 노름 제곱의 미분: $\frac{\partial \|f(\mathbf{x})\|^2}{\partial \mathbf{x}}$

#### 일상적 비유

"예측값과 정답 사이의 거리의 제곱"을 줄이고 싶다. 이 거리 제곱이 입력에 따라 어떻게 변하는지 알아야 한다.

#### 수식 설명

$\|f(\mathbf{x})\|^2 = f(\mathbf{x})^\top f(\mathbf{x})$이므로, Product Rule과 Chain Rule을 결합하면:

$$\frac{\partial \|f(\mathbf{x})\|^2}{\partial \mathbf{x}} = 2f(\mathbf{x})^\top \cdot \frac{\partial f(\mathbf{x})}{\partial \mathbf{x}}$$

한 줄씩 이해하기:
- $f(\mathbf{x})^\top$: 현재 함수값을 행벡터로 전치 ($1 \times m$)
- $\frac{\partial f(\mathbf{x})}{\partial \mathbf{x}}$: 야코비안 ($m \times n$)
- 곱의 결과: $1 \times n$ 행벡터 (스칼라의 벡터 미분)

#### 구체적 계산 예시

$f(\mathbf{x}) = A\mathbf{x} - \mathbf{b}$일 때 $\|A\mathbf{x} - \mathbf{b}\|^2$의 미분:

$$\frac{\partial \|A\mathbf{x} - \mathbf{b}\|^2}{\partial \mathbf{x}} = 2(A\mathbf{x} - \mathbf{b})^\top \cdot A$$

그래디언트(열벡터)로 쓰면:

$$\nabla_\mathbf{x} \|A\mathbf{x} - \mathbf{b}\|^2 = 2A^\top(A\mathbf{x} - \mathbf{b})$$

#### 딥러닝에서의 활용

MSE 손실 함수 $L = \|W\mathbf{x} - \mathbf{y}\|^2$에서 $W$에 대한 그래디언트:

$$\nabla_W L = 2(W\mathbf{x} - \mathbf{y})\mathbf{x}^\top$$

이것이 선형 회귀에서 가중치 업데이트의 핵심 공식이다.

---

### 2.6 핵심 문제: $\frac{\partial \mathbf{z}}{\partial \mathbf{x}}$ where $\mathbf{z} = BA\mathbf{x}$

#### 일상적 비유

두 개의 렌즈를 통과하는 빛을 생각하자. 첫 번째 렌즈(행렬 $A$)를 통과한 다음 두 번째 렌즈(행렬 $B$)를 통과한다. "입력 빛($\mathbf{x}$)이 살짝 변하면 최종 출력($\mathbf{z}$)이 어떻게 변하는가?"

#### 수식 설명

$\mathbf{z} = BA\mathbf{x}$에서 $\frac{\partial \mathbf{z}}{\partial \mathbf{x}}$를 구하자.

**방법 1 -- 직접 계산**: $BA$를 하나의 행렬 $C = BA$로 보면, $\mathbf{z} = C\mathbf{x}$이므로:

$$\frac{\partial \mathbf{z}}{\partial \mathbf{x}} = C = BA$$

**방법 2 -- Chain Rule**: $\mathbf{y} = A\mathbf{x}$, $\mathbf{z} = B\mathbf{y}$로 놓으면:

$$\frac{\partial \mathbf{z}}{\partial \mathbf{x}} = \frac{\partial \mathbf{z}}{\partial \mathbf{y}} \cdot \frac{\partial \mathbf{y}}{\partial \mathbf{x}} = B \cdot A = BA$$

> **시험 주의**: 만약 문제가 "스칼라 $L$이 있고 $\frac{\partial L}{\partial \mathbf{x}}$를 구하라. 단 $L$은 $\mathbf{z}$를 거쳐서 $\mathbf{x}$에 의존한다"면:
>
> $$\frac{\partial L}{\partial \mathbf{x}} = \frac{\partial L}{\partial \mathbf{z}} \cdot BA$$
>
> 그래디언트(열벡터)로 쓰면: $\nabla_\mathbf{x} L = (BA)^\top \nabla_\mathbf{z} L = A^\top B^\top \nabla_\mathbf{z} L$

#### 구체적 계산 예시

$B = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}$, $A = \begin{bmatrix} 5 & 6 \\ 7 & 8 \end{bmatrix}$, $\mathbf{x} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}$

$$BA = \begin{bmatrix} 1 \cdot 5 + 2 \cdot 7 & 1 \cdot 6 + 2 \cdot 8 \\ 3 \cdot 5 + 4 \cdot 7 & 3 \cdot 6 + 4 \cdot 8 \end{bmatrix} = \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix}$$

$$\frac{\partial \mathbf{z}}{\partial \mathbf{x}} = BA = \begin{bmatrix} 19 & 22 \\ 43 & 50 \end{bmatrix}$$

**의미**: $x_1$을 1만큼 증가시키면 $z_1$은 약 19, $z_2$는 약 43 증가한다.

### 2.7 연습 문제

**문제 1**: $f(\mathbf{x}) = \mathbf{a}^\top \mathbf{x}$에서 $\frac{\partial f}{\partial \mathbf{x}}$를 구하라. ($\mathbf{a} = [2, 3, 5]^\top$)

<details>
<summary>풀이 보기</summary>

$\mathbf{a}^\top \mathbf{x} = 2x_1 + 3x_2 + 5x_3$이므로:

$$\frac{\partial f}{\partial \mathbf{x}} = \begin{bmatrix} 2 & 3 & 5 \end{bmatrix} = \mathbf{a}^\top$$

**문제 2**: $f(\mathbf{x}) = \|\mathbf{x}\|^2 = x_1^2 + x_2^2 + x_3^2$에서 $\frac{\partial f}{\partial \mathbf{x}}$를 구하라.

<details>
<summary>풀이 보기</summary>

$$\frac{\partial f}{\partial \mathbf{x}} = \begin{bmatrix} 2x_1 & 2x_2 & 2x_3 \end{bmatrix} = 2\mathbf{x}^\top$$

</details>

**문제 3**: $L = \|A\mathbf{x} - \mathbf{b}\|^2$에서 $\nabla_\mathbf{x} L = 0$을 풀어 최적 $\mathbf{x}^*$를 구하라.

<details>
<summary>풀이 보기</summary>

$\nabla_\mathbf{x} L = 2A^\top(A\mathbf{x} - \mathbf{b}) = 0$

$A^\top A \mathbf{x} = A^\top \mathbf{b}$

$$\mathbf{x}^* = (A^\top A)^{-1} A^\top \mathbf{b}$$

이것이 **최소제곱법(least squares)**의 정규방정식이다!

</details>

**문제 4**: $\mathbf{z} = BA\mathbf{x}$이고 $L = \|\mathbf{z}\|^2$일 때, $\nabla_\mathbf{x} L$을 구하라.

<details>
<summary>풀이 보기</summary>

Chain Rule + 노름 제곱 공식:

$$\frac{\partial L}{\partial \mathbf{x}} = 2\mathbf{z}^\top \cdot \frac{\partial \mathbf{z}}{\partial \mathbf{x}} = 2(BA\mathbf{x})^\top \cdot BA = 2\mathbf{x}^\top A^\top B^\top BA$$

그래디언트:

$$\nabla_\mathbf{x} L = 2(BA)^\top BA\mathbf{x} = 2A^\top B^\top BA\mathbf{x}$$

</details>

## 3. 최적화 (Optimization)

### 3.1 최적화란? -- 임계점과 극값

#### 일상적 비유

눈을 감고 산속에 서 있다고 상상하자. 목표는 **가장 낮은 골짜기**를 찾는 것이다. 발밑의 경사를 느끼면서 "내리막 방향으로 한 걸음씩" 걸으면 언젠가 골짜기 바닥에 도착한다. 바닥에서는 어느 방향으로 가도 오르막이므로, 경사(기울기)가 0이다. 이렇게 **기울기가 0인 점**을 **임계점(critical point)**이라 한다.

하지만 조심! 산꼭대기도 기울기가 0이다(극대). 말 안장 모양의 점도 기울기가 0이다(안장점). 골짜기 바닥(극소)만 우리가 원하는 답이다.

#### 수식 설명

**임계점**: $f'(x) = 0$인 점 $x$

**극값 판정** (2차 도함수 검사):
- $f'(x_0) = 0$이고 $f''(x_0) > 0$: **극소** (아래로 볼록, 골짜기)
- $f'(x_0) = 0$이고 $f''(x_0) < 0$: **극대** (위로 볼록, 산꼭대기)
- $f'(x_0) = 0$이고 $f''(x_0) = 0$: **판정 불가** (더 분석 필요)

**다변수 확장**: 헤시안(Hessian) 행렬 $H = \nabla^2 f$의 **고유값**으로 판정:
- 모든 고유값 $> 0$: **극소**
- 모든 고유값 $< 0$: **극대**
- 부호 혼합: **안장점(saddle point)**

#### 구체적 계산 예시

$f(x) = x^4 - 2x^2$의 모든 임계점과 극값을 찾아보자.

1단계: 도함수를 구한다.

$$f'(x) = 4x^3 - 4x = 4x(x^2 - 1) = 4x(x-1)(x+1)$$

2단계: $f'(x) = 0$을 풀면 임계점은 $x = 0, +1, -1$

3단계: 2차 도함수로 판정한다.

$$f''(x) = 12x^2 - 4$$

- $x = 0$: $f''(0) = -4 < 0$ $\to$ **극대**, $f(0) = 0$
- $x = 1$: $f''(1) = 8 > 0$ $\to$ **극소**, $f(1) = -1$
- $x = -1$: $f''(-1) = 8 > 0$ $\to$ **극소**, $f(-1) = -1$

#### 딥러닝에서의 활용

딥러닝의 손실 함수는 수백만 차원이다. 고차원 공간에서는 **모든 고유값이 동시에 양수일 확률**이 극도로 낮아서, 극소보다 **안장점**이 훨씬 많다. SGD는 안장점을 빠져나갈 수 있는 노이즈(확률적 기울기)를 갖고 있어 유리하다.

---

### 3.2 제약 최적화 (Constrained Optimization)

#### 일상적 비유

예산 1000원 안에서 가장 맛있는 간식 조합을 고르는 문제이다. "맛"을 최대화하되, "총 가격 $\leq$ 1000원"이라는 **규칙(제약)**을 지켜야 한다.

$$\mathbf{x}^* \in \arg\min_{\boldsymbol{\theta} \in C} f(\mathbf{x})$$

- $f(\mathbf{x})$: 최소화(또는 최대화)하려는 **목적 함수**
- $C$: 허용되는 범위 = **가능 집합(feasible set)**
- $\arg\min$: "최솟값을 달성하는 $\mathbf{x}$의 집합"

#### 수식 설명

제약이 없으면 $f'(x) = 0$만 풀면 된다. 하지만 제약이 있으면 $f'(x) = 0$인 점이 가능 집합 밖에 있을 수 있다. 이때 **라그랑주 승수법**을 사용한다.

---

### 3.3 라그랑주 승수법 (Lagrange Multipliers)

#### 일상적 비유

울타리가 쳐진 놀이터에서 가장 높은 곳을 찾아야 한다. 울타리 안에서 자유롭게 다닐 수 있지만, 울타리 밖으로는 나갈 수 없다.

핵심 통찰: 최적점은 **등고선(목적함수의 레벨선)과 울타리(제약)가 접하는 곳**에 있다. 접한다는 것은 두 곡선의 법선(기울기) 방향이 **같다(평행하다)**는 뜻이다.

$$\nabla f = \lambda \nabla g$$

여기서 $\lambda$는 "울타리가 나를 얼마나 세게 잡고 있는가"를 나타내는 숫자이다.

#### 수식 설명

등식 제약 $g(\mathbf{x}) = 0$ 하에서 $f(\mathbf{x})$를 최소화하는 문제:

**라그랑지안(Lagrangian)**을 정의한다:

$$\mathcal{L}(\mathbf{x}, \lambda) = f(\mathbf{x}) + \lambda \cdot g(\mathbf{x})$$

**풀이 절차**:

1. $\nabla_{\mathbf{x}, \lambda} \mathcal{L} = 0$을 세운다 (모든 변수에 대해 편미분 = 0)
2. 연립방정식을 풀어 후보 해를 구한다
3. 후보 해 중 $f$값이 가장 작은(큰) 것을 선택한다

**주의**: 모든 정지점이 최적해는 아니다. 하지만 최적해는 반드시 정지점 중 하나이다.

#### 구체적 계산 예시

**문제**: 원 $x^2 + y^2 = 1$ 위에서 $f(x, y) = x + y$를 최소화하라.

1단계: 라그랑지안을 세운다.

$$\mathcal{L}(x, y, \lambda) = x + y + \lambda(x^2 + y^2 - 1)$$

2단계: 편미분을 0으로 놓는다.

$$\frac{\partial \mathcal{L}}{\partial x} = 1 + 2\lambda x = 0 \quad \Rightarrow \quad x = -\frac{1}{2\lambda}$$

$$\frac{\partial \mathcal{L}}{\partial y} = 1 + 2\lambda y = 0 \quad \Rightarrow \quad y = -\frac{1}{2\lambda}$$

$$\frac{\partial \mathcal{L}}{\partial \lambda} = x^2 + y^2 - 1 = 0$$

3단계: 연립방정식을 풀면 $x = y$이므로:

$$2x^2 = 1 \quad \Rightarrow \quad x = \pm \frac{\sqrt{2}}{2}$$

해:
- $(x, y) = \left(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2}\right)$: $f = \sqrt{2}$ (최대)
- $(x, y) = \left(-\frac{\sqrt{2}}{2}, -\frac{\sqrt{2}}{2}\right)$: $f = -\sqrt{2}$ (최소)

**기하학적 확인**: 원의 좌하단 점에서 $x + y$가 가장 작다. 직선 $x + y = c$가 원에 접하는 점!

#### 딥러닝에서의 활용

- **Weight Decay**: $\min L(\theta)$ s.t. $\|\theta\|^2 \leq r$은 라그랑주 형태로 $\min L(\theta) + \lambda\|\theta\|^2$이 된다
- **Softmax 유도**: 엔트로피 최대화 + 확률 합 = 1 제약을 라그랑주로 풀면 softmax가 나온다

---

### 3.4 Softmax 유도: 엔트로피 최대화에서 Softmax까지

#### 일상적 비유

주사위가 있다. 각 면에 "점수(에너지)"가 적혀 있다. 가장 공평한(편향 없는) 확률분포를 구하되, 점수가 높은 면이 더 잘 나오도록 하고 싶다. 이 "가장 공평하면서도 점수를 반영한 분포"가 바로 **softmax**이다.

#### 수식 설명 -- 단계별 유도

**목표**: 다음을 최대화하라.

$$f(\mathbf{p}) = \sum_i p_i z_i + \tau H(\mathbf{p})$$

여기서:
- $z_i$: 각 클래스의 점수(로짓)
- $H(\mathbf{p}) = -\sum_i p_i \log p_i$: 엔트로피 (불확실성의 척도)
- $\tau$: 온도(temperature) 매개변수

**제약 조건**: $\sum_i p_i = 1$ (확률의 합은 1)

**풀이**:

1단계: 라그랑지안을 세운다.

$$\mathcal{L}(\mathbf{p}, \lambda) = \sum_i p_i z_i - \tau \sum_i p_i \log p_i + \lambda\left(1 - \sum_i p_i\right)$$

2단계: $p_i$로 편미분 = 0.

$$\frac{\partial \mathcal{L}}{\partial p_i} = z_i - \tau(\log p_i + 1) - \lambda = 0$$

3단계: $p_i$에 대해 정리한다.

$$\log p_i = \frac{z_i - \lambda - \tau}{\tau}$$

$$p_i = \exp\left(\frac{z_i - \lambda - \tau}{\tau}\right) = \frac{1}{Z}\exp\left(\frac{z_i}{\tau}\right)$$

4단계: $\sum_i p_i = 1$ 제약으로 $Z$를 결정한다.

$$Z = \sum_j \exp\left(\frac{z_j}{\tau}\right)$$

**최종 결과**:

$$\boxed{p_i = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}}$$

이것이 바로 **온도 $\tau$를 가진 softmax 함수**이다.

#### 온도 $\tau$의 역할

- $\tau \to 0$: 가장 큰 $z_i$에 확률 1을 몰아준다 (argmax처럼 동작)
- $\tau = 1$: 표준 softmax
- $\tau \to \infty$: 모든 클래스에 균등한 확률 (uniform distribution)

#### 구체적 계산 예시

로짓 $\mathbf{z} = [2, 1, 0]$, 온도 $\tau = 1$:

$$p_1 = \frac{e^2}{e^2 + e^1 + e^0} = \frac{7.389}{7.389 + 2.718 + 1} = \frac{7.389}{11.107} \approx 0.665$$

$$p_2 = \frac{e^1}{11.107} = \frac{2.718}{11.107} \approx 0.245$$

$$p_3 = \frac{e^0}{11.107} = \frac{1}{11.107} \approx 0.090$$

확인: $0.665 + 0.245 + 0.090 = 1.000$ (확률 합 = 1)

#### 딥러닝에서의 활용

- 분류 문제의 출력층에서 로짓을 확률로 변환
- **Knowledge Distillation**: 높은 온도로 soft label을 생성하여 작은 모델에게 "어두운 지식"을 전달
- **LLM 텍스트 생성**: 온도를 조절하여 창의성 수준을 제어

### 3.5 연습 문제

**문제 1**: $f(x) = x^3 - 3x + 1$에서 $x \in [-1.5, 3]$ 범위의 극값을 모두 구하라.

<details>
<summary>풀이 보기</summary>

$f'(x) = 3x^2 - 3 = 3(x-1)(x+1) = 0$ $\Rightarrow$ $x = \pm 1$

$f''(x) = 6x$
- $x = 1$: $f''(1) = 6 > 0$ $\to$ 극소, $f(1) = -1$
- $x = -1$: $f''(-1) = -6 < 0$ $\to$ 극대, $f(-1) = 3$

경계점 확인:
- $f(-1.5) = -3.375 + 4.5 + 1 = 2.125$
- $f(3) = 27 - 9 + 1 = 19$

전체 최솟값: $f(1) = -1$, 전체 최댓값: $f(3) = 19$

</details>

**문제 2**: $x^2 + y^2 = 3$ 위에서 $f(x,y) = x^2 y$를 최소화/최대화하라.

<details>
<summary>풀이 보기</summary>

$\mathcal{L} = x^2 y + \lambda(x^2 + y^2 - 3)$

$$\begin{cases} 2xy + 2\lambda x = 0 \\ x^2 + 2\lambda y = 0 \\ x^2 + y^2 = 3 \end{cases}$$

첫째 식에서: $2x(y + \lambda) = 0$ $\Rightarrow$ $x = 0$ 또는 $\lambda = -y$

**경우 1** ($x = 0$): $y^2 = 3$ $\Rightarrow$ $y = \pm\sqrt{3}$, $f = 0$

**경우 2** ($\lambda = -y$): 둘째 식에서 $x^2 - 2y^2 = 0$ $\Rightarrow$ $x^2 = 2y^2$
$3y^2 = 3$ $\Rightarrow$ $y = \pm 1$, $x = \pm\sqrt{2}$

- $f(\pm\sqrt{2}, 1) = 2 \cdot 1 = 2$ (최대)
- $f(\pm\sqrt{2}, -1) = 2 \cdot (-1) = -2$ (최소)

</details>

**문제 3**: "확률 합 = 1" 제약 하에서 엔트로피 $H(\mathbf{p}) = -\sum_i p_i \log p_i$를 최대화하면 어떤 분포가 나오는지 유도하라. ($n$개의 클래스)

<details>
<summary>풀이 보기</summary>

$\mathcal{L} = -\sum_i p_i \log p_i + \lambda(\sum_i p_i - 1)$

$$\frac{\partial \mathcal{L}}{\partial p_i} = -\log p_i - 1 + \lambda = 0$$

$$p_i = e^{\lambda - 1}$$

모든 $i$에 대해 $p_i$가 같으므로: $np_i = 1$ $\Rightarrow$ $p_i = \frac{1}{n}$

**균등분포(uniform distribution)**가 엔트로피를 최대화한다.

</details>

**문제 4**: $\mathbf{z} = [3, 1, -1]$일 때 softmax 확률을 계산하라 ($\tau = 1$).

<details>
<summary>풀이 보기</summary>

$$p_1 = \frac{e^3}{e^3 + e^1 + e^{-1}} = \frac{20.086}{20.086 + 2.718 + 0.368} = \frac{20.086}{23.172} \approx 0.867$$

$$p_2 = \frac{2.718}{23.172} \approx 0.117$$

$$p_3 = \frac{0.368}{23.172} \approx 0.016$$

가장 큰 로짓($z_1 = 3$)이 86.7%의 확률을 차지한다.

</details>

## 4. 동역학계와 미분방정식 (ODE)

### 4.1 미분방정식이란? -- 변화율의 법칙

#### 일상적 비유

물병에 구멍이 뚫려 있어서 물이 빠지고 있다. 물이 많이 남아 있으면 수압이 세서 물이 빨리 빠지고, 물이 적으면 천천히 빠진다.

"물이 빠지는 속도(변화율) = 남은 물의 양에 비례"

이 규칙을 수식으로 쓰면:

$$x' = -ax \quad (a > 0)$$

- $x$: 남은 물의 양
- $x'$: 물이 변하는 속도 (빠지니까 음수)
- $-a$: 비례 상수

이것이 **미분방정식(ODE: Ordinary Differential Equation)**이다. "현재 상태($x$)가 변화율($x'$)을 결정한다"는 법칙.

#### 수식 설명

**기본 형태**: $x' = f(x)$ 또는 $\frac{dx}{dt} = f(x)$

- $x(t)$: 시간 $t$에서의 상태
- $x' = \frac{dx}{dt}$: 상태의 변화율 (시간에 대한 도함수)
- $f(x)$: 변화율을 결정하는 함수

**가장 단순한 경우**: $x' = f(t)$ ($x$에 의존하지 않고 시간에만 의존)

$$x(t) = \int f(t) \, dt + C = x(0) + \int_0^t f(s) \, ds$$

#### 구체적 계산 예시

$x' = 3$ (일정한 속도로 증가)

$$x(t) = x(0) + 3t$$

$x(0) = 5$이면: $x(1) = 8$, $x(2) = 11$, $x(3) = 14$, ...

이것은 등속 운동이다.

#### 딥러닝에서의 활용

**ResNet의 잔차 연결**이 ODE의 이산화(오일러 방법)와 같다:

$$\mathbf{h}_{l+1} = \mathbf{h}_l + f_\theta(\mathbf{h}_l) \quad \leftrightarrow \quad x(t + \Delta t) = x(t) + f(x(t)) \Delta t$$

이 관찰에서 **Neural ODE** (2018, Chen et al.)가 탄생했다.

---

### 4.2 선형 ODE: 지수적 해

#### 일상적 비유

**복리 이자**가 대표적인 예이다. 은행에 100만원을 넣고 연 5% 복리를 받으면:
- 1년 후: $100 \times 1.05 = 105$만원
- 2년 후: $105 \times 1.05 = 110.25$만원
- 돈이 많을수록 이자가 많이 붙고, 이자가 붙은 돈에 또 이자가 붙는다

연속 복리로 극한을 취하면 $x(t) = x(0) e^{at}$가 된다.

#### 수식 설명

**$x' = ax$의 풀이** (변수분리법):

$$\frac{dx}{x} = a \, dt$$

양변을 적분한다:

$$\int \frac{dx}{x} = \int a \, dt$$

$$\ln|x| = at + C$$

$$x(t) = x(0) e^{at}$$

**$a$의 부호에 따른 해의 행동**:
- $a > 0$: **지수 성장** (폭발적으로 커짐)
- $a < 0$: **지수 감쇠** (0으로 수렴)
- $a = 0$: $x(t) = x(0)$ (변화 없음)

**$x' = ax + b$의 풀이**:

$$x(t) = \left(x(0) + \frac{b}{a}\right) e^{at} - \frac{b}{a}$$

평형점: $x^* = -\frac{b}{a}$ ($x' = 0$이 되는 점)

#### 구체적 계산 예시

**예시 1**: $x' = 2x$, $x(0) = 3$

$$x(t) = 3e^{2t}$$

- $t = 0$: $x = 3$
- $t = 1$: $x = 3e^2 \approx 22.17$
- $t = 2$: $x = 3e^4 \approx 163.79$

$\to$ 폭발적으로 성장!

**예시 2**: $x' = -0.5x$, $x(0) = 10$

$$x(t) = 10e^{-0.5t}$$

- $t = 0$: $x = 10$
- $t = 2$: $x = 10e^{-1} \approx 3.68$
- $t = 4$: $x = 10e^{-2} \approx 1.35$
- $t \to \infty$: $x \to 0$

$\to$ 0으로 부드럽게 감소!

#### 딥러닝에서의 활용

**Gradient Flow**: 2차 손실 $L(\theta) = \frac{a}{2}\theta^2$에서 연속 경사 하강법:

$$\dot{\theta} = -\nabla L = -a\theta$$

해: $\theta(t) = \theta(0) e^{-at}$

$a > 0$이면 가중치가 지수적으로 0에 수렴 $\to$ **학습이 수렴한다!**

이것이 경사 하강법이 작동하는 수학적 근거이다.

### 4.3 시그모이드 곡선이 ODE에서 나오는 과정

#### 일상적 비유

호수에 물고기가 살고 있다. 처음에는 물고기가 적고 먹이가 풍부해서 **빠르게 번식**한다. 하지만 물고기가 많아지면 먹이가 부족해져서 **성장이 둔화**된다. 결국 호수가 수용할 수 있는 **최대 수**에서 안정된다.

이 과정을 그래프로 그리면 **S자 곡선(시그모이드)**이 나온다. 누군가 인위적으로 설계한 것이 아니라, **자연의 포화 현상**을 수학적으로 풀면 나오는 함수이다.

#### 수식 설명 -- 로지스틱 방정식

$$x' = ax(1 - x)$$

이 방정식의 의미를 분해해보자:
- $x$: 현재 개체 비율 (0에서 1 사이)
- $ax$: 현재 개체수에 비례하는 성장 (물고기가 많을수록 새끼가 많다)
- $(1 - x)$: 남은 자원에 비례하는 억제 (1에 가까워질수록 성장이 멈춘다)
- $x' = ax(1 - x)$: 성장과 억제가 동시에 작용

**평형점**: $x' = 0$이 되는 점
- $x = 0$: 물고기가 없으면 번식할 수 없다 (불안정)
- $x = 1$: 호수가 가득 차면 더 이상 늘지 않는다 (안정)

#### 풀이 과정 (변수분리법 + 부분분수)

$$\frac{dx}{x(1 - x)} = a \, dt$$

부분분수 분해:

$$\frac{1}{x(1-x)} = \frac{1}{x} + \frac{1}{1-x}$$

양변을 적분한다:

$$\ln|x| - \ln|1 - x| = at + C$$

$$\ln\left|\frac{x}{1-x}\right| = at + C$$

$$\frac{x}{1-x} = e^{at+C}$$

$x$에 대해 정리한다:

$$\boxed{x(t) = \frac{1}{1 + Ce^{-at}}} \quad \text{where } C = \frac{1 - x(0)}{x(0)}$$

#### 구체적 계산 예시

$a = 1$, $x(0) = 0.01$ (초기 개체 비율 1%):

$C = \frac{1 - 0.01}{0.01} = 99$

$$x(t) = \frac{1}{1 + 99e^{-t}}$$

| $t$ | $x(t)$ | 해석 |
|---|---|---|
| 0 | 0.01 | 시작 (1%) |
| 2 | 0.069 | 아직 느림 |
| $\ln(99) \approx 4.6$ | 0.50 | **반감점** (가장 빠른 성장) |
| 7 | 0.917 | 거의 포화 |
| 10 | 0.993 | 사실상 포화 |

이 함수의 그래프가 바로 **시그모이드(sigmoid) 곡선**이다!

표준 시그모이드 함수 $\sigma(z) = \frac{1}{1 + e^{-z}}$는 $a = 1$, $x(0) = 0.5$ ($C = 1$)인 경우이다.

#### 반감 시간 (Half-time)

$x = 0.5$가 되는 시간:

$$t_{1/2} = \frac{\ln C}{a} = \frac{\ln(1/x_0 - 1)}{a} \approx \frac{\ln(1/x_0)}{a}$$

초기값 $x_0$가 작을수록 반감 시간이 길다.

#### 딥러닝에서의 활용

1. **시그모이드 활성화 함수**: 로지스틱 방정식의 해. 출력을 0~1 사이로 압축하여 확률로 해석
2. **Vanishing Gradient 이해**: 시그모이드의 도함수 $\sigma'(z) = \sigma(z)(1-\sigma(z))$는 최대 0.25. 레이어를 거칠 때마다 기울기가 $\frac{1}{4}$로 줄어들어 깊은 네트워크에서 학습이 어려워진다
3. **로지스틱 회귀**: 이진 분류 모델의 출력층에 시그모이드를 사용하여 확률을 출력

### 4.4 다양한 ODE 유형 요약

#### 핵심 분류표

| 방정식 | 우변의 근 개수 | 해의 유형 | 비유 |
|---|---|---|---|
| $x' = a$ | 근 없음 | 선형 성장 | 일정 속도로 걷기 |
| $x' = ax$ | 1개 ($x=0$) | 지수 성장/감쇠 | 복리 이자 |
| $x' = x^2$ | 1개 ($x=0$) | 쌍곡 성장 (유한 시간 폭발!) | 통제 불능 소문 |
| $x' = ax(1-x)$ | 2개 ($x=0, 1$) | 시그모이드 (포화) | 호수의 물고기 |

**핵심 통찰**: 우변이 $x$의 **2차 함수**이고 **서로 다른 두 근**을 가지면, 해는 항상 **시그모이드 형태**이다.

#### 쌍곡 성장 ($x' = x^2$)에 대한 경고

$$x(t) = \frac{1}{1/x_0 - t}$$

$t = 1/x_0$에서 $x \to \infty$: **유한 시간 안에 폭발!**

$x_0 = 0.1$이면 $t = 10$에서 폭발한다.

지수 성장은 무한한 시간 동안 점점 커지지만, 쌍곡 성장은 **정해진 시간 안에 무한대에 도달**한다. 이것이 gradient explosion의 극단적 형태와 관련된다.

#### 안정성 이론 (Stability)

시스템 $\dot{X} = AX$에서:
- $\det(A) < 0$: **안장점** (불안정)
- $\det(A) \geq 0$이고 $\text{tr}(A) < 0$: **안정** (수렴)
- $\det(A) \geq 0$이고 $\text{tr}(A) > 0$: **불안정** (발산)

**비유**: 그릇 안에 구슬을 놓으면 바닥으로 굴러간다 (안정). 그릇을 뒤집어 놓으면 구슬이 떨어진다 (불안정).

### 4.5 연습 문제

**문제 1**: $x' = 3x$, $x(0) = 2$의 해를 구하고, $t = 2$에서의 값을 계산하라.

<details>
<summary>풀이 보기</summary>

$$x(t) = 2e^{3t}$$

$t = 2$: $x(2) = 2e^6 \approx 2 \times 403.43 = 806.86$

</details>

**문제 2**: $x' = -2x + 6$, $x(0) = 0$의 해를 구하고, 평형점을 찾아라.

<details>
<summary>풀이 보기</summary>

공식 $x(t) = (x(0) + b/a)e^{at} - b/a$에서 $a = -2$, $b = 6$:

$$x(t) = (0 + 6/(-2))e^{-2t} - 6/(-2) = -3e^{-2t} + 3 = 3(1 - e^{-2t})$$

평형점: $x^* = -b/a = -6/(-2) = 3$

$t \to \infty$이면 $x \to 3$ (안정 평형점으로 수렴)

</details>

**문제 3**: 로지스틱 방정식 $x' = 2x(1-x)$, $x(0) = 0.1$에서 $x = 0.5$가 되는 시간을 구하라.

<details>
<summary>풀이 보기</summary>

$a = 2$, $C = (1 - 0.1)/0.1 = 9$

반감 시간:

$$t_{1/2} = \frac{\ln C}{a} = \frac{\ln 9}{2} = \frac{2.197}{2} \approx 1.099$$

약 $t = 1.1$에서 절반에 도달한다.

</details>

**문제 4**: $x' = x^2$, $x(0) = 0.5$에서 폭발 시간은?

<details>
<summary>풀이 보기</summary>

폭발 시간: $t^* = \frac{1}{x_0} = \frac{1}{0.5} = 2$

$t = 2$에서 $x \to \infty$. 지수 성장과 달리 유한 시간 안에 발산한다!

검증: $x(t) = \frac{1}{2 - t}$
- $t = 0$: $x = 0.5$
- $t = 1$: $x = 1$
- $t = 1.5$: $x = 2$
- $t = 1.9$: $x = 10$
- $t = 1.99$: $x = 100$
- $t \to 2$: $x \to \infty$

</details>

**문제 5** (종합): 시그모이드 함수 $\sigma(z) = \frac{1}{1 + e^{-z}}$가 어떤 ODE의 해인지 보여라.

<details>
<summary>풀이 보기</summary>

$\sigma(z)$를 $z$에 대해 미분하자:

$$\sigma'(z) = \frac{e^{-z}}{(1 + e^{-z})^2} = \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}}$$

$$= \sigma(z) \cdot (1 - \sigma(z))$$

$x = \sigma(z)$로 놓으면:

$$\frac{dx}{dz} = x(1 - x)$$

이것이 바로 **로지스틱 방정식** $x' = x(1-x)$ ($a = 1$)이다!

시그모이드 함수는 로지스틱 ODE의 해이다.

</details>

### 미분 기본

| 공식 | 설명 |
|---|---|
| $(x^n)' = nx^{n-1}$ | 멱함수 미분 |
| $(e^x)' = e^x$ | 지수함수 미분 |
| $(\ln x)' = 1/x$ | 로그함수 미분 |
| $(f \circ g)' = f'(g(x)) \cdot g'(x)$ | Chain Rule |
| $(fg)' = f'g + fg'$ | Product Rule |

### 행렬 미적분

| 공식 | 결과 |
|---|---|
| $\partial(\mathbf{a}^\top \mathbf{x})/\partial \mathbf{x}$ | $\mathbf{a}^\top$ |
| $\partial(A\mathbf{x})/\partial \mathbf{x}$ | $A$ |
| $\partial\|\mathbf{x}\|^2/\partial \mathbf{x}$ | $2\mathbf{x}^\top$ |
| $\partial\|f(\mathbf{x})\|^2/\partial \mathbf{x}$ | $2f(\mathbf{x})^\top \cdot \partial f/\partial \mathbf{x}$ |
| $\partial(BA\mathbf{x})/\partial \mathbf{x}$ | $BA$ |

### 최적화

| 개념 | 공식/조건 |
|---|---|
| 임계점 | $f'(x) = 0$ |
| 라그랑지안 | $\mathcal{L} = f(\mathbf{x}) + \lambda g(\mathbf{x})$ |
| Softmax | $p_i = \exp(z_i/\tau) / \sum_j \exp(z_j/\tau)$ |

### ODE

| 방정식 | 해 |
|---|---|
| $x' = ax$ | $x(t) = x(0)e^{at}$ |
| $x' = ax + b$ | $x(t) = (x(0) + b/a)e^{at} - b/a$ |
| $x' = x^2$ | $x(t) = 1/(1/x_0 - t)$ (폭발: $t^* = 1/x_0$) |
| $x' = ax(1-x)$ | $x(t) = 1/(1 + Ce^{-at})$ (시그모이드) |
