# 05. 시험장 시간 배분 + 부분점수 전술

## 1. 시험 시작 후 처음 5분 — **읽기**

문제지 받자마자:
1. **모든 문제를 한 번 훑기** (5분)
2. 각 문제의 난이도 표시 (★ 쉬움, ★★ 보통, ★★★ 어려움)
3. 시간 배분 결정

---

## 2. 시간 배분 (60분 시험 가정)

| 단계 | 시간 | 작업 |
|------|------|-----|
| 1 | 0~5분 | 전체 문제 훑기 |
| 2 | 5~10분 | 가장 쉬운 문제부터 (예: 기출 3 균일분포) |
| 3 | 10~25분 | 중간 난이도 (예: 기출 1, 2, 8) |
| 4 | 25~50분 | 핵심 문제 (예: 기출 4 MLE, 5, 6 MAP) |
| 5 | 50~55분 | 어려운 문제 (예: 기출 7 텐트) |
| 6 | 55~60분 | **검토** + 빠진 부분 채우기 |

**원칙:** 한 문제에 8분 이상 쓰지 않기. 막히면 다음.

## 3. 부분점수 사냥 전술

답을 못 풀어도 **단계별 점수**가 살아있음.

### 전술 1: 정의 1줄 = 5~15%
모든 문제 시작에 정의 적기:
- 고유값: $A\mathbf{v} = \lambda\mathbf{v}$
- 기댓값: $E[X] = \int x p(x) dx$
- 우도: $L(\theta) = p(D|\theta)$

### 전술 2: 가정 명시 = 10~15%
- "i.i.d 가정 하에"
- "$\theta \in (0,1)$ 내부"
- "미분 가능 가정"

### 전술 3: 핵심 정리 인용 = 10~20%
- "페르마 정리에 의해 $\ell'(\theta) = 0$"
- "베이즈 정리: posterior ∝ likelihood × prior"
- "Jensen 부등식으로 KL ≥ 0"

### 전술 4: 풀이 단계마다 점수 = 부분점수
- 미분 식 (정확하지 않아도 형태)
- 방정식 정리
- 결과 형태

### 전술 5: 막혔을 때 — "직관"이라도
어려운 문제에서 풀이 막히면, **직관/예측**이라도 적기:
- "m → ∞이면 prior가 우세해 데이터 무시"
- "MLE는 표본 비율로 자연스럽다"

→ 이런 한 줄도 5% 가산.

---

## 4. 막혔을 때 응급처치

### 상황 A: "어떻게 시작할지 모르겠다"
**처방:** 정의를 적어라. 그 다음 단계가 자연스럽게 떠오름.

### 상황 B: "미분이 복잡해서 못 풀겠다"
**처방:** 미분 식을 정확히 적기만이라도 — 부분점수 살아남.

### 상황 C: "텐트 문제 (기출 7) 막혔다"
**처방:**
1. 절댓값 → 영역 분리 (점수 +20%)
2. 정의역 명시 (예: m=6 → [1/3, 2/3]) (+10%)
3. 단조성/극값 후보 분석 (+10%)
4. 정확한 답 못 적어도 50% 확보 가능

### 상황 D: "시간이 부족하다"
**처방 (마지막 5분):**
1. 모든 문제에 **답 박스**라도 채우기 (예측이라도)
2. 빠진 정의나 가정 보충
3. 스펠링/계산 오류 수정

## 5. 답안 작성 미학

### 글씨
- 깔끔하게. 채점관이 못 읽으면 -점수.

### 식 정렬
- 등호 줄 맞추기:
  ```
  L(θ) = ∏ θ^y_i (1-θ)^(1-y_i)
       = θ^k (1-θ)^(n-k)
  ```

### 박스
- 최종 답은 **박스**로 강조:
  ```
  ┌────────────────┐
  │ θ̂_MLE = k/n  │
  └────────────────┘
  ```

### 단계 번호
- (1), (2), (3) 또는 i, ii, iii 로 단계 명시.
