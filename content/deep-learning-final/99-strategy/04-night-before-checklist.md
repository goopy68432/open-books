# 04. 시험 전날 30분 체크리스트

## ⏱ 30분 점검표

새로운 거 공부 X. **외운 거 점검만**.

### Phase 1: 7단계 체인 (5분)
- [ ] 정의 → 가정 → 조작 → 정리 → 결과 → 검증 → 직관 (소리내어)

### Phase 2: 5대 표준 문장 (5분)
- [ ] "i.i.d 가정에서 결합확률은 곱이다."
- [ ] "로그는 단조증가이므로 argmax 보존, 곱→합으로 미분 단순, underflow 방지."
- [ ] "ℓ은 (0,1) 내부에서 미분 가능하므로 페르마 정리에 의해 ℓ'(θ)=0이 극값 조건."
- [ ] "2계 미분이 음수이므로 ℓ은 오목, 임계점이 최댓값."
- [ ] "베이즈 정리: posterior ∝ likelihood × prior."

### Phase 3: 기출 핵심 답 (10분)
- [ ] 기출 1: λ = ±1, $\mathbf{v}_{1,2} = (1, ±1)/\sqrt{2}$
- [ ] 기출 2: $E[X^k] = (k-1)!!$ (짝수), 0 (홀수)
- [ ] 기출 3: $E[X] = (a+b)/2$, $\text{Var} = (b-a)^2/12$
- [ ] 기출 4: $L = \theta^k(1-\theta)^{n-k}$, MLE = $k/n$
- [ ] 기출 5: MAP = $(k+m)/(n+2m)$, $m \to \infty$이면 1/2
- [ ] 기출 6: MAP = $(k+m)/(n+m)$, $m \to \infty$이면 1
- [ ] 기출 7: m=2 → 2/3, m=6 → 1/2 (텐트, 영역 분리)
- [ ] 기출 8: $J = \text{diag}(\mathbf{p}) - \mathbf{pp}^T$, $\partial p_i/\partial z_j = p_i(\delta_{ij} - p_j)$

### Phase 4: 가우스 적분 5단계 (5분)
- [ ] $I^2$ → 이중적분 → 극좌표 → $r$ 적분 1 → $\phi$ 적분 $2\pi$ → $I = \sqrt{2\pi}$

### Phase 5: 답안 작성 5가지 패턴 (5분)
- [ ] 정의로 시작
- [ ] i.i.d 곱 정당화
- [ ] 로그 3대 이유
- [ ] 페르마 인용
- [ ] 검증 한 줄

```

DEEP LEARNING THEORY — CHEAT CARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7단계: 정의→가정→조작→정리→결과→검증→직관

i.i.d → ∏          ← 독립 = 곱
log:               ① 곱→합 ② argmax 보존 ③ 수치안정
미분=0:            페르마 정리 (내부 미분가능 극값)
2계 미분 < 0:      오목 → 전역 최댓값
베이즈:            posterior ∝ likelihood × prior

가우스 적분: I² 극좌표 r dr dφ → 2π → √(2π)
가우스 모멘트: E[X^(2n)] = (2n-1)!!, 홀수 0

베르누이 MLE: L = θ^k(1-θ)^(n-k), θ̂ = k/n
정규 MLE (μ): μ̂ = x̄
지수 MLE (λ): λ̂ = 1/x̄
포아송 MLE (λ): λ̂ = x̄

MAP: posterior 미분=0
  prior θ^m(1-θ)^m → (k+m)/(n+2m), m→∞ : 1/2
  prior θ^m → (k+m)/(n+m), m→∞ : 1

Softmax 미분: ∂p_i/∂z_j = p_i(δ_ij - p_j)
              J = diag(p) - pp^T

CE+Softmax 그래디언트: p - y (예측-정답)

대칭행렬 → 실수 고유값 + 직교 고유벡터 (스펙트럴)
KL ≥ 0 (Jensen)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
