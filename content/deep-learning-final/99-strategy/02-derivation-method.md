# 02. 유도 체인 작성 7단계 템플릿

> 모든 풀이를 이 템플릿에 따라 작성하면 만점.

## 7단계 템플릿

```
(1) 정의/모델 명시         ← 출발점
(2) 가정 명시              ← i.i.d, 미분 가능, 도메인
(3) 조작 (곱, 로그, 미분)   ← 각 조작마다 "왜?"
(4) 보조정리 인용           ← 페르마, 베이즈, Jensen 등
(5) 결과 도출               ← 풀이 결론
(6) 검증                    ← 2계 미분, 경계, 일관성
(7) 직관 한 줄              ← 보너스
```

## 적용 예 — 베르누이 MLE

### (1) 정의/모델
> $y_i \sim \text{Bern}(\theta)$ i.i.d, $i = 1, \ldots, n$.
> 단일 pmf: $p(y_i|\theta) = \theta^{y_i}(1-\theta)^{1-y_i}$.

### (2) 가정
> i.i.d (독립 + 동일분포), $\theta \in (0, 1)$.

### (3) 조작
> i.i.d 가정으로 결합확률은 곱: $L = \prod p(y_i|\theta) = \theta^k(1-\theta)^{n-k}$.
> 로그를 취해 곱→합: $\ell = k\log\theta + (n-k)\log(1-\theta)$.
> (이유: 미분 단순화, argmax 보존, underflow 방지)

### (4) 정리 인용
> $\theta \in (0,1)$ 내부에서 ℓ 미분 가능. 페르마 정리에 의해 $\ell'(\theta) = 0$이 극값 조건.

### (5) 결과
> $\ell'(\theta) = k/\theta - (n-k)/(1-\theta) = 0 \Rightarrow \hat{\theta}_{\text{MLE}} = k/n$.

### (6) 검증
> $\ell''(\theta) = -k/\theta^2 - (n-k)/(1-\theta)^2 < 0$. ℓ은 오목, 임계점은 전역 최댓값.

### (7) 직관
> $k/n$은 표본 비율로, MLE의 결과가 데이터의 자연스러운 요약과 일치.

## 적용 예 — 가우스 모멘트 E(X²)

### (1) 정의
> $X \sim N(0,1)$, pdf $p(x) = e^{-x^2/2}/\sqrt{2\pi}$.
> 기댓값 LOTUS: $E[X^k] = \int x^k p(x)\,dx$.

### (2) 가정
> 적분 가능 (지수 감쇠로 보장).

### (3) 조작
> $E[X^2] = \int x^2 e^{-x^2/2}/\sqrt{2\pi}\,dx$.
> 부분적분 $u = x$, $dv = x e^{-x^2/2}\,dx$, $v = -e^{-x^2/2}$.

### (4) 정리 인용
> 가우스 적분 $\int e^{-x^2/2}\,dx = \sqrt{2\pi}$ (보조정리).

### (5) 결과
> $\int x^2 e^{-x^2/2}\,dx = [-xe^{-x^2/2}]_{-\infty}^\infty + \int e^{-x^2/2}\,dx = 0 + \sqrt{2\pi}$.
> $E[X^2] = \sqrt{2\pi}/\sqrt{2\pi} = 1$.

### (6) 검증
> $X \sim N(0,1)$이면 $\text{Var}[X] = 1$, $E[X] = 0$, $\text{Var} = E[X^2] - E[X]^2 = 1$. ✓

### (7) 직관
> 표준정규의 분산 = 1이라는 정의와 일관.

## 7단계 활용 가이드

### 시간 배분 (한 문제 5분)

| 시간 | 단계 |
|------|-----|
| 0:00 ~ 0:30 | (1), (2) |
| 0:30 ~ 3:30 | (3), (4), (5) |
| 3:30 ~ 4:30 | (6) |
| 4:30 ~ 5:00 | (7) |

### 외워야 할 7단계 키워드

> **정의 → 가정 → 조작 → 정리 → 결과 → 검증 → 직관**

이 7단어를 외우고, 시험장에서 하나씩 떠올리며 답안 작성.
