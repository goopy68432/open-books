# 08. 지수와 로그 — 곱을 합으로 바꾸는 마법

> 우도함수에 로그 취하는 이유, softmax의 e^z, MAP의 prior — 모두 지수·로그.

---

## 1. 왜 배우나

- 기출 4-7번: $\log L(\theta)$ — **이걸 안 하면 미분이 지옥**
- 기출 8번: softmax = $e^{z_i} / \sum e^{z_j}$
- 기출 2번: 가우스분포 $e^{-x^2/2}$

## 2. 지수함수 $e^x$

### e의 정의
$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n \approx 2.718281828\ldots$$

### 성질

| 성질 | 식 |
|------|-----|
| 곱 | $e^a \cdot e^b = e^{a+b}$ |
| 나눗셈 | $e^a / e^b = e^{a-b}$ |
| 거듭제곱 | $(e^a)^b = e^{ab}$ |
| $e^0$ | 1 |
| 미분 | $(e^x)' = e^x$ (자기 자신!) |
| 적분 | $\int e^x dx = e^x + C$ |

### 그래프

- 항상 양수 ($e^x > 0$)
- 단조증가 (값이 항상 늘어남)
- $x \to -\infty$일 때 $e^x \to 0$
- $x \to +\infty$일 때 $e^x \to \infty$

---

## 3. 로그함수 $\log x$ (자연로그 $\ln x$)

이 노트에서는 $\log = \log_e = \ln$ (자연로그)으로 통일. 시험도 동일.

### 정의
$$\log x = y \iff e^y = x$$

(지수함수의 역함수)

### 핵심 성질 (외워라!)

| 성질 | 식 |
|------|-----|
| **곱→합** | $\log(ab) = \log a + \log b$ |
| **나눗셈→차** | $\log(a/b) = \log a - \log b$ |
| **거듭제곱→곱** | $\log(a^b) = b \log a$ |
| $\log 1$ | 0 |
| $\log e$ | 1 |
| 미분 | $(\log x)' = 1/x$ |
| 적분 | $\int \log x\,dx = x \log x - x + C$ |

### 정의역
$\log x$는 $x > 0$에서만 정의됨. 음수의 로그는 없음 (실수 범위에서).

---

## 4. **왜 우도에 로그를 취하는가** — 시험 단골 질문

> "i.i.d 독립 가정으로 우도함수가 곱이 됩니다. 곱은 미분이 어렵습니다 (곱셈 규칙 반복). **로그**를 취하면 곱이 합이 되어 미분이 쉬워집니다. 또 로그는 **단조증가** 함수이므로 $L$의 최댓값과 $\log L$의 최댓값이 같은 곳에서 일어납니다 ($\arg\max L = \arg\max \log L$). 추가로 곱은 0에 가까워지면 컴퓨터에서 underflow가 나기 쉬우나 로그를 취하면 안전합니다."

이 한 문장이 **35% 출제** 핵심 체인의 절반.

### 구체 예시 (베르누이)

원래 우도:
$$L(\theta) = \prod_{i=1}^n \theta^{y_i}(1-\theta)^{1-y_i}$$

곱이라 미분 끔찍. 로그:

$$\log L = \sum_i [y_i \log\theta + (1-y_i)\log(1-\theta)]$$
$$= k \log\theta + (n-k)\log(1-\theta), \quad k = \sum y_i$$

**합으로 변환** → 미분 쉬움 → MLE 풀이 가능.

---

## 5. 자주 보는 지수·로그 패턴

### 패턴 1: 거듭제곱의 로그
$$\log(\theta^k(1-\theta)^{n-k}) = k\log\theta + (n-k)\log(1-\theta)$$

(기출 4번 그대로)

### 패턴 2: $e^{\log a} = a$ (지수와 로그는 역연산)

### 패턴 3: $\log(e^a) = a$

### 패턴 4: softmax 안의 지수 (기출 8번)
$$p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$
- 분자, 분모 모두 양수 ($e^{z} > 0$)
- 합이 1 ($\sum_i p_i = 1$)
- 음수 $z$도 OK (지수가 양수로 만듦)

### 패턴 5: 가우스분포 안의 지수 (기출 2번)
$$\frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

---

## 6. 로그 미분의 마법

함수 $f$가 곱으로 표현될 때, **로그 미분법**:

$$\frac{f'}{f} = \frac{d}{dx}\log f$$

기출 응용: NLL을 풀 때 $\log L$의 미분 = $L'/L$ (score function)

---

## 7. 스털링 근사 (Stirling) — 알아두면 유리

$$n! \approx \sqrt{2\pi n} \left(\frac{n}{e}\right)^n$$

(시험 직접 출제는 드물지만, 가우스 적분의 응용 등에 등장)

---

## 8. 다리 놓기

| 중학교 | 대학 |
|-------|------|
| $2^3 = 8$, $\log_2 8 = 3$ | $e^x$, $\log x$ ($\log_e$) |
| $\log(ab) = \log a + \log b$ (밑은 10이나 2) | 동일하지만 $e$ 사용 |
| (배운 적 없음) | $(e^x)' = e^x$, $(\log x)' = 1/x$ |
| (배운 적 없음) | "곱→합" 변환의 의의 |

---

## 9. 시험 답안 작성법

### "왜 로그?" 표준 문장

답안에 **반드시** 한 문장:
> "i.i.d 가정에서 우도는 곱 형태이다. 미분과 수치안정성을 위해 로그를 취하며, 로그는 단조증가이므로 $\arg\max$가 보존된다."

### 계산 시 자주 쓰는 변환

- $\log(\theta^k) = k \log \theta$
- $\log(1) = 0$ (정규화 상수 사라짐)
- $e^{\log x} = x$
