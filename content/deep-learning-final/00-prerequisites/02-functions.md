# 02. 함수 — 입력과 출력의 약속

> "L(θ)는 θ에 대한 함수다" — 이 한 줄을 이해해야 MLE를 풀 수 있습니다.

---

## 1. 왜 배우나

- 기출 4번의 **우도함수** $L(\theta)$ — θ가 입력, 우도가 출력인 함수
- 기출 8번의 **softmax** $\mathbf{p} = \text{softmax}(\mathbf{z})$ — z 벡터가 입력, p 벡터가 출력
- **합성함수**가 미분에 결정적 — `04-chain-rule.md`에서 활용

---

## 2. 중학교에서 배운 것

$y = f(x)$, 예를 들어 $f(x) = 2x + 3$
- x = 1을 넣으면 y = 5
- x = 2를 넣으면 y = 7

**핵심:** 함수 = "입력을 받아 출력을 만드는 기계"

---

## 3. 대학에서는 이렇게 본다

함수는 다음 4가지로 구분됩니다.

### ① 단변수 함수 $f: \mathbb{R} \to \mathbb{R}$

입력 1개, 출력 1개.

예: $f(x) = x^2$, $f(x) = e^x$, $f(x) = \log x$

### ② 다변수 함수 $f: \mathbb{R}^n \to \mathbb{R}$

입력 여러 개, 출력 1개.

예: $f(x, y) = x^2 + y^2$ — 두 입력의 제곱합

**기출 4번 우도함수가 다변수일 수도 있는가?**
$L(\theta)$는 θ가 입력 1개라서 단변수처럼 보이지만, 데이터 $y_1, \dots, y_n$이 **고정된 상수**로 취급됨. 그래서 사실상 $L: \mathbb{R} \to \mathbb{R}$.

### ③ 벡터 함수 $f: \mathbb{R}^n \to \mathbb{R}^m$

입력도 벡터, 출력도 벡터.

**기출 8번:** $\text{softmax}: \mathbb{R}^c \to \mathbb{R}^c$
- 입력: $\mathbf{z} = (z_1, z_2, \dots, z_c)$
- 출력: $\mathbf{p} = (p_1, p_2, \dots, p_c)$, $p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$

### ④ 함수의 함수 (functional)

함수를 입력으로 받아 숫자를 출력. 예: $L[f] = \int_0^1 f(x)^2 dx$

(시험 범위 아님. 알아두기만)

---

## 4. 합성함수 (composition)

### 정의

$(f \circ g)(x) = f(g(x))$

"먼저 g 통과, 그 다음 f 통과"

### 중1 비유

자판기 두 개를 줄 세웠다고 생각.
- 첫 번째 자판기 g: "동전 → 토큰"
- 두 번째 자판기 f: "토큰 → 음료"
- 합성 $f \circ g$: "동전 → 음료"

### 예시

$g(x) = x + 1$, $f(x) = x^2$
- $f(g(x)) = f(x+1) = (x+1)^2$
- $g(f(x)) = g(x^2) = x^2 + 1$

**순서가 중요!** $f \circ g \neq g \circ f$

### 기출에서의 활용

NLL 미분할 때 **체인 룰**(`04-chain-rule.md`)이 등장하는데, 합성함수 미분의 핵심.

예: $\log(L(\theta))$
- $L$ 먼저 계산 (안쪽)
- $\log$ 적용 (바깥쪽)
- 합성함수: $\log \circ L$

---

## 5. 역함수 (inverse function)

### 정의

$f^{-1}(y) = x$  ⇔  $f(x) = y$

"f를 거꾸로 돌리는 함수"

### 중1 비유

$f(x) = 2x$ → $f^{-1}(y) = y/2$

### 자주 쓰는 역함수 쌍

| f(x) | f⁻¹(y) | 조건 |
|------|--------|-----|
| $e^x$ | $\log y$ | y > 0 |
| $x^2$ | $\sqrt{y}$ | x ≥ 0, y ≥ 0 |
| $\sin x$ | $\arcsin y$ | -π/2 ≤ x ≤ π/2 |

### 시험에서의 함정

확률밀도 변환:
- $X \sim p_X(x)$, $Y = f(X)$
- $p_Y(y) = p_X(f^{-1}(y)) \cdot \left|\frac{df^{-1}}{dy}\right|$

**가우스 적분 증명**(기출 2번 보조정리)에서 극좌표 변환할 때 등장.

## 6. argmax / argmin

함수 자체가 아니라 **함수를 최대/최소로 만드는 입력값**.

$$\arg\max_x f(x) = \text{f가 최대일 때의 x값}$$
$$\max_x f(x) = \text{f의 최댓값 자체}$$

**예시:** $f(x) = -(x-3)^2 + 5$
- $\max f = 5$
- $\arg\max f = 3$

### 기출에서의 활용

**MLE의 정의:** $\hat{\theta}_{\text{MLE}} = \arg\max_\theta L(\theta)$

(L의 최대값 자체가 아니라, L을 최대로 만드는 θ)

**MAP의 정의:** $\hat{\theta}_{\text{MAP}} = \arg\max_\theta p(\theta | D)$

## 7. 다리 놓기 — 중1에서 대학으로

| 중1 | 대학 (시험) |
|-----|-----------|
| $y = 2x + 3$ | $f: \mathbb{R} \to \mathbb{R}$, $f(x) = 2x + 3$ |
| 일차함수, 이차함수 | $f: \mathbb{R}^n \to \mathbb{R}$ (다변수) |
| 함수 = 그래프 | 함수 = 입력→출력 매핑 (그래프는 시각화 도구) |
| y = f(x)의 최댓값 | $\max f$, $\arg\max f$ 구분 |

---

## 8. 기출 적용 사례

### 사례 1 — 우도함수의 정체 (기출 4번)

$$L(\theta) = \prod_{i=1}^{n} \theta^{y_i}(1-\theta)^{1-y_i}$$

이건 **함수**입니다.
- 입력: $\theta$ (한 개의 실수, 0과 1 사이)
- 출력: $L(\theta)$ (한 개의 실수, 우도값)
- 데이터 $y_1, \dots, y_n$은 **고정된 상수** (입력 아님)

**시험 답안에서 명시할 것:**
> "여기서 데이터 y_i는 고정이고, $\theta$만이 변수이므로 $L(\theta)$는 $\theta$의 함수이다."

### 사례 2 — Softmax 함수 구조 (기출 8번)

$$\text{softmax}: \mathbb{R}^c \to \mathbb{R}^c$$

$$p_i = \frac{e^{z_i}}{\sum_{j=1}^{c} e^{z_j}}$$

- 입력: c차원 벡터 z
- 출력: c차원 벡터 p (단, $\sum_i p_i = 1$, $p_i > 0$ — 즉 확률분포)

**자코비안:** 입력이 벡터, 출력이 벡터인 함수의 미분은 **행렬**(c × c).

## 9. 자가 점검

1. $f(x) = 2x + 3$의 역함수를 구하시오.
2. $f(x) = x^2$, $g(x) = x + 1$일 때 $(f \circ g)(2)$를 구하시오.
3. $f(x) = -(x-1)^2 + 4$의 $\max$와 $\arg\max$를 구하시오.
4. softmax 함수가 $\mathbb{R}^3 \to \mathbb{R}^3$일 때 자코비안 행렬 크기는?

**답:**
1. $f^{-1}(y) = (y-3)/2$
2. $g(2) = 3$, $f(3) = 9$
3. $\max = 4$, $\arg\max = 1$
4. 3 × 3
