# 03. 왜 미분 = 0 인가 — 페르마 정리

> "미분=0"을 그냥 적으면 -10%. **이유**를 글로 적어야 함.

## 1. 페르마 정리 (Fermat's Theorem)

**정리:** 함수 $f$가 점 $x = a$에서 **국소 극값**(local max/min)을 가지고 $f$가 $a$에서 미분 가능하면:
$$f'(a) = 0$$

## 2. 직관

곡선이 매끈하게 정점을 만들 때, 정점에서 접선은 **수평선** → 기울기 = 0.

```
       f(x)
        │   ___
        │  ╱   ╲     ← 정점 (f'=0)
        │ ╱     ╲
        │╱       ╲
        │
        └────────── x
```

## 3. 증명 (간단)

$f(a)$가 국소 최댓값이라고 가정.

$h > 0$ 작을 때 $f(a + h) \leq f(a)$ → $\frac{f(a+h) - f(a)}{h} \leq 0$ → $\lim_{h \to 0^+} \leq 0$.

$h < 0$ 작을 때 $f(a + h) \leq f(a)$ → $\frac{f(a+h) - f(a)}{h} \geq 0$ (h < 0이므로 부호 뒤집힘) → $\lim_{h \to 0^-} \geq 0$.

미분 가능이면 좌·우 극한 같음. $\geq 0$이고 $\leq 0$이므로 = 0. ∎

## 4. **주의 — 미분=0이 충분조건은 아님**

$f'(a) = 0$이지만 극값이 아닐 수도 있음 (변곡점).

예: $f(x) = x^3$, $f'(0) = 0$이지만 0은 극값 아님 (단조증가).

### 해결: 2계 미분 검증

| 조건 | 결론 |
|------|------|
| $f''(a) > 0$ | $a$는 **국소 최솟값** |
| $f''(a) < 0$ | $a$는 **국소 최댓값** |
| $f''(a) = 0$ | 결론 불가 (다른 방법) |

**MLE 답안에서:** 2계 미분 < 0 검증 필수.

## 5. **경계 점은 페르마 적용 안 됨**

함수의 정의역이 $[a, b]$일 때, 경계 a 또는 b에서 극값이 일어나면 페르마 정리 사용 못 함 (미분이 한쪽만 정의).

**시험에서 주의:**
- 베르누이 MLE: $\theta \in (0, 1)$이라고 명시 (열린 구간)
- 경계 $\theta = 0, 1$은 $L = 0$이라 후보 아님 (단, k=0 또는 k=n인 특수 경우 별도 처리)

## 6. 시험 답안 표준 문장

> "함수 $\ell(\theta)$는 (0, 1) 내부에서 미분 가능하고, 최댓값은 내부 점에서 달성된다 (k=0, n인 경우 제외). **페르마 정리**(미분 가능한 함수의 내부 극값에서 1차 도함수가 0)에 의해 $\ell'(\theta) = 0$인 θ가 후보다. 또한 $\ell''(\theta) < 0$이므로 ℓ은 오목하고 임계점은 최댓값이다."

## 7. 오목/볼록과 전역 최댓값

함수가 **오목**(concave)이면 임계점은 **전역 최댓값**.

| 함수 | 오목? | 임계점 |
|------|------|-------|
| 베르누이 ℓ(θ) | O | 전역 최댓값 |
| 정규분포 ℓ(μ) | O | 전역 최댓값 |
| 일반 비선형 | × (보통) | 국소만 보장 |

**시험 답안에:** "ℓ이 오목하므로 임계점이 전역 최댓값"이라고 적으면 가산점.

## 8. 한 줄 요약

> "페르마 정리: 미분 가능한 함수의 내부 극값에서 1차 도함수 = 0. 2계 미분으로 max/min 구분."
