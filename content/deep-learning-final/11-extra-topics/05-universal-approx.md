# 05. 보편 근사 정리 (Universal Approximation Theorem)

> "1개 은닉층 + 충분한 뉴런 + 비선형 활성화 = 임의 연속함수 근사 가능"

---

## 1. 정리 (Cybenko 1989, Hornik 1991)

$\sigma$가 비상수, 유계, 단조증가 연속 함수 (예: sigmoid)일 때, 임의의 연속 함수 $f: [0,1]^d \to \mathbb{R}$와 임의 $\epsilon > 0$에 대해, 다음 형태의 함수 $g$가 존재:

$$g(x) = \sum_{i=1}^N \alpha_i \sigma(w_i^T x + b_i)$$

이고
$$\sup_{x \in [0,1]^d} |f(x) - g(x)| < \epsilon.$$

즉, **1개 은닉층 신경망으로 임의 정확도** 근사 가능.

---

## 2. 직관

활성화 함수 (예: sigmoid)는 "계단 모양" 비슷. 여러 개를 더하면 임의 모양 만들기 가능.

```
   y                        y
   │                        │   ╲
   │  ┌─                    │     ╲___╱──
   │  │     계단 ─────→     │   ╱
   │__┘     하나만        많이 결합
   └────                    └────
```

**비유:** 푸리에 급수 (사인 결합 = 임의 주기함수). UAT는 신경망 버전.

---

## 3. 한계

UAT는 **존재성**만 보장:
- 필요한 뉴런 수 $N$이 폭발적일 수 있음
- 학습으로 그 가중치를 **찾을 수 있는지**는 별개 문제
- 일반화 (테스트 성능) 보장 X

**즉, "신경망이 강력함을 보장하지만, 실제 성능 보장은 X"**.

---

## 4. 깊이의 중요성 (Deep Learning이 왜 필요한가)

UAT는 **너비**(뉴런 수)로만 함수 근사. 그러나 깊이가 더 효율적:

- **Universal Approximation with Width:** 1층 + N개 뉴런으로 가능. 그러나 N이 지수적으로 많이 필요.
- **Deep Networks:** 같은 함수를 **깊이로 다항 시간** 안에 근사 가능 (어떤 함수에 대해).

→ "Deep > Wide" — 표현력은 이론적으로 비슷하지만 **효율** 차이.

---

## 5. 다양한 변형

| 활성화 | UAT 성립? |
|-------|----------|
| Sigmoid | O (Cybenko 1989) |
| Tanh | O |
| ReLU | O (Sonoda & Murata 2017) |
| 다항식 | X (다항식만 만들 수 있음) |
| 선형 | X (선형만) |

**핵심 조건:** "비선형이고 다항식이 아니어야" (비다항식 비선형성).

---

## 6. 시험 답안 — UAT 진술

### [문제] 보편 근사 정리를 진술하라.

### [답안]

> 비상수·유계·단조증가 연속 활성화 함수 $\sigma$ (예: sigmoid)를 사용하는 1개 은닉층 신경망 $g(x) = \sum_{i=1}^N \alpha_i \sigma(w_i^T x + b_i)$는, 임의의 연속 함수 $f: K \to \mathbb{R}$ (K compact)와 임의 정확도 $\epsilon > 0$에 대해, 충분히 큰 N과 적절한 $\alpha_i, w_i, b_i$로 $\sup_x |f(x) - g(x)| < \epsilon$을 만족시킬 수 있다. (Cybenko 1989, Hornik 1991)

> **단, 이는 존재성만 보장하며, 필요한 N이 지수적일 수 있고, 학습 알고리즘이 그 가중치를 찾을 수 있는지는 별개 문제이다.**

---

## 7. 한 줄 요약

> "UAT: 신경망은 임의 연속함수를 근사할 수 있다. 단, 효율성과 학습 가능성은 별개."
