## 1. 파일 단위 종합 평가

### A (Claude) — "통찰·일반화 우위, 분량 풍부"
- **강점**:
  - 의미 해석(pseudo-counts, conjugate prior, GLM canonical link, heteroscedastic regression)이 가장 풍부.
  - 일반화(Beta(α,β), σ² 일반, M→0 vs M→∞ 대칭) 적극 제시.
  - 퀴즈 간 연결(Q3↔Q10, Q6↔Q7↔Q9, Q8↔Q10) 명시.
  - Conv 단원에서 정의 채택의 메타 논의 + 출제표 오류 선형성 교차검증 + doubly block-Toeplitz 구조 통찰 등 가장 깊이 있는 분석.
- **약점**:
  - Q9 m=6 케이스에서 prior 미분항을 끝까지 풀지 않고 정성적 결론으로 회피.
  - Q11 (3)에서 정의 갈팡질팡한 흔적이 본문에 그대로 남아 있음(편집 정리 필요).
  - Q5에서 2계 도함수 검증 누락(strict concavity 미증명).

### B (Codex) — "엄밀성·단계 추적성 우위, 통찰 부족"
- **강점**:
  - 한 식 한 줄의 압도적 단계 추적성 → 시험 부분점수 회수에 최적.
  - **Q9에서 유일하게 양 구간 미분 + 2차방정식 풀이 + 엄밀해(1/2) vs 강의해(2/3) 두 해석 분리** — 가장 중요한 차별화 요소.
  - Q5에서 2계 도함수 strictly concave 검증, Q1에서 "Aeⱼ = j번째 열" 통찰로 Q12·13 연결, Q2에서 4 fundamental subspaces 직교분해, Q3에서 J = Cov(p) 해석.
- **약점**:
  - Q6~10의 의미 해석·일반화 통찰이 A 대비 빈약.
  - 분량이 길어 한눈에 들어오지 않음.
  - Q12에서 도입은 "기저의 상을 열로" 라 했으나 실제 풀이는 행 관점으로 전개 → 도입과 풀이 관점 불일치.

### C (Gemini) — "압축적, 결정적 결함 다수"
- **강점**:
  - 가장 짧고 핵심만 빠르게 훑기에 좋음 (252줄).
  - 결과만 빨리 확인할 때 유용한 치트시트 역할.
- **결정적 약점**:
  - **Q9 m=2 답이 모호하고 부정확** ("0.7~0.75 부근" — 실제 정답 2/3 ≈ 0.667과 다름). 미분 자체를 수행하지 않음.
  - **Q11에서 (1)만 풀고 (2)(3)(4)는 통째로 누락**.
  - **Q12에서 6×7 행렬 자체를 본문에 명시하지 않음** (서술로만 "Toeplitz" 라 처리).
  - Q8에서 NLL closed-form 직접 전개 누락.
  - 시험 모범답안으로서의 신뢰도가 가장 낮음.

### Quiz 3 — Softmax Jacobian

세 답안 모두 일치:
- i = j: ∂p_i/∂z_i = p_i(1 − p_i)
- i ≠ j: ∂p_i/∂z_j = −p_i p_j
- 행렬: J = diag(p) − pp ᵀ

차별화 포인트:
- B: **두 가지 검증 — (i) 열의 합 = 0 (∑pᵢ=1 미분 결과로 자명), (ii) J = Cov(p) (분포의 공분산 행렬)** + Q10 재활용 예고.
- A: 두 케이스 + Kronecker delta 통합.
- C: 두 케이스 압축.

**추천: B** — Cov(p) 해석은 Softmax를 본질적으로 이해시키는 결정적 통찰.

### Quiz 5 — MLE Bernoulli

세 답안 모두:
- dℓ/dθ = k/θ − (n−k)/(1−θ)
- θ\* = k/n

차별화 포인트:
- B: **유일하게 2계 도함수 −k/θ² − (n−k)/(1−θ)² < 0 으로 strictly concave 증명** → 진짜 최대점임을 보임. 시험 감점 방지 결정적. 추가로 log 단조성 명시(arg max 보존), 경계 케이스(k=0, n) 처리, 지수족 sufficient statistic 평균 = MLE 일반화.
- A & C: 1계 조건만, 2계 미수행.

**추천: B** — 2계 검증 + 일반화로 가장 견고.

### Quiz 6 — MAP (Beta(2,2) prior)

차별화 포인트:

**추천: A** — 일반화·해석이 압도적으로 깊음.

### Quiz 9 — Triangular Prior MAP (m=2, m=6) ⚠️ **세 답안 사이 가장 큰 차이**

**독립 검증** (이 리포트에서 직접 수행):

**m=2 케이스**: support [0,1]. 오른쪽 구간 θ∈[0.5,1] 에서 p_2(θ) = 4(1−θ).
- Posterior ∝ θ⁴(1−θ) · 4(1−θ) = 4θ⁴(1−θ)².
- log 미분 = 4/θ − 2/(1−θ) = 0 → 4(1−θ) = 2θ → **θ\* = 2/3**. ✓

**m=6 케이스**: support [1/3, 2/3]. 오른쪽 구간 θ∈[0.5, 2/3] 에서 p_6(θ) = 24−36θ.
- Posterior ∝ θ⁴(1−θ)(24−36θ).
- log 미분 = 4/θ − 1/(1−θ) − 36/(24−36θ).
- θ=0.5 대입: 8 − 2 − 36/6 = 0. → **θ=0.5 가 임계점**.
- θ=0.55 대입: ≈ 7.84 − 2.04 − 6.38 ≈ −0.58 < 0 (감소).
- 왼쪽 구간 [1/3, 0.5]: 미분식 4/θ − 1/(1−θ) + 3/(3θ−1), θ=0.4 대입 → 양수(증가).
- B의 2차방정식 18θ² − 25θ + 8 = 0 의 두 해 (25 ± √49)/36 = 1/2 또는 8/9. 8/9는 support 밖.
- **엄밀 풀이 정답: θ\* = 1/2.** 그러나 강의 의도(prior를 hard support 제약으로만 보고 likelihood만 최대화)에서는 **θ\* = 2/3**.

**세 파일 답 비교**:

| 케이스 | A (Claude) | B (Codex) | C (Gemini) | 검증 |
|--------|-----------|-----------|------------|------|
| m=2 | 2/3 | 2/3 | "0.7~0.75 부근" (모호) | **2/3** (A·B 정확, **C 부정확**) |
| m=6 | 2/3 (경계) | **1/2 (엄밀) + 2/3 (강의해) 둘 다 명시** | 2/3 | 엄밀 1/2, 강의해 2/3 |

평가:
- **C는 m=2에서 미분조차 수행하지 않고 "내부 임계점" 만 적어 명백한 오류.**
- **A는 m=6에서 우측 경계 2/3만 결론짓고, 자체 풀이의 "p_6 → 0 이므로 곱은 0" 과 모순됨**. prior가 경계에서 0이 되는 사실을 감안하면 임계점 분석을 끝까지 수행해야 하나 회피.
- **B만 유일하게 양 구간 분리 미분 + 2차방정식 풀이 + 임계점/경계/꼭짓점 비교 + 엄밀해와 강의해 두 해석 명시적 분리**.

**추천: B 압도적**. Q9는 이 리포트 전체에서 가장 중요한 차별 케이스.

### Quiz 10 — Backpropagation chain rule

세 답안 모두:
- ∂L/∂p_y = −1/p_y
- ∂p_y/∂p = e_yᵀ
- ∂p/∂z = diag(p) − pp ᵀ
- 합성: ∂L/∂z = **p − e_y**

Chain rule 합성 트릭(e_yᵀ diag(p) = p_y e_yᵀ, e_yᵀ pp ᵀ = p_y p ᵀ) 모두 정확히 수행.

차별화 포인트:
- A: **차원 정합 표기 (1×1)·(1×C)·(C×C) → 1×C 명시 + "p − e_y = 예측 − 정답 원-핫" 의미 해석 + GLM canonical link 일반정리**.
- B: 성분식과 행렬식 두 형태 모두 제시, 단계별 박스 4개.
- C: 모든 단계 압축, 정확하나 통찰 한 줄.

**추천: A** — GLM 일반화로 "왜 분류·회귀가 같은 형태로 풀리는가" 까지.

### Quiz 12 — 6×7 Convolution Matrix

세 답안 모두 동일 Toeplitz 행렬 도출 — 셀 단위 검증 통과.

차별화 포인트:
- A: **f(eⱼ) 7개를 표로 명시 → "기저의 상을 열로" 정리(linear map의 행렬표현 정리)를 가장 교과서적·체계적으로 적용**.
- B: 행 관점 (yᵢ = xᵢ + 2x_{i+1}) 6식 나열 후 행렬화 → 도입은 "기저→열"이지만 실제 풀이는 행 관점이라 불일치.
- C: f(e₁), f(e₂)만 보이고 "이하 반복" 처리 + **행렬 자체를 본문에 명시하지 않음** ("Toeplitz" 서술로만).

**추천: A** — 문제 지문의 요구("표준기저의 상을 열로 모아 만들 것")에 정확히 부응.

### Quiz 13 — 4×9 Convolution Matrix (2D)

세 답안 모두 동일한 4×9 행렬 도출 — 36셀 전부 일치, row-major 인덱싱 (x₅ 가 4개 출력 모두에 등장하며 계수 3,2,1,0) 일관.

차별화 포인트:
- A: **f(e₅) = (3,2,1,0)ᵀ = 5번째 열로 기저 관점 검증 + doubly block-Toeplitz, locality, weight sharing 등 구조 통찰**.
- B: 패치별 yᵢ 식 → 행렬화. 깔끔하나 검산 없음.
- C: 행렬 명시 + 친절한 행 매핑. 그러나 검산·구조 통찰 부재.

**추천: A** — 셀 정확성은 셋 다 동등하나 검증·구조 통찰이 차별화.

## 3. Quiz 11 출제표 오류 권장 처리 방안

**사실 관계** (정의대로 계산 시):
- 정의: yᵢ = xᵢ + 2x_{i+1}
- x = (1,2,3,4,5,6,7) ⇒ yᵢ = i + 2(i+1) = 3i + 2 ⇒ **(5,8,11,14,17,20)**
- 출제표: (4,7,10,13,16,19) = 3i + 1. **정의와 모순.**
- 선형성 교차검증: x⁽³⁾ = x⁽¹⁾ + 𝟏 ⇒ w*x⁽³⁾ = w*x⁽¹⁾ + w*𝟏 = (2,5,8,11,14,17) + (3,3,3,3,3,3) = **(5,8,11,14,17,20)** — 자기무모순적으로 옳음.
- 출제표 (4,7,10,13,16,19)는 어떤 정합적 정의로도 설명 안 됨 → **인쇄/계산 오기**로 판단.

**권장 시험장 처리**:
> 두 값 모두 적되 정의 기반 계산 결과를 우선 표기하고, 출제표 값과의 차이를 명시한 후 선형성 교차검증을 부기. 채점 기준에 따라 출제표 값을 답해야 할 가능성도 있으므로 강사 사전 확인 권장.
