# 딥러닝이론 8주차 퀴즈

8주차 강의에서 교수가 학생들에게 직접 풀이/계산 시간을 준 문제들. **공식 퀴즈 첨부본 매칭은 퀴즈 4 (Backpropagation) 1건**이며, 퀴즈 1·2·3은 강의 중 즉석 풀이.

---

## ❌ 퀴즈 1. 3차 함수 L의 미분 f의 형태 상상하기 [퀴즈 아님 / 직관 발문]

> **공식 퀴즈 첨부본에 미포함**. 직관 시각화용 즉석 발문.

- **위치**: 약 라인 125
- **분류**: 짧은 사고 시간 부여
- **문제 (원문)**:
  > "L이라는 함수가 있어서 이게 3차 함수라면 얘의 미분인 f는 어떻게 생겼을까요? 지금 L이 증가하는 동안 f는 어떻게 생겼을까요?"
- **맥락**: Optimization 단원에서 Newton's method 직관 도입 — "L의 최소화 = L의 미분 f의 zero를 찾기".
- **기대 답 (라인 127~135)**: L이 증가하는 구간에서 f(=L')는 양수, L의 변곡점에서 f는 0. 3차 함수 L → f는 2차 함수(포물선).

---

## ❌ 퀴즈 2. 구체적 3차 함수 L(x) 의 x=3 근방 2차 근사 [퀴즈 아님 / 강의 중 함께 풀이]

> **공식 퀴즈 첨부본에 미포함**.

- **위치**: 약 라인 169~179
- **문제 (원문)**:
  > "2번 미분했을 때 얼마나 휘어있는지 한번 봐볼까요? L(x)를 2번 미분하면 뭐가 되죠? y(3), y'(3), y''(3)을 각각 구해서 x=3 근방에서의 2차 근사식을 써 보세요."
- **맥락**: Newton's method 시각화. L(x) = x³/3 − 7x 형태 (√7 찾기 예시와 연결).
- **기대 답 (라인 173~179)**:
  - L(3) = −12
  - L'(3) = 2
  - L''(3) = 6
  - 2차 근사: y = 3(x−3)² + 2(x−3) − 12

## ❌ 퀴즈 3. Newton's method 업데이트 식 유도 — 6분 [퀴즈 아님 / 강의 내 메인 풀이]

> **공식 퀴즈 첨부본에 미포함**. 6분의 시간을 부여한 강의 내 핵심 풀이지만 채점형 공식 퀴즈로 출제되지는 않음. (의외이므로 실제 출제 여부 재확인 권장)

- **위치**: 라인 303~311 ("한 6분정도 드리겠습니다")
- **분류**: **명시적 시간 부여형 메인 퀴즈**
- **문제 (원문)**:
  > "L을 minimize하고 싶은데, f쪽에서 무엇을 했었는지 다시 봅시다. (L'=f) θ_t를 업데이트할 때 업데이트 식이 어떻게 되는지 (1) f에 대한 식으로 써보고, (2) 그 식을 L에 대한 식으로 바꿔서 써보세요. 한 6분정도 드리겠습니다."
- **맥락**: Newton's method 옵티마이저 도입. 선형근사 zero를 찾는 식을 f에 대해 쓴 뒤 f = L', f' = L''로 변환.
- **기대 답 (라인 313~317)**:
  - (1) f의 선형근사 zero: **θ_{t+1} = θ_t − f(θ_t) / f'(θ_t)**
  - (2) L의 식으로: **θ_{t+1} = θ_t − L'(θ_t) / L''(θ_t)**
  - 핵심: gradient descent의 학습률 자리에 Hessian의 역수(1/L'')가 들어감 → second-order method.

## ✅ 퀴즈 4. Backpropagation — 3개 미분 직접 계산 [공식 퀴즈]

- **위치**: 약 라인 413~415, 마무리 425~429
- **분류**: "직접 해보시고" — 슬라이드 다음 페이지에 답이 있으니 먼저 풀어볼 것
- **공식 퀴즈 첨부본 매칭**: 2차 Quiz 3 (슬라이드 p.393)
- **문제 (원문)**:
  > "3개의 미분을 계산하라는 겁니다. 이 3개를 곱하고 마지막으로 이 주황색까지만 곱하면 최종적으로 W2가 얻어지는데요. 답은 바로 뒤에 있는데 직접 좀 해보시고 보시는 걸 (권장합니다). 이때 p를 z로 미분하는 거 이전에 풀었었죠? 다시 한번 해보시면서 (빈칸을) 채워주세요."
- **맥락**: 2-layer MLP (x → W1 → z1 → ReLU → W2 → g → softmax → p → CE → L)에서 ∂L/∂W2를 chain rule로 분해.
- **기대 답 힌트**:
  - softmax + cross-entropy: ∂L/∂g = p − y
  - ∂g/∂W2 = z1
  - ReLU': 1 (x>0), 0 (x≤0)
  - 곱하여 ∂L/∂W2, ∂L/∂x 도출.

---

### 📌 공식 퀴즈 첨부본의 분해 위치 (보조 노트)

공식 퀴즈는 다음 네트워크 구조에서 노란 형광펜으로 표시된 **체인의 처음 3단계** 편미분을 요구:

```
x → z₁ = W₁x → x₁ = ReLU(z₁) → z = W₂·x₁ → p = softmax(z) → p_y = e_yᵀ p → L = −log p_y
```

**(1) ∂L / ∂p_y**
- L = −log p_y → ∂L/∂p_y = **−1 / p_y**

**(2) ∂p_y / ∂p**
- p_y = e_yᵀ · p (true class y의 인덱스 추출)
- ∂p_y/∂p = **e_yᵀ** (1×C 행벡터, y번째만 1)

**(3) ∂p / ∂z** (단, p = softmax(z))
- 2주차 퀴즈 4 결과 재활용: **Softmax Jacobian = diag(p) − p · pᵀ**
  - 대각성분: p_i (1 − p_i)
  - 비대각: −p_i · p_j

**Chain rule 합성:**
- ∂L/∂z = (∂L/∂p_y) · (∂p_y/∂p) · (∂p/∂z)
- = (−1/p_y) · e_yᵀ · (diag(p) − p·pᵀ)
- = **p − e_y** (= p − y_onehot, 유명한 "Softmax + CE 미분 = predicted − true" 결과)

> 추출본 퀴즈 4와 본질 동일하지만 **체인 분해 위치가 다름** (추출본은 ∂L/∂g 부터, 공식은 ∂L/∂p_y 부터). 두 분해 모두 학습 가치 있음.
