# 딥러닝이론 1주차 퀴즈

## ✅ 퀴즈 1 — 행렬 A의 작용 (선형변환 확인) [공식 퀴즈]

**위치:** 약 line 851 (관련 설명 line 841~851)

**행렬 A (공식 퀴즈 첨부본 기준 — 슬라이드/판서값):**
```
A = [[1, 1, 1],
     [1, 2, 3]]    (2×3, R³ → R²)
e1 = (1,0,0)ᵀ,  e2 = (0,1,0)ᵀ,  e3 = (0,0,1)ᵀ
```

**문맥:**
교수가 Linear Transformation(선형변환)의 정의(`L(v+w)=L(v)+L(w)`, `L(αv)=αL(v)`)를 설명한 뒤, 이를 행렬과 연결시키기 위해 직접 손으로 풀어보라고 제시한 첫 번째 퀴즈.

**문제:**
주어진 행렬 A와 표준기저 e1, e2, e3에 대해 다음 두 가지를 보여라.
1. **A(e1) + A(e2) = A(e1 + e2)** (덧셈 보존)
2. **2 · A(e1) = A(2 · e1)** (스칼라배 보존)

**검증:**
- A·e1 = (1, 1)ᵀ, A·e2 = (1, 2)ᵀ → A·e1 + A·e2 = (2, 3)ᵀ
- e1 + e2 = (1, 1, 0)ᵀ → A·(e1+e2) = (2, 3)ᵀ ✓
- 2·A·e1 = (2, 2)ᵀ; 2·e1 = (2, 0, 0)ᵀ → A·(2·e1) = (2, 2)ᵀ ✓

**전사 인용 (line 851):**
> "010 두 개를 보내면은 뭐가 나오는지 얻을 수 있겠죠? 두 개 보내보고, 둘 다 더하면 뭐가 돼요? 110이잖아요? 1, 2, 0을 곱하면 뭐가 나오는지 3개의 과정에서 어떻게 되는지 좀 봐주실 수 있을까요? 퀴즈인데요."

**기대되는 접근/답:**
- `(0,1,0)`을 A로 보낸 결과 + 다른 벡터를 A로 보낸 결과 = `(1,1,0)`을 통째로 A로 보낸 결과 (덧셈 보존).
- 벡터를 2배 한 뒤 A로 보내는 것 = 먼저 A로 보낸 뒤 2배 하는 것 (스칼라배 보존).
- 따라서 `L_A(x) = Ax`는 **Linear Transformation**임을 직접 계산으로 확인.

## ❌ 퀴즈 2 — 선형변환에 대응되는 행렬 찾기 [퀴즈 아님 / 즉석 연습]

> **공식 퀴즈 첨부본에 미포함**. 강의 중 함께 풀이로 진행된 즉석 연습 활동. 시험 제출 대상이 아니지만 학습 가치 있음.

**위치:** 약 line 879~881

**문맥:**
첫 번째 퀴즈로 "행렬 → 선형변환"을 보였으니, 이제 역방향("선형변환 → 행렬")을 보이는 문제. R³ → R² 인 어떤 선형변환 L이 주어졌을 때(표준기저 e1, e2, e3 = `(1,0,0)`, `(0,1,0)`, `(0,0,1)`의 상이 명시됨), 이에 대응하는 2×3 행렬을 찾으라는 문제.

**문제:**
R³에서 R²로 보내는 선형변환 L이 주어지고, 표준기저 벡터 e1, e2, e3가 각각 어떤 벡터로 보내지는지가 명시되어 있다. 이 선형변환 L에 대응되는 2×3 행렬 M을 구하라.

**전사 인용 (line 881):**
> "리니어 트랜스포메이션에 대응되는 매트리스를 찾는 문제예요. … 답은 E1을 보내는 것을 첫 번째에 쓰고 E2를 보내는 것을 두 번째에 쓰고 E3를 보내는 것을 세 번째에 씁니다."

**기대되는 답:**
표준기저 `e_i`의 상 `L(e_i)`를 i번째 열(column)로 차례로 배치한 행렬. 즉 `M = [ L(e1) | L(e2) | L(e3) ]`.
