# 딥러닝이론 2주차 퀴즈

2주차 강의에서 학생들에게 직접 풀어보라고 시간을 준 문제는 총 **4개**.
이 중 **공식 퀴즈 첨부본에 포함된 항목은 퀴즈 1, 4** (2건)이며, 나머지 2건은 즉석 연습입니다.

---

## ✅ 퀴즈 1. Image / Kernel 4종 구하기 [공식 퀴즈]

- **위치**: 약 107~111행 ("5분 정도 드릴 테니까... 2개에 대해서 풀어보시고")
- **명시 형태**: "5분 드릴게요" + "댓글로 적어주세요"

**행렬 A (공식 퀴즈 첨부본 기준 — 정정됨):**
```
A = (1  2)    (1×2 행 벡터, R² → R¹)
```

> ⚠️ **정정 사항**: 강의 녹취록만 보고 추정한 초기본은 A=[[1,1],[1,1]] (2×2)였으나, 공식 퀴즈 첨부본은 **A=(1 2)** 임. 정답이 달라지므로 정정.

**문제:** A에 대해 다음 4가지를 구하시오.
1. **R(A)** (Image of A)
2. **R(Aᵀ)** (Image of Aᵀ)
3. **N(A)** (Kernel of A)
4. **N(Aᵀ)** (Kernel of Aᵀ)

**필요 개념:**
- Image (= column space): {Ax | x ∈ 정의역}
- Kernel (= null space): {x | Ax = 0}
- Rank-Nullity Theorem: dim(domain) = rank(A) + nullity(A)

**정답:**
- **R(A)** = ℝ¹ (= span{1}, **rank = 1**)
- **R(Aᵀ)** = span{(1, 2)ᵀ} ⊂ ℝ² (1차원)
- **N(A)** = {(x₁, x₂) ∈ ℝ² : x₁ + 2x₂ = 0} = span{(2, −1)ᵀ} (1차원)
- **N(Aᵀ)** = {0} ⊂ ℝ¹ (0차원)
- Rank-Nullity 검증:
  - A: dim(ℝ²) = 2 = rank 1 + nullity 1 ✓
  - Aᵀ: dim(ℝ¹) = 1 = rank 1 + nullity 0 ✓

## ❌ 퀴즈 2. 5×5 대각행렬의 Image, Kernel, Eigenvalue/Eigenvector [퀴즈 아님 / 즉석 연습]

> **공식 퀴즈 첨부본에 미포함**. 강의 중 함께 풀이로 진행됨.

- **위치**: 약 155~163행
- **명시 형태**: 명시적 "퀴즈" 호명은 없으나 학생들이 함께 풀이 진행

**문제:**
대각성분 (4, 3, 2, 1, 0)인 5×5 대각행렬 A에 대해:
1. Image R(A) 와 차원
2. Kernel N(A) 와 차원
3. A의 eigenvalue/eigenvector
4. 가장 큰 eigenvalue 1/2/3개만 살린 근사 행렬 A₁, A₂, A₃의 모양 및 rank

**정답 (183~193행):**
- Image: (x₁', x₂', x₃', x₄', 0) → **rank = 4**
- Kernel: (0, 0, 0, 0, x₅) → **nullity = 1**
- Eigenvalues: 4, 3, 2, 1, 0 / Eigenvectors: 표준기저 e₁~e₅
- A₁ = diag(4,0,0,0,0), rank 1; A₂ = diag(4,3,0,0,0), rank 2; A₃ = diag(4,3,2,0,0), rank 3.

## ❌ 퀴즈 3. f(x) = x² − 7 의 점 (3, 2)에서의 접선 방정식 (Newton's Method 1단계) [퀴즈 아님 / 즉석 연습]

> **공식 퀴즈 첨부본에 미포함**. 직관 시각화용 1~2분 즉석 풀이.

- **위치**: 약 261~269행 ("1, 2분 정도면 될 것 같아요")

**문제:**
√7 근사를 위해 f(x) = x² − 7의 영점을 찾는 과정에서, 점 (3, 2)에서의 접선 방정식을 y = ax + b 형태로 구하시오.

**필요 개념:**
- f'(x) = 2x → x=3 에서 기울기 6
- Newton's method 1 step: 1차 근사의 영점 = 다음 추정값

**정답 (269행):** **y = 6x − 16**
0으로 두면 x = 8/3 ≈ 2.66 → √7의 첫 번째 근사값.

## ✅ 퀴즈 4. Softmax 함수의 Jacobian (∂p/∂g) 계산 [공식 퀴즈]

- **위치**: 약 363~379행 ("이거 퀴즈 풀고 오늘 마무리... 58분 정도까지")
- **명시 형태**: "**퀴즈**"라 명시

**문제:**
g ∈ ℝᶜ → p = softmax(g), 즉 `p_i = exp(g_i) / Σ_k exp(g_k)`에 대해 Jacobian ∂p/∂g (c×c 행렬)의 모든 성분을 구하시오.

1. i = j 인 경우: ∂p_i / ∂g_i = ?
2. i ≠ j 인 경우: ∂p_i / ∂g_j = ?

**필요 개념:** vector-by-vector 미분, 몫의 미분.

**정답 (385~413행):**
- i = j: ∂p_i/∂g_i = **p_i (1 − p_i)**
- i ≠ j: ∂p_i/∂g_j = **− p_i · p_j**
