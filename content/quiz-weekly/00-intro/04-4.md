# 딥러닝이론 4주차 퀴즈

본 회차 강의에서 풀이를 권한 문제는 2건. **공식 퀴즈 첨부본에는 퀴즈 2 (KL divergence) 만 부분적으로 포함**됨.

> 참고: 7, 15, 17행의 "퀴즈" 언급은 기말고사용 자료에 대한 안내이며, 본 강의에서 새로 출제된 퀴즈는 아님.

---

## ❌ 퀴즈 1 — Prior 설정에 따른 MAP/MLE 비교 (Beta prior, m → ∞) [퀴즈 아님 / 자율 권유]

> **공식 퀴즈 첨부본에 미포함**. 3주차 퀴즈 5(M→∞ MAP)의 후속 정리 성격으로, 별도 출제되지 않음.

- **위치**: 약 105~123행 설명, **299행** "이것도 직접 풀어보셨으면 좋겠는데 … 풀어보시길 바랍니다 꼭"
- **문제**: 베타-베르누이 모형에서 prior 설정에 따른 MAP 비교
  - (1) Maximum Likelihood (uniform prior) → θ\*_MLE = k/n
  - (2) Prior ∝ θ(1−θ) (m=1) → θ\*_MAP = (k+1)/(n+2)
  - (3) Prior ∝ θ^m (1−θ)^m, m → ∞ → θ\*_MAP = (k+m)/(n+2m) → 1/2
- **기대 답안 핵심**:
  - prior의 강도(m)에 따라 데이터 vs. knowledge 의존도가 달라진다
  - m → ∞ 일 때 prior가 데이터를 완전히 압도하여 1/2로 수렴

## ⚠️ 퀴즈 2 — 두 정규분포 간 KL Divergence 직접 계산 [공식 퀴즈 — 변형/확장됨]

- **위치**: **301행** "특히 아래 문제는 그러니까 풀어보시기 바랍니다." / 315~319행 "이것도 직접 좀 해보시는 게 좋은데 시간 관계상 넘어가겠습니다."
- **문제**: 두 가우시안 p = N(μ₁, σ₁²), q = N(μ₂, σ₂²)에 대해
  D_KL(p ‖ q) = E_{x~p}[log p(x) − log q(x)] 를 직접 계산.
- **정답**:
  D_KL = log(σ₂/σ₁) + (σ₁² + (μ₁−μ₂)²) / (2σ₂²) − 1/2
- **검증 케이스**:
  - σ₁ = σ₂일 때: 거리 ∝ (μ₁−μ₂)²
  - p = q이면 D_KL = 0
  - 항상 D_KL ≥ 0
- **직관**: KL divergence는 분포 간 "거리" 척도

### 📌 공식 퀴즈 첨부본의 추가 요구사항 (보조 노트)

공식 퀴즈 첨부본(2차 Quiz 2)은 KL divergence **공식이 이미 주어진 상태**에서 다음 두 가지를 추가로 요구:

**(1) σ₁² = σ₂² = 1 인 경우 위 식 단순화**
- 대입: log(1/1) + (1 + (μ₁−μ₂)²)/2 − 1/2
- = 0 + 1/2 + (μ₁−μ₂)²/2 − 1/2
- = **(μ₁ − μ₂)² / 2**
- → 분산이 같으면 KL은 평균 차이의 제곱에 비례 (스케일 1/2).

**(2) CE → NLL → (Gaussian 가정) → MSE 연결 고리 설명**
- Cross Entropy: H(p, q) = H(p) + D_KL(p ‖ q)
- 학습 시 p (true)는 고정 → CE 최소화 = NLL 최소화 = D_KL 최소화
- 모델 출력을 N(μ_θ(x), 1) (등분산 Gaussian)로 가정하고 target을 N(y, 1) 로 본다면:
  - D_KL ∝ (μ_θ(x) − y)² / 2  (위 (1) 결과)
  - = **MSE / 2**
- 결론: **MSE Loss는 "출력이 등분산 Gaussian이라는 가정 하에서 NLL을 최소화"하는 것과 동치**. 회귀 문제에서 MSE를 쓰는 정당화의 핵심.

> ※ 첨부 자체에 "퀴즈 여부 확실치 않음" 표기 존재 — 출제 가능성 있는 보조 문제로 다룰 것.
