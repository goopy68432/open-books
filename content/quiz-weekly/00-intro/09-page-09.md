## Quiz 1. 선형변환 성질 보이기 (1주차)

**행렬 / 기저 벡터:**
```
A = [[1, 1, 1],
     [1, 2, 3]]    (2×3, R³ → R²)

e1 = (1, 0, 0)ᵀ,  e2 = (0, 1, 0)ᵀ,  e3 = (0, 0, 1)ᵀ
```

**문제:** 다음 두 가지를 보여라.
1. **A(e1) + A(e2) = A(e1 + e2)**
2. **2 · A(e1) = A(2 · e1)**

**검증:**
- A·e1 = (1, 1)ᵀ, A·e2 = (1, 2)ᵀ
- A·e1 + A·e2 = (2, 3)ᵀ
- A·(e1 + e2) = A·(1, 1, 0)ᵀ = (2, 3)ᵀ ✓
- 2·A·e1 = (2, 2)ᵀ; A·(2·e1) = A·(2, 0, 0)ᵀ = (2, 2)ᵀ ✓

## Quiz 2. Image / Kernel 4종 구하기 (2주차)

**행렬:**
```
A = (1  2)    (1×2 행 벡터, R² → R¹)
```

**문제:** 다음을 구하시오.
1. **R(A)** (Image of A)
2. **R(Aᵀ)** (Image of Aᵀ)
3. **N(A)** (Kernel of A)
4. **N(Aᵀ)** (Kernel of Aᵀ)

**정답:**
- R(A) = ℝ¹ (rank = 1)
- R(Aᵀ) = span{(1, 2)ᵀ} ⊂ ℝ² (1차원)
- N(A) = {(x₁, x₂) ∈ ℝ² : x₁ + 2x₂ = 0} = span{(2, −1)ᵀ} (1차원)
- N(Aᵀ) = {0} ⊂ ℝ¹ (0차원)

**Rank-Nullity 검증:**
- A: dim(ℝ²) = rank 1 + nullity 1 = 2 ✓
- Aᵀ: dim(ℝ¹) = rank 1 + nullity 0 = 1 ✓

## Quiz 3. Softmax Jacobian (2주차)

**문제:** z ∈ ℝⁿ 에 대해 p = softmax(z) ∈ ℝⁿ 이고
```
p_i = exp(z_i) / Σ_{k=1}^{n} exp(z_k)
```
일 때, **∂p_i / ∂z_j** 를 구하시오.

**정답:**
- **i = j 인 경우**: ∂p_i / ∂z_i = **p_i (1 − p_i)** = p_i − p_i²
- **i ≠ j 인 경우**: ∂p_i / ∂z_j = **− p_i · p_j**

**행렬 형태:** Jacobian J = diag(p) − p · pᵀ ∈ ℝⁿˣⁿ

## Quiz 4. Bayes' theorem 증명 (3주차)

**문제:** 다음을 증명하시오.
```
P(H | E) = P(E | H) · P(H) / P(E)
```
조건부확률의 정의만 사용할 것.

**증명:**
- 정의: P(H | E) = P(H ∩ E) / P(E)
- 정의: P(E | H) = P(H ∩ E) / P(H)
- 두 번째 식에서: **P(H ∩ E) = P(E | H) · P(H)**
- 첫 번째 식에 대입: P(H | E) = **P(E | H) · P(H) / P(E)** ∎

## Quiz 5. MLE (베르누이) — dℓ/dθ (3주차)

**문제:** Likelihood가
```
L(θ) = θ^k · (1 − θ)^(n−k)
```
일 때, ℓ(θ) = log L(θ) 이면 **dℓ(θ) / dθ** 를 구하시오. (MLE)

**풀이:**
- ℓ(θ) = k log θ + (n − k) log(1 − θ)
- **dℓ/dθ = k/θ − (n−k)/(1−θ)**
- 0으로 두고 풀면: k(1−θ) = (n−k)θ → **θ\* = k/n**

---

## Quiz 6. MAP (Beta prior) — dℓ/dθ (3주차)

**문제:** Likelihood가
```
L(θ) = θ^(k+1) · (1 − θ)^(n−k+1)
```
일 때, ℓ(θ) = log L(θ) 이면 **dℓ(θ) / dθ** 를 구하시오. (MLE 형식이지만 본질은 prior θ(1−θ)를 곱한 MAP)

**풀이:**
- ℓ(θ) = (k+1) log θ + (n−k+1) log(1−θ)
- **dℓ/dθ = (k+1)/θ − (n−k+1)/(1−θ)**
- 0으로 두고 풀면: **θ\*\* = (k+1) / (n+2)**
- 예: n=3, k=3 → θ\*\* = 4/5 = 0.8 (MLE의 1.0 대비 prior가 끌어내림)

---

## Quiz 7. MAP 극한 (3주차)

**문제:** Prior가
```
p(θ) ∝ θ^M · (1 − θ)^M
```
일 때, **M → ∞ 이면 θ\*_MAP = ?**

**풀이:**
- log posterior ∝ (k+M) log θ + (n−k+M) log(1−θ) + const
- MAP: **θ\*_MAP = (k+M) / (n+2M)**
- M → ∞ 극한: (k+M)/(n+2M) → M/(2M) = **1/2**

**핵심:** prior가 0.5에 매우 강하게 집중되면(M 큼) 데이터를 무시하고 θ → 1/2.

## Quiz 8. KL Divergence + MSE 연결 (4주차 영역) ⚠️ 퀴즈 여부 확실치 않음

**전제 (주어진 식):** 1변량 Gaussian 분포의 KL divergence
```
KL(N(μ₁, σ₁²) ‖ N(μ₂, σ₂²))
  = (1/2) [ 2 log(σ₂/σ₁) + σ₁²/σ₂² + (μ₁ − μ₂)²/σ₂² − 1 ]
```

### (1) σ₁² = σ₂² = 1 인 경우 위 식을 단순화
**풀이:**
- = (1/2) [ 2·0 + 1 + (μ₁ − μ₂)² − 1 ]
- = **(μ₁ − μ₂)² / 2**

### (2) 이 결과가 딥러닝 학습의 CE → NLL → (Gaussian 가정) → MSE 연결 고리와 어떻게 이어지는지 설명

**설명:**
- Cross Entropy: H(p, q) = H(p) + D_KL(p ‖ q)
  - 학습 시 p (true)는 고정 → CE 최소화 ⇔ NLL 최소화 ⇔ D_KL(p ‖ q_θ) 최소화
- 모델 출력을 q_θ = N(μ_θ(x), 1) (등분산 1 Gaussian), target을 p = N(y, 1) 로 가정
- (1) 결과 적용: D_KL = (μ_θ(x) − y)² / 2 = **MSE / 2**
- 결론: **MSE Loss는 "출력이 등분산 Gaussian이라는 가정 하의 NLL 최소화"와 동치**.
- → 회귀 문제에서 MSE를 쓰는 통계적 정당화의 핵심 고리.

## Quiz 9. Triangular Prior MAP (6주차 영역)

**Prior 정의:**
```
              ┌  0                           if |θ − 0.5| ≥ 1/m
p_m(θ) =  ──┤
              └  m − m² |θ − 0.5|            if |θ − 0.5| ≤ 1/m
```
- 받침(support): [0.5 − 1/m, 0.5 + 1/m]
- 정점: θ = 0.5에서 p_m(0.5) = m
- 적분 면적 = 1 (정규화된 PDF)

**관측:** 동전을 n = 5 번 던져 k = 4 번 앞면.

**문제:** **m = 2 일 때**와 **m = 6 일 때**, prior p_m(θ) 는 각각 어떤 형태인가? (그리고 각 경우 MAP θ\* 은?)

**답안:**

| m | 받침 | 정점 높이 | 형태 | MAP θ\* (n=5, k=4) |
|---|------|-----------|------|---------------------|
| 2 | [0, 1] (전 구간) | 2 | 넓고 완만한 삼각형 | log posterior 미분 0 → 받침이 전 구간이므로 내부 임계점 (대략 θ\* ≈ 0.7~0.75 부근) |
| 6 | [1/3, 2/3] | 6 | 좁고 뾰족한 삼각형 | MLE = k/n = 0.8 은 받침 밖 → **θ\* = 2/3** (받침 경계에서 최대) |

**핵심 통찰:** m이 클수록 prior가 0.5 주변에 집중되어 strong prior로 기능. 데이터가 받침 밖의 θ를 선호해도 prior가 그것을 막음.

## Quiz 10. Backpropagation 편미분 (8주차)

**네트워크 구조:**
```
x → z₁ = W₁·x → x₁ = ReLU(z₁) → z = W₂·x₁ → p = softmax(z) → p_y = e_yᵀ·p → L = −log p_y
```

**문제:** 노란 형광펜으로 표시된 다음 3개의 편미분을 구하시오.

### (1) ∂L / ∂p_y
- L = −log p_y
- **∂L / ∂p_y = −1 / p_y**

### (2) ∂p_y / ∂p
- p_y = e_yᵀ · p (true class y 위치만 추출)
- **∂p_y / ∂p = e_yᵀ** (1×C 행벡터, y번째 성분만 1, 나머지 0)

### (3) ∂p / ∂z (단, p = softmax(z))
- Softmax Jacobian (Quiz 3 결과 재활용)
- **∂p / ∂z = diag(p) − p · pᵀ** ∈ ℝᶜˣᶜ

### Chain rule 합성 (참고)
- ∂L/∂z = (∂L/∂p_y) · (∂p_y/∂p) · (∂p/∂z)
- = (−1/p_y) · e_yᵀ · (diag(p) − p·pᵀ)
- = **p − e_y** (predicted − true_onehot)

→ "Softmax + Cross Entropy 미분 = predicted − true" 라는 유명한 결과.

## Quiz 11. 1D Convolution 직접 계산 (9주차)

**문제:** Kernel `w = [1, 2]` 를 사용하여 다음 각 x ∈ ℝ⁷ 에 대해 **w * x ∈ ℝ⁶** 을 구하라.

**정의:** (w * x)_i = 1 · x_i + 2 · x_{i+1}, i = 1, ..., 6

| # | 입력 x | 출력 w * x |
|---|--------|------------|
| (1) | (0, 1, 2, 3, 4, 5, 6)ᵀ | **(2, 5, 8, 11, 14, 17)** |
| (2) | (1, 1, 1, 1, 1, 1, 1)ᵀ | **(3, 3, 3, 3, 3, 3)** |
| (3) | (1, 2, 3, 4, 5, 6, 7)ᵀ | **(4, 7, 10, 13, 16, 19)** |
| (4) | (0, 2, 4, 6, 8, 10, 12)ᵀ | **(4, 10, 16, 22, 28, 34)** |

**관찰:** (2)와 (4)는 (1)의 상수배·선형결합으로 생성 가능 → 컨볼루션은 **선형 변환**.

## Quiz 12. 1D Convolution Matrix (6×7) (9주차)

**문제:** Kernel `w = [1, 2]` 를 사용하는 convolution `f: ℝ⁷ → ℝ⁶` 에 대해, 7차원 표준 기저 벡터 e₁, e₂, …, e₇ 각각의 convolution 결과를 이용하여 **Convolution Matrix A ∈ ℝ⁶ˣ⁷** 를 구하라.

**풀이 방법:** A의 j번째 열 = f(e_j) (Quiz 1·Quiz 2와 동일한 "기저의 상을 열로" 구성법)

**정답:**
```
       col1 col2 col3 col4 col5 col6 col7
row1 [  1    2    0    0    0    0    0  ]
row2 [  0    1    2    0    0    0    0  ]
row3 [  0    0    1    2    0    0    0  ]
row4 [  0    0    0    1    2    0    0  ]
row5 [  0    0    0    0    1    2    0  ]
row6 [  0    0    0    0    0    1    2  ]
```

**구조적 관찰:**
- **Sparse**: 42개 셀 중 비영(非零) 12개
- **Weight sharing**: 모든 행이 동일 가중치 [1, 2] 사용 (위치만 시프트)
- **Toeplitz** (= banded sparse + translation-invariant)

**검증:** A · (0,1,2,3,4,5,6)ᵀ = (2, 5, 8, 11, 14, 17)ᵀ ✓ (Quiz 11-(1)과 일치)

## Quiz 13. 2D Convolution Matrix (4×9) (9주차)

**문제:** Kernel
```
w = [[0, 1],
     [2, 3]]    (2×2)
```
를 사용하는 2D convolution `f: ℝ⁹ → ℝ⁴` (입력: 3×3 이미지, 출력: 2×2 feature map) 에 대해, 9차원 표준 기저 벡터 e₁, …, e₉ 각각의 convolution 결과를 이용하여 **Convolution Matrix A ∈ ℝ⁴ˣ⁹** 를 구하라.

**입력 평탄화 인덱스 (row-major):**
```
이미지 위치       평탄화 인덱스
(0,0) (0,1) (0,2)        1  2  3
(1,0) (1,1) (1,2)   →    4  5  6
(2,0) (2,1) (2,2)        7  8  9
```

**출력 (i, j) 계산식:** 입력 2×2 패치와 [[0,1],[2,3]] 의 element-wise 곱 합
- 출력 (0,0) = 0·x₁ + 1·x₂ + 2·x₄ + 3·x₅
- 출력 (0,1) = 0·x₂ + 1·x₃ + 2·x₅ + 3·x₆
- 출력 (1,0) = 0·x₄ + 1·x₅ + 2·x₇ + 3·x₈
- 출력 (1,1) = 0·x₅ + 1·x₆ + 2·x₈ + 3·x₉

**정답 행렬 A ∈ ℝ⁴ˣ⁹:**
```
       x1   x2   x3   x4   x5   x6   x7   x8   x9
y1 [   0    1    0    2    3    0    0    0    0  ]   ← 출력 (0,0)
y2 [   0    0    1    0    2    3    0    0    0  ]   ← 출력 (0,1)
y3 [   0    0    0    0    1    0    2    3    0  ]   ← 출력 (1,0)
y4 [   0    0    0    0    0    1    0    2    3  ]   ← 출력 (1,1)
```

**구조적 관찰 (1D 케이스 일반화):**
- **Sparse**: 36개 셀 중 비영(非零) 16개 (4행 × 4개)
- **Weight sharing**: 4개 출력 모두 동일 가중치 집합 {0, 1, 2, 3} 사용
- **Locality**: 각 출력은 입력의 인접 4개 위치만 참조
- → 2D 컨볼루션도 **sparse + weight-shared 선형 변환**임이 행렬 형태로 명시됨.
