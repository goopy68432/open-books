# 딥러닝이론 9주차 퀴즈

수업 중 풀이 4건이 확인됨. **공식 퀴즈 첨부본에 매칭되는 항목은 퀴즈 1, 2, 3** (3건)이며, 퀴즈 4 (AlexNet)는 자율 과제로 공식 퀴즈에 미포함.

## ✅ 퀴즈 1. 1D Convolution 직접 계산 (4개 입력) [공식 퀴즈]

- **위치**: 스크립트 약 209~231행
- **교안 슬라이드**: `DL/0425_images/page_512.jpeg` (강의자료 슬라이드 #464, 우측 상단 "Q." 배지)
- **시간**: 약 5분

### 문제 설정 (슬라이드 기준)
- 커널: **w = [1, 2]**
- 입력 7차원 → 출력 6차원
- 컨볼루션 공식: `[w*x](i) = Σ_u w_u · x_{i−u}` (slide #463 / `page_511.jpeg`)

### 4개 입력 벡터 (슬라이드에 명시)
| # | 입력 x ∈ ℝ⁷ | 출력 (w * x) ∈ ℝ⁶ |
|---|-------------|--------------------|
| 1 | (0, 1, 2, 3, 4, 5, 6) | **(2, 5, 8, 11, 14, 17)** ← 강의 중 예시로 제공 |
| 2 | (1, 1, 1, 1, 1, 1, 1) | (3, 3, 3, 3, 3, 3) |
| 3 | (1, 2, 3, 4, 5, 6, 7) | (4, 7, 10, 13, 16, 19) |
| 4 | (0, 2, 4, 6, 8, 10, 12) | (4, 10, 16, 22, 28, 34) |

> 출력 i번째 = `1 · x_i + 2 · x_{i+1}` (커널 [1,2] 기준 1D 컨볼루션 / 사실상 cross-correlation)

### 보너스 sub-문제 (같은 슬라이드)
- 표준 기저 e₁, e₂, …, e₇ ∈ ℝ⁷ 각각을 컨볼루션해 보라.
- → 결과들이 **다음 퀴즈(2번)의 6×7 행렬의 각 열**이 된다는 점이 핵심 통찰.

### 사고 과제 (스크립트 241행)
다 푼 학생에게 결과의 시사점 생각해보라 → 분배법칙 확인:
`f(x+y) = f(x)+f(y)`, `f(αx) = α·f(x)` ⇒ **컨볼루션은 linear transformation**.

## ✅ 퀴즈 2. Convolution에 대응하는 6×7 행렬 채우기 [공식 퀴즈]

- **위치**: 스크립트 약 281~303행 (지시 285·291행, "5분 드릴게요" 두 차례)
- **교안 슬라이드**: `DL/0425_images/page_513.jpeg` (슬라이드 #465)
- **시간**: 약 5분

### 슬라이드 헤더 (학습 포인트)
- convolution operation = **linear** = matrix
- inductive bias (feature detector)
- **locality** ⇒ sparse matrix
- **translation invariance** ⇒ weight sharing

### 문제
빈 6×7 행렬 W ∈ ℝ⁶ˣ⁷ 의 각 칸을 채워, `W·x = w * x` (퀴즈 1의 입력에 대해) 가 성립하도록 하라.

### 정답 (Toeplitz 형태, banded sparse + weight-shared)
```
       col1 col2 col3 col4 col5 col6 col7
row1 [  1    2    0    0    0    0    0  ]
row2 [  0    1    2    0    0    0    0  ]
row3 [  0    0    1    2    0    0    0  ]
row4 [  0    0    0    1    2    0    0  ]
row5 [  0    0    0    0    1    2    0  ]
row6 [  0    0    0    0    0    1    2  ]
```

### 도출 방법 (퀴즈 1 보너스와 연결)
- W의 j번째 **열** = `f(e_j)` (e_j는 j번째 표준기저)
- e₁ → (1,0,0,0,0,0) → 1열
- e₂ → (2,1,0,0,0,0) → 2열
- ⋯ 한 칸씩 시프트되는 [1,2] 패턴 = **Toeplitz**

### 슬라이드 검증식
`x = [0,1,2,3,4,5,6]` 대입 시 `W·x = [2, 5, 8, 11, 14, 17]` (퀴즈 1 결과와 일치).

## ✅ 퀴즈 3. 2D Convolution에 대응하는 4×9 행렬 (3×3 → 2×2) [공식 퀴즈]

- **위치**: 스크립트 line 327~343 (1D conv 행렬 풀이 직후 자연스럽게 이어짐)
- **교안 슬라이드**: `DL/0425_images/page_513.jpeg` 부근 (슬라이드 #463)

### 문제 설정
- Kernel: **w = [[0, 1], [2, 3]]** (2×2)
- 입력: 3×3 이미지 → 9차원으로 평탄화 (`x ∈ ℝ⁹`)
- 출력: 2×2 feature map (`y ∈ ℝ⁴`)
- **표준 기저** e₁, e₂, …, e₉를 conv에 통과시켜 결과를 열에 채워 **A ∈ ℝ⁴ˣ⁹** 행렬 작성

### 인용 (스크립트)
> line 327: "9를 4차원으로 보내는 거죠. 그럼 매트릭스로서는 몇 차원, 몇 바이브 하실까요?"
> line 337: "e1, e2, e9까지 9개를 보내야 돼요. 9개를 보내서 걔네들을 컬럼으로 채워 놔야 됩니다."
> line 339: "이걸 아홉 개를 생각해서 아홉 개를 다 보내봐서 어떻게 되는지 이 4x9 매트릭스 채워주는 거"

### 풀이 방법
입력 3×3 이미지를 row-major로 평탄화하여 인덱스 부여:
```
이미지 위치  →  평탄화 인덱스
(0,0) (0,1) (0,2)      1  2  3
(1,0) (1,1) (1,2)  =>  4  5  6
(2,0) (2,1) (2,2)      7  8  9
```

출력 위치 (i, j)의 값 = 입력 2×2 패치와 커널 [[0,1],[2,3]]의 element-wise 곱 합:
- 출력 (0,0): 0·x[1] + 1·x[2] + 2·x[4] + 3·x[5]
- 출력 (0,1): 0·x[2] + 1·x[3] + 2·x[5] + 3·x[6]
- 출력 (1,0): 0·x[4] + 1·x[5] + 2·x[7] + 3·x[8]
- 출력 (1,1): 0·x[5] + 1·x[6] + 2·x[8] + 3·x[9]

### 정답 행렬 A ∈ ℝ⁴ˣ⁹
```
       x1   x2   x3   x4   x5   x6   x7   x8   x9
y1 [   0    1    0    2    3    0    0    0    0  ]   ← 출력 (0,0)
y2 [   0    0    1    0    2    3    0    0    0  ]   ← 출력 (0,1)
y3 [   0    0    0    0    1    0    2    3    0  ]   ← 출력 (1,0)
y4 [   0    0    0    0    0    1    0    2    3  ]   ← 출력 (1,1)
```

### 핵심 관찰 (1D 케이스와 동일)
- **Sparse**: 36개 셀 중 비영(非零) 16개. 패치 밖 위치는 모두 0.
- **Weight sharing**: 4개 행 모두 같은 가중치 집합 {0, 1, 2, 3}을 사용. 위치만 시프트.
- **Locality**: 각 출력은 입력의 인접한 4개 위치만 참조.
- → 2D 컨볼루션도 sparse + weight-shared 선형 변환임이 행렬 형태로 명시됨.

## ❌ 퀴즈 4. AlexNet 레이어별 Shape 변환 직접 검증 [퀴즈 아님 / 자율 과제]

> **공식 퀴즈 첨부본에 미포함**. 강의 마무리에 "시간 났을 때 해보시길" 수준의 자율 권유.

- **위치**: 스크립트 약 463행
- **교안 슬라이드**: `DL/0425_images/page_520.jpeg` (슬라이드 #472, "ConvNet - AlexNet")
- **차원 공식 슬라이드**: `DL/0425_images/page_515.jpeg` (슬라이드 #467)
- **시간**: 자율 과제

### 차원 공식
`H_out = ⌊(H_in + 2p − k) / s⌋ + 1`
(default: s = 1, p = 0)

### 검증해야 할 4단계 변환 (슬라이드 기준)
| 단계 | 연산 | 입력 shape | 출력 shape |
|------|------|------------|------------|
| 0 | 입력 | — | **227 × 227 × 3** |
| 1 | ReLU ∘ Conv(c_in=3, c_out=96, k=11, s=4) | 227×227×3 | **55 × 55 × 96** |
| 2 | MaxPool(k=3, s=2) | 55×55×96 | **27 × 27 × 96** |
| 3 | ReLU ∘ Conv(c_in=96, c_out=256, k=5, p=2) | 27×27×96 | **27 × 27 × 256** |
| 4 | MaxPool(k=3, s=2) | 27×27×256 | **13 × 13 × 256** |
| ⋮ | (중간 conv 생략) | — | — |
| 최종 feature map | — | — | **6 × 6 × 256** |

### 검증 예
- 단계 1: `(227 + 0 − 11)/4 + 1 = 216/4 + 1 = 54 + 1 = 55` ✓
- 단계 2: `(55 − 3)/2 + 1 = 26 + 1 = 27` ✓
- 단계 3: `(27 + 4 − 5)/1 + 1 = 26 + 1 = 27` ✓ (padding=2가 차원 유지)
- 단계 4: `(27 − 3)/2 + 1 = 12 + 1 = 13` ✓
