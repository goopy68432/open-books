## Quiz 1. 선형변환 성질 보이기 (1주차)
**[접근 방식]**
행렬 연산이 선형 변환(Linear Transformation)의 두 가지 핵심 공리인 '가산성(Additivity)'과 '동차성(Homogeneity)'을 만족함을 벡터의 합과 스칼라 곱을 통해 증명합니다.

**[수식 유도 및 증명]**
주어진 행렬 $A = \begin{pmatrix} 1 & 1 & 1 \\ 1 & 2 & 3 \end{pmatrix}$ 와 기저 벡터 $e_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, e_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}$ 에 대하여:

**1. 가산성 보존: $A(e_1) + A(e_2) = A(e_1 + e_2)$**
좌변 계산:
$A e_1 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}, \quad A e_2 = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$
$A e_1 + A e_2 = \begin{pmatrix} 1 \\ 1 \end{pmatrix} + \begin{pmatrix} 1 \\ 2 \end{pmatrix} = \begin{pmatrix} 2 \\ 3 \end{pmatrix}$

우변 계산:
벡터의 합 $e_1 + e_2 = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}$
$A(e_1 + e_2) = \begin{pmatrix} 1 & 1 & 1 \\ 1 & 2 & 3 \end{pmatrix} \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} = \begin{pmatrix} 1\cdot1 + 1\cdot1 + 1\cdot0 \\ 1\cdot1 + 2\cdot1 + 3\cdot0 \end{pmatrix} = \begin{pmatrix} 2 \\ 3 \end{pmatrix}$
좌변과 우변이 동일하므로 성립. $\blacksquare$

**2. 동차성 보존: $2 \cdot A(e_1) = A(2 \cdot e_1)$**
좌변 계산:
$2 \cdot A e_1 = 2 \cdot \begin{pmatrix} 1 \\ 1 \end{pmatrix} = \begin{pmatrix} 2 \\ 2 \end{pmatrix}$

우변 계산:
$2 \cdot e_1 = \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix}$
$A(2 \cdot e_1) = \begin{pmatrix} 1 & 1 & 1 \\ 1 & 2 & 3 \end{pmatrix} \begin{pmatrix} 2 \\ 0 \\ 0 \end{pmatrix} = \begin{pmatrix} 1\cdot2 \\ 1\cdot2 \end{pmatrix} = \begin{pmatrix} 2 \\ 2 \end{pmatrix}$
좌변과 우변이 동일하므로 성립. $\blacksquare$

## Quiz 2. Image / Kernel 4종 구하기 (2주차)
**[접근 방식]**
행렬 $A$ 의 Image(상공간, 열공간)와 Kernel(영공간)의 정의를 사용합니다. $\text{Image}(A) = \{ Ax \mid x \in \mathbb{R}^n \}$, $\text{Kernel}(A) = \{ x \in \mathbb{R}^n \mid Ax = 0 \}$. 이후 Rank-Nullity Theorem으로 차원의 보존을 검증합니다.

**[수식 유도 및 증명]**
$A = \begin{pmatrix} 1 & 2 \end{pmatrix} : \mathbb{R}^2 \to \mathbb{R}^1$

**1. $R(A)$ (Image of $A$)**
$Ax = \begin{pmatrix} 1 & 2 \end{pmatrix} \begin{pmatrix} x_1 \\ x_2 \end{pmatrix} = x_1 + 2x_2 \in \mathbb{R}$. $x_1, x_2$는 임의의 실수이므로 모든 실수를 생성할 수 있습니다.
$\therefore R(A) = \mathbb{R}^1$ (Rank = 1)

**2. $R(A^T)$ (Image of $A^T$)**
$A^T = \begin{pmatrix} 1 \\ 2 \end{pmatrix} : \mathbb{R}^1 \to \mathbb{R}^2$. 입력값 $c \in \mathbb{R}$ 에 대해 $c \begin{pmatrix} 1 \\ 2 \end{pmatrix}$ 형태로 나타납니다.
$\therefore R(A^T) = \text{span}\left\{ \begin{pmatrix} 1 \\ 2 \end{pmatrix} \right\} \subset \mathbb{R}^2$ (Rank = 1)

**3. $N(A)$ (Kernel of $A$)**
$Ax = x_1 + 2x_2 = 0 \implies x_1 = -2x_2$. 이를 만족하는 해공간은 $x_2 \begin{pmatrix} -2 \\ 1 \end{pmatrix}$ 의 형태입니다.
$\therefore N(A) = \text{span}\left\{ \begin{pmatrix} -2 \\ 1 \end{pmatrix} \right\}$ (Nullity = 1)

**4. $N(A^T)$ (Kernel of $A^T$)**
$A^T x = \begin{pmatrix} 1 \\ 2 \end{pmatrix} x = \begin{pmatrix} 0 \\ 0 \end{pmatrix} \implies x = 0$.
$\therefore N(A^T) = \{ 0 \} \subset \mathbb{R}^1$ (Nullity = 0)

**[Rank-Nullity 검증]**
- $A: \mathbb{R}^2 \to \mathbb{R}^1$ 에서, 정의역 차원(2) = Rank(1) + Nullity(1) $\blacksquare$
- $A^T: \mathbb{R}^1 \to \mathbb{R}^2$ 에서, 정의역 차원(1) = Rank(1) + Nullity(0) $\blacksquare$

## Quiz 3. Softmax Jacobian (2주차)
**[접근 방식]**
소프트맥스 함수는 벡터를 입력받아 벡터를 출력하므로 미분 결과는 야코비안 행렬(Jacobian matrix) 형태를 가집니다. 지수함수의 미분과 몫의 미분법(Quotient Rule)을 사용하여 유도합니다.

**[수식 유도 및 증명]**
소프트맥스 함수: $p_i = \frac{e^{z_i}}{\sum_{k=1}^n e^{z_k}}$. 분모를 $S = \sum_{k=1}^n e^{z_k}$ 라 둡니다.

**1. $i = j$ 인 경우의 편미분:**
$\frac{\partial}{\partial z_i} (e^{z_i}) = e^{z_i}$, $\frac{\partial}{\partial z_i} (S) = e^{z_i}$ 이므로 몫의 미분법에 의해:
$\frac{\partial p_i}{\partial z_i} = \frac{\frac{\partial (e^{z_i})}{\partial z_i} S - e^{z_i} \frac{\partial S}{\partial z_i}}{S^2} = \frac{e^{z_i} S - (e^{z_i})^2}{S^2} = \frac{e^{z_i}}{S} - \left(\frac{e^{z_i}}{S}\right)^2 = p_i - p_i^2 = p_i(1 - p_i)$

**2. $i \neq j$ 인 경우의 편미분:**
$\frac{\partial}{\partial z_j} (e^{z_i}) = 0$, $\frac{\partial}{\partial z_j} (S) = e^{z_j}$ 이므로:
$\frac{\partial p_i}{\partial z_j} = \frac{0 \cdot S - e^{z_i} e^{z_j}}{S^2} = -\left(\frac{e^{z_i}}{S}\right)\left(\frac{e^{z_j}}{S}\right) = -p_i p_j$

이를 결합하면 야코비안 행렬 $J \in \mathbb{R}^{n \times n}$ 은 $J = \text{diag}(p) - p p^T$ 형태가 됩니다. $\blacksquare$

## Quiz 4. Bayes' theorem 증명 (3주차)
**[접근 방식]**
조건부 확률의 수학적 정의 $P(A|B) = \frac{P(A \cap B)}{P(B)}$ 로부터 교집합 확률을 매개변수로 삼아 베이즈 정리를 유도합니다.

**[수식 유도 및 증명]**
1) 조건부 확률 정의에 따라 사후 확률은:
$P(H | E) = \frac{P(H \cap E)}{P(E)}$
2) 우도 연관 조건부 확률의 정의는:
$P(E | H) = \frac{P(E \cap H)}{P(H)} = \frac{P(H \cap E)}{P(H)}$
3) 두 번째 식의 양변에 $P(H)$를 곱하여 교집합 확률을 표현합니다:
$P(H \cap E) = P(E | H) P(H)$
4) 이를 첫 번째 식의 분자에 대입합니다:
$P(H | E) = \frac{P(E | H) P(H)}{P(E)}$
조건부 확률의 정의만으로 베이즈 정리 유도 완료. $\blacksquare$

## Quiz 5. MLE (베르누이) (3주차)
**[접근 방식]**
곱셈 형태의 우도(Likelihood) 함수를 로그 우도(Log-likelihood)로 변환하여 덧셈 형태로 만들고, 파라미터 $\theta$ 에 대해 1계 도함수를 구하여 최적점(기울기가 0이 되는 지점)을 찾습니다.

**[수식 유도 및 증명]**
$L(\theta) = \theta^k (1 - \theta)^{n-k}$
로그 우도 함수 변환:
$\ell(\theta) = \ln L(\theta) = k \ln \theta + (n-k) \ln(1 - \theta)$

$\theta$ 에 대한 편미분:
$\frac{d\ell}{d\theta} = \frac{k}{\theta} - \frac{n-k}{1-\theta}$

극대값을 찾기 위해 미분값을 0으로 둡니다:
$\frac{k}{\theta} - \frac{n-k}{1-\theta} = 0 \implies \frac{k}{\theta} = \frac{n-k}{1-\theta}$
대각선으로 곱하여 정리:
$k(1-\theta) = \theta(n-k)$
$k - k\theta = n\theta - k\theta$
$k = n\theta \implies \theta^*_{\text{MLE}} = \frac{k}{n}$ $\blacksquare$

## Quiz 6. MAP (Beta prior) (3주차)
**[접근 방식]**
사전 확률(Beta prior)이 적용되어 지수가 $+1$ 씩 증가한 우도 함수에 대해 MLE와 동일한 로그 변환 및 미분 과정을 거쳐 Maximum A Posteriori 추정치를 유도합니다.

**[수식 유도 및 증명]**
$L(\theta) \propto \theta^{k+1} (1 - \theta)^{n-k+1}$
로그 변환:
$\ell(\theta) = (k+1) \ln \theta + (n-k+1) \ln(1 - \theta)$

$\theta$ 에 대한 편미분:
$\frac{d\ell}{d\theta} = \frac{k+1}{\theta} - \frac{n-k+1}{1-\theta}$

미분값을 0으로 둡니다:
$\frac{k+1}{\theta} = \frac{n-k+1}{1-\theta}$
$(k+1)(1-\theta) = \theta(n-k+1)$
$k+1 - (k+1)\theta = n\theta - k\theta + \theta$
$k+1 = n\theta - k\theta + \theta + k\theta + \theta = \theta(n+2)$
$\therefore \theta^*_{\text{MAP}} = \frac{k+1}{n+2}$ $\blacksquare$

## Quiz 7. MAP 극한 (3주차)
**[접근 방식]**
MAP 공식에서 사전 확률의 강도를 조절하는 하이퍼파라미터 $M$ 이 무한대로 갈 때의 극한값을 계산하여, 사전 편견이 극단적으로 강할 경우 데이터의 영향을 무시함을 증명합니다.

**[수식 유도 및 증명]**
Prior $p(\theta) \propto \theta^M (1-\theta)^M$ 일 때 MAP 추정치는 $\theta^*_{\text{MAP}} = \frac{k+M}{n+2M}$ 입니다.
극한 계산:
$\lim_{M \to \infty} \frac{k+M}{n+2M} = \lim_{M \to \infty} \frac{M(\frac{k}{M} + 1)}{M(\frac{n}{M} + 2)}$
$M \to \infty$ 일 때 $\frac{k}{M} \to 0$, $\frac{n}{M} \to 0$ 이므로:
$= \frac{0 + 1}{0 + 2} = \frac{1}{2}$
강력한 사전 확률에 의해 $\theta$ 가 0.5로 수렴함을 논리적으로 완결. $\blacksquare$

## Quiz 8. KL Divergence + MSE 연결 (4주차 영역)
**[접근 방식]**
가우시안 분포 간의 KL Divergence 일반식에 등분산 가정($\sigma_1^2 = \sigma_2^2 = 1$)을 적용하여 수식을 정리하고, 이를 통해 딥러닝 회귀 문제에서 NLL(Negative Log Likelihood) 최소화가 MSE 최소화와 수학적으로 동치임을 보입니다.

**[수식 유도 및 증명]**
1변량 Gaussian KL Divergence:
$D_{KL}(N(\mu_1, \sigma_1^2) \| N(\mu_2, \sigma_2^2)) = \frac{1}{2} \left[ 2 \ln \frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2}{\sigma_2^2} + \frac{(\mu_1 - \mu_2)^2}{\sigma_2^2} - 1 \right]$

$\sigma_1 = \sigma_2 = 1$ 대입:
$= \frac{1}{2} \left[ 2 \ln(1) + 1 + \frac{(\mu_1 - \mu_2)^2}{1} - 1 \right]$
$\ln(1) = 0$ 이고 $1$ 과 $-1$ 이 상쇄되므로:
$= \frac{1}{2} (\mu_1 - \mu_2)^2$

**논리적 연결성:**
예측값 $\mu_\theta(x)$ 와 실제 타겟 $y$ 에 대해 각각을 평균으로 하는 등분산 가우시안 분포를 가정하면, 두 분포 간의 KL Divergence는 $\frac{(\mu_\theta(x) - y)^2}{2}$ 가 됩니다. 이는 상수 배율을 제외하면 정확히 Mean Squared Error(MSE)와 동일합니다. 따라서 MSE는 출력이 가우시안이라는 가정 하의 NLL 최소화와 동치입니다. $\blacksquare$

## Quiz 9. Triangular Prior MAP (6주차 영역)
**[접근 방식]**
사전 확률 분포가 삼각형(Piecewise function) 형태로 주어졌을 때, 받침(Support) 구간의 변화에 따라 최대 사후 확률(MAP) 추정치가 어떻게 변하는지 구간적 조건과 함께 분석합니다.

**[수식 유도 및 증명]**
$m=2$ 일 때, 받침 범위: $[0.5 - 1/2, 0.5 + 1/2] = [0, 1]$
모든 가능한 확률 $\theta$ 구간에 대해 사전 확률이 정의되므로 극대값 미분 조건에 의해 $\theta^*$ 는 관측치에 기반한 내부 임계점(대략 0.7~0.75 부근)으로 수렴합니다.

$m=6$ 일 때, 받침 범위: $[0.5 - 1/6, 0.5 + 1/6] = [1/3, 2/3]$
데이터(n=5, k=4)에 의한 MLE는 $\theta = 0.8$ 이지만, 이는 받침 영역 밖이므로 $p_m(0.8) = 0$ 이 되어 사후 확률이 0이 됩니다. 함수가 지원되는 구간 $[1/3, 2/3]$ 내에서 우도(Likelihood)는 단조 증가하므로 구간의 상한인 $\theta^*_{\text{MAP}} = 2/3$ 가 채택됩니다. $\blacksquare$

## Quiz 10. Backpropagation 편미분 (8주차)
**[접근 방식]**
손실 함수에서 가중치 합 $z$ 로 이어지는 연쇄 법칙(Chain Rule)을 각 단계별(Cross Entropy $\to$ 정답 클래스 추출 $\to$ Softmax) 야코비안 계산으로 분리하여 전개합니다.

**[수식 유도 및 증명]**
목표 미분: $\frac{\partial L}{\partial z} = \frac{\partial L}{\partial p_y} \frac{\partial p_y}{\partial p} \frac{\partial p}{\partial z}$
주어진 식: $L = -\ln p_y, \quad p_y = e_y^T p, \quad p = \text{softmax}(z)$

(1) $\frac{\partial L}{\partial p_y} = -\frac{1}{p_y}$
(2) $\frac{\partial p_y}{\partial p} = e_y^T$ (정답 인덱스 y에만 1이 있는 원-핫 행벡터)
(3) $\frac{\partial p}{\partial z} = \text{diag}(p) - p p^T$ (Quiz 3 결과 인용)

**연쇄 법칙 조립:**
$\frac{\partial L}{\partial z} = \left(-\frac{1}{p_y}\right) e_y^T (\text{diag}(p) - p p^T)$
벡터와 행렬의 분배법칙 적용:
$e_y^T \text{diag}(p)$ 는 벡터 $p$ 의 $y$번째 성분 $p_y$ 만 남긴 행벡터 $[0, \dots, p_y, \dots, 0]$
$e_y^T p p^T = (e_y^T p) p^T = p_y p^T$
대입:
$= -\frac{1}{p_y} \left( [0, \dots, p_y, \dots, 0] - p_y p^T \right)$
$= -[0, \dots, 1, \dots, 0] + p^T = p^T - e_y^T$
열벡터 표기법으로 전환하면 $\frac{\partial L}{\partial z} = p - e_y$ (예측 확률 벡터 - 정답 원-핫 벡터) 가 도출됩니다. $\blacksquare$

## Quiz 11. 1D Convolution 직접 계산 (9주차)
**[접근 방식]**
1차원 합성곱의 정의 수식을 이산 벡터 공간의 스칼라 선형 결합으로 치환하여 직접 계산합니다.

**[수식 유도 및 증명]**
수식: $(w * x)_i = 1 \cdot x_i + 2 \cdot x_{i+1}$ (Kernel $w=[1, 2]$)
$x = (0, 1, 2, 3, 4, 5, 6)^T$ 인 경우:
- $y_1 = 1(0) + 2(1) = 2$
- $y_2 = 1(1) + 2(2) = 5$
- $y_3 = 1(2) + 2(3) = 8$
- $y_4 = 1(3) + 2(4) = 11$
- $y_5 = 1(4) + 2(5) = 14$
- $y_6 = 1(5) + 2(6) = 17$
결과 벡터: $(2, 5, 8, 11, 14, 17)^T$. 선형 변환 성질을 만족함을 확인. $\blacksquare$

## Quiz 12. 1D Convolution Matrix (6×7) (9주차)
**[접근 방식]**
모든 선형 변환은 표준 기저 벡터 $e_j$ 들의 상(Image)을 열벡터로 갖는 행렬로 표현될 수 있다는 대수적 원리를 이용합니다.

**[수식 유도 및 증명]**
입력 벡터의 차원 7, 출력 벡터의 차원 6.
각 기저 벡터 $e_j$ (j번째 인덱스만 1이고 나머지는 0)를 합성곱 연산에 통과시킵니다.
- $f(e_1)$: $x_1=1$, 나머지 $x_i=0 \implies y_1=1$, 나머지 $y_i=0 \implies (1, 0, 0, 0, 0, 0)^T$ (행렬의 1열)
- $f(e_2)$: $x_2=1 \implies y_1=2, y_2=1 \implies (2, 1, 0, 0, 0, 0)^T$ (행렬의 2열)
위 과정을 7열까지 반복하면 대각선을 따라 가중치 $[1, 2]$가 이동하는 Sparse한 Toeplitz 행렬 $A \in \mathbb{R}^{6 \times 7}$ 이 구성됩니다. $\blacksquare$

## Quiz 13. 2D Convolution Matrix (4×9) (9주차)
**[접근 방식]**
2차원 입력 이미지를 행-우선(Row-major) 방식으로 평탄화(Flatten)하여 9차원 벡터로 만들고, 각 출력 노드에 대응하는 필터의 스칼라 곱 매핑 규칙을 찾아 행렬의 각 행을 구성합니다.

**[수식 유도 및 증명]**
필터 $w = \begin{pmatrix} 0 & 1 \\ 2 & 3 \end{pmatrix}$. 평탄화된 입력 노드 인덱스를 $x_1, \dots, x_9$ 로 둡니다.
각 출력 픽셀 연산식 전개:
- $y_1$ (좌상단 패치): $0x_1 + 1x_2 + 2x_4 + 3x_5$ $\implies$ $A$의 1행: $[0, 1, 0, 2, 3, 0, 0, 0, 0]$
- $y_2$ (우상단 패치): $0x_2 + 1x_3 + 2x_5 + 3x_6$ $\implies$ $A$의 2행: $[0, 0, 1, 0, 2, 3, 0, 0, 0]$
- $y_3$ (좌하단 패치): $0x_4 + 1x_5 + 2x_7 + 3x_8$ $\implies$ $A$의 3행: $[0, 0, 0, 0, 1, 0, 2, 3, 0]$
- $y_4$ (우하단 패치): $0x_5 + 1x_6 + 2x_8 + 3x_9$ $\implies$ $A$의 4행: $[0, 0, 0, 0, 0, 1, 0, 2, 3]$
이 과정을 통해 2D 컨볼루션 역시 가중치가 공유(Weight sharing)되고 국소적(Locality) 연결만을 갖는 선형 행렬 곱셈 연산임을 행렬 형태로 명시적 증명 완료. $\blacksquare$
