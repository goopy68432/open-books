# 03. 완벽 답안 — 시험장 그대로

---

## 답안 (10분 분량)

---

### [문제] $X \sim N(0,1)$일 때 $E(X), E(X^2), E(X^3), E(X^4)$를 구하라. (가우스 적분도 증명)

### [풀이]

**(0) 정규분포 정의 명시**

$X \sim N(0,1)$의 pdf:
$$p(x) = \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{x^2}{2}\right).$$

기댓값 정의 (LOTUS):
$$E[X^k] = \int_{-\infty}^\infty x^k p(x)\,dx.$$

**(1) 보조정리: 가우스 적분**

$I = \int_{-\infty}^\infty e^{-x^2/2}\,dx$로 두면

$$I^2 = \int_{-\infty}^\infty\int_{-\infty}^\infty e^{-(x^2+y^2)/2}\,dx\,dy.$$

극좌표 $(x,y) = (r\cos\phi, r\sin\phi)$, $dx\,dy = r\,dr\,d\phi$:

$$I^2 = \int_0^{2\pi}\int_0^\infty e^{-r^2/2} r\,dr\,d\phi.$$

내부 적분: $u = r^2/2$ 치환으로 $\int_0^\infty e^{-u}\,du = 1$.

$$I^2 = 2\pi \cdot 1 = 2\pi, \quad \therefore I = \sqrt{2\pi}.$$

따라서 $\int_{-\infty}^\infty p(x)\,dx = 1$ (정규화 확인).

**(2) E(X)**

피적분함수 $x \cdot e^{-x^2/2}$는 기함수 ($x$ 기함수 × $e^{-x^2/2}$ 우함수). 적분 구간이 대칭이므로

$$E[X] = 0.$$

**(3) E(X²)**

부분적분 ($u = x$, $dv = x e^{-x^2/2}dx$, $v = -e^{-x^2/2}$):
$$\int_{-\infty}^\infty x^2 e^{-x^2/2}\,dx = [-x e^{-x^2/2}]_{-\infty}^\infty + \int_{-\infty}^\infty e^{-x^2/2}\,dx = 0 + \sqrt{2\pi}.$$

(경계항: $|x| \to \infty$일 때 $x e^{-x^2/2} \to 0$ — 지수 감쇠 우세.)

$$E[X^2] = \frac{1}{\sqrt{2\pi}} \cdot \sqrt{2\pi} = 1.$$

**(4) E(X³)**

피적분함수 $x^3 \cdot e^{-x^2/2}$도 기함수. 대칭구간 적분이므로

$$E[X^3] = 0.$$

**(5) E(X⁴)**

부분적분 ($u = x^3$, $dv = x e^{-x^2/2}dx$, $v = -e^{-x^2/2}$):
$$\int x^4 e^{-x^2/2}\,dx = [-x^3 e^{-x^2/2}]_{-\infty}^\infty + 3\int x^2 e^{-x^2/2}\,dx = 0 + 3\sqrt{2\pi}.$$

(경계항 0 동일 이유.)

$$E[X^4] = \frac{1}{\sqrt{2\pi}} \cdot 3\sqrt{2\pi} = 3.$$

---

### [최종 답]

$$\boxed{E(X) = 0, \quad E(X^2) = 1, \quad E(X^3) = 0, \quad E(X^4) = 3.}$$

**일반화:** 표준정규의 짝수차 모멘트 $E[X^{2n}] = (2n-1)!!$, 홀수차는 모두 0.
