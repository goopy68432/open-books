# 01. 텐트 함수와 미분 불가능 점

## 1. 텐트 모양 prior

$$p_m(\theta) = \begin{cases} m - m^2|\theta - 0.5| & |\theta - 0.5| \leq 1/m \\ 0 & \text{otherwise} \end{cases}$$

### 그림 (m=2)

```
   p(θ)
    │
  2 ┤      ╱╲                ← 정점 (0.5, m=2)
    │     ╱  ╲
  1 ┤    ╱    ╲
    │   ╱      ╲
  0 ┤__╱        ╲__
    └──┼────┼────┼─── θ
       0   0.5    1
```

### 그림 (m=6)

```
   p(θ)
    │
  6 ┤        ╱╲              ← 더 좁고 높음
    │       ╱  ╲
    │      ╱    ╲
  3 ┤     ╱      ╲
    │    ╱        ╲
  0 ┤___╱          ╲___
    └────┼────┼────┼── θ
        1/3  0.5  2/3
       (정의역 [1/3, 2/3])
```

## 2. 정의역과 정점

| m | 정의역 | 정점 높이 | 정점 위치 |
|---|-------|---------|---------|
| 2 | [0, 1] | 2 | 0.5 |
| 6 | [1/3, 2/3] | 6 | 0.5 |
| m | [0.5-1/m, 0.5+1/m] | m | 0.5 |

**관찰:** m이 클수록 prior 폭이 좁아지고 (정의역 줄어듦) 높이가 커짐. 면적은 항상 1 (정규화).

### 정규화 확인

m=2: 삼각형 밑 2 (=2/m), 높이 2 (=m), 넓이 = (1/2)(2)(2) = 2. **이상한데?**

다시 확인. 텐트 함수: 밑 = 2/m, 높이 = m → 넓이 = (1/2)(2/m)(m) = 1 ✓

## 3. 미분 불가능 점 — 0.5

$|\theta - 0.5|$는 $\theta = 0.5$에서 미분 불가능.
- 좌미분: $-1$ ($\theta < 0.5$일 때 |·|의 도함수)
- 우미분: $+1$ ($\theta > 0.5$일 때)

**의미:** 단순히 "미분=0" 못 씀. **정점이 미분 불가능 점**일 가능성 높음 (텐트의 꼭짓점).

## 4. 풀이 전략 — 케이스 분석

### 케이스 A: 미분 가능한 두 영역 분리

$\theta < 0.5$: $p_m(\theta) = m - m^2(0.5 - \theta) = m^2 \theta + (m - m^2/2)$
$\theta > 0.5$: $p_m(\theta) = m - m^2(\theta - 0.5) = -m^2 \theta + (m + m^2/2)$

각각 부분에서 미분 가능. likelihood × prior에서 미분=0 풀이.

### 케이스 B: 미분 불가능 점 (꼭짓점 0.5)

좌·우 미분 부호 비교:
- 좌측에서 increasing, 우측에서 decreasing → **0.5가 최댓값**
- 둘 다 increasing → 우측에 최댓값
- 둘 다 decreasing → 좌측에 최댓값

### 케이스 C: 경계 (정의역 끝)

prior가 0이 되는 경계. 그곳에서 posterior = 0 → 후보 아님.
단, **경계 직전**에서 최댓값 가능.

## 5. 이번 문제의 핵심 사실

**likelihood:** $L(\theta) = \theta^k(1-\theta)^{n-k}$

n=5, k=4 → $L(\theta) = \theta^4(1-\theta)$

MLE: $\hat{\theta}_{\text{MLE}} = 4/5 = 0.8$

**비교:**
- m=2: MLE=0.8이 정의역 [0,1] 안 → 내부 극값 가능
- m=6: MLE=0.8이 정의역 [1/3, 2/3] 밖 → 경계나 정점에서 최댓값

## 6. 풀이 미리보기

각 케이스마다:
1. posterior = likelihood × prior 식
2. log + 미분 (영역별)
3. 미분=0 풀이
4. 정점 0.5와 경계 비교
5. 최댓값 결정
