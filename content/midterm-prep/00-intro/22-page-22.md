## Part A: 개념 서술형 (각 3점, 시험의 ~25%)

### Q1. (영어) Explain the difference between induction and deduction. Why is machine learning fundamentally inductive?

(한국어) 귀납과 연역의 차이를 설명하고, 머신러닝이 본질적으로 귀납적인 이유를 설명하라.

**모범 답안**:

**연역(Deduction)**: 일반적 전제(규칙)에서 출발하여 구체적 결론을 도출.
- 예: "모든 포유류는 폐호흡을 한다" + "고래는 포유류다" → "고래는 폐호흡을 한다"
- 전제가 참이면 결론은 반드시 참 (논리적 확실성)

**귀납(Induction)**: 구체적 관측(데이터)에서 출발하여 일반적 패턴을 추출.
- 예: 1000번의 관측 → "해는 동쪽에서 뜬다"
- 데이터가 많아도 결론의 확실성은 보장되지 않음 (확률적)

**ML이 귀납적인 이유**: ML은 데이터(E)에서 패턴을 찾아 가설(H)을 만든다. 이것은 관측 → 가설의 귀납적 과정이다. 교수님 인용: "50년간의 교훈: 귀납적 추론이 승리한다."

### Q2. (영어) What is an inductive bias? Give two examples in neural networks.

(한국어) 귀납 편향이란 무엇인가? 신경망에서의 예시 2가지를 들어라.

**모범 답안**:

**귀납 편향(Inductive Bias)**: 모델이 학습 데이터에서 본 적 없는 새로운 입력으로 일반화하기 위해 두는 가정의 집합. 전체 함수공간 $\mathcal{F}$를 제한된 가설공간 $\mathcal{H} \subset \mathcal{F}$로 축소하는 것.

**예시**:
1. **CNN (ConvNet)**: 지역성(locality)과 이동 불변성(stationarity/weight sharing). "이미지에서 중요한 패턴은 국소적이고, 위치에 관계없이 동일하다"는 가정.
2. **MLP**: 특별한 구조적 가정 없이 모든 함수를 근사할 수 있음 (약한 귀납 편향). 보편근사정리에 의해 충분한 너비의 2층 MLP는 임의 함수를 근사 가능.

### Q3. (영어) Why do we take the logarithm of the likelihood? State at least two reasons.

(한국어) 우도에 로그를 취하는 이유를 최소 2가지 서술하라.

**모범 답안**:

1. **계산 편의**: 곱(product)이 합(sum)으로 변환됨. $\log\prod = \sum\log$. 합의 미분이 곱의 미분보다 간단.
2. **수치 안정성**: 확률값의 곱은 매우 작아질 수 있음 (예: $0.01^{100} = 10^{-200}$). log를 취하면 $-200$으로 언더플로 방지.
3. **최적값 보존**: log는 단조증가 함수이므로 $\arg\max_\theta L(\theta) = \arg\max_\theta \log L(\theta)$.

### Q4. (영어) What does it mean for a prior to be "uniform"? What happens to MAP when the prior is uniform?

(한국어) "균등 사전분포"의 의미와, 균등 Prior일 때 MAP에 무슨 일이 일어나는지 설명하라.

**모범 답안**:

균등 사전분포(Uniform Prior): 모든 매개변수 값에 동일한 확률을 부여. $P(\theta) = \text{constant}$.

MAP 목적함수: $\log P(H|E) = \log P(E|H) + \log P(H) + C$

균등 Prior이면 $\log P(H) = \text{constant}$이므로 MAP 최적화에서 prior 항이 사라지고:

$$\theta_{MAP} = \arg\max_\theta \log P(E|H) = \theta_{MLE}$$

**MAP = MLE**. 즉, 사전 정보가 없으면(= 모든 θ를 동등하게 취급하면) MAP는 순수하게 데이터만 보는 MLE와 동일.

---

### Q5. (영어) Why does MLE sometimes overfit? How does MAP address this?

(한국어) MLE가 과적합하는 이유와, MAP가 이를 어떻게 해결하는지 설명하라.

**모범 답안**:

**MLE 과적합 예시**: 동전 3번 던져서 3번 앞면 → $\theta_{MLE} = 3/3 = 1$. "앞으로 모든 동전 던지기가 앞면"이라는 극단적 예측. 데이터가 적을 때 MLE는 데이터에 과도하게 맞춤.

**MAP의 해결**: Prior를 추가하여 극단적 값을 억제.
- Beta(2,2) Prior: $\theta_{MAP} = \frac{k+1}{n+2} = \frac{4}{5} = 0.8$
- "가상의 관측 데이터를 미리 추가한 것"과 같은 효과
- n이 커지면 Prior의 영향은 줄어들고 MAP → MLE로 수렴 (데이터가 충분하면 Prior는 무관)

### Q6. (영어) Explain the relationship between entropy, cross-entropy, and KL divergence using the formula KL(p||q) = CE(p,q) - H(p).

(한국어) 엔트로피, 교차 엔트로피, KL divergence의 관계를 수식과 함께 설명하라.

**모범 답안**:

- **엔트로피 H(p)**: 분포 p의 불확실성. $H(p) = -\mathbb{E}_p[\log p(X)]$. 균등분포가 최대, 델타분포가 최소.
- **교차 엔트로피 CE(p,q)**: p로 샘플링하되 q의 코드로 인코딩할 때의 평균 비트 수. $CE(p,q) = -\mathbb{E}_p[\log q(X)]$
- **KL(p||q)**: p와 q의 차이. $KL = CE(p,q) - H(p) \geq 0$

CE는 "q가 p를 얼마나 잘 설명하는가". H(p)는 p 자체의 불확실성. 따라서 KL은 "q를 쓸 때 p를 쓰는 것 대비 추가로 드는 비용".

학습에서 p=p_E(고정)이므로 H(p_E)는 상수 → **CE 최소화 = KL 최소화**.

### Q7. (영어) Why do neural networks need nonlinear activation functions?

(한국어) 신경망에 비선형 활성함수가 필요한 이유를 설명하라.

**모범 답안**:

비선형 활성함수 없이 L개 층을 쌓으면:

$$z = W_{L-1} W_{L-2} \cdots W_0 x_0 = W' x$$

선형 변환의 합성은 여전히 선형 변환이므로, 아무리 깊게 쌓아도 단일 선형 변환과 동일하다. 즉, 깊은 네트워크가 얕은 네트워크보다 표현력이 나을 것이 없다.

비선형 활성함수(ReLU, sigmoid 등)를 추가하면 각 층이 입력 공간을 비선형으로 변환하여, 깊은 네트워크가 복잡한 함수를 표현할 수 있게 된다. (보편근사정리)

## Part B: 비교/분석형 (각 5점, 시험의 ~10%)

### Q8. (영어) Compare L1 and L2 regularization: mathematical form, effect on weights, connection to priors, and when to use each.

(한국어) L1과 L2 정규화를 수학적 형태, 가중치에 대한 효과, Prior와의 관계, 사용 시점으로 비교하라.

**모범 답안**:

|  | L1 (LASSO) | L2 (Ridge/Weight Decay) |
|--|-----------|------------------------|
| **수학적 형태** | $\lambda\sum\|\theta_i\|$ | $\lambda\sum\theta_i^2$ |
| **Prior** | Laplace 분포 | Gaussian 분포 |
| **가중치 효과** | 일부를 정확히 0으로 (희소성) | 모두 0 근처로 축소 (크기 감소) |
| **기하학** | L1 공 = 다이아몬드 → 축과 만남 | L2 공 = 원 → 축과 만나지 않음 |
| **사용 시점** | 특징 선택이 필요할 때 | 일반적인 과적합 방지 |

### Q9. (영어) Compare SGD and Adam. What problem does Adam solve?

(한국어) SGD와 Adam을 비교하고, Adam이 해결하는 문제를 설명하라.

**모범 답안**:

**SGD**: $\theta \leftarrow \theta - \eta g$
- 단순. 모든 파라미터에 동일한 학습률.
- 방향이 진동할 수 있음 (등고선이 타원일 때).

**Adam**: 1차 모멘트(방향) + 2차 모멘트(크기)를 추적.
- $m \leftarrow \beta_1 m + (1-\beta_1)g$ (이동 평균 — 모멘텀)
- $s \leftarrow \beta_2 s + (1-\beta_2)g^2$ (그래디언트 크기의 이동 평균)
- $\theta \leftarrow \theta - \eta \frac{\hat{m}}{\sqrt{\hat{s}}+\epsilon}$

**Adam이 해결하는 문제**:
1. 파라미터마다 다른 스케일의 그래디언트 → 적응적 학습률
2. SGD의 진동 → 모멘텀으로 안정화
3. 학습 초반의 편향 → bias correction

### Q10. (영어) Compare Batch Normalization and Layer Normalization. When is each preferred?

(한국어) BN과 LN을 비교하고 각각 언제 선호되는지 설명하라.

**모범 답안**:

|  | Batch Normalization | Layer Normalization |
|--|--------------------|--------------------|
| **정규화 축** | 배치(batch) 축 | 특징(feature) 축 |
| **의미** | 같은 feature의 배치 내 통계 | 같은 sample의 feature 내 통계 |
| **배치 의존** | Yes — 배치 크기에 민감 | No — 단일 샘플로 동작 |
| **추론 시** | 학습 중 이동평균 사용 | 그대로 사용 |
| **선호 상황** | CNN (이미지) | Transformer, RNN (시퀀스) |

**LN이 Transformer에서 선호되는 이유**: 시퀀스 길이가 가변적이고, 배치 크기에 독립적이어야 하기 때문.

## Part C: 종합 응용형 (시험의 ~5%)

### Q11. (영어) Given a 2-layer neural network for 3-class classification with input x∈ℝ², hidden layer of size 4 (ReLU), and output z∈ℝ³ (softmax + CE loss):
1. Write the forward pass equations
2. State the shapes of all weight matrices
3. Compute ∂L/∂z

(한국어) 2층 3-class 분류 신경망의 순전파, 가중치 행렬 크기, 출력 그래디언트를 구하라.

**모범 답안**:

**1. 순전파**:
$$x_1 = \text{ReLU}(W_0 x_0 + b_0) \in \mathbb{R}^4$$
$$z = W_1 x_1 + b_1 \in \mathbb{R}^3$$
$$p = \text{softmax}(z) \in \mathbb{R}^3$$
$$L = -e_y^\top \log p$$

**2. 가중치 크기**:
- $W_0 \in \mathbb{R}^{4 \times 2}$, $b_0 \in \mathbb{R}^4$
- $W_1 \in \mathbb{R}^{3 \times 4}$, $b_1 \in \mathbb{R}^3$
- 총 파라미터: $4\times2 + 4 + 3\times4 + 3 = 27$

**3. 출력 그래디언트**:
$$\frac{\partial L}{\partial z} = (p - e_y)^\top$$

예: 정답이 class 1이고 $p = [0.7, 0.2, 0.1]$이면:
$$\frac{\partial L}{\partial z} = [0.7-1, 0.2-0, 0.1-0] = [-0.3, 0.2, 0.1]$$
