## 유도 #1: MLE → Cross-Entropy Loss 유도 ★★★

### 문제 (Problem)
**Show that the cross-entropy loss is derived from maximum likelihood estimation with a categorical distribution.**

Categorical 분포를 가정했을 때, MLE로부터 Cross-Entropy 손실함수가 유도됨을 보여라.

### 풀이 (한국어)

**Step 1: 모델 가정 설정**

지도학습에서 모델 h는 입력 x를 받아 C개 클래스에 대한 확률벡터를 출력한다.
범주형(Categorical) 분포를 가정:

$$p(y \mid x, h) = h(x)_y$$

즉, 정답 클래스 y에 해당하는 확률값이 h(x)의 y번째 원소이다.

**Step 2: 로그 우도 구성**

데이터 $E = \{(x_1, y_1), ..., (x_n, y_n)\}$이 i.i.d.라고 가정하면, 우도(likelihood)는:

$$P(E \mid H) = \prod_{i=1}^{n} p(y_i \mid x_i, h) = \prod_{i=1}^{n} h(x_i)_{y_i}$$

로그를 취한다 (log는 단조증가이므로 argmax를 보존):

$$\log P(E \mid H) = \sum_{i=1}^{n} \log h(x_i)_{y_i}$$

**Step 3: MLE → 음의 로그 우도 → CE Loss**

MLE는 log-likelihood를 최대화:

$$\theta_{ML} = \arg\max_\theta \log P(E \mid H)$$

최대화를 최소화로 바꾸기 위해 음수를 취한다:

$$\theta_{ML} = \arg\min_\theta \left[ -\sum_{i=1}^{n} \log h(x_i)_{y_i} \right]$$

one-hot 벡터 $e_{y_i}$를 사용하면:

$$-\sum_{i=1}^{n} \log h(x_i)_{y_i} = -\sum_{i=1}^{n} e_{y_i}^\top \log h(x_i)$$

이것이 바로 **Cross-Entropy Loss**:

$$\boxed{L_{CE} = -\frac{1}{|E|} \sum_{i=1}^{n} e_{y_i}^\top \log h(x_i)}$$

**Step 4: 정보이론 관점에서의 연결**

경험분포 $p_E$와 모델분포 $p_\theta$에 대해:

$$CE(p_E, p_\theta) = -\mathbb{E}_{Z \sim p_E}[\log p(Z \mid H)]$$

이는 NLL(음의 로그 우도)과 동일하다.

### 채점 포인트
- [ ] Categorical 분포 가정을 명시했는가
- [ ] i.i.d. 가정을 언급했는가
- [ ] log의 단조증가 성질로 argmax 보존을 설명했는가
- [ ] 최대화 → 최소화(음수 부호) 변환을 설명했는가

## 유도 #2: MLE → MSE Loss 유도 ★★★

### 문제 (Problem)
**Show that the MSE loss is derived from maximum likelihood estimation with a Gaussian distribution.**

Gaussian 분포를 가정했을 때, MLE로부터 MSE 손실함수가 유도됨을 보여라.

### 풀이 (한국어)

**Step 1: 모델 가정 설정**

회귀 문제에서 y가 모델 출력 h(x) 주변의 가우시안 분포를 따른다고 가정:

$$p(y \mid x, h) = \mathcal{N}(y;\ h(x),\ \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y - h(x))^2}{2\sigma^2}\right)$$

즉, $p(y \mid x, h) \propto e^{-c(y - h(x))^2}$ (교안 슬라이드 1의 표현).

**Step 2: 로그 우도 전개**

i.i.d. 가정 하에서:

$$\log P(E \mid H) = \sum_{i=1}^{n} \log \mathcal{N}(y_i;\ h(x_i),\ \sigma^2)$$

$$= \sum_{i=1}^{n} \left[ -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - h(x_i))^2}{2\sigma^2} \right]$$

$$= -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{i=1}^{n} (y_i - h(x_i))^2$$

**Step 3: h에 대한 최적화 → MSE**

$\sigma^2$를 고정하고 h에 대해 최대화하면, 첫째 항은 상수이므로:

$$\arg\max_h \log P(E \mid H) = \arg\min_h \sum_{i=1}^{n} (y_i - h(x_i))^2$$

$$\boxed{L_{MSE} = \frac{1}{|E|} \sum_{i=1}^{n} (y_i - h(x_i))^2}$$

**핵심**: Gaussian 가정 → MLE → 지수 안의 제곱항만 남음 → MSE

### 채점 포인트
- [ ] Gaussian 분포 가정을 명시했는가
- [ ] 로그를 취할 때 exp가 사라지는 과정을 보였는가
- [ ] σ² 항이 h에 대해 상수임을 언급했는가

## 유도 #3: MAP = MLE + Prior 관계 ★★★

### 문제 (Problem)
**Show that MAP estimation decomposes into MLE plus a prior term, and explain the connection to regularization.**

MAP 추정이 MLE + Prior 항으로 분해됨을 보이고, 정규화와의 관계를 설명하라.

### 풀이 (한국어)

**Step 1: 베이즈 정리 적용**

$$P(H \mid E) = \frac{P(E \mid H) P(H)}{P(E)}$$

$P(E)$는 H에 대해 상수이므로:

$$P(H \mid E) \propto P(E \mid H) \cdot P(H)$$

**Step 2: 로그 취하기**

$$\log P(H \mid E) = \log P(E \mid H) + \log P(H) + C$$

$$\underbrace{\log \text{posterior}}_{\text{MAP 목적함수}} = \underbrace{\log \text{likelihood}}_{\text{MLE 목적함수}} + \underbrace{\log \text{prior}}_{\text{정규화 항}} + C$$

**Step 3: MAP 추정**

$$\theta_{MAP} = \arg\max_\theta [\log P(E \mid H) + \log P(H)]$$

- Prior가 균등분포이면: $\log P(H)$ = 상수 → **MAP = MLE**
- Prior가 비균등이면: Prior가 MLE 결과를 "끌어당김" (정규화 효과)

**Step 4: 구체적 예시 — 동전 던지기**

- 베르누이 MLE: $\theta_{ML} = k/n$
- Beta(2,2) Prior일 때: $p(\theta) = 6\theta(1-\theta)$, $\log P(H) = \log\theta + \log(1-\theta) + C$

$$\log\text{post} = \underbrace{k\log\theta + (n-k)\log(1-\theta)}_{\text{MLE}} + \underbrace{\log\theta + \log(1-\theta)}_{\text{Prior}}$$

$$= (k+1)\log\theta + (n-k+1)\log(1-\theta)$$

미분하여 0으로 놓으면: $\theta_{MAP} = \frac{k+1}{n+2}$

**핵심 비교**: n=3, k=3일 때 $\theta_{ML}=1$ (과적합!) vs $\theta_{MAP}=4/5$ (Prior가 완화)

### 채점 포인트
- [ ] 베이즈 정리에서 출발했는가
- [ ] P(E)가 상수인 이유를 설명했는가
- [ ] log 변환 후 곱→합 분해를 보였는가
- [ ] 균등 Prior일 때 MAP=MLE임을 언급했는가

## 유도 #4: KL Divergence와 Cross-Entropy 관계 ★★☆

### 문제 (Problem)
**Show that KL(p_E || p_θ) = CE(p_E, p_θ) - H(p_E), and explain why minimizing CE is equivalent to minimizing KL divergence.**

KL divergence와 Cross-Entropy의 관계를 보이고, CE 최소화가 KL 최소화와 동치인 이유를 설명하라.

### 풀이 (한국어)

**Step 1: 정의로부터 출발**

$$KL(p \| q) = \mathbb{E}_p\left[\log\frac{p(X)}{q(X)}\right] = \mathbb{E}_p[\log p(X)] - \mathbb{E}_p[\log q(X)]$$

$$= -H(p) - (-CE(p, q))$$

$$\boxed{KL(p \| q) = CE(p, q) - H(p)}$$

**Step 2: 학습에서의 의미**

$p = p_E$ (경험분포, 고정), $q = p_\theta$ (모델분포, 학습 대상)일 때:

$$KL(p_E \| p_\theta) = CE(p_E, p_\theta) - H(p_E)$$

$H(p_E)$는 $\theta$에 대해 **상수**이므로:

$$\arg\min_\theta KL(p_E \| p_\theta) = \arg\min_\theta CE(p_E, p_\theta)$$

**CE를 최소화하는 것은 KL을 최소화하는 것과 동일하다.**

**Step 3: KL ≥ 0의 의미**

Gibbs' inequality에 의해 $KL(p \| q) \geq 0$, 등호는 $p = q$일 때만 성립.

따라서 $CE(p, q) \geq H(p)$이고, CE의 최솟값은 $q = p$일 때 달성된다.

### 채점 포인트
- [ ] KL의 정의를 정확히 전개했는가
- [ ] H(p_E)가 θ에 대해 상수임을 명시했는가
- [ ] CE 최소화 = KL 최소화의 동치를 보였는가

## 유도 #5: L2 정규화 = Gaussian Prior ★★☆

### 문제 (Problem)
**Show that L2 regularization is equivalent to MAP estimation with a Gaussian prior on the parameters.**

L2 정규화가 매개변수에 대한 Gaussian Prior를 사용한 MAP 추정과 동치임을 보여라.

### 풀이 (한국어)

**Step 1: MAP 목적함수**

$$\theta_{MAP} = \arg\max_\theta [\log P(E \mid \theta) + \log P(\theta)]$$

**Step 2: Gaussian Prior 설정**

매개변수에 대해 $P(\theta) = \mathcal{N}(\theta;\ 0,\ \tau^2 I)$를 가정:

$$\log P(\theta) = -\frac{1}{2\tau^2}\|\theta\|^2 + C$$

**Step 3: MAP에 대입**

$$\theta_{MAP} = \arg\max_\theta \left[\log P(E \mid \theta) - \frac{1}{2\tau^2}\|\theta\|^2\right]$$

최대화를 최소화로 바꾸면:

$$\theta_{MAP} = \arg\min_\theta \left[-\log P(E \mid \theta) + \frac{1}{2\tau^2}\|\theta\|^2\right]$$

$$= \arg\min_\theta \left[L(\theta) + \lambda\|\theta\|^2\right]$$

여기서 $\lambda = \frac{1}{2\tau^2}$.

$$\boxed{\text{MAP with Gaussian prior} = \text{MLE} + \text{L2 regularization (weight decay)}}$$

**핵심**: Prior가 강할수록(τ²가 작을수록) → λ가 커짐 → 정규화가 강해짐 → θ가 0에 가까워짐

### 채점 포인트
- [ ] Gaussian Prior의 log를 정확히 전개했는가
- [ ] λ와 τ²의 관계를 보였는가
- [ ] Prior 강도와 정규화 강도의 관계를 설명했는가

## 유도 #6: Softmax 미분 ★★☆

### 문제 (Problem)
**Derive the partial derivative of the softmax function: ∂softmax(z)_i / ∂z_j.**

Softmax 함수의 편미분을 유도하라.

### 풀이 (한국어)

**Step 1: Softmax 정의**

$$\text{softmax}(z)_i = \frac{\exp(z_i)}{\sum_{k=1}^{C} \exp(z_k)} = \frac{\exp(z_i)}{S}$$

여기서 $S = \sum_k \exp(z_k)$

**Step 2: i = j인 경우 (같은 클래스)**

몫의 미분법을 적용:

$$\frac{\partial}{\partial z_j} \frac{\exp(z_i)}{S} = \frac{\exp(z_i) \cdot S - \exp(z_i) \cdot \exp(z_j)}{S^2}$$

$$= \frac{\exp(z_i)}{S} - \frac{\exp(z_i)}{S} \cdot \frac{\exp(z_j)}{S}$$

$$= \text{softmax}_i (1 - \text{softmax}_j) = \text{softmax}_i (1 - \text{softmax}_i)$$

**Step 3: i ≠ j인 경우 (다른 클래스)**

분자 $\exp(z_i)$는 $z_j$에 대해 상수이므로:

$$\frac{\partial}{\partial z_j} \frac{\exp(z_i)}{S} = \frac{0 \cdot S - \exp(z_i) \cdot \exp(z_j)}{S^2}$$

$$= -\frac{\exp(z_i)}{S} \cdot \frac{\exp(z_j)}{S} = -\text{softmax}_i \cdot \text{softmax}_j$$

**Step 4: 통합 표현**

$$\boxed{\frac{\partial \text{softmax}(z)_i}{\partial z_j} = \text{softmax}(z)_i \cdot (\delta_{ij} - \text{softmax}(z)_j)}$$

여기서 $\delta_{ij}$는 Kronecker delta ($i=j$이면 1, 아니면 0).

**보너스**: CE Loss와 Softmax를 합치면 그래디언트가 간결해진다:

$$\frac{\partial L_{CE}}{\partial z} = (p - e_y)^\top$$

여기서 $p = \text{softmax}(z)$, $e_y$는 정답의 one-hot 벡터. (교안 슬라이드 389)

### 채점 포인트
- [ ] 몫의 미분법을 정확히 적용했는가
- [ ] i=j와 i≠j 경우를 분리했는가
- [ ] Kronecker delta로 통합 표현을 제시했는가

## 유도 #7: Chain Rule / 역전파 ★★★

### 문제 (Problem)
**Using the chain rule, compute the gradients ∂L/∂W for a 2-layer neural network with cross-entropy loss.**

Chain rule을 사용하여 2층 신경망의 가중치에 대한 그래디언트를 계산하라.

### 풀이 (한국어)

**Step 1: 2층 신경망 구조**

$$x_0 \in \mathbb{R}^{d_0} \quad \text{(입력)}$$
$$x_1 = \sigma(W_0 x_0) \in \mathbb{R}^{d_1} \quad \text{(은닉층, σ=활성함수)}$$
$$z = W_1 x_1 \in \mathbb{R}^{d_2} \quad \text{(출력, logits)}$$
$$L = CE(z, y) \quad \text{(손실)}$$

**Step 2: 출력층 그래디언트 (∂L/∂W₁)**

CE + Softmax의 그래디언트 (교안 슬라이드 389):

$$\frac{\partial L}{\partial z} = (p - e_y)^\top \quad \text{여기서 } p = \text{softmax}(z)$$

Chain rule로 $W_1$에 대해:

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial W_1}$$

$z = W_1 x_1$이므로 $\frac{\partial z}{\partial W_1} = x_1^\top$:

$$\boxed{\frac{\partial L}{\partial W_1} = (p - e_y) \cdot x_1^\top}$$

**Step 3: 은닉층 그래디언트 (∂L/∂W₀)**

역전파로 $x_1$까지 전달:

$$\frac{\partial L}{\partial x_1} = W_1^\top \frac{\partial L}{\partial z} = W_1^\top (p - e_y)$$

활성함수를 통과 (ReLU의 경우):

$$\frac{\partial L}{\partial (W_0 x_0)} = \frac{\partial L}{\partial x_1} \odot \sigma'(W_0 x_0)$$

ReLU이면: $\sigma'(z) = \mathbf{1}(z > 0)$ (교안 슬라이드 393)

최종:

$$\boxed{\frac{\partial L}{\partial W_0} = \left[\frac{\partial L}{\partial x_1} \odot \sigma'(W_0 x_0)\right] \cdot x_0^\top}$$

**핵심 패턴**: 역전파는 출력 → 입력 방향으로 chain rule을 반복 적용하는 것이다.

### 채점 포인트
- [ ] 순전파 구조를 명확히 정의했는가
- [ ] CE+Softmax의 간결한 그래디언트를 사용했는가
- [ ] Chain rule의 각 단계를 명시적으로 보였는가
- [ ] 활성함수 미분을 포함했는가

## 유도 #8: Gradient Descent 유도 ★★☆

### 문제 (Problem)
**Derive the gradient descent update rule from the first-order Taylor approximation.**

1차 Taylor 근사로부터 경사 하강법의 업데이트 규칙을 유도하라.

### 풀이 (한국어)

**Step 1: 1차 Taylor 근사**

함수 f를 현재 점 $\theta_t$ 근처에서 1차 근사:

$$f(\theta) \approx f(\theta_t) + \nabla f(\theta_t)^\top (\theta - \theta_t)$$

**Step 2: 최대 감소 방향 찾기**

$\theta - \theta_t = \eta d$ (방향 d, 스텝 크기 η)로 놓으면:

$$f(\theta_t + \eta d) \approx f(\theta_t) + \eta \nabla f(\theta_t)^\top d$$

f를 최대한 줄이려면 $\nabla f(\theta_t)^\top d$를 최소화해야 한다.

코시-슈바르츠 부등식에 의해, ||d||=1 제약 하에서:

$$\nabla f^\top d \geq -\|\nabla f\| \cdot \|d\|$$

등호 조건: $d = -\frac{\nabla f}{\|\nabla f\|}$ (그래디언트의 반대 방향)

**Step 3: 업데이트 규칙**

$$\boxed{\theta_{t+1} = \theta_t - \eta \nabla f(\theta_t)}$$

**변형**:
- **SGD**: $\nabla f$ 대신 미니배치 그래디언트 $\nabla L_B$ 사용
- **Momentum**: $m \leftarrow \beta m + g$, $\theta \leftarrow \theta - \eta m$
- **Adam**: 1차(m) + 2차(s) 모멘트를 모두 추적

### 채점 포인트
- [ ] Taylor 1차 근사에서 출발했는가
- [ ] 최대 감소 방향이 -∇f임을 보였는가
- [ ] 코시-슈바르츠 또는 내적의 기하학적 해석을 사용했는가

## 유도 #9: Bias-Variance Decomposition ★★☆

### 문제 (Problem)
**Derive the bias-variance decomposition: E_S[(h_S - f)²] = Var(h_S) + bias²(h_S).**

편향-분산 분해를 유도하라.

### 풀이 (한국어)

**Step 1: 정의**

- $f$: 참 함수 (고정)
- $h_S$: 훈련 데이터 S로 학습한 모델 (S에 따라 확률적)
- $\bar{h} = \mathbb{E}_S[h_S]$: S에 대한 기대 모델

**Step 2: 전개**

$$\mathbb{E}_S[(h_S - f)^2]$$

$\bar{h}$를 빼고 더하기:

$$= \mathbb{E}_S[(h_S - \bar{h} + \bar{h} - f)^2]$$

$$= \mathbb{E}_S[(h_S - \bar{h})^2 + 2(h_S - \bar{h})(\bar{h} - f) + (\bar{h} - f)^2]$$

**Step 3: 기대값 계산**

- 첫째 항: $\mathbb{E}_S[(h_S - \bar{h})^2] = \text{Var}_S[h_S]$ (분산의 정의)
- 둘째 항: $2(\bar{h} - f) \cdot \underbrace{\mathbb{E}_S[h_S - \bar{h}]}_{=0} = 0$ (기대값의 정의에 의해)
- 셋째 항: $(\bar{h} - f)^2 = \text{bias}^2(h_S)$ (편향의 제곱, S에 무관한 상수)

$$\boxed{\mathbb{E}_S[(h_S - f)^2] = \text{Var}_S[h_S] + \text{bias}^2(h_S)}$$

**Step 4: 의미**

- **모델이 단순하면**: bias↑ (과소적합), variance↓
- **모델이 복잡하면**: bias↓, variance↑ (과적합)
- **최적 복잡도**: bias²+variance가 최소인 지점

### 채점 포인트
- [ ] $\bar{h}$를 빼고 더하는 트릭을 사용했는가
- [ ] 교차항이 0이 되는 이유를 설명했는가

## 유도 #10: Batch Normalization ★☆☆

### 문제 (Problem)
**Describe the Batch Normalization algorithm and explain why it helps training.**

Batch Normalization 알고리즘을 기술하고 학습에 도움이 되는 이유를 설명하라.

### 풀이 (한국어)

**Step 1: 배치 통계 계산**

배치 $B = \{x^{(1)}, ..., x^{(m)}\}$에 대해 (k번째 차원):

$$(\mu_B)_k = \frac{1}{m} \sum_{i=1}^{m} x_k^{(i)}$$

$$(\sigma_B^2)_k = \frac{1}{m} \sum_{i=1}^{m} (x_k^{(i)} - (\mu_B)_k)^2$$

**Step 2: 정규화**

$$\hat{x}_k^{(i)} = \frac{x_k^{(i)} - (\mu_B)_k}{\sqrt{(\sigma_B^2)_k + \epsilon}}$$

$\epsilon$은 0으로 나누는 것을 방지하는 작은 상수.

**Step 3: 스케일 & 시프트 (학습 가능 파라미터)**

$$y^{(i)} = \gamma \odot \hat{x}^{(i)} + \beta$$

$\gamma$와 $\beta$는 학습 가능한 파라미터.

만약 $\gamma = \sigma_B$, $\beta = \mu_B$이면 원래 값을 복원할 수 있다 (항등 변환).
→ 네트워크가 BN이 불필요하다면 학습을 통해 무효화할 수 있음.

**Step 4: 왜 도움이 되는가?**

- Internal Covariate Shift 감소: 각 층의 입력 분포를 안정화
- 더 큰 학습률 사용 가능
- 초기화에 덜 민감
- 일종의 정규화 효과 (배치 의존 노이즈)

**BN vs LN**:
- **BN**: batch 축에 대해 정규화 (같은 feature의 배치 내 평균/분산)
- **LN**: feature 축에 대해 정규화 (같은 sample의 feature 내 평균/분산)
- Transformer에서는 LN을 사용 (배치 크기에 독립적)

### 채점 포인트
- [ ] 3단계(통계 → 정규화 → 스케일/시프트)를 모두 포함했는가
- [ ] γ, β가 학습 가능함을 언급했는가
- [ ] BN의 장점을 최소 2가지 서술했는가
