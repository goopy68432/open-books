## 1. 이 수업이 가르치고자 하는 것

### 1.1 수업의 핵심 내러티브: "딥러닝의 수학적 기초를 연역적으로 이해하라"

이 수업은 딥러닝을 **"수학적 도구들의 정교한 조합"**으로 보는 관점을 가르친다. 프로그래밍이나 실습이 아니라, **선형대수 → 미적분/최적화 → 확률/통계 → 베이지안 추론 → 신경망**이라는 수학적 토대 위에서 "왜 이 구조가 작동하는가"를 증명하고 유도할 수 있는 능력을 키우는 것이 목표다.

```
[수학적 기초]                [통계적 추론]              [딥러닝 응용]
     │                           │                        │
 선형대수                    확률/분포                 신경망/역전파
 미적분/최적화               베이즈/MLE/MAP            손실함수/정규화
     │                           │                        │
 Week 1-3                    Week 4-5                  Week 6-7
```

### 1.2 교수님의 학문적 배경이 수업에 미치는 영향

이성윤 교수님은 **서울대 수리과학과 박사** 출신으로:

### 3.2 Part B: 미적분 & 최적화 (출제 비중 ~25%)

#### 반드시 알아야 하는 개념

| # | 개념 | 알아야 할 수준 | 출제 확률 |
|---|------|---------------|----------|
| 1 | **편미분 & 그래디언트** | $\nabla f$ 계산, 최급강하 방향이 $-\nabla f$인 이유 | ★★★★★ |
| 2 | **자코비안** | $J = \partial\mathbf{f}/\partial\mathbf{x}$ 계산, 차원 서술, 선형 근사 | ★★★★★ |
| 3 | **헤시안** | 2차 도함수 행렬, 임계점 판별 (극소/극대/안장점), condition number | ★★★★ |
| 4 | **체인룰 (벡터 버전)** | $\nabla_\mathbf{x} f = J_g^T \nabla_\mathbf{z} h$, 역전파의 수학적 근거 | ★★★★★ |
| 5 | **테일러 전개** | 1차 근사(선형화), 뉴턴 방법 유도 | ★★★ |
| 6 | **볼록함수** | 정의, 볼록함수의 국소 최소 = 전역 최소, 헤시안 PSD 조건 | ★★★ |
| 7 | **경사하강법 유도** | 선형 근사에서 최급강하 방향 유도, 학습률의 역할 | ★★★★★ |
| 8 | **소프트맥스 미분** | $\partial\sigma_i/\partial z_j$ ($i=j$ vs $i\neq j$), 자코비안 = $\text{diag}(\sigma) - \sigma\sigma^T$ | ★★★★★ |

#### 반드시 외워야 할 공식

```
1. 그래디언트:        ∇f = [∂f/∂x₁, ..., ∂f/∂xₙ]ᵀ
2. 자코비안:          J_ij = ∂fᵢ/∂xⱼ
3. 체인룰 (벡터):     ∇ₓf = Jᵍᵀ · ∇ᵤh
4. 뉴턴 방법:        x_{k+1} = x_k - [H(x_k)]⁻¹ ∇f(x_k)
5. 경사하강법:        θ_{t+1} = θ_t - η∇f(θ_t)
6. ‖x‖² 미분:        ∂(xᵀx)/∂x = 2x
7. xᵀAx 미분:        ∂(xᵀAx)/∂x = 2Ax  (A 대칭)
8. ‖Xw - y‖² 미분:   ∇w = 2Xᵀ(Xw - y)
9. Ridge 해:          w* = (XᵀX + λI)⁻¹Xᵀy
```

#### 반드시 알아야 하는 개념

| # | 개념 | 알아야 할 수준 | 출제 확률 |
|---|------|---------------|----------|
| 1 | **베이즈 정리** | 조건부 확률에서 유도, 의료 진단 예제 계산, Prior→Posterior 업데이트 | ★★★★★ |
| 2 | **MLE (최대우도추정)** | i.i.d 가정 → 결합확률 → 로그 → 미분=0. Gaussian→MSE 유도 | ★★★★★ |
| 3 | **MAP (최대사후확률)** | MLE + Prior, Gaussian Prior→L2 정규화, Laplace Prior→L1 정규화 | ★★★★★ |
| 4 | **Bernoulli 분포** | $E[X]=\theta$, $\text{Var}(X)=\theta(1-\theta)$ 유도 | ★★★★ |
| 5 | **Gaussian 분포** | PDF, MLE로 $\mu, \sigma^2$ 추정, Gaussian→MSE 연결 | ★★★★★ |
| 6 | **KL Divergence** | 정의, 비대칭성, Cross-Entropy와의 관계 ($H(P,Q) = H(P) + D_{KL}(P\|Q)$) | ★★★★ |
| 7 | **엔트로피** | $H(P) = -\sum P(x)\log P(x)$, 정보량의 의미 | ★★★ |
| 8 | **독립성** | 정의, i.i.d 가정이 MLE에서 쓰이는 이유 | ★★★★ |
| 9 | **중심극한정리** | 정식 진술, 딥러닝(배치 평균)과의 연결 | ★★ |

#### 핵심 유도 체인 (이것이 시험의 뼈대)

```
[데이터] → [i.i.d 가정] → [결합확률 = 곱] → [로그 변환 (언더플로우 방지)]
   │
   ├── Gaussian 가정 → log-likelihood → 미분=0 → MSE Loss 유도
   │
   ├── Bernoulli 가정 → log-likelihood → Cross-Entropy Loss 유도
   │
   └── + Prior 추가 → MAP → L1/L2 정규화 유도
```

**이 유도 체인을 처음부터 끝까지 글로 설명할 수 있으면 A+ 확정**

### 3.4 Part D: 신경망 & 딥러닝 응용 (출제 비중 ~25%)

| 2 | **Cross-Entropy + Softmax 미분** | $\partial\mathcal{L}/\partial\mathbf{z} = \hat{\mathbf{y}} - \mathbf{y}$ 유도 (★교수님 강조) | ★★★★★ |
| 3 | **활성화 함수** | ReLU/Sigmoid/Tanh 수식+미분+장단점, dying ReLU | ★★★★ |

| 7 | **Adam Optimizer** | 업데이트 수식 (1차/2차 모멘트, bias correction), SGD 대비 장점 | ★★★ |
| 8 | **Gradient Vanishing/Exploding** | 정의, 완화 기법 (Residual connection, Gradient clipping) | ★★★★ |
| 9 | **편향-분산 트레이드오프** | 정의, 정규화/앙상블과의 관계 | ★★★ |
| 10 | **Universal Approximation Theorem** | 핵심 내용 + 실용성 미보장 이유 (존재성 vs 학습 가능성) | ★★★ |

#### 반드시 외워야 할 공식

```
1. Softmax:          σ(z)_i = exp(z_i) / Σ_j exp(z_j)
2. CE Loss (이진):   L = -[y log ŷ + (1-y) log(1-ŷ)]
3. CE Loss (다중):   L = -Σ_c y_c log ŷ_c
4. Sigmoid 미분:     σ'(x) = σ(x)(1-σ(x))
5. BN Forward:       ŷ_i = γ · (x_i - μ_B)/√(σ²_B + ε) + β
6. Adam:             θ_{t+1} = θ_t - η·m̂_t/(√v̂_t + ε)
7. ResNet:           y = F(x) + x
8. Softmax Jacobian: diag(σ) - σσᵀ
9. CE+Softmax 결합:  ∂L/∂z = ŷ - y  (★★★ 최빈출)
```

## 4. A+를 위한 차별화 전략

### 4.1 "합격"과 "A+" 사이의 간격

| 수준 | 특징 |
|------|------|
| **C~B** | 공식 암기 + 단순 계산. "왜"가 없음 |
| **B+~A** | 공식 유도 가능 + 가정 일부 명시 |
| **A+** | **모든 단계에서 "왜"를 글로 설명** + 가정 완벽 명시 + 딥러닝 응용 연결 |

### 4.2 A+ 답안의 공식: "연역적 서술 프레임워크"

이 수업에서 가장 중요한 것은 **답을 얻는 과정을 글로 설명하는 것**이다:

```
① 문제 파악 & 가정 선언
   → "데이터가 i.i.d이고 Gaussian 분포를 따른다고 가정한다"

② 수학적 도구 선택과 이유
   → "곱셈을 덧셈으로 바꾸고 언더플로우를 방지하기 위해 로그를 취한다"

③ 단계별 유도 (각 단계에 한 줄 설명)
   → "Fermat 정리에 의해 극값에서 미분값이 0이므로..."

④ 결론 및 딥러닝 연결
   → "따라서 Gaussian 가정 하 MLE는 MSE 최소화와 동치이다"
```

### 4.3 교수님이 좋아할 핵심 연결고리 10개

1. **i.i.d → 곱 → 로그 → 합**: MLE의 핵심 트릭. 모든 손실함수 유도의 출발점
2. **Gaussian + MLE → MSE**: 회귀 문제의 손실함수가 왜 MSE인지
3. **Bernoulli + MLE → Cross-Entropy**: 분류 문제의 손실함수가 왜 CE인지
4. **MAP = MLE + Prior → 정규화**: L2 = Gaussian Prior, L1 = Laplace Prior
5. **그래디언트 = 최급강하 방향**: 경사하강법의 수학적 정당화
6. **자코비안 → 체인룰 → 역전파**: 역전파가 왜 작동하는지의 수학
7. **헤시안 고유값 → 곡률 → 학습 난이도**: condition number와 최적화의 관계
8. **SVD → 저랭크 근사 → PCA**: 차원 축소의 수학적 근거
9. **CE + Softmax → $\hat{y} - y$**: 계산적 편의성의 아름다운 결과
10. **KL Divergence = CE - Entropy**: 정보이론과 손실함수의 연결

### 4.4 가장 위험한 함정 (감점 포인트)

| 함정 | 올바른 이해 |
|------|------------|
| "MLE에서 갑자기 로그를 취한다" | 로그를 취하는 이유를 명시: (1) 곱→합 변환, (2) 언더플로우 방지, (3) 단조증가이므로 argmax 불변 |
| "미분해서 0으로 놓는다" | Fermat 정리를 인용: "극값의 필요조건으로 $f'(x^*)=0$" |
| "i.i.d 가정 없이 결합확률을 곱셈으로" | 반드시 i.i.d 가정을 먼저 선언해야 곱으로 분리 가능 |
| "L2 = 큰 가중치 방지" | 더 정확하게: "Gaussian prior 하에서 MAP 추정의 결과. 모든 가중치를 균등하게 작게" |
| "역전파 = 그냥 체인룰" | 체인룰의 **효율적 적용**: forward 계산 결과를 저장하고, backward로 재사용 |
| "Softmax 미분 생략" | $i=j$와 $i\neq j$ 경우를 반드시 나누어 유도 |

## 6. 종합 결론

### 이 수업의 한 줄 요약

> **"딥러닝의 모든 구성요소(손실함수, 최적화, 정규화, 역전파)가 왜 그런 형태인지를 선형대수·미적분·확률의 언어로 연역적으로 유도하고 증명하는 것"**

### A+를 위한 핵심 3원칙

1. **모든 단계에 "왜"를 적어라** — 가정 선언, 로그 이유, 미분=0 이유를 글로
2. **유도 체인을 처음부터 끝까지 재현하라** — 특히 MLE→MSE, MLE→CE, MAP→L2
3. **수학적 엄밀함과 딥러닝 직관을 연결하라** — 고유값↔곡률, SVD↔PCA, Prior↔정규화

### 시간 투자 우선순위

```
[최우선] 핵심 유도 체인 (35%) — Gaussian→MSE, Bernoulli→CE, MAP→L2, CE+Softmax→(ŷ-y)
   ↓
[높음]   증명 재현 (25%) — 랭크-널리티, 고유값 선형독립, 베이즈, Softmax 미분
   ↓
[중간]   계산 연습 (20%) — 고유값, 그래디언트, 자코비안, 베이즈 수치
   ↓
[보조]   개념 서술 (15%) — 활성화함수, 정규화, BN, Dropout
   ↓
[마무리] 종합 역전파 (5%) — 2층 신경망 전체 유도
```
