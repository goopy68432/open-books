# 입문 (Beginner)

## 1.1 정보(Information)란 무엇인가? — "놀라움"으로서의 정보

### 직관적 이해

동전을 던져서 앞면이 나왔다고 하자. 공정한 동전이라면 이 결과는 "적당히 놀랍다." 하지만 주사위를 던져서 정확히 6이 나왔다면? 이건 "더 놀랍다." 정보 이론에서 **정보량(information content)**은 바로 이 **놀라움의 정도**를 수학적으로 표현한 것이다.

### 자기 정보 (Self-Information)

사건 $x$가 확률 $P(x)$로 발생할 때, 이 사건의 **자기 정보(self-information)**는 다음과 같이 정의된다:

$$I(x) = -\log P(x)$$

- $\log$의 밑이 2이면 단위는 **bit**, 자연로그($\ln$)이면 단위는 **nat**
- 확률이 낮을수록 → 정보량이 크다 (더 놀랍다)
- 확률이 1이면 → 정보량은 0 (전혀 놀랍지 않다)

**예시:**
- 공정한 동전의 앞면: $I(\text{앞면}) = -\log_2(0.5) = 1$ bit
- 공정한 주사위에서 6: $I(6) = -\log_2(1/6) \approx 2.585$ bit
- 확실한 사건 ($P=1$): $I = -\log_2(1) = 0$ bit

### 왜 로그를 쓰는가?

1. **독립 사건의 정보량은 더해진다**: 동전 두 번 던지기에서 (앞, 앞)의 정보량 = 앞면 정보량 + 앞면 정보량
   $$I(x, y) = -\log P(x)P(y) = -\log P(x) - \log P(y) = I(x) + I(y)$$
2. **확률 → 정보 변환이 단조감소**: 확률이 높을수록 정보는 적다
3. **연속적이고 매끄러운 함수**

## 1.2 엔트로피 (Shannon Entropy) — 불확실성의 척도

### 정의

확률변수 $X$의 **엔트로피(entropy)**는 자기 정보의 **기대값**이다:

$$H(X) = -\sum_{x \in \mathcal{X}} P(x) \log P(x) = \mathbb{E}_{x \sim P}[-\log P(x)]$$

엔트로피는 "이 확률 분포가 평균적으로 얼마나 불확실한가"를 측정한다.

### 직관적 이해

- **동전 던지기** ($P(\text{앞}) = 0.5$):
  $$H = -0.5\log_2(0.5) - 0.5\log_2(0.5) = 1 \text{ bit}$$
  → 결과를 알려면 1비트(예/아니오 질문 1번)가 필요하다.

- **편향된 동전** ($P(\text{앞}) = 0.9$):
  $$H = -0.9\log_2(0.9) - 0.1\log_2(0.1) \approx 0.469 \text{ bit}$$
  → 거의 앞면이 나오므로 불확실성이 낮다.

- **확실한 결과** ($P(\text{앞}) = 1.0$):
  $$H = 0 \text{ bit}$$
  → 불확실성이 전혀 없다.

### 엔트로피의 핵심 성질

| 성질 | 설명 |
|------|------|
| $H(X) \geq 0$ | 엔트로피는 항상 0 이상 |
| $H(X) = 0$ iff 결정적 | 하나의 사건 확률이 1일 때만 0 |
| 균등분포에서 최대 | $|\mathcal{X}|$개 결과 중 균등분포일 때 $H = \log|\mathcal{X}|$ |

## 1.3 교차 엔트로피 (Cross-Entropy)

### 정의

진짜 분포 $P$와 모델 분포 $Q$가 있을 때:

$$H(P, Q) = -\sum_{x} P(x) \log Q(x) = \mathbb{E}_{x \sim P}[-\log Q(x)]$$

### 직관적 의미

"진짜 분포 $P$에서 데이터가 오는데, 모델 $Q$를 사용해서 인코딩하면 평균적으로 몇 비트가 필요한가?"

- 만약 $Q = P$이면: $H(P, Q) = H(P)$ (최적)
- $Q \neq P$이면: $H(P, Q) > H(P)$ (항상 더 많은 비트 필요)

### 딥러닝에서의 교차 엔트로피 손실함수

분류 문제에서 정답 레이블이 원-핫 벡터 $\mathbf{y} = [0, 0, 1, 0, \ldots]$이고, 모델 출력(softmax 후)이 $\hat{\mathbf{y}} = [0.1, 0.05, 0.7, 0.15, \ldots]$일 때:

$$\mathcal{L} = -\sum_{c=1}^{C} y_c \log \hat{y}_c$$

원-핫이므로 정답 클래스 $c^*$에 대해서만 살아남아:

$$\mathcal{L} = -\log \hat{y}_{c^*}$$

**왜 교차 엔트로피를 쓰는가?**
- 모델이 정답에 높은 확률을 부여하면 → 손실이 작다
- 정답에 낮은 확률을 부여하면 → 손실이 매우 크다 ($-\log$의 성질)
- MSE 대비 기울기가 더 크고, 학습이 빠르다 (sigmoid/softmax의 포화 문제 해결)

## 1.4 KL 다이버전스 (Kullback-Leibler Divergence)

### 정의

$$D_{\text{KL}}(P \| Q) = \sum_{x} P(x) \log \frac{P(x)}{Q(x)} = \mathbb{E}_{x \sim P}\left[\log \frac{P(x)}{Q(x)}\right]$$

### 핵심 관계

$$\boxed{H(P, Q) = H(P) + D_{\text{KL}}(P \| Q)}$$

- 교차 엔트로피 = 엔트로피 + KL 다이버전스
- $H(P)$는 고정값(데이터 분포는 바뀌지 않음)이므로, **교차 엔트로피를 최소화하는 것 = KL 다이버전스를 최소화하는 것**

### 중요한 성질

- $D_{\text{KL}}(P \| Q) \geq 0$ (깁스 부등식, Gibbs' inequality)
- $D_{\text{KL}}(P \| Q) = 0$ iff $P = Q$
- **비대칭**: $D_{\text{KL}}(P \| Q) \neq D_{\text{KL}}(Q \| P)$ 일반적으로
- 거리 함수(metric)가 아니다 (삼각 부등식도 만족하지 않음)

## 1.5 상호 정보량 (Mutual Information)

### 정의

$$I(X; Y) = D_{\text{KL}}(P(X, Y) \| P(X)P(Y)) = \sum_{x, y} P(x, y) \log \frac{P(x, y)}{P(x)P(y)}$$

### 직관적 의미

"$X$를 관찰함으로써 $Y$에 대해 얼마나 많은 정보를 얻는가?"

### 엔트로피와의 관계

$$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X, Y)$$

- $I(X; Y) \geq 0$
- $I(X; Y) = 0$ iff $X$와 $Y$가 독립

## 1.6 주요 확률 분포 — 입문

### 베르누이 분포 (Bernoulli Distribution)

동전 던지기처럼 두 가지 결과만 있는 시행:

$$P(X = x) = \mu^x (1-\mu)^{1-x}, \quad x \in \{0, 1\}$$

- 평균: $\mathbb{E}[X] = \mu$
- 분산: $\text{Var}(X) = \mu(1-\mu)$
- 엔트로피: $H(X) = -\mu\log\mu - (1-\mu)\log(1-\mu)$

### 이항 분포 (Binomial Distribution)

$n$번 독립 베르누이 시행에서 성공 횟수:

$$P(X = k) = \binom{n}{k} \mu^k (1-\mu)^{n-k}$$

### 정규(가우시안) 분포 (Normal/Gaussian Distribution)

$$\mathcal{N}(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

- 평균 $\mu$, 분산 $\sigma^2$에 의해 완전히 결정
- 중심극한정리(CLT)에 의해 자연계에서 가장 흔히 등장
- 주어진 평균과 분산 하에서 **엔트로피를 최대화**하는 분포

# 중급 (Intermediate)

## 2.1 엔트로피의 엄밀한 유도와 성질

### 연속 확률변수의 미분 엔트로피 (Differential Entropy)

연속 확률변수 $X$에 대해:

$$h(X) = -\int_{-\infty}^{\infty} f(x) \log f(x) \, dx$$

**주의**: 미분 엔트로피는 음수가 될 수 있다! (이산 엔트로피와 다른 점)

**예시 — 가우시안의 미분 엔트로피:**

$$h(X) = -\int f(x) \log f(x) \, dx$$

$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$를 대입하면:

$$\log f(x) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(x-\mu)^2}{2\sigma^2}$$

따라서:

$$h(X) = \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2}\mathbb{E}[(X-\mu)^2] = \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2}$$

$$\boxed{h(X) = \frac{1}{2}\log(2\pi e \sigma^2)}$$

### 조건부 엔트로피 (Conditional Entropy)

$$H(Y|X) = -\sum_{x, y} P(x, y) \log P(y|x) = H(X, Y) - H(X)$$

**체인 룰**:

$$H(X_1, X_2, \ldots, X_n) = \sum_{i=1}^{n} H(X_i | X_1, \ldots, X_{i-1})$$

## 2.2 깁스 부등식 (Gibbs' Inequality) 증명

**정리**: 임의의 두 확률 분포 $P$, $Q$에 대해 $D_{\text{KL}}(P \| Q) \geq 0$이며, 등호는 $P = Q$일 때만 성립한다.

**증명**:

Jensen의 부등식을 사용한다. $\log$는 오목(concave) 함수이므로:

$$-D_{\text{KL}}(P \| Q) = \sum_x P(x) \log \frac{Q(x)}{P(x)} \leq \log \sum_x P(x) \cdot \frac{Q(x)}{P(x)} = \log \sum_x Q(x) = \log 1 = 0$$

따라서 $D_{\text{KL}}(P \| Q) \geq 0$. $\square$

등호 조건: $\frac{Q(x)}{P(x)}$가 상수, 즉 $P = Q$일 때.

### 깁스 부등식의 중요한 귀결

**귀결 1**: 균등분포의 최대 엔트로피

$|\mathcal{X}| = n$인 이산 확률변수에서 균등분포 $U(x) = 1/n$에 대해:

$$0 \leq D_{\text{KL}}(P \| U) = \sum_x P(x) \log \frac{P(x)}{1/n} = -H(P) + \log n$$

따라서 $H(P) \leq \log n$이고, 등호는 $P$가 균등분포일 때.

**귀결 2**: 교차 엔트로피의 하한

$$H(P, Q) = H(P) + D_{\text{KL}}(P \| Q) \geq H(P)$$

## 2.3 KL 다이버전스의 비대칭성과 변형

### Forward KL vs Reverse KL

**Forward KL**: $D_{\text{KL}}(P \| Q)$ — "mean-seeking"
- $P(x) > 0$인 곳에서 $Q(x) \approx 0$이면 → 큰 벌점
- 모델 $Q$가 $P$의 모든 모드를 커버하도록 유도

**Reverse KL**: $D_{\text{KL}}(Q \| P)$ — "mode-seeking"
- $Q(x) > 0$인 곳에서 $P(x) \approx 0$이면 → 큰 벌점
- 모델 $Q$가 $P$의 한 모드에 집중하도록 유도

딥러닝에서 VAE의 ELBO는 reverse KL을 최소화하고, 일반적인 지도학습은 forward KL(= 교차 엔트로피)을 최소화한다.

### Jensen-Shannon 다이버전스

대칭적인 다이버전스:

$$D_{\text{JS}}(P \| Q) = \frac{1}{2}D_{\text{KL}}\left(P \left\| \frac{P+Q}{2}\right.\right) + \frac{1}{2}D_{\text{KL}}\left(Q \left\| \frac{P+Q}{2}\right.\right)$$

- $0 \leq D_{\text{JS}} \leq \log 2$ (밑이 2일 때 최대 1)
- GAN의 원래 목적함수가 JS 다이버전스와 관련된다

## 2.4 KL 다이버전스와 MLE의 관계

### 핵심 연결

데이터 분포를 $P_{\text{data}}$, 모델을 $P_\theta$라 하면:

$$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \frac{1}{N}\sum_{i=1}^{N} \log P_\theta(x_i)$$

이것은 다음과 **동치**이다:

$$\hat{\theta}_{\text{MLE}} = \arg\min_\theta D_{\text{KL}}(P_{\text{data}} \| P_\theta)$$

**유도**:

$$D_{\text{KL}}(P_{\text{data}} \| P_\theta) = \mathbb{E}_{x \sim P_{\text{data}}}[\log P_{\text{data}}(x)] - \mathbb{E}_{x \sim P_{\text{data}}}[\log P_\theta(x)]$$

첫째 항은 $\theta$와 무관한 상수이므로, KL을 최소화하려면:

$$\max_\theta \mathbb{E}_{x \sim P_{\text{data}}}[\log P_\theta(x)] \approx \max_\theta \frac{1}{N}\sum_{i=1}^{N} \log P_\theta(x_i)$$

이것이 바로 **로그 우도의 최대화(MLE)**이다.

**결론**: MLE는 모델 분포와 데이터 분포 사이의 KL 다이버전스를 최소화하는 것과 같다.

## 2.5 다변량 정규분포 (Multivariate Normal Distribution)

### 정의

$\mathbf{x} \in \mathbb{R}^d$에 대해:

$$\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{(2\pi)^{d/2}|\boldsymbol{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\right)$$

여기서:
- $\boldsymbol{\mu} \in \mathbb{R}^d$: 평균 벡터
- $\boldsymbol{\Sigma} \in \mathbb{R}^{d \times d}$: 공분산 행렬 (양의 정부호, symmetric)
- $|\boldsymbol{\Sigma}|$: 공분산 행렬의 행렬식(determinant)
- $\boldsymbol{\Sigma}^{-1}$: 정밀도 행렬(precision matrix)

### 주요 성질

**1. 주변 분포(Marginal)도 정규분포:**

$$\begin{pmatrix} \mathbf{x}_1 \\ \mathbf{x}_2 \end{pmatrix} \sim \mathcal{N}\left(\begin{pmatrix} \boldsymbol{\mu}_1 \\ \boldsymbol{\mu}_2 \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma}_{11} & \boldsymbol{\Sigma}_{12} \\ \boldsymbol{\Sigma}_{21} & \boldsymbol{\Sigma}_{22} \end{pmatrix}\right)$$

이면 $\mathbf{x}_1 \sim \mathcal{N}(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_{11})$

**2. 조건부 분포도 정규분포:**

$$\mathbf{x}_1 | \mathbf{x}_2 \sim \mathcal{N}(\boldsymbol{\mu}_{1|2}, \boldsymbol{\Sigma}_{1|2})$$

여기서:
$$\boldsymbol{\mu}_{1|2} = \boldsymbol{\mu}_1 + \boldsymbol{\Sigma}_{12}\boldsymbol{\Sigma}_{22}^{-1}(\mathbf{x}_2 - \boldsymbol{\mu}_2)$$
$$\boldsymbol{\Sigma}_{1|2} = \boldsymbol{\Sigma}_{11} - \boldsymbol{\Sigma}_{12}\boldsymbol{\Sigma}_{22}^{-1}\boldsymbol{\Sigma}_{21}$$

**3. 선형 변환**: $\mathbf{y} = \mathbf{A}\mathbf{x} + \mathbf{b}$이면 $\mathbf{y} \sim \mathcal{N}(\mathbf{A}\boldsymbol{\mu} + \mathbf{b}, \mathbf{A}\boldsymbol{\Sigma}\mathbf{A}^\top)$

**4. 두 가우시안 간의 KL 다이버전스:**

$$D_{\text{KL}}(\mathcal{N}_0 \| \mathcal{N}_1) = \frac{1}{2}\left[\text{tr}(\boldsymbol{\Sigma}_1^{-1}\boldsymbol{\Sigma}_0) + (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0)^\top \boldsymbol{\Sigma}_1^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_0) - d + \log\frac{|\boldsymbol{\Sigma}_1|}{|\boldsymbol{\Sigma}_0|}\right]$$

이 공식은 **VAE의 KL 항** 계산에 직접 사용된다.

## 2.6 교차 엔트로피 손실함수의 수학적 정당성

### 이진 분류 (Binary Classification)

모델이 시그모이드를 통해 $\hat{y} = \sigma(z)$를 출력할 때:

$$\mathcal{L}_{\text{BCE}} = -[y \log \hat{y} + (1-y) \log(1-\hat{y})]$$

이것은 베르누이 분포의 **음의 로그 우도(Negative Log-Likelihood)**와 정확히 같다:

$$P(y | x; \theta) = \hat{y}^y (1-\hat{y})^{1-y}$$

$$-\log P(y | x; \theta) = -y\log\hat{y} - (1-y)\log(1-\hat{y}) = \mathcal{L}_{\text{BCE}}$$

### 다중 분류 (Multi-class Classification)

모델이 소프트맥스를 통해 $\hat{\mathbf{y}}$를 출력할 때:

$$\mathcal{L}_{\text{CE}} = -\sum_{c=1}^{C} y_c \log \hat{y}_c$$

이것은 카테고리컬 분포의 음의 로그 우도이다.

### MSE vs 교차 엔트로피: 기울기 비교

시그모이드 출력 + MSE:
$$\frac{\partial \mathcal{L}_{\text{MSE}}}{\partial z} = (\hat{y} - y) \cdot \sigma'(z) = (\hat{y} - y) \cdot \hat{y}(1-\hat{y})$$

$\hat{y} \approx 0$ 또는 $\hat{y} \approx 1$일 때 $\sigma'(z) \approx 0$ → **기울기 소실!**

시그모이드 출력 + 교차 엔트로피:
$$\frac{\partial \mathcal{L}_{\text{CE}}}{\partial z} = \hat{y} - y$$

기울기가 깔끔하게 나오며, 포화 구간에서도 학습이 잘 된다.

# 고급 (Advanced)

## 3.1 지수족 분포 (Exponential Family)

### 일반적 형태

$$P(x | \boldsymbol{\eta}) = h(x) \exp\left(\boldsymbol{\eta}^\top \mathbf{T}(x) - A(\boldsymbol{\eta})\right)$$

여기서:
- $\boldsymbol{\eta}$: **자연 모수 (natural parameter)**
- $\mathbf{T}(x)$: **충분 통계량 (sufficient statistic)**
- $A(\boldsymbol{\eta})$: **로그 정규화 상수 (log-partition function)** — cumulant generating function
- $h(x)$: 기저 측도 (base measure)

### 주요 분포의 지수족 표현

**베르누이 분포:**

$$P(x | \mu) = \mu^x (1-\mu)^{1-x} = (1-\mu) \exp\left(x \log\frac{\mu}{1-\mu}\right)$$

- $\eta = \log\frac{\mu}{1-\mu}$ (로그 오즈, logit)
- $T(x) = x$
- $A(\eta) = \log(1 + e^\eta)$ (softplus 함수!)
- $\mu = \sigma(\eta)$ (시그모이드가 자연스럽게 등장)

**가우시안 분포 (분산 기지):**

$$P(x | \mu) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

$$= \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(\frac{\mu}{\sigma^2}x - \frac{\mu^2}{2\sigma^2} - \frac{x^2}{2\sigma^2}\right)$$

- $\eta = \mu / \sigma^2$
- $T(x) = x$
- $A(\eta) = \frac{\sigma^2 \eta^2}{2} = \frac{\mu^2}{2\sigma^2}$

**가우시안 분포 (평균, 분산 모두 미지):**

$$\boldsymbol{\eta} = \begin{pmatrix} \mu/\sigma^2 \\ -1/(2\sigma^2) \end{pmatrix}, \quad \mathbf{T}(x) = \begin{pmatrix} x \\ x^2 \end{pmatrix}$$

### 로그 정규화 상수 $A(\boldsymbol{\eta})$의 놀라운 성질

$$\frac{\partial A(\boldsymbol{\eta})}{\partial \boldsymbol{\eta}} = \mathbb{E}[\mathbf{T}(x)]$$

$$\frac{\partial^2 A(\boldsymbol{\eta})}{\partial \boldsymbol{\eta} \partial \boldsymbol{\eta}^\top} = \text{Cov}[\mathbf{T}(x)]$$

즉, 로그 정규화 상수를 미분하면 충분 통계량의 모멘트를 얻는다! 이것이 $A$를 **cumulant generating function**이라 부르는 이유이다.

또한 공분산은 항상 양의 반정부호이므로, $A(\boldsymbol{\eta})$는 **볼록 함수(convex function)**이다. 이는 지수족의 MLE가 전역 최적해를 가짐을 보장한다.

## 3.2 충분 통계량 (Sufficient Statistics)

### 정의

통계량 $T(x)$가 모수 $\theta$에 대한 **충분 통계량**이라 함은, $T(x)$가 주어졌을 때 $x$의 조건부 분포가 $\theta$에 의존하지 않는 것이다:

$$P(x | T(x), \theta) = P(x | T(x))$$

### Fisher-Neyman 인수분해 정리

$T(x)$가 $\theta$에 대한 충분 통계량 $\iff$

$$P(x | \theta) = g(T(x), \theta) \cdot h(x)$$

여기서 $g$는 $T(x)$와 $\theta$만의 함수, $h$는 $x$만의 함수.

### 지수족과 충분 통계량

지수족에서 $\mathbf{T}(x)$는 자연스럽게 충분 통계량이 된다. 이는 지수족의 MLE가 충분 통계량만으로 계산 가능함을 의미한다.

**예시**: 가우시안의 MLE에서 $\hat{\mu} = \bar{x}$, $\hat{\sigma}^2 = \frac{1}{N}\sum(x_i - \bar{x})^2$이므로, $T = (\sum x_i, \sum x_i^2)$만 있으면 된다. 개별 데이터 $x_1, \ldots, x_N$은 불필요하다.

## 3.3 피셔 정보 (Fisher Information)

### 정의

$$\mathcal{I}(\theta) = \mathbb{E}\left[\left(\frac{\partial \log P(x|\theta)}{\partial \theta}\right)^2\right] = -\mathbb{E}\left[\frac{\partial^2 \log P(x|\theta)}{\partial \theta^2}\right]$$

### 피셔 정보 행렬 (Fisher Information Matrix, FIM)

다변량 모수 $\boldsymbol{\theta}$에 대해:

$$[\mathbf{F}(\boldsymbol{\theta})]_{ij} = \mathbb{E}\left[\frac{\partial \log P(x|\boldsymbol{\theta})}{\partial \theta_i} \cdot \frac{\partial \log P(x|\boldsymbol{\theta})}{\partial \theta_j}\right]$$

$$= -\mathbb{E}\left[\frac{\partial^2 \log P(x|\boldsymbol{\theta})}{\partial \theta_i \partial \theta_j}\right]$$

### 피셔 정보의 의미

- 모수 $\theta$에 대해 데이터가 "얼마나 많은 정보를 제공하는가"
- 피셔 정보가 크면 → $\theta$의 추정이 정밀하다
- **크라메르-라오 하한(Cramer-Rao Lower Bound)**: 임의의 불편 추정량 $\hat{\theta}$에 대해:
  $$\text{Var}(\hat{\theta}) \geq \frac{1}{N \cdot \mathcal{I}(\theta)}$$

### 지수족에서의 피셔 정보

지수족에서 피셔 정보 행렬은 로그 정규화 상수의 헤시안과 같다:

$$\mathbf{F}(\boldsymbol{\eta}) = \nabla^2_{\boldsymbol{\eta}} A(\boldsymbol{\eta}) = \text{Cov}[\mathbf{T}(x)]$$

## 3.4 자연 기울기 (Natural Gradient)

### 문제 제기

일반적인 경사하강법:

$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \alpha \nabla_\theta \mathcal{L}(\boldsymbol{\theta}_t)$$

이것은 유클리드 거리 관점에서 가장 빠른 감소 방향이다. 하지만 확률 분포의 공간에서는 유클리드 거리가 자연스럽지 않다.

**예시**: $\theta = 0.01$에서 $\theta = 0.02$로의 변화와 $\theta = 0.50$에서 $\theta = 0.51$로의 변화는 유클리드 거리로는 같지만, 확률 분포의 변화량은 크게 다르다.

### 자연 기울기의 정의

확률 분포 공간에서 KL 다이버전스를 기준으로 한 최속강하 방향:

$$\tilde{\nabla}_\theta \mathcal{L} = \mathbf{F}(\boldsymbol{\theta})^{-1} \nabla_\theta \mathcal{L}$$

**자연 기울기 갱신**:

$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \alpha \mathbf{F}(\boldsymbol{\theta}_t)^{-1} \nabla_\theta \mathcal{L}(\boldsymbol{\theta}_t)$$

### 왜 자연 기울기가 좋은가?

1. **재매개변수화 불변(reparameterization invariant)**: $\theta$를 $\phi = g(\theta)$로 바꿔도 업데이트가 동일
2. **지수족에서 특히 효과적**: 자연 모수 공간에서의 자연 기울기는 기대 모수(expectation parameter) 공간의 일반 기울기와 동치
3. **실용적 근사**: Adam, K-FAC 등이 피셔 정보의 근사로 볼 수 있다

### 딥러닝에서의 연결

- **K-FAC (Kronecker-Factored Approximate Curvature)**: FIM을 Kronecker 곱으로 근사하여 효율적으로 자연 기울기를 계산
- **Adam optimizer**: 적응적 학습률이 FIM의 대각 근사로 해석 가능
- **TRPO/PPO (강화학습)**: KL 다이버전스 제약 하에서의 정책 최적화 — 자연 기울기의 직접적 응용

## 3.5 정보 기하학 (Information Geometry) 개요

확률 분포의 공간을 리만 다양체(Riemannian manifold)로 볼 수 있다:
- **리만 계량(metric tensor)** = 피셔 정보 행렬
- **측지선(geodesic)** = 분포 사이의 "최단 경로"
- 지수족은 이 다양체에서 **평평한(flat)** 부분 다양체를 형성

이 관점에서 **e-connection**(exponential connection)과 **m-connection**(mixture connection)이라는 두 가지 아핀 연결이 존재하며, 이들의 이중성(duality)이 지수족의 수학적 구조를 완전히 설명한다.

## 3.6 최대 엔트로피 원리 (Maximum Entropy Principle)

### 원리

주어진 제약 조건 하에서 엔트로피를 최대화하는 분포를 선택해야 한다 — 이것이 가장 "편향 없는(least biased)" 분포이다.

### 제약에 따른 결과 분포

| 제약 조건 | 최대 엔트로피 분포 |
|-----------|-------------------|
| 지지(support)가 유한 | 균등 분포 |
| $\mathbb{E}[X] = \mu$, $\text{Var}(X) = \sigma^2$ | 가우시안 분포 |
| $X \geq 0$, $\mathbb{E}[X] = \lambda^{-1}$ | 지수 분포 |
| $X \in \{0, 1, \ldots\}$, $\mathbb{E}[X] = \lambda$ | 포아송 분포 |

### 라그랑주 승수법을 이용한 유도

$\mathbb{E}[X] = \mu$, $\text{Var}(X) = \sigma^2$ 제약 하에서:

$$\max_{f} h(f) = -\int f(x) \log f(x) \, dx$$

$$\text{s.t.} \quad \int f(x) dx = 1, \quad \int x f(x) dx = \mu, \quad \int (x-\mu)^2 f(x) dx = \sigma^2$$

라그랑주 함수:

$$\mathcal{L} = -\int f \log f \, dx + \lambda_0\left(\int f \, dx - 1\right) + \lambda_1\left(\int xf \, dx - \mu\right) + \lambda_2\left(\int (x-\mu)^2 f \, dx - \sigma^2\right)$$

변분법(calculus of variations)으로 $\frac{\delta \mathcal{L}}{\delta f} = 0$을 풀면:

$$f^*(x) = \exp\left(-1 + \lambda_0 + \lambda_1 x + \lambda_2(x-\mu)^2\right)$$

이것은 정확히 가우시안 분포의 형태이다. 이것이 **가우시안이 왜 특별한가**에 대한 정보 이론적 답이다.

### 지수족과의 연결

최대 엔트로피 원리로 얻어지는 분포는 항상 **지수족**이다. 제약 조건이 $\mathbb{E}[T_i(x)] = \tau_i$의 형태일 때, 최대 엔트로피 분포는:

$$P^*(x) = h(x) \exp\left(\sum_i \eta_i T_i(x) - A(\boldsymbol{\eta})\right)$$

여기서 $\eta_i$는 제약 조건을 만족하도록 결정되는 라그랑주 승수이다.

## 공식 정리표

| 개념 | 공식 | 핵심 포인트 |
|------|------|------------|
| 자기 정보 | $I(x) = -\log P(x)$ | 놀라움의 정도 |
| 엔트로피 | $H(X) = -\sum P(x)\log P(x)$ | 평균 불확실성 |
| 교차 엔트로피 | $H(P,Q) = -\sum P(x)\log Q(x)$ | $Q$로 $P$ 인코딩 비용 |
| KL 다이버전스 | $D_{\text{KL}}(P\|Q) = \sum P\log\frac{P}{Q}$ | 분포 차이 측정, 비대칭 |
| 상호 정보량 | $I(X;Y) = H(X) - H(X|Y)$ | 공유 정보량 |
| 가우시안 엔트로피 | $h = \frac{1}{2}\log(2\pi e\sigma^2)$ | $\sigma$만의 함수 |

## 시험에 자주 나오는 증명/유도

1. **깁스 부등식** (Jensen 부등식 이용)
2. **MLE = KL 최소화** 동치 유도
3. **교차 엔트로피 기울기**가 $\hat{y} - y$가 되는 유도
4. **가우시안의 미분 엔트로피** 계산
5. **두 가우시안 간 KL 다이버전스** 유도

## 딥러닝 연결 포인트

- 분류 손실함수 = 교차 엔트로피 = NLL
- MLE = KL 다이버전스 최소화
- VAE: ELBO에 KL(q||p) 항 포함
- GAN: JS 다이버전스 관련
- Adam/K-FAC: 피셔 정보의 근사
- Softmax: 지수족의 자연 출력
- Batch Normalization: 피셔 정보 행렬의 조건수(condition number) 개선으로 해석 가능
