# 1. 입문 (Beginner)

## 1.1 일반화란 무엇인가?

딥러닝 모델의 궁극적 목표는 **학습 데이터에서 본 적 없는 새로운 데이터**에 대해서도 좋은 성능을 보이는 것이다. 이 능력을 **일반화(generalization)**라 부른다.

- **Training Error**: 학습 데이터에 대한 손실(loss)
- **Test Error**: 학습에 사용되지 않은 데이터에 대한 손실
- **Generalization Gap**: Test Error - Training Error

$$
\text{Generalization Gap} = \mathcal{L}_{\text{test}}(\theta) - \mathcal{L}_{\text{train}}(\theta)
$$

일반화 갭이 작을수록 모델이 학습 데이터에만 맞춰진 것이 아니라 실제 데이터 분포를 잘 학습한 것이다.

## 1.2 Bias-Variance Tradeoff 기초

모델의 예측 오차는 세 가지 성분으로 분해할 수 있다:

$$
\mathbb{E}[(y - \hat{f}(x))^2] = \text{Bias}^2 + \text{Variance} + \text{Irreducible Noise}
$$

| 요소 | 의미 | 직관 |
|------|------|------|
| **Bias** | 모델이 얼마나 단순해서 참 함수를 못 맞추는가 | 과소적합(underfitting) |
| **Variance** | 학습 데이터가 바뀌면 모델 예측이 얼마나 흔들리는가 | 과적합(overfitting) |
| **Irreducible Noise** | 데이터 자체의 노이즈 | 줄일 수 없음 |

**핵심 직관**:
- 모델이 너무 단순하면 → 높은 Bias, 낮은 Variance (과소적합)
- 모델이 너무 복잡하면 → 낮은 Bias, 높은 Variance (과적합)
- 전통적으로는 둘 사이의 **최적 지점(sweet spot)**이 있다고 봄

## 1.3 Training vs Test Error Curves

모델 복잡도를 $x$축에, 오류를 $y$축에 놓으면:

```
Error
  │
  │  ╲  Training Error
  │    ╲_______________
  │   /
  │  / Test Error
  │ /        ╲_____╱  ← sweet spot
  │/
  └─────────────────── Model Complexity
```

- 복잡도 증가 → Training Error 감소 (데이터를 더 잘 외우므로)
- 복잡도 증가 → Test Error는 처음에 감소했다가 다시 증가 (U자 곡선)

## 1.4 정규화(Regularization) 기초 기법

과적합을 방지하기 위한 대표적 기법들을 살펴보자.

### 1.4.1 Weight Decay (L2 Regularization)

손실 함수에 가중치의 크기에 대한 페널티를 추가한다:

$$
\mathcal{L}_{\text{reg}}(\theta) = \mathcal{L}(\theta) + \frac{\lambda}{2} \|\theta\|_2^2
$$

- $\lambda$: 정규화 강도를 조절하는 하이퍼파라미터
- 가중치가 지나치게 커지는 것을 방지 → 모델이 데이터의 노이즈에 민감하게 반응하는 것을 억제
- SGD 업데이트 시: $\theta \leftarrow \theta - \eta \nabla \mathcal{L}(\theta) - \eta \lambda \theta$
  - 매 스텝마다 가중치가 $(1 - \eta\lambda)$ 비율로 줄어듦 → "weight decay"라 불림

### 1.4.2 Dropout

학습 시 각 뉴런을 확률 $p$로 랜덤하게 비활성화한다:

$$
\tilde{h}_i = \begin{cases} 0 & \text{with probability } p \\ \frac{h_i}{1-p} & \text{with probability } 1-p \end{cases}
$$

- $(1-p)$로 나누는 이유: 테스트 시에는 모든 뉴런을 사용하므로, 학습 시의 기대값과 맞추기 위함 (inverted dropout)
- 효과: 특정 뉴런에 과도하게 의존하는 것을 방지, 앙상블 효과

### 1.4.3 Data Augmentation

학습 데이터를 인위적으로 변형하여 데이터 양을 늘리는 기법:

- 이미지: 회전, 반전, 크롭, 색상 변환, 노이즈 추가
- 텍스트: 동의어 치환, 문장 셔플, 역번역(back-translation)
- 음성: 속도 변환, 노이즈 추가, pitch 변환

### 1.4.4 Early Stopping

학습 중 검증(validation) 오류를 모니터링하여 오류가 증가하기 시작하면 학습을 중단한다:

```
Validation Error
  │
  │     ╱╲
  │    ╱  ╲___
  │   ╱
  │  ╱
  │ ╱    ← 이 지점에서 학습 중단
  │╱
  └─────────────── Epochs
```

- **Patience**: 검증 오류가 개선되지 않는 에폭 수의 허용치
- 사실상 모델 복잡도(학습 시간)를 제한하는 정규화 기법

## 1.5 최적화 기초: 경사 하강법

### 1.5.1 Gradient Descent (GD)

파라미터 $\theta$를 손실 함수의 기울기 반대 방향으로 업데이트:

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t)
$$

- $\eta$: 학습률(learning rate)
- **Batch GD**: 전체 데이터로 gradient 계산 → 정확하지만 느림
- **Mini-batch SGD**: 미니배치(batch)로 gradient 추정 → 실용적

### 1.5.2 Stochastic Gradient Descent (SGD)

미니배치 $B$를 샘플링하여 gradient를 추정:

$$
g_t = \frac{1}{|B|} \sum_{i \in B} \nabla_\theta \mathcal{L}_i(\theta_t)
$$

$$
\theta_{t+1} = \theta_t - \eta \, g_t
$$

SGD의 핵심 성질:
- $\mathbb{E}[g_t] = \nabla \mathcal{L}(\theta_t)$ → 불편 추정량(unbiased estimator)
- gradient에 노이즈가 섞여 있음 → 이것이 오히려 일반화에 도움

# 2. 중급 (Intermediate)

## 2.1 Loss Surface와 최적화 지형

딥러닝의 손실 함수 $\mathcal{L}(\theta)$는 고차원 공간에서의 복잡한 지형(landscape)을 형성한다.

### 2.1.1 Local Minima

$$
\nabla \mathcal{L}(\theta^*) = 0, \quad \nabla^2 \mathcal{L}(\theta^*) \succ 0 \quad (\text{positive definite})
$$

- 고전적 우려: SGD가 나쁜 local minimum에 갇히면?
- 현대적 관점: 고차원에서 대부분의 local minima는 global minimum과 유사한 loss 값을 가짐
- Choromanska et al. (2015): 랜덤 행렬 이론으로 분석 → 나쁜 local minima는 고차원에서 지수적으로 드묾

### 2.1.2 Saddle Points

$$
\nabla \mathcal{L}(\theta^*) = 0, \quad \text{but } \nabla^2 \mathcal{L}(\theta^*) \text{ has both positive and negative eigenvalues}
$$

- 고차원에서 saddle point는 local minima보다 **훨씬** 많음
- $d$차원에서 Hessian의 모든 고유값이 양수일 확률 $\approx (1/2)^d$ → $d$가 크면 극히 작음
- 실제로 학습이 느려지는 주범은 local minima가 아니라 saddle point와 그 주변의 **plateau**

### 2.1.3 Loss Surface 시각화

Li et al. (2018)의 "Visualizing the Loss Landscape"에서 제안한 방법:
- 파라미터 공간에서 두 랜덤 방향 $\delta_1, \delta_2$를 선택
- $\mathcal{L}(\theta^* + \alpha \delta_1 + \beta \delta_2)$를 $(\alpha, \beta)$ 평면에서 시각화
- filter normalization을 통해 스케일 불변한 시각화 가능

## 2.2 SGD 수렴 이론

### 2.2.1 Convex Case

$\mathcal{L}$이 convex이고 $L$-smooth($\|\nabla^2 \mathcal{L}\| \leq L$)일 때, 고정 학습률 $\eta$의 SGD:

$$
\mathbb{E}[\mathcal{L}(\theta_T)] - \mathcal{L}(\theta^*) \leq \frac{\|\theta_0 - \theta^*\|^2}{2\eta T} + \frac{\eta \sigma^2}{2}
$$

- $\sigma^2$: gradient 노이즈의 분산
- $T \to \infty$이면 첫째 항은 사라지지만, 둘째 항이 남음 → 학습률을 줄여야 수렴

### 2.2.2 학습률 스케줄링

수렴을 보장하려면 Robbins-Monro 조건을 만족해야 한다:

$$
\sum_{t=1}^{\infty} \eta_t = \infty, \quad \sum_{t=1}^{\infty} \eta_t^2 < \infty
$$

대표적 스케줄:
- **Step Decay**: 일정 에폭마다 $\eta$를 $\gamma$배로 줄임
- **Cosine Annealing**: $\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\frac{t}{T}\pi))$
- **Linear Warmup + Decay**: 처음 몇 스텝은 $\eta$를 선형으로 증가시킨 후 감소

### 2.2.3 Learning Rate Warmup

학습 초기에 학습률을 점진적으로 증가시키는 기법:

$$
\eta_t = \begin{cases} \frac{t}{T_{\text{warmup}}} \cdot \eta_{\max} & \text{if } t < T_{\text{warmup}} \\ \text{decay schedule} & \text{otherwise} \end{cases}
$$

**필요한 이유**:
- 초기에 gradient 크기가 불안정 → 큰 학습률은 발산 유발
- Batch Normalization 등의 통계가 안정화되기 전에 큰 업데이트는 위험
- 특히 Transformer, 큰 배치 사이즈 학습에서 필수적
- Goyal et al. (2017): 대규모 배치 학습에서 linear warmup 제안

## 2.3 Batch Size의 영향

### 2.3.1 큰 배치 vs 작은 배치

| 특성 | 큰 배치 | 작은 배치 |
|------|---------|----------|
| Gradient 노이즈 | 작음 (정밀한 추정) | 큼 (노이즈 많음) |
| 학습 속도 | 병렬화로 빠름 | 순차적으로 느림 |
| 일반화 | 상대적으로 나쁠 수 있음 | 상대적으로 좋을 수 있음 |
| 수렴 지점 | sharp minima로 수렴 경향 | flat minima로 수렴 경향 |

### 2.3.2 Linear Scaling Rule

배치 사이즈를 $k$배 키우면 학습률도 $k$배 키워야 유사한 학습 동역학 유지:

$$
\eta_{\text{new}} = k \cdot \eta_{\text{base}}
$$

- 직관: 배치가 커지면 gradient 노이즈가 줄어들어 같은 학습률에서 진전이 느려짐
- 한계: 너무 큰 배치에서는 이 규칙이 깨짐 → warmup 필요

### 2.3.3 Gradient Noise Scale

Smith et al. (2018)이 제안한 개념:

$$
B_{\text{noise}} = \frac{\text{tr}(\Sigma)}{G^2}
$$

- $\Sigma$: per-sample gradient의 공분산 행렬
- $G = \|\nabla \mathcal{L}\|$: full gradient의 norm
- $B < B_{\text{noise}}$이면 gradient 노이즈가 지배적 → 배치 키워도 효율적
- $B > B_{\text{noise}}$이면 gradient 노이즈가 작음 → 배치 키워도 학습 속도 향상 미미

## 2.4 정규화 기법 심화

### 2.4.1 Dropout 이론적 해석

- **앙상블 관점**: 지수적으로 많은 서브네트워크의 기하 평균 앙상블
- **베이지안 관점**: Gal & Ghahramani (2016) — dropout은 근사 베이지안 추론
  - dropout을 적용한 채 $T$번 forward → 예측의 분산으로 불확실성 추정 (MC Dropout)

$$
\text{Var}[\hat{y}] \approx \frac{1}{T}\sum_{t=1}^{T} \hat{y}_t^2 - \left(\frac{1}{T}\sum_{t=1}^{T}\hat{y}_t\right)^2
$$

### 2.4.2 Label Smoothing

hard label 대신 soft label을 사용:

$$
y_{\text{smooth}} = (1 - \epsilon) \cdot y_{\text{one-hot}} + \frac{\epsilon}{K}
$$

- $K$: 클래스 수, $\epsilon$: smoothing 계수 (보통 0.1)
- 효과: 모델이 지나치게 확신(overconfident)하는 것을 방지
- logit의 크기를 제한하여 일반화 향상

### 2.4.3 Mixup

Zhang et al. (2018):

$$
\tilde{x} = \lambda x_i + (1-\lambda) x_j, \quad \tilde{y} = \lambda y_i + (1-\lambda) y_j
$$

- $\lambda \sim \text{Beta}(\alpha, \alpha)$, 보통 $\alpha = 0.2$
- 학습 샘플 사이를 선형 보간 → 결정 경계를 부드럽게 만듦
- CutMix, CutOut 등의 변형도 있음

## 2.5 Flat Minima vs Sharp Minima 직관

Hochreiter & Schmidhuber (1997)부터 논의된 개념:

- **Flat minimum**: loss surface가 넓고 평탄한 영역의 최솟값
  - 파라미터에 작은 perturbation을 줘도 loss 변화가 적음
  - 일반화가 좋은 경향
- **Sharp minimum**: loss surface가 좁고 뾰족한 영역의 최솟값
  - 작은 perturbation에도 loss가 크게 변함
  - 일반화가 나쁜 경향

수학적으로 flatness는 Hessian의 고유값 크기로 측정:

$$
\text{Sharpness} \propto \max_{\|\epsilon\| \leq \rho} \mathcal{L}(\theta + \epsilon) - \mathcal{L}(\theta)
$$

# 3. 고급 (Advanced)

## 3.1 Double Descent Phenomenon

### 3.1.1 전통적 U자 곡선의 한계

전통적 bias-variance tradeoff는 모델 복잡도가 증가하면 test error가 U자를 그린다고 예측한다. 그러나 현대 딥러닝에서는 **double descent** 현상이 관찰된다.

### 3.1.2 Model-wise Double Descent

Belkin et al. (2019), Nakkiran et al. (2021):

```
Test Error
  │
  │ ╲           ╱╲
  │   ╲       ╱    ╲
  │     ╲   ╱        ╲_________
  │       ╲╱
  │        ↑
  │   Interpolation
  │   Threshold
  └────────────────────────── Model Complexity
      Classical    │    Modern
      Regime       │    Regime
```

**세 가지 영역**:
1. **Under-parameterized regime**: 전통적 bias-variance tradeoff (U자의 왼쪽)
2. **Interpolation threshold**: 모델이 학습 데이터를 정확히 외울 수 있는 최소 크기 → **peak**
3. **Over-parameterized regime**: 복잡도가 더 증가하면 test error가 다시 감소

### 3.1.3 왜 발생하는가?

**보간 임계점(Interpolation Threshold)**에서:
- 모델은 학습 데이터를 겨우 외울 수 있는 용량
- 유일한 해가 존재하며, 이 해는 매우 복잡함 (고주파 성분이 많음)
- 따라서 일반화가 최악

**과매개변수화 영역(Over-parameterized)**에서:
- 학습 데이터를 만족하는 해가 무수히 많음
- SGD(혹은 경사 하강법)는 이 중 **최소 노름 해(minimum norm solution)**를 선택하는 경향
- 최소 노름 해는 더 부드럽고 일반화가 좋음

### 3.1.4 Epoch-wise Double Descent

같은 모델에서도 학습 에폭에 따라 double descent 발생:

$$
\text{Test Error}(T) = \text{classical curve up to } T^* + \text{second descent after } T^*
$$

- 특정 에폭 $T^*$ 근처에서 test error가 피크를 찍고 다시 감소
- 노이즈가 있는 데이터에서 더 두드러짐

### 3.1.5 Sample-wise Double Descent

학습 데이터 수 $n$에 대해서도 double descent 관찰:
- 데이터를 더 추가하면 오히려 test error가 증가하는 구간이 존재
- $n \approx d$ (모델 파라미터 수) 근처에서 피크

## 3.2 SGD의 Implicit Regularization

### 3.2.1 Minimum Norm Solution

선형 모델 $y = X\theta$에서 $X \in \mathbb{R}^{n \times d}$, $n < d$ (과매개변수화)일 때:

$$
\theta_{\text{GD}} = X^T(XX^T)^{-1}y = \arg\min_\theta \|\theta\|_2 \quad \text{s.t. } X\theta = y
$$

- Gradient descent가 $\theta_0 = 0$에서 시작하면 자동으로 minimum $\ell_2$ norm solution으로 수렴
- 명시적 정규화 없이도 정규화 효과 발생 → **implicit regularization**

### 3.2.2 SGD 노이즈의 정규화 효과

SGD의 gradient 노이즈:

$$
g_t = \nabla \mathcal{L}(\theta_t) + \xi_t, \quad \text{Cov}(\xi_t) = \frac{1}{B}\Sigma(\theta_t)
$$

이 노이즈는 **등방적(isotropic)**이지 않다:
- loss가 큰 gradient를 가진 방향으로 노이즈가 큼
- sharp direction에서 더 큰 perturbation → sharp minima에서 탈출하는 효과
- 작은 배치 → 노이즈 큼 → 더 강한 implicit regularization

### 3.2.3 SGD as Approximate Bayesian Inference

Mandt et al. (2017):

일정 학습률 $\eta$의 SGD를 충분히 오래 돌리면, $\theta$의 정상 분포(stationary distribution)는 근사적으로:

$$
q(\theta) \approx \mathcal{N}\left(\theta^*, \frac{\eta}{2B} H^{-1} \Sigma H^{-1}\right)
$$

- $H$: Hessian, $\Sigma$: gradient noise covariance
- 이는 특정 prior를 가진 베이지안 사후 분포의 근사
- 학습률과 배치 사이즈가 implicit prior의 강도를 결정

## 3.3 PAC-Bayes Generalization Bound

### 3.3.1 PAC-Bayes Theorem

데이터에 독립인 사전 분포 $P$와 학습 후 사후 분포 $Q$ (파라미터 위의 분포)에 대해:

$$
\mathbb{E}_{\theta \sim Q}[\mathcal{L}_{\text{test}}(\theta)] \leq \mathbb{E}_{\theta \sim Q}[\mathcal{L}_{\text{train}}(\theta)] + \sqrt{\frac{D_{\text{KL}}(Q \| P) + \ln(n/\delta)}{2n}}
$$

- $n$: 학습 샘플 수, $\delta$: 신뢰도 파라미터
- $D_{\text{KL}}(Q \| P)$: 사전과 사후 분포 사이의 KL divergence

### 3.3.2 Flat Minima와 PAC-Bayes의 연결

Flat minimum 주변에서:
- $Q$를 $\mathcal{N}(\theta^*, \sigma^2 I)$로 설정해도 training loss가 크게 증가하지 않음
- → 큰 $\sigma$를 사용 가능
- → $D_{\text{KL}}(Q \| P)$가 작아짐 (prior $P$가 넓은 Gaussian일 때)
- → 더 타이트한 generalization bound

Sharp minimum에서는:
- $\sigma$를 크게 하면 training loss가 급증
- → 작은 $\sigma$ 필요
- → $D_{\text{KL}}(Q \| P)$가 커짐
- → 느슨한 bound

### 3.3.3 PAC-Bayes Bound의 최적화

Dziugaite & Roy (2017): PAC-Bayes bound 자체를 최적화하여 일반화가 좋은 모델 학습:

$$
\min_{Q} \left[ \mathbb{E}_{\theta \sim Q}[\mathcal{L}_{\text{train}}(\theta)] + \lambda \cdot D_{\text{KL}}(Q \| P) \right]
$$

이것은 variational inference와 동일한 형태 → 베이지안 딥러닝과의 연결

## 3.4 Sharpness-Aware Minimization (SAM)

### 3.4.1 핵심 아이디어

Foret et al. (2021): loss 값 자체가 아니라, **이웃 전체에서의 최대 loss**를 최소화:

$$
\min_\theta \max_{\|\epsilon\| \leq \rho} \mathcal{L}(\theta + \epsilon)
$$

이는 minimax 문제로, flat minima를 직접 찾는 것에 해당한다.

### 3.4.2 SAM 알고리즘

내부 maximization을 1차 근사로 풀면:

$$
\hat{\epsilon}(\theta) = \rho \frac{\nabla_\theta \mathcal{L}(\theta)}{\|\nabla_\theta \mathcal{L}(\theta)\|}
$$

그 후 외부 minimization:

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t + \hat{\epsilon}(\theta_t))
$$

**알고리즘 요약**:
1. 현재 $\theta$에서 gradient 계산 → $\nabla \mathcal{L}(\theta)$
2. adversarial perturbation 계산: $\hat{\epsilon} = \rho \frac{\nabla \mathcal{L}(\theta)}{\|\nabla \mathcal{L}(\theta)\|}$
3. perturbation된 지점에서 gradient 다시 계산: $\nabla \mathcal{L}(\theta + \hat{\epsilon})$
4. 이 gradient로 파라미터 업데이트

**비용**: forward-backward pass가 2배 → 학습 시간 약 2배

### 3.4.3 ASAM (Adaptive SAM)

Kwon et al. (2021): 파라미터 스케일에 적응적인 perturbation:

$$
\hat{\epsilon} = \rho \frac{T_\theta^2 \nabla \mathcal{L}(\theta)}{\|T_\theta \nabla \mathcal{L}(\theta)\|}
$$

- $T_\theta = \text{diag}(|\theta|)$ 또는 관련 스케일링 행렬
- 파라미터 크기에 비례하는 perturbation → reparameterization 불변

## 3.5 Neural Tangent Kernel (NTK) 관점

### 3.5.1 NTK 정의

무한 폭(infinite width) 신경망에서, 학습 동역학이 **kernel regression**으로 귀결됨:

$$
K_{\text{NTK}}(x, x') = \left\langle \frac{\partial f(\theta_0, x)}{\partial \theta}, \frac{\partial f(\theta_0, x')}{\partial \theta} \right\rangle
$$

- Jacot et al. (2018): 무한 폭 극한에서 이 kernel은 학습 중 변하지 않음 (lazy training regime)
- Gradient descent 동역학: $\frac{d f_t}{dt} = -K_{\text{NTK}}(f_t - y)$

### 3.5.2 일반화에 대한 시사점

- NTK의 고유값 스펙트럼이 빠르게 감소 → 저주파 함수를 먼저 학습 (spectral bias)
- 이는 implicit regularization의 한 형태: 부드러운 함수를 선호

## 3.6 Grokking 현상

Power et al. (2022):

- 작은 데이터셋에서 학습 시, training accuracy가 100%에 도달한 **한참 후**에야 test accuracy가 갑자기 향상
- 예: modular arithmetic 문제에서 수만 에폭 뒤에 일반화 달성

$$
\text{Train Acc} \to 100\% \quad \text{at epoch } T_1, \quad \text{Test Acc} \to 100\% \quad \text{at epoch } T_2 \gg T_1
$$

**해석**:
- 초기: 암기(memorization) 단계 → training loss 감소, test loss 변화 없음
- 후기: weight decay 등의 정규화가 점진적으로 구조화된 해로 이동시킴
- 궁극적으로 일반화 가능한 알고리즘(회로)이 출현

## 3.7 Lottery Ticket Hypothesis

Frankle & Carlin (2019):

> 랜덤 초기화된 밀집 네트워크에는 초기 가중치의 부분집합(subnetwork)이 존재하여, 그것만 독립적으로 학습해도 원래 네트워크와 유사한 성능에 도달할 수 있다.

**Iterative Magnitude Pruning (IMP)**:
1. 네트워크 초기화: $\theta_0$
2. 학습하여 $\theta_T$ 획득
3. 크기가 작은 가중치 $p\%$ 제거 (pruning mask $m$ 생성)
4. 남은 가중치를 $\theta_0$의 값으로 되돌림: $m \odot \theta_0$
5. 다시 학습 → 2-4 반복

**시사점**:
- 과매개변수화가 학습을 쉽게 만들지만, 최종적으로 필요한 파라미터는 훨씬 적을 수 있음
- Winning ticket을 찾는 것 자체가 학습의 핵심 역할

## 3.8 정규화의 통합적 관점

모든 정규화 기법은 결국 다음 중 하나(혹은 여러 개)에 해당한다:

1. **함수 공간 제한**: Weight decay → 작은 가중치, Dropout → 서브네트워크 앙상블
2. **데이터 분포 확장**: Data augmentation, Mixup → 학습 분포를 넓힘
3. **학습 동역학 조절**: Early stopping, 학습률 스케줄 → 탐색 경로 제한
4. **손실 함수 수정**: Label smoothing → 타겟 분포 완화
5. **파라미터 공간 탐색 유도**: SAM → 평탄한 영역으로 유도

이들의 조합이 현대 딥러닝의 일반화를 가능하게 한다.
