# 완전 유도 논리 체인 — 중간고사 마스터

> **목적**: 모든 유도가 어디서 시작하고, 왜 각 단계를 밟는지, 어디로 향하는지를 끊김 없이 보여주는 자료.
> **사용법**: 각 Part를 순서대로 읽되, ★ 표시 단계에서 멈추고 백지에 직접 재현해보라.
> **출처**: 한양대 이성윤 교수 딥러닝 강의 (2025), 694슬라이드 기반

```
[선형대수: 행렬/벡터/고유값/SVD]

```

# Part 1: 선형대수 유도 체인 (W2)

## 1.1 선형변환 ↔ 행렬의 동치성 증명

### 문제 (Problem)
**Prove that every linear transformation L: Rⁿ → Rᵐ corresponds bijectively to a matrix A_L ∈ Rᵐˣⁿ.**

모든 선형변환 L: Rⁿ → Rᵐ은 행렬 A_L ∈ Rᵐˣⁿ 과 일대일 대응됨을 증명하라.

### 전제 조건
- 선형변환의 정의: L(u+v) = L(u)+L(v), L(av) = aL(v)
- 표준 기저 벡터 e₁, e₂, ..., eₙ의 개념
- 임의의 벡터를 기저의 선형결합으로 표현할 수 있다는 성질

### Step-by-step 유도

**Step 1: 선형변환의 정의를 명확히 한다**

L: Rⁿ → Rᵐ이 선형변환이라는 것은 다음 두 조건을 만족한다는 뜻이다:
```
L(u + v) = L(u) + L(v)    (가법성)
L(av) = aL(v)              (동차성)
```
이 두 조건을 합치면: L(au + bv) = aL(u) + bL(v) (선형성)

**Step 2: 임의의 벡터를 기저로 분해한다**

Rⁿ의 표준 기저는 {e₁, e₂, ..., eₙ}이다. 임의의 v ∈ Rⁿ은:
```
v = v₁e₁ + v₂e₂ + ... + vₙeₙ
```
로 유일하게 표현된다. (v₁, ..., vₙ은 v의 성분)

**Step 3: 선형성을 적용해 L(v)를 기저 이미지로 분해한다**

★ 핵심 논리 전환점: 선형성 덕분에 L 전체를 알기 위해서는 기저에서의 값만 알면 된다!

```
L(v) = L(v₁e₁ + v₂e₂ + ... + vₙeₙ)
     = v₁L(e₁) + v₂L(e₂) + ... + vₙL(eₙ)   ← 선형성 적용
```

각 L(eᵢ) ∈ Rᵐ 이다.

**Step 4: 행렬 A_L을 구성한다**

L(eᵢ)를 열벡터로 나란히 놓아 행렬을 만든다:
```
A_L := [L(e₁) | L(e₂) | ... | L(eₙ)] ∈ Rᵐˣⁿ
```
그러면:
```
L(v) = v₁L(e₁) + ... + vₙL(eₙ) = A_L · v
```
즉, L(v) = A_L v 가 모든 v에 대해 성립한다.

**Step 5: 전단사 대응 (bijection) 증명**

- L → A_L 방향: 위에서 유일하게 구성됨 (단사)
- A_L → L_A 방향: 임의의 행렬 A에 대해 L_A(v) := Av 로 정의하면 선형변환이 됨
  - 가법성: L_A(u+v) = A(u+v) = Au+Av = L_A(u)+L_A(v) ✓
  - 동차성: L_A(av) = A(av) = aAv = aL_A(v) ✓
- 따라서 A ↔ L의 대응은 전단사(bijection)이다.

**결론**: 선형변환의 집합과 행렬의 집합 사이에 완전한 동치가 성립한다.

$$\boxed{A \mapsto L_A \mapsto A_{L_A} = A \quad \text{and} \quad L \mapsto A_L \mapsto L_{A_L} = L}$$

### 핵심 논리 전환점 (★)
- "선형변환은 기저에서의 값으로 완전히 결정된다" — 이것이 전체 증명의 핵심이다.
- 기저 이미지 L(eᵢ)를 열로 나열하면 행렬이 된다는 것이 직관이다.

### 연결
- → 1.3 고유값 분해: A의 특수한 벡터(고유벡터)에 대해 L_A(v) = λv
- → 1.4 SVD: A = UΣVᵀ는 "세 개의 선형변환의 합성"으로 해석
- → Part 4 역전파: Jacobian 행렬도 선형변환의 표현

### 채점 포인트 체크리스트
- [ ] 선형변환의 두 조건(가법성, 동차성)을 명시했는가
- [ ] 임의의 v를 기저 분해한 뒤 선형성을 적용했는가
- [ ] A_L의 열이 L(eᵢ)임을 보였는가
- [ ] 전단사 대응을 양방향으로 확인했는가

## 1.2 랭크-널리티 정리 증명

### 문제 (Problem)
**Prove the Rank-Nullity Theorem: for A ∈ Rᵐˣⁿ, rank(A) + null(A) = n.**

A ∈ Rᵐˣⁿ 에 대해 rank(A) + null(A) = n 임을 증명하라.

### 전제 조건
- 치역(column space): R(A) = {Av : v ∈ Rⁿ} ⊆ Rᵐ
- 영공간(null space): N(A) = {v ∈ Rⁿ : Av = 0} ⊆ Rⁿ
- rank(A) = dim(R(A)), null(A) = dim(N(A))
- 기저의 개념과 차원의 유일성

### Step-by-step 유도

**Step 1: N(A)의 기저를 구성한다**

dim(N(A)) = k라 하자. N(A)의 기저를 {n₁, n₂, ..., nₖ}라 부르자.
- 이 k개의 벡터는 선형독립이고 N(A)를 생성한다.

**Step 2: 기저를 Rⁿ 전체로 확장한다**

{n₁, ..., nₖ}는 Rⁿ의 부분공간의 기저이다.
이를 Rⁿ 전체의 기저로 확장한다:

```
{n₁, ..., nₖ, v₁, ..., v_r}    where r = n - k
```

즉, n개의 선형독립 벡터로 Rⁿ 전체를 기저로 갖는다.

★ 핵심: v₁, ..., v_r 이 추가된 벡터들이다. 이들의 A-이미지가 R(A)의 기저가 됨을 보인다.

**Step 3: {Av₁, ..., Av_r}이 R(A)를 생성함을 보인다**

임의의 Av ∈ R(A)에 대해, v = α₁n₁ + ... + αₖnₖ + β₁v₁ + ... + βᵣvᵣ 로 쓸 수 있다.

그러면:
```
Av = A(α₁n₁ + ... + αₖnₖ + β₁v₁ + ... + βᵣvᵣ)
   = α₁(An₁) + ... + αₖ(Anₖ) + β₁(Av₁) + ... + βᵣ(Avᵣ)
   = 0 + ... + 0 + β₁(Av₁) + ... + βᵣ(Avᵣ)   ← nᵢ ∈ N(A)이므로 Anᵢ = 0
   = β₁(Av₁) + ... + βᵣ(Avᵣ)
```
따라서 {Av₁, ..., Avᵣ}이 R(A)를 생성한다.

**Step 4: {Av₁, ..., Av_r}이 선형독립임을 보인다**

β₁(Av₁) + ... + βᵣ(Avᵣ) = 0 이라고 가정하면:
```
A(β₁v₁ + ... + βᵣvᵣ) = 0
```
따라서 (β₁v₁ + ... + βᵣvᵣ) ∈ N(A).

그런데 N(A)의 기저는 {n₁, ..., nₖ}이므로:
```
β₁v₁ + ... + βᵣvᵣ = γ₁n₁ + ... + γₖnₖ
```
이는 β₁v₁ + ... + βᵣvᵣ - γ₁n₁ - ... - γₖnₖ = 0 을 의미한다.

그런데 {n₁, ..., nₖ, v₁, ..., vᵣ}은 Rⁿ의 기저(선형독립!)이므로 모든 계수 = 0.
따라서 β₁ = ... = βᵣ = 0, 즉 {Av₁, ..., Avᵣ}은 선형독립이다.

**Step 5: 결론**

{Av₁, ..., Avᵣ}이 R(A)의 기저이므로:
```
rank(A) = dim(R(A)) = r = n - k = n - null(A)
```

$$\boxed{rank(A) + null(A) = n}$$

### 핵심 논리 전환점 (★)
- N(A)의 기저에서 시작해 Rⁿ으로 확장하는 것이 핵심 아이디어이다.
- vᵢ의 이미지 Avᵢ가 선형독립임을 보일 때, 역방향으로 Rⁿ의 기저 독립성을 활용한다.

### 연결
- → 1.4 SVD: 특이값의 개수 = rank(A)
- → 선형방정식 Ax=b의 해의 구조: 일반해 = 특수해 + N(A)의 원소

### 채점 포인트 체크리스트
- [ ] N(A)의 기저 {n₁,...,nₖ}에서 출발했는가
- [ ] 이를 Rⁿ의 기저로 확장하는 단계를 보였는가
- [ ] {Av₁,...,Avᵣ}이 R(A)를 생성함을 보였는가
- [ ] {Av₁,...,Avᵣ}의 선형독립성을 증명했는가

## 1.3 고유값 분해 유도 (스펙트럴 분해)

### 문제 (Problem)
**Derive the eigendecomposition A = UΛUᵀ for a real symmetric matrix A.**

실수 대칭행렬 A에 대해 A = UΛUᵀ 분해를 유도하라.

### 전제 조건
- 고유값 방정식: Av = λv (v ≠ 0)
- 특성 방정식: det(A - λI) = 0
- 대칭행렬의 성질: A = Aᵀ
- 직교행렬: UᵀU = I

### Step-by-step 유도

**Step 1: 특성 방정식으로 고유값을 구한다**

A ∈ Rⁿˣⁿ가 대칭행렬이라 하자. 고유값 λ를 구하기 위해:
```
det(A - λI) = 0
```
이것이 n차 다항식이므로 (대수학의 기본정리에 의해) n개의 해를 가진다.

대칭행렬의 고유값은 항상 실수이다 (증명: 켤레를 이용한 표준 증명).

**Step 2: 각 고유값에 대한 고유벡터를 구한다**

고유값 λᵢ에 대해:
```
(A - λᵢI)vᵢ = 0
```
를 풀면 고유벡터 vᵢ를 얻는다 (단위 벡터로 정규화: ‖vᵢ‖ = 1).

**Step 3: 대칭행렬의 고유벡터는 서로 직교함을 보인다**

★ 핵심 성질 증명: λᵢ ≠ λⱼ 이면 vᵢ ⊥ vⱼ

```
Avᵢ = λᵢvᵢ  →  vⱼᵀAvᵢ = λᵢ(vⱼᵀvᵢ)
Avⱼ = λⱼvⱼ  →  vᵢᵀAvⱼ = λⱼ(vᵢᵀvⱼ)

A가 대칭이므로: vⱼᵀAvᵢ = (Avⱼ)ᵀvᵢ = (λⱼvⱼ)ᵀvᵢ = λⱼ(vⱼᵀvᵢ)
```
따라서:
```
λᵢ(vⱼᵀvᵢ) = λⱼ(vⱼᵀvᵢ)
(λᵢ - λⱼ)(vⱼᵀvᵢ) = 0
```
λᵢ ≠ λⱼ 이면 vⱼᵀvᵢ = 0, 즉 vᵢ ⊥ vⱼ.

**Step 4: 직교행렬 U를 구성한다**

정규직교 고유벡터 {v₁, ..., vₙ}을 열로 나열:
```
U = [v₁ | v₂ | ... | vₙ] ∈ Rⁿˣⁿ
```
직교성에 의해: UᵀU = I (직교행렬의 정의).

고유값 대각행렬:
```
Λ = diag(λ₁, λ₂, ..., λₙ)
```

**Step 5: A = UΛUᵀ를 검증한다**

AU = [Av₁ | Av₂ | ... | Avₙ] = [λ₁v₁ | λ₂v₂ | ... | λₙvₙ] = UΛ

따라서:
```
AU = UΛ
A = UΛU⁻¹ = UΛUᵀ   ← U가 직교행렬이므로 U⁻¹ = Uᵀ
```

$$\boxed{A = U\Lambda U^\top = \sum_{i=1}^{n} \lambda_i \mathbf{u}_i \mathbf{u}_i^\top}$$

외적 분해 형태 (spectral decomposition):
```
A = λ₁u₁u₁ᵀ + λ₂u₂u₂ᵀ + ... + λₙuₙuₙᵀ
```
각 항 uᵢuᵢᵀ는 uᵢ 방향으로의 투영 행렬이다.

### 핵심 논리 전환점 (★)
- A가 대칭이면 AU = UΛ가 성립한다 — 이로부터 A = UΛUᵀ가 따라온다.
- 각 항 λᵢuᵢuᵢᵀ는 "λᵢ만큼 늘린 uᵢ 방향 투영"으로 해석된다.

### 연결
- → 1.4 SVD: 일반 행렬로 확장 (정사각 대칭 → 직사각)
- → 1.5 PSD: 모든 λᵢ ≥ 0 ↔ A가 PSD
- → 2.5 볼록함수: 헤시안 H가 PSD ↔ f가 볼록

### 채점 포인트 체크리스트
- [ ] 특성 방정식 det(A-λI)=0 에서 출발했는가
- [ ] 대칭행렬의 고유벡터 직교성을 증명했는가
- [ ] AU = UΛ 관계를 보였는가
- [ ] U가 직교행렬이므로 U⁻¹ = Uᵀ임을 사용했는가

## 1.4 SVD 유도 (AᵀA에서 출발)

### 문제 (Problem)
**Derive the Singular Value Decomposition A = UΣVᵀ starting from the eigendecomposition of AᵀA.**

AᵀA의 고유분해에서 출발해 A = UΣVᵀ를 유도하라.

### 전제 조건
- 1.3의 스펙트럴 분해
- AᵀA는 PSD임 (1.5에서 증명)
- 직교행렬의 성질

### Step-by-step 유도

**Step 1: AᵀA의 고유분해를 구한다**

A ∈ Rᵐˣⁿ에 대해 AᵀA ∈ Rⁿˣⁿ는 대칭 PSD 행렬이다.
1.3에 의해:
```
AᵀA = VΛVᵀ
```
여기서 V = [v₁|...|vₙ]은 직교행렬, Λ = diag(λ₁,...,λₙ), λᵢ ≥ 0.

★ 핵심: λᵢ = σᵢ² (특이값의 제곱)으로 정의한다.

**Step 2: σᵢ > 0인 경우의 uᵢ를 구성한다**

r = rank(A)개의 양수 고유값 λ₁ ≥ λ₂ ≥ ... ≥ λᵣ > 0 에 대해:
```
Avᵢ = ?
```
‖Avᵢ‖²를 계산하면:
```
‖Avᵢ‖² = (Avᵢ)ᵀ(Avᵢ) = vᵢᵀ(AᵀA)vᵢ = vᵢᵀ(λᵢvᵢ) = λᵢ‖vᵢ‖² = λᵢ = σᵢ²
```
따라서 ‖Avᵢ‖ = σᵢ.

이제 uᵢ를 정규화된 Avᵢ로 정의:
$$\boxed{u_i = \frac{Av_i}{\sigma_i}}$$

이것이 Rᵐ에서의 단위 벡터이다.

**Step 3: {u₁,...,uᵣ}이 직교함을 보인다**

i ≠ j에 대해:
```
uᵢᵀuⱼ = (Avᵢ/σᵢ)ᵀ(Avⱼ/σⱼ) = (1/σᵢσⱼ)vᵢᵀ(AᵀA)vⱼ
       = (1/σᵢσⱼ)vᵢᵀ(λⱼvⱼ) = (λⱼ/σᵢσⱼ)vᵢᵀvⱼ = 0
```
V가 직교행렬이므로 vᵢᵀvⱼ = 0. 따라서 {u₁,...,uᵣ}는 정규직교 벡터집합이다.

**Step 4: {u₁,...,uᵣ}을 Rᵐ 전체 기저로 확장한다**

r < m이면 {u₁,...,uᵣ}을 Rᵐ의 기저로 확장:
```
U = [u₁|u₂|...|uᵣ|uᵣ₊₁|...|uₘ] ∈ Rᵐˣᵐ  (직교행렬)
```
나머지 열은 R(A)의 직교보완에서 임의로 선택.

**Step 5: A = UΣVᵀ를 검증한다**

uᵢ = Avᵢ/σᵢ 이므로 Avᵢ = σᵢuᵢ (i ≤ r).
Avᵢ = 0 (i > r, vᵢ ∈ N(A)이므로).

AV = [Av₁|...|Avₙ] = [σ₁u₁|...|σᵣuᵣ|0|...|0] = UΣ

따라서:
```
AV = UΣ
A = UΣV⁻¹ = UΣVᵀ   ← V가 직교행렬
```

$$\boxed{A = U\Sigma V^\top = \sum_{i=1}^{r} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top}$$

여기서 Σ ∈ Rᵐˣⁿ는 대각원소가 σ₁ ≥ σ₂ ≥ ... ≥ σᵣ > 0인 직사각 대각행렬.

### 핵심 논리 전환점 (★)
- uᵢ = Avᵢ/σᵢ 정의가 전체 유도의 핵심이다. V의 직교성을 이용해 U의 직교성이 자동으로 따라온다.
- AᵀA (PSD) → 고유분해 → V 구성 → U 구성 → A = UΣVᵀ의 논리 흐름을 외워라.

### 연결
- ← 1.3 스펙트럴 분해: AᵀA에 적용
- → 저랭크 근사: A_r = Σᵢ₌₁ʳ σᵢuᵢvᵢᵀ (Eckart-Young 정리)
- → 주성분분석(PCA): 공분산행렬의 SVD

### 채점 포인트 체크리스트
- [ ] AᵀA의 고유분해에서 σᵢ² = λᵢ를 정의했는가
- [ ] uᵢ = Avᵢ/σᵢ로 정의했는가
- [ ] U의 직교성을 vᵢᵀvⱼ=0을 이용해 보였는가
- [ ] AV = UΣ에서 A = UΣVᵀ를 유도했는가

## 1.5 PSD/PD 판정과 이차형식

### 문제 (Problem)
**Prove: A is PSD ⟺ all eigenvalues of A are ≥ 0. Also prove that BᵀB is always PSD.**

A가 PSD ⟺ 모든 고유값 ≥ 0 임을 증명하라. 또한 BᵀB가 항상 PSD임을 증명하라.

### 전제 조건
- PSD 정의: vᵀAv ≥ 0, ∀v ≠ 0
- 1.3의 스펙트럴 분해: A = UΛUᵀ

### Step-by-step 유도

**Part A: A가 PSD ⟺ 모든 고유값 ≥ 0**

**(⟹ 방향)**: A가 PSD이면 고유값 ≥ 0

고유값 λᵢ에 대응하는 고유벡터 vᵢ에 대해:
```
vᵢᵀAvᵢ = vᵢᵀ(λᵢvᵢ) = λᵢ‖vᵢ‖²
```
A가 PSD이면 vᵢᵀAvᵢ ≥ 0이고 ‖vᵢ‖² > 0이므로 λᵢ ≥ 0.

**(⟸ 방향)**: 모든 고유값 ≥ 0이면 A가 PSD

A = UΛUᵀ (스펙트럴 분해)로 쓰면, 임의의 v에 대해:
```
vᵀAv = vᵀ(UΛUᵀ)v = (Uᵀv)ᵀΛ(Uᵀv)
```
y = Uᵀv로 치환하면:
```
vᵀAv = yᵀΛy = Σᵢ λᵢyᵢ² ≥ 0   ← λᵢ ≥ 0이므로
```

$$\boxed{A \text{ is PSD} \Longleftrightarrow \text{all eigenvalues of } A \geq 0}$$

**Part B: BᵀB는 항상 PSD이다**

임의의 v ≠ 0에 대해:
```
vᵀ(BᵀB)v = (Bv)ᵀ(Bv) = ‖Bv‖² ≥ 0
```
제곱 노름은 항상 0 이상이므로 BᵀB ⊵ 0.

★ 의미: A = BᵀB 형태의 행렬은 반드시 PSD이다. 공분산행렬, Gram 행렬이 이 형태이다.

### 이차형식과의 연결

이차형식 f(x) = xᵀAx에서:
- A가 PD이면: f(x) > 0, ∀x ≠ 0 → 유일한 최솟값 (x=0)
- A가 PSD이면: f(x) ≥ 0 → 최솟값 존재하나 유일하지 않을 수 있음
- 고유값 관점: f(x) = Σᵢ λᵢ(uᵢᵀx)² (스펙트럴 분해 후 변수 치환)

### 채점 포인트 체크리스트
- [ ] PSD 정의에 고유벡터를 직접 대입했는가 (⟹ 방향)
- [ ] 스펙트럴 분해와 변수 치환 y=Uᵀv를 사용했는가 (⟸ 방향)
- [ ] BᵀB에서 ‖Bv‖² ≥ 0을 사용했는가

# Part 2: 미적분/최적화 유도 체인 (W3)

## 2.1 다변수 Taylor 전개

### 문제 (Problem)
**Derive the first and second order Taylor expansions of f(x+δ) around x.**

f(x+δ)의 x 주변 1차 및 2차 Taylor 전개를 유도하라.

### 전제 조건
- 1차원 Taylor 전개: f(x+δ) = f(x) + f'(x)δ + (1/2)f''(x)δ² + O(δ³)
- 그래디언트: ∇f = [∂f/∂x₁, ..., ∂f/∂xₙ]ᵀ
- 헤시안: Hᵢⱼ = ∂²f/∂xᵢ∂xⱼ

### Step-by-step 유도

**Step 1: 1차원에서 다차원으로 확장하는 원리**

스칼라 t에 대해 g(t) = f(x + tδ)로 정의하면:
```
g(0) = f(x),  g(1) = f(x+δ)
```
g(t)를 t=0 주변에서 Taylor 전개:
```
g(t) = g(0) + g'(0)t + (1/2)g''(0)t² + O(t³)
```

**Step 2: g'(0)을 계산한다 → 1차 항**

연쇄 법칙으로:
```
g'(t) = Σᵢ (∂f/∂xᵢ)(x + tδ) · δᵢ = ∇f(x + tδ)ᵀ δ
g'(0) = ∇f(x)ᵀ δ
```

**Step 3: g''(0)을 계산한다 → 2차 항**

```
g''(t) = Σᵢ Σⱼ (∂²f/∂xᵢ∂xⱼ)(x + tδ) · δᵢδⱼ = δᵀH(x + tδ)δ
g''(0) = δᵀH(x)δ
```

**Step 4: 결합**

$$\boxed{f(\mathbf{x} + \boldsymbol{\delta}) \approx f(\mathbf{x}) + \nabla f(\mathbf{x})^\top \boldsymbol{\delta} + \frac{1}{2}\boldsymbol{\delta}^\top H(\mathbf{x}) \boldsymbol{\delta}}$$

- 1차 근사: f(x+δ) ≈ f(x) + ∇f(x)ᵀδ
- 2차 근사: + (1/2)δᵀH(x)δ 추가

### 핵심 직관
- ∇f(x)ᵀδ: "δ 방향으로의 방향 미분" — 1차 선형 근사
- (1/2)δᵀHδ: "곡률" — 2차 보정항

### 연결
- → 2.2 Gradient Descent: 1차 근사를 최소화
- → 2.3 Newton's Method: 2차 근사를 최소화
- → 2.5 볼록함수: H ≥ 0 (PSD) ↔ 볼록함수

### 채점 포인트 체크리스트
- [ ] g(t) = f(x+tδ) 정의로 1차원 문제로 환원했는가
- [ ] 연쇄 법칙으로 g'(0) = ∇f(x)ᵀδ를 구했는가
- [ ] g''(0) = δᵀHδ를 구했는가

## 2.2 Gradient Descent 유도 (Taylor 1차에서)

### 문제 (Problem)
**Derive the gradient descent update rule from the first-order Taylor approximation.**

1차 Taylor 근사로부터 경사 하강법의 업데이트 규칙을 유도하라.

### 전제 조건
- 2.1의 1차 Taylor 근사
- 코시-슈바르츠 부등식: |aᵀb| ≤ ‖a‖‖b‖

### Step-by-step 유도

**Step 1: 1차 근사를 최소화할 방향을 찾는다**

현재 점 θₜ에서 스텝 크기 η > 0로 이동한다:
```
θ = θₜ + ηd    (d: 이동 방향, ‖d‖ = 1로 제한)
```

1차 Taylor 근사:
```
f(θₜ + ηd) ≈ f(θₜ) + η∇f(θₜ)ᵀd
```

f를 최소화하려면 ∇f(θₜ)ᵀd를 최소화해야 한다.

**Step 2: 최소화 방향을 구한다**

코시-슈바르츠 부등식:
```
∇f(θₜ)ᵀd ≥ -‖∇f(θₜ)‖ · ‖d‖ = -‖∇f(θₜ)‖
```
등호 조건: d가 ∇f(θₜ)와 반대 방향일 때:
```
d* = -∇f(θₜ) / ‖∇f(θₜ)‖
```

★ 핵심: "가장 빠르게 감소하는 방향 = 그래디언트의 반대 방향"

**Step 3: 업데이트 규칙**

$$\boxed{\theta_{t+1} = \theta_t - \eta \nabla f(\theta_t)}$$

여기서 η는 학습률(learning rate)이다.

**Step 4: 변형들**

- **SGD (Stochastic GD)**: ∇f 대신 미니배치 그래디언트 ∇Lᴮ 사용
  - 기댓값: E[∇Lᴮ] = ∇f (불편 추정량)
  - 분산으로 인한 노이즈가 local minimum 탈출을 도울 수 있음
- **Momentum**: 이전 방향을 관성처럼 반영
  ```
  mₜ = β·mₜ₋₁ + ∇f(θₜ)
  θₜ₊₁ = θₜ - η·mₜ
  ```

### 왜 η를 작게 해야 하는가?
1차 근사 f(x+δ) ≈ f(x) + ∇fᵀδ는 δ가 작을 때만 유효하다.
η가 너무 크면 근사 오차가 커져 오히려 f가 증가할 수 있다.

### 연결
- ← 2.1 Taylor 1차 근사
- → 2.3 Newton's Method: 2차 근사 사용
- → Part 5 Adam: Momentum + 적응적 학습률

### 채점 포인트 체크리스트
- [ ] Taylor 1차 근사에서 출발했는가
- [ ] 최대 감소 방향이 -∇f임을 보였는가 (코시-슈바르츠 또는 내적의 기하학)
- [ ] 업데이트 규칙 θ = θ - η∇f를 명확히 적었는가

## 2.3 Newton's Method 유도 (Taylor 2차에서)

### 문제 (Problem)
**Derive Newton's method update rule from the second-order Taylor approximation.**

2차 Taylor 근사로부터 뉴턴법의 업데이트 규칙을 유도하라.

### 전제 조건
- 2.1의 2차 Taylor 근사
- 헤시안 H가 PD (가역성 보장)

### Step-by-step 유도

**Step 1: 2차 근사 함수를 설정한다**

현재 점 θₜ 근방에서 f를 2차 근사:
```
f(θₜ + δ) ≈ q(δ) := f(θₜ) + ∇f(θₜ)ᵀδ + (1/2)δᵀH(θₜ)δ
```

**Step 2: 근사 함수를 최소화한다**

q(δ)를 δ에 대해 미분하고 0으로 놓는다:
```
∂q/∂δ = ∇f(θₜ) + H(θₜ)δ = 0
H(θₜ)δ = -∇f(θₜ)
δ* = -H(θₜ)⁻¹∇f(θₜ)
```

★ H가 PD이면 H가 가역이고, 이 δ*가 q의 유일한 최솟값이다.

**Step 3: 업데이트 규칙**

$$\boxed{\theta_{t+1} = \theta_t - H(\theta_t)^{-1} \nabla f(\theta_t)}$$

**Step 4: GD와 비교**

| 방법 | 업데이트 | 방향 | 스텝 크기 |
|------|---------|------|---------|
| GD | θ - η∇f | -∇f (1차) | 수동 설정 η |
| Newton | θ - H⁻¹∇f | 곡률 보정된 방향 | 자동 (H⁻¹이 조정) |

뉴턴법은 이차함수에서 **한 번에** 최솟값에 도달한다.

**Step 5: 실용적 문제점**

H⁻¹ 계산 비용 = O(n³) → 파라미터가 수십억 개인 신경망에는 비실용적.
→ 대안: L-BFGS (H⁻¹을 근사), Adam (대각 근사)

### 연결
- ← 2.1 Taylor 2차 근사
- ← 1.5 PD 행렬: H가 PD이어야 함
- → Part 5 Adam: H의 대각 근사 (2차 모멘트)

### 채점 포인트 체크리스트
- [ ] 2차 Taylor 근사 q(δ)를 명시했는가
- [ ] ∂q/∂δ = 0으로 δ*를 구했는가
- [ ] H⁻¹이 필요하므로 H가 PD 이어야 함을 언급했는가

## 2.4 Sigmoid 미분 유도

### 문제 (Problem)
**Derive σ'(z) = σ(z)(1 - σ(z)) for σ(z) = 1/(1 + e^{-z}).**

σ(z) = 1/(1+e⁻ᶻ) 의 미분이 σ(z)(1-σ(z))임을 유도하라.

### Step-by-step 유도

**Step 1: 몫의 미분을 적용한다**

```
σ(z) = 1 / (1 + e^{-z})
```
u = 1, v = 1 + e^{-z}로 놓으면 σ = u/v:
```
σ'(z) = (u'v - uv') / v²
u' = 0
v' = -e^{-z}
σ'(z) = (0 · v - 1 · (-e^{-z})) / v² = e^{-z} / (1 + e^{-z})²
```

**Step 2: 분수를 σ로 표현한다**

★ 핵심 트릭: 분자와 분모를 나눠 σ 형태로 만든다.

```
σ'(z) = e^{-z} / (1 + e^{-z})²
       = [1/(1+e^{-z})] · [e^{-z}/(1+e^{-z})]
       = σ(z) · [e^{-z}/(1+e^{-z})]
```

e^{-z}/(1+e^{-z}) = 1 - 1/(1+e^{-z}) = 1 - σ(z):
```
σ'(z) = σ(z) · (1 - σ(z))
```

$$\boxed{\sigma'(z) = \sigma(z)(1 - \sigma(z))}$$

**직관적 해석**:
- σ(z) → 1 이면 σ'(z) → 0 (포화)
- σ(z) → 0 이면 σ'(z) → 0 (포화)
- σ(z) = 0.5 이면 σ'(z) = 0.25 (최대)

**Vanishing Gradient 문제와의 연결**:
출력이 0 또는 1에 가까울 때 σ' ≈ 0 → 역전파 시 그래디언트 소실 발생!

### 채점 포인트 체크리스트
- [ ] 몫의 미분을 적용했는가
- [ ] e^{-z}/(1+e^{-z}) = 1-σ(z) 변환을 보였는가
- [ ] 최종 형태 σ(z)(1-σ(z))를 명확히 적었는가

## 2.5 볼록함수의 동치 조건

### 문제 (Problem)
**State and explain the three equivalent conditions for a function to be convex.**

볼록함수의 세 가지 동치 조건을 서술하라.

### Step-by-step 유도

**조건 1 (정의): 직선 아래에 함수가 위치**

f: Rⁿ → R이 볼록이라는 것은 임의의 x, y와 t ∈ [0,1]에 대해:
```
f(tx + (1-t)y) ≤ tf(x) + (1-t)f(y)
```
즉, 곡선 위의 두 점을 잇는 직선이 곡선보다 위에 있다.

**조건 2 (1차 조건): 접선 위에 함수가 위치**

f가 미분가능하면:
```
f(y) ≥ f(x) + ∇f(x)ᵀ(y - x),  ∀x, y
```
즉, 접선(1차 근사)이 항상 아래에 있다.

★ 학습에서의 의미: GD가 수렴하는 이유. f의 접선이 항상 lower bound이므로 접선 최솟값 방향으로 이동하면 반드시 f가 감소.

**조건 3 (2차 조건): 헤시안이 PSD**

f가 두 번 미분가능하면:
```
H(x) ≥ 0 (PSD),  ∀x
```
즉, 모든 점에서 헤시안의 고유값이 0 이상이다.

**세 조건의 동치성 증명 요약**:
- 조건1 ↔ 조건2: Jensen 부등식과의 연결
- 조건2 ↔ 조건3: Taylor 2차 전개에서 δᵀHδ ≥ 0 ↔ H PSD

$$\boxed{\text{볼록} \Longleftrightarrow f(y) \geq f(x) + \nabla f(x)^\top(y-x) \Longleftrightarrow H(x) \succeq 0}$$

### 연결
- ← 2.1 Taylor 2차 전개
- ← 1.5 PSD 판정
- → 2.6 Jensen 부등식
- → GD 수렴 보장: f가 볼록이면 GD가 전역 최솟값으로 수렴

## 2.6 Jensen 부등식과 KL ≥ 0 증명

### 문제 (Problem)
**Use Jensen's inequality and the convexity of -log to prove KL(p||q) ≥ 0.**

Jensen 부등식과 -log의 볼록성을 이용해 KL(p‖q) ≥ 0을 증명하라.

### Step-by-step 유도

**Step 1: Jensen 부등식 (볼록함수에 대해)**

f가 볼록이면:
```
f(E[X]) ≤ E[f(X)]
```
즉, 기대값을 먼저 취한 후 볼록함수를 적용한 것이 직접 볼록함수를 적용한 것의 기대값보다 작거나 같다.

**Step 2: -log는 볼록함수임을 보인다**

g(x) = -log(x)의 2차 도함수:
```
g'(x) = -1/x
g''(x) = 1/x² > 0  (x > 0이면)
```
g''(x) > 0이므로 g(x) = -log(x)는 순볼록 함수이다.

**Step 3: KL ≥ 0 증명 (Gibbs' Inequality)**

$$KL(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = -\sum_x p(x) \log \frac{q(x)}{p(x)} = E_p\left[-\log\frac{q(X)}{p(X)}\right]$$

-log가 볼록이므로 Jensen 부등식 적용:

★ 핵심 적용: E_p[f(Y)] ≥ f(E_p[Y]) (볼록 f에 대해)

여기서 Y = q(X)/p(X), f = -log:

$$KL(p \| q) = E_p\left[-\log\frac{q(X)}{p(X)}\right] \geq -\log E_p\left[\frac{q(X)}{p(X)}\right]$$

$$E_p\left[\frac{q(X)}{p(X)}\right] = \sum_x p(x) \cdot \frac{q(x)}{p(x)} = \sum_x q(x) = 1$$

따라서:
$$KL(p \| q) \geq -\log(1) = 0$$

$$\boxed{KL(p \| q) \geq 0, \text{ 등호는 } p = q \text{ 일 때만 성립}}$$

### 연결
- ← 2.5 볼록함수
- → 3.4 정보이론: CE = H(p) + KL(p‖q)
- → 3.5/3.6 MLE = CE/MSE 최소화

# Part 3: 확률/베이지안 유도 체인 (W4-W5)

## 3.1 베르누이 MLE 완전 유도

### 문제 (Problem)
**Derive the MLE for the Bernoulli distribution parameter θ given n observations with k successes.**

n번 관측 중 k번 성공했을 때 베르누이 분포 파라미터 θ의 MLE를 유도하라.

### 전제 조건
- 베르누이 분포: p(x=1|θ) = θ, p(x=0|θ) = 1-θ
- i.i.d. 가정
- 로그의 단조증가 성질 (argmax 보존)

### Step-by-step 유도

**Step 1: 우도 함수를 구성한다**

n번 관측 xᵢ ∈ {0,1}, i=1,...,n에 대해 k = Σxᵢ번 성공했다고 하자.
i.i.d. 가정으로 우도:
```
P(D|θ) = Π p(xᵢ|θ) = θᵏ(1-θ)ⁿ⁻ᵏ
```

**Step 2: 로그 우도를 취한다**

로그는 단조증가이므로 argmax를 보존:
```
ℓ(θ) = log P(D|θ) = k log θ + (n-k) log(1-θ)
```

**Step 3: 미분하고 0으로 놓는다**

```
dℓ/dθ = k/θ - (n-k)/(1-θ) = 0
k(1-θ) = (n-k)θ
k - kθ = nθ - kθ
k = nθ
```

$$\boxed{\theta_{ML} = \frac{k}{n}}$$

**Step 4: 2차 도함수로 최댓값 확인**

```
d²ℓ/dθ² = -k/θ² - (n-k)/(1-θ)² < 0
```
2차 도함수가 음수이므로 최댓값임을 확인.

★ 직관: MLE는 관측된 비율 그 자체이다. n번 중 k번 성공했으면 θ_ML = k/n.

### 연결
- → 3.3 MAP: Prior가 있으면 θ_MAP ≠ θ_ML
- → 3.2 가우시안 MLE: 연속분포로 확장

## 3.2 가우시안 MLE 완전 유도

### 문제 (Problem)
**Derive the MLE for the parameters of a Gaussian distribution: μ_ML and σ²_ML.**

가우시안 분포의 파라미터 μ_ML과 σ²_ML을 MLE로 유도하라.

### Step-by-step 유도

**Step 1: 가우시안 우도 함수**

n개의 i.i.d. 관측 {x₁,...,xₙ}, xᵢ ~ N(μ, σ²):
```
p(xᵢ|μ,σ²) = (1/√(2πσ²)) exp(-(xᵢ-μ)²/(2σ²))
```
로그 우도:
```
ℓ(μ,σ²) = -n/2 · log(2πσ²) - 1/(2σ²) · Σᵢ(xᵢ-μ)²
          = -n/2·log(2π) - n/2·log(σ²) - 1/(2σ²)·Σ(xᵢ-μ)²
```

**Step 2: μ_ML 유도**

μ에 대해 편미분:
```
∂ℓ/∂μ = 1/σ² · Σ(xᵢ-μ) = 0
Σ(xᵢ-μ) = 0
nμ = Σxᵢ
```

$$\boxed{\mu_{ML} = \frac{1}{n}\sum_{i=1}^{n} x_i}$$

**Step 3: σ²_ML 유도**

σ²에 대해 편미분 (s = σ²로 치환):
```
∂ℓ/∂s = -n/(2s) + 1/(2s²)·Σ(xᵢ-μ)² = 0
n/(2s) = 1/(2s²)·Σ(xᵢ-μ)²
ns = Σ(xᵢ-μ)²
```

$$\boxed{\sigma^2_{ML} = \frac{1}{n}\sum_{i=1}^{n}(x_i - \mu_{ML})^2}$$

**Step 4: σ²_ML은 편향 추정량임을 보인다 ★**

E[σ²_ML]을 계산:
```
E[σ²_ML] = E[1/n · Σ(xᵢ-x̄)²]
```
xᵢ - x̄ = (xᵢ-μ) - (x̄-μ)로 분해하면:
```
Σ(xᵢ-x̄)² = Σ(xᵢ-μ)² - n(x̄-μ)²
E[Σ(xᵢ-x̄)²] = n·Var(xᵢ) - n·Var(x̄) = nσ² - n·(σ²/n) = (n-1)σ²
```
따라서:
```
E[σ²_ML] = (n-1)σ²/n ≠ σ²
```

★ 불편 추정량: s² = 1/(n-1)·Σ(xᵢ-x̄)² (베셀 보정)

### 채점 포인트 체크리스트
- [ ] 로그 우도를 정확히 전개했는가
- [ ] μ_ML = (1/n)Σxᵢ를 유도했는가
- [ ] σ²_ML이 편향 추정량임을 언급했는가

## 3.3 MAP 완전 유도 (Beta Prior)

### 문제 (Problem)
**Derive the MAP estimate for a Bernoulli distribution with a Beta(α,β) prior.**

Beta(α,β) Prior를 사용한 베르누이 분포의 MAP 추정값을 유도하라.

### Step-by-step 유도

**Step 1: 베이즈 정리를 적용한다**

$$P(\theta|D) \propto P(D|\theta) \cdot P(\theta)$$

**Step 2: Beta Prior를 설정한다**

Beta(α,β) 분포:
```
p(θ|α,β) = θ^{α-1}(1-θ)^{β-1}/B(α,β)
```
B(α,β)는 정규화 상수로 θ에 대해 상수이다.

**Step 3: 로그 사후확률을 전개한다**

```
log P(θ|D) = log P(D|θ) + log P(θ) + C
           = [k log θ + (n-k) log(1-θ)]   ← 로그 우도
           + [(α-1) log θ + (β-1) log(1-θ)] + C  ← 로그 Prior
           = (k+α-1) log θ + (n-k+β-1) log(1-θ) + C
```

**Step 4: MAP 추정값을 구한다**

θ에 대해 미분하고 0으로 놓는다:
```
d/dθ [log P(θ|D)] = (k+α-1)/θ - (n-k+β-1)/(1-θ) = 0
```
정리하면:
```
(k+α-1)(1-θ) = (n-k+β-1)θ
k+α-1 = (n+α+β-2)θ
```

$$\boxed{\theta_{MAP} = \frac{k + \alpha - 1}{n + \alpha + \beta - 2}}$$

**Step 5: MLE와 비교**

| 상황 | 공식 | 의미 |
|------|------|------|
| MLE | θ_ML = k/n | 관측 비율 |
| MAP (α=β=1, 균등 Prior) | θ_MAP = k/n | MAP = MLE |
| MAP (Alpha, Beta > 1) | θ_MAP ≠ k/n | Prior가 MLE를 당김 |

- n이 클수록 MAP → MLE (데이터가 Prior를 압도)
- n이 작을수록 Prior의 영향이 커짐

★ 극단적 예: n=3, k=3이면 θ_ML=1 (과적합!) vs Beta(2,2) Prior 시 θ_MAP=4/6=2/3

### 채점 포인트 체크리스트
- [ ] 베이즈 정리 P(θ|D) ∝ P(D|θ)P(θ)에서 출발했는가
- [ ] 로그 우도와 로그 Prior를 합쳤는가
- [ ] 미분→0으로 θ_MAP를 구했는가
- [ ] α=β=1일 때 MAP=MLE를 확인했는가

## 3.4 정보이론 유도 체인

### 문제 (Problem)
**Derive the chain: H(p) → H(p,q) → KL(p||q) = H(p,q) - H(p) ≥ 0.**

엔트로피에서 KL Divergence까지의 논리 체인을 유도하라.

### Step-by-step 유도

**Step 1: 엔트로피 (Shannon Entropy)**

확률분포 p에 대해:
$$H(p) = -\sum_x p(x) \log p(x) = -E_p[\log p(X)]$$

정보 이론적 해석: "p로부터 하나의 샘플을 인코딩하는 데 필요한 최소 평균 비트 수"

**Step 2: 크로스 엔트로피 (Cross-Entropy)**

참 분포 p, 모델 분포 q에 대해:
$$CE(p,q) = -\sum_x p(x) \log q(x) = -E_p[\log q(X)]$$

해석: "참 분포 p에서 샘플링한 데이터를 모델 q로 인코딩할 때의 평균 비트 수"
- p=q이면 CE(p,q) = H(p) (최솟값)
- p≠q이면 CE(p,q) > H(p)

**Step 3: KL Divergence**

$$KL(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = E_p\left[\log\frac{p(X)}{q(X)}\right]$$

**Step 4: KL = CE - H 유도**

$$KL(p \| q) = \sum_x p(x) \log p(x) - \sum_x p(x) \log q(x)$$
$$= -H(p) + CE(p,q)$$
$$\boxed{KL(p \| q) = CE(p,q) - H(p)}$$

**Step 5: KL ≥ 0 (Gibbs' Inequality)**

2.6에서 증명했으므로: KL(p‖q) ≥ 0.
따라서: CE(p,q) ≥ H(p), 등호는 p=q일 때만.

**Forward KL vs Reverse KL 비교**:

| | KL(p‖q) (Forward) | KL(q‖p) (Reverse) |
|--|--|--|
| 최소화 방향 | q가 p를 따름 | p의 일부를 q가 커버 |
| 특성 | Mean-seeking (mean 방향) | Mode-seeking (하나의 mode만 커버) |
| 사용처 | MLE, CE loss | VAE의 ELBO |

**학습에서의 의미**:
```
min_θ KL(p_E ‖ p_θ) = min_θ CE(p_E, p_θ)    ← H(p_E)는 θ에 무관한 상수
```

### 채점 포인트 체크리스트
- [ ] H(p), CE(p,q), KL(p‖q)를 각각 정의했는가
- [ ] KL = CE - H를 대수적으로 유도했는가
- [ ] KL ≥ 0의 근거를 제시했는가

---

## 3.5 CE Loss = MLE with Categorical

### 문제 (Problem)
**Show that the cross-entropy loss is equivalent to MLE under a categorical distribution assumption.**

범주형 분포 가정 하에서 CE 손실 = MLE임을 보여라. (자세한 유도는 Part 1에 있으므로 여기선 핵심 논리만)

### 논리 체인 요약

```
[가정] y | x ~ Categorical, p(y|x,h) = h(x)_y

↓ [우도]
P(D|H) = Π h(xᵢ)_{yᵢ}

↓ [로그 우도]
log P(D|H) = Σ log h(xᵢ)_{yᵢ}

↓ [최대화 → 최소화]
argmax = argmin of -Σ log h(xᵢ)_{yᵢ}

↓ [one-hot 표현]
= argmin Σ -e_{yᵢ}ᵀ log h(xᵢ)

↓ [정규화]
L_CE = -1/n · Σ e_{yᵢ}ᵀ log h(xᵢ)
```

$$\boxed{L_{CE} = -\frac{1}{n}\sum_{i=1}^{n} \log h(x_i)_{y_i}}$$

## 3.6 MSE Loss = MLE with Gaussian

### 문제 (Problem)
**Show that the MSE loss is equivalent to MLE under a Gaussian distribution assumption.**

### 논리 체인 요약

```
[가정] y | x ~ N(h(x), σ²)

↓ [로그 우도]

↓ [h에 대해 최대화]
σ² 고정 → 첫 항은 상수

argmax_h = argmin_h Σ(yᵢ-h(xᵢ))²

L_MSE = 1/n·Σ(yᵢ-h(xᵢ))²
```

## 3.7 L2 정규화 = Gaussian Prior MAP

### 문제 (Problem)
**Prove that L2 regularization corresponds to MAP estimation with a Gaussian prior.**

L2 정규화가 Gaussian Prior를 사용한 MAP와 동치임을 증명하라.

### Step-by-step 유도

**Step 1: MAP 목적함수**

$$\theta_{MAP} = \arg\max_\theta [\log P(D|\theta) + \log P(\theta)]$$

**Step 2: Gaussian Prior 설정**

$$P(\theta) = \mathcal{N}(\theta; 0, \tau^2 I) = \frac{1}{(2\pi\tau^2)^{d/2}} \exp\left(-\frac{\|\theta\|^2}{2\tau^2}\right)$$

로그를 취하면:
```
log P(θ) = -d/2·log(2πτ²) - 1/(2τ²)·‖θ‖²
```
상수 항을 제외하면:
```
log P(θ) ∝ -‖θ‖²/(2τ²)
```

**Step 3: MAP에 대입**

```
θ_MAP = argmax_θ [log P(D|θ) + log P(θ)]
      = argmax_θ [log P(D|θ) - ‖θ‖²/(2τ²)]
      = argmin_θ [-log P(D|θ) + ‖θ‖²/(2τ²)]
      = argmin_θ [L(θ) + λ‖θ‖²]
```

$$\boxed{\lambda = \frac{1}{2\tau^2}}$$

$$\boxed{\text{Gaussian Prior MAP} \equiv \text{MLE} + \text{L2 정규화 (Weight Decay)}}$$

**해석**:
- τ²가 작을수록 (Prior가 강할수록) → λ가 클수록 → θ를 0으로 강하게 당김
- Prior를 강하게 → 파라미터 크기 제한 → 모델 복잡도 감소 → 일반화 개선

### 채점 포인트 체크리스트
- [ ] Gaussian Prior의 log를 전개했는가
- [ ] λ = 1/(2τ²) 관계를 보였는가
- [ ] 최대화→최소화 변환(음수 부호)을 명시했는가

---

## 3.8 L1 정규화 = Laplace Prior MAP (★신규)

### 문제 (Problem)
**Prove that L1 regularization corresponds to MAP estimation with a Laplace prior.**

L1 정규화가 Laplace Prior를 사용한 MAP와 동치임을 증명하라.

### Step-by-step 유도

**Step 1: Laplace 분포 Prior**

$$P(\theta_j) = \text{Laplace}(\theta_j; 0, b) = \frac{1}{2b} \exp\left(-\frac{|\theta_j|}{b}\right)$$

독립 파라미터에 대해:
```
P(θ) = Π_j P(θⱼ) = (1/2b)^d · exp(-Σⱼ|θⱼ|/b)
log P(θ) = -d·log(2b) - (1/b)·Σⱼ|θⱼ|
         ∝ -(1/b)·‖θ‖₁
```

**Step 2: MAP에 대입**

```
θ_MAP = argmin_θ [L(θ) + (1/b)·‖θ‖₁]
      = argmin_θ [L(θ) + λ‖θ‖₁]
```

$$\boxed{\lambda = \frac{1}{b}}$$

$$\boxed{\text{Laplace Prior MAP} \equiv \text{MLE} + \text{L1 정규화 (LASSO)}}$$

**L1 vs L2 비교**:

| | L2 (Ridge) | L1 (LASSO) |
|--|--|--|
| Prior | Gaussian | Laplace |
| 효과 | 파라미터를 0에 가깝게 | 파라미터를 정확히 0으로 (희소성) |
| 기하학 | 구 형태 제약 | 다이아몬드 형태 제약 |

★ L1이 희소 해를 만드는 이유: 다이아몬드의 꼭짓점(축 위)에서 접함 → 일부 파라미터가 정확히 0

### 채점 포인트 체크리스트
- [ ] Laplace Prior P(θ) ∝ exp(-|θ|/b)를 명시했는가
- [ ] log P(θ) ∝ -‖θ‖₁/b를 유도했는가
- [ ] λ = 1/b 관계를 보였는가

## 4.1 Softmax 미분 완전 유도

### 문제 (Problem)
**Derive the Jacobian of the softmax function: ∂softmax(z)_i / ∂z_j for all i, j.**

Softmax 함수의 Jacobian ∂softmax(z)_i/∂z_j 를 모든 i,j에 대해 유도하라.

### 전제 조건
- Softmax: softmax(z)_i = exp(zᵢ) / Σₖ exp(zₖ)
- 몫의 미분법: (u/v)' = (u'v - uv')/v²

### Step-by-step 유도

**Step 1: 표기 설정**

pᵢ = softmax(z)_i = exp(zᵢ)/S, 여기서 S = Σₖ exp(zₖ).

**Step 2: i = j인 경우 (같은 인덱스)**

몫의 미분:
```
∂pᵢ/∂zᵢ = ∂/∂zᵢ [exp(zᵢ)/S]
         = [exp(zᵢ)·S - exp(zᵢ)·exp(zᵢ)] / S²
         = exp(zᵢ)/S - [exp(zᵢ)/S]²
         = pᵢ - pᵢ²
         = pᵢ(1 - pᵢ)
```

**Step 3: i ≠ j인 경우 (다른 인덱스)**

분자 exp(zᵢ)는 zⱼ (i≠j)에 대해 상수:
```
∂pᵢ/∂zⱼ = ∂/∂zⱼ [exp(zᵢ)/S]
          = [0·S - exp(zᵢ)·exp(zⱼ)] / S²
          = -[exp(zᵢ)/S]·[exp(zⱼ)/S]
          = -pᵢpⱼ
```

**Step 4: Kronecker delta로 통합**

$$\boxed{\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)}$$

여기서 δᵢⱼ는 Kronecker delta:
```
δᵢⱼ = 1 (i=j), 0 (i≠j)
```

**Step 5: Jacobian 행렬로 표현**

$$\frac{\partial \mathbf{p}}{\partial \mathbf{z}} = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top \in \mathbb{R}^{C \times C}$$

이것이 Softmax의 Jacobian 행렬이다.

### 핵심 논리 전환점 (★)
- i=j와 i≠j를 분리해 계산한 후 Kronecker delta로 통합하는 것이 핵심이다.
- 최종 형태 p_i(δᵢⱼ - pⱼ)를 외워야 CE 그래디언트 유도에서 쓸 수 있다.

### 채점 포인트 체크리스트
- [ ] i=j와 i≠j 케이스를 분리했는가
- [ ] 몫의 미분을 정확히 적용했는가
- [ ] Kronecker delta로 통합 표현을 제시했는가

---

## 4.2 CE + Softmax 결합 그래디언트

### 문제 (Problem)
**Derive ∂L/∂z = p - e_y for the cross-entropy loss with softmax output.**

Softmax 출력에 대한 CE 손실의 그래디언트 ∂L/∂z = p - e_y를 유도하라.

### Step-by-step 유도

**Step 1: 손실 함수 정의**

C 클래스 분류, 정답 클래스 y에 대해:
```
L = -log(p_y) = -log(softmax(z)_y)
p = softmax(z)
```

**Step 2: Chain rule 적용**

```
∂L/∂zⱼ = Σᵢ (∂L/∂pᵢ)(∂pᵢ/∂zⱼ)
```

**Step 3: ∂L/∂pᵢ를 계산한다**

L = -log(p_y)이므로:
```
∂L/∂pᵢ = -1/p_y  (i=y인 경우)
∂L/∂pᵢ = 0       (i≠y인 경우)
```

**Step 4: 합산한다**

4.1에서 ∂pᵢ/∂zⱼ = pᵢ(δᵢⱼ - pⱼ)를 사용:

```
∂L/∂zⱼ = Σᵢ (∂L/∂pᵢ)(∂pᵢ/∂zⱼ)
         = (∂L/∂p_y)(∂p_y/∂zⱼ)   ← i=y인 항만 남음
         = (-1/p_y) · p_y(δ_{yj} - pⱼ)
         = -(δ_{yj} - pⱼ)
         = pⱼ - δ_{yj}
```

$$\boxed{\frac{\partial L}{\partial z_j} = p_j - \mathbf{1}(j = y)}$$

벡터 형태:
$$\frac{\partial L}{\partial \mathbf{z}} = \mathbf{p} - \mathbf{e}_y$$

여기서 e_y는 y번째 원소만 1인 one-hot 벡터이다.

★ 아름다운 결과: CE + Softmax를 합치면 그래디언트가 매우 단순해진다!
- 정답 클래스: ∂L/∂z_y = p_y - 1 (p_y가 1에 가까울수록 그래디언트 작아짐 → 잘 분류되면 업데이트 없음)
- 오답 클래스: ∂L/∂zⱼ = pⱼ (pⱼ가 클수록 그래디언트 큼 → 잘못된 클래스에 높은 확률을 주면 강하게 수정)

### 채점 포인트 체크리스트
- [ ] Chain rule을 명시적으로 적용했는가
- [ ] ∂L/∂pᵢ가 i=y일 때만 0이 아님을 보였는가
- [ ] 4.1의 결과를 사용했는가
- [ ] 최종 결과 p - e_y를 명확히 적었는가

## 4.3 2층 신경망 역전파 완전 유도

### 문제 (Problem)
**Derive all gradients ∂L/∂W₁ and ∂L/∂W₀ for a 2-layer neural network step by step.**

2층 신경망의 모든 가중치에 대한 그래디언트를 단계별로 완전히 유도하라.

### 전제 조건
- 4.2의 CE+Softmax 그래디언트
- Chain rule: ∂L/∂x = (∂z/∂x)ᵀ · ∂L/∂z

### Step-by-step 유도

**Step 1: 순전파 구조를 명확히 정의한다**

```
x₀ ∈ Rᵈ⁰           입력
z₁ = W₀x₀ ∈ Rᵈ¹    첫 번째 선형변환 (W₀ ∈ Rᵈ¹ˣᵈ⁰)
x₁ = σ(z₁) ∈ Rᵈ¹   활성함수 (원소별 적용)
z₂ = W₁x₁ ∈ Rᵈ²   두 번째 선형변환 (W₁ ∈ Rᵈ²ˣᵈ¹)
p = softmax(z₂)     출력 확률
L = CE(p, y) = -log p_y
```

**Step 2: 출력층 그래디언트 ∂L/∂z₂**

4.2에서 직접 적용:
```
∂L/∂z₂ = p - e_y ∈ Rᵈ²
```

**Step 3: 출력층 가중치 ∂L/∂W₁**

z₂ = W₁x₁에서 ∂z₂/∂W₁을 chain rule로 계산:
```
(∂L/∂W₁)ᵢⱼ = ∂L/∂(z₂)ᵢ · ∂(z₂)ᵢ/∂(W₁)ᵢⱼ = (p-e_y)ᵢ · (x₁)ⱼ
```

$$\boxed{\frac{\partial L}{\partial W_1} = (\mathbf{p} - \mathbf{e}_y) \mathbf{x}_1^\top \in \mathbb{R}^{d_2 \times d_1}}$$

★ 패턴: 앞 그래디언트(∂L/∂z₂) × 이전 활성화(x₁ᵀ) = 가중치 그래디언트

**Step 4: 중간 그래디언트 ∂L/∂x₁**

z₂ = W₁x₁에서 ∂z₂/∂x₁ = W₁:
```
∂L/∂x₁ = W₁ᵀ · ∂L/∂z₂ = W₁ᵀ(p - e_y) ∈ Rᵈ¹
```

이 그래디언트를 "오차 신호"가 역방향으로 흘러가는 것으로 이해하면 된다.

**Step 5: 활성함수를 통과하는 그래디언트 ∂L/∂z₁**

x₁ = σ(z₁)에서 σ는 원소별 함수이므로:
```
∂L/∂z₁ = ∂L/∂x₁ ⊙ σ'(z₁) ∈ Rᵈ¹
```

여기서 ⊙는 원소별 곱(Hadamard product).

ReLU를 사용하면 σ'(z₁) = 1(z₁ > 0):
```
∂L/∂z₁ = (W₁ᵀ(p-e_y)) ⊙ 1(z₁ > 0)
```

**Step 6: 첫 번째 가중치 ∂L/∂W₀**

z₁ = W₀x₀에서:
```
(∂L/∂W₀)ᵢⱼ = (∂L/∂z₁)ᵢ · (x₀)ⱼ
```

$$\boxed{\frac{\partial L}{\partial W_0} = \frac{\partial L}{\partial \mathbf{z}_1} \cdot \mathbf{x}_0^\top \in \mathbb{R}^{d_1 \times d_0}}$$

**전체 역전파 흐름 요약**:

```
L → p-e_y = ∂L/∂z₂
         ↓ (W₁ᵀ 곱하기)
         W₁ᵀ(p-e_y) = ∂L/∂x₁
         ↓ (⊙ σ'(z₁))
         ∂L/∂z₁
         ↓ (W₀ᵀ 곱하기)
         W₀ᵀ·∂L/∂z₁ = ∂L/∂x₀
```

각 층에서의 가중치 그래디언트:
- ∂L/∂W₁ = (∂L/∂z₂) · x₁ᵀ
- ∂L/∂W₀ = (∂L/∂z₁) · x₀ᵀ

### 핵심 역전파 패턴 (★)
모든 층에서 같은 패턴이 반복된다:
```
1. "들어오는 그래디언트" × "이전 활성화ᵀ" = 가중치 그래디언트
2. W^T × "들어오는 그래디언트" = 이전 층으로 전달되는 그래디언트
3. ⊙ σ'(z) = 활성함수 게이팅
```

### 채점 포인트 체크리스트
- [ ] 순전파 구조를 명확히 정의했는가
- [ ] ∂L/∂z₂ = p - e_y를 정확히 적었는가
- [ ] ∂L/∂W₁ = (p-e_y)x₁ᵀ의 외적 형태를 보였는가
- [ ] 활성함수를 통과할 때 ⊙ σ'(z₁)를 적용했는가
- [ ] Chain rule의 각 단계를 명시했는가

## 4.4 ReLU 미분과 Dead Neuron 문제

### 문제 (Problem)
**Derive the derivative of ReLU and explain the dead neuron problem.**

ReLU의 미분을 유도하고 Dead Neuron 문제를 설명하라.

### Step-by-step 유도

**Step 1: ReLU 정의**

$$\text{ReLU}(z) = \max(0, z) = \begin{cases} z & \text{if } z > 0 \\ 0 & \text{if } z \leq 0 \end{cases}$$

**Step 2: ReLU 미분**

$$\text{ReLU}'(z) = \frac{d}{dz}\max(0,z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z < 0 \\ \text{undefined} & \text{if } z = 0 \end{cases}$$

실용적으로 z=0에서 0 또는 1을 사용한다.

**Step 3: Dead ReLU 문제**

z < 0이면 ReLU(z) = 0이고 ReLU'(z) = 0.

역전파에서:
```
∂L/∂z = ∂L/∂a · ReLU'(z) = ∂L/∂a · 0 = 0
```
따라서 z₁ = W₀x₀의 모든 원소가 음수이면 W₀에 대한 그래디언트가 0이 된다.

★ Dead Neuron 조건: 어떤 뉴런이 "항상" z < 0이면 영원히 그래디언트 = 0 → 학습 불가.

**Dead ReLU 발생 원인**:
- 학습률이 너무 크면 가중치가 크게 업데이트되어 z < 0에 고착
- 초기화가 잘못되면 처음부터 z < 0

**대안 활성함수**:
- Leaky ReLU: ReLU'(z) = α (z<0에서 작은 기울기 α>0 유지)
- ELU, GELU 등

### 채점 포인트 체크리스트
- [ ] ReLU'(z) = 1(z>0)을 명시했는가
- [ ] Dead Neuron이 z<0에서 그래디언트=0 때문임을 설명했는가

# Part 5: 최적화/일반화 유도 체인 (W7)

## 5.1 Bias-Variance Decomposition

### 문제 (Problem)
**Derive the bias-variance decomposition: E_S[(h_S - f)²] = Var(h_S) + Bias²(h_S).**

편향-분산 분해를 완전히 유도하라.

### 전제 조건
- E_S[h_S] = h̄ (S에 대한 기대 모델)
- E_S[h_S - h̄] = 0 (정의에 의해)

### Step-by-step 유도

**Step 1: 설정**

- f: 참 함수 (고정된 ground truth)
- hS: 데이터 S로 학습한 모델 (S에 따라 확률적 변동)
- h̄ = E_S[hS]: S에 대한 기대 모델

목표: E_S[(hS - f)²]를 분해

**Step 2: h̄를 빼고 더하는 트릭**

$$E_S[(h_S - f)^2] = E_S[(h_S - \bar{h} + \bar{h} - f)^2]$$

a = hS - h̄, b = h̄ - f로 놓으면:
```
(a + b)² = a² + 2ab + b²
```
따라서:
```
E_S[(hS-f)²] = E_S[(hS-h̄)²] + 2E_S[(hS-h̄)(h̄-f)] + E_S[(h̄-f)²]
```

**Step 3: 교차항이 0임을 보인다**

★ 핵심: 가운데 교차항이 0이 됨!

```
E_S[(hS-h̄)(h̄-f)] = (h̄-f) · E_S[hS-h̄]    ← (h̄-f)는 S에 무관한 상수
                   = (h̄-f) · (E_S[hS] - h̄)
                   = (h̄-f) · (h̄ - h̄)
                   = (h̄-f) · 0
                   = 0
```

**Step 4: 각 항을 식별한다**

- 첫째 항: E_S[(hS-h̄)²] = Var_S[hS] (분산의 정의)
- 둘째 항: 0
- 셋째 항: (h̄-f)² = Bias²(hS) (S에 무관한 상수)

$$\boxed{E_S[(h_S - f)^2] = \underbrace{\text{Var}_S[h_S]}_{\text{분산}} + \underbrace{(\bar{h} - f)^2}_{\text{편향}^2}}$$

**Step 5: 의미**

| | 편향 | 분산 |
|--|--|--|
| **단순 모델** | 높음 (구조적 오류) | 낮음 (안정적) |
| **복잡 모델** | 낮음 (유연함) | 높음 (S에 민감) |
| **최적 복잡도** | bias²+var 최소화 | |

**Bias-Variance Tradeoff**: 모델 복잡도를 키우면 bias↓ but var↑, 줄이면 bias↑ but var↓.

### 핵심 논리 전환점 (★)
- "h̄를 빼고 더하는 트릭"이 핵심이다. 이 트릭 없이는 분해 불가능.
- 교차항이 0이 되는 이유: E_S[hS-h̄] = 0 (h̄의 정의로부터).

### 채점 포인트 체크리스트
- [ ] h̄를 빼고 더하는 트릭을 사용했는가
- [ ] 교차항이 0이 되는 이유를 설명했는가
- [ ] 각 항을 분산, 편향²으로 식별했는가

## 5.2 Batch Normalization 수식과 역전파

### 문제 (Problem)
**Describe the Batch Normalization algorithm including its forward and backward pass.**

Batch Normalization의 순전파와 역전파를 완전히 기술하라.

### Step-by-step 유도

**순전파 (Forward Pass)**

배치 B = {x⁽¹⁾,...,x⁽ᵐ⁾}에 대해 (k번째 차원):

**1단계: 배치 평균**
$$\mu_k = \frac{1}{m}\sum_{i=1}^{m} x_k^{(i)}$$

**2단계: 배치 분산**
$$\sigma_k^2 = \frac{1}{m}\sum_{i=1}^{m}(x_k^{(i)} - \mu_k)^2$$

**3단계: 정규화**
$$\hat{x}_k^{(i)} = \frac{x_k^{(i)} - \mu_k}{\sqrt{\sigma_k^2 + \epsilon}}$$

**4단계: 스케일 & 시프트**
$$y^{(i)} = \gamma \odot \hat{x}^{(i)} + \beta$$

여기서 γ (scale)와 β (shift)는 학습 가능한 파라미터이다.

**역전파 (Backward Pass)**

∂L/∂γ, ∂L/∂β, ∂L/∂x 를 구한다.

$$\frac{\partial L}{\partial \gamma} = \sum_{i=1}^{m} \frac{\partial L}{\partial y^{(i)}} \odot \hat{x}^{(i)}$$

$$\frac{\partial L}{\partial \beta} = \sum_{i=1}^{m} \frac{\partial L}{\partial y^{(i)}}$$

$$\frac{\partial L}{\partial \hat{x}_k^{(i)}} = \frac{\partial L}{\partial y_k^{(i)}} \cdot \gamma_k$$

σᵢ = √(σ²+ε)로 표기하면:

$$\frac{\partial L}{\partial x_k^{(i)}} = \frac{1}{m\sigma_k}\left[m\frac{\partial L}{\partial \hat{x}_k^{(i)}} - \sum_j \frac{\partial L}{\partial \hat{x}_k^{(j)}} - \hat{x}_k^{(i)}\sum_j \frac{\partial L}{\partial \hat{x}_k^{(j)}}\hat{x}_k^{(j)}\right]$$

★ BN 역전파의 핵심: μₖ와 σ²ₖ가 모두 x에 의존하므로, ∂L/∂x를 구할 때 이 의존성을 chain rule로 모두 추적해야 한다.

**왜 BN이 도움이 되는가?**

1. **Internal Covariate Shift 감소**: 각 층의 입력 분포를 안정화 → 더 큰 학습률 가능
2. **정규화 효과**: 배치 의존 노이즈가 과적합을 줄임 (Dropout과 유사)
3. **초기화 민감도 감소**: 활성화가 포화 영역을 피함
4. **γ=σ, β=μ로 설정하면 원래 값 복원 가능** → BN이 필요 없으면 학습이 이를 알아낸다

**추론(Inference) 시**:
훈련 중 이동 평균/분산(μ_running, σ²_running)을 저장해두고, 추론 시 배치 통계 대신 사용.

### 채점 포인트 체크리스트
- [ ] 4단계(μ→σ²→x̂→y)를 순서대로 기술했는가
- [ ] γ, β가 학습 가능함을 언급했는가
- [ ] ε이 0 나누기 방지를 위한 것임을 언급했는가
- [ ] BN의 장점을 2가지 이상 설명했는가

## 5.3 Adam 알고리즘 유도

### 문제 (Problem)
**Explain the evolution from SGD to Adam: SGD → Momentum → RMSProp → Adam.**

SGD에서 Adam까지의 발전 과정을 논리적으로 설명하라.

### Step-by-step 유도

**Step 1: SGD의 한계**

```
θₜ₊₁ = θₜ - η · gₜ    (gₜ = 미니배치 그래디언트)
```

한계:
- 학습률 η가 모든 파라미터에 동일 → 일부 파라미터는 큰 스텝이 필요하고 일부는 작은 스텝 필요
- 노이즈가 심한 방향으로 진동

**Step 2: Momentum (1차 모멘트 추적)**

과거 그래디언트를 "관성"으로 활용:
```
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ     (1차 모멘트: 지수 이동 평균)
θₜ₊₁ = θₜ - η · mₜ
```
β₁ ≈ 0.9 (과거 그래디언트를 90% 반영)

장점: 진동 감소, 평탄한 방향에서 가속

**Step 3: RMSProp (2차 모멘트 추적)**

그래디언트의 제곱 크기를 추적:
```
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²    (2차 모멘트: 제곱 이동 평균)
θₜ₊₁ = θₜ - η / √(vₜ+ε) · gₜ
```
장점: 각 파라미터의 그래디언트 크기에 맞게 학습률 자동 조정

★ 핵심 아이디어: 자주 큰 그래디언트를 받는 파라미터는 학습률을 줄이고, 작은 그래디언트를 받는 파라미터는 학습률을 키운다.

**Step 4: Adam = Momentum + RMSProp**

1차와 2차 모멘트를 모두 추적:
```
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ           (1차 모멘트)
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²          (2차 모멘트)
```

**Bias Correction** (초기 0 편향 보정):
```
m̂ₜ = mₜ/(1-β₁ᵗ)    (1차 보정)
v̂ₜ = vₜ/(1-β₂ᵗ)    (2차 보정)
```

★ 왜 Bias Correction이 필요한가? t=1에서 m₁ = (1-β₁)g₁ ≈ 0.1·g₁ (너무 작음). 초기 몇 스텝에서 m̂₁ = m₁/0.1 = g₁으로 보정.

업데이트:
$$\boxed{\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \cdot \hat{m}_t}$$

**권장 하이퍼파라미터** (논문 기본값):
- β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸

### 채점 포인트 체크리스트
- [ ] SGD → Momentum → RMSProp → Adam의 흐름을 설명했는가
- [ ] 1차, 2차 모멘트 갱신 공식을 적었는가
- [ ] Bias Correction이 필요한 이유를 설명했는가
- [ ] 최종 업데이트 규칙을 적었는가

## 5.4 정규화의 통일적 관점

### 문제 (Problem)
**Explain the unified view: Prior = Regularization = Inductive Bias.**

Prior = 정규화 = 귀납 편향의 통일적 관점을 설명하라.

### 논리 체인

```
[베이지안 관점]
사전지식 Prior P(θ) → MAP 목적함수 → 추가 항 log P(θ)

[최적화 관점]
추가 항 log P(θ) → 손실 함수에서의 정규화 항

[학습 이론 관점]
정규화 → 가설공간 제한 → 모델 복잡도 감소 → 일반화 개선

[귀납 편향 관점]
"어떤 해를 선호하는가?"에 대한 명시적 또는 암묵적 가정
```

**구체적 대응**:

| Prior | 정규화 | 귀납 편향 | 효과 |
|-------|--------|---------|------|
| Gaussian N(0,τ²I) | L2 (λ‖θ‖²) | 작은 가중치 선호 | 가중치 소멸, 일반화 |
| Laplace | L1 (λ‖θ‖₁) | 희소 가중치 선호 | 특성 선택 |
| 가중치 공유 | CNN | 공간 이동 불변성 | 이미지 분류 |
| 순서 의존성 | RNN | 시간적 지역성 | 언어 모델링 |
| 자기 주의 | Transformer | 임의 의존성 | 장거리 관계 |

$$\boxed{P(\theta) = \text{Prior} = \text{Regularization} = \text{Inductive Bias}}$$

**일반화와의 연결**:
- 정규화 없음: 가설공간 = 모든 파라미터 → 고분산 (과적합)
- 강한 정규화: 가설공간 제한 → 고편향 (과소적합)
- 최적 정규화: Bias² + Variance 균형 (5.1 Bias-Variance Tradeoff)

## 6.3 가장 자주 나오는 유도 Top 5 (예상)

**1위: CE Loss = MLE** (★★★ 필수)
```
Categorical 가정 → 우도 → 로그 → 최대화 → 음수 → CE
```

**2위: 역전파/Chain rule** (★★★ 필수)
```
순전파 정의 → CE+Softmax 그래디언트 → W₁ 그래디언트 → W₀ 그래디언트
```

**3위: MAP = MLE + Prior** (★★★ 필수)
```
베이즈 정리 → 로그 사후 = 로그 우도 + 로그 Prior
```

**4위: L2 정규화 = Gaussian Prior** (★★☆)
```
Gaussian Prior → 로그 → -‖θ‖²/(2τ²) → λ‖θ‖²
```

**5위: KL ≥ 0 (Gibbs' Inequality)** (★★☆)
```
-log 볼록 → Jensen → E[-log(q/p)] ≥ -log(E[q/p]) = 0
```

## F. 각 유도의 "막히기 쉬운 포인트" 모음

**유도 #1: 선형변환↔행렬**
- 막히는 곳: "왜 L(eᵢ)를 열로 나열하면 되는가?"
- 해결: L(v) = v₁L(e₁)+...+vₙL(eₙ) 이므로, 이것이 [L(e₁)|...|L(eₙ)]·v 형태임을 확인하면 됨

**유도 #2: 랭크-널리티**
- 막히는 곳: "{Avᵢ}의 선형독립성 증명"
- 해결: Σβᵢ(Avᵢ)=0 → A(Σβᵢvᵢ)=0 → N(A)에 속함 → {nᵢ, vᵢ}의 독립성으로 βᵢ=0

**유도 #3: 스펙트럴 분해**
- 막히는 곳: "고유벡터 직교성 증명"
- 해결: λᵢ(vⱼᵀvᵢ) = λⱼ(vⱼᵀvᵢ) → (λᵢ-λⱼ)(vⱼᵀvᵢ)=0 → λᵢ≠λⱼ이면 직교

**유도 #4: SVD**
- 막히는 곳: "uᵢ를 어떻게 정의하는가?"
- 해결: uᵢ = Avᵢ/σᵢ (정규화). ‖Avᵢ‖=σᵢ이므로 단위벡터.

**유도 #5: GD**
- 막히는 곳: "왜 -∇f 방향이 최대 감소 방향인가?"
- 해결: ∇fᵀd를 최소화 → 코시-슈바르츠에서 d=-∇f/‖∇f‖일 때 최솟값

**유도 #6: MAP**
- 막히는 곳: "P(E)가 왜 상수인가?"
- 해결: P(H|E) ∝ P(E|H)P(H)에서 P(E)는 H에 대해 상수 (marginalization의 결과)

**유도 #7: CE+Softmax**
- 막히는 곳: "Σᵢ(∂L/∂pᵢ)(∂pᵢ/∂zⱼ)에서 왜 i=y인 항만 남는가?"
- 해결: L = -log(p_y)이므로 ∂L/∂pᵢ = 0 (i≠y), -1/p_y (i=y)

**유도 #8: Bias-Variance**
- 막히는 곳: "교차항이 왜 0인가?"
- 해결: E_S[hS-h̄] = E_S[hS]-h̄ = h̄-h̄ = 0 (h̄의 정의 이용)

>
