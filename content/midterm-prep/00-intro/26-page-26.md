**A-Q1 해설: 벡터공간과 부분공간 (3점)**

채점 기준:
- 벡터공간 정의 언급 (1점)
- 부분공간 3조건 정확히 서술 (각 0.5점 × 3 = 1.5점)
- 조건 1개 이상 누락 시 1점 감점

완전 풀이:

벡터공간(Vector Space) $V$는 덧셈과 스칼라배가 정의된 원소들의 집합으로, 8개의 공리(교환법칙, 결합법칙, 항등원 존재, 역원 존재, 분배법칙 2개, 스칼라 결합법칙, 단위원 존재)를 만족한다.

부분공간(Subspace) 판정의 3조건:
1. **영벡터 포함**: $\mathbf{0} \in W$
2. **덧셈에 닫힘**: $\mathbf{u}, \mathbf{v} \in W \Rightarrow \mathbf{u} + \mathbf{v} \in W$
3. **스칼라배에 닫힘**: $\mathbf{v} \in W, c \in \mathbb{R} \Rightarrow c\mathbf{v} \in W$

이 세 조건이 성립하면 $W$는 자동으로 $V$의 모든 벡터공간 공리를 상속받는다.

자주 하는 실수: 영벡터 조건을 빠트리는 경우. "$\mathbf{u}, \mathbf{v} \in W \Rightarrow \mathbf{u} - \mathbf{v} \in W$"와 "$\mathbf{0} \in W$"를 합쳐서 두 조건으로 쓰는 것도 허용된다.

**A-Q2 해설: 커널, 이미지, 랭크-널리티 정리 (3점)**

채점 기준:
- 커널 정의 (1점), 이미지 정의 (1점), 정리 수식 (1점)

완전 풀이:

- **커널(Kernel, 핵)**: $\ker(A) = \{\mathbf{x} \in \mathbb{R}^n \mid A\mathbf{x} = \mathbf{0}\}$. 즉, $A$에 의해 영벡터로 보내지는 벡터들의 집합. $A$의 **영공간(null space)**이라고도 한다.

- **이미지(Image, 열공간)**: $\text{Im}(A) = \{A\mathbf{x} \mid \mathbf{x} \in \mathbb{R}^n\} \subseteq \mathbb{R}^m$. 즉, $A$의 열벡터들의 선형결합으로 만들 수 있는 모든 벡터의 집합.

**랭크-널리티 정리(Rank-Nullity Theorem)**:

$$\dim(\ker(A)) + \dim(\text{Im}(A)) = n$$

즉, $\text{nullity}(A) + \text{rank}(A) = $ (열의 수).

직관: 선형변환 $A$는 $\mathbb{R}^n$의 일부는 영벡터로 "찌부러뜨리고"(커널 부분), 나머지를 이미지로 보낸다. 두 부분의 차원을 합치면 원래 공간의 차원이 된다.

관련 슬라이드: 선형대수 슬라이드 50-60번대

**A-Q3 해설: PSD (양반정치) (3점)**

채점 기준:
- 정의 정확히 서술 (1.5점), 동치 조건 하나 더 (1.5점)

완전 풀이:

행렬 $A \in \mathbb{R}^{n \times n}$이 **양반정치(Positive Semi-Definite, PSD)**라는 것은:

**정의**: 모든 벡터 $\mathbf{x} \in \mathbb{R}^n$에 대해 $\mathbf{x}^\top A \mathbf{x} \geq 0$.

동치 조건들:
- 모든 고유값 $\lambda_i \geq 0$
- $A = B^\top B$인 행렬 $B$가 존재한다 (Cholesky 분해)
- $A$가 대칭이고 Cholesky 분해 가능

딥러닝에서의 중요성: 공분산 행렬은 항상 PSD이다. 왜냐하면 임의의 행렬 $B$에 대해 $B^\top B$는 항상 PSD이기 때문이다 ($\mathbf{x}^\top B^\top B \mathbf{x} = \|B\mathbf{x}\|^2 \geq 0$). 헤시안이 PSD이면 임계점이 최솟값임을 보장한다(볼록함수 조건).

**A-Q4 해설: 그래디언트 (3점)**

완전 풀이:

$f: \mathbb{R}^n \to \mathbb{R}$의 그래디언트:
$$\nabla f(\mathbf{x}) = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right]^\top \in \mathbb{R}^n$$

**그래디언트의 방향**: 함수값이 가장 빠르게 증가하는 방향. 수학적으로, 단위벡터 $\mathbf{d}$ 방향의 방향 도함수는 $D_\mathbf{d} f = \nabla f^\top \mathbf{d}$이고, 코시-슈바르츠 부등식에 의해 $\|\mathbf{d}\|=1$일 때 이 값은 $\mathbf{d} = \nabla f / \|\nabla f\|$일 때 최대가 된다.

**$-\nabla f(\mathbf{x})$의 의미**: 함수값이 가장 빠르게 감소하는 방향. 최소화 문제에서 경사 하강법의 이론적 근거이다. 이 방향으로 작은 스텝을 내딛으면 1차 근사에서 함수값이 가장 많이 줄어든다.

**A-Q5 해설: 벡터 체인룰 (3점)**

완전 풀이:

함수 합성 $L = h(g(\mathbf{x}))$에서, $\mathbf{z} = g(\mathbf{x}) \in \mathbb{R}^k$, $L = h(\mathbf{z}) \in \mathbb{R}$일 때:

$$\nabla_\mathbf{x} L = J_g^\top \nabla_\mathbf{z} h$$

여기서 $J_g = \frac{\partial g}{\partial \mathbf{x}} \in \mathbb{R}^{k \times n}$은 $g$의 야코비안 행렬이고, $\nabla_\mathbf{z} h \in \mathbb{R}^k$는 $h$의 그래디언트이다.

성분 표기: $(J_g)_{ij} = \frac{\partial g_i}{\partial x_j}$이므로

$$\frac{\partial L}{\partial x_j} = \sum_{i=1}^k \frac{\partial L}{\partial z_i} \cdot \frac{\partial z_i}{\partial x_j}$$

**역전파와의 연결**: 역전파는 이 체인룰을 레이어마다 반복 적용하는 것이다. "그래디언트가 역방향으로 흐른다"는 것은 $J^\top$에 의한 선형 변환이 연쇄적으로 적용됨을 의미한다.

**A-Q6 해설: 엔트로피 (3점)**

완전 풀이:

이산 분포 $P$의 **엔트로피(Entropy)**:
$$H(P) = -\sum_x P(x) \log P(x)$$

(로그의 밑은 2이면 비트 단위, $e$이면 나트 단위)

$P(x) \log P(x)$에서 $P(x) = 0$이면 $0 \log 0 = 0$으로 정의 (연속성에 의해).

**엔트로피를 최대화하는 분포**: 유한 알파벳 $|\mathcal{X}| = N$에서 **균등 분포(Uniform distribution)** $P(x) = 1/N$이 엔트로피를 최대화한다. 최대 엔트로피 = $\log N$.

**딥러닝에서의 의미**:
- CE Loss = $-\log \hat{y}_{\text{true}}$. CE = $H(p_E) + KL(p_E \| p_\theta)$이므로, 모델이 데이터 분포를 완벽히 학습하면 CE = $H(p_E)$ (데이터 자체의 엔트로피)에 수렴한다.
- 엔트로피가 낮은 분포 = 예측이 확실함. 높은 엔트로피 = 불확실성이 큼.

**A-Q7 해설: MLE vs MAP (3점)**

완전 풀이:

**MLE(최대우도추정)**: 관측 데이터의 확률을 최대화하는 파라미터를 구한다:
$$\theta_{ML} = \arg\max_\theta P(E \mid \theta) = \arg\max_\theta \log P(E \mid \theta)$$

**MAP(최대사후확률추정)**: 베이즈 정리를 이용하여 사후확률을 최대화:
$$\theta_{MAP} = \arg\max_\theta P(\theta \mid E) = \arg\max_\theta [\log P(E \mid \theta) + \log P(\theta)]$$

MAP = MLE + 사전분포 항.

**동치 조건**: Prior $P(\theta)$가 **균등분포(uniform distribution)**이면 $\log P(\theta)$는 상수이므로 MAP = MLE.

핵심 차이:
- MLE는 데이터만으로 추정 → 데이터가 적으면 과적합 가능
- MAP는 Prior를 통해 정규화 → 데이터가 적어도 안정적
- Prior가 Gaussian이면 MAP = L2 정규화된 MLE (Ridge regression)

**A-Q8 해설: 활성화 함수 (3점)**

완전 풀이:

**활성화 함수의 역할**: 신경망에 비선형성(non-linearity)을 도입한다.

**비선형성이 필요한 이유**: 선형 변환의 합성은 여전히 선형 변환이다. 즉 $W_2(W_1 x) = (W_2 W_1)x$이므로, 비선형 활성화 없이는 층을 아무리 쌓아도 하나의 선형 변환과 동치이다. 비선형성이 있어야 Universal Approximation이 가능하다.

대표적인 활성화 함수:
- **ReLU(Rectified Linear Unit)**: $\text{ReLU}(x) = \max(0, x)$
  - 미분: $\text{ReLU}'(x) = \mathbf{1}(x > 0)$ (0 이상이면 1, 미만이면 0)
  - 장점: 계산 효율, 기울기 소실 완화
  - 단점: Dying ReLU ($x < 0$에서 기울기 = 0 → 뉴런이 "죽음")

- **Sigmoid**: $\sigma(x) = \frac{1}{1+e^{-x}}$, 출력 범위 $(0, 1)$
  - 미분: $\sigma'(x) = \sigma(x)(1-\sigma(x))$
  - 단점: 기울기 소실 (saturation 구간에서 미분값 ≈ 0)

**A-Q9 해설: 기울기 소실 문제 (3점)**

완전 풀이:

**기울기 소실(Vanishing Gradient Problem)**: 역전파 시 그래디언트가 층을 거슬러 올라갈수록 지수적으로 작아져, 앞쪽 층(입력에 가까운 층)의 가중치가 거의 업데이트되지 않는 문제.

수학적 이유: 체인룰에서 $\partial L / \partial W_1 = \prod_{l} J_l \cdot \nabla_\text{output} L$. 각 $J_l$의 스펙트럼 반경(최대 고유값)이 1보다 작으면 곱이 지수적으로 0에 수렴.

**주로 발생하는 아키텍처**:
- 깊은 층을 가진 sigmoid/tanh 활성화 신경망 (포화 구간에서 미분 ≈ 0)
- 순환 신경망(RNN)에서 긴 시퀀스 처리 시

**완화 기법**:
1. **Residual Connection (Skip Connection)**: $y = F(x) + x$ (ResNet). 그래디언트가 지름길로 흘러 소실 방지. $\partial L / \partial x = \partial L / \partial y \cdot (1 + \partial F/\partial x)$에서 최소 1의 그래디언트 보장.
2. **Batch Normalization**: 각 층의 입력을 정규화하여 활성화값이 포화 구간에 들어가는 것을 방지.
3. 추가: **ReLU 활성화 함수** 사용 (포화 구간 없음), **Gradient Clipping** (폭발 방지)

**A-Q10 해설: 편향-분산 트레이드오프 (3점)**

완전 풀이:

**편향(Bias)**: 모델의 평균 예측값과 참값의 차이. 모델이 단순할수록(표현력 부족) 편향이 크다. → 과소적합(Underfitting)

**분산(Variance)**: 훈련 데이터가 달라질 때 모델 예측값의 변동성. 모델이 복잡할수록(너무 훈련 데이터에 맞춤) 분산이 크다. → 과적합(Overfitting)

**트레이드오프**: 모델 복잡도가 증가하면 편향 감소, 분산 증가. 총 오차 $= \text{Bias}^2 + \text{Variance} + \text{Noise}$를 최소화하는 최적 복잡도가 존재한다.

**L2 정규화의 효과**: 가중치를 0 방향으로 수축시켜 모델의 유효 복잡도를 낮춘다. 따라서 **분산 감소, 편향 약간 증가**. $\lambda$가 클수록 정규화가 강하고 분산이 더 줄어든다 (단, 너무 크면 과소적합).

**A-Q12 해설: 그래디언트 계산과 최솟값 (5점)**

완전 풀이:

$f(\mathbf{x}) = \mathbf{x}^\top A \mathbf{x} + \mathbf{b}^\top \mathbf{x}$

**(a) 그래디언트:**

이차형식의 미분 공식: $\nabla(\mathbf{x}^\top A \mathbf{x}) = (A + A^\top)\mathbf{x} = 2A\mathbf{x}$ ($A$ 대칭이므로)

$\nabla(\mathbf{b}^\top \mathbf{x}) = \mathbf{b}$

따라서:
$$\nabla f(\mathbf{x}) = 2A\mathbf{x} + \mathbf{b} = \begin{bmatrix} 4x_1 + 1 \\ 2x_2 + 2 \\ 6x_3 + 3 \end{bmatrix}$$

**(b) 임계점:**

$\nabla f(\mathbf{x}^*) = \mathbf{0}$으로 놓으면:
$$4x_1^* + 1 = 0 \Rightarrow x_1^* = -1/4$$
$$2x_2^* + 2 = 0 \Rightarrow x_2^* = -1$$
$$6x_3^* + 3 = 0 \Rightarrow x_3^* = -1/2$$

$\mathbf{x}^* = [-1/4, -1, -1/2]^\top$

**(c) 헤시안으로 최솟값 확인:**

헤시안 $H = \nabla^2 f = 2A = \begin{bmatrix} 4 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & 6 \end{bmatrix}$

모든 대각 원소(고유값) $= 4, 2, 6 > 0$이므로 헤시안은 양정치(Positive Definite, PD). Fermat 정리에 의해 임계점에서 2차 조건을 확인하면: 헤시안이 PD이면 강한 극솟값(strong local minimum). $f$가 볼록함수이므로 이는 전역 최솟값이기도 하다.

**A-Q13 해설: 베이즈 정리 응용 (5점)**

완전 풀이:

주어진 값: $P(D) = 0.01$, $P(\neg D) = 0.99$, $P(T^+ \mid D) = 0.95$, $P(T^- \mid \neg D) = 0.90$이므로 $P(T^+ \mid \neg D) = 0.10$.

**(a) 전확률 공식:**

$$P(T^+) = P(T^+ \mid D) P(D) + P(T^+ \mid \neg D) P(\neg D)$$
$$= 0.95 \times 0.01 + 0.10 \times 0.99$$
$$= 0.0095 + 0.099 = 0.1085$$

**(b) 베이즈 정리:**

$$P(D \mid T^+) = \frac{P(T^+ \mid D) P(D)}{P(T^+)} = \frac{0.95 \times 0.01}{0.1085} = \frac{0.0095}{0.1085} \approx 0.0875$$

즉, 양성 판정을 받았더라도 실제로 병에 걸릴 확률은 약 8.75%에 불과하다.

**(c) 해석:**

이것을 **기저율 오류(Base Rate Fallacy)** 혹은 **사전확률의 중요성**이라 한다. 질병 유병률(Prior $P(D) = 0.01$)이 매우 낮기 때문에, 검사 정확도가 높더라도 양성 판정의 대부분이 **위양성(False Positive)**이다. 희귀 질병의 스크리닝에는 단일 검사 결과만으로 판단하면 안 된다. 이는 딥러닝에서 데이터 불균형(class imbalance) 문제와 직접 연결된다.

자주 하는 실수: $P(D \mid T^+) \approx P(T^+ \mid D) = 0.95$로 착각. 조건부 확률의 인수 순서를 뒤집는 오류.

**A-Q14 해설: 정보이론 계산 (5점)**

완전 풀이:

$p_E = [0.5, 0.3, 0.2]$, $p_\theta = [0.4, 0.4, 0.2]$

**(a) 엔트로피:**
$$H(p_E) = -(0.5\log_2 0.5 + 0.3\log_2 0.3 + 0.2\log_2 0.2)$$
$$= -(0.5 \times (-1) + 0.3 \times (-1.737) + 0.2 \times (-2.322))$$
$$= -(-0.5 - 0.521 - 0.464) = 1.485 \text{ bits}$$

**(b) 교차 엔트로피:**
$$CE(p_E, p_\theta) = -(0.5\log_2 0.4 + 0.3\log_2 0.4 + 0.2\log_2 0.2)$$

$\log_2 0.4 = \log_2(2/5) = 1 - \log_2 5 \approx 1 - 2.322 = -1.322$
$\log_2 0.2 = -2.322$

$$= -(0.5 \times (-1.322) + 0.3 \times (-1.322) + 0.2 \times (-2.322))$$
$$= -(-0.661 - 0.397 - 0.464) = 1.522 \text{ bits}$$

**(c) KL Divergence:**
$$KL(p_E \| p_\theta) = CE(p_E, p_\theta) - H(p_E) = 1.522 - 1.485 = 0.037 \text{ bits}$$

**A-Q15 해설: CE Loss 유도 (10점)**

채점 기준:
- 분포 가정 명시 (2점)
- i.i.d. + 우도 구성 (2점)
- 로그 이유 서술 (2점)
- 최대화 → 최소화 전환 (2점)
- 최종 CE 형태 (2점)

완전 풀이:

**Step 1: 확률 모델 가정**

지도학습에서 $C$개 클래스 분류를 위한 모델 $h$가 입력 $x$를 받아 확률 벡터 $h(x) \in \Delta^C$ (확률 단체)를 출력한다고 가정한다. 정답 레이블 $y \in \{1, \ldots, C\}$에 대해 **Categorical(범주형) 분포**를 가정:

$$p(y \mid x, h) = h(x)_y$$

즉, 모델이 출력한 $y$번째 확률값이 $y$가 발생할 확률이다.

**Step 2: i.i.d. 가정과 우도 구성**

데이터 $E = \{(x_1, y_1), \ldots, (x_n, y_n)\}$의 각 샘플이 **독립적이고 동일한 분포(i.i.d.)**에서 추출되었다고 가정한다. 그러면 결합 우도(joint likelihood)는:

$$P(E \mid H) = \prod_{i=1}^{n} p(y_i \mid x_i, h) = \prod_{i=1}^{n} h(x_i)_{y_i}$$

i.i.d. 가정이 핵심: 이 가정이 없으면 결합 확률이 곱으로 분해되지 않는다.

**Step 3: 로그를 취하는 이유**

$$\log P(E \mid H) = \sum_{i=1}^{n} \log h(x_i)_{y_i}$$

로그를 취하는 이유는 세 가지이다:
1. **수치 안정성**: 확률값의 곱은 $n$이 크면 부동소수점 언더플로우가 발생한다. 로그를 취하면 곱 → 합으로 바뀌어 안전하다.
2. **수학적 편의**: 곱 → 합이 되어 미분이 쉬워진다.
3. **argmax 불변성**: 로그 함수는 단조증가이므로 $\arg\max_\theta f(\theta) = \arg\max_\theta \log f(\theta)$.

**Step 4: MLE 최대화 → 음의 로그 우도 최소화**

$$\theta_{ML} = \arg\max_\theta \log P(E \mid H) = \arg\max_\theta \sum_{i=1}^{n} \log h(x_i)_{y_i}$$

최대화를 최소화로 변환하기 위해 음수를 취한다:

$$\theta_{ML} = \arg\min_\theta \left[-\sum_{i=1}^{n} \log h(x_i)_{y_i}\right]$$

**Step 5: Cross-Entropy Loss의 최종 형태**

one-hot 벡터 $e_{y_i}$를 사용하여 표현하면:

$$-\sum_{i=1}^{n} \log h(x_i)_{y_i} = -\sum_{i=1}^{n} e_{y_i}^\top \log h(x_i)$$

이를 샘플 수로 정규화하면:

$$\boxed{L_{CE} = -\frac{1}{n}\sum_{i=1}^{n} e_{y_i}^\top \log h(x_i)}$$

이것이 **Cross-Entropy Loss**이다. 정보이론 관점에서는 경험분포 $p_E$와 모델분포 $p_\theta$의 교차 엔트로피 $CE(p_E, p_\theta) = -\mathbb{E}_{Z \sim p_E}[\log p(Z \mid H)]$이기도 하다.

자주 하는 실수:
- i.i.d. 가정 언급을 빠트림
- 로그 변환의 이유를 "계산이 편하기 때문"으로만 서술
- 최대화→최소화 전환 시 음수 부호를 빠트림

**A-Q16 해설: MAP와 L2 정규화 (10점)**

채점 기준:
- 베이즈 정리 적용 (2점)
- log 분해 (2점)
- Gaussian Prior 전개 (2점)
- 최종 목적함수 (2점)
- λ와 τ² 관계 (2점)

완전 풀이:

**Step 1: 베이즈 정리 적용**

$$P(\theta \mid E) = \frac{P(E \mid \theta) \cdot P(\theta)}{P(E)}$$

$P(E)$는 $\theta$에 대해 상수이므로 (주변화된 우도, 정규화 상수):

$$P(\theta \mid E) \propto P(E \mid \theta) \cdot P(\theta)$$

MAP 추정은 사후확률을 최대화한다:

$$\theta_{MAP} = \arg\max_\theta P(\theta \mid E) = \arg\max_\theta [P(E \mid \theta) \cdot P(\theta)]$$

**Step 2: 로그 후 분해**

로그를 취하면 (로그는 단조증가이므로 argmax 불변):

$$\theta_{MAP} = \arg\max_\theta [\log P(E \mid \theta) + \log P(\theta)]$$

$$= \arg\max_\theta \underbrace{\log P(E \mid \theta)}_{\text{log-likelihood (MLE 항)}} + \underbrace{\log P(\theta)}_{\text{log-prior (정규화 항)}}$$

**Step 3: Gaussian Prior 설정**

파라미터 $\theta$에 대해 등방 가우시안 사전분포를 가정:

$$P(\theta) = \mathcal{N}(\theta;\ \mathbf{0},\ \tau^2 I) = \frac{1}{(2\pi\tau^2)^{d/2}} \exp\left(-\frac{\|\theta\|^2}{2\tau^2}\right)$$

로그를 취하면:

$$\log P(\theta) = -\frac{d}{2}\log(2\pi\tau^2) - \frac{\|\theta\|^2}{2\tau^2} = -\frac{\|\theta\|^2}{2\tau^2} + C_1$$

여기서 $C_1$은 $\theta$에 무관한 상수.

**Step 4: MAP 목적함수**

$$\theta_{MAP} = \arg\max_\theta \left[\log P(E \mid \theta) - \frac{\|\theta\|^2}{2\tau^2}\right]$$

최대화를 최소화로 변환 (음수 부호):

$$\theta_{MAP} = \arg\min_\theta \left[-\log P(E \mid \theta) + \frac{\|\theta\|^2}{2\tau^2}\right]$$

$$= \arg\min_\theta \left[L(\theta) + \lambda\|\theta\|^2\right]$$

**Step 5: λ와 τ²의 관계**

$$\boxed{\lambda = \frac{1}{2\tau^2}}$$

따라서 **Gaussian Prior를 사용한 MAP 추정 = MLE + L2 정규화(가중치 감쇠)**이다.

해석:
- $\tau^2$가 작으면(Prior가 강함, θ가 0에 가까울 것이라는 강한 믿음) → $\lambda$가 커짐 → L2 정규화가 강해짐 → 가중치가 0에 가까워짐
- $\tau^2 \to \infty$(균등 Prior, 정보 없음) → $\lambda \to 0$ → MAP → MLE

자주 하는 실수: $P(E)$가 상수인 이유를 설명하지 않는 것. 로그 변환 후 Prior 항에서 상수를 제거하는 과정 누락.

**A-Q17 해설: 역전파 유도 (10점)**

채점 기준:
- 순전파 구조 정의 (1점)
- ∂L/∂z₂ 계산 (2점)
- ∂L/∂W₁ (3점)
- ∂L/∂x₁ (2점)
- ∂L/∂W₀ (2점)

완전 풀이:

**순전파 구조 정의:**

$$x_0 \in \mathbb{R}^{d_0}: \text{입력}$$
$$z_1 = W_0 x_0 \in \mathbb{R}^{d_1}: \text{1층 선형 변환}$$
$$x_1 = \text{ReLU}(z_1) \in \mathbb{R}^{d_1}: \text{1층 출력}$$
$$z_2 = W_1 x_1 \in \mathbb{R}^{d_2}: \text{2층 선형 변환 (logits)}$$
$$L = CE(\text{softmax}(z_2), y): \text{손실}$$

**(a) $\partial L / \partial W_1$ 계산:**

먼저 $\partial L / \partial z_2$를 구한다. CE+Softmax 합성 그래디언트는 잘 알려진 결과(유도 #6-#7 참조):

$$\frac{\partial L}{\partial z_2} = p - e_y \in \mathbb{R}^{d_2}$$

여기서 $p = \text{softmax}(z_2)$, $e_y$는 정답 클래스의 one-hot 벡터.

이제 $z_2 = W_1 x_1$이므로 체인룰:

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial W_1}$$

$z_2 = W_1 x_1$에서 $z_2$의 $j$번째 원소: $z_{2,j} = (W_1)_{j,:} x_1$이므로 $\frac{\partial z_{2,j}}{\partial (W_1)_{jk}} = (x_1)_k$.

벡터화하면: $\frac{\partial z_2}{\partial W_1}$에서 외적(outer product)이 나온다:

$$\boxed{\frac{\partial L}{\partial W_1} = (p - e_y) \cdot x_1^\top \in \mathbb{R}^{d_2 \times d_1}}$$

**(b) $\partial L / \partial x_1$ 계산:**

$z_2 = W_1 x_1$이므로 $\frac{\partial z_2}{\partial x_1} = W_1$. 체인룰:

$$\frac{\partial L}{\partial x_1} = W_1^\top \cdot \frac{\partial L}{\partial z_2} = W_1^\top (p - e_y) \in \mathbb{R}^{d_1}$$

**(c) $\partial L / \partial W_0$ 계산:**

먼저 $\partial L / \partial z_1$을 구한다. $x_1 = \text{ReLU}(z_1)$에서 ReLU의 미분은 $\text{ReLU}'(z) = \mathbf{1}(z > 0)$. 원소별 곱(Hadamard product):

$$\frac{\partial L}{\partial z_1} = \frac{\partial L}{\partial x_1} \odot \text{ReLU}'(z_1) = \frac{\partial L}{\partial x_1} \odot \mathbf{1}(z_1 > 0) \in \mathbb{R}^{d_1}$$

마지막으로, $z_1 = W_0 x_0$이므로 동일한 패턴:

$$\boxed{\frac{\partial L}{\partial W_0} = \frac{\partial L}{\partial z_1} \cdot x_0^\top \in \mathbb{R}^{d_1 \times d_0}}$$

**역전파의 핵심 패턴**: 매 층마다 반복되는 패턴은 "위에서 내려온 그래디언트 × 현재 층 입력$^\top$". 이것이 역전파 알고리즘의 본질이다.

자주 하는 실수: $\partial L / \partial W_1$에서 열벡터와 행벡터의 외적 방향을 틀리는 것. ReLU 미분에서 원소별 곱(⊙)이 아닌 행렬 곱을 쓰는 것.

**A-Q19 해설: 정규화와 일반화 종합 (10점)**

완전 풀이:

**(a) 과적합 정의:**

훈련 오차(training error): $\hat{R}(h) = \frac{1}{|S|}\sum_{(x,y)\in S} \ell(h(x), y)$

일반화 오차(generalization error): $R(h) = \mathbb{E}_{(x,y)\sim\mathcal{D}}[\ell(h(x), y)]$

**과적합**: 훈련 오차는 작지만 일반화 오차가 크게 차이나는 상황, 즉 $R(h) - \hat{R}(h) \gg 0$인 경우. 모델이 훈련 데이터의 노이즈까지 학습하여 새로운 데이터에 일반화가 안 된다.

**(b) 편향-분산 분해 유도:**

$\bar{h} = \mathbb{E}_S[h_S]$로 정의하면:

$$\mathbb{E}_S[(h_S - f)^2] = \mathbb{E}_S[(h_S - \bar{h} + \bar{h} - f)^2]$$

전개하면:

$$= \mathbb{E}_S[(h_S - \bar{h})^2] + 2\mathbb{E}_S[(h_S - \bar{h})(\bar{h} - f)] + (\bar{h} - f)^2$$

**교차항 = 0인 이유**: $(\bar{h} - f)$는 $S$에 대해 상수이므로:

$$2(\bar{h} - f) \cdot \mathbb{E}_S[h_S - \bar{h}] = 2(\bar{h} - f) \cdot (\underbrace{\mathbb{E}_S[h_S]}_{= \bar{h}} - \bar{h}) = 0$$

따라서:

$$\mathbb{E}_S[(h_S - f)^2] = \underbrace{\mathbb{E}_S[(h_S - \bar{h})^2]}_{\text{Variance}} + \underbrace{(\bar{h} - f)^2}_{\text{Bias}^2}$$

**(c) L2 정규화의 세 관점:**

수학적 관점: 손실 함수가 $L(\theta) + \lambda\|\theta\|^2$가 되어, 이 추가 항이 $\theta = 0$ 방향으로 끌어당기는 힘으로 작용한다. 최솟값의 위치가 이동하고, 가중치의 크기가 제약된다.

베이지안 관점: Gaussian Prior $P(\theta) = \mathcal{N}(0, \tau^2 I)$를 사용한 MAP 추정. $\lambda = 1/(2\tau^2)$. 파라미터가 0 주변에 분포할 것이라는 사전 믿음을 반영한다.

실용적 관점: 가중치의 크기가 줄어들어 모델이 단일 특징에 과도하게 의존하지 않는다. 이는 과적합을 방지하고 분산을 줄이는 효과가 있다. L1 정규화는 일부 가중치를 정확히 0으로 만드는 희소성(sparsity)을 유도한다.

**(d) Batch Normalization 수식 및 정규화 효과:**

BN forward pass 3단계:

Step 1 — 배치 통계 계산:
$$\mu_B = \frac{1}{m}\sum_{i=1}^m x^{(i)}, \quad \sigma_B^2 = \frac{1}{m}\sum_{i=1}^m (x^{(i)} - \mu_B)^2$$

Step 2 — 정규화:
$$\hat{x}^{(i)} = \frac{x^{(i)} - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$

Step 3 — 스케일 & 시프트 (학습 가능 파라미터 $\gamma, \beta$):
$$y^{(i)} = \gamma \odot \hat{x}^{(i)} + \beta$$

**BN의 정규화 효과**: BN은 미니배치 통계($\mu_B, \sigma_B^2$)를 사용하므로, 같은 샘플이라도 배치마다 다른 정규화를 적용받는다. 이는 **훈련 시 노이즈(stochastic regularization)**로 작용하여 Dropout과 유사한 효과를 낸다. 하지만 추론 시에는 전체 훈련 데이터의 이동 평균 통계를 사용하므로 노이즈가 없다.

**B-Q15 해설: MSE Loss 유도 (10점)**

완전 풀이:

**Step 1: Gaussian 모델 가정**

$$p(y \mid x, h) = \mathcal{N}(y;\ h(x),\ \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y - h(x))^2}{2\sigma^2}\right)$$

모델 $h(x)$가 $y$의 조건부 평균, $\sigma^2$가 고정된 분산이라고 가정한다.

**Step 2: i.i.d. 가정과 log-likelihood**

$n$개 샘플이 i.i.d.로 추출되었다고 가정:

$$\log P(E \mid H) = \sum_{i=1}^{n} \log \mathcal{N}(y_i;\ h(x_i),\ \sigma^2)$$

**Step 3: 로그 가우시안 전개**

$$\log \mathcal{N}(y_i;\ h(x_i),\ \sigma^2) = -\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - h(x_i))^2}{2\sigma^2}$$

합산하면:

$$\log P(E \mid H) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - h(x_i))^2$$

**Step 4: 상수 항 제거**

$h$에 대해 최적화할 때, $\sigma^2$를 고정하면 첫째 항 $-\frac{n}{2}\log(2\pi\sigma^2)$은 $h$에 무관한 상수이다. 따라서:

$$\arg\max_h \log P(E \mid H) = \arg\max_h \left[-\frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - h(x_i))^2\right]$$

**Step 5: 동치 변환**

$$= \arg\min_h \sum_{i=1}^n (y_i - h(x_i))^2 = \arg\min_h \frac{1}{n}\sum_{i=1}^n (y_i - h(x_i))^2$$

$$= \arg\min_h L_{MSE}$$

$$\boxed{\text{Gaussian 가정 하 MLE} \iff \text{MSE 최소화}}$$

자주 하는 실수: exp()가 사라지는 과정에서 $-1/(2\sigma^2)$ 계수를 누락. $\sigma^2$가 h에 대해 상수임을 명시하지 않음.

**B-Q16 해설: KL과 Cross-Entropy (10점)**

완전 풀이:

**(a) KL = CE - H 유도:**

$$KL(p \| q) = \mathbb{E}_p\left[\log\frac{p(X)}{q(X)}\right] = \mathbb{E}_p[\log p(X)] - \mathbb{E}_p[\log q(X)]$$

- $\mathbb{E}_p[\log p(X)] = -H(p)$ (엔트로피의 정의에서 음수)
- $-\mathbb{E}_p[\log q(X)] = CE(p, q)$ (교차 엔트로피의 정의)

따라서:

$$KL(p \| q) = -H(p) + CE(p, q) = CE(p, q) - H(p)$$

$$\boxed{KL(p_E \| p_\theta) = CE(p_E, p_\theta) - H(p_E)}$$

**(b) CE 최소화 = KL 최소화:**

$H(p_E)$는 $\theta$에 대해 **상수** (경험분포 $p_E$는 데이터에 의해 고정):

$$\arg\min_\theta KL(p_E \| p_\theta) = \arg\min_\theta [CE(p_E, p_\theta) - H(p_E)] = \arg\min_\theta CE(p_E, p_\theta)$$

**CE를 최소화하는 것은 KL divergence를 최소화하는 것과 동치.**

**(c) KL ≥ 0 증명 (Jensen's inequality):**

$\phi(t) = -\log t$는 볼록함수 (이계도함수 $1/t^2 > 0$). Jensen's inequality에 의해:

$$KL(p \| q) = \mathbb{E}_p\left[\log\frac{p(X)}{q(X)}\right] = \mathbb{E}_p[-\log\frac{q(X)}{p(X)}]$$

$$\geq -\log \mathbb{E}_p\left[\frac{q(X)}{p(X)}\right] = -\log \sum_x p(x) \cdot \frac{q(x)}{p(x)} = -\log \sum_x q(x) = -\log 1 = 0$$

등호는 $q(x)/p(x)$가 상수일 때, 즉 $p = q$일 때만 성립.

**(d) CE = H의 기하학적 의미:**

$CE(p_E, p_\theta) = H(p_E)$이면 KL = 0, 즉 $p_\theta = p_E$. 모델이 데이터의 참 분포를 완벽히 학습한 상태. 더 이상 개선 불가능한 최솟값. 실제로는 유한 데이터로 인해 $p_E$가 참 분포의 근사이므로, 이 상태에 도달해도 일반화 오차가 존재할 수 있다.

**B-Q17 해설: Softmax 미분 (10점)**

완전 풀이:

**(a) 편미분 유도:**

$$\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{S}, \quad S = \sum_k e^{z_k}$$

**Case 1: $i = j$** (분자가 $z_j$를 포함)

몫의 미분법 $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$:

$$\frac{\partial}{\partial z_j}\frac{e^{z_i}}{S} = \frac{e^{z_i} \cdot S - e^{z_i} \cdot e^{z_j}}{S^2} = \frac{e^{z_i}}{S} \cdot \frac{S - e^{z_j}}{S} = p_i(1 - p_j) = p_i(1-p_i)$$

**Case 2: $i \neq j$** (분자 $e^{z_i}$는 $z_j$에 대해 상수)

$$\frac{\partial}{\partial z_j}\frac{e^{z_i}}{S} = \frac{0 \cdot S - e^{z_i} \cdot e^{z_j}}{S^2} = -\frac{e^{z_i}}{S} \cdot \frac{e^{z_j}}{S} = -p_i p_j$$

**통합 표현** (Kronecker delta $\delta_{ij}$):

$$\boxed{\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)}$$

**(b) Softmax 야코비안:**

$(J)_{ij} = \frac{\partial p_i}{\partial z_j} = p_i\delta_{ij} - p_ip_j$

행렬 형태로:
$$J = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top$$

여기서 $(\text{diag}(\mathbf{p}))_{ij} = p_i\delta_{ij}$, $(\mathbf{p}\mathbf{p}^\top)_{ij} = p_ip_j$.

**(c) CE+Softmax의 결합 그래디언트:**

$L = -\log p_y = -\log \text{softmax}(\mathbf{z})_y = -z_y + \log S$

직접 미분하면:

$$\frac{\partial L}{\partial z_j} = -\mathbf{1}(j=y) + \frac{e^{z_j}}{S} = -\delta_{jy} + p_j$$

벡터 형태:

$$\boxed{\frac{\partial L}{\partial \mathbf{z}} = \mathbf{p} - \mathbf{e}_y}$$

**왜 "아름다운" 결과인가**: CE와 Softmax를 각각 따로 미분하면 복잡한 야코비안 행렬 곱이 필요하다. 그러나 합성 후 미분하면 단순히 (예측 확률 - 정답 one-hot 벡터)가 된다. 수치적으로도 안정하고(log와 exp를 별도로 계산하면 overflow 발생 가능), 구현도 단순하다. 딥러닝 프레임워크에서 이 두 레이어를 항상 묶어서 처리하는 이유이다.

자주 하는 실수: Case 1과 Case 2를 구분하지 않고 같은 공식을 적용하는 것. Kronecker delta를 Dirac delta와 혼동하는 것.

**B-Q18 해설: SVD와 저랭크 근사 (10점)**

$A = \begin{bmatrix}3&0\\4&0\\0&5\end{bmatrix}$

**(a)** $A^\top A = \begin{bmatrix}3&4&0\\0&0&5\end{bmatrix}\begin{bmatrix}3&0\\4&0\\0&5\end{bmatrix} = \begin{bmatrix}25&0\\0&25\end{bmatrix}$

고유값: $\lambda_1 = \lambda_2 = 25$? 잠깐, 다시 계산:

$A^\top A = \begin{bmatrix}3^2+4^2 & 0 \\ 0 & 5^2\end{bmatrix} = \begin{bmatrix}25 & 0 \\ 0 & 25\end{bmatrix}$

고유값 $\lambda_1 = 25, \lambda_2 = 25$이므로 특이값 $\sigma_1 = \sigma_2 = 5$.

사실 $A^\top A$는 대각행렬이므로 고유벡터는 표준기저: $v_1 = [1,0]^\top$, $v_2 = [0,1]^\top$.

**(b)-(c)** 좌특이벡터:

$u_1 = Av_1/\sigma_1 = [3,4,0]^\top / 5 = [3/5, 4/5, 0]^\top$

$u_2 = Av_2/\sigma_2 = [0,0,5]^\top / 5 = [0, 0, 1]^\top$

검증: $\|u_1\| = \sqrt{9/25+16/25} = \sqrt{25/25} = 1$ ✓, $\|u_2\| = 1$ ✓

**(d)** $A = U\Sigma V^\top$:

$$U = \begin{bmatrix}3/5&0\\4/5&0\\0&1\end{bmatrix}, \quad \Sigma = \begin{bmatrix}5&0\\0&5\\0&0\end{bmatrix}, \quad V = I_2$$

**(e)** $A_1 = \sigma_1 u_1 v_1^\top = 5 \cdot [3/5,4/5,0]^\top \cdot [1,0] = \begin{bmatrix}3&0\\4&0\\0&0\end{bmatrix}$

에너지 비율: $\sigma_1^2 / (\sigma_1^2 + \sigma_2^2) = 25/50 = 50\%$

**(f)** SVD와 PCA의 관계: 데이터 행렬 $A$의 열이 데이터 포인트라면, 오른쪽 특이벡터 $V$의 열들이 데이터의 **주성분 방향(principal component directions)**이다. 첫 번째 특이벡터 $v_1$은 데이터의 분산을 가장 많이 설명하는 방향이다. PCA를 SVD로 수행하는 것이 공분산 행렬 $A^\top A$의 고유분해를 직접 수행하는 것과 동치이다.

**B-Q19 해설: SGD부터 Adam까지 (10점)**

**(a)** 경사 하강법 업데이트: $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$
- $\eta$: 학습률 (스텝 크기)
- $\nabla L$: 손실 함수의 그래디언트 (최급강하 방향의 반대)

실제로 전체 데이터셋 기울기를 계산하는 것은 $n$이 클 때 계산 비용이 너무 크다. ($O(n)$ per step)

**(b)** SGD 장점: 계산이 빠르고 메모리 효율적. 잡음 있는 그래디언트가 정규화 효과를 낸다.
단점: 잡음 때문에 수렴이 불안정하고 학습률 선택이 민감하다.
국소 최솟값 탈출: 잡음이 "에너지 장벽"을 넘는 확률적 도약을 가능하게 한다.

**(c)** 모멘텀의 효과: 가파른 방향(고곡률)에서는 기울기가 부호 변동이 커서 상쇄되고, 완만한 방향(저곡률)에서는 기울기가 일관되어 누적된다. 즉, 곡률이 낮은 방향으로 "가속"하고 진동을 감소시킨다.

**(d)** Adam 설명:
- 편향 보정 이유: 초기에 $m_0 = v_0 = 0$이므로 $m_t$와 $v_t$가 실제 값보다 0에 가깝게 편향된다(과소추정). 편향 보정 $\hat{m}_t = m_t/(1-\beta_1^t)$가 초기 스텝에서 이를 보상한다.
- $v_t$의 역할: $v_t$는 그래디언트의 **2차 모멘트(분산)의 추정값**이다. $\sqrt{v_t}$로 나누면 각 파라미터의 학습률이 그래디언트의 크기에 따라 적응적으로 조정된다. 자주 업데이트되는 파라미터(큰 그래디언트)는 학습률이 작아지고, 드물게 업데이트되는 파라미터는 학습률이 커진다.
- 유효 스텝 크기: $\hat{m}_t/(\sqrt{\hat{v}_t}+\epsilon) \approx \text{sign}(g_t)$에 가까워진다. 즉, 곡률이 높은 방향과 낮은 방향에서 스텝 크기를 자동으로 조절하는 효과 (헤시안의 대각 근사).

**(e)** 편향-분산 분석:
훈련 정확도 95%, 테스트 정확도 70% → 일반화 갭 25%는 **과적합(high variance)** 신호이다.

Dropout(p=0.5): 훈련 시 무작위로 뉴런의 50%를 끄므로, 각 미니배치마다 다른 부분 네트워크를 학습한다. 이는 앙상블 효과를 만들어 분산을 줄인다. Inverted dropout으로 추론 시 스케일 조정 ($\times 1/(1-p)$).

L2 정규화: 가중치 크기를 제약하여 모델 복잡도를 낮춘다 → 분산 감소. $\lambda = 10^{-4}$는 보통 합리적인 값이지만, 데이터 스케일에 따라 조정이 필요하다.

결론: 두 기법 모두 과적합(high variance)을 줄이는 방향으로 작동하므로 제안은 타당하다. 단, 정규화가 너무 강하면 편향이 증가할 수 있으므로 검증 세트로 $\lambda$와 Dropout 비율을 조정해야 한다.

## 시험 전 최종 체크리스트

### 반드시 완벽히 재현할 수 있어야 하는 유도 7개

1. **CE Loss ← MLE (Categorical)**: i.i.d. → 결합우도 → log → 음수 → CE
2. **MSE Loss ← MLE (Gaussian)**: i.i.d. → 결합우도 → log → 전개 → 제곱항만 남음
3. **MAP = MLE + Prior → L2 정규화**: 베이즈 정리 → log 분해 → Gaussian Prior → λ‖θ‖²
4. **KL = CE - H**: 정의 전개 → 분리 → 각항 식별
5. **Softmax 미분**: i=j / i≠j 케이스 분리 → Kronecker delta → 야코비안
6. **CE+Softmax 결합 그래디언트**: 직접 미분 → p - e_y
7. **2층 역전파**: 순전파 정의 → ∂L/∂W₁ → ∂L/∂x₁ → ∂L/∂W₀ → ReLU 미분

### 핵심 수식 암기표

| 이름 | 수식 |
|------|------|
| CE Loss | $L = -\frac{1}{n}\sum_i e_{y_i}^\top \log h(x_i)$ |
| MSE Loss | $L = \frac{1}{n}\sum_i (y_i - h(x_i))^2$ |
| KL Divergence | $KL(p\|q) = \mathbb{E}_p[\log p/q]$ |
| Softmax | $p_i = e^{z_i}/\sum_k e^{z_k}$ |
| Softmax 미분 | $\partial p_i/\partial z_j = p_i(\delta_{ij}-p_j)$ |
| CE+Softmax 그래디언트 | $\partial L/\partial z = p - e_y$ |
| 역전파 기본 패턴 | $\partial L/\partial W = (\partial L/\partial z) \cdot x^\top$ |
| BN Forward | $\hat{x} = (x-\mu_B)/\sqrt{\sigma_B^2+\epsilon}$, $y=\gamma\hat{x}+\beta$ |
| Adam | $\theta \leftarrow \theta - \eta\hat{m}/(\sqrt{\hat{v}}+\epsilon)$ |
| Ridge 해 | $w^* = (X^\top X + \lambda I)^{-1}X^\top y$ |
