# 딥러닝 중간고사 용어 사전 v2 — 완전 체화 버전

> **v1과 다른 점**: 읽기만 해서는 내 것이 안 된다. v2는 **직접 해보고, 두 가지 비유로 교차 확인하고, 오해 포인트를 짚고, 의존 관계를 보여주는** 버전이다.
>
> **학습 방법**: 각 용어를 (1) 일상 비유로 감 잡기 → (2) 숫자 예시로 직접 해보기 → (3) 백엔드 비유로 재확인 → (4) "직접 해보기" 문제 풀기 → (5) 한 문장 카드로 압축

---

# 용어 의존성 맵 (이 순서대로 읽어야 함)

```
[변수/함수] → [벡터/행렬] → [내적/노름] → [선형변환]
                                    ↓
[확률] → [조건부확률] → [베이즈정리] → [MLE] → [MAP]
    ↓                                    ↓        ↓
[기댓값/분산] → [가우시안분포]          [NLL]    [Prior=정규화]
                    ↓                    ↓
               [CLT] → [가우시안 노이즈 가정] → [MSE Loss]
                                                     ↓
[시그마(Σ)] → [로그] → [교차 엔트로피] → [KL] → [CE Loss]
                                                     ↓
[미분] → [편미분] → [체인룰] → [역전파] → [경사하강법]
                        ↓
               [Jacobian] → [Softmax 미분]
```

**규칙: 화살표 왼쪽을 모르면 오른쪽은 이해 불가. 막히면 왼쪽으로 돌아가라.**

## 1-1. Generalization (일반화)

**선수 지식**: 없음 (첫 번째로 읽을 것)

### 한 문장 카드 (시험 직전용)
> "훈련 데이터가 아닌 **처음 보는 데이터**에서도 잘 작동하는 능력. 이것이 모델 평가의 유일한 진짜 기준."

### 일상 비유
요리사가 레시피 10개를 완벽하게 외웠다. 그런데 레시피에 없는 재료가 들어오면 아무것도 못 만든다. 이 요리사는 "외웠을 뿐 요리를 이해한 게 아니다." 반면, 요리의 **원리**를 이해한 요리사는 새로운 재료가 와도 적절한 요리를 만든다. 후자가 **일반화가 된 것**이다.

### 백엔드 비유
- 테스트 환경에서 잘 돌아간다 = 훈련 에러 낮음
- 프로덕션에서도 잘 돌아간다 = **일반화 좋음**
- 테스트는 통과하는데 프로덕션에서 죽는다 = **과적합 (일반화 실패)**

### 숫자로 직접 보기

```
모델 A: 훈련 정확도 99%, 테스트 정확도 97% → Gap = 2% (좋음)
모델 B: 훈련 정확도 99%, 테스트 정확도 60% → Gap = 39% (과적합!)
모델 C: 훈련 정확도 70%, 테스트 정확도 68% → Gap = 2% (좋지만 둘 다 낮음 = 과소적합)
```

핵심: Gap이 작으면서 테스트 정확도가 높은 것이 최고.

### 직접 해보기
> Q: 모델 X의 훈련 정확도 95%, 테스트 정확도 55%이다. 진단하라.
> <details><summary>답</summary>Generalization Gap = 40%. 심한 과적합. 정규화 추가, 데이터 증강, 모델 단순화 필요.</details>

### 오해하기 쉬운 포인트
- "훈련 정확도 99%니까 좋은 모델이다" → **아니다.** 테스트 정확도가 핵심.
- "과소적합과 과적합 중 뭐가 더 나쁜가?" → 둘 다 나쁘지만, 과적합이 더 교활하다 (겉으로는 잘하는 것처럼 보이니까).

## 1-2. MLE vs MAP

**선수 지식**: 확률 기본 개념, 조건부 확률

### 한 문장 카드
> "MLE = 증거만 보고 판단. MAP = 증거 + 경험을 합쳐 판단. 딥러닝의 loss + regularization = MAP."

### 일상 비유: 의사의 진단

환자가 기침을 한다.

**MLE 의사** (증거만): "기침 → 감기다." 데이터(증상)만 봄.

**MAP 의사** (증거 + 경험):
- "기침 → 감기일 수도 있지만..."
- "이 환자는 30년간 하루 2갑 흡연자다" (prior = 사전 지식)
- "폐 검사부터 하자"

MLE 의사는 **대부분** 맞겠지만, 중요한 케이스에서 놓친다.
MAP 의사는 **사전 지식**을 반영해서 더 현명한 판단을 한다.

### 백엔드 비유: 장애 원인 분석

로그에 DB 타임아웃이 3번 찍혔다.

- **MLE**: "DB가 원인" (로그만 봄)
- **MAP**: "DB는 5년간 무사고. 최근 네트워크 공사 있었음. 네트워크가 더 의심" (이력 반영)

### 숫자로 직접 보기: 동전 문제

동전을 3번 던져서 3번 다 앞면.

```python
# MLE: 데이터만 봄
θ_MLE = 앞면 수 / 총 수 = 3/3 = 1.0
# "이 동전은 100% 앞면만 나온다" ← 말이 안 됨!

# MAP (Prior: "동전은 대체로 공정하다" = Beta(2,2))
θ_MAP = (3 + 2 - 1) / (3 + 2 + 2 - 2) = 4/5 = 0.8
# "앞면 확률이 높지만, 100%까지는 아니다" ← 합리적
```

**MLE의 한계가 보이는가?** 데이터가 3개뿐인데 "100%"라고 결론짓는 것은 비합리적이다. MAP는 "동전은 대체로 공정하다"는 상식(prior)을 더해서 극단을 완화한다.

### 직접 해보기
> Q: 동전 10번 던져 7번 앞면. Uniform prior에서 MAP는? Beta(2,2) prior에서 MAP는?
> <details><summary>답</summary>Uniform: MAP = MLE = 7/10 = 0.7. Beta(2,2): MAP = (7+1)/(10+2) = 8/12 = 2/3 ≈ 0.667. Prior가 0.5 방향으로 끌어당김.</details>

### 오해하기 쉬운 포인트
- "MAP가 항상 MLE보다 좋다" → **아니다.** 데이터가 충분하면 MAP ≈ MLE. Prior가 잘못되면 MAP가 오히려 나쁨.
- "Prior는 어디서 오는가?" → 도메인 지식, 이전 실험, 또는 "모델이 단순할수록 좋다"는 Occam's razor 같은 일반 원칙.

### 딥러닝에서의 핵심 연결

```
MAP = MLE + Prior

딥러닝으로 번역하면:
MAP        =  Loss(데이터 적합)     + Regularization(모델 제약)
           =  CE 또는 MSE          + λ||θ||²

Loss = NLL = -log p(D|θ)    ← MLE 부분
Reg  = -log p(θ)            ← Prior 부분
```

이 연결이 이 강의의 **가장 중요한 메시지**다. 교수님이 "이 흐름을 다 이해해야 한다"고 강조한 것.

## 1-3. Overparameterized (과매개변수화) & Double Descent

**선수 지식**: Generalization, 과적합/과소적합

### 한 문장 카드
> "파라미터가 데이터보다 많은데 잘 작동한다. 중간 크기가 가장 위험하고, 넉넉하게 크면 오히려 안정."

### 일상 비유: 팀 규모

프로젝트에 사람을 배치한다고 하자:
- **2명** (너무 적음): 일을 못 감당 → 과소적합
- **5명** (딱 맞음): 일은 되는데 한 명이라도 빠지면 전체가 흔들림 → **interpolation threshold** (가장 불안정!)
- **20명** (넉넉함): 여유 있어서 누가 빠져도 커버 가능 → 오히려 안정 → 과매개변수화 영역

```
테스트 에러
  │
  │ ╲           ╱╲
  │   ╲       ╱    ╲
  │     ╲   ╱        ╲_________ ← 넉넉하면 안정
  │       ╲╱
  │        ↑
  │   여기가 최악! (딱 맞는 크기)
  └────────────────────────── 모델 크기
```

### 직접 해보기
> Q: GPT-3는 1750억 파라미터, 학습 데이터는 수백억 토큰이다. 이것은 과매개변수화인가? 왜 일반화가 되는가?
> <details><summary>답</summary>파라미터 > 데이터이므로 과매개변수화. SGD가 최소 노름 해(가장 단순한 해)를 자동 선택하는 implicit regularization 덕분에 일반화됨.</details>

## 2-1. 벡터(Vector) / 내적(Inner Product) / 노름(Norm)

**선수 지식**: 사칙연산, 좌표 개념

### 한 문장 카드
> "벡터 = 숫자 리스트. 내적 = 같은 위치 곱해서 더하기 = 유사도. 노름 = 리스트의 크기."

### 일상 비유: 학생의 성적표

학생 A의 성적: [수학 90, 영어 80, 과학 70] ← **이게 벡터**
학생 B의 성적: [수학 85, 영어 85, 과학 75]

**내적** = 두 학생이 "비슷한 패턴인지":
```
90×85 + 80×85 + 70×75 = 7650 + 6800 + 5250 = 19700
```
값이 클수록 → 비슷한 패턴 (둘 다 수학>영어>과학)

**노름** = 한 학생의 "전체적인 점수 크기":
```
||A|| = √(90² + 80² + 70²) = √(8100+6400+4900) = √19400 ≈ 139.3
```

### 백엔드 비유

```python
# 벡터 = 서버 메트릭 스냅샷
server_a = [cpu_80, mem_60, disk_30, net_45]
server_b = [cpu_75, mem_55, disk_35, net_50]

# 내적 = 두 서버의 부하 패턴이 비슷한가?
dot = 80*75 + 60*55 + 30*35 + 45*50 = 12600

# 노름 = 이 서버의 전체적 부하 크기
norm_a = sqrt(80² + 60² + 30² + 45²) ≈ 113.7
```

### 숫자로 직접 보기: 왜 내적이 유사도인가

```
A = [1, 0]   (오른쪽만 가리킴)
B = [1, 0]   (같은 방향!)
C = [0, 1]   (위를 가리킴 — 직각)
D = [-1, 0]  (반대 방향!)

A·B = 1×1 + 0×0 = 1    ← 양수! 같은 방향
A·C = 1×0 + 0×1 = 0    ← 0! 무관 (직각)
A·D = 1×(-1) + 0×0 = -1 ← 음수! 반대 방향
```

```
양수: 같은 방향 → 유사
  0: 직각 → 무관
음수: 반대 방향 → 반대
```

### 직접 해보기
> Q1: a = [3, 4]의 L2 노름은?
> <details><summary>답</summary>√(9+16) = √25 = 5. 3-4-5 직각삼각형!</details>

> Q2: a = [1, 2, 3]과 b = [4, 5, 6]의 내적은?
> <details><summary>답</summary>1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32</details>

> Q3: 코사인 유사도가 0이면 무엇을 의미하는가?
> <details><summary>답</summary>두 벡터가 직교(수직). 서로 아무 관련이 없다.</details>

### 오해하기 쉬운 포인트
- "내적이 크면 항상 유사하다" → **아니다.** 벡터 크기가 크면 내적도 커진다. **코사인 유사도**(크기로 나눈 것)를 써야 순수한 방향 비교.
- "노름이 뭐가 여러 개야?" → L1(절대값 합), L2(직선 거리), L∞(최대값) 등 재는 방법이 여러 개. 정규화에서 L1은 0을 만들고, L2는 골고루 줄인다.

### 딥러닝에서 이게 왜 중요한가
1. **뉴런 하나의 연산 = 내적**. 가중치 벡터와 입력 벡터의 내적이 "이 입력이 이 패턴과 얼마나 맞는지".
2. **Attention의 Query·Key = 내적**. "이 단어가 저 단어와 얼마나 관련 있는지".
3. **L2 정규화 = 가중치 벡터의 노름 제한**. "가중치를 작게 유지해라".

## 2-2. 행렬(Matrix) / 선형변환(Linear Transformation)

**선수 지식**: 벡터, 함수 개념

### 한 문장 카드
> "행렬 = 벡터를 다른 벡터로 바꾸는 변환기. 신경망의 한 층 = 행렬 곱 + 편향 + 활성화."

### 일상 비유: 번역기

영어 → 한국어 번역기를 생각해 보자:
- 입력: 영어 문장 (벡터)
- 변환 규칙: 번역 사전 (**행렬**)
- 출력: 한국어 문장 (다른 벡터)

행렬은 "입력을 받아서 규칙에 따라 출력을 만드는 변환기"다.

### 숫자로 직접 보기

```
행렬 W = [[2, 0],    입력 x = [3]
          [0, 3]]           [2]

출력 = W × x = [2×3 + 0×2] = [6]    ← x축을 2배, y축을 3배 늘림
               [0×3 + 3×2]   [6]
```

이것이 **선형변환**이다. 입력 [3, 2]를 [6, 6]으로 바꿨다.

### 신경망과의 연결

```python
# 신경망 한 층의 본질
output = activation(W @ input + bias)
#        ^^^^^^^^^^  ^^^^^^^^   ^^^^
#        비선형성     행렬 곱    편향
#                    (선형변환)
```

활성화 함수가 없으면 아무리 많은 층을 쌓아도 하나의 행렬 곱과 같다:
```
W3 × (W2 × (W1 × x)) = (W3 × W2 × W1) × x = W_total × x
```
→ **비선형 활성화 함수가 있어야 깊이가 의미 있다.**

### 직접 해보기
> Q: W = [[1, 2], [3, 4]], x = [1, 0]. W×x는?
> <details><summary>답</summary>[1×1 + 2×0, 3×1 + 4×0] = [1, 3]. 행렬의 첫 번째 열이 추출됨!</details>

## 2-3. 고유값(Eigenvalue) / 고유벡터(Eigenvector)

**선수 지식**: 행렬, 선형변환

### 한 문장 카드
> "행렬이 변환해도 방향이 안 바뀌는 특별한 벡터가 고유벡터. 그때 크기가 몇 배 되는지가 고유값."

### 일상 비유: 바람에 흔들리는 나무

강풍(= 행렬 변환)이 불 때:
- 대부분의 가지는 방향이 바뀜 (일반 벡터)
- 하지만 바람 방향과 **정확히 같은 방향**의 가지는 방향은 안 바뀌고 **크기만** 변함 (고유벡터)
- 얼마나 휘었는지가 **고유값**

### 숫자로 직접 보기

```
A = [[2, 1],    v = [1]
     [0, 3]]        [0]

A × v = [2×1 + 1×0] = [2] = 2 × [1]
        [0×1 + 3×0]   [0]       [0]

→ 방향은 [1, 0] 그대로! 크기만 2배!
→ v = [1, 0]은 고유벡터, λ = 2는 고유값
```

### 딥러닝에서 왜 중요한가
1. **PCA**: 데이터 공분산 행렬의 고유벡터 = 데이터가 가장 많이 퍼진 방향. 고유값이 큰 방향만 남기면 = 차원 축소.
2. **Hessian의 고유값**: loss surface가 얼마나 급한지. 고유값 크면 = 그 방향으로 loss 급변 = sharp minimum.
3. **RNN의 gradient**: 가중치 행렬의 최대 고유값 > 1이면 gradient 폭발, < 1이면 소실.

### 직접 해보기
> Q: A = [[3, 0], [0, 5]]. 고유값과 고유벡터는?
> <details><summary>답</summary>대각행렬이므로 자명: λ₁=3, v₁=[1,0]; λ₂=5, v₂=[0,1]. 각 축 방향이 고유벡터, 대각 원소가 고유값.</details>

## 2-4. SVD (특이값 분해)

**선수 지식**: 행렬, 고유값

### 한 문장 카드
> "아무 행렬이든 '회전 → 늘리기 → 회전' 세 단계로 분해. 특이값이 큰 것만 남기면 = 압축/노이즈 제거."

### 일상 비유: 사진 압축

100만 픽셀 사진이 있다. SVD로 분해하면:
- 특이값 상위 10개만 남기면 → 사진이 **흐릿하지만** 형태는 보임 (10% 저장 공간)
- 상위 100개 → 거의 원본과 같음 (30% 저장 공간)
- 전체 → 완벽한 원본 (100% 저장 공간)

**큰 특이값 = 중요한 정보, 작은 특이값 = 노이즈.**

### 딥러닝에서의 응용: LoRA

GPT를 내 데이터에 맞추려면 수십억 파라미터를 다 바꿔야 할까?

LoRA: "가중치 변화량은 사실 저랭크다" → $\Delta W = B \times A$ ($B$: d×r, $A$: r×d, $r \ll d$)

```
원래: d² = 4096² = 16,777,216개 파라미터 학습
LoRA (r=8): 2 × 4096 × 8 = 65,536개만 학습 (0.4%!)
```

SVD 아이디어: 대부분의 변화는 소수의 방향에 집중 → 전체를 다 건드릴 필요 없다.

### 직접 해보기
> Q: 행렬의 특이값이 [100, 50, 2, 0.1, 0.01]이면, 랭크-2 근사의 정보 보존율은 대략?
> <details><summary>답</summary>||A||²_F = 100²+50²+2²+0.1²+0.01² = 12504. 상위2: 10000+2500=12500. 보존율 ≈ 99.97%. 거의 정보 손실 없이 랭크 2로 압축 가능!</details>

# CH03. 미적분과 최적화

## 3-1. 미분 / 편미분 / 그래디언트

**선수 지식**: 함수, 변수 개념

### 한 문장 카드
> "미분 = 입력을 살짝 바꾸면 출력이 얼마나 변하는지. 그래디언트 = 모든 편미분을 모은 벡터 = 가장 가파른 방향."

### 일상 비유: 산에서 눈 감고 내려가기

산 정상에 서 있다. 눈을 감았다.
- **미분** = 한 발을 특정 방향으로 내밀었을 때 경사가 얼마나 급한지
- **편미분** = 동쪽으로만 움직였을 때 경사 (남북은 고정)
- **그래디언트** = "어느 방향이 가장 가파른지" 알려주는 화살표

### 숫자로 직접 보기

```
f(x) = x²

x = 3일 때: f(3) = 9
x = 3.01일 때: f(3.01) = 9.0601

변화율 = (9.0601 - 9) / (3.01 - 3) = 0.0601 / 0.01 = 6.01 ≈ 6

정확한 미분: f'(x) = 2x → f'(3) = 6  ✓
```

"x = 3에서 x를 1만큼 키우면 f는 대략 6만큼 커진다."

### 편미분 — 여러 설정 중 하나만 바꿀 때

```
f(x, y) = x² + 3xy

∂f/∂x = 2x + 3y   (y는 상수 취급)
∂f/∂y = 3x         (x는 상수 취급)

(x, y) = (1, 2)에서:
∂f/∂x = 2 + 6 = 8   → "x를 1 늘리면 f가 ~8 증가"
∂f/∂y = 3           → "y를 1 늘리면 f가 ~3 증가"

그래디언트 = [8, 3] → "x 방향이 더 가파르다"
```

### 딥러닝 연결
- 가중치를 조금 바꾸면 loss가 얼마나 변하는가? = **가중치에 대한 loss의 편미분**
- 모든 가중치에 대해 이걸 한꺼번에 구하면 = **그래디언트**
- 그래디언트의 반대 방향으로 가면 loss가 줄어든다 = **경사 하강법**

### 직접 해보기
> Q: f(x) = 3x³의 도함수는? x=2에서 값은?
> <details><summary>답</summary>f'(x) = 9x². f'(2) = 36. "x=2에서 x를 1 늘리면 f가 약 36 증가."</details>

## 3-2. 체인 룰(Chain Rule) = 역전파의 핵심

**선수 지식**: 미분

### 한 문장 카드
> "합성 함수의 미분 = 각 단계의 미분을 곱하기. 역전파는 이 곱셈을 뒤에서 앞으로 전파하는 것."

### 일상 비유: 도미노 효과

```
A가 쓰러지면 → B가 30% 확률로 쓰러짐 → C가 50% 확률로 쓰러짐
A → C의 영향 = 0.3 × 0.5 = 0.15 (15%)
```

체인 룰도 같다: 전체 영향 = 각 단계 영향의 **곱**.

### 숫자로 직접 보기

```
y = (3x + 1)²
x = 2일 때 dy/dx = ?

체인룰: 바깥 미분 × 안쪽 미분
  u = 3x + 1 → du/dx = 3
  y = u² → dy/du = 2u = 2(3×2+1) = 14

dy/dx = dy/du × du/dx = 14 × 3 = 42
```

### 역전파 연결

```
x → [W₁곱] → [ReLU] → [W₂곱] → [Loss]

∂Loss/∂W₁ = ∂Loss/∂출력 × ∂출력/∂중간 × ∂중간/∂W₁
            = 각 단계의 미분을 뒤에서 앞으로 곱하기
```

이것이 **역전파(Backpropagation)**의 전부다. 체인 룰을 뒤에서 앞으로 적용하는 것.

### 직접 해보기
> Q: f(x) = sin(x²). df/dx를 체인룰로 구하라.
> <details><summary>답</summary>u = x², f = sin(u). df/du = cos(u) = cos(x²). du/dx = 2x. df/dx = cos(x²) × 2x = 2x·cos(x²).</details>

## 4-1. 조건부 확률 / 베이즈 정리

**선수 지식**: 확률 기본 (0~1, 합=1)

### 한 문장 카드
> "P(A|B) = B가 일어났을 때 A의 확률. 베이즈 = 이걸 뒤집는 공식: P(원인|결과)를 P(결과|원인)에서 구한다."

### 일상 비유: 비가 올 때 우산

- P(우산 | 비) = 0.9 → 비가 오면 90%가 우산을 가져옴 (관찰하기 쉬움)
- P(비 | 우산) = ? → 우산을 들고 있는 사람을 봤을 때, 실제로 비가 올 확률? (이걸 알고 싶음)

**베이즈 정리가 바로 이 "뒤집기"를 해준다.**

### 숫자로 직접 보기: 의료 진단

```
질병 유병률: P(질병) = 0.001 (1000명 중 1명)
검사 정확도: P(양성|질병) = 0.99, P(양성|건강) = 0.01

양성 나왔을 때 실제 질병 확률은?

P(질병|양성) = P(양성|질병) × P(질병) / P(양성)
            = 0.99 × 0.001 / (0.99×0.001 + 0.01×0.999)
            = 0.00099 / 0.01098
            ≈ 9%

99% 정확도 검사인데 실제는 9%??
→ Prior(유병률)가 극히 낮아서 대부분 거짓 양성!
```

**이것이 Prior의 힘이다.** 데이터(양성)만 보면 "질병이다"지만, prior(유병률 0.1%)를 고려하면 "아닐 가능성이 훨씬 높다."

### 딥러닝 연결

$$p(\theta|D) = \frac{p(D|\theta) \cdot p(\theta)}{p(D)}$$

- $p(\theta|D)$ = 데이터를 본 후 모델에 대한 믿음 → **MAP**
- $p(D|\theta)$ = 이 모델이 맞다면 데이터가 나올 확률 → **Likelihood (→ Loss)**
- $p(\theta)$ = 모델에 대한 사전 믿음 → **Prior (→ Regularization)**

### 직접 해보기
> Q: 위 의료 예에서 1차 양성(9%) 후 2차 검사도 양성이면 확률은?
> <details><summary>답</summary>새 prior = 0.09. P(양성) = 0.99×0.09 + 0.01×0.91 = 0.0981. P(질병|양성₂) = 0.99×0.09/0.0981 ≈ 91%. 증거 누적의 힘!</details>

## 4-2. 가우시안(정규) 분포

**선수 지식**: 확률, 기댓값/분산

### 한 문장 카드
> "종 모양 곡선. 평균(μ)과 분산(σ²)으로 완전히 결정. 자연에서 가장 흔한 분포. 왜? CLT 때문."

### 일상 비유

100명의 키를 재면:
- 평균(170cm) 근처에 가장 많이 모여있고
- 평균에서 멀어질수록 급격히 줄어들고
- 좌우 대칭

이 종 모양이 **가우시안 분포**다.

### 왜 가우시안을 가정하는가? — CLT

```
노이즈 = 측정 오차 + 날씨 영향 + 센서 오차 + 수십 가지 미지 요인의 합

중심극한정리(CLT): 독립적인 요인 여러 개를 더하면 → 가우시안에 수렴!

→ 그래서 "노이즈는 가우시안이다"가 합리적인 가정
→ 가우시안 가정에서 NLL을 최소화하면 → MSE가 나옴!
```

이것이 교수님이 강조한 체인: **CLT → 가우시안 → NLL → MSE**

### 직접 해보기
> Q: 가우시안 PDF에 -log를 취하면 무엇이 나오는가?
> <details><summary>답</summary>$-\log\exp(-\frac{(y-μ)^2}{2σ^2}) = \frac{(y-μ)^2}{2σ^2}$. **제곱 오차**가 나온다! 이것이 "가우시안 → MSE"의 수학적 핵심.</details>

## 5-1. Entropy / Cross-Entropy / KL Divergence

**선수 지식**: 확률 분포, 로그

### 한 문장 카드
> "Entropy = 불확실성. CE = 잘못된 모델의 비용. KL = 두 분포의 차이. CE 최소화 = KL 최소화 = 모델을 데이터에 가깝게."

### 일상 비유: 택배 포장

**Entropy**: 상품 종류가 다양할수록 포장 방법이 복잡 = 불확실성 높음 = 엔트로피 높음.
- 쇼핑몰이 양말 1종류만 팜: 포장 간단 → 엔트로피 낮음
- 쇼핑몰이 1만 종류 팜: 포장 복잡 → 엔트로피 높음

**Cross-Entropy**: 내 포장 시스템이 현실에 얼마나 안 맞는지.
- 양말 가게인데 TV용 큰 박스만 준비해둠 → 낭비 = CE 높음
- 양말 크기 박스 준비 → 효율적 = CE 낮음

**KL Divergence**: 내 포장 시스템과 최적 시스템의 **차이**.
- KL = CE - Entropy = 낭비량 - 최소 비용 = **순수한 비효율**

### 핵심 관계 (숫자로)

```
P = [0.25, 0.25, 0.25, 0.25]  (균등, 실제 분포)
Q = [0.5, 0.25, 0.125, 0.125]  (모델 분포)

H(P) = -4 × 0.25 × log₂(0.25) = 2 bits (최소 비용)
H(P,Q) = -(0.25×log₂0.5 + 0.25×log₂0.25 + 0.25×log₂0.125 + 0.25×log₂0.125)
       = 2.25 bits (내 모델의 비용)
KL = 2.25 - 2 = 0.25 bits (순수한 낭비)
```

### 딥러닝에서의 핵심

```
학습 목표: CE(데이터분포, 모델분포)를 최소화
        = KL(데이터, 모델) + H(데이터) 최소화
        = KL 최소화 (H(데이터)는 상수)
        = 모델을 데이터에 최대한 가깝게
```

### 직접 해보기
> Q: P = (1, 0, 0)일 때 H(P)는? 이것은 어떤 상태를 의미하는가?
> <details><summary>답</summary>H = -1×log1 - 0 - 0 = 0 bits. 불확실성 제로 = 결과가 확정적. 원-핫 분포.</details>

## 6-1. 활성화 함수 (ReLU / Sigmoid / Softmax)

**선수 지식**: 함수, 미분

### 한 문장 카드
> "활성화 없으면 아무리 깊어도 직선. ReLU: max(0,x)로 비선형. Sigmoid: 0~1로 압축. Softmax: 확률 분포로 변환."

### 일상 비유

**활성화 없는 신경망** = 직선 자(ruler)로만 그림 그리기. 아무리 긴 자를 이어도 곡선은 못 그림.

**활성화 있는 신경망** = 자유 곡선 도구. 자를 꺾을 수 있게 해주는 것이 활성화 함수.

| 함수 | 하는 일 | 비유 | 쓰는 곳 |
|------|---------|------|---------|
| ReLU | 음수→0, 양수→그대로 | 일방통행 문 | 은닉층 (기본값) |

| Softmax | 벡터→확률 분포 (합=1) | 투표 결과 비율화 | 다중 분류 출력 |

### 숫자로 보기

```python
ReLU(5) = 5       ReLU(-3) = 0      ReLU(0) = 0
Sigmoid(0) = 0.5  Sigmoid(5) ≈ 0.99  Sigmoid(-5) ≈ 0.01
Softmax([2, 1, 0]) = [0.67, 0.24, 0.09]  # 합 = 1.0
```

## 9-1. Bias-Variance Tradeoff / Flat vs Sharp Minima

**선수 지식**: 일반화, 과적합

### 한 문장 카드
> "단순하면 편향 높고, 복잡하면 분산 높다. 넓고 평평한 최솟값(flat minimum)이 좁고 뾰족한 것(sharp)보다 일반화에 좋다."

### 일상 비유: 시험 공부

- **Bias 높음** (과소적합): 교과서 1장만 읽고 시험. 내용이 부족.
- **Variance 높음** (과적합): 기출문제 답을 통째로 외움. 같은 문제는 완벽하지만 숫자만 바뀌면 못 풀음.
- **적정**: 원리를 이해하고 다양한 문제를 풀어봄.

### Flat vs Sharp: 설정의 안정성

- **Flat minimum**: 서버 설정이 조금 바뀌어도 서비스 안정. "여유 있는 최적."
- **Sharp minimum**: 설정이 조금만 바뀌어도 서비스 불안정. "아슬아슬한 최적."

프로덕션에서는 항상 약간의 변동이 있으므로, flat이 더 좋다.

## 10-1. Attention / Transformer

**선수 지식**: 행렬 곱, 내적, 소프트맥스

### 한 문장 카드
> "Attention = Query로 Key를 검색해서 관련 Value를 가져오는 것. DB 쿼리와 같은 원리. Transformer = Attention만으로 만든 모델."

### 백엔드 비유: DB 쿼리

```sql
SELECT value FROM data WHERE key LIKE '%query%'
```

- **Query**: "나는 뭘 찾고 있나"
- **Key**: 각 데이터가 "나는 이런 정보야"라고 태그한 것
- **Value**: 실제 데이터

```python
# Attention 핵심 (의사코드)
scores = query @ keys.T / sqrt(d_k)  # 유사도 계산 (내적!)
weights = softmax(scores)            # 확률로 변환
output = weights @ values            # 가중 평균으로 정보 수집
```

### 왜 sqrt(d_k)로 나누는가?

```
d_k = 512이면 내적의 분산 = 512 (매우 큼)
→ softmax 입력이 극단적 → one-hot에 가까워짐 → gradient ≈ 0

sqrt(512)로 나누면 분산 = 1로 정규화 → softmax가 적절히 작동
```

### 직접 해보기
> Q: Q = [[1,0]], K = [[1,0],[0,1]], V = [[10],[20]]. Attention 출력은? (d_k=2)

# 부록: 자주 헷갈리는 용어 쌍 (v2 확장)

| 쌍 | 차이 | 함정 |
|-----|------|------|
| Parameter vs Hyperparameter | Parameter=모델이 학습 (가중치). Hyper=사람이 설정 (lr, λ) | "학습률도 학습되나요?" → 일반적으로 아니다 (하지만 meta-learning에서는 가능) |
| Epoch vs Iteration vs Batch | Epoch=전체 1회. Batch=한 묶음. Iteration=배치 1개 처리 | Epoch 100 = 전체 데이터를 100번 봤다 |
| Training vs Validation vs Test | Train=학습. Valid=튜닝(모의고사). Test=최종(실제시험, 1번만) | "Validation으로 모델 골랐으면 Test는 그 모델로 1번만" |
| Bias(편향) vs bias(편향항 b) | B-V의 Bias=모델 단순함 에러. 신경망 bias=절편 | 문맥에 따라 의미 다름! |
| Normalization vs Regularization | Normalization=데이터 정규화(BatchNorm). Regularization=과적합 방지(L2) | 이름이 비슷해서 혼동. 목적이 다르다 |
| Convolution vs Cross-Correlation | 수학 Conv=커널 뒤집기. CNN의 "Conv"=실제로는 Cross-Correlation | 학습하므로 실질 차이 없음 |
| MLE vs MAP | MLE=데이터만. MAP=데이터+Prior | Uniform prior면 MAP=MLE |
| CE vs MSE | CE=분류. MSE=회귀 | CE는 가우시안 가정에서 안 나옴, MSE는 카테고리컬에서 안 나옴 |
| Loss vs Objective vs Cost | 전부 "최소화할 함수"라는 뜻. 문맥에 따라 혼용 | 보통 같은 뜻 |
| Forward vs Backward | Forward=입력→출력 계산. Backward=출력→입력 방향으로 gradient 전파 | "역전파"는 미분을 뒤에서 앞으로 하는 것 |

# 시험 직전 속성 복습 카드 (30초 복습)

```
1. Generalization = 안 본 데이터 성능 = 진짜 실력
2. MLE = 데이터만, MAP = 데이터 + Prior
3. MAP = Loss + Regularization
4. CLT → 가우시안 → NLL → MSE
5. Categorical → NLL → CE Loss
6. KL = CE - Entropy. CE 최소화 = KL 최소화
7. 내적 = 유사도. 뉴런 = 내적. Attention = 내적
8. 미분 = 변화율. 그래디언트 = 가장 가파른 방향
9. 체인룰 = 각 단계 미분의 곱 = 역전파의 수학
10. Sigmoid max 미분 = 1/4 → 10층이면 (1/4)^10 → vanishing gradient
11. ReLU 양수 미분 = 1 → gradient 살아있음
12. SVD: A = UΣV^T. 큰 특이값 = 중요. 작은 것 버리면 = 압축
13. Softmax Jacobian: i=j → p(1-p), i≠j → -p_i·p_j
14. Inductive bias: Linear > CNN > MLP > Transformer
15. 적은 데이터 → 강한 bias(CNN), 많은 데이터 → 약한 bias(Transformer)
```
