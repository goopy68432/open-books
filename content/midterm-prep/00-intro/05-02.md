## 1. 벡터 (Vectors)

### 입문 (Beginner)

**비유**: 벡터는 "화살표"이자 "숫자 리스트"이다.

- **기하학적 관점**: 공간에서 방향과 크기를 가진 화살표
- **대수적 관점**: 숫자들의 순서 있는 목록 $\mathbf{v} = (v_1, v_2, \ldots, v_n)^T$

딥러닝에서 벡터는 어디에나 등장한다:
- 이미지의 한 픽셀 행 = 벡터
- 단어 임베딩 = 벡터 (예: "왕" = [0.2, -0.5, 0.8, ...])
- 뉴런의 입력 = 벡터
- 기울기(gradient) = 벡터

**내적(Dot Product)의 직관**: 두 벡터가 얼마나 "같은 방향"을 가리키는지를 측정한다.
- 같은 방향: 내적 > 0
- 수직: 내적 = 0
- 반대 방향: 내적 < 0

### 중급 (Intermediate)

**벡터 공간(Vector Space)** $V$: 덧셈과 스칼라 곱에 대해 닫혀 있는 집합.

8개 공리 만족:
1. 결합법칙, 교환법칙 (덧셈)
2. 영벡터 존재
3. 역원 존재
4. 스칼라 곱 결합법칙, 분배법칙, 항등원

**노름(Norm)**: 벡터의 "크기"를 측정하는 함수.

| 노름 | 정의 | 특징 |
|------|------|------|
| $L^1$ (Manhattan) | $\|\mathbf{x}\|_1 = \sum_i \|x_i\|$ | 희소성 유도 (Lasso 정규화) |
| $L^2$ (Euclidean) | $\|\mathbf{x}\|_2 = \sqrt{\sum_i x_i^2}$ | 가장 일반적, 미분 가능 |
| $L^\infty$ (Max) | $\|\mathbf{x}\|_\infty = \max_i \|x_i\|$ | 최대 원소 크기 |
| $L^p$ (일반) | $\|\mathbf{x}\|_p = \left(\sum_i \|x_i\|^p\right)^{1/p}$ | $p \geq 1$에서 노름 |

**내적(Inner Product)**:

$$\langle \mathbf{u}, \mathbf{v} \rangle = \mathbf{u}^T \mathbf{v} = \sum_{i=1}^{n} u_i v_i = \|\mathbf{u}\| \|\mathbf{v}\| \cos\theta$$

**코사인 유사도**: 방향만 비교할 때 사용

$$\text{cos\_sim}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u}^T \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$$

단어 임베딩에서 의미적 유사성을 측정할 때 핵심적으로 사용된다.

### 고급 (Advanced)

**함수 공간에서의 벡터**: 함수도 벡터 공간의 원소가 될 수 있다.

힐베르트 공간 $L^2([a,b])$에서의 내적:

$$\langle f, g \rangle = \int_a^b f(x) g(x) \, dx$$

이 관점에서 푸리에 변환은 직교 기저 $\{e^{i n \omega t}\}$로의 좌표 변환이다.

**커널 트릭과의 연결**: 커널 함수 $k(\mathbf{x}, \mathbf{y}) = \langle \phi(\mathbf{x}), \phi(\mathbf{y}) \rangle_{\mathcal{H}}$는 고차원 특성 공간에서의 내적을 명시적 매핑 없이 계산한다.

$$k(\mathbf{x}, \mathbf{y}) = (\mathbf{x}^T \mathbf{y} + c)^d \quad \text{(다항식 커널)}$$

$$k(\mathbf{x}, \mathbf{y}) = \exp\left(-\frac{\|\mathbf{x} - \mathbf{y}\|^2}{2\sigma^2}\right) \quad \text{(RBF 커널)}$$

## 2. 행렬 (Matrices)

### 입문 (Beginner)

**비유**: 행렬은 "변환 기계"이다. 벡터를 넣으면 다른 벡터가 나온다.

예를 들어, 2D 회전 행렬:
$$R = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

이 행렬에 벡터를 곱하면 그 벡터가 $\theta$만큼 회전한다.

**딥러닝에서의 행렬**:
- 가중치 행렬 $W$: 입력 벡터를 다른 공간으로 변환
- 배치 데이터: 각 행이 하나의 데이터 포인트인 행렬
- 이미지: 2D 행렬 (또는 채널을 포함한 3D 텐서)

### 중급 (Intermediate)

**특수 행렬의 종류와 성질**:

| 행렬 | 조건 | 성질 |
|------|------|------|
| 대칭 (Symmetric) | $A = A^T$ | 고유값이 모두 실수 |
| 직교 (Orthogonal) | $A^T A = I$ | 길이와 각도를 보존 |
| 양정치 (Positive Definite) | $\mathbf{x}^T A \mathbf{x} > 0, \forall \mathbf{x} \neq 0$ | 고유값이 모두 양수 |
| 대각 (Diagonal) | $a_{ij} = 0$ for $i \neq j$ | 각 축을 독립적으로 스케일링 |
| 상삼각/하삼각 | 대각선 위/아래만 비영 | 연립방정식의 효율적 풀이 |
| 에르미트 (Hermitian) | $A = A^*$ (복소수) | 대칭 행렬의 복소수 일반화 |

**행렬 곱셈의 해석**:

$C = AB$에서 $C_{ij} = \sum_k A_{ik} B_{kj}$

네 가지 관점:
1. **내적 관점**: $C_{ij}$ = $A$의 $i$행과 $B$의 $j$열의 내적
2. **열 관점**: $C$의 $j$열 = $A$의 열들의 선형 결합 (계수: $B$의 $j$열)
3. **행 관점**: $C$의 $i$행 = $B$의 행들의 선형 결합 (계수: $A$의 $i$행)
4. **외적 관점**: $C = \sum_k \mathbf{a}_k \mathbf{b}_k^T$ (랭크-1 행렬들의 합)

**딥러닝 응용 예제 - 완전 연결층(Fully Connected Layer)**:

$$\mathbf{y} = W\mathbf{x} + \mathbf{b}$$

$W \in \mathbb{R}^{m \times n}$: $n$차원 입력을 $m$차원 출력으로 변환.

배치 처리: 입력 $X \in \mathbb{R}^{B \times n}$ (B: 배치 크기)

$$Y = XW^T + \mathbf{1}\mathbf{b}^T$$

### 고급 (Advanced)

**행렬의 미분 (Matrix Calculus)**:

스칼라를 벡터로 미분 (기울기):
$$\frac{\partial f}{\partial \mathbf{x}} = \begin{pmatrix} \frac{\partial f}{\partial x_1} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{pmatrix}$$

중요한 항등식:

| 함수 $f$ | $\frac{\partial f}{\partial \mathbf{x}}$ |
|----------|----------------------------------------|
| $\mathbf{a}^T \mathbf{x}$ | $\mathbf{a}$ |
| $\mathbf{x}^T A \mathbf{x}$ | $(A + A^T)\mathbf{x}$ |
| $\mathbf{x}^T \mathbf{x}$ | $2\mathbf{x}$ |
| $\|A\mathbf{x} - \mathbf{b}\|^2$ | $2A^T(A\mathbf{x} - \mathbf{b})$ |

스칼라를 행렬로 미분:
$$\left(\frac{\partial f}{\partial W}\right)_{ij} = \frac{\partial f}{\partial W_{ij}}$$

**Trace 트릭**: 스칼라 함수를 trace로 표현하면 행렬 미분이 편리하다.

$$f = \text{tr}(A^T B) \implies \frac{\partial f}{\partial A} = B$$

딥러닝에서 손실 함수의 기울기를 유도할 때 자주 사용:

$$\mathcal{L} = \|Y - XW\|_F^2 = \text{tr}((Y - XW)^T(Y - XW))$$

$$\frac{\partial \mathcal{L}}{\partial W} = -2X^T(Y - XW) = 2X^T X W - 2X^T Y$$

최적해(정규방정식): $\hat{W} = (X^T X)^{-1} X^T Y$

## 3. 선형변환 (Linear Transformations)

### 입문 (Beginner)

**비유**: 선형변환은 "고무판 위의 격자를 변형하는 것"과 같다. 단, 규칙이 있다:
- 직선은 직선으로 유지된다 (곡선으로 변하지 않음)
- 원점은 움직이지 않는다
- 평행한 선들은 평행을 유지한다

**예시**: 회전, 확대/축소, 기울이기(shear), 반사 → 모두 선형변환

비선형인 것: 이동(translation), 구부리기 → 선형변환이 아님

> 참고: $f(\mathbf{x}) = W\mathbf{x} + \mathbf{b}$에서 $\mathbf{b} \neq 0$이면 "아핀 변환(affine transformation)"이다. 엄밀히는 선형이 아니지만, 딥러닝에서는 관례적으로 "선형 층(linear layer)"이라 부른다.

### 중급 (Intermediate)

**정의**: $T: V \to W$가 선형변환이면:

$$T(\alpha \mathbf{u} + \beta \mathbf{v}) = \alpha T(\mathbf{u}) + \beta T(\mathbf{v})$$

**행렬 표현**: 유한 차원 벡터 공간에서 모든 선형변환은 행렬로 표현 가능:

$$T(\mathbf{x}) = A\mathbf{x}$$

여기서 $A$의 $j$번째 열은 $T(\mathbf{e}_j)$이다 ($\mathbf{e}_j$: $j$번째 표준 기저 벡터).

**딥러닝에서의 해석**: 가중치 행렬 $W$는 입력 공간에서 출력 공간으로의 선형변환이다. 활성화 함수 $\sigma$가 비선형성을 추가한다.

만약 활성화 함수가 없다면:

$$f(\mathbf{x}) = W_L \cdots W_2 W_1 \mathbf{x} = \tilde{W}\mathbf{x}$$

이는 단일 선형변환과 동일하므로, 깊이를 아무리 쌓아도 표현력이 증가하지 않는다. 이것이 **비선형 활성화 함수가 필수적인 이유**이다.

### 고급 (Advanced)

**선형변환의 기하학적 분류 (2D 기준)**:

행렬 $A$의 행렬식과 고유값에 따라:

| $\det(A)$ | 고유값 | 변환 유형 |
|-----------|--------|-----------|
| $> 0$ | 양의 실수 | 확대/축소 |
| $= 1$, $A^T A = I$ | $\|$고유값$\| = 1$ | 회전 |
| $< 0$ | 하나가 음수 | 반사 포함 |
| $= 0$ | 하나가 0 | 차원 축소 (사영) |

**선형변환의 합성 = 행렬의 곱**:

$$T_2 \circ T_1 \leftrightarrow A_2 \cdot A_1$$

이것이 딥러닝에서 층을 쌓는 것이 행렬 곱을 쌓는 것인 이유이다.

## 4. 랭크 (Rank)와 영공간 (Null Space)

### 입문 (Beginner)

**랭크의 직관**: 행렬이 "실질적으로 사용하는 차원의 수"이다.

비유: 3명이 의견을 내는데, A는 항상 B와 같은 말을 한다면, 실질적으로 독립적인 의견은 2개뿐이다. 이 행렬의 "랭크"는 2이다.

**영공간의 직관**: 행렬에 곱했을 때 0이 되는 벡터들의 집합이다. 즉, 변환 과정에서 "사라지는" 방향들이다.

### 중급 (Intermediate)

**정의**:

- **랭크(Rank)**: 행렬의 선형 독립인 열(또는 행)의 최대 수

$$\text{rank}(A) = \dim(\text{Col}(A)) = \dim(\text{Row}(A))$$

- **영공간(Null Space / Kernel)**: $A\mathbf{x} = \mathbf{0}$의 해 집합

$$\text{Null}(A) = \{\mathbf{x} \in \mathbb{R}^n : A\mathbf{x} = \mathbf{0}\}$$

- **영도(Nullity)**: $\text{nullity}(A) = \dim(\text{Null}(A))$

**랭크-영도 정리 (Rank-Nullity Theorem)**:

$$\text{rank}(A) + \text{nullity}(A) = n$$

여기서 $n$은 열의 수 (= 정의역의 차원).

**해석**: 입력 공간의 차원 = 보존되는 차원(rank) + 소멸되는 차원(nullity)

**worked example**:

$$A = \begin{pmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \end{pmatrix}$$

2행 = 2 x 1행이므로 $\text{rank}(A) = 1$.

$A\mathbf{x} = \mathbf{0}$: $x_1 + 2x_2 + 3x_3 = 0$

자유 변수 2개 ($x_2, x_3$):

$$\text{Null}(A) = \text{span}\left\{\begin{pmatrix}-2\\1\\0\end{pmatrix}, \begin{pmatrix}-3\\0\\1\end{pmatrix}\right\}$$

$\text{nullity}(A) = 2$. 검증: $\text{rank} + \text{nullity} = 1 + 2 = 3 = n$. $\checkmark$

### 고급 (Advanced)

**Low-Rank Approximation과 딥러닝**:

LoRA (Low-Rank Adaptation, Hu et al., 2021): 대규모 언어모델 미세조정 시, 가중치 업데이트를 저랭크 행렬로 제한:

$$W = W_0 + \Delta W = W_0 + BA$$

여기서 $B \in \mathbb{R}^{d \times r}$, $A \in \mathbb{R}^{r \times k}$, $r \ll \min(d, k)$.

파라미터 수: $dk$ 대신 $r(d+k)$로 대폭 감소.

**행렬 랭크와 정보 보존**: $\text{rank}(A) < n$이면 $A$에 의한 선형변환은 정보를 손실한다 (비가역). 딥러닝에서 bottleneck 층(차원 축소)은 의도적으로 랭크를 낮춰 핵심 정보만 보존하는 것이다 (오토인코더의 원리).

## 5. 고유값과 고유벡터 (Eigenvalues & Eigenvectors)

### 입문 (Beginner)

**비유**: 지진이 나면 건물이 흔들리는데, 특정 방향으로는 더 많이 흔들리고 다른 방향으로는 덜 흔들린다. 이 "특별한 방향"이 고유벡터이고, 그 방향으로 얼마나 늘어나거나 줄어드는지가 고유값이다.

**핵심**: 행렬 $A$에 의해 **방향이 바뀌지 않고** 크기만 변하는 특별한 벡터가 고유벡터이다.

$$A\mathbf{v} = \lambda \mathbf{v}$$

$\mathbf{v}$: 고유벡터 (방향), $\lambda$: 고유값 (배율)

### 중급 (Intermediate)

**고유값 분해 (Eigendecomposition)**:

$n \times n$ 행렬 $A$가 $n$개의 선형 독립인 고유벡터를 가지면:

$$A = V \Lambda V^{-1}$$

여기서:
- $V = [\mathbf{v}_1 | \mathbf{v}_2 | \cdots | \mathbf{v}_n]$: 고유벡터 행렬
- $\Lambda = \text{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$: 고유값 대각 행렬

**대칭 행렬의 스펙트럴 정리 (Spectral Theorem)**:

실수 대칭 행렬 $A = A^T$이면:
1. 모든 고유값이 실수
2. 고유벡터들이 직교: $V^T V = I$, 즉 $V^{-1} = V^T$
3. $A = V \Lambda V^T = \sum_{i=1}^{n} \lambda_i \mathbf{v}_i \mathbf{v}_i^T$

**고유값 계산**:

$$A\mathbf{v} = \lambda \mathbf{v} \iff (A - \lambda I)\mathbf{v} = \mathbf{0}$$

비자명해가 존재하려면: $\det(A - \lambda I) = 0$ (특성 방정식)

**worked example**:

$$A = \begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}$$

특성 방정식:

$$\det \begin{pmatrix} 4-\lambda & 1 \\ 2 & 3-\lambda \end{pmatrix} = (4-\lambda)(3-\lambda) - 2 = \lambda^2 - 7\lambda + 10 = 0$$

$$\lambda_1 = 5, \quad \lambda_2 = 2$$

$\lambda_1 = 5$일 때: $(A - 5I)\mathbf{v} = \mathbf{0}$

$$\begin{pmatrix} -1 & 1 \\ 2 & -2 \end{pmatrix}\mathbf{v} = \mathbf{0} \implies \mathbf{v}_1 = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$$

$\lambda_2 = 2$일 때:

$$\begin{pmatrix} 2 & 1 \\ 2 & 1 \end{pmatrix}\mathbf{v} = \mathbf{0} \implies \mathbf{v}_2 = \begin{pmatrix} 1 \\ -2 \end{pmatrix}$$

### 고급 (Advanced)

**딥러닝에서의 고유값 분석**:

1. **Hessian 행렬의 고유값 분석**: 손실 함수의 곡률(curvature)을 이해하는 데 사용

$$H_{ij} = \frac{\partial^2 \mathcal{L}}{\partial \theta_i \partial \theta_j}$$

- 모든 고유값 > 0: 극소점 (local minimum)
- 음의 고유값 존재: 안장점 (saddle point)
- Sadasivan et al.: 고차원에서 안장점이 극소점보다 훨씬 흔하다

2. **가중치 행렬의 스펙트럼 분석**: 네트워크 안정성과 학습 역학(dynamics) 분석

$$\rho(W) = \max_i |\lambda_i(W)|$$

스펙트럴 반경 $\rho(W) > 1$이면 RNN에서 기울기가 폭발하고, $\rho(W) < 1$이면 소실한다.

3. **그래프 신경망 (GNN)**: 인접 행렬의 고유값 = 그래프의 주파수. 그래프 푸리에 변환에서 직접 사용.

**행렬 거듭제곱과 고유분해**:

$$A^k = V \Lambda^k V^{-1}$$

이것이 RNN에서 시간 $t$이 지남에 따라 은닉 상태가 어떻게 변하는지를 설명한다:

$$\mathbf{h}_t = W^t \mathbf{h}_0 = V \Lambda^t V^{-1} \mathbf{h}_0$$

$|\lambda_i| > 1$인 고유값 방향으로는 지수적 폭발, $|\lambda_i| < 1$인 방향으로는 지수적 소실.

## 6. 특이값 분해 (Singular Value Decomposition, SVD)

### 입문 (Beginner)

**비유**: 모든 선형변환(행렬)은 세 단계로 분해할 수 있다:
1. **회전** (또는 반사)
2. **축 방향 늘이기/줄이기**
3. **다시 회전** (또는 반사)

이것이 SVD이다. 어떤 행렬이든, 아무리 복잡해 보여도, 이 세 단계로 나눌 수 있다.

**고유값 분해와의 차이**: 고유분해는 정방 행렬에만 적용되지만, SVD는 **모든 행렬** (직사각형 포함)에 적용 가능하다.

### 중급 (Intermediate)

**SVD 정의**: 임의의 $m \times n$ 행렬 $A$에 대해:

$$A = U \Sigma V^T$$

| 행렬 | 크기 | 성질 | 의미 |
|------|------|------|------|
| $U$ | $m \times m$ | 직교 행렬 ($U^T U = I$) | 출력 공간의 직교 기저 (좌특이벡터) |
| $\Sigma$ | $m \times n$ | 대각 행렬 (비음) | 특이값 $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$ |
| $V$ | $n \times n$ | 직교 행렬 ($V^T V = I$) | 입력 공간의 직교 기저 (우특이벡터) |

**Compact (경제) SVD**: $r = \text{rank}(A)$일 때:

$$A = U_r \Sigma_r V_r^T$$

$U_r \in \mathbb{R}^{m \times r}$, $\Sigma_r \in \mathbb{R}^{r \times r}$, $V_r \in \mathbb{R}^{n \times r}$

**SVD와 고유분해의 관계**:

$$A^T A = V \Sigma^T U^T U \Sigma V^T = V (\Sigma^T \Sigma) V^T$$
$$A A^T = U (\Sigma \Sigma^T) U^T$$

즉:
- $V$의 열: $A^T A$의 고유벡터
- $U$의 열: $A A^T$의 고유벡터
- $\sigma_i = \sqrt{\lambda_i(A^T A)}$

**저랭크 근사 (Low-Rank Approximation)**:

**Eckart-Young 정리**: 랭크-$k$ 근사 중 프로베니우스 노름을 최소화하는 것은:

$$A_k = \sum_{i=1}^{k} \sigma_i \mathbf{u}_i \mathbf{v}_i^T = U_k \Sigma_k V_k^T$$

$$\min_{\text{rank}(B)=k} \|A - B\|_F = \|A - A_k\|_F = \sqrt{\sum_{i=k+1}^{r} \sigma_i^2}$$

### 고급 (Advanced)

**SVD의 딥러닝 응용**:

1. **추천 시스템 (Collaborative Filtering)**:

사용자-아이템 행렬 $R \in \mathbb{R}^{m \times n}$ (대부분 결측값)을 SVD로 분해:

$$R \approx U_k \Sigma_k V_k^T$$

사용자 $i$의 아이템 $j$에 대한 예측 평점: $\hat{r}_{ij} = \mathbf{u}_i^T \Sigma_k \mathbf{v}_j$

Netflix Prize (2006-2009)에서 SVD 기반 방법이 핵심 역할을 했다.

2. **이미지 압축**:

$m \times n$ 이미지를 랭크-$k$ 근사로 압축:
- 원본 저장 공간: $mn$
- 압축 저장 공간: $k(m + n + 1)$
- $k \ll \min(m,n)$이면 대폭 압축

3. **가중치 행렬 압축**: 훈련된 네트워크의 가중치 행렬을 SVD로 분해하여 모델 경량화.

$W \approx U_k \Sigma_k V_k^T$로 하나의 FC 층을 두 개의 작은 층으로 대체.

**Truncated SVD의 계산**:

전체 SVD는 $O(\min(mn^2, m^2 n))$이지만, 상위 $k$개 특이값/벡터만 필요하면 반복 알고리즘(Lanczos, randomized SVD)으로 $O(mnk)$에 계산 가능.

**SVD와 4가지 기본 부분공간**:

$A = U\Sigma V^T$에서:
- 열공간 (Column Space): $U$의 처음 $r$개 열의 span
- 영공간 (Null Space): $V$의 나머지 $n-r$개 열의 span
- 행공간 (Row Space): $V$의 처음 $r$개 열의 span
- 좌영공간 (Left Null Space): $U$의 나머지 $m-r$개 열의 span

이 4개 부분공간은 직교 관계를 이루며, $\mathbb{R}^n = \text{Row}(A) \oplus \text{Null}(A)$, $\mathbb{R}^m = \text{Col}(A) \oplus \text{Null}(A^T)$.

## 7. 유사역행렬 (Pseudoinverse / Moore-Penrose Inverse)

### 입문 (Beginner)

**문제 상황**: $A\mathbf{x} = \mathbf{b}$를 풀고 싶은데:
- $A$가 정방이 아니면? (방정식 수 $\neq$ 미지수 수)
- $A$가 역행렬이 없으면?

**유사역행렬** $A^+$는 이런 경우에도 "최선의 답"을 제공한다:

$$\mathbf{x}^* = A^+ \mathbf{b}$$

"최선의 답"이란: $\|A\mathbf{x} - \mathbf{b}\|$를 최소화하는 $\mathbf{x}$ 중 $\|\mathbf{x}\|$가 가장 작은 것.

### 중급 (Intermediate)

**SVD를 이용한 유사역행렬 계산**:

$A = U \Sigma V^T$이면:

$$A^+ = V \Sigma^+ U^T$$

여기서 $\Sigma^+$는 $\Sigma$의 비영 대각 원소를 역수로 바꾸고 전치한 것:

$$\Sigma = \text{diag}(\sigma_1, \ldots, \sigma_r, 0, \ldots, 0) \implies \Sigma^+ = \text{diag}(1/\sigma_1, \ldots, 1/\sigma_r, 0, \ldots, 0)^T$$

**세 가지 경우**:

| 조건 | 해의 성질 | $A^+\mathbf{b}$ |
|------|----------|------------------|
| $m = n$, full rank | 유일한 정확한 해 | $A^{-1}\mathbf{b}$ |
| $m > n$ (overdetermined) | 최소제곱 해 | $(A^T A)^{-1} A^T \mathbf{b}$ |
| $m < n$ (underdetermined) | 최소 노름 해 | $A^T(A A^T)^{-1} \mathbf{b}$ |

**worked example** (최소제곱):

$$A = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}, \quad \mathbf{b} = \begin{pmatrix} 1 \\ 2 \\ 4 \end{pmatrix}$$

$A^T A = 14$, $A^T \mathbf{b} = 17$

$$x^* = (A^T A)^{-1} A^T \mathbf{b} = \frac{17}{14} \approx 1.214$$

### 고급 (Advanced)

**딥러닝과의 연결**:

1. **선형 회귀의 닫힌 형태 해**: $\hat{\mathbf{w}} = X^+ \mathbf{y}$

2. **과적합과 유사역행렬**: 과매개변수화된 네트워크에서 SGD로 찾는 해는 최소 노름 해에 가깝다는 연구 결과가 있다 (implicit regularization).

3. **수치 안정성**: 특이값이 매우 작으면 $1/\sigma_i$가 폭발한다. 실제로는 Tikhonov 정규화를 사용:

$$A^+_\alpha = V \text{diag}\left(\frac{\sigma_i}{\sigma_i^2 + \alpha}\right) U^T$$

이는 Ridge 회귀와 동치: $\hat{\mathbf{w}} = (X^T X + \alpha I)^{-1} X^T \mathbf{y}$

## 8. 행렬 미적분 기초 (Matrix Calculus Basics)

### 입문 (Beginner)

**왜 필요한가?**: 딥러닝의 학습 = 손실 함수의 기울기 계산 + 경사 하강법. 입력과 출력이 벡터/행렬이면, 미분도 벡터/행렬이 된다.

**기울기(Gradient)의 직관**: 각 가중치를 살짝 바꿨을 때 손실이 얼마나 변하는지를 나타낸다. 기울기의 방향은 손실이 가장 빠르게 증가하는 방향이다.

### 중급 (Intermediate)

**야코비안 행렬 (Jacobian Matrix)**:

벡터 함수 $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$의 야코비안:

$$J = \frac{\partial \mathbf{f}}{\partial \mathbf{x}} = \begin{pmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{pmatrix} \in \mathbb{R}^{m \times n}$$

**역전파에서의 야코비안**:

$\mathbf{y} = f(\mathbf{x})$이고 스칼라 손실 $\mathcal{L}$이 있을 때:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{x}} = J^T \frac{\partial \mathcal{L}}{\partial \mathbf{y}}$$

이것이 벡터-야코비안 곱(VJP)이며, 역전파의 핵심 연산이다.

**중요한 미분 규칙**:

1. Softmax의 야코비안: $\mathbf{p} = \text{softmax}(\mathbf{z})$

$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$$

$$J = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T$$

2. Cross-entropy loss + Softmax의 결합 기울기:

$$\frac{\partial \mathcal{L}}{\partial \mathbf{z}} = \mathbf{p} - \mathbf{y}$$

이 간결한 결과가 역전파 구현을 크게 단순화한다.

### 고급 (Advanced)

**헤시안 (Hessian)과 2차 최적화**:

$$H = \nabla^2 \mathcal{L} = \frac{\partial^2 \mathcal{L}}{\partial \theta \partial \theta^T} \in \mathbb{R}^{p \times p}$$

뉴턴 방법: $\theta_{t+1} = \theta_t - H^{-1} \nabla \mathcal{L}$

문제: $p$가 수백만이면 $H$는 $p \times p$ 행렬로 저장/역행렬 불가능.

근사 방법:
- **L-BFGS**: 제한된 메모리로 $H^{-1}$을 근사
- **Fisher Information Matrix**: $F = \mathbb{E}[\nabla \log p \cdot (\nabla \log p)^T]$로 $H$를 근사 → Natural Gradient
- **Kronecker-Factored (K-FAC)**: $F \approx A \otimes B$로 크로네커 곱 구조를 이용한 효율적 근사

**텐서 미적분**: 딥러닝에서 입력이 텐서(3D 이상)일 때는 아인슈타인 합산 표기법이 유용하다:

$$C_{ij} = \sum_k A_{ik} B_{kj} \quad \longrightarrow \quad C_{ij} = A_{ik} B_{kj}$$

PyTorch의 `torch.einsum`이 이를 구현한다.

## 9. PCA (Principal Component Analysis)

### 입문 (Beginner)

**비유**: 사진을 찍을 때 가장 정보가 많은 각도를 찾는 것과 같다.

100개의 특성을 가진 데이터가 있을 때, 모든 특성이 똑같이 중요하지는 않다. PCA는 데이터의 분산(변동)이 가장 큰 방향을 찾아, 핵심 정보를 유지하면서 차원을 줄인다.

**예시**: 키와 몸무게를 동시에 측정하면 둘은 강하게 상관된다. PCA를 적용하면:
- PC1: "체격" (키와 몸무게가 함께 증가하는 방향) → 분산의 대부분 설명
- PC2: "체형" (키 대비 몸무게 비율) → 나머지 분산 설명

### 중급 (Intermediate)

**PCA 알고리즘**:

1. 데이터 중심화: $\tilde{X} = X - \bar{X}$
2. 공분산 행렬 계산: $C = \frac{1}{n-1} \tilde{X}^T \tilde{X}$
3. 고유값 분해: $C = V \Lambda V^T$
4. 상위 $k$개 고유벡터 선택: $V_k = [\mathbf{v}_1 | \cdots | \mathbf{v}_k]$
5. 차원 축소: $Z = \tilde{X} V_k \in \mathbb{R}^{n \times k}$

**최적성**: PCA는 다음 최적화 문제의 해이다:

$$\mathbf{v}_1 = \arg\max_{\|\mathbf{v}\|=1} \text{Var}(\tilde{X}\mathbf{v}) = \arg\max_{\|\mathbf{v}\|=1} \mathbf{v}^T C \mathbf{v}$$

라그랑주 승수법으로 풀면:

$$C\mathbf{v} = \lambda \mathbf{v}$$

즉, 분산을 최대화하는 방향 = 공분산 행렬의 고유벡터!

**설명 분산 비율 (Explained Variance Ratio)**:

$$\text{EVR}_k = \frac{\lambda_k}{\sum_{i=1}^{d} \lambda_i}$$

$$\text{Cumulative EVR} = \frac{\sum_{i=1}^{k} \lambda_i}{\sum_{i=1}^{d} \lambda_i}$$

보통 누적 EVR이 95% 이상이 되도록 $k$를 선택한다.

**SVD를 이용한 PCA**: 공분산 행렬을 명시적으로 계산하지 않고 SVD로 직접 수행:

$\tilde{X} = U \Sigma V^T$이면:

$$C = \frac{1}{n-1}\tilde{X}^T \tilde{X} = V \frac{\Sigma^2}{n-1} V^T$$

따라서 $V$의 열이 주성분이고, $\lambda_i = \sigma_i^2 / (n-1)$.

이 방법이 수치적으로 더 안정적이다.

### 고급 (Advanced)

**Kernel PCA**: 비선형 차원 축소

데이터가 선형적으로 분리되지 않을 때, 커널 트릭을 사용:

$$K_{ij} = k(\mathbf{x}_i, \mathbf{x}_j) = \langle \phi(\mathbf{x}_i), \phi(\mathbf{x}_j) \rangle$$

커널 행렬 $K$의 고유값 분해로 비선형 주성분을 얻는다.

**Probabilistic PCA (PPCA)**:

생성 모델 관점에서의 PCA:

$$\mathbf{z} \sim \mathcal{N}(\mathbf{0}, I_k)$$
$$\mathbf{x} = W\mathbf{z} + \boldsymbol{\mu} + \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \sigma^2 I)$$

ML 추정 결과: $\hat{W} = V_k (\Lambda_k - \sigma^2 I)^{1/2} R$, 여기서 $R$은 임의의 회전 행렬.

$\sigma^2 \to 0$이면 표준 PCA로 수렴한다.

PPCA의 장점: 결측값 처리 가능, 베이지안 확장 가능, 생성 모델로서 새 데이터 생성 가능.

**오토인코더와 PCA의 관계**:

선형 활성화 함수를 가진 단일 은닉층 오토인코더:

$$\hat{\mathbf{x}} = W_2 (W_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2$$

이 네트워크를 MSE 손실로 학습하면, $W_1$의 행공간이 PCA의 주성분 부분공간과 일치한다.

비선형 활성화를 추가하면 비선형 차원 축소가 되어, Kernel PCA의 일반화로 볼 수 있다.

**t-SNE, UMAP과의 비교**:

| 방법 | 선형/비선형 | 보존하는 구조 | 계산 복잡도 | 역변환 |
|------|-----------|-------------|------------|--------|
| PCA | 선형 | 전역 분산 | $O(d^2 n)$ | 가능 |
| t-SNE | 비선형 | 지역 이웃 | $O(n^2)$~$O(n \log n)$ | 불가 |
| UMAP | 비선형 | 지역+전역 | $O(n^{1.14})$ | 가능 (근사) |
| Autoencoder | 비선형 | 학습 가능 | 학습 필요 | 디코더 |

## 10. 종합 연결: 선형대수가 딥러닝에서 작동하는 방식

**한 눈에 보는 연결 구조**:

```
입력 데이터 (벡터/텐서)
    │
    ▼
가중치 행렬 (선형변환) ←── 랭크 = 표현 용량
    │                         │
    ▼                    SVD로 압축 가능 (LoRA, pruning)
활성화 함수 (비선형성)
    │
    ▼
손실 함수 (스칼라)
    │
    ▼
역전파 (야코비안, 연쇄 법칙) ←── 행렬 미적분
    │
    ▼
기울기 (벡터) → 파라미터 업데이트
    │
    ├── Hessian (고유값) → 곡률, 학습률 결정
    └── Fisher 정보 행렬 → 자연 경사법
```

**데이터 전처리**: PCA로 차원 축소 / 백색화(whitening) → 학습 가속

**모델 분석**: 가중치 행렬의 SVD → 네트워크가 학습한 특징 분석

**모델 압축**: 저랭크 근사 → 추론 속도 향상

## 11. 흔한 오해 정리

| 오해 | 사실 |
|------|------|
| "고유값은 모든 행렬에 적용된다" | 고유값 분해는 정방 행렬에만 가능. 직사각형 행렬에는 SVD를 사용 |
| "PCA는 비지도 학습이 아니다" | PCA는 레이블 없이 데이터의 분산만으로 작동하는 대표적 비지도 학습 |
| "행렬 곱은 교환법칙이 성립한다" | $AB \neq BA$ (일반적). 크기가 다르면 아예 정의도 안 됨 |
| "역행렬은 항상 존재한다" | $\det(A) = 0$ (특이행렬)이면 역행렬 불존재. 이때 유사역행렬 사용 |
| "SVD와 고유분해는 같다" | 대칭 양반정치 행렬에서만 동일. 일반적으로 특이값 $\neq$ 고유값 |
| "차원 축소는 정보 손실이다" | 랭크가 낮은 데이터는 정보 손실 없이 차원 축소 가능 |
