# 07. 머신러닝 기초 (Machine Learning Fundamentals) - 추가자료

---

## 입문 (Beginner)

### 머신러닝이란 무엇인가?

머신러닝은 **데이터로부터 패턴을 학습**하여 새로운 데이터에 대해 예측하는 알고리즘을 연구하는 분야이다. Tom Mitchell의 정의에 따르면:

> "어떤 작업(T)에 대해 경험(E)으로부터 학습하여 성능 측정(P)이 향상되면, 그 프로그램은 학습했다고 말한다."

**일상적 비유**: 아이가 동물 사진을 보면서 "이건 고양이야", "이건 강아지야"라고 부모에게 배우는 과정과 같다. 충분히 많은 예시를 본 후, 처음 보는 동물 사진도 분류할 수 있게 된다.

---

### 머신러닝의 세 가지 패러다임

#### 1. 지도학습 (Supervised Learning)

**비유**: 정답지가 있는 시험 문제를 풀면서 공부하는 것.

- 입력 $x$와 정답 레이블 $y$의 쌍 $(x, y)$으로 구성된 데이터셋으로 학습
- 목표: 새로운 입력 $x'$에 대해 올바른 $y'$를 예측하는 함수 $f$ 학습

**예시**:
- 분류(Classification): 이메일이 스팸인지 아닌지 판별
- 회귀(Regression): 집의 크기로 가격 예측

#### 2. 비지도학습 (Unsupervised Learning)

**비유**: 정답 없이 비슷한 것끼리 모아보는 것.

- 레이블 없이 입력 $x$만으로 데이터의 구조를 발견
- 목표: 데이터의 숨겨진 패턴이나 구조를 찾기

**예시**:
- 군집화(Clustering): 고객 세분화
- 차원 축소(Dimensionality Reduction): PCA
- 생성 모델(Generative Model): VAE, GAN

#### 3. 강화학습 (Reinforcement Learning)

**비유**: 게임을 플레이하면서 점수(보상)를 통해 전략을 배우는 것.

- 에이전트가 환경과 상호작용하며 보상을 최대화하는 정책(policy)을 학습
- 상태(state) $s$에서 행동(action) $a$를 선택 → 보상(reward) $r$과 다음 상태 $s'$를 받음

**예시**:
- AlphaGo: 바둑에서 승리하는 전략 학습
- 로봇 제어: 걷기, 물건 잡기

### 가설 공간 (Hypothesis Class)

머신러닝에서 우리는 **가설 공간** $\mathcal{H}$라는 함수들의 집합에서 최적의 함수를 찾는다.

**비유**: 퍼즐 조각을 맞추는 것. 가설 공간은 "시도해볼 수 있는 퍼즐 조각들의 상자"이고, 학습은 "데이터에 가장 잘 맞는 조각을 찾는 과정"이다.

- 선형 모델: $\mathcal{H} = \{f(x) = w^T x + b \mid w \in \mathbb{R}^d, b \in \mathbb{R}\}$
- 다항식 모델: $\mathcal{H} = \{f(x) = \sum_{k=0}^{K} a_k x^k\}$
- 신경망: 훨씬 넓은 가설 공간

가설 공간이 너무 작으면 데이터를 잘 설명하지 못하고(과소적합), 너무 크면 훈련 데이터에 과도하게 맞춰진다(과적합).

---

### 손실 함수 (Loss Functions) - 직관적 이해

손실 함수는 "예측이 얼마나 틀렸는지"를 수치로 측정한다.

| 손실 함수 | 용도 | 직관 |
|-----------|------|------|
| MSE | 회귀 | 예측과 정답의 거리의 제곱 |
| Cross-Entropy | 분류 | 예측 확률이 정답과 얼마나 다른지 |
| Hinge Loss | SVM | 결정 경계로부터의 마진 |

**간단한 예시** (MSE):
- 실제 집값: 3억, 예측: 2.5억 → 손실 = $(3 - 2.5)^2 = 0.25$
- 실제 집값: 3억, 예측: 2.9억 → 손실 = $(3 - 2.9)^2 = 0.01$ (더 좋은 예측)

### 과적합과 과소적합

```
  오차
  │
  │  \                    ╱
  │   \      과소적합    ╱ 과적합
  │    \               ╱
  │     \    ·---·   ╱
  │      ·--       -·     ← 검증 오차
  │     ╱   ·-------·---- ← 훈련 오차
  │   ╱
  └──────────────────────── 모델 복잡도
       단순              복잡
```

- **과소적합(Underfitting)**: 모델이 너무 단순하여 훈련 데이터조차 잘 맞추지 못함
- **과적합(Overfitting)**: 모델이 훈련 데이터의 노이즈까지 외워서 새로운 데이터에 일반화하지 못함
- **적절한 복잡도**: 검증 오차가 최소인 지점

---

### 데이터 분할: Train / Validation / Test

```
전체 데이터셋
├── 훈련 세트 (60~80%)  → 모델 학습에 사용
├── 검증 세트 (10~20%)  → 하이퍼파라미터 튜닝, 모델 선택
└── 테스트 세트 (10~20%) → 최종 성능 평가 (한 번만 사용!)
```

**비유**: 시험 공부에 비유하면:
- 훈련 세트 = 교재의 연습 문제 (풀면서 공부)
- 검증 세트 = 모의고사 (공부 방법 조정)
- 테스트 세트 = 실제 시험 (최종 실력 평가)

## 중급 (Intermediate)

### 경험적 위험 최소화 (Empirical Risk Minimization, ERM)

#### 모집단 위험 (Population Risk)

데이터 분포 $\mathcal{D}$ 위에서 정의되는 실제 위험:

$$R(h) = \mathbb{E}_{(x,y) \sim \mathcal{D}}[\ell(h(x), y)]$$

하지만 $\mathcal{D}$를 직접 알 수 없으므로, 유한한 훈련 데이터 $S = \{(x_i, y_i)\}_{i=1}^{n}$로 근사한다.

#### 경험적 위험 (Empirical Risk)

$$\hat{R}_S(h) = \frac{1}{n} \sum_{i=1}^{n} \ell(h(x_i), y_i)$$

**ERM 원칙**: 가설 공간 $\mathcal{H}$에서 경험적 위험을 최소화하는 가설을 선택한다:

$$h^* = \arg\min_{h \in \mathcal{H}} \hat{R}_S(h)$$

#### 정칙화된 ERM

과적합을 방지하기 위해 정칙화 항을 추가:

$$h^* = \arg\min_{h \in \mathcal{H}} \left[ \hat{R}_S(h) + \lambda \Omega(h) \right]$$

여기서 $\Omega(h)$는 가설의 복잡도를 측정하는 정칙화 함수이다.

### 손실 함수의 수학적 정의

#### 1. 평균 제곱 오차 (Mean Squared Error, MSE)

$$\ell_{\text{MSE}}(\hat{y}, y) = (\hat{y} - y)^2$$

$$\hat{R}_{\text{MSE}} = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2$$

**특성**:
- 미분 가능, 볼록(convex) → 최적화 용이
- 이상치(outlier)에 민감 (제곱 때문에 큰 오차가 과도하게 페널티)
- 확률적 해석: 가우시안 노이즈 가정 하 최대우도추정(MLE)과 동치

**MLE와의 관계**: $y = f(x) + \epsilon$, $\epsilon \sim \mathcal{N}(0, \sigma^2)$일 때:

$$\log p(y|x,w) = -\frac{(y - f_w(x))^2}{2\sigma^2} + \text{const}$$

따라서 MLE = MSE 최소화.

#### 2. 교차 엔트로피 (Cross-Entropy Loss)

이진 분류의 경우 ($y \in \{0, 1\}$, $\hat{y} = \sigma(z) \in (0,1)$):

$$\ell_{\text{CE}} = -[y \log \hat{y} + (1-y) \log(1 - \hat{y})]$$

다중 클래스 분류 ($y$가 one-hot 벡터, $\hat{y}_k = \text{softmax}(z)_k$):

$$\ell_{\text{CE}} = -\sum_{k=1}^{K} y_k \log \hat{y}_k$$

**특성**:
- 정보 이론에서 유래: 두 분포 $p$와 $q$ 사이의 교차 엔트로피 $H(p, q) = -\sum p \log q$
- KL divergence와의 관계: $H(p,q) = H(p) + D_{\text{KL}}(p \| q)$
- 확률적 해석: 베르누이/카테고리 분포 가정 하 MLE (negative log-likelihood)

#### 3. 힌지 손실 (Hinge Loss)

SVM에서 사용. $y \in \{-1, +1\}$일 때:

$$\ell_{\text{hinge}}(\hat{y}, y) = \max(0, 1 - y \cdot \hat{y})$$

**특성**:
- 마진 $y \cdot \hat{y} \geq 1$이면 손실 0 → 희소 해(sparse solution)
- $y \cdot \hat{y} = 0$ 에서 미분 불가능하지만 subgradient 사용 가능
- 로지스틱 손실($\log(1 + e^{-y\hat{y}})$)과 비교: 힌지 손실은 더 공격적으로 0이 됨

### 선형 회귀 (Linear Regression)

모델: $\hat{y} = w^T x + b = [w; b]^T [x; 1] = \theta^T \tilde{x}$

비용 함수 (MSE):

$$J(\theta) = \frac{1}{2n}\sum_{i=1}^{n}(\theta^T \tilde{x}_i - y_i)^2 = \frac{1}{2n}\|\tilde{X}\theta - y\|^2$$

여기서 $\tilde{X} \in \mathbb{R}^{n \times (d+1)}$는 디자인 행렬.

#### 폐쇄형 해 (Closed-form Solution / Normal Equation)

$J(\theta)$를 $\theta$에 대해 미분하고 0으로 놓으면:

$$\nabla_\theta J = \frac{1}{n}\tilde{X}^T(\tilde{X}\theta - y) = 0$$

$$\tilde{X}^T\tilde{X}\theta = \tilde{X}^T y$$

$$\boxed{\theta^* = (\tilde{X}^T\tilde{X})^{-1}\tilde{X}^T y}$$

**유도 과정**:

1. $J(\theta) = \frac{1}{2n}(\tilde{X}\theta - y)^T(\tilde{X}\theta - y)$
2. $= \frac{1}{2n}(\theta^T\tilde{X}^T\tilde{X}\theta - 2\theta^T\tilde{X}^T y + y^T y)$
3. $\nabla_\theta J = \frac{1}{n}(\tilde{X}^T\tilde{X}\theta - \tilde{X}^T y) = 0$
4. $\theta^* = (\tilde{X}^T\tilde{X})^{-1}\tilde{X}^T y$ (단, $\tilde{X}^T\tilde{X}$가 가역일 때)

**시간 복잡도**: $O(nd^2 + d^3)$ — $d$가 크면 비실용적.

#### 경사 하강법 (Gradient Descent)

$d$가 크거나 데이터가 메모리에 안 들어올 때 사용:

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta J(\theta_t)$$

여기서 $\eta$는 학습률(learning rate).

**변형**:
- **배치 경사 하강법 (Batch GD)**: 전체 데이터로 그래디언트 계산. 안정적이나 느림.
- **확률적 경사 하강법 (SGD)**: 하나의 샘플로 그래디언트 근사. 빠르나 노이즈.

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta \ell(\theta; x_i, y_i)$$

- **미니배치 SGD**: 절충안. $B$개의 샘플로 그래디언트 근사.

$$\theta_{t+1} = \theta_t - \frac{\eta}{|B|}\sum_{i \in B}\nabla_\theta \ell(\theta; x_i, y_i)$$

### 로지스틱 회귀 (Logistic Regression)

이진 분류: $y \in \{0, 1\}$

**모델**: 선형 함수의 출력에 시그모이드 함수를 적용:

$$P(y=1|x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}$$

**시그모이드 함수의 성질**:
- $\sigma(z) \in (0, 1)$: 확률로 해석 가능
- $\sigma(-z) = 1 - \sigma(z)$: 대칭성
- $\sigma'(z) = \sigma(z)(1 - \sigma(z))$: 미분이 자기 자신으로 표현됨

**비용 함수** (negative log-likelihood):

$$J(w,b) = -\frac{1}{n}\sum_{i=1}^{n}[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]$$

**그래디언트 유도**:

$z_i = w^T x_i + b$, $\hat{y}_i = \sigma(z_i)$라 하면:

$$\frac{\partial J}{\partial w} = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)x_i$$

$$\frac{\partial J}{\partial b} = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i - y_i)$$

이 그래디언트의 형태가 선형 회귀의 MSE 그래디언트와 동일한 구조를 가진다는 것이 주목할 만하다.

**결정 경계(Decision Boundary)**: $w^T x + b = 0$인 초평면.

---

### 소프트맥스 회귀 (Softmax Regression)

$K$-클래스 분류를 위한 로지스틱 회귀의 일반화.

**모델**: 각 클래스 $k$에 대해:

$$P(y=k|x) = \frac{e^{w_k^T x + b_k}}{\sum_{j=1}^{K} e^{w_j^T x + b_j}} = \text{softmax}(z)_k$$

**소프트맥스 함수의 성질**:
- $\sum_{k=1}^{K} P(y=k|x) = 1$: 유효한 확률 분포
- $\text{softmax}(z + c) = \text{softmax}(z)$: 상수 이동 불변 (수치 안정성에 활용)
- 온도(temperature) $\tau$: $\text{softmax}(z/\tau)$ — $\tau \to 0$이면 argmax, $\tau \to \infty$이면 균등 분포

**비용 함수** (cross-entropy):

$$J(W, b) = -\frac{1}{n}\sum_{i=1}^{n}\sum_{k=1}^{K} \mathbb{1}[y_i = k] \log P(y=k|x_i)$$

**그래디언트**:

$$\frac{\partial J}{\partial w_k} = \frac{1}{n}\sum_{i=1}^{n}(\hat{y}_{ik} - \mathbb{1}[y_i = k])x_i$$

### 교차 검증 (Cross-Validation)

데이터가 부족할 때 검증 세트를 효율적으로 활용하는 방법.

#### K-fold Cross-Validation

1. 데이터를 $K$개의 동일한 크기 폴드로 분할
2. 각 반복에서 1개 폴드를 검증용, 나머지 $K-1$개를 훈련용으로 사용
3. $K$번 반복하여 평균 성능 계산

```
Fold 1: [검증] [훈련] [훈련] [훈련] [훈련]
Fold 2: [훈련] [검증] [훈련] [훈련] [훈련]
Fold 3: [훈련] [훈련] [검증] [훈련] [훈련]
Fold 4: [훈련] [훈련] [훈련] [검증] [훈련]
Fold 5: [훈련] [훈련] [훈련] [훈련] [검증]
```

**일반적으로 $K = 5$ 또는 $K = 10$ 사용.**

- **Leave-One-Out (LOO)**: $K = n$인 특수한 경우. 편향 낮지만 분산 높고 계산 비용 큼.

### 정칙화 (Regularization)

과적합을 방지하기 위해 모델 복잡도에 페널티를 부여.

#### L2 정칙화 (Ridge / Weight Decay)

$$J_{\text{ridge}}(\theta) = \hat{R}_S(\theta) + \frac{\lambda}{2}\|\theta\|_2^2 = \hat{R}_S(\theta) + \frac{\lambda}{2}\sum_j \theta_j^2$$

- 그래디언트: $\nabla J_{\text{ridge}} = \nabla \hat{R}_S + \lambda\theta$
- 업데이트: $\theta_{t+1} = (1 - \eta\lambda)\theta_t - \eta \nabla \hat{R}_S$ → **가중치 감쇠 (weight decay)**
- 선형 회귀의 폐쇄형 해: $\theta^* = (\tilde{X}^T\tilde{X} + \lambda I)^{-1}\tilde{X}^T y$
  - $\lambda I$의 추가로 항상 가역 → 수치적 안정성 향상
- **효과**: 가중치를 0에 가깝게 줄이지만 정확히 0으로 만들지는 않음

#### L1 정칙화 (Lasso)

$$J_{\text{lasso}}(\theta) = \hat{R}_S(\theta) + \lambda\|\theta\|_1 = \hat{R}_S(\theta) + \lambda\sum_j |\theta_j|$$

- **효과**: 일부 가중치를 정확히 0으로 만듦 → **특성 선택(feature selection)** 효과
- $\|\theta\|_1 = 0$에서 미분 불가능 → subgradient 또는 proximal gradient 사용

#### L1 vs L2 기하학적 비교

```
  L1 (다이아몬드)          L2 (원)
       ◇                    ○
      ╱ ╲                  ╱  ╲
     ╱   ╲               ╱    ╲
    ◇     ◇             ○      ○
     ╲   ╱               ╲    ╱
      ╲ ╱                  ╲  ╱
       ◇                    ○

  → 꼭짓점에서 만남          → 어디서든 만남
    (희소 해)              (희소하지 않은 해)
```

등고선(loss function)과 제약 영역(regularization)이 만나는 점이 해가 되며, L1은 꼭짓점(축 위)에서 만날 확률이 높아 희소 해를 유도한다.

#### Elastic Net

L1과 L2의 조합:

$$\Omega(\theta) = \alpha\|\theta\|_1 + \frac{1-\alpha}{2}\|\theta\|_2^2$$

### 편향-분산 트레이드오프 (Bias-Variance Tradeoff)

MSE 손실에서 예측 오차를 분해하면:

$$\mathbb{E}[(\hat{y} - y)^2] = \underbrace{(\mathbb{E}[\hat{y}] - y^*)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}[(\hat{y} - \mathbb{E}[\hat{y}])^2]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Irreducible Noise}}$$

**유도**:

$y = y^* + \epsilon$ ($\epsilon$은 노이즈, $\mathbb{E}[\epsilon] = 0$, $\text{Var}(\epsilon) = \sigma^2$)라 하면:

$$\mathbb{E}[(\hat{y} - y)^2] = \mathbb{E}[(\hat{y} - y^* - \epsilon)^2]$$
$$= \mathbb{E}[(\hat{y} - y^*)^2] - 2\mathbb{E}[(\hat{y} - y^*)\epsilon] + \mathbb{E}[\epsilon^2]$$
$$= \mathbb{E}[(\hat{y} - y^*)^2] + \sigma^2 \quad (\because \hat{y} \perp \epsilon)$$

$\mathbb{E}[\hat{y}] = \bar{y}$로 놓으면:

$$\mathbb{E}[(\hat{y} - y^*)^2] = \mathbb{E}[(\hat{y} - \bar{y} + \bar{y} - y^*)^2]$$
$$= \mathbb{E}[(\hat{y} - \bar{y})^2] + 2\mathbb{E}[(\hat{y} - \bar{y})](\bar{y} - y^*) + (\bar{y} - y^*)^2$$
$$= \text{Var}(\hat{y}) + \text{Bias}^2(\hat{y})$$

**해석**:
- **편향(Bias)**: 모델의 가정으로 인한 체계적 오차. 단순한 모델 → 높은 편향
- **분산(Variance)**: 훈련 데이터의 변화에 대한 모델의 민감도. 복잡한 모델 → 높은 분산
- **트레이드오프**: 모델 복잡도를 높이면 편향 ↓, 분산 ↑

| 모델 복잡도 | 편향 | 분산 | 훈련 오차 | 테스트 오차 | 상태 |
|------------|------|------|----------|-----------|------|
| 낮음 | 높음 | 낮음 | 높음 | 높음 | 과소적합 |
| 적절 | 적절 | 적절 | 낮음 | 낮음 | 최적 |
| 높음 | 낮음 | 높음 | 매우 낮음 | 높음 | 과적합 |

## 고급 (Advanced)

### PAC 학습 (Probably Approximately Correct Learning)

#### 정의

학습 알고리즘 $\mathcal{A}$가 가설 공간 $\mathcal{H}$에서 PAC-학습 가능(PAC-learnable)하다 함은:

임의의 $\epsilon > 0$ (정확도), $\delta > 0$ (신뢰도)에 대해, 샘플 수 $n$이 $n \geq n_0(\epsilon, \delta)$이면:

$$P\left[R(h_S) - R(h^*) \leq \epsilon\right] \geq 1 - \delta$$

여기서 $h_S$는 학습 알고리즘이 출력한 가설, $h^* = \arg\min_{h \in \mathcal{H}} R(h)$.

**즉, "높은 확률로(probably), 거의 정확한(approximately correct) 가설을 찾을 수 있다"는 의미.**

#### 유한 가설 공간에서의 PAC 바운드

$\mathcal{H}$가 유한($|\mathcal{H}| < \infty$)이고, 실현 가능(realizable) 설정에서:

$$n \geq \frac{1}{\epsilon}\left(\ln|\mathcal{H}| + \ln\frac{1}{\delta}\right)$$

이면 PAC 학습이 보장된다.

**유도 (Union Bound + Hoeffding)**:

1. 각 "나쁜" 가설 $h$ (즉, $R(h) > \epsilon$이면서 $\hat{R}_S(h) = 0$)에 대해:
   - $P[\hat{R}_S(h) = 0] \leq (1-\epsilon)^n \leq e^{-\epsilon n}$
2. Union bound: $P[\exists h \in \mathcal{H}_{\text{bad}}: \hat{R}_S(h) = 0] \leq |\mathcal{H}| \cdot e^{-\epsilon n}$
3. 이를 $\delta$ 이하로 만들려면: $|\mathcal{H}| \cdot e^{-\epsilon n} \leq \delta$
4. 따라서: $n \geq \frac{1}{\epsilon}(\ln|\mathcal{H}| + \ln\frac{1}{\delta})$

---

### VC 차원 (Vapnik-Chervonenkis Dimension)

유한하지 않은 가설 공간의 복잡도를 측정하기 위한 개념.

#### Shattering

점 집합 $S = \{x_1, \ldots, x_m\}$이 가설 공간 $\mathcal{H}$에 의해 **shatter**된다 함은, $S$의 모든 $2^m$개 이진 레이블링을 $\mathcal{H}$의 어떤 가설로 실현할 수 있다는 의미.

#### VC 차원의 정의

$$\text{VCdim}(\mathcal{H}) = \max\{m : \exists S, |S| = m, \mathcal{H} \text{ shatters } S\}$$

$\mathcal{H}$가 shatter할 수 있는 점 집합의 최대 크기.

#### 예시

- **$\mathbb{R}^1$에서의 구간 $[a,b]$ 분류기**: VCdim = 2
  - 2개의 점은 shatter 가능
  - 3개의 점 $x_1 < x_2 < x_3$에서 $\{+,-,+\}$ 레이블링 불가능

- **$\mathbb{R}^d$에서의 선형 분류기**: VCdim = $d + 1$
  - $d+1$개의 일반 위치(general position)의 점을 shatter 가능
  - $d+2$개는 불가능 (Radon's theorem)

#### VC 일반화 바운드

$\text{VCdim}(\mathcal{H}) = d$이면, 확률 $1-\delta$로:

$$R(h_S) \leq \hat{R}_S(h_S) + \sqrt{\frac{d(\ln(2n/d) + 1) + \ln(4/\delta)}{n}}$$

**해석**: 일반화 갭은 대략 $O\left(\sqrt{\frac{d}{n}}\right)$에 비례.

- $d$ 증가 (가설 공간 복잡 ↑) → 일반화 바운드 증가 (과적합 위험 ↑)
- $n$ 증가 (데이터 많아짐) → 일반화 바운드 감소

---

### Rademacher 복잡도 (Rademacher Complexity)

VC 차원보다 더 세밀한 복잡도 측정. 데이터 분포에 의존.

#### 정의

훈련 세트 $S = \{x_1, \ldots, x_n\}$에 대한 경험적 Rademacher 복잡도:

$$\hat{\mathfrak{R}}_S(\mathcal{H}) = \mathbb{E}_{\sigma}\left[\sup_{h \in \mathcal{H}} \frac{1}{n}\sum_{i=1}^{n} \sigma_i h(x_i)\right]$$

여기서 $\sigma_i \in \{-1, +1\}$는 독립적이고 균등한 Rademacher 확률변수.

**직관**: $\mathcal{H}$가 랜덤 레이블 $\sigma$를 얼마나 잘 맞출 수 있는지를 측정. 랜덤 노이즈에 잘 맞출수록 → 복잡도 높음 → 과적합 위험.

#### Rademacher 일반화 바운드

확률 $1 - \delta$로, 모든 $h \in \mathcal{H}$에 대해:

$$R(h) \leq \hat{R}_S(h) + 2\mathfrak{R}_n(\mathcal{H}) + \sqrt{\frac{\ln(1/\delta)}{2n}}$$

여기서 $\mathfrak{R}_n(\mathcal{H}) = \mathbb{E}_S[\hat{\mathfrak{R}}_S(\mathcal{H})]$은 Rademacher 복잡도.

#### 예시: 선형 함수 클래스

$\mathcal{H} = \{x \mapsto w^T x : \|w\|_2 \leq W\}$이고 $\|x_i\|_2 \leq X$이면:

$$\hat{\mathfrak{R}}_S(\mathcal{H}) \leq \frac{WX}{\sqrt{n}}$$

**유도** (Jensen's 부등식과 Cauchy-Schwarz):

$$\hat{\mathfrak{R}}_S(\mathcal{H}) = \frac{1}{n}\mathbb{E}_\sigma\left[\sup_{\|w\| \leq W} w^T \sum_i \sigma_i x_i\right] = \frac{W}{n}\mathbb{E}_\sigma\left[\left\|\sum_i \sigma_i x_i\right\|\right]$$

$$\leq \frac{W}{n}\sqrt{\mathbb{E}_\sigma\left[\left\|\sum_i \sigma_i x_i\right\|^2\right]} = \frac{W}{n}\sqrt{\sum_i \|x_i\|^2} \leq \frac{WX}{\sqrt{n}}$$

---

### 일반화 바운드의 비교

| 바운드 | 장점 | 단점 |
|-------|------|------|
| PAC (유한 $\mathcal{H}$) | 단순, 직관적 | 무한 가설 공간에 적용 불가 |
| VC 바운드 | 무한 가설 공간에 적용 가능 | 데이터 분포 독립 → 느슨함 |
| Rademacher 바운드 | 데이터 의존적, 더 타이트 | 계산이 어려울 수 있음 |

---

### 정칙화의 이론적 정당화

#### 구조적 위험 최소화 (Structural Risk Minimization, SRM)

중첩된 가설 공간 $\mathcal{H}_1 \subset \mathcal{H}_2 \subset \cdots$에서:

$$h^* = \arg\min_{k} \left[\min_{h \in \mathcal{H}_k} \hat{R}_S(h) + \text{complexity}(\mathcal{H}_k)\right]$$

ERM + 정칙화는 SRM의 근사: $\lambda\|\theta\|^2$가 가설 공간을 암묵적으로 제한.

#### 베이지안 해석

- **L2 정칙화**: $\theta$에 대한 가우시안 사전분포 $\theta \sim \mathcal{N}(0, \frac{1}{\lambda}I)$의 MAP 추정
- **L1 정칙화**: $\theta$에 대한 라플라스 사전분포의 MAP 추정

MAP 추정:

$$\theta_{\text{MAP}} = \arg\max_\theta \log p(\theta|D) = \arg\max_\theta [\log p(D|\theta) + \log p(\theta)]$$

$\log p(\theta) = -\frac{\lambda}{2}\|\theta\|^2 + \text{const}$ (가우시안 사전분포)일 때 L2 정칙화와 동치.

### 현대 딥러닝에서의 일반화 미스터리

전통적 이론은 "매개변수 수 > 데이터 수 → 과적합"을 예측하지만, 딥러닝은 과매개변수화(overparameterized)에도 불구하고 일반화가 잘 된다. 이를 설명하기 위한 현대적 관점:

1. **이중 하강 (Double Descent)**: 모델 복잡도가 보간(interpolation) 임계점을 넘으면 테스트 오차가 다시 감소
2. **암묵적 정칙화 (Implicit Regularization)**: SGD가 자연스럽게 단순한 해를 선호
3. **NTK (Neural Tangent Kernel)**: 무한 너비 신경망은 커널 회귀로 수렴
4. **PAC-Bayes 바운드**: 사후분포의 복잡도로 일반화 설명

$$R(h) \leq \hat{R}_S(h) + \sqrt{\frac{D_{\text{KL}}(Q\|P) + \ln(n/\delta)}{2(n-1)}}$$

여기서 $Q$는 학습된 사후분포, $P$는 사전분포.

### 핵심 정리

| 개념 | 핵심 수식 | 한 줄 요약 |
|------|----------|-----------|
| ERM | $\min_h \frac{1}{n}\sum \ell(h(x_i), y_i)$ | 경험적 위험을 최소화 |
| 선형 회귀 해 | $\theta^* = (X^TX)^{-1}X^Ty$ | 해석적 해 존재 |
| 로지스틱 회귀 | $\sigma(w^Tx + b) = 1/(1+e^{-z})$ | 이진 분류의 기본 |
| 소프트맥스 | $e^{z_k}/\sum_j e^{z_j}$ | 다중 분류 확률 출력 |
| L2 정칙화 | $+ \lambda\|\theta\|_2^2$ | 가우시안 사전분포 |
| L1 정칙화 | $+ \lambda\|\theta\|_1$ | 희소 해, 특성 선택 |
| 편향-분산 | $\text{Error} = \text{Bias}^2 + \text{Var} + \sigma^2$ | 모델 복잡도의 트레이드오프 |
| VC 바운드 | $O(\sqrt{d/n})$ | 가설 공간 복잡도 → 일반화 |
| Rademacher | $\mathbb{E}[\sup \frac{1}{n}\sum \sigma_i h(x_i)]$ | 데이터 의존적 복잡도 |
