# 1. 입문 (Beginner)

## 1.1 합성곱(Convolution) 연산

### 1.1.1 1D Convolution

입력 신호 $x[n]$과 커널(필터) $w[k]$의 이산 합성곱:

$$
(x * w)[n] = \sum_{k=0}^{K-1} w[k] \cdot x[n - k]
$$

- $K$: 커널 크기
- 실제 CNN에서는 수학적으로 **상관(cross-correlation)**에 더 가까움:

$$
(x \star w)[n] = \sum_{k=0}^{K-1} w[k] \cdot x[n + k]
$$

차이점: convolution은 커널을 뒤집지만(flip), cross-correlation은 뒤집지 않음. 학습에서는 커널이 학습되므로 실질적 차이 없음.

### 1.1.2 2D Convolution

이미지 $X \in \mathbb{R}^{H \times W}$와 커널 $W \in \mathbb{R}^{K_H \times K_W}$:

$$
(X \star W)[i, j] = \sum_{m=0}^{K_H - 1} \sum_{n=0}^{K_W - 1} W[m, n] \cdot X[i+m, j+n]
$$

다중 채널 입력 $X \in \mathbb{R}^{C_{\text{in}} \times H \times W}$에 대해:

$$
Y[j, i_h, i_w] = b_j + \sum_{c=0}^{C_{\text{in}}-1} \sum_{m=0}^{K_H-1} \sum_{n=0}^{K_W-1} W[j, c, m, n] \cdot X[c, i_h + m, i_w + n]
$$

- $j$: 출력 채널 인덱스 ($j = 0, 1, \ldots, C_{\text{out}}-1$)
- 커널 $W \in \mathbb{R}^{C_{\text{out}} \times C_{\text{in}} \times K_H \times K_W}$

## 1.2 핵심 하이퍼파라미터

### 1.2.1 Stride

커널이 이동하는 간격:

$$
H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} - K_H}{S} \right\rfloor + 1
$$

- $S = 1$: 기본, 한 칸씩 이동
- $S = 2$: 두 칸씩 이동 → 출력 크기 절반 (다운샘플링 효과)

### 1.2.2 Padding

입력의 가장자리에 값(보통 0)을 추가:

$$
H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} + 2P - K_H}{S} \right\rfloor + 1
$$

- **Valid padding** ($P = 0$): 패딩 없음, 출력이 작아짐
- **Same padding** ($P = \lfloor K/2 \rfloor$, $S=1$일 때): 입출력 크기 동일

### 1.2.3 파라미터 수 계산

하나의 conv 레이어:

$$
\text{Params} = C_{\text{out}} \times (C_{\text{in}} \times K_H \times K_W + 1)
$$

(+1은 bias)

**예시**: 입력 3채널, 출력 64채널, $3 \times 3$ 커널
$$
\text{Params} = 64 \times (3 \times 3 \times 3 + 1) = 64 \times 28 = 1{,}792
$$

## 1.3 Pooling 연산

Feature map의 공간적 크기를 줄이는 연산.

### 1.3.1 Max Pooling

영역 내 최댓값을 선택:

$$
Y[i, j] = \max_{(m, n) \in \text{pool window}} X[i \cdot S + m, j \cdot S + n]
$$

- 가장 강한 활성화를 보존 → 위치에 대한 불변성(invariance) 제공
- 학습 가능한 파라미터 없음

### 1.3.2 Average Pooling

영역 내 평균값:

$$
Y[i, j] = \frac{1}{K^2} \sum_{(m, n) \in \text{pool window}} X[i \cdot S + m, j \cdot S + n]
$$

### 1.3.3 Global Average Pooling (GAP)

전체 feature map을 하나의 값으로 평균:

$$
Y[c] = \frac{1}{H \times W} \sum_{i=0}^{H-1} \sum_{j=0}^{W-1} X[c, i, j]
$$

- 각 채널이 하나의 스칼라가 됨 → FC layer를 대체
- Lin et al. (2014) "Network in Network"에서 제안
- 파라미터 수 대폭 감소, 과적합 방지

## 1.4 Feature Map과 계층적 특징 학습

CNN의 핵심 통찰: 깊이에 따라 추상적 특징이 학습됨

| 레이어 | 학습되는 특징 | 예시 |
|--------|-------------|------|
| 초기 (1-2층) | 저수준 특징 | 엣지, 코너, 색상 |
| 중간 (3-4층) | 중수준 특징 | 텍스처, 패턴, 부분 |
| 후기 (5+층) | 고수준 특징 | 물체, 장면, 의미 |

Zeiler & Fergus (2014)의 시각화 연구로 확인됨.

## 1.5 CNN의 핵심 특성

### 1.5.1 Parameter Sharing (가중치 공유)

같은 커널이 입력의 모든 위치에 적용됨:
- FC layer와 비교: $H \times W$ 위치마다 별도의 가중치 → 파라미터 폭발
- Conv layer: 하나의 커널이 모든 위치 담당 → 파라미터 효율적

### 1.5.2 Translation Equivariance (이동 동등성)

입력이 이동하면 출력도 동일하게 이동:

$$
\text{Conv}(\text{Shift}(X)) = \text{Shift}(\text{Conv}(X))
$$

- 이미지에서 물체의 위치가 바뀌어도 같은 특징이 감지됨
- Pooling과 결합하면 근사적 **translation invariance**

## 1.6 간단한 CNN 구조 예시

```
Input (3, 32, 32)
    ↓
Conv2d(3, 32, 3, padding=1) → (32, 32, 32) → ReLU → MaxPool(2) → (32, 16, 16)
    ↓
Conv2d(32, 64, 3, padding=1) → (64, 16, 16) → ReLU → MaxPool(2) → (64, 8, 8)
    ↓
Flatten → (64 × 8 × 8 = 4096)
    ↓
Linear(4096, 10) → Softmax
```

# 2. 중급 (Intermediate)

## 2.1 Receptive Field (수용 영역)

### 2.1.1 정의

출력의 한 픽셀에 영향을 미치는 입력 영역의 크기.

$L$개의 conv 레이어 (커널 크기 $K_l$, stride $S_l$)에 대해:

$$
R_L = 1 + \sum_{l=1}^{L} (K_l - 1) \prod_{j=1}^{l-1} S_j
$$

**예시**: $3 \times 3$ 커널, stride 1, 3개 레이어:
$$
R = 1 + (3-1) \times 1 + (3-1) \times 1 + (3-1) \times 1 = 7
$$

### 2.1.2 Effective Receptive Field

Luo et al. (2016): 이론적 receptive field 내에서도 중심 부근의 픽셀이 훨씬 큰 영향력을 가짐:
- Effective receptive field ≈ Gaussian 분포 형태
- 이론적 RF보다 훨씬 작음
- 깊은 네트워크, skip connection이 이를 키우는 데 도움

## 2.2 고전 CNN 아키텍처

### 2.2.1 LeNet-5 (LeCun, 1998)

CNN의 원조. 손글씨 숫자 인식(MNIST)용:

```
Input (1, 32, 32)
→ Conv(6, 5×5) → Sigmoid → AvgPool(2)
→ Conv(16, 5×5) → Sigmoid → AvgPool(2)
→ FC(120) → FC(84) → FC(10)
```

- 약 60K 파라미터
- 당시 혁신: 학습 가능한 필터 + subsampling

### 2.2.2 AlexNet (Krizhevsky et al., 2012)

ImageNet 대회에서 딥러닝의 시대를 연 모델:

```
Input (3, 227, 227)
→ Conv(96, 11×11, stride=4) → ReLU → MaxPool(3, stride=2) → LRN
→ Conv(256, 5×5, pad=2) → ReLU → MaxPool(3, stride=2) → LRN
→ Conv(384, 3×3, pad=1) → ReLU
→ Conv(384, 3×3, pad=1) → ReLU
→ Conv(256, 3×3, pad=1) → ReLU → MaxPool(3, stride=2)
→ FC(4096) → Dropout → FC(4096) → Dropout → FC(1000)
```

- 약 62M 파라미터
- 핵심 기여: ReLU, Dropout, Data Augmentation, GPU 학습, LRN

### 2.2.3 VGGNet (Simonyan & Zisserman, 2014)

"작은 필터를 깊게 쌓자":

- 모든 conv 레이어에서 $3 \times 3$ 커널만 사용
- $3 \times 3$ 두 개 = $5 \times 5$의 receptive field, 그러나 파라미터 적고 비선형성 추가

$$
\text{두 개의 } 3 \times 3: 2 \times (3^2 C^2) = 18C^2 \quad \text{vs} \quad \text{한 개의 } 5 \times 5: 25C^2
$$

- VGG-16: 13 conv + 3 FC = 138M 파라미터
- 단순하고 규칙적인 구조 → 전이학습의 기본 backbone으로 널리 사용

### 2.2.4 GoogLeNet / Inception (Szegedy et al., 2015)

**Inception Module**: 여러 크기의 필터를 병렬로 적용하고 결합

```
         Input
       /  |   |  \
    1×1  3×3  5×5  MaxPool(3×3)
       \  |   |  /
       Concat (채널 차원)
```

핵심 기법:
- **1×1 convolution**으로 차원 축소 (bottleneck)
- 다양한 스케일의 특징을 동시에 포착
- 22개 레이어, 약 5M 파라미터 (VGG 대비 매우 적음)

### 2.2.5 ResNet (He et al., 2016)

**Skip Connection (Residual Connection)**:

$$
y = \mathcal{F}(x, \{W_i\}) + x
$$

- $\mathcal{F}$: residual function (2-3개의 conv 레이어)
- 입력 $x$를 출력에 직접 더함 → **항등 사상(identity mapping)을 학습하기 쉬움**

**Residual Block**:
```
x ─────────────────────(+)──→ ReLU → y
    │                    ↑
    └→ Conv → BN → ReLU → Conv → BN ─┘
```

**왜 작동하는가?**
- Gradient가 skip connection을 통해 직접 전파 → **vanishing gradient 완화**
- 최악의 경우에도 $\mathcal{F} = 0$을 학습하면 항등 사상 → 레이어 추가가 해롭지 않음
- ResNet-152까지 깊게 쌓아도 학습 가능

**Bottleneck Block** (ResNet-50+):
```
x → 1×1 Conv(↓채널) → 3×3 Conv → 1×1 Conv(↑채널) → (+x) → ReLU
```

### 2.2.6 DenseNet (Huang et al., 2017)

모든 이전 레이어의 출력을 현재 레이어의 입력으로 연결:

$$
x_l = H_l([x_0, x_1, \ldots, x_{l-1}])
$$

- $[\cdot]$: 채널 차원으로 concatenation
- 특징 재사용(feature reuse) 극대화
- Growth rate $k$: 각 레이어가 추가하는 채널 수
- 파라미터 효율적이지만 메모리 사용량 많음

## 2.3 1x1 Convolution

$1 \times 1$ 크기의 커널로 수행하는 합성곱:

$$
Y[j, i, k] = \sum_{c=0}^{C_{\text{in}}-1} W[j, c] \cdot X[c, i, k] + b_j
$$

**역할**:
1. **채널 수 조절 (차원 축소/확장)**: $C_{\text{in}} \to C_{\text{out}}$
2. **비선형성 추가**: ReLU와 결합하면 채널 간 비선형 결합
3. **연산량 감소**: Inception, ResNet의 bottleneck에서 핵심

**연산량 비교 예시**: 입력 $(256, 56, 56)$에서 $3 \times 3$ conv로 256채널 출력
- 직접: $256 \times 256 \times 3 \times 3 \times 56 \times 56 \approx 1.8 \times 10^9$ FLOPs
- 1×1 bottleneck (256→64→256): $256 \times 64 \times 56^2 + 64 \times 64 \times 9 \times 56^2 + 64 \times 256 \times 56^2 \approx 0.6 \times 10^9$ FLOPs

## 2.4 Batch Normalization in CNNs

Conv 레이어 출력에 BN 적용 시, **채널별(channel-wise)**로 정규화:

$$
\hat{X}[c, :, :] = \frac{X[c, :, :] - \mu_c}{\sqrt{\sigma_c^2 + \epsilon}}
$$

$$
Y[c, :, :] = \gamma_c \cdot \hat{X}[c, :, :] + \beta_c
$$

- $\mu_c, \sigma_c^2$: 채널 $c$에 대해 배치 내 모든 위치 $(i, j)$와 모든 샘플에 걸쳐 계산
- 학습 가능한 파라미터: $\gamma_c, \beta_c$ (각 채널마다 2개)
- 총 파라미터: $2 \times C_{\text{out}}$

**효과**:
- Internal Covariate Shift 감소 (논란은 있음)
- 더 큰 학습률 사용 가능
- 정규화 효과 (약한 dropout처럼 작용)
- 초기화에 덜 민감

## 2.5 Depthwise Separable Convolution

Howard et al. (2017), MobileNet에서 핵심:

**표준 Convolution**:
$$
\text{FLOPs} = C_{\text{in}} \times C_{\text{out}} \times K^2 \times H \times W
$$

**Depthwise Separable Convolution** = Depthwise + Pointwise:

1. **Depthwise Conv**: 각 입력 채널에 독립적으로 $K \times K$ 필터 적용
$$
\text{FLOPs}_{\text{dw}} = C_{\text{in}} \times K^2 \times H \times W
$$

2. **Pointwise Conv**: $1 \times 1$ conv로 채널 결합
$$
\text{FLOPs}_{\text{pw}} = C_{\text{in}} \times C_{\text{out}} \times H \times W
$$

**연산량 비율**:
$$
\frac{\text{Depthwise Separable}}{\text{Standard}} = \frac{1}{C_{\text{out}}} + \frac{1}{K^2}
$$

$K = 3$, $C_{\text{out}} = 256$이면 약 $\frac{1}{256} + \frac{1}{9} \approx 0.115$, 즉 **약 8-9배 효율적**.

## 2.6 Transfer Learning with Pretrained CNNs

### 2.6.1 기본 전략

ImageNet 등 대규모 데이터셋에서 사전학습된 CNN을 새로운 태스크에 활용:

| 데이터 양 | 유사도 높음 | 유사도 낮음 |
|----------|-----------|-----------|
| 많음 | 전체 fine-tuning | 전체 fine-tuning (작은 lr) |
| 적음 | 마지막 레이어만 학습 | 중간 레이어부터 fine-tuning |

### 2.6.2 Fine-tuning 전략

1. **Feature Extraction**: 마지막 FC 레이어만 교체하고 학습
2. **Gradual Unfreezing**: 뒷쪽 레이어부터 점진적으로 해동
3. **Discriminative Learning Rates**: 앞쪽 레이어는 작은 lr, 뒷쪽은 큰 lr

$$
\eta_l = \eta_{\text{base}} \times \gamma^{L - l}
$$

- $L$: 총 레이어 수, $l$: 현재 레이어, $\gamma < 1$ (e.g., 0.9)

# 3. 고급 (Advanced)

## 3.1 ResNet의 이론적 분석

### 3.1.1 Gradient Flow 분석

ResNet에서 $L$번째 레이어의 출력:

$$
x_L = x_l + \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i)
$$

Loss에 대한 gradient:

$$
\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \left(1 + \frac{\partial}{\partial x_l} \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i)\right)
$$

- 첫째 항 "1"은 skip connection을 통한 직접 gradient → 항상 존재
- gradient가 0이 되려면 괄호 안이 정확히 -1이어야 함 → 확률적으로 극히 드묾
- 따라서 vanishing gradient 문제가 본질적으로 완화됨

### 3.1.2 Ensemble 관점

Veit et al. (2016): ResNet은 다양한 길이의 경로들의 **앙상블**로 볼 수 있음

$n$개의 residual block이 있으면 $2^n$개의 경로가 존재:
- 각 block에서 skip하거나 residual을 거치거나 → 2가지 선택
- 학습된 ResNet에서 특정 block을 제거해도 성능 저하가 완만 (graceful degradation)
- Plain network에서는 한 레이어 제거 시 성능 급락

### 3.1.3 Pre-activation ResNet

He et al. (2016b):

**Original**: $x + \mathcal{F}(\text{BN}(\text{ReLU}(x)))$ (post-activation)

**Pre-activation**: $x + \mathcal{F}(\text{BN}(x), \text{ReLU})$, 즉:

$$
x_{l+1} = x_l + \mathcal{F}(\text{BN}(\text{ReLU}(x_l)))
$$

- skip connection이 순수한 정보 고속도로(information highway)
- gradient flow 더욱 개선
- 1001 레이어까지 안정적 학습 가능

## 3.2 Neural Architecture Search (NAS) 관련

### 3.2.1 EfficientNet (Tan & Le, 2019)

네트워크의 세 가지 차원을 균형 있게 확장:

$$
\text{depth}: d = \alpha^\phi, \quad \text{width}: w = \beta^\phi, \quad \text{resolution}: r = \gamma^\phi
$$

제약 조건:
$$
\alpha \cdot \beta^2 \cdot \gamma^2 \approx 2
$$

- $\phi$: compound coefficient (자원에 따라 조절)
- Grid search로 $\alpha = 1.2, \beta = 1.1, \gamma = 1.15$ 발견
- EfficientNet-B0 ~ B7: 같은 구조에서 $\phi$만 변경

### 3.2.2 NAS의 탐색 공간

대표적 탐색 공간 요소:
- 커널 크기: $\{3, 5, 7\}$
- 확장 비율 (MBConv): $\{1, 4, 6\}$
- 레이어 수: 블록별 $\{1, 2, 3, 4\}$
- 채널 수: $\{16, 24, 40, 80, 112, 192, 320\}$
- Skip connection 유무

## 3.3 Object Detection 기초

### 3.3.1 R-CNN Family

**R-CNN** (Girshick et al., 2014):
1. Selective Search로 region proposal (~2000개) 추출
2. 각 proposal을 CNN에 독립적으로 통과
3. SVM으로 분류, Bounding Box Regression으로 위치 보정

**문제**: 2000개 region 각각에 CNN forward → 매우 느림

**Fast R-CNN** (Girshick, 2015):
1. 전체 이미지를 한 번만 CNN에 통과 → feature map
2. Region proposal을 feature map 위에 투영
3. RoI Pooling으로 고정 크기 feature 추출
4. FC layer로 분류 + bbox regression

**Faster R-CNN** (Ren et al., 2015):
- Selective Search 대신 **Region Proposal Network (RPN)** 사용
- RPN도 CNN feature map 위에서 동작 → end-to-end 학습 가능

**RPN 동작**:
- Feature map의 각 위치에서 $k$개의 anchor box 생성
- 각 anchor에 대해: objectness score + bbox offset 예측
- Anchor 크기/비율 조합: $\{128^2, 256^2, 512^2\} \times \{1:1, 1:2, 2:1\}$ = 9개

### 3.3.2 YOLO (You Only Look Once)

Redmon et al. (2016):

기존 two-stage detector와 달리, **단일 네트워크**로 한 번에 검출:

1. 입력 이미지를 $S \times S$ 그리드로 분할
2. 각 그리드 셀이 $B$개의 bounding box 예측:
   - $(x, y, w, h, \text{confidence})$ 각 bbox마다
   - $C$개 클래스 확률
3. 출력 텐서: $S \times S \times (B \times 5 + C)$

**Loss 함수** (YOLOv1 단순화):

$$
\mathcal{L} = \lambda_{\text{coord}} \mathcal{L}_{\text{coord}} + \mathcal{L}_{\text{obj}} + \lambda_{\text{noobj}} \mathcal{L}_{\text{noobj}} + \mathcal{L}_{\text{class}}
$$

$$
\mathcal{L}_{\text{coord}} = \sum_{i=0}^{S^2} \sum_{j=0}^{B} \mathbb{1}_{ij}^{\text{obj}} \left[(x_i - \hat{x}_i)^2 + (y_i - \hat{y}_i)^2 + (\sqrt{w_i} - \sqrt{\hat{w}_i})^2 + (\sqrt{h_i} - \sqrt{\hat{h}_i})^2\right]
$$

- $\sqrt{w}, \sqrt{h}$: 큰 박스와 작은 박스의 오차를 비슷한 스케일로 만들기 위함
- 장점: 실시간 속도 (45 FPS), 전체 이미지의 맥락 활용
- 단점: 작은 물체 검출 취약, 근접 물체 겹침 처리 어려움

### 3.3.3 IoU (Intersection over Union)

검출 성능 평가의 핵심 지표:

$$
\text{IoU} = \frac{|A \cap B|}{|A \cup B|}
$$

- $A$: 예측 bounding box
- $B$: ground truth bounding box
- 보통 IoU > 0.5이면 올바른 검출로 간주

## 3.4 Dilated (Atrous) Convolution

커널 원소 사이에 간격을 두는 합성곱:

$$
(X \star_d W)[i, j] = \sum_{m} \sum_{n} W[m, n] \cdot X[i + d \cdot m, j + d \cdot n]
$$

- $d$: dilation rate (일반 conv는 $d = 1$)
- 파라미터 수 변화 없이 receptive field 확대:
  - $d = 1, K = 3$: RF = 3
  - $d = 2, K = 3$: RF = 5
  - $d = 4, K = 3$: RF = 9
- Semantic segmentation (DeepLab 등)에서 핵심

## 3.5 Deformable Convolution

Dai et al. (2017):

표준 conv의 고정 그리드 대신, 학습 가능한 offset을 추가:

$$
y(p_0) = \sum_{p_n \in \mathcal{R}} w(p_n) \cdot x(p_0 + p_n + \Delta p_n)
$$

- $p_n$: 표준 그리드 위치
- $\Delta p_n$: 학습된 offset (실수값 → bilinear interpolation)
- 물체의 형태에 적응적으로 샘플링 가능

## 3.6 Group Convolution과 Channel Attention

### 3.6.1 Group Convolution

입력 채널을 $G$개의 그룹으로 나눠 독립적으로 conv:

$$
\text{FLOPs} = G \times \frac{C_{\text{in}}}{G} \times \frac{C_{\text{out}}}{G} \times K^2 \times H \times W = \frac{C_{\text{in}} \times C_{\text{out}} \times K^2 \times H \times W}{G}
$$

- $G = C_{\text{in}}$: Depthwise Convolution의 특수 경우
- ShuffleNet: Group Conv + Channel Shuffle로 그룹 간 정보 교환

### 3.6.2 SE (Squeeze-and-Excitation) Block

Hu et al. (2018): 채널별 중요도를 학습:

1. **Squeeze**: Global Average Pooling → $z_c = \frac{1}{HW}\sum_{i,j} X[c,i,j]$
2. **Excitation**: $s = \sigma(W_2 \cdot \text{ReLU}(W_1 \cdot z))$
   - $W_1 \in \mathbb{R}^{C/r \times C}$, $W_2 \in \mathbb{R}^{C \times C/r}$ (reduction ratio $r$)
3. **Scale**: $\tilde{X}[c,:,:] = s_c \cdot X[c,:,:]$

## 3.7 CNN의 이론적 한계와 개선

### 3.7.1 Translation Invariance의 실제

Azulay & Weiss (2019): 현대 CNN은 실제로 translation invariance가 약함
- Stride와 max pooling이 anti-aliasing 없이 적용 → 입력의 미세한 이동에도 출력이 크게 변함
- **해결**: Zhang (2019) — anti-aliased pooling (blur before subsample)

$$
\text{MaxPool}_{\text{AA}}(X) = \text{BlurPool}(\text{MaxMap}(X))
$$

### 3.7.2 CNN vs Transformer (ViT)

| 특성 | CNN | Vision Transformer |
|------|-----|-------------------|
| Inductive bias | Locality, translation equivariance | 최소 (positional encoding만) |
| 데이터 효율 | 적은 데이터에 강함 | 대규모 데이터 필요 |
| Global context | 깊은 레이어에서만 | 모든 레이어에서 |
| 연산 복잡도 | $O(K^2 \cdot C^2 \cdot HW)$ | $O((HW)^2 \cdot C)$ |

## 3.8 Feature Pyramid Network (FPN)

Lin et al. (2017):

멀티스케일 특징을 효과적으로 결합하는 구조:

```
C5 ──→ P5
 ↓(upsample + lateral)
C4 ──→ P4
 ↓(upsample + lateral)
C3 ──→ P3
 ↓(upsample + lateral)
C2 ──→ P2
```

- Bottom-up: 일반 CNN forward (ResNet 등)
- Top-down: 고해상도 + 고수준 의미 정보 결합
- Lateral connection: $1 \times 1$ conv로 채널 수 맞춤
- 모든 스케일의 P에서 예측 → 작은 물체부터 큰 물체까지 효과적 검출

## 핵심 수식 요약

| 개념 | 수식 |
|------|------|
| 2D Convolution | $(X \star W)[i,j] = \sum_m \sum_n W[m,n] \cdot X[i+m, j+n]$ |
| 출력 크기 | $H_{\text{out}} = \lfloor \frac{H+2P-K}{S} \rfloor + 1$ |
| Conv 파라미터 수 | $C_{\text{out}} \times (C_{\text{in}} \times K^2 + 1)$ |
| Receptive Field | $R_L = 1 + \sum_{l=1}^{L}(K_l - 1)\prod_{j < l} S_j$ |
| Residual Block | $y = \mathcal{F}(x) + x$ |
| Depthwise Separable 효율 | $\frac{1}{C_{\text{out}}} + \frac{1}{K^2}$ |
| IoU | $\frac{|A \cap B|}{|A \cup B|}$ |
