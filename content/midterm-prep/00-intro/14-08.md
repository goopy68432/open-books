# 08. 신경망과 역전파 (Neural Networks & Backpropagation) - 추가자료

---

## 입문 (Beginner)

### 신경망이란 무엇인가?

신경망(Neural Network)은 인간의 뇌 신경 구조에서 영감을 받은 계산 모델이다. 하지만 현대 신경망은 실제 뇌와는 상당히 다르므로, 이 비유에 너무 집착하지 않는 것이 좋다.

**핵심 아이디어**: 간단한 함수(뉴런)를 여러 층으로 쌓아 복잡한 함수를 만든다.

**비유**: 레고 블록. 하나하나는 단순하지만, 조합하면 복잡한 구조를 만들 수 있다.

---

### 퍼셉트론 (Perceptron)

가장 단순한 신경망 단위. Frank Rosenblatt(1958)이 제안.

```
  x₁ ──w₁──╲
             ╲
  x₂ ──w₂───→ Σ + b ──→ σ(·) ──→ ŷ
             ╱
  x₃ ──w₃──╱
```

$$\hat{y} = \sigma\left(\sum_{i=1}^{d} w_i x_i + b\right) = \sigma(w^T x + b)$$

- $x$: 입력 벡터
- $w$: 가중치 (weights)
- $b$: 편향 (bias)
- $\sigma$: 활성화 함수 (activation function)

**퍼셉트론의 한계**: XOR 문제를 풀 수 없다 (Minsky & Papert, 1969). 선형 분리 가능한 문제만 해결 가능.

```
AND (가능 ✓)          XOR (불가능 ✗)
  ·─── 1               ·─── 1
  │  ╲                  │ ╲   ╱ ?
  │   ╲ 결정 경계       │  ╲ ╱
  │    ╲                │   ╳
  0 ── · ── 1           0 ── · ── 1
```

**해결**: 여러 퍼셉트론을 층으로 쌓으면 (Multi-Layer Perceptron) 비선형 문제 해결 가능.

---

### 다층 퍼셉트론 (Multi-Layer Perceptron, MLP)

```
입력층        은닉층 1      은닉층 2      출력층
  ○───────────○            ○
  ○───────────○────────────○────────────○
  ○───────────○            ○            ○
  ○───────────○────────────○
              ○            ○
```

- **입력층(Input Layer)**: 데이터를 받는 층
- **은닉층(Hidden Layer)**: 중간 계산을 수행. 여러 개일 수 있음
- **출력층(Output Layer)**: 최종 예측을 출력

**층이 깊어지면** 더 복잡한 패턴을 학습할 수 있다 → 이것이 "딥(deep)" 러닝의 의미.

---

### 활성화 함수 (Activation Functions) - 직관적 이해

활성화 함수가 없으면 아무리 많은 층을 쌓아도 전체가 하나의 선형 변환이다:

$$W_2(W_1 x + b_1) + b_2 = (W_2 W_1)x + (W_2 b_1 + b_2) = W'x + b'$$

활성화 함수는 **비선형성(non-linearity)**을 도입하여 신경망이 복잡한 함수를 표현할 수 있게 해준다.

#### 주요 활성화 함수 목록

| 이름 | 수식 | 특징 |
|------|------|------|
| Sigmoid | $\frac{1}{1+e^{-z}}$ | 0~1 출력, 기울기 소실 문제 |
| Tanh | $\frac{e^z - e^{-z}}{e^z + e^{-z}}$ | -1~1 출력, 영점 중심 |
| ReLU | $\max(0, z)$ | 단순, 빠름, 죽은 뉴런 문제 |
| Leaky ReLU | $\max(0.01z, z)$ | 죽은 뉴런 문제 완화 |
| GELU | $z \cdot \Phi(z)$ | Transformer에서 주로 사용 |
| Swish/SiLU | $z \cdot \sigma(z)$ | 자기 게이팅, 부드러운 ReLU |

**시각적 비교**:

```
Sigmoid           Tanh              ReLU
  1 ·····──────   1 ·····──────     ╱
    │    ╱          │    ╱        ╱
0.5 │  ╱          0 ├──╱        ╱
    │╱              │╱        ──┤
  0 ├──────      -1 ├──────     0
```

### 순전파 (Forward Pass) - 비유로 이해

신경망의 순전파는 "공장의 조립 라인"과 같다.

1. 원자재(입력 데이터)가 들어온다
2. 각 공정(층)에서 가공(가중치 곱 + 편향 + 활성화)된다
3. 최종 제품(예측)이 나온다

**2층 신경망의 순전파 예시**:

$$z^{(1)} = W^{(1)}x + b^{(1)}$$
$$a^{(1)} = \sigma(z^{(1)})$$
$$z^{(2)} = W^{(2)}a^{(1)} + b^{(2)}$$
$$\hat{y} = \text{softmax}(z^{(2)})$$

---

### 역전파 (Backpropagation) - 비유로 이해

역전파는 "결함 추적 시스템"과 같다.

1. 최종 제품(예측)에서 결함(오차)이 발견됨
2. 어떤 공정(층)이 결함에 얼마나 기여했는지 역추적
3. 각 공정의 설정(가중치)을 결함을 줄이는 방향으로 조정

**핵심 원리**: 미적분의 **연쇄 법칙(Chain Rule)**

$$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$$

---

### 보편 근사 정리 (Universal Approximation Theorem) - 직관

**정리** (Cybenko, 1989; Hornik, 1991): 하나의 은닉층을 가진 신경망은 충분한 뉴런이 있으면 임의의 연속 함수를 원하는 정밀도로 근사할 수 있다.

**비유**: 충분히 많은 계단 함수(ReLU의 조합)를 합치면 어떤 곡선이든 근사할 수 있다.

```
실제 함수:    ╭──╮   ╭─
            ╱    ╲ ╱
   ─────╱      ╲╱

근사:         ┌──┐   ┌─
            ┌┘  └┐ ┌┘
   ─────┘    └┘
```

**주의**: 이 정리는 "존재성"만 보장하며, 어떻게 학습하는지는 말해주지 않는다. 또한 필요한 뉴런 수가 지수적으로 클 수 있다 → 깊은 네트워크가 실질적으로 더 효율적.

## 중급 (Intermediate)

### 순전파의 수학적 표현

$L$층 신경망의 순전파:

$$\text{For } l = 1, 2, \ldots, L:$$
$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$$
$$a^{(l)} = f^{(l)}(z^{(l)})$$

여기서 $a^{(0)} = x$ (입력), $f^{(l)}$은 $l$번째 층의 활성화 함수.

**차원 분석** (배치 크기 $B$, 층 $l$의 뉴런 수 $n_l$):
- $W^{(l)} \in \mathbb{R}^{n_l \times n_{l-1}}$
- $b^{(l)} \in \mathbb{R}^{n_l}$
- $z^{(l)}, a^{(l)} \in \mathbb{R}^{n_l \times B}$ (배치 처리 시)

---

### 계산 그래프 (Computational Graph)

신경망의 연산을 노드와 엣지로 표현한 방향성 비순환 그래프(DAG).

#### 예시: 2층 신경망의 계산 그래프

```
x ──→ [×W¹] ──→ [+b¹] ──→ [ReLU] ──→ [×W²] ──→ [+b²] ──→ [softmax] ──→ [CE Loss]
       │           │         │          │           │                        │
       W¹          b¹       z¹→a¹       W²          b²                      y(정답)
```

더 세분화하면:

```
         W¹    b¹              W²    b²         y
          │     │               │     │          │
          ▼     ▼               ▼     ▼          ▼
x ──→ [matmul]──→[add]──→[relu]──→[matmul]──→[add]──→[softmax]──→[cross_entropy]──→ L
         z¹_pre   z¹      a¹      z²_pre    z²        ŷ               Loss
```

**각 노드는**:
1. 순전파: 입력으로부터 출력 계산
2. 역전파: 출력의 그래디언트로부터 입력의 그래디언트 계산

---

### 역전파 알고리즘 (Backpropagation) - 상세 유도

#### 단계별 역전파 예시: 2층 네트워크

**네트워크 구조**:

$$x \xrightarrow{W^{(1)}, b^{(1)}} z^{(1)} \xrightarrow{\text{ReLU}} a^{(1)} \xrightarrow{W^{(2)}, b^{(2)}} z^{(2)} \xrightarrow{\text{softmax}} \hat{y} \xrightarrow{\text{CE}} L$$

**순전파**:

1. $z^{(1)} = W^{(1)}x + b^{(1)}$ ($n_1$차원)
2. $a^{(1)} = \text{ReLU}(z^{(1)})$
3. $z^{(2)} = W^{(2)}a^{(1)} + b^{(2)}$ ($K$차원, $K$는 클래스 수)
4. $\hat{y} = \text{softmax}(z^{(2)})$
5. $L = -\sum_k y_k \log \hat{y}_k$ (cross-entropy loss)

**역전파 (출력에서 입력 방향으로)**:

**Step 1**: $\frac{\partial L}{\partial z^{(2)}}$ 계산

Softmax + Cross-Entropy의 그래디언트 (잘 알려진 결과):

$$\boxed{\frac{\partial L}{\partial z^{(2)}} = \hat{y} - y}$$

이를 $\delta^{(2)}$로 표기. 이 간결한 결과는 softmax와 cross-entropy를 함께 미분할 때 얻어진다.

**유도**: $\hat{y}_k = \text{softmax}(z^{(2)})_k$일 때, $\frac{\partial \hat{y}_k}{\partial z^{(2)}_j} = \hat{y}_k(\delta_{kj} - \hat{y}_j)$이고:

$$\frac{\partial L}{\partial z^{(2)}_j} = -\sum_k \frac{y_k}{\hat{y}_k} \cdot \hat{y}_k(\delta_{kj} - \hat{y}_j) = -y_j + \hat{y}_j\sum_k y_k = \hat{y}_j - y_j$$

**Step 2**: $W^{(2)}$와 $b^{(2)}$의 그래디언트

$$\frac{\partial L}{\partial W^{(2)}} = \delta^{(2)} (a^{(1)})^T$$

$$\frac{\partial L}{\partial b^{(2)}} = \delta^{(2)}$$

**Step 3**: $\frac{\partial L}{\partial a^{(1)}}$ 계산 (오차 역전파)

$$\frac{\partial L}{\partial a^{(1)}} = (W^{(2)})^T \delta^{(2)}$$

**Step 4**: $\frac{\partial L}{\partial z^{(1)}}$ 계산 (ReLU 통과)

$$\delta^{(1)} = \frac{\partial L}{\partial z^{(1)}} = \frac{\partial L}{\partial a^{(1)}} \odot \text{ReLU}'(z^{(1)})$$

여기서 $\odot$는 원소별 곱(Hadamard product)이고:

$$\text{ReLU}'(z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z \leq 0 \end{cases}$$

**Step 5**: $W^{(1)}$와 $b^{(1)}$의 그래디언트

$$\frac{\partial L}{\partial W^{(1)}} = \delta^{(1)} x^T$$

$$\frac{\partial L}{\partial b^{(1)}} = \delta^{(1)}$$

#### 일반화: $L$층 네트워크의 역전파

$$\delta^{(L)} = \frac{\partial L}{\partial z^{(L)}} \quad (\text{출력층의 그래디언트})$$

$$\text{For } l = L, L-1, \ldots, 1:$$

$$\frac{\partial L}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$

$$\frac{\partial L}{\partial b^{(l)}} = \delta^{(l)}$$

$$\delta^{(l-1)} = \left((W^{(l)})^T \delta^{(l)}\right) \odot f'^{(l-1)}(z^{(l-1)})$$

### 구체적 수치 예제

**설정**: 입력 $x = [1, 2]^T$, 정답 $y = [0, 1]^T$ (클래스 2), 2층 네트워크

$$W^{(1)} = \begin{bmatrix} 0.1 & 0.3 \\ 0.2 & 0.4 \end{bmatrix}, \quad b^{(1)} = \begin{bmatrix} 0.1 \\ 0.1 \end{bmatrix}$$

$$W^{(2)} = \begin{bmatrix} 0.5 & 0.6 \\ 0.7 & 0.8 \end{bmatrix}, \quad b^{(2)} = \begin{bmatrix} 0.1 \\ 0.1 \end{bmatrix}$$

**순전파**:

1. $z^{(1)} = W^{(1)}x + b^{(1)} = \begin{bmatrix}0.1 \cdot 1 + 0.3 \cdot 2 + 0.1\\0.2 \cdot 1 + 0.4 \cdot 2 + 0.1\end{bmatrix} = \begin{bmatrix}0.8\\1.1\end{bmatrix}$

2. $a^{(1)} = \text{ReLU}(z^{(1)}) = \begin{bmatrix}0.8\\1.1\end{bmatrix}$ (모두 양수이므로 그대로)

3. $z^{(2)} = W^{(2)}a^{(1)} + b^{(2)} = \begin{bmatrix}0.5 \cdot 0.8 + 0.6 \cdot 1.1 + 0.1\\0.7 \cdot 0.8 + 0.8 \cdot 1.1 + 0.1\end{bmatrix} = \begin{bmatrix}1.16\\1.54\end{bmatrix}$

4. $\hat{y} = \text{softmax}(z^{(2)}) = \begin{bmatrix}\frac{e^{1.16}}{e^{1.16}+e^{1.54}}\\\frac{e^{1.54}}{e^{1.16}+e^{1.54}}\end{bmatrix} \approx \begin{bmatrix}0.406\\0.594\end{bmatrix}$

5. $L = -(0 \cdot \log 0.406 + 1 \cdot \log 0.594) \approx 0.521$

**역전파**:

Step 1: $\delta^{(2)} = \hat{y} - y = \begin{bmatrix}0.406\\-0.406\end{bmatrix}$

Step 2:
$$\frac{\partial L}{\partial W^{(2)}} = \delta^{(2)}(a^{(1)})^T = \begin{bmatrix}0.406\\-0.406\end{bmatrix}\begin{bmatrix}0.8 & 1.1\end{bmatrix} = \begin{bmatrix}0.325 & 0.447\\-0.325 & -0.447\end{bmatrix}$$

$$\frac{\partial L}{\partial b^{(2)}} = \begin{bmatrix}0.406\\-0.406\end{bmatrix}$$

Step 3:
$$\frac{\partial L}{\partial a^{(1)}} = (W^{(2)})^T\delta^{(2)} = \begin{bmatrix}0.5 & 0.7\\0.6 & 0.8\end{bmatrix}\begin{bmatrix}0.406\\-0.406\end{bmatrix} = \begin{bmatrix}-0.081\\-0.081\end{bmatrix}$$

Step 4: $\text{ReLU}'(z^{(1)}) = \begin{bmatrix}1\\1\end{bmatrix}$ (둘 다 양수였으므로)

$$\delta^{(1)} = \begin{bmatrix}-0.081\\-0.081\end{bmatrix} \odot \begin{bmatrix}1\\1\end{bmatrix} = \begin{bmatrix}-0.081\\-0.081\end{bmatrix}$$

Step 5:
$$\frac{\partial L}{\partial W^{(1)}} = \delta^{(1)}x^T = \begin{bmatrix}-0.081\\-0.081\end{bmatrix}\begin{bmatrix}1 & 2\end{bmatrix} = \begin{bmatrix}-0.081 & -0.163\\-0.081 & -0.163\end{bmatrix}$$

### 자동 미분 (Automatic Differentiation)

수치 미분(유한 차분)이나 기호 미분과 구별되는, 정확하고 효율적인 미분 방법.

#### 세 가지 미분 방법 비교

| 방법 | 원리 | 장점 | 단점 |
|------|------|------|------|
| 수치 미분 | $\frac{f(x+h)-f(x)}{h}$ | 구현 간단 | 근사, 느림, 수치 불안정 |
| 기호 미분 | 수식 전개 후 미분 | 정확한 수식 | 표현식 폭발 (expression swell) |
| 자동 미분 | 연쇄 법칙의 체계적 적용 | 정확, 효율적 | 구현 복잡 |

#### Forward Mode vs Reverse Mode

**Forward Mode (전방 모드)**:
- 입력에서 출력 방향으로 미분 전파
- 입력 변수 하나에 대한 모든 출력의 미분을 한 번에 계산
- $f: \mathbb{R}^n \to \mathbb{R}^m$에서 $n$번의 패스 필요
- **입력 적을 때 효율적** ($n < m$)

**Reverse Mode (역방 모드)**:
- 출력에서 입력 방향으로 미분 전파 = **역전파**
- 출력 변수 하나에 대한 모든 입력의 미분을 한 번에 계산
- $f: \mathbb{R}^n \to \mathbb{R}^m$에서 $m$번의 패스 필요
- **출력 적을 때 효율적** ($m < n$)

**딥러닝에서는** 출력이 스칼라(손실 함수 값) 하나이므로, **역방 모드가 압도적으로 유리**. 한 번의 역전파로 모든 매개변수의 그래디언트를 계산.

```
Forward Mode (n passes):      Reverse Mode (1 pass):
   ∂y/∂x₁, ∂y/∂x₂, ...        ∂L/∂x₁, ∂L/∂x₂, ..., ∂L/∂xₙ
   각각 별도 패스 필요              한 번의 역전파로 모두 계산
```

#### 자동 미분의 구현: 이중 수 (Dual Numbers, Forward Mode)

이중 수: $a + b\epsilon$ (여기서 $\epsilon^2 = 0$)

$$f(a + b\epsilon) = f(a) + f'(a) \cdot b\epsilon$$

함수 값과 미분 값이 동시에 계산된다.

### 활성화 함수 상세

#### Sigmoid

$$\sigma(z) = \frac{1}{1 + e^{-z}}, \quad \sigma'(z) = \sigma(z)(1 - \sigma(z))$$

- **문제**: $|z|$가 크면 $\sigma'(z) \approx 0$ → **기울기 소실(vanishing gradient)**
- $\sigma'(z)$의 최댓값은 $z=0$에서 $0.25$ → 층마다 그래디언트가 최소 $1/4$로 줄어듦

#### Tanh

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1, \quad \tanh'(z) = 1 - \tanh^2(z)$$

- Sigmoid보다 나음: 출력이 0 중심 → 그래디언트의 방향이 더 다양
- 여전히 포화(saturation) 문제 존재

#### ReLU (Rectified Linear Unit)

$$\text{ReLU}(z) = \max(0, z), \quad \text{ReLU}'(z) = \begin{cases}1 & z > 0\\0 & z \leq 0\end{cases}$$

- **장점**: 양수 영역에서 그래디언트 = 1 → 기울기 소실 완화, 계산 빠름
- **문제**: **죽은 뉴런(Dead Neuron)** — $z \leq 0$이면 그래디언트 0 → 영원히 비활성

**변형**:
- **Leaky ReLU**: $\max(\alpha z, z)$, $\alpha = 0.01$ → 음수 영역에도 작은 기울기
- **Parametric ReLU (PReLU)**: $\alpha$도 학습 가능한 매개변수
- **ELU**: $z > 0$이면 $z$, $z \leq 0$이면 $\alpha(e^z - 1)$

#### GELU (Gaussian Error Linear Unit)

$$\text{GELU}(z) = z \cdot \Phi(z) = z \cdot \frac{1}{2}\left[1 + \text{erf}\left(\frac{z}{\sqrt{2}}\right)\right]$$

근사: $\text{GELU}(z) \approx 0.5z\left(1 + \tanh\left[\sqrt{2/\pi}(z + 0.044715z^3)\right]\right)$

- **직관**: 입력 $z$를 확률적으로 통과시킴. $z$가 클수록 통과 확률 높음.
- GPT, BERT 등 Transformer 모델에서 표준으로 사용

#### Swish / SiLU (Sigmoid Linear Unit)

$$\text{Swish}(z) = z \cdot \sigma(\beta z)$$

$\beta = 1$일 때 SiLU: $\text{SiLU}(z) = z \cdot \sigma(z)$

- **자기 게이팅(self-gating)**: 입력 자체가 게이트 역할
- ReLU보다 부드럽고, 음수 영역에서 약간의 음의 출력 허용
- GELU와 유사한 성능, 더 단순한 수식

### 기울기 소실 / 폭발 문제 (Vanishing / Exploding Gradients)

#### 문제의 원인

$L$층 신경망에서 첫 번째 층의 그래디언트:

$$\frac{\partial L}{\partial W^{(1)}} \propto \prod_{l=2}^{L} W^{(l)} \cdot \text{diag}(f'(z^{(l-1)}))$$

이 곱이:
- 각 항이 1보다 작으면 → 지수적으로 0에 수렴 (**기울기 소실**)
- 각 항이 1보다 크면 → 지수적으로 발산 (**기울기 폭발**)

#### 기울기 소실의 예시 (Sigmoid)

$\sigma'(z) \leq 0.25$이므로, 층이 $L$개이면:

$$|\delta^{(1)}| \leq (0.25)^{L-1} \cdot |\delta^{(L)}|$$

$L = 10$이면: $(0.25)^9 \approx 3.8 \times 10^{-6}$ → 사실상 학습 불가능

#### 해결 방법

1. **ReLU 활성화 함수**: 양수 영역에서 그래디언트 = 1
2. **적절한 가중치 초기화**: Xavier, He 초기화
3. **배치 정규화 (Batch Normalization)**
4. **잔차 연결 (Residual Connection)**: $a^{(l)} = f(z^{(l)}) + a^{(l-1)}$
5. **LSTM/GRU** (순환 신경망에서)
6. **그래디언트 클리핑**: $\|g\| > \theta$이면 $g \leftarrow \theta \cdot g / \|g\|$

### 가중치 초기화 (Weight Initialization)

잘못된 초기화의 결과:
- 모두 0으로 초기화: 모든 뉴런이 동일한 그래디언트 → **대칭성 파괴 실패**
- 너무 크게 초기화: 활성화 포화 → 기울기 소실
- 너무 작게 초기화: 활성화 값이 0으로 수렴 → 기울기 소실

#### Xavier/Glorot 초기화 (2010)

**목표**: 각 층의 출력 분산이 입력 분산과 같도록 유지.

$$W^{(l)} \sim \mathcal{N}\left(0, \frac{2}{n_{l-1} + n_l}\right) \quad \text{또는} \quad \mathcal{U}\left(-\sqrt{\frac{6}{n_{l-1}+n_l}}, \sqrt{\frac{6}{n_{l-1}+n_l}}\right)$$

**유도**: 선형 활성화(또는 tanh의 선형 영역) 가정 하에:

$z^{(l)} = W^{(l)}a^{(l-1)}$에서 $\text{Var}(z_j^{(l)}) = n_{l-1} \cdot \text{Var}(W_{ji}^{(l)}) \cdot \text{Var}(a_i^{(l-1)})$

분산 보존 조건:
- 순전파: $n_{l-1} \cdot \text{Var}(W^{(l)}) = 1$
- 역전파: $n_l \cdot \text{Var}(W^{(l)}) = 1$
- 절충: $\text{Var}(W^{(l)}) = \frac{2}{n_{l-1} + n_l}$

**적합한 활성화 함수**: Sigmoid, Tanh

#### He 초기화 (2015)

**ReLU를 위한 초기화**. ReLU는 음수를 0으로 만들므로 분산이 절반으로 줄어드는 것을 보상:

$$W^{(l)} \sim \mathcal{N}\left(0, \frac{2}{n_{l-1}}\right)$$

**유도**: ReLU 가정 하에 $\text{Var}(a^{(l)}) = \frac{1}{2} n_{l-1} \cdot \text{Var}(W^{(l)}) \cdot \text{Var}(a^{(l-1)})$

분산 보존: $\frac{1}{2} n_{l-1} \cdot \text{Var}(W^{(l)}) = 1 \Rightarrow \text{Var}(W^{(l)}) = \frac{2}{n_{l-1}}$

**적합한 활성화 함수**: ReLU, Leaky ReLU

| 초기화 | 분산 | 적합한 활성화 |
|--------|------|-------------|
| Xavier | $\frac{2}{n_{\text{in}} + n_{\text{out}}}$ | Sigmoid, Tanh |
| He | $\frac{2}{n_{\text{in}}}$ | ReLU, Leaky ReLU |

### 배치 정규화 (Batch Normalization, BN)

Ioffe & Szegedy (2015). 학습을 안정화하고 가속화하는 기법.

#### 알고리즘

미니배치 $B = \{z_1, \ldots, z_m\}$에 대해:

1. **배치 평균**: $\mu_B = \frac{1}{m}\sum_{i=1}^{m} z_i$

2. **배치 분산**: $\sigma_B^2 = \frac{1}{m}\sum_{i=1}^{m}(z_i - \mu_B)^2$

3. **정규화**: $\hat{z}_i = \frac{z_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$

4. **스케일 및 시프트**: $\tilde{z}_i = \gamma \hat{z}_i + \beta$

여기서 $\gamma$, $\beta$는 학습 가능한 매개변수, $\epsilon$은 수치 안정성을 위한 작은 상수.

#### BN의 효과

1. **내부 공변량 이동(Internal Covariate Shift) 완화**: 각 층의 입력 분포를 안정화
2. **더 높은 학습률 사용 가능**: 기울기 폭발 방지
3. **정칙화 효과**: 미니배치의 통계를 사용하므로 노이즈 도입
4. **초기화에 덜 민감**: 정규화가 스케일을 자동 조정

#### 추론 시

훈련 시 계산된 이동 평균(running mean/variance)을 사용:

$$\mu_{\text{running}} \leftarrow (1-\alpha)\mu_{\text{running}} + \alpha \mu_B$$
$$\sigma^2_{\text{running}} \leftarrow (1-\alpha)\sigma^2_{\text{running}} + \alpha \sigma^2_B$$

#### BN의 위치

일반적으로 **선형 변환 후, 활성화 함수 전**에 적용:

$$a = f(\text{BN}(Wx + b))$$

**참고**: BN이 평균을 빼므로 $b$ (편향)이 상쇄됨 → BN 사용 시 편향을 제거해도 무방.

#### BN의 역전파

$\hat{z}_i = \frac{z_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$에서의 그래디언트:

$$\frac{\partial L}{\partial \gamma} = \sum_i \frac{\partial L}{\partial \tilde{z}_i} \cdot \hat{z}_i$$

$$\frac{\partial L}{\partial \beta} = \sum_i \frac{\partial L}{\partial \tilde{z}_i}$$

$$\frac{\partial L}{\partial z_i} = \frac{\gamma}{\sqrt{\sigma_B^2 + \epsilon}} \left(\frac{\partial L}{\partial \tilde{z}_i} - \frac{1}{m}\sum_j \frac{\partial L}{\partial \tilde{z}_j} - \frac{\hat{z}_i}{m}\sum_j \frac{\partial L}{\partial \tilde{z}_j}\hat{z}_j\right)$$

### PyTorch autograd 실습 가이드

PyTorch의 `autograd`는 역방 모드 자동 미분을 구현한다.

#### 기본 사용법

```python
import torch

# requires_grad=True로 설정하면 연산이 추적됨
x = torch.tensor([2.0, 3.0], requires_grad=True)
W = torch.tensor([[1.0, 0.5], [0.3, 0.7]], requires_grad=True)

# 순전파
z = W @ x          # 행렬 곱
a = torch.relu(z)  # ReLU 활성화
loss = a.sum()     # 스칼라 손실

# 역전파
loss.backward()    # 자동으로 모든 그래디언트 계산

print(x.grad)  # ∂loss/∂x
print(W.grad)  # ∂loss/∂W
```

#### 주요 개념

1. **Tensor.grad**: `backward()` 호출 후 누적된 그래디언트
2. **Tensor.grad_fn**: 텐서를 생성한 연산 (계산 그래프의 노드)
3. **torch.no_grad()**: 그래디언트 계산 비활성화 (추론 시)
4. **detach()**: 텐서를 계산 그래프에서 분리
5. **retain_graph=True**: `backward()` 후에도 그래프 유지

#### 커스텀 autograd 함수

```python
class MyReLU(torch.autograd.Function):
    @staticmethod
    def forward(ctx, input):
        ctx.save_for_backward(input)
        return input.clamp(min=0)

    @staticmethod
    def backward(ctx, grad_output):
        input, = ctx.saved_tensors
        grad_input = grad_output.clone()
        grad_input[input < 0] = 0
        return grad_input

# 사용
output = MyReLU.apply(input_tensor)
```

#### 그래디언트 확인 (Gradient Checking)

수치 미분과 자동 미분을 비교하여 구현 검증:

```python
from torch.autograd import gradcheck

input = torch.randn(3, 3, dtype=torch.double, requires_grad=True)
test = gradcheck(MyReLU.apply, input, eps=1e-6, atol=1e-4)
print(f"Gradient check passed: {test}")
```

## 고급 (Advanced)

### 보편 근사 정리 (Universal Approximation Theorem) - 엄밀한 진술

#### Cybenko (1989) - 원본 정리

$\sigma$가 연속이고 시그모이드형(sigmoidal)이면, 다음 형태의 함수:

$$f(x) = \sum_{j=1}^{N} \alpha_j \sigma(w_j^T x + b_j)$$

의 집합은 $C([0,1]^d)$ (단위 큐브 위의 연속 함수 공간)에서 조밀하다(dense).

즉, 임의의 연속 함수 $g$와 $\epsilon > 0$에 대해, 충분히 큰 $N$이 존재하여:

$$\sup_{x \in [0,1]^d} |f(x) - g(x)| < \epsilon$$

#### Hornik (1991) - 일반화

비다항식(non-polynomial)인 임의의 연속 활성화 함수에 대해 성립.

#### 깊이의 이점 (Depth Efficiency)

Telgarsky (2016): $k$층 네트워크로 효율적으로 표현 가능하지만, $k-1$층으로는 지수적으로 많은 뉴런이 필요한 함수가 존재한다.

$$\text{Width needed for depth } k-1 \geq 2^{\Omega(k^{1/3})}$$

이는 깊은 네트워크가 얕은 네트워크보다 **표현적으로 더 효율적**임을 증명한다.

---

### 역전파의 시간/공간 복잡도 분석

#### 시간 복잡도

순전파와 역전파의 시간 복잡도는 동일한 차수:

$$T_{\text{backward}} = O(T_{\text{forward}})$$

이는 역전파가 순전파의 각 연산에 대해 상수 배의 추가 연산만 필요하기 때문이다 (Baur-Strassen 정리의 결과).

구체적으로, $L$층 네트워크에서 주요 연산은 행렬 곱:

$$T = O\left(\sum_{l=1}^{L} n_l \cdot n_{l-1}\right)$$

#### 공간 복잡도

역전파를 위해 순전파의 중간 결과를 저장해야 함:

$$S = O\left(\sum_{l=1}^{L} n_l\right)$$

**메모리-계산 트레이드오프**:
- **체크포인팅 (Gradient Checkpointing)**: 일부 중간 결과만 저장하고, 필요 시 재계산
  - $L$층을 $\sqrt{L}$개 세그먼트로 나누면: 메모리 $O(\sqrt{L})$, 시간 $O(2 \cdot T_{\text{forward}})$
- Chen et al. (2016): $O(\sqrt{n})$ 메모리로 $O(n)$ 계산 가능

### 자동 미분의 이론적 기초

#### Wengert List (Trace)

모든 계산을 기본 연산의 순서로 분해:

$$v_i = \phi_i(v_{\text{parents}(i)})$$

여기서 $\phi_i$는 기본 연산 ($+$, $\times$, $\exp$, $\log$, ...).

#### Jacobian 행렬과 자동 미분

$f: \mathbb{R}^n \to \mathbb{R}^m$의 Jacobian:

$$J = \frac{\partial f}{\partial x} \in \mathbb{R}^{m \times n}$$

- **Forward mode**: Jacobian-vector product (JVP): $Jv$ ($v \in \mathbb{R}^n$)
- **Reverse mode**: Vector-Jacobian product (VJP): $u^T J$ ($u \in \mathbb{R}^m$)

딥러닝에서 $m = 1$ (스칼라 손실)이므로 VJP가 한 번의 패스로 전체 그래디언트 $\nabla_x L = \frac{\partial L}{\partial x}$를 계산.

#### Higher-order 미분

2차 미분(Hessian) $H = \nabla^2 L$:
- 직접 계산: $O(n^2)$ 메모리, $O(n^2 \cdot T_{\text{forward}})$ 시간
- Hessian-vector product $Hv$: forward-over-reverse로 $O(n)$ 시간에 계산 가능

```python
# PyTorch에서 Hessian-vector product
v = torch.randn_like(params)
grad = torch.autograd.grad(loss, params, create_graph=True)[0]
Hv = torch.autograd.grad(grad, params, grad_outputs=v)[0]
```

### 배치 정규화의 이론적 분석

#### BN이 최적화를 돕는 이유 (Santurkar et al., 2018)

원래 주장된 "내부 공변량 이동 감소"보다는, BN이 **손실 함수의 landscape를 매끄럽게** 만드는 것이 핵심:

$$\|\nabla L_{\text{BN}}(\theta_1) - \nabla L_{\text{BN}}(\theta_2)\| \leq \beta_{\text{BN}} \|\theta_1 - \theta_2\|$$

여기서 $\beta_{\text{BN}} < \beta_{\text{no-BN}}$ (Lipschitz 상수 감소).

이는 그래디언트가 더 예측 가능하게 변하므로, 더 큰 학습률을 사용할 수 있음을 의미.

#### BN의 대안

| 방법 | 정규화 축 | 적합한 경우 |
|------|----------|-----------|
| Batch Norm | 배치 차원 | CNN, 큰 배치 |
| Layer Norm | 특성 차원 | RNN, Transformer |
| Instance Norm | 공간 차원 | Style Transfer |
| Group Norm | 채널 그룹 | 작은 배치 |
| RMS Norm | 특성 차원 (평균 제거 없음) | LLM (LLaMA 등) |

### 고급 최적화와 초기화 이론

#### 신호 전파 분석 (Mean Field Theory)

랜덤 초기화된 신경망에서 신호(활성화 값)와 그래디언트가 어떻게 전파되는지 분석.

$l$번째 층에서의 활성화 분포:

$$q^l = \sigma_w^2 \int \phi(z)^2 \mathcal{D}z \cdot q^{l-1} + \sigma_b^2$$

여기서 $\mathcal{D}z = \frac{1}{\sqrt{2\pi}}e^{-z^2/2}dz$.

**임계 초기화(Edge of Chaos)**: 분산이 층을 통해 불변인 고정점을 찾는 것이 최적의 초기화.

#### 정보 병목 이론 (Information Bottleneck)

Shwartz-Ziv & Tishby (2017): 학습 과정에서 은닉층은:

1. **적합(fitting) 단계**: $I(T;Y)$ 증가 (유용한 정보 보존)
2. **압축(compression) 단계**: $I(T;X)$ 감소 (불필요한 정보 제거)

여기서 $I(\cdot;\cdot)$는 상호 정보량(mutual information), $T$는 은닉 표현.

### 실전 팁 모음

#### 학습이 잘 안 될 때 체크리스트

1. **학습률이 적절한가?** 너무 크면 발산, 너무 작으면 수렴 안 함. 1e-3에서 시작.
2. **데이터 전처리를 했는가?** 입력을 평균 0, 분산 1로 정규화.
3. **가중치 초기화가 적절한가?** ReLU → He, Sigmoid/Tanh → Xavier.
4. **배치 크기가 적절한가?** 너무 작으면 노이즈, 너무 크면 일반화 저하.
5. **그래디언트가 정상인가?** `torch.nn.utils.clip_grad_norm_`으로 확인.
6. **손실 함수가 맞는가?** 분류 → CE, 회귀 → MSE.

#### 디버깅 전략

```
1. 먼저 1개 배치에 과적합 시도 → 학습 능력 확인
2. 학습률 범위 테스트 (1e-5 ~ 1e-1) → 적절한 범위 파악
3. 그래디언트 노름 모니터링 → 소실/폭발 확인
4. 각 층의 활성화 분포 시각화 → 죽은 뉴런 등 확인
5. 수치 그래디언트 검사 → 역전파 구현 검증
```

#### PyTorch 모범 코드 구조

```python
import torch
import torch.nn as nn

class TwoLayerNet(nn.Module):
    def __init__(self, d_in, d_hidden, d_out):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(d_in, d_hidden),
            nn.BatchNorm1d(d_hidden),
            nn.ReLU(),
            nn.Linear(d_hidden, d_out)
        )
        # He 초기화
        for m in self.modules():
            if isinstance(m, nn.Linear):
                nn.init.kaiming_normal_(m.weight, nonlinearity='relu')

    def forward(self, x):
        return self.net(x)

# 학습 루프
model = TwoLayerNet(784, 256, 10)
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()

for epoch in range(num_epochs):
    for x_batch, y_batch in dataloader:
        optimizer.zero_grad()             # 그래디언트 초기화
        logits = model(x_batch)           # 순전파
        loss = criterion(logits, y_batch) # 손실 계산
        loss.backward()                   # 역전파
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()                  # 가중치 업데이트
```

| 개념 | 핵심 수식/내용 | 한 줄 요약 |
|------|--------------|-----------|
| 퍼셉트론 | $\sigma(w^Tx + b)$ | 선형 분류기, XOR 불가 |
| MLP | 층 쌓기 | 비선형 문제 해결 |
| ReLU | $\max(0, z)$ | 기울기 소실 완화, 빠름 |

| Forward AD | JVP: $Jv$ | 입력 적을 때 유리 |
| Reverse AD | VJP: $u^TJ$ | 출력 적을 때 유리 (= 역전파) |
| Xavier 초기화 | $\text{Var} = 2/(n_{\text{in}}+n_{\text{out}})$ | Sigmoid/Tanh용 |
| He 초기화 | $\text{Var} = 2/n_{\text{in}}$ | ReLU용 |
| 배치 정규화 | $\gamma\frac{z-\mu}{\sigma} + \beta$ | 학습 안정화, landscape 매끄럽게 |

> **시험 대비 팁**: 2층 네트워크에서의 역전파 수식을 직접 유도할 수 있어야 한다. softmax + CE의 그래디언트가 $\hat{y} - y$로 간결해지는 유도 과정, Xavier/He 초기화의 유도, BN의 순전파/역전파 수식을 숙지할 것. 자동 미분에서 Forward vs Reverse mode의 복잡도 차이가 왜 발생하는지 설명할 수 있어야 한다.
