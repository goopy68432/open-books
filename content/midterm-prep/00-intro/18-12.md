# Part A: Transfer Learning

## [입문] Transfer Learning 개요

### 핵심 동기

딥러닝 모델은 대규모 데이터가 필요하지만, 실제 응용에서는 레이블된 데이터가 부족한 경우가 많다. **Transfer Learning**은 소스 도메인(source domain)에서 학습한 지식을 타겟 도메인(target domain)으로 전이하는 기법이다.

### 기본 패러다임

```
[대규모 데이터셋] → Pre-training → [Pre-trained Model]
                                          ↓
[소규모 타겟 데이터셋] → Fine-tuning → [Task-specific Model]
```

### 1. Pre-training (사전학습)

대규모 데이터셋(예: ImageNet 1.4M장, BookCorpus+Wikipedia)에서 일반적인 표현(representation)을 학습한다.

**Vision 예시:**
- ImageNet에서 학습한 CNN → 하위 레이어는 엣지/텍스처, 상위 레이어는 의미적 패턴 학습

**NLP 예시:**
- 대규모 텍스트 코퍼스에서 언어 모델 학습 → 문법, 의미, 세계 지식 획득

### 2. Fine-tuning (미세조정)

사전학습된 모델의 파라미터를 타겟 태스크에 맞게 추가 학습한다.

**전략:**

| 전략 | 방법 | 적용 상황 |
|------|------|-----------|
| Full Fine-tuning | 모든 파라미터 업데이트 | 타겟 데이터 충분, 도메인 차이 클 때 |
| Partial Fine-tuning | 상위 레이어만 업데이트 | 타겟 데이터 적당, 도메인 유사 |
| Linear Probing | 최종 분류기만 학습 | 타겟 데이터 매우 적을 때 |

**학습률 설정:**
- 사전학습 레이어: 작은 학습률 ($\eta_{\text{base}} \approx 10^{-5}$)
- 새로 추가된 레이어: 큰 학습률 ($\eta_{\text{new}} \approx 10^{-3}$)
- **Discriminative fine-tuning**: 레이어별 다른 학습률 적용

### 3. Feature Extraction (특징 추출)

사전학습된 모델을 고정(frozen)하고 중간 표현을 특징 벡터로 사용한다.

$$\mathbf{z} = f_{\theta^*}(\mathbf{x}), \quad \theta^* \text{ (frozen)}$$

이 특징 벡터를 SVM, 로지스틱 회귀 등 간단한 분류기에 입력한다.

**장점:** 계산 비용 저렴, 과적합 방지
**단점:** 도메인 차이가 크면 성능 저하

## [중급] Domain Adaptation

### 형식적 정의

- **소스 도메인**: $\mathcal{D}_S = \{(\mathbf{x}_i^s, y_i^s)\}_{i=1}^{n_s}$, 분포 $P_S(\mathbf{x}, y)$
- **타겟 도메인**: $\mathcal{D}_T = \{(\mathbf{x}_j^t)\}_{j=1}^{n_t}$ (레이블 없음), 분포 $P_T(\mathbf{x}, y)$
- **목표**: $P_S \neq P_T$일 때 타겟에서 좋은 성능 달성

### Domain Adaptation의 유형

| 유형 | 조건 | 예시 |
|------|------|------|
| Covariate Shift | $P_S(\mathbf{x}) \neq P_T(\mathbf{x})$, $P(y|\mathbf{x})$ 동일 | 합성 이미지 → 실제 이미지 |
| Label Shift | $P_S(y) \neq P_T(y)$, $P(\mathbf{x}|y)$ 동일 | 클래스 비율 변화 |
| Concept Drift | $P_S(y|\mathbf{x}) \neq P_T(y|\mathbf{x})$ | 시간에 따른 의미 변화 |

### Domain-Adversarial Neural Network (DANN)

$$\min_{\theta_f, \theta_y} \max_{\theta_d} \; \mathcal{L}_y(\theta_f, \theta_y) - \lambda \mathcal{L}_d(\theta_f, \theta_d)$$

- $\theta_f$: 특징 추출기 — 도메인 불변 특징 학습
- $\theta_y$: 레이블 예측기 — 태스크 성능 최대화
- $\theta_d$: 도메인 판별기 — 소스/타겟 구분 시도

**Gradient Reversal Layer (GRL)**: 역전파 시 도메인 판별기의 그래디언트 부호를 반전시켜, 특징 추출기가 도메인 불변 특징을 학습하도록 유도한다.

### Maximum Mean Discrepancy (MMD)

두 분포 간 거리를 재생 커널 힐베르트 공간(RKHS)에서 측정한다:

$$\text{MMD}^2(\mathcal{D}_S, \mathcal{D}_T) = \left\| \frac{1}{n_s}\sum_{i=1}^{n_s}\phi(\mathbf{x}_i^s) - \frac{1}{n_t}\sum_{j=1}^{n_t}\phi(\mathbf{x}_j^t) \right\|_{\mathcal{H}}^2$$

특징 공간에서 소스와 타겟의 MMD를 최소화하는 방향으로 학습한다.

## [중급] Few-Shot Learning & Meta-Learning

### Few-Shot Learning 설정

- **$N$-way $K$-shot**: $N$개 클래스, 각 클래스 $K$개 예시
- **Support set** $\mathcal{S}$: 학습용 소량 데이터
- **Query set** $\mathcal{Q}$: 평가용 데이터
- **에피소드 학습(Episodic training)**: 여러 에피소드에서 반복 학습

### 접근법 분류

**1. Metric-based (거리 기반)**

쿼리 샘플과 서포트 샘플 간 거리를 측정하여 분류한다.

- **Siamese Network**: 쌍(pair) 입력의 유사도 학습
- **Prototypical Network**: 클래스 프로토타입(평균 임베딩)과의 거리로 분류

$$\mathbf{c}_k = \frac{1}{|\mathcal{S}_k|} \sum_{(\mathbf{x}_i, y_i) \in \mathcal{S}_k} f_\theta(\mathbf{x}_i)$$

$$P(y=k|\mathbf{x}) = \frac{\exp(-d(f_\theta(\mathbf{x}), \mathbf{c}_k))}{\sum_{k'} \exp(-d(f_\theta(\mathbf{x}), \mathbf{c}_{k'}))}$$

- **Matching Network**: attention 기반 가중 이웃 분류

**2. Optimization-based (최적화 기반)**

### MAML (Model-Agnostic Meta-Learning)

핵심 아이디어: **좋은 초기 파라미터**를 찾아, 소량의 그래디언트 스텝으로 새 태스크에 적응할 수 있게 한다.

**알고리즘:**

1. 태스크 $\mathcal{T}_i$ 샘플링
2. **Inner loop** (태스크 적응):
$$\theta_i' = \theta - \alpha \nabla_\theta \mathcal{L}_{\mathcal{T}_i}(\theta)$$
3. **Outer loop** (메타 업데이트):
$$\theta \leftarrow \theta - \beta \nabla_\theta \sum_{\mathcal{T}_i} \mathcal{L}_{\mathcal{T}_i}(\theta_i')$$

**핵심 포인트:**
- Inner loop의 그래디언트를 통해 다시 미분 → **이차 미분(second-order gradient)** 필요
- First-order MAML (FOML): 이차 미분 무시하여 계산 효율화
- Reptile: $\theta \leftarrow \theta + \epsilon(\theta_i' - \theta)$ — 더 단순한 변형

```
메타-학습 루프:
┌─────────────────────────────────┐
│  for each meta-batch:           │
│    for each task T_i:           │
│      θ'_i = θ - α∇L_T_i(θ)    │  ← Inner loop
│    θ = θ - β∇Σ L_T_i(θ'_i)    │  ← Outer loop (meta-update)
└─────────────────────────────────┘
```

---

## [고급] MAML 이론적 분석

### MAML과 Feature Reuse

Raghu et al. (2020)의 분석:
- MAML의 성능은 주로 **표현 학습(representation learning)**에서 기인
- Inner loop는 주로 분류 헤드를 적응시키는 역할
- ANIL (Almost No Inner Loop): 내부 루프에서 헤드만 업데이트해도 유사한 성능

### 수렴 보장

MAML의 메타 목적함수가 비볼록임에도, 적절한 조건 하에서 $\epsilon$-일차 정상점으로 수렴:

$$\|\nabla \mathcal{F}(\theta)\|^2 \leq \epsilon \quad \text{after} \; O(1/\epsilon^2) \; \text{iterations}$$

조건: Lipschitz 연속 그래디언트, 유계 분산

## [입문] Self-Supervised Learning 개요

### 핵심 아이디어

레이블 없는 데이터에서 **pretext task**(사전 과제)를 정의하여 유용한 표현을 학습한다.

$$\text{레이블 없는 데이터} \xrightarrow{\text{pretext task}} \text{풍부한 표현} \xrightarrow{\text{downstream task}} \text{최종 성능}$$

### Pretext Task 예시

| 분야 | Pretext Task | 설명 |
|------|-------------|------|
| Vision | Rotation prediction | 이미지 회전 각도(0°, 90°, 180°, 270°) 예측 |
| Vision | Jigsaw puzzle | 패치 순서 맞추기 |
| Vision | Colorization | 흑백 → 컬러 복원 |
| NLP | Masked LM | 마스킹된 토큰 예측 (BERT) |
| NLP | Next sentence prediction | 문장 쌍의 연속성 판단 |
| Audio | Temporal order | 오디오 세그먼트 순서 예측 |

## [중급] Contrastive Learning

### 기본 원리

**양성 쌍(positive pair)**은 가깝게, **음성 쌍(negative pair)**은 멀리 배치하는 표현 학습.

### InfoNCE Loss

$$\mathcal{L}_{\text{InfoNCE}} = -\log \frac{\exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_k)/\tau)}$$

- $\mathbf{z}_i, \mathbf{z}_j$: 양성 쌍의 표현
- $\tau$: 온도 파라미터 (sharpness 조절)
- $\text{sim}(\mathbf{u}, \mathbf{v}) = \mathbf{u}^\top \mathbf{v} / (\|\mathbf{u}\| \|\mathbf{v}\|)$: 코사인 유사도

**정보이론적 해석**: InfoNCE는 $I(\mathbf{z}_i; \mathbf{z}_j)$ (상호정보량)의 하한을 최대화한다.

### SimCLR (Simple Framework for Contrastive Learning of Visual Representations)

**파이프라인:**
```
이미지 x
  ├─ augmentation t  → x̃_i → Encoder f(·) → h_i → Projector g(·) → z_i
  └─ augmentation t' → x̃_j → Encoder f(·) → h_j → Projector g(·) → z_j
                                                          ↓
                                                   InfoNCE Loss
```

**핵심 설계 요소:**
1. **데이터 증강 조합**: Random crop + Color jitter가 가장 효과적
2. **Projection head** $g(\cdot)$: 비선형 MLP (학습 후 제거, $h$를 downstream에 사용)
3. **큰 배치 크기**: 더 많은 음성 쌍 → 더 나은 성능 (배치 4096~8192)
4. **온도** $\tau$: 작을수록 hard negative에 집중 (보통 0.07~0.5)

**Projection head가 필요한 이유:**
- $g(\cdot)$가 태스크 특정 정보를 흡수하여 $h$에 더 일반적인 표현이 남음
- $g(\cdot)$ 없이 $h$에 직접 대조 손실 적용 시 정보 손실 발생

### MoCo (Momentum Contrast)

SimCLR의 큰 배치 문제를 해결하기 위해 **큐(queue)**와 **모멘텀 인코더**를 도입.

**구조:**
```
Query encoder f_q(θ_q): 일반적 역전파로 업데이트
Key encoder f_k(θ_k):  모멘텀 업데이트 (느리게 변화)

θ_k ← m·θ_k + (1-m)·θ_q,    m = 0.999
```

**Queue**: 최근 미니배치의 키를 저장하는 FIFO 큐 → 배치 크기와 독립적으로 많은 음성 쌍 확보

**장점:**
- 메모리 효율적 (큰 배치 불필요)
- 키 인코더의 일관성 유지 (모멘텀 업데이트)

### BYOL (Bootstrap Your Own Latent)

**음성 쌍 없이** 학습하는 획기적 접근법.

```
Online network:  x̃_i → f_θ → g_θ → predictor q_θ → p_i
Target network:  x̃_j → f_ξ → g_ξ ────────────────→ z_j (stop gradient)

Loss: L = 2 - 2·⟨p_i, z_j⟩ / (‖p_i‖·‖z_j‖)
Target update: ξ ← τξ + (1-τ)θ
```

**Collapse를 피하는 이유 (직관):**
1. **Predictor 비대칭성**: online만 predictor 보유
2. **모멘텀 타겟**: 느리게 변하는 타겟이 안정적 학습 신호 제공
3. **배치 정규화**: 배치 내 통계가 암묵적으로 음성 역할 (논란 있음)

## [중급] Masked Prediction

### BERT (Bidirectional Encoder Representations from Transformers)

**Masked Language Modeling (MLM):**
- 입력 토큰의 15%를 랜덤 마스킹
  - 80%: `[MASK]` 토큰으로 대체
  - 10%: 랜덤 토큰으로 대체
  - 10%: 원본 유지
- 마스킹된 위치의 원래 토큰을 예측

$$\mathcal{L}_{\text{MLM}} = -\sum_{i \in \mathcal{M}} \log P(x_i | \mathbf{x}_{\backslash \mathcal{M}}; \theta)$$

여기서 $\mathcal{M}$은 마스킹된 위치의 집합, $\mathbf{x}_{\backslash \mathcal{M}}$는 마스킹되지 않은 토큰.

### MAE (Masked Autoencoder)

비전에 마스크 예측을 적용한 방법 (He et al., 2022).

**구조:**
```
입력 이미지 → 패치화 → 75% 마스킹 → 가시 패치만 인코더 입력
                                              ↓
              마스크 토큰 추가 ← 인코더 출력 + 마스크 토큰 → 디코더 → 픽셀 복원
```

**설계 철학:**
- 높은 마스킹 비율 (75%): NLP(15%)보다 훨씬 높음 — 이미지의 redundancy가 높기 때문
- 비대칭 구조: 인코더는 가시 패치만 처리 → 계산 효율성 (75% 절약)
- 디코더는 가벼운 구조로 충분

**NLP vs Vision 마스킹 비율 차이의 이유:**
- 언어: 높은 information density → 적은 마스킹으로도 어려운 문제
- 이미지: 공간적 중복성(spatial redundancy) 높음 → 많이 마스킹해야 비자명한(non-trivial) 문제

### CLIP (Contrastive Language-Image Pre-training)

이미지와 텍스트의 **멀티모달 대조 학습**.

$$\mathcal{L}_{\text{CLIP}} = -\frac{1}{N}\sum_{i=1}^{N}\left[\log\frac{\exp(\mathbf{z}_i^{\text{img}} \cdot \mathbf{z}_i^{\text{txt}}/\tau)}{\sum_j \exp(\mathbf{z}_i^{\text{img}} \cdot \mathbf{z}_j^{\text{txt}}/\tau)} + \log\frac{\exp(\mathbf{z}_i^{\text{txt}} \cdot \mathbf{z}_i^{\text{img}}/\tau)}{\sum_j \exp(\mathbf{z}_i^{\text{txt}} \cdot \mathbf{z}_j^{\text{img}}/\tau)}\right]$$

**Zero-shot 분류:**
1. 클래스 이름으로 텍스트 프롬프트 생성: "a photo of a {class}"
2. 이미지 임베딩과 각 텍스트 임베딩의 유사도 계산
3. 가장 높은 유사도의 클래스를 예측

## [고급] Self-Supervised Learning의 이론적 이해

### Contrastive Learning과 Spectral Graph Theory

증강 그래프(augmentation graph)의 관점:
- 노드: 데이터 포인트 (또는 뷰)
- 엣지 가중치: 두 뷰가 같은 이미지에서 나올 확률
- InfoNCE 최적화 ≈ 증강 그래프의 라플라시안 고유벡터 학습

### Dimensional Collapse 문제

표현이 전체 공간이 아닌 저차원 부분공간으로 축소되는 현상.

**원인:** 특정 차원에 정보가 집중되고 나머지 차원이 무용해짐

**대응:**
- VICReg: Variance + Invariance + Covariance 정규화
- Barlow Twins: 교차상관 행렬을 항등행렬에 가깝게 유도

$$\mathcal{L}_{\text{BT}} = \underbrace{\sum_i (1 - \mathcal{C}_{ii})^2}_{\text{invariance}} + \lambda \underbrace{\sum_i \sum_{j \neq i} \mathcal{C}_{ij}^2}_{\text{redundancy reduction}}$$

여기서 $\mathcal{C}_{ij} = \frac{\sum_b z_{b,i}^A z_{b,j}^B}{\sqrt{\sum_b (z_{b,i}^A)^2} \sqrt{\sum_b (z_{b,j}^B)^2}}$

## [입문] 생성 모델 개요

### 목표

데이터 분포 $p_{\text{data}}(\mathbf{x})$를 모델 $p_\theta(\mathbf{x})$로 근사하고, 이로부터 새로운 샘플을 생성한다.

### 생성 모델 분류

```
생성 모델
├── 명시적 밀도 (Explicit Density)
│   ├── 정확한 밀도 (Tractable)
│   │   ├── Autoregressive Models (PixelCNN, GPT)
│   │   └── Normalizing Flows
│   └── 근사 밀도 (Approximate)
│       ├── VAE (Variational)
│       └── Energy-Based Models
├── 암묵적 밀도 (Implicit Density)
│   └── GAN
└── Score-Based / Diffusion Models
```

---

## [중급] VAE (Variational Autoencoder)

### 동기

잠재 변수 모델에서 직접적인 MLE가 불가능한 이유:

$$p_\theta(\mathbf{x}) = \int p_\theta(\mathbf{x}|\mathbf{z}) p(\mathbf{z}) d\mathbf{z} \quad \text{(intractable)}$$

후방 분포 $p_\theta(\mathbf{z}|\mathbf{x})$도 계산 불가 → **변분 추론(variational inference)** 도입.

### ELBO 유도 (Evidence Lower Bound)

**출발점: 로그 주변 우도(log marginal likelihood)**

$$\log p_\theta(\mathbf{x}) = \log \int p_\theta(\mathbf{x}, \mathbf{z}) d\mathbf{z}$$

**근사 후방 분포** $q_\phi(\mathbf{z}|\mathbf{x})$를 도입:

$$\log p_\theta(\mathbf{x}) = \log \int \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\phi(\mathbf{z}|\mathbf{x})} q_\phi(\mathbf{z}|\mathbf{x}) d\mathbf{z}$$

**Jensen's inequality 적용** ($\log$는 오목함수):

$$\log p_\theta(\mathbf{x}) \geq \int q_\phi(\mathbf{z}|\mathbf{x}) \log \frac{p_\theta(\mathbf{x}, \mathbf{z})}{q_\phi(\mathbf{z}|\mathbf{x})} d\mathbf{z} = \text{ELBO}(\theta, \phi; \mathbf{x})$$

**ELBO 분해 (두 가지 형태):**

**형태 1: 복원 + 정규화**
$$\text{ELBO} = \underbrace{\mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}[\log p_\theta(\mathbf{x}|\mathbf{z})]}_{\text{복원 항 (Reconstruction)}} - \underbrace{D_{\text{KL}}(q_\phi(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))}_{\text{정규화 항 (Regularization)}}$$

**형태 2: 갭 관계**
$$\log p_\theta(\mathbf{x}) = \text{ELBO} + D_{\text{KL}}(q_\phi(\mathbf{z}|\mathbf{x}) \| p_\theta(\mathbf{z}|\mathbf{x}))$$

KL 발산은 항상 $\geq 0$이므로 ELBO는 항상 $\log p_\theta(\mathbf{x})$의 하한.

### Reparameterization Trick

$q_\phi(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\boldsymbol{\mu}_\phi(\mathbf{x}), \text{diag}(\boldsymbol{\sigma}_\phi^2(\mathbf{x})))$일 때:

$$\mathbf{z} = \boldsymbol{\mu}_\phi(\mathbf{x}) + \boldsymbol{\sigma}_\phi(\mathbf{x}) \odot \boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$

이를 통해 $\phi$에 대한 그래디언트를 역전파할 수 있다. (확률적 노드를 결정적 변환으로 대체)

### KL 항의 해석적 계산

$q = \mathcal{N}(\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}^2))$, $p = \mathcal{N}(\mathbf{0}, \mathbf{I})$일 때:

$$D_{\text{KL}}(q \| p) = \frac{1}{2} \sum_{j=1}^{d} \left(\mu_j^2 + \sigma_j^2 - \log \sigma_j^2 - 1\right)$$

### Posterior Collapse 문제

**현상:** $q_\phi(\mathbf{z}|\mathbf{x}) \approx p(\mathbf{z})$로 수렴하여 잠재 변수가 무시됨.

**원인:** 강력한 디코더(예: autoregressive)가 $\mathbf{z}$ 없이도 $\mathbf{x}$를 복원 가능

**해결책:**
- KL annealing: $\beta$를 0에서 1로 서서히 증가
- Free bits: KL의 최소값을 보장
- $\delta$-VAE: 디코더 용량 제한

## [중급] GAN (Generative Adversarial Network)

### Minimax Game

$$\min_G \max_D \; V(D, G) = \mathbb{E}_{\mathbf{x} \sim p_{\text{data}}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim p_z}[\log(1 - D(G(\mathbf{z})))]$$

- **판별자 $D$**: 진짜/가짜 구분 능력 최대화
- **생성자 $G$**: 판별자를 속이는 능력 최대화

### 최적 판별자

$G$가 고정일 때, 최적 판별자:

$$D^*_G(\mathbf{x}) = \frac{p_{\text{data}}(\mathbf{x})}{p_{\text{data}}(\mathbf{x}) + p_g(\mathbf{x})}$$

**유도:**

$$V(D, G) = \int \left[ p_{\text{data}}(\mathbf{x}) \log D(\mathbf{x}) + p_g(\mathbf{x}) \log(1 - D(\mathbf{x})) \right] d\mathbf{x}$$

각 $\mathbf{x}$에서 $f(D) = a \log D + b \log(1-D)$를 최대화:
$$f'(D) = \frac{a}{D} - \frac{b}{1-D} = 0 \implies D^* = \frac{a}{a+b}$$

### GAN 목적함수와 JS 발산의 관계

$D^*$를 대입하면:

$$V(D^*, G) = -\log 4 + 2 \cdot D_{\text{JS}}(p_{\text{data}} \| p_g)$$

$$D_{\text{JS}}(P \| Q) = \frac{1}{2}D_{\text{KL}}\left(P \| \frac{P+Q}{2}\right) + \frac{1}{2}D_{\text{KL}}\left(Q \| \frac{P+Q}{2}\right)$$

따라서 GAN은 JS 발산을 최소화한다. 최적해: $p_g = p_{\text{data}}$일 때 $D_{\text{JS}} = 0$.

### Training Dynamics

**교대 최적화:**
1. 판별자 $k$스텝 업데이트 (보통 $k=1$)
2. 생성자 1스텝 업데이트

**실전 트릭 — Non-saturating loss:**

원래 $G$의 목적함수: $\min_G \mathbb{E}[\log(1 - D(G(\mathbf{z})))]$ → 초기에 그래디언트 매우 작음

대안: $\max_G \mathbb{E}[\log D(G(\mathbf{z}))]$ → 초기에 강한 그래디언트 제공

### Mode Collapse

**현상:** 생성자가 데이터 분포의 일부 모드(mode)만 생성하고 나머지를 무시.

**원인:**
- $G$가 $D$를 속이는 특정 출력에 수렴
- $D$가 이를 감지하면 $G$가 다른 모드로 이동 → 순환 반복

**해결책:**

| 방법 | 설명 |
|------|------|
| Mini-batch discrimination | 배치 내 다양성 고려 |
| Unrolled GAN | $D$의 미래 업데이트를 $G$ 학습에 반영 |
| Spectral normalization | $D$의 Lipschitz 상수 제어 |
| WGAN | Wasserstein 거리 사용 |

### WGAN (Wasserstein GAN)

**JS 발산의 문제:** 두 분포의 지지(support)가 겹치지 않으면 JS 발산이 상수 → 유용한 그래디언트 없음.

**Wasserstein 거리 (Earth-Mover distance):**

$$W(p_{\text{data}}, p_g) = \inf_{\gamma \in \Pi(p_{\text{data}}, p_g)} \mathbb{E}_{(\mathbf{x}, \mathbf{y}) \sim \gamma}[\|\mathbf{x} - \mathbf{y}\|]$$

**Kantorovich-Rubinstein 쌍대성:**

$$W(p_{\text{data}}, p_g) = \sup_{\|f\|_L \leq 1} \left[ \mathbb{E}_{\mathbf{x} \sim p_{\text{data}}}[f(\mathbf{x})] - \mathbb{E}_{\mathbf{x} \sim p_g}[f(\mathbf{x})] \right]$$

$f$는 1-Lipschitz 함수. 실제 구현: weight clipping 또는 gradient penalty.

## [고급] Normalizing Flows

### 핵심 아이디어

가역 변환(invertible transformation) $f: \mathbb{R}^d \to \mathbb{R}^d$을 통해 간단한 분포를 복잡한 분포로 변환.

### Change of Variables Formula

$$\mathbf{x} = f(\mathbf{z}), \quad \mathbf{z} \sim p_Z(\mathbf{z})$$

$$p_X(\mathbf{x}) = p_Z(f^{-1}(\mathbf{x})) \left| \det \frac{\partial f^{-1}}{\partial \mathbf{x}} \right| = p_Z(\mathbf{z}) \left| \det \frac{\partial f}{\partial \mathbf{z}} \right|^{-1}$$

**로그 우도:**

$$\log p_X(\mathbf{x}) = \log p_Z(f^{-1}(\mathbf{x})) + \log \left| \det \frac{\partial f^{-1}}{\partial \mathbf{x}} \right|$$

### 변환의 합성

$$\mathbf{x} = f_K \circ f_{K-1} \circ \cdots \circ f_1(\mathbf{z})$$

$$\log p_X(\mathbf{x}) = \log p_Z(\mathbf{z}_0) + \sum_{k=1}^{K} \log \left| \det \frac{\partial f_k^{-1}}{\partial \mathbf{z}_k} \right|$$

### 실용적 아키텍처

**Coupling Layer (RealNVP):**

입력을 두 부분으로 분할: $\mathbf{z} = [\mathbf{z}_{1:d/2}, \mathbf{z}_{d/2+1:d}]$

$$\mathbf{x}_{1:d/2} = \mathbf{z}_{1:d/2}$$
$$\mathbf{x}_{d/2+1:d} = \mathbf{z}_{d/2+1:d} \odot \exp(s(\mathbf{z}_{1:d/2})) + t(\mathbf{z}_{1:d/2})$$

- $s, t$: 임의의 신경망 (가역성 불필요)
- 야코비안이 삼각행렬 → $\det$가 $O(d)$로 계산 가능

## [고급] Energy-Based Models (EBM)

### 정의

$$p_\theta(\mathbf{x}) = \frac{\exp(-E_\theta(\mathbf{x}))}{Z(\theta)}, \quad Z(\theta) = \int \exp(-E_\theta(\mathbf{x})) d\mathbf{x}$$

$E_\theta$는 에너지 함수, $Z(\theta)$는 분배 함수(partition function) — 일반적으로 계산 불가(intractable).

### 학습: Contrastive Divergence

$$\nabla_\theta \log p_\theta(\mathbf{x}) = -\nabla_\theta E_\theta(\mathbf{x}) + \mathbb{E}_{p_\theta}[\nabla_\theta E_\theta(\mathbf{x})]$$

두 번째 항의 기댓값을 MCMC(예: Langevin dynamics)로 근사:

$$\mathbf{x}_{t+1} = \mathbf{x}_t - \frac{\eta}{2} \nabla_\mathbf{x} E_\theta(\mathbf{x}_t) + \sqrt{\eta} \boldsymbol{\epsilon}_t, \quad \boldsymbol{\epsilon}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$

## [고급] Diffusion Models

### DDPM (Denoising Diffusion Probabilistic Models)

#### Forward Process (확산 과정)

데이터에 점진적으로 가우시안 노이즈를 추가:

$$q(\mathbf{x}_t | \mathbf{x}_{t-1}) = \mathcal{N}(\mathbf{x}_t; \sqrt{1-\beta_t}\mathbf{x}_{t-1}, \beta_t \mathbf{I})$$

$\alpha_t = 1 - \beta_t$, $\bar{\alpha}_t = \prod_{s=1}^t \alpha_s$로 정의하면:

$$q(\mathbf{x}_t | \mathbf{x}_0) = \mathcal{N}(\mathbf{x}_t; \sqrt{\bar{\alpha}_t}\mathbf{x}_0, (1-\bar{\alpha}_t)\mathbf{I})$$

$$\mathbf{x}_t = \sqrt{\bar{\alpha}_t}\mathbf{x}_0 + \sqrt{1-\bar{\alpha}_t}\boldsymbol{\epsilon}, \quad \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$$

$t \to T$에서 $\mathbf{x}_T \approx \mathcal{N}(\mathbf{0}, \mathbf{I})$.

#### Reverse Process (역확산 과정)

$$p_\theta(\mathbf{x}_{t-1} | \mathbf{x}_t) = \mathcal{N}(\mathbf{x}_{t-1}; \boldsymbol{\mu}_\theta(\mathbf{x}_t, t), \sigma_t^2 \mathbf{I})$$

**훈련 목적함수 (간소화):**

$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{t, \mathbf{x}_0, \boldsymbol{\epsilon}}\left[\|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)\|^2\right]$$

모델 $\boldsymbol{\epsilon}_\theta$는 $\mathbf{x}_t$에 추가된 노이즈 $\boldsymbol{\epsilon}$을 예측한다.

**ELBO와의 관계:**

$$\log p_\theta(\mathbf{x}_0) \geq \mathbb{E}_q\left[-\log\frac{p_\theta(\mathbf{x}_{0:T})}{q(\mathbf{x}_{1:T}|\mathbf{x}_0)}\right]$$

이를 분해하면:

$$-\text{ELBO} = \underbrace{D_{\text{KL}}(q(\mathbf{x}_T|\mathbf{x}_0) \| p(\mathbf{x}_T))}_{L_T} + \sum_{t=2}^{T}\underbrace{D_{\text{KL}}(q(\mathbf{x}_{t-1}|\mathbf{x}_t, \mathbf{x}_0) \| p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t))}_{L_{t-1}} - \underbrace{\log p_\theta(\mathbf{x}_0|\mathbf{x}_1)}_{L_0}$$

#### 샘플링 알고리즘

```
x_T ~ N(0, I)
for t = T, T-1, ..., 1:
    z ~ N(0, I) if t > 1 else z = 0
    x_{t-1} = (1/√α_t)(x_t - (β_t/√(1-ᾱ_t))ε_θ(x_t, t)) + σ_t·z
return x_0
```

### Score Matching

#### Score Function

$$\mathbf{s}_\theta(\mathbf{x}) = \nabla_\mathbf{x} \log p_\theta(\mathbf{x})$$

정규화 상수 $Z(\theta)$에 독립적이므로 계산 가능.

#### Denoising Score Matching

직접적인 score matching은 어려우므로, 노이즈가 추가된 분포에서 학습:

$$\mathcal{L}_{\text{DSM}} = \mathbb{E}_{q_\sigma(\tilde{\mathbf{x}}|\mathbf{x})p_{\text{data}}(\mathbf{x})}\left[\|\mathbf{s}_\theta(\tilde{\mathbf{x}}) - \nabla_{\tilde{\mathbf{x}}} \log q_\sigma(\tilde{\mathbf{x}}|\mathbf{x})\|^2\right]$$

가우시안 노이즈 $q_\sigma(\tilde{\mathbf{x}}|\mathbf{x}) = \mathcal{N}(\tilde{\mathbf{x}}; \mathbf{x}, \sigma^2\mathbf{I})$일 때:

$$\nabla_{\tilde{\mathbf{x}}} \log q_\sigma(\tilde{\mathbf{x}}|\mathbf{x}) = -\frac{\tilde{\mathbf{x}} - \mathbf{x}}{\sigma^2} = -\frac{\boldsymbol{\epsilon}}{\sigma}$$

**DDPM과 Score Matching의 연결:**

$$\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t) = -\sqrt{1-\bar{\alpha}_t} \cdot \mathbf{s}_\theta(\mathbf{x}_t, t)$$

노이즈 예측 ≡ 스코어 추정 (스케일 차이만 존재).

## [중급] Autoregressive Models

### 기본 원리

Chain rule을 통한 밀도 분해:

$$p(\mathbf{x}) = \prod_{i=1}^{d} p(x_i | x_1, \ldots, x_{i-1})$$

각 조건부 확률을 신경망으로 모델링한다.

**예시:**
- **PixelCNN**: 이미지 픽셀을 래스터 순서로 생성
- **GPT**: 텍스트 토큰을 왼쪽에서 오른쪽으로 생성
- **WaveNet**: 오디오 샘플을 순차 생성

**장점:** 정확한 우도 계산 가능, 안정적 훈련
**단점:** 순차적 생성 → 느린 샘플링

## [중급] Controllable Generation

### Conditional Generation

조건 $\mathbf{c}$에 따른 생성: $p(\mathbf{x}|\mathbf{c})$

**조건부 GAN:**
$$\min_G \max_D \; \mathbb{E}_{\mathbf{x}, \mathbf{c}}[\log D(\mathbf{x}, \mathbf{c})] + \mathbb{E}_{\mathbf{z}, \mathbf{c}}[\log(1 - D(G(\mathbf{z}, \mathbf{c}), \mathbf{c}))]$$

**Classifier-Free Guidance (Diffusion):**

$$\tilde{\boldsymbol{\epsilon}}_\theta(\mathbf{x}_t, t, \mathbf{c}) = (1+w) \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \mathbf{c}) - w \boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \varnothing)$$

- $w > 0$: guidance scale — 조건 방향으로 더 강하게 유도
- $w = 0$: 일반 조건부 생성
- 학습 시 $\mathbf{c}$를 일정 확률로 드롭하여 unconditional 모델도 동시 학습

### Latent Space Manipulation (VAE)

- **Arithmetic**: $\mathbf{z}_{\text{smile}} = \mathbf{z}_{\text{smile face}} - \mathbf{z}_{\text{neutral face}}$
- 새 이미지: $\mathbf{z}_{\text{new}} = \mathbf{z}_{\text{target}} + \alpha \cdot \mathbf{z}_{\text{smile}}$

### Text-Guided Generation

CLIP이나 T5 등 텍스트 인코더를 조건으로 사용:
- DALL-E 2: CLIP 이미지 임베딩을 diffusion으로 생성
- Stable Diffusion: 잠재 공간에서 diffusion 수행 (LDM)
- Imagen: T5-XXL 텍스트 인코더 + cascaded diffusion
