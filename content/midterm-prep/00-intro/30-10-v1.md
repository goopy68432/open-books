# 수학 기초 도구상자 (유도에 필요한 모든 것)

이 도구상자를 먼저 이해하면, 아래 유도 10개가 전부 읽힙니다.

---

## 도구 1: 함수란 무엇인가

**중1 설명**: 함수는 "기계"입니다. 뭔가를 넣으면 뭔가가 나옵니다.

```
입력 → [함수 기계] → 출력

예: f(x) = 2x + 1

  3 → [f] → 7      (3을 넣으면 2×3+1 = 7)
  5 → [f] → 11     (5를 넣으면 2×5+1 = 11)
```

**딥러닝에서**: 모델 h도 함수입니다. 이미지를 넣으면 "고양이일 확률 70%, 개일 확률 30%"가 나옵니다.

```
고양이 사진 → [모델 h] → [0.7, 0.3]
                          고양이  개
```

---

## 도구 2: 확률이란 무엇인가

**중1 설명**: 확률은 "얼마나 가능한가"를 0~1 사이 숫자로 표현한 것입니다.

```
0 = 절대 안 일어남
0.5 = 반반
1 = 반드시 일어남
```

**동전 예시**:
- 공정한 동전: 앞면 나올 확률 = 0.5
- 편향된 동전: 앞면 나올 확률 = 0.7 (앞면이 더 잘 나옴)

이 "0.7"을 θ(세타)라고 부릅니다. **θ를 찾는 것이 학습**입니다.

---

## 도구 3: 곱셈과 독립

**중1 설명**: 동전을 2번 던져서 둘 다 앞면이 나올 확률은?

만약 첫 번째 결과가 두 번째에 영향을 안 주면 (= **독립**):

```
P(앞면, 앞면) = P(앞면) × P(앞면) = 0.7 × 0.7 = 0.49
```

3번 연속 앞면:

```
P(앞, 앞, 앞) = 0.7 × 0.7 × 0.7 = 0.7³ = 0.343
```

일반적으로 n번 중 k번 앞면:

```
P = θᵏ × (1-θ)ⁿ⁻ᵏ

예: 10번 중 7번 앞면, θ=0.7이면
P = 0.7⁷ × 0.3³ = 0.00222...
```

**이것이 "우도(likelihood)"의 정체입니다.** "θ가 이 값이라면, 이 데이터가 나올 확률은 얼마?" 를 계산하는 것.

---

## 도구 4: 로그(log)란 무엇인가

**중1 설명**: 로그는 "거듭제곱의 반대"입니다.

```
2³ = 8    →    log₂(8) = 3    ("2를 몇 번 곱하면 8이 되나? 3번!")
10² = 100  →    log₁₀(100) = 2  ("10을 몇 번 곱하면 100? 2번!")
```

**로그의 핵심 성질 3가지** (이것만 외우면 유도가 다 됩니다):

```
① log(A × B) = log(A) + log(B)     ← 곱셈이 덧셈이 됨!
② log(Aⁿ) = n × log(A)            ← 거듭제곱이 곱셈이 됨!
③ log는 항상 오르막길               ← A < B이면 log(A) < log(B)
```

**왜 로그를 쓰나?**

```
원래:     P = 0.7 × 0.7 × 0.7 × ... × 0.7  (100번 곱하면?)
           = 0.7¹⁰⁰ = 0.0000000000000003   ← 컴퓨터가 0으로 처리해버림!

로그:     log P = log(0.7) × 100 = -0.155 × 100 = -15.5   ← 다룰 수 있는 숫자!
```

그리고 성질 ①에 의해:

```
log(0.7 × 0.7 × 0.7) = log(0.7) + log(0.7) + log(0.7)
```

**곱셈이 덧셈이 되니까 미분도 쉬워집니다!**

---

## 도구 5: 미분이란 무엇인가

**중1 설명**: 미분은 "기울기"입니다. 산의 경사면이 얼마나 가파른지 알려줍니다.

```
  ^
  |     /       ← 기울기 = 양수 (오르막)
  |    /
  |   /
  |  /
  +---------->

  ^
  | \           ← 기울기 = 음수 (내리막)
  |  \
  |   \
  |    \
  +---------->

  ^
  | ___         ← 기울기 = 0 (꼭대기 또는 바닥!)
  |/   \
  |     \
  +---------->
```

**핵심**: 기울기가 0인 곳이 **최댓값 또는 최솟값**입니다.

**기본 미분 공식** (이것만 알면 됨):

```
f(x) = xⁿ      →   f'(x) = n × xⁿ⁻¹

예:
  f(x) = x²    →   f'(x) = 2x
  f(x) = x³    →   f'(x) = 3x²
  f(x) = x     →   f'(x) = 1
  f(x) = 5     →   f'(x) = 0  (상수는 기울기 없음)

특수:
  f(x) = log(x)  →   f'(x) = 1/x     ← 이거 중요!
  f(x) = eˣ      →   f'(x) = eˣ      ← 자기 자신!
```

---

## 도구 6: "최대화"와 "최소화"

**중1 설명**:

- **최대화**: f(x)가 가장 클 때의 x를 찾기 → 미분해서 0이 되는 x
- **최소화**: f(x)가 가장 작을 때의 x를 찾기 → 미분해서 0이 되는 x

```
최대화: f'(x) = 0 을 풀면 됨
최소화: f'(x) = 0 을 풀면 됨 (같은 방법!)
```

**최대화를 최소화로 바꾸는 트릭**:

```
f(x)를 최대화  =  -f(x)를 최소화

왜? 가장 큰 값에 마이너스를 붙이면 가장 작은 값이 되니까!

  최대 3  →  -3 (최소)
  최소 -5 →  +5 (최대)
```

---

## 도구 7: Σ(시그마) — 더하기의 줄임말

**중1 설명**: Σ는 "다 더해!"라는 기호입니다.

```
Σᵢ₌₁³ xᵢ = x₁ + x₂ + x₃

읽는 법: "i가 1부터 3까지, x_i를 다 더해"

예: x₁=2, x₂=5, x₃=3 이면
Σ = 2 + 5 + 3 = 10
```

---

## 도구 8: Π(파이) — 곱하기의 줄임말

**중1 설명**: Π는 "다 곱해!"라는 기호입니다.

```
Πᵢ₌₁³ xᵢ = x₁ × x₂ × x₃

예: x₁=2, x₂=5, x₃=3 이면
Π = 2 × 5 × 3 = 30
```

**로그의 마법**: log(Π) = Σlog

```
log(x₁ × x₂ × x₃) = log(x₁) + log(x₂) + log(x₃)

Π (곱하기)  --log-->  Σ (더하기)
```

## 도구 9: 벡터 — 숫자 여러 개를 한 묶음으로

**중1 설명**: 벡터는 숫자들의 목록입니다.

```
v = [3, 5, 1]   ← 3개의 숫자를 하나로 묶은 것

딥러닝에서:
  모델 출력 = [0.7, 0.2, 0.1]   ← "고양이 70%, 개 20%, 새 10%"
```

**내적**: 두 벡터의 "유사도"를 숫자 하나로 계산

```
a = [1, 0, 0]    (고양이가 정답!)
b = [0.7, 0.2, 0.1]   (모델의 예측)

내적 = 1×0.7 + 0×0.2 + 0×0.1 = 0.7   (정답 클래스의 확률만 남음!)
```

## 도구 11: exp(지수함수)와 자연로그(ln)

**중1 설명**:

e ≈ 2.718... (특별한 숫자, 자연의 성장률)

```

```

# 이제 유도 시작!

위 도구 1~12를 알면 아래 유도 10개를 전부 이해할 수 있습니다.

---

## 유도 #1: MLE → Cross-Entropy Loss ★★★

> **필요한 도구**: 2(확률), 3(곱셈/독립), 4(로그), 5(미분), 6(최대화/최소화), 7(Σ), 8(Π), 9(벡터), 10(one-hot)

### 이 유도가 뭘 하는 건가?

AI 모델을 학습시키려면 "모델이 얼마나 틀렸는지"를 측정하는 점수가 필요합니다.
이 점수를 **손실함수(Loss Function)**라고 합니다.
이 유도는 "가장 자연스러운 손실함수"가 어떻게 나오는지 보여줍니다.

```
질문: "모델이 데이터를 가장 잘 설명하려면?"
답: "데이터가 나올 확률을 최대화하면 됨!" ← 이게 MLE
      ↓ 수학적으로 전개하면
    Cross-Entropy Loss가 나옴!
```

### Step 1: 상황 설정

고양이/개/새 분류 문제. 모델이 사진을 보고 확률을 출력합니다.

```
고양이 사진을 넣었더니:
  모델 출력: h(x) = [0.7, 0.2, 0.1]
                     고양이  개    새
  정답:              고양이 (= 클래스 1)
```

모델이 정답을 맞출 확률 = **0.7** (고양이 확률)

이걸 수식으로:

```
p(정답 | 사진, 모델) = h(x)의 정답 위치 값 = 0.7
```

수학 표기: $p(y \mid x, h) = h(x)_y$

→ "h(x)라는 벡터에서 y번째 원소를 꺼낸다"는 뜻

### Step 2: 데이터가 여러 개일 때

사진이 3장 있다고 합시다:

```
사진1 (고양이): 모델이 고양이라고 0.7 → 맞출 확률 0.7
사진2 (개):     모델이 개라고 0.8     → 맞출 확률 0.8
사진3 (새):     모델이 새라고 0.3     → 맞출 확률 0.3 (못 맞춤!)
```

**3장 모두** 맞출 확률은? (각 사진이 **독립**이라고 가정 = **i.i.d.**)

```
전체 확률 = 0.7 × 0.8 × 0.3 = 0.168
```

수학 표기: $P(E \mid H) = \prod_{i=1}^{n} h(x_i)_{y_i}$

→ "모든 데이터에 대해 정답 확률을 **다 곱한 것**" = **우도(likelihood)**

### Step 3: 로그를 취하자 (도구 4 사용!)

곱셈(Π)을 덧셈(Σ)으로 바꾸기 위해 로그를 취합니다.

```
log(0.7 × 0.8 × 0.3)
= log(0.7) + log(0.8) + log(0.3)    ← 도구4의 성질 ①
= -0.36 + (-0.22) + (-1.20)
= -1.78
```

**로그를 취해도 최대/최소 위치는 안 바뀝니다!** (도구4의 성질 ③)

수학 표기: $\log P(E \mid H) = \sum_{i=1}^{n} \log h(x_i)_{y_i}$

### Step 4: MLE = "이 값을 최대화하는 모델을 찾자"

```
MLE: θ_ML = argmax_θ [log(0.7) + log(0.8) + log(0.3)]
                       ↑
                 이 합을 최대화하는 모델 파라미터 θ를 찾아!
```

### Step 5: 최대화 → 최소화로 바꾸기 (도구 6 사용!)

컴퓨터는 보통 **최소화**를 합니다. 마이너스를 붙이면 됩니다:

```
최대화:  log(0.7) + log(0.8) + log(0.3) = -1.78   ← 이걸 크게!
최소화: -log(0.7) - log(0.8) - log(0.3) = +1.78   ← 이걸 작게!
```

$L_{CE} = -\frac{1}{n} \sum_{i=1}^{n} \log h(x_i)_{y_i}$

**이것이 Cross-Entropy Loss입니다!**

### 한 줄 요약

```
"데이터가 나올 확률(우도)을 최대화"
= "마이너스 로그 우도를 최소화"
= "Cross-Entropy Loss를 최소화"

전부 같은 말입니다!
```

### 숫자 예시로 확인

```
좋은 모델: h(x) = [0.9, 0.05, 0.05], 정답 = 고양이
  CE Loss = -log(0.9) = 0.105   ← 작다! (잘 맞춤)

나쁜 모델: h(x) = [0.1, 0.5, 0.4], 정답 = 고양이
  CE Loss = -log(0.1) = 2.303   ← 크다! (못 맞춤)

완벽한 모델: h(x) = [1.0, 0, 0], 정답 = 고양이
  CE Loss = -log(1.0) = 0       ← 0! (완벽!)
```

## 유도 #2: MLE → MSE Loss ★★★

> **필요한 도구**: 4(로그), 5(미분), 6(최대화/최소화), 11(exp)

### 이 유도가 뭘 하는 건가?

유도 #1은 "분류"(고양이? 개?)용이었습니다.
유도 #2는 "회귀"(집값이 얼마?)용입니다.

```
분류: 정답이 카테고리 → CE Loss
회귀: 정답이 숫자    → MSE Loss  ← 이걸 유도합니다
```

### Step 1: 상황 설정

집 크기를 넣으면 가격을 예측하는 모델:

```
집 크기 30평 → [모델 h] → 예측 가격: 5억
                          실제 가격: 4.5억
                          오차: 0.5억
```

"실제 가격은 예측 주변에서 **종 모양(가우시안)**으로 분포한다"고 가정:

```
        ___
       /   \         ← 가우시안(정규) 분포
      /     \
     /       \       예측값 h(x) = 5억이 중심
    /    |    \      실제값이 5억에서 멀수록 확률↓
___/     |     \___
      h(x)=5억
```

수식: $p(y \mid x, h) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y - h(x))^2}{2\sigma^2}\right)$

복잡해 보이지만 핵심은 이것:

```
exp(-(y - h(x))² / ...)

이것의 의미:
  y와 h(x)가 가까우면 → (y-h(x))² 작음 → exp(작은 음수) → 확률 큼 (좋음!)
  y와 h(x)가 멀면   → (y-h(x))² 큼  → exp(큰 음수)   → 확률 작음 (나쁨!)
```

### Step 2: 로그 취하기

데이터 n개의 우도에 로그를 취하면:

```
log P = 상수 - 1/(2σ²) × [(y₁-h(x₁))² + (y₂-h(x₂))² + ... + (yₙ-h(xₙ))²]
        ─────   ──────   ──────────────────────────────────────────────────
        ①        ②                        ③
```

- ①: 데이터 수 n과 σ에만 관련된 숫자 (모델 h와 무관!)
- ②: 양수 상수 (나눗셈)
- ③: **(예측 - 실제)²의 합** ← 이게 핵심!

### Step 3: 최대화하면?

log P를 최대화하려면, ①은 h와 무관하니 무시하고, ②는 양수 상수이니:

```
log P를 최대화 = ③을 최소화 = Σ(yᵢ - h(xᵢ))²를 최소화!
```

$$\boxed{L_{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - h(x_i))^2}$$

**이것이 MSE(Mean Squared Error) Loss입니다!**

### 한 줄 요약

```
"실제값이 예측 주변의 가우시안 분포를 따른다"고 가정
→ MLE로 가장 그럴듯한 모델을 찾으면
→ (예측 - 실제)²의 합을 최소화하는 것과 같다
→ 이것이 MSE Loss!
```

### 숫자 예시

```
예측: [5억, 3억, 7억]
실제: [4.5억, 3.2억, 6.5억]

MSE = [(5-4.5)² + (3-3.2)² + (7-6.5)²] / 3
    = [0.25 + 0.04 + 0.25] / 3
    = 0.18억²
```

## 유도 #3: MAP = MLE + Prior ★★★

> **필요한 도구**: 2(확률), 4(로그), 5(미분)

### 이 유도가 뭘 하는 건가?

MLE의 문제점: 데이터만 보고 판단 → **과적합!**

```
동전 3번 던져서 3번 다 앞면:
  MLE: θ = 3/3 = 1.0  → "앞으로 무조건 앞면!" ← 말이 안 됨!
```

MAP: "데이터 + 상식"을 합쳐서 판단

```
상식(Prior): "동전은 보통 0.5 근처일 거야"
데이터: "3번 중 3번 앞면"
결합: θ = 0.8  ← MLE의 1.0보다 합리적!
```

### Step 1: 베이즈 정리 (확률의 뒤집기)

```
P(가설 | 데이터) = P(데이터 | 가설) × P(가설) / P(데이터)
  사후확률            우도              사전확률     (상수)
 (posterior)       (likelihood)        (prior)    (evidence)
```

비유:

```
의사의 진단:
  P(데이터 | 가설) = "감기라면 이 증상이 나올 확률"
  P(가설)         = "감기에 걸릴 확률" (통계적으로 알고 있음)
  P(가설 | 데이터) = "이 증상이 있을 때 감기일 확률" ← 이걸 알고 싶다!
```

### Step 2: P(데이터)는 무시해도 됨

P(데이터)는 모든 가설에 대해 **같은 값**이므로 비교할 때 무시 가능:

```
P(가설 | 데이터) ∝ P(데이터 | 가설) × P(가설)
사후확률            우도              사전확률
```

∝ 는 "비례한다"는 뜻. 상수 배를 빼면 같다는 의미.

### Step 3: 로그 취하기

양변에 로그를 취하면 (곱셈 → 덧셈!):

```
log P(가설|데이터) = log P(데이터|가설) + log P(가설) + 상수
     ↑                     ↑                  ↑
   MAP 목적함수          MLE 목적함수       정규화 항
```

$$\boxed{\log \text{posterior} = \log \text{likelihood} + \log \text{prior} + C}$$

**MAP = MLE + Prior!**

### Step 4: Prior가 균등이면? → MAP = MLE

```
균등 Prior: "모든 θ가 동등하게 가능" → P(θ) = 상수

log P(θ) = log(상수) = 상수   ← 어떤 θ를 선택해도 같은 값

→ MAP 최적화에서 prior 항이 사라짐
→ MAP = MLE
```

### Step 5: 구체적 예시 — 동전 던지기

Prior: $p(\theta) = 6\theta(1-\theta)$ (= "0.5 근처를 약간 선호")

```
log posterior
= log likelihood + log prior + C
= [k·log(θ) + (n-k)·log(1-θ)] + [log(θ) + log(1-θ)] + C
   ───────── MLE 부분 ─────────   ── Prior 부분 ──
= (k+1)·log(θ) + (n-k+1)·log(1-θ) + C
   ↑                ↑
  k에 1 더해짐!    (n-k)에 1 더해짐!
```

미분해서 0으로 놓으면:

```
(k+1)/θ - (n-k+1)/(1-θ) = 0

→ θ_MAP = (k+1) / (n+2)
```

**n=3, k=3:**

```
θ_MLE = 3/3 = 1.0     ← "무조건 앞면!" (과적합)
θ_MAP = 4/5 = 0.8     ← "대부분 앞면이지만 뒷면도 가능" (합리적!)
```

## 유도 #4: KL Divergence와 CE 관계 ★★☆

> **필요한 도구**: 4(로그), 7(Σ)

### 이 유도가 뭘 하는 건가?

세 가지 개념의 관계를 정리합니다:

```
엔트로피 H(p):       p의 불확실성 (p 자체의 성질)
교차 엔트로피 CE(p,q): q로 p를 설명할 때의 비용
KL divergence:        p와 q가 얼마나 다른가

관계: KL(p||q) = CE(p,q) - H(p)
```

### 비유로 이해

```
택배 배달 비유:

  H(p) = 내 동네 안에서 배달하는 비용 (최적 경로)
  CE(p,q) = 다른 동네 지도(q)를 보고 내 동네(p)를 배달하는 비용
  KL = CE - H = "잘못된 지도 때문에 추가로 드는 비용"

  → KL ≥ 0 (잘못된 지도가 최적보다 나을 수는 없다!)
  → KL = 0이면 p = q (같은 지도!)
```

### 수식 유도

```
KL(p||q) = Σ p(x) × log(p(x)/q(x))         ← 정의

         = Σ p(x) × [log p(x) - log q(x)]    ← log(A/B) = logA - logB

         = Σ p(x)·log p(x) - Σ p(x)·log q(x)
           ─────────────     ────────────────
               -H(p)              CE(p,q)에 -를 붙인 것

         = -H(p) + CE(p,q)
```

$$\boxed{KL(p \| q) = CE(p, q) - H(p)}$$

### 왜 CE 최소화 = KL 최소화?

```
학습에서:
  p = 실제 데이터 분포 (고정! 바꿀 수 없음)
  q = 모델의 예측 분포 (학습으로 바꿈)

KL(p||q) = CE(p,q) - H(p)
                       ↑
                    p는 고정이므로 H(p)는 상수!

→ KL을 최소화 = CE를 최소화 (상수를 빼도 최소 위치는 같으니까!)
```

## 유도 #5: L2 정규화 = Gaussian Prior ★★☆

> **필요한 도구**: 4(로그), 6(최대화/최소화), 11(exp)

### 이 유도가 뭘 하는 건가?

"모델 파라미터가 너무 크면 벌점을 주는 것"(L2 정규화)이
사실은 "파라미터가 0 근처에 있을 거라는 믿음"(Gaussian Prior)과
수학적으로 **완전히 같은 것**임을 보여줍니다.

### Step 1: MAP 목적함수 (유도 #3에서)

```
MAP: 최대화할 것 = log(우도) + log(Prior)
```

### Step 2: Gaussian Prior 넣기

"파라미터 θ는 0 근처에 있을 거야":

```
P(θ) = 가우시안(평균=0, 분산=τ²)
     ∝ exp(-θ²/(2τ²))
```

로그를 취하면:

```
log P(θ) = -θ²/(2τ²) + 상수
            ↑
          θ가 0에서 멀수록 이 값이 더 음수 → 벌점!
```

여러 파라미터면: $\log P(\theta) = -\frac{1}{2\tau^2}\|\theta\|^2 + C$

$\|\theta\|^2 = \theta_1^2 + \theta_2^2 + ... + \theta_p^2$ (모든 파라미터의 제곱합)

### Step 3: MAP에 대입

```
MAP: 최대화 → log(우도) + [-1/(2τ²) × ||θ||²]
     최소화 → -log(우도) + 1/(2τ²) × ||θ||²
             = Loss(θ)   + λ × ||θ||²

여기서 λ = 1/(2τ²)
```

$$\boxed{\text{MAP with Gaussian Prior} = \text{Loss} + \lambda\|\theta\|^2 = \text{L2 정규화!}}$$

### 직관

```
τ² 크다 = "파라미터가 자유롭게 커도 됨" = λ 작다 = 정규화 약함
τ² 작다 = "파라미터는 0 근처여야 함"   = λ 크다 = 정규화 강함
```

## 유도 #6: Softmax 미분 ★★☆

> **필요한 도구**: 5(미분), 11(exp)

### Softmax가 뭔가?

점수(아무 숫자)를 확률(0~1, 합이 1)로 바꾸는 함수:

```
점수: z = [2.0, 1.0, 0.1]

exp:  [e², e¹, e⁰·¹] = [7.39, 2.72, 1.10]
합:   7.39 + 2.72 + 1.10 = 11.21
나누기: [7.39/11.21, 2.72/11.21, 1.10/11.21]
      = [0.659, 0.243, 0.098]   ← 확률! 합 = 1 ✓
```

수식: $\text{softmax}(z)_i = \frac{e^{z_i}}{e^{z_1} + e^{z_2} + ... + e^{z_C}}$

줄여서: $s_i = \frac{e^{z_i}}{S}$, 여기서 $S = \sum_k e^{z_k}$

### 미분: "z_j가 살짝 바뀌면 s_i가 얼마나 바뀌나?"

**경우 1: i = j (같은 클래스)**

$s_i$를 $z_i$로 미분 (분수의 미분 = 몫의 미분법):

```
d(분자/분모)/dx = (분자'×분모 - 분자×분모') / 분모²

분자 = e^{z_i}     → 분자' = e^{z_i}
분모 = S            → 분모' = e^{z_i}  (S를 z_i로 미분하면 e^{z_i}만 남음)

= (e^{z_i} × S - e^{z_i} × e^{z_i}) / S²
= e^{z_i}/S × (S - e^{z_i})/S
= s_i × (1 - s_i)
```

**경우 2: i ≠ j (다른 클래스)**

$s_i$를 $z_j$로 미분 (i ≠ j):

```
분자 = e^{z_i}     → 분자' = 0  (z_i는 z_j와 무관!)
분모 = S            → 분모' = e^{z_j}

= (0 × S - e^{z_i} × e^{z_j}) / S²
= -(e^{z_i}/S) × (e^{z_j}/S)
= -s_i × s_j
```

### 통합 공식

$$\boxed{\frac{\partial s_i}{\partial z_j} = s_i(\delta_{ij} - s_j)}$$

여기서 $\delta_{ij}$ = i와 j가 같으면 1, 다르면 0

### 보너스: CE + Softmax 합치면?

놀랍게도 매우 간단해집니다:

```
∂L/∂z = p - e_y

여기서 p = softmax(z), e_y = 정답의 one-hot 벡터
```

예: 정답이 고양이(클래스 1), 모델 출력 p = [0.7, 0.2, 0.1]

```
∂L/∂z = [0.7, 0.2, 0.1] - [1, 0, 0] = [-0.3, 0.2, 0.1]

의미:
  고양이 점수를 높여! (-0.3 → 음수 = 올려야 함)
  개 점수를 낮춰!   (+0.2 → 양수 = 낮춰야 함)
  새 점수를 낮춰!   (+0.1 → 양수 = 낮춰야 함)
```

## 유도 #7: Chain Rule / 역전파 ★★★

> **필요한 도구**: 5(미분), 9(벡터)

### 역전파가 뭔가?

"Loss를 줄이려면 각 가중치를 어느 방향으로 얼마나 바꿔야 하나?"를 계산하는 방법.

### 체인룰 = 합성함수의 미분

```
쉬운 예: f(x) = (2x + 1)³

안쪽: u = 2x + 1
바깥: f = u³

df/dx = df/du × du/dx = 3u² × 2 = 6(2x+1)²

규칙: "바깥 미분 × 안쪽 미분"
```

### 2층 신경망에 적용

```
입력 x₀ → [W₀ 곱하기] → [활성함수 σ] → x₁ → [W₁ 곱하기] → z → [Softmax+CE] → Loss L

순전파(→): x₀ → x₁ → z → L
역전파(←): L → z → x₁ → x₀  (거꾸로 미분 전달!)
```

### Step 1: ∂L/∂z (출력에서의 미분)

유도 #6의 보너스에서:

```
∂L/∂z = p - e_y    (softmax 출력 - 정답 one-hot)
```

### Step 2: ∂L/∂W₁ (출력층 가중치)

z = W₁ × x₁ 이므로:

```
∂L/∂W₁ = ∂L/∂z × ∂z/∂W₁
        = (p - e_y) × x₁ᵀ

※ x₁ᵀ는 x₁을 가로로 눕힌 것
```

### Step 3: ∂L/∂x₁ (은닉층 출력까지 역전파)

```
∂L/∂x₁ = W₁ᵀ × (∂L/∂z)
        = W₁ᵀ × (p - e_y)

※ W₁ᵀ는 W₁을 뒤집은 것 (전치). 역전파에서는 가중치를 뒤집어서 전달!
```

### Step 4: ∂L/∂W₀ (은닉층 가중치)

x₁ = σ(W₀ × x₀) 이므로, 활성함수 미분을 통과해야 합니다:

```
ReLU의 미분: σ'(z) = { 1  (z > 0일 때)
                       { 0  (z ≤ 0일 때)

∂L/∂W₀ = [∂L/∂x₁ ⊙ σ'(W₀x₀)] × x₀ᵀ

⊙ = 원소별 곱셈 (같은 위치끼리 곱하기)
```

### 전체 그림

```
순전파(→):
  x₀ →[W₀]→ σ → x₁ →[W₁]→ z →[softmax]→ p →[CE]→ L

역전파(←):
  L → ∂L/∂z = (p-e_y)
    → ∂L/∂W₁ = (p-e_y)·x₁ᵀ        ← W₁ 업데이트에 사용
    → ∂L/∂x₁ = W₁ᵀ·(p-e_y)        ← 뒤로 전달
    → ∂L/∂W₀ = [∂L/∂x₁ ⊙ σ']·x₀ᵀ  ← W₀ 업데이트에 사용
```

## 유도 #8: Gradient Descent 유도 ★★☆

> **필요한 도구**: 5(미분), 도구 6(최소화)

### 이 유도가 뭘 하는 건가?

"산을 내려가는 방법"을 수학적으로 유도합니다.

### 비유

```
안개 낀 산에서 눈을 감고 내려가야 합니다.
발밑을 더듬어 "어느 방향이 가장 가파르게 내려가는지" 느낍니다.
그 방향으로 한 걸음 갑니다.
다시 발밑을 더듬습니다.
반복!
```

### 수학적 유도

현재 위치 θ_t에서 함수 f를 **1차 근사** (도구 5의 기울기):

```
f(θ_t + δ) ≈ f(θ_t) + ∇f(θ_t)ᵀ × δ

∇f = 기울기 벡터 (각 방향의 가파른 정도)
δ = 이동 방향과 크기
```

f를 줄이려면 $\nabla f^T \times \delta$가 음수여야 합니다.

**가장 많이 줄이는 방향은?** → 기울기의 반대 방향!

```
δ = -η × ∇f(θ_t)

이유: 내적이 가장 작은(가장 음수인) 방향 = 벡터의 반대 방향
```

$$\boxed{\theta_{t+1} = \theta_t - \eta \nabla f(\theta_t)}$$

η(에타) = **학습률** (한 걸음의 크기)

```
η 너무 크면: 산을 넘어서 반대편으로 날아감!
η 너무 작으면: 1000년이 걸림
η 적당하면: 안전하게 바닥 도착
```

## 유도 #9: Bias-Variance Decomposition ★★☆

> **필요한 도구**: 2(확률/기대값), 5(미분)

### 이 유도가 뭘 하는 건가?

모델의 오차를 두 가지 원인으로 분해합니다:

```
총 오차 = 편향(Bias)² + 분산(Variance)

편향: "평균적으로 정답에서 얼마나 벗어나는가" (과소적합)
분산: "데이터마다 예측이 얼마나 흔들리는가" (과적합)
```

비유:

```
과녁 맞추기:

  편향 큼, 분산 작음:    편향 작음, 분산 큼:    둘 다 작음:
    · · ·                   ·                   · · ·
    · · ·   ⊕               · ⊕ ·               ⊕
    · · ·                 ·     ·               · · ·
  (일관되게 빗나감)      (중심은 맞는데 흔들림)  (완벽!)
```

### 수학적 유도

**정의**:
- f = 정답 함수 (진짜, 고정)
- h_S = 훈련 데이터 S로 학습한 모델 (S에 따라 달라짐)
- h̄ = E[h_S] = 여러 S로 학습했을 때의 **평균 모델**

**전개**:

```
E[(h_S - f)²]

= E[(h_S - h̄ + h̄ - f)²]              ← h̄를 빼고 더하기 (아무것도 안 바뀜!)

= E[(h_S - h̄)² + 2(h_S - h̄)(h̄ - f) + (h̄ - f)²]    ← (a+b)² = a² + 2ab + b²

= E[(h_S - h̄)²] + 2(h̄ - f)·E[(h_S - h̄)] + (h̄ - f)²
  ─────────────   ──────────────────────   ──────────
    분산(Var)        이 항은 0이 됨!          편향²(Bias²)
```

**교차항이 0인 이유**:

```
E[h_S - h̄] = E[h_S] - h̄ = h̄ - h̄ = 0

"평균에서의 편차"의 평균은 항상 0!
(키 평균이 170cm인 반에서 (키-170)의 평균 = 0인 것과 같음)
```

$$\boxed{E[(h_S - f)^2] = \text{Var}(h_S) + \text{Bias}^2(h_S)}$$

### 의미

```
모델이 단순하면 (예: 직선 하나):
  Bias ↑ (단순해서 복잡한 패턴 못 잡음)
  Variance ↓ (데이터 바뀌어도 비슷한 직선)

모델이 복잡하면 (예: 아주 구불구불한 곡선):
  Bias ↓ (복잡한 패턴도 잡음)
  Variance ↑ (데이터 조금만 바뀌어도 곡선이 완전히 달라짐)

최적: Bias² + Variance가 가장 작은 복잡도
```

## 유도 #10: Batch Normalization ★☆☆

> **필요한 도구**: 7(Σ), 기초 산술

### Batch Normalization이 뭔가?

신경망 중간에서 데이터를 **정규화**(평균=0, 분산=1로 맞추기)하는 기법.

비유:

```
시험 성적 표준화와 같습니다:

원래 점수: [90, 85, 70, 95, 80]    ← 범위가 제각각
평균 = 84, 표준편차 = 9.35

표준화:   [(90-84)/9.35, (85-84)/9.35, ...]
        = [0.64, 0.11, -1.50, 1.18, -0.43]  ← 평균=0, 분산≈1
```

### 3단계 알고리즘

**Step 1: 배치(batch) 평균과 분산 계산**

배치 = 한 번에 처리하는 데이터 묶음 (예: 32개)

```
μ = (x₁ + x₂ + ... + xₘ) / m         ← 평균
σ² = [(x₁-μ)² + (x₂-μ)² + ... + (xₘ-μ)²] / m  ← 분산
```

**Step 2: 정규화 (평균=0, 분산=1로)**

```
x̂ᵢ = (xᵢ - μ) / √(σ² + ε)

ε = 0.00001 같은 아주 작은 수 (0으로 나누기 방지!)
```

**Step 3: 스케일 & 시프트 (학습 가능!)**

```
yᵢ = γ × x̂ᵢ + β

γ, β = 학습이 되는 파라미터
```

**왜 γ, β가 필요한가?**

```
Step 2에서 무조건 평균=0, 분산=1로 만들었는데,
그게 항상 최적은 아닐 수 있음.

γ=σ, β=μ로 학습하면 → 원래 값 복원! (BN 무효화)
→ 네트워크가 "BN이 필요 없다"고 판단하면 스스로 끌 수 있음
```

### 왜 BN이 도움이 되나?

```
1. 각 층의 입력 분포가 안정화 → 학습이 빨라짐
2. 더 큰 학습률(η) 사용 가능 → 수렴이 빨라짐
3. 초기화에 덜 민감 → 시작이 쉬워짐
4. 약간의 정규화 효과 → 과적합 감소
```
