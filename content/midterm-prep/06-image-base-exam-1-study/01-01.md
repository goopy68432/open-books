# 딥러닝 수학 기초 - 초급 단계

## 학습 목표
> 선형대수와 미적분의 기본 용어와 개념을 이해하고, 왜 딥러닝에 필요한지 감을 잡는다.

---

## 1. 선형대수 (Linear Algebra) - 기초

### 1.1 표기법 (Notation)

#### 행렬과 벡터란?

**스칼라 (Scalar)**: 하나의 숫자
```
x = 5
```

**벡터 (Vector)**: 숫자들의 1차원 배열
```
행 벡터 (Horizontal/Row Vector):  v = [1, 2, 3]

열 벡터 (Vertical/Column Vector): v = | 1 |
                                       | 2 |
                                       | 3 |
```

**행렬 (Matrix)**: 숫자들의 2차원 배열
```
A = | 1  2  3 |
    | 4  5  6 |
    | 7  8  9 |
```

> **왜 중요한가?**
> 딥러닝에서 이미지는 행렬(픽셀값)로, 데이터는 벡터로, 가중치는 행렬로 표현된다.
> 예: 28x28 흑백 이미지 = 28x28 행렬

#### 내적 (Inner Product / Dot Product)

두 벡터의 대응하는 원소끼리 곱한 후 모두 더한 값이다.

```
a = [1, 2, 3]
b = [4, 5, 6]

a · b = (1×4) + (2×5) + (3×6) = 4 + 10 + 18 = 32
```

> **직관적 이해**: 내적은 두 벡터가 "얼마나 같은 방향을 가리키는지"를 측정한다.
> - 같은 방향 → 양수 (큰 값)
> - 직각 → 0
> - 반대 방향 → 음수

> **딥러닝에서의 역할**: 뉴런의 출력 = 입력 벡터와 가중치 벡터의 내적 + 편향

```
neuron_output = w · x + b
             = (w1*x1 + w2*x2 + ... + wn*xn) + b
```

### 1.2 행렬 연산

#### 행렬-벡터 곱셈

행렬 A와 벡터 x의 곱은 각 행과 벡터의 내적이다.

```
A = | 1  2 |    x = | 3 |
    | 3  4 |        | 5 |

A·x = | 1×3 + 2×5 | = | 13 |
      | 3×3 + 4×5 |   | 29 |
```

> **딥러닝에서**: 하나의 층(layer)의 연산이 바로 행렬-벡터 곱셈이다!
> ```
> 출력 = W·입력 + b   (W: 가중치 행렬, b: 편향 벡터)
> ```

#### 행렬-행렬 곱셈

```
A = | 1  2 |    B = | 5  6 |
    | 3  4 |        | 7  8 |

A·B = | 1×5+2×7  1×6+2×8 | = | 19  22 |
      | 3×5+4×7  3×6+4×8 |   | 43  50 |
```

**핵심 규칙**: A가 (m×n), B가 (n×p)일 때만 곱셈 가능 → 결과는 (m×p)

#### 행렬 곱셈의 계산 복잡도: O(n³)

n×n 행렬 두 개를 곱하면 약 n³번의 곱셈이 필요하다.

```
n = 10    →  1,000번 연산
n = 100   →  1,000,000번 연산
n = 1000  →  1,000,000,000번 연산
```

> **이것이 GPU가 필요한 이유**: GPU는 이 대량 연산을 병렬로 처리한다.

#### 역행렬과 계산 비용

역행렬 A⁻¹는 A·A⁻¹ = I (단위행렬)를 만족하는 행렬이다.

```
A = | 2  1 |    A⁻¹ = | 3  -1 |
    | 5  3 |           |-5   2 |

확인: A·A⁻¹ = | 2×3+1×(-5)  2×(-1)+1×2 | = | 1  0 | = I
              | 5×3+3×(-5)  5×(-1)+3×2 |   | 0  1 |
```

> 역행렬 계산은 O(n³)으로 매우 비싸서, 딥러닝에서는 직접 역행렬을 구하지 않고
> 경사하강법 같은 반복 알고리즘을 사용한다.

### 1.3 주요 개념 입문

#### 선형 결합 (Linear Combination)

벡터들에 상수(스칼라)를 곱해서 더하는 것이다.

```
v1 = [1, 0],  v2 = [0, 1]

2·v1 + 3·v2 = 2·[1,0] + 3·[0,1] = [2,0] + [0,3] = [2, 3]
```

> 어떤 벡터든 다른 벡터들의 선형 결합으로 표현할 수 있는지가 핵심 질문이다.

#### 스팬 (Span)

주어진 벡터들의 모든 가능한 선형 결합으로 만들 수 있는 공간이다.

```
v1 = [1, 0], v2 = [0, 1]
→ span({v1, v2}) = 2차원 평면 전체 (R²)

v1 = [1, 0], v2 = [2, 0]
→ span({v1, v2}) = x축 위의 직선만 (1차원)
```

> 두 벡터가 같은 방향이면 아무리 결합해도 직선밖에 못 만든다!

#### 선형 독립 (Linear Independence)

벡터들 중 어느 하나도 나머지의 선형 결합으로 표현할 수 없는 상태이다.

```
독립: v1 = [1, 0], v2 = [0, 1]  → v1을 v2로 만들 수 없다!

종속: v1 = [1, 2], v2 = [2, 4]  → v2 = 2·v1 이므로 종속!
```

> **딥러닝에서**: 특징(feature)들이 선형 독립이어야 각각 고유한 정보를 담는다.
> 종속적인 특징은 중복 정보일 뿐이다.

#### 기저 (Basis)와 차원 (Dimension)

- **기저**: 공간을 span하면서 선형 독립인 벡터들의 집합
- **차원**: 기저 벡터의 개수

```
R²의 표준 기저: e1 = [1, 0], e2 = [0, 1]  → 차원 = 2
R³의 표준 기저: e1 = [1,0,0], e2 = [0,1,0], e3 = [0,0,1]  → 차원 = 3
```

## 2. 미분 (Calculus) - 기초

### 2.1 미분이란?

함수의 변화율, 즉 "기울기"를 구하는 것이다.

```
f(x) = x²

f'(x) = 2x  (미분 결과)

x = 3일 때 기울기 = f'(3) = 6
→ x가 3 근처에서 1만큼 증가하면 f(x)는 약 6만큼 증가한다
```

### 2.2 왜 딥러닝에 미분이 필요한가?

딥러닝의 학습 = 손실 함수(Loss Function)를 최소화하는 과정

```
손실(Loss)이 줄어드는 방향 = 기울기의 반대 방향

가중치 업데이트: w_new = w_old - learning_rate × (∂Loss/∂w)
```

> 이것이 **경사하강법 (Gradient Descent)**이다!
> 미분으로 기울기를 구하고, 기울기의 반대 방향으로 가중치를 조금씩 수정한다.

### 2.3 기본 미분 공식

```
f(x) = c       → f'(x) = 0          (상수)
f(x) = x^n     → f'(x) = n·x^(n-1)  (거듭제곱)
f(x) = e^x     → f'(x) = e^x        (지수함수)
f(x) = ln(x)   → f'(x) = 1/x        (로그함수)
f(x) = g(x) + h(x) → f'(x) = g'(x) + h'(x)  (합의 법칙)
f(x) = g(h(x)) → f'(x) = g'(h(x)) · h'(x)   (연쇄 법칙, Chain Rule)
```

> **연쇄 법칙 (Chain Rule)**은 딥러닝의 핵심인 역전파(Backpropagation)의 수학적 기반이다!

## 3. 초급 자가 점검 문제

### 문제 1
```
벡터 a = [2, 3, 1], b = [1, 0, 4]의 내적을 구하시오.
```
<details>
<summary>정답 보기</summary>

```
a · b = 2×1 + 3×0 + 1×4 = 2 + 0 + 4 = 6
```
</details>

### 문제 2
```
다음 행렬-벡터 곱을 계산하시오.

A = | 2  1 |    x = | 3 |
    | 0  4 |        | 1 |
```
<details>
<summary>정답 보기</summary>

```
A·x = | 2×3 + 1×1 | = | 7 |
      | 0×3 + 4×1 |   | 4 |
```
</details>

### 문제 3
```
v1 = [1, 2], v2 = [3, 6]은 선형 독립인가?
```
<details>
<summary>정답 보기</summary>

```
v2 = 3·v1 이므로 선형 종속이다.
v2는 v1의 스칼라 배이므로 같은 방향을 가리킨다.
```
</details>

### 문제 4
```
f(x) = 3x² + 2x + 1을 미분하시오.
```
<details>
<summary>정답 보기</summary>

```
f'(x) = 6x + 2
```
</details>
