## 학습 목표

> 역전파에서 이들이 어떻게 연결되는지 파악한다.

## 1. 딥러닝 핵심 함수의 미분

### 1.1 소프트맥스 (Softmax) 미분

#### Softmax 정의

로짓(logit) 벡터 z를 확률 분포로 변환한다.

```
softmax(z_i) = exp(z_i) / Σ_j exp(z_j)

예: z = [2.0, 1.0, 0.1]

exp(z) = [7.389, 2.718, 1.105]
합계 = 11.212

softmax(z) = [0.659, 0.242, 0.099]  (합 = 1.0)
```

> **핵심 성질**: 모든 출력이 (0,1) 범위이고, 합이 1이 되어 확률로 해석 가능하다.
> 가장 큰 입력이 확률적으로 더 강조된다.

#### Softmax의 야코비안 행렬

```
∂softmax(z_i)/∂z_j 를 구해야 한다.

s_i = softmax(z_i)로 놓으면:

i = j일 때: ∂s_i/∂z_i = s_i(1 - s_i)
i ≠ j일 때: ∂s_i/∂z_j = -s_i · s_j
```

**유도 과정** (i = j인 경우):
```
s_i = exp(z_i) / S    (S = Σ exp(z_k))

∂s_i/∂z_i = [exp(z_i) · S - exp(z_i) · exp(z_i)] / S²
           = exp(z_i)/S · [1 - exp(z_i)/S]
           = s_i · (1 - s_i)
```

**행렬 형태**:
```
J_softmax = diag(s) - s·sᵀ

예: s = [0.7, 0.2, 0.1]

J = | 0.7(1-0.7)   -0.7·0.2    -0.7·0.1  |
    | -0.2·0.7    0.2(1-0.2)   -0.2·0.1  |
    | -0.1·0.7    -0.1·0.2    0.1(1-0.1) |

  = | 0.21   -0.14   -0.07 |
    |-0.14    0.16   -0.02 |
    |-0.07   -0.02    0.09 |
```

### 1.2 크로스 엔트로피 (Cross-Entropy) 미분

#### 정의

```
L = -Σ_i y_i · log(ŷ_i)

y: 원-핫 인코딩된 정답 레이블 (예: [0, 1, 0])
ŷ: 모델의 예측 확률 (softmax 출력, 예: [0.1, 0.7, 0.2])

L = -(0·log(0.1) + 1·log(0.7) + 0·log(0.2))
  = -log(0.7)
  ≈ 0.357
```

> 정답 클래스의 예측 확률이 높을수록 손실이 작아진다.
> 완벽한 예측(ŷ=1) → L=0, 잘못된 예측(ŷ→0) → L→∞

#### Cross-Entropy의 미분

```
∂L/∂ŷ_i = -y_i / ŷ_i
```

#### Softmax + Cross-Entropy 결합 미분 (핵심!)

실전에서는 softmax 출력이 cross-entropy에 바로 들어가므로, 결합 그래디언트가 중요하다.

```
∂L/∂z_i = ŷ_i - y_i    ← 놀랍도록 깔끔한 결과!

예: 정답 y = [0, 1, 0], 예측 ŷ = [0.1, 0.7, 0.2]

∂L/∂z = [0.1-0, 0.7-1, 0.2-0] = [0.1, -0.3, 0.2]
```

> **이것이 왜 중요한가?**
> 1. 계산이 매우 간단하다 (뺄셈 한 번)
> 2. 수치적으로 안정적이다 (log와 exp가 상쇄)
> 3. 이것 때문에 실제 구현에서 softmax와 cross-entropy를 항상 합쳐서 계산한다
>    (PyTorch의 `nn.CrossEntropyLoss`가 softmax를 내부 포함하는 이유)

**유도**:
```
∂L/∂z_i = Σ_k (∂L/∂ŷ_k) · (∂ŷ_k/∂z_i)    (연쇄법칙)

= Σ_k (-y_k/ŷ_k) · (∂softmax_k/∂z_i)

k=i: (-y_i/ŷ_i) · ŷ_i(1-ŷ_i) = -y_i(1-ŷ_i) = -y_i + y_i·ŷ_i
k≠i: (-y_k/ŷ_k) · (-ŷ_k·ŷ_i) = y_k·ŷ_i

합계: -y_i + y_i·ŷ_i + Σ_{k≠i} y_k·ŷ_i
    = -y_i + ŷ_i·(y_i + Σ_{k≠i} y_k)
    = -y_i + ŷ_i·(Σ_k y_k)
    = -y_i + ŷ_i·1     (원-핫이므로 합=1)
    = ŷ_i - y_i         ∎
```

### 1.3 ReLU와 활성화 함수의 미분

#### ReLU (Rectified Linear Unit)

```
ReLU(x) = max(0, x) = { x  if x > 0
                       { 0  if x ≤ 0

ReLU'(x) = { 1  if x > 0
            { 0  if x < 0
            { 정의되지 않음  if x = 0  (실전에서는 0으로 처리)
```

> **왜 ReLU가 인기있는가?**
> 1. 미분이 0 또는 1 → 그래디언트가 사라지지 않는다 (x>0일 때)
> 2. 계산이 매우 빠르다 (비교 연산 하나)
> 3. 희소성(sparsity): 약 50%의 뉴런이 0 → 효율적

#### ReLU의 문제: Dying ReLU

```
x < 0인 영역에서 그래디언트 = 0 → 가중치 업데이트 불가 → 뉴런이 "죽는다"

해결책:
- Leaky ReLU: f(x) = max(0.01x, x)  →  f'(x<0) = 0.01 (죽지 않음)
- ELU: f(x) = { x          if x > 0
              { α(eˣ - 1)  if x ≤ 0
- GELU: f(x) = x · Φ(x)  (Φ: 표준정규분포의 CDF, Transformer에서 사용)
```

#### Sigmoid와 Tanh

```
Sigmoid: σ(x) = 1/(1+e⁻ˣ)
σ'(x) = σ(x)(1 - σ(x))

최대 그래디언트 = 0.25 (x=0일 때)
→ 층이 깊어지면 0.25ⁿ → 0으로 급속 감소: 그래디언트 소실(Vanishing Gradient)!

Tanh: tanh(x) = (eˣ - e⁻ˣ)/(eˣ + e⁻ˣ)
tanh'(x) = 1 - tanh²(x)

최대 그래디언트 = 1 (x=0일 때)
→ Sigmoid보다 낫지만 여전히 소실 문제 존재
```

### 1.4 어텐션 (Attention) 메커니즘의 수학

#### Scaled Dot-Product Attention

```
Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k) · V

Q: Query 행렬 (n × d_k)
K: Key 행렬   (m × d_k)
V: Value 행렬 (m × d_v)
d_k: Key의 차원
```

**단계별 분해**:
```
1단계: 유사도 계산
   S = Q · Kᵀ          (n × m 행렬, 각 원소 = query와 key의 내적)

2단계: 스케일링
   S_scaled = S / √d_k  (내적 값이 커지면 softmax가 극단적이 되므로 정규화)

3단계: 어텐션 가중치
   A = softmax(S_scaled) (각 행이 확률분포, 합 = 1)

4단계: 가중 합
   Output = A · V        (n × d_v, Value의 가중 합)
```

> **√d_k로 나누는 이유**:
> Q, K의 각 원소가 평균 0, 분산 1이면:
> 내적의 분산 = d_k (d_k개 원소의 곱의 합이므로)
> → d_k가 크면 내적 값도 커져서 softmax의 그래디언트가 거의 0이 된다
> → √d_k로 나눠서 분산을 1로 맞춘다

#### Attention의 그래디언트 흐름

```
역전파 경로:

∂L/∂V = Aᵀ · (∂L/∂Output)

∂L/∂A = (∂L/∂Output) · Vᵀ

∂L/∂S = J_softmax · (∂L/∂A)  (행별로 softmax 야코비안 적용)

∂L/∂Q = (∂L/∂S) · K / √d_k
∂L/∂K = (∂L/∂S)ᵀ · Q / √d_k
```

> Attention은 모든 토큰 간의 내적을 계산하므로 O(n²) 복잡도이다.
> 이것이 긴 시퀀스에서의 계산 병목이 되고, 다양한 효율적 Attention 기법의 동기가 된다.

## 2. 벡터-벡터 미분과 야코비안 행렬 심화

### 2.1 벡터 미분의 체계

```
스칼라 → 스칼라: 일반 미분 f'(x)
벡터 → 스칼라: 그래디언트 ∇f  (n×1 벡터)
스칼라 → 벡터: (1×m 벡터)
벡터 → 벡터: 야코비안 J  (m×n 행렬)
```

### 2.2 야코비안과 역전파

신경망에서 각 층의 변환을 f₁, f₂, ..., f_L이라 하면:

```
출력 = f_L(f_{L-1}(...f₂(f₁(x))...))

연쇄법칙:
∂L/∂x = (∂f_L/∂f_{L-1}) · (∂f_{L-1}/∂f_{L-2}) · ... · (∂f₂/∂f₁) · (∂f₁/∂x)
       = J_L · J_{L-1} · ... · J₂ · J₁

각 J_i는 해당 층의 야코비안 행렬
```

> **Jacobian-Vector Product (JVP)**: 순방향, J·v 계산
> **Vector-Jacobian Product (VJP)**: 역방향, vᵀ·J 계산
> 역전파는 VJP를 출력에서 입력으로 반복 적용하는 것!

## 3. 고급 자가 점검 문제

### 문제 1: Softmax + Cross-Entropy
```
로짓 z = [1.0, 2.0, 0.5], 정답 레이블 y = [0, 1, 0]일 때:
1) softmax(z)를 계산하시오.
2) cross-entropy 손실을 계산하시오.
3) ∂L/∂z를 계산하시오.
```
<details>
<summary>정답 보기</summary>

```
1) exp(z) = [2.718, 7.389, 1.649], 합 = 11.756
   softmax(z) = [0.231, 0.629, 0.140]

2) L = -log(0.629) ≈ 0.464

3) ∂L/∂z = ŷ - y = [0.231-0, 0.629-1, 0.140-0]
         = [0.231, -0.371, 0.140]
```
</details>

### 문제 2: ReLU 네트워크
```
f(x) = ReLU(2x - 1)에서 x = 3일 때와 x = 0일 때의 그래디언트를 구하시오.
```
<details>
<summary>정답 보기</summary>

```
x = 3: 2(3)-1 = 5 > 0 → ReLU'(5) = 1
   df/dx = ReLU'(2x-1) · 2 = 1 · 2 = 2  (연쇄법칙)

x = 0: 2(0)-1 = -1 < 0 → ReLU'(-1) = 0
   df/dx = 0 · 2 = 0  (그래디언트 사라짐 = Dying ReLU)
```
</details>

### 문제 3: Attention 스케일링
```
d_k = 64일 때, √d_k는 얼마이며,
스케일링 없이 내적 값의 기대 분산은 얼마인가?
```
<details>
<summary>정답 보기</summary>

```
√64 = 8

각 원소가 N(0,1)이면 내적의 분산 = d_k = 64
표준편차 = 8

스케일링 후 분산 = 64/64 = 1, 표준편차 = 1
→ softmax의 입력이 적절한 범위에 들어온다.
```
</details>

## 핵심 요약

| 개념 | 미분 결과 | 핵심 포인트 |
|------|----------|------------|
| Softmax | J = diag(s) - ssᵀ | 출력 간 상호 의존적 |
| Cross-Entropy | -y/ŷ | 정답 클래스만 기여 |
| Softmax+CE 결합 | ŷ - y | 놀랍도록 깔끔, 수치 안정 |
| ReLU | 0 또는 1 | 그래디언트 보존, Dying 문제 |
| Sigmoid | σ(1-σ), 최대 0.25 | Vanishing Gradient 원인 |
| Attention | O(n²) 복잡도 | √d_k 스케일링 필수 |
| 야코비안 | m×n 행렬 | 역전파 = VJP 반복 |
