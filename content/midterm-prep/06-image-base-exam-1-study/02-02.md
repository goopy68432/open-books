# 딥러닝 수학 기초 - 중급 단계

## 학습 목표
> 선형대수의 핵심 정리와 고유값/특이값 분해를 이해하고, 벡터 미분과 최적화의 원리를 파악한다.

---

## 1. 선형대수 기본정리 (Fundamental Theorem of Linear Algebra)

### 1.1 이미지/치역 (Image / Range)

선형 변환 T(x) = Ax에서, 가능한 모든 출력값의 집합이다.

```
A = | 1  2 |
    | 2  4 |
    | 3  6 |

A의 열벡터: c1 = [1,2,3], c2 = [2,4,6]

c2 = 2·c1 이므로, Image(A) = span({[1,2,3]}) → 1차원 직선
```

> **직관**: 행렬 A가 벡터를 변환할 때, 출력이 "도달할 수 있는" 공간이 이미지다.
> 이미지의 차원 = 행렬의 랭크(rank)

#### 이미지의 의미

```
Ax = b 가 해를 가지려면, b가 A의 이미지 안에 있어야 한다.

Image(A) = {Ax | x ∈ Rⁿ} = A의 열공간 (Column Space)
```

### 1.2 커널/영공간 (Kernel / Null Space)

Ax = 0을 만족하는 모든 벡터 x의 집합이다.

```
A = | 1  2 |
    | 2  4 |

Ax = 0:
  x + 2y = 0
  2x + 4y = 0  (첫 번째 식의 2배 → 같은 조건)

해: x = -2t, y = t  →  Kernel(A) = {t·[-2, 1] | t ∈ R}
```

> **직관**: 커널은 A에 의해 "무(0)로 보내지는" 벡터들의 집합이다.
> 커널이 크다 = 정보 손실이 크다.

### 1.3 랭크-넬리티 정리 (Rank-Nullity Theorem)

```
rank(A) + nullity(A) = n  (열의 개수)

rank(A)    = dim(Image(A))   = 이미지의 차원
nullity(A) = dim(Kernel(A))  = 커널의 차원
n          = 입력 공간의 차원
```

**예시**:
```
A는 3×5 행렬, rank(A) = 3이라면:
nullity(A) = 5 - 3 = 2

→ 5차원 입력 중 3차원은 보존되고, 2차원은 소실된다.
```

> **딥러닝 연결**: 신경망의 각 층은 선형 변환 + 비선형 활성함수이다.
> 층의 rank가 낮으면 표현력이 제한되고, 정보가 손실된다.
> 이것이 "병목(bottleneck) 구조"의 수학적 근거이다.

## 2. 고유값과 고유벡터 (Eigenvalue & Eigenvector)

### 2.1 정의: Ax = λx

행렬 A를 곱해도 방향이 바뀌지 않고 크기만 λ배 되는 벡터 x가 고유벡터이다.

```
A = | 2  1 |
    | 1  2 |

고유값 구하기: det(A - λI) = 0
| 2-λ   1  |
|  1   2-λ | = (2-λ)² - 1 = λ² - 4λ + 3 = (λ-1)(λ-3) = 0

λ₁ = 1, λ₂ = 3
```

**고유벡터 구하기**:
```
λ₁ = 1일 때: (A - I)x = 0
| 1  1 | |x₁| = |0|  →  x₁ + x₂ = 0  →  v₁ = [-1, 1]
| 1  1 | |x₂|   |0|

λ₂ = 3일 때: (A - 3I)x = 0
|-1  1 | |x₁| = |0|  →  -x₁ + x₂ = 0  →  v₂ = [1, 1]
| 1 -1 | |x₂|   |0|
```

### 2.2 큰 고유값 = 높은 중요도

고유값의 크기는 해당 방향으로의 "영향력"을 나타낸다.

```
데이터의 공분산 행렬을 고유분해하면:
- 가장 큰 고유값의 고유벡터 = 데이터가 가장 많이 퍼진 방향
- 가장 작은 고유값의 고유벡터 = 데이터가 거의 변하지 않는 방향

예: 고유값 [100, 1]
→ 첫 번째 방향의 분산이 100배 더 크다
→ 두 번째 방향은 거의 무시해도 된다
→ 차원 축소 가능!
```

### 2.3 응용: 구글 페이지랭크 (PageRank)

```
웹 페이지 간 링크 구조 → 전이 행렬 M

M의 최대 고유값(=1)에 대응하는 고유벡터 = 각 페이지의 중요도 점수

직관: "중요한 페이지가 링크하는 페이지도 중요하다"를 반복하면
      결국 고유벡터로 수렴한다.
```

## 3. 특이값 분해 (SVD: Singular Value Decomposition)

### 3.1 SVD란?

모든 행렬 A를 세 행렬의 곱으로 분해하는 것이다.

```
A = U · Σ · Vᵀ

A: m×n 원본 행렬
U: m×m 직교 행렬 (왼쪽 특이벡터)
Σ: m×n 대각 행렬 (특이값, σ₁ ≥ σ₂ ≥ ... ≥ 0)
V: n×n 직교 행렬 (오른쪽 특이벡터)
```

> 고유분해(eigendecomposition)는 정방행렬에서만 가능하지만,
> SVD는 **모든 행렬**에 적용 가능하다!

### 3.2 데이터 압축 및 근사

특이값을 크기 순으로 정렬한 후, 상위 k개만 사용하면 근사가 가능하다.

```
원본: A = U · Σ · Vᵀ              (특이값 100개)
근사: A ≈ U_k · Σ_k · V_k^T      (상위 10개만 사용)

저장 공간: m×n → m×k + k + k×n  (k << n이면 큰 절약)
```

**이미지 압축 예시**:
```
1000×1000 이미지 = 1,000,000 픽셀 저장

SVD로 상위 50개 특이값만 사용:
1000×50 + 50 + 50×1000 = 100,050 값만 저장
→ 원본의 약 10%만으로 원본과 거의 동일한 이미지!
```

### 3.3 PCA의 기초 (Principal Component Analysis)

PCA는 SVD를 데이터의 공분산 행렬에 적용한 것이다.

```
데이터 행렬 X (n개 샘플, d개 특징)
1. 평균 중심화: X_centered = X - mean(X)
2. 공분산 행렬: C = (1/n) · X_centeredᵀ · X_centered
3. C를 고유분해 (또는 X_centered를 SVD)
4. 상위 k개 고유벡터 방향으로 사영 → k차원으로 축소

결과: d차원 데이터 → k차원 데이터 (정보 손실 최소화)
```

> **딥러닝 연결**: 오토인코더(Autoencoder)는 PCA의 비선형 일반화 버전이다!

## 4. 미분과 최적화 - 중급

### 4.1 선형 근사 (Linear Approximation)

복잡한 함수를 특정 점 근처에서 직선으로 근사한다.

```
f(x) ≈ f(a) + f'(a) · (x - a)

예: f(x) = √x,  a = 4
f(4) = 2,  f'(x) = 1/(2√x),  f'(4) = 1/4

√(4.1) ≈ 2 + (1/4)(4.1 - 4) = 2 + 0.025 = 2.025
실제값: √4.1 ≈ 2.02485...  (매우 근접!)
```

> **딥러닝에서**: 활성함수, 손실함수 등 복잡한 함수를 국소적으로 선형화하여
> 최적화 알고리즘이 "다음 스텝"을 결정한다.

### 4.2 뉴턴 방법 (Newton's Method)

방정식 f(x) = 0의 근을 빠르게 찾는 반복 알고리즘이다.

```
x_{n+1} = x_n - f(x_n) / f'(x_n)

예: f(x) = x² - 5 (√5를 구하고 싶다)
    f'(x) = 2x

x₀ = 2
x₁ = 2 - (4-5)/(2·2) = 2 - (-1/4) = 2.25
x₂ = 2.25 - (5.0625-5)/(4.5) = 2.25 - 0.01389 = 2.23611
실제 √5 ≈ 2.23607 (2번 반복으로 소수점 4자리 정확!)
```

> **2차 수렴**: 매 반복마다 정확한 자릿수가 약 2배씩 증가한다.
> 경사하강법(1차)보다 빠르지만, 2차 미분(헤시안)이 필요해서 비용이 크다.

### 4.3 벡터/스칼라 미분

#### 스칼라를 벡터로 미분 → 그래디언트 (Gradient)

```
f(x₁, x₂) = x₁² + 3x₁x₂ + x₂²

∇f = | ∂f/∂x₁ | = | 2x₁ + 3x₂ |
     | ∂f/∂x₂ |   | 3x₁ + 2x₂ |

x = [1, 2]일 때:
∇f(1,2) = | 2(1) + 3(2) | = | 8 |
           | 3(1) + 2(2) |   | 7 |
```

> **핵심**: 그래디언트 벡터는 함수가 가장 빠르게 증가하는 방향을 가리킨다.
> 경사하강법은 이 반대 방향으로 이동한다!

#### 벡터를 벡터로 미분 → 야코비안 (Jacobian)

```
f: Rⁿ → Rᵐ일 때

f(x₁, x₂) = | f₁(x) | = | x₁² + x₂  |
             | f₂(x) |   | x₁ · x₂   |

J = | ∂f₁/∂x₁  ∂f₁/∂x₂ | = | 2x₁   1  |
    | ∂f₂/∂x₁  ∂f₂/∂x₂ |   |  x₂   x₁ |
```

> **역전파에서**: 각 층의 야코비안을 연쇄법칙으로 곱해서 그래디언트를 전파한다.

## 5. 중급 자가 점검 문제

### 문제 1: 고유값/고유벡터
```
A = | 3  0 |의 고유값과 고유벡터를 구하시오.
    | 0  2 |
```
<details>
<summary>정답 보기</summary>

```
대각행렬이므로 대각 원소가 곧 고유값이다.
λ₁ = 3, v₁ = [1, 0]
λ₂ = 2, v₂ = [0, 1]
```
</details>

### 문제 2: 랭크-넬리티
```
4×6 행렬 A의 rank가 3이면, nullity는?
```
<details>
<summary>정답 보기</summary>

```
rank + nullity = 열의 수
3 + nullity = 6
nullity = 3

→ 6차원 입력 중 3차원의 정보가 소실된다.
```
</details>

### 문제 3: 그래디언트
```
f(x, y) = x²y + y³ 의 그래디언트를 구하고,
점 (1, 2)에서의 값을 계산하시오.
```
<details>
<summary>정답 보기</summary>

```
∇f = [∂f/∂x, ∂f/∂y] = [2xy, x² + 3y²]

(1, 2)에서: ∇f = [2(1)(2), 1² + 3(2²)] = [4, 13]

→ (1,2)에서 [4, 13] 방향으로 함수가 가장 빠르게 증가한다.
```
</details>

### 문제 4: 뉴턴 방법
```
f(x) = x³ - 2에서 x₀ = 1로 시작하여 1회 반복하시오.
(∛2를 근사)
```
<details>
<summary>정답 보기</summary>

```
f'(x) = 3x²
x₁ = x₀ - f(x₀)/f'(x₀) = 1 - (1-2)/(3) = 1 - (-1/3) = 4/3 ≈ 1.333

실제 ∛2 ≈ 1.2599이므로 아직 좀 차이가 있지만,
2~3회 반복하면 빠르게 수렴한다.
```
</details>
