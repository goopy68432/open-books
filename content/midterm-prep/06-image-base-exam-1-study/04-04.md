# 딥러닝 수학 기초 - 마스터 단계

## 학습 목표
> 모든 개념을 통합하여 실제 딥러닝 시스템에서의 수학적 흐름을 완전히 추적하고,
> 확률론과의 연결, 수치 안정성, 최적화 심화까지 마스터한다.

## 1. 전체 통합: 신경망의 순전파/역전파 수학적 추적

### 1.1 완전한 2층 신경망 수학 추적

```
입력: x ∈ R⁴ (4차원 특징)
1층: z₁ = W₁x + b₁,  a₁ = ReLU(z₁)     W₁ ∈ R^(3×4)
2층: z₂ = W₂a₁ + b₂, ŷ = softmax(z₂)   W₂ ∈ R^(3×3)
손실: L = CrossEntropy(y, ŷ)
```

#### 순전파 (Forward Pass) - 수치 예시

```
x = [1.0, 0.5, -1.0, 2.0]

W₁ = | 0.1  0.3  -0.2  0.4 |    b₁ = | 0.1 |
     | 0.2 -0.1   0.5  0.1 |         |-0.2 |
     |-0.3  0.2   0.1  0.3 |         | 0.0 |

z₁ = W₁x + b₁
   = | 0.1(1) + 0.3(0.5) + (-0.2)(-1) + 0.4(2) + 0.1 |
     | 0.2(1) + (-0.1)(0.5) + 0.5(-1) + 0.1(2) + (-0.2) |
     | (-0.3)(1) + 0.2(0.5) + 0.1(-1) + 0.3(2) + 0.0 |

   = | 0.1 + 0.15 + 0.2 + 0.8 + 0.1 |   | 1.35 |
     | 0.2 - 0.05 - 0.5 + 0.2 - 0.2 |  = |-0.35 |
     | -0.3 + 0.1 - 0.1 + 0.6 + 0.0 |   | 0.30 |

a₁ = ReLU(z₁) = | 1.35 |  (음수는 0으로)
                 | 0.00 |
                 | 0.30 |

z₂ = W₂a₁ + b₂  (생략, 동일 방식)

ŷ = softmax(z₂) = [0.25, 0.50, 0.25]  (가정)
y = [0, 1, 0]  (정답: 클래스 2)

L = -log(0.50) = 0.693
```

#### 역전파 (Backward Pass) - 전체 그래디언트 추적

```
Step 1: 출력층 그래디언트
   ∂L/∂z₂ = ŷ - y = [0.25, -0.50, 0.25]

Step 2: W₂, b₂의 그래디언트
   ∂L/∂W₂ = (∂L/∂z₂) · a₁ᵀ
           = | 0.25 |                     | 0.25×1.35  0.25×0  0.25×0.30 |
             |-0.50 | · [1.35, 0, 0.30] = |-0.50×1.35 -0.50×0 -0.50×0.30|
             | 0.25 |                     | 0.25×1.35  0.25×0  0.25×0.30 |

           = | 0.3375   0   0.075 |
             |-0.675    0  -0.15  |
             | 0.3375   0   0.075 |

   ∂L/∂b₂ = ∂L/∂z₂ = [0.25, -0.50, 0.25]

Step 3: 은닉층으로 그래디언트 전파
   ∂L/∂a₁ = W₂ᵀ · (∂L/∂z₂)     ← 이것이 행렬의 전치가 필요한 이유!

Step 4: ReLU 통과
   ∂L/∂z₁ = ∂L/∂a₁ ⊙ ReLU'(z₁)    (⊙: 원소별 곱)

   ReLU'(z₁) = ReLU'([1.35, -0.35, 0.30]) = [1, 0, 1]

   → z₁의 두 번째 원소가 음수였으므로, 해당 그래디언트는 완전히 차단!

Step 5: W₁, b₁의 그래디언트
   ∂L/∂W₁ = (∂L/∂z₁) · xᵀ
   ∂L/∂b₁ = ∂L/∂z₁
```

> **핵심 관찰**:
> 1. 모든 그래디언트는 행렬 곱셈과 원소별 연산의 조합이다
> 2. ReLU의 0/1 게이트가 그래디언트 흐름을 제어한다
> 3. 전치 행렬 W₂ᵀ가 역방향에서 사용된다 (순방향의 "역경로")
> 4. 각 층의 그래디언트는 이전 활성값(a)과 이후 그래디언트(∂L/∂z)의 외적(outer product)이다

## 2. SVD와 신경망의 깊은 연결

### 2.1 가중치 행렬의 SVD 해석

```
W = U · Σ · Vᵀ

W에 의한 변환: y = Wx = U · Σ · (Vᵀ · x)

1단계: Vᵀ · x → 입력을 새로운 좌표계로 회전
2단계: Σ · (...) → 각 축 방향으로 스케일링 (특이값이 배율)
3단계: U · (...) → 출력 좌표계로 다시 회전
```

> **해석**: 모든 선형 변환은 "회전 → 스케일링 → 회전"으로 분해된다!

### 2.2 Low-Rank Approximation과 LoRA

```
원래 가중치: W ∈ R^(d×d)  → d² 파라미터

LoRA (Low-Rank Adaptation):
W' = W + ΔW,  ΔW = B·A

B ∈ R^(d×r), A ∈ R^(r×d), r << d

파라미터: d² + 2dr  (r=16, d=4096이면 ΔW는 0.8% 추가)
```

> **SVD와의 연결**: LoRA는 본질적으로 업데이트 행렬 ΔW를 rank-r로 제한하는 것이다.
> SVD에서 상위 r개 특이값만 사용하는 것과 동일한 원리!

### 2.3 행렬의 조건수 (Condition Number)와 학습 안정성

```
조건수 κ(A) = σ_max / σ_min  (최대 특이값 / 최소 특이값)

κ ≈ 1: 잘 조건화된 (well-conditioned) 행렬 → 안정적 학습
κ >> 1: 나쁘게 조건화된 (ill-conditioned) 행렬 → 불안정 학습
```

> **학습에의 영향**:
> - 조건수가 크면 손실 함수의 등고선이 길쭉한 타원 → 경사하강법이 지그재그
> - 해결: 배치 정규화, 학습률 스케줄링, Adam 옵티마이저 등

## 3. 수치 안정성 (Numerical Stability)

### 3.1 Softmax의 수치 안정성 트릭

```
문제: exp(1000) = Inf (오버플로)

해결: softmax(z_i) = exp(z_i - max(z)) / Σ exp(z_j - max(z))

수학적으로 동일하지만 수치적으로 안정적이다.

증명:
exp(z_i - c) / Σ exp(z_j - c) = exp(z_i)·exp(-c) / Σ exp(z_j)·exp(-c)
                                = exp(z_i) / Σ exp(z_j)  ← 원래 softmax!
```

### 3.2 Log-Sum-Exp 트릭

```
log(Σ exp(z_i)) 를 직접 계산하면 오버플로 위험

LSE(z) = max(z) + log(Σ exp(z_i - max(z)))

이렇게 하면 exp 내부가 항상 0 이하 → 오버플로 방지
```

### 3.3 그래디언트 소실/폭발 정량 분석

```
L층 네트워크에서 그래디언트 크기:

∂L/∂W₁ = Π_{i=2}^{L} (diag(f'_i) · W_i) · (∂L/∂z_L)

각 층의 스펙트럼 반경(최대 고유값의 절대값)을 ρ_i라 하면:
||∂L/∂W₁|| ∝ Π ρ_i

ρ_i < 1 → ρ₁·ρ₂·...·ρ_L → 0  (소실)
ρ_i > 1 → ρ₁·ρ₂·...·ρ_L → ∞  (폭발)
```

> **초기화 전략의 수학적 근거**:
>
> **Xavier 초기화**: W ~ N(0, 2/(n_in + n_out))
> → 순전파/역전파 모두에서 분산 보존
>
> **He 초기화**: W ~ N(0, 2/n_in)
> → ReLU가 절반의 값을 0으로 만드는 것을 보정 (분산이 1/2로 줄므로 2배)

## 4. 최적화 심화

### 4.1 경사하강법과 2차 최적화의 관계

```
1차 (SGD):     θ_{t+1} = θ_t - η · ∇L(θ_t)
2차 (Newton):  θ_{t+1} = θ_t - H⁻¹ · ∇L(θ_t)

H = 헤시안 행렬 (2차 편미분의 행렬)
H_{ij} = ∂²L / (∂θ_i ∂θ_j)
```

> Newton's method는 곡률 정보를 사용해서 최적의 스텝을 밟지만,
> 파라미터 n개에 대해 H는 n×n → 1억 파라미터면 10^16 원소 → 불가능!

### 4.2 Adam: 1차와 2차의 절충

```
Adam은 그래디언트의 1차 모멘트(평균)와 2차 모멘트(분산)를 추정한다.

m_t = β₁·m_{t-1} + (1-β₁)·g_t          (1차 모멘트, 이동 평균)
v_t = β₂·v_{t-1} + (1-β₂)·g_t²         (2차 모멘트, 분산의 이동 평균)

m̂_t = m_t / (1-β₁ᵗ)                     (편향 보정)
v̂_t = v_t / (1-β₂ᵗ)

θ_{t+1} = θ_t - η · m̂_t / (√v̂_t + ε)
```

> **수학적 해석**: Adam은 각 파라미터의 곡률을 √v̂로 근사하여
> 곡률이 큰 방향은 작게, 작은 방향은 크게 업데이트한다.
> 이것은 대각 헤시안 근사(diagonal Hessian approximation)와 유사하다.

## 5. 확률론과의 연결 (다음 주제 예고)

### 5.1 베이지안 확률 (Bayesian Probability)

```
P(θ|D) = P(D|θ) · P(θ) / P(D)

사후확률 = 우도 × 사전확률 / 증거

P(θ|D): 데이터를 본 후 파라미터의 확률 분포
P(D|θ): 우도 (likelihood) - 모델이 데이터를 설명하는 정도
P(θ): 사전확률 - 데이터 관찰 전의 믿음
P(D): 증거 - 정규화 상수
```

> **딥러닝 연결**:
> - 정규화(Regularization) = 사전확률 P(θ) 설정과 동일
>   - L2 정규화 ↔ 가우시안 사전확률 P(θ) ~ N(0, σ²I)
>   - L1 정규화 ↔ 라플라스 사전확률
> - MLE (Maximum Likelihood Estimation) = 사전확률 무시하고 우도만 최대화
> - MAP (Maximum A Posteriori) = 사전확률 포함 최대화 = 정규화된 MLE

### 5.2 귀납적 추론 (Induction)과 학습

```
유한한 학습 데이터 → 일반적 규칙을 추론

PAC (Probably Approximately Correct) 학습:
P(|L_true - L_train| > ε) ≤ δ

"충분한 데이터가 있으면, 높은 확률(1-δ)로 학습 오차와 실제 오차가 ε 이내"

필요 데이터 수: n ≥ (1/2ε²) · log(2|H|/δ)
|H|: 가설 공간의 크기
```

> 이것이 "딥러닝은 왜 일반화되는가?"라는 근본 질문과 연결된다.
> 과적합 = 가설 공간이 너무 커서 학습 데이터에만 맞는 모델을 찾는 것.

y = [1, 0] (정답: 클래스 1)

1) 순전파로 z₁, a₁, z₂, ŷ, L을 모두 구하시오.

```

→ W₁의 첫 번째 행 그래디언트가 0! (ReLU가 차단했으므로)

A = |3  0|의 SVD를 구하고, rank-1 근사의 오차를 구하시오.

### 문제 4: 베이지안 해석
```
L2 정규화가 가우시안 사전확률과 동일함을 보이시오.

힌트: MAP 추정은 -log(P(D|θ)) - log(P(θ))를 최소화하는 것이고,
     P(θ) ~ N(0, σ²I)이다.
```
<details>
<summary>정답 보기</summary>

```
MAP 목적함수: argmin_θ [-log P(D|θ) - log P(θ)]

P(θ) ~ N(0, σ²I)일 때:
-log P(θ) = -log(1/√(2πσ²)^n · exp(-||θ||²/(2σ²)))
           = n/2 · log(2πσ²) + ||θ||²/(2σ²)
           ∝ (1/(2σ²)) · ||θ||²         (상수 제거)

따라서:
MAP 목적함수 = -log P(D|θ) + λ||θ||²   (λ = 1/(2σ²))
            = NLL + L2_regularization

→ L2 정규화 = 가우시안 사전확률 하의 MAP 추정!
  σ가 작을수록 (확신이 강할수록) λ가 커져서 정규화가 강해진다.
```
</details>

                          +CE결합   초기화   스케일링
                          ŷ-y     He/Xavier  √d_k
```

## 핵심 요약

| 주제 | 마스터 레벨 핵심 통찰 |
|------|---------------------|
| 역전파 | 야코비안의 VJP 체인. 순전파의 전치가 역방향을 구성 |
| SVD/LoRA | 모든 행렬 = 회전+스케일+회전. Low-rank로 파라미터 효율화 |
| 조건수 | σ_max/σ_min → 학습 안정성의 정량적 지표 |
| 수치 안정성 | max 빼기 트릭, LSE 트릭으로 오버플로/언더플로 방지 |
| 초기화 | Xavier(σ²=2/(n_in+n_out)), He(σ²=2/n_in) → 분산 보존 |
| Adam | 대각 헤시안 근사 → 적응적 학습률 |
| 베이지안 | 정규화 = 사전확률, MLE↔MAP, 불확실성 정량화 |
| Attention | O(n²) 복잡도, softmax의 야코비안이 그래디언트 전파 결정 |
