# Ch.19 생성모델과 판별모델

---

## 1. 학습 목표

이 장을 마친 후 다음을 할 수 있어야 한다:

- 결합확률(joint probability), 주변확률(marginal probability), 조건부확률(conditional probability)의 정의를 정확히 진술할 수 있다
- 생성모델(generative model)과 판별모델(discriminative model)의 **확률적 정의**를 각각 서술할 수 있다
- 생성모델이 모델링하는 대상($P(\mathbf{x}, y)$ 또는 $P(\mathbf{x})$)과 판별모델이 모델링하는 대상($P(y|\mathbf{x})$)의 차이를 명확히 설명할 수 있다
- 베이즈 정리(Bayes' theorem)를 이용하여 생성모델로부터 분류 규칙을 유도할 수 있다
- 나이브 베이즈(Naive Bayes) 분류기의 독립 가정을 진술하고, 이로부터 분류 규칙을 유도할 수 있다
- 베이즈 최적 분류기(Bayes optimal classifier)가 최소 오류율을 달성함을 증명할 수 있다
- 구체적인 숫자 예제에서 생성모델과 판별모델 각각을 사용하여 분류 문제를 풀 수 있다
- 언어모델(language model)이 생성모델의 한 형태임을 확률적으로 설명할 수 있다
- 두 접근법의 장단점을 정보량(information)의 관점에서 비교할 수 있다

---

## 2. 필수 정의

### Definition 19.1 (결합확률, Joint Probability)

확률변수 $\mathbf{x} \in \mathcal{X}$와 $y \in \mathcal{Y}$에 대해, **결합확률**(joint probability)은 $\mathbf{x}$와 $y$가 동시에 특정 값을 가질 확률이다:

$$P(\mathbf{x}, y) = P(\mathbf{x} = \mathbf{x}_0, \, y = y_0)$$

이는 입력과 레이블이 **함께** 어떻게 분포하는지를 기술한다.

> **해석:** 결합확률은 데이터의 전체적인 구조를 담고 있다. "어떤 입력이 어떤 레이블과 함께 나타나는가"에 대한 완전한 정보를 제공한다. 결합확률을 알면 조건부확률과 주변확률을 모두 유도할 수 있다.

**예시:**

- **이미지 분류:** $\mathbf{x}$가 이미지 픽셀, $y$가 "고양이/개" 레이블일 때, $P(\mathbf{x}, y)$는 "이 특정 이미지가 고양이 레이블과 함께 나타날 확률"이다.
- **의료 진단:** $\mathbf{x}$가 환자의 증상 벡터, $y$가 질병 여부일 때, $P(\mathbf{x}, y)$는 "이 증상 패턴이 특정 질병과 함께 관찰될 확률"이다.

---

### Definition 19.2 (주변확률, Marginal Probability)

결합확률 $P(\mathbf{x}, y)$로부터, 한 변수를 **주변화**(marginalization)하여 얻는 확률이다.

이산 변수인 경우:

$$P(\mathbf{x}) = \sum_{y \in \mathcal{Y}} P(\mathbf{x}, y)$$

연속 변수인 경우:

$$P(\mathbf{x}) = \int_{\mathcal{Y}} P(\mathbf{x}, y) \, dy$$

마찬가지로:

$$P(y) = \sum_{\mathbf{x} \in \mathcal{X}} P(\mathbf{x}, y) \quad \text{(이산)}, \qquad P(y) = \int_{\mathcal{X}} P(\mathbf{x}, y) \, d\mathbf{x} \quad \text{(연속)}$$

> **해석:** 주변확률은 결합확률에서 관심 없는 변수를 "합산하여 제거"한 결과이다. $P(\mathbf{x})$는 레이블과 무관하게 입력 자체가 나타날 확률, $P(y)$는 사전확률(prior probability)이다.

**예시:**

- **스팸 필터:** 전체 이메일 중 스팸의 비율 $P(y = \text{spam}) = 0.3$은 주변확률이다. 이메일 내용 $\mathbf{x}$와 무관하게 레이블만의 분포를 나타낸다.
- **언어모델:** 단어 $w$의 출현 확률 $P(w)$는 문맥을 무시한 주변확률(유니그램 확률)이다.

---

### Definition 19.3 (조건부확률, Conditional Probability)

$P(\mathbf{x}) > 0$일 때, $\mathbf{x}$가 주어졌을 때 $y$의 **조건부확률**(conditional probability)은:

$$P(y|\mathbf{x}) = \frac{P(\mathbf{x}, y)}{P(\mathbf{x})}$$

마찬가지로, $P(y) > 0$일 때:

$$P(\mathbf{x}|y) = \frac{P(\mathbf{x}, y)}{P(y)}$$

> **해석:** $P(y|\mathbf{x})$는 "입력 $\mathbf{x}$를 관측한 후 레이블 $y$에 대한 믿음의 갱신"이다. 분류 문제의 핵심 목표는 바로 이 조건부확률을 정확히 추정하는 것이다.

**예시:**

- **이미지 분류:** $P(y = \text{고양이} | \mathbf{x})$는 "이 이미지가 주어졌을 때 고양이일 확률"이다.
- **우도(likelihood):** $P(\mathbf{x} | y = \text{고양이})$는 "고양이 클래스에서 이 이미지가 생성될 확률"이다.

---

### Definition 19.4 (생성모델, Generative Model)

**생성모델**(generative model)은 데이터의 결합분포 $P(\mathbf{x}, y)$를 모델링하거나, 이를 다음과 같이 분해하여 모델링하는 모델이다:

$$P(\mathbf{x}, y) = P(\mathbf{x}|y) \, P(y)$$

여기서 $P(\mathbf{x}|y)$는 클래스-조건부 우도(class-conditional likelihood), $P(y)$는 사전확률(prior)이다.

레이블 없이 $P(\mathbf{x})$ 자체를 모델링하는 **비지도 생성모델**(unsupervised generative model)도 이 범주에 포함된다.

> **해석:** 생성모델은 "데이터가 어떻게 생성되는지"의 과정을 확률적으로 모델링한다. 클래스별로 데이터의 분포를 학습하므로, 새로운 데이터를 **생성(sampling)**할 수 있다는 것이 핵심 특징이다.

**대표 모델:**

| 모델 | 모델링 대상 | 비고 |
|------|-------------|------|
| 나이브 베이즈(Naive Bayes) | $P(\mathbf{x}|y)P(y)$ | 특징 간 조건부 독립 가정 |
| 가우시안 혼합 모델(GMM) | $P(\mathbf{x}) = \sum_k \pi_k \mathcal{N}(\mathbf{x}; \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$ | 비지도 생성모델 |
| 변분 오토인코더(VAE) | $P_\theta(\mathbf{x}) = \int P_\theta(\mathbf{x}|\mathbf{z}) P(\mathbf{z}) \, d\mathbf{z}$ | 잠재변수 생성모델 |
| GPT (언어모델) | $P(w_1, w_2, \ldots, w_T) = \prod_{t=1}^{T} P(w_t | w_{<t})$ | 자기회귀 생성모델 |
| 확산 모델(Diffusion Model) | $P(\mathbf{x})$ via denoising | 최신 이미지 생성 |

---

### Definition 19.5 (판별모델, Discriminative Model)

**판별모델**(discriminative model)은 조건부확률 $P(y|\mathbf{x})$를 **직접** 모델링하는 모델이다.

$$\text{목표: } P(y|\mathbf{x}) \text{를 직접 학습}$$

생성모델처럼 $P(\mathbf{x})$나 $P(\mathbf{x}|y)$를 거치지 않고, 입력에서 레이블로의 매핑을 바로 학습한다.

> **해석:** 판별모델은 "데이터가 어떻게 생성되는지"에는 관심이 없고, 오직 "주어진 데이터에 어떤 레이블을 붙여야 하는지"만 학습한다. 분류 성능 자체는 일반적으로 판별모델이 우수한 경우가 많다.

**대표 모델:**

| 모델 | 모델링 대상 | 비고 |
|------|-------------|------|
| 로지스틱 회귀(Logistic Regression) | $P(y|\mathbf{x}) = \sigma(\mathbf{w}^\top \mathbf{x} + b)$ | 선형 판별모델 |
| 소프트맥스 회귀(Softmax Regression) | $P(y=k|\mathbf{x}) = \frac{e^{\mathbf{w}_k^\top \mathbf{x}}}{\sum_j e^{\mathbf{w}_j^\top \mathbf{x}}}$ | 다중 클래스 확장 |
| 신경망(Neural Network) | $P(y|\mathbf{x}; \theta)$ | 비선형 판별모델 |
| 조건부 랜덤 필드(CRF) | $P(\mathbf{y}|\mathbf{x})$ | 구조적 예측 |
| SVM (서포트 벡터 머신) | 결정 경계 직접 학습 | 확률 모델 아님, 판별 함수 |

## 3. 핵심 정리와 명제

### Theorem 19.1 (베이즈 분류 규칙, Bayes Classification Rule)

생성모델이 $P(\mathbf{x}|y)$와 $P(y)$를 학습했다면, 베이즈 정리에 의해 사후확률(posterior)을 다음과 같이 계산할 수 있다:

$$P(y|\mathbf{x}) = \frac{P(\mathbf{x}|y) \, P(y)}{P(\mathbf{x})} = \frac{P(\mathbf{x}|y) \, P(y)}{\displaystyle\sum_{y' \in \mathcal{Y}} P(\mathbf{x}|y') \, P(y')}$$

분류 결정은:

$$\hat{y} = \arg\max_{y \in \mathcal{Y}} \; P(y|\mathbf{x}) = \arg\max_{y \in \mathcal{Y}} \; P(\mathbf{x}|y) \, P(y)$$

(분모 $P(\mathbf{x})$는 $y$에 무관하므로 $\arg\max$에서 생략 가능)

> **왜 중요한가:** 이 정리는 생성모델과 판별모델을 잇는 다리(bridge)이다. 생성모델은 $P(\mathbf{x}|y)P(y)$를 모델링하지만, 최종적으로 분류에 사용할 때는 베이즈 정리를 통해 $P(y|\mathbf{x})$를 구한다. 즉, 생성모델도 간접적으로 판별 작업을 수행할 수 있다.

> **어디에 쓰이는가:** 나이브 베이즈 분류기, 가우시안 판별 분석(GDA), 의료 진단 시스템, 스팸 필터 등에서 핵심적으로 사용된다.

---

### Theorem 19.2 (정보량 차이, Information Gap)

생성모델은 판별모델보다 **더 많은 정보**를 학습한다. 구체적으로:

$$P(\mathbf{x}, y) = P(y|\mathbf{x}) \, P(\mathbf{x})$$

이므로, 결합분포 $P(\mathbf{x}, y)$를 아는 것은 조건부확률 $P(y|\mathbf{x})$를 아는 것보다 **엄밀히 더 강한** 조건이다:

$$P(\mathbf{x}, y) \text{를 알면} \implies P(y|\mathbf{x}) \text{를 유도할 수 있다}$$

$$P(y|\mathbf{x}) \text{를 알아도} \implies P(\mathbf{x}, y) \text{를 복원할 수 없다} \quad (\text{∵ } P(\mathbf{x}) \text{를 모름})$$

> **왜 중요한가:** 이 비대칭성은 두 모델의 근본적 차이를 설명한다.
>
> - 생성모델: 더 많은 정보를 학습 → 데이터 생성, 이상 탐지, 결측치 처리 가능 → 하지만 더 어려운 문제를 품
> - 판별모델: 분류에 필요한 정보만 학습 → 더 적은 데이터로 높은 분류 성능 → 하지만 데이터 생성 불가

> **어디에 쓰이는가:** 모델 선택의 근거가 된다. 분류 정확도만 중요하면 판별모델, 데이터 생성·이상 탐지·결측치 처리가 필요하면 생성모델을 선택한다.

**Ng & Jordan (2002)의 관찰:** 나이브 베이즈(생성)와 로지스틱 회귀(판별)를 비교했을 때:
- 학습 데이터가 **적을 때**: 생성모델이 더 빠르게 수렴 (모델 가정이 강한 귀납적 편향 제공)
- 학습 데이터가 **많을 때**: 판별모델이 점근적으로 더 낮은 오류율 달성

---

### Theorem 19.3 (나이브 베이즈의 가정과 분류 규칙, Naive Bayes Assumption and Rule)

**가정 (조건부 독립, Conditional Independence):** 입력 벡터 $\mathbf{x} = (x_1, x_2, \ldots, x_d)$의 각 특징(feature)은 클래스 $y$가 주어졌을 때 **조건부 독립**(conditionally independent)이다:

$$P(\mathbf{x}|y) = P(x_1, x_2, \ldots, x_d | y) = \prod_{i=1}^{d} P(x_i | y)$$

이로부터 나이브 베이즈 분류 규칙은:

$$\hat{y} = \arg\max_{y \in \mathcal{Y}} \; P(y) \prod_{i=1}^{d} P(x_i | y)$$

로그를 취하면:

$$\hat{y} = \arg\max_{y \in \mathcal{Y}} \left[ \log P(y) + \sum_{i=1}^{d} \log P(x_i | y) \right]$$

> **왜 중요한가:** 독립 가정 없이 $P(\mathbf{x}|y)$를 추정하려면 $|\mathcal{X}|$ 크기의 파라미터 테이블이 필요하여 차원의 저주(curse of dimensionality)에 빠진다. 독립 가정을 도입하면 파라미터 수가 $d \cdot |\mathcal{Y}|$로 **선형적으로** 감소한다.

> **어디에 쓰이는가:** 텍스트 분류(스팸 필터, 감성 분석), 의료 진단, 추천 시스템 등에서 빠르고 효과적인 기준선(baseline) 모델로 널리 사용된다.

## 4. 공식 및 수식 유도

### 4.1 생성모델로부터 분류기 유도 (Bayes Decision Rule)

**출발점:** 생성모델이 $P(\mathbf{x}|y)$와 $P(y)$를 학습했다고 하자.

**단계 1.** 베이즈 정리를 적용한다:

$$P(y|\mathbf{x}) = \frac{P(\mathbf{x}|y) P(y)}{P(\mathbf{x})}$$

**단계 2.** 분모를 전확률의 법칙으로 전개한다:

$$P(\mathbf{x}) = \sum_{y' \in \mathcal{Y}} P(\mathbf{x}|y') P(y')$$

**단계 3.** 분류 결정 규칙을 구성한다. $\arg\max$에서 분모는 $y$에 무관한 상수이므로:

$$\hat{y} = \arg\max_{y} P(y|\mathbf{x}) = \arg\max_{y} \frac{P(\mathbf{x}|y) P(y)}{P(\mathbf{x})} = \arg\max_{y} P(\mathbf{x}|y) P(y)$$

**단계 4.** 로그를 취하면 (로그는 단조증가 함수이므로 $\arg\max$가 보존됨):

$$\hat{y} = \arg\max_{y} \left[ \log P(\mathbf{x}|y) + \log P(y) \right]$$

> **요약:** 생성모델의 출력 $P(\mathbf{x}|y)$, $P(y)$ → 베이즈 정리 → 사후확률 $P(y|\mathbf{x})$ → $\arg\max$ → 분류 결정

---

### 4.2 이미지 분류의 확률적 표현

$K$개의 클래스가 있는 이미지 분류 문제에서, 입력 이미지 $\mathbf{x} \in \mathbb{R}^{H \times W \times C}$에 대해:

$$\hat{y} = \arg\max_{k \in \{1, \ldots, K\}} P(y = k | \mathbf{x})$$

**판별모델 접근 (신경망):** 소프트맥스를 사용하여 $P(y=k|\mathbf{x})$를 직접 모델링한다:

$$P(y = k | \mathbf{x}; \theta) = \frac{\exp(f_k(\mathbf{x}; \theta))}{\displaystyle\sum_{j=1}^{K} \exp(f_j(\mathbf{x}; \theta))}$$

여기서 $f_k(\mathbf{x}; \theta)$는 신경망의 $k$번째 로짓(logit) 출력이다.

**생성모델 접근:** 각 클래스별 이미지 분포 $P(\mathbf{x}|y=k)$를 모델링한 후 베이즈 정리를 적용한다:

$$P(y = k | \mathbf{x}) = \frac{P(\mathbf{x} | y=k) P(y=k)}{\displaystyle\sum_{j=1}^{K} P(\mathbf{x}|y=j) P(y=j)}$$

---

### 4.3 다음 단어 예측의 확률적 표현 (자기회귀 언어모델)

시퀀스 $\mathbf{w} = (w_1, w_2, \ldots, w_T)$의 결합확률을 체인룰(chain rule of probability)로 분해한다:

$$P(w_1, w_2, \ldots, w_T) = \prod_{t=1}^{T} P(w_t | w_1, w_2, \ldots, w_{t-1})$$

즉, 자기회귀 언어모델(autoregressive language model)은 다음 단어의 조건부확률을 순차적으로 모델링한다:

$$P(w_t | w_1, \ldots, w_{t-1}) = P(w_t | w_{<t})$$

**생성모델로서의 해석:**

- 모델링 대상: $P(\mathbf{w}) = P(w_1, \ldots, w_T)$ — 텍스트의 결합분포
- 이는 레이블 없는 비지도 생성모델이다
- 샘플링을 통해 새로운 텍스트를 **생성**할 수 있다
- GPT 계열 모델이 이 구조를 사용한다

**구체적 예시:**

$$P(\text{"오늘 날씨가 좋다"}) = P(\text{오늘}) \cdot P(\text{날씨가}|\text{오늘}) \cdot P(\text{좋다}|\text{오늘 날씨가})$$

---

### 4.4 나이브 베이즈 분류기 유도

**목표:** $d$차원 입력 $\mathbf{x} = (x_1, \ldots, x_d)$에 대해 분류 규칙을 유도한다.

**단계 1.** 베이즈 정리를 적용한다:

$$P(y|\mathbf{x}) \propto P(\mathbf{x}|y) P(y) = P(x_1, x_2, \ldots, x_d | y) P(y)$$

**단계 2.** 조건부 독립 가정(나이브 가정)을 적용한다:

$$P(x_1, x_2, \ldots, x_d | y) = \prod_{i=1}^{d} P(x_i | y)$$

**단계 3.** 결합하면:

$$P(y|\mathbf{x}) \propto P(y) \prod_{i=1}^{d} P(x_i | y)$$

**단계 4.** 분류 규칙:

$$\hat{y} = \arg\max_{y} P(y) \prod_{i=1}^{d} P(x_i | y)$$

**단계 5.** 수치 안정성을 위해 로그를 취한다 (확률의 곱은 매우 작은 수가 되어 언더플로 발생 가능):

$$\hat{y} = \arg\max_{y} \left[ \log P(y) + \sum_{i=1}^{d} \log P(x_i | y) \right]$$

**파라미터 추정 (MLE):** 학습 데이터 $\{(\mathbf{x}^{(n)}, y^{(n)})\}_{n=1}^{N}$로부터:

$$\hat{P}(y = c) = \frac{N_c}{N}, \qquad \hat{P}(x_i = v | y = c) = \frac{N_{c, i, v}}{N_c}$$

여기서 $N_c$는 클래스 $c$의 샘플 수, $N_{c,i,v}$는 클래스 $c$에서 $i$번째 특징이 $v$인 샘플 수이다.

## 5. 증명

### 증명 5.1: 베이즈 최적 분류기 (Bayes Optimal Classifier)

**명제:** 모든 분류기 $h: \mathcal{X} \to \mathcal{Y}$ 중에서, 오분류 확률(misclassification probability)을 최소화하는 분류기는 다음과 같다:

$$h^*(\mathbf{x}) = \arg\max_{y \in \mathcal{Y}} P(y|\mathbf{x})$$

즉, $P(\text{error} | h^*) \leq P(\text{error} | h)$가 모든 분류기 $h$에 대해 성립한다.

**증명 전략:** 임의의 입력 $\mathbf{x}$에 대해, 사후확률이 가장 큰 클래스를 선택하는 것이 해당 점에서의 조건부 오류율을 최소화함을 보인다. 이를 전체 입력 공간에 대해 적분하여 전체 오류율의 최소성을 보인다.

**증명:**

**단계 1.** 분류기 $h$의 전체 오류 확률을 정의한다:

$$P(\text{error} | h) = P(h(\mathbf{x}) \neq y) = \int_{\mathcal{X}} P(h(\mathbf{x}) \neq y | \mathbf{x}) \, P(\mathbf{x}) \, d\mathbf{x}$$

**단계 2.** 주어진 $\mathbf{x}$에서의 조건부 오류 확률을 분석한다. 분류기 $h$가 $\mathbf{x}$에 대해 클래스 $c$를 출력한다면:

$$P(h(\mathbf{x}) \neq y | \mathbf{x}) = 1 - P(y = c | \mathbf{x})$$

**단계 3.** 이 조건부 오류를 최소화하려면, $1 - P(y = c | \mathbf{x})$를 최소화해야 하므로, $P(y = c | \mathbf{x})$를 **최대화**하는 $c$를 선택해야 한다:

$$h^*(\mathbf{x}) = \arg\max_{y \in \mathcal{Y}} P(y | \mathbf{x})$$

이때 조건부 오류 확률은:

$$P(h^*(\mathbf{x}) \neq y | \mathbf{x}) = 1 - \max_{y} P(y|\mathbf{x})$$

**단계 4.** 임의의 다른 분류기 $h$에 대해:

$$P(h(\mathbf{x}) \neq y | \mathbf{x}) = 1 - P(y = h(\mathbf{x}) | \mathbf{x}) \geq 1 - \max_{y} P(y|\mathbf{x}) = P(h^*(\mathbf{x}) \neq y | \mathbf{x})$$

부등호는 $P(y = h(\mathbf{x}) | \mathbf{x}) \leq \max_y P(y|\mathbf{x})$이므로 성립한다.

**단계 5.** 양변을 $P(\mathbf{x})$에 대해 적분하면:

$$P(\text{error} | h) = \int_{\mathcal{X}} P(h(\mathbf{x}) \neq y | \mathbf{x}) \, P(\mathbf{x}) \, d\mathbf{x} \geq \int_{\mathcal{X}} P(h^*(\mathbf{x}) \neq y | \mathbf{x}) \, P(\mathbf{x}) \, d\mathbf{x} = P(\text{error} | h^*)$$

따라서 $h^*$는 모든 분류기 중 오분류 확률을 최소화한다. $\qquad \blacksquare$

> **의의:** 이 증명은 왜 분류 문제에서 $P(y|\mathbf{x})$를 정확히 추정하는 것이 핵심인지를 보여준다. 생성모델이든 판별모델이든, 궁극적으로는 $P(y|\mathbf{x})$의 $\arg\max$를 정확히 구하는 것이 최적 분류의 조건이다.

---

### 증명 5.2: 나이브 베이즈 독립 가정 하에서의 계산 간소화

**명제:** $d$차원 이진(binary) 특징 $\mathbf{x} \in \{0, 1\}^d$와 $K$개 클래스에 대해:
- 독립 가정 **없이** $P(\mathbf{x}|y)$를 추정하려면 $K \cdot (2^d - 1)$개의 독립 파라미터가 필요하다.
- 독립 가정 **하에서** $P(\mathbf{x}|y)$를 추정하려면 $K \cdot d$개의 독립 파라미터면 충분하다.

**증명 전략:** 독립 가정이 없는 경우와 있는 경우의 파라미터 수를 직접 세어 비교한다.

**증명:**

**단계 1 (독립 가정 없는 경우).**

$\mathbf{x} \in \{0,1\}^d$이므로 $|\mathcal{X}| = 2^d$이다. 각 클래스 $y = c$에 대해, $P(\mathbf{x}|y=c)$는 $2^d$개의 가능한 값 위의 확률분포이다.

확률분포의 제약 $\sum_{\mathbf{x}} P(\mathbf{x}|y=c) = 1$이 있으므로, 각 클래스당 자유 파라미터 수는 $2^d - 1$이다.

$K$개 클래스에 대해 총 파라미터 수: $K(2^d - 1)$

**단계 2 (독립 가정이 있는 경우).**

$$P(\mathbf{x}|y=c) = \prod_{i=1}^{d} P(x_i | y=c)$$

각 $P(x_i|y=c)$는 이진 변수에 대한 베르누이 분포이므로, 파라미터 1개 ($p_{i,c} = P(x_i = 1 | y = c)$)로 결정된다.

각 클래스당 파라미터 수: $d$개

$K$개 클래스에 대해 총 파라미터 수: $K \cdot d$

**단계 3 (비교).**

$d$가 조금만 커져도 차이는 극적이다:

| $d$ | 독립 가정 없음: $K(2^d - 1)$ | 독립 가정 있음: $Kd$ |
|-----|------|------|
| 10 | $1{,}023K$ | $10K$ |
| 20 | $1{,}048{,}575K$ | $20K$ |
| 100 | $\approx 10^{30} K$ | $100K$ |

독립 가정에 의해 파라미터 수가 **지수적**에서 **선형적**으로 감소한다. $\qquad \blacksquare$

> **의의:** 나이브 베이즈의 "나이브(naive)"한 가정은 현실에서 거의 성립하지 않지만, 차원의 저주를 극복하기 위한 실용적 절충이다. 놀랍게도 독립 가정이 위배되는 상황에서도 $\arg\max$의 순서는 보존되는 경우가 많아 분류 성능은 양호한 경우가 많다.

## 6. 계산 예제와 단계별 풀이

### Example 19.1: 2클래스 문제에서 생성모델로 분류

**문제:** 질병 진단 문제를 생각하자. $y \in \{\text{양성}(+), \text{음성}(-)\}$이고, 검사 결과 $x \in \{\text{반응}, \text{무반응}\}$이다. 다음이 알려져 있다:

- 사전확률: $P(y = +) = 0.01$, $P(y = -) = 0.99$
- 우도: $P(x = \text{반응} | y = +) = 0.95$, $P(x = \text{반응} | y = -) = 0.05$

검사에서 반응이 나왔을 때, 실제로 양성일 확률은?

**풀이:**

**단계 1.** 베이즈 정리를 적용한다:

$$P(y = + | x = \text{반응}) = \frac{P(x = \text{반응} | y = +) \cdot P(y = +)}{P(x = \text{반응})}$$

**단계 2.** 분모를 전확률의 법칙으로 계산한다:

$$P(x = \text{반응}) = P(x = \text{반응} | y = +) P(y = +) + P(x = \text{반응} | y = -) P(y = -)$$

$$= 0.95 \times 0.01 + 0.05 \times 0.99 = 0.0095 + 0.0495 = 0.059$$

**단계 3.** 사후확률을 계산한다:

$$P(y = + | x = \text{반응}) = \frac{0.95 \times 0.01}{0.059} = \frac{0.0095}{0.059} \approx 0.161$$

**단계 4.** 분류 결정:

$$P(y = + | x = \text{반응}) \approx 0.161 < 0.5 = 1 - 0.161 \approx P(y = - | x = \text{반응})$$

따라서 $\hat{y} = -$ (음성으로 분류).

> **해석:** 검사의 민감도가 95%로 높지만, 사전확률이 $P(y=+) = 0.01$로 매우 낮기 때문에, 반응이 나와도 실제 양성일 확률은 약 16.1%에 불과하다. 이것이 **기저율 무시**(base rate neglect)의 전형적인 예이다.

---

### Example 19.2: 같은 문제를 판별모델로 직접 풀기

**문제:** Example 19.1과 같은 데이터가 있되, 이번에는 학습 데이터 10,000건이 직접 주어졌다고 하자.

| | $x = \text{반응}$ | $x = \text{무반응}$ | 합계 |
|---|---|---|---|
| $y = +$ | 95 | 5 | 100 |
| $y = -$ | 495 | 9,405 | 9,900 |
| 합계 | 590 | 9,410 | 10,000 |

판별모델 접근으로 분류하라.

**풀이:**

**단계 1.** 판별모델은 $P(y|x)$를 데이터로부터 **직접** 추정한다.

$$\hat{P}(y = + | x = \text{반응}) = \frac{95}{590} \approx 0.161$$

$$\hat{P}(y = - | x = \text{반응}) = \frac{495}{590} \approx 0.839$$

**단계 2.** 분류 결정:

$$\hat{y} = \arg\max_{y} \hat{P}(y | x = \text{반응}) = - \quad (\text{음성})$$

> **비교:** 결과는 Example 19.1과 동일하지만, 판별모델은 베이즈 정리를 거치지 않고 조건부확률을 **직접** 추정했다. $P(\mathbf{x})$나 $P(\mathbf{x}|y)$를 따로 모델링할 필요가 없다.

---

### Example 19.3: 나이브 베이즈 분류 예제 (스팸 필터)

**문제:** 이메일을 스팸($y = S$) 또는 정상($y = H$, ham)으로 분류한다. 학습 데이터로부터 다음을 추정했다:

- $P(y = S) = 0.4$, $P(y = H) = 0.6$
- 단어별 조건부확률:

| 단어 ($x_i$) | $P(x_i = 1 \mid y = S)$ | $P(x_i = 1 \mid y = H)$ |
|---|---|---|
| "무료" ($x_1$) | 0.8 | 0.1 |
| "회의" ($x_2$) | 0.1 | 0.7 |
| "할인" ($x_3$) | 0.7 | 0.05 |

새 이메일에 "무료"와 "할인"이 포함되고 "회의"는 없다: $\mathbf{x} = (1, 0, 1)$. 이 이메일은 스팸인가?

**풀이:**

**단계 1.** 각 클래스에 대해 $P(y) \prod_i P(x_i | y)$를 계산한다.

**스팸:**

$$P(y=S) \prod_{i=1}^{3} P(x_i | y=S) = 0.4 \times P(x_1 = 1|S) \times P(x_2 = 0|S) \times P(x_3 = 1|S)$$

$$= 0.4 \times 0.8 \times (1 - 0.1) \times 0.7 = 0.4 \times 0.8 \times 0.9 \times 0.7$$

$$= 0.4 \times 0.504 = 0.2016$$

**정상:**

$$P(y=H) \prod_{i=1}^{3} P(x_i | y=H) = 0.6 \times P(x_1 = 1|H) \times P(x_2 = 0|H) \times P(x_3 = 1|H)$$

$$= 0.6 \times 0.1 \times (1 - 0.7) \times 0.05 = 0.6 \times 0.1 \times 0.3 \times 0.05$$

$$= 0.6 \times 0.0015 = 0.0009$$

**단계 2.** 정규화하여 사후확률을 구한다:

$$P(y=S|\mathbf{x}) = \frac{0.2016}{0.2016 + 0.0009} = \frac{0.2016}{0.2025} \approx 0.9956$$

$$P(y=H|\mathbf{x}) = \frac{0.0009}{0.2025} \approx 0.0044$$

**단계 3.** 분류 결정:

$$\hat{y} = S \quad (\text{스팸})$$

> **해석:** "무료"와 "할인"이 포함되고 "회의"가 없는 이메일은 99.6%의 확률로 스팸으로 분류된다. 나이브 베이즈는 각 단어를 독립적으로 처리하므로 계산이 매우 간단하다.

### Example 19.4: 언어모델에서 다음 단어 확률

**문제:** 어휘(vocabulary)가 $V = \{\text{나는}, \text{밥을}, \text{먹는다}, \text{공부를}, \text{한다}\}$이고, 간단한 바이그램(bigram) 언어모델의 조건부확률이 다음과 같다:

| $w_{t-1}$ | $P(\text{밥을} \mid w_{t-1})$ | $P(\text{공부를} \mid w_{t-1})$ |
|---|---|---|
| 나는 | 0.4 | 0.5 |

$P(\text{먹는다} \mid \text{밥을}) = 0.7$, $P(\text{한다} \mid \text{공부를}) = 0.6$이라 하자.

"나는 밥을 먹는다"와 "나는 공부를 한다"의 확률을 비교하라. ($P(\text{나는}) = 0.3$)

**풀이:**

**단계 1.** 자기회귀 분해를 적용한다.

$$P(\text{나는 밥을 먹는다}) = P(\text{나는}) \cdot P(\text{밥을}|\text{나는}) \cdot P(\text{먹는다}|\text{밥을})$$

$$= 0.3 \times 0.4 \times 0.7 = 0.084$$

**단계 2.**

$$P(\text{나는 공부를 한다}) = P(\text{나는}) \cdot P(\text{공부를}|\text{나는}) \cdot P(\text{한다}|\text{공부를})$$

$$= 0.3 \times 0.5 \times 0.6 = 0.090$$

**단계 3.** 비교:

$$P(\text{나는 공부를 한다}) = 0.090 > 0.084 = P(\text{나는 밥을 먹는다})$$

> **해석:** 이 언어모델에 따르면 "나는 공부를 한다"가 약간 더 높은 확률을 가진다. 생성 시 $\arg\max$ 디코딩을 사용하면 "나는 공부를 한다"가 선택된다. 이처럼 언어모델은 시퀀스의 결합확률을 조건부확률의 곱으로 모델링하는 **생성모델**이다.

## 7. 자주 나오는 함정과 반례

### 함정 1: "생성모델은 항상 판별모델보다 분류 성능이 낮다"

**왜 틀린가:** 이것은 일반적 경향이지 보편적 법칙이 아니다. 데이터가 적을 때, 생성모델의 강한 귀납적 편향(inductive bias)이 오히려 더 나은 일반화를 제공할 수 있다. 또한 생성모델의 가정이 실제 데이터 분포와 잘 맞으면 판별모델보다 우수할 수 있다.

**구체적 반례:** 100개의 학습 샘플로 10,000차원의 텍스트 분류를 할 때, 나이브 베이즈가 로지스틱 회귀보다 나은 성능을 보이는 경우가 흔하다.

---

### 함정 2: "나이브 베이즈의 조건부 독립 가정이 틀리면 분류기도 틀린다"

**왜 틀린가:** 나이브 베이즈가 추정하는 $P(y|\mathbf{x})$의 **절대값**은 부정확할 수 있지만, 클래스 간 **순서(ranking)**가 보존되면 $\arg\max$에 의한 분류 결정은 여전히 정확하다.

**구체적 예시:** $P(y=A|\mathbf{x})$의 참값이 0.7이고 나이브 베이즈 추정이 0.95일 때, 추정치의 절대값은 부정확하지만 "클래스 $A$가 가장 가능성이 높다"는 판단은 정확하다. 분류에서는 절대적 확률값보다 **상대적 순서**가 중요하다.

---

### 함정 3: "판별모델은 데이터를 생성할 수 없으므로 쓸모가 제한적이다"

**왜 틀린가:** 판별모델은 분류, 회귀, 구조 예측 등 지도학습 과제에서 핵심적인 역할을 하며, 실무에서 가장 많이 사용되는 모델 유형이다. 데이터 생성이 필요하지 않은 과제가 대부분이다.

**추가 참고:** 최근에는 경계가 모호해지고 있다. 조건부 생성모델 $P(\mathbf{x}|y)$와 판별모델 $P(y|\mathbf{x})$를 결합하는 하이브리드 접근법도 활발히 연구되고 있다.

---

### 함정 4: "GPT는 판별모델이다 (왜냐하면 다음 토큰을 '예측'하니까)"

**왜 틀린가:** GPT는 $P(w_t | w_{<t})$를 모델링하여 시퀀스의 결합분포 $P(w_1, \ldots, w_T)$를 학습하는 **자기회귀 생성모델**이다. "예측"이라는 단어 때문에 혼동하기 쉽지만, 다음 토큰의 조건부확률을 모델링하는 것은 체인룰에 의해 결합분포를 분해한 것이다. 샘플링을 통해 새로운 텍스트를 생성할 수 있다는 것이 이를 뒷받침한다.

---

### 함정 5: "베이즈 정리의 분모 $P(\mathbf{x})$는 항상 계산해야 한다"

**왜 틀린가:** 분류 목적에서 $\hat{y} = \arg\max_y P(y|\mathbf{x})$를 구할 때, 분모 $P(\mathbf{x})$는 $y$에 무관한 상수이므로 생략 가능하다. 그러나 $P(y|\mathbf{x})$의 **정확한 수치**가 필요한 경우(예: 보정된 확률 추정, 불확실성 정량화)에는 $P(\mathbf{x})$의 계산이 필요하다. "분류에서는 분모가 필요 없다"와 "분모를 절대 계산하지 않아도 된다"는 다른 말이다.

## 8. 시험형 서술 문제와 모범답안

### 문제 1: 생성모델과 판별모델의 차이를 확률식으로 설명하라

**모범답안:**

생성모델과 판별모델은 지도학습에서 입력 $\mathbf{x}$와 레이블 $y$ 사이의 관계를 모델링하는 두 가지 근본적으로 다른 접근법이다.

**생성모델(Generative Model)**은 데이터의 결합확률분포 $P(\mathbf{x}, y)$를 모델링한다. 이를 보통 다음과 같이 분해한다:

$$P(\mathbf{x}, y) = P(\mathbf{x}|y) \cdot P(y)$$

여기서 $P(\mathbf{x}|y)$는 클래스-조건부 우도(class-conditional likelihood)이고, $P(y)$는 사전확률(prior)이다. 생성모델은 "데이터가 어떻게 생성되는지"의 과정을 모델링한다. 대표적 예시로 나이브 베이즈, 가우시안 혼합 모델, VAE가 있다.

**판별모델(Discriminative Model)**은 조건부확률 $P(y|\mathbf{x})$를 직접 모델링한다:

$$\text{직접 학습: } P(y|\mathbf{x})$$

$P(\mathbf{x})$나 $P(\mathbf{x}|y)$를 모델링하지 않는다. 대표적 예시로 로지스틱 회귀, 신경망, SVM이 있다.

두 접근법의 관계는 다음과 같다:

$$P(\mathbf{x}, y) = P(y|\mathbf{x}) \cdot P(\mathbf{x})$$

결합분포를 알면 조건부확률을 유도할 수 있지만, 그 역은 성립하지 않는다 ($P(\mathbf{x})$를 모르므로). 따라서 생성모델이 더 많은 정보를 학습하지만, 동시에 더 어려운 문제를 풀어야 한다. 분류 성능만 놓고 보면 판별모델이 일반적으로 우수하지만, 생성모델은 데이터 생성, 이상 탐지, 결측치 처리 등 추가적인 능력을 제공한다.

### 문제 2: 베이즈 정리를 이용해 분류 규칙을 유도하라

**모범답안:**

$K$개의 클래스 $y \in \{1, 2, \ldots, K\}$에 대한 분류 문제를 생각하자. 생성모델이 $P(\mathbf{x}|y)$와 $P(y)$를 학습했다고 가정한다.

**[1단계: 베이즈 정리 적용]**

$$P(y = k | \mathbf{x}) = \frac{P(\mathbf{x} | y = k) \cdot P(y = k)}{P(\mathbf{x})}$$

**[2단계: 분모 전개 (전확률의 법칙)]**

$$P(\mathbf{x}) = \sum_{j=1}^{K} P(\mathbf{x} | y = j) \cdot P(y = j)$$

따라서:

$$P(y = k | \mathbf{x}) = \frac{P(\mathbf{x} | y = k) \cdot P(y = k)}{\displaystyle\sum_{j=1}^{K} P(\mathbf{x} | y = j) \cdot P(y = j)}$$

**[3단계: 분류 규칙 구성]**

최적 분류기는 사후확률을 최대화하는 클래스를 선택한다 (Theorem 19.1에 의해 이것이 오분류 확률을 최소화함):

$$\hat{y} = \arg\max_{k \in \{1, \ldots, K\}} P(y = k | \mathbf{x})$$

**[4단계: 분모 생략]**

분모 $P(\mathbf{x})$는 $k$에 무관하므로:

$$\hat{y} = \arg\max_{k} P(\mathbf{x} | y = k) \cdot P(y = k)$$

**[5단계: 로그 변환]**

로그는 단조증가 함수이므로 $\arg\max$가 보존된다:

$$\hat{y} = \arg\max_{k} \left[ \log P(\mathbf{x} | y = k) + \log P(y = k) \right]$$

이 규칙은 우도(likelihood)와 사전확률(prior)의 균형을 반영한다. 우도가 아무리 높아도 사전확률이 극히 낮으면 해당 클래스가 선택되지 않을 수 있다 (Example 19.1의 질병 진단 참조).

### 문제 3: 나이브 베이즈의 조건부 독립 가정을 수식으로 기술하고, 이 가정의 실용적 효과를 설명하라

**모범답안:**

**[조건부 독립 가정]**

$d$차원 입력 $\mathbf{x} = (x_1, x_2, \ldots, x_d)$에 대해, 나이브 베이즈는 다음을 가정한다:

$$P(x_1, x_2, \ldots, x_d | y) = \prod_{i=1}^{d} P(x_i | y)$$

즉, 클래스 $y$가 주어졌을 때 각 특징 $x_i$는 서로 **조건부 독립**(conditionally independent)이다.

**[실용적 효과 1: 파라미터 수의 극적 감소]**

이진 특징 $x_i \in \{0, 1\}$과 $K$개 클래스를 가정하면:

- 독립 가정 없이: $K(2^d - 1)$개 파라미터 (지수적)
- 독립 가정 하에서: $Kd$개 파라미터 (선형적)

예컨대 $d = 1000$ (1000개 단어 특징)이면, 독립 가정 없이는 $2^{1000}$에 비례하는 파라미터가 필요하지만, 독립 가정 하에서는 $1000K$개면 충분하다.

**[실용적 효과 2: 학습 데이터 효율성]**

파라미터 수가 적으므로, 적은 데이터로도 안정적인 추정이 가능하다. 각 $P(x_i|y)$를 독립적으로 추정하므로, 한 특징의 데이터 부족이 다른 특징의 추정에 영향을 미치지 않는다.

**[실용적 효과 3: 분류 규칙의 단순화]**

$$\hat{y} = \arg\max_y \left[ \log P(y) + \sum_{i=1}^d \log P(x_i|y) \right]$$

이 규칙은 각 특징의 로그-우도 기여를 단순히 **합산**하는 형태이므로, 계산이 $O(dK)$로 매우 빠르다.

**[한계]**

현실에서 특징들은 대부분 상관관계를 가진다 (예: "무료 배송"에서 "무료"와 "배송"은 독립이 아님). 그러나 분류에서 중요한 것은 확률의 절대값이 아니라 클래스 간 **순서**이므로, 독립 가정이 위배되더라도 분류 성능은 양호한 경우가 많다.

### 문제 4: 생성모델이 판별모델보다 유리한 상황과 불리한 상황을 각각 설명하고, 그 이유를 확률론적으로 분석하라

**모범답안:**

**[생성모델이 유리한 상황]**

**(1) 학습 데이터가 부족한 경우:**

생성모델은 $P(\mathbf{x}|y)$에 대한 구조적 가정(예: 가우시안 분포, 독립 가정)을 도입하여 파라미터 수를 줄인다. 이는 강한 귀납적 편향(inductive bias)을 제공하여 적은 데이터로도 합리적인 추정이 가능하다.

확률론적 분석: $P(\mathbf{x}|y)$를 가우시안으로 모델링하면 파라미터는 $\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k$로 한정되어, 자유도가 $O(d^2 K)$이다. 반면 판별모델이 $P(y|\mathbf{x})$를 임의의 함수로 학습하면 자유도가 훨씬 클 수 있다.

**(2) 결측값 처리, 이상 탐지, 데이터 생성이 필요한 경우:**

$P(\mathbf{x})$를 알고 있으므로, $P(\mathbf{x})$가 낮은 입력을 이상치로 탐지할 수 있다. 결측된 특징은 주변화로 처리할 수 있다:

$$P(y | x_1, x_3) = \frac{\sum_{x_2} P(x_1, x_2, x_3 | y) P(y)}{P(x_1, x_3)}$$

판별모델은 $P(\mathbf{x})$를 모델링하지 않으므로 이러한 작업이 원칙적으로 불가능하다.

**[판별모델이 유리한 상황]**

**(1) 충분한 학습 데이터가 있는 경우:**

판별모델은 불필요한 $P(\mathbf{x})$를 모델링하지 않고, 분류에 직접 필요한 $P(y|\mathbf{x})$에 모든 모델 용량을 집중한다. 결합분포를 분해하면:

$$P(\mathbf{x}, y) = P(y|\mathbf{x}) \cdot P(\mathbf{x})$$

$P(\mathbf{x})$는 고차원 데이터의 복잡한 분포이며, 분류에는 기여하지 않는다. 생성모델이 이 불필요한 항까지 정확히 모델링하려는 노력은 분류 성능 향상에 직접적으로 기여하지 않을 수 있다.

**(2) 모델 가정이 실제 데이터에 맞지 않는 경우:**

생성모델의 성능은 $P(\mathbf{x}|y)$에 대한 가정의 정확성에 크게 의존한다. 가정이 틀리면 (예: 데이터가 가우시안이 아닌데 가우시안으로 모델링) 편향(bias)이 발생한다. 판별모델은 이러한 분포 가정이 불필요하므로 더 유연하다.

### 문제 5: 다음 명제의 참/거짓을 판정하고, 수식을 이용하여 근거를 제시하라. "결합확률 $P(\mathbf{x}, y)$를 정확히 알면, 최적 분류기를 구성할 수 있다."

**모범답안:**

**참(True).**

**[근거]**

**단계 1.** $P(\mathbf{x}, y)$를 알면, 조건부확률을 정확히 계산할 수 있다:

$$P(y|\mathbf{x}) = \frac{P(\mathbf{x}, y)}{P(\mathbf{x})} = \frac{P(\mathbf{x}, y)}{\displaystyle\sum_{y'} P(\mathbf{x}, y')}$$

분모 $P(\mathbf{x})$도 결합확률로부터 주변화하여 구할 수 있으므로, $P(y|\mathbf{x})$를 정확히 계산할 수 있다.

**단계 2.** 증명 5.1 (Bayes Optimal Classifier)에 의해, $P(y|\mathbf{x})$의 $\arg\max$를 취하는 분류기는 모든 분류기 중 오분류 확률을 최소화한다:

$$h^*(\mathbf{x}) = \arg\max_y P(y|\mathbf{x})$$

**단계 3.** 따라서 $P(\mathbf{x}, y) \implies P(y|\mathbf{x}) \implies h^*$로의 유도가 가능하며, 이 $h^*$는 최적 분류기이다.

**[역(逆)은 성립하지 않음에 주의]**

최적 분류기 $h^*$를 알아도 $P(\mathbf{x}, y)$를 복원할 수 없다. $h^*(\mathbf{x})$는 각 $\mathbf{x}$에 대해 하나의 클래스 레이블만 출력하므로, 확률 분포에 대한 정보를 제공하지 않는다. 심지어 $P(y|\mathbf{x})$를 안다 하더라도, $P(\mathbf{x})$를 모르면 $P(\mathbf{x}, y) = P(y|\mathbf{x}) P(\mathbf{x})$를 복원할 수 없다.

이는 생성모델이 판별모델보다 정보적으로 더 풍부하다는 Theorem 19.2의 직접적 예시이다.

### 문제 6: 자기회귀 언어모델 $P(w_t | w_{<t})$이 생성모델인 이유를 확률의 체인룰을 이용하여 설명하라

**모범답안:**

**[주장]** 자기회귀 언어모델 $P_\theta(w_t | w_1, \ldots, w_{t-1})$은 시퀀스의 결합분포 $P(w_1, w_2, \ldots, w_T)$를 모델링하는 생성모델이다.

**[유도]**

확률의 체인룰(chain rule of probability)에 의해, 임의의 확률변수 $w_1, \ldots, w_T$의 결합분포는 다음과 같이 분해된다:

$$P(w_1, w_2, \ldots, w_T) = P(w_1) \cdot P(w_2|w_1) \cdot P(w_3|w_1, w_2) \cdots P(w_T|w_1, \ldots, w_{T-1})$$

$$= \prod_{t=1}^{T} P(w_t | w_1, \ldots, w_{t-1}) = \prod_{t=1}^{T} P(w_t | w_{<t})$$

이 분해는 어떠한 가정도 필요 없이 **항상** 성립한다 (확률의 곱 정리의 반복 적용).

**[생성모델로서의 해석]**

- 모델링 대상: $P_\theta(w_1, \ldots, w_T) = \prod_{t=1}^T P_\theta(w_t | w_{<t})$ — 이것은 텍스트 시퀀스의 **결합확률분포**이다.
- 생성 과정: $w_1 \sim P_\theta(w_1)$을 샘플링하고, $w_2 \sim P_\theta(w_2|w_1)$을 샘플링하고, 이를 반복하여 완전한 시퀀스를 생성할 수 있다.
- Definition 19.4에 따라, 데이터의 결합분포를 모델링하고 새로운 데이터를 생성할 수 있으므로, 이것은 생성모델이다.

**[판별모델과의 구분]**

만약 이 모델이 주어진 문장에 대해 감성(긍정/부정)을 분류하는 $P(y|\mathbf{w})$를 직접 모델링했다면 판별모델이 될 것이다. 그러나 언어모델은 레이블 $y$ 없이 텍스트 자체의 분포 $P(\mathbf{w})$를 모델링하므로, 비지도 생성모델에 해당한다.

**[참고]** GPT를 감성 분류에 사용할 때는 (fine-tuning 또는 프롬프트를 통해) 생성모델 위에 판별적 태스크를 수행하는 것이다. 모델의 기저 구조 자체는 여전히 생성적이다.

### 문제 7: 아래 표를 이용하여 나이브 베이즈 분류기의 예측을 수행하고, 로그 공간에서의 계산 과정을 보여라

| | $P(x_i = 1 \mid y = A)$ | $P(x_i = 1 \mid y = B)$ |
|---|---|---|
| $x_1$ | 0.9 | 0.3 |
| $x_2$ | 0.2 | 0.8 |
| $x_3$ | 0.7 | 0.4 |

$P(y = A) = 0.6$, $P(y = B) = 0.4$. 입력: $\mathbf{x} = (1, 0, 1)$.

**모범답안:**

**[로그 공간 계산]**

나이브 베이즈 분류 규칙:

$$\hat{y} = \arg\max_y \left[ \log P(y) + \sum_{i=1}^{3} \log P(x_i | y) \right]$$

**클래스 A에 대해:**

$$\log P(y=A) + \log P(x_1=1|A) + \log P(x_2=0|A) + \log P(x_3=1|A)$$

$$= \log 0.6 + \log 0.9 + \log(1 - 0.2) + \log 0.7$$

$$= \log 0.6 + \log 0.9 + \log 0.8 + \log 0.7$$

$$\approx -0.5108 + (-0.1054) + (-0.2231) + (-0.3567) = -1.1960$$

**클래스 B에 대해:**

$$\log P(y=B) + \log P(x_1=1|B) + \log P(x_2=0|B) + \log P(x_3=1|B)$$

$$= \log 0.4 + \log 0.3 + \log(1 - 0.8) + \log 0.4$$

$$= \log 0.4 + \log 0.3 + \log 0.2 + \log 0.4$$

$$\approx -0.9163 + (-1.2040) + (-1.6094) + (-0.9163) = -4.6460$$

**비교:**

$$-1.1960 > -4.6460$$

따라서 $\hat{y} = A$.

**[사후확률 계산 (검증)]**

비정규화 점수를 지수로 되돌린다:

$$\text{score}(A) = e^{-1.1960} \approx 0.3024, \qquad \text{score}(B) = e^{-4.6460} \approx 0.0096$$

정규화:

$$P(y=A|\mathbf{x}) = \frac{0.3024}{0.3024 + 0.0096} = \frac{0.3024}{0.3120} \approx 0.969$$

클래스 A로 분류되며, 사후확률은 약 96.9%이다.
