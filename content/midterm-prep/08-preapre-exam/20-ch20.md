# Ch.20 딥러닝 응용 연결

---

## 1. 학습 목표

이 장을 마친 후 다음을 할 수 있어야 한다:

- 소프트맥스 함수(Softmax)의 정의를 정확히 진술하고, 출력이 확률분포를 이루는 이유를 **증명**할 수 있다
- 어텐션 메커니즘(Attention Mechanism)의 수식을 쓰고, $Q, K, V$ 행렬의 선형대수적 의미를 설명할 수 있다
- Scaled Dot-Product Attention에서 $\sqrt{d_k}$로 나누는 이유를 분산 분석을 통해 수학적으로 정당화할 수 있다
- 크로스 엔트로피 손실(Cross-Entropy Loss)의 정의를 쓰고, KL 발산(KL Divergence)과의 관계를 유도할 수 있다
- 로지스틱 회귀(Logistic Regression)가 선형 모델 + 시그모이드 + 크로스 엔트로피로 구성됨을 설명할 수 있다
- 소프트맥스와 크로스 엔트로피를 합성한 그레이디언트가 $\hat{\mathbf{y}} - \mathbf{y}$임을 유도할 수 있다
- 소프트맥스의 수치 안정성(numerical stability) 문제와 해결 방법을 설명할 수 있다
- temperature scaling이 소프트맥스 출력 분포에 미치는 영향을 분석할 수 있다
- 위의 모든 개념이 딥러닝의 분류, 시퀀스 모델링, Transformer 아키텍처에서 어떻게 연결되는지 서술할 수 있다

## 2. 필수 정의

### Definition 20.1 (소프트맥스 함수, Softmax Function)

$K$차원 벡터 $\mathbf{z} = (z_1, z_2, \ldots, z_K)^T \in \mathbb{R}^K$에 대해, **소프트맥스 함수**(softmax function) $\sigma: \mathbb{R}^K \to \mathbb{R}^K$는 다음과 같이 정의된다:

$$\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{k=1}^{K} e^{z_k}}, \quad i = 1, 2, \ldots, K$$

> **해석:** 소프트맥스는 임의의 실수 벡터(로짓, logit)를 **확률분포**로 변환한다. 각 출력 $\sigma(\mathbf{z})_i$는 $i$번째 클래스에 속할 확률로 해석된다. 지수 함수 $e^{z_i}$는 모든 값을 양수로 만들고, 분모의 합으로 나누어 총합이 1이 되도록 **정규화**(normalization)한다.

**예시:**

$\mathbf{z} = (2, 1, 0)^T$에 대해:

$$e^2 = 7.389, \quad e^1 = 2.718, \quad e^0 = 1.000$$

$$\sum_{k=1}^{3} e^{z_k} = 7.389 + 2.718 + 1.000 = 11.107$$

$$\sigma(\mathbf{z}) = \left(\frac{7.389}{11.107},\; \frac{2.718}{11.107},\; \frac{1.000}{11.107}\right) \approx (0.665,\; 0.245,\; 0.090)$$

확인: $0.665 + 0.245 + 0.090 = 1.000$ ✓, 각 성분 > 0 ✓

**비예시:**

단순히 양수로 만들고 합으로 나누는 $f(\mathbf{z})_i = \frac{|z_i|}{\sum_k |z_k|}$는 소프트맥스가 **아니다**. $z_i = 0$인 경우 해당 성분이 0이 되어 확률 해석에 문제가 생기며, 입력의 순서 관계가 부호 변환 시 뒤집힐 수 있다.

### Definition 20.2 (어텐션 메커니즘, Attention Mechanism)

쿼리(query) 행렬 $Q \in \mathbb{R}^{n \times d_k}$, 키(key) 행렬 $K \in \mathbb{R}^{m \times d_k}$, 밸류(value) 행렬 $V \in \mathbb{R}^{m \times d_v}$에 대해, **Scaled Dot-Product Attention**은 다음과 같이 정의된다:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

여기서:
- $QK^T \in \mathbb{R}^{n \times m}$: 쿼리와 키 사이의 **내적 유사도 행렬**(dot-product similarity matrix)
- $\sqrt{d_k}$: **스케일링 인자**(scaling factor), 내적 값의 분산을 조절
- $\text{softmax}$: 행 단위(row-wise)로 적용하여 각 쿼리에 대한 **가중치 분포** 생성
- 최종 출력: 가중치 분포에 따른 밸류의 **가중 합**(weighted sum)

> **해석:** Attention은 "어디에 집중할 것인가"를 수학적으로 모델링한다. 쿼리 $\mathbf{q}$와 각 키 $\mathbf{k}_j$의 내적이 클수록 해당 밸류 $\mathbf{v}_j$에 더 큰 가중치를 부여한다. 이는 데이터베이스의 검색과 유사하다: 쿼리에 가장 관련 있는 키를 찾아 그에 대응하는 값을 가져온다.

**예시:**

$Q = \begin{pmatrix} 1 & 0 \end{pmatrix}$, $K = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}$, $V = \begin{pmatrix} 5 \\ 3 \end{pmatrix}$, $d_k = 2$일 때:

$$QK^T = \begin{pmatrix} 1 & 0 \end{pmatrix}\begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 0 \end{pmatrix}$$

$$\frac{QK^T}{\sqrt{2}} = \begin{pmatrix} 0.707 & 0 \end{pmatrix}$$

$$\text{softmax}\left(\begin{pmatrix} 0.707 & 0 \end{pmatrix}\right) = \begin{pmatrix} 0.670 & 0.330 \end{pmatrix}$$

$$\text{Attention} = 0.670 \times 5 + 0.330 \times 3 = 4.340$$

쿼리 $(1, 0)$이 첫 번째 키 $(1, 0)$과 더 유사하므로, 첫 번째 밸류 $5$에 더 높은 가중치가 부여되었다.

### Definition 20.3 (크로스 엔트로피 손실, Cross-Entropy Loss)

진짜 분포(true distribution) $\mathbf{y} = (y_1, \ldots, y_K)$와 예측 분포(predicted distribution) $\hat{\mathbf{y}} = (\hat{y}_1, \ldots, \hat{y}_K)$에 대해, **크로스 엔트로피 손실**(cross-entropy loss)은 다음과 같이 정의된다:

$$L = -\sum_{i=1}^{K} y_i \log \hat{y}_i$$

분류 문제에서 $\mathbf{y}$가 원-핫 벡터(one-hot vector)이고 정답 클래스가 $c$이면:

$$L = -\log \hat{y}_c$$

> **해석:** 크로스 엔트로피는 "예측 분포가 진짜 분포와 얼마나 다른가"를 측정하는 **정보 이론적 거리**이다. 정답 클래스의 예측 확률이 1에 가까우면 손실이 0에 가까워지고, 0에 가까우면 손실이 $+\infty$로 발산한다. 이 성질이 분류 모델의 학습을 효과적으로 유도한다.

**예시:**

3-class 분류에서 정답이 클래스 1이면 $\mathbf{y} = (1, 0, 0)$이고, 예측이 $\hat{\mathbf{y}} = (0.7, 0.2, 0.1)$이면:

$$L = -(1 \cdot \log 0.7 + 0 \cdot \log 0.2 + 0 \cdot \log 0.1) = -\log 0.7 \approx 0.357$$

만약 예측이 $\hat{\mathbf{y}} = (0.1, 0.8, 0.1)$이면:

$$L = -\log 0.1 \approx 2.303$$

정답 클래스에 낮은 확률을 배정할수록 손실이 급격히 증가한다.

### Definition 20.4 (로지스틱 회귀, Logistic Regression)

입력 $\mathbf{x} \in \mathbb{R}^d$에 대해, **로지스틱 회귀**(logistic regression)는 다음 3단계로 구성된다:

**1단계 - 선형 변환:**

$$z = \mathbf{w}^T\mathbf{x} + b, \quad \mathbf{w} \in \mathbb{R}^d,\; b \in \mathbb{R}$$

**2단계 - 시그모이드 함수 적용:**

$$\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}$$

**3단계 - 이진 크로스 엔트로피 손실:**

$$L = -[y \log \hat{y} + (1 - y)\log(1 - \hat{y})]$$

> **해석:** 로지스틱 회귀는 가장 기본적인 신경망이다. 입력에 선형 변환을 적용하여 로짓(logit) $z$를 만들고, 시그모이드로 확률 $\hat{y} \in (0, 1)$로 변환한 뒤, 크로스 엔트로피로 손실을 계산한다. 이는 단일 뉴런(neuron)과 정확히 동일한 구조이며, 딥러닝의 모든 분류 문제가 이 패턴의 일반화이다.

**예시:**

$\mathbf{w} = (0.5, -0.3)^T$, $b = 0.1$, $\mathbf{x} = (2, 1)^T$, $y = 1$일 때:

$$z = 0.5 \times 2 + (-0.3) \times 1 + 0.1 = 1.0 - 0.3 + 0.1 = 0.8$$

$$\hat{y} = \frac{1}{1 + e^{-0.8}} = \frac{1}{1 + 0.449} = 0.690$$

$$L = -[1 \cdot \log 0.690 + 0 \cdot \log 0.310] = -\log 0.690 \approx 0.371$$

**시그모이드와 소프트맥스의 관계:** 2-class 소프트맥스는 시그모이드와 동치이다. $K = 2$이고 $\mathbf{z} = (z_1, z_2)$일 때:

$$\sigma(\mathbf{z})_1 = \frac{e^{z_1}}{e^{z_1} + e^{z_2}} = \frac{1}{1 + e^{-(z_1 - z_2)}} = \text{sigmoid}(z_1 - z_2)$$

## 3. 핵심 정리와 명제

### Theorem 20.1 (소프트맥스의 확률분포 성질)

임의의 $\mathbf{z} \in \mathbb{R}^K$에 대해, 소프트맥스 출력 $\sigma(\mathbf{z})$는 **확률분포**를 이룬다. 즉:

**(a)** 양수성: $\sigma(\mathbf{z})_i > 0, \quad \forall\, i = 1, \ldots, K$

**(b)** 정규성: $\displaystyle\sum_{i=1}^{K} \sigma(\mathbf{z})_i = 1$

> **왜 중요한가:** 신경망의 최종 출력이 유효한 확률분포여야 분류 확률로 해석할 수 있고, 크로스 엔트로피 손실의 $\log$ 인수가 양수임이 보장되어 손실 함수가 잘 정의된다.

> **어디에 쓰이는가:** 분류 신경망의 출력층, Attention의 가중치 계산, 강화학습의 정책(policy) 출력, 생성 모델의 다음 토큰 확률 분포.

---

### Theorem 20.2 (Attention에서의 내적의 역할)

쿼리 벡터 $\mathbf{q} \in \mathbb{R}^{d_k}$와 키 벡터 $\mathbf{k} \in \mathbb{R}^{d_k}$의 내적 $\mathbf{q}^T\mathbf{k}$는 두 벡터의 **유사도**(similarity)를 측정한다:

$$\mathbf{q}^T\mathbf{k} = \|\mathbf{q}\|\|\mathbf{k}\|\cos\theta$$

여기서 $\theta$는 두 벡터 사이의 각도이다. 따라서:

- $\mathbf{q}$와 $\mathbf{k}$가 같은 방향 → 내적이 크다 → 높은 attention 가중치
- $\mathbf{q}$와 $\mathbf{k}$가 직교 → 내적이 0 → 낮은 attention 가중치
- $\mathbf{q}$와 $\mathbf{k}$가 반대 방향 → 내적이 음수 → 매우 낮은 attention 가중치

> **왜 중요한가:** 내적을 유사도로 사용하면 $O(d_k)$ 시간에 계산이 가능하고, 행렬곱 $QK^T$로 모든 쿼리-키 쌍의 유사도를 $O(nmd_k)$에 **병렬 계산**할 수 있다.

> **어디에 쓰이는가:** Transformer의 Self-Attention, Cross-Attention, Multi-Head Attention. GPT, BERT 등 모든 현대적 언어 모델의 핵심 연산.

---

### Theorem 20.3 (크로스 엔트로피와 KL 발산의 관계)

진짜 분포 $\mathbf{y}$와 예측 분포 $\hat{\mathbf{y}}$에 대해:

$$H(\mathbf{y}, \hat{\mathbf{y}}) = H(\mathbf{y}) + D_{KL}(\mathbf{y} \| \hat{\mathbf{y}})$$

여기서:
- $H(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_i y_i \log \hat{y}_i$ : 크로스 엔트로피
- $H(\mathbf{y}) = -\sum_i y_i \log y_i$ : 진짜 분포의 엔트로피
- $D_{KL}(\mathbf{y} \| \hat{\mathbf{y}}) = \sum_i y_i \log \frac{y_i}{\hat{y}_i}$ : KL 발산

학습 시 $\mathbf{y}$는 고정이므로 $H(\mathbf{y})$는 상수이다. 따라서:

$$\arg\min_{\hat{\mathbf{y}}} H(\mathbf{y}, \hat{\mathbf{y}}) = \arg\min_{\hat{\mathbf{y}}} D_{KL}(\mathbf{y} \| \hat{\mathbf{y}})$$

> **왜 중요한가:** 크로스 엔트로피를 최소화하는 것이 KL 발산을 최소화하는 것과 **동치**임을 알 수 있다. 즉, 예측 분포를 진짜 분포에 최대한 가깝게 만드는 것이다. $D_{KL} \geq 0$이고, $D_{KL} = 0 \iff \hat{\mathbf{y}} = \mathbf{y}$이므로 학습의 방향이 명확하다.

> **어디에 쓰이는가:** 분류 문제의 손실 함수, 변분 추론(variational inference)의 ELBO, 지식 증류(knowledge distillation), 생성 모델의 학습.

---

### Theorem 20.4 (로지스틱 회귀의 통합 구조)

로지스틱 회귀는 다음과 같이 **선형 모델 + 시그모이드 + 크로스 엔트로피**의 합성이며, 이는 딥러닝 분류 모델의 기본 단위이다:

$$L(\mathbf{w}, b) = -\left[y\log\sigma(\mathbf{w}^T\mathbf{x} + b) + (1-y)\log(1 - \sigma(\mathbf{w}^T\mathbf{x} + b))\right]$$

이 손실 함수는 $\mathbf{w}$와 $b$에 대해 **볼록**(convex)하다. 따라서 경사하강법으로 전역 최솟값(global minimum)에 수렴한다.

> **왜 중요한가:** 단일 뉴런의 학습이 수학적으로 잘 정의되어 있음을 보장한다. 딥러닝에서 마지막 층의 구조가 로지스틱 회귀와 동일하므로, 이 이해가 전체 네트워크 학습의 기초가 된다.

> **어디에 쓰이는가:** 이진 분류의 기본 모델, 신경망 출력층의 구조, 다중 레이블 분류(각 레이블에 독립 시그모이드 적용).

## 4. 공식 및 수식 유도

### 4.1 소프트맥스가 확률분포를 만드는 이유

**양수성:** 지수 함수의 성질에서 임의의 $z_i \in \mathbb{R}$에 대해 $e^{z_i} > 0$이다. 양수끼리의 나눗셈은 양수이므로:

$$\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{k=1}^{K} e^{z_k}} > 0$$

**합이 1:** 분자들의 합이 분모와 같다:

$$\sum_{i=1}^{K} \sigma(\mathbf{z})_i = \sum_{i=1}^{K} \frac{e^{z_i}}{\sum_{k=1}^{K} e^{z_k}} = \frac{\sum_{i=1}^{K} e^{z_i}}{\sum_{k=1}^{K} e^{z_k}} = 1$$

---

### 4.2 Attention Score 계산 과정

$n$개의 쿼리와 $m$개의 키-밸류 쌍이 있다고 하자.

**Step 1: 유사도 행렬 계산**

$$S = QK^T \in \mathbb{R}^{n \times m}$$

여기서 $S_{ij} = \mathbf{q}_i^T \mathbf{k}_j$는 $i$번째 쿼리와 $j$번째 키의 내적 유사도이다.

선형대수적 의미: $Q$의 각 행(쿼리 벡터)과 $K^T$의 각 열(키 벡터)의 내적을 **행렬곱 한 번**으로 모든 쌍에 대해 계산한다. 이것이 행렬곱의 강력함이다.

**Step 2: 스케일링**

$$S' = \frac{S}{\sqrt{d_k}}$$

**Step 3: 소프트맥스로 가중치 생성**

$$A = \text{softmax}(S') \in \mathbb{R}^{n \times m}$$

행 단위로 소프트맥스를 적용하여, $A$의 각 행이 확률분포를 이룬다. $A_{ij}$는 $i$번째 쿼리가 $j$번째 밸류에 부여하는 가중치이다.

**Step 4: 밸류의 가중합**

$$\text{Output} = AV \in \mathbb{R}^{n \times d_v}$$

$i$번째 출력 벡터는:

$$\text{Output}_i = \sum_{j=1}^{m} A_{ij}\,\mathbf{v}_j$$

이는 $\mathbf{v}_1, \ldots, \mathbf{v}_m$의 **볼록 결합**(convex combination)이다 ($A_{ij} \geq 0$, $\sum_j A_{ij} = 1$).

---

### 4.3 $\sqrt{d_k}$로 나누는 이유

$\mathbf{q}$와 $\mathbf{k}$의 각 성분이 평균 0, 분산 1인 독립 확률변수라고 가정하자.

내적 $\mathbf{q}^T\mathbf{k} = \sum_{j=1}^{d_k} q_j k_j$에서 각 항 $q_j k_j$는:

$$\mathbb{E}[q_j k_j] = \mathbb{E}[q_j]\mathbb{E}[k_j] = 0$$

$$\text{Var}(q_j k_j) = \mathbb{E}[q_j^2 k_j^2] - (\mathbb{E}[q_j k_j])^2 = \mathbb{E}[q_j^2]\mathbb{E}[k_j^2] - 0 = 1 \cdot 1 = 1$$

$d_k$개의 독립 항의 합이므로:

$$\text{Var}(\mathbf{q}^T\mathbf{k}) = d_k$$

따라서 $d_k$가 크면 내적의 분산이 커져서 소프트맥스 입력값의 절대값이 커진다. 소프트맥스에 큰 값이 들어가면 출력이 원-핫에 가까워져 **그레이디언트가 소실**(vanishing gradient)된다.

$\sqrt{d_k}$로 나누면:

$$\text{Var}\left(\frac{\mathbf{q}^T\mathbf{k}}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = 1$$

분산이 $d_k$에 무관하게 1로 유지되어, 소프트맥스가 적절한 범위에서 작동한다.

---

### 4.4 크로스 엔트로피의 그레이디언트 유도

로짓 $\mathbf{z} \in \mathbb{R}^K$에 소프트맥스를 적용하여 $\hat{\mathbf{y}} = \sigma(\mathbf{z})$를 얻고, 크로스 엔트로피 $L = -\sum_i y_i \log \hat{y}_i$를 계산하는 전체 과정의 그레이디언트를 유도한다.

**소프트맥스의 야코비안(Jacobian):**

$$\frac{\partial \hat{y}_i}{\partial z_j} = \begin{cases} \hat{y}_i(1 - \hat{y}_i) & \text{if } i = j \\ -\hat{y}_i \hat{y}_j & \text{if } i \neq j \end{cases}$$

이를 간결하게 쓰면:

$$\frac{\partial \hat{y}_i}{\partial z_j} = \hat{y}_i(\delta_{ij} - \hat{y}_j)$$

여기서 $\delta_{ij}$는 크로네커 델타(Kronecker delta)이다.

**증명:** $\hat{y}_i = \frac{e^{z_i}}{S}$이고 $S = \sum_k e^{z_k}$일 때, 몫의 미분법(quotient rule)을 적용한다.

$i = j$인 경우:

$$\frac{\partial \hat{y}_i}{\partial z_i} = \frac{e^{z_i} \cdot S - e^{z_i} \cdot e^{z_i}}{S^2} = \frac{e^{z_i}}{S} \cdot \frac{S - e^{z_i}}{S} = \hat{y}_i(1 - \hat{y}_i)$$

$i \neq j$인 경우:

$$\frac{\partial \hat{y}_i}{\partial z_j} = \frac{0 \cdot S - e^{z_i} \cdot e^{z_j}}{S^2} = -\frac{e^{z_i}}{S} \cdot \frac{e^{z_j}}{S} = -\hat{y}_i \hat{y}_j$$

**크로스 엔트로피의 로짓에 대한 그레이디언트:**

체인 룰을 적용하면:

$$\frac{\partial L}{\partial z_j} = -\sum_{i=1}^{K} y_i \cdot \frac{1}{\hat{y}_i} \cdot \frac{\partial \hat{y}_i}{\partial z_j}$$

$$= -\sum_{i=1}^{K} y_i \cdot \frac{1}{\hat{y}_i} \cdot \hat{y}_i(\delta_{ij} - \hat{y}_j)$$

$$= -\sum_{i=1}^{K} y_i(\delta_{ij} - \hat{y}_j)$$

$$= -y_j + \hat{y}_j \sum_{i=1}^{K} y_i$$

$\mathbf{y}$가 확률분포이므로 $\sum_i y_i = 1$이다. 따라서:

$$\boxed{\frac{\partial L}{\partial z_j} = \hat{y}_j - y_j}$$

벡터로 쓰면:

$$\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y}$$

이 결과는 놀라울 정도로 간단하다. 소프트맥스의 복잡한 야코비안과 크로스 엔트로피의 $\log$가 결합되면서 대부분의 항이 상쇄된다.

## 5. 증명

### 증명 5.1: 소프트맥스 출력이 확률분포임을 증명

**명제:** 임의의 $\mathbf{z} \in \mathbb{R}^K$에 대해, $\sigma(\mathbf{z})_i > 0$ $(i = 1, \ldots, K)$이고 $\sum_{i=1}^K \sigma(\mathbf{z})_i = 1$이다.

**증명 전략:** 지수 함수의 양수 성질과 합의 정의를 이용한 직접 증명.

**증명:**

**(a)** 양수성을 보인다.

$z_i \in \mathbb{R}$이 임의의 실수일 때, 지수 함수의 성질로부터:

$$e^{z_i} > 0 \quad \text{for all } z_i \in \mathbb{R} \tag{1}$$

$K \geq 1$이므로 분모는:

$$\sum_{k=1}^{K} e^{z_k} \geq e^{z_1} > 0 \tag{2}$$

(1)과 (2)에 의해, 양수를 양수로 나누면:

$$\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{k=1}^{K} e^{z_k}} > 0$$

**(b)** 정규성(합이 1)을 보인다.

$$\sum_{i=1}^{K} \sigma(\mathbf{z})_i = \sum_{i=1}^{K} \frac{e^{z_i}}{\sum_{k=1}^{K} e^{z_k}}$$

분모 $\sum_{k=1}^{K} e^{z_k}$는 $i$에 의존하지 않는 상수이므로 합 밖으로 뺄 수 있다:

$$= \frac{1}{\sum_{k=1}^{K} e^{z_k}} \sum_{i=1}^{K} e^{z_i} = \frac{\sum_{i=1}^{K} e^{z_i}}{\sum_{k=1}^{K} e^{z_k}} = 1$$

(a)와 (b)에 의해, $\sigma(\mathbf{z})$는 유효한 확률분포이다. $\blacksquare$

---

### 증명 5.2: 소프트맥스 + 크로스 엔트로피의 그레이디언트

**명제:** 로짓 $\mathbf{z} \in \mathbb{R}^K$, 소프트맥스 출력 $\hat{\mathbf{y}} = \sigma(\mathbf{z})$, 원-핫 레이블 $\mathbf{y}$ ($\sum_i y_i = 1$, $y_i \geq 0$)에 대해, 크로스 엔트로피 손실 $L = -\sum_i y_i \log \hat{y}_i$의 로짓에 대한 그레이디언트는:

$$\frac{\partial L}{\partial \mathbf{z}} = \hat{\mathbf{y}} - \mathbf{y}$$

**증명 전략:** 소프트맥스의 야코비안을 먼저 유도한 후, 체인 룰로 합성한다.

**증명:**

**Step 1:** 소프트맥스의 편미분을 구한다. $\hat{y}_i = \frac{e^{z_i}}{S}$, $S = \sum_{k=1}^K e^{z_k}$로 놓자.

$i = j$인 경우, 몫의 미분법에 의해:

$$\frac{\partial \hat{y}_i}{\partial z_i} = \frac{e^{z_i} S - e^{z_i} e^{z_i}}{S^2} = \frac{e^{z_i}(S - e^{z_i})}{S^2} = \hat{y}_i(1 - \hat{y}_i) \tag{3}$$

$i \neq j$인 경우, 분자 $e^{z_i}$는 $z_j$에 의존하지 않으므로:

$$\frac{\partial \hat{y}_i}{\partial z_j} = \frac{0 - e^{z_i} e^{z_j}}{S^2} = -\hat{y}_i \hat{y}_j \tag{4}$$

(3)과 (4)를 통합하면:

$$\frac{\partial \hat{y}_i}{\partial z_j} = \hat{y}_i(\delta_{ij} - \hat{y}_j) \tag{5}$$

**Step 2:** 체인 룰을 적용한다.

$$\frac{\partial L}{\partial z_j} = \sum_{i=1}^K \frac{\partial L}{\partial \hat{y}_i} \cdot \frac{\partial \hat{y}_i}{\partial z_j}$$

$\frac{\partial L}{\partial \hat{y}_i} = -\frac{y_i}{\hat{y}_i}$이므로:

$$\frac{\partial L}{\partial z_j} = \sum_{i=1}^K \left(-\frac{y_i}{\hat{y}_i}\right) \hat{y}_i(\delta_{ij} - \hat{y}_j)$$

$$= -\sum_{i=1}^K y_i(\delta_{ij} - \hat{y}_j)$$

$$= -\sum_{i=1}^K y_i \delta_{ij} + \hat{y}_j \sum_{i=1}^K y_i$$

첫째 항: $\sum_{i} y_i \delta_{ij} = y_j$ (크로네커 델타의 선별 성질)

둘째 항: $\sum_{i} y_i = 1$ (확률분포의 정규성)

따라서:

$$\frac{\partial L}{\partial z_j} = -y_j + \hat{y}_j \cdot 1 = \hat{y}_j - y_j$$

이를 벡터로 정리하면:

$$\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y} \qquad \blacksquare$$

### 증명 5.3: Attention의 선형대수적 해석

**명제:** Scaled Dot-Product Attention의 출력은 밸류 벡터들의 **볼록 결합**(convex combination)이다.

**증명 전략:** 소프트맥스 출력이 확률분포임을 이용하여 볼록 결합 조건을 확인한다.

**증명:**

Attention 가중치 행렬 $A = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) \in \mathbb{R}^{n \times m}$의 각 행 $\mathbf{a}_i = (A_{i1}, \ldots, A_{im})$에 대해:

Theorem 20.1에 의해, 소프트맥스 출력은 확률분포이므로:

$$A_{ij} > 0 \quad \forall\, j, \qquad \sum_{j=1}^{m} A_{ij} = 1 \tag{6}$$

$i$번째 쿼리에 대한 Attention 출력은:

$$\mathbf{o}_i = \sum_{j=1}^{m} A_{ij}\, \mathbf{v}_j \tag{7}$$

(6)에 의해 가중치가 음이 아니고 합이 1이므로, (7)은 $\mathbf{v}_1, \ldots, \mathbf{v}_m$의 **볼록 결합**(convex combination)의 정의를 정확히 만족한다.

**기하학적 의미:** Attention 출력 $\mathbf{o}_i$는 밸류 벡터들이 이루는 **볼록 껍질**(convex hull) 내부의 점이다. 어떤 키와 유사도가 특히 높으면 그에 대응하는 밸류 근처에, 모든 키와 비슷한 유사도이면 밸류들의 무게중심 근처에 위치한다.

$$\mathbf{o}_i \in \text{conv}(\mathbf{v}_1, \ldots, \mathbf{v}_m) \qquad \blacksquare$$

## 6. 계산 예제와 단계별 풀이

### Example 20.1: 3차원 벡터의 소프트맥스 계산

**문제:** $\mathbf{z} = (3, 1, -1)^T$에 대해 소프트맥스를 계산하라.

**풀이:**

**Step 1:** 수치 안정성을 위해 최댓값 $M = \max(3, 1, -1) = 3$을 빼자.

$$\mathbf{z}' = \mathbf{z} - M = (0, -2, -4)^T$$

> **참고:** $\sigma(\mathbf{z}) = \sigma(\mathbf{z} - c\mathbf{1})$이 성립한다 (이동 불변성). 분자·분모에 $e^{-c}$가 공통으로 곱해져 약분되기 때문이다.

**Step 2:** 지수 계산.

$$e^0 = 1.000, \quad e^{-2} = 0.135, \quad e^{-4} = 0.018$$

**Step 3:** 분모 계산.

$$S = 1.000 + 0.135 + 0.018 = 1.153$$

**Step 4:** 소프트맥스 출력.

$$\sigma(\mathbf{z})_1 = \frac{1.000}{1.153} = 0.867$$

$$\sigma(\mathbf{z})_2 = \frac{0.135}{1.153} = 0.117$$

$$\sigma(\mathbf{z})_3 = \frac{0.018}{1.153} = 0.016$$

**검증:**

- 양수성: $0.867, 0.117, 0.016 > 0$ ✓
- 합: $0.867 + 0.117 + 0.016 = 1.000$ ✓
- 순서 보존: $z_1 > z_2 > z_3$이고 $\sigma_1 > \sigma_2 > \sigma_3$ ✓

---

### Example 20.2: 간단한 Attention Score 계산

**문제:** 2개의 토큰, $d_k = 2$인 경우의 Self-Attention을 계산하라.

$$Q = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}, \quad K = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}, \quad V = \begin{pmatrix} 10 \\ 20 \end{pmatrix}$$

여기서 $V \in \mathbb{R}^{2 \times 1}$ ($d_v = 1$).

**풀이:**

**Step 1:** 유사도 행렬 계산.

$$QK^T = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}\begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$$

**Step 2:** 스케일링. $\sqrt{d_k} = \sqrt{2} \approx 1.414$.

$$\frac{QK^T}{\sqrt{2}} = \begin{pmatrix} 0.707 & 0 \\ 0.707 & 0.707 \end{pmatrix}$$

**Step 3:** 행 단위 소프트맥스.

행 1: $\text{softmax}(0.707, 0) = \left(\frac{e^{0.707}}{e^{0.707} + e^0}, \frac{e^0}{e^{0.707} + e^0}\right) = \left(\frac{2.028}{3.028}, \frac{1.000}{3.028}\right) = (0.670, 0.330)$

행 2: $\text{softmax}(0.707, 0.707) = (0.5, 0.5)$ (같은 값이므로 균등 분포)

$$A = \begin{pmatrix} 0.670 & 0.330 \\ 0.500 & 0.500 \end{pmatrix}$$

**Step 4:** 가중합 계산.

$$AV = \begin{pmatrix} 0.670 & 0.330 \\ 0.500 & 0.500 \end{pmatrix}\begin{pmatrix} 10 \\ 20 \end{pmatrix} = \begin{pmatrix} 6.70 + 6.60 \\ 5.00 + 10.00 \end{pmatrix} = \begin{pmatrix} 13.30 \\ 15.00 \end{pmatrix}$$

**해석:**
- 첫 번째 쿼리 $(1, 0)$은 첫 번째 키 $(1, 1)$과 더 유사 → $V_1 = 10$에 더 큰 가중치 → 출력 $13.30$ (10에 더 가깝다)
- 두 번째 쿼리 $(0, 1)$은 두 키와 동일한 유사도 → 균등 가중 → 출력 $15.00$ (산술평균 $\frac{10+20}{2}$)

### Example 20.3: 크로스 엔트로피 손실 계산

**문제:** 4-class 분류에서 정답이 클래스 3이고, 모델의 소프트맥스 출력이 $\hat{\mathbf{y}} = (0.1, 0.2, 0.6, 0.1)$일 때, 크로스 엔트로피 손실을 계산하라.

**풀이:**

정답 레이블: $\mathbf{y} = (0, 0, 1, 0)$ (원-핫)

$$L = -\sum_{i=1}^{4} y_i \log \hat{y}_i = -(0 \cdot \log 0.1 + 0 \cdot \log 0.2 + 1 \cdot \log 0.6 + 0 \cdot \log 0.1)$$

$$= -\log 0.6 \approx 0.511$$

**비교:** 만약 $\hat{\mathbf{y}} = (0.1, 0.1, 0.1, 0.7)$ (정답 클래스에 가장 낮은 확률):

$$L = -\log 0.1 \approx 2.303$$

만약 $\hat{\mathbf{y}} = (0.01, 0.01, 0.97, 0.01)$ (매우 확신 있는 정답):

$$L = -\log 0.97 \approx 0.030$$

| 예측 확률 $\hat{y}_c$ | 크로스 엔트로피 $L$ | 해석 |
|:---:|:---:|:---:|
| 0.97 | 0.030 | 매우 좋은 예측 |
| 0.60 | 0.511 | 적당한 예측 |
| 0.10 | 2.303 | 나쁜 예측 |
| 0.01 | 4.605 | 매우 나쁜 예측 |

### Example 20.4: Softmax + CE Gradient 계산

**문제:** 로짓 $\mathbf{z} = (2, 1, 0)$, 정답 레이블 $\mathbf{y} = (1, 0, 0)$일 때, $\nabla_\mathbf{z} L$을 계산하라.

**풀이:**

**Step 1:** 소프트맥스 계산 (Example 20.1의 $(2,1,0)$ 사용).

$$\hat{\mathbf{y}} = \sigma(\mathbf{z}) \approx (0.665, 0.245, 0.090)$$

**Step 2:** 그레이디언트 공식 적용.

$$\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y} = (0.665, 0.245, 0.090) - (1, 0, 0) = (-0.335, 0.245, 0.090)$$

**해석:**

- $\frac{\partial L}{\partial z_1} = -0.335 < 0$: $z_1$을 **증가**시켜야 손실이 줄어든다 (정답 클래스이므로 확률을 높여야)
- $\frac{\partial L}{\partial z_2} = 0.245 > 0$: $z_2$를 **감소**시켜야 손실이 줄어든다
- $\frac{\partial L}{\partial z_3} = 0.090 > 0$: $z_3$를 **감소**시켜야 손실이 줄어든다

**검증:** 그레이디언트의 합 = $-0.335 + 0.245 + 0.090 = 0$. 이는 소프트맥스 출력의 합이 항상 1이라는 제약 조건의 결과이다. 한 클래스의 확률을 올리면 나머지 클래스의 확률이 내려가야 하므로 그레이디언트의 합은 0이 되어야 한다.

## 7. 자주 나오는 함정과 반례

### 함정 7.1: 소프트맥스의 수치 오버플로우 (Numerical Overflow)

**문제:** $\mathbf{z} = (1000, 1001, 999)$에 소프트맥스를 직접 적용하면 $e^{1000} \approx 10^{434}$로 **부동소수점 오버플로우**가 발생한다.

**해결:** 이동 불변성(shift invariance)을 이용한다. $M = \max_i z_i$라 하면:

$$\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_k e^{z_k}} = \frac{e^{z_i - M}}{\sum_k e^{z_k - M}}$$

**증명:** 분자·분모에 $e^{-M}$을 곱하면:

$$\frac{e^{z_i}}{\sum_k e^{z_k}} = \frac{e^{z_i} \cdot e^{-M}}{\sum_k e^{z_k} \cdot e^{-M}} = \frac{e^{z_i - M}}{\sum_k e^{z_k - M}}$$

$M$을 빼면 최댓값이 0이 되어 $e^{z_i - M} \leq e^0 = 1$이므로 오버플로우가 발생하지 않는다.

**시험 함정:** "소프트맥스를 구현하라"는 문제에서 이동 불변성 처리 없이 구현하면 감점.

---

### 함정 7.2: Temperature Scaling

**문제:** 소프트맥스에 temperature $\tau > 0$를 도입하면:

$$\sigma(\mathbf{z}; \tau)_i = \frac{e^{z_i / \tau}}{\sum_k e^{z_k / \tau}}$$

- $\tau \to 0^+$: 출력이 원-핫 벡터에 수렴 (argmax와 동일, **greedy**)
- $\tau = 1$: 표준 소프트맥스
- $\tau \to \infty$: 출력이 균등 분포 $\left(\frac{1}{K}, \ldots, \frac{1}{K}\right)$에 수렴 (**최대 불확실성**)

**함정:** temperature는 확률 **분포의 형태**를 바꿀 뿐, **순서**를 바꾸지 않는다. $z_i > z_j$이면 모든 $\tau > 0$에 대해 $\sigma(\mathbf{z}; \tau)_i > \sigma(\mathbf{z}; \tau)_j$이다.

**시험 함정:** "$\tau$가 커지면 가장 높은 확률의 클래스가 바뀔 수 있다"는 서술은 **거짓**이다.

---

### 함정 7.3: 크로스 엔트로피는 대칭이 아니다

**문제:** $H(\mathbf{p}, \mathbf{q}) \neq H(\mathbf{q}, \mathbf{p})$ 일반적으로 성립한다.

**예시:** $\mathbf{p} = (0.9, 0.1)$, $\mathbf{q} = (0.5, 0.5)$일 때:

$$H(\mathbf{p}, \mathbf{q}) = -(0.9\log 0.5 + 0.1\log 0.5) = -\log 0.5 = 0.693$$

$$H(\mathbf{q}, \mathbf{p}) = -(0.5\log 0.9 + 0.5\log 0.1) = -(0.5 \times (-0.105) + 0.5 \times (-2.303)) = 1.204$$

$0.693 \neq 1.204$이므로 크로스 엔트로피는 **비대칭**이다.

**시험 함정:** 딥러닝에서 $H(\mathbf{y}, \hat{\mathbf{y}})$를 사용할 때, $\mathbf{y}$와 $\hat{\mathbf{y}}$의 순서를 바꾸면 다른 손실 함수가 된다. 관례적으로 첫 번째 인수가 **진짜 분포**, 두 번째 인수가 **예측 분포**이다.

---

### 함정 7.4: $\log$의 밑과 단위

**문제:** 크로스 엔트로피 공식에서 $\log$의 밑에 따라 값이 달라진다.

- $\log_2$: 단위가 **비트**(bit)
- $\ln$ (자연로그): 단위가 **나트**(nat)
- $\log_{10}$: 단위가 **하틀리**(hartley)

**딥러닝 관례:** 대부분의 프레임워크(PyTorch, TensorFlow)는 **자연로그** $\ln$을 사용한다. 시험에서 밑이 명시되지 않으면 $\ln$으로 가정하라.

**시험 함정:** 정보 이론 교과서에서는 $\log_2$를, 딥러닝에서는 $\ln$을 쓰는 경우가 많으므로 문맥을 확인해야 한다.

---

### 함정 7.5: 소프트맥스의 그레이디언트 소실

**문제:** 로짓의 차이가 매우 크면 소프트맥스 출력이 원-핫에 가까워져 그레이디언트가 거의 0이 된다.

$\mathbf{z} = (100, 0, 0)$이면 $\hat{\mathbf{y}} \approx (1, 0, 0)$이 되어:

$$\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y} \approx (0, 0, 0) \quad \text{(정답이 클래스 1인 경우)}$$

모델이 이미 매우 확신하고 있다면 학습이 멈춘다. 이것이 **label smoothing**이 도입된 이유 중 하나이다.

**Label smoothing:** 원-핫 $\mathbf{y}$를 살짝 부드럽게 만든다:

$$y_i^{\text{smooth}} = (1 - \epsilon)y_i + \frac{\epsilon}{K}$$

이렇게 하면 모델이 과도하게 확신하는 것을 방지하고, 그레이디언트가 완전히 소실되는 것을 막는다.

## 8. 시험형 서술 문제와 모범답안

### 문제 8.1

> 소프트맥스 함수의 출력이 유효한 확률분포를 이루는 이유를 수학적으로 증명하라. 또한 소프트맥스의 이동 불변성(shift invariance)을 증명하고, 이것이 수치 구현에서 왜 중요한지 설명하라.

**모범답안:**

**(1) 확률분포의 두 조건 증명**

**양수성 증명:** 임의의 $z_i \in \mathbb{R}$에 대해 $e^{z_i} > 0$이다 (지수 함수의 치역은 $(0, \infty)$). 분모 $\sum_{k=1}^K e^{z_k}$는 양수의 합이므로 양수이다. 양수를 양수로 나누면 양수이므로 $\sigma(\mathbf{z})_i > 0$이다.

**정규성 증명:**

$$\sum_{i=1}^K \sigma(\mathbf{z})_i = \sum_{i=1}^K \frac{e^{z_i}}{\sum_{k=1}^K e^{z_k}} = \frac{\sum_{i=1}^K e^{z_i}}{\sum_{k=1}^K e^{z_k}} = 1$$

분모가 $i$에 의존하지 않는 상수이므로 합 밖으로 빼낼 수 있고, 분자와 분모가 동일한 합이 되어 1이 된다.

**(2) 이동 불변성 증명**

임의의 상수 $c \in \mathbb{R}$에 대해:

$$\sigma(\mathbf{z} + c\mathbf{1})_i = \frac{e^{z_i + c}}{\sum_{k=1}^K e^{z_k + c}} = \frac{e^{z_i} \cdot e^c}{\sum_{k=1}^K e^{z_k} \cdot e^c} = \frac{e^c \cdot e^{z_i}}{e^c \cdot \sum_{k=1}^K e^{z_k}} = \frac{e^{z_i}}{\sum_{k=1}^K e^{z_k}} = \sigma(\mathbf{z})_i$$

$e^c$가 분자·분모에 공통 인수로 나타나 약분된다.

**(3) 수치 구현에서의 중요성**

부동소수점(floating-point) 연산에서 $e^{z_i}$는 $z_i$가 큰 경우 오버플로우, 매우 작은 경우 언더플로우가 발생한다. $c = -\max_i z_i$를 선택하면 $z_i + c \leq 0$이 되어 $e^{z_i + c} \leq 1$로 오버플로우가 방지된다. 이동 불변성에 의해 결과는 정확히 같으므로 수학적 정확성을 잃지 않는다. $\blacksquare$

### 문제 8.2

> Scaled Dot-Product Attention 계산에서 내적과 행렬곱이 어떻게 쓰이는지 설명하라. $QK^T$의 선형대수적 의미, $\sqrt{d_k}$로 나누는 이유, 그리고 소프트맥스 적용 후 $V$와의 곱의 의미를 각각 서술하라.

**모범답안:**

**(1) $QK^T$의 선형대수적 의미**

$Q \in \mathbb{R}^{n \times d_k}$의 $i$번째 행은 $i$번째 쿼리 벡터 $\mathbf{q}_i^T$이고, $K \in \mathbb{R}^{m \times d_k}$의 $j$번째 행은 $j$번째 키 벡터 $\mathbf{k}_j^T$이다.

행렬곱 $QK^T \in \mathbb{R}^{n \times m}$의 $(i, j)$ 성분은:

$$(QK^T)_{ij} = \mathbf{q}_i^T \mathbf{k}_j = \sum_{l=1}^{d_k} q_{il} k_{jl}$$

이는 $\mathbf{q}_i$와 $\mathbf{k}_j$의 **내적**이며, 두 벡터 사이의 유사도를 측정한다. 기하학적으로 $\mathbf{q}_i^T \mathbf{k}_j = \|\mathbf{q}_i\|\|\mathbf{k}_j\|\cos\theta_{ij}$이므로, 방향이 비슷할수록(각도가 작을수록) 값이 크다.

행렬곱 $QK^T$는 $n \times m$개의 모든 쿼리-키 쌍에 대한 유사도를 **한 번의 행렬 연산**으로 병렬 계산한다.

**(2) $\sqrt{d_k}$로 나누는 이유**

$\mathbf{q}_i$와 $\mathbf{k}_j$의 각 성분이 독립이고 평균 0, 분산 1이라고 가정하면, 내적 $\mathbf{q}_i^T\mathbf{k}_j = \sum_{l=1}^{d_k} q_{il}k_{jl}$의 분산은:

$$\text{Var}(\mathbf{q}_i^T\mathbf{k}_j) = \sum_{l=1}^{d_k} \text{Var}(q_{il}k_{jl}) = d_k$$

$d_k$가 크면 내적 값의 분산이 커져 절대값이 큰 값이 소프트맥스에 입력되고, 소프트맥스 출력이 원-핫에 가까워져 그레이디언트가 소실된다.

$\sqrt{d_k}$로 나누면 $\text{Var}\left(\frac{\mathbf{q}_i^T\mathbf{k}_j}{\sqrt{d_k}}\right) = 1$이 되어, $d_k$에 무관하게 소프트맥스 입력의 분산이 일정하게 유지된다.

**(3) 소프트맥스 적용 후 $V$와의 곱**

$A = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)$의 각 행은 Theorem 20.1에 의해 확률분포이다. $AV$의 $i$번째 행은:

$$\mathbf{o}_i = \sum_{j=1}^m A_{ij} \mathbf{v}_j$$

이는 밸류 벡터들의 **볼록 결합**(가중 평균)이다. 가중치 $A_{ij}$는 $i$번째 쿼리와 $j$번째 키의 유사도에 비례하므로, 유사한 키에 대응하는 밸류에 더 큰 가중치가 부여된다.

전체적으로 Attention은 **유사도 기반 검색**(similarity-based retrieval)을 미분 가능한(differentiable) 연산으로 구현한 것이다. $\blacksquare$

### 문제 8.3

> 크로스 엔트로피 손실과 KL 발산의 관계를 유도하고, 크로스 엔트로피 최소화가 왜 두 분포를 가깝게 만드는지 정보 이론적으로 설명하라.

**모범답안:**

**(1) 관계 유도**

크로스 엔트로피의 정의:

$$H(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{i=1}^K y_i \log \hat{y}_i$$

$-\sum y_i \log y_i + \sum y_i \log y_i$를 더하고 빼면:

$$H(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_i y_i \log y_i + \sum_i y_i \log y_i - \sum_i y_i \log \hat{y}_i$$

$$= H(\mathbf{y}) + \sum_i y_i \log \frac{y_i}{\hat{y}_i}$$

$$= H(\mathbf{y}) + D_{KL}(\mathbf{y} \| \hat{\mathbf{y}})$$

여기서 $H(\mathbf{y}) = -\sum_i y_i \log y_i$는 진짜 분포의 **엔트로피**(entropy)이고, $D_{KL}(\mathbf{y} \| \hat{\mathbf{y}}) = \sum_i y_i \log \frac{y_i}{\hat{y}_i}$는 **KL 발산**(Kullback-Leibler divergence)이다.

**(2) 크로스 엔트로피 최소화의 의미**

학습 시 $\mathbf{y}$는 고정(상수)이므로 $H(\mathbf{y})$도 상수이다. 따라서:

$$\min_{\hat{\mathbf{y}}} H(\mathbf{y}, \hat{\mathbf{y}}) = H(\mathbf{y}) + \min_{\hat{\mathbf{y}}} D_{KL}(\mathbf{y} \| \hat{\mathbf{y}})$$

**Gibbs의 부등식**에 의해 $D_{KL}(\mathbf{y} \| \hat{\mathbf{y}}) \geq 0$이며, 등호는 $\hat{\mathbf{y}} = \mathbf{y}$일 때만 성립한다.

따라서 크로스 엔트로피를 최소화하는 것은 KL 발산을 최소화하는 것과 동치이며, 이는 예측 분포 $\hat{\mathbf{y}}$를 진짜 분포 $\mathbf{y}$에 최대한 가깝게 만드는 것이다.

**(3) 정보 이론적 해석**

- $H(\mathbf{y})$: 진짜 분포의 **최적 부호화 길이**(optimal code length). 데이터의 고유한 불확실성.
- $D_{KL}(\mathbf{y} \| \hat{\mathbf{y}})$: 예측 분포로 부호화했을 때의 **추가적 비트 수**. 예측이 부정확할수록 더 많은 비트가 필요.
- $H(\mathbf{y}, \hat{\mathbf{y}})$: 예측 분포를 사용한 **총 부호화 길이**.

크로스 엔트로피를 줄이는 것은 "예측 분포가 불필요하게 사용하는 추가적 비트 수를 줄이는 것"과 같다. $\blacksquare$

### 문제 8.4

> 소프트맥스와 크로스 엔트로피를 합성한 손실 함수의 로짓에 대한 그레이디언트가 $\hat{\mathbf{y}} - \mathbf{y}$임을 처음부터 유도하라. 이 결과의 실용적 의미를 설명하라.

**모범답안:**

**(1) 소프트맥스의 야코비안 유도**

$\hat{y}_i = \frac{e^{z_i}}{S}$, $S = \sum_k e^{z_k}$로 정의한다.

$i = j$일 때 (몫의 미분법):

$$\frac{\partial \hat{y}_i}{\partial z_i} = \frac{e^{z_i} \cdot S - e^{z_i} \cdot e^{z_i}}{S^2} = \frac{e^{z_i}}{S}\left(1 - \frac{e^{z_i}}{S}\right) = \hat{y}_i(1 - \hat{y}_i)$$

$i \neq j$일 때:

$$\frac{\partial \hat{y}_i}{\partial z_j} = \frac{0 - e^{z_i} \cdot e^{z_j}}{S^2} = -\hat{y}_i\hat{y}_j$$

통합 표현: $\frac{\partial \hat{y}_i}{\partial z_j} = \hat{y}_i(\delta_{ij} - \hat{y}_j)$

**(2) 체인 룰 적용**

$$\frac{\partial L}{\partial z_j} = \sum_i \frac{\partial L}{\partial \hat{y}_i} \cdot \frac{\partial \hat{y}_i}{\partial z_j} = \sum_i \left(-\frac{y_i}{\hat{y}_i}\right)\hat{y}_i(\delta_{ij} - \hat{y}_j)$$

$$= -\sum_i y_i(\delta_{ij} - \hat{y}_j) = -y_j + \hat{y}_j\underbrace{\sum_i y_i}_{=1} = \hat{y}_j - y_j$$

따라서 $\nabla_{\mathbf{z}} L = \hat{\mathbf{y}} - \mathbf{y}$.

**(3) 실용적 의미**

- **구현 단순성:** 역전파에서 출력층의 그레이디언트를 별도의 야코비안 없이 단순한 뺄셈으로 계산할 수 있다. PyTorch의 `CrossEntropyLoss`가 내부적으로 소프트맥스와 크로스 엔트로피를 합성하여 사용하는 이유이다.
- **수치 안정성:** 소프트맥스와 크로스 엔트로피를 분리하여 계산하면 $\log(\hat{y}_i)$에서 $\hat{y}_i \approx 0$일 때 수치 불안정성이 생기지만, 합성하면 log-sum-exp 트릭으로 안정적으로 계산 가능하다.
- **직관적 해석:** 그레이디언트 $\hat{y}_j - y_j$는 "예측과 정답의 차이"이다. 정답 클래스에 대해서는 $\hat{y}_j - 1 < 0$이므로 로짓을 키우고, 나머지 클래스에 대해서는 $\hat{y}_j - 0 > 0$이므로 로짓을 줄이는 방향으로 학습이 진행된다. $\blacksquare$

### 문제 8.5

> Multi-Head Attention의 구조를 수식으로 기술하고, 단일 Attention 대비 이점을 선형대수의 관점에서 설명하라. 또한 각 구성 요소의 파라미터 수를 분석하라.

**모범답안:**

**(1) Multi-Head Attention 수식**

입력 $Q, K, V$에 대해 $h$개의 head를 사용하는 Multi-Head Attention은:

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)W^O$$

각 head는:

$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

여기서:
- $W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$: $i$번째 head의 쿼리 투영 행렬
- $W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$: $i$번째 head의 키 투영 행렬
- $W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$: $i$번째 head의 밸류 투영 행렬
- $W^O \in \mathbb{R}^{hd_v \times d_{\text{model}}}$: 출력 투영 행렬
- 보통 $d_k = d_v = d_{\text{model}} / h$

**(2) 단일 Attention 대비 이점**

단일 Attention은 하나의 유사도 기준(하나의 $d_k$차원 부분 공간에서의 내적)으로만 관계를 측정한다. Multi-Head Attention은 $h$개의 **서로 다른 부분 공간**(subspace)에서 독립적으로 유사도를 측정한다.

선형대수적으로, 투영 행렬 $W_i^Q, W_i^K$는 원래의 $d_{\text{model}}$차원 공간을 $d_k$차원 부분 공간으로 **사영**(projection)한다. 각 head가 서로 다른 사영을 학습하므로:

- Head 1은 의미적(semantic) 유사성에 집중
- Head 2는 위치적(positional) 관계에 집중
- Head 3은 문법적(syntactic) 관계에 집중

이처럼 서로 다른 관계 패턴을 병렬적으로 포착할 수 있다.

**(3) 파라미터 수 분석**

| 구성 요소 | 크기 | 개수 | 총 파라미터 |
|:---:|:---:|:---:|:---:|
| $W_i^Q$ | $d_{\text{model}} \times d_k$ | $h$ | $h \cdot d_{\text{model}} \cdot d_k$ |
| $W_i^K$ | $d_{\text{model}} \times d_k$ | $h$ | $h \cdot d_{\text{model}} \cdot d_k$ |
| $W_i^V$ | $d_{\text{model}} \times d_v$ | $h$ | $h \cdot d_{\text{model}} \cdot d_v$ |
| $W^O$ | $hd_v \times d_{\text{model}}$ | $1$ | $h \cdot d_v \cdot d_{\text{model}}$ |

$d_k = d_v = d_{\text{model}}/h$를 대입하면:

$$\text{총 파라미터} = 3h \cdot d_{\text{model}} \cdot \frac{d_{\text{model}}}{h} + h \cdot \frac{d_{\text{model}}}{h} \cdot d_{\text{model}} = 4d_{\text{model}}^2$$

이는 단일 head로 $d_{\text{model}}$차원 전체를 사용하는 Attention의 파라미터 수 $4d_{\text{model}}^2$와 **동일**하다. 즉, Multi-Head는 추가 파라미터 없이 다양한 관계를 포착할 수 있다는 것이 핵심이다. $\blacksquare$

### 문제 8.6 (종합)

> 딥러닝 분류 모델의 순전파(forward pass)와 역전파(backward pass)를 로지스틱 회귀를 예로 들어 처음부터 끝까지 수식으로 기술하라. 각 단계에서 사용되는 수학적 도구(선형대수, 미분, 확률)를 명시하라.

**모범답안:**

입력 $\mathbf{x} \in \mathbb{R}^d$, 가중치 $\mathbf{w} \in \mathbb{R}^d$, 편향 $b \in \mathbb{R}$, 정답 $y \in \{0, 1\}$.

**(1) 순전파**

| 단계 | 연산 | 수학적 도구 |
|:---:|:---:|:---:|
| 1 | $z = \mathbf{w}^T\mathbf{x} + b$ | 선형대수 (내적) |
| 2 | $\hat{y} = \sigma(z) = \frac{1}{1+e^{-z}}$ | 해석학 (지수함수) |
| 3 | $L = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ | 확률/정보이론 (크로스 엔트로피) |

**(2) 역전파 (체인 룰 적용)**

**Step 3 → 2:** 손실의 $\hat{y}$에 대한 미분.

$$\frac{\partial L}{\partial \hat{y}} = -\frac{y}{\hat{y}} + \frac{1-y}{1-\hat{y}} = \frac{\hat{y} - y}{\hat{y}(1-\hat{y})}$$

**Step 2 → 1:** 시그모이드의 $z$에 대한 미분.

$$\frac{d\hat{y}}{dz} = \hat{y}(1 - \hat{y})$$

(이 성질은 시그모이드의 특별한 성질이다: 도함수가 자기 자신으로 표현된다.)

**합성:** 체인 룰에 의해:

$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{d\hat{y}}{dz} = \frac{\hat{y} - y}{\hat{y}(1-\hat{y})} \cdot \hat{y}(1-\hat{y}) = \hat{y} - y$$

다시 한번 $\hat{y} - y$라는 간결한 결과를 얻는다.

**Step 1 → 파라미터:**

$$\frac{\partial L}{\partial \mathbf{w}} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial \mathbf{w}} = (\hat{y} - y)\mathbf{x}$$

$$\frac{\partial L}{\partial b} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial b} = \hat{y} - y$$

**(3) 파라미터 업데이트 (경사하강법)**

$$\mathbf{w} \leftarrow \mathbf{w} - \eta(\hat{y} - y)\mathbf{x}$$

$$b \leftarrow b - \eta(\hat{y} - y)$$

여기서 $\eta$는 학습률(learning rate)이다.

**수학적 도구 총괄:**
- **선형대수:** 내적, 행렬-벡터 곱 (순전파, 그레이디언트 계산)
- **미적분:** 체인 룰, 몫의 미분법, 지수함수의 도함수 (역전파)
- **확률/정보이론:** 크로스 엔트로피, 확률 해석 (손실 함수 설계)
- **최적화:** 경사하강법 (파라미터 업데이트)

이처럼 로지스틱 회귀 하나에 딥러닝의 모든 수학적 기초가 응축되어 있다. $\blacksquare$
