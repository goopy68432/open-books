# Ch.12 최적화 이론

---

## 1. 학습 목표

이 장을 마친 후 다음을 할 수 있어야 한다:

- 임계점(critical point), 극소(local minimum), 극대(local maximum), 안장점(saddle point), 전역 최소(global minimum)의 정의를 정확히 진술할 수 있다
- 볼록 함수(convex function)의 정의를 진술하고, 볼록성 여부를 판정할 수 있다
- **Fermat 정리를 1변수 및 다변수 버전으로 증명할 수 있다** (PRIORITY PROOF #8)
- 2차 미분 판정법(second derivative test)을 1변수 및 다변수에 적용하여 임계점을 분류할 수 있다
- 헤시안(Hessian) 행렬의 양정치성(positive definiteness)을 이용하여 극값 유형을 판별할 수 있다
- 볼록 함수에서 극소 = 전역 최소임을 증명할 수 있다
- 경사 하강법(gradient descent) 업데이트 규칙을 1차 테일러 근사로부터 유도할 수 있다
- 학습률(learning rate)의 역할을 이해하고, 적절한 학습률 선택의 중요성을 설명할 수 있다
- 구체적 함수에 대해 gradient descent를 수동으로 수회 반복 계산할 수 있다

---

## 2. 필수 정의

### Definition 12.1 (임계점, Critical Point)

함수 $f : \mathbb{R}^n \to \mathbb{R}$가 점 $\mathbf{x}^* \in \mathbb{R}^n$에서 미분가능할 때,

$$\nabla f(\mathbf{x}^*) = \mathbf{0}$$

이면 $\mathbf{x}^*$를 $f$의 **임계점**(critical point) 또는 **정류점**(stationary point)이라 한다.

1변수의 경우: $f'(x^*) = 0$이면 $x^*$는 $f$의 임계점이다.

> **해석:** 임계점에서는 함수의 모든 편미분이 0이므로, 함수의 그래프가 "평평한" 지점이다. 이 지점은 극소, 극대, 또는 안장점일 수 있다.

**예시:**

$$f(x) = x^2 - 4x + 3$$

$$f'(x) = 2x - 4 = 0 \implies x^* = 2$$

$x^* = 2$는 $f$의 임계점이다.

다변수 예시:

$$f(x, y) = x^2 + y^2$$

$$\nabla f = \begin{pmatrix} 2x \\ 2y \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix} \implies (x^*, y^*) = (0, 0)$$

**비예시:**

$$f(x) = x^3 + 1$$

$$f'(x) = 3x^2 = 0 \implies x^* = 0$$

$x = 1$은 이 함수의 임계점이 **아니다**: $f'(1) = 3 \neq 0$이므로.

또한 $f(x) = |x|$는 $x = 0$에서 미분불가능하다. $x = 0$은 최솟값이지만, 미분가능하지 않으므로 위 정의의 임계점은 아니다 (미분가능성이 전제).

---

### Definition 12.2 (국소 최솟값, Local Minimum)

함수 $f : \mathbb{R}^n \to \mathbb{R}$에 대해, 점 $\mathbf{x}^*$의 어떤 근방(neighborhood) $B_\delta(\mathbf{x}^*)$가 존재하여

$$f(\mathbf{x}^*) \leq f(\mathbf{x}), \quad \forall \mathbf{x} \in B_\delta(\mathbf{x}^*)$$

이면 $\mathbf{x}^*$를 $f$의 **국소 최솟값**(local minimum)이라 한다.

여기서 $B_\delta(\mathbf{x}^*) = \{\mathbf{x} \in \mathbb{R}^n : \|\mathbf{x} - \mathbf{x}^*\| < \delta\}$이다.

> **해석:** "주변보다 낮은 점." 국소적으로 보면 가장 작은 함숫값을 가지지만, 전역적으로는 더 작은 값이 존재할 수 있다.

**예시:**

$$f(x) = x^4 - 2x^2 + 1 = (x^2 - 1)^2$$

$f'(x) = 4x^3 - 4x = 4x(x-1)(x+1) = 0$에서 $x = -1, 0, 1$.

$x = -1$과 $x = 1$에서 $f(-1) = f(1) = 0$이고, 이 점들의 근방에서 $f(x) \geq 0$이므로 국소 최솟값이다.

**비예시:**

같은 함수에서 $x = 0$은 임계점이지만 $f(0) = 1$이고, 근방에서 $f(x) < 1$인 점들이 존재하므로 ($f(0.5) = 0.5625 < 1$) 국소 최솟값이 **아니다**. 실제로 $x = 0$은 국소 최댓값이다.

---

### Definition 12.3 (국소 최댓값, Local Maximum)

함수 $f : \mathbb{R}^n \to \mathbb{R}$에 대해, 점 $\mathbf{x}^*$의 어떤 근방 $B_\delta(\mathbf{x}^*)$가 존재하여

$$f(\mathbf{x}^*) \geq f(\mathbf{x}), \quad \forall \mathbf{x} \in B_\delta(\mathbf{x}^*)$$

이면 $\mathbf{x}^*$를 $f$의 **국소 최댓값**(local maximum)이라 한다.

> **해석:** "주변보다 높은 점." 산봉우리에 해당한다.

**예시:**

$$f(x) = -x^2 + 4x - 3$$

$f'(x) = -2x + 4 = 0 \implies x^* = 2$, $f''(2) = -2 < 0$이므로 $x^* = 2$는 국소 최댓값이다. $f(2) = 1$.

**비예시:**

$$f(x) = x^3$$

$f'(0) = 0$이지만, $x = 0$의 좌측에서 $f(x) < 0$이고 우측에서 $f(x) > 0$이므로 $x = 0$은 극대도 극소도 아니다 (변곡점).

---

### Definition 12.4 (안장점, Saddle Point)

점 $\mathbf{x}^*$가 $f$의 임계점($\nabla f(\mathbf{x}^*) = \mathbf{0}$)이면서 국소 최솟값도 국소 최댓값도 아닌 점을 **안장점**(saddle point)이라 한다.

즉, $\mathbf{x}^*$의 임의의 근방에서 $f(\mathbf{x}) > f(\mathbf{x}^*)$인 점과 $f(\mathbf{x}) < f(\mathbf{x}^*)$인 점이 동시에 존재한다.

> **해석:** 말의 안장 모양. 어떤 방향으로는 올라가고 어떤 방향으로는 내려간다. 고차원 최적화에서 안장점은 극솟값보다 훨씬 많이 출현한다.

**예시:**

$$f(x, y) = x^2 - y^2$$

$\nabla f = (2x, -2y)^T = \mathbf{0}$에서 $(x^*, y^*) = (0, 0)$.

$x$-방향으로는 $f(x, 0) = x^2 \geq 0$ (위로 볼록), $y$-방향으로는 $f(0, y) = -y^2 \leq 0$ (아래로 볼록). 따라서 $(0, 0)$은 안장점이다.

**비예시:**

$$f(x, y) = x^2 + y^2$$

$(0, 0)$은 임계점이고, 모든 방향에서 함숫값이 증가하므로 안장점이 **아니라** 국소 최솟값(실제로 전역 최솟값)이다.

---

### Definition 12.5 (전역 최솟값, Global Minimum)

함수 $f : \mathbb{R}^n \to \mathbb{R}$에 대해,

$$f(\mathbf{x}^*) \leq f(\mathbf{x}), \quad \forall \mathbf{x} \in \mathbb{R}^n$$

이면 $\mathbf{x}^*$를 $f$의 **전역 최솟값**(global minimum)이라 한다.

> **해석:** 정의역 전체에서 가장 작은 함숫값을 달성하는 점. 국소 최솟값은 여러 개일 수 있지만, 전역 최솟값은 (값이) 유일하다 (달성하는 점은 여러 개일 수 있다).

**예시:**

$$f(x) = (x - 3)^2$$

$f(x) \geq 0$이고 $f(3) = 0$이므로 $x^* = 3$은 전역 최솟값이다.

**비예시:**

$$f(x) = \sin(x)$$

$x = -\pi/2 + 2k\pi$ ($k \in \mathbb{Z}$)에서 $f = -1$이므로 전역 최솟값 **점**은 무한히 많다 (전역 최솟값 자체는 $-1$로 유일하다).

$$f(x) = e^x$$

이 함수는 $\inf f = 0$이지만 이 값을 달성하는 $x$가 존재하지 않는다. 따라서 전역 최솟값이 **존재하지 않는다**.

---

### Definition 12.6 (볼록 함수, Convex Function)

함수 $f : \mathbb{R}^n \to \mathbb{R}$가 **볼록 함수**(convex function)라 함은, 임의의 $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$과 $0 \leq t \leq 1$에 대해

$$f(t\mathbf{x} + (1-t)\mathbf{y}) \leq t f(\mathbf{x}) + (1-t) f(\mathbf{y})$$

가 성립하는 것이다.

> **해석:** 임의의 두 점을 잇는 선분이 함수 그래프 **위**에 놓인다. "아래로 볼록."

**2차 미분 조건:** $f$가 두 번 미분가능하면,
- 1변수: $f''(x) \geq 0, \; \forall x$ $\iff$ $f$가 볼록
- 다변수: 헤시안 $H(\mathbf{x}) = \nabla^2 f(\mathbf{x})$가 모든 $\mathbf{x}$에서 양반정치(positive semidefinite) $\iff$ $f$가 볼록

**예시:**

$$f(x) = x^2$$

$f''(x) = 2 > 0$이므로 (강)볼록 함수이다.

$$f(\mathbf{x}) = \|\mathbf{x}\|^2 = \mathbf{x}^T \mathbf{x}$$

$\nabla^2 f = 2I$ (양정치)이므로 볼록 함수이다.

**비예시:**

$$f(x) = -x^2$$

$f''(x) = -2 < 0$이므로 볼록 함수가 **아니다** (오목 함수, concave).

$$f(x) = \sin(x)$$

$f''(x) = -\sin(x)$은 구간에 따라 부호가 바뀌므로 볼록도 오목도 아니다.

## 3. 핵심 정리와 명제

### Theorem 12.1 (Fermat 정리, Fermat's Theorem) ⭐ PRIORITY PROOF #8

> 함수 $f$가 점 $x^*$에서 미분가능하고, $x^*$가 $f$의 극값(극소 또는 극대)이면,
> $$f'(x^*) = 0$$
> 다변수 버전: $f : \mathbb{R}^n \to \mathbb{R}$가 $\mathbf{x}^*$에서 미분가능하고 극값을 가지면,
> $$\nabla f(\mathbf{x}^*) = \mathbf{0}$$

**왜 중요한가:**
- 극값의 **필요조건**을 제공한다. 극값 후보를 찾으려면 $\nabla f = \mathbf{0}$을 풀면 된다.
- 딥러닝에서 손실 함수의 최솟값을 찾기 위해 그레이디언트를 0으로 만드는 점을 탐색하는 것의 이론적 정당화.
- 주의: **역은 성립하지 않는다.** $f'(x^*) = 0$이라고 극값인 것은 아니다 ($f(x) = x^3$에서 $x = 0$).

**어디에 쓰이는가:**
- 경사 하강법의 수렴 목표 설정: $\|\nabla f\| \to 0$
- 신경망 학습의 종료 조건
- 최적화 문제의 해석적 풀이

---

### Theorem 12.2 (2차 미분 판정법, Second Derivative Test)

> **1변수:** $f'(x^*) = 0$이고 $f$가 $x^*$ 근방에서 두 번 미분가능하면,
> - $f''(x^*) > 0 \implies x^*$는 국소 최솟값
> - $f''(x^*) < 0 \implies x^*$는 국소 최댓값
> - $f''(x^*) = 0 \implies$ 판정 불가 (더 높은 차수 필요)
>
> **다변수:** $\nabla f(\mathbf{x}^*) = \mathbf{0}$이고 헤시안 $H = \nabla^2 f(\mathbf{x}^*)$에 대해,
> - $H$가 **양정치**(positive definite, PD) $\implies$ $\mathbf{x}^*$는 국소 최솟값
> - $H$가 **음정치**(negative definite, ND) $\implies$ $\mathbf{x}^*$는 국소 최댓값
> - $H$가 **부정치**(indefinite) $\implies$ $\mathbf{x}^*$는 안장점
> - $H$가 반정치(semidefinite)이면 판정 불가

여기서 **헤시안 행렬**(Hessian matrix)은:

$$H = \nabla^2 f(\mathbf{x}^*) = \begin{pmatrix} \dfrac{\partial^2 f}{\partial x_1^2} & \dfrac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \\ \dfrac{\partial^2 f}{\partial x_2 \partial x_1} & \dfrac{\partial^2 f}{\partial x_2^2} & \cdots \\ \vdots & \vdots & \ddots \end{pmatrix}$$

**2변수 판정 간소화:** $f(x,y)$의 임계점 $(x^*, y^*)$에서

$$D = f_{xx} f_{yy} - (f_{xy})^2 = \det(H)$$

- $D > 0$이고 $f_{xx} > 0$: 극소
- $D > 0$이고 $f_{xx} < 0$: 극대
- $D < 0$: 안장점
- $D = 0$: 판정 불가

**왜 중요한가:**
- 임계점을 찾은 후 그 **유형을 분류**하는 도구.
- 딥러닝에서 손실 함수의 임계점이 극소인지 안장점인지 판별.
- 헤시안의 고유값 분포가 최적화 landscape의 성격을 결정.

**어디에 쓰이는가:**
- Newton's method에서 2차 정보 활용
- 손실 함수의 곡률(curvature) 분석
- 학습률 스케줄링에서 곡률 기반 적응

---

### Theorem 12.3 (볼록 함수의 극소 = 전역 최소)

> 함수 $f : \mathbb{R}^n \to \mathbb{R}$가 **볼록 함수**이면, $f$의 모든 국소 최솟값은 **전역 최솟값**이다.
>
> 특히, $f$가 볼록이고 미분가능하며 $\nabla f(\mathbf{x}^*) = \mathbf{0}$이면, $\mathbf{x}^*$는 $f$의 전역 최솟값이다.

**왜 중요한가:**
- 볼록 최적화에서는 "지역 해 = 전역 해"이므로 경사 하강법이 전역 최적에 수렴할 수 있다.
- 비볼록 함수(딥러닝의 일반적 손실 함수)에서는 이 성질이 성립하지 않으므로, 다수의 국소 최솟값/안장점에 빠질 수 있다.

**어디에 쓰이는가:**
- 선형 회귀의 MSE 손실은 볼록 → 경사 하강법으로 전역 최적 보장
- SVM의 최적화 문제는 볼록
- 신경망의 손실 함수는 일반적으로 비볼록 → 전역 최적 보장 불가

---

### Theorem 12.4 (Gradient Descent 수렴 직관)

> 함수 $f$가 미분가능하고 $L$-**립시츠 연속 그레이디언트**(Lipschitz continuous gradient)를 가지면, 즉
> $$\|\nabla f(\mathbf{x}) - \nabla f(\mathbf{y})\| \leq L\|\mathbf{x} - \mathbf{y}\|, \quad \forall \mathbf{x}, \mathbf{y}$$
> 이고, 학습률 $\eta \leq \dfrac{1}{L}$이면, gradient descent 업데이트
> $$\mathbf{x}_{t+1} = \mathbf{x}_t - \eta \nabla f(\mathbf{x}_t)$$
> 는 매 스텝에서 함숫값을 감소시킨다:
> $$f(\mathbf{x}_{t+1}) \leq f(\mathbf{x}_t) - \frac{\eta}{2}\|\nabla f(\mathbf{x}_t)\|^2$$

**왜 중요한가:**
- 학습률이 너무 크면 발산, 너무 작으면 수렴이 느리다는 직관에 이론적 근거를 제공한다.
- 학습률의 상한이 그레이디언트의 립시츠 상수 $L$의 역수임을 보여준다.
- $\frac{\eta}{2}\|\nabla f(\mathbf{x}_t)\|^2$만큼의 "보장된 감소"가 있다.

**어디에 쓰이는가:**
- 학습률 선택의 이론적 가이드라인
- 적응적 학습률 알고리즘 (Adam, AdaGrad 등)의 동기
- 수렴 속도 분석: 볼록 함수에서 $O(1/T)$ 수렴

## 4. 공식 및 수식 유도

### 4.1 Gradient Descent 업데이트 규칙의 유도 (1차 근사 관점)

**목표:** 현재 위치 $\mathbf{x}_t$에서 $f$를 가장 빠르게 감소시키는 방향으로 이동하고 싶다.

**Step 1: 1차 테일러 근사**

$f$의 $\mathbf{x}_t$ 주위 1차 테일러 근사:

$$f(\mathbf{x}_t + \boldsymbol{\delta}) \approx f(\mathbf{x}_t) + \nabla f(\mathbf{x}_t)^T \boldsymbol{\delta}$$

**Step 2: 함숫값 감소 조건**

$f(\mathbf{x}_{t+1}) < f(\mathbf{x}_t)$가 되려면:

$$\nabla f(\mathbf{x}_t)^T \boldsymbol{\delta} < 0$$

**Step 3: 최적 방향 결정**

$\boldsymbol{\delta} = \alpha \mathbf{d}$ ($\|\mathbf{d}\| = 1$)로 놓으면, $\nabla f(\mathbf{x}_t)^T \mathbf{d}$를 최소화하는 방향은 코시-슈바르츠 부등식에 의해:

$$\nabla f(\mathbf{x}_t)^T \mathbf{d} \geq -\|\nabla f(\mathbf{x}_t)\| \cdot \|\mathbf{d}\| = -\|\nabla f(\mathbf{x}_t)\|$$

등호 조건: $\mathbf{d} = -\dfrac{\nabla f(\mathbf{x}_t)}{\|\nabla f(\mathbf{x}_t)\|}$

즉, **음의 그레이디언트 방향**이 가장 가파른 하강 방향(steepest descent direction)이다.

**Step 4: 업데이트 규칙**

$$\boxed{\mathbf{x}_{t+1} = \mathbf{x}_t - \eta \nabla f(\mathbf{x}_t)}$$

여기서 $\eta > 0$은 **학습률**(learning rate) 또는 **스텝 크기**(step size)이다.

---

### 4.2 학습률(Learning Rate)의 역할

학습률 $\eta$는 그레이디언트 방향으로 얼마나 크게 이동할지를 결정한다.

| 학습률 | 효과 |
|--------|------|
| $\eta$ 너무 큼 | 함숫값이 진동하거나 발산 (overshooting) |
| $\eta$ 적절 | 빠르고 안정적인 수렴 |
| $\eta$ 너무 작음 | 수렴은 보장되지만 매우 느림 |

**2차 근사 관점에서의 최적 학습률:**

$f$의 2차 테일러 근사:

$$f(\mathbf{x}_t - \eta \nabla f) \approx f(\mathbf{x}_t) - \eta \|\nabla f\|^2 + \frac{\eta^2}{2} \nabla f^T H \nabla f$$

$\eta$에 대해 최소화하면:

$$\frac{d}{d\eta}\left(- \eta \|\nabla f\|^2 + \frac{\eta^2}{2} \nabla f^T H \nabla f\right) = 0$$

$$\eta^* = \frac{\|\nabla f\|^2}{\nabla f^T H \nabla f}$$

이는 헤시안의 곡률 정보를 반영한 최적 학습률이다. Newton's method는 $\eta^* = 1$, $\boldsymbol{\delta} = -H^{-1}\nabla f$로 설정하여 2차 정보를 완전히 활용한다.

## 5. 증명

### 증명 1: Fermat 정리 (PRIORITY PROOF #8)

#### 1변수 버전

**정리:** $f$가 $x^*$에서 미분가능하고, $x^*$가 $f$의 극소이면 $f'(x^*) = 0$.

**증명 전략:** 극소의 정의를 이용하여, $x^*$ 좌측과 우측에서의 차분 몫(difference quotient)의 부호를 분석한다. 좌측에서는 $f'(x^*) \leq 0$, 우측에서는 $f'(x^*) \geq 0$을 보이면, $f'(x^*) = 0$을 얻는다.

**Formal Proof:**

$x^*$가 $f$의 극소이므로, 어떤 $\delta > 0$에 대해

$$f(x) \geq f(x^*), \quad \forall x \in (x^* - \delta, x^* + \delta)$$

$f$가 $x^*$에서 미분가능하므로, $f'(x^*) = \lim_{h \to 0} \dfrac{f(x^* + h) - f(x^*)}{h}$가 존재한다.

**우극한** ($h \to 0^+$):

$0 < h < \delta$이면 $f(x^* + h) \geq f(x^*)$이므로:

$$\frac{f(x^* + h) - f(x^*)}{h} \geq 0$$

$$\therefore f'(x^*) = \lim_{h \to 0^+} \frac{f(x^* + h) - f(x^*)}{h} \geq 0 \quad \cdots (1)$$

**좌극한** ($h \to 0^-$):

$-\delta < h < 0$이면 $f(x^* + h) \geq f(x^*)$이고 $h < 0$이므로:

$$\frac{f(x^* + h) - f(x^*)}{h} \leq 0$$

$$\therefore f'(x^*) = \lim_{h \to 0^-} \frac{f(x^* + h) - f(x^*)}{h} \leq 0 \quad \cdots (2)$$

$(1)$과 $(2)$에서:

$$0 \leq f'(x^*) \leq 0 \implies f'(x^*) = 0$$

극대의 경우도 동일한 논증에서 부등호가 뒤집히므로 같은 결론을 얻는다. $\blacksquare$

#### 다변수 버전

**정리:** $f : \mathbb{R}^n \to \mathbb{R}$가 $\mathbf{x}^*$에서 미분가능하고, $\mathbf{x}^*$가 $f$의 극소이면 $\nabla f(\mathbf{x}^*) = \mathbf{0}$.

**증명 전략:** 임의의 방향 $\mathbf{v}$에 대해, 1변수 함수 $g(t) = f(\mathbf{x}^* + t\mathbf{v})$를 정의하면 $g$는 $t = 0$에서 극소를 가진다. 1변수 Fermat 정리에 의해 $g'(0) = 0$이다. 이것이 방향 도함수 $\nabla f(\mathbf{x}^*)^T \mathbf{v} = 0$을 의미하고, $\mathbf{v}$가 임의이므로 $\nabla f(\mathbf{x}^*) = \mathbf{0}$이다.

**Formal Proof:**

임의의 $\mathbf{v} \in \mathbb{R}^n$을 고정하고, $g : \mathbb{R} \to \mathbb{R}$를

$$g(t) = f(\mathbf{x}^* + t\mathbf{v})$$

로 정의한다.

$\mathbf{x}^*$가 $f$의 극소이므로, 충분히 작은 $|t|$에 대해

$$g(t) = f(\mathbf{x}^* + t\mathbf{v}) \geq f(\mathbf{x}^*) = g(0)$$

따라서 $t = 0$은 $g$의 극소이다.

$f$가 $\mathbf{x}^*$에서 미분가능하므로, 연쇄법칙에 의해 $g$는 $t = 0$에서 미분가능하고:

$$g'(t)\Big|_{t=0} = \nabla f(\mathbf{x}^*)^T \mathbf{v}$$

1변수 Fermat 정리에 의해:

$$g'(0) = 0 \implies \nabla f(\mathbf{x}^*)^T \mathbf{v} = 0$$

이것이 **임의의** $\mathbf{v} \in \mathbb{R}^n$에 대해 성립하므로:

특히 $\mathbf{v} = \mathbf{e}_i$ (표준 기저벡터)를 취하면:

$$\nabla f(\mathbf{x}^*)^T \mathbf{e}_i = \frac{\partial f}{\partial x_i}(\mathbf{x}^*) = 0, \quad i = 1, \ldots, n$$

$$\therefore \nabla f(\mathbf{x}^*) = \mathbf{0} \qquad \blacksquare$$

---

### 증명 2: 2차 미분 판정법의 정당화 (1변수)

**정리:** $f'(x^*) = 0$이고 $f''(x^*) > 0$이면, $x^*$는 극소이다.

**증명 전략:** 2차 테일러 전개를 이용하여, $x^*$ 근방에서 $f(x) - f(x^*)$의 부호가 양수임을 보인다.

**Formal Proof:**

$f$의 $x^*$ 주위 2차 테일러 전개:

$$f(x^* + h) = f(x^*) + f'(x^*)h + \frac{1}{2}f''(x^*)h^2 + o(h^2)$$

$f'(x^*) = 0$이므로:

$$f(x^* + h) - f(x^*) = \frac{1}{2}f''(x^*)h^2 + o(h^2)$$

$$= \frac{h^2}{2}\left(f''(x^*) + \frac{o(h^2)}{h^2}\right)$$

$f''(x^*) > 0$이므로, 충분히 작은 $|h|$에 대해:

$$\frac{o(h^2)}{h^2} \to 0 \implies f''(x^*) + \frac{o(h^2)}{h^2} > 0$$

따라서 $0 < |h| < \delta$인 적절한 $\delta > 0$에 대해:

$$f(x^* + h) - f(x^*) = \frac{h^2}{2}\left(f''(x^*) + \frac{o(h^2)}{h^2}\right) > 0$$

이는 $f(x^* + h) > f(x^*)$를 의미하므로, $x^*$는 극소이다.

$f''(x^*) < 0$이면 동일한 논증에서 부호가 뒤집혀 극대가 된다. $\blacksquare$

**다변수 확장 (스케치):**

$\nabla f(\mathbf{x}^*) = \mathbf{0}$일 때, 테일러 전개:

$$f(\mathbf{x}^* + \mathbf{h}) - f(\mathbf{x}^*) = \frac{1}{2}\mathbf{h}^T H \mathbf{h} + o(\|\mathbf{h}\|^2)$$

$H$가 양정치이면 최소 고유값 $\lambda_{\min} > 0$에 대해 $\mathbf{h}^T H \mathbf{h} \geq \lambda_{\min}\|\mathbf{h}\|^2 > 0$ ($\mathbf{h} \neq \mathbf{0}$), 따라서 충분히 작은 $\|\mathbf{h}\|$에서 $f(\mathbf{x}^* + \mathbf{h}) > f(\mathbf{x}^*)$. $\blacksquare$

---

### 증명 3: 볼록 함수에서 극소 = 전역 최소

**정리:** $f : \mathbb{R}^n \to \mathbb{R}$가 볼록 함수이고, $\mathbf{x}^*$가 $f$의 국소 최솟값이면, $\mathbf{x}^*$는 $f$의 전역 최솟값이다.

**증명 전략:** 귀류법을 사용한다. 전역 최솟값이 아니라고 가정하면, 더 작은 함숫값을 가지는 점이 존재한다. 볼록성을 이용하여 $\mathbf{x}^*$의 근방에서도 더 작은 값이 있음을 보여 국소 최소와 모순.

**Formal Proof:**

$\mathbf{x}^*$가 $f$의 국소 최솟값이라 하자. 즉, 어떤 $\delta > 0$에 대해:

$$f(\mathbf{x}^*) \leq f(\mathbf{x}), \quad \forall \mathbf{x} \in B_\delta(\mathbf{x}^*)$$

귀류법: $\mathbf{x}^*$가 전역 최솟값이 아니라고 가정하자. 그러면 어떤 $\mathbf{y} \in \mathbb{R}^n$에 대해:

$$f(\mathbf{y}) < f(\mathbf{x}^*) \quad \cdots (\star)$$

$f$가 볼록이므로, 임의의 $t \in (0, 1)$에 대해:

$$f(t\mathbf{y} + (1-t)\mathbf{x}^*) \leq t f(\mathbf{y}) + (1-t) f(\mathbf{x}^*)$$

$(\star)$에 의해 $f(\mathbf{y}) < f(\mathbf{x}^*)$이므로:

$$f(t\mathbf{y} + (1-t)\mathbf{x}^*) \leq t f(\mathbf{y}) + (1-t) f(\mathbf{x}^*) < t f(\mathbf{x}^*) + (1-t) f(\mathbf{x}^*) = f(\mathbf{x}^*)$$

즉:

$$f(t\mathbf{y} + (1-t)\mathbf{x}^*) < f(\mathbf{x}^*)$$

이제 $\mathbf{z}_t = t\mathbf{y} + (1-t)\mathbf{x}^*$로 놓으면:

$$\|\mathbf{z}_t - \mathbf{x}^*\| = t\|\mathbf{y} - \mathbf{x}^*\|$$

$t \to 0^+$으로 취하면 $\|\mathbf{z}_t - \mathbf{x}^*\| \to 0$이므로, 충분히 작은 $t > 0$에 대해 $\mathbf{z}_t \in B_\delta(\mathbf{x}^*)$.

그런데 $f(\mathbf{z}_t) < f(\mathbf{x}^*)$이므로, 이는 $\mathbf{x}^*$가 국소 최솟값이라는 가정에 모순.

따라서 $\mathbf{x}^*$는 전역 최솟값이다. $\blacksquare$

## 6. 계산 예제와 단계별 풀이

### Example 12.1: 1변수 함수의 임계점과 극값 판정

**문제:** $f(x) = x^3 - 6x^2 + 9x + 1$의 임계점을 구하고, 각 임계점의 유형을 판별하라.

**풀이:**

**Step 1: 임계점 구하기**

$$f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)$$

$$f'(x) = 0 \implies x = 1, \quad x = 3$$

**Step 2: 2차 미분 판정법**

$$f''(x) = 6x - 12$$

$x = 1$에서: $f''(1) = 6(1) - 12 = -6 < 0$ → **극대**

$x = 3$에서: $f''(3) = 6(3) - 12 = 6 > 0$ → **극소**

**Step 3: 함숫값 계산**

- $f(1) = 1 - 6 + 9 + 1 = 5$ (극댓값)
- $f(3) = 27 - 54 + 27 + 1 = 1$ (극솟값)

**결론:** $x = 1$은 극대 (함숫값 5), $x = 3$은 극소 (함숫값 1).

---

### Example 12.2: 2변수 함수의 임계점과 헤시안 분류

**문제:** $f(x, y) = x^3 + y^3 - 3xy$의 임계점을 구하고 분류하라.

**풀이:**

**Step 1: 임계점 구하기**

$$f_x = 3x^2 - 3y = 0 \implies y = x^2$$

$$f_y = 3y^2 - 3x = 0 \implies x = y^2$$

$y = x^2$를 두 번째 식에 대입:

$$x = (x^2)^2 = x^4 \implies x^4 - x = 0 \implies x(x^3 - 1) = 0$$

$$x = 0 \text{ 또는 } x = 1$$

- $x = 0 \implies y = 0$: 임계점 $(0, 0)$
- $x = 1 \implies y = 1$: 임계점 $(1, 1)$

**Step 2: 헤시안 계산**

$$f_{xx} = 6x, \quad f_{yy} = 6y, \quad f_{xy} = -3$$

$$H = \begin{pmatrix} 6x & -3 \\ -3 & 6y \end{pmatrix}$$

$$D = \det(H) = 36xy - 9$$

**Step 3: 각 임계점 분류**

**$(0, 0)$에서:**

$$D = 36(0)(0) - 9 = -9 < 0$$

$D < 0$이므로 → **안장점**

**$(1, 1)$에서:**

$$D = 36(1)(1) - 9 = 27 > 0, \quad f_{xx}(1,1) = 6 > 0$$

$D > 0$이고 $f_{xx} > 0$이므로 → **극소**

$f(1, 1) = 1 + 1 - 3 = -1$ (극솟값)

---

### Example 12.3: Gradient Descent 반복 계산

**문제:** $f(x) = x^2 - 4x + 5$에 대해, 초기값 $x_0 = 0$, 학습률 $\eta = 0.3$으로 gradient descent를 4회 반복하라.

**풀이:**

$$f'(x) = 2x - 4$$

업데이트 규칙: $x_{t+1} = x_t - \eta f'(x_t) = x_t - 0.3(2x_t - 4)$

**Step 0:** $x_0 = 0$

$$f'(0) = -4, \quad x_1 = 0 - 0.3(-4) = 1.2, \quad f(x_1) = 1.44 - 4.8 + 5 = 1.64$$

**Step 1:** $x_1 = 1.2$

$$f'(1.2) = 2(1.2) - 4 = -1.6, \quad x_2 = 1.2 - 0.3(-1.6) = 1.68, \quad f(x_2) = 2.8224 - 6.72 + 5 = 1.1024$$

**Step 2:** $x_2 = 1.68$

$$f'(1.68) = 2(1.68) - 4 = -0.64, \quad x_3 = 1.68 - 0.3(-0.64) = 1.872, \quad f(x_3) = 3.504384 - 7.488 + 5 = 1.016384$$

**Step 3:** $x_3 = 1.872$

$$f'(1.872) = 2(1.872) - 4 = -0.256, \quad x_4 = 1.872 - 0.3(-0.256) = 1.9488, \quad f(x_4) = 3.797862 - 7.7952 + 5 = 1.002662$$

**관찰:**

| $t$ | $x_t$ | $f(x_t)$ | $f'(x_t)$ |
|-----|--------|-----------|------------|
| 0 | 0 | 5 | $-4$ |
| 1 | 1.2 | 1.64 | $-1.6$ |
| 2 | 1.68 | 1.1024 | $-0.64$ |
| 3 | 1.872 | 1.0164 | $-0.256$ |
| 4 | 1.9488 | 1.0026 | $-0.1024$ |

- 진짜 최솟값: $x^* = 2$, $f(x^*) = 1$
- 매 반복마다 $x_t$가 $x^* = 2$에 수렴하고, $f(x_t) \to 1$로 감소
- 그레이디언트의 크기 $|f'(x_t)|$도 매 반복마다 $0.4$배로 감소 (수렴 비율: $|1 - 2\eta| = |1 - 0.6| = 0.4$)

---

### Example 12.4: 안장점 예시

**문제:** $f(x, y) = x^2 - y^2 + 2x$의 임계점을 구하고, 안장점임을 확인하라.

**풀이:**

**Step 1: 임계점**

$$f_x = 2x + 2 = 0 \implies x = -1$$

$$f_y = -2y = 0 \implies y = 0$$

임계점: $(-1, 0)$

**Step 2: 헤시안**

$$H = \begin{pmatrix} f_{xx} & f_{xy} \\ f_{xy} & f_{yy} \end{pmatrix} = \begin{pmatrix} 2 & 0 \\ 0 & -2 \end{pmatrix}$$

$$D = \det(H) = (2)(-2) - 0 = -4 < 0$$

$D < 0$이므로 $(-1, 0)$은 **안장점**이다.

**Step 3: 방향별 확인**

$f(-1, 0) = 1 - 0 - 2 = -1$

- $x$-방향: $f(-1+h, 0) = (-1+h)^2 + 2(-1+h) = h^2 - 1 > -1$ ($h \neq 0$) → 증가
- $y$-방향: $f(-1, k) = 1 - k^2 - 2 = -1 - k^2 < -1$ ($k \neq 0$) → 감소

$x$-방향으로는 극소처럼 보이고, $y$-방향으로는 극대처럼 보이므로, 전형적인 안장점이다.

**Step 4: 헤시안의 고유값으로 해석**

$$H = \begin{pmatrix} 2 & 0 \\ 0 & -2 \end{pmatrix}$$

고유값: $\lambda_1 = 2 > 0$, $\lambda_2 = -2 < 0$ → 부정치(indefinite) → 안장점 확인.

## 7. 자주 나오는 함정과 반례

### 함정 1: "$f'(x^*) = 0$이면 극값이다"는 거짓

**반례:** $f(x) = x^3$

$f'(0) = 0$이지만, $x = 0$은 극소도 극대도 아니다 (변곡점). Fermat 정리는 **필요조건**이지 충분조건이 아니다.

> **교훈:** 임계점을 찾은 후 반드시 2차 미분 판정법 등으로 유형을 분류해야 한다.

---

### 함정 2: "$f''(x^*) = 0$이면 변곡점이다" 또는 "판정 불가 = 안장점"

**반례:** $f(x) = x^4$

$f'(0) = 0$, $f''(0) = 0$ (판정 불가). 그러나 $x = 0$은 **극소**이다 ($f(x) = x^4 \geq 0 = f(0)$).

**또 다른 반례:** $f(x) = x^6 - x^4$ (판정 불가이면서 극소도 아닌 경우도 존재)

> **교훈:** 2차 미분이 0이면, 고차 미분을 사용하거나 직접 함숫값을 비교해야 한다.

---

### 함정 3: 다변수에서 "$f_{xx} > 0$이고 $f_{yy} > 0$이면 극소" — 거짓

**반례:** $f(x, y) = x^2 + 4xy + y^2$

$(0,0)$에서: $f_{xx} = 2 > 0$, $f_{yy} = 2 > 0$.

그러나 $D = f_{xx}f_{yy} - (f_{xy})^2 = 4 - 16 = -12 < 0$.

$(0,0)$은 **안장점**이다! ($f(1, -1) = 1 - 4 + 1 = -2 < 0 = f(0,0)$)

> **교훈:** 다변수에서는 **반드시 헤시안의 행렬식** $D$(또는 고유값)를 확인해야 한다. 대각 성분만으로는 부족하다.

---

### 함정 4: "Gradient descent는 항상 전역 최소로 수렴한다"

**반례:** $f(x) = x^4/4 - x^2/2$

이 함수는 비볼록이며, $x = 0$ (극대), $x = \pm 1$ (극소, 전역 최소)을 갖는다.

초기값 $x_0 = 0$에서 시작하면 $f'(0) = 0$이므로 gradient descent가 한 걸음도 움직이지 않는다. 극대점에 갇힌다.

더 일반적으로, 비볼록 함수에서는:
- 국소 최솟값에 빠질 수 있다
- 안장점 근처에서 매우 느리게 진행한다
- 초기값에 따라 다른 해에 수렴한다

> **교훈:** 전역 최소 수렴 보장은 볼록 함수에서만 성립한다. 딥러닝의 비볼록 최적화에서는 초기화, 모멘텀 등의 기법이 필요하다.

---

### 함정 5: 학습률을 키우면 항상 더 빠르게 수렴한다

**반례:** $f(x) = x^2$에서 $f'(x) = 2x$, 업데이트: $x_{t+1} = x_t - 2\eta x_t = (1 - 2\eta)x_t$

- $\eta = 0.5$: $x_{t+1} = 0$ → 한 번에 수렴 (이상적)
- $\eta = 0.8$: $x_{t+1} = -0.6 x_t$ → 진동하며 수렴
- $\eta = 1.0$: $x_{t+1} = -x_t$ → 진동, 수렴하지 않음
- $\eta = 1.5$: $x_{t+1} = -2x_t$ → **발산**

> **교훈:** 학습률은 $\eta < 1/L$ (여기서 $L$은 립시츠 상수)를 만족해야 수렴이 보장된다.

## 8. 시험형 서술 문제와 모범답안

### 문제 1: Fermat 정리를 증명하라

**문제:** "함수 $f$가 점 $a$에서 미분가능하고, $f$가 $a$에서 극솟값을 가지면 $f'(a) = 0$임을 증명하라."

**모범답안:**

$f$가 $a$에서 극솟값을 가지므로, 어떤 $\delta > 0$이 존재하여

$$f(x) \geq f(a), \quad \forall x \in (a - \delta, a + \delta) \quad \cdots (\star)$$

$f$가 $a$에서 미분가능하므로 극한 $f'(a) = \lim_{h \to 0} \dfrac{f(a+h) - f(a)}{h}$가 존재한다.

**우극한을 고려하자.** $0 < h < \delta$이면, $(\star)$에 의해 $f(a+h) - f(a) \geq 0$이고 $h > 0$이므로:

$$\frac{f(a+h) - f(a)}{h} \geq 0$$

극한의 부등식 보존에 의해:

$$f'(a) = \lim_{h \to 0^+} \frac{f(a+h) - f(a)}{h} \geq 0 \quad \cdots (1)$$

**좌극한을 고려하자.** $-\delta < h < 0$이면, $(\star)$에 의해 $f(a+h) - f(a) \geq 0$이고 $h < 0$이므로:

$$\frac{f(a+h) - f(a)}{h} \leq 0$$

극한의 부등식 보존에 의해:

$$f'(a) = \lim_{h \to 0^-} \frac{f(a+h) - f(a)}{h} \leq 0 \quad \cdots (2)$$

$(1)$과 $(2)$를 결합하면: $0 \leq f'(a) \leq 0$, 따라서 $f'(a) = 0$. $\blacksquare$

### 문제 2: 함수의 임계점을 구하고 극값 유형을 판별하라

**문제:** "$f(x, y) = 2x^3 + 6xy^2 - 3y^3 - 150x$의 모든 임계점을 구하고, 각 임계점이 극대, 극소, 안장점 중 무엇인지 판별하라."

**모범답안:**

**Step 1: 임계점 구하기**

$$f_x = 6x^2 + 6y^2 - 150 = 0 \implies x^2 + y^2 = 25 \quad \cdots (A)$$

$$f_y = 12xy - 9y^2 = 0 \implies 3y(4x - 3y) = 0 \quad \cdots (B)$$

$(B)$에서: $y = 0$ 또는 $y = \dfrac{4x}{3}$

**경우 1:** $y = 0$ → $(A)$에서 $x^2 = 25$, $x = \pm 5$

임계점: $(5, 0)$, $(-5, 0)$

**경우 2:** $y = \dfrac{4x}{3}$ → $(A)$에서 $x^2 + \dfrac{16x^2}{9} = 25$, $\dfrac{25x^2}{9} = 25$, $x^2 = 9$, $x = \pm 3$

$x = 3 \implies y = 4$: 임계점 $(3, 4)$

$x = -3 \implies y = -4$: 임계점 $(-3, -4)$

**Step 2: 헤시안 분류**

$$f_{xx} = 12x, \quad f_{yy} = 12x - 18y, \quad f_{xy} = 12y$$

$$D = f_{xx} f_{yy} - (f_{xy})^2 = 12x(12x - 18y) - 144y^2$$

**$(5, 0)$:** $D = 60(60) - 0 = 3600 > 0$, $f_{xx} = 60 > 0$ → **극소**

**$(-5, 0)$:** $D = (-60)(-60) - 0 = 3600 > 0$, $f_{xx} = -60 < 0$ → **극대**

**$(3, 4)$:** $f_{xx} = 36$, $f_{yy} = 36 - 72 = -36$, $f_{xy} = 48$

$D = 36(-36) - 48^2 = -1296 - 2304 = -3600 < 0$ → **안장점**

**$(-3, -4)$:** $f_{xx} = -36$, $f_{yy} = -36 + 72 = 36$, $f_{xy} = -48$

$D = (-36)(36) - (-48)^2 = -1296 - 2304 = -3600 < 0$ → **안장점**

**결론:**

| 임계점 | $D$ | $f_{xx}$ | 유형 |
|--------|-----|----------|------|
| $(5, 0)$ | $3600 > 0$ | $60 > 0$ | 극소 |
| $(-5, 0)$ | $3600 > 0$ | $-60 < 0$ | 극대 |
| $(3, 4)$ | $-3600 < 0$ | — | 안장점 |
| $(-3, -4)$ | $-3600 < 0$ | — | 안장점 |

$\blacksquare$

### 문제 3: 볼록 함수에서 극소 = 전역 최소를 증명하라

**문제:** "$f : \mathbb{R}^n \to \mathbb{R}$가 볼록 함수이고 $\mathbf{x}^*$가 $f$의 국소 최솟값이면, $\mathbf{x}^*$는 전역 최솟값임을 증명하라."

**모범답안:**

$\mathbf{x}^*$가 국소 최솟값이므로, 어떤 $\delta > 0$이 존재하여:

$$f(\mathbf{x}^*) \leq f(\mathbf{x}), \quad \forall \mathbf{x} \in B_\delta(\mathbf{x}^*) \quad \cdots (\star)$$

**귀류법.** $\mathbf{x}^*$가 전역 최솟값이 아니라 가정하자. 그러면 어떤 $\mathbf{y} \in \mathbb{R}^n$이 존재하여 $f(\mathbf{y}) < f(\mathbf{x}^*)$.

$t \in (0, 1)$에 대해 $\mathbf{z}_t = t\mathbf{y} + (1-t)\mathbf{x}^*$로 놓자.

$f$의 볼록성에 의해:

$$f(\mathbf{z}_t) \leq tf(\mathbf{y}) + (1-t)f(\mathbf{x}^*) < tf(\mathbf{x}^*) + (1-t)f(\mathbf{x}^*) = f(\mathbf{x}^*)$$

(두 번째 부등식은 $f(\mathbf{y}) < f(\mathbf{x}^*)$에 의해 성립.)

한편, $\|\mathbf{z}_t - \mathbf{x}^*\| = t\|\mathbf{y} - \mathbf{x}^*\|$이므로, $t < \dfrac{\delta}{\|\mathbf{y} - \mathbf{x}^*\|}$로 충분히 작게 택하면 $\mathbf{z}_t \in B_\delta(\mathbf{x}^*)$.

그런데 $f(\mathbf{z}_t) < f(\mathbf{x}^*)$이므로, 이는 $(\star)$에 모순.

따라서 $\mathbf{x}^*$는 전역 최솟값이다. $\blacksquare$

### 문제 4: Gradient Descent를 수행하고 수렴 과정을 분석하라

**문제:** "$f(x, y) = x^2 + 2y^2$에 대해, 초기점 $(x_0, y_0) = (4, 2)$, 학습률 $\eta = 0.1$로 gradient descent를 3회 반복하라. 수렴 방향과 속도를 논하라."

**모범답안:**

$$\nabla f(x, y) = \begin{pmatrix} 2x \\ 4y \end{pmatrix}$$

업데이트: $\begin{pmatrix} x_{t+1} \\ y_{t+1} \end{pmatrix} = \begin{pmatrix} x_t \\ y_t \end{pmatrix} - 0.1 \begin{pmatrix} 2x_t \\ 4y_t \end{pmatrix} = \begin{pmatrix} 0.8 x_t \\ 0.6 y_t \end{pmatrix}$

**Step 0:** $(x_0, y_0) = (4, 2)$, $f = 16 + 8 = 24$

**Step 1:** $(x_1, y_1) = (0.8 \times 4, \; 0.6 \times 2) = (3.2, \; 1.2)$, $f = 10.24 + 2.88 = 13.12$

**Step 2:** $(x_2, y_2) = (0.8 \times 3.2, \; 0.6 \times 1.2) = (2.56, \; 0.72)$, $f = 6.5536 + 1.0368 = 7.5904$

**Step 3:** $(x_3, y_3) = (0.8 \times 2.56, \; 0.6 \times 0.72) = (2.048, \; 0.432)$, $f = 4.1943 + 0.3732 = 4.5675$

| $t$ | $x_t$ | $y_t$ | $f(x_t, y_t)$ |
|-----|--------|--------|----------------|
| 0 | 4 | 2 | 24 |
| 1 | 3.2 | 1.2 | 13.12 |
| 2 | 2.56 | 0.72 | 7.5904 |
| 3 | 2.048 | 0.432 | 4.5675 |

**수렴 분석:**

- $x$-방향 수렴 비율: $|1 - 2\eta \cdot 1| = |1 - 0.2| = 0.8$
- $y$-방향 수렴 비율: $|1 - 2\eta \cdot 2| = |1 - 0.4| = 0.6$

$y$-방향의 곡률이 더 크므로 ($\partial^2 f / \partial y^2 = 4 > \partial^2 f / \partial x^2 = 2$), $y$-방향이 더 빠르게 수렴한다. $x$-방향이 수렴의 **병목**(bottleneck)이 된다.

이는 조건수(condition number) $\kappa = \lambda_{\max}/\lambda_{\min} = 4/2 = 2$에 의해 설명된다. 조건수가 클수록 방향별 수렴 속도 차이가 커져 "지그재그" 경로가 나타난다. $\blacksquare$

### 문제 5: 2차 미분 판정법이 실패하는 경우를 논하라

**문제:** "2차 미분 판정법이 적용 불가능한 함수의 예를 들고, 해당 임계점의 유형을 다른 방법으로 판별하라."

**모범답안:**

**예시 1:** $f(x) = x^4$

$f'(x) = 4x^3$, $f'(0) = 0$ → $x = 0$은 임계점.

$f''(x) = 12x^2$, $f''(0) = 0$ → 2차 미분 판정법 **적용 불가**.

**대안적 판별:** $f(x) = x^4 \geq 0 = f(0)$이 모든 $x$에 대해 성립하므로, $x = 0$은 전역 최솟값 (따라서 극소).

또는 고차 미분: $f'''(0) = 0$, $f^{(4)}(0) = 24 > 0$. 0이 아닌 최소 차수의 도함수가 짝수 차수이고 양수이므로 극소.

**예시 2:** $f(x) = x^3$

$f'(0) = 0$, $f''(0) = 0$ → 판정 불가.

$f'''(0) = 6 \neq 0$이고 차수가 홀수 → 극값이 아닌 **변곡점**.

직접 확인: $f(x) = x^3$은 $x < 0$에서 음, $x > 0$에서 양이므로 극값이 아니다.

**예시 3 (2변수):** $f(x, y) = x^2 y^2$

$\nabla f = (2xy^2, 2x^2y)^T$, $(0, 0)$에서 $\nabla f = \mathbf{0}$.

$$H(0,0) = \begin{pmatrix} 2y^2 & 4xy \\ 4xy & 2x^2 \end{pmatrix}\Bigg|_{(0,0)} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$$

헤시안이 영행렬 → 판정 불가.

직접 확인: $f(x, y) = x^2 y^2 \geq 0 = f(0, 0)$이 모든 $(x, y)$에 대해 성립하므로, $(0, 0)$은 **전역 최솟값**.

**일반적 전략:** 2차 미분 판정법이 실패하면
1. 고차 미분을 조사한다 (1변수)
2. 함숫값을 직접 비교한다 ($f(\mathbf{x}^* + \mathbf{h}) - f(\mathbf{x}^*)$의 부호)
3. 정의를 직접 적용한다

$\blacksquare$

### 문제 6: Gradient Descent의 수렴 조건과 학습률의 관계를 서술하라

**문제:** "경사 하강법의 수렴이 학습률에 어떻게 의존하는지 설명하고, $f(x) = ax^2$ ($a > 0$)에 대해 수렴 조건을 유도하라."

**모범답안:**

$f(x) = ax^2$에 대해 $f'(x) = 2ax$.

Gradient descent 업데이트:

$$x_{t+1} = x_t - \eta \cdot 2ax_t = (1 - 2a\eta)x_t$$

따라서:

$$x_t = (1 - 2a\eta)^t x_0$$

$x_t \to 0$ (최솟값)으로 수렴하려면:

$$|1 - 2a\eta| < 1$$

$$-1 < 1 - 2a\eta < 1$$

$$0 < 2a\eta < 2$$

$$0 < \eta < \frac{1}{a}$$

여기서 $a = f''(x)/2$이고, $L = 2a$는 그레이디언트 $f'(x) = 2ax$의 립시츠 상수이므로, 수렴 조건은:

$$\boxed{\eta < \frac{1}{a} = \frac{2}{L}}$$

**분석:**

- $\eta = \dfrac{1}{2a}$: $1 - 2a\eta = 0$ → **한 번에 수렴** (이상적)
- $0 < \eta < \dfrac{1}{2a}$: $0 < 1 - 2a\eta < 1$ → **단조 수렴** (진동 없이)
- $\dfrac{1}{2a} < \eta < \dfrac{1}{a}$: $-1 < 1 - 2a\eta < 0$ → **진동하면서 수렴**
- $\eta = \dfrac{1}{a}$: $1 - 2a\eta = -1$ → $x_t$가 부호만 바뀌며 **수렴하지 않음**
- $\eta > \dfrac{1}{a}$: $|1 - 2a\eta| > 1$ → **발산**

**다변수 확장:** $f(\mathbf{x}) = \dfrac{1}{2}\mathbf{x}^T A \mathbf{x}$ ($A$ 양정치)에서, $A$의 고유값이 $0 < \lambda_1 \leq \cdots \leq \lambda_n$이면, 수렴 조건은 $\eta < \dfrac{2}{\lambda_n}$이고, 최적 수렴 속도는 $\eta = \dfrac{2}{\lambda_1 + \lambda_n}$에서 달성되며, 수렴 비율은 $\dfrac{\kappa - 1}{\kappa + 1}$이다 ($\kappa = \lambda_n / \lambda_1$: 조건수). $\blacksquare$

### 문제 7: 다변수 Fermat 정리를 증명하라

**문제:** "$f : \mathbb{R}^n \to \mathbb{R}$가 $\mathbf{x}^*$에서 미분가능하고 극소를 가지면 $\nabla f(\mathbf{x}^*) = \mathbf{0}$임을 증명하라."

**모범답안:**

임의의 $\mathbf{v} \in \mathbb{R}^n$을 고정하자. 함수 $g : \mathbb{R} \to \mathbb{R}$를

$$g(t) = f(\mathbf{x}^* + t\mathbf{v})$$

로 정의한다.

$\mathbf{x}^*$가 $f$의 극소이므로, 어떤 $\delta > 0$에 대해 $\|\mathbf{x} - \mathbf{x}^*\| < \delta$이면 $f(\mathbf{x}) \geq f(\mathbf{x}^*)$.

$|t| < \delta / \|\mathbf{v}\|$ (단, $\mathbf{v} \neq \mathbf{0}$)이면 $\|\mathbf{x}^* + t\mathbf{v} - \mathbf{x}^*\| = |t|\|\mathbf{v}\| < \delta$이므로:

$$g(t) = f(\mathbf{x}^* + t\mathbf{v}) \geq f(\mathbf{x}^*) = g(0)$$

따라서 $t = 0$은 $g$의 극소이다.

$f$가 $\mathbf{x}^*$에서 미분가능하므로, 연쇄법칙에 의해:

$$g'(0) = \nabla f(\mathbf{x}^*)^T \mathbf{v}$$

1변수 Fermat 정리에 의해 $g'(0) = 0$이므로:

$$\nabla f(\mathbf{x}^*)^T \mathbf{v} = 0$$

이것이 모든 $\mathbf{v} \in \mathbb{R}^n$에 대해 성립한다. ($\mathbf{v} = \mathbf{0}$이면 자명하게 성립.)

특히 $\mathbf{v} = \mathbf{e}_i$ ($i$번째 표준 기저벡터)를 대입하면:

$$\frac{\partial f}{\partial x_i}(\mathbf{x}^*) = \nabla f(\mathbf{x}^*)^T \mathbf{e}_i = 0, \quad i = 1, 2, \ldots, n$$

따라서 $\nabla f(\mathbf{x}^*) = \mathbf{0}$. $\blacksquare$
