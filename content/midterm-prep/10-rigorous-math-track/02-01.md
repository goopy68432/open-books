# 초급 엄밀 수학 학습자료

## 문서 목적
이 문서는 “직관은 이해하지만 수학적으로는 아직 불안한 상태”를 벗어나기 위한 초급용 자료다. 초급이라고 해도 요약만 하지 않는다. 정의를 정확히 쓰고, 가장 짧고 핵심적인 증명을 통해 논리 구조를 익히는 것이 목표다.

## 공통 읽기 규칙
- 각 장에서 먼저 정의를 직접 써 본다.
- 그 다음 “왜 이런 정의가 필요한가”를 확인한다.
- 마지막으로 짧은 증명과 기본 예제를 손으로 풀어 본다.

---

## Part 1. 선형대수 기초

### 1. 벡터와 행렬
- 정의
  - 벡터는 체 위의 원소들로 이루어진 순서 있는 배열이다.
  - 행렬은 선형사상을 좌표계에서 표현한 배열이다.
- 왜
  - 딥러닝에서 데이터, 가중치, 특징량은 좌표를 가진 대상이므로 벡터와 행렬로 표현된다.
- 어디에 쓰이는가
  - 완전연결층, 임베딩, 선형변환, attention score 계산
- 핵심 공식
  - `y = Ax`
- 예제
  - `A = [[1,2],[3,4]]`, `x = [1,1]^T` 일 때 `Ax = [3,7]^T`
- 시험형 문제
  - 벡터와 행렬의 정의를 쓰고, 왜 행렬이 선형변환의 좌표 표현인지 설명하라.

### 2. 내적
- 정의
  - 실벡터공간에서 내적은 양의 정부호, 대칭성, 선형성을 만족하는 함수 `⟨·,·⟩`
- 왜
  - 길이와 각도 개념을 만들기 위해 필요하다.
- 어디에 쓰이는가
  - 유사도, 뉴런 출력, attention의 score
- 핵심 정리
  - `||x||^2 = ⟨x,x⟩`
- 짧은 증명
  - 양의 정부호 정의에 의해 `x != 0`이면 `⟨x,x⟩ > 0`
- 예제
  - `x=(1,2)`, `y=(3,4)` 이면 `⟨x,y⟩ = 11`
- 시험형 문제
  - 내적의 공리를 쓰고 노름 정의를 유도하라.

### 3. 행렬 곱셈과 선형변환
- 정의
  - 행렬 곱 `AB`는 선형변환의 합성 `x -> A(Bx)`를 좌표로 표현한 것이다.
- 왜
  - 여러 층의 변환을 한 번의 식으로 다루기 위해 필요하다.
- 핵심 정리
  - 행렬 곱셈은 결합법칙을 만족한다.
- 증명 아이디어
  - 임의의 벡터 `x`에 대해 `(AB)Cx = A(BCx)`를 보이면 된다.
- 예제
  - 두 2x2 행렬을 곱하고, 어떤 순서가 가능한지 차원으로 판정한다.
- 시험형 문제
  - 행렬 곱셈이 선형변환의 합성에 대응함을 보이라.

### 4. 역행렬
- 정의
  - `AA^{-1} = A^{-1}A = I`
- 핵심 정리
  - 역행렬이 존재하면 유일하다.
- 짧은 증명
  - `AB=I`, `CA=I`이면 `B = IB = (CA)B = C(AB) = CI = C`
- 시험형 문제
  - 가역행렬의 역행렬이 유일함을 증명하라.

## Part 2. 벡터공간, 기저, 차원

### 5. 벡터공간 공리
- 정의
  - 덧셈과 스칼라곱이 닫혀 있고, 결합법칙, 항등원, 역원, 분배법칙 등을 만족하는 집합
- 왜
  - “계산 가능한 공간”의 최소 조건을 제공한다.
- 시험형 문제
  - 주어진 집합이 벡터공간인지 공리로 판정하라.

### 6. 선형 결합, 스팬, 선형 독립
- 정의
  - 선형 결합: `a_1v_1 + ... + a_kv_k`
  - 스팬: 가능한 모든 선형 결합의 집합
  - 선형 독립: `a_1v_1 + ... + a_kv_k = 0` 이면 모든 계수가 0
- 왜
  - 공간을 생성하고 중복 없는 표현을 만들기 위해
- 예제
  - `e_1, e_2`가 `R^2`를 span하며 선형 독립임을 확인
- 시험형 문제
  - 주어진 벡터들이 선형 독립인지 판정하라.

### 7. 기저와 차원
- 정의
  - 기저는 span하면서 선형 독립인 집합
  - 차원은 기저의 원소 수
- 핵심 정리
  - 유한차원 공간의 모든 기저는 같은 개수의 원소를 가진다.
- 초급 수준 증명 방향
  - 교환정리의 아이디어를 설명하고 결과를 받아들인다.
- 시험형 문제
  - 기저와 차원의 정의를 쓰고 `R^3`의 표준기저를 제시하라.

### 8. 부분공간
- 정의
  - 0벡터를 포함하고 덧셈과 스칼라곱에 닫힌 부분집합
- 짧은 증명
  - 부분공간 판정은 세 조건 확인으로 충분하다.
- 시험형 문제
  - 주어진 집합이 부분공간인지 판정하고 이유를 써라.

## Part 3. 이미지, 커널, 랭크-널리티

### 9. 이미지와 커널
- 정의
  - `Im(T) = {T(x) | x in V}`
  - `Ker(T) = {x in V | T(x)=0}`
- 왜
  - 선형변환이 어떤 방향을 보존하고 어떤 정보를 잃는지 알기 위해
- 핵심 정리
  - 이미지와 커널은 부분공간이다.
- 짧은 증명
  - 선형성을 이용해 닫힘을 보이면 된다.
- 시험형 문제
  - 선형사상 `T`에 대해 `Ker(T)`가 부분공간임을 보여라.

### 10. 랭크-널리티 정리
- 정리
  - `dim(V) = rank(T) + nullity(T)`
- 왜
  - 보존되는 자유도와 사라지는 자유도의 합이 전체 차원이라는 뜻
- 어디에 쓰이는가
  - 연립방정식의 해공간 차원 계산, 병목 구조 이해
- 시험형 문제
  - 랭크와 널리티를 정의하고 정리를 진술하라.

---

## Part 4. 고유값, 고유벡터, SVD

### 11. 고유값과 고유벡터
- 정의
  - `Av = lambda v`, `v != 0`
- 왜
  - 변환이 공간을 “어떤 고정 방향”으로 작용하는지 파악하기 위해
- 핵심 공식
  - `det(A - lambda I)=0`
- 시험형 문제
  - 고유값과 고유벡터를 정의하고 특성방정식을 써라.

### 12. 직교행렬, 대칭행렬, PD/PSD
- 정의
  - 직교행렬: `Q^TQ=I`
  - PD: 모든 `x != 0`에 대해 `x^TAx > 0`
- 어디에 쓰이는가
  - 거리 보존, 공분산, 최적화의 곡률 해석
- 시험형 문제
  - PD와 PSD의 차이를 설명하라.

### 13. SVD
- 정의
  - `A = U Sigma V^T`
- 왜
  - 모든 행렬을 안정적으로 분해하고 중요한 방향만 남길 수 있다.
- 어디에 쓰이는가
  - 이미지 압축, PCA, 추천시스템
- 시험형 문제
  - SVD의 형태를 쓰고 각 행렬의 의미를 설명하라.

### 14. PageRank
- 핵심 아이디어
  - 링크 그래프를 전이행렬로 만들고 주 고유벡터를 찾는다.
- 시험형 문제
  - 왜 PageRank가 고유벡터 문제인지 설명하라.

## Part 5. 미분과 최적화

### 15. 도함수와 편미분
- 정의
  - 도함수는 변화율의 극한
  - 편미분은 여러 변수 중 하나만 변화시킬 때의 변화율
- 왜
  - 손실 함수의 감소 방향을 찾기 위해
- 시험형 문제
  - 편미분의 정의를 쓰고 간단한 함수를 계산하라.

### 16. 그레이디언트, 자코비안, 헤시안
- 정의
  - Gradient: 스칼라함수의 1차 미분 벡터
  - Jacobian: 벡터함수의 1차 미분 행렬
  - Hessian: 스칼라함수의 2차 미분 행렬
- 어디에 쓰이는가
  - 최적화, 역전파, 곡률 분석
- 시험형 문제
  - Gradient, Jacobian, Hessian을 각각 정의하라.

### 17. 체인 룰
- 정리
  - 합성함수의 미분은 바깥 미분과 안쪽 미분의 곱
- 왜
  - 역전파의 핵심
- 시험형 문제
  - 체인 룰을 쓰고 `f(g(x))`의 미분을 계산하라.

### 18. 선형 근사와 뉴턴 방법
- 핵심 공식
  - `f(x) ≈ f(a) + f'(a)(x-a)`
  - `x_{n+1} = x_n - f(x_n)/f'(x_n)`
- 어디에 쓰이는가
  - 근 찾기, 최적화, 복잡한 함수의 국소 해석

### 19. 최적화 기초
- 정의
  - 임계점, 국소 최소, 국소 최대, 안장점
- 핵심 정리
  - Fermat 정리: 내부 극값점에서 미분가능하면 도함수는 0
- 시험형 문제
  - Fermat 정리를 서술하라.

## Part 6. 확률론 기초

### 20. 표본공간, 사건, 확률측도
- 정의
  - 표본공간 `Omega`, 사건 `A subset Omega`, 확률 `P`
- 왜
  - 불확실성을 수학적으로 다루기 위해
- 시험형 문제
  - 표본공간과 사건의 정의를 쓰고 예를 들어라.

### 21. 조건부 확률과 독립
- 정의
  - `P(A|B) = P(A cap B) / P(B)`
  - 독립: `P(A cap B) = P(A)P(B)`
- 시험형 문제
  - 조건부 확률과 독립의 차이를 설명하라.

### 22. 확률변수와 분포
- 정의
  - 확률변수는 표본공간에서 실수로 가는 함수
- 핵심 용어
  - PMF, PDF, CDF, 기댓값, 분산
- 시험형 문제
  - 확률변수의 정의를 사건의 역상 관점에서 설명하라.

### 23. Bernoulli와 Gaussian
- 핵심 공식
  - Bernoulli: `P(X=1)=theta`, `P(X=0)=1-theta`
  - Gaussian: `N(mu, sigma^2)`
- 어디에 쓰이는가
  - 이진 분류, 노이즈 모델링, 중심극한정리

### 24. 중심극한정리
- 핵심 메시지
  - 독립동일분포의 합은 적절한 정규화 후 가우시안으로 수렴
- 시험형 문제
  - 중심극한정리의 의미를 설명하라.

## Part 7. 베이즈 정리와 추정

### 25. 베이즈 정리
- 공식
  - `P(H|E) = P(E|H)P(H) / P(E)`
- 왜
  - 관측 후 믿음을 업데이트하기 위해
- 시험형 문제
  - 베이즈 정리를 쓰고 항들의 의미를 설명하라.

### 26. MLE와 MAP
- 정의
  - MLE: 우도를 최대화하는 추정
  - MAP: 사후확률을 최대화하는 추정
- 차이
  - MAP는 prior를 반영한다.
- 시험형 문제
  - MLE와 MAP의 차이를 말하라.

### 27. 생성모델과 판별모델
- 핵심 구분
  - 생성모델은 `P(x,y)` 또는 `P(x)`를 다루고, 판별모델은 `P(y|x)`를 다룬다.
- 시험형 문제
  - 이미지 분류에서 판별모델 관점을 설명하라.

## Part 8. 딥러닝 응용 연결

### 28. Softmax
- 정의
  - `softmax(z_i) = exp(z_i) / sum_j exp(z_j)`
- 왜
  - 실수 벡터를 확률분포로 바꾼다.
- 시험형 문제
  - Softmax가 왜 확률분포를 만드는지 설명하라.

### 29. Attention
- 핵심 구조
  - query와 key의 내적을 점수로 쓰고 value를 가중합한다.
- 어디에 쓰이는가
  - 트랜스포머, 언어모델
- 시험형 문제
  - attention 계산에서 내적이 왜 필요한지 설명하라.
