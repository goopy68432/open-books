## 3. 증명 골격 템플릿

### 3.1 부분공간 판정 정리
답안 틀:
1. 0벡터가 포함됨을 보인다.
2. 덧셈에 대해 닫힘을 보인다.
3. 스칼라곱에 대해 닫힘을 보인다.
4. 세 조건이 성립하므로 부분공간이다.

### 3.2 역행렬 유일성
답안 틀:
1. `AB=I`, `CA=I`라 둔다.
2. `B = IB = (CA)B = C(AB) = CI = C`
3. 따라서 역행렬은 유일하다.

### 3.3 랭크-널리티 정리
답안 틀:
1. 커널의 기저를 잡는다.
2. 이를 전체 공간의 기저로 확장한다.
3. 확장한 나머지 벡터들의 상이 이미지를 생성함을 보인다.
4. 그 상들이 선형독립임을 보인다.
5. 차원 공식을 결론으로 쓴다.

### 3.4 서로 다른 고유값의 고유벡터 선형독립성
답안 틀:
1. 선형결합이 0이라 가정한다.
2. 행렬 `A`를 한 번 작용시킨 식을 만든다.
3. 원래 식의 적절한 상수배를 빼서 마지막 벡터를 제거한다.
4. 귀납법을 사용한다.

### 3.5 Fermat 정리
답안 틀:
1. 국소 최소 또는 최대의 정의를 쓴다.
2. 차분몫의 부호를 좌우에서 비교한다.
3. 좌우도함수의 부호가 반대 방향에서 제한됨을 쓴다.
4. 미분가능성을 이용해 둘이 같아야 하므로 0이라는 결론을 낸다.

### 3.6 베이즈 정리
답안 틀:
1. 조건부 확률 정의 두 개를 쓴다.
2. 공통항 `P(H cap E)`를 제거한다.
3. 정리 공식을 정리한다.

### 3.7 Bernoulli 평균과 분산
답안 틀:
1. 평균 정의에 PMF를 넣는다.
2. `X^2=X`를 사용한다.
3. `Var(X)=E[X^2]-(E[X])^2`를 계산한다.

### 3.8 체인 룰
답안 틀:
1. 합성함수 정의를 쓴다.
2. 차분몫을 안쪽 변화량과 바깥 함수 변화량으로 분해한다.
3. 각각의 극한을 취한다.

### 3.9 Softmax 미분
답안 틀:
1. `s_i = e^{z_i} / sum_k e^{z_k}`를 둔다.
2. 분자와 분모를 각각 미분한다.
3. 몫의 미분 또는 로그 미분 형태로 정리한다.
4. `i=j`, `i!=j` 두 경우를 나눠 쓴다.

## 4. 계산형 문제 풀이 템플릿

### 4.1 고유값 문제
1. `det(A-lambda I)=0`을 세운다.
2. 특성다항식을 전개한다.
3. 근을 구한다.
4. 각 고유값에 대해 `(A-lambda I)v=0`을 풀어 고유벡터를 구한다.
5. 대각화 가능성은 고유벡터 개수와 차원으로 판단한다.

### 4.2 랭크와 널리티 문제
1. 행렬을 가우스 소거한다.
2. 피벗 개수를 세어 랭크를 구한다.
3. `nullity = 열의 수 - rank`를 적용한다.

### 4.3 Bernoulli MLE 문제
1. 우도함수를 쓴다.
2. 로그우도로 바꾼다.
3. 미분해 0으로 둔다.
4. 최대점 여부를 확인하거나 자연스럽게 결론을 쓴다.

### 4.4 뉴턴 방법 문제
1. 함수와 도함수를 계산한다.
2. `x_{n+1} = x_n - f(x_n)/f'(x_n)`를 쓴다.
3. 수치를 대입해 한 단계씩 갱신한다.

### 4.5 Softmax 미분 문제
1. 출력 벡터를 정의한다.
2. 한 성분을 기준으로 분자와 분모를 구분한다.
3. 경우를 나눠 편미분을 계산한다.
4. Jacobian 꼴로 정리한다.

## 5. 대표 서술형 문제와 모범 답안 방향

### 문제 1
행렬 곱셈이 선형변환의 합성에 대응함을 증명하라.

답안 방향:
- 두 선형변환의 좌표행렬을 `A`, `B`라 둔다.
- 기저벡터에 대한 작용을 비교한다.
- `T(S(e_j)) = A(Be_j) = (AB)e_j`를 보여 합성의 좌표행렬이 `AB`임을 결론낸다.

### 문제 2
랭크-널리티 정리를 진술하고 증명하라.

답안 방향:
- 커널 기저 선택
- 전체 공간 기저로 확장
- 확장된 벡터의 상이 이미지의 기저임을 보임
- 차원 합 공식 결론

### 문제 3
서로 다른 고유값에 대응하는 고유벡터들이 선형독립임을 증명하라.

답안 방향:
- 선형결합 0 가정
- `A` 적용
- 적절히 빼서 항 제거
- 귀납법 마무리

### 문제 4
조건부 확률의 정의로부터 베이즈 정리를 유도하라.

답안 방향:
- `P(H|E)=P(H∩E)/P(E)`
- `P(E|H)=P(H∩E)/P(H)`
- `P(H∩E)=P(E|H)P(H)`
- 대입해 정리

### 문제 5
Bernoulli 분포의 평균과 분산을 유도하라.

답안 방향:
- PMF를 쓰고 평균 계산
- `X^2=X` 이용
- 분산 공식으로 정리

### 문제 6
그레이디언트가 최대 증가 방향임을 증명하라.

답안 방향:
- 방향도함수 식 `D_u f = grad f · u`
- 코시-슈바르츠 적용
- 등호 조건으로 최대 방향을 제시

### 문제 7
소프트맥스가 확률분포를 만드는 이유와 미분 공식을 설명하라.

답안 방향:
- 각 성분의 양수성
- 합이 1임을 보여 확률분포 확인
- 편미분은 경우 분리 후 Jacobian 형태로 정리

## 6. 모의문제 세트

### A. 정의형
1. 벡터공간, 선형독립, 기저를 각각 정의하라.
2. 조건부 확률과 독립을 각각 정의하고 차이를 설명하라.
3. Gradient, Jacobian, Hessian을 정의하라.

### B. 증명형
1. 부분공간 판정 정리를 증명하라.
2. 역행렬의 유일성을 증명하라.
3. Fermat 정리를 증명하라.
4. 베이즈 정리를 조건부 확률 정의에서 유도하라.

### C. 유도형
1. 특성방정식 `det(A-lambda I)=0`가 나오는 이유를 설명하라.
2. 뉴턴 방법 공식을 1차 테일러 전개에서 유도하라.
3. Bernoulli MLE를 유도하라.
4. Softmax 미분 공식을 유도하라.

### D. 계산형
1. 주어진 2x2 행렬의 고유값과 고유벡터를 구하라.
2. 주어진 행렬의 랭크와 널리티를 구하라.
3. 주어진 Bernoulli 표본으로 MLE와 MAP를 비교 계산하라.
4. 한 단계 뉴턴 업데이트를 계산하라.

### E. 응용형
1. PageRank가 왜 고유벡터 문제인지 설명하라.
2. SVD가 왜 이미지 압축에 적합한지 설명하라.
3. Softmax와 cross-entropy가 분류 문제에 적합한 이유를 설명하라.
4. 생성모델과 판별모델을 확률식으로 비교하라.

## 7. 시험 직전 체크리스트
- 정의를 애매한 한국어가 아니라 수학 문장으로 말할 수 있는가
- 정리를 가정과 결론으로 분리해 말할 수 있는가
- 핵심 증명을 골격만 보고 재현할 수 있는가
- 공식 유도 과정에서 출발 정의를 알고 있는가
- 계산형 문제에서 중간 전개를 생략하지 않는가
- 응용형 문제를 직관이 아니라 정리 결과로 설명할 수 있는가
