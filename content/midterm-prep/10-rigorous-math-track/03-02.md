# 중급 엄밀 수학 학습자료

## 문서 목적
이 문서는 엄밀한 수학 트랙의 표준 본문이다. 초급 문서가 용어와 기본 직관을 세우는 문서라면, 이 문서는 정리의 정확한 진술, 공식 유도, 표준 증명, 계산형 예제와 단계별 풀이를 담당한다.

## Part 1. 선형대수의 표준 정리

### 1. 내적 공간
#### 정의
실벡터공간 `V`에서 함수 `⟨·,·⟩ : V x V -> R`가 다음을 만족하면 내적이라 한다.
1. 대칭성: `⟨x,y⟩ = ⟨y,x⟩`
2. 선형성: `⟨ax+by,z⟩ = a⟨x,z⟩ + b⟨y,z⟩`
3. 양의 정부호성: `x != 0`이면 `⟨x,x⟩ > 0`

#### 정리
`||x|| = sqrt(⟨x,x⟩)`는 노름을 정의한다.

#### 증명 골격
- `||x|| >= 0`는 양의 정부호성에서 즉시 나온다.
- `||x|| = 0`이면 `⟨x,x⟩ = 0`, 따라서 `x=0`
- 스칼라배에 대한 동차성과 삼각부등식은 추가 정리로 보인다.

#### 예제
표준 내적 `⟨x,y⟩ = x^T y`가 내적 공리를 만족함을 직접 확인하라.

### 2. 행렬 곱셈과 선형사상
#### 정리
선형사상 `T: R^n -> R^m`, `S: R^p -> R^n`에 대해 좌표행렬을 각각 `A`, `B`라 하면 `T o S`의 좌표행렬은 `AB`이다.

#### 증명
기저벡터 `e_j`에 대해
`S(e_j)`의 좌표가 `B`의 `j`번째 열이고,
`T(S(e_j)) = A(Be_j) = (AB)e_j`이다.
모든 기저벡터에 대해 성립하므로 합성의 좌표행렬은 `AB`.

#### 계산형 예제
`A=[[1,2],[0,1]]`, `B=[[2,0],[1,3]]`에 대해 `AB`와 `BA`를 계산하고 왜 다른지 설명하라.

### 3. 역행렬의 유일성
#### 정리
행렬 `A`가 역행렬을 가지면 그 역행렬은 유일하다.

#### 증명
`AB=I`, `CA=I`라 하자.
그러면
`B = IB = (CA)B = C(AB) = CI = C`
이므로 `B=C`.

## Part 2. 벡터공간, 기저, 차원

### 4. 부분공간 판정 정리
#### 정리
벡터공간 `V`의 부분집합 `W`가 부분공간이기 위한 필요충분조건은
1. `0 in W`
2. `u,v in W`이면 `u+v in W`
3. `a in F`, `u in W`이면 `au in W`

#### 왜
부분공간의 핵심은 같은 연산 규칙을 유지하는 것이다.

#### 증명
- 필요성은 정의에서 자명하다.
- 충분성은 `W`가 `V`의 연산을 그대로 물려받는다는 점을 사용한다.
- `V`의 공리들이 `W`에서 제한되어 그대로 성립한다.

#### 시험형 문제
`W = {(x,y,z) in R^3 : x+y+z=0}`가 부분공간임을 증명하라.

### 5. 기저 원소 수의 불변성
#### 정리
유한차원 벡터공간의 모든 기저는 같은 개수의 원소를 가진다.

#### 증명 전략
- Steinitz 교환정리를 이용한다.
- 선형독립 집합의 원소 수는 생성집합의 원소 수를 넘을 수 없음을 먼저 보인다.
- 두 기저는 각각 생성집합이자 선형독립 집합이므로 원소 수가 서로 크거나 같아야 한다.
- 따라서 원소 수가 같다.

#### 어디에 쓰이는가
- 차원의 정의 정당화
- 좌표 표현의 일관성

### 6. 랭크-널리티 정리
#### 정리
선형사상 `T: V -> W`가 유한차원 `V`에서 정의되면
`dim(V) = dim(Ker(T)) + dim(Im(T))`

#### 증명
1. `Ker(T)`의 기저를 `v_1,...,v_k`라 하자.
2. 이를 `V`의 기저 `v_1,...,v_k,v_{k+1},...,v_n`으로 확장한다.
3. `T(v_{k+1}),...,T(v_n)`이 `Im(T)`를 생성함을 보인다.
4. 또한 이들이 선형독립임을 보이면 `Im(T)`의 기저가 된다.
5. 따라서 `dim(Im(T)) = n-k`, 곧 `n = k + dim(Im(T))`.

#### 계산형 예제
`A = [[1,2,3],[2,4,6]]`의 랭크와 널리티를 구하라.

풀이:
1. 두 행은 종속이므로 `rank(A)=1`
2. 열의 개수는 3이므로 `nullity(A)=3-1=2`

## Part 3. 고유이론과 분해

### 7. 특성방정식 유도
`Av = lambda v`는
`(A - lambda I)v = 0`
와 동치다. 비영벡터 해가 존재하려면 `A-lambda I`가 가역이 아니어야 하므로
`det(A-lambda I)=0`
이 성립한다.

### 8. 서로 다른 고유값의 고유벡터는 선형독립
#### 정리
서로 다른 고유값 `lambda_1,...,lambda_k`에 대응하는 고유벡터 `v_1,...,v_k`는 선형독립이다.

#### 증명
귀납법을 사용한다.
`a_1v_1 + ... + a_kv_k = 0`라 하자.
양변에 `A`를 작용시키면
`a_1 lambda_1 v_1 + ... + a_k lambda_k v_k = 0`
원래 식에 `lambda_k`를 곱해 빼면
`a_1(lambda_1-lambda_k)v_1 + ... + a_{k-1}(lambda_{k-1}-lambda_k)v_{k-1}=0`
귀납가정으로 `a_1=...=a_{k-1}=0`, 다시 원래 식에 넣어 `a_k=0`.

### 9. PD 행렬의 고유값은 양수
#### 정리
실대칭행렬 `A`가 PD이면 모든 고유값은 양수이다.

#### 증명
`Av = lambda v`, `v != 0`인 고유벡터 `v`를 잡자.
그러면
`v^TAv = v^T(lambda v) = lambda v^Tv`
한편 PD이므로 `v^TAv > 0`, 또한 `v^Tv > 0`
따라서 `lambda > 0`.

### 10. SVD와 `A^TA`
#### 정리
`A^TA`는 대칭이고 PSD이며, 그 고유값은 `A`의 특이값 제곱이다.

#### 증명 요지
- 대칭성: `(A^TA)^T = A^TA`
- PSD: 임의의 `x`에 대해 `x^TA^TAx = ||Ax||^2 >= 0`
- 따라서 고유값은 모두 음이 아니다.

#### 응용
- PCA
- 저랭크 근사
- 이미지 압축

## Part 4. 미분과 최적화

### 11. 그레이디언트가 최대 증가 방향임의 증명
#### 정리
미분가능한 함수 `f: R^n -> R`에 대해 단위벡터 `u` 방향의 방향도함수 `D_u f(x)`는 `u = grad f(x) / ||grad f(x)||`일 때 최대가 된다.

#### 증명
`D_u f(x) = grad f(x)^T u`
코시-슈바르츠 부등식에 의해
`grad f(x)^T u <= ||grad f(x)|| ||u|| = ||grad f(x)||`
등호는 `u`가 `grad f(x)`와 같은 방향일 때 성립한다.

### 12. 체인 룰
#### 정리
`h(x) = f(g(x))`이면
`h'(x) = f'(g(x)) g'(x)`

#### 다변수 버전
`J_{f o g}(x) = J_f(g(x)) J_g(x)`

#### 왜
- 역전파의 핵심 계산 규칙이다.

### 13. 뉴턴 방법의 유도
함수 `f`를 점 `x_n` 근처에서 1차 테일러 전개하면
`f(x) ≈ f(x_n) + f'(x_n)(x-x_n)`
근을 찾기 위해 좌변을 0으로 두면
`0 ≈ f(x_n) + f'(x_n)(x_{n+1}-x_n)`
따라서
`x_{n+1} = x_n - f(x_n)/f'(x_n)`

### 14. Fermat 정리
#### 정리
`c`가 내부점이고 `f`가 `c`에서 미분가능하며 `f`가 `c`에서 국소 극값을 가지면 `f'(c)=0`.

#### 증명
국소최소의 경우 `h>0`에 대해
`(f(c+h)-f(c))/h >= 0`
`h<0`에 대해
`(f(c+h)-f(c))/h <= 0`
좌우극한이 존재하고 같으므로 둘 다 0이어야 한다.

## Part 5. 확률론과 베이지안 추론

### 15. 확률 공리에서 나오는 기본 정리
#### 여사건 공식
`A`와 `A^c`는 서로소이고 `A union A^c = Omega`
따라서
`1 = P(Omega) = P(A) + P(A^c)`
즉
`P(A^c)=1-P(A)`

#### 덧셈정리
`A union B = A union (B \ A)`
또는
`A union B = (A \cap B^c) union (A \cap B) union (A^c \cap B)`
를 이용해
`P(A union B)=P(A)+P(B)-P(A cap B)`

### 16. 베이즈 정리 유도
조건부 확률 정의에서
`P(H|E)=P(H cap E)/P(E)`
또한
`P(E|H)=P(H cap E)/P(H)`
이므로
`P(H cap E)=P(E|H)P(H)`
따라서
`P(H|E)=P(E|H)P(H)/P(E)`

### 17. Bernoulli 평균과 분산
`X ~ Bernoulli(theta)`라 하자.

#### 평균
`E[X] = 1*theta + 0*(1-theta) = theta`

#### 분산
`Var(X) = E[X^2] - (E[X])^2`
Bernoulli에서는 `X^2 = X`이므로
`E[X^2] = E[X] = theta`
따라서
`Var(X)=theta-theta^2 = theta(1-theta)`

### 18. MLE와 MAP
#### Bernoulli MLE
표본 `x_1,...,x_n in {0,1}`에 대해
`L(theta)=prod_i theta^{x_i}(1-theta)^{1-x_i}`
로그를 취하면
`ell(theta)=sum_i x_i log theta + sum_i (1-x_i) log(1-theta)`
미분 후 0으로 두면
`hat theta_MLE = (1/n) sum_i x_i`

#### MAP
prior `theta ~ Beta(alpha,beta)`를 두면
사후분포는
`theta | x ~ Beta(alpha + sum x_i, beta + n - sum x_i)`
따라서 MAP 추정은 prior를 반영한 형태가 된다.
