## 개념 25: MLE (최대 우도 추정, Maximum Likelihood Estimation)

### 왜 필요한가 (큰 그림에서의 위치)

딥러닝의 최종 목표는 "데이터를 잘 설명하는 모델"을 만드는 것이다. 그런데 "잘 설명한다"는 것을 어떻게 숫자로 측정할까? MLE는 이 질문에 대한 가장 기본적인 답이다. "우리가 관찰한 데이터가 나올 확률을 최대한 높게 만드는 파라미터를 골라라"가 MLE의 핵심이다. 딥러닝에서 흔히 쓰는 크로스 엔트로피 손실, MSE 손실 모두 사실 MLE에서 유도된다. 즉 MLE는 "왜 이 손실 함수를 쓰는가?"에 대한 이론적 근거이다.

### 선수 개념

- **확률**: 어떤 사건이 일어날 가능성을 0~1 사이 숫자로 나타낸 것
- **곱셈**: 독립적인 사건들이 동시에 일어날 확률 = 각 확률의 곱
- **로그(log)**: 곱셈을 덧셈으로 바꿔주는 함수. $\log(a \times b) = \log a + \log b$
- **미분**: 함수의 기울기를 구하는 것. 기울기=0인 점이 최대/최소

### 관련 문제

Q6, Q10, Q14, Q20

### 중1 눈높이 설명

**동전 던지기로 MLE 완전 이해하기**

동전 하나가 있다. 이 동전이 앞면이 나올 확률이 얼마인지 모른다. 이것을 $p$라고 부르자. $p$는 0과 1 사이의 어떤 숫자이다.

이 동전을 10번 던졌더니 7번 앞면, 3번 뒷면이 나왔다.

**질문: $p$는 얼마일까?**

직감적으로 $p = 0.7$ (= 7/10)이 맞을 것 같다. MLE는 이 직감을 수학적으로 정당화하는 방법이다.

**1단계: 우도(Likelihood) 함수 만들기**

"$p$가 이 값일 때, 10번 중 7번 앞면이 나올 확률이 얼마나 되나?"를 계산한다.

각 동전 던지기는 독립적이다 (한 번 던진 결과가 다음 결과에 영향을 주지 않는다). 독립적인 사건의 동시 확률은 곱이다.

- 앞면 1번의 확률: $p$
- 앞면이 7번 연속: $p \times p \times p \times p \times p \times p \times p = p^7$
- 뒷면 1번의 확률: $1-p$
- 뒷면이 3번 연속: $(1-p)^3$

따라서 "7번 앞면, 3번 뒷면"이 나올 확률:

$$L(p) = p^7 \times (1-p)^3$$

이것을 **우도 함수(Likelihood function)**라고 부른다. $L(p)$는 "$p$가 이 값일 때 데이터가 나올 가능성"이다.

**2단계: 우도가 최대인 $p$ 찾기**

$L(p)$를 최대로 만드는 $p$를 찾으면 된다. 즉 "데이터가 나올 가능성이 가장 큰 파라미터"를 고르는 것이다.

여기서 곱셈으로 된 식은 다루기 어려우니, 로그를 취한다:

$$\ell(p) = \log L(p) = 7\log p + 3\log(1-p)$$

왜 로그를 취해도 될까? 로그는 단조증가 함수이기 때문이다. $L(p)$가 최대인 점과 $\ell(p)$가 최대인 점이 같다.

**3단계: 미분해서 기울기=0 찾기**

$$\frac{d\ell}{dp} = \frac{7}{p} - \frac{3}{1-p} = 0$$

$\frac{7}{p} = \frac{3}{1-p}$를 풀면:

$$7(1-p) = 3p$$
$$7 - 7p = 3p$$
$$7 = 10p$$
$$p = \frac{7}{10} = 0.7$$

**결론**: MLE 추정값 $\hat{p} = 0.7$. 직감과 일치한다!

**일반화**: $n$번 던져서 $k$번 앞면이면 $\hat{p} = k/n$.

**딥러닝과의 연결**: 딥러닝에서 모델의 출력이 "데이터가 나올 확률"을 표현한다. MLE는 이 확률을 최대화하는 것 = 손실을 최소화하는 것이다. 구체적으로:

- 분류 문제: MLE → 크로스 엔트로피 손실 최소화
- 회귀 문제: 가우시안 가정 + MLE → MSE 손실 최소화

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 우도 함수 | $L(\theta) = \prod_{i=1}^{n} p(x_i \mid \theta)$ |
| 로그 우도 | $\ell(\theta) = \sum_{i=1}^{n} \log p(x_i \mid \theta)$ |
| MLE 추정 | $\hat{\theta}_{\text{MLE}} = \arg\max_{\theta} \ell(\theta)$ |
| 베르누이 MLE | $\hat{p} = k/n$ |
| 로그 변환 이유 | $\log(\prod) = \sum \log$ (곱→합) |

### 숫자로 확인

동전 5번 던지기: 앞면 3번, 뒷면 2번.

$$L(p) = p^3(1-p)^2$$

$p = 0.5$일 때: $L(0.5) = 0.5^3 \times 0.5^2 = 0.03125$

$p = 0.6$일 때: $L(0.6) = 0.6^3 \times 0.4^2 = 0.216 \times 0.16 = 0.03456$

$p = 0.7$일 때: $L(0.7) = 0.7^3 \times 0.3^2 = 0.343 \times 0.09 = 0.03087$

$p = 0.6$일 때 가장 크다! MLE 공식으로도 $\hat{p} = 3/5 = 0.6$. 일치한다.

### 다른 개념과의 연결

- **개념 27 (교차 엔트로피)**: CE 손실 최소화 = 로그 우도 최대화 = MLE와 동치
- **개념 26 (MAP)**: MLE에 사전 분포(prior)를 추가하면 MAP가 됨
- **개념 33 (정규화)**: MLE만 쓰면 과적합 위험 → prior 추가(MAP) → 정규화 등장
- **개념 30 (경사 하강법)**: MLE의 해를 닫힌 형태로 못 구할 때 경사 하강법으로 수치적으로 품

3. 로그를 취해도 최대점이 변하지 않는 이유는?

## 개념 26: MAP (최대 사후 확률 추정, Maximum A Posteriori)

### 왜 필요한가 (큰 그림에서의 위치)

MLE는 "데이터만 보고" 파라미터를 결정한다. 하지만 데이터가 적으면 MLE가 극단적인 답을 줄 수 있다 (동전 2번 던져 2번 다 앞면 → $\hat{p} = 1$?). MAP는 "데이터를 보기 전에 이미 가지고 있던 믿음(prior)"을 함께 고려한다. 이것이 딥러닝에서 정규화(regularization)가 등장하는 이론적 근거이다.

### 선수 개념

- **개념 25 (MLE)**: MAP는 MLE의 확장이므로 MLE를 먼저 이해해야 함
- **베이즈 정리**: $p(\theta|D) = \frac{p(D|\theta) \cdot p(\theta)}{p(D)}$
- **정규분포**: 종 모양 곡선, 평균 근처에 데이터가 모여 있는 분포

### 관련 문제

Q21, Q23

### 중1 눈높이 설명

**비유: 선생님의 조언을 반영한 시험 준비**

MLE는 "친구들한테 물어본 결과만 보고" 공부 범위를 정하는 것이다. MAP는 "선생님의 조언(prior)도 함께 반영"해서 공부 범위를 정하는 것이다.

**수학으로 들어가보자.**

베이즈 정리는 이렇게 생겼다:

$$p(\theta|D) = \frac{p(D|\theta) \cdot p(\theta)}{p(D)}$$

각 부분의 의미:
- $p(\theta|D)$: **사후 분포(posterior)** — 데이터를 본 후 "$\theta$가 이 값일 가능성이 얼마나 되나?"
- $p(D|\theta)$: **우도(likelihood)** — "$\theta$가 이 값일 때, 이 데이터가 나올 확률" (MLE에서 쓰던 것!)
- $p(\theta)$: **사전 분포(prior)** — 데이터를 보기 전, "$\theta$는 대략 이런 값일 거야"라는 사전 믿음
- $p(D)$: **증거(evidence)** — 데이터 자체의 확률. $\theta$에 의존하지 않으므로 상수 취급!

MAP는 사후 분포 $p(\theta|D)$를 최대화하는 $\theta$를 찾는다:

$$\theta_{\text{MAP}} = \arg\max_\theta \; p(\theta|D)$$

$p(D)$는 상수이므로:

$$\theta_{\text{MAP}} = \arg\max_\theta \; p(D|\theta) \cdot p(\theta)$$

로그를 취하면:

$$\theta_{\text{MAP}} = \arg\max_\theta \; \left[\log p(D|\theta) + \log p(\theta)\right]$$

**MLE와 비교하면?**

$$\theta_{\text{MLE}} = \arg\max_\theta \; \log p(D|\theta)$$
$$\theta_{\text{MAP}} = \arg\max_\theta \; \left[\underbrace{\log p(D|\theta)}_{\text{MLE와 같은 부분}} + \underbrace{\log p(\theta)}_{\text{추가된 부분: prior}}\right]$$

즉, **MAP = MLE + Prior**이다!

**가우시안 Prior가 L2 정규화가 되는 과정**

사전 분포로 $p(\theta) = \mathcal{N}(0, \tau^2)$를 쓰면:

$$\log p(\theta) = -\frac{\theta^2}{2\tau^2} + \text{const}$$

이것을 MAP 목적함수에 넣으면:

$$\theta_{\text{MAP}} = \arg\max_\theta \left[\log p(D|\theta) - \frac{\theta^2}{2\tau^2}\right]$$

부호를 뒤집어 최소화 문제로 바꾸면:

$$\theta_{\text{MAP}} = \arg\min_\theta \left[-\log p(D|\theta) + \frac{\theta^2}{2\tau^2}\right]$$

여기서 $-\log p(D|\theta)$는 원래의 손실 함수(MLE)이고, $\frac{\theta^2}{2\tau^2}$는 $\theta$가 커지면 벌을 주는 항이다. 이것이 바로 **L2 정규화**이다!

가우시안 우도(MSE 손실)와 결합하면:

$$\arg\min_\theta \left[\frac{1}{2\sigma^2}\sum_i(y_i - \theta x_i)^2 + \frac{\theta^2}{2\tau^2}\right]$$

공통 인수를 정리하면:

$$\arg\min_\theta \left[\sum_i(y_i - \theta x_i)^2 + \frac{\sigma^2}{\tau^2}\theta^2\right]$$

따라서 정규화 계수는:

$$\lambda = \frac{\sigma^2}{\tau^2}$$

**라플라스 Prior가 L1 정규화가 되는 과정**

사전 분포로 라플라스 분포 $p(\theta) \propto \exp(-|\theta|/b)$를 쓰면:

$$\log p(\theta) = -\frac{|\theta|}{b} + \text{const}$$

이것은 $|\theta|$에 비례하는 벌점 → **L1 정규화**!

**Prior가 정규화 역할을 하는 직관**

- Prior $\mathcal{N}(0, \tau^2)$는 "$\theta$는 0 근처에 있을 가능성이 높다"는 믿음
- $\theta$가 너무 크면 prior의 확률이 매우 낮아짐 → MAP에서 불리
- 결과: 모델이 극단적인 파라미터를 사용하지 못하게 제한 = 정규화!
- $\tau^2$가 작으면: prior가 좁다 → 0 가까이로 강하게 끌어당김 → 강한 정규화
- $\tau^2$가 크면: prior가 넓다 → 거의 제약 없음 → 약한 정규화 → MLE에 수렴

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| MAP 목적함수 | $\arg\max_\theta [\log p(D|\theta) + \log p(\theta)]$ |
| 가우시안 prior → L2 | $\log p(\theta) = -\frac{\theta^2}{2\tau^2} + C$ |
| 라플라스 prior → L1 | $\log p(\theta) = -\frac{|\theta|}{b} + C$ |
| 정규화 계수 | $\lambda = \sigma^2 / \tau^2$ |
| MAP vs MLE | MAP = MLE + $\log p(\theta)$ |

### 숫자로 확인

동전 2번 던져 2번 다 앞면. MLE: $\hat{p} = 2/2 = 1.0$ (극단적!).

Prior: $p$는 $0.5$ 근처일 것이다 (공정한 동전이라는 사전 믿음).

MAP 계산 (Beta prior $\text{Beta}(3,3)$ 사용 시):
- 사후 분포: $\text{Beta}(2+3, 0+3) = \text{Beta}(5, 3)$
- MAP 추정: $\hat{p}_{\text{MAP}} = \frac{5-1}{5+3-2} = \frac{4}{6} \approx 0.67$

$1.0$보다 훨씬 합리적인 답이다! Prior가 극단값을 완화해준다.

### 다른 개념과의 연결

- **개념 25 (MLE)**: MAP에서 prior를 제거하면(= uniform prior) MLE가 됨
- **개념 33 (정규화)**: L2 정규화 = 가우시안 prior, L1 정규화 = 라플라스 prior
- **개념 35 (편향-분산)**: prior를 넣으면 bias는 증가하지만 variance가 감소 → 과적합 방지

### 자가 점검 문제

2. 가우시안 prior가 L2 정규화에 대응하는 이유를 수식으로 보여라.
3. $\lambda = \sigma^2/\tau^2$에서 $\tau^2 \to \infty$이면 어떻게 되는가?
4. 데이터가 매우 많아지면 MAP와 MLE의 차이는 어떻게 되는가? 왜?

## 개념 27: 정보이론 — 엔트로피, KL 발산, 교차 엔트로피

### 왜 필요한가 (큰 그림에서의 위치)

딥러닝에서 가장 많이 쓰는 손실 함수인 크로스 엔트로피(CE) 손실의 이론적 기반이다. "왜 하필 이 손실 함수를 쓰는가?"를 이해하려면 정보이론이 필요하다. 또한 KL 발산은 "두 분포가 얼마나 다른가"를 측정하는 도구로, 생성 모델(VAE, GAN 등) 이해의 기초이다.

### 선수 개념

- **확률 분포**: 가능한 결과에 확률을 배정한 것 (합 = 1)
- **로그(log)**: $\log_2$는 "정보의 비트 수", $\ln$은 자연로그
- **기대값**: 확률로 가중 평균을 낸 것. $E[X] = \sum_i p_i x_i$

### 관련 문제

Q1, Q14, Q20

### 중1 눈높이 설명

**엔트로피 (Entropy): "불확실성의 양"**

내일 날씨를 맞춰야 한다고 하자.

- 상황 A: 사막 지역. 맑을 확률 99%, 비 올 확률 1%.
  - 거의 확실히 맑을 거니까 불확실성이 **낮다**.
- 상황 B: 변덕스러운 지역. 맑을 확률 50%, 비 올 확률 50%.
  - 뭐가 될지 전혀 모르니까 불확실성이 **높다**.

엔트로피는 이 "불확실성"을 숫자로 측정한다:

$$H(p) = -\sum_{i} p_i \log p_i$$

**직접 계산해보자.**

상황 A: $p = [0.99, 0.01]$

$$H = -(0.99 \times \log_2 0.99 + 0.01 \times \log_2 0.01)$$
$$= -(0.99 \times (-0.0145) + 0.01 \times (-6.644))$$
$$= -(- 0.01435 - 0.06644)$$
$$= 0.0808 \text{ 비트}$$

상황 B: $p = [0.5, 0.5]$

$$H = -(0.5 \times \log_2 0.5 + 0.5 \times \log_2 0.5)$$
$$= -(0.5 \times (-1) + 0.5 \times (-1))$$
$$= -(-0.5 - 0.5) = 1 \text{ 비트}$$

결과: 상황 A의 엔트로피(0.08비트) < 상황 B의 엔트로피(1비트). 예상대로 불확실한 상황 B가 엔트로피가 높다!

**공정한 동전**: $H = 1$비트 (최대). **편향된 동전**: $H < 1$비트.

**KL 발산 (Kullback-Leibler Divergence): "두 분포의 차이"**

두 개의 확률 분포 $p$와 $q$가 있다. KL 발산은 "진짜 분포 $p$ 대신 $q$를 사용하면 얼마나 손해를 보는가"를 측정한다.

$$KL(p \| q) = \sum_i p_i \log \frac{p_i}{q_i}$$

**중요한 성질들:**

1. **$KL \geq 0$** (항상 0 이상). 이것을 Gibbs 부등식이라 한다.
2. **$KL = 0$이면 $p = q$** (두 분포가 같다).
3. **비대칭**: $KL(p\|q) \neq KL(q\|p)$ (일반적으로). 그래서 "거리"가 아니라 "발산"이라 부른다.

**$KL \geq 0$인 이유 (직관)**

$\log$는 오목(concave) 함수이다. 젠센 부등식(Jensen's inequality)에 의해:

$$-KL(p\|q) = \sum_i p_i \log \frac{q_i}{p_i} \leq \log \sum_i p_i \cdot \frac{q_i}{p_i} = \log \sum_i q_i = \log 1 = 0$$

따라서 $-KL(p\|q) \leq 0$, 즉 $KL(p\|q) \geq 0$. 

**교차 엔트로피 (Cross-Entropy): CE = H + KL**

$$CE(p, q) = -\sum_i p_i \log q_i$$

이것과 엔트로피, KL 발산의 관계:

$$CE(p, q) = H(p) + KL(p \| q)$$

증명:

$$CE(p, q) = -\sum_i p_i \log q_i = -\sum_i p_i \log p_i + \sum_i p_i \log \frac{p_i}{q_i} = H(p) + KL(p\|q)$$

**왜 이것이 중요한가?**

딥러닝에서 $p$는 정답 분포(고정), $q$는 모델의 예측 분포(학습 대상). CE를 최소화하면:

$$\min_q CE(p, q) = \min_q [H(p) + KL(p\|q)]$$

$H(p)$는 정답 분포의 엔트로피로 **상수**이다 (모델이 바꿀 수 없다). 따라서:

$$\min_q CE(p, q) = \min_q KL(p\|q)$$

**CE 최소화 = KL 최소화 = 모델 분포를 정답 분포에 가깝게 만들기!**

**CE Loss = NLL = MLE의 동치 관계**

- **CE Loss**: $-\sum_i p_i \log q_i$ (정보이론 관점)
- **NLL (Negative Log-Likelihood)**: $-\log q_y$ (통계학 관점)
- **MLE**: $\arg\max \log q_y$ (최적화 관점)

원-핫 분포에서 $p_y = 1$이고 나머지는 0이므로 $CE = -\log q_y = NLL$. 그리고 NLL 최소화 = 로그 우도 최대화 = MLE. 따라서 세 가지가 모두 같다!

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 엔트로피 | $H(p) = -\sum_i p_i \log p_i$ |
| KL 발산 | $KL(p\|q) = \sum_i p_i \log \frac{p_i}{q_i}$ |
| 교차 엔트로피 | $CE(p,q) = -\sum_i p_i \log q_i$ |
| 핵심 관계 | $CE(p,q) = H(p) + KL(p\|q)$ |
| KL 성질 | $KL(p\|q) \geq 0$, 등호는 $p=q$일 때만 |

### 숫자로 확인

$p = [0.7, 0.3]$ (진짜 분포), $q = [0.5, 0.5]$ (예측 분포).

$$H(p) = -(0.7\log 0.7 + 0.3\log 0.3) = -(0.7 \times (-0.357) + 0.3 \times (-1.204))$$
$$= -(- 0.250 - 0.361) = 0.611$$

$$KL(p\|q) = 0.7\log\frac{0.7}{0.5} + 0.3\log\frac{0.3}{0.5} = 0.7 \times 0.336 + 0.3 \times (-0.511)$$
$$= 0.235 - 0.153 = 0.082$$

$$CE(p, q) = -(0.7\log 0.5 + 0.3\log 0.5) = -\log 0.5 = 0.693$$

검증: $H(p) + KL(p\|q) = 0.611 + 0.082 = 0.693 = CE(p, q)$ ✓

### 다른 개념과의 연결

- **개념 25 (MLE)**: CE 최소화 = MLE와 동치
- **개념 29 (소프트맥스)**: 소프트맥스가 확률 분포를 만들어야 CE를 계산할 수 있음
- **개념 31 (역전파)**: CE 손실의 그래디언트 = 예측 - 정답 (깔끔한 형태!)

### 자가 점검 문제

1. $p = [0.5, 0.5]$일 때 $H(p)$를 계산하라 ($\log_2$ 사용).
2. $KL(p\|q) \geq 0$인 이유를 직관적으로 설명하라.
3. CE 최소화가 KL 최소화와 같은 이유를 한 문장으로 설명하라.
4. CE Loss, NLL, MLE가 같다는 것을 원-핫 벡터를 사용하여 보여라.

## 개념 28: 정규방정식 (Normal Equation)

### 왜 필요한가 (큰 그림에서의 위치)

딥러닝에서는 경사 하강법으로 반복적으로 파라미터를 업데이트하지만, 선형 회귀에서는 수학적으로 정답을 한 번에 구할 수 있다. 이 "한 방에 구하는 공식"이 정규방정식이다. 정규방정식은 "왜 기울기=0으로 놓으면 최적해를 찾을 수 있는가"를 가장 명확하게 보여주는 예시이며, 행렬 미분의 기초를 배우는 가장 좋은 연습 문제이다.

### 선수 개념

- **행렬 곱셈**: $A$가 $m \times n$이고 $B$가 $n \times k$이면 $AB$는 $m \times k$
- **전치(transpose)**: 행과 열을 뒤바꾸는 것. $(AB)^T = B^TA^T$
- **역행렬**: $A^{-1}$은 $AA^{-1} = I$ (단위행렬)을 만족하는 행렬
- **미분**: 함수의 기울기. 최솟값에서 기울기 = 0

### 관련 문제

Q11, Q25

### 중1 눈높이 설명

**문제 설정**

학생 $n$명의 데이터가 있다. 각 학생에 대해 특성(키, 공부 시간 등) $d$개와 결과(시험 점수) 1개를 알고 있다.

이 데이터를 행렬로 정리하면:
- $X$: $n \times d$ 행렬 (각 행 = 학생 1명의 특성들)
- $y$: $n \times 1$ 벡터 (각 학생의 시험 점수)
- $w$: $d \times 1$ 벡터 (각 특성의 가중치 — 우리가 찾고 싶은 것!)

예측: $\hat{y} = Xw$ (각 특성에 가중치를 곱해서 더한 것).

**손실 함수: "얼마나 틀렸나?"**

$$L(w) = \frac{1}{2}\|Xw - y\|^2 = \frac{1}{2}\sum_{i=1}^{n}(\hat{y}_i - y_i)^2$$

이것은 "각 학생에 대한 예측 오차를 제곱해서 모두 더한 것"이다. $\frac{1}{2}$는 나중에 미분할 때 깔끔하게 하려고 붙인 것이다 (최적해에 영향 없음).

**유도 과정**

**1단계: 손실 함수를 행렬로 전개**

$\|v\|^2 = v^Tv$ (벡터의 각 성분을 제곱해서 더한 것)을 이용:

$$L(w) = \frac{1}{2}(Xw - y)^T(Xw - y)$$

괄호를 전개하면 (보통의 곱셈 분배법칙과 같다):

$$L(w) = \frac{1}{2}(w^TX^TXw - 2y^TXw + y^Ty)$$

**2단계: $w$에 대해 미분**

행렬 미분의 핵심 공식 두 가지:
- $\frac{\partial}{\partial w}(w^TAw) = 2Aw$ ($A$가 대칭행렬일 때)
- $\frac{\partial}{\partial w}(b^Tw) = b$

$X^TX$는 항상 대칭행렬이다 ($(X^TX)^T = X^TX$). 따라서:

$$\frac{\partial L}{\partial w} = \frac{1}{2}(2X^TXw - 2X^Ty) = X^TXw - X^Ty$$

**3단계: 기울기 = 0으로 놓기**

$$X^TXw - X^Ty = 0$$
$$X^TXw = X^Ty$$

양변에 $(X^TX)^{-1}$을 곱하면:

$$\boxed{w^* = (X^TX)^{-1}X^Ty}$$

이것이 **정규방정식(Normal Equation)**이다!

**왜 딥러닝에서는 정규방정식을 안 쓰는가?**

1. **계산 비용**: $(X^TX)^{-1}$을 구하는 데 $O(d^3)$이 걸림. 특성이 100만개면 $10^{18}$번 계산 → 불가능
2. **비선형 모델**: 정규방정식은 $y = Xw$ (선형)일 때만 성립. 딥러닝은 비선형이라 닫힌 해가 없음
3. **메모리**: $X^TX$가 $d \times d$ 행렬인데, $d$가 크면 메모리에 안 들어감

그래서 딥러닝에서는 **경사 하강법**(개념 30)으로 반복적으로 최적화한다.

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 선형 회귀 모델 | $\hat{y} = Xw$ |
| 손실 함수 | $L(w) = \frac{1}{2}\|Xw - y\|^2$ |
| 기울기 | $\nabla_w L = X^TXw - X^Ty$ |
| 정규방정식 | $w^* = (X^TX)^{-1}X^Ty$ |
| 행렬 미분 1 | $\frac{\partial}{\partial w}(w^TAw) = 2Aw$ (대칭 $A$) |
| 행렬 미분 2 | $\frac{\partial}{\partial w}(b^Tw) = b$ |

### 숫자로 확인

데이터 3개: $(x_1, y_1) = (1, 2)$, $(x_2, y_2) = (2, 4)$, $(x_3, y_3) = (3, 5)$.

$y = wx$ 모델 (절편 없음, $d=1$):

$$X = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}, \quad y = \begin{pmatrix} 2 \\ 4 \\ 5 \end{pmatrix}$$

$$X^TX = 1^2 + 2^2 + 3^2 = 14$$

$$X^Ty = 1 \times 2 + 2 \times 4 + 3 \times 5 = 2 + 8 + 15 = 25$$

$$w^* = \frac{X^Ty}{X^TX} = \frac{25}{14} \approx 1.786$$

검증: 예측 $= [1.786, 3.571, 5.357]$. 실제 $= [2, 4, 5]$. 오차가 작다!

### 다른 개념과의 연결

- **개념 30 (경사 하강법)**: 정규방정식의 반복적 근사 버전
- **개념 25 (MLE)**: 가우시안 노이즈 가정 + MLE → MSE 최소화 → 정규방정식
- **개념 33 (정규화)**: L2 정규화 추가 시 $w^* = (X^TX + \lambda I)^{-1}X^Ty$ (Ridge 회귀)

### 자가 점검 문제

1. 손실 함수에 $\frac{1}{2}$가 붙어 있는 이유는?
2. $X^TX$가 항상 대칭인 이유를 보여라.
3. 정규방정식의 계산 복잡도가 $O(d^3)$인 이유는 무엇인가?
4. 딥러닝에서 정규방정식을 쓸 수 없는 이유 두 가지를 말하라.

## 개념 29: 소프트맥스 함수 (Softmax Function)

### 왜 필요한가 (큰 그림에서의 위치)

분류 문제에서 모델은 각 클래스에 점수(logit)를 매긴다. 하지만 이 점수는 아무 실수값이라 "확률"이 아니다 (음수일 수도 있고, 합이 1이 아닐 수도 있다). 소프트맥스는 이 임의의 실수 벡터를 확률 분포로 변환한다. 이것이 있어야 크로스 엔트로피 손실을 계산할 수 있다.

### 선수 개념

- **지수 함수**: $e^x$. 항상 양수, $x$가 크면 매우 빠르게 증가
- **확률 분포**: 모든 값이 0 이상이고, 합이 1인 것
- **편미분**: 여러 변수 중 하나만 변화시킬 때의 기울기

### 관련 문제

Q13, Q22

### 중1 눈높이 설명

**문제 상황**

모델이 3개 클래스에 대해 점수를 냈다: $z = [2.0, 1.0, 0.1]$.

이 점수를 "확률"로 바꾸고 싶다. 조건:
1. 모든 확률은 0보다 커야 한다
2. 확률의 합은 1이어야 한다
3. 점수가 높은 클래스의 확률이 높아야 한다

**소프트맥스가 하는 일**

$$p_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}$$

**1단계: 각 점수에 $e$를 거듭제곱**

- $e^{2.0} = 7.389$
- $e^{1.0} = 2.718$
- $e^{0.1} = 1.105$

모두 양수가 된다! ($e^x > 0$ 항상)

**2단계: 합 계산**

$$\sum = 7.389 + 2.718 + 1.105 = 11.212$$

**3단계: 각각을 합으로 나누기**

- $p_1 = 7.389 / 11.212 = 0.659$
- $p_2 = 2.718 / 11.212 = 0.242$
- $p_3 = 1.105 / 11.212 = 0.099$

결과: $p = [0.659, 0.242, 0.099]$. 합 = 1.000 ✓. 모두 양수 ✓. 점수 높은 순서 유지 ✓.

**소프트맥스의 자코비안 (역전파에 필요)**

역전파를 하려면 "소프트맥스 출력 $p_i$가 입력 $z_j$에 대해 얼마나 민감한가"를 알아야 한다. 이것이 자코비안이다:

$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$$

여기서 $\delta_{ij}$는 크로네커 델타: $i = j$이면 1, $i \neq j$이면 0.

**두 가지 경우로 나눠보자:**

- $i = j$일 때: $\frac{\partial p_i}{\partial z_i} = p_i(1 - p_i)$
  - "자기 자신에 대한 변화율". 시그모이드 도함수 $\sigma(1-\sigma)$와 같은 형태!
  
- $i \neq j$일 때: $\frac{\partial p_i}{\partial z_j} = -p_i p_j$
  - "다른 클래스의 점수가 올라가면 내 확률은 줄어든다" (부호가 마이너스!)

**유도 (간략)**

$p_i = e^{z_i} / S$ (여기서 $S = \sum_k e^{z_k}$)

$i = j$인 경우: 몫의 미분법 적용

$$\frac{\partial p_i}{\partial z_i} = \frac{e^{z_i} \cdot S - e^{z_i} \cdot e^{z_i}}{S^2} = \frac{e^{z_i}}{S} \cdot \frac{S - e^{z_i}}{S} = p_i(1 - p_i)$$

$i \neq j$인 경우: 분자 $e^{z_i}$는 $z_j$에 무관 (상수), 분모만 미분

$$\frac{\partial p_i}{\partial z_j} = e^{z_i} \cdot \frac{-e^{z_j}}{S^2} = -\frac{e^{z_i}}{S} \cdot \frac{e^{z_j}}{S} = -p_i p_j$$

두 경우를 합치면: $\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$ ✓

**역전파에서 이 자코비안이 필요한 이유**: 손실에서 logit $z$까지의 그래디언트를 계산하려면 체인룰 $\frac{\partial L}{\partial z_j} = \sum_i \frac{\partial L}{\partial p_i} \cdot \frac{\partial p_i}{\partial z_j}$이 필요하다. 이때 자코비안 $\frac{\partial p_i}{\partial z_j}$가 쓰인다.

**최대 엔트로피 원리와 라그랑주 유도**: 소프트맥스는 "확률의 합 = 1" 제약 아래 엔트로피를 최대화하는 분포 형태에서 자연스럽게 유도된다 (라그랑주 승수법 사용).

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 소프트맥스 | $p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$ |
| 자코비안 ($i=j$) | $\frac{\partial p_i}{\partial z_i} = p_i(1 - p_i)$ |
| 자코비안 ($i \neq j$) | $\frac{\partial p_i}{\partial z_j} = -p_i p_j$ |
| 통합 표현 | $\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$ |
| CE + Softmax 역전파 | $\frac{\partial L}{\partial z_i} = p_i - y_i$ (깔끔!) |

### 숫자로 확인

$z = [1, 2, 3]$이면:

$e^1 = 2.718$, $e^2 = 7.389$, $e^3 = 20.086$, 합 = $30.193$

$p = [0.090, 0.245, 0.665]$

자코비안 확인: $\frac{\partial p_1}{\partial z_1} = 0.090 \times (1 - 0.090) = 0.082$

$\frac{\partial p_1}{\partial z_2} = -0.090 \times 0.245 = -0.022$

### 다른 개념과의 연결

- **개념 27 (교차 엔트로피)**: 소프트맥스 출력에 CE 손실을 적용
- **개념 31 (역전파)**: 소프트맥스 자코비안이 역전파 계산의 핵심 부분
- **개념 32 (활성화 함수)**: 소프트맥스는 출력층에서 쓰는 특수한 활성화 함수

### 자가 점검 문제

1. $z = [1, 1, 1]$일 때 소프트맥스 출력을 구하라.
2. 소프트맥스 출력의 합이 항상 1인 이유를 수식으로 보여라.
3. $\frac{\partial p_i}{\partial z_j}$가 $i \neq j$일 때 음수인 직관적 이유는?
4. CE 손실 + 소프트맥스를 결합하면 역전파 그래디언트가 $p_i - y_i$로 깔끔해지는 이유를 설명하라.

## 개념 30: 경사 하강법 (Gradient Descent)

### 왜 필요한가 (큰 그림에서의 위치)

딥러닝 모델의 파라미터는 수백만~수십억 개이다. 정규방정식처럼 한 번에 답을 구할 수 없다. 경사 하강법은 "현재 위치에서 기울기(그래디언트)가 가리키는 반대 방향으로 조금씩 이동"하는 반복적 최적화 방법이다. 딥러닝의 모든 학습이 이 방법으로 이루어진다.

### 선수 개념

- **미분/기울기**: 함수가 증가하는 방향과 그 정도
- **그래디언트**: 다변수 함수에서 각 변수에 대한 편미분을 모은 벡터
- **학습률**: 한 번에 얼마나 이동할지를 정하는 하이퍼파라미터

### 관련 문제

Q18

### 중1 눈높이 설명

**비유: 안개 낀 산에서 가장 낮은 곳 찾기**

눈을 감고 산에 서 있다고 상상하자. 가장 낮은 곳(골짜기)을 찾고 싶다.

방법: 발밑의 경사를 느낀다. 내리막 방향으로 한 걸음 간다. 반복한다.

이것이 경사 하강법이다!

**수학으로 표현**

파라미터 $\theta$를 반복적으로 업데이트한다:

$$\theta_{\text{new}} = \theta_{\text{old}} - \eta \nabla L(\theta_{\text{old}})$$

각 기호의 의미:
- $\theta$: 현재 위치 (파라미터 값)
- $\nabla L(\theta)$: 현재 위치에서의 기울기 (가장 가파르게 올라가는 방향)
- $\eta$: **학습률(learning rate)** — 한 걸음의 크기
- $-\eta \nabla L$: 기울기의 **반대** 방향으로 $\eta$만큼 이동 (내리막!)

**학습률의 중요성**

- $\eta$가 **너무 크면**: 골짜기를 뛰어넘어 반대편 산으로 가버린다 → **발산**
- $\eta$가 **너무 작으면**: 한 걸음이 너무 작아서 영원히 골짜기에 도달 못함 → **느림**
- $\eta$가 **적당하면**: 점점 골짜기에 가까워진다 → **수렴**

**숫자 예시**

$L(\theta) = \theta^2$ (포물선). 최소점은 $\theta = 0$.

$\nabla L(\theta) = 2\theta$.

학습률 $\eta = 0.1$, 초기값 $\theta_0 = 5$:

| 단계 | $\theta$ | $\nabla L = 2\theta$ | 업데이트: $\theta - 0.1 \times 2\theta$ |
|------|---------|---------------------|--------------------------------------|
| 0 | 5.000 | 10.000 | $5 - 1.0 = 4.0$ |
| 1 | 4.000 | 8.000 | $4 - 0.8 = 3.2$ |
| 2 | 3.200 | 6.400 | $3.2 - 0.64 = 2.56$ |
| 3 | 2.560 | 5.120 | $2.56 - 0.512 = 2.048$ |
| ... | ... | ... | ... |

$\theta$가 0을 향해 점점 줄어든다!

**SGD (확률적 경사 하강법)**

데이터가 100만 개면, 전체 데이터에 대해 기울기를 계산하는 것은 매우 느리다.

**해결책**: 전체 데이터 대신 **미니배치(mini-batch)** (예: 32개)만 뽑아서 기울기를 추정한다.

- 장점: 매우 빠름 (1번 업데이트에 32개만 계산)
- 단점: 기울기가 부정확함 (노이즈가 섞임)
- 하지만: 노이즈 덕분에 오히려 지역 최소점(local minimum)을 탈출할 수 있다!

**모멘텀 (Momentum)**

SGD는 노이즈 때문에 지그재그로 움직인다. 모멘텀은 "관성"을 추가해서 일관된 방향으로 빠르게 이동하게 한다.

$$m_t = \beta m_{t-1} + \nabla L(\theta_t)$$
$$\theta_{t+1} = \theta_t - \eta m_t$$

- $m$: 모멘텀 (과거 기울기의 누적)
- $\beta$: 관성 계수 (보통 0.9). 과거 방향을 얼마나 기억할지

비유: 공이 언덕을 굴러 내려간다. 평평한 곳에서도 관성으로 계속 굴러간다. 작은 언덕은 넘어갈 수 있다!

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 기본 GD | $\theta \leftarrow \theta - \eta \nabla L(\theta)$ |
| SGD | 전체 대신 미니배치로 $\nabla L$ 근사 |
| 모멘텀 SGD | $m \leftarrow \beta m + \nabla L$, $\theta \leftarrow \theta - \eta m$ |
| 수렴 조건 | $\eta < 2/L_{\text{smooth}}$ (볼록 함수에서) |

### 숫자로 확인

$L(\theta) = (\theta - 3)^2$, $\nabla L = 2(\theta - 3)$, $\eta = 0.3$, $\theta_0 = 0$:

- Step 0: $\theta = 0$, $\nabla L = -6$, $\theta_1 = 0 - 0.3 \times (-6) = 1.8$
- Step 1: $\theta = 1.8$, $\nabla L = -2.4$, $\theta_2 = 1.8 + 0.72 = 2.52$
- Step 2: $\theta = 2.52$, $\nabla L = -0.96$, $\theta_3 = 2.52 + 0.288 = 2.808$

정답 $\theta^* = 3$에 점점 수렴한다!

- **개념 31 (역전파)**: GD에 필요한 $\nabla L$을 효율적으로 계산하는 방법
- **개념 32 (활성화 함수)**: 기울기 소실 문제가 GD의 효율에 영향

## 개념 31: 역전파 (Backpropagation)

### 왜 필요한가 (큰 그림에서의 위치)

경사 하강법은 $\nabla L(\theta)$ (그래디언트)를 알아야 작동한다. 딥러닝 모델은 수백만 개의 파라미터가 있는데, 각 파라미터에 대한 그래디언트를 어떻게 효율적으로 계산할까? 역전파는 체인룰(연쇄법칙)을 체계적으로 적용하여 모든 파라미터의 그래디언트를 한 번에 계산하는 알고리즘이다.

### 선수 개념

- **체인룰(연쇄법칙)**: $y = f(g(x))$이면 $\frac{dy}{dx} = \frac{dy}{dg} \cdot \frac{dg}{dx}$
- **편미분**: 여러 변수 중 하나에 대한 미분
- **계산 그래프**: 연산을 노드와 간선으로 표현한 그래프

### 관련 문제

Q8, Q24, Q30

### 중1 눈높이 설명

**비유: 도미노 효과 역추적**

100개의 도미노가 연쇄적으로 쓰러졌다. 마지막 도미노가 얼마나 세게 쓰러졌는지 알고 있다. 각 도미노가 다음 도미노에 미친 영향을 거꾸로 추적하면, 첫 번째 도미노가 마지막에 얼마나 영향을 줬는지 계산할 수 있다.

**순전파 (Forward Pass)**

입력 → 중간 계산 → 출력 → 손실. 앞에서 뒤로 계산.

**역전파 (Backward Pass)**

손실 → 출력 → 중간 계산 → 입력. 뒤에서 앞으로 그래디언트 계산.

**구체적 예시**

간단한 함수: $L = (wx + b - y)^2$

순전파의 계산 그래프:

1. $a = wx$ (곱셈)
2. $c = a + b$ (덧셈)
3. $d = c - y$ (뺄셈)
4. $L = d^2$ (제곱)

역전파: 뒤에서부터 체인룰 적용!

**4단계에서 시작**: $\frac{\partial L}{\partial d} = 2d$

**3단계**: $\frac{\partial L}{\partial c} = \frac{\partial L}{\partial d} \cdot \frac{\partial d}{\partial c} = 2d \cdot 1 = 2d$

**2단계**: 
- $\frac{\partial L}{\partial a} = \frac{\partial L}{\partial c} \cdot \frac{\partial c}{\partial a} = 2d \cdot 1 = 2d$
- $\frac{\partial L}{\partial b} = \frac{\partial L}{\partial c} \cdot \frac{\partial c}{\partial b} = 2d \cdot 1 = 2d$

**1단계**:
- $\frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial w} = 2d \cdot x = 2(wx + b - y) \cdot x$

**핵심 패턴: "local gradient × upstream gradient"**

각 노드에서:
- **Local gradient**: 그 노드 자체의 입출력 관계 (예: 곱셈 노드에서 $\frac{\partial(wx)}{\partial w} = x$)
- **Upstream gradient**: 손실에서 그 노드의 출력까지의 그래디언트 (윗단에서 흘러내려온 것)
- **이 노드의 그래디언트** = local gradient × upstream gradient

이 패턴을 모든 노드에 적용하면, 한 번의 역방향 통과로 모든 파라미터의 그래디언트를 계산할 수 있다!

**왜 효율적인가?**

파라미터가 $p$개이면, 각각 개별적으로 미분하면 $O(p)$번의 순전파가 필요하다. 하지만 역전파는 단 1번의 역방향 통과로 모든 그래디언트를 계산한다. PyTorch의 `loss.backward()`가 바로 이것을 수행한다.

**숫자 예시**

$w = 2$, $x = 3$, $b = 1$, $y = 8$.

순전파:
1. $a = wx = 2 \times 3 = 6$
2. $c = a + b = 6 + 1 = 7$
3. $d = c - y = 7 - 8 = -1$
4. $L = d^2 = (-1)^2 = 1$

역전파:
- $\frac{\partial L}{\partial d} = 2d = 2 \times (-1) = -2$
- $\frac{\partial L}{\partial c} = -2 \times 1 = -2$
- $\frac{\partial L}{\partial b} = -2 \times 1 = -2$
- $\frac{\partial L}{\partial a} = -2 \times 1 = -2$
- $\frac{\partial L}{\partial w} = -2 \times x = -2 \times 3 = -6$

검증: $\frac{\partial L}{\partial w} = 2(wx+b-y) \cdot x = 2(7-8) \times 3 = -6$ ✓

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 체인룰 | $\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial x}$ |
| 노드 규칙 | gradient = local gradient × upstream gradient |
| 덧셈 노드 | 그래디언트를 그대로 통과 (×1) |
| 곱셈 노드 | 그래디언트에 "상대방 입력"을 곱함 |
| 제곱 노드 | $\frac{\partial(x^2)}{\partial x} = 2x$ |

### 다른 개념과의 연결

- **개념 30 (경사 하강법)**: 역전파가 제공한 그래디언트로 GD 업데이트
- **개념 32 (활성화 함수)**: 활성화 함수의 도함수가 역전파에 직접 사용됨
- **개념 29 (소프트맥스)**: 소프트맥스 자코비안이 역전파 경로의 일부
- **개념 27 (교차 엔트로피)**: CE + 소프트맥스 역전파 → $p - y$ (놀라울 만큼 깔끔)

## 개념 32: 활성화 함수 (Activation Functions)

### 왜 필요한가 (큰 그림에서의 위치)

신경망에서 활성화 함수가 없으면 아무리 많은 층을 쌓아도 전체가 하나의 선형변환에 불과하다. 활성화 함수가 비선형성을 도입하여 신경망이 복잡한 패턴을 학습할 수 있게 한다. 또한 활성화 함수의 도함수 특성은 기울기 소실/폭발 문제에 직결된다.

### 선수 개념

- **선형 함수**: $f(x) = ax + b$ 형태. 직선 그래프
- **비선형 함수**: 직선이 아닌 곡선. 예: $x^2$, $e^x$
- **도함수**: 함수의 기울기. 역전파에서 필수

### 관련 문제

Q28, Q30

### 중1 눈높이 설명

**왜 활성화가 필요한가?**

선형 함수만 쓰면 어떻게 되는지 보자.

1층: $h_1 = W_1 x + b_1$
2층: $h_2 = W_2 h_1 + b_2 = W_2(W_1 x + b_1) + b_2 = W_2 W_1 x + W_2 b_1 + b_2$

이것을 정리하면 $h_2 = W' x + b'$. 결국 하나의 선형변환!

100층을 쌓아도 마찬가지: $W_{100} \cdots W_2 W_1 x + \text{(상수)} = W' x + b'$.

결론: **활성화 함수 없이는 깊은 네트워크가 의미 없다**. 선형 함수 + 선형 함수 = 선형 함수이기 때문.

**주요 활성화 함수들**

**1. ReLU (Rectified Linear Unit)**

$$\text{ReLU}(x) = \max(0, x) = \begin{cases} x & \text{if } x > 0 \\ 0 & \text{if } x \leq 0 \end{cases}$$

도함수: 

$$\text{ReLU}'(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x < 0 \end{cases}$$

그래프: $x < 0$이면 바닥(0), $x > 0$이면 $y = x$ 직선. 꺾인 선 모양!

장점: 양수 구간에서 도함수 = 1. 기울기가 줄어들지 않는다!
단점: 음수 구간에서 도함수 = 0. 한번 죽으면 영영 학습 안됨 ("dying ReLU").

**2. Sigmoid**

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

도함수: $\sigma'(x) = \sigma(x)(1 - \sigma(x))$

출력 범위: $(0, 1)$. 확률로 해석 가능!

도함수의 최대값: $x = 0$일 때 $\sigma(0) = 0.5$이므로 $\sigma'(0) = 0.5 \times 0.5 = 0.25$.

**기울기 소실 문제**: 도함수가 최대 0.25. 10개 층을 거치면?

$$0.25^{10} = 0.25 \times 0.25 \times \cdots \times 0.25 = \frac{1}{4^{10}} = \frac{1}{1048576} \approx 9.5 \times 10^{-7}$$

기울기가 100만분의 1로 줄어든다! 앞쪽 층은 거의 학습이 안 된다. 이것이 **기울기 소실(vanishing gradient) 문제**이다.

**3. Tanh**

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$$

도함수: $\tanh'(x) = 1 - \tanh^2(x)$

출력 범위: $(-1, 1)$. 0 중심이라 sigmoid보다 나음.

도함수 최대: $x = 0$일 때 $\tanh(0) = 0$이므로 $\tanh'(0) = 1 - 0 = 1$.

하지만 $|x|$가 크면 $\tanh \approx \pm 1$이므로 도함수 $\approx 0$. 여전히 기울기 소실 가능.

**ReLU가 기울기 소실을 해결하는 이유**

ReLU의 도함수는 양수 구간에서 **정확히 1**. 10층을 거쳐도:

$$1 \times 1 \times 1 \times \cdots \times 1 = 1$$

기울기가 줄어들지 않는다! 이것이 ReLU가 딥러닝에서 가장 많이 쓰이는 이유이다.

### 핵심 공식 정리

| 함수 | 공식 | 도함수 | 출력 범위 | 도함수 최대 |
|------|------|--------|----------|-----------|
| ReLU | $\max(0, x)$ | $0$ 또는 $1$ | $[0, \infty)$ | $1$ |
| Sigmoid | $\frac{1}{1+e^{-x}}$ | $\sigma(1-\sigma)$ | $(0, 1)$ | $0.25$ |
| Tanh | $\frac{e^x-e^{-x}}{e^x+e^{-x}}$ | $1-\tanh^2$ | $(-1, 1)$ | $1$ |

### 숫자로 확인

$x = 2$일 때 각 활성화 함수:

- ReLU(2) = max(0, 2) = 2. 도함수 = 1.
- Sigmoid(2) = $\frac{1}{1+e^{-2}} = \frac{1}{1+0.135} = 0.881$. 도함수 = $0.881 \times 0.119 = 0.105$.
- Tanh(2) = $\frac{e^2-e^{-2}}{e^2+e^{-2}} = \frac{7.389-0.135}{7.389+0.135} = \frac{7.254}{7.524} = 0.964$. 도함수 = $1 - 0.964^2 = 0.071$.

$x = 2$에서 이미 sigmoid, tanh의 도함수는 0.1~0.07로 작아졌다. 여러 층 거치면 급격히 감소!

### 다른 개념과의 연결

- **개념 31 (역전파)**: 활성화 함수의 도함수가 역전파의 local gradient
- **개념 30 (경사 하강법)**: 기울기 소실이면 GD가 제대로 작동하지 않음
- **개념 34 (배치 정규화)**: 입력을 적절한 범위로 유지하여 활성화 함수가 포화 영역에 빠지지 않게 함

1. 활성화 함수가 없으면 깊은 네트워크가 의미 없는 이유를 수식으로 보여라.
2. Sigmoid의 기울기 소실 문제를 10층 예시로 계산하라.
3. ReLU가 기울기 소실을 해결하는 이유는?
4. ReLU의 단점("dying ReLU")은 무엇인가?

## 개념 33: 정규화 (Regularization)

### 왜 필요한가 (큰 그림에서의 위치)

모델이 학습 데이터에 너무 잘 맞추면(과적합), 새로운 데이터에서 성능이 떨어진다. 정규화는 모델의 복잡도를 제한하여 과적합을 방지한다. L2 정규화(Ridge)와 L1 정규화(Lasso)가 대표적이며, 이들은 MAP 추정(개념 26)과 직접 연결된다.

### 선수 개념

- **과적합(overfitting)**: 학습 데이터에는 잘 맞지만 새 데이터에 실패
- **노름(norm)**: 벡터의 "크기". $\|w\|_2 = \sqrt{\sum w_i^2}$, $\|w\|_1 = \sum |w_i|$
- **개념 26 (MAP)**: 정규화의 확률론적 근거

### 관련 문제

Q21, Q23, Q26

### 중1 눈높이 설명

**비유: 시험 답안지에 "간단하게 쓰세요" 규칙 추가**

학생이 서술형 시험 답안을 쓴다고 하자.

- **규칙 없이**: 학생은 복잡하고 긴 답을 써서 예시 문제(학습 데이터)에 100점을 맞을 수 있다. 하지만 새로운 문제에는 엉뚱한 답을 쓸 수 있다.
- **"간단하게 쓰세요" 규칙 추가**: 복잡한 답에 감점(벌점)을 매긴다. 학생은 핵심만 간결하게 쓰게 된다. 예시 문제에서 100점은 아니지만, 새 문제에도 적절한 답을 쓸 가능성이 높아진다.

수학적으로:

$$L_{\text{regularized}} = L_{\text{data}} + \lambda \cdot R(w)$$

- $L_{\text{data}}$: 원래 손실 ("데이터에 얼마나 맞는가")
- $R(w)$: 정규화 항 ("파라미터가 얼마나 복잡한가")
- $\lambda$: 정규화 강도 ("규칙을 얼마나 엄격히 적용할지")

**L2 정규화 (Ridge)**

$$L = L_{\text{data}} + \lambda \sum_i w_i^2 = L_{\text{data}} + \lambda \|w\|_2^2$$

$w_i^2$를 더하므로 큰 가중치에 강한 벌을 준다 ($w = 10$이면 벌 = 100, $w = 1$이면 벌 = 1).

효과: 모든 가중치를 0에 가깝게 줄인다 (하지만 정확히 0으로 만들지는 않는다).

MAP 관점: 가우시안 prior $p(w) = \mathcal{N}(0, \tau^2)$에 대응.

**L1 정규화 (Lasso)**

$$L = L_{\text{data}} + \lambda \sum_i |w_i| = L_{\text{data}} + \lambda \|w\|_1$$

$|w_i|$를 더하므로 크기에 비례한 벌을 준다 ($w = 10$이면 벌 = 10, $w = 1$이면 벌 = 1).

효과: 일부 가중치를 정확히 0으로 만든다! → **희소성(sparsity)**

MAP 관점: 라플라스 prior에 대응.

**L1이 희소성을 만드는 이유 (기하학적 설명)**

2차원에서 등고선(같은 손실 값을 가진 점들의 집합)을 그려보자:

- L2: $w_1^2 + w_2^2 \leq c$ → **원** 모양
- L1: $|w_1| + |w_2| \leq c$ → **다이아몬드(마름모)** 모양

손실 함수의 등고선과 정규화 영역이 만나는 점이 최적해이다.

- 원(L2)은 매끄러워서 축 위에서 만날 이유가 없다 → $w_i$가 정확히 0이 될 가능성 낮음
- 다이아몬드(L1)는 꼭짓점이 축 위에 있다 → 등고선이 축 위에서 만날 가능성 높음 → $w_i = 0$!

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| L2 정규화 | $L + \lambda\|w\|_2^2 = L + \lambda\sum_i w_i^2$ |
| L1 정규화 | $L + \lambda\|w\|_1 = L + \lambda\sum_i |w_i|$ |
| L2 = 가우시안 prior | $p(w) \propto \exp(-\|w\|^2/(2\tau^2))$ |
| L1 = 라플라스 prior | $p(w) \propto \exp(-\|w\|/b)$ |
| $\lambda$ 역할 | 클수록 강한 정규화, 작을수록 약한 정규화 |

### 숫자로 확인

$w = [3, 0.1]$일 때:

- L2 벌점: $3^2 + 0.1^2 = 9 + 0.01 = 9.01$
- L1 벌점: $|3| + |0.1| = 3 + 0.1 = 3.1$

$w = [2, 2]$일 때:

- L2 벌점: $4 + 4 = 8$
- L1 벌점: $2 + 2 = 4$

L2는 $[3, 0.1]$(9.01)보다 $[2, 2]$(8)를 선호 → 값을 고르게 분산.
L1도 $[3, 0.1]$(3.1)보다 $[2, 2]$(4)를... 아니, L1은 $[3, 0.1]$을 선호! → 희소한 해를 좋아함.

### 다른 개념과의 연결

- **개념 26 (MAP)**: 정규화 = prior의 효과. $\lambda = \sigma^2/\tau^2$
- **개념 35 (편향-분산)**: 정규화 ↑ → bias ↑, variance ↓
- **개념 28 (정규방정식)**: L2 추가 시 $w^* = (X^TX + \lambda I)^{-1}X^Ty$

### 자가 점검 문제

1. L2 정규화가 가중치를 0에 가깝게 만드는 이유를 직관적으로 설명하라.
2. L1 정규화가 일부 가중치를 정확히 0으로 만드는 기하학적 이유는?
3. $\lambda$가 0이면 어떤 추정법과 같아지는가?
4. L2 정규화가 가우시안 prior에 대응하는 이유를 수식으로 보여라.

## 개념 34: 배치 정규화 (Batch Normalization)

### 왜 필요한가 (큰 그림에서의 위치)

딥러닝 모델이 깊어지면 각 층의 입력 분포가 학습 중에 계속 바뀐다 (Internal Covariate Shift). 이러면 학습이 불안정해진다. 배치 정규화는 각 층의 입력을 정규화하여 학습을 안정화하고 가속화한다.

### 선수 개념

- **평균과 분산**: 평균 = 데이터의 중심, 분산 = 데이터가 퍼진 정도
- **정규화(normalization)**: 데이터를 평균 0, 분산 1로 바꾸는 것
- **미니배치**: 전체 데이터에서 일부를 뽑은 것

### 관련 문제

Q29

### 중1 눈높이 설명

**비유: 시험 점수 표준화**

학교마다 시험 난이도가 다르다. A학교 평균 80점, B학교 평균 50점이면 점수를 직접 비교할 수 없다.

해결: 각 학교에서 "(내 점수 - 평균) / 표준편차"를 계산하면 공정하게 비교 가능!

배치 정규화는 이것을 신경망의 각 층에서 해주는 것이다.

**수학적 과정**

미니배치의 데이터가 $\{x_1, x_2, \ldots, x_m\}$일 때:

**1단계: 미니배치 평균 계산**

$$\mu_B = \frac{1}{m}\sum_{i=1}^{m} x_i$$

**2단계: 미니배치 분산 계산**

$$\sigma_B^2 = \frac{1}{m}\sum_{i=1}^{m}(x_i - \mu_B)^2$$

**3단계: 정규화**

$$\hat{x}_i = \frac{x_i - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$$

여기서 $\epsilon$은 아주 작은 수 (예: $10^{-5}$). 분모가 0이 되는 것을 방지!

결과: $\hat{x}$는 대략 평균 0, 분산 1이 됨.

**4단계: 스케일과 시프트 (학습 가능!)**

$$y_i = \gamma \hat{x}_i + \beta$$

- $\gamma$: 스케일 파라미터 (분산을 조절)
- $\beta$: 시프트 파라미터 (평균을 조절)

**왜 4단계가 필요한가?** 3단계만 하면 항상 평균 0, 분산 1로 강제된다. 하지만 어떤 층에서는 다른 분포가 더 좋을 수도 있다. $\gamma$와 $\beta$를 학습시키면 모델이 "필요하면 원래 분포로 되돌릴 수 있다". 만약 $\gamma = \sigma_B$, $\beta = \mu_B$로 학습되면 정규화를 완전히 취소하는 셈!

**Internal Covariate Shift란?**

3층짜리 네트워크에서:
- 2층의 파라미터가 업데이트되면 → 3층의 입력 분포가 바뀜
- 3층은 "어? 입력이 갑자기 바뀌었네?" → 혼란 → 학습 불안정

배치 정규화는 각 층의 입력을 일정한 범위로 유지시켜 이 문제를 완화한다.

**추론(inference) 시의 차이**

학습 중: 미니배치의 $\mu_B$, $\sigma_B^2$를 사용.
추론 중: 미니배치가 없다! (데이터가 1개씩 들어올 수 있으므로)

해결: 학습 중에 $\mu_B$, $\sigma_B^2$의 **이동 평균(running average)**을 저장해둔다.

$$\mu_{\text{running}} = (1 - \alpha)\mu_{\text{running}} + \alpha \mu_B$$

추론 시 이 저장된 값을 사용한다.

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 배치 평균 | $\mu_B = \frac{1}{m}\sum_i x_i$ |
| 배치 분산 | $\sigma_B^2 = \frac{1}{m}\sum_i(x_i-\mu_B)^2$ |
| 정규화 | $\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$ |
| 출력 | $y = \gamma\hat{x} + \beta$ |
| 학습 가능 파라미터 | $\gamma$ (스케일), $\beta$ (시프트) |

### 숫자로 확인

미니배치: $x = [1, 3, 5, 7]$ ($m = 4$)

$\mu_B = (1+3+5+7)/4 = 4$

$\sigma_B^2 = \frac{1}{4}((1-4)^2 + (3-4)^2 + (5-4)^2 + (7-4)^2) = \frac{9+1+1+9}{4} = 5$

$\hat{x}_1 = \frac{1-4}{\sqrt{5+0.00001}} = \frac{-3}{2.236} = -1.342$

$\hat{x}_2 = \frac{3-4}{2.236} = -0.447$

$\hat{x}_3 = \frac{5-4}{2.236} = 0.447$

$\hat{x}_4 = \frac{7-4}{2.236} = 1.342$

평균 확인: $(-1.342 - 0.447 + 0.447 + 1.342)/4 = 0$ ✓

$\gamma = 2$, $\beta = 1$이면: $y_1 = 2 \times (-1.342) + 1 = -1.684$

### 다른 개념과의 연결

- **개념 32 (활성화 함수)**: BN이 입력을 적절한 범위로 유지 → 활성화 함수의 포화 방지
- **개념 30 (경사 하강법)**: BN이 학습을 안정화하여 더 큰 학습률 사용 가능
- **개념 33 (정규화)**: BN도 약한 정규화 효과가 있음 (배치의 랜덤성이 노이즈 역할)

### 자가 점검 문제

1. 배치 정규화의 4단계를 순서대로 설명하라.
2. $\gamma$와 $\beta$가 학습 가능한 이유는?
3. 추론 시 미니배치 통계량 대신 무엇을 사용하는가?
4. Internal Covariate Shift가 무엇인지 한 문장으로 설명하라.

## 개념 35: 편향-분산 트레이드오프 (Bias-Variance Tradeoff)

### 왜 필요한가 (큰 그림에서의 위치)

모델의 예측 오차는 세 가지 원인으로 분해된다: 편향(bias), 분산(variance), 노이즈. 이 분해를 이해하면 "모델이 왜 안 좋은가"를 진단할 수 있고, "어떻게 고칠 것인가"를 결정할 수 있다. 과소적합 vs 과적합의 이론적 기초이다.

### 선수 개념

- **기대값(E)**: 여러 번 반복했을 때의 평균값
- **편향(bias)**: 체계적인 오차. 평균적으로 정답에서 벗어난 정도
- **분산(variance)**: 결과가 얼마나 흔들리는가

### 관련 문제

Q26

### 중1 눈높이 설명

**비유: 다트 던지기**

과녁의 중심이 정답이라고 하자. 여러 번 다트를 던진다.

**경우 1: 높은 bias, 낮은 variance**
- 다트가 한쪽으로 치우쳐서 모여 있다.
- 매번 비슷한 곳에 꽂히지만 (일관적), 중심에서 떨어져 있다 (부정확).
- → **과소적합(underfitting)**: 모델이 너무 단순해서 패턴을 못 잡음.

**경우 2: 낮은 bias, 높은 variance**
- 다트가 중심 근처에 "평균적으로는" 있지만, 이리저리 흩어져 있다.
- 평균은 맞지만 (정확), 매번 다른 곳에 꽂힌다 (불안정).
- → **과적합(overfitting)**: 모델이 학습 데이터의 노이즈까지 외워버림.

**경우 3: 낮은 bias, 낮은 variance**
- 다트가 중심에 모여 있다.
- 정확하고 일관적! → **이상적인 모델**

**수학적 분해**

예측 오차의 기대값:

$$E[(y - \hat{h}(x))^2] = \text{Bias}^2 + \text{Variance} + \sigma^2_{\text{noise}}$$

각 항의 의미:

$$\text{Bias} = E[\hat{h}(x)] - h^*(x)$$

여기서 $h^*(x)$는 정답 함수이고, $E[\hat{h}(x)]$는 모델 예측의 평균.

"다양한 학습 데이터셋으로 학습시켰을 때, 예측의 평균이 정답에서 얼마나 떨어져 있나?"

$$\text{Variance} = E[(\hat{h}(x) - E[\hat{h}(x)])^2]$$

"다양한 학습 데이터셋으로 학습시켰을 때, 예측이 얼마나 흔들리나?"

$$\sigma^2_{\text{noise}} = \text{줄일 수 없는 노이즈}$$

**트레이드오프가 존재하는 이유**

- 모델을 단순하게 만들면 (예: 직선): bias ↑, variance ↓
  - 직선은 항상 비슷한 예측을 하지만(안정적), 곡선 패턴을 못 잡음(부정확)
  
- 모델을 복잡하게 만들면 (예: 10차 다항식): bias ↓, variance ↑
  - 복잡한 패턴도 잡을 수 있지만(정확할 수 있음), 데이터에 따라 예측이 크게 변함(불안정)

**정규화와의 관계**

정규화 강도 $\lambda$를 키우면:
- 모델이 단순해짐 → bias ↑, variance ↓
- 과적합 감소, 과소적합 가능성 증가

$\lambda$를 줄이면:
- 모델이 복잡해짐 → bias ↓, variance ↑
- 과소적합 감소, 과적합 가능성 증가

**최적 $\lambda$**: bias² + variance가 최소인 지점!

### 핵심 공식 정리

| 항목 | 공식 |
|------|------|
| 오차 분해 | $E[(y-\hat{h})^2] = \text{Bias}^2 + \text{Var} + \sigma^2$ |
| Bias | $E[\hat{h}(x)] - h^*(x)$ |
| Variance | $E[(\hat{h}(x) - E[\hat{h}(x)])^2]$ |
| Noise | $\sigma^2$ (줄일 수 없음) |

### 숫자로 확인

정답: $h^*(x) = 5$.

모델 A (단순): 5번 학습시킬 때마다 예측 = $[4, 4.2, 3.8, 4.1, 3.9]$
- 평균 = 4.0
- Bias = $4.0 - 5.0 = -1.0$, Bias² = 1.0
- Variance = $\frac{(0+0.04+0.04+0.01+0.01)}{5} = 0.02$

모델 B (복잡): 5번 학습시킬 때마다 예측 = $[3, 7, 5, 2, 8]$
- 평균 = 5.0
- Bias = $5.0 - 5.0 = 0$, Bias² = 0
- Variance = $\frac{(4+4+0+9+9)}{5} = 5.2$

| 모델 | Bias² | Variance | 합 |
|------|-------|----------|-----|
| A (단순) | 1.0 | 0.02 | 1.02 |
| B (복잡) | 0.0 | 5.20 | 5.20 |

모델 A가 총 오차가 더 작다! Bias가 있어도 variance가 낮아서 더 안정적.

### 다른 개념과의 연결

- **개념 33 (정규화)**: 정규화 강도가 bias-variance 균형을 결정
- **개념 26 (MAP)**: prior = bias 도입, 과적합(variance) 감소
- **개념 30 (경사 하강법)**: 조기 종료(early stopping)도 정규화의 일종 → bias-variance에 영향

### 자가 점검 문제

1. 다트판 비유로 높은 bias/낮은 variance와 낮은 bias/높은 variance를 설명하라.
2. 오차 분해 $E[(y-\hat{h})^2] = \text{Bias}^2 + \text{Var} + \sigma^2$에서 줄일 수 없는 항은 무엇인가?
3. 정규화 $\lambda$를 키우면 bias와 variance 각각 어떻게 변하는가?
4. "모델 복잡도"와 bias-variance의 관계를 설명하라.

## 문제 역추적 인덱스

> 각 시험 문제를 풀기 위해 필요한 개념들과 그 연결 흐름을 정리한다. 개념 번호는 Part 1(개념 1~12), Part 2(개념 13~24), Part 3(개념 25~35)를 참조한다.

### Q1: 벡터 내적과 CE Loss
**필요 개념**: 개념 5(벡터), 개념 6(내적), 개념 3(로그), 개념 27(교차 엔트로피)
**개념 연결 흐름**: 원-핫 벡터(개념5) → 내적으로 정답 클래스 선택(개념6) → 로그 씌우기(개념3) → CE Loss 완성(개념27)
**핵심 포인트**: 내적이 "정답 클래스만 골라내는" 메커니즘임을 이해. $\mathbf{e}_y^\top \log \mathbf{h}(x) = \log h_y(x)$로 축약되는 과정이 핵심.

### Q2: 고유값 계산
**필요 개념**: 개념 7(행렬), 개념 8(고유값/고유벡터), 개념 9(행렬식)
**개념 연결 흐름**: 행렬 $A$(개념7) → 특성방정식 $\det(A - \lambda I) = 0$(개념9) → 고유값 $\lambda$ 구하기(개념8) → 고유벡터 구하기(개념8) → 대각화(개념8)
**핵심 포인트**: $\det(A - \lambda I) = 0$을 풀어 고유값을 구하고, $(A - \lambda I)v = 0$으로 고유벡터를 구하는 전체 과정.

### Q3: 미분의 정의에서 도함수 유도
**필요 개념**: 개념 10(극한), 개념 11(미분의 정의)
**개념 연결 흐름**: 미분의 정의 $\lim_{h \to 0}\frac{f(x+h)-f(x)}{h}$(개념10,11) → 대수적 정리 → 도함수 공식 유도
**핵심 포인트**: 극한의 정의에서 출발하여 도함수를 직접 유도하는 과정. $h$로 나눌 수 있도록 식을 정리하는 테크닉.

### Q4: 편미분과 그래디언트
**필요 개념**: 개념 11(미분), 개념 12(편미분/그래디언트)
**개념 연결 흐름**: 다변수 함수 → 각 변수에 대해 편미분(개념12) → 그래디언트 벡터 구성(개념12) → 기울기 방향 해석
**핵심 포인트**: 그래디언트는 "함수가 가장 빠르게 증가하는 방향"을 가리키는 벡터. 경사 하강법(개념30)의 기초.

### Q5: 조건부 확률과 베이즈 정리
**필요 개념**: 개념 13(확률의 기본), 개념 14(조건부 확률), 개념 15(베이즈 정리)
**개념 연결 흐름**: 표본 공간 정의(개념13) → 조건부 확률 $P(A|B) = P(A \cap B)/P(B)$(개념14) → 베이즈 정리 적용(개념15) → 사후 확률 계산
**핵심 포인트**: 베이즈 정리 $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$의 각 항의 의미를 이해하고 적용.

### Q6: 베르누이 분포의 MLE
**필요 개념**: 개념 13(확률), 개념 16(독립), 개념 25(MLE), 개념 3(로그)
**개념 연결 흐름**: 베르누이 분포 정의(개념13) → 독립성 가정으로 우도 = 곱(개념16) → 로그 우도(개념3) → 미분해서 최적 $p$ 구하기(개념25)
**핵심 포인트**: 독립성 가정이 $L(\theta) = \prod p(x_i|\theta)$를 가능하게 하고, 로그 변환으로 곱을 합으로 바꿔 미분 가능하게 만드는 흐름.

### Q7: 특이값 분해 (SVD)
**필요 개념**: 개념 7(행렬), 개념 8(고유값/고유벡터), 개념 9(행렬식)
**개념 연결 흐름**: 행렬 $A$(개념7) → $A^TA$의 고유값 분해(개념8) → 특이값 = $\sqrt{\lambda}$ → $U, \Sigma, V^T$ 구성
**핵심 포인트**: SVD는 임의의 행렬을 분해하는 방법. $A^TA$와 $AA^T$의 고유값 분해에서 유도.

### Q8: 체인룰과 역전파
**필요 개념**: 개념 11(미분), 개념 12(편미분), 개념 31(역전파)
**개념 연결 흐름**: 합성 함수 정의 → 체인룰 $\frac{dL}{dx} = \frac{dL}{dy}\frac{dy}{dx}$(개념11) → 계산 그래프에서 역방향 적용(개념31) → 모든 파라미터의 그래디언트 계산
**핵심 포인트**: "local gradient × upstream gradient" 패턴. 각 노드에서 이 규칙을 반복 적용.

### Q9: 볼록 함수 (Convex Function)
**필요 개념**: 개념 11(미분), 개념 17(이차미분/헤시안), 개념 18(볼록성)
**개념 연결 흐름**: 함수 정의 → 이차미분 $\geq 0$ 확인(개념17) → 볼록성 증명(개념18) → 지역 최소 = 전역 최소 결론
**핵심 포인트**: 볼록 함수에서는 기울기=0인 점이 반드시 전역 최솟값. 이것이 최적화를 쉽게 만드는 이유.

### Q10: 가우시안 분포와 MSE 손실
**필요 개념**: 개념 13(확률), 개념 19(정규분포), 개념 25(MLE), 개념 3(로그)
**개념 연결 흐름**: 가우시안 노이즈 가정(개념19) → 우도 함수 작성(개념25) → 로그 우도(개념3) → 상수 제거 → MSE 형태 도출
**핵심 포인트**: "가우시안 분포 + MLE = MSE 손실 최소화"의 동치 관계. 왜 MSE를 쓰는가의 이론적 근거.

### Q11: 정규방정식 유도
**필요 개념**: 개념 7(행렬), 개념 12(편미분), 개념 28(정규방정식)
**개념 연결 흐름**: 손실 함수 $L = \frac{1}{2}\|Xw-y\|^2$ 설정 → 행렬 곱으로 전개(개념7) → 행렬 미분(개념12) → $\nabla L = 0$ 풀기(개념28)
**핵심 포인트**: 행렬 미분 공식 $\frac{\partial}{\partial w}(w^TAw) = 2Aw$와 $\frac{\partial}{\partial w}(b^Tw) = b$를 정확히 적용.

### Q12: 시그모이드 도함수 유도
**필요 개념**: 개념 11(미분), 개념 32(활성화 함수), 개념 31(역전파)
**개념 연결 흐름**: 시그모이드 정의 $\sigma(z) = \frac{1}{1+e^{-z}}$(개념32) → 체인룰로 미분(개념11) → $\sigma'(z) = \sigma(z)(1-\sigma(z))$ 도출 → 역전파에서의 효율성(개념31)
**핵심 포인트**: 도함수가 자기 자신으로 표현됨 → 순전파에서 계산한 $\sigma(z)$를 재사용하여 역전파 효율적.

### Q13: 라그랑주 승수법으로 소프트맥스 유도
**필요 개념**: 개념 20(라그랑주 승수법), 개념 29(소프트맥스), 개념 27(엔트로피)
**개념 연결 흐름**: 최대 엔트로피 원리(개념27) → 제약 조건 $\sum p_i = 1$ 설정 → 라그랑주 함수 구성(개념20) → 편미분 = 0 풀기 → 소프트맥스 형태 도출(개념29)
**핵심 포인트**: 소프트맥스가 "제약 조건하 엔트로피 최대화"에서 자연스럽게 유도되는 함수임을 이해.

### Q14: KL 발산의 성질
**필요 개념**: 개념 27(엔트로피/KL 발산), 개념 3(로그), 개념 18(볼록성)
**개념 연결 흐름**: KL 발산 정의(개념27) → $\log$의 오목성(개념3) → 젠센 부등식(개념18) 적용 → $KL \geq 0$ 증명 → 비대칭성 확인
**핵심 포인트**: KL 발산이 항상 $\geq 0$인 이유 (Gibbs 부등식)와, CE 최소화가 KL 최소화와 같은 이유.

### Q15: 테일러 전개
**필요 개념**: 개념 11(미분), 개념 21(테일러 급수)
**개념 연결 흐름**: 함수 $f(x)$의 $a$ 근처 근사(개념21) → $f(a) + f'(a)(x-a) + \frac{f''(a)}{2}(x-a)^2 + \cdots$ → 각 항의 의미 이해
**핵심 포인트**: 테일러 전개가 경사 하강법(1차 근사)과 뉴턴법(2차 근사)의 수학적 기초.


### Q16: 행렬 곱셈과 선형 변환
**필요 개념**: 개념 7(행렬), 개념 22(선형 변환)
**개념 연결 흐름**: 행렬의 정의(개념7) → 행렬 곱 = 선형 변환(개념22) → 기하학적 의미 (회전, 스케일링, 반사 등) → 신경망의 각 층이 선형 변환임을 이해
**핵심 포인트**: 행렬 곱셈이 "공간의 변환"이라는 기하학적 직관. $Ax$는 벡터 $x$를 새로운 공간으로 보내는 것.

### Q17: 기대값과 분산
**필요 개념**: 개념 13(확률), 개념 23(기대값), 개념 24(분산)
**개념 연결 흐름**: 확률 분포 정의(개념13) → 기대값 $E[X] = \sum x_i p_i$(개념23) → 분산 $\text{Var}[X] = E[(X-\mu)^2] = E[X^2] - (E[X])^2$(개념24) → 독립 변수의 성질
**핵심 포인트**: $\text{Var}[X] = E[X^2] - (E[X])^2$ 공식과, 독립일 때 $\text{Var}[X+Y] = \text{Var}[X] + \text{Var}[Y]$.

### Q18: 경사 하강법 단계별 계산
**필요 개념**: 개념 12(편미분/그래디언트), 개념 30(경사 하강법)
**개념 연결 흐름**: 손실 함수 정의 → 그래디언트 계산(개념12) → 업데이트 규칙 $\theta \leftarrow \theta - \eta \nabla L$(개념30) → 수치 예시로 수렴 확인
**핵심 포인트**: 학습률의 역할과, 단계별로 직접 계산하여 수렴 과정을 추적하는 능력.

### Q19: 확률의 독립성
**필요 개념**: 개념 13(확률), 개념 14(조건부 확률), 개념 16(독립)
**개념 연결 흐름**: 독립의 정의 $P(A \cap B) = P(A)P(B)$(개념16) → 조건부 확률과의 관계 $P(A|B) = P(A)$(개념14) → MLE에서 우도를 곱으로 쓸 수 있는 근거(개념25)
**핵심 포인트**: 독립성이 MLE의 우도 함수에서 곱 형태를 정당화하는 핵심 가정.

### Q20: 크로스 엔트로피 손실 유도
**필요 개념**: 개념 25(MLE), 개념 27(교차 엔트로피), 개념 29(소프트맥스), 개념 3(로그)
**개념 연결 흐름**: 분류 문제에서 MLE 목적함수(개념25) → 로그 우도 = 로그 소프트맥스 확률(개념29) → 부호 반전 → CE 손실(개념27) → NLL과 동치
**핵심 포인트**: CE Loss = NLL = -log(정답 클래스의 예측 확률). MLE, 정보이론, 손실 함수가 모두 하나로 연결.

### Q21: MAP 추정
**필요 개념**: 개념 15(베이즈 정리), 개념 25(MLE), 개념 26(MAP), 개념 33(정규화)
**개념 연결 흐름**: 베이즈 정리(개념15) → 사후 분포 최대화(개념26) → log posterior = log likelihood + log prior → 가우시안 prior 대입 → MSE + L2 형태 도출(개념33)
**핵심 포인트**: MAP = MLE + prior. 가우시안 prior → L2 정규화, $\lambda = \sigma^2/\tau^2$.

### Q22: 소프트맥스 자코비안
**필요 개념**: 개념 11(미분), 개념 29(소프트맥스), 개념 31(역전파)
**개념 연결 흐름**: 소프트맥스 정의(개념29) → 몫의 미분법 적용(개념11) → $i=j$와 $i \neq j$ 경우 분리 → $\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$ → 역전파에서 활용(개념31)
**핵심 포인트**: 자코비안의 두 가지 경우를 구분하고 하나의 공식으로 통합. CE + softmax 결합 시 $\nabla_z L = p - y$.

### Q23: 노름과 정규화
**필요 개념**: 개념 5(벡터), 개념 33(정규화), 개념 26(MAP)
**개념 연결 흐름**: L1/L2 노름 정의(개념5) → 정규화 항 추가(개념33) → L1의 희소성 (다이아몬드 vs 원) → MAP 관점에서의 해석(개념26)
**핵심 포인트**: L1이 희소해를 만드는 기하학적 이유와, L2가 가중치를 고르게 줄이는 이유.

### Q24: 계산 그래프와 역전파
**필요 개념**: 개념 11(미분), 개념 12(편미분), 개념 31(역전파)
**개념 연결 흐름**: 수식을 계산 그래프로 변환 → 순전파로 값 계산 → 역전파: 각 노드에서 local gradient × upstream gradient(개념31) → 모든 입력의 그래디언트 획득
**핵심 포인트**: 계산 그래프를 그리고, 역방향으로 체인룰을 적용하는 구체적 절차.

### Q25: 유사역행렬과 최소제곱
**필요 개념**: 개념 7(행렬), 개념 28(정규방정식), 개념 8(고유값)
**개념 연결 흐름**: 과결정/미결정 시스템(개념7) → $X^TX$가 역행렬이 없을 때(개념8) → 유사역행렬 $X^+ = (X^TX)^{-1}X^T$ 또는 SVD 기반 유사역행렬 → 최소 노름 해
**핵심 포인트**: 정규방정식의 확장. $X^TX$가 특이(singular)일 때의 처리 방법.

### Q26: 편향-분산 트레이드오프
**필요 개념**: 개념 23(기대값), 개념 24(분산), 개념 35(편향-분산), 개념 33(정규화)
**개념 연결 흐름**: 예측 오차를 기대값으로 분해(개념23) → $\text{Bias}^2 + \text{Variance} + \text{Noise}$(개념35) → 모델 복잡도와의 관계 → 정규화가 이 균형을 조절(개념33)
**핵심 포인트**: 다트판 비유를 수식으로 연결. 정규화 강도 $\lambda$가 bias-variance 트레이드오프를 제어.

### Q27: 호프딩 부등식과 일반화
**필요 개념**: 개념 13(확률), 개념 23(기대값), 개념 24(분산), 개념 16(독립)
**개념 연결 흐름**: i.i.d. 가정(개념16) → 표본 평균과 모집단 평균의 차이 확률 바운드 → 호프딩 부등식 $P(|\bar{X}-\mu| \geq t) \leq 2\exp(-2nt^2/(b-a)^2)$ → 훈련 오차와 테스트 오차의 관계
**핵심 포인트**: 샘플이 많을수록 표본 평균이 모집단 평균에 가까워진다는 것의 정량적 보장.

### Q28: 활성화 함수
**필요 개념**: 개념 32(활성화 함수), 개념 11(미분), 개념 31(역전파)
**개념 연결 흐름**: ReLU/Sigmoid/Tanh 정의(개념32) → 각각의 도함수(개념11) → 기울기 소실 문제(개념32) → ReLU가 해결하는 이유 → 왜 활성화가 필요한가(비선형성)
**핵심 포인트**: sigmoid 10층에서 $0.25^{10} \approx 10^{-6}$. ReLU는 양수 구간에서 도함수 1로 기울기 유지.

### Q29: 배치 정규화
**필요 개념**: 개념 23(기대값/평균), 개념 24(분산), 개념 34(배치 정규화)
**개념 연결 흐름**: 미니배치 평균/분산 계산(개념23,24) → 정규화 $\hat{x} = (x-\mu)/\sigma$(개념34) → $\gamma$, $\beta$로 복원(개념34) → 추론 시 running average
**핵심 포인트**: 4단계 과정 (평균→분산→정규화→스케일/시프트)과, 추론 시 running average를 사용하는 이유.

### Q30: 종합 문제 (순전파~역전파 전 과정)
**필요 개념**: 개념 7(행렬), 개념 29(소프트맥스), 개념 27(교차 엔트로피), 개념 31(역전파), 개념 30(경사 하강법), 개념 32(활성화 함수)
**개념 연결 흐름**: 입력 데이터(개념7) → 선형 변환 $z = Wx + b$ → 활성화 함수 적용(개념32) → 소프트맥스로 확률 변환(개념29) → CE 손실 계산(개념27) → 역전파로 그래디언트 계산(개념31) → GD로 파라미터 업데이트(개념30)
**핵심 포인트**: 딥러닝의 전체 파이프라인을 하나의 문제에서 처음부터 끝까지 추적. 모든 개념이 어떻게 연결되는지 종합적으로 이해.
