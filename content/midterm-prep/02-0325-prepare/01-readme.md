## 학습 가이드

### 교수님 평가 기준 (매우 중요)
> **최종 답안보다 답을 얻는 논리적 과정을 훨씬 더 중요하게 평가합니다.**

- 단순히 정답만 적으면 점수 **0점**
- Independence(독립성) 가정이 **어디서** 쓰였는지 명시
- 미분해서 0으로 놓은 이유를 **왜** 그렇게 하는지 설명
- 수식 나열이 아닌, **글로** 논리적 과정을 서술

### 추천 학습 순서

1. **1회독**: 문제만 읽고 직접 풀어보기 (Level 1 풀이 참고하지 않고)
