## 🔥 1. 벡터 (Vector) 기초

### 한 줄 결론

벡터는 "숫자를 줄 세워 놓은 것"이며, 딥러닝에서 모든 데이터(이미지, 텍스트, 음성)는 벡터로 표현됩니다.

---

### [입문 단계] 비전공자도 이해하는 직관

벡터를 처음 들으면 어렵게 느껴지지만, 사실 우리는 매일 벡터를 쓰고 있습니다.

- **쉽게 말하면:** 편의점에서 라면 3개, 삼각김밥 2개, 음료수 1개를 샀다고 해볼게요.
  이걸 숫자로 나열하면 [3, 2, 1] — 이것이 바로 벡터입니다!

- **또 다른 비유:** 네비게이션에서 "동쪽으로 3km, 북쪽으로 4km 가세요"라고 하면,
  이 이동을 [3, 4]라는 벡터로 표현할 수 있습니다. 방향과 크기를 동시에 담고 있죠.

- **딥러닝에서는?** 이미지의 각 픽셀 밝기를 숫자로 쭉 나열하면 벡터가 됩니다.
  28×28 크기의 손글씨 이미지 = 784개의 숫자를 나열한 벡터 [0.1, 0.8, 0.3, ..., 0.5]

💬 **퀴즈 1:** 키 170cm, 몸무게 65kg인 사람을 벡터로 표현하면?
→ 정답: [170, 65] (숫자를 순서대로 나열하면 벡터!)

---

### [중급 단계] 벡터의 연산

벡터끼리 더하고, 빼고, 숫자를 곱할 수 있습니다. 아주 쉽습니다.

**1) 벡터의 덧셈: 같은 위치끼리 더하기**

  a = [1, 2, 3]
  b = [4, 5, 6]
  a + b = [1+4, 2+5, 3+6] = [5, 7, 9]

이 수식의 의미는: 두 이동을 합친 것입니다. 동쪽 1km + 동쪽 4km = 동쪽 5km, 이런 식이죠.

**2) 벡터의 뺄셈: 같은 위치끼리 빼기**

  a = [5, 7, 9]
  b = [1, 2, 3]
  a - b = [5-1, 7-2, 9-3] = [4, 5, 6]

이 수식의 의미는: 두 벡터의 "차이"를 구한 것입니다. 딥러닝에서 (예측값 벡터 - 실제값 벡터)가 바로 오차 벡터!

**3) 스칼라 곱: 벡터에 숫자 하나를 곱하기**

  a = [1, 2, 3]
  2 × a = [2×1, 2×2, 2×3] = [2, 4, 6]

이 수식의 의미는: 벡터의 방향은 그대로, 크기만 2배로 키운 것입니다. 딥러닝에서 learning rate를 곱하는 것과 같은 원리!

---

### [고급 단계] 내적 (Dot Product) — 🔥 Self-Attention의 핵심!

**내적이란?** 두 벡터의 같은 위치 원소끼리 곱한 뒤, 그 결과를 모두 더한 것입니다.

  a = [1, 2, 3]
  b = [4, 5, 6]
  a · b = (1×4) + (2×5) + (3×6) = 4 + 10 + 18 = 32

이 수식의 의미는: 두 벡터가 **얼마나 같은 방향을 보고 있는지** (= 유사도)를 하나의 숫자로 알려줍니다.

**내적의 기하학적 의미:**

  a · b = ||a|| × ||b|| × cos(θ)

여기서 θ는 두 벡터 사이의 각도입니다.

- cos(0°) = 1 → 같은 방향 → 내적이 크다 → **"두 벡터가 비슷하다"**
- cos(90°) = 0 → 수직 → 내적이 0 → **"두 벡터가 완전히 다르다 (직교/orthogonal)"**
- cos(180°) = -1 → 반대 방향 → 내적이 음수 → **"두 벡터가 정반대다"**

**🔥 딥러닝 연결 — Self-Attention:**
Transformer(ChatGPT의 핵심 구조)에서 "이 단어와 저 단어가 얼마나 관련 있는가?"를 계산할 때,
각 단어를 벡터로 만든 뒤 **내적**을 구합니다. 내적 값이 크면 = 관련이 높다 = 더 많이 주목(Attention)!

💬 **퀴즈 2:** a = [1, 0]과 b = [0, 1]의 내적은? 이 두 벡터의 관계는?
→ 정답: a · b = (1×0) + (0×1) = 0. 내적이 0이므로 두 벡터는 **수직(orthogonal)**입니다.
  서로 완전히 독립적인 정보를 담고 있다는 뜻!

---

### [고급 단계] 노름 (Norm) — 정규화(Regularization)의 기초

**노름이란?** 벡터의 "크기(길이)"를 측정하는 방법입니다.

**L2 노름 (유클리드 노름) — 가장 많이 씀:**

  ||v||₂ = √(v₁² + v₂² + ... + vₙ²)

숫자 예시:
  v = [3, 4]
  ||v||₂ = √(3² + 4²) = √(9 + 16) = √25 = 5

이 수식의 의미는: [3, 4] 벡터의 길이는 5입니다. 피타고라스 정리 그 자체!
(가로 3, 세로 4인 직각삼각형의 빗변 = 5)

**L1 노름 (맨해튼 노름):**

  ||v||₁ = |v₁| + |v₂| + ... + |vₙ|

숫자 예시:
  v = [3, -4]
  ||v||₁ = |3| + |-4| = 3 + 4 = 7

이 수식의 의미는: 뉴욕 맨해튼에서 택시가 이동하는 거리처럼, 격자 길만 따라 가는 거리입니다.

**🔥 딥러닝 연결 — Regularization (정규화):**
- **L2 정규화 (Ridge):** 모델 파라미터 벡터의 L2 노름을 Loss에 더해서, 파라미터가 너무 커지지 않게 합니다.
  → 효과: 모든 파라미터가 골고루 작아짐 (오버피팅 방지)
- **L1 정규화 (Lasso):** 모델 파라미터 벡터의 L1 노름을 Loss에 더합니다.
  → 효과: 불필요한 파라미터가 정확히 0이 됨 (변수 선택 효과, 희소성)

---

### 💡 핵심 킬러 요약

1. 벡터 = 숫자의 나열 = 딥러닝에서 모든 데이터의 표현 방식
2. 내적 = 유사도 측정 도구 = Transformer Self-Attention의 핵심 연산
3. 내적이 0 = 수직(orthogonal) = 서로 독립적
4. L2 노름 = 벡터의 길이(피타고라스) → L2 정규화
5. L1 노름 = 절댓값 합 → L1 정규화 (희소성 유도)

### 🎯 결국 뭐가 중요한가 (Top 3)

1. **내적의 의미:** "두 벡터의 유사도"라는 기하학적 해석을 반드시 쓸 수 있어야 합니다. Self-Attention과 연결!
2. **L1 vs L2 노름의 차이:** 시험에서 "L1과 L2 정규화의 차이를 설명하시오"가 나오면, 노름의 정의부터 시작해야 합니다.
3. **직교(orthogonal)의 의미:** 내적 = 0 ↔ 수직 ↔ 서로 독립적 정보

### 📌 교수님 채점 기준 저격 포인트

- 내적을 설명할 때 **"같은 위치 원소끼리 곱해서 더한다"**라는 계산법만 쓰면 절반 점수.
  반드시 **"기하학적으로 두 벡터 간의 유사도(cosine similarity)를 나타낸다"**고 추가해야 만점.
- 정규화를 설명할 때, **"왜 L1은 희소성을 만들고 L2는 만들지 않는가?"**에 대한 직관도 준비하세요.
  → L1: 마름모 모양 제약 → 꼭짓점(축 위)에서 만남 → 0이 됨
  → L2: 원 모양 제약 → 축 위가 아닌 곳에서 만남 → 0이 되지 않음

### 📝 시험용 모범 답안

**문제:** "벡터의 내적(dot product)의 정의와 기하학적 의미를 설명하고, 딥러닝에서의 응용을 서술하시오."

**모범 답안:**
"벡터 a, b의 내적은 a·b = Σᵢ aᵢbᵢ로 정의되며, 기하학적으로 a·b = ||a|| ||b|| cos θ이다.
cos θ는 두 벡터 사이의 각도를 나타내므로, 내적은 두 벡터의 유사도(similarity)를 정량화한다.
특히, Transformer의 Self-Attention 메커니즘에서 Query와 Key 벡터의 내적을 통해
각 토큰 간의 관련성(attention score)을 계산하며, 이는 입력 시퀀스 내의
문맥적 관계를 포착하는 핵심 연산이다."

## 🔥 2. 행렬 (Matrix) 기초

### 한 줄 결론

행렬은 "숫자의 직사각형 표"이며, 딥러닝에서 뉴럴 네트워크의 각 층(layer)은 행렬 곱셈으로 작동합니다.

---

### [입문 단계] 비전공자도 이해하는 직관

- **쉽게 말하면:** 학교 시험 성적표를 떠올려 보세요.

  | 이름 | 국어 | 영어 | 수학 |
  |------|------|------|------|
  | 철수 |  90  |  85  |  70  |
  | 영희 |  80  |  95  |  88  |

  이 표의 숫자 부분만 떼어내면:

  A = | 90  85  70 |
      | 80  95  88 |

  이것이 2×3 행렬 (2행 3열)입니다. 행(가로줄)이 2개, 열(세로줄)이 3개!

- **딥러닝에서는?** 뉴럴 네트워크의 가중치(weight)들이 행렬로 저장됩니다.
  입력 벡터에 가중치 행렬을 곱하면 → 출력 벡터가 나옵니다. 이것이 한 층(layer)의 전부!

---

### [중급 단계] 행렬 곱셈 — Neural Network의 핵심 연산

행렬 곱셈은 딥러닝에서 **가장 많이** 수행되는 연산입니다. 규칙만 알면 어렵지 않습니다.

**규칙: (m × n) 행렬 × (n × p) 행렬 = (m × p) 행렬**

핵심: 앞 행렬의 열 수(n)와 뒷 행렬의 행 수(n)가 **반드시 같아야** 곱할 수 있습니다.

숫자 예시:

  A = | 1  2 |      B = | 5  6 |
      | 3  4 |          | 7  8 |

  A × B = | (1×5 + 2×7)  (1×6 + 2×8) |   =   | 19  22 |
          | (3×5 + 4×7)  (3×6 + 4×8) |       | 43  50 |

이 수식의 의미는: A의 각 행(가로줄)과 B의 각 열(세로줄)을 **내적**한 것입니다!
행렬 곱셈 = 내적을 여러 번 모아 놓은 것.

**🔥 딥러닝 연결 — 순전파 (Forward Pass):**

  입력: x = [x₁, x₂]  (2차원 입력)
  가중치: W = | w₁₁  w₁₂  w₁₃ |  (2×3 행렬)
              | w₂₁  w₂₂  w₂₃ |
  출력: y = x × W = [y₁, y₂, y₃]  (3차원 출력)

즉, 2차원 입력을 3차원 출력으로 변환한 것! 이것이 **선형 변환(Linear Transformation)**이며,
Neural Network의 한 층은 이런 행렬 곱셈 + 활성화 함수(ReLU 등)로 구성됩니다.

구체적 예시:

  입력: x = [1, 2]  (키와 몸무게를 의미한다고 상상)
  가중치: W = | 0.5  0.3  0.1 |
              | 0.2  0.4  0.6 |

  출력: y = [1×0.5 + 2×0.2,  1×0.3 + 2×0.4,  1×0.1 + 2×0.6]
           = [0.9, 1.1, 1.3]

2차원 입력 [1, 2]이 3차원 출력 [0.9, 1.1, 1.3]으로 변환되었습니다!

💬 **퀴즈 3:** (3×2) 행렬과 (2×4) 행렬을 곱하면 결과 행렬의 크기는?
→ 정답: (3×4). 앞의 행 수(3)와 뒤의 열 수(4)가 결과!

💬 **퀴즈 4:** (3×2) 행렬과 (3×4) 행렬을 곱할 수 있을까?
→ 정답: 불가능! 앞의 열 수(2)와 뒤의 행 수(3)가 다르므로 곱셈 불가.

---

### [중급 단계] 특수한 행렬들

**1) 전치 행렬 (Transpose): Aᵀ — 행과 열을 뒤집는다**

  A = | 1  2  3 |       Aᵀ = | 1  4 |
      | 4  5  6 |            | 2  5 |
                              | 3  6 |

이 수식의 의미는: 행(가로)을 열(세로)로, 열을 행으로 바꾼 것입니다.
원래 (2×3) → 전치 후 (3×2). 거울에 비친 것처럼 대각선을 기준으로 뒤집힘!

**딥러닝에서:** 역전파(Backpropagation) 시 가중치 행렬의 전치를 자주 사용합니다.

**2) 단위 행렬 (Identity Matrix): I — 곱해도 변하지 않는 행렬**

  I = | 1  0  0 |
      | 0  1  0 |
      | 0  0  1 |

이 수식의 의미는: 어떤 행렬 A에 단위행렬 I를 곱해도 A 그대로 나옵니다. A × I = I × A = A
숫자에서 ×1과 같은 역할! (1을 곱해도 숫자가 안 변하듯이)

숫자 예시:
  A = | 3  7 |      I = | 1  0 |
      | 2  5 |          | 0  1 |

  A × I = | 3×1+7×0  3×0+7×1 | = | 3  7 | = A (그대로!)
          | 2×1+5×0  2×0+5×1 |   | 2  5 |

**3) 역행렬 (Inverse Matrix): A⁻¹ — "되돌리기" 버튼**

  A × A⁻¹ = A⁻¹ × A = I (단위 행렬)

이 수식의 의미는: A라는 변환을 했다가, A⁻¹로 원래 상태로 되돌리는 것입니다.
숫자에서 ×3을 했다가 ×(1/3)으로 되돌리는 것과 같은 원리!

숫자 예시 (2×2 역행렬 구하기):

  A = | 2  1 |
      | 5  3 |

  A의 행렬식(determinant): det(A) = 2×3 - 1×5 = 6 - 5 = 1

  A⁻¹ = (1/det(A)) × |  3  -1 | = | 3  -1 |
                       | -5   2 |   |-5   2 |

  검증: A × A⁻¹ = | 2  1 | × | 3  -1 | = | 6-5    -2+2 | = | 1  0 | = I  ✓
                   | 5  3 |   |-5   2 |   | 15-15  -5+6 |   | 0  1 |

**⚠️ 중요:** 역행렬이 존재하려면 det(A) ≠ 0이어야 합니다!
det(A) = 0이면 역행렬이 없고, 이런 행렬을 **특이 행렬(singular matrix)**이라 합니다.

**4) 대칭 행렬 (Symmetric Matrix): A = Aᵀ**

  A = | 1  2  3 |
      | 2  5  4 |
      | 3  4  6 |

이 수식의 의미는: 대각선을 기준으로 위아래가 거울처럼 똑같은 행렬입니다.
(1행 2열의 값 = 2행 1열의 값, 1행 3열의 값 = 3행 1열의 값, ...)

**딥러닝에서:** 공분산 행렬, Hessian 행렬 등 중요한 행렬들이 대칭 행렬입니다.
대칭 행렬은 고유값이 항상 실수라는 좋은 성질이 있어서 분석이 쉽습니다.

---

### 💡 핵심 킬러 요약

1. 행렬 곱셈 = 내적의 모음 = Neural Network 순전파의 본체
2. (m×n) × (n×p) = (m×p) — 안쪽 차원이 같아야 곱할 수 있다
3. 전치(Aᵀ) = 행↔열 교환 → 역전파에서 등장
4. 역행렬(A⁻¹) = "되돌리기" → det(A) ≠ 0일 때만 존재
5. 대칭 행렬 = 고유값이 항상 실수 → Hessian, 공분산 행렬

### 🎯 결국 뭐가 중요한가 (Top 3)

1. **행렬 곱셈의 차원 규칙:** (m×n) × (n×p) = (m×p). 안쪽이 같아야 곱할 수 있다.
2. **선형 변환의 의미:** 행렬 곱셈 = 입력 공간을 출력 공간으로 변환. 딥러닝의 각 층이 이것!
3. **역행렬의 존재 조건:** det(A) ≠ 0. det(A) = 0이면 정보가 소실되어 되돌릴 수 없다.

### 📌 교수님 채점 기준 저격 포인트

- 행렬 곱셈을 설명할 때, 단순히 계산만 하지 말고 **"이는 선형 변환으로, 입력 벡터를 다른 차원의 출력 벡터로 mapping하는 것"**이라고 적어야 합니다.
- 역행렬 문제에서 **det(A) = 0인 경우를 반드시 언급**하세요. "역행렬이 존재하려면 det(A) ≠ 0이어야 하며, 이는 행렬의 행(또는 열)이 선형 독립임을 의미한다."

### 📝 시험용 모범 답안

**문제:** "딥러닝에서 행렬 곱셈이 어떤 역할을 하는지 설명하시오."

**모범 답안:**
"Neural Network의 각 층(layer)에서 입력 벡터 x에 가중치 행렬 W를 곱하는 연산 y = Wx + b가
수행된다. 이때 행렬 곱셈 Wx는 입력 공간에서 출력 공간으로의 선형 변환(linear transformation)이며,
학습이란 이 W의 값을 데이터에 맞게 조정하는 과정이다. 여기에 비선형 활성화 함수(ReLU 등)를
추가하여 비선형 변환을 가능하게 함으로써, 복잡한 패턴을 학습할 수 있다."

## 🔥 3. 선형 독립과 Rank

### 한 줄 결론

선형 독립은 "벡터들이 서로 새로운 정보를 제공하는가?"이고, Rank는 "행렬이 담고 있는 독립적인 정보의 양"입니다.

---

### [입문 단계] 비전공자도 이해하는 직관

- **쉽게 말하면:** 팀 프로젝트를 생각해 보세요.

  - **선형 독립:** 팀원 A는 코딩을 잘하고, 팀원 B는 디자인을 잘합니다.
    두 사람은 **서로 다른 능력**을 가져옵니다. → 선형 독립!

  - **선형 종속:** 팀원 A는 코딩을 잘하고, 팀원 C도 코딩을 잘합니다 (디자인 못 함).
    팀원 C는 **A가 이미 제공하는 능력의 복사본**입니다. → 선형 종속!
    C를 빼도 팀의 능력은 줄지 않습니다.

  - **Rank:** 팀에 정말 "서로 다른 역할"을 하는 사람이 몇 명인가? 그것이 Rank!
    위 예시에서 A, B, C 세 명이지만 진짜 독립적인 역할은 2개 → Rank = 2

---

### [중급 단계] 수학적 정의

**선형 독립 (Linear Independence):**
벡터 v₁, v₂, ..., vₖ가 선형 독립이란,
c₁v₁ + c₂v₂ + ... + cₖvₖ = 0 을 만족하는 유일한 해가 c₁ = c₂ = ... = cₖ = 0인 경우입니다.

이 수식의 의미는: "이 벡터들을 아무리 섞어 봐도 영벡터(0)를 만들 수 없다" = 어떤 벡터도 다른 벡터들로 표현 불가.

숫자 예시 — 선형 독립:

  v₁ = [1, 0]
  v₂ = [0, 1]

  c₁[1, 0] + c₂[0, 1] = [0, 0]
  → [c₁, c₂] = [0, 0] (유일한 해)
  → 선형 독립! (v₁은 동쪽, v₂는 북쪽 — 서로 완전히 다른 방향)

숫자 예시 — 선형 종속:

  v₁ = [1, 2]
  v₂ = [2, 4]

  v₂ = 2 × v₁ (v₂는 v₁의 2배일 뿐!)
  → c₁ = 2, c₂ = -1로 놓으면: 2[1,2] + (-1)[2,4] = [0,0]
  → 0이 아닌 해가 존재! → 선형 종속!

**Rank: 행렬에서 선형 독립인 행(또는 열)의 최대 개수**

  A = | 1  2  3 |
      | 2  4  6 |
      | 0  1  1 |

2행 = 2 × 1행이므로, 독립인 행은 1행과 3행뿐.
→ rank(A) = 2

**중요한 성질:**
  rank(A) ≤ min(m, n)   (m×n 행렬에서)

이 수식의 의미는: Rank는 행 수와 열 수 중 작은 값을 넘을 수 없습니다.
3×5 행렬이면 rank ≤ 3. 모든 행이 독립이더라도 최대 3개밖에 안 되니까요.

---

### [고급 단계] 영공간과 Rank-Nullity Theorem

**영공간 (Null Space / Kernel):** Ax = 0을 만족하는 모든 벡터 x의 집합

이 수식의 의미는: 행렬 A를 곱했을 때 "사라져 버리는" 벡터들의 모임입니다.
이 벡터들은 A라는 변환에 의해 정보가 완전히 소실됩니다.

숫자 예시:

  A = | 1  2 |
      | 2  4 |

  Ax = 0:
  | 1  2 | × | x₁ | = | 0 |
  | 2  4 |   | x₂ |   | 0 |

  1행: x₁ + 2x₂ = 0 → x₁ = -2x₂
  해: x = t × [-2, 1] (t는 임의의 실수)

  영공간 = {t[-2, 1] : t ∈ ℝ} → 차원(nullity) = 1

**Rank-Nullity Theorem (랭크-널리티 정리):**

  n = rank(A) + nullity(A)

여기서 n은 열의 수입니다.

숫자 예시로 확인:
  위의 A는 2×2 행렬 (n = 2)
  rank(A) = 1 (두 행이 종속이므로 독립인 행은 1개)
  nullity(A) = 1 (위에서 구한 영공간의 차원)
  → 2 = 1 + 1  ✓

이 수식의 의미는: 열의 수(전체 정보량) = 독립적 정보량(rank) + 소실된 정보량(nullity)

**🔥 딥러닝 연결:** 이것은 선형 시스템 Ax = b의 해의 존재성과 유일성을 판단하는 핵심 도구입니다.
- rank(A) = n (full column rank) → 해가 유일하거나 없음
- rank(A) < n → 무한히 많은 해 (자유도가 있음)

💬 **퀴즈 5:** 3×4 행렬의 rank가 3이면, nullity는?
→ 정답: n - rank = 4 - 3 = 1. 영공간의 차원이 1이므로, Ax=0의 해 공간은 1차원 직선입니다.

---

### 💡 핵심 킬러 요약

1. 선형 독립 = 벡터들이 서로 "새로운 정보" 제공 = 중복 없음
2. 선형 종속 = 어떤 벡터가 다른 벡터의 조합으로 표현 가능 = 중복 있음
3. Rank = 독립인 행(또는 열)의 수 = 행렬의 "실질적 정보량"
4. Rank-Nullity: n = rank + nullity (전체 = 유용한 정보 + 소실된 정보)

### 🎯 결국 뭐가 중요한가 (Top 3)

1. **선형 독립/종속 판별:** c₁v₁ + c₂v₂ + ... = 0에서 자명해(모두 0)만 존재하면 독립.
2. **Rank의 의미:** 행렬이 가진 "실질적 정보의 차원 수". rank가 낮으면 정보가 중복/소실.
3. **Rank-Nullity Theorem:** n = rank + nullity. 시험에서 rank 또는 nullity 중 하나를 구할 때 필수!

### 📌 교수님 채점 기준 저격 포인트

- 선형 독립을 설명할 때, **"자명해(trivial solution)만 존재"**라는 용어를 반드시 사용하세요.
- Rank를 구할 때, "행 사다리꼴(row echelon form)로 변환 후 영이 아닌 행의 수"라고 방법도 언급하면 가점.
- **Rank와 LoRA의 연결:** "Low-rank adaptation은 가중치 행렬을 rank가 낮은 두 행렬의 곱으로 근사하여 파라미터 수를 줄이는 기법"이라고 쓸 수 있으면 최고.

### 📝 시험용 모범 답안

**문제:** "Rank-Nullity Theorem을 설명하고, 선형 시스템의 해와의 관계를 서술하시오."

**모범 답안:**
"m×n 행렬 A에 대해 n = rank(A) + nullity(A)가 성립한다.
rank(A)는 A의 선형 독립인 열의 최대 개수이고, nullity(A)는 Ax=0의 해 공간의 차원이다.
Ax=b 시스템에서, rank(A) = rank([A|b])이면 해가 존재하고,
이때 rank(A) = n이면 유일한 해, rank(A) < n이면 무한히 많은 해가 존재한다.
nullity가 크다는 것은 변환 A에 의해 소실되는 정보가 많다는 의미이다."

## 🔥 4. 고유값과 고유벡터 (Eigenvalues & Eigenvectors)

### 한 줄 결론

고유벡터는 행렬(변환)에 의해 "방향이 바뀌지 않는 특별한 벡터"이고, 고유값은 그때 "크기가 몇 배 변하는지"를 나타냅니다.

---

### [입문 단계] 비전공자도 이해하는 직관

- **쉽게 말하면:** 거센 바람(= 행렬 A)이 불고 있다고 상상해 보세요.
  바람을 맞으면 대부분의 사람(= 벡터)은 방향이 바뀌어 이리저리 날아갑니다.
  그런데 **딱 바람 방향으로 서 있는 사람**은? 방향은 안 바뀌고 그냥 뒤로 밀리기만 합니다.

  이때:
  - **고유벡터 (Eigenvector):** 바람(A)을 맞아도 방향이 안 바뀌는 특별한 방향의 사람
  - **고유값 (Eigenvalue):** 그 사람이 얼마나 세게 밀려나는지 (2배? 3배? 0.5배?)

- **수식으로:** Av = λv

  이 수식의 의미는: 행렬 A를 벡터 v에 곱했더니, 방향은 그대로인데 크기만 λ배가 되었다!
  v가 고유벡터, λ가 고유값.

---

### [중급 단계] 고유값/고유벡터 구하기

**구하는 방법:** det(A - λI) = 0 을 풀어서 λ(고유값)를 구하고, 각 λ에 대해 (A - λI)v = 0을 풀어 v(고유벡터)를 구합니다.

숫자 예시 (2×2):

  A = | 4  1 |
      | 2  3 |

  **1단계: 고유값 구하기**
  det(A - λI) = 0

  A - λI = | 4-λ   1  |
           |  2   3-λ |

  det = (4-λ)(3-λ) - (1)(2) = 0
      = 12 - 4λ - 3λ + λ² - 2 = 0
      = λ² - 7λ + 10 = 0
      = (λ - 5)(λ - 2) = 0

  → λ₁ = 5, λ₂ = 2

  이 수식의 의미는: 행렬 A는 두 개의 특별한 방향이 있고, 하나는 5배, 다른 하나는 2배로 늘린다.

  **2단계: 고유벡터 구하기**

  λ₁ = 5일 때:
  (A - 5I)v = 0
  | -1  1 | × | v₁ | = | 0 |
  |  2 -2 |   | v₂ |   | 0 |

  -v₁ + v₂ = 0 → v₂ = v₁
  → v₁ = [1, 1] (또는 이 방향의 임의의 배수)

  λ₂ = 2일 때:
  (A - 2I)v = 0
  | 2  1 | × | v₁ | = | 0 |
  | 2  1 |   | v₂ |   | 0 |

  2v₁ + v₂ = 0 → v₂ = -2v₁
  → v₂ = [1, -2] (또는 이 방향의 임의의 배수)

  **검증:**
  A × v₁ = | 4  1 | × | 1 | = | 5 | = 5 × | 1 | ✓ (방향 그대로, 5배!)
            | 2  3 |   | 1 |   | 5 |       | 1 |

  A × v₂ = | 4  1 | × | 1  | = |  2 | = 2 × | 1  | ✓ (방향 그대로, 2배!)
            | 2  3 |   | -2 |   | -4 |       | -2 |

---

### [고급 단계] 대칭 행렬의 고유값 성질과 양정치 행렬

**대칭 행렬의 특별한 성질:**
대칭 행렬(A = Aᵀ)의 고유값은 **항상 실수**입니다. (허수가 나오지 않음!)
또한 서로 다른 고유값에 대응하는 고유벡터들은 **직교(orthogonal)**합니다.

이 수식의 의미는: 대칭 행렬은 분석하기가 훨씬 편합니다. 모든 성질이 "깔끔"합니다.

**🔥 양정치 행렬 (Positive Definite): 모든 고유값 > 0**

숫자 예시:

  A = | 2  1 |
      | 1  2 |

  고유값: det(A - λI) = (2-λ)² - 1 = 0
  → λ² - 4λ + 3 = 0 → (λ-3)(λ-1) = 0
  → λ₁ = 3, λ₂ = 1

  두 고유값 모두 > 0 → A는 양정치 행렬!

**왜 중요한가? → 볼록 함수(Convex)의 조건 → 최적화에서 유일한 최소값 보장!**

딥러닝에서 Loss 함수의 **Hessian 행렬**(2차 미분으로 만든 행렬)이 양정치이면,
그 지점은 **볼록(convex)**하므로 유일한 최소값이 보장됩니다.

- 양정치 (모든 고유값 > 0): 모든 방향으로 "위로 볼록한 그릇" 모양 → **유일한 최소값 존재**
- 양반정치 (모든 고유값 ≥ 0): 어떤 방향은 평평할 수 있지만, 아래로 파이지는 않음
- 부정치 (모든 고유값 < 0): 모든 방향으로 "아래로 볼록" → 유일한 최대값
- 비정부호 (양수/음수 고유값 혼재): 안장점(saddle point) → 최소도 최대도 아닌 불안정 지점

💬 **퀴즈 6:** 고유값이 λ₁ = 3, λ₂ = -1인 행렬은 양정치인가?
→ 정답: 아닙니다. λ₂ = -1 < 0이므로 양정치가 아닙니다. 이 행렬의 2차 형식은 안장점을 가집니다.

---

### [고급 단계] 고유값 분해 (Eigendecomposition)

대칭 행렬 A는 다음과 같이 분해할 수 있습니다:

  A = QΛQ⁻¹

여기서:
- Q: 고유벡터들을 열로 나열한 행렬
- Λ: 고유값들을 대각선에 놓은 대각 행렬
- Q⁻¹: Q의 역행렬 (대칭 행렬이면 Q⁻¹ = Qᵀ, 즉 A = QΛQᵀ)

숫자 예시:

  A = | 2  1 |,  고유값: λ₁=3, λ₂=1
      | 1  2 |

  고유벡터:
  λ₁=3: v₁ = [1, 1] → 정규화: [1/√2, 1/√2]
  λ₂=1: v₂ = [1, -1] → 정규화: [1/√2, -1/√2]

  Q = | 1/√2   1/√2 |,  Λ = | 3  0 |
      | 1/√2  -1/√2 |       | 0  1 |

  A = QΛQᵀ (검증 가능!)

이 수식의 의미는: 행렬 A의 "본질"은 고유값과 고유벡터에 있습니다.
A라는 변환은 "고유벡터 방향으로 좌표를 바꾸고(Q), 각 축 방향으로 고유값만큼 늘리고(Λ), 다시 원래 좌표로 돌아오는(Qᵀ)" 것입니다.

**Power Method (거듭제곱법):**
행렬 A를 벡터에 반복적으로 곱하면, 가장 큰 고유값에 대응하는 고유벡터 방향으로 수렴합니다.

  v → Av → A²v → A³v → ... → λ₁ⁿ × (v₁ 방향)

이 수식의 의미는: 가장 큰 고유값이 반복할수록 지배적이 되기 때문입니다.
**Google PageRank**가 바로 이 원리! 웹페이지 간 링크 행렬을 반복 곱해서 가장 중요한 페이지를 찾습니다.

---

### 💡 핵심 킬러 요약

1. Av = λv: 행렬은 고유벡터의 방향을 바꾸지 않고 크기만 λ배 변환
2. 대칭 행렬 → 고유값 항상 실수 + 고유벡터 직교
3. 양정치 (모든 λ > 0) → 볼록 → 유일한 최소값 보장 → 최적화에서 핵심!
4. 고유값 분해 A = QΛQᵀ: 행렬의 본질을 드러냄
5. Power method → 가장 큰 고유값 찾기 → PageRank

### 🎯 결국 뭐가 중요한가 (Top 3)

1. **Av = λv의 의미:** "방향 불변, 크기만 변화"를 글로 설명할 수 있어야 합니다.
2. **양정치 행렬과 볼록함수의 연결:** Hessian이 양정치 → Loss가 볼록 → 유일한 최소값 → 최적화 보장
3. **고유값의 부호가 알려주는 것:** 양수→볼록, 음수→오목, 혼합→안장점

### 📌 교수님 채점 기준 저격 포인트

- 고유값/고유벡터를 구하는 문제에서, det(A - λI) = 0이라는 **특성방정식(characteristic equation)**을 명시하세요.
- 양정치 행렬을 설명할 때, **"모든 0이 아닌 벡터 x에 대해 xᵀAx > 0"**이라는 정의도 함께 쓰면 만점.
  (이것은 "어떤 방향으로 가도 함수값이 양수" = "그릇 모양"이라는 뜻)
- **Hessian 연결:** "Loss 함수의 Hessian 행렬이 양정치이면 해당 critical point는 local minimum이다"

### 📝 시험용 모범 답안

**문제:** "양정치 행렬(Positive Definite Matrix)의 정의를 쓰고, 딥러닝 최적화에서 왜 중요한지 설명하시오."

**모범 답안:**
"대칭 행렬 A가 양정치(positive definite)라 함은, 모든 영이 아닌 벡터 x에 대해
xᵀAx > 0이 성립하는 것이다. 이는 A의 모든 고유값이 양수인 것과 동치이다.
딥러닝에서 Loss 함수 L(θ)의 Hessian 행렬 H = ∂²L/∂θ²가 양정치이면,
해당 θ에서 L은 locally convex이므로 그 점은 local minimum이 된다.
이는 경사하강법으로 찾은 해가 실제로 오차를 최소화하는 점임을 보장한다.
반대로 Hessian의 고유값 중 음수가 있으면 안장점(saddle point)이며, 이는 최소값이 아니다."

## 💡 5. 특이값 분해 (SVD: Singular Value Decomposition)

### 한 줄 결론

SVD는 **어떤 행렬이든** (정방행렬이 아니어도!) 세 개의 행렬로 깔끔하게 분해하는 만능 도구이며, 차원 축소·이미지 압축·PCA의 수학적 기반입니다.

---

### [입문 단계] 비전공자도 이해하는 직관

- **쉽게 말하면:** 요리를 생각해 보세요.

  - **고유값 분해:** 정사각형 케이크(정방행렬)만 분해할 수 있는 칼입니다.
  - **SVD:** 직사각형 빵(아무 행렬이나)도 분해할 수 있는 만능 칼입니다!

  복잡한 데이터(큰 행렬)를 가지고 있을 때, SVD로 분해하면
  "가장 중요한 정보"와 "덜 중요한 정보"를 깔끔하게 분리할 수 있습니다.
  중요한 것만 남기면 = **차원 축소** = 데이터가 가벼워짐!

- **이미지 압축 비유:** 1000×1000 해상도의 사진이 있다고 해볼게요.
  SVD로 분해하면 "이 사진에서 가장 중요한 패턴 순서대로" 정렬됩니다.
  상위 50개 패턴만 남기면? 사진이 조금 흐려지지만 파일 크기는 1/20로 줄어듭니다!

---

### [중급 단계] SVD의 구조

**A = UΣVᵀ**

여기서 A는 m×n 행렬이고:
- U: m×m **직교 행렬** (UᵀU = I). 행 공간의 기저. "입력 패턴"
- Σ (시그마): m×n **대각 행렬**. 대각 원소 = 특이값 σ₁ ≥ σ₂ ≥ ... ≥ 0. "각 패턴의 중요도"
- Vᵀ: n×n **직교 행렬** (VᵀV = I). 열 공간의 기저. "출력 패턴"

이 수식의 의미는: 어떤 변환 A도 "회전(V) → 스케일링(Σ) → 다시 회전(U)"의 3단계로 분해 가능!

숫자 예시 (2×2):

  A = | 3  0 |
      | 0  2 |

  이 경우 이미 대각행렬이므로 SVD가 매우 간단합니다:
  U = | 1  0 |,  Σ = | 3  0 |,  V = | 1  0 |
      | 0  1 |       | 0  2 |       | 0  1 |

  특이값: σ₁ = 3, σ₂ = 2

좀 더 의미 있는 예시 (2×3):

  A = | 1  0  1 |
      | 0  1  0 |

  AᵀA = | 1  0  1 |     AAᵀ = | 2  0 |
         | 0  1  0 |            | 0  1 |
         | 1  0  1 |

  AAᵀ의 고유값: λ₁ = 2, λ₂ = 1
  특이값: σ₁ = √2, σ₂ = 1

**특이값과 고유값의 관계:**

  σᵢ = √(AᵀA의 고유값 λᵢ)

이 수식의 의미는: 특이값은 AᵀA의 고유값에 루트를 씌운 것입니다.
AᵀA는 항상 양반정치이므로 고유값 ≥ 0 → 특이값도 항상 ≥ 0!

---

### [고급 단계] SVD의 딥러닝 응용

**1) 차원 축소 (Dimensionality Reduction):**
특이값이 큰 것 k개만 남기면 (나머지는 0으로 만들면),
원래 행렬을 rank-k 행렬로 근사할 수 있습니다.

  A ≈ Aₖ = UₖΣₖVₖᵀ

**Eckart-Young 정리:** 이 rank-k 근사가 Frobenius 노름 기준으로 **최적의 근사**입니다!
즉, 정보 손실을 최소화하면서 차원을 줄이는 최고의 방법.

숫자 예시 (이미지 압축 원리):
  1000×1000 이미지 행렬 A의 특이값이:
  σ₁=500, σ₂=300, σ₃=100, σ₄=50, σ₅=10, ...

  상위 3개만 남기면:
  - 원래 저장 용량: 1000×1000 = 1,000,000개 숫자
  - 근사 저장 용량: 1000×3 + 3 + 3×1000 = 6,003개 숫자
  - 압축률: 약 99.4% 압축! 하지만 대부분의 정보는 보존.

**2) PCA (주성분 분석)의 기초:**
데이터의 공분산 행렬에 SVD를 적용하면, 분산이 가장 큰 방향(주성분)을 찾을 수 있습니다.
첫 번째 주성분 = 데이터의 분산이 가장 큰 방향 = 가장 중요한 패턴.

**3) Low-rank Approximation → LoRA!**
대규모 언어 모델(LLM)의 가중치 행렬 W를 직접 학습하면 파라미터가 너무 많습니다.
LoRA는 W의 변화량 ΔW를 low-rank 행렬로 근사합니다: ΔW ≈ BA (B는 d×r, A는 r×d, r << d)
이것이 SVD의 low-rank approximation 아이디어를 직접 활용한 것!

💬 **퀴즈 7:** 100×100 행렬의 특이값 중 상위 5개만 남기면, 근사 행렬의 rank는?
→ 정답: 5. k개의 특이값만 남기면 rank-k 행렬이 됩니다.

### 💡 핵심 킬러 요약

1. SVD: A = UΣVᵀ. 어떤 행렬이든 분해 가능 (정방행렬이 아니어도!)
2. 특이값 σ = √(AᵀA의 고유값). 항상 0 이상.
3. 특이값이 큰 것만 남기면 = 최적의 차원 축소 (Eckart-Young 정리)
4. PCA의 수학적 기반 = 공분산 행렬의 SVD
5. LoRA = SVD의 low-rank approximation 아이디어 직접 활용

### 🎯 결국 뭐가 중요한가 (Top 3)

3. **Low-rank approximation의 활용:** 이미지 압축, PCA, LoRA 등 실질적 응용.

### 📌 교수님 채점 기준 저격 포인트

- SVD를 설명할 때 **"고유값 분해와의 차이"**를 반드시 언급하세요: "고유값 분해는 정방행렬에만 적용 가능하지만, SVD는 임의의 m×n 행렬에 적용 가능하다."
- 차원 축소 문제에서 **Eckart-Young 정리**를 언급하면 가점: "rank-k 근사 중 Frobenius 노름을 최소화하는 것은 SVD의 상위 k개 특이값을 사용한 근사이다."
- **PCA와의 연결:** "PCA에서 주성분은 데이터 공분산 행렬의 고유벡터이며, 이는 데이터 행렬의 SVD에서 V의 열벡터에 대응한다."

**모범 답안:**

## 💡 6. 최소제곱법과 유사역행렬 (Least Squares & Pseudoinverse)

### 한 줄 결론

Ax = b에 정확한 해가 없을 때, "가장 가까운 해"를 찾는 방법이 최소제곱법이며, 이것이 Linear Regression의 수학적 본질입니다.

---

### [입문 단계] 비전공자도 이해하는 직관

- **쉽게 말하면:** 시험 문제를 풀 때, 정확한 답을 모르면 어떻게 하나요?
  "가장 그럴듯한 답"을 적죠! 최소제곱법도 똑같습니다.

  데이터가 100개 있는데, 이 데이터를 **완벽하게** 지나는 직선은 없다고 해봅시다.
  (현실에서 데이터에 노이즈가 있으므로 완벽한 직선은 거의 불가능)
  그러면 "최대한 모든 점에 가까이 지나는 직선"을 찾는 것이 최선!

  각 데이터 점과 직선 사이의 **거리(오차)를 제곱해서 모두 더한 값**이 가장 작은 직선 = 최소제곱 해.

- **sample_1.txt 와의 연결:** 기억나시죠? 가우시안 분포 가정 → Log trick → MSE가 튀어나온다!
  그 MSE를 최소화하는 것이 바로 최소제곱법입니다. 같은 이야기를 다른 각도에서 보는 것!

---

### [중급 단계] 유사역행렬 (Pseudoinverse)

**문제:** Ax = b를 풀고 싶은데, A가 정방행렬이 아니거나 역행렬이 없으면?

**해결:** 유사역행렬 A⁺를 사용합니다!

  A⁺ = (AᵀA)⁻¹Aᵀ

이 수식의 의미는: A의 역행렬이 없어도, "역행렬 비슷한 것"을 만들어서 해를 구하겠다!

**최소제곱해:**

  x̂ = A⁺b = (AᵀA)⁻¹Aᵀb

이 수식의 의미는: ||Ax - b||² (오차의 제곱합)을 최소화하는 x를 구하는 공식!

숫자 예시:

  데이터: (1, 2), (2, 3), (3, 5)
  → y = ax + b 형태의 직선을 찾고 싶다

  행렬로 표현:
  A = | 1  1 |    b = | 2 |
      | 2  1 |        | 3 |
      | 3  1 |        | 5 |

  (A의 첫째 열 = x 값, 둘째 열 = 1 (절편을 위해))

  AᵀA = | 1  2  3 | × | 1  1 | = | 14  6 |
         | 1  1  1 |   | 2  1 |   |  6  3 |
                        | 3  1 |

  Aᵀb = | 1  2  3 | × | 2 | = | 23 |
         | 1  1  1 |   | 3 |   | 10 |
                        | 5 |

  (AᵀA)⁻¹ = (1/(14×3 - 6×6)) × |  3  -6 | = (1/6) × |  3  -6 |
                                   | -6  14 |            | -6  14 |

  x̂ = (AᵀA)⁻¹ × Aᵀb = (1/6) × |  3  -6 | × | 23 | = (1/6) × | 69-60  | = (1/6) × |  9 | = | 1.5  |
                                   | -6  14 |   | 10 |            | -138+140|           |  2 |   | 1/3  |

  → y = 1.5x + 1/3 (≈ 0.33)

  검증:
  x=1: y = 1.5 + 0.33 = 1.83 (실제 2, 오차 0.17)
  x=2: y = 3.0 + 0.33 = 3.33 (실제 3, 오차 0.33)
  x=3: y = 4.5 + 0.33 = 4.83 (실제 5, 오차 0.17)

  완벽하지는 않지만, 오차의 제곱합이 최소인 직선!

---

### [고급 단계] 도출 과정과 딥러닝 연결

**최소제곱해의 도출:**

  최소화 목표: ||Ax - b||² = (Ax - b)ᵀ(Ax - b)

  이것을 x에 대해 미분하여 0으로 놓으면:

  ∂/∂x ||Ax - b||² = 2Aᵀ(Ax - b) = 0
  → AᵀAx = Aᵀb
  → x = (AᵀA)⁻¹Aᵀb  (AᵀA가 역행렬 가능할 때)

이 수식의 의미는: "오차의 제곱합을 미분해서 0이 되는 지점을 찾는다" — sample_1에서 배운
"미분해서 0을 찾는다"가 여기서도 그대로 적용됩니다!

**🔥 딥러닝 연결 — Linear Regression의 Closed-form Solution:**

y = Wx + b를 학습할 때, 경사하강법(Gradient Descent)을 쓰지 않고도
위의 공식 W = (XᵀX)⁻¹Xᵀy로 한 번에 최적해를 구할 수 있습니다!

그런데 왜 딥러닝에서는 이 공식 대신 경사하강법을 쓸까요?
- (XᵀX)⁻¹ 계산: O(n³) 복잡도 → 데이터가 수백만 개면 계산 불가능!
- 행렬이 특이(singular)하면 역행렬이 존재하지 않음
- 비선형 모델(Neural Network)에는 closed-form solution이 없음

💬 **퀴즈 8:** Linear Regression에서 closed-form solution이 있는데 왜 경사하강법을 쓸까요?
→ 정답: (1) 역행렬 계산의 O(n³) 복잡도가 대규모 데이터에서 비현실적이고,
(2) 비선형 모델에는 closed-form이 존재하지 않으며,
(3) mini-batch SGD로 근사하면 메모리/시간 효율적이기 때문입니다.

---

### 💡 핵심 킬러 요약

1. Ax = b에 정확한 해가 없으면 → ||Ax - b||²를 최소화하는 해를 찾음
2. 최소제곱해: x̂ = (AᵀA)⁻¹Aᵀb (유사역행렬 A⁺ 사용)
3. 도출: 오차 제곱합을 미분해서 0 → 정규방정식(Normal Equation) AᵀAx = Aᵀb
4. Linear Regression의 closed-form = 최소제곱법 그 자체
5. 실전에서는 계산량 때문에 경사하강법(SGD)을 선호

### 🎯 결국 뭐가 중요한가 (Top 3)

1. **유사역행렬 공식:** A⁺ = (AᵀA)⁻¹Aᵀ를 외우고, 의미("역행렬이 없어도 최적해를 구하는 도구")를 설명.
2. **정규방정식과 MSE의 연결:** ||Ax-b||² 최소화 → 미분해서 0 → AᵀAx = Aᵀb.
3. **Closed-form vs SGD:** 왜 closed-form이 있는데도 SGD를 쓰는지 이유 3가지 서술.

### 📌 교수님 채점 기준 저격 포인트

- 최소제곱법을 도출할 때, **"||Ax-b||²을 x에 대해 미분하여 0으로 놓으면"**이라는 과정을 반드시 보여주세요.
  (sample_1에서 배운 "미분해서 0 찾기"와 동일한 논리입니다!)
- **"AᵀA가 역행렬 가능해야 한다"**는 조건도 꼭 명시하세요.
  AᵀA가 역행렬 불가능하면? → SVD 기반 유사역행렬(Moore-Penrose pseudoinverse)을 씁니다.
- sample_1에서 배운 내용과의 연결: **"가우시안 분포 가정 → MLE → MSE 최소화 → 최소제곱법"**이 하나의 일관된 논리 체인임을 보여주면 최고 점수.

### 📝 시험용 모범 답안

**문제:** "최소제곱법(Least Squares)의 도출 과정을 서술하고, Linear Regression과의 관계를 설명하시오."

**모범 답안:**
"Ax = b에서 정확한 해가 존재하지 않을 때, 잔차(residual) r = Ax - b의 L2 노름 제곱
||Ax - b||²를 최소화하는 x를 구한다. 이를 x에 대해 미분하면
∂/∂x ||Ax-b||² = 2Aᵀ(Ax-b) = 0이 되어 정규방정식 AᵀAx = Aᵀb를 얻고,
AᵀA가 가역이면 x̂ = (AᵀA)⁻¹Aᵀb이다.
이는 Linear Regression에서 MSE를 최소화하는 가중치의 closed-form solution과 동일하며,
가우시안 분포 가정 하의 MLE와도 수학적으로 같다."

## 🎯 7. 개념 간 연결 지도 — 이 모든 것이 딥러닝에서 어떻게 연결되는가

### 한 줄 결론

선형대수학의 모든 개념은 딥러닝의 특정 핵심 메커니즘과 직접적으로 연결됩니다. 이 연결을 아는 것이 "단순 암기"와 "진정한 이해"의 차이입니다.

---

### 🔥 연결 지도 (큰 그림)

```
[내적 (Dot Product)]
     │
     ├──→ Attention Score 계산 (Self-Attention에서 Q·K)
     ├──→ Cosine Similarity (유사도 측정)
     └──→ 벡터 간 직교성 판별

[행렬 곱셈 (Matrix Multiplication)]
     │
     ├──→ Neural Network 순전파 (y = Wx + b)
     ├──→ 역전파 (∂L/∂W = ∂L/∂y × xᵀ)
     └──→ Batch 처리 (여러 데이터를 행렬로 한번에 계산)

[고유값 (Eigenvalues)]
     │
     ├──→ Hessian 행렬의 고유값 → Loss landscape 분석
     │    - 양정치 → 볼록 → 유일한 최소값
     │    - 음수 고유값 포함 → 안장점
     ├──→ 공분산 행렬의 고유값 → PCA (데이터의 분산 방향)
     └──→ Power iteration → PageRank, 고유값 근사

[SVD (특이값 분해)]
     │
     ├──→ 차원 축소 / 데이터 압축
     ├──→ 이미지 압축 (low-rank approximation)
     ├──→ PCA (공분산 행렬의 SVD = 주성분)
     └──→ LoRA (Low-rank Adaptation) — LLM 파인튜닝 핵심 기법

[Rank (행렬의 계수)]
     │
     ├──→ 모델의 표현력 (rank가 높을수록 표현력 ↑)
     ├──→ Low-rank adaptation (LoRA): rank를 제한하여 효율적 학습
     └──→ 행렬이 full rank가 아니면 → 정보 손실 → 역행렬 불존재

[양정치 행렬 (Positive Definite)]
     │
     ├──→ Convex optimization → 유일한 최적해 보장
     ├──→ Hessian이 PD → local minimum 확인
     └──→ 공분산 행렬은 항상 양반정치 (PSD)

[최소제곱법 (Least Squares)]
     │
     ├──→ Linear Regression의 closed-form solution
     ├──→ 가우시안 가정 → MLE → MSE → 최소제곱법 (sample_1 연결!)
     └──→ Normal Equation: (XᵀX)⁻¹Xᵀy
```

---

### 🔥 핵심 연결 체인: sample_1 → sample_2

이전 가이드(sample_1)에서 배운 것과 이번에 배운 것이 어떻게 연결되는지 정리합니다:

1. **데이터가 가우시안 분포를 따른다고 가정** (sample_1)
2. **i.i.d 가정으로 확률을 곱하고 Log trick 적용** (sample_1)
3. **MSE가 튀어나옴** (sample_1)
4. **MSE 최소화 = ||Ax-b||² 최소화 = 최소제곱법** (sample_2)
5. **미분해서 0 찾기 → 정규방정식 → 유사역행렬로 해 구하기** (sample_2)
6. **Hessian(2차 미분)이 양정치면 찾은 해가 진짜 최소값** (sample_2)
7. **대규모에서는 계산량 때문에 SGD(경사하강법) 사용** (sample_2)

이 체인을 시험 답안에 쭉 적을 수 있으면, 교수님은 **"이 학생은 수식만 외운 게 아니라 전체 흐름을 이해하고 있구나"**라고 판단하실 겁니다.

### 📝 시험용 종합 모범 답안 (여러 개념을 엮는 서술형)

**문제:** "딥러닝에서 선형대수학의 핵심 개념들이 어떻게 활용되는지, 구체적 예시를 들어 설명하시오."

**모범 답안:**
"딥러닝의 모든 과정은 선형대수학에 기반한다.

(1) 순전파: 입력 벡터 x에 가중치 행렬 W를 곱하는 행렬 곱셈 y = Wx + b가 핵심이며,
이는 입력을 새로운 표현 공간으로의 선형 변환이다.

(2) Attention: Transformer의 Self-Attention에서 Query와 Key 벡터의 내적(dot product)으로
토큰 간 유사도를 계산하며, 이 값이 클수록 높은 attention weight가 부여된다.

(3) 최적화: Loss 함수의 Hessian 행렬의 고유값이 모두 양수(양정치)이면
해당 critical point는 local minimum임이 보장된다. 고유값 중 음수가 있으면
안장점(saddle point)으로, 최적화가 불안정해진다.

(4) 모델 압축: SVD의 low-rank approximation을 활용한 LoRA 기법으로,
대규모 모델의 가중치 업데이트를 rank-r 행렬의 곱 ΔW = BA로 근사하여
학습 파라미터 수를 크게 줄인다.

(5) 정규화: L1/L2 노름을 Loss에 추가하여 과적합을 방지하며,
L2는 가중치를 전반적으로 축소하고, L1은 희소한(sparse) 해를 유도한다."

## 💬 추가 퀴즈 모음 (시험 직전 셀프 체크용)

**Q1.** 내적 a·b = 0이면 두 벡터의 관계는?
→ 수직(orthogonal). 서로 독립적인 정보를 가짐.

**Q2.** (5×3) 행렬과 (3×7) 행렬을 곱하면?
→ (5×7) 행렬. 안쪽 차원 3이 같으므로 곱셈 가능.

**Q3.** det(A) = 0이면?
→ 역행렬이 존재하지 않음 (특이 행렬). 행(또는 열)이 선형 종속.

**Q4.** 대칭 행렬의 고유값은 항상 어떤 수?
→ 실수(real number). 허수가 나오지 않음.

**Q5.** SVD와 고유값 분해의 가장 큰 차이는?
→ 고유값 분해는 정방행렬에만 적용 가능. SVD는 임의의 m×n 행렬에 적용 가능.

**Q6.** Hessian 행렬의 고유값이 [5, 3, -1]이면 그 점은?
→ 안장점(saddle point). 음수 고유값이 존재하므로 양정치가 아님.

**Q7.** LoRA가 활용하는 선형대수 개념은?
→ Low-rank approximation (SVD 기반). ΔW ≈ BA로 rank를 제한.

**Q8.** 최소제곱법과 MLE(sample_1)의 관계는?
→ 가우시안 분포 가정 하의 MLE = MSE 최소화 = 최소제곱법. 수학적으로 동일!

## 🏁 마무리

여기까지 읽고 이해했다면, 선형대수학의 핵심 개념과 딥러닝에서의 역할을 모두 정복한 겁니다.

**시험 직전 최종 체크리스트:**

□ 내적의 정의와 기하학적 의미 (유사도, cosθ) 쓸 수 있다
□ 행렬 곱셈의 차원 규칙 (m×n)(n×p)=(m×p) 알고, 선형변환 의미 설명 가능
□ 역행렬 존재 조건 (det≠0) 알고, 2×2 역행렬 구할 수 있다
□ 선형 독립/종속 판별할 수 있고, Rank 구할 수 있다
□ Rank-Nullity Theorem (n=rank+nullity) 쓰고 활용 가능
□ 고유값/고유벡터 정의 (Av=λv) 쓰고, 2×2 행렬에서 구할 수 있다
□ 양정치 행렬의 정의와 볼록 함수/최적화 연결 설명 가능
□ SVD (A=UΣVᵀ)의 의미와 고유값 분해와의 차이 설명 가능
□ 최소제곱해 (x̂=(AᵀA)⁻¹Aᵀb) 도출 과정 쓸 수 있다
□ 위 모든 개념의 딥러닝 연결 (Attention, 순전파, Hessian, LoRA, Regression) 설명 가능

이 체크리스트를 모두 채울 수 있다면, 선형대수학 파트는 만점입니다! 💪
