딥러닝의 핵심 수학은 **"손실 함수를 미분(Gradient)해서, 그 반대 방향으로 파라미터를 조금씩 움직여 에러가 가장 작은 골짜기를 찾아가는 것"**이며, 이 과정에서 Chain Rule(연쇄 법칙)이 각 층의 gradient를 전달하는 역할을 합니다.

🔥 1. 미분(Derivative) 기초 — 모든 것의 시작점
================================================================================

### **[입문 단계] 미분이 뭔지 진짜 쉽게**

미분이란 한마디로 **"기울기를 구하는 계산"**입니다.

비유를 들어볼게요. 🏔️ 당신이 산 위에 서 있다고 상상해 보세요.
- 발밑의 경사가 **가파르면** → 미분값이 **크다**
- 발밑이 **평평하면** → 미분값이 **0**이다
- **왼쪽으로 기울어져 있으면** → 미분값이 **음수**
- **오른쪽으로 기울어져 있으면** → 미분값이 **양수**

💬 퀴즈: y = 3 (그냥 수평선)을 미분하면 얼마일까요?
→ 정답: 0! 수평선은 기울기가 없으니까요.

**이 수식의 의미는...**
미분의 정의: f'(x) = lim(h→0) [f(x+h) - f(x)] / h

이 수식의 의미는 "x를 아주아주 조금(h만큼) 움직였을 때, 함수 값이 얼마나 변하느냐"입니다.
h가 0에 가까워질수록 정확한 '순간 변화율'을 얻게 됩니다.

쉽게 말하면, 자동차의 속도계와 같습니다 🚗
- 거리 함수 f(t) = "시간 t에서의 총 이동 거리"
- 미분 f'(t) = "시간 t에서의 순간 속도"
- 속도가 0이면? 차가 멈춘 거죠 = 기울기가 0

---

### **[중급 단계] 기본 미분 규칙 — 이것만 외우면 끝**

시험에 나오는 미분 공식은 사실 몇 개 안 됩니다. 하나씩 짚어볼게요.

**① 상수의 미분**
d/dx (c) = 0
→ 이 수식의 의미는: 상수는 변하지 않으니 변화율이 0입니다. 체중이 항상 70kg인 사람의 "체중 변화율"은 0이죠.

**② x^n의 미분 (Power Rule) — 가장 많이 쓰는 공식!**
d/dx (x^n) = n × x^(n-1)

→ 이 수식의 의미는: 지수(n)를 앞으로 내리고, 지수에서 1을 빼라.

예시:
- d/dx (x²) = 2x        ← 지수 2를 앞으로 내리고, 2-1=1이니까 x¹ = x
- d/dx (x³) = 3x²       ← 지수 3을 앞으로 내리고, 3-1=2니까 x²
- d/dx (x¹⁰) = 10x⁹     ← 같은 패턴!
- d/dx (x) = 1           ← x = x¹이니까, 1 × x⁰ = 1

💬 퀴즈: d/dx (x⁵) = ?
→ 정답: 5x⁴

**③ e^x의 미분 — 딥러닝에서 왕초 중요!**
d/dx (e^x) = e^x

→ 이 수식의 의미는: e^x는 미분해도 자기 자신! 이런 신기한 성질 때문에 딥러닝에서 활성화 함수(시그모이드, 소프트맥스)에 e가 등장합니다.

**④ ln(x)의 미분**
d/dx (ln x) = 1/x

→ 이 수식의 의미는: x가 커질수록 변화율이 점점 작아집니다. 로그 함수의 그래프가 점점 완만해지는 이유!

**⑤ 삼각함수의 미분**
d/dx (sin x) = cos x
d/dx (cos x) = -sin x

→ 딥러닝 시험에서 직접적으로 자주 나오진 않지만, Chain Rule 예제로 등장할 수 있습니다.

### **[고급 단계] 편미분 (Partial Derivative) — 변수가 여러 개일 때**

딥러닝에서 함수는 변수(파라미터)가 수백만 개입니다. 이때 **하나의 변수만 미분하고 나머지는 상수 취급**하는 것이 편미분입니다.

**이 수식의 의미는...**
∂f/∂x = "다른 변수는 전부 꽁꽁 얼려놓고, x만 살짝 건드렸을 때 f가 얼마나 변하느냐"

📝 구체적 예시:
f(x, y) = x² + 3xy + y²

∂f/∂x = 2x + 3y    (y는 상수 취급! y²은 상수니까 미분하면 0)
∂f/∂y = 3x + 2y    (x는 상수 취급! x²은 상수니까 미분하면 0)

💬 퀴즈: f(x, y) = 5x³ + 2xy² 일 때 ∂f/∂x = ?
→ 정답: 15x² + 2y² (x로만 미분! y²은 그냥 상수처럼 놔두세요)

💬 퀴즈: 같은 함수에서 ∂f/∂y = ?
→ 정답: 4xy (x³ 항은 y가 없으니 0, 2xy²에서 y로 미분하면 2x·2y = 4xy)

---

### **기울기 벡터 (Gradient) ∇f — 딥러닝의 나침반! 🧭**

편미분들을 한 줄로 쭉 모아놓은 벡터가 바로 **Gradient(기울기 벡터)**입니다.

∇f = (∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ)

→ 이 수식의 의미는: **"함수가 가장 빠르게 증가하는 방향"**을 가리키는 화살표입니다.

비유: 산에서 나침반을 들고 있는데, 이 나침반은 항상 **"가장 가파르게 올라가는 방향"**을 가리킵니다.

그런데 우리의 목표는 에러를 **줄이는** 것이죠? 그러면?
→ Gradient의 **반대 방향**으로 가면 됩니다! 이것이 바로 **경사 하강법(Gradient Descent)**의 핵심 원리입니다.

📝 구체적 예시:
f(x, y) = x² + y² 일 때
∇f = (2x, 2y)

만약 현재 위치가 (3, 4)라면:
∇f = (6, 8) → 이 방향이 가장 가파르게 올라가는 방향
-∇f = (-6, -8) → 이 방향으로 가야 에러가 가장 빨리 줄어듦!

---

### 💡 핵심 킬러 요약

1. **미분 = 기울기 = 변화율**: 함수가 얼마나 가파른지 측정하는 도구
2. **편미분**: 변수가 여러 개일 때, 하나만 골라서 미분
3. **Gradient(∇f)**: 편미분을 모아놓은 벡터 → 가장 가파른 상승 방향
4. **Gradient의 반대 방향** = 에러가 가장 빨리 줄어드는 방향 = 경사 하강법의 원리

### 🎯 Top 3

1. Power Rule (d/dx x^n = nx^(n-1))은 반사적으로 나올 때까지 외우세요.
2. 편미분할 때 "다른 변수는 상수 취급"이라는 원칙만 기억하면 절대 틀리지 않습니다.
3. ∇f가 "가장 빠르게 증가하는 방향"이라는 의미를 시험에 반드시 서술하세요.

### 📌 채점 저격

- "Gradient란 무엇인가?"에 대해 단순히 "편미분의 벡터"라고만 쓰면 감점.
- **"각 파라미터에 대한 편미분을 모아놓은 벡터로, 함수가 가장 빠르게 증가하는 방향을 나타내며, 최적화에서는 이 반대 방향(-∇f)으로 이동하여 손실을 최소화한다"**라고 적어야 만점.

🔥 2. Chain Rule (연쇄 법칙) — 딥러닝의 심장! ❤️

### **[입문 단계] Chain Rule이 왜 딥러닝의 심장인가?**

### **한 줄 결론**
역전파(Backpropagation) = Chain Rule의 반복 적용. Chain Rule 없이는 딥러닝이 존재할 수 없습니다.

Neural Network는 함수가 겹겹이 쌓인 구조입니다:
y = f₃(f₂(f₁(x)))

입력 x가 첫 번째 함수(층)을 통과하고, 그 결과가 두 번째 함수를 통과하고... 마치 **러시아 인형(마트료시카)** 🪆처럼 함수 안에 함수 안에 함수가 들어있습니다.

이때 "맨 바깥 함수의 변화가 맨 안쪽 입력(x)에 의해 얼마나 영향받는가?"를 계산하는 것이 Chain Rule입니다.

---

### **[중급 단계] Chain Rule의 공식과 작동 방식**

**기본 공식:**
f(g(x))의 미분 = f'(g(x)) × g'(x)

→ 이 수식의 의미는: **"바깥 함수를 미분한 것 × 안쪽 함수를 미분한 것"을 곱하라!**

📝 구체적 예시 1: 쉬운 것부터
h(x) = (3x + 1)²을 미분하시오.

바깥 함수: ( )² → 미분하면 2( )
안쪽 함수: 3x + 1 → 미분하면 3

Chain Rule 적용:
h'(x) = 2(3x + 1) × 3 = 6(3x + 1)

📝 구체적 예시 2: 딥러닝에서 자주 보는 것
h(x) = e^(2x+1)을 미분하시오.

바깥 함수: e^( ) → 미분하면 e^( ) (자기 자신!)
안쪽 함수: 2x + 1 → 미분하면 2

Chain Rule 적용:
h'(x) = e^(2x+1) × 2 = 2e^(2x+1)

📝 구체적 예시 3: 3겹 합성 함수
h(x) = sin(x²)을 미분하시오.

바깥 함수: sin( ) → 미분하면 cos( )
안쪽 함수: x² → 미분하면 2x

Chain Rule 적용:
h'(x) = cos(x²) × 2x = 2x·cos(x²)

💬 퀴즈: h(x) = (x³ + 2)⁵를 미분하시오.
→ 정답: 5(x³ + 2)⁴ × 3x² = 15x²(x³ + 2)⁴
(바깥: ( )⁵ → 5( )⁴, 안쪽: x³+2 → 3x²)

---

### **Chain Rule과 역전파(Backpropagation)의 연결**

이것이 시험에서 가장 중요한 포인트입니다! 🔥

Neural Network가 3층이라고 합시다:

입력 x → [1층: z₁ = W₁x] → [활성화: a₁ = σ(z₁)] → [2층: z₂ = W₂a₁] → [활성화: a₂ = σ(z₂)] → [3층: z₃ = W₃a₂] → 출력 y → Loss L

이제 "W₁(첫 번째 층의 가중치)이 Loss에 얼마나 영향을 미치는가?"를 알아야 W₁을 업데이트할 수 있겠죠?

Chain Rule 적용:
∂L/∂W₁ = (∂L/∂y) × (∂y/∂z₃) × (∂z₃/∂a₂) × (∂a₂/∂z₂) × (∂z₂/∂a₁) × (∂a₁/∂z₁) × (∂z₁/∂W₁)

→ 이 수식의 의미는: Loss에서 시작해서, 각 층의 미분을 **연쇄적으로 곱하면서** 뒤로(back) 전파(propagation)해 나가는 것!

비유: 도미노 🁡 를 세우고 마지막 도미노(Loss)가 넘어진 충격이 첫 번째 도미노(W₁)까지 전달되는 것과 같습니다. 중간에 도미노 하나라도 없으면 충격(gradient)이 전달되지 않습니다.

---

### **[고급 단계] 행렬 버전의 Chain Rule**

실제 딥러닝에서 x, y, z는 스칼라(숫자 하나)가 아니라 벡터/행렬입니다.

**행렬 Chain Rule:**
∂(f∘g)/∂x = (∂f/∂y)|_{y=g(x)} × (∂g/∂x)

→ 이 수식의 의미는: 스칼라 Chain Rule과 동일하지만, 곱하기가 **행렬 곱**이 됩니다.

**차원 추적 (Dimension Tracking) — 시험에서 실수 방지 핵심!** 🎯

만약:
- z는 d(z)차원 벡터
- y는 d(y)차원 벡터
- x는 d(x)차원 벡터

그러면 ∂z/∂x의 차원은?
d(z)×d(x) = [d(z)×d(y)] × [d(y)×d(x)]

→ 이 수식의 의미는: 행렬 곱에서 **안쪽 차원 d(y)가 서로 맞아야** 곱셈이 가능하다는 뜻입니다. 마치 레고 블럭의 돌기와 구멍이 맞아야 결합되듯이! 🧱

📝 구체적 예시:
z ∈ ℝ³, y ∈ ℝ⁴, x ∈ ℝ²

∂z/∂x는 3×2 행렬이어야 합니다.
(∂z/∂y)는 3×4 행렬, (∂y/∂x)는 4×2 행렬
3×4 행렬 × 4×2 행렬 = 3×2 행렬 ✓ (안쪽 4가 맞음!)

💬 퀴즈: z ∈ ℝ⁵, y ∈ ℝ³, x ∈ ℝ⁷ 일 때, ∂z/∂x의 차원은?
→ 정답: 5×7 (∂z/∂y는 5×3, ∂y/∂x는 3×7, 곱하면 5×7)

---

### **Product Rule (곱의 법칙)**

∂(fg)/∂x = g(∂f/∂x) + f(∂g/∂x)

→ 이 수식의 의미는: 두 함수가 곱해져 있으면, 하나씩 번갈아 미분하고 나머지는 그대로 두어서 더하라!

비유: 두 사람이 짝꿍으로 일하고 있을 때 🤝
- A가 변하는 정도 × B는 가만히 + A는 가만히 × B가 변하는 정도

📝 구체적 예시:
f(x) = x², g(x) = e^x 일 때
d/dx [x² · e^x] = e^x · 2x + x² · e^x = e^x(2x + x²)

---

### **노름의 미분 — 시험 단골 출제! 🔥**

∂||f(x)||²/∂x = 2f(x)ᵀ × (∂f/∂x)

→ 이 수식의 의미는: ||f(x)||²은 f(x)의 각 원소를 제곱해서 더한 것(유클리드 노름의 제곱)입니다. 이걸 x로 미분하면, f(x)의 전치(transpose)에 2를 곱하고, f(x)의 야코비안(∂f/∂x)을 곱합니다.

📝 구체적 예시:
f(x) = Ax (A는 행렬, x는 벡터)
||f(x)||² = ||Ax||² = (Ax)ᵀ(Ax) = xᵀAᵀAx

∂||Ax||²/∂x = 2(Ax)ᵀ × A = 2xᵀAᵀA

이 공식이 중요한 이유: **MSE 손실 함수의 gradient를 구할 때 정확히 이 형태가 나옵니다!**
L = ||y - Xw||² → ∂L/∂w = -2(y - Xw)ᵀX

---

### 💡 핵심 킬러 요약

1. **Chain Rule** = 바깥 미분 × 안쪽 미분 = 역전파의 수학적 원리
2. **행렬 Chain Rule**에서는 차원 추적이 핵심: d(z)×d(x) = [d(z)×d(y)] × [d(y)×d(x)]
3. **∂||f(x)||²/∂x = 2f(x)ᵀ(∂f/∂x)** → MSE gradient 계산의 핵심

### 🎯 Top 3

1. "역전파 = Chain Rule의 반복 적용"이라는 한 문장은 반드시 시험에 쓰세요.
2. 행렬 Chain Rule에서 차원이 맞는지 항상 확인하세요 (안쪽 차원 일치!).
3. ||f(x)||²의 미분 공식은 MSE gradient 유도에 직접 사용됩니다.

### 📌 채점 저격

- "Backpropagation의 수학적 원리를 서술하시오"에서:
  ❌ "역전파는 gradient를 뒤로 전달하는 것이다" → 감점
  ✅ "역전파는 합성 함수의 미분법인 Chain Rule을 출력층에서 입력층 방향으로 반복 적용하여, 각 층의 파라미터에 대한 손실 함수의 gradient를 계산하는 알고리즘이다. ∂L/∂Wₖ = (∂L/∂aₙ)(∂aₙ/∂zₙ)⋯(∂zₖ₊₁/∂aₖ)(∂aₖ/∂zₖ)(∂zₖ/∂Wₖ)와 같이 각 층의 편미분을 연쇄적으로 곱한다."

🔥 3. Hessian 행렬 — 2차 미분의 행렬 버전
================================================================================

### **[입문 단계] Hessian이 뭔가요?**

### **한 줄 결론**
Hessian은 **"이 골짜기가 얼마나 깊고 좁은지(곡률)"**를 알려주는 2차 미분 행렬입니다.

미분(1차 미분)이 "기울기"를 알려준다면, 2차 미분은 **"기울기가 얼마나 빠르게 변하는가"**를 알려줍니다.

비유 🎢:
- 1차 미분 = 롤러코스터에서 지금 얼마나 가파른지 (속도)
- 2차 미분 = 롤러코스터의 경사가 얼마나 빠르게 변하는지 (가속도)
- Hessian = 여러 방향에서의 가속도를 한 행렬에 모아놓은 것

---

### **[중급 단계] Hessian 행렬의 정의와 구조**

**정의:**
H_ij = ∂²f / (∂xᵢ ∂xⱼ)

→ 이 수식의 의미는: 함수 f를 먼저 xⱼ로 미분하고, 그 결과를 다시 xᵢ로 미분한 것입니다.

📝 구체적 예시:
f(x₁, x₂) = x₁² + 3x₁x₂ + 2x₂²

1차 편미분:
∂f/∂x₁ = 2x₁ + 3x₂
∂f/∂x₂ = 3x₁ + 4x₂

2차 편미분 (Hessian 행렬):
H = | ∂²f/∂x₁²      ∂²f/∂x₁∂x₂ |   =   | 2   3 |
    | ∂²f/∂x₂∂x₁    ∂²f/∂x₂²    |       | 3   4 |

- H₁₁ = ∂²f/∂x₁² = 2        (x₁ 방향의 곡률)
- H₁₂ = ∂²f/∂x₁∂x₂ = 3      (x₁과 x₂ 방향이 서로 영향을 주는 정도)
- H₂₁ = ∂²f/∂x₂∂x₁ = 3      (대칭! H₁₂ = H₂₁)
- H₂₂ = ∂²f/∂x₂² = 4        (x₂ 방향의 곡률)

💬 퀴즈: f(x, y) = x³ + xy + y² 의 Hessian을 구하시오.
→ ∂f/∂x = 3x² + y, ∂f/∂y = x + 2y
→ H = | 6x   1 |
      |  1   2 |

---

### **[고급 단계] Hessian의 양정치/양반정치와 볼록 함수의 관계**

이것이 시험 출제 포인트입니다! 🎯

**양정치 (Positive Definite, PD):**
모든 0이 아닌 벡터 v에 대해 vᵀHv > 0

→ 이 수식의 의미는: **모든 방향으로 아래로 볼록(그릇 모양)**이라는 뜻!

**양반정치 (Positive Semi-Definite, PSD):**
모든 벡터 v에 대해 vᵀHv ≥ 0

→ 이 수식의 의미는: 어떤 방향으로는 평평할 수 있지만, 위로 볼록한 방향은 없다는 뜻.

**핵심 연결:**
- Hessian이 PD → **순볼록 함수(Strictly Convex)** → 극소점이 **유일**하게 존재! → GD로 반드시 찾을 수 있음
- Hessian이 PSD → **볼록 함수(Convex)** → 극소점이 존재하지만 유일하지 않을 수 있음
- Hessian이 부정치(Indefinite) → **비볼록 함수(Non-convex)** → 안장점(Saddle Point)이 존재 → 이것이 딥러닝의 현실!

📝 구체적 예시:
위에서 구한 H = | 2   3 |
                | 3   4 |

이것이 PD인지 확인하려면 고유값(eigenvalue)을 봅니다:
det(H - λI) = (2-λ)(4-λ) - 9 = λ² - 6λ - 1 = 0
λ = (6 ± √40) / 2 ≈ 6.16 또는 -0.16

고유값 중 하나가 음수! → 이 행렬은 PD가 아닙니다 (Indefinite). → 이 함수는 볼록이 아니고, 안장점이 있을 수 있습니다.

---

### **딥러닝에서 Hessian의 의미**

딥러닝의 손실 함수 L(θ)의 Hessian은 **손실 함수의 곡률(curvature)**을 나타냅니다.

- Hessian의 고유값이 **큰** 방향: 손실이 급격히 변함 → 학습률을 작게 해야 함
- Hessian의 고유값이 **작은** 방향: 손실이 천천히 변함 → 학습률을 크게 해도 됨
- 이 차이가 크면 → **ill-conditioning** → 학습이 어려움 (지그재그 현상)

비유: 긴 타원형 골짜기에서 공을 굴리면, 좁은 쪽으로는 빠르게 진동하고 긴 쪽으로는 천천히 내려갑니다 🏈

---

### 💡 핵심 킬러 요약

1. **Hessian = 2차 미분 행렬** → 함수의 곡률(curvature) 정보
2. **Hessian PD → 볼록 → 극소점 유일** (최적화가 쉬움)
3. **딥러닝 손실 함수의 Hessian** → 학습 난이도를 결정 (ill-conditioning 문제)

### 📌 채점 저격

- Hessian 문제에서 "2차 미분 행렬이다"로 끝내면 감점.
- **"Hessian이 양정치(PD)이면 해당 점이 극소점(local minimum)임을 보장하고, 함수가 볼록임을 의미한다. 반대로 부정치이면 안장점(saddle point)이 존재하여 최적화가 어려워진다"**고 서술해야 합니다.

🔥 4. 경사 하강법 (Gradient Descent) — 딥러닝의 엔진!
================================================================================

### **[입문 단계] 경사 하강법이란?**

### **한 줄 결론**
눈을 감고 산에서 내려오는 방법: **발밑의 기울기를 느끼고, 가장 가파르게 내려가는 방향으로 한 걸음씩 걷는 것.**

이것이 경사 하강법(Gradient Descent)입니다! 🏔️➡️🏖️

**업데이트 규칙:**
θ_{t+1} = θ_t - α∇L(θ_t)

→ 이 수식의 의미는:
- θ_t: 현재 위치 (현재 파라미터)
- ∇L(θ_t): 현재 위치에서의 기울기 (Gradient)
- α: 학습률 (한 걸음의 크기)
- θ_{t+1}: 다음 위치 (업데이트된 파라미터)
- **마이너스(-)**: Gradient는 "올라가는 방향"이므로, **반대로** 가야 내려갑니다!

📝 구체적 예시:
L(θ) = θ² (단순한 포물선, 최소점은 θ=0)
∇L = 2θ

현재 θ = 5, 학습률 α = 0.1

1단계: θ₁ = 5 - 0.1 × 2(5) = 5 - 1 = 4
2단계: θ₂ = 4 - 0.1 × 2(4) = 4 - 0.8 = 3.2
3단계: θ₃ = 3.2 - 0.1 × 2(3.2) = 3.2 - 0.64 = 2.56
...

보세요! θ가 점점 0(최소점)에 가까워지고 있습니다! 🎯

---

### **[중급 단계] 학습률(Learning Rate) α의 중요성**

α가 너무 크면? α가 너무 작으면? 이것이 시험 단골 문제입니다!

**α가 너무 클 때 (예: α = 2):**
θ₁ = 5 - 2 × 2(5) = 5 - 20 = -15  (반대쪽으로 튕겨나감!)
θ₂ = -15 - 2 × 2(-15) = -15 + 60 = 45  (더 멀리 튕겨나감!!)
→ 발산(Diverge)! 최소점을 못 찾고 날아가 버립니다 🚀💥

**α가 너무 작을 때 (예: α = 0.001):**
θ₁ = 5 - 0.001 × 2(5) = 5 - 0.01 = 4.99
θ₂ = 4.99 - 0.001 × 2(4.99) = 4.99 - 0.00998 = 4.98002
→ 수렴은 하지만, 너무 느림! 🐌 시간이 100배 걸립니다.

**적절한 α:**
- 너무 크지도, 작지도 않게 설정해야 합니다.
- 이론적으로 볼록 함수에서 α < 1/L (L은 Lipschitz 상수)이면 수렴이 보장됩니다.

💬 퀴즈: 학습률이 너무 크면 어떤 현상이 발생하나요?
→ 정답: 발산(Divergence). 파라미터가 최적점을 넘어서 점점 더 멀어집니다.

---

### **[고급 단계] 볼록 함수에서의 수렴 보장 vs 비볼록 함수의 한계**

**볼록 함수(Convex Function)에서:**
- 적절한 학습률을 사용하면 → GD는 **반드시** 전역 최소점(Global Minimum)에 수렴합니다.
- 수렴 속도: O(1/t) (t는 반복 횟수)
- 이유: 볼록 함수에는 골짜기가 **딱 하나**뿐이므로, 어디서 출발해도 같은 바닥에 도달합니다.

**비볼록 함수(Non-convex Function)에서 — 딥러닝의 현실:**
- 골짜기가 **여러 개**입니다 (Local Minima).
- GD는 시작점에 따라 **다른 골짜기**에 빠질 수 있습니다.
- 안장점(Saddle Point)에서 멈출 수도 있습니다.
- 그래서 SGD, Momentum, Adam 같은 변형이 필요합니다!

비유: 볼록 함수 = 그릇 🥣 (어디서 공을 놓아도 같은 바닥)
      비볼록 함수 = 달걀 판 🥚 (놓는 위치에 따라 다른 홈에 빠짐)

---

### 💡 핵심 킬러 요약

1. **GD 업데이트: θ_{t+1} = θ_t - α∇L(θ_t)** → Gradient의 반대 방향으로 한 걸음
2. **학습률 α**: 너무 크면 발산, 너무 작으면 수렴 느림
3. **볼록 → 수렴 보장**, **비볼록 → Local Minimum에 빠질 위험**

### 📌 채점 저격

- "GD가 최적해를 찾는 이유"를 물으면:
  ✅ "∇L(θ)는 함수가 가장 빠르게 증가하는 방향이므로, 그 반대 방향(-∇L)으로 이동하면 손실이 가장 빠르게 감소한다. 볼록 함수에서는 모든 극소점이 전역 최소점이므로 적절한 학습률 하에 수렴이 보장된다."

🔥 5. Newton's Method — 2차 정보를 사용하는 고급 최적화
================================================================================

### **[입문 단계] Newton's Method란?**

### **한 줄 결론**
GD가 "기울기만 보고 한 걸음씩" 내려가는 것이라면, Newton's Method는 **"곡률까지 보고 최적의 점프"**를 하는 것입니다.

**근을 찾는 Newton's Method (원래 버전):**
x_{n+1} = x_n - f(x_n) / f'(x_n)

→ 이 수식의 의미는: 현재 점에서 접선을 그어 x축과 만나는 점으로 이동!

📝 구체적 예시: f(x) = x² - 4의 근(=0이 되는 x)을 찾자

x₀ = 3에서 시작
f(3) = 9 - 4 = 5
f'(3) = 6

x₁ = 3 - 5/6 = 3 - 0.833 = 2.167
f(2.167) = 4.696 - 4 = 0.696
f'(2.167) = 4.333

x₂ = 2.167 - 0.696/4.333 = 2.167 - 0.161 = 2.006

x = 2에 빠르게 접근! (실제 답은 x = 2) 🎯

---

### **[중급 단계] 최적화에 적용한 Newton's Method**

최적화에서는 **미분값이 0인 점**을 찾아야 합니다.
→ f(x)의 최소점 = f'(x) = 0인 점 = "f'(x)라는 함수의 근"

그래서 Newton's Method를 f'(x)에 적용하면:
x_{n+1} = x_n - f'(x_n) / f''(x_n)

다변수로 확장하면:
**θ_{n+1} = θ_n - H⁻¹ ∇L**

→ 이 수식의 의미는:
- ∇L: gradient (1차 미분 = 기울기)
- H⁻¹: Hessian의 역행렬 (2차 미분의 역수 = 곡률의 역수)
- GD는 ∇L만 사용하지만, Newton은 H⁻¹까지 사용해서 더 정확한 이동!

비유: 🏹
- GD = 과녁 방향은 알지만 거리를 모름 → 한 걸음씩 조심스럽게
- Newton = 과녁 방향도 알고 거리도 알 때 → 한 번에 정확히 날아감!

---

### **[고급 단계] Newton vs GD 비교 — 시험 필수 서술!**

| 항목 | Gradient Descent | Newton's Method |
|------|-----------------|-----------------|
| 사용 정보 | 1차 미분 (Gradient) | 1차 + 2차 미분 (Gradient + Hessian) |
| 수렴 속도 | 선형 수렴 (느림) | 2차 수렴 (빠름) |
| 1회 계산 비용 | O(n) | O(n³) ← Hessian 역행렬! |
| 딥러닝 적용 | ✅ 실전에서 사용 | ❌ 비현실적 |
| 이유 | gradient만 계산하면 됨 | 파라미터 수백만 개의 Hessian 역행렬 계산 불가능 |

📝 구체적 수치 예시:
파라미터가 n = 1,000,000개인 Neural Network:
- GD: 1,000,000개의 gradient 계산 → OK
- Newton: 1,000,000 × 1,000,000 = 10¹² 크기의 Hessian 역행렬 계산 → 불가능! 💀

**2차 수렴이란?**
만약 현재 오차가 ε이라면:
- 선형 수렴: 다음 오차 ≈ cε (c < 1) → 한 단계에 오차가 c배로 줄어듦
- 2차 수렴: 다음 오차 ≈ cε² → 한 단계에 오차의 **제곱**으로 줄어듦!

예시: ε = 0.1일 때
- 선형 수렴 (c=0.5): 0.1 → 0.05 → 0.025 → 0.0125 → ...
- 2차 수렴 (c=1):    0.1 → 0.01 → 0.0001 → 0.00000001 → ...
→ Newton이 압도적으로 빠르지만, 한 번 계산하는 데 드는 비용이 너무 비쌈!

💬 퀴즈: Newton's Method가 딥러닝에서 실전적으로 사용되지 않는 가장 큰 이유는?
→ 정답: Hessian 역행렬의 계산 비용이 O(n³)으로, 파라미터 수가 수백만인 딥러닝에서는 비현실적이기 때문.

---

### 💡 핵심 킬러 요약

1. **Newton = GD + Hessian 역행렬**: 2차 정보를 사용해 더 빠르게 수렴
2. **2차 수렴**: 매 스텝마다 오차가 제곱으로 줄어듦 → 엄청 빠름
3. **치명적 단점**: H⁻¹ 계산이 O(n³) → 딥러닝에서 사용 불가능

### 📌 채점 저격

- "Newton vs GD의 차이"를 물으면 반드시 **세 가지**를 비교하세요:
  1. 사용하는 미분 정보의 차수 (1차 vs 1차+2차)
  2. 수렴 속도 (선형 vs 2차)
  3. 계산 비용 (O(n) vs O(n³))

================================================================================
💡 6. 볼록 함수 (Convex Function) — 최적화의 천국
================================================================================

### **[입문 단계] 볼록 함수가 왜 그렇게 좋은가?**

### **한 줄 결론**
볼록 함수는 **"어디서 출발해도 같은 바닥에 도달"**하기 때문에, 최적화하기 가장 쉬운 이상적인 함수입니다. 딥러닝은 이 천국에 살지 못합니다(Non-convex).

**볼록 함수의 정의:**
f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y),  ∀x, y, ∀λ ∈ [0, 1]

→ 이 수식의 의미는... 이 수식이 정말 무서워 보이지만, 실은 아주 간단합니다!

비유로 설명하겠습니다 🎯:
두 점 (x, f(x))와 (y, f(y))를 잡아서 직선으로 이으세요.
**그 직선이 항상 함수 그래프의 "위쪽"에 있으면** → 볼록 함수!

그릇(🥣)을 생각하세요:
- 그릇의 양쪽 가장자리 두 점을 고무줄로 이으면, 고무줄은 항상 그릇 **위**에 있죠?
- 이게 볼록 함수의 정의입니다!

📝 구체적 예시:
f(x) = x² 는 볼록 함수인가?

x = 2, y = 4, λ = 0.5로 확인:
좌변: f(0.5×2 + 0.5×4) = f(3) = 9
우변: 0.5×f(2) + 0.5×f(4) = 0.5×4 + 0.5×16 = 2 + 8 = 10

9 ≤ 10 ✓ → 볼록!

실제로 f(x) = x²의 그래프는 아래로 볼록한 포물선이고, 두 점을 잇는 선분은 항상 그래프 위에 있습니다.

💬 퀴즈: f(x) = -x² 은 볼록 함수인가요?
→ 정답: 아닙니다! 위로 볼록(오목)합니다. 두 점을 잇는 선분이 그래프 아래에 있습니다.

---

### **[중급 단계] Convex Set (볼록 집합)**

**정의:** 집합 C 안의 임의의 두 점 x, y에 대해, 그 사이의 모든 점 λx + (1-λ)y도 C 안에 있으면 볼록 집합.

→ 이 수식의 의미는: **두 점을 잇는 선분이 항상 집합 안에 있으면** 볼록 집합!

예시:
- 원(disk) → 볼록 집합 ✅ (안의 두 점을 이어도 원 안에 있음)
- 초승달 모양 🌙 → 볼록 집합 ❌ (두 점을 이으면 밖으로 나갈 수 있음)
- 직사각형 → 볼록 집합 ✅
- 별 모양 ⭐ → 볼록 집합 ❌

---

### **[고급 단계] 볼록 함수의 핵심 성질 — 시험 최다 출제!**

**성질 1: Local Minimum = Global Minimum** 🎯🎯🎯

이것이 볼록 함수가 최적화에서 중요한 가장 핵심적인 이유입니다!

- 볼록 함수: 골짜기가 **1개** → 어떤 지역 최소점도 전역 최소점
- 비볼록 함수: 골짜기가 **여러 개** → 지역 최소점 ≠ 전역 최소점일 수 있음

비유:
- 볼록 = 그릇 🥣 : 구슬을 어디서 놓아도 같은 바닥에 도달
- 비볼록 = 달걀 판 🥚 : 놓는 위치에 따라 다른 홈에 빠짐

**성질 2: Hessian과의 관계**
- f가 볼록 ↔ Hessian H가 모든 점에서 양반정치(PSD)
- f가 순볼록(strictly convex) ↔ Hessian H가 모든 점에서 양정치(PD)

**성질 3: 볼록 함수의 1차 조건**
f(y) ≥ f(x) + ∇f(x)ᵀ(y - x)

→ 이 수식의 의미는: 볼록 함수의 어떤 점에서 접선을 그으면, 함수는 항상 그 접선 **위**에 있다. (접선이 하한이 된다)

📝 구체적 예시:
f(x) = x² 에서 x = 1인 점에서의 접선:
접선: L(y) = f(1) + f'(1)(y-1) = 1 + 2(y-1) = 2y - 1

y = 3일 때 확인:
f(3) = 9
L(3) = 2(3) - 1 = 5
9 ≥ 5 ✓ → 함수가 접선 위에 있음!

---

### **딥러닝과 볼록성의 관계**

**핵심: 딥러닝의 손실 함수는 Non-convex입니다!**

왜?
- Neural Network의 파라미터 공간은 매우 복잡합니다.
- 같은 함수를 표현하는 파라미터 조합이 여러 개 존재합니다 (대칭성).
- 따라서 Local Minimum이 여러 개 존재하고, Saddle Point도 매우 많습니다.

그런데 놀라운 사실:
- 실전에서 딥러닝은 잘 작동합니다! 🤔
- 이유: 고차원에서는 대부분의 Local Minimum이 Global Minimum과 비슷한 값을 가진다는 연구 결과가 있습니다.
- 또한 SGD의 노이즈가 오히려 나쁜 Local Minimum에서 빠져나오는 데 도움이 됩니다.

---

### 💡 핵심 킬러 요약

1. **볼록 함수 정의**: f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y) → 선분이 그래프 위
2. **가장 중요한 성질**: Local Min = Global Min → 최적화의 천국
3. **딥러닝은 Non-convex** → 그래서 최적화가 어렵고, 다양한 기법이 필요

### 🎯 Top 3

1. 볼록 함수의 정의(부등식)를 쓰고, "이는 두 점을 잇는 선분이 함수 그래프 위에 위치함을 의미한다"라고 해석을 반드시 적으세요.
2. "왜 볼록 함수에서 GD가 전역 최소점을 찾는가?" → "Local Min = Global Min이므로"
3. "딥러닝은 Non-convex이지만, 실전에서 잘 작동하는 이유"를 설명할 수 있으면 보너스 점수!

### 📌 채점 저격

- "볼록 함수란 무엇인가?"에 대해:
  ❌ "아래로 볼록한 함수" → 너무 부정확, 감점
  ✅ "임의의 두 점 x, y와 λ ∈ [0,1]에 대해 f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)를 만족하는 함수로, 기하학적으로 두 점을 잇는 선분이 항상 함수 그래프 위에 위치함을 의미하며, 이로 인해 모든 지역 최소점이 전역 최소점과 일치하여 최적화가 용이하다."

💡 7. Constrained Optimization (제약 조건 최적화)

### **[입문 단계] 제약 조건이 있는 최적화란?**

### **한 줄 결론**
"예산은 100만원인데 가장 맛있는 식사를 하고 싶다" = **제약 조건 하에서 목적 함수를 최적화하는 것.**

지금까지 배운 GD, Newton 등은 **아무 제약 없이** 최소점을 찾았습니다.
하지만 현실에서는:
- 신경망의 가중치를 너무 크지 않게 하고 싶다 (제약!)
- 확률 값은 0 이상이고 합이 1이어야 한다 (제약!)
- 특정 조건을 만족하면서 에러를 최소화하고 싶다 (제약!)

**수학적 표현:**
min f(x)   subject to   g(x) = 0  (등식 제약)
                         h(x) ≤ 0  (부등식 제약)

→ 이 수식의 의미는: f(x)를 최소화하되, g(x) = 0이라는 조건과 h(x) ≤ 0이라는 조건을 반드시 지켜야 한다.

---

### **[중급 단계] Lagrange Multiplier (라그랑주 승수법)**

**아이디어:** 제약 조건을 목적 함수에 **합쳐서** 하나의 함수로 만든 뒤 최적화!

**등식 제약일 때:**
min f(x)  s.t.  g(x) = 0

→ Lagrangian: L(x, λ) = f(x) + λ·g(x)

→ 이 수식의 의미는: λ(라그랑주 승수)라는 새 변수를 도입해서, 제약 조건 g(x)=0을 "벌금"처럼 목적 함수에 추가한 것!

**필요 조건 (최적점에서 만족해야 할 것):**
∂L/∂x = 0  →  ∇f = -λ∇g  (목적 함수의 gradient와 제약의 gradient가 평행!)
∂L/∂λ = 0  →  g(x) = 0    (제약 조건 자체!)

📝 구체적 예시:
min f(x,y) = x² + y²  s.t.  x + y = 1

Lagrangian: L = x² + y² + λ(x + y - 1)

∂L/∂x = 2x + λ = 0  →  x = -λ/2
∂L/∂y = 2y + λ = 0  →  y = -λ/2
∂L/∂λ = x + y - 1 = 0

x = y이므로: x + x = 1 → x = 1/2, y = 1/2, λ = -1

답: (1/2, 1/2)에서 최소값 f = 1/4 + 1/4 = 1/2

직관: 원점(0,0)이 제약 없을 때의 최소점이지만, x+y=1이라는 직선 위에 있어야 하므로 직선 위에서 원점에 가장 가까운 점을 찾는 것!

💬 퀴즈: 위 문제에서 λ = -1의 의미는?
→ 정답: 제약 조건이 조금 완화되면(x+y=1 대신 x+y=1+ε), 최적값이 약 -1·ε만큼 변합니다. 즉 λ는 "제약의 그림자 가격(shadow price)"입니다.

---

### **[고급 단계] KKT 조건 (Karush-Kuhn-Tucker)**

부등식 제약이 있을 때의 일반화:

min f(x)  s.t.  gᵢ(x) ≤ 0,  hⱼ(x) = 0

**KKT 필요 조건:**
1. ∇f + Σμᵢ∇gᵢ + Σλⱼ∇hⱼ = 0  (Stationarity)
2. gᵢ(x) ≤ 0                      (Primal Feasibility)
3. μᵢ ≥ 0                          (Dual Feasibility)
4. μᵢ·gᵢ(x) = 0                   (Complementary Slackness) ← 가장 중요!

→ 조건 4의 의미는: **제약이 "활성"(gᵢ=0, 경계에 걸림)이면 μᵢ > 0이고, 제약이 "비활성"(gᵢ<0, 여유 있음)이면 μᵢ = 0이다.**

비유: 예산이 100만원인데 80만원만 쓰면? → 예산 제약이 비활성 → 해당 제약의 승수 μ = 0 (예산이 더 늘어나도 최적해가 안 바뀜)
예산 100만원을 딱 맞게 쓰면? → 예산 제약이 활성 → μ > 0 (예산이 늘면 최적해가 바뀜!)

---

### **딥러닝과의 연결: 정규화(Regularization) = 제약 조건!**

딥러닝에서 과적합(overfitting)을 방지하기 위해 가중치에 패널티를 주는 것이 정규화입니다.

**L2 정규화 (Weight Decay):**
min L(θ) + λ||θ||²

이것은 사실 다음 제약 최적화 문제와 동치입니다:
min L(θ)  s.t.  ||θ||² ≤ c  (가중치의 크기가 c 이하)

→ 이 수식의 의미는: "에러도 줄이고 싶지만, 가중치가 너무 커지는 것도 막고 싶다"는 두 마리 토끼를 동시에 잡는 것! 🐰🐰

λ가 크면? → 가중치에 대한 제약이 강함 → 가중치가 작아짐 → 단순한 모델
λ가 작으면? → 가중치에 대한 제약이 약함 → 데이터에 맞추는 데 집중 → 복잡한 모델

---

### 💡 핵심 킬러 요약

1. **Lagrange Multiplier**: 제약을 목적 함수에 합쳐서 → 무제약 문제로 변환
2. **KKT의 Complementary Slackness**: 제약이 활성이면 μ>0, 비활성이면 μ=0
3. **정규화 = 제약 조건**: L2 정규화는 가중치 크기 제한과 동치

### 📌 채점 저격

- 정규화 문제에서:
  ✅ "L2 정규화(λ||θ||²)는 라그랑주 쌍대(Lagrangian dual) 관점에서 가중치 크기에 대한 부등식 제약(||θ||² ≤ c)과 동치이며, λ는 이 제약의 라그랑주 승수에 해당한다"

🔥 8. Gradient Descent 변형 — 시험 최다 출제 영역!! 🔥🔥🔥

### **한 줄 결론**
실전 딥러닝에서는 단순 GD가 아니라, 데이터를 쪼개고(Mini-batch), 관성을 추가하고(Momentum), 학습률을 자동 조절하는(Adam) **변형된 GD**를 사용합니다.

---

### **[입문 단계] 왜 단순 GD로는 안 되는가?**

문제: ImageNet 데이터셋은 이미지가 **1,400만 장**입니다.

단순 GD(Batch GD):
- 1,400만 장 **전부**를 보고 gradient를 1번 계산
- 1번 업데이트하는 데 몇 시간 걸림
- 100번 업데이트하려면? → 며칠!!! 💀

그래서 데이터를 쪼개서 보자! → 이것이 SGD와 Mini-batch의 탄생 배경입니다.

---

### **① Batch Gradient Descent (전체 배치)**

θ_{t+1} = θ_t - α · (1/N) Σᵢ₌₁ᴺ ∇Lᵢ(θ_t)

→ 이 수식의 의미는: **모든** N개 데이터의 gradient를 평균 내서 업데이트.

장점: Gradient가 정확함 (노이즈 없음)
단점: 데이터가 크면 너무 느림

---

### **② SGD (Stochastic Gradient Descent) — 확률적 경사 하강법**

θ_{t+1} = θ_t - α · ∇Lᵢ(θ_t)   (데이터 1개 i를 랜덤으로 뽑아서!)

→ 이 수식의 의미는: 데이터 **1개만** 랜덤으로 뽑아서 gradient를 계산하고 바로 업데이트!

📝 구체적 비유:
- Batch GD = 반 전체 30명의 시험 점수를 다 모아서 평균 내고 교육 방침 결정 (정확하지만 느림)
- SGD = 학생 1명을 무작위로 뽑아서 그 점수만 보고 교육 방침 결정 (빠르지만 불안정)

장점:
- 매우 빠름! (데이터 1개만 보면 되니까)
- 노이즈가 오히려 Local Minimum에서 빠져나오는 데 도움 🎲

단점:
- Gradient에 노이즈가 큼 → 수렴 경로가 들쭉날쭉 (진동)
- 정확한 최소점에 수렴하기 어려움

💬 퀴즈: SGD에서 노이즈가 오히려 도움이 되는 경우가 있다면 어떤 경우인가요?
→ 정답: 비볼록 함수에서 나쁜 Local Minimum이나 Saddle Point에 빠졌을 때, 노이즈 덕분에 빠져나와 더 좋은 최소점을 찾을 수 있습니다.

---

### **③ Mini-batch Gradient Descent — 실전의 왕! 👑**

θ_{t+1} = θ_t - α · (1/B) Σᵢ∈batch ∇Lᵢ(θ_t)   (B개의 데이터로!)

→ 이 수식의 의미는: Batch GD와 SGD의 **절충안**! 전체도 아니고 1개도 아닌, **B개(보통 32, 64, 128, 256)**의 데이터를 뽑아서 gradient를 계산.

📝 구체적 비유:
- 반 전체 30명 중 **5명을 무작위 추출**해서 평균 점수를 보고 교육 방침 결정
- 30명 전부 보는 것보다 빠르면서, 1명만 보는 것보다 안정적!

실전에서 가장 많이 사용되는 이유:
1. GPU가 행렬 연산에 최적화 → 배치 단위 병렬 처리가 효율적
2. Gradient 노이즈가 적당해서 수렴도 안정적

**Batch Size에 따른 차이:**
| Batch Size | Gradient 정확도 | 업데이트 빈도 | 일반화 성능 |
|------------|----------------|-------------|------------|
| 큰 배치 (1024+) | 높음 | 낮음 | 낮을 수 있음 (sharp minimum) |
| 작은 배치 (32) | 낮음 (노이즈 많음) | 높음 | 높을 수 있음 (flat minimum) |

→ 흥미로운 발견: 배치가 작을수록 오히려 일반화 성능이 좋을 수 있습니다! (노이즈가 flat minimum을 찾는 데 도움)

---

### **④ Momentum — 관성을 추가하다! 🏎️**

**문제:** SGD가 지그재그로 진동하면서 느리게 수렴하는 경우가 있습니다.

비유: 공이 좁고 긴 골짜기를 내려가고 있다고 합시다 ⚽
- SGD: 좌우로 벽에 부딪히면서 조금씩 앞으로
- Momentum: 공에 **관성(무게)**을 주면, 좌우 진동은 상쇄되고 앞으로 가는 속도는 누적!

**업데이트 규칙:**
v_t = β·v_{t-1} + ∇L(θ_t)         (속도 = 이전 속도 × 관성 + 현재 gradient)
θ_{t+1} = θ_t - α·v_t             (위치 업데이트)

→ 이 수식의 의미는:
- v_t: 속도 (이전 gradient들의 누적)
- β: 관성 계수 (보통 0.9) → 이전 속도의 90%를 유지!
- 좌우 진동: 방향이 계속 바뀌므로 → 관성에 의해 상쇄됨
- 앞으로 가는 방향: 방향이 일정하므로 → 관성에 의해 가속됨!

📝 구체적 예시:
스텝 1: gradient = (+2, +10)  →  v₁ = (2, 10)
스텝 2: gradient = (-2, +10)  →  v₂ = 0.9×(2,10) + (-2,10) = (1.8-2, 9+10) = (-0.2, 19)
스텝 3: gradient = (+2, +10)  →  v₃ = 0.9×(-0.2,19) + (2,10) = (-0.18+2, 17.1+10) = (1.82, 27.1)

x 방향(좌우 진동): 2 → -0.2 → 1.82 (작게 진동)
y 방향(앞으로): 10 → 19 → 27.1 (점점 가속!) 🚀

---

### **⑤ Adam (Adaptive Moment Estimation) — 실전 최강! 🏆**

Adam = Momentum + RMSProp → 학습률까지 자동 조절!

**업데이트 규칙:**
m_t = β₁·m_{t-1} + (1-β₁)·∇L        (1차 모멘트 = gradient의 이동평균)
v_t = β₂·v_{t-1} + (1-β₂)·(∇L)²     (2차 모멘트 = gradient 제곱의 이동평균)

편향 보정:
m̂_t = m_t / (1 - β₁ᵗ)
v̂_t = v_t / (1 - β₂ᵗ)

최종 업데이트:
θ_{t+1} = θ_t - α · m̂_t / (√v̂_t + ε)

→ 이 수식의 의미는:
- m_t: Momentum과 같은 역할 → gradient의 방향을 부드럽게
- v_t: RMSProp과 같은 역할 → gradient의 크기를 추적
- m̂_t / √v̂_t: **gradient가 큰 방향은 학습률을 줄이고, 작은 방향은 학습률을 키운다!**
- ε: 0으로 나누는 것 방지 (보통 10⁻⁸)
- 편향 보정: 초기에 m, v가 0으로 초기화되므로 발생하는 편향을 보정

**기본 하이퍼파라미터 (거의 이 값을 씁니다):**
- α = 0.001 (학습률)
- β₁ = 0.9 (1차 모멘트 감쇠)
- β₂ = 0.999 (2차 모멘트 감쇠)
- ε = 10⁻⁸

비유: Adam은 **자동 기어 자동차** 🚗
- 오르막(gradient 큼) → 자동으로 기어를 낮춰 천천히
- 평지(gradient 작음) → 자동으로 기어를 높여 빠르게
- Momentum이 진행 방향을 안정화하고, RMSProp이 속도를 자동 조절!

💬 퀴즈: Adam이 SGD + Momentum보다 좋은 점은 무엇인가요?
→ 정답: Adam은 각 파라미터별로 학습률을 적응적(adaptive)으로 조절합니다. gradient가 자주 크게 변하는 파라미터는 학습률을 줄이고, 작은 파라미터는 키워서 효율적으로 학습합니다.

---

### **⑥ Learning Rate Scheduling — 학습률 스케줄링**

학습 초기에는 α를 크게 (빠르게 탐색), 후반에는 α를 줄여서 (정밀하게 수렴).

**주요 방법들:**
1. **Step Decay**: 일정 epoch마다 α를 1/10로 줄임
   - 예: epoch 30에서 α = 0.1 → 0.01, epoch 60에서 → 0.001

2. **Cosine Annealing**: α가 코사인 곡선처럼 부드럽게 감소
   - α_t = α_min + 0.5(α_max - α_min)(1 + cos(πt/T))

3. **Warmup**: 초기 몇 epoch 동안 α를 0에서 서서히 올림
   - 이유: 초기에 gradient가 불안정하므로, 작은 학습률로 시작해서 안정되면 올림

비유: 자전거 타기 🚴
- 출발: 천천히 페달 (Warmup)
- 내리막: 쭉쭉 달림 (큰 학습률)
- 목적지 가까이: 브레이크 (학습률 감소)

| 방법 | 특징 | 장점 | 단점 |
|------|------|------|------|
| Batch GD | 전체 데이터 | 정확한 gradient | 느림 |

### **📝 모범 답안 1: "Backpropagation이 작동하는 수학적 원리를 서술하시오"**

---

**[답안]**

Backpropagation(역전파)은 **합성 함수의 미분법인 Chain Rule(연쇄 법칙)을 출력층에서 입력층 방향으로 반복 적용**하여, 손실 함수 L의 각 파라미터에 대한 gradient를 효율적으로 계산하는 알고리즘이다.

**1. Neural Network의 구조와 Chain Rule**

Neural Network는 여러 층의 함수를 합성한 합성 함수이다:
ŷ = fₙ(fₙ₋₁(...f₂(f₁(x; W₁); W₂)...; Wₙ₋₁); Wₙ)

k번째 층의 파라미터 Wₖ에 대한 손실 L의 gradient는 Chain Rule에 의해:
∂L/∂Wₖ = (∂L/∂aₙ)(∂aₙ/∂zₙ)(∂zₙ/∂aₙ₋₁)⋯(∂aₖ/∂zₖ)(∂zₖ/∂Wₖ)

여기서 zₖ = Wₖaₖ₋₁ + bₖ (선형 변환), aₖ = σ(zₖ) (활성화 함수)이다.

**2. 역전파의 효율성**

출력층에서 시작하여 ∂L/∂aₙ을 먼저 계산하고, 각 층을 역방향으로 순회하며 이전 층의 gradient를 재사용한다. 이로 인해 순전파(Forward Pass) 한 번과 동일한 O(n) 시간 복잡도로 모든 파라미터의 gradient를 계산할 수 있다.

**3. 핵심 수학적 근거**

Chain Rule의 행렬 버전에서 차원이 일관되게 유지됨을 확인할 수 있다:
∂L/∂Wₖ의 차원 = [d(L)×d(aₙ)] × [d(aₙ)×d(zₙ)] × ⋯ × [d(zₖ)×d(Wₖ)]

각 인접 행렬의 안쪽 차원이 일치하므로 연쇄 행렬 곱이 성립한다.

### **📝 모범 답안 2: "Gradient Descent가 최적해를 찾는 이유를 볼록 함수 관점에서 설명하시오"**

---

**[답안]**

**1. Gradient의 의미와 업데이트 방향**

∇L(θ)는 손실 함수 L이 θ에서 **가장 빠르게 증가하는 방향**이다. 따라서 θ_{t+1} = θ_t - α∇L(θ_t)로 gradient의 반대 방향으로 이동하면, 매 스텝마다 손실이 감소하는 방향으로 파라미터가 업데이트된다.

**2. 볼록 함수에서의 수렴 보장**

볼록 함수(convex function)의 정의에 의해, 임의의 두 점 x, y에 대해:
f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)

이 성질로부터 **모든 지역 최소점(Local Minimum)이 전역 최소점(Global Minimum)**과 일치한다. 이는 다음과 같이 증명된다:

볼록 함수의 1차 조건에 의해 f(y) ≥ f(x) + ∇f(x)ᵀ(y-x)이며, ∇f(x*) = 0인 점 x*에서 모든 y에 대해 f(y) ≥ f(x*)이므로 x*는 전역 최소점이다.

**3. 적절한 학습률 하에서의 수렴**

L-Lipschitz 연속인 gradient를 갖는 볼록 함수에서, 학습률 α ≤ 1/L로 설정하면 GD는 O(1/t)의 속도로 전역 최소점에 수렴함이 보장된다.

따라서 볼록 함수에서 GD는 적절한 학습률 하에 반드시 전역 최적해에 도달한다.

### **📝 모범 답안 3: "Newton's Method와 Gradient Descent의 차이점을 설명하시오"**

---

**[답안]**

| 비교 항목 | Gradient Descent | Newton's Method |
|----------|-----------------|-----------------|
| 사용 정보 | 1차 미분(Gradient ∇L) | 1차 미분(∇L) + 2차 미분(Hessian H) |
| 업데이트 규칙 | θ_{t+1} = θ_t - α∇L | θ_{t+1} = θ_t - H⁻¹∇L |
| 수렴 속도 | 선형 수렴 (Linear) | 2차 수렴 (Quadratic) |
| 1회 계산 비용 | O(n) | O(n³) (Hessian 역행렬 계산) |
| 학습률 | 하이퍼파라미터로 직접 설정 | Hessian이 자동으로 결정 (별도 설정 불필요) |

**핵심 차이의 직관적 이해:**

GD는 손실 함수를 1차 함수(직선)로 근사하여 이동 방향만 결정하고, 이동 거리는 학습률 α에 의존한다. 반면 Newton's Method는 손실 함수를 **2차 함수(포물선)로 근사**하여 이동 방향과 거리를 동시에 결정하므로, 수렴이 빠르다.

**딥러닝에서의 적용 가능성:**

딥러닝 모델은 파라미터 수 n이 수백만~수십억에 달한다. Newton's Method는 n×n 크기의 Hessian 역행렬 계산이 필요하므로 메모리(O(n²))와 계산 비용(O(n³)) 모두 비현실적이다. 따라서 실전에서는 1차 미분만 사용하는 GD 변형(SGD, Adam 등)이 표준이며, 2차 정보를 근사적으로 활용하는 방법(L-BFGS, Natural Gradient 등)이 연구되고 있다.

### **📝 모범 답안 4: "SGD, Momentum, Adam의 차이를 서술하고, 각각의 장단점을 비교하시오"**

---

**[답안]**

**1. SGD (Stochastic Gradient Descent)**

업데이트: θ_{t+1} = θ_t - α∇Lᵢ(θ_t)

무작위로 선택한 단일 데이터(또는 미니배치)의 gradient로 업데이트한다.
- 장점: 계산 비용이 낮고, gradient의 확률적 노이즈가 비볼록 함수에서 나쁜 지역 최소점이나 안장점 탈출에 도움
- 단점: 수렴 경로가 불안정하고 진동이 심함

**2. SGD + Momentum**

업데이트:
v_t = βv_{t-1} + ∇L(θ_t)
θ_{t+1} = θ_t - αv_t

이전 gradient를 관성(β, 보통 0.9)만큼 누적하여 속도 벡터 v_t를 유지한다.
- 장점: 일관된 방향의 gradient는 가속되고, 방향이 바뀌는 진동 성분은 상쇄되어 수렴 안정성과 속도가 향상됨
- 단점: β 하이퍼파라미터 추가 튜닝 필요

**3. Adam (Adaptive Moment Estimation)**

업데이트:
m_t = β₁m_{t-1} + (1-β₁)∇L       (1차 모멘트: 방향)
v_t = β₂v_{t-1} + (1-β₂)(∇L)²    (2차 모멘트: 크기)
θ_{t+1} = θ_t - α · m̂_t/(√v̂_t + ε)

Momentum(1차 모멘트)과 RMSProp(2차 모멘트)을 결합하여, **각 파라미터별로 적응적 학습률**을 사용한다.
- 장점: 하이퍼파라미터 튜닝이 거의 불필요(기본값이 잘 작동), 희소한 gradient에도 효과적
- 단점: 일부 연구에서 SGD+Momentum 대비 일반화(generalization) 성능이 떨어질 수 있다는 보고

**결론:** 실전에서는 Adam이 기본(default)으로 가장 많이 사용되며, 최종 성능 튜닝 시 SGD+Momentum으로 전환하는 전략도 활용된다.

### **📝 모범 답안 5: "Hessian 행렬의 정의와 딥러닝에서의 역할을 서술하시오"**

---

**[답안]**

**1. 정의**

Hessian 행렬 H는 다변수 함수 f의 2차 편미분으로 구성된 대칭 행렬로, (i,j) 원소는:
H_{ij} = ∂²f/(∂xᵢ∂xⱼ)

**2. 볼록성 판정에서의 역할**

모든 점에서 H가 양정치(Positive Definite)이면 f는 순볼록(strictly convex)이고, 양반정치(PSD)이면 볼록이다. 특정 임계점에서 H가 PD이면 해당 점이 극소점(local minimum)임이 보장된다. H가 부정치(indefinite)이면 안장점(saddle point)이다.

**3. 딥러닝 손실 함수에서의 의미**

Hessian의 고유값(eigenvalue)은 해당 방향의 **곡률(curvature)**을 나타낸다:
- 큰 고유값: 해당 방향으로 손실이 급격히 변함 → 학습률을 작게 해야 안정
- 작은 고유값: 해당 방향으로 손실이 완만 → 학습률을 크게 해도 무방
- 최대/최소 고유값의 비(condition number)가 크면 ill-conditioning이 발생하여 학습이 어려워짐

이러한 Hessian 정보를 활용하면 최적의 학습률과 이동 방향을 동시에 결정할 수 있으나(Newton's Method), 계산 비용이 O(n³)으로 비현실적이므로 실전에서는 1차 미분 기반 방법이 사용된다.

### 💡 전체 핵심 킬러 요약 (시험 직전에 이것만 보세요!)

**1. 미분 기초**
- 미분 = 기울기 = 변화율
- Power Rule: d/dx(x^n) = nx^(n-1)
- 편미분: 다른 변수 상수 취급
- Gradient ∇f = 가장 빠르게 증가하는 방향 → GD는 반대 방향!

**2. Chain Rule (역전파의 수학)**
- f(g(x))' = f'(g(x)) × g'(x) → 바깥 미분 × 안쪽 미분
- 역전파 = Chain Rule 반복 적용
- 행렬 버전: 차원 추적이 핵심 (안쪽 차원 일치!)
- ∂||f(x)||²/∂x = 2f(x)ᵀ(∂f/∂x) → MSE gradient

**3. Hessian**
- 2차 미분 행렬 → 곡률(curvature)
- PD → 볼록 → 극소점 유일
- 딥러닝: ill-conditioning 문제

**4. Gradient Descent**
- θ_{t+1} = θ_t - α∇L → gradient 반대로 한 걸음
- α 너무 크면 발산, 작으면 느림
- 볼록: 수렴 보장 / 비볼록: local min 위험

**5. Newton's Method**
- θ_{t+1} = θ_t - H⁻¹∇L → 2차 정보 사용
- 2차 수렴(빠름) but O(n³) 비용 → 딥러닝 비현실적

**6. 볼록 함수**
- f(λx+(1-λ)y) ≤ λf(x)+(1-λ)f(y) → 선분이 그래프 위
- 핵심: Local Min = Global Min
- 딥러닝은 Non-convex → 다양한 최적화 기법 필요

**7. Constrained Optimization**
- Lagrange Multiplier: 제약을 목적함수에 합침
- KKT: Complementary Slackness (활성 제약만 μ>0)
- 정규화 = 가중치 크기 제약과 동치

**8. GD 변형 (실전 최중요!)**
- Batch GD: 전체 데이터 → 정확하지만 느림
- SGD: 1개 데이터 → 빠르지만 노이즈
- Mini-batch: B개 → 실전의 기본
- Momentum: 관성 추가 → 진동 줄이고 가속
- Adam: Momentum + 적응 학습률 → 실전 최강
