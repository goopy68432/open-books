# 🔥 제1장. 확률 기초 — "불확실한 세상을 숫자로 표현하기"
# ═══════════════════════════════════════════

---

## **[입문 단계] 비전공자도 이해하는 직관**

확률이란 뭘까요? 중학교 때 배운 "동전 앞면 나올 확률 = 1/2"이 전부입니다.

- **쉽게 말하면:** 확률은 **0부터 1 사이의 숫자**로, 어떤 일이 일어날 가능성을 표현합니다.
  - 0 = 절대 안 일어남 (내일 해가 서쪽에서 뜸)
  - 1 = 반드시 일어남 (내일 해가 동쪽에서 뜸)
  - 0.5 = 반반 (동전 앞면)

- **왜 딥러닝에서 확률을 배우나?**
  딥러닝 모델은 "이 사진이 고양이일 확률 = 0.95"처럼 답을 확률로 내놓습니다.
  확률을 모르면 모델이 내뱉는 숫자가 뭔지 해석할 수가 없어요.

---

## **[중급 단계] 확률의 공리 (Axioms of Probability)**

확률에는 반드시 지켜야 할 3가지 규칙이 있습니다.
수학자 콜모고로프(Kolmogorov)가 정한 "확률의 헌법" 같은 것입니다.

**공리 1. 비음수성 (Non-negativity)**
  P(A) >= 0
  → 이 수식의 의미는: 어떤 사건의 확률도 음수가 될 수 없다는 것입니다.
  → "비가 올 확률이 -30%"라는 건 말이 안 되죠.

**공리 2. 정규성 (Normalization)**
  P(S) = 1   (S = 전체 표본 공간)
  → 이 수식의 의미는: 가능한 모든 결과를 합치면 확률은 정확히 1이 된다는 것입니다.
  → 동전을 던지면 앞면 or 뒷면이 반드시 나옴 → P(앞) + P(뒤) = 1

**공리 3. 가산 가법성 (Additivity)**
  서로 겹치지 않는(배타적인) 사건 A, B에 대해:
  P(A ∪ B) = P(A) + P(B)
  → 이 수식의 의미는: 겹치지 않는 사건이면 확률을 단순히 더할 수 있다는 것입니다.
  → 주사위에서 1 나올 확률 + 2 나올 확률 = 1 또는 2 나올 확률

  만약 겹치는 경우라면?
  P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
  → 겹치는 부분을 한 번 빼줘야 중복 계산이 안 됩니다.

---

💬 **퀴즈 1.**
주사위를 던져서 짝수(2,4,6)가 나올 확률과 3의 배수(3,6)가 나올 확률을 각각 구하고,
"짝수 또는 3의 배수"가 나올 확률을 구해보세요. (힌트: 6이 겹칩니다!)

**모범 답:** P(짝수) = 3/6 = 1/2, P(3의배수) = 2/6 = 1/3
겹치는 사건 = {6} → P(겹침) = 1/6
P(짝수 ∪ 3의배수) = 1/2 + 1/3 - 1/6 = 3/6 + 2/6 - 1/6 = 4/6 = 2/3

---

## **[고급 단계] 조건부 확률 (Conditional Probability)**

이제 딥러닝에서 가장 많이 쓰이는 확률 개념이 등장합니다.

### 정의:
  P(A|B) = P(A ∩ B) / P(B)     (단, P(B) > 0)

→ 이 수식의 의미는: **"B가 이미 일어난 세계에서 A가 일어날 확률"**입니다.

### 벤 다이어그램으로 직관적 이해:

전체 세계가 큰 사각형이라고 합시다.
그 안에 동그라미 A와 동그라미 B가 겹쳐져 있습니다.

  ┌─────────────────────────┐
  │    전체 세계 (S)          │
  │   ┌───────┐              │
  │   │   A   │              │
  │   │  ┌──┼──┐             │
  │   │  │A∩B│ │             │
  │   └──┼──┘  │             │
  │      │  B  │             │
  │      └─────┘             │
  └─────────────────────────┘

- P(A|B)를 구한다는 건? → **B라는 동그라미만 남기고 나머지를 다 잘라낸다**는 뜻입니다.
- B만 남은 세계에서 A와 겹치는 부분(A∩B)의 비율이 바로 P(A|B)입니다.
- 즉, "B가 이미 일어났어. 이 좁아진 세계에서 A도 일어났을 비율이 얼마야?" → 그게 조건부 확률!

### 쉬운 예시:

학교에 100명이 있습니다.
- 안경 쓴 사람 = 40명
- 딥러닝 수강생 = 30명
- 안경 쓰고 딥러닝 수강하는 사람 = 15명

**P(딥러닝 수강 | 안경 씀) = ?**
= P(딥러닝 ∩ 안경) / P(안경)
= (15/100) / (40/100)
= 15/40 = 3/8

→ 안경 쓴 사람들만 모아놓고 보면, 그 중 3/8이 딥러닝을 수강합니다.

---

💬 **퀴즈 2.**
비가 오는 날(B)에 우산을 가져오는(A) 확률 P(A|B) = 0.9입니다.
비가 올 확률 P(B) = 0.3입니다.
비가 오면서 동시에 우산을 가져올 확률 P(A ∩ B)는?

**모범 답:** P(A|B) = P(A∩B)/P(B)이므로,
P(A∩B) = P(A|B) × P(B) = 0.9 × 0.3 = 0.27

---

### **💡 핵심 킬러 요약**

1. 확률은 0~1 사이 숫자, 전부 합치면 1
2. 조건부 확률 P(A|B)는 "B라는 좁은 세계에서 A의 비율"
3. P(A|B) = P(A∩B)/P(B) ← 이 공식은 베이즈 정리의 출발점이니 반드시 외우세요!

## **[입문 단계] 결합 확률이 뭔가요?**

- **결합 확률 (Joint Probability):** 두 가지 사건이 동시에 일어나는 확률입니다.
  p(x, y) = P(X = x 이고 Y = y)

- **쉽게 말하면:** 주사위 2개를 동시에 던져서
  "첫 번째가 3이고 두 번째가 5"가 동시에 나올 확률 = p(3, 5)

### 결합 확률 표 예시:

성별(X)과 딥러닝 성적(Y)의 결합 확률 표:

              | Y=A   | Y=B   | Y=C   | 합계
  X=남        | 0.15  | 0.20  | 0.10  | 0.45
  X=여        | 0.20  | 0.25  | 0.10  | 0.55
  합계        | 0.35  | 0.45  | 0.20  | 1.00

p(남, A) = 0.15 → 남자이면서 A학점일 확률

---

## **[중급 단계] 주변 확률 (Marginal Probability)**

결합 확률 표에서 한쪽 변수를 모두 더해서 없애버리는 것입니다.

**수식:**
  p(x) = Σ_y p(x, y)

→ 이 수식의 의미는: Y가 뭐든 상관없이 X만의 확률을 구하려면,
  Y의 모든 가능한 값에 대해 결합 확률을 다 더하면 됩니다.

**위 표에서:**
  p(X=남) = p(남,A) + p(남,B) + p(남,C) = 0.15 + 0.20 + 0.10 = 0.45 ✓

- 왜 "주변(Marginal)"이냐? → 표의 **가장자리(margin)**에 적힌 합계가 바로 이 값이기 때문!

---

## **[고급 단계] 독립 (Independence)**

### 정의:
두 사건 X, Y가 **독립**이라 함은:
  p(x, y) = p(x) × p(y)

→ 이 수식의 의미는: X가 일어나든 말든 Y에 아무 영향이 없고,
  그 반대도 마찬가지라는 뜻입니다.

### 쉬운 비유:
- 서울의 날씨와 뉴욕의 날씨 → 독립 (서로 영향 없음)
- 서울의 날씨와 서울 우산 판매량 → 독립 아님 (강하게 연관)

### 독립의 동치 조건:
  p(x, y) = p(x)p(y)
  ↔ P(X|Y) = P(X)    (Y를 알아도 X에 대한 정보가 추가 안 됨)
  ↔ P(Y|X) = P(Y)    (X를 알아도 Y에 대한 정보가 추가 안 됨)

---

## **i.i.d 가정 — sample_1에서 배운 "곱하기"의 수학적 근거!**

**i.i.d = Independent and Identically Distributed (독립 동일 분포)**

sample_1에서 "데이터가 서로 독립이라서 확률을 곱할 수 있다"고 배웠죠?
이제 그 수학적 근거를 정확히 이해합시다.

**독립이면 결합 확률 = 개별 확률의 곱:**

  데이터 D = {(x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)}가 i.i.d라고 가정하면:

  p(D|θ) = p(y₁,y₂,...,yₙ | x₁,x₂,...,xₙ, θ)
         = Π_{i=1}^{N} p(yᵢ | xᵢ, θ)

→ 이 수식의 의미는:
  "모든 데이터가 서로 독립이니까, 전체 데이터의 확률을
   각 데이터의 확률을 **전부 곱한 것**으로 쓸 수 있다."

→ 이것이 바로 sample_1에서 배운 "1만 개 데이터의 확률을 곱하기로 묶는다"의 정확한 수학 표현입니다!

---

💬 **퀴즈 3.**
동전을 3번 던져서 앞,앞,뒤가 나왔습니다. 앞면 확률 = p라 할 때,
i.i.d 가정 하에서 이 결과의 전체 확률(Likelihood)을 식으로 쓰세요.

**모범 답:** p × p × (1-p) = p²(1-p)
(독립이므로 각 시행의 확률을 곱함)

---

### **📌 채점 저격 포인트**

시험 답안에서 "확률을 곱한다"고 쓸 때 반드시:
"**i.i.d 가정에 의해** 결합 확률을 개별 확률의 곱으로 분리할 수 있다"
라고 명시해야 합니다. 이 한 줄이 없으면 감점!

## **[입문 단계] 비전공자도 이해하는 직관**

### 한 줄 요약:
**"새로운 증거(데이터)를 보고, 내 원래 믿음을 업데이트하는 수학 공식"**

### 일상 비유 — 범인 추리:
경찰이 범인을 추리한다고 합시다.

- 처음에 용의자 A가 범인일 확률: 20% → 이게 **Prior (사전 확률)**
- 새로운 증거 발견: 범행 현장에서 A의 지문이 나옴!
- "A가 진짜 범인이면 지문이 나올 확률": 90% → 이게 **Likelihood (우도)**
- 이 증거를 반영해서 업데이트한 결과: A가 범인일 확률 80% → 이게 **Posterior (사후 확률)**

→ 증거가 추가될 때마다 확률이 **업데이트**되는 것, 이게 베이즈 정리의 핵심!

---

## **[중급 단계] 공식과 각 항의 의미**

### 베이즈 정리 공식:

  P(H|E) = P(E|H) × P(H) / P(E)

각 항의 이름을 하나씩 뜯어봅시다:

**1. P(H|E) : Posterior (사후 확률)**
  → "증거 E를 본 후 가설 H가 맞을 확률"
  → 데이터를 관찰한 뒤 **업데이트된 믿음**
  → 이걸 구하는 게 최종 목표!

**2. P(E|H) : Likelihood (우도, 가능도)**
  → "가설 H가 맞다면, 이 증거 E가 나올 확률"
  → 모델이 데이터를 얼마나 잘 설명하는가

**3. P(H) : Prior (사전 확률)**
  → "데이터를 보기 전의 원래 믿음"
  → 배경지식, 경험, 직감을 수학적으로 표현한 것

**4. P(E) : Evidence (증거, 정규화 상수)**
  → "이 증거가 나올 전체 확률"
  → P(E) = Σ_H P(E|H)P(H) (전체 확률 법칙)
  → 최적화할 때는 H와 무관하므로 **상수 취급해서 무시** 가능!

---

### 구체적 숫자 예시 — 질병 검사:

- 인구의 1%가 특정 질병에 걸림 → P(질병) = 0.01 (Prior)
- 질병 있을 때 양성 나올 확률 → P(양성|질병) = 0.99 (Likelihood)
- 질병 없을 때 양성 나올 확률(오진) → P(양성|정상) = 0.05
- 양성 판정을 받았을 때, 진짜 질병일 확률은?

**풀이:**
P(질병|양성) = P(양성|질병) × P(질병) / P(양성)

P(양성) = P(양성|질병)P(질병) + P(양성|정상)P(정상)
        = 0.99 × 0.01 + 0.05 × 0.99
        = 0.0099 + 0.0495
        = 0.0594

P(질병|양성) = 0.0099 / 0.0594 ≈ 0.167

→ 양성 판정을 받아도 실제 질병일 확률은 약 16.7%밖에 안 됩니다!
→ Prior(사전 확률 1%)가 너무 낮아서, 강력한 검사 결과가 나와도 사후 확률이 크게 높아지지 않습니다.
→ 이것이 **Prior의 힘**입니다!

---

💬 **퀴즈 4.**
위 예시에서 인구의 50%가 질병에 걸린다고 바뀌면(Prior가 0.5), P(질병|양성)은 어떻게 될까요?

**모범 답:**
P(양성) = 0.99 × 0.5 + 0.05 × 0.5 = 0.495 + 0.025 = 0.52
P(질병|양성) = (0.99 × 0.5) / 0.52 = 0.495/0.52 ≈ 0.952

→ Prior가 높아지니 사후 확률이 95.2%로 급등!
→ 사전 확률(Prior)이 얼마나 중요한지 보여주는 예시입니다.

---

## **[고급 단계] MAP와 MLE의 수학적 도출**

이것이 시험의 핵심 of 핵심입니다.

### MAP (Maximum A Posteriori):

**목표:** Posterior를 최대화하는 가설(모델 파라미터) 찾기

  θ_MAP = argmax_θ P(θ|D)
        = argmax_θ [P(D|θ) × P(θ) / P(D)]

→ P(D) = Evidence는 θ에 의존하지 않는 상수!
→ argmax를 구할 때 상수는 결과에 영향을 안 줌

  ∴ θ_MAP = argmax_θ P(D|θ) × P(θ)
                      ~~~~~~~~   ~~~~
                      Likelihood   Prior

→ 이 수식의 의미는: "데이터가 이 모델에서 나올 확률 × 모델에 대한 사전 믿음"을
  가장 크게 만드는 θ를 찾는 것!

### MLE (Maximum Likelihood Estimation):

**만약 Prior를 균등 분포(Uniform)로 가정하면?**
→ P(θ)가 모든 θ에 대해 동일한 상수
→ 상수는 argmax에 영향 없음

  ∴ θ_MLE = argmax_θ P(D|θ)

→ 이 수식의 의미는: "사전 지식을 아예 쓰지 않고, 오직 데이터만 보고 가장 그럴듯한 θ를 찾겠다!"

### MAP와 MLE의 관계 정리:

  MAP = MLE + Prior의 영향

  Prior가 균등 → MAP = MLE (특수한 경우)
  Prior가 강함 → MAP ≠ MLE (Prior가 답을 끌어당김)

### Prior가 강하면 → Inductive Bias 강함

  - sample_1에서 배운 것: "동전이 50:50이라고 강하게 믿으면(Prior가 강하면),
    앞면만 100번 나와도 결론이 쉽게 바뀌지 않는다"
  - 이것이 바로 **Inductive Bias (귀납적 편향)**가 강하게 작용하는 것!
  - Prior가 강하면 → 모델이 데이터에 과도하게 맞추는 것(Overfitting)을 방지
  - Prior가 약하면(또는 없으면 = MLE) → 데이터에만 의존 → Overfitting 위험 증가

---

💬 **퀴즈 5.**
MLE가 MAP의 특수한 경우인 이유를 한 문장으로 설명하세요.

**모범 답:** "MAP에서 Prior를 균등 분포로 놓으면 P(θ)가 상수가 되어
argmax에 영향을 주지 않으므로, Likelihood만 최대화하는 MLE와 같아진다."

---

### **📌 채점 저격 포인트**

**시험에서 "MAP와 MLE의 관계를 설명하시오"라고 나오면:**
1. 베이즈 정리 공식 쓰기
2. Evidence(P(D))가 θ와 무관한 상수임을 명시
3. MAP = argmax_θ P(D|θ)P(θ)임을 보이기
4. Prior를 균등 분포로 놓으면 MLE가 됨을 보이기
5. "따라서 MLE는 MAP에서 Prior가 균등할 때의 특수한 경우이다" 결론

이 5단계를 빠짐없이 쓰면 만점!

# 🔥 제4장. 주요 확률 분포 — "분포를 알아야 Loss를 안다"
# ═══════════════════════════════════════════

---

왜 확률 분포를 배워야 하나?
→ 딥러닝에서 "데이터가 어떤 분포를 따른다"고 **가정**하는 순간,
  Loss 함수가 자동으로 결정되기 때문입니다!

---

## **Part A. 이산 분포 (Discrete Distribution)**

### **1. 베르누이 분포 (Bernoulli Distribution)**

**한 줄 요약:** 결과가 딱 2개(성공/실패, 0/1)인 한 번의 시행

**수식:**
  P(Y = y) = p^y × (1-p)^(1-y)     (y = 0 또는 1)

→ 이 수식의 의미는:
  - y = 1(성공)이면: p^1 × (1-p)^0 = p      → 성공 확률
  - y = 0(실패)이면: p^0 × (1-p)^1 = (1-p)  → 실패 확률
  - 이 한 줄의 수식이 두 경우를 깔끔하게 통합합니다!

**딥러닝 연결:** 이진 분류(Binary Classification)의 기초!
  - "이 이메일이 스팸인가(1) 아닌가(0)?"
  - 모델의 출력 = p (Sigmoid 함수를 통과한 값)

---

### **2. 이항 분포 (Binomial Distribution)**

**한 줄 요약:** 베르누이를 n번 반복했을 때, 성공 횟수의 분포

**수식:**
  P(X = k) = C(n,k) × p^k × (1-p)^(n-k)

→ 이 수식의 의미는:
  - n번 시행 중 정확히 k번 성공할 확률
  - C(n,k) = n! / (k!(n-k)!) → 순서 조합의 수
  - p^k → 성공 k번의 확률
  - (1-p)^(n-k) → 실패 (n-k)번의 확률

**예시:** 동전(앞면 확률 0.5)을 10번 던져서 정확히 7번 앞면이 나올 확률?
  P(X=7) = C(10,7) × 0.5^7 × 0.5^3
         = 120 × (1/128) × (1/8)
         = 120/1024 ≈ 0.117

---

### **3. 카테고리컬 분포 (Categorical Distribution)**

**한 줄 요약:** 결과가 K개 중 하나인 분포 (베르누이의 일반화)

**수식:**
  P(Y = k) = p_k     (k = 1, 2, ..., K)
  단, Σ_{k=1}^{K} p_k = 1

→ 이 수식의 의미는:
  - 주사위(K=6), 가위바위보(K=3), 이미지 분류(K=10, 예: 0~9 숫자)
  - 각 클래스의 확률을 모두 합하면 1

**딥러닝 연결:**
  - 다중 클래스 분류(Multi-class Classification)의 기초!
  - 모델의 출력 = **Softmax 함수**를 통과한 벡터 [p₁, p₂, ..., p_K]
  - 이것과 정답을 비교하는 Loss가 **Cross-Entropy**!

---

💬 **퀴즈 6.**
"이 사진은 고양이(0.7), 개(0.2), 토끼(0.1)이다"라는 모델 출력은
어떤 분포를 따르나요?

**모범 답:** 카테고리컬 분포 (K=3, p₁=0.7, p₂=0.2, p₃=0.1, 합=1.0)

---

## **Part B. 연속 분포 (Continuous Distribution)**

### **1. 가우시안 분포 (Gaussian/Normal Distribution) — 만능 분포!**

**한 줄 요약:** 종 모양 곡선. 평균(μ) 주변에 데이터가 몰려 있다.

**수식:**
  p(x) = (1 / √(2πσ²)) × exp(-(x - μ)² / (2σ²))

→ 이 수식의 의미는:
  - μ (뮤) = 평균, 종의 꼭대기 위치
  - σ² (시그마 제곱) = 분산, 종이 얼마나 퍼져있는지
  - σ가 크면 → 종이 넓고 납작 → 데이터가 넓게 퍼짐
  - σ가 작으면 → 종이 좁고 뾰족 → 데이터가 평균 근처에 몰림
  - exp 안의 (x-μ)² → x가 평균에서 멀수록 확률이 작아짐

**간략 표기:** X ~ N(μ, σ²)  (X는 평균 μ, 분산 σ²인 정규분포를 따른다)

### 왜 가우시안이 만능인가? → Central Limit Theorem (중심극한정리)!

아무리 이상한 분포의 데이터라도, 충분히 많이 모아서 평균을 내면
그 평균값의 분포는 가우시안에 가까워집니다!

→ 현실 세계의 많은 것들(키, 몸무게, 시험 점수, 측정 오차)이
  가우시안처럼 생기는 이유가 바로 이것!

### 가우시안에 로그를 씌우면 → MSE가 나온다!

  log p(x) = log(1/√(2πσ²)) + (-(x-μ)²/(2σ²))
           = 상수 - (x-μ)²/(2σ²)

→ 상수를 무시하면 **(x-μ)²** 형태만 남음!
→ 이것이 바로 **MSE(Mean Squared Error)**의 핵심!
→ 7장에서 이 도출 과정을 완전히 전개합니다.

---

### **2. 다변량 가우시안 (Multivariate Gaussian)**

**한 줄 요약:** 가우시안의 고차원 확장. 변수가 여러 개일 때.

**수식:**
  p(x) = (1 / √((2π)^d |Σ|)) × exp(-½(x-μ)ᵀ Σ⁻¹ (x-μ))

→ 이 수식의 의미는:
  - x = d차원 벡터 (예: 키와 몸무게를 동시에)
  - μ = d차원 평균 벡터
  - Σ (대문자 시그마) = d×d **공분산 행렬**
  - Σ는 변수들 사이의 관계(상관관계)를 담고 있음!

### 공분산 행렬 Σ의 의미:

  Σ = [ σ₁²    ρσ₁σ₂ ]
      [ ρσ₁σ₂  σ₂²   ]

- 대각선(σ₁², σ₂²) = 각 변수의 분산 (자기 자신이 얼마나 퍼져있는지)
- 비대각선(ρσ₁σ₂) = 공분산 (두 변수가 같이 움직이는 정도)
  - 양수 → 같이 증가 (키↑ → 몸무게↑)
  - 음수 → 반대로 움직임 (공부시간↑ → 게임시간↓)
  - 0 → 상관없음

# 🔥 제5장. 기댓값과 분산 — "확률의 요약 통계"
# ═══════════════════════════════════════════

---

## **[입문 단계] 기댓값이 뭔가요?**

### 기댓값 E[X] — 확률적 평균

**쉽게 말하면:** 이 실험을 무한히 반복하면 평균적으로 나올 값

**이산 확률 변수:**
  E[X] = Σ_x x × p(x)

→ 이 수식의 의미는: 각 값에 그 값이 나올 확률을 곱해서 전부 더한 것

**예시:** 주사위 기댓값
  E[X] = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
       = 21/6 = 3.5

→ 주사위를 무한히 던지면 평균은 3.5에 수렴합니다!

**연속 확률 변수:**
  E[X] = ∫ x × p(x) dx

→ 이산에서 Σ(합) → 연속에서 ∫(적분)으로 바뀔 뿐, 개념은 동일!

---

## **[중급 단계] 분산 Var[X]**

### 분산 — 데이터가 평균에서 얼마나 퍼져있는가

**수식:**
  Var[X] = E[(X - μ)²]

→ 이 수식의 의미는: "각 값이 평균에서 얼마나 떨어져 있는지"를 제곱해서 평균 낸 것

**왜 제곱?** → 평균에서의 거리를 그냥 더하면 양수/음수가 상쇄되어 0이 됨.
  제곱해서 항상 양수로 만든 뒤 더하는 거!

**유용한 공식 (시험에 자주 나옴!):**
  Var[X] = E[X²] - (E[X])²

→ 이 수식의 의미는: "제곱의 평균 - 평균의 제곱"
→ 계산이 훨씬 편리해서 실전에서 이걸 씁니다.

**예시:** 주사위
  E[X²] = 1²×(1/6) + 2²×(1/6) + ... + 6²×(1/6) = 91/6 ≈ 15.17
  (E[X])² = 3.5² = 12.25
  Var[X] = 15.17 - 12.25 = 2.92

**표준편차:**
  σ = √Var[X]
  → 분산에 루트를 씌워서 원래 단위로 돌려놓은 것

---

## **[고급 단계] 대수의 법칙과 중심극한정리**

### 대수의 법칙 (Law of Large Numbers, LLN)

**한 줄 요약:** 실험을 많이 반복할수록, 표본 평균은 참 평균에 수렴한다.

  X̄_n = (X₁ + X₂ + ... + Xₙ) / n  →  E[X]  (n → ∞)

**쉬운 비유:** 동전을 10번 던지면 앞면이 7번 나올 수도 있지만,
10000번 던지면 앞면 비율이 거의 정확히 50%에 가까워집니다.

→ 딥러닝에서의 의미: 데이터가 많을수록 학습이 잘 되는 수학적 근거!

---

### 중심극한정리 (Central Limit Theorem, CLT)

**한 줄 요약:** 어떤 분포든, 충분히 많은 표본의 평균은 가우시안 분포를 따른다.

  X̄_n ~ N(μ, σ²/n)   (n이 충분히 클 때)

→ 이 수식의 의미는:
  - 원래 분포가 뭐든 간에(균등, 지수, 이상한 분포...)
  - n개를 뽑아 평균을 내면, 그 평균값은 가우시안을 따른다!
  - n이 커질수록 분산(σ²/n)이 줄어듦 → 평균이 더 정확해짐

→ 딥러닝에서의 의미: 가우시안을 가정하는 것이 합리적인 이유!
→ 이것이 바로 4장에서 "가우시안이 왜 만능인가"의 근거였습니다.

---

💬 **퀴즈 7.**
E[X] = 5, E[X²] = 30일 때, Var[X]는?

**모범 답:** Var[X] = E[X²] - (E[X])² = 30 - 25 = 5

# 💡 제6장. KL Divergence와 정보 이론 — "Loss 함수의 진짜 정체"
# ═══════════════════════════════════════════

---

## **[입문 단계] 엔트로피 (Entropy)**

### 한 줄 요약: 불확실성을 숫자로 측정하는 도구

**수식:**
  H(p) = -Σ_x p(x) × log p(x)

→ 이 수식의 의미는: 확률 분포 p가 얼마나 "불확실한지"를 하나의 숫자로 요약한 것

**직관:**
- 동전이 완벽히 공정(50:50) → 불확실성 최대 → 엔트로피 높음
- 동전이 100:0 (항상 앞면) → 불확실성 없음 → 엔트로피 = 0
- 주사위(1/6씩) → 동전보다 경우의 수가 많으므로 → 엔트로피 더 높음

**계산 예시 (공정한 동전):**
  H = -(0.5 × log₂(0.5) + 0.5 × log₂(0.5))
    = -(0.5 × (-1) + 0.5 × (-1))
    = -(-1) = 1 bit

---

## **[중급 단계] Cross-Entropy (교차 엔트로피)**

### 수식:
  CE(p, q) = -Σ_x p(x) × log q(x)

→ 이 수식의 의미는: 진짜 분포 p의 데이터를 모델 분포 q로 설명할 때 필요한 평균 정보량

→ **p = 정답 분포, q = 모델의 예측 분포**

### 왜 분류 문제의 Loss가 Cross-Entropy인가?

이것이 시험 출제 포인트입니다!

**예시:** 정답이 "고양이"인 사진

  정답 분포 p = [1, 0, 0]  (고양이=1, 개=0, 토끼=0)    → one-hot 벡터
  모델 예측 q = [0.7, 0.2, 0.1]                         → Softmax 출력

  CE(p, q) = -(1×log(0.7) + 0×log(0.2) + 0×log(0.1))
           = -log(0.7)
           ≈ 0.357

→ p가 one-hot이므로, 정답 클래스의 log 확률만 남는다!
→ 모델이 정답을 높은 확률로 예측할수록 CE가 작아짐 → 이걸 최소화하면 학습!

만약 모델이 완벽하게 맞추면?
  q = [1.0, 0, 0]일 때
  CE = -log(1.0) = 0  → Loss = 0 (완벽!)

---

## **[고급 단계] KL Divergence**

### 수식:
  KL(p || q) = Σ_x p(x) × log(p(x)/q(x))
             = CE(p, q) - H(p)

→ 이 수식의 의미는: 두 확률 분포 p와 q가 **얼마나 다른지** 측정하는 거리 같은 것

### 핵심 성질:
  - KL(p || q) ≥ 0 (항상 0 이상! → **깁스 부등식**)
  - KL(p || q) = 0 ↔ p = q (두 분포가 완전히 같을 때만 0)
  - KL(p || q) ≠ KL(q || p) (비대칭! 진짜 거리는 아님)

### CE와 KL의 관계:
  CE(p, q) = H(p) + KL(p || q)

→ 이 수식의 의미는:
  - H(p)는 정답 분포의 엔트로피로, 학습과 무관한 **상수**!
  - 따라서 CE를 최소화 = KL을 최소화 = **모델 q를 정답 p에 가깝게 만드는 것!**
  - 이것이 Cross-Entropy Loss의 수학적 정당성!

---

### **슬라이드 핵심 강조 (page 272):**
**"CE와 MSE는 결국 같은 목적(NLL, Negative Log-Likelihood)이다!"**

  - 가우시안 분포를 가정하고 NLL → MSE
  - 베르누이/카테고리컬 분포를 가정하고 NLL → Cross-Entropy
  - 둘 다 "모델의 예측을 정답에 가깝게" 하는 것이 목적
  - 차이는 단지 **가정하는 분포가 다를 뿐**!

---

## **Mutual Information (상호 정보량)**

**수식:**
  I(X; Y) = KL(p(x,y) || p(x)p(y))

→ 이 수식의 의미는: X와 Y가 **얼마나 서로 정보를 공유하는지**

→ 만약 X와 Y가 독립이면:
  p(x,y) = p(x)p(y) → KL = 0 → 상호 정보량 = 0 (정보 공유 없음)

→ X를 알면 Y를 완벽히 예측 가능 → 상호 정보량 최대

---

정답 분포 p = [1, 0]이고 모델 예측 q = [0.8, 0.2]일 때,
Binary Cross-Entropy를 계산하세요.

**모범 답:**
CE = -(1 × log(0.8) + 0 × log(0.2))
   = -log(0.8) ≈ 0.223

## **Part A. 가우시안에서 MLE → MSE 도출 (완전 전개)**

### **[Step 0] 가정 명시 (이걸 빼먹으면 감점!)**

- 데이터: D = {(x₁,y₁), (x₂,y₂), ..., (xₙ,yₙ)}
- 모델: y의 조건부 확률이 가우시안 분포를 따른다고 가정
  p(yᵢ | xᵢ, θ) = N(yᵢ ; h(xᵢ), σ²)
  = (1/√(2πσ²)) × exp(-(yᵢ - h(xᵢ))² / (2σ²))

  여기서 h(xᵢ)는 모델의 예측값, σ²는 분산(상수 취급)

### **[Step 1] i.i.d 가정으로 결합 확률을 곱으로**

- "데이터가 i.i.d를 따르므로, 결합 확률을 개별 확률의 곱으로 분리할 수 있다."

  p(D|θ) = Π_{i=1}^{N} p(yᵢ | xᵢ, θ)

→ 이 수식의 의미는: N개 데이터의 전체 확률 = 각 데이터 확률을 전부 곱한 것

### **[Step 2] Log Likelihood — 로그를 씌운다**

- "로그는 단조 증가 함수이므로, 로그를 씌워도 최대/최소 위치가 바뀌지 않는다.
  또한 곱셈이 덧셈으로 바뀌어 계산이 용이해지고 언더플로우를 방지한다."

  log p(D|θ) = Σ_{i=1}^{N} log p(yᵢ | xᵢ, θ)

→ Π(곱)이 Σ(합)으로 바뀜!

### **[Step 3] 가우시안 대입**

  log p(yᵢ | xᵢ, θ) = log[ (1/√(2πσ²)) × exp(-(yᵢ - h(xᵢ))² / (2σ²)) ]

  = log(1/√(2πσ²)) + log(exp(-(yᵢ - h(xᵢ))² / (2σ²)))

  = -½log(2πσ²) - (yᵢ - h(xᵢ))² / (2σ²)

→ 이 수식의 의미는: log 안의 exp가 서로 상쇄되어,
  지수에 있던 (yᵢ - h(xᵢ))²가 밖으로 튀어나옴!

### **[Step 4] 전체 Log Likelihood**

  log p(D|θ) = Σ_{i=1}^{N} [ -½log(2πσ²) - (yᵢ - h(xᵢ))² / (2σ²) ]

  = -N/2 × log(2πσ²) - (1/(2σ²)) × Σ_{i=1}^{N} (yᵢ - h(xᵢ))²
    ~~~~~~~~~~~~~~~~      ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    θ와 무관한 상수!       이 부분만 θ에 의존!

### **[Step 5] 최대화 → 최소화 변환**

- MLE의 목표: log p(D|θ)를 최대화
- 상수 부분은 무시 가능
- 남은 부분: -(1/(2σ²)) × Σ(yᵢ - h(xᵢ))²를 최대화
  = Σ(yᵢ - h(xᵢ))²를 **최소화** (앞의 음수 부호 때문에 방향 반전!)

  ∴ θ_MLE = argmin_θ  Σ_{i=1}^{N} (yᵢ - h(xᵢ))²

→ 이것이 바로 **MSE(Mean Squared Error)**!!!

### **한 줄 결론:**
  **"데이터가 가우시안 분포를 따른다고 가정하고 MLE를 적용하면, MSE를 최소화하는 것과 동일하다."**

---

## **Part B. 베르누이에서 MLE → Cross-Entropy 도출 (완전 전개)**

### **[Step 0] 가정 명시**

- 이진 분류 문제: y ∈ {0, 1}
- 모델: p(y=1 | x, θ) = σ(h(x)) = p  (Sigmoid 출력)
  p(yᵢ | xᵢ, θ) = p^{yᵢ} × (1-p)^{1-yᵢ}   (베르누이 분포)

### **[Step 1] i.i.d 가정으로 곱**

  p(D|θ) = Π_{i=1}^{N} p^{yᵢ} × (1-p)^{1-yᵢ}

### **[Step 2] Log Likelihood**

  log p(D|θ) = Σ_{i=1}^{N} [ yᵢ × log(p) + (1-yᵢ) × log(1-p) ]

→ 이 수식의 의미는:
  - yᵢ=1일 때: log(p) → 정답이 1인데 모델이 높은 p를 줘야 log가 0에 가까워짐(좋음)
  - yᵢ=0일 때: log(1-p) → 정답이 0인데 모델이 낮은 p를 줘야 좋음

### **[Step 3] 최대화 → 최소화 변환**

  MLE: maximize Σ [ yᵢlog(p) + (1-yᵢ)log(1-p) ]
  = minimize -Σ [ yᵢlog(p) + (1-yᵢ)log(1-p) ]

  ∴ Loss = -Σ [ yᵢlog(p) + (1-yᵢ)log(1-p) ]

→ 이것이 바로 **Binary Cross-Entropy (BCE) Loss**!!!

### **한 줄 결론:**
  **"데이터가 베르누이 분포를 따른다고 가정하고 MLE를 적용하면, Cross-Entropy를 최소화하는 것과 동일하다."**

---

### **CE와 MSE의 통합 — NLL (Negative Log-Likelihood)**

정리하면:

  | 가정하는 분포      | MLE 적용 결과        | 대응 Loss 함수    | 사용처     |
  |--------------------|--------------------|------------------|-----------|
  | 가우시안 (연속값)    | NLL → Σ(y-ŷ)²     | MSE              | 회귀      |
  | 베르누이 (0 or 1)   | NLL → -Σ[ylog(p)] | Binary CE        | 이진 분류  |
  | 카테고리컬 (K개)    | NLL → -Σ[ylog(p)] | Categorical CE   | 다중 분류  |

→ **전부 같은 원리(NLL 최소화)에서 파생된 것!**
→ 분포만 바꾸면 Loss가 자동으로 결정됨!

---

💬 **퀴즈 9.**
"왜 회귀 문제에서 MSE를 쓰고, 분류 문제에서 Cross-Entropy를 쓰나요?"
한 문장으로 답하세요.

**모범 답:** "회귀에서는 출력이 가우시안 분포를 따른다고 가정하므로 NLL이 MSE가 되고,
분류에서는 출력이 베르누이/카테고리컬 분포를 따른다고 가정하므로 NLL이 Cross-Entropy가 된다."

# 💡 제8장. MAP와 정규화의 연결 — 시험 출제 가능!
# ═══════════════════════════════════════════

---

## **[입문 단계] 직관 — Prior를 쓰면 왜 좋은가?**

MLE는 데이터만 보고 모델을 맞춤 → 데이터에 과도하게 맞출 위험 (Overfitting)

MAP는 Prior(사전 지식)을 추가 → "너무 극단적인 파라미터는 싫어!"라는 제약을 검

**쉬운 비유:**
- MLE = 시험 문제만 외워서 시험 치는 학생 (그 시험엔 잘 보지만, 새 문제엔 약함)
- MAP = 교과서 기본기를 탄탄히 한 학생 (특정 시험엔 MLE보다 못 볼 수 있지만, 새 문제에 강함)

---

## **[중급 단계] MAP 수식 전개**

  θ_MAP = argmax_θ P(D|θ) × P(θ)

양변에 log를 씌우면:

  θ_MAP = argmax_θ [ log P(D|θ) + log P(θ) ]
                     ~~~~~~~~~~~~   ~~~~~~~~~
                     Log-Likelihood  Log-Prior

→ 이 수식의 의미는:
  MAP = MLE + Prior 항
  Prior가 추가됨으로써 파라미터에 제약이 생김!

---

## **[고급 단계] 가우시안 Prior → L2 정규화 (Ridge)**

### 가정: θ의 Prior가 가우시안
  P(θ) = N(0, τ²I) = (1/√(2πτ²)) × exp(-θ²/(2τ²))

### Log-Prior:
  log P(θ) = -θ²/(2τ²) + 상수

### MAP 목표 함수:
  θ_MAP = argmax_θ [ log P(D|θ) - θ²/(2τ²) ]
        = argmin_θ [ -log P(D|θ) + θ²/(2τ²) ]
        = argmin_θ [ NLL + λ||θ||² ]

  여기서 λ = 1/(2τ²)

→ 이 수식의 의미는:
  **NLL(손실 함수) + λ||θ||²(L2 정규화)**를 최소화하는 것!
  = 우리가 흔히 쓰는 **L2 정규화 (Ridge Regression, Weight Decay)**와 완전히 같다!

### 핵심 통찰:
  **"L2 정규화 = 파라미터에 가우시안 Prior를 거는 것이다"**

  - λ가 크면 → Prior가 강함 → θ를 0 가까이로 강하게 끌어당김 → 정규화 강함
  - λ가 작으면 → Prior가 약함 → 데이터에 더 의존 → MLE에 가까워짐
  - λ = 0이면 → Prior 없음 → MLE와 동일

---

## **라플라스 Prior → L1 정규화 (Lasso)**

### 가정: θ의 Prior가 라플라스 분포
  P(θ) ∝ exp(-|θ|/b)

### Log-Prior:
  log P(θ) = -|θ|/b + 상수

### MAP 목표 함수:
  θ_MAP = argmin_θ [ NLL + λ||θ||₁ ]

→ 이 수식의 의미는:
  **NLL + λΣ|θᵢ|(L1 정규화)**를 최소화하는 것!
  = **L1 정규화 (Lasso)**와 완전히 같다!

### L1 vs L2 정규화 비교:

  | 구분      | L1 (Lasso)           | L2 (Ridge)           |
  |----------|---------------------|---------------------|
  | Prior    | 라플라스 분포         | 가우시안 분포          |
  | 수식     | λΣ|θᵢ|              | λΣθᵢ²               |
  | 효과     | 일부 θ를 정확히 0으로  | θ를 0 근처로 작게     |
  | 특징     | Feature Selection    | 모든 feature 유지     |

---

### **대통일 요약: 정규화 = Prior를 강하게 거는 것!**

  MAP = MLE + Prior
  정규화된 Loss = NLL + 정규화 항
  → 정규화 항은 곧 Prior의 Log!

이 연결고리를 이해하면:
1. 왜 정규화가 Overfitting을 줄이는지 (Prior가 극단적 파라미터를 억제)
2. 왜 λ를 "정규화 강도"라고 부르는지 (Prior의 강도 = λ)
3. 왜 L1은 feature selection이 되는지 (라플라스 Prior의 뾰족한 모양)
전부 하나의 원리로 설명됩니다!

---

💬 **퀴즈 10.**
"L2 정규화가 MAP의 가우시안 Prior에 해당한다"는 것을 3줄로 설명하세요.

**모범 답:**
1. MAP = argmax [log P(D|θ) + log P(θ)]에서 P(θ)를 가우시안 N(0,τ²)으로 놓으면,
2. log P(θ) = -θ²/(2τ²) + 상수이므로, MAP = argmin [NLL + (1/(2τ²))·||θ||²]가 되어,
3. 이는 NLL + λ||θ||²를 최소화하는 L2 정규화와 수학적으로 동일하다.

## **📝 모범 답안 1: "베이즈 정리에서 MAP와 MLE의 관계를 설명하시오"**

**[답안 시작]**

베이즈 정리에 의해 파라미터 θ의 사후 확률은 다음과 같다:

  P(θ|D) = P(D|θ) × P(θ) / P(D)

여기서 P(D|θ)는 Likelihood, P(θ)는 Prior, P(D)는 Evidence이다.

**MAP(Maximum A Posteriori)**는 사후 확률을 최대화하는 θ를 구하는 것이다:

  θ_MAP = argmax_θ P(θ|D)

이때 P(D)는 θ에 의존하지 않는 상수이므로 argmax에 영향을 주지 않아 무시할 수 있다:

  θ_MAP = argmax_θ P(D|θ) × P(θ)

여기서 만약 Prior P(θ)를 균등 분포(Uniform Distribution)로 놓으면,
P(θ)는 모든 θ에 대해 동일한 상수가 되어 argmax에 영향을 주지 않는다.

  θ_MAP = argmax_θ P(D|θ) = θ_MLE

따라서 **MLE(Maximum Likelihood Estimation)**는 MAP에서 Prior가 균등 분포인
특수한 경우이다. MAP는 Likelihood와 Prior를 모두 고려하며,
MLE는 Likelihood만을 고려한다는 차이가 있다.

Prior가 강할수록 모델에 Inductive Bias가 강하게 작용하여
데이터에 대한 과적합(Overfitting)을 방지하는 효과가 있다.

**[답안 끝]**

---

## **📝 모범 답안 2: "가우시안 분포에서 MLE를 적용하면 MSE가 도출되는 과정을 논리적으로 서술하시오"**

**[답안 시작]**

**가정:** N개의 데이터 {(xᵢ, yᵢ)}가 i.i.d이고, 각 데이터의 조건부 확률이
가우시안 분포를 따른다고 가정한다.

  p(yᵢ|xᵢ,θ) = N(yᵢ; h(xᵢ), σ²)

**Step 1.** i.i.d 가정에 의해 전체 데이터의 결합 확률을 개별 확률의 곱으로 분리한다:
  P(D|θ) = Π_{i=1}^{N} p(yᵢ|xᵢ,θ)

**Step 2.** 로그는 단조 증가 함수이므로, 최대화 지점이 변하지 않으면서
곱셈을 덧셈으로 변환하고 언더플로우를 방지하기 위해 Log를 취한다:
  log P(D|θ) = Σ_{i=1}^{N} log p(yᵢ|xᵢ,θ)

**Step 3.** 가우시안 분포의 확률 밀도 함수를 대입하면:
  log p(yᵢ|xᵢ,θ) = -½log(2πσ²) - (yᵢ - h(xᵢ))² / (2σ²)

**Step 4.** 전체 Log-Likelihood는:
  Σ_{i=1}^{N} [ -½log(2πσ²) - (yᵢ - h(xᵢ))² / (2σ²) ]
  = -N/2·log(2πσ²) - 1/(2σ²) × Σ(yᵢ - h(xᵢ))²

**Step 5.** 첫째 항은 θ와 무관한 상수이고, 1/(2σ²)도 양의 상수이므로,
Log-Likelihood를 최대화하는 것은 Σ(yᵢ - h(xᵢ))²를 **최소화**하는 것과 같다.

  ∴ θ_MLE = argmin_θ Σ_{i=1}^{N} (yᵢ - h(xᵢ))²

이것이 바로 MSE(Mean Squared Error)이다.

**결론:** 가우시안 분포 가정 하에서 MLE를 적용하면, Negative Log-Likelihood의
최소화는 MSE의 최소화와 수학적으로 동일하다.

**[답안 끝]**

---

## **📝 모범 답안 3: "Cross-Entropy Loss와 MSE Loss가 같은 목적(NLL)이라는 것을 설명하시오"**

**[답안 시작]**

두 Loss 함수 모두 **Negative Log-Likelihood(NLL)**를 최소화하는 것에서 파생된다.
차이점은 가정하는 확률 분포가 다를 뿐이다.

**Case 1. 가우시안 분포 가정 (회귀 문제):**
  p(y|x,θ) = N(y; h(x), σ²)을 가정하면,
  NLL = -log P(D|θ) ∝ Σ(yᵢ - h(xᵢ))² = MSE

**Case 2. 베르누이 분포 가정 (이진 분류 문제):**
  p(y|x,θ) = p^y(1-p)^{1-y}를 가정하면,
  NLL = -log P(D|θ) = -Σ[yᵢlog(pᵢ) + (1-yᵢ)log(1-pᵢ)] = Binary Cross-Entropy

**Case 3. 카테고리컬 분포 가정 (다중 분류 문제):**
  p(y=k|x,θ) = softmax(h(x))_k를 가정하면,
  NLL = -Σ Σ_k y_{ik}log(p_{ik}) = Categorical Cross-Entropy

따라서 MSE와 Cross-Entropy는 모두 NLL을 최소화하는 것이며,
가정하는 분포(가우시안 vs 베르누이/카테고리컬)만 다를 뿐
**"모델의 예측을 데이터에 최대한 가깝게 만든다"는 동일한 목적**을 가진다.

**[답안 끝]**

---

## **📝 모범 답안 4: "L2 정규화가 MAP의 가우시안 Prior에 해당한다는 것을 설명하시오"**

**[답안 시작]**

MAP는 사후 확률을 최대화하므로:
  θ_MAP = argmax_θ [log P(D|θ) + log P(θ)]

여기서 Prior P(θ)를 평균 0, 분산 τ²인 가우시안 분포 N(0, τ²I)로 놓으면:
  log P(θ) = -||θ||²/(2τ²) + const

이를 대입하면:
  θ_MAP = argmax_θ [log P(D|θ) - ||θ||²/(2τ²)]
        = argmin_θ [NLL + (1/(2τ²)) × ||θ||²]

여기서 λ = 1/(2τ²)로 치환하면:
  θ_MAP = argmin_θ [NLL + λ||θ||²]

이는 NLL에 L2 정규화 항 λ||θ||²를 추가한 것과 수학적으로 동일하다.

따라서 **L2 정규화(Ridge/Weight Decay)는 MAP에서 파라미터의 Prior를
가우시안으로 설정한 것과 같다.** 정규화 강도 λ가 클수록 Prior가 강해져
파라미터가 0 근처에 머물도록 유도하며, 이는 Overfitting을 방지하는 효과가 있다.

마찬가지로, Prior를 라플라스 분포로 놓으면 L1 정규화(Lasso)가 도출된다.

**[답안 끝]**

### **이 파일에서 배운 모든 것을 한 장으로 요약:**

```
확률 기초
  ├── P(A|B) = P(A∩B)/P(B)  ← 조건부 확률
  ├── p(x,y) = p(x)p(y)     ← 독립이면 곱!
  └── i.i.d 가정             ← 전체 확률 = 개별 곱

베이즈 정리: P(H|E) = P(E|H)P(H) / P(E)
  ├── MAP = argmax P(D|θ)P(θ)   ← Likelihood × Prior
  └── MLE = argmax P(D|θ)       ← Prior 균등 → 특수 경우

확률 분포 → Loss 함수 자동 결정:
  ├── 가우시안  → NLL → MSE      (회귀)
  ├── 베르누이  → NLL → BCE      (이진 분류)
  └── 카테고리컬 → NLL → CE      (다중 분류)

MAP + 가우시안 Prior → L2 정규화 (Ridge)
MAP + 라플라스 Prior → L1 정규화 (Lasso)

정보 이론:
  ├── Entropy H(p) = 불확실성 측정
  ├── Cross-Entropy CE(p,q) = 분류 Loss
  ├── KL(p||q) = CE - H = 분포 차이 측정
  └── CE 최소화 = KL 최소화 = 모델을 정답에 가깝게!
```

---

### **🎯 Top 3 — 결국 뭐가 중요한가**

1. **베이즈 정리와 MAP/MLE 관계:** 베이즈 공식에서 Prior를 균등으로 놓으면 MLE,
   Prior를 가우시안으로 놓으면 L2 정규화. 이 연결고리를 수식과 글로 모두 전개 가능해야 합니다.

2. **가우시안 → MSE, 베르누이 → CE 도출 과정:** i.i.d 가정 → 곱 → 로그 → 더하기 →
   분포 대입 → Loss 도출. 이 5단계를 "왜 그렇게 되는지" 이유와 함께 서술해야 합니다.

3. **CE와 MSE는 같은 목적(NLL):** 가정하는 분포만 다를 뿐 전부 NLL 최소화.
   이걸 한 문장으로 설명할 수 있으면 교수님이 좋아합니다.

**[확률 기초]**
  P(A|B) = P(A∩B) / P(B)
  독립: P(A∩B) = P(A)P(B)
  주변확률: p(x) = Σ_y p(x,y)

**[베이즈 정리]**
  P(H|E) = P(E|H)P(H) / P(E)
  MAP: θ* = argmax_θ P(D|θ)P(θ)
  MLE: θ* = argmax_θ P(D|θ)

**[확률 분포]**
  베르누이: p^y(1-p)^{1-y}
  가우시안: (1/√(2πσ²)) exp(-(x-μ)²/(2σ²))

**[기댓값/분산]**
  E[X] = Σ x·p(x)
  Var[X] = E[X²] - (E[X])²

**[정보 이론]**
  H(p) = -Σ p(x)log p(x)
  CE(p,q) = -Σ p(x)log q(x)
  KL(p||q) = CE(p,q) - H(p)
  I(X;Y) = KL(p(x,y) || p(x)p(y))

**[MLE → Loss]**
  가우시안 + MLE → MSE = Σ(y-ŷ)²
  베르누이 + MLE → BCE = -Σ[ylog(p)+(1-y)log(1-p)]

**[MAP → 정규화]**
  가우시안 Prior + MAP → NLL + λ||θ||²  (L2 정규화)
  라플라스 Prior + MAP → NLL + λ||θ||₁  (L1 정규화)
