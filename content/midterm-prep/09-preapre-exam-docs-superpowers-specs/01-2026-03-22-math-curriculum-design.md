## Chapter Standard Structure

모든 챕터는 아래 8개 섹션을 포함한다:

### 1. 학습 목표
- 이 장에서 증명/유도할 수 있어야 하는 것 목록

### 2. 필수 정의
- **Definition X.X (이름)** 형식
- 정의 후 예시(example)와 비예시(non-example) 포함

### 3. 핵심 정리와 명제
- **Theorem X.X (이름)**: 정식 서술
- **왜 중요한가**: 1~2문장
- **어디에 쓰이는가**: 딥러닝/ML 맥락 연결

### 4. 공식 및 수식 유도
- 정의에서 출발하여 단계별 유도
- 각 단계에 근거(어떤 정의/정리를 사용했는지) 명시

### 5. 증명
- 정리별 엄밀한 증명
- 증명 전략을 먼저 1~2줄로 요약 후 전개

### 6. 계산 예제와 단계별 풀이
- 구체적 숫자로 된 예제, 중간 계산 생략 없이 전개

### 7. 자주 나오는 함정과 반례
- 흔한 오개념, 실수 패턴

### 8. 시험형 서술 문제와 모범답안
- 정의형 / 증명형 / 유도형 / 계산형 / 응용형
- 각 문제에 모범답안 포함

## Exam Problem Types

모든 시험문제는 5가지 유형을 포함한다:

- **정의형**: 정의를 쓰고 예시와 비예시를 들어 설명
- **증명형**: 정리를 진술하고 엄밀히 증명
- **유도형**: 공식을 처음 정의에서부터 유도
- **계산형**: 중간 계산을 생략하지 말고 단계별로 전개
- **응용형**: 배운 정리가 PageRank, SVD, Softmax, Bayesian inference에 어떻게 쓰이는지 설명
