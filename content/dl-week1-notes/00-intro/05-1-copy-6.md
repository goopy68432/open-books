# PART 1. 왜 학습률 조건이 필요한가 — 직관부터

---

## 🟢 입문: 중1 수준으로 시작

### 가장 쉬운 비유: 계단 내려가기

산꼭대기에서 가장 낮은 골짜기로 내려가야 한다고 상상하세요.

- **한 걸음 = 학습률(η)**
- **경사(기울기) = Gradient(∇f)**
- **골짜기 최저점 = 최솟값(θ*)**

**학습률이 너무 작으면**: 1cm씩 걸어가니 평생 걸린다 → 수렴은 하지만 너무 느림

**학습률이 딱 맞으면**: 적당히 빠르게 골짜기로 내려간다 → 최적

**학습률이 너무 크면**: 한 걸음에 반대편 산봉우리로 넘어가 버린다 → **발산!**

---

## 🟡 중급: 백엔드 개발자 관점으로

20년차 백엔드 개발자로서 기억하실 **Rate Limiter** 패턴이 있으신가요?

- **학습률 η = API 호출 빈도**: 너무 높으면 서버 과부하(발산), 너무 낮으면 처리량 부족(느린 수렴)
- **λ_max(A) = 시스템의 최대 허용 부하 한계**: 가장 민감한 방향의 곡률
- **η < 2/λ_max = Rate Limit 임계값**: 이 값 이하로 유지하면 안정적 수렴 **보장**

Rate Limiter에 `config.max_rate = 2 / system_max_load` 설정하는 것과 완전히 같은 구조입니다.

# PART 2. 이차 함수(Quadratic)에서의 설정

---

## 🟢 입문: 왜 이차 함수인가?

### 교수님의 핵심 원칙
> "복잡한 함수는 다루기가 어렵고 무조건 선형으로 근사"

실제 딥러닝의 손실 함수는 복잡한 비선형 함수입니다. 하지만 수렴 분석을 하려면 다루기 쉬운 형태가 필요합니다.

**Taylor 전개 (2차 근사)**를 사용하면 어떤 함수든 이차 함수로 근사할 수 있습니다.

중학교 수준으로 먼저 이해해 봅시다:

```
f(x) ≈ f(x₀) + f'(x₀)(x - x₀) + (1/2)f''(x₀)(x - x₀)²
        [상수]   [1차항: 기울기]   [2차항: 곡률]
```

이 2차 근사의 일반적인 형태가 바로 **이차 함수(Quadratic Form)**입니다.

---

## 🔴 고급: Quadratic 함수 정의

### 목적 함수 설정

$$f(\theta) = \frac{1}{2}\theta^T A\theta + b^T\theta + c$$

**기호 Line-by-Line 해체:**

```
f(θ)
└── θ: 우리가 최적화하는 파라미터 (모델의 가중치들)
    벡터이므로 [θ₁, θ₂, ..., θₙ]^T 형태

(1/2)
└── 왜 1/2를 곱하는가?
    나중에 미분할 때 2가 나오는데, 이 2와 곱해져 1이 되어 깔끔해짐
    (미적분 편의를 위한 관례)

θ^T A θ
└── θ^T: θ의 전치(transpose) — 행벡터로 변환
    A: 행렬 (A = A^T 대칭, A ≻ 0 양정치 라고 가정)
    θ: 열벡터
    전체 의미: 스칼라 값 (벡터 × 행렬 × 벡터 = 스칼라)
    이것이 바로 "이차 형식(Quadratic Form)"

b^T θ
└── b: 상수 벡터
    b^T θ = b₁θ₁ + b₂θ₂ + ... + bₙθₙ (내적)
    이것은 선형항 (1차)

c
└── 상수항 — 최적화에 영향 없음 (θ와 무관)
```

**왜 A = A^T (대칭) 조건이 필요한가?**

이차 형식 x^T A x에서 A가 대칭이 아니어도 실제 값은 같습니다 (A와 (A+A^T)/2의 결과가 같음). 하지만 분석을 쉽게 하기 위해 대칭으로 가정합니다.

**왜 A ≻ 0 (양정치) 조건이 필요한가?**

- 양정치 = 모든 고유값이 양수
- 이것이 보장되어야 f(θ)가 **아래로 볼록(convex)**
- 아래로 볼록해야 **전역 최솟값(global minimum)**이 존재

---

## 🟡 Gradient 계산

$$\nabla f(\theta) = A\theta + b$$

**왜 이렇게 미분되는가? — 중1 수준 유도:**

먼저 1차원(숫자)으로 이해합시다:

```
f(x) = (1/2) a x² + bx + c 라면
f'(x) = (1/2) · a · 2x + b = ax + b
```

이것을 다차원으로 일반화하면:

```
f(θ) = (1/2) θ^T A θ + b^T θ + c
∇f(θ) = Aθ + b
```

```
∇f(θ)
└── ∇: "nabla" 기호, 각 성분에 대해 편미분한 벡터
    ∇f = [∂f/∂θ₁, ∂f/∂θ₂, ..., ∂f/∂θₙ]^T
    이것이 gradient = "가장 가파르게 올라가는 방향과 크기"
```

---

## 🟡 최적해 계산

최솟값에서는 gradient = 0:

$$\nabla f(\theta^*) = A\theta^* + b = 0$$

$$A\theta^* = -b$$

$$\theta^* = -A^{-1}b$$

```
왜 A^{-1}이 존재하는가?
└── A ≻ 0 (양정치)이면 모든 고유값이 양수
    고유값이 모두 0이 아님 → A 가역(역행렬 존재) 성립
    (역행렬 존재 조건: 모든 고유값 ≠ 0)
```

# PART 3. GD 업데이트와 오차 벡터 유도 (핵심 증명)

---

## 🟢 입문: GD가 하는 일

Gradient Descent의 업데이트 규칙:

$$\theta_{t+1} = \theta_t - \eta \nabla f(\theta_t)$$

```
θ_{t+1}: 다음 스텝에서의 파라미터
θ_t: 현재 파라미터
η: 학습률 (Learning Rate, eta) — 한 걸음의 크기
∇f(θ_t): 현재 위치에서의 기울기 (gradient)
-: 기울기의 반대 방향으로 이동 (내리막 방향)
```

이 공식이 의미하는 것: "지금 있는 곳에서 가장 가파르게 내려가는 방향으로 η만큼 이동해라"

---

## 🔴 고급: 오차 벡터의 재귀 관계 유도 (시험 핵심 증명)

### Step 1: 오차 벡터 정의

$$e_t = \theta_t - \theta^*$$

```
e_t: t번째 스텝에서의 오차 벡터
     (현재 파라미터와 최적 파라미터의 차이)
θ_t: 현재 파라미터
θ*: 최적 파라미터 (우리가 도달하려는 목표)

수렴 = e_t → 0 = θ_t가 θ*에 가까워지는 것
```

---

### Step 2: GD 업데이트를 오차로 표현

**GD 업데이트 공식에 ∇f = Aθ + b 대입:**

$$\theta_{t+1} = \theta_t - \eta(A\theta_t + b)$$

**오차 벡터의 다음 스텝:**

$$e_{t+1} = \theta_{t+1} - \theta^*$$

**우변에 θ_{t+1} 대입:**

$$e_{t+1} = (\theta_t - \eta A\theta_t - \eta b) - \theta^*$$

---

### Step 3: b를 A와 θ*로 교체하는 트릭 (핵심!)

앞서 구한 최적해 조건: $\theta^* = -A^{-1}b$

이를 변환하면: $A\theta^* = -b$ → $b = -A\theta^*$

**b = -Aθ*를 대입:**

$$e_{t+1} = (\theta_t - \eta A\theta_t + \eta A\theta^*) - \theta^*$$

**θ_t와 θ*를 묶기:**

$$e_{t+1} = (\theta_t - \theta^*) - \eta A(\theta_t - \theta^*)$$

```
왜 이렇게 묶을 수 있는가?
θ_t - ηAθ_t + ηAθ* - θ*
= (θ_t - θ*) - ηA(θ_t - θ*)   ← θ_t와 θ*를 묶음, A는 공통인수 추출
= (1 - ηA)(θ_t - θ*)           ← 1과 ηA를 묶음 (행렬에서 I를 생략)
```

**e_t = θ_t - θ* 이므로:**

$$\boxed{e_{t+1} = (I - \eta A)e_t}$$

```
I: 단위행렬 (Identity Matrix) — 대각선이 1, 나머지 0인 행렬
   행렬에서 숫자 1의 역할 (어떤 행렬에 곱해도 변화 없음)
η: 학습률 (스칼라 = 숫자)
A: 목적함수의 Hessian (행렬)
ηA: 학습률 × 행렬 = 행렬의 모든 원소에 η를 곱한 것
I - ηA: 단위행렬에서 ηA를 뺀 행렬
전체 의미: "오차가 한 스텝마다 (I - ηA)를 곱한 만큼 변한다"
```

---

### Step 4: 귀납법으로 일반항 도출

t=0부터 반복 적용:

```
e_1 = (I - ηA) e_0
e_2 = (I - ηA) e_1 = (I - ηA)² e_0
e_3 = (I - ηA) e_2 = (I - ηA)³ e_0
...
```

$$\boxed{e_t = (I - \eta A)^t e_0}$$

```
(I - ηA)^t: 행렬을 t번 곱한 것
e_0: 초기 오차 (처음 시작할 때의 파라미터 오차)
전체 의미: "t번 업데이트 후의 오차는, 초기 오차에 (I-ηA)를 t번 곱한 것"
```

**이것이 왜 중요한가?** 수렴 조건을 분석하는 핵심 도구가 됩니다.

# PART 4. 수렴 조건 증명: η < 2/λ_max(A) ★★★★★

---

## 🟢 입문: 수렴 = 오차가 0에 가까워지는 것

$$e_t = (I - \eta A)^t e_0 \to 0 \text{ as } t \to \infty$$

행렬의 t제곱이 0에 가까워지려면?

중학교 수준으로: 숫자 r에 대해 $r^t \to 0$이 되려면 $|r| < 1$ 이어야 합니다.

예:
- $0.5^t$: 0.5, 0.25, 0.125, ... → 0에 수렴 ✓ (|0.5| < 1)
- $1.5^t$: 1.5, 2.25, 3.375, ... → 무한대로 발산 ✗ (|1.5| > 1)
- $(-0.5)^t$: -0.5, 0.25, -0.125, ... → 0에 수렴 ✓ (|-0.5| < 1)
- $(-1.5)^t$: -1.5, 2.25, -3.375, ... → 발산 ✗ (|-1.5| > 1)

행렬의 경우도 똑같습니다. 단지 숫자 대신 **고유값(eigenvalue)**이 그 역할을 합니다.

---

## 🔴 고급: 고유값 분석으로 수렴 조건 도출

### Step 1: 고유값 설정

**A의 고유값:** $\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n$ (모두 양수, A ≻ 0이므로)

**A의 고유벡터:** $u_1, u_2, \ldots, u_n$ (서로 직교, A가 대칭이므로)

```
고유값(eigenvalue)이란?
Av = λv를 만족하는 λ
행렬 A를 벡터 v에 곱했을 때, v의 방향은 변하지 않고 크기만 λ배 변하는 특별한 경우
```

---

### Step 2: (I - ηA)의 고유값 계산

**핵심 트릭:** A의 고유벡터 u에 대해 (I - ηA)를 적용:

$$(I - \eta A)u = Iu - \eta Au = u - \eta\lambda u = (1 - \eta\lambda)u$$

```
Line-by-Line:
(I - ηA)u
= Iu - ηAu           ← 분배법칙 (행렬에서도 성립)
= u - η(λu)          ← Iu = u, Au = λu (고유값/고유벡터 정의)
= (1 - ηλ)u          ← u를 공통인수로 묶음
```

따라서:
- A의 고유값: **λᵢ**
- A의 고유벡터: **uᵢ**
- (I - ηA)의 고유값: **1 - ηλᵢ** (같은 고유벡터에 대해!)

---

### Step 3: 수렴 조건 부등식 풀기 (시험 핵심)

수렴 조건: (I - ηA)의 **모든 고유값의 절댓값 < 1**

$$|1 - \eta\lambda_i| < 1$$

**절댓값 부등식을 풀면:**

$$-1 < 1 - \eta\lambda_i < 1$$

**오른쪽 부등식:** $1 - \eta\lambda_i < 1$

$$-\eta\lambda_i < 0 \iff \eta\lambda_i > 0$$

```
이것은 자동으로 성립합니다.
η > 0 (학습률은 양수)
λᵢ > 0 (A가 양정치이므로 모든 고유값은 양수)
따라서 ηλᵢ > 0 → 항상 참
```

**왼쪽 부등식:** $1 - \eta\lambda_i > -1$

$$-\eta\lambda_i > -2$$

$$\eta\lambda_i < 2$$

$$\eta < \frac{2}{\lambda_i}$$

---

### Step 4: 모든 i에 대해 동시 성립 — 최대 고유값이 결정

위 조건이 **모든 i = 1, 2, ..., n에 대해 동시에** 성립해야 합니다.

가장 제한적인 (가장 만족하기 어려운) 조건은 $\lambda_i$가 **가장 클 때**입니다:

$$\eta < \frac{2}{\lambda_1}, \quad \eta < \frac{2}{\lambda_2}, \quad \ldots, \quad \eta < \frac{2}{\lambda_n}$$

모두 만족하려면:

$$\boxed{\eta < \frac{2}{\lambda_{\max}(A)}}$$

```
λ_max(A): 행렬 A의 가장 큰 고유값 (maximum eigenvalue)
2/λ_max: 학습률의 상한값 — 이보다 작아야 수렴 보장

직관: λ_max가 클수록 → 분모가 커져서 → 상한이 작아짐
      즉, "가파른 방향(큰 고유값)이 있을수록 조심스럽게 걸어야 한다"
```

---

## 🟡 수렴 조건의 의미 — 시각적 이해

**이차 형식의 등고선은 타원:**

- 각 축 방향 = 고유벡터 $u_i$
- 각 축의 "뾰족한 정도" = 고유값 $\lambda_i$
- 큰 고유값 방향 = 등고선이 좁고 가파름
- 작은 고유값 방향 = 등고선이 넓고 완만함

**학습률과 발산의 관계:**

가장 가파른 방향(λ_max 방향)에서 한 걸음이 너무 크면 그 방향으로 발산합니다. 따라서 가장 가파른 방향이 수렴하도록 학습률 상한을 결정하는 것이 바로 $2/\lambda_{max}$ 조건입니다.

# PART 5. 최적 학습률과 조건수

---

## 🟡 최적 학습률 유도

수렴 속도는 $\max_i |1 - \eta\lambda_i|$ 에 의해 결정됩니다.

이 값을 최소화하려면, 가장 큰 고유값 방향과 가장 작은 고유값 방향의 수렴 속도가 균형을 이루어야 합니다:

$$|1 - \eta\lambda_{\max}| = |1 - \eta\lambda_{\min}|$$

```
왜 두 값을 같게 맞추는가?
한쪽이 더 느리면 전체 수렴 속도는 느린 쪽에 의해 결정됨
두 값이 같을 때가 균형 최적화 상태
```

대칭성으로부터:

$$(1 - \eta\lambda_{\min}) = -(1 - \eta\lambda_{\max})$$

$$1 - \eta\lambda_{\min} = -1 + \eta\lambda_{\max}$$

$$2 = \eta(\lambda_{\max} + \lambda_{\min})$$

$$\boxed{\eta^* = \frac{2}{\lambda_{\max} + \lambda_{\min}}}$$

---

## 🔴 조건수(Condition Number)

$$\kappa = \frac{\lambda_{\max}}{\lambda_{\min}}$$

```
κ: 그리스 문자 "카파" (kappa)
λ_max / λ_min: 가장 큰 고유값 / 가장 작은 고유값
전체 의미: "이 문제가 얼마나 최적화하기 어려운가"를 나타내는 숫자
```

**최적 학습률 η*에서의 수렴 속도:**

$$r = \max_i|1 - \eta^*\lambda_i| = \frac{\lambda_{\max} - \lambda_{\min}}{\lambda_{\max} + \lambda_{\min}} = \frac{\kappa - 1}{\kappa + 1}$$

**이것이 의미하는 것:**

| 조건수 κ | 수렴 속도 r | 의미 |
|---------|------------|------|
| κ = 1 (완벽한 원형 등고선) | r = 0 | 한 번에 수렴 |
| κ = 10 | r = 9/11 ≈ 0.82 | 느린 수렴 |
| κ = 100 | r = 99/101 ≈ 0.98 | 매우 느린 수렴 |
| κ = ∞ | r = 1 | 수렴 불가 |

```
조건수가 클수록 r이 1에 가까워집니다.
r이 1에 가까우면 매 스텝마다 오차가 거의 줄어들지 않습니다.
이것이 ill-conditioned 문제에서 GD가 느린 수학적 이유입니다.
```

---

## 🟢 Adam, AdaGrad의 등장 이유

조건수가 크면 → GD가 느림 → **해결책**: 각 방향마다 다른 학습률을 사용

```
Adam/AdaGrad의 핵심:
각 파라미터 방향별로 적응적 학습률(adaptive learning rate) 적용
→ 큰 고유값 방향: 학습률을 작게
→ 작은 고유값 방향: 학습률을 크게
→ 등고선을 원형에 가깝게 만드는 효과
→ 조건수 문제를 완화
```

**백엔드 비유:** 각 서비스마다 다른 Rate Limit를 설정하는 것과 같습니다. 부하가 큰 서비스는 낮게, 여유 있는 서비스는 높게.

# PART 6. Newton's Method — 1차 vs 2차 근사

---

## 🟢 입문: 교수님의 핵심 비교

> "GD는 1차 근사, Newton은 2차 근사"

| | Gradient Descent | Newton's Method |
|---|---|---|
| 근사 차수 | 1차 (기울기만 사용) | 2차 (기울기 + 곡률 사용) |
| 학습률 | 필요 (η 설정 필요) | 불필요 (자동 결정) |
| Hessian 계산 | 불필요 | H^{-1} 계산 필요 O(n³) |
| 수렴 속도 | 선형 수렴 | **2차 수렴** |
| 대규모 딥러닝 | ✓ 사용 | ✗ 비실용적 |

---

## 🟡 Newton's Method — 근 찾기 (Root Finding)

**핵심 공식:**

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

```
x_{n+1}: 다음 스텝의 x
x_n: 현재 x
f(x_n): 현재 x에서의 함수값
f'(x_n): 현재 x에서의 미분값 (기울기)
f(x_n)/f'(x_n): 접선의 x절편까지의 거리
```

**직관:** 현재 점에서 접선을 그어서 x축과 만나는 점으로 이동. 반복하면 f(x)=0인 근에 수렴.

---

## 🔴 교수님 직접 예제: √7 계산

**f(x) = x² - 7 을 풀어서 √7 구하기**

f'(x) = 2x

Newton 공식:

$$x_{n+1} = x_n - \frac{x_n^2 - 7}{2x_n}$$

**통분 정리:**

$$x_{n+1} = \frac{2x_n^2 - (x_n^2 - 7)}{2x_n} = \frac{x_n^2 + 7}{2x_n} = \frac{x_n + 7/x_n}{2}$$

**x₀ = 3에서 시작:**

**1번째 반복:**

$$x_1 = \frac{3 + 7/3}{2} = \frac{3 + 2.333...}{2} = \frac{9/3 + 7/3}{2} = \frac{16/3}{2} = \frac{16}{6} \approx 2.666...$$

**2번째 반복:**

$$x_2 = \frac{2.666... + 7/2.666...}{2} \approx \frac{2.666 + 2.625}{2} \approx 2.6458$$

$\sqrt{7} = 2.6457513...$

**단 2번의 반복으로 소수점 3자리 정확!**

이것이 2차 수렴의 위력입니다. 정확한 자릿수가 매 반복마다 **2배로** 늘어납니다.

---

## 🔴 Newton's Method — 최적화로 확장

최적화 문제: f'(θ) = 0 을 풀어야 함

GD는 f'에 대응하는 것이므로, Newton을 최적화에 적용하면:

$$\theta_{n+1} = \theta_n - \frac{f'(\theta_n)}{f''(\theta_n)}$$

다차원에서:

$$\theta_{n+1} = \theta_n - [H(\theta_n)]^{-1}\nabla f(\theta_n)$$

```
H(θ): Hessian 행렬 (2차 미분을 모아놓은 행렬, 곡률 정보)
H^{-1}: Hessian의 역행렬 — 등고선의 타원을 원형으로 교정하는 효과
∇f: Gradient

H^{-1}이 하는 일:
큰 고유값 방향 → 학습률을 작게 (가파르니까 조심)
작은 고유값 방향 → 학습률을 크게 (완만하니까 대담하게)
→ 자동으로 조건수 문제 해결!
```

**왜 실용적이지 않은가?**

- H의 크기: n × n (n = 파라미터 수)
- GPT-4 기준 파라미터 수 n ≈ 1조
- H의 메모리: n² = 10²⁴ 바이트 → 불가능
- H^{-1} 계산: O(n³) → 교수님 표현: "역행렬로 문제를 풀어야 된다면 굉장히 느린 알고리즘"

# PART 7. Critical Point 분류

---

## 🟢 입문: 도함수 = 0 이면 뭔가?

중학교에서 배운 내용: 함수의 최댓값/최솟값에서 접선이 수평 → 미분 = 0

하지만 **미분 = 0 이라고 해서 무조건 극값은 아닙니다!**

**예시: f(x) = x³**

f'(x) = 3x² → f'(0) = 0 이지만, x=0은 극값이 아닙니다!

```
x < 0 에서도 증가
x = 0 에서도 증가
x > 0 에서도 증가
→ 단지 x=0에서 잠깐 수평일 뿐
```

이런 점을 **안장점(Saddle Point)**이라고 합니다.

---

## 🔴 고급: Fermat 정리와 2차 미분 판별

### Fermat 정리 (필요조건)

x가 극값이고 f가 미분가능 → f'(x) = 0

**주의!** 역은 성립하지 않습니다:
- f'(x) = 0 이라고 극값이라는 보장 없음

---

### 1차원 2차 미분 판별

| 조건 | 결론 |
|------|------|
| f'(x) = 0, f''(x) > 0 | 극소 (local minimum) |
| f'(x) = 0, f''(x) < 0 | 극대 (local maximum) |
| f'(x) = 0, f''(x) = 0 | 판별 불가 (더 조사 필요) |

**직관:**
- f'' > 0: "아래로 오목" (웃음 모양 ∪) → 바닥 = 극소
- f'' < 0: "위로 오목" (슬픔 모양 ∩) → 꼭대기 = 극대

---

### 고차원: Hessian 행렬로 판별

$$H_{ij} = \frac{\partial^2 f}{\partial \theta_i \partial \theta_j}$$

```
H: Hessian 행렬 (헤시안)
i행 j열 원소 = θᵢ로 한 번, θⱼ로 한 번 편미분한 값
= 각 방향에서의 "곡률(curvature)"을 모아놓은 행렬
1차원에서 f''(x)의 다차원 버전
```

| Hessian 조건 | 결론 |
|-------------|------|
| H ≻ 0 (양정치, 모든 고유값 > 0) | 극소 (local minimum) |
| H ≺ 0 (음정치, 모든 고유값 < 0) | 극대 (local maximum) |
| H 부정치 (양수/음수 고유값 혼재) | **안장점 (Saddle Point)** |

---

### 딥러닝에서 대부분 안장점

**왜 극소에 갇히는 것이 아니라 안장점에서 느려지는 것이 실제 문제인가?**

n차원에서 극소일 조건: **모든 n개의 고유값이 양수**여야 함

확률적으로:
- 각 고유값이 양수일 확률 ≈ 1/2 (독립 가정 시)
- n개 모두 양수일 확률 ≈ (1/2)^n

딥러닝의 파라미터 수 n이 수백만~수십억이면:
- 극소 확률 ≈ (1/2)^(수백만) ≈ **0**

따라서 **거의 모든 critical point는 안장점**입니다.

**백엔드 비유:** 수백만 개의 CPU 코어가 모두 동시에 최대 효율로 작동할 확률이 극히 낮은 것처럼.

# PART 8. Subgradient — 미분 불가능 점 처리

---

## 🟢 입문: ReLU는 어디서 미분이 안 되나?

**ReLU 함수:** f(x) = max(0, x)

```
x > 0 이면: f(x) = x, 기울기 = 1
x < 0 이면: f(x) = 0, 기울기 = 0
x = 0 이면: 왼쪽은 기울기 0, 오른쪽은 기울기 1 → **미분 불가능!**
```

**|x|도 비슷한 문제:**

```
x > 0 이면: |x| = x, 기울기 = 1
x < 0 이면: |x| = -x, 기울기 = -1
x = 0 이면: V자의 꼭짓점 → 미분 불가능!
```

그런데 딥러닝에서 ReLU는 가장 많이 쓰이는 활성함수고, L1 정규화는 |w|를 사용합니다. 미분 불가능 점이 있는데 어떻게 학습하나요?

---

## 🔴 고급: Subgradient (하위미분) 정의

$$\partial f(x) = \{g \in \mathbb{R}^n : f(z) \geq f(x) + g^T(z-x), \forall z\}$$

```
∂f(x): f의 x에서의 하위미분 집합 (집합!)
       (일반 미분은 하나의 값, 하위미분은 여러 값의 집합)
g: 하위미분의 원소 (subgradient)
f(z) ≥ f(x) + g^T(z-x): "g를 기울기로 하는 접선이 항상 함수 아래에 있다"는 조건
∀z: 모든 z에 대해
```

**쉽게 말하면:** 미분 불가능 점에서 "그래도 접선이 될 수 있는 기울기들의 집합"

---

## 🟡 예시: |x|의 Subgradient

| x의 범위 | ∂|x| | 설명 |
|---------|------|------|
| x > 0 | {1} | 기울기 = 1 (일반 미분과 같음) |
| x = 0 | [-1, 1] | -1부터 1 사이의 모든 값 |
| x < 0 | {-1} | 기울기 = -1 (일반 미분과 같음) |

```
x = 0 에서 왜 [-1, 1]인가?
|x|의 그래프에서 V자 꼭짓점에 "지지선"을 그어보면
기울기 -1보다 가파른 직선도 아래에 있고
기울기 1보다 가파른 직선도 아래에 있습니다.
즉 기울기 -1 ~ 1 사이의 어떤 직선도 |x| 그래프 아래에 있음
→ 이 모든 기울기가 subgradient
```

---

## 🟡 예시: ReLU의 Subgradient

| x의 범위 | ∂ReLU(x) | 실무 관례 |
|---------|----------|---------|
| x > 0 | {1} | 1 |
| x = 0 | [0, 1] | 보통 0으로 처리 |
| x < 0 | {0} | 0 |

**실무 연결:** PyTorch에서 ReLU의 x=0 미분값을 0으로 처리하는 것이 바로 subgradient [0,1]에서 0을 선택한 것입니다.

# PART 10. 시험 답안 작성 템플릿 ⭐⭐⭐

---

## 표준 증명 체인 (이것을 외워라)

```
① 가정 명시:
   "목적 함수가 이차 함수 f(θ) = (1/2)θ^T Aθ + b^Tθ + c이고,
    A는 대칭 양정치 행렬 (A = A^T ≻ 0)이라고 가정한다"

② 최적해 도출:
   ∇f(θ*) = Aθ* + b = 0 → θ* = -A^{-1}b

③ GD 업데이트 규칙 명시:
   θ_{t+1} = θ_t - η∇f(θ_t) = θ_t - η(Aθ_t + b)

④ 오차 벡터 정의:
   e_t = θ_t - θ*  정의

⑤ 오차의 재귀 관계 유도:
   e_{t+1} = θ_{t+1} - θ*
           = (θ_t - ηAθ_t - ηb) - θ*
           = (θ_t - θ*) - ηA(θ_t - θ*)  (b = -Aθ* 대입)
           = (I - ηA)e_t

⑥ 일반항 표현:
   e_t = (I - ηA)^t e_0

⑦ 수렴 조건 분석:
   수렴 ⟺ (I - ηA)^t → 0
        ⟺ (I - ηA)의 모든 고유값의 절댓값 < 1

⑧ 고유값 분석:
   (I - ηA)의 고유값 = 1 - ηλᵢ  (A의 고유값이 λᵢ)

⑨ 부등식 풀기:
   |1 - ηλᵢ| < 1
   ⟺ -1 < 1 - ηλᵢ < 1
   ⟺ 0 < ηλᵢ < 2  (오른쪽은 자동 성립, η>0, λᵢ>0)
   ⟺ η < 2/λᵢ

⑩ 결론:
   모든 i에 대해 성립하려면 가장 제한적인 조건 선택:
   η < 2/λ_max(A)  ■
```

---

## 시험 답안 실전 예시 (이 형식으로 써라)

**문제:** 이차 함수에서 GD의 수렴 조건 $\eta < 2/\lambda_{max}(A)$를 증명하라.

**답안:**

**[가정 설정]**

목적 함수: $f(\theta) = \frac{1}{2}\theta^T A\theta + b^T\theta + c$, $A = A^T \succ 0$

GD Update: $\theta_{t+1} = \theta_t - \eta(A\theta_t + b)$

최적해: $\theta^* = -A^{-1}b$ ($b = -A\theta^*$)

**[오차 재귀 관계 유도]**

$e_t = \theta_t - \theta^*$로 정의하면:

$e_{t+1} = (\theta_t - \eta A\theta_t - \eta b) - \theta^* = (I - \eta A)(\theta_t - \theta^*) = (I - \eta A)e_t$

따라서: $e_t = (I - \eta A)^t e_0$

**[수렴 조건 분석]**

수렴 $\Leftrightarrow$ $(I - \eta A)^t \to 0$ $\Leftrightarrow$ 모든 고유값 $|1 - \eta\lambda_i| < 1$

왼쪽 부등식: $1 - \eta\lambda_i > -1 \Rightarrow \eta < \frac{2}{\lambda_i}$

모든 $i$에 대해: $\boxed{\eta < \frac{2}{\lambda_{\max}(A)}}$ $\square$

## 주요 공식 요약표

| 이름 | 공식 | 조건 |
|------|------|------|
| GD Update | $\theta_{t+1} = \theta_t - \eta\nabla f$ | 항상 |
| 오차 재귀 | $e_{t+1} = (I - \eta A)e_t$ | f가 이차함수, A ≻ 0 |
| 오차 일반항 | $e_t = (I - \eta A)^t e_0$ | 위와 같음 |
| 수렴 조건 | $\eta < 2/\lambda_{\max}(A)$ | A ≻ 0 |
| 최적 학습률 | $\eta^* = 2/(\lambda_{\max} + \lambda_{\min})$ | A ≻ 0 |
| 수렴 속도 | $r = (\kappa-1)/(\kappa+1)$ | 조건수 κ = λ_max/λ_min |
| Newton Update | $\theta_{t+1} = \theta_t - H^{-1}\nabla f$ | H 가역 |

| √7 Newton | $x_{n+1} = (x_n + 7/x_n)/2$ | f(x)=x²-7 |

# 🔥 핵심 요약

## 한 줄 결론
**Gradient Descent가 수렴하려면 학습률이 Hessian 최대 고유값의 역수의 2배보다 작아야 하며, 이는 오차 벡터의 재귀 관계 e_t = (I-ηA)^t e_0에서 (I-ηA)의 모든 고유값의 절댓값을 1 미만으로 만드는 조건이다.**

## 💡 쉽게 설명하면
가파른 산(큰 고유값 방향)이 있을 때, 발을 너무 크게 내딛으면 반대편 산으로 넘어가 버립니다(발산). 가장 가파른 방향의 곡률(λ_max)이 발 크기의 상한을 결정합니다.

## 🧠 남에게 설명한다면
"이차 함수에서 GD의 오차는 (I-ηA)를 반복 곱하는 형태로 줄어드는데, 이것이 수렴하려면 (I-ηA)의 고유값 절댓값이 1 미만이어야 하고, 이를 풀면 η < 2/λ_max 조건이 나온다."

## ⚡ 핵심 킬러 요약
- **수렴 조건**: η < 2/λ_max(A) — 시험에서 유도 과정 전부 써야 함
- **오차 일반항**: e_t = (I-ηA)^t e_0 — 이 식이 핵심
- **조건수**: κ = λ_max/λ_min — 클수록 느린 수렴, Adam의 동기
- **Newton vs GD**: 2차 수렴이지만 O(n³) — 교수님 "역행렬은 굉장히 느린 알고리즘"

## 📌 핵심 정리
**핵심**: η < 2/λ_max, e_t = (I-ηA)^t e_0, 최적 η* = 2/(λ_max + λ_min)

**주의**: A가 양정치(A ≻ 0)일 때만 성립. condition number κ가 수렴 속도 결정

**연구 포인트**: Edge of Stability 현상 (η가 2/λ_max에 근접할 때의 동작), Natural Gradient, K-FAC (Hessian 근사)
