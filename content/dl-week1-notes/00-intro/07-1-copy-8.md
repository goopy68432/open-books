# PART 1. 특수 행렬 — Orthogonal / PSD / PD

---

## 🟢 입문: 비유부터 시작

**백엔드 개발자 관점으로 이해하기:**

세 가지 특수 행렬을 백엔드 시스템으로 비유하면:

- **직교 행렬 (Orthogonal)** = Lossless 압축 (zip). 데이터를 변환해도 정보량(노름)이 전혀 손실되지 않는다.
- **PSD (Positive Semi-Definite)** = 바닥이 평평하거나 올라가는 그릇. 에너지가 절대 음수가 되지 않는다. (최솟값이 존재하거나 평평할 수 있다)
- **PD (Positive Definite)** = 반드시 바닥이 있는 그릇. 에너지가 반드시 양수. 유일한 최솟값이 보장된다.

---

## 🔴 고급: 수식 Line-by-Line 해체

### 1. 직교 행렬 (Orthogonal Matrix)

**정의:**

$$U^T U = U U^T = I \qquad (U \in O(n))$$

```
U      : n×n 정사각 행렬
U^T    : U의 전치 행렬 (행과 열을 뒤집은 것)
I      : 단위행렬 (대각선이 1, 나머지 0)
O(n)   : n×n 직교 행렬의 집합

열(column) 조건:
u_i^T u_i = 1    → 각 열의 길이(노름)가 1
u_i^T u_j = 0    → 다른 열끼리는 수직(직교)
```

**핵심 성질 — 노름 보존 (시험 단골 증명):**

$$\|Ux\|^2 = (Ux)^T(Ux)$$

```
Step 1: 노름의 제곱 = 벡터를 자기 자신과 내적
       ||v||² = v^T v   이므로
       ||Ux||² = (Ux)^T (Ux)
```

$$= x^T U^T U x$$

```
Step 2: 전치의 성질 적용
       (AB)^T = B^T A^T 이므로
       (Ux)^T = x^T U^T
       
       따라서: (Ux)^T (Ux) = x^T U^T U x
```

$$= x^T I x = x^T x = \|x\|^2$$

```
Step 3: U^T U = I (직교 행렬의 정의)를 대입
       x^T (U^T U) x = x^T I x = x^T x = ||x||²

결론: ||Ux||² = ||x||²  → 직교 행렬은 벡터의 길이(노름)를 보존한다
     → gradient 계산 시 값이 폭발하거나 사라지지 않는다
     → RNN의 gradient vanishing 문제 해결에 활용
```

**왜 중요한가?** 역행렬이 공짜 — U^{-1} = U^T (저장한 행렬을 그냥 전치하면 됨)

---

### 2. 양의 준정부호 행렬 (PSD, Positive Semi-Definite)

**정의:**

$$v^T A v \geq 0, \quad \forall v \neq 0 \qquad (A \succeq 0)$$

```
v      : 임의의 영이 아닌 벡터 (어떤 방향이든)
A      : 대칭 행렬 (A = A^T)
v^T Av : 이차형식 (스칼라 값) — 다음 파트에서 자세히 다룸
≥ 0   : 비음수 (0이 될 수 있음)
∀v ≠ 0: "영이 아닌 모든 v에 대해서"
A ≽ 0 : PSD 표기법
```

**핵심 성질:**
- 모든 고유값(eigenvalue) ≥ 0
- BB^T 와 B^TB (그람 행렬)는 항상 PSD

**그람 행렬이 항상 PSD인 이유 증명:**

$$v^T (B^T B) v = (Bv)^T (Bv) = \|Bv\|^2 \geq 0$$

```
Step 1: v^T (B^T B) v
Step 2: 괄호 재배치: (B^T B)v = B^T (Bv)
       v^T · B^T · (Bv)
Step 3: (B^T)^T = B 이므로 v^T B^T = (Bv)^T
       = (Bv)^T (Bv) = ||Bv||²  ← 노름의 제곱은 항상 ≥ 0
결론: B^T B 는 항상 PSD ✓
```

---

### 3. 양의 정부호 행렬 (PD, Positive Definite)

**정의:**

$$v^T A v > 0, \quad \forall v \neq 0 \qquad (A \succ 0)$$

```
> 0 : 엄격히 양수 (0이 될 수 없음)
PSD와의 차이: ≥ vs >

PSD: 고유값 ≥ 0 (고유값이 0인 방향이 있을 수 있음)
PD : 고유값 > 0 (모든 방향에서 반드시 양수)
```

**핵심 성질:**
- 모든 고유값 > 0
- 반드시 가역(역행렬 존재)
- BB^T + λI (λ > 0)는 항상 PD

**BB^T + λI가 PD인 이유 증명:**

$$v^T(BB^T + \lambda I)v = v^T BB^T v + \lambda v^T v = \|B^T v\|^2 + \lambda\|v\|^2$$

```
||B^T v||² ≥ 0  (노름의 제곱은 항상 비음수)
λ||v||²  > 0   (λ > 0이고 v ≠ 0이면 ||v||² > 0)

따라서 전체 합 > 0
→ BB^T + λI 는 PD ✓

이것이 릿지 회귀에서 λI를 더하는 이유! (항상 역행렬 존재 보장)
```

---

## 📊 세 행렬 비교 요약

| 속성 | 직교 행렬 | PSD | PD |
|------|----------|-----|-----|
| 고유값 조건 | 크기 = 1 | ≥ 0 | > 0 |
| 가역성 | 항상 가역 (U^{-1} = U^T) | 불확실 | 항상 가역 |
| 이차형식 | — | v^T Av ≥ 0 | v^T Av > 0 |
| 비유 | Lossless 변환 | 평평하거나 볼록한 그릇 | 반드시 바닥 있는 그릇 |
| ML 활용 | 가중치 초기화, RNN | 공분산 행렬, 커널 | 손실 함수의 Hessian |

# PART 2. 이차형식 (Quadratic Form) — 정의와 직관

---

## 🟢 입문: 중1 수준에서 시작

**가장 단순한 예시 — 2차 다항식:**

여러분이 이미 아는 것:

$$f(x) = 3x^2$$

이것을 x가 벡터(여러 변수)일 때로 확장하면?

$$f(x, y) = 3x^2 + 2xy + 5y^2$$

이걸 행렬로 깔끔하게 표현한 것이 이차형식이다!

---

## 🟡 중급: 이차형식의 행렬 표현

**핵심 아이디어:** 2차(quadratic) 항을 행렬과 벡터로 표현

### 구체적인 숫자 예시

$f(x_1, x_2) = 3x_1^2 + 2x_1 x_2 + 5x_2^2$ 를 행렬로 표현하려면?

**Step 1:** 벡터 x와 행렬 A를 설정

$$x = \begin{bmatrix} x_1 \\ x_2 \end{bmatrix}, \quad A = \begin{bmatrix} 3 & 1 \\ 1 & 5 \end{bmatrix}$$

```
왜 A의 대각선이 3, 5인가? 
→ x₁²의 계수가 3, x₂²의 계수가 5

왜 비대각선이 1인가?
→ x₁x₂의 계수가 2인데, 위아래로 절반씩 나눔 (1+1=2)
→ 이렇게 하면 A = A^T (대칭 행렬)이 됨

왜 대칭으로 만드는가?
→ 이차형식의 고유분해를 위해 대칭 행렬 필요
→ 고유분해: A = UΛU^T (직교 행렬 U, 대각 행렬 Λ)
```

**Step 2:** x^T A x 계산 확인

$$x^T A x = \begin{bmatrix} x_1 & x_2 \end{bmatrix} \begin{bmatrix} 3 & 1 \\ 1 & 5 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \end{bmatrix}$$

**내부 행렬-벡터 곱 먼저:**

$$\begin{bmatrix} 3 & 1 \\ 1 & 5 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} 3x_1 + x_2 \\ x_1 + 5x_2 \end{bmatrix}$$

**그 다음 행벡터와 곱:**

$$\begin{bmatrix} x_1 & x_2 \end{bmatrix} \begin{bmatrix} 3x_1 + x_2 \\ x_1 + 5x_2 \end{bmatrix} = x_1(3x_1 + x_2) + x_2(x_1 + 5x_2)$$

$$= 3x_1^2 + x_1 x_2 + x_1 x_2 + 5x_2^2 = 3x_1^2 + 2x_1 x_2 + 5x_2^2 \checkmark$$

**이차형식의 일반 정의:**

$$\boxed{f(x) = x^T A x}$$

```
x     : p-차원 벡터 (p개의 변수)
A     : p×p 대칭 행렬 (A = A^T)
x^T   : x의 전치 (행벡터)
x^T A x : 결과는 스칼라(숫자 하나)

"이차형식"이라는 이름의 이유:
→ x의 모든 항이 2차 (x_i · x_j 형태)
→ x^T Ax = Σ_i Σ_j A_{ij} x_i x_j
```

# PART 3. 이차형식의 고유분해 — 유도 전 과정

---

## 🟢 입문: 왜 고유분해가 필요한가?

**문제:** x^T A x 는 변수들이 서로 얽혀있어서(교차항 x_i x_j) 분석이 복잡하다.

**해결책:** 좌표계를 회전해서 교차항을 없애자!

**백엔드 비유:** 복잡하게 얽힌 테이블 조인을 정규화(normalization)해서 독립적인 테이블로 분리하는 것과 같다.

---

## 🔴 고급: 완전 유도 (시험 답안 형식)

### 전제: 대칭 행렬의 고유분해 (Spectral Theorem)

대칭 행렬 A는 항상 다음과 같이 분해된다:

$$A = U \Lambda U^T$$

```
A    : p×p 대칭 행렬
U    : p×p 직교 행렬 (U^T U = I)
     각 열 u_i가 A의 고유벡터(eigenvector)
Λ    : p×p 대각 행렬 (대각선 = 고유값, 나머지 = 0)

     Λ = diag(λ₁, λ₂, ..., λ_p) = | λ₁  0  0  |
                                     | 0   λ₂ 0  |
                                     | 0   0  λ_p|

왜 이 분해가 가능한가?
→ 대칭 행렬의 핵심 정리 (Spectral Theorem):
   "대칭 행렬의 고유벡터는 서로 직교하고, 항상 실수 고유값을 가진다"
```

### Step 1: A를 고유분해로 치환

$$f(x) = x^T A x = x^T (U \Lambda U^T) x$$

```
A = UΛU^T 를 그대로 대입
```

### Step 2: 결합법칙 재배치

$$= x^T U \Lambda (U^T x)$$

```
행렬 곱에서 결합법칙 적용:
x^T · (U · Λ · U^T) · x
= (x^T · U) · Λ · (U^T · x)

여기서 괄호를 이렇게 묶어보자:
= x^T U · Λ · (U^T x)
```

### Step 3: 좌표 변환 정의

$$y = U^T x \quad \text{(새로운 좌표계)}$$

```
y    : 새로운 좌표계에서의 벡터
U^T  : 직교 행렬의 전치 → 좌표 회전
x    : 원래 좌표계의 벡터

핵심 관계:
x^T U = (U^T x)^T = y^T  (전치의 성질)
U^T x = y

기하학적 의미:
→ x를 U^T로 회전시키면 y를 얻는다
→ U의 열 = 고유벡터 방향으로 좌표축을 재설정
→ 이 새로운 좌표계에서 교차항이 사라진다!
```

### Step 4: y로 치환

$$x^T A x = y^T \Lambda y$$

```
x^T U = y^T    (위에서 유도)
U^T x = y      (정의)

따라서: x^T U · Λ · U^T x
      = y^T · Λ · y
      = y^T Λ y
```

### Step 5: 대각 행렬 전개

$$y^T \Lambda y = \sum_{i=1}^{p} \lambda_i y_i^2$$

```
Λ = diag(λ₁, λ₂, ..., λ_p) 이므로

y^T Λ y = [y₁, y₂, ..., y_p] · | λ₁  0  | · | y₁ |
                                  | 0   λ₂ |   | y₂ |
                                  
= [y₁·λ₁, y₂·λ₂, ...] · [y₁, y₂, ...]^T

= λ₁y₁² + λ₂y₂² + ... + λ_p y_p²

= Σᵢ λᵢ yᵢ²

왜 이게 놀라운가?
→ 원래 x^T Ax는 교차항(x_i x_j)이 있었음
→ 새 좌표 y에서는 각 y_i²에 독립적인 계수 λ_i만 있음
→ 완전히 분리된(decoupled) 형태!
```

### 최종 결과 (시험에서 반드시 써야 함)

$$\boxed{f(x) = x^T A x = \sum_{i=1}^{p} \lambda_i y_i^2, \quad \text{where} \quad y_i = u_i^T x}$$

```
y_i = u_i^T x  : x를 i번째 고유벡터 u_i 방향으로 투영(projection)한 값
λ_i            : i번째 고유값 (그 방향의 "가중치")

직관:
→ 각 고유벡터 방향으로 x를 분해
→ 각 방향의 기여도에 고유값을 가중치로 곱해서 합산
→ A가 PD이면 모든 λ_i > 0 → 항상 양수 → 유일한 최솟값 존재
```

---

## 📊 기하학적 의미 (등고선의 타원)

**f(x) = c 인 등고선은 타원이다:**

$$\lambda_1 y_1^2 + \lambda_2 y_2^2 = c$$

```
타원의 방정식: y₁²/a² + y₂²/b² = 1 과 같은 형태

λ₁ y₁² + λ₂ y₂² = c
→ y₁²/(c/λ₁) + y₂²/(c/λ₂) = 1

타원의 축 방향 = 고유벡터 u₁, u₂
타원의 반지름  = √(c/λ₁), √(c/λ₂)
               = √c / √λ₁, √c / √λ₂

결론:
→ 고유값이 클수록 타원이 그 방향으로 좁음 (가파름)
→ 고유값이 작을수록 타원이 그 방향으로 넓음 (완만함)
→ 조건수 κ = λ_max/λ_min이 크면 타원이 길쭉 = 경사하강법이 느림
```

**조건수(Condition Number)와 최적화:**

| 조건수 κ | 타원 형태 | 경사하강법 |
|---------|----------|----------|
| κ ≈ 1 | 거의 원형 | 빠르게 수렴 |
| κ >> 1 | 매우 길쭉 | 지그재그, 느린 수렴 |
| κ → ∞ | 한 방향으로 무한히 길쭉 | 수렴 불가 |

# PART 4. 트레이스 (Trace) — 정의와 5대 성질

---

## 🟢 입문: 트레이스란?

**가장 단순한 설명:**

행렬의 대각선 원소만 더한 값

$$A = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 9 \end{bmatrix} \quad \Rightarrow \quad \text{Tr}(A) = 1 + 5 + 9 = 15$$

```
대각선: 왼쪽 위에서 오른쪽 아래로 내려가는 원소들
(1,1) 위치 = 1
(2,2) 위치 = 5
(3,3) 위치 = 9
합 = 15
```

**백엔드 비유:** 행렬 전체의 "합산 메트릭". CPU 사용률 여러 개를 하나의 숫자로 요약하는 것과 같다.

---

## 🔴 고급: 5대 성질 Line-by-Line 해체

### 성질 1: 정의

$$\text{Tr}(A) = \sum_{i} a_{ii}$$

```
a_{ii} : 행렬 A의 i번째 행, i번째 열의 원소 (대각 원소)
Σ_i   : 모든 i에 대해 더하라
결과  : 스칼라(숫자 하나)
```

### 성질 2: 전치 불변

$$\text{Tr}(A^T) = \text{Tr}(A)$$

```
이유: 전치해도 대각 원소는 바뀌지 않는다
     A의 (i,i) 원소 = A^T의 (i,i) 원소
     → 대각합이 같다
```

### 성질 3: 선형성

$$\text{Tr}(A + B) = \text{Tr}(A) + \text{Tr}(B)$$

```
증명:
Tr(A + B) = Σ_i (A + B)_{ii}
           = Σ_i (a_{ii} + b_{ii})
           = Σ_i a_{ii} + Σ_i b_{ii}
           = Tr(A) + Tr(B)   ✓
```

### 성질 4: 순환 성질 (Cyclic Property) — 시험 단골

$$\text{Tr}(AB) = \text{Tr}(BA)$$

**주의: 임의 순서 변경 불가 — 순환만 가능**

$$\text{Tr}(ABC) = \text{Tr}(CAB) = \text{Tr}(BCA) \quad \text{단, } \neq \text{Tr}(BAC)$$

```
증명 (Tr(AB) = Tr(BA)):

Tr(AB) = Σ_i (AB)_{ii} = Σ_i Σ_j A_{ij} B_{ji}

Tr(BA) = Σ_i (BA)_{ii} = Σ_i Σ_j B_{ij} A_{ji}

두 식의 차이: 단순히 i, j 인덱스를 바꾼 것 → 합이 같음 ✓

왜 중요한가?
→ 복잡한 수식을 정리할 때 행렬 곱의 순서를 바꿀 수 있음
→ 예: x^T Ax = Tr(x^T Ax) = Tr(Axx^T)  ← 이것이 핵심 트릭!

왜 Tr(ABC) ≠ Tr(BAC)인가?
→ 순환(cyclic) 회전만 가능: A→B→C→A 방향으로만 회전
→ AB를 BA로 바꾸는 것은 "뒤집기"이지 "회전"이 아님
```

### 성질 5: 고유값의 합

$$\text{Tr}(A) = \sum_{i} \lambda_i$$

```
증명 방향:
A = UΛU^T  (고유분해)
Tr(A) = Tr(UΛU^T)
      = Tr(U^T · U · Λ)   (순환 성질: Tr(UΛU^T) = Tr(U^T·UΛ))
      = Tr(I · Λ)          (U^T U = I)
      = Tr(Λ)
      = λ₁ + λ₂ + ... + λ_p  (대각 행렬의 트레이스)
```

### 보너스 성질: 프로베니우스 노름과 관계

$$\|A\|_F^2 = \text{Tr}(A^T A)$$

```
프로베니우스 노름: ||A||_F = √(Σ_i Σ_j a_{ij}²)
→ 모든 원소의 제곱합의 제곱근

증명:
Tr(A^T A) = Σ_i (A^T A)_{ii} = Σ_i Σ_j (A^T)_{ij} A_{ji}
           = Σ_i Σ_j A_{ji} A_{ji}
           = Σ_i Σ_j a_{ji}²
           = ||A||_F²   ✓

활용: L2 정규화 ||W||_F² = Tr(W^T W)
     PyTorch의 weight_decay가 이것을 손실에 더함
```

# PART 5. 행렬 미분 공식 — 6대 공식 유도

---

## 🟢 입문: 왜 행렬 미분이 필요한가?

**백엔드 비유:** 경사하강법(Gradient Descent)은 손실함수의 기울기를 구해서 파라미터를 업데이트한다. 손실함수가 행렬로 표현될 때, 행렬에 대한 미분이 필요하다.

**결과의 형태 규칙:**

스칼라 f 를 벡터 x (p차원)에 대해 미분하면 → 행벡터 (1×p)

$$\frac{d f}{d x} = \left[\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_p}\right]$$

```
행벡터로 나오는 이유:
→ x = [x₁, x₂, ..., x_p]^T (열벡터)
→ df/dx = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂x_p] (행벡터)
→ 이것을 "gradient의 전치" 라고도 함

교재 표기: d/dx로 표기하면 결과가 행벡터
          ∇_x 로 표기하면 결과가 열벡터 (전치 관계)
```

---

## 🔴 고급: 6대 공식 Line-by-Line 유도

### 공식 1: 선형 함수의 미분

$$\frac{d(a^T x)}{dx} = a^T$$

**중1 산술로 시작:**

$f(x) = 3x$ 를 x로 미분하면? → 3

행벡터 버전:
$f(x_1, x_2) = 2x_1 + 5x_2 = a^T x$, 여기서 $a = [2, 5]^T$

$$\frac{\partial f}{\partial x_1} = 2, \quad \frac{\partial f}{\partial x_2} = 5$$

$$\frac{d(a^T x)}{dx} = [2, 5] = a^T \checkmark$$

```
일반 유도:
a^T x = a₁x₁ + a₂x₂ + ... + a_p x_p

∂/∂x_j (a^T x) = a_j  (x_j에 곱해진 계수)

따라서: d(a^T x)/dx = [a₁, a₂, ..., a_p] = a^T
```

---

### 공식 2: 이차형식의 미분 (핵심 공식)

$$\frac{d(x^T A x)}{dx} = x^T(A + A^T)$$

**중1 산술로 시작:**

$f(x) = 3x^2$ 를 미분하면? → 6x

행렬 버전: $f(x) = x^T A x$

**완전 유도:**

Step 1: x^T A x 를 성분으로 전개

$$x^T A x = \sum_{i=1}^{p} \sum_{j=1}^{p} A_{ij} x_i x_j$$

```
이것은 2변수 이상의 이차형식을 완전히 펼친 것
예: 2변수라면 A₁₁x₁² + A₁₂x₁x₂ + A₂₁x₂x₁ + A₂₂x₂²
```

Step 2: x_k에 대해 편미분

$$\frac{\partial(x^T A x)}{\partial x_k} = \sum_{j=1}^{p} A_{kj} x_j + \sum_{i=1}^{p} A_{ik} x_i$$

```
왜 두 항이 나오는가?
→ x_k 가 두 군데 등장한다: x_i 자리와 x_j 자리
→ 첫 번째 합: x_k가 i=k 일 때 → Σ_j A_{kj} x_j = (Ax)_k 의 k번째 성분
→ 두 번째 합: x_k가 j=k 일 때 → Σ_i A_{ik} x_i = (A^T x)_k 의 k번째 성분

예시 (2×2):
f(x) = A₁₁x₁² + A₁₂x₁x₂ + A₂₁x₂x₁ + A₂₂x₂²
∂f/∂x₁ = 2A₁₁x₁ + A₁₂x₂ + A₂₁x₂
        = (A₁₁+A₁₁)x₁ + (A₁₂+A₂₁)x₂
        = (A + A^T)의 첫 번째 행 × x
```

Step 3: 행벡터 형태로 모으면

$$\frac{d(x^T A x)}{dx} = x^T A^T + x^T A = x^T(A + A^T)$$

```
각 k에 대해 ∂/∂x_k 를 모으면:
= (Ax)^T + (A^T x)^T
= x^T A^T + x^T A
= x^T (A^T + A)
= x^T (A + A^T)  ✓
```

### 대칭 행렬일 때 (A = A^T): 자주 나오는 특수 케이스

$$\frac{d(x^T S x)}{dx} = 2x^T S \quad (S = S^T \text{ 일 때})$$

```
A + A^T = S + S = 2S  (A = A^T = S 이면)
따라서 d(x^T S x)/dx = x^T · 2S = 2x^T S
```

---

### 공식 3: 노름의 제곱 미분

$$\frac{d(\|x\|^2)}{dx} = 2x^T$$

```
||x||² = x₁² + x₂² + ... + x_p²
       = x^T x     (단위행렬 I를 쓰면 x^T I x)

S = I (단위 행렬, 대칭)이면
d(x^T I x)/dx = 2x^T I = 2x^T  ✓

직관: d(x²)/dx = 2x 의 벡터 버전
```

---

### 공식 4: 선형 변환의 미분

$$\frac{d(Ax)}{dx} = A$$

```
Ax = [a₁^T x, a₂^T x, ..., a_p^T x]^T  (a_i^T = A의 i번째 행)

각 성분의 미분:
∂(a_i^T x)/∂x = a_i^T

이를 모으면 행렬: [a₁^T; a₂^T; ...; a_p^T] = A  ✓

직관: d(ax)/dx = a 의 행렬 버전
```

---

### 공식 5: 2차+1차 함수의 그래디언트 (정규방정식의 기초)

$$\nabla_\theta \left(\frac{1}{2}\theta^T S \theta + a^T \theta\right) = S\theta + a \quad (S = S^T)$$

**유도:**

$$\frac{d}{d\theta}\left(\frac{1}{2}\theta^T S \theta\right) = \frac{1}{2} \cdot 2\theta^T S = \theta^T S$$

$$\frac{d}{d\theta}(a^T \theta) = a^T$$

```
따라서 전치를 취하면 (∇ = 열벡터):
∇_θ (1/2 θ^T S θ + a^T θ) = (θ^T S + a^T)^T = Sθ + a

∇ 기호: gradient를 열벡터로 쓸 때 사용
d/dx:  결과가 행벡터
∇_x:  결과가 열벡터 (= (d/dx)^T)
```

---

### 6대 공식 요약표

| 공식 | 수식 | 한 줄 설명 |
|------|------|----------|
| 1 | d(a^T x)/dx = a^T | 선형 = 계수 |
| 2 | d(x^T Ax)/dx = x^T(A+A^T) | 이차형식 = A+A^T |
| 3 | d(x^T Sx)/dx = 2x^T S | 대칭이면 2배 |
| 4 | d(‖x‖²)/dx = 2x^T | 노름² = 2×자기자신 |
| 5 | d(Ax)/dx = A | 선형변환 = 행렬 자체 |
| 6 | ∇(½θ^T Sθ + a^T θ) = Sθ + a | 정규방정식의 기반 |

# PART 6. 최소제곱법 — 정규방정식 완전 유도

---

## 🟢 입문: 무엇을 구하는가?

**상황:** n개의 데이터 (x_i, y_i)가 있을 때, 가장 잘 맞는 선형 모델 w를 찾고 싶다.

**백엔드 비유:** n개의 서버 로그에서 CPU 사용률과 응답시간의 관계를 찾는 것. 완벽하게 맞는 직선은 없지만, 오차의 합을 최소로 만드는 직선을 찾는다.

---

## 🔴 고급: 완전 유도 (시험 답안 형식)

### 설정 명시 (이것 없으면 감점)

- 데이터: $X \in \mathbb{R}^{n \times p}$ (n개 샘플, p개 특성), $y \in \mathbb{R}^n$ (정답 벡터)
- 모델: $\hat{y} = Xw$ (선형 예측)
- 목표: 손실 L_S(w)를 최소화하는 $\hat{\beta}$ 찾기

---

### Step 1: 손실 함수 정의

$$L_S(w) = \frac{1}{2}\|Xw - y\|^2$$

```
||Xw - y||²  : 예측값 Xw와 실제값 y의 차이(오차)의 크기² 
              = Σᵢ (x_i^T w - yᵢ)²  (각 샘플의 오차² 합)
1/2          : 미분 시 2가 상쇄되어 깔끔해지는 편의 상수
              (최적해에는 영향 없음)

왜 제곱을 쓰는가?
→ 오차의 부호(+ / -)를 없애기 위해
→ 미분 가능하게 하기 위해 (절댓값은 특정 점에서 미분 불가)
→ 큰 오차에 더 큰 패널티 (제곱 특성)
```

### Step 2: 손실 함수 전개

$$L_S(w) = \frac{1}{2}(Xw - y)^T(Xw - y)$$

```
||v||² = v^T v 공식 적용, v = Xw - y
```

전치 분배:

$$(Xw - y)^T = (Xw)^T - y^T = w^T X^T - y^T$$

전개:

$$= \frac{1}{2}(w^T X^T - y^T)(Xw - y)$$

$$= \frac{1}{2}(w^T X^T X w - w^T X^T y - y^T X w + y^T y)$$

```
각 항 설명:
w^T X^T X w  : 이차형식 (스칼라)
w^T X^T y    : 선형 항 (스칼라) = (y^T X w)^T = y^T X w (스칼라의 전치 = 자기 자신)
y^T X w      : 선형 항 (스칼라)
y^T y        : 상수 (w와 무관)

y^T X w = w^T X^T y 이므로 두 항을 합치면:
```

$$= \frac{1}{2}(w^T X^T X w - 2y^T X w + y^T y)$$

---

### Step 3: w에 대해 미분

공식 5번 (∇(½θ^T Sθ + a^T θ) = Sθ + a) 적용:

여기서 $S = X^T X$, $a = -X^T y$ 로 놓으면:

$$\frac{d L_S(w)}{dw}\bigg|_{w=\hat{\beta}} = \hat{\beta}^T X^T X - y^T X = 0$$

```
세부 미분:
d/dw [½ w^T (X^T X) w]  = w^T (X^T X)   (공식 3번: d(x^T Sx)/dx = 2x^T S 에서 ½ 곱하면 x^T S)
d/dw [-y^T X w]          = -y^T X         (공식 1번: d(a^T x)/dx = a^T, 여기서 a = X^T y)
d/dw [y^T y]             = 0              (w와 무관한 상수)

합산: w^T(X^T X) - y^T X = 0
```

전치를 취해서 열벡터로:

$$X^T X \hat{\beta} - X^T y = 0$$

$$\boxed{X^T X \hat{\beta} = X^T y} \quad \text{← 정규 방정식 (Normal Equation)}$$

---

### Step 4: 정규방정식 풀기

$$\hat{\beta} = (X^T X)^{-1} X^T y \quad \text{(rank(X) = p 일 때)}$$

```
조건: X^T X 의 역행렬이 존재해야 함
     ↔ X^T X 가 양의 정부호(PD)여야 함
     ↔ X가 열 풀랭크 (rank(X) = p)여야 함
     = 모든 특성(열)이 선형 독립

왜 (X^T X)^{-1}을 직접 계산하면 안 좋은가?
→ O(p³) 연산 + 수치 불안정
→ 대신 np.linalg.solve(X.T @ X, X.T @ y) 권장
```

---

### 정규방정식 유도 체인 요약 (시험 답안 형식)

```
① 가정: X ∈ R^{n×p}, y ∈ R^n, 선형 모델 ŷ = Xw

② 손실 정의:
   L_S(w) = ½||Xw - y||²

③ 전개:
   L_S(w) = ½(w^T X^T Xw - 2y^T Xw + y^T y)

④ 미분 = 0 (왜? 최솟값의 필요 조건):
   dL_S/dw|_{w=β̂} = β̂^T X^T X - y^T X = 0

⑤ 전치하여 열벡터로:
   X^T X β̂ - X^T y = 0

⑥ 정규방정식:
   X^T X β̂ = X^T y

⑦ 해:
   β̂ = (X^T X)^{-1} X^T y  [rank(X) = p일 때]
```

# PART 7. 정규방정식이 항상 해를 갖는 이유

---

## 🟢 입문: "해가 없을 수도 있는가?"

**일반적인 선형방정식 Ax = b 는 해가 없을 수 있다.**

예: 미지수 1개, 방정식 2개
- 2x = 4 → x = 2
- 3x = 9 → x = 3
→ 모순 → 해 없음

**그런데 정규방정식 X^T X β̂ = X^T y 는 항상 해가 있다. 왜?**

---

## 🔴 고급: 증명

### 핵심 보조 정리: im(X^T) = im(X^T X)

```
im(A) : A의 image (치역, column space)
        = {Av | v는 임의의 벡터}
        = A의 열들의 모든 선형 결합

선형대수의 기본 정리 (FToLA):
→ 임의의 행렬 M에 대해 ker(M) ⊥ im(M^T)
→ 즉, R^n = ker(M) ⊕ im(M^T)  (직교 분해)
```

**증명:**

Step 1: im(X^T X) ⊆ im(X^T) 는 자명하다.

```
X^T X v = X^T (Xv) = X^T × (어떤 벡터)
→ 결과가 X^T × 뭔가 = im(X^T)에 속함
```

Step 2: im(X^T) ⊆ im(X^T X) 증명

임의의 $x \in \text{im}(X^T)$를 잡자. 즉, $x = X^T z$ 인 어떤 z가 존재.

$z$를 직교 분해: $z = z_1 + z_2$, 여기서 $z_1 \in \ker(X^T)$, $z_2 \in \ker(X^T)^\perp$

선형대수의 기본 정리에 의해:

$$\ker(X^T)^\perp = \text{im}(X)$$

```
설명: ker(X^T)의 직교 보공간 = im(X)

왜? 선형대수의 기본 정리:
→ R^n = ker(X^T) ⊕ im(X)
→ 따라서 ker(X^T)^⊥ = im(X)
```

따라서 $z_2 \in \text{im}(X)$ 이므로 $z_2 = Xv$ 인 v가 존재.

그러면:

$$x = X^T z = X^T(z_1 + z_2) = X^T z_1 + X^T z_2$$

$z_1 \in \ker(X^T)$ 이면 $X^T z_1 = 0$ 이므로:

$$x = X^T z_2 = X^T (Xv) = (X^T X) v \in \text{im}(X^T X)$$

```
따라서 x ∈ im(X^T X) 이 성립
→ im(X^T) ⊆ im(X^T X)  ✓
```

**결론:** $\text{im}(X^T) = \text{im}(X^T X)$

**따라서 정규방정식이 항상 해를 갖는 이유:**

$$b = X^T y \in \text{im}(X^T) = \text{im}(X^T X) = \text{im}(A)$$

```
A β̂ = b 에서 b가 A의 치역 안에 있으면 해가 반드시 존재
b = X^T y ∈ im(X^T X)  → 해 존재 ✓

추가: 이차함수의 볼록성
→ L_S(w) = ½||Xw - y||²는 w의 볼록 이차함수
→ 볼록 함수는 최솟값이 반드시 존재
→ 이 최솟값에서 gradient = 0 (정규방정식)
→ 따라서 해가 반드시 존재
```

---

## 해의 유일성 — rank에 따른 분류

### 경우 1: rank(X) = p (풀 랭크) — 유일한 해

$$\hat{\beta} = (X^T X)^{-1} X^T y$$

```
rank(X) = p → X의 모든 열이 선형 독립
           → X^T X 의 모든 고유값 > 0 (PD)
           → 역행렬 존재
           → 해가 정확히 하나
```

### 경우 2: rank(X) < p (랭크 부족) — 무한히 많은 해

$$\hat{\beta} \in (X^T X)^+ X^T y + \ker(X)$$

```
(X^T X)^+ : 의사역행렬 (pseudoinverse)
ker(X)    : X의 영공간 (Xv = 0인 모든 v의 집합)

무한히 많은 해 중 가장 단순한 것:
최소 노름 해 = (X^T X)^+ X^T y = X^+ y

언제 발생하는가?
→ n < p인 경우 (샘플 수 < 파라미터 수)
→ 딥러닝의 전형적 상황 (과매개변수화)
→ numpy: np.linalg.lstsq(X, y)가 자동 처리
```

# PART 8. 릿지 회귀 — L2 정규화 완전 유도

---

## 🟢 입문: 왜 정규화가 필요한가?

**문제:** rank(X) < p 이면 해가 무한히 많다. 또는 rank(X) = p 여도 X^T X 의 조건수가 크면 수치적으로 불안정.

**해결책:** 손실 함수에 "가중치를 작게 유지하라"는 페널티 추가

**백엔드 비유:** 커넥션 풀 최대 제한 (MAX_CONNECTIONS). 서버 과부하(과적합) 방지를 위해 연결 수를 제한하는 것.

---

## 🔴 고급: 완전 유도

### Step 1: 릿지 손실 함수 정의

$$L_S(w; \lambda) = \frac{1}{2}\|Xw - y\|^2 + \frac{\lambda}{2}\|w\|^2 \quad (\lambda > 0)$$

```
첫 번째 항: ½||Xw - y||²  → 예측 오차 최소화 (데이터에 맞추기)
두 번째 항: ½λ||w||²     → 가중치 크기 제한 (과적합 방지)
λ (람다)  : 정규화 강도 조절 하이퍼파라미터
           λ = 0 → 일반 최소제곱법
           λ → ∞ → 모든 w → 0
```

### Step 2: 손실 함수 전개

$$L_S(w;\lambda) = \frac{1}{2}(w^T X^T Xw - 2y^T Xw + y^T y) + \frac{\lambda}{2}w^T w$$

```
||w||² = w^T w  (w^T I w, 단위 행렬 S = I)
```

### Step 3: w에 대해 미분

$$\frac{dL_S}{dw}\bigg|_{w=\hat{\beta}_\lambda} = \hat{\beta}_\lambda^T X^T X - y^T X + \lambda \hat{\beta}_\lambda^T = 0$$

```
각 항 미분:
d/dw [½w^T(X^T X)w] = w^T(X^T X)   (공식 3번 응용)
d/dw [-y^T Xw]       = -y^T X        (공식 1번)
d/dw [½λ w^T w]      = λw^T          (공식 3번: d(½||w||²)/dw = w^T)
```

전치하여 열벡터로:

$$X^T X \hat{\beta}_\lambda + \lambda \hat{\beta}_\lambda - X^T y = 0$$

$$\boxed{(X^T X + \lambda I)\hat{\beta}_\lambda = X^T y}$$

### Step 4: 해 도출

$$\hat{\beta}_\lambda = (X^T X + \lambda I)^{-1} X^T y$$

### Step 5: X^T X + λI 가 항상 가역인 이유 (PD 증명)

$X^T X$는 PSD (모든 고유값 ≥ 0).

$X^T X$의 고유값을 $\mu_i \geq 0$ 이라 하면,

$(X^T X + \lambda I)$의 고유값은 $\mu_i + \lambda$

$\lambda > 0$ 이면: $\mu_i + \lambda > 0$ → 모든 고유값 > 0 → PD → 역행렬 존재

```
수학적 표현:
v^T(X^T X + λI)v = v^T(X^T X)v + λv^T Iv
                  = ||Xv||² + λ||v||²
                  ≥ 0 + λ||v||²
                  > 0  (λ > 0이고 v ≠ 0이면 ||v||² > 0)
→ X^T X + λI 는 PD ✓
→ 항상 역행렬 존재 → 유일한 해 보장!
```

---

### 릿지 회귀 유도 체인 요약

```
① 손실: L_S(w;λ) = ½||Xw-y||² + ½λ||w||²

② 전개: ½(w^T X^T Xw - 2y^T Xw + y^T y) + ½λw^T w

③ 미분 = 0:
   β̂_λ^T(X^T X) - y^T X + λβ̂_λ^T = 0

④ 정규방정식:
   (X^T X + λI)β̂_λ = X^T y

⑤ λ > 0 → X^T X + λI 는 PD → 역행렬 존재 → 유일한 해

⑥ 해: β̂_λ = (X^T X + λI)^{-1} X^T y
```

---

### MAP와의 연결 (Gaussian Prior → L2 정규화)

**왜 릿지 회귀 = MAP 추정인가?**

Prior 설정 (가중치 w에 대한 사전 믿음):

$$P(w) = \mathcal{N}(w; 0, \tau^2 I) \propto \exp\left(-\frac{\|w\|_2^2}{2\tau^2}\right)$$

MAP 목적함수:

$$\hat{w}_{MAP} = \arg\max_w [P(D|w) \cdot P(w)]$$

로그 취하고 음수로 변환 (최소화):

$$= \arg\min_w \left[\underbrace{\frac{1}{2\sigma^2}\sum_i(y_i - x_i^T w)^2}_{\text{NLL} \propto \text{MSE}} + \underbrace{\frac{1}{2\tau^2}\|w\|_2^2}_{-\log P(w)}\right]$$

$\lambda = \sigma^2/\tau^2$ 으로 놓으면:

$$\boxed{\arg\min_w \left[\text{MSE} + \lambda\|w\|_2^2\right] = \text{릿지 회귀}}$$

```
직관: 
→ 릿지 회귀 = "Gaussian Prior를 쓴 MAP 추정"
→ λ가 크면 Prior(Gaussian)를 강하게 믿는 것
→ PyTorch: optimizer = Adam(..., weight_decay=λ)
```

# PART 9. 라그랑주 승수법 — 제약 최적화

---

## 🟢 입문: 비유부터 시작

**상황:** 직선 위에서 원점에 가장 가까운 점을 찾아라.

**백엔드 비유:** "총 메모리 제한 = 100GB"라는 제약 아래서 서비스 A와 B에 메모리를 어떻게 배분해야 응답시간이 최소가 되는가?

**라그랑주 승수법의 핵심 아이디어:**

제약이 있는 문제 → 제약을 "벌금 항"으로 목적함수에 합쳐서 → 제약 없는 문제로 변환

---

## 🔴 고급: 완전 유도 — 예제 1

### 문제 설정 (교재 p.115)

**최소화:** $f(x, y) = x^2 + y^2$ (원점으로부터의 거리²)

**제약:** $g(x, y) = x + y - 1 = 0$ (직선 위)

---

### Step 1: 라그랑지안 구성

$$\mathcal{L}(x, y, \lambda) = f(x,y) + \lambda \cdot g(x,y)$$

$$= x^2 + y^2 + \lambda(x + y - 1)$$

```
λ (람다): 라그랑주 승수 (Lagrange Multiplier)
         제약이 목적함수에 미치는 "민감도"를 나타냄
         (최적점에서 제약을 약간 완화하면 최적값이 λ만큼 변함)

라그랑지안의 구조:
L = [최소화하고 싶은 함수] + λ × [제약 함수]
```

### Step 2: 모든 변수에 대해 편미분 = 0

$$\frac{\partial \mathcal{L}}{\partial x} = 2x + \lambda = 0 \quad \cdots (1)$$

$$\frac{\partial \mathcal{L}}{\partial y} = 2y + \lambda = 0 \quad \cdots (2)$$

$$\frac{\partial \mathcal{L}}{\partial \lambda} = x + y - 1 = 0 \quad \cdots (3)$$

```
왜 세 개의 편미분을 모두 0으로 놓는가?
→ 라그랑지안의 안장점(saddle point)에서 최적해가 나타남
→ 직관: x,y 방향 기울기가 0이면 목적함수의 극값
         λ 방향 기울기 = 0이면 제약이 만족됨

∂L/∂λ = 0 이 바로 제약 조건 g(x,y) = 0과 동일!
```

### Step 3: 연립방정식 풀기

식 (1)에서: $\lambda = -2x$

식 (2)에서: $\lambda = -2y$

따라서: $-2x = -2y$ → $x = y$

식 (3)에 대입: $x + x = 1$ → $2x = 1$ → $x = \frac{1}{2}$

$$\boxed{(x, y, \lambda) = \left(\frac{1}{2}, \frac{1}{2}, -1\right)}$$

**최솟값 확인:** $f\left(\frac{1}{2}, \frac{1}{2}\right) = \frac{1}{4} + \frac{1}{4} = \frac{1}{2}$

```
λ = -1의 의미:
→ 제약 직선을 약간(ε) 이동시키면 최적값이 λ·ε = -ε 만큼 변함
→ 제약을 완화(직선을 원점에서 멀리)하면 최솟값이 작아짐
→ 직관과 일치: 원점에서 멀어지면 더 가까운 점이 생길 수 있음

왜 최대값은 없는가?
→ 직선이 무한히 뻗어 있음 (비유계, unbounded)
→ 직선 위에서 원점까지 거리는 무한히 커질 수 있음
→ 따라서 최솟값만 존재
```

---

### 라그랑주 승수법 일반 절차 (시험 답안 템플릿)

```
① 문제 설정:
   최소화 f(x), 제약 g(x) = 0

② 라그랑지안 구성:
   L(x, λ) = f(x) + λ g(x)

③ 모든 변수에 대해 편미분 = 0:
   ∂L/∂x_i = 0  (i = 1, ..., n)
   ∂L/∂λ = 0   (= 제약 조건)

④ 연립방정식 풀기

⑤ 해가 최솟값인지 최댓값인지 확인
   (이차 조건, 또는 경계값 비교)

⑥ λ의 의미 해석:
   "제약을 1단위 완화할 때 목적함수 변화량 = λ"
```

# PART 10. 시험 답안 템플릿 ⭐⭐⭐

## 이차형식 관련 핵심 증명 체크리스트

### 증명 1: 직교 행렬의 노름 보존

```
||Ux||² = (Ux)^T(Ux)    [노름의 정의]
        = x^T U^T U x   [(AB)^T = B^T A^T]
        = x^T I x       [U^T U = I]
        = x^T x         [I는 단위행렬]
        = ||x||²  ✓
```

### 증명 2: B^T B 는 항상 PSD

```
v^T(B^T B)v = (Bv)^T(Bv)  [(AB)^T = B^T A^T 역방향]
            = ||Bv||²       [노름의 정의]
            ≥ 0             [노름의 제곱은 항상 비음수]  ✓
```

### 증명 3: 이차형식의 대각화 f(x) = Σ λᵢyᵢ²

```
f(x) = x^T A x
     = x^T (UΛU^T) x        [고유분해 A = UΛU^T]
     = (U^T x)^T Λ (U^T x)  [결합법칙 + (U^T x)^T = x^T U]
     = y^T Λ y               [y = U^T x 정의]
     = Σᵢ λᵢ yᵢ²            [Λ가 대각행렬이므로]  ✓

y_i = u_i^T x (x를 i번째 고유벡터 방향으로 투영)
```

### 증명 4: 정규방정식 유도 (최소제곱법)

```
L(w) = ½||Xw - y||²
     = ½(w^T X^T Xw - 2y^T Xw + y^T y)   [전개]

dL/dw|_{β̂} = β̂^T(X^T X) - y^T X = 0     [미분 공식 적용]

전치: (X^T X)β̂ - X^T y = 0

∴ (X^T X)β̂ = X^T y  (정규방정식)

rank(X) = p → β̂ = (X^T X)^{-1} X^T y  ✓
```

### 증명 5: X^T X + λI 는 PD (릿지 역행렬 존재 보장)

```
v^T(X^T X + λI)v = v^T(X^T X)v + λv^T v
                 = ||Xv||² + λ||v||²
                 > 0   (λ > 0, v ≠ 0이면)  ✓
∴ 역행렬 존재 → β̂_λ = (X^T X + λI)^{-1} X^T y 는 유일한 해
```

### 증명 6: MAP → 릿지 회귀 연결

```
P(w) = N(w; 0, τ²I) → log P(w) ∝ -||w||₂²/(2τ²)

MAP: arg min [-log P(D|w) - log P(w)]
   = arg min [NLL + ||w||₂²/(2τ²)]
   = arg min [½σ² × MSE + ||w||₂²/(2τ²)]  [Gaussian noise]

λ = σ²/τ² 으로 놓으면:
   = arg min [MSE + λ||w||₂²]  = 릿지 회귀  ✓
```
