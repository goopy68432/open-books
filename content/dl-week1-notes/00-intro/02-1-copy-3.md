# 🗺️ PART 0. 전체 관계 지도 — 먼저 큰 그림을 보자

---

## 🟢 입문: 백엔드 개발자 비유로 시작

당신이 분산 시스템에서 **"실제 트래픽 패턴(p)"** 과 **"모델이 예측한 트래픽 패턴(q)"** 이 얼마나 다른지 측정한다고 상상하세요.

- **NLL (Negative Log-Likelihood)** = "모델이 실제 데이터를 얼마나 잘 예측하는가"의 패널티 점수
- **MSE** = 연속 출력(집값, 온도)에서의 NLL (Gaussian 노이즈 가정)
- **CE (Cross-Entropy)** = 이산 출력(분류)에서의 NLL (Categorical 분포 가정)
- **KL Divergence** = 두 분포 p, q의 차이를 정보량으로 측정 → CE - H(p)

**핵심 관계:**

```
MLE 최대화
    ↕ (동치)
NLL 최소화
    ↕ (동치)
KL(p_data || q_model) 최소화
    ↕ (분포 가정에 따라)
Gaussian → MSE 최소화
Categorical → CE 최소화
```

---

## 관계 지도 전체

```
[실제 데이터 분포 p_s]
        │
        │ 측정 도구: KL(p_s || q)
        ↓
[모델 분포 q]의 차이를 최소화
        │
        ├── KL(p_s || q) = CE(p_s, q) - H(p_s)
        │        │                │
        │        │         H(p_s)는 상수 (데이터 고유 불확실성)
        │        │
        │        ↓
        │    CE 최소화 = KL 최소화
        │        │
        │        ↓
        │    CE = -E_p[log q] = NLL (표본 평균)
        │
        └── 분포 가정에 따라
                 ├── q = Gaussian  →  NLL = (1/2σ²) Σ(y_i - h(x_i))²  →  MSE
                 └── q = Categorical  →  NLL = -Σ log[h(x_i)]_{y_i}  →  CE Loss
```

# PART 1. NLL의 정의와 의미

---

## 🟢 입문: 중1 수준부터

**상황**: 내일 비가 올 확률이 30%인 날씨 앱이 있는데, 실제로 비가 왔다.
- 모델의 "놀라움"(surprise): 비가 올 확률 30%를 예측했는데 진짜 비가 왔다면, 모델은 꽤 놀란다
- 비가 올 확률 90%를 예측했다면, 비가 와도 별로 안 놀란다

**"놀라움"을 수식으로 표현하면:**
- 낮은 확률 예측 → 실제 발생 → 큰 놀라움 = 큰 패널티
- 높은 확률 예측 → 실제 발생 → 작은 놀라움 = 작은 패널티

수학적으로 "놀라움" = $-\log q(x)$

---

## 🟡 중급: NLL의 정의

**NLL = Negative Log-Likelihood (음의 로그 가능도)**

$$\text{NLL}(\theta) = -\log P(D|\theta)$$

### 기호 Line-by-Line 해체

```
NLL(θ)
│   └── θ: 우리가 추정하려는 파라미터 (신경망의 가중치 w 등)
└── NLL: "Negative Log-Likelihood"의 약자

-log P(D|θ)
│    │ │ └── θ: 파라미터
│    │ └──── D: 관찰된 데이터 전체
│    └────── P(D|θ): "θ가 이 값일 때 데이터 D가 나올 확률" = Likelihood
│                    (θ가 얼마나 데이터를 잘 설명하는지의 점수)
└─────────── -log: 두 가지 역할을 동시에
             ① log: 곱 → 합 변환, 수치 안정성
             ② -(음수): 최대화 → 최소화 변환 (ML 프레임워크는 minimize가 기본)
```

### i.i.d. 가정 적용

**가정**: 데이터 $x_1, x_2, ..., x_n$이 **독립적이고 동일한 분포**에서 추출됨 (i.i.d.)

왜 i.i.d. 가정이 필요한가?
→ 독립 사건의 확률은 **곱**으로 표현된다: P(A∩B) = P(A)·P(B)
→ 이 덕분에 전체 데이터의 Likelihood를 각 데이터의 확률의 **곱**으로 쓸 수 있다

$$P(D|\theta) = \prod_{i=1}^{n} P(x_i|\theta)$$

```
∏ (파이): 곱하기 기호. Σ가 더하기인 것처럼, ∏는 곱하기
∏_{i=1}^{n}: i=1부터 n까지 모두 곱하라
i.i.d 덕분에 이렇게 쓸 수 있다
```

**log 취하기 (왜?):**

이유 1: 곱 → 합으로 변환 (미분 쉬워짐)
이유 2: 아주 작은 확률들을 곱하면 컴퓨터에서 0으로 수렴(언더플로우) → log로 방지
이유 3: log는 단조증가 함수 → argmax 유지

$$\text{NLL}(\theta) = -\log P(D|\theta) = -\sum_{i=1}^{n} \log P(x_i|\theta)$$

```
log(∏ a_i) = Σ log(a_i)  ← log의 핵심 성질: 곱의 log = log의 합
- 붙이면: -Σ log P(x_i|θ)
```

### 핵심 등치 관계

$$\underbrace{\arg\max_\theta \log P(D|\theta)}_{\text{MLE}} = \underbrace{\arg\min_\theta \text{NLL}(\theta)}_{\text{NLL 최소화}}$$

```
arg max ℓ(θ)  ↔  arg min -ℓ(θ)
(최대화)              (최소화)
이건 단순히 부호를 바꾼 것 — 수학적으로 완전히 동일한 문제
```

# PART 2. Gaussian → MSE 완전 유도

---

## 🟢 입문: 중1 수준에서 시작

**상황**: 집값을 예측한다. 실제 집값 y=3억, 모델 예측 h(x)=2.5억
- 오차 = 3 - 2.5 = 0.5억
- 오차의 제곱 = 0.5² = 0.25

MSE는 이 오차 제곱의 평균이다. 왜 제곱을 쓰는가?
→ "노이즈가 정규분포(Gaussian)를 따른다"는 가정에서 자동으로 유도된다!
→ 가정만 바뀌면 다른 손실함수가 나온다

---

## 🔴 고급: 완전 유도 (시험 답안 형식)

### 설정 명시 (이것 없으면 감점)

- 데이터: $\{(x_i, y_i)\}_{i=1}^n$, $x_i \in \mathbb{R}^d$, $y_i \in \mathbb{R}$ (연속)
- 가설: 노이즈 $\varepsilon_i \sim \mathcal{N}(0, \sigma^2)$ i.i.d.
- 따라서 **Gaussian 노이즈 가정**: $y_i | x_i \sim \mathcal{N}(h(x_i), \sigma^2)$

---

### Step 1: Gaussian PDF 쓰기

가우시안 확률밀도함수:

$$p(y_i | x_i, \theta) = \mathcal{N}(y_i; h(x_i), \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - h(x_i))^2}{2\sigma^2}\right)$$

```
기호 해체:
1/√(2πσ²): 정규화 상수. PDF 전체 면적 = 1 이 되도록 만드는 상수
exp(-...): 자연상수 e의 거듭제곱
(y_i - h(x_i))²: 실제값과 예측값의 차이의 제곱
2σ²: 분산의 2배 (분모)
σ² 클수록 분포가 넓게 퍼짐 (불확실성 큼)
```

---

### Step 2: Likelihood 쓰기

i.i.d. 가정 → 전체 Likelihood는 각 데이터의 확률의 **곱**:

$$P(D|\theta) = \prod_{i=1}^{n} \mathcal{N}(y_i; h(x_i), \sigma^2)$$

---

### Step 3: Log-Likelihood 취하기

**왜 log를 취하는가?** → 곱 → 합 변환, 수치 안정성

$$\log P(D|\theta) = \sum_{i=1}^{n} \log \mathcal{N}(y_i; h(x_i), \sigma^2)$$

Gaussian의 log를 전개한다:

$$= \sum_{i=1}^{n} \log \left[\frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - h(x_i))^2}{2\sigma^2}\right)\right]$$

**log 법칙 적용**: $\log(A \cdot B) = \log A + \log B$

$$= \sum_{i=1}^{n} \left[\log\frac{1}{\sqrt{2\pi\sigma^2}} + \log \exp\!\left(-\frac{(y_i - h(x_i))^2}{2\sigma^2}\right)\right]$$

**두 가지 정리:**

$\log \frac{1}{\sqrt{2\pi\sigma^2}} = -\frac{1}{2}\log(2\pi\sigma^2)$ → 상수 (θ와 무관)

$\log \exp(-A) = -A$ (log와 exp가 역함수 관계)

$$= \sum_{i=1}^{n} \left[-\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - h(x_i))^2}{2\sigma^2}\right]$$

$$= -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - h(x_i))^2$$

---

### Step 4: NLL로 변환 (부호 뒤집기)

$$\text{NLL}(\theta) = -\log P(D|\theta) = \frac{n}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - h(x_i))^2$$

---

### Step 5: MSE와 연결

$\sigma^2$이 **고정된 상수**일 때:

- $\frac{n}{2}\log(2\pi\sigma^2)$ → θ와 무관한 **상수** C
- $\frac{1}{2\sigma^2}$ → θ와 무관한 **양의 상수**

따라서:

$$\text{NLL}(\theta) = \underbrace{\frac{n}{2\sigma^2}}_{\text{양의 상수}} \cdot \underbrace{\frac{1}{n}\sum_{i=1}^{n}(y_i - h(x_i))^2}_{\text{MSE}(h)} + C$$

$$\boxed{\text{NLL}(\theta) = \frac{n}{2\sigma^2} \cdot \text{MSE}(h) + C}$$

**결론:**

$$\arg\min_\theta \text{NLL}(\theta) = \arg\min_\theta \text{MSE}(h)$$

```
왜 NLL 최소화 = MSE 최소화인가?
- 앞의 n/(2σ²)는 양의 상수 → 최소화에 영향 없음
- C도 상수 → 최소화에 영향 없음
- 남은 것은 MSE 뿐
따라서 MSE를 최소화하는 θ가 NLL도 최소화한다
```

---

### ⭐ 결론: 4개의 이름, 하나의 실체

$$\boxed{\text{최소제곱법} = \text{MSE 최소화} = \text{Gaussian NLL 최소화} = \text{Gaussian 하의 MLE}}$$

# PART 3. Bernoulli/Categorical → CE 완전 유도

---

## 🟢 입문: 이진 분류 예시

**상황**: 이메일이 스팸(y=1)인지 아닌지(y=0) 분류한다.
- 모델 출력: $\sigma(x^Tw)$ = 스팸일 확률 (0~1 사이)
- y=1이면 → 스팸 확률이 높기를 원함 → $-\log(\text{스팸 확률})$이 작기를 원함
- y=0이면 → 비스팸 확률이 높기를 원함 → $-\log(1-\text{스팸 확률})$이 작기를 원함

두 경우를 한 수식으로 합치면: **Binary Cross-Entropy**

---

## 🔴 고급: 이진 분류 NLL 완전 유도

### 설정

- 분류: $y_i \in \{0, 1\}$ (이진)
- 가정: $y_i | x_i \sim \text{Bernoulli}(\sigma(x_i^T w))$
- $f_w(x_i) = \sigma(x_i^T w) \in [0,1]$: 모델이 예측하는 "1일 확률"

---

### Step 1: Bernoulli PMF

$$P(y_i | x_i, w) = f_w(x_i)^{y_i} \cdot (1 - f_w(x_i))^{1-y_i}$$

```
기호 해체:
f_w(x_i): 모델이 예측한 "y=1일 확률"
y_i: 실제 정답 (0 또는 1)

y_i = 1일 때:
  P = f_w(x_i)^1 · (1-f_w(x_i))^0 = f_w(x_i)     ← 스팸 확률 그 자체
y_i = 0일 때:
  P = f_w(x_i)^0 · (1-f_w(x_i))^1 = 1-f_w(x_i)   ← 비스팸 확률
```

---

### Step 2: 전체 Likelihood (i.i.d.)

$$P(D|w) = \prod_{i=1}^{n} f_w(x_i)^{y_i}(1-f_w(x_i))^{1-y_i}$$

---

### Step 3: Log-Likelihood

$$\log P(D|w) = \sum_{i=1}^{n} \left[y_i \log f_w(x_i) + (1-y_i)\log(1-f_w(x_i))\right]$$

```
log 법칙 적용:
log(A · B) = log A + log B
log(A^n) = n log A

따라서:
log [f^{y_i} · (1-f)^{1-y_i}]
= y_i log f + (1-y_i) log(1-f)
```

---

### Step 4: NLL = Binary Cross-Entropy

$$\text{NLL}(w) = -\sum_{i=1}^{n} \left[y_i \log f_w(x_i) + (1-y_i)\log(1-f_w(x_i))\right]$$

$$\boxed{\text{BCE}(w) = -\sum_{i=1}^{n} \left[y_i \log \sigma(x_i^Tw) + (1-y_i)\log(1-\sigma(x_i^Tw))\right]}$$

**이것이 Binary Cross-Entropy = Bernoulli NLL**

---

## 🔴 고급: 다중 분류 NLL 완전 유도

### 설정

- 분류: $y_i \in \{1, 2, ..., C\}$ (C개 클래스)
- 가정: $y_i | x_i \sim \text{Cat}(h(x_i))$, 여기서 $h(x_i) \in [0,1]^C$, $\sum_c h_c(x_i) = 1$
- $[h(x_i)]_{y_i}$: 모델이 정답 클래스 $y_i$에 부여한 확률

---

### Step 1: Categorical PMF

$$P(y_i | x_i, \theta) = [h(x_i)]_{y_i} = \prod_{c=1}^{C} h_c(x_i)^{\mathbf{1}[y_i = c]}$$

```
기호 해체:
[h(x_i)]_{y_i}: h(x_i) 벡터의 y_i 번째 원소 = 정답 클래스의 확률
1[y_i = c]: y_i = c이면 1, 아니면 0 (indicator function)

예시: C=3, y_i=2, h(x_i)=[0.1, 0.7, 0.2]
→ [h(x_i)]_2 = 0.7 (클래스 2의 확률)
```

---

### Step 2: NLL 전개

$$\text{NLL}(\theta) = -\sum_{i=1}^{n} \log [h(x_i)]_{y_i}$$

```
i.i.d. 가정 → Likelihood = ∏ [h(x_i)]_{y_i}
log 취하면 → Σ log [h(x_i)]_{y_i}
음수 취하면 → -Σ log [h(x_i)]_{y_i}
```

**원-핫(one-hot) 벡터 $e_{y_i}$를 써서 표현:**

$$\text{NLL}(\theta) = -\sum_{i=1}^{n} e_{y_i}^T \log h(x_i)$$

```
e_{y_i}: y_i 번째 원소만 1이고 나머지는 0인 벡터 (one-hot)
e_{y_i}^T log h(x_i): 정답 위치의 log 확률만 선택
```

**이것이 Categorical Cross-Entropy Loss:**

$$\boxed{\mathcal{L}_{CE} = -\sum_{i=1}^{n} \sum_{c=1}^{C} \mathbf{1}[y_i=c] \log h_c(x_i)}$$

---

# PART 4. KL Divergence 정의와 성질

---

## 🟢 입문: 비유로 시작

두 분포를 **지도(map)** 에 비유하자:
- **p**: 실제 지형 (데이터의 진짜 분포)
- **q**: 모델이 그린 지도 (예측 분포)

KL Divergence = "q라는 잘못된 지도로 p라는 실제 지형을 탐색할 때 발생하는 **추가 비용**"

완벽한 지도(q=p)면 추가 비용 = 0 → KL = 0

---

## 🟡 중급: 정의와 성질

### KL Divergence 정의

$$KL(p \| q) := E_p\left[\log \frac{p(X)}{q(X)}\right] = \int p(x) \log \frac{p(x)}{q(x)} \, dx$$

```
기호 Line-by-Line 해체:

KL(p ‖ q)
│   │  └── q: 비교 대상 분포 (모델 분포)
│   └───── p: 기준 분포 (실제 데이터 분포)
└───────── KL: Kullback-Leibler의 약자
           ‖ 기호의 방향이 중요: KL(p‖q) ≠ KL(q‖p)

E_p[...]
│   └── p 분포를 기준으로 기댓값 계산
└───── 기댓값 (Expected value)

log(p(x)/q(x))
    │    └── q(x): x가 모델 분포 q에서 나올 확률밀도
    └──────── p(x): x가 실제 분포 p에서 나올 확률밀도
log(p/q): p와 q가 비슷하면 log(1) = 0
          p > q이면 log값 > 0 (p가 있는 곳에 q가 적다)
          p < q이면 log값 < 0
```

이산 분포의 경우:

$$KL(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)}$$

---

### 핵심 성질 3가지 (시험 단골)

**성질 1: 비음수 (Non-negativity)**

$$KL(p \| q) \geq 0$$

등호 조건: $p = q$ 일 때만 KL = 0

```
증명 스케치: Jensen's Inequality 적용
log는 오목함수(concave)
E[log(q/p)] ≤ log(E[q/p]) = log(∫ p(x)·q(x)/p(x)dx) = log(1) = 0
따라서 E[log(q/p)] ≤ 0 → E[log(p/q)] ≥ 0 → KL ≥ 0
```

**성질 2: 비대칭성 (Asymmetry)**

$$KL(p \| q) \neq KL(q \| p) \quad \text{(일반적으로)}$$

→ KL은 진짜 "거리"가 아니다 (거리는 대칭이어야 함)
→ "발산(divergence)"이라고 부르는 이유

**성질 3: 분해 (Decomposition)**

$$KL(p \| q) = CE(p, q) - H(p)$$

→ 이것이 CE와 KL의 핵심 연결고리 (PART 5에서 자세히 유도)

---

### 🔴 고급: Gaussian 간의 KL 공식

단변량 Gaussian:

$$KL\!\left(\mathcal{N}(\mu_1, \sigma_1^2) \| \mathcal{N}(\mu_2, \sigma_2^2)\right) = \frac{1}{2}\left[2\log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2}{\sigma_2^2} + \frac{(\mu_1-\mu_2)^2}{\sigma_2^2} - 1\right]$$

**특수 케이스 (시험에 자주 등장):**

$\sigma_1 = \sigma_2 = 1$이면:

$$KL = \frac{(\mu_1 - \mu_2)^2}{2}$$

```
이 결과의 의미:
분산이 같은 두 Gaussian의 KL = 평균 차이의 제곱 / 2
= MSE (스케일 차이만 있음)

이것이 KL(Gaussian) ∝ MSE의 근거!
```

# PART 5. NLL = KL 최소화 완전 증명

---

## 🟡 중급: 경험적 분포 개념

실제 데이터 $\{x_1, ..., x_n\}$로부터 구성하는 **경험적 분포(empirical distribution)**:

$$p_S(x) := \frac{1}{n} \sum_{i=1}^{n} \delta(x - x_i)$$

```
기호 해체:
δ(x - x_i): 디랙 델타 함수
            x = x_i일 때 무한대, 그 외에서 0
            (데이터 포인트 위에 "스파이크"가 있는 형태)
1/n: n개 데이터 포인트에 균등하게 1/n의 확률 할당

의미: "우리가 가진 데이터로 만든 가장 단순한 확률분포"
      데이터 있는 곳에만 확률이 있고, 없는 곳은 0
```

---

## 🔴 고급: NLL = KL 완전 증명

### 증명

**KL 발산의 정의 적용:**

$$KL(p_S \| q_\theta) = E_{p_S}\left[\log \frac{p_S(X)}{q_\theta(X)}\right]$$

**기댓값을 경험적 분포로 계산:**

$$= E_{p_S}[\log p_S(X)] - E_{p_S}[\log q_\theta(X)]$$

```
log(A/B) = log A - log B 적용
```

**각 항 분석:**

$$E_{p_S}[\log p_S(X)] = -H(p_S)$$

```
H(p_S) = -E_p[log p_S(X)] = 엔트로피 (상수)
왜 상수인가? p_S는 데이터에 의해 완전히 결정된다
파라미터 θ를 바꿔도 p_S는 바뀌지 않는다
```

$$E_{p_S}[\log q_\theta(X)] = \frac{1}{n}\sum_{i=1}^{n} \log q_\theta(x_i)$$

```
경험적 분포의 기댓값 = 표본 평균
E_{p_S}[f(X)] = (1/n)Σ f(x_i)
```

**따라서:**

$$KL(p_S \| q_\theta) = -H(p_S) - \frac{1}{n}\sum_{i=1}^{n} \log q_\theta(x_i)$$

$$= \underbrace{-H(p_S)}_{\text{상수}} + \underbrace{\frac{1}{n}\sum_{i=1}^{n} (-\log q_\theta(x_i))}_{\text{NLL (표본 평균)}}$$

**결론:**

$$\arg\min_\theta KL(p_S \| q_\theta) = \arg\min_\theta \frac{1}{n}\sum_{i=1}^{n}(-\log q_\theta(x_i)) = \arg\min_\theta \text{NLL}(\theta)$$

$$\boxed{KL \text{ 최소화} = \text{NLL 최소화} = \text{MLE}}$$

```
핵심 트릭 정리:
① p_S의 엔트로피 H(p_S)는 θ에 무관한 상수
② 상수를 최소화에서 무시할 수 있다
③ 남는 것은 NLL (표본 평균 형태)
④ 따라서 KL 최소화 = NLL 최소화
```

# PART 6. CE = KL + H 관계 유도

---

## 🟢 입문: 세 개념의 관계

**엔트로피** H(p): 분포 p의 고유 불확실성 ("최소한 이만큼은 틀린다")

**교차 엔트로피** CE(p,q): 잘못된 분포 q로 p를 예측할 때 드는 비용

**KL 발산**: 잘못된 분포 때문에 발생하는 **추가** 비용

$$\underbrace{CE(p,q)}_{\text{총 비용}} = \underbrace{H(p)}_{\text{고유 불확실성}} + \underbrace{KL(p\|q)}_{\text{추가 비용}}$$

---

## 🔴 고급: CE = KL + H 완전 유도

### 정의 먼저

**엔트로피:**

$$H(p) := -E_p[\log p(X)] = -\sum_x p(x) \log p(x)$$

```
H(p): 분포 p의 불확실성
p 자신이 얼마나 예측하기 어려운지
균등분포 → 최대 엔트로피
확정적 분포(one-hot) → 엔트로피 = 0
```

**교차 엔트로피:**

$$CE(p, q) := -E_p[\log q(X)] = -\sum_x p(x) \log q(x)$$

```
p를 기준으로 q의 log를 취하는 기댓값
"실제 분포 p 하에서 모델 q의 로그 확률의 평균"
= 모델 q로 분포 p를 설명할 때의 평균 비용
```

**KL 발산:**

$$KL(p\|q) := E_p\left[\log \frac{p(X)}{q(X)}\right] = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

### 유도

KL을 분해한다:

$$KL(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

$\log(p/q) = \log p - \log q$ 적용:

$$= \sum_x p(x)[\log p(x) - \log q(x)]$$

$$= \sum_x p(x)\log p(x) - \sum_x p(x)\log q(x)$$

$$= -\left(-\sum_x p(x)\log p(x)\right) + \left(-\sum_x p(x)\log q(x)\right)$$

$$= -H(p) + CE(p, q)$$

따라서:

$$\boxed{CE(p, q) = H(p) + KL(p \| q)}$$

또는:

$$\boxed{KL(p \| q) = CE(p, q) - H(p)}$$

---

### 핵심 결론 (시험 단골)

**p가 고정되어 있다면** (즉, 실제 데이터 분포는 고정):

$$H(p) = \text{상수}$$

$$\arg\min_q CE(p, q) = \arg\min_q [H(p) + KL(p\|q)] = \arg\min_q KL(p\|q)$$

$$\boxed{CE \text{ 최소화} = KL \text{ 최소화}}$$

---

### 섀넌의 소스 코딩 정리

$$H(p) = CE(p, p) = \min_q CE(p, q)$$

```
의미: p와 똑같은 코드북(q=p)을 쓸 때 교차 엔트로피가 최소
즉, 엔트로피는 교차 엔트로피의 하한(lower bound)
CE ≥ H(p), 등호 조건: q = p
```

---

### 분류에서의 적용 (원-핫 레이블)

분류에서 정답 레이블 p는 **원-핫 벡터**:

$$p(y) = \begin{cases} 1 & \text{if } y = y_{\text{true}} \\ 0 & \text{otherwise} \end{cases}$$

이때:

$$H(p) = -\sum_y p(y)\log p(y) = -(1 \cdot \log 1) = 0$$

따라서:

$$CE(p, q) = H(p) + KL(p\|q) = 0 + KL(p\|q) = KL(p\|q)$$

$$CE(p, q) = -\sum_y p(y)\log q(y) = -\log q(y_{\text{true}}) = \text{NLL}$$

$$\boxed{\text{원-핫 레이블에서: } CE = KL = NLL = -\log q(y_{\text{true}})}$$

# PART 7. MSE · NLL · KL 전체 체인 완전 정리

---

## 🟡 전체 등치 체인

$$\boxed{\text{MLE} = \arg\max \log P(D|\theta) = \arg\min \text{NLL} = \arg\min KL(p_S \| q_\theta)}$$

**Gaussian 노이즈 가정 시:**

$$= \arg\min \text{MSE}$$

**Categorical 분포 가정 시:**

$$= \arg\min CE = \arg\min \text{NLL}_{\text{categorical}}$$

---

## 🔴 완전 증명 체인 (시험 답안 형식)

### 체인 1: MLE = NLL 최소화

$$\arg\max_\theta P(D|\theta) \overset{(1)}{=} \arg\max_\theta \log P(D|\theta) \overset{(2)}{=} \arg\min_\theta (-\log P(D|\theta)) = \arg\min_\theta \text{NLL}(\theta)$$

```
(1): log는 단조증가 함수 → argmax 유지 (argmax f = argmax log f)
(2): 최대화의 부호를 바꾸면 최소화 (argmax f = argmin -f)
```

### 체인 2: NLL = KL 최소화

$$\arg\min_\theta \text{NLL}(\theta) = \arg\min_\theta KL(p_S \| q_\theta)$$

```
증명: KL(p_S || q_θ) = -H(p_S) + NLL(θ)
-H(p_S)는 θ에 무관한 상수
따라서 KL 최소화 = NLL 최소화 ■
```

### 체인 3: KL 최소화 = CE 최소화

$$\arg\min_\theta KL(p \| q_\theta) = \arg\min_\theta CE(p, q_\theta)$$

```
증명: CE(p, q) = H(p) + KL(p||q)
H(p)는 θ에 무관한 상수
따라서 CE 최소화 = KL 최소화 ■
```

### 체인 4 (Gaussian): CE = NLL → MSE

**가정**: $q_\theta = \mathcal{N}(h_\theta(x), \sigma^2)$, $\sigma^2$ 고정

$$\text{NLL}(\theta) = \frac{n}{2\sigma^2}\text{MSE}(h_\theta) + C$$

$$\arg\min_\theta \text{NLL}(\theta) = \arg\min_\theta \text{MSE}(h_\theta) \quad \text{■}$$

### 전체 체인 통합

$$\text{MLE} \underset{(1)}{=} \arg\min \text{NLL} \underset{(2)}{=} \arg\min KL(p_S \| q) \underset{(3)}{=} \arg\min CE \underset{\text{Gaussian}}{=} \arg\min \text{MSE}$$

---

## 비교표: 분포 가정 → 손실함수

| 문제 유형 | 분포 가정 | NLL 전개 결과 | 손실함수 이름 |
|---------|----------|-------------|------------|
| 이진 분류 | Bernoulli | $-\Sigma[y_i \log q + (1-y_i)\log(1-q)]$ | Binary CE |
| 다중 분류 | Categorical | $-\Sigma \log [h(x_i)]_{y_i}$ | Cross-Entropy |
| 회귀 | Gaussian | $\frac{1}{2\sigma^2}\Sigma(y_i - h(x_i))^2$ | MSE |
| 회귀 (Robust) | Laplace | $\frac{1}{b}\Sigma|y_i - h(x_i)|$ | MAE |
| 카운트 데이터 | Poisson | $\Sigma[-y_i \log\lambda + \lambda]$ | Poisson Loss |

```
핵심 메시지:
손실함수는 "발명"하는 것이 아니라 "분포 가정 → NLL 유도"로 자동으로 나온다
새로운 문제 → 적절한 분포 가정 → NLL 전개 → 손실함수 도출
```

# PART 8. Forward KL vs Reverse KL

---

## 🟡 두 방향의 차이

**Forward KL (순방향)**: $\arg\min_q KL(p \| q)$
- p(참 분포)를 기준으로 측정
- p가 있는 곳에 q도 반드시 있어야 함 (zero-avoiding)
- **mode-covering**: p의 모든 봉우리를 커버하려 함
- **CE 최소화와 동치** → 일반적인 지도학습 손실

**Reverse KL (역방향)**: $\arg\min_q KL(q \| p)$
- q(모델)를 기준으로 측정
- p가 없는 곳에 q도 없어야 함 (zero-forcing)
- **mode-seeking**: p의 하나의 봉우리에 집중
- 변분 추론(VI)에서 사용

### 키워드 매핑 (시험 단골)

| | Forward KL: $KL(p\|q)$ | Reverse KL: $KL(q\|p)$ |
|--|------------------------|------------------------|
| 최소화 기준 | p가 기준 | q가 기준 | 
| 특성 | inclusive | exclusive |
| 영 회피 | zero-avoiding | zero-forcing |
| 행동 | mode-covering | mode-seeking |
| 비유 | "빠뜨리지 마라" | "확실한 것만" |
| 응용 | 지도학습 CE | 변분 추론 |

---

### 왜 방향이 다르면 행동이 다른가? (수식 증명)

**Forward KL**: $KL(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$

- p(x) > 0이고 q(x) ≈ 0이면: $\log(p/q) \to +\infty$ → **KL이 폭발**
- 따라서 q는 반드시 p가 있는 모든 곳을 커버해야 한다

**Reverse KL**: $KL(q\|p) = \sum_x q(x)\log\frac{q(x)}{p(x)}$

- p(x) ≈ 0이고 q(x) > 0이면: $\log(q/p) \to +\infty$ → **KL이 폭발**
- 따라서 q는 p가 0인 곳에서 반드시 0이어야 한다

# PART 10. 시험 답안 작성 템플릿 ⭐⭐⭐

---

## 표준 유도 체인 (이것을 외워라)

```
① 가정 명시:
   "Assume {(x_i, y_i)} are i.i.d., y_i|x_i ~ [분포명]"

② 목표 설정:
   "We seek θ that minimizes NLL (= maximizes MLE)"

③ Likelihood 작성:
   P(D|θ) = ∏_{i=1}^n P(y_i|x_i, θ)  ← i.i.d. 덕분에 곱으로 표현

④ Log 취하기:
   "Taking log (monotone transformation preserves argmin):"
   log P(D|θ) = Σ log P(y_i|x_i, θ) = [분포에 따라 전개]

⑤ NLL 변환:
   NLL = -log P(D|θ) = [전개 결과]

⑥ 분포에 따른 단순화:
   [Gaussian이면] = n/(2σ²)·MSE + C → arg min NLL = arg min MSE
   [Bernoulli이면] = BCE (Binary Cross-Entropy)
   [Categorical이면] = CE (Cross-Entropy)

⑦ KL 연결 (필요시):
   NLL = KL(p_S || q_θ) + H(p_S) ← H(p_S)는 상수
   따라서 arg min NLL = arg min KL(p_S || q_θ)

⑧ 결론:
   "MLE = NLL 최소화 = KL 최소화 = [분포에 따라] MSE/CE 최소화"
```

---

## 문제 유형별 답안 패턴

### 유형 1: "MSE와 NLL의 관계를 유도하라"

```
① 가정: y_i|x_i ~ N(h(x_i), σ²)  (Gaussian 노이즈)
② NLL = -Σ log N(y_i; h(x_i), σ²)
③ Gaussian PDF 대입: N(y;μ,σ²) = (1/√(2πσ²))exp(-(y-μ)²/2σ²)
④ log 전개: log N = -1/2 log(2πσ²) - (y-μ)²/(2σ²)
⑤ NLL = Σ [1/2 log(2πσ²) + (y_i - h(x_i))²/(2σ²)]
⑥ = n/2 log(2πσ²) + 1/(2σ²)·Σ(y_i - h(x_i))²
⑦ = n/(2σ²)·MSE + C   ← (C = n/2 log(2πσ²))
⑧ 결론: σ² 고정이면 arg min NLL = arg min MSE  ■
```

### 유형 2: "NLL과 KL의 관계를 증명하라"

```
① 경험적 분포 정의: p_S(x) = (1/n)Σ δ(x - x_i)
② KL(p_S || q_θ) = E_{p_S}[log(p_S/q_θ)]
③ = E_{p_S}[log p_S] - E_{p_S}[log q_θ]
④ = -H(p_S) - (1/n)Σ log q_θ(x_i)
⑤ = -H(p_S) + (1/n)NLL
⑥ H(p_S)는 θ에 무관한 상수
⑦ ∴ arg min_θ KL(p_S || q_θ) = arg min_θ NLL(θ)  ■
```

### 유형 3: "CE = KL + H를 증명하라"

```
① 정의 대입:
   KL(p||q) = Σ p(x) log(p(x)/q(x))
② log 분리:
   = Σ p(x)[log p(x) - log q(x)]
③ 항 분리:
   = Σ p(x) log p(x) - Σ p(x) log q(x)
④ 정의 대입:
   = -H(p) + CE(p, q)
⑤ 정리:
   CE(p, q) = H(p) + KL(p||q)  ■
```

### 유형 4: "MSE = NLL = KL의 전체 체인을 설명하라"

```
MLE
 = arg max P(D|θ)
 = arg max log P(D|θ)       ← log는 단조증가
 = arg min NLL(θ)            ← 부호 변환
 = arg min KL(p_S || q_θ)   ← H(p_S) 상수 제거
 = arg min CE(p, q_θ)        ← H(p) 상수 제거
 = arg min MSE(h_θ)          ← Gaussian 가정 시

각 등호의 이유:
① log는 단조증가 → argmax 유지
② 부호 변환 → argmax ↔ argmin
③ KL = -H(p_S) + NLL, H(p_S) 상수
④ CE = H(p) + KL, H(p) 상수
⑤ NLL = n/(2σ²)·MSE + C, 상수 제거
```

# PART 11. 자가 진단 질문 — 시험 전날

---

## 이것을 말로 설명할 수 있으면 A+

1. **"왜 NLL에 log를 취하는가?"**
   → 3가지 이유: 곱→합, 수치안정성, argmax 유지

2. **"Gaussian 가정에서 NLL = MSE임을 처음부터 유도하라"**
   → Gaussian PDF → log 전개 → 상수 제거 → MSE

3. **"NLL 최소화가 KL 최소화와 같은 이유를 증명하라"**
   → KL(p_S||q) = -H(p_S) + NLL, H(p_S) 상수

4. **"CE = H + KL을 유도하라"**
   → KL 정의에서 log(p/q) = log p - log q 분리

5. **"원-핫 레이블에서 CE = NLL인 이유는?"**
   → H(one-hot) = 0 → CE = 0 + KL = KL = NLL

6. **"Forward KL과 Reverse KL의 차이를 설명하라"**
   → mode-covering vs mode-seeking, zero-avoiding vs zero-forcing

7. **"왜 MSE는 회귀에, CE는 분류에 쓰는가?"**
   → 분포 가정의 차이: Gaussian → MSE, Categorical → CE

8. **"Laplace 노이즈를 가정하면 어떤 손실이 나오는가?"**
   → NLL of Laplace = MAE (Mean Absolute Error)

# 🔥 핵심 요약 — 날카로운 관점 정리

---

## 이 모든 것의 본질

> **MSE, CE, NLL, KL은 이름이 다른 하나의 실체다.**

- **시작점**: MLE — "데이터에 가장 높은 확률을 부여하는 파라미터를 찾아라"
- **수학적 구현**: NLL 최소화 (log + 부호 변환)
- **정보이론적 해석**: KL(데이터 분포 || 모델 분포) 최소화
- **분포 가정 Gaussian** → 자동으로 MSE가 나온다
- **분포 가정 Categorical** → 자동으로 CE가 나온다

## 시험에서 절대 틀리지 않으려면

**3가지를 암기하지 말고 유도하라:**

1. **Gaussian NLL → MSE**: PDF log 전개 → $-(y_i-h(x_i))^2/2\sigma^2$ + 상수
2. **NLL = KL**: $KL = -H(p_S) + NLL$, H 상수 제거
3. **CE = H + KL**: $\log(p/q) = \log p - \log q$ 분리

**이 3가지 유도를 백지에 30분 안에 쓸 수 있으면 A+**
