# PART 1. KL Divergence 정의와 직관

---

## 🟢 입문: 비유부터 시작

**백엔드 개발자 관점으로 이해하기:**

당신이 API 응답 시간을 모니터링한다고 상상하세요.

- **p(x)** = 실제 프로덕션 서버에서 측정된 응답 시간 분포 (현실)
- **q(x)** = 스테이징 서버에서 예측한 응답 시간 분포 (모델/예측)
- **KL(p||q)** = "예측(q)이 실제(p)와 얼마나 다른가?" 를 숫자 하나로 나타낸 것

완벽히 같으면 KL = 0.
스테이징과 프로덕션 응답 분포가 다를수록 KL 값이 커집니다.

**교수님이 말씀하신 것:** "p가 q랑 같으면 log(p/q) = log(1) = 0이 되죠. KL이 0이 됩니다."

---

## 🟡 중급: KL Divergence의 정의

### 이산(Discrete) 확률분포 버전

$$\text{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

### 연속(Continuous) 확률분포 버전

$$\text{KL}(p\|q) = \int p(x)\log\frac{p(x)}{q(x)}\,dx$$

---

### 수식 기호 Line-by-Line 해체

```
KL(p || q) = Σ p(x) · log[ p(x) / q(x) ]
│   │   │     │   │         │       │
│   │   │     │   │         │       └─ q(x): x가 나올 확률 (모델/예측 분포)
│   │   │     │   │         └───────── p(x): x가 나올 확률 (실제/정답 분포)
│   │   │     │   │
│   │   │     │   └─────── p(x): 가중치! "p(x)가 큰 곳을 더 중요하게 봄"
│   │   │     └─────────── Σ: 모든 x에 대해 합산 (파이썬 for문)
│   │   └─────────────────── q: 근사/예측 분포 (우리가 학습시키는 모델)
│   └─────────────────────── p: 기준/정답 분포 (실제 데이터가 따르는 분포)
└─────────────────────────── KL: Kullback-Leibler, 두 분포의 차이 측정
```

**핵심 해석:** `log(p(x)/q(x))`는 x라는 사건에 대해 p와 q가 얼마나 다른지를 측정합니다. 여기에 `p(x)`를 곱해서 더하면 → "p의 관점에서 평균적인 차이"가 됩니다.

---

## 🔴 고급: 핵심 성질

### 성질 1: 비음수성 (가장 중요!)

$$\text{KL}(p\|q) \geq 0$$

**등호 조건:** p = q 일 때만 KL = 0 (이하 Part 4, 5에서 증명)

### 성질 2: 비대칭성 (시험 자주 나옴!)

$$\text{KL}(p\|q) \neq \text{KL}(q\|p)$$

**비유:** "A가 B를 얼마나 모방하는가"와 "B가 A를 얼마나 모방하는가"는 다릅니다.
그래서 KL은 **거리(distance)가 아닌 발산(divergence)**이라고 부릅니다.

(거리라면 d(A,B) = d(B,A)여야 하는데, KL은 이를 만족하지 않음)

### 성질 3: 분해 관계

$$\text{KL}(p\|q) = \text{CE}(p,q) - H(p)$$

이 관계는 PART 8에서 완전 유도합니다.

# PART 2. 엔트로피 H(p) 완전 이해

---

## 🟢 입문: 엔트로피란?

**비유:** 날씨 예보를 생각하세요.

- **서울 겨울 날씨**: 맑음 90%, 비 10% → 예측하기 쉬움 → 불확실성 낮음 → **엔트로피 낮음**
- **서울 봄 날씨**: 맑음 50%, 비 50% → 예측하기 어려움 → 불확실성 높음 → **엔트로피 높음**

**엔트로피 = 분포의 불확실성(혼란도)**

---

## 🔴 고급: 엔트로피 수식

### 정의

$$H(p) = -\mathbb{E}_p[\log p(X)] = -\sum_x p(x)\log p(x)$$

### 수식 기호 Line-by-Line 해체

```
H(p) = -E_p[ log p(X) ]
│        │        └─── p(X): X가 나올 확률
│        └──────────── E_p[...]: p 분포에 대한 기댓값 (가중 평균)
└───────────────────── H: 엔트로피 기호 (Shannon이 정의)

풀어쓰면:
H(p) = - Σ p(x) · log p(x)
         │   │
         │   └─ log p(x): p(x)가 작을수록 큰 값 (정보량이 많음)
         └───── p(x): 가중치 (자주 나오는 사건을 더 중요하게 봄)

왜 마이너스(-)를 붙이는가?
p(x)는 0~1 사이 값 → log p(x)는 항상 음수 (또는 0)
마이너스를 붙여서 H(p) >= 0 이 되도록 만듦
```

### 엔트로피의 핵심 성질

| 상황 | 엔트로피 값 | 이유 |
|------|------------|------|
| 확정적 분포 (한 결과만 가능) | H = 0 | log(1) = 0 |
| 균등 분포 (모두 같은 확률) | H = 최대 | 가장 불확실 |
| 베르누이 p=0.5 | H = log(2) ≈ 0.693 | 최대 불확실성 |

# PART 3. 교차 엔트로피 CE(p,q)와 KL 연결

---

## 🟢 입문: 교차 엔트로피란?

**비유:** 당신은 서울 날씨 예보를 위해 두 기상 모델을 만들었습니다.

- **실제 날씨** p(x): 맑음=0.7, 비=0.3
- **모델 A** q_A(x): 맑음=0.7, 비=0.3 (정확)
- **모델 B** q_B(x): 맑음=0.4, 비=0.6 (부정확)

CE(p, q)는 "모델 q가 실제 p를 얼마나 잘 예측하는가"를 측정합니다.
q가 p에 가까울수록 CE 값이 작아집니다.

딥러닝에서 Cross-Entropy Loss가 바로 이것입니다!

---

## 🔴 고급: 교차 엔트로피 수식

### 정의

$$\text{CE}(p, q) = -\mathbb{E}_p[\log q(X)] = -\sum_x p(x)\log q(x)$$

### 수식 기호 Line-by-Line 해체

```
CE(p, q) = - Σ p(x) · log q(x)
│              │   │       │
│              │   │       └─── q(x): 모델의 예측 확률 (우리가 학습시키는 것)
│              │   └─────────── p(x): 실제 정답 분포 (레이블 데이터)
│              └─────────────── Σ: 모든 x에 대해 합산
│
└─── CE: Cross-Entropy (교차 엔트로피)

엔트로피 H(p)와의 차이:
H(p)  = - Σ p(x) · log p(x)  ← 로그 안에도 p
CE(p,q)= - Σ p(x) · log q(x)  ← 로그 안에는 q (다른 분포!)

"교차" 엔트로피라고 부르는 이유:
가중치는 p, 로그는 q → 두 분포가 "교차"됨
```

### H(p) vs CE(p,q) 비교

| | 수식 | 의미 |
|--|------|------|
| **H(p)** | −Σ p(x)log p(x) | p 자체의 불확실성 (상수) |
| **CE(p,q)** | −Σ p(x)log q(x) | q로 p를 코딩할 때의 비효율성 |

항상: CE(p,q) ≥ H(p) (같은 분포로 코딩할 때 가장 효율적)

# PART 4. KL ≥ 0 증명 — Jensen 부등식 사용 ⭐⭐⭐

---

## 🟢 입문: Jensen 부등식이 뭔가?

**중학교 수준 직관:**

f(x) = x²라는 함수를 생각하세요.

- x = 2, x = 4의 평균: (2+4)/2 = **3**
- f(3) = 9
- f(2)+f(4)의 평균: (4+16)/2 = **10**

f(평균) = 9 < 평균의 f = 10

**이것이 Jensen 부등식입니다:** 볼록(convex) 함수에서 f(E[X]) ≤ E[f(X)]

---

## 🟡 중급: Jensen 부등식 공식

$$\text{f가 볼록(convex)이면:} \quad f\left(\mathbb{E}[X]\right) \leq \mathbb{E}[f(X)]$$

```
f(E[X])  ≤  E[f(X)]
│               │
│               └─ X를 먼저 f에 통과시킨 뒤 평균
└─ 먼저 평균을 구한 뒤 f에 통과

볼록 함수 예시: x², e^x, -log(x)
오목 함수 예시: log(x), √x → 부등호 방향 반대
```

**왜 -log(x)는 볼록인가?**

d/dx [-log x] = -1/x

d²/dx² [-log x] = 1/x² > 0 (2차 미분이 양수 → 볼록)

---

## 🔴 고급: KL ≥ 0 증명 (Jensen 사용)

### 목표

$$\text{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)} \geq 0$$

### 완전 유도 (시험 답안 형식)

**[Step 1] KL을 기댓값 형태로 변환**

$$\text{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

분자 분모를 뒤집어서 음수를 앞으로 빼면:

$$= -\sum_x p(x)\log\frac{q(x)}{p(x)}$$

이것은 p 분포에 대한 기댓값이므로:

$$= -\mathbb{E}_p\!\left[\log\frac{q(X)}{p(X)}\right]$$

```
왜 부호를 뒤집는가?
log(a/b) = -log(b/a) 이므로
log(p/q) = -log(q/p)
나중에 Jensen 부등식을 적용하기 위해 이 형태로 변환
```

**[Step 2] Jensen 부등식 적용**

−log는 **볼록 함수(convex)**입니다.

볼록 함수 f에 대해 Jensen 부등식: **E[f(X)] ≥ f(E[X])**

여기서 f = −log, X = q(x)/p(x)로 놓으면:

$$-\mathbb{E}_p\!\left[\log\frac{q(X)}{p(X)}\right] \geq -\log\,\mathbb{E}_p\!\left[\frac{q(X)}{p(X)}\right]$$

```
왜 부등호 방향이 이렇게 되는가?
E[f(X)] ≥ f(E[X]) 에서
E[-log(q/p)] ≥ -log(E[q/p])
좌변 = KL(p||q)
우변 = -log(E_p[q/p])
```

**[Step 3] 우변을 계산**

$$\mathbb{E}_p\!\left[\frac{q(X)}{p(X)}\right] = \sum_x p(x) \cdot \frac{q(x)}{p(x)} = \sum_x q(x) = 1$$

```
계산 과정 세부:
Σ p(x) · q(x)/p(x)
= Σ q(x)        ← p(x)가 약분됨
= 1             ← 확률의 합 = 1 (q는 유효한 확률분포)
```

따라서:

$$-\log\,\mathbb{E}_p\!\left[\frac{q(X)}{p(X)}\right] = -\log 1 = 0$$

**[Step 4] 결론**

$$\boxed{\text{KL}(p\|q) \geq 0}$$

$$\therefore \text{KL}(p\|q) = -\mathbb{E}_p\!\left[\log\frac{q}{p}\right] \geq -\log\,\mathbb{E}_p\!\left[\frac{q}{p}\right] = -\log 1 = 0$$

### 등호 조건 (반드시 써야 함!)

Jensen 부등식에서 등호가 성립하려면:
`q(x)/p(x) = 상수 c` (모든 x에 대해)

$$\sum_x p(x) = 1 \text{ 이고 } \sum_x q(x) = 1 \text{ 이므로 } c = 1$$

$$\therefore \text{KL}(p\|q) = 0 \iff p = q \quad \square$$

# PART 5. KL ≥ 0 증명 — log t ≤ t−1 사용 (대안 증명) ⭐⭐⭐

---

## 🟢 입문: log t ≤ t−1 이 뭔가?

**중학교 수준 직관:**

log(t) 함수와 (t−1) 직선을 그래프로 그려보면,
모든 t > 0에서 log(t) 직선이 (t−1) 아래에 있습니다.

- t = 1: log(1) = 0, (1−1) = 0 → **등호 성립**
- t = 2: log(2) ≈ 0.693, (2−1) = 1 → log(2) < 1 ✓
- t = 0.5: log(0.5) ≈ −0.693, (0.5−1) = −0.5 → −0.693 < −0.5 ✓

**보조 정리:** $\log t \leq t - 1$ (모든 t > 0에서, 등호: t = 1)

---

## 🔴 고급: KL ≥ 0 증명 (log t ≤ t−1 사용)

### 목표

$$\text{KL}(p\|q) \geq 0$$

### 완전 유도

**[Step 1] −KL을 만들어서 ≤ 0임을 보인다**

$$-\text{KL}(p\|q) = -\sum_x p(x)\log\frac{p(x)}{q(x)}$$

$$= \sum_x p(x)\log\frac{q(x)}{p(x)}$$

```
log(p/q) = -log(q/p) 변환 사용
-KL을 증명하면 KL의 부호를 뒤집어서 KL >= 0을 보일 수 있음
```

**[Step 2] 보조 정리 log t ≤ t−1 적용**

t = q(x)/p(x)로 놓으면:

$$\log\frac{q(x)}{p(x)} \leq \frac{q(x)}{p(x)} - 1$$

```
log t ≤ t - 1 에서
t = q(x)/p(x) 로 대입:
log(q(x)/p(x)) ≤ (q(x)/p(x)) - 1
```

**[Step 3] 양변에 p(x)를 곱하고 합산**

$$p(x)\log\frac{q(x)}{p(x)} \leq p(x)\left(\frac{q(x)}{p(x)} - 1\right) = q(x) - p(x)$$

모든 x에 대해 합산:

$$\sum_x p(x)\log\frac{q(x)}{p(x)} \leq \sum_x \left[q(x) - p(x)\right]$$

$$= \sum_x q(x) - \sum_x p(x) = 1 - 1 = 0$$

```
Σ q(x) = 1   (q는 유효한 확률분포)
Σ p(x) = 1   (p는 유효한 확률분포)
1 - 1 = 0
```

**[Step 4] 결론**

$$-\text{KL}(p\|q) \leq 0$$

$$\boxed{\therefore \text{KL}(p\|q) \geq 0} \quad \square$$

### 등호 조건

$\log t = t - 1$이 성립하는 조건: **t = 1**

즉 q(x)/p(x) = 1, 모든 x에서 → **p = q 일 때만 등호**

---

### 두 증명 방법 비교

| | Jensen 부등식 | log t ≤ t−1 |
|--|--------------|-------------|
| 핵심 도구 | 볼록 함수 성질 | 부등식 직접 적용 |
| 단계 수 | 4단계 | 4단계 |
| 직관성 | 기댓값 형태로 변환 후 적용 | 더 직접적 계산 |
| 시험에서 | 두 방법 중 하나 선택 OK | 두 방법 중 하나 선택 OK |
| **등호 조건** | **p = q (반드시 명시!)** | **p = q (반드시 명시!)** |

# PART 6. KL = CE − H 관계 증명 ⭐⭐⭐

---

## 🟢 입문: 왜 이 관계가 중요한가?

이 관계가 딥러닝 전체의 이론적 토대입니다.

- 모델을 학습할 때 우리는 KL을 줄이고 싶다
- 하지만 H(p)는 데이터의 고유한 불확실성 → 우리가 바꿀 수 없는 상수
- 따라서 **KL을 줄이는 것 = CE를 줄이는 것**
- 이것이 딥러닝에서 Cross-Entropy Loss를 쓰는 수학적 이유!

---

## 🔴 고급: KL = CE − H 유도

### 완전 유도

$$\text{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

**log의 분수 분리:**

$$\log\frac{p(x)}{q(x)} = \log p(x) - \log q(x)$$

따라서:

$$\text{KL}(p\|q) = \sum_x p(x)\left[\log p(x) - \log q(x)\right]$$

$$= \sum_x p(x)\log p(x) - \sum_x p(x)\log q(x)$$

```
항을 둘로 분리:
첫 번째 항: Σ p(x) log p(x) = -H(p) (엔트로피의 정의에 마이너스 붙인 것)
두 번째 항: -Σ p(x) log q(x) = CE(p, q) (교차 엔트로피의 정의)
```

**각 항의 정의 대입:**

$$= -H(p) + \text{CE}(p,q)$$

정리하면:

$$\boxed{\text{KL}(p\|q) = \text{CE}(p,q) - H(p)}$$

또는 동치로:

$$\boxed{\text{CE}(p,q) = H(p) + \text{KL}(p\|q)}$$

---

### 시험 핵심: 왜 CE 최소화 = KL 최소화인가?

**[핵심 논리]**

$$\text{CE}(p,q) = \underbrace{H(p)}_{\text{상수 (데이터 고정)}} + \underbrace{\text{KL}(p\|q)}_{\text{q에 따라 변함}}$$

```
H(p): 실제 데이터 분포 p의 엔트로피
      → 데이터가 고정되면 p도 고정 → H(p)도 고정 → 상수!
      → q를 바꿔도 H(p)는 변하지 않음

KL(p||q): q(모델)에 의존
          → 모델을 학습시키면 q가 바뀜 → KL도 바뀜
```

따라서 q에 대해 최소화할 때:

$$\arg\min_q \text{CE}(p,q) = \arg\min_q \left[H(p) + \text{KL}(p\|q)\right] = \arg\min_q \text{KL}(p\|q)$$

$$\boxed{\text{CE 최소화} \Leftrightarrow \text{KL 최소화} \Leftrightarrow \text{MLE}}$$

# PART 7. Gaussian KL 완전 유도 ⭐⭐⭐

---

## 🟢 입문: 왜 Gaussian KL을 아는가?

시험 문제 직접 출제:
> "P ~ N(μ₁, 1), Q ~ N(μ₂, 1)일 때 KL(P||Q) 구하기"

이 계산을 위해서는 일반 Gaussian KL 공식을 유도하고, 특수 경우를 적용할 수 있어야 합니다.

---

## 🔴 고급: 일변량 Gaussian KL 완전 유도

### 설정

$$P = \mathcal{N}(\mu_1, \sigma_1^2), \quad Q = \mathcal{N}(\mu_2, \sigma_2^2)$$

**Gaussian PDF (확률밀도함수):**

$$p(x) = \frac{1}{\sqrt{2\pi\sigma_1^2}} \exp\!\left(-\frac{(x-\mu_1)^2}{2\sigma_1^2}\right)$$

$$q(x) = \frac{1}{\sqrt{2\pi\sigma_2^2}} \exp\!\left(-\frac{(x-\mu_2)^2}{2\sigma_2^2}\right)$$

```
각 기호 해설:
1/√(2πσ²): 정규화 상수 (PDF 전체 면적 = 1이 되게 조정)
exp(-...): e^{-...} (지수 함수)
(x-μ)²: x와 평균의 거리의 제곱
2σ²: 분산의 2배 (분모에 있음 → 분산이 클수록 더 완만한 모양)
```

---

### Step 1: log(p/q) 계산

$$\log\frac{p(x)}{q(x)} = \log p(x) - \log q(x)$$

**log p(x) 계산:**

$$\log p(x) = \log\frac{1}{\sqrt{2\pi\sigma_1^2}} - \frac{(x-\mu_1)^2}{2\sigma_1^2}$$

$$= -\frac{1}{2}\log(2\pi\sigma_1^2) - \frac{(x-\mu_1)^2}{2\sigma_1^2}$$

```
log(1/A) = -log(A) 사용
log(√A) = (1/2)log(A) 사용
log(exp(B)) = B 사용
```

**log q(x) 계산:**

$$\log q(x) = -\frac{1}{2}\log(2\pi\sigma_2^2) - \frac{(x-\mu_2)^2}{2\sigma_2^2}$$

**log(p/q) = log p − log q:**

$$\log\frac{p(x)}{q(x)} = \left[-\frac{1}{2}\log(2\pi\sigma_1^2) - \frac{(x-\mu_1)^2}{2\sigma_1^2}\right] - \left[-\frac{1}{2}\log(2\pi\sigma_2^2) - \frac{(x-\mu_2)^2}{2\sigma_2^2}\right]$$

$$= \frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{(x-\mu_2)^2}{2\sigma_2^2} - \frac{(x-\mu_1)^2}{2\sigma_1^2}$$

```
항 정리:
-log(σ₁²) + log(σ₂²) = log(σ₂²/σ₁²) = log(σ₂/σ₁)² = 2·log(σ₂/σ₁)
따라서 (1/2)·log(σ₂²/σ₁²) = log(σ₂/σ₁)
```

---

### Step 2: KL 정의에 대입 → 기댓값 계산

$$\text{KL}(P\|Q) = \mathbb{E}_P\!\left[\log\frac{p(X)}{q(X)}\right] = \int p(x)\log\frac{p(x)}{q(x)}\,dx$$

Step 1 결과 대입:

$$= \mathbb{E}_P\!\left[\frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{(X-\mu_2)^2}{2\sigma_2^2} - \frac{(X-\mu_1)^2}{2\sigma_1^2}\right]$$

**기댓값 분리 (선형성 이용):**

$$= \frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{1}{2\sigma_2^2}\mathbb{E}_P[(X-\mu_2)^2] - \frac{1}{2\sigma_1^2}\mathbb{E}_P[(X-\mu_1)^2]$$

```
E[상수] = 상수 → (1/2)log(σ₂²/σ₁²) 항은 그대로
E[X-μ₁)²] = σ₁² (P의 분산 = σ₁²이 P의 기댓값 아래서 계산될 때)
E[X-μ₂)²]는 좀 더 계산이 필요 (평균이 μ₁인 분포에서 μ₂와의 거리)
```

---

### Step 3: 핵심 기댓값 계산

**항 ③: E_P[(X − μ₁)²]**

X ~ P = N(μ₁, σ₁²)이므로:

$$\mathbb{E}_P[(X-\mu_1)^2] = \sigma_1^2 \quad \text{(분산의 정의)}$$

**항 ②: E_P[(X − μ₂)²]**

이것은 P 분포(평균 μ₁)에서 μ₂와의 평균 제곱 거리입니다.

수학 트릭: μ₂를 μ₁로 쪼갭니다.

$$(X - \mu_2) = (X - \mu_1) + (\mu_1 - \mu_2)$$

양변을 제곱:

$$(X-\mu_2)^2 = (X-\mu_1)^2 + 2(X-\mu_1)(\mu_1-\mu_2) + (\mu_1-\mu_2)^2$$

기댓값:

$$\mathbb{E}_P[(X-\mu_2)^2] = \mathbb{E}_P[(X-\mu_1)^2] + 2(\mu_1-\mu_2)\underbrace{\mathbb{E}_P[(X-\mu_1)]}_{=0} + (\mu_1-\mu_2)^2$$

```
E_P[X - μ₁] = E_P[X] - μ₁ = μ₁ - μ₁ = 0
(P의 평균이 μ₁이므로 E_P[X] = μ₁)
```

따라서:

$$\mathbb{E}_P[(X-\mu_2)^2] = \sigma_1^2 + (\mu_1-\mu_2)^2$$

---

### Step 4: 모두 대입하여 최종 공식 도출

$$\text{KL}(P\|Q) = \frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{\sigma_1^2}{2\sigma_1^2}$$

$$= \frac{1}{2}\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

**log 항 변환:** $\log\frac{\sigma_2^2}{\sigma_1^2} = 2\log\frac{\sigma_2}{\sigma_1}$

$$\boxed{\text{KL}(\mathcal{N}(\mu_1,\sigma_1^2)\|\mathcal{N}(\mu_2,\sigma_2^2)) = \frac{1}{2}\left[2\log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2}{\sigma_2^2} + \frac{(\mu_1-\mu_2)^2}{\sigma_2^2} - 1\right]}$$

---

## 🔴 특수 경우: 시험에 가장 많이 나오는 케이스

### 특수 경우 1: **분산 동일 (σ₁ = σ₂ = σ)**

$$\text{KL}(\mathcal{N}(\mu_1,\sigma^2)\|\mathcal{N}(\mu_2,\sigma^2))$$

공식에 σ₁ = σ₂ = σ 대입:

$$= \frac{1}{2}\left[2\log\frac{\sigma}{\sigma} + \frac{\sigma^2}{\sigma^2} + \frac{(\mu_1-\mu_2)^2}{\sigma^2} - 1\right]$$

$$= \frac{1}{2}\left[2\cdot 0 + 1 + \frac{(\mu_1-\mu_2)^2}{\sigma^2} - 1\right]$$

$$\boxed{\text{KL} = \frac{(\mu_1-\mu_2)^2}{2\sigma^2}}$$

```
항별 계산:
2·log(σ/σ) = 2·log(1) = 2·0 = 0
σ²/σ² = 1
(μ₁-μ₂)²/σ² = 그대로
1 - 1 = 0 이므로 남는 것: (1/2)·(μ₁-μ₂)²/σ²
```

**핵심 의미:** 분산이 같으면 KL은 평균 차이의 제곱에 비례!

$$\text{KL} \propto (\mu_1 - \mu_2)^2 = \text{MSE}$$

---

### 특수 경우 2: **시험 직출 — P~N(μ₁,1), Q~N(μ₂,1)**

σ₁ = σ₂ = 1 대입:

$$= \frac{1}{2}\left[2\log\frac{1}{1} + \frac{1}{1} + \frac{(\mu_1-\mu_2)^2}{1} - 1\right]$$

$$= \frac{1}{2}\left[0 + 1 + (\mu_1-\mu_2)^2 - 1\right]$$

$$\boxed{\text{KL}(\mathcal{N}(\mu_1,1)\|\mathcal{N}(\mu_2,1)) = \frac{(\mu_1-\mu_2)^2}{2}}$$

**이것이 핵심:** 표준 분산(σ=1)에서 KL = (평균차)²/2

---

### 각 항의 의미 정리표

| 항 | 의미 |
|----|------|
| $2\log(\sigma_2/\sigma_1)$ | 분산 크기 비율의 차이 |
| $\sigma_1^2/\sigma_2^2$ | 분산의 형태 차이 |
| $(\mu_1-\mu_2)^2/\sigma_2^2$ | 평균 차이 (Q의 분산으로 정규화) |
| $-1$ | 정규화 상수 |

# PART 8. Forward KL vs Reverse KL (시험 빈출 개념)

---

## 🟡 중급: 두 방향의 차이

| | Forward KL: KL(p\|\|q) | Reverse KL: KL(q\|\|p) |
|--|------------------------|------------------------|
| **최소화 대상** | q를 p에 맞춤 | q를 p에 맞춤 |
| **행동 패턴** | **Mode-Covering** (zero-avoiding) | **Mode-Seeking** (zero-forcing) |
| **p(x)>0, q(x)≈0이면** | 큰 페널티 → q가 모든 봉우리 커버 | 페널티 작음 |
| **p(x)≈0, q(x)>0이면** | 페널티 작음 | 큰 페널티 → q가 p없는 곳 피함 |
| **응용** | MLE, 딥러닝 CE Loss | 변분 추론(VI), GAN |

---

## 🔴 고급: 왜 이런 행동이 나오는가?

### Forward KL: Mode-Covering 이유

$$\text{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

p(x) > 0이고 q(x) ≈ 0이면:

$$\log\frac{p(x)}{q(x)} = \log\frac{\text{양수}}{\text{아주 작은 수}} \to +\infty$$

→ p(x) > 0인 모든 곳에서 q(x) > 0이어야 함

→ **q가 p가 존재하는 모든 곳을 커버해야 한다** (Mode-Covering)

### Reverse KL: Mode-Seeking 이유

$$\text{KL}(q\|p) = \sum_x q(x)\log\frac{q(x)}{p(x)}$$

q(x) > 0이고 p(x) ≈ 0이면:

$$\log\frac{q(x)}{p(x)} = \log\frac{\text{양수}}{\text{아주 작은 수}} \to +\infty$$

→ p(x) ≈ 0인 곳에서 q(x) ≈ 0이어야 함

→ **q가 p가 없는 곳을 반드시 피해야 한다** → 하나의 봉우리에만 집중

# PART 9. 수치 계산 예제 풀이

---

## 예제 1: 이산 분포 KL 계산

**문제:** p = (1/2, 1/4, 1/4), q = (1/3, 1/3, 1/3)일 때 KL(p||q) 구하기

**풀이:**

$$\text{KL}(p\|q) = \sum_{i=1}^{3} p(x_i)\log\frac{p(x_i)}{q(x_i)}$$

각 항 계산:

$$= p(x_1)\log\frac{p(x_1)}{q(x_1)} + p(x_2)\log\frac{p(x_2)}{q(x_2)} + p(x_3)\log\frac{p(x_3)}{q(x_3)}$$

$$= \frac{1}{2}\log\frac{1/2}{1/3} + \frac{1}{4}\log\frac{1/4}{1/3} + \frac{1}{4}\log\frac{1/4}{1/3}$$

$$= \frac{1}{2}\log\frac{3}{2} + \frac{1}{4}\log\frac{3}{4} + \frac{1}{4}\log\frac{3}{4}$$

$$= \frac{1}{2}\log\frac{3}{2} + \frac{1}{2}\log\frac{3}{4}$$

$$= \frac{1}{2}\left(\log\frac{3}{2} + \log\frac{3}{4}\right)$$

**log 법칙 적용:** log(A) + log(B) = log(A·B)

$$= \frac{1}{2}\log\left(\frac{3}{2} \times \frac{3}{4}\right) = \frac{1}{2}\log\frac{9}{8}$$

**검증:** log(9/8) > 0 (9/8 > 1이므로) → KL > 0 ✓ (p ≠ q이므로 당연)

---

## 예제 2: 시험 직출 — P~N(μ₁,1), Q~N(μ₂,1), 구체적 수치 대입

**문제:** μ₁ = 2, μ₂ = 0일 때 KL(P||Q) 구하기

**풀이:**

Part 7 특수 경우 2의 결과 사용:

$$\text{KL}(\mathcal{N}(\mu_1,1)\|\mathcal{N}(\mu_2,1)) = \frac{(\mu_1-\mu_2)^2}{2}$$

대입:

$$= \frac{(2-0)^2}{2} = \frac{4}{2} = 2$$

**검증:** μ₁ = μ₂ = 0이면 KL = 0/2 = 0 ✓ (같은 분포면 KL=0)

---

## 예제 3: 비대칭성 확인

**문제:** P~N(2,1), Q~N(0,1)일 때 KL(P||Q)와 KL(Q||P) 비교

**KL(P||Q):**

$$\text{KL}(P\|Q) = \frac{(2-0)^2}{2} = 2$$

**KL(Q||P):**

$$\text{KL}(Q\|P) = \frac{(0-2)^2}{2} = \frac{4}{2} = 2$$

**결과:** 이 특수 경우(σ₁=σ₂=1)에서는 KL(P||Q) = KL(Q||P) = 2

**중요 주의:** 이것은 분산이 같은 특수 경우! 일반적으로 KL(p||q) ≠ KL(q||p)

일반 Gaussian에서 σ₁ ≠ σ₂이면 비대칭이 됩니다:

**예시:** P~N(0,1), Q~N(0,4) (σ₁=1, σ₂=2, μ₁=μ₂=0)

$$\text{KL}(P\|Q) = \frac{1}{2}\left[2\log\frac{2}{1} + \frac{1}{4} + 0 - 1\right] = \frac{1}{2}\left[2\log 2 - \frac{3}{4}\right]$$

$$\text{KL}(Q\|P) = \frac{1}{2}\left[2\log\frac{1}{2} + \frac{4}{1} + 0 - 1\right] = \frac{1}{2}\left[-2\log 2 + 3\right]$$

→ KL(P||Q) ≠ KL(Q||P) 확인 ✓

```
[등호 조건 반드시 명시!]
"등호는 p(x) = q(x) (모든 x에 대해)일 때만 성립한다. □"
```

## 표준 답안 형식 — Gaussian KL 계산

```
[설정 명시]
P = N(μ₁, σ₁²), Q = N(μ₂, σ₂²)로 설정한다.

[공식 적용 or 유도]

= (1/2)[0 + 1 + (μ₁-μ₂)² - 1]
= (μ₁-μ₂)² / 2

[결론]
∴ KL(P||Q) = (μ₁-μ₂)² / 2
```

# PART 11. 핵심 요약 — 시험 전날 복습용

---

## 모든 공식 한 곳에

| 이름 | 공식 | 조건/비고 |
|------|------|---------|
| **KL 정의 (이산)** | KL(p\|\|q) = Σ p(x)·log(p(x)/q(x)) | |
| **KL 정의 (연속)** | KL(p\|\|q) = ∫ p(x)·log(p(x)/q(x))dx | |
| **비음수성** | KL(p\|\|q) >= 0 | 등호: p=q |
| **CE 분해** | CE(p,q) = H(p) + KL(p\|\|q) | |
| **KL = CE - H** | KL(p\|\|q) = CE(p,q) - H(p) | |
| **Gaussian KL (일반)** | (1/2)[2log(σ₂/σ₁) + σ₁²/σ₂² + (μ₁-μ₂)²/σ₂² - 1] | |
| **Gaussian KL (σ₁=σ₂=σ)** | (μ₁-μ₂)² / (2σ²) | |
| **Gaussian KL (σ₁=σ₂=1)** | (μ₁-μ₂)² / 2 | 시험 직출! |
| **KL vs MSE** | Gaussian 동분산 → KL ∝ MSE | |
| **Forward KL** | KL(p\|\|q) 최소화 → mode-covering | CE 최소화 = MLE |
| **Reverse KL** | KL(q\|\|p) 최소화 → mode-seeking | 변분 추론 |

---

## 연결 관계 지도

```
[정보 이론]
엔트로피 H(p) = -E_p[log p(X)]
         │
         │ + KL
         ▼
교차 엔트로피 CE(p,q) = H(p) + KL(p||q)
         │
         │ H(p) = 상수 (데이터 고정)
         ▼
[딥러닝]
CE 최소화 = KL 최소화 = MLE 최대화
         │
         │ Gaussian 분포 가정
         ▼
KL ∝ MSE (분산 동일한 경우)
         │
         │ Bernoulli 분포 가정
         ▼
CE = Binary Cross-Entropy Loss

[비대칭성]
Forward KL (p||q):  mode-covering  → 딥러닝 분류 학습
Reverse KL (q||p):  mode-seeking   → 변분 추론(VAE)
```

---

## 증명 키워드 체크리스트 (시험 답안 필수 포함)

### KL >= 0 증명 시 반드시 포함:

- [ ] **Jensen 경로**: "-log는 볼록 함수" → 젠센 적용 → E[q/p] = 1 → -log(1) = 0
- [ ] **log t 경로**: "log t ≤ t-1" → -KL ≤ 0 → KL ≥ 0
- [ ] **등호 조건**: "p = q일 때만 KL = 0" (반드시 명시!)
- [ ] **결론 기호**: □ 또는 QED

### Gaussian KL 계산 시 반드시 포함:

- [ ] 설정: P = N(μ₁,σ₁²), Q = N(μ₂,σ₂²) 명시
- [ ] 공식 적용 또는 유도 과정
- [ ] 특수 조건(σ₁=σ₂=1) 대입 단계 명시
- [ ] 최종 답: KL = (μ₁-μ₂)²/2

```
[KL Divergence 전체 연결]

정의: KL(p||q) = Σ p(x)·log(p(x)/q(x))
         │
         ├─────────────────────────────────────────────────
         │ 성질 1: 비음수성 증명
         │    방법 A: Jensen 부등식
         │    KL = E_p[-log(q/p)] ≥ -log(E_p[q/p]) = -log(1) = 0
         │
         │    방법 B: log t ≤ t-1
         │    -KL = Σ p(x)·log(q/p) ≤ Σ(q(x)-p(x)) = 1-1 = 0
         │    ∴ KL ≥ 0
         │
         ├─────────────────────────────────────────────────
         │ 성질 2: 비대칭성
         │    KL(p||q) ≠ KL(q||p) (일반적으로)
         │    ↓ 방향에 따라
         │    Forward: mode-covering (CE Loss)
         │    Reverse: mode-seeking  (VI/ELBO)
         │
         ├─────────────────────────────────────────────────
         │ 분해 관계
         │    KL(p||q) = CE(p,q) - H(p)
         │    ↓ H(p)가 상수이므로
         │    CE 최소화 ⟺ KL 최소화 ⟺ MLE
         │
         └─────────────────────────────────────────────────
           Gaussian 특수 경우
               σ₁=σ₂: KL = (μ₁-μ₂)²/(2σ²)
               σ₁=σ₂=1: KL = (μ₁-μ₂)²/2
               → KL ∝ MSE (분산 동일)
               → CE-NLL-Gaussian-MSE 등가 연결
```
