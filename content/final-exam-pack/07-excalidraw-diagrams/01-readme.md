## 🖼️ 어떻게 보나?

### 방법 1. Excalidraw 웹 (가장 쉬움)
1. https://excalidraw.com/ 접속.
2. 왼쪽 상단 햄버거 메뉴 → **Open** → 위 `.excalidraw` 파일 선택.
3. 마우스 휠로 줌, 드래그로 이동, 더블클릭으로 텍스트 편집.

### 방법 2. VS Code 확장
- 확장 프로그램에서 "Excalidraw" 설치.
- 파일을 VS Code에서 더블클릭하면 바로 편집/뷰 가능.

### 방법 3. PNG/SVG 내보내기
- Excalidraw 웹에서 파일 연 뒤 **Export image** → PNG/SVG 저장.
- 인쇄용으로 좋다.

## 🎯 다이어그램 읽는 법

### 01. 커리큘럼 로드맵
- **왼쪽 수직선**이 학습 진행 축. 위에서 아래로.
- **5개 색깔 마커** = 5개 Stage. 각 색이 의미를 가짐:
  - 🟠 주황 (Start): Stage 1 (수학 언어)
  - 🔵 파랑 (Primary): Stage 2 (도구)
  - 🟣 보라 (AI): Stage 3 (확률)
  - 🟢 초록 (Success): Stage 4 (본 게임)
  - 🟡 노랑 (Decision): Stage 5 (검증)
- 오른쪽 두 박스: **도달 목표 체크리스트** + **6대 학습 원칙**.

### 02. MAP 동치 변환
- 가로 흐름 → 세로 꺾임으로 5단계가 하나의 **변환 파이프라인**.
- 각 화살표 옆에 **변환 이름**(Bayes 적용, log, 부호 뒤집기, 명명).
- 마지막 초록 박스가 결론. 굵은 화살표·테두리로 강조.
- 왼쪽 컬럼: **사전분포에 따른 정규화 매핑** (Gaussian/Laplace/Uniform).
- 가운데: **3개 핵심 도구**(Bayes·log 단조성·부호반전) — 이것만 알면 5단계가 굴러간다.

### 03. Softmax + CE 미분
- **Part A (왼쪽)**: 두 case 자코비안을 fan-in 패턴으로 합쳐 `ŷᵢ(δᵢⱼ-ŷⱼ)` 한 줄.
- **Part B (오른쪽)**: 체인룰 5단계가 **수직 timeline + 점**으로 흐름.
- 양쪽 끝의 굵은 초록 박스 = 핵심 결과.
- 하단 노란 박스: 직관 4줄 (BCE 일반화, 잔차 신호, 핵심 트릭, 백지 연습 권장).

## 🔧 직접 편집하기

`.excalidraw` 는 **사람이 읽을 수 있는 JSON**이다. 텍스트 에디터로 열면 모든 요소(`elements` 배열)와 좌표·색·텍스트를 볼 수 있다. 색은 모두 일관된 팔레트:

| 의미 | Fill | Stroke |
|---|---|---|
| Primary/Neutral | `#3b82f6` / `#dbeafe` | `#1e3a5f` |
| Start/Trigger | `#fed7aa` | `#c2410c` |
| End/Success | `#a7f3d0` | `#047857` |
| Decision | `#fef3c7` | `#b45309` |
| AI/사전분포 | `#ddd6fe` | `#6d28d9` |

`fontFamily: 3` 은 손글씨 풍 폰트. 한글 폰트는 시스템 기본을 사용.
