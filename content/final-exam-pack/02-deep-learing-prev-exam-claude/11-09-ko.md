## 문제 1. 확률 분포 (20점)

### (a) [5점] 균등 분포 (Uniform Distribution): 평균과 분산

$X \sim \text{Uniform}[a, b]$라고 하자.

**기댓값의 정의로부터** $E[X]$와 $\text{Var}[X]$를 유도하시오.

즉, 다음에서 출발하시오:

$$E[X] = \int_{-\infty}^{\infty} x \, f(x) \, dx$$

여기서 $f(x)$는 균등 분포의 확률 밀도 함수(PDF)이다. 모든 적분 과정을 보이시오.

---

### (b) [5점] 표준 정규 분포 (Standard Normal Distribution): 모멘트

$X \sim N(0, 1)$이라고 하자.

**(i)** 모든 양의 정수 $n$에 대해 $E[X^{2n-1}] = 0$임을 보이시오.

**(ii)** $E[X^{2n}] = (2n-1)!!$임을 보이시오. 여기서 $(2n-1)!! = 1 \cdot 3 \cdot 5 \cdots (2n-1)$이다.

> **힌트:** 부분 적분을 재귀적으로 사용하시오. 다음 식에서 시작할 것:
> $$E[X^{2n}] = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} x^{2n} e^{-x^2/2} \, dx$$
> 그리고 $u = x^{2n-1}$, $dv = x \, e^{-x^2/2} dx$로 둘 것.

---

### (c) [5점] 푸아송 분포 (Poisson Distribution): 평균과 분산

$X \sim \text{Poisson}(\lambda)$라고 하자.

**정의로부터** $E[X]$와 $\text{Var}[X]$를 유도하시오.

즉, 다음에서 출발하시오:

$$E[X] = \sum_{k=0}^{\infty} k \cdot P(X = k) = \sum_{k=0}^{\infty} k \cdot \frac{\lambda^k e^{-\lambda}}{k!}$$

모든 단계를 보이시오. $\text{Var}[X]$를 구할 때, $\text{Var}[X] = E[X^2] - (E[X])^2$을 사용해도 무방함.

---

### (d) [5점] 분포 비교 표

각 분포의 **평균(mean)**과 **분산(variance)**으로 아래 표를 완성하시오:

| 분포 (Distribution) | $E[X]$ | $\text{Var}[X]$ |
|---|---|---|
| $\text{Bernoulli}(p)$ | | |
| $\text{Binomial}(n, p)$ | | |
| $\text{Poisson}(\lambda)$ | | |
| $\text{Uniform}[a, b]$ | | |
| $N(\mu, \sigma^2)$ | | |

그런 다음 답하시오: **어떤 분포에서 $E[X] = \text{Var}[X]$가 성립하는가?** 근거를 들어 설명하시오.

## 문제 2. 최대 우도 추정(MLE) / 최대 사후 확률 추정(MAP) / 베이지안 추정 (25점)

**설정:** 동전을 독립적으로 $n$번 던져 앞면이 $k$번 나왔다. $\theta = P(\text{앞면})$이라고 하자.

### (a) [5점] 최대 우도 추정 (MLE)

i.i.d. 베르누이 시행(Bernoulli trials)을 가정하고 우도 함수(likelihood function) $L(\theta)$를 작성하시오.

MLE 추정량 $\hat{\theta}_{ML}$을 유도하시오.

유도 과정 중 **어디에서 i.i.d. 가정을 사용하는지 명확히 밝히시오**.

---

### (b) [5점] 대칭적 사전 확률을 갖는 MAP

이제 사전 확률(prior)이 $p(\theta) \propto \theta(1 - \theta)$라고 가정하자.

**(i)** MAP 추정량 $\hat{\theta}_{MAP}$를 유도하시오.

**(ii)** $n = 3, k = 3$일 때 다음을 보이시오:

$$\hat{\theta}_{ML} = 1 \quad \text{but} \quad \hat{\theta}_{MAP} = \frac{4}{5}$$

**(iii)** 이 경우 왜 MAP가 더 합리적인 추정치를 제공하는지 설명하시오.

---

### (c) [5점] 일반화된 대칭적 사전 확률

사전 확률을 $m > 0$에 대해 $p(\theta) \propto \theta^m (1 - \theta)^m$로 일반화하자.

**(i)** $k, n, m$의 함수로 $\hat{\theta}_{MAP}$를 유도하시오.

**(ii)** $m \to \infty$일 때 $\hat{\theta}_{MAP}$는 어떻게 되는가? 이 결과를 해석하시오.

---

### (d) [5점] 비대칭적 사전 확률

이제 비대칭적 사전 확률 $p(\theta) \propto \theta^m$을 고려하자.

**(i)** $\hat{\theta}_{MAP}$를 유도하시오.

**(ii)** 이 결과를 (c)번 문항과 비교하시오. 사전 확률의 비대칭성이 추정치에 어떤 영향을 미치는가?

---

### (e) [5점] 미분 불가능한 사전 확률

다음과 같은 사전 확률을 고려하자:

$$p(\theta) = 2|\theta - \tfrac{1}{2}| \quad \text{for } \theta \in [0, 1]$$

이 사전 확률은 $\theta = \tfrac{1}{2}$에서 **미분 불가능(NOT differentiable)**하다.

$n = 4, k = 2$일 때 $\hat{\theta}_{MAP}$를 구하시오.

> **참고:** 반드시 다음 사항들을 확인해야 함:
> 1. 구간 $(0, \tfrac{1}{2})$과 $(\tfrac{1}{2}, 1)$ 각각에서의 내부 임계점(interior critical points)
> 2. 미분 불가능 지점 $\theta = \tfrac{1}{2}$
> 3. 경계 지점 $\theta = 0$ 및 $\theta = 1$

## 문제 3. 손실 함수 (Loss Functions) 및 정보 이론 (Information Theory) (20점)

### (a) [7점] 가우시안 노이즈 모델과 거시 오차(MSE)

다음 가정에서 출발하여:

$$y_i = h_{\mathbf{w}}(\mathbf{x}_i) + \varepsilon, \quad \varepsilon \sim N(0, \sigma^2)$$

**음의 로그 우도(Negative Log-Likelihood, NLL)**를 최소화하는 것이 **평균 제곱 오차(MSE)**를 최소화하는 것과 동치임을 유도하시오.

각 단계별로 명확한 근거를 서술하시오:
- 어디에서 i.i.d. 가정을 사용하는가?
- 어디에서 로그 변환을 적용하는가?
- 어떤 항이 $\mathbf{w}$에 대해 상수(constant) 취급되는가?

---

### (b) [6점] 크로스 엔트로피 분해

**(i)** 다음을 증명하시오:

$$CE(p, q) = H(p) + D_{KL}(p \| q)$$

여기서 $CE$는 크로스 엔트로피, $H$는 엔트로피, $D_{KL}$은 KL 발산(KL divergence)이다.

**(ii)** **원-핫 레이블(one-hot labels)**에 대해 (즉, $p$가 원-핫 벡터인 경우) 다음이 성립함을 보이시오:

$$CE = D_{KL} = NLL$$

필요한 모든 가정을 명시하시오.

---

### (c) [7점] 동치의 대연쇄

다음의 완전한 관계식을 증명하시오:

$$\text{MLE} = \arg\min_{\mathbf{w}} \text{NLL} = \arg\min_{\mathbf{w}} CE = \arg\min_{\mathbf{w}} D_{KL}(p \| q_{\mathbf{w}})$$

각각의 "$=$" 기호에 대해 그에 대한 증명 또는 근거를 제시하시오.

그리고 답하시오: **왜 $H(p)$는 모델 파라미터 $\mathbf{w}$에 대해 상수인가?**

## 문제 4. KL 발산 (KL Divergence) (15점)

### (a) [5점] KL 발산의 비음성 (Non-Negativity)

**옌센 부등식(Jensen's inequality)**을 사용하여 $D_{KL}(p \| q) \geq 0$임을 증명하시오.

- 옌센 부등식을 적용하기 전에 그것을 명확히 명시할 것.
- **등호 성립 조건**을 명시할 것: 어떤 경우에 $D_{KL}(p \| q) = 0$이 되는가?

---

### (b) [5점] 가우시안 간의 KL 발산

두 분포가 **동일한 분산** $\sigma^2$을 공유할 때, $D_{KL}\big(N(\mu_1, \sigma^2) \| N(\mu_2, \sigma^2)\big)$를 계산하시오.

이것이 다음과 같이 단순화됨을 보이시오:

$$D_{KL} = \frac{(\mu_1 - \mu_2)^2}{2\sigma^2}$$

> 정의에서 출발할 것:
> $$D_{KL}(p \| q) = \int_{-\infty}^{\infty} p(x) \ln \frac{p(x)}{q(x)} \, dx$$

---

### (c) [5점] KL 발산의 비대칭성 (Asymmetry)

$p = \left(\frac{1}{2}, \frac{1}{4}, \frac{1}{4}\right)$ 이고 $q = \left(\frac{1}{3}, \frac{1}{3}, \frac{1}{3}\right)$이라고 하자.

**(i)** $D_{KL}(p \| q)$를 계산하시오.

**(ii)** $D_{KL}(q \| p)$를 계산하시오.

**(iii)** $D_{KL}(p \| q) \neq D_{KL}(q \| p)$임을 확인하고, 왜 KL 발산이 **참된 의미의 거리 척도(true distance metric)가 아닌지** 설명하시오.

# 문제 5: 행렬 미적분학, 역전파 및 최적화 (20점)

## (a) [4점] Sigmoid를 포함한 함수의 미분

$f(\mathbf{x}) = -\log \sigma(\mathbf{a}^T \mathbf{x} + b)$ 에서 $\sigma$는 시그모이드 함수이다.

$\frac{\partial f}{\partial \mathbf{x}}$를 구하시오.

모든 단계에서 chain rule을 명시적으로 사용할 것.

**Hint:** $\sigma'(z) = \sigma(z)(1 - \sigma(z))$

## (b) [4점] Softmax의 Jacobian 행렬

$\mathbf{p} = \text{softmax}(\mathbf{z})$, 즉 $p_i = \frac{\exp(z_i)}{\sum_k \exp(z_k)}$ 일 때,

Jacobian $\frac{\partial \mathbf{p}}{\partial \mathbf{z}}$를 유도하시오.

- $i = j$인 경우와 $i \neq j$인 경우를 분리하여 유도
- 최종 결과를 행렬 형태로 작성

## (c) [4점] 단층 네트워크의 역전파

단층 네트워크 $\mathbf{y} = \text{softmax}(W\mathbf{x} + \mathbf{b})$에 cross-entropy 손실 $L = -\log y_c$ ($c$는 정답 클래스)를 사용할 때,

$\frac{\partial L}{\partial W}$와 $\frac{\partial L}{\partial \mathbf{b}}$를 chain rule을 사용하여 유도하시오.

**Hint:** softmax와 cross-entropy를 먼저 결합하라.

## (d) [4점] Gradient Descent 수렴 조건 증명

이차 목적함수 $f(\boldsymbol{\theta}) = \frac{1}{2}\boldsymbol{\theta}^T A\boldsymbol{\theta} + \mathbf{b}^T\boldsymbol{\theta}$ ($A$는 대칭 양정치 행렬)에 대해,

경사하강법이 수렴하기 위한 필요충분조건이 $\eta < \frac{2}{\lambda_{\max}(A)}$임을 증명하시오.

- 오차 재귀식 $\mathbf{e}_t = (I - \eta A)^t \mathbf{e}_0$을 유도할 것

## (e) [4점] Average Pooling의 행렬 곱 표현

$4 \times 4$ 입력 행렬에 대해 $2 \times 2$ average pooling (stride 2) 연산을 행렬 곱으로 표현하시오.
