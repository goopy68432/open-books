## 입문: 왜 loss 함수들이 연결되는가?

### Goal
- 딥러닝의 CE 손실(분류)과 MSE 손실(회귀)은 임의 선택이 아니다
- **확률 모델을 가정하고 MLE를 수행하면 자연스럽게 유도**된다

### 통일 프레임워크 -- 일반 원리

> **분포를 정하면 loss가 자동으로 나온다.**

절차:
1. 출력의 **확률분포** p(y|x; w)를 가정한다
2. 데이터의 **NLL**: -log p(y|x; w)를 구한다
3. NLL을 전개하면 **표준 loss**가 자동으로 유도된다

```
  확률분포 가정        NLL 전개          결과 loss
  ─────────────     ──────────       ──────────
  Gaussian(y|h,σ²) → -logN(y;h,σ²) → MSE (회귀)
  Bernoulli(y|h)   → -logBer(y;h)  → BCE (이진 분류)
  Categorical(y|h) → -logCat(y;h)  → CE  (다중 분류)
  Laplace(y|h,b)   → -logLap(y;h)  → MAE
```

### 백엔드 관점
- **NLL = 범용 비용함수**: REST API에서 response code별로 다른 에러 핸들링을 하듯, 각 확률 분포별로 NLL을 전개하면 서로 다른 loss가 나옴
- 하지만 **원리는 하나**: "모델이 데이터를 얼마나 잘 설명하는가"를 최대화

| 문제 | 분포 가정 | NLL 형태 | 표준 손실 |

## 고급: 유도 체인 (시험 핵심)

### 유도 1: Gaussian → MSE (4주차 교수님 직접 유도)

> 교수님: "제곱오차의 합이 되었죠... 제곱을 줄여라 이렇게 결과가 나온 겁니다"

**가정**: $Y = h_w(X) + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, \sigma^2)$

이 가정이 의미하는 것: 관측값 y는 모델 예측 h(x) 주변에 Gaussian noise가 섞인 것이다.

**Step 1 -- 단일 데이터 포인트의 우도 (Likelihood)**

$\varepsilon = y_i - h_w(x_i) \sim \mathcal{N}(0, \sigma^2)$이므로:

$$p(y_i | x_i; w) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - h_w(x_i))^2}{2\sigma^2}\right)$$

**Step 2 -- i.i.d 가정으로 전체 데이터 우도 (곱)**

> 시험 포인트: "인디펜던스도 어디서 쓰고" -- i.i.d 가정을 반드시 명시!

데이터가 **독립 동일 분포(i.i.d)**이므로 결합확률 = 개별확률의 곱:

$$L(w) = \prod_{i=1}^{n} p(y_i | x_i; w)$$

**Step 3 -- Log 변환 (곱 → 합)**

$$\log L(w) = \sum_{i=1}^{n} \left[-\frac{1}{2}\log(2\pi\sigma^2) - \frac{(y_i - h_w(x_i))^2}{2\sigma^2}\right]$$

**Step 4 -- NLL 최소화**

부호를 뒤집고 상수 제거:

$$\text{NLL}(w) = -\log L(w) = \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - h_w(x_i))^2 + \underbrace{\frac{n}{2}\log(2\pi\sigma^2)}_{\text{w에 무관한 상수}}$$

**Step 5 -- 결론**

$$\arg\min_w \text{NLL}(w) = \arg\min_w \frac{1}{2\sigma^2}\sum_{i=1}^{n}(y_i - h_w(x_i))^2 = \arg\min_w \sum_{i=1}^{n}(y_i - h_w(x_i))^2$$

$$\boxed{\text{NLL 최소화} = \text{MSE 최소화}}$$

> **핵심**: $\sigma^2$는 상수이므로 argmin에 영향 없음. 시험에서 $\sigma^2$가 최적화를 바꾼다고 착각하면 안 됨!
> 교수님: "nll 줄이는게 likelihood를 키우는거죠"

### 유도 2: Bernoulli → Binary Cross-Entropy (p.276-277)

**가정**: $y_i \in \{0, 1\}$, $y_i \sim \text{Bernoulli}(h_w(x_i))$, $h_w(x) = \sigma(w^T x)$

**Step 1 -- 우도** (Bernoulli 분포의 compact 형태):

$$p(y_i | x_i; w) = h_w(x_i)^{y_i} (1 - h_w(x_i))^{1-y_i}$$

검증: y=1이면 $h_w$, y=0이면 $1-h_w$.

**Step 2 -- i.i.d 곱 → Log**:

$$\log L(w) = \sum_{i=1}^{n} \left[y_i \log h_w(x_i) + (1-y_i)\log(1-h_w(x_i))\right]$$

**Step 3 -- NLL = BCE**:

$$\boxed{\text{BCE}(w) = -\frac{1}{n}\sum_{i=1}^{n}\left[y_i \log h_w(x_i) + (1-y_i)\log(1-h_w(x_i))\right]}$$

> **핵심**: Bernoulli 분포 가정 → NLL이 Binary Cross-Entropy와 정확히 일치

### 유도 3: Categorical → Cross-Entropy (p.276-277)

**가정**: $y_i \in \{1, ..., K\}$, $y_i \sim \text{Cat}(h_w(x_i))$, $h_w(x) = \text{softmax}(Wx)$

**NLL 전개**: one-hot 인코딩 $\mathbf{e}_{y_i}$에서 해당 클래스 확률만 살아남음:

$$\text{NLL}(w) = -\sum_{i=1}^{n} \log [h_w(x_i)]_{y_i} = -\sum_{i=1}^{n} \log P(y_i | x_i, w)$$

$$\boxed{\text{CE}(w) = -\frac{1}{n}\sum_{i=1}^{n} \log h_{y_i}(x_i)}$$

## NLL <-> KL <-> CE 연결 증명 (p.253, 257)

> 교수님: "p가 q랑 같으면 로그가 0이 되죠. k-다운스가 0이 됩니다"

### 정의 복습

**Shannon 엔트로피**: $H(p) = -\sum_x p(x)\log p(x)$

**교차 엔트로피**: $\text{CE}(p, q) = -\sum_x p(x)\log q(x)$

**KL Divergence**: $\text{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$

### 핵심 분해 (p.257)

$$\boxed{\text{CE}(p, q) = H(p) + \text{KL}(p\|q)}$$

**증명**:

$$\text{CE}(p,q) - H(p) = -\sum_x p(x)\log q(x) - \left(-\sum_x p(x)\log p(x)\right)$$

$$= \sum_x p(x)\log p(x) - \sum_x p(x)\log q(x)$$

$$= \sum_x p(x)\log\frac{p(x)}{q(x)} = \text{KL}(p\|q) \geq 0$$

따라서 $\text{CE}(p,q) = H(p) + \text{KL}(p\|q)$. $\square$

### One-Hot Label의 경우 (분류 문제)

$p = $ one-hot vector $\mathbf{e}_y$이면:

- **$H(p) = 0$** (확정적 분포이므로 엔트로피 = 0)
- 따라서:

$$\text{CE}(p, q) = 0 + \text{KL}(p\|q) = -\log q(y_{\text{true}}) = \text{NLL}$$

$$\boxed{\text{One-hot일 때: } \text{CE} = \text{KL} = \text{NLL}}$$

### MLE = KL 최소화 (p.253)

경험적 분포 $p_S$와 모델 분포 $q_\theta$에 대해:

$$\arg\min_\theta \text{KL}(p_S \| q_\theta)$$
$$= \arg\min_\theta \left[H(p_S) + \text{CE}(p_S, q_\theta) - H(p_S)\right]$$
$$= \arg\min_\theta \text{CE}(p_S, q_\theta) \quad (\because H(p_S)\text{는 } \theta\text{와 무관})$$
$$= \arg\min_\theta \left[-\frac{1}{n}\sum_{i=1}^{n}\log q_\theta(x_i)\right]$$
$$= \arg\max_\theta \sum_{i=1}^{n}\log q_\theta(x_i) = \text{MLE}$$

$$\boxed{\text{MLE} = \arg\min \text{NLL} = \arg\min \text{CE} = \arg\min \text{KL}}$$

> **핵심**: H(p_S)는 $\theta$와 무관한 상수이므로 KL 최소화 = CE 최소화 = NLL 최소화 = MLE

## 최종 관계 정리

```
MLE = argmax Sigma log p(x_i|theta)
    = argmin NLL
    = argmin CE(p_data, p_model)
    = argmin KL(p_data || p_model)    [H(p_data)는 상수이므로]

Gaussian 가정 → NLL ∝ MSE        ("제곱을 줄여라")
Bernoulli 가정 → NLL = BCE
Categorical 가정 → NLL = CE
Laplace 가정 → NLL ∝ MAE
```

### 일반 원리 표 (p.280)

> 출력 확률분포 p(y|x)를 정하고 → NLL: -log p(y|x)를 계산하면 → 최적 손실함수가 자동으로 유도된다.

| 분포 | → | 손실 | 왜? |
|-----|---|-----|-----|
| **Gaussian** | → | **MSE** | $-\log \mathcal{N} \propto (y-\hat{y})^2$ |
| **Bernoulli** | → | **BCE** | $-\log \text{Ber} = -[y\log p + (1-y)\log(1-p)]$ |
| **Categorical** | → | **CE** | $-\log \text{Cat} = -\log p_y$ |
| **Laplace** | → | **MAE** | $-\log \text{Lap} \propto |y-\hat{y}|$ |

## 쉽게 설명하면
> 모든 loss 함수는 "모델이 데이터를 얼마나 잘 설명하나"의 다른 표현일 뿐이다.
> 교수님 표현: "이 데이터를 가장 잘 설명하는 분포를 찾고 싶은 거에요"

## 남에게 설명한다면
> "MSE든 Cross-Entropy든, 결국 '데이터가 모델에서 나올 확률의 -log'를 최소화하는 것이다. 분포만 다르고 원리는 같다."

## 핵심 정리
- **핵심**: CE = H + KL, NLL = CE (one-hot), MLE = argmin NLL = argmin KL
- **시험 필수**: Gaussian → MSE 유도 5단계 (i.i.d 명시, sigma^2 상수 언급)
- **주의**: H(p)가 상수인 이유를 설명할 수 있어야 함 (p는 데이터 분포이므로 모델 파라미터와 무관)
- **교수님 강조**: "답을 얻는 과정을 더 평가" -- 유도 과정에서 independence, identical distribution, 미분=0 등 근거를 반드시 명시할 것
