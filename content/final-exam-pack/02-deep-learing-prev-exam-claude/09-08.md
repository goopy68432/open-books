# Part 8: 회귀 & 분류 — 선형/릿지/로지스틱

> **교재**: p.293~310 | **핵심**: Normal Equation, Ridge, Logistic Regression, Softmax

## 한 줄 결론
> 선형회귀(closed form) -> 릿지회귀(정규화) -> 로지스틱회귀(no closed form) 순으로 이해하면 된다.

> **교수님**: "하이포테시스를 찾는 것" — 이것이 Classification과 Regression의 공통점이다.

## 입문: Regression vs Classification

### 교수님의 주택 가격 예측 예제

> **교수님**: Price = f(Size, Location, Bedrooms, ...)
> 주택의 크기, 위치, 방 개수 등의 특성(feature)으로 가격을 예측하는 것이 회귀의 대표적 예시.

$$Y = h(X) + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, \sigma^2)$$

> **교수님**: "이거를 하이포테시스라고 합니다" — h(X)가 바로 hypothesis function.

### 핵심 구분

| | Classification | Regression |
|---|---------------|------------|
| **출력** | $y \in \{1, \ldots, k\}$ (이산) | $y \in \mathbb{R}$ (연속) |
| **예시** | 스팸 분류, 이미지 인식 | 주택 가격, 온도 예측 |
| **Loss** | Cross-Entropy | MSE |
| **공통점** | **"하이포테시스를 찾는 것"** | **"하이포테시스를 찾는 것"** |

### 백엔드 관점
- **Regression = 응답 시간 예측**: 요청 크기(feature) -> 예상 응답 시간(연속값)
- **Classification = 요청 라우팅**: 요청 특성(feature) -> 어느 서버로 보낼지(이산 선택)

## 중급: 선형 회귀 (p.293-300)

### 모델
$$f_w(x) = x^T w + b$$

**증강 표기** (bias 흡수): $x \leftarrow [x; 1]$, $w \leftarrow [w; b]$
$$f_w(x) = x^T w$$

### 설계 행렬 (Design Matrix)
$$X = \begin{bmatrix} x_1^T \\ x_2^T \\ \vdots \\ x_n^T \end{bmatrix} \in \mathbb{R}^{n \times p}, \quad f_w(X) = Xw$$

### 최소제곱 손실 (Least Squares Loss) (p.295)
$$L_S(w) = \frac{1}{2}\|Xw - y\|^2$$

**전개**:
$$= \frac{1}{2}(w^T X^T Xw - 2y^T Xw + y^T y)$$

### Gradient
$$\nabla L_S(w) = X^T Xw - X^T y$$

### Hessian
$$\nabla^2 L_S(w) = X^T X \succeq 0 \quad \text{(항상 PSD — Gram 행렬이므로)}$$

### 정규방정식 (Normal Equation) (p.296)

$$\nabla L_S(w) = 0 \implies \boxed{X^T Xw = X^T y}$$

### 해 (p.298-299)

**Full rank (rank(X) = p)**:
$$\boxed{\hat{\beta} = (X^T X)^{-1} X^T y}$$

**Rank deficient (rank(X) < p)**:
$$\hat{\beta} = X^+ y \quad \text{(pseudoinverse로 최소 노름 해)}$$

### Implicit Bias (p.300)
- GD를 x_0 = 0에서 시작하면 최소 노름 해에 수렴
- 명시적 정규화 없이도 암묵적 정규화 효과

## 중급: 릿지 회귀 (Ridge Regression) (p.301)

### 동기
- $X^TX$가 특이(singular)하면 역행렬이 없다
- 과적합(overfitting) 방지를 위한 정규화 필요

### 손실 함수
$$\boxed{L_S(w; \lambda) = \frac{1}{2}\|Xw - y\|^2 + \frac{\lambda}{2}\|w\|^2}$$

### Gradient -> Critical Point
$$(X^T X + \lambda I)\hat{\beta}_\lambda = X^T y$$

### Closed Form 해
$$\boxed{\hat{\beta}_\lambda = (X^T X + \lambda I)^{-1} X^T y}$$

### 핵심 성질: X^TX + lambda*I는 항상 양정치!

$X^TX$의 고유값이 $\{\sigma_1^2, \ldots, \sigma_p^2\}$이면:
$X^TX + \lambda I$의 고유값 = $\{\sigma_1^2 + \lambda, \ldots, \sigma_p^2 + \lambda\}$ → 모두 > 0

> 따라서 **역행렬이 항상 존재**한다. lambda > 0이기만 하면 어떤 X가 오더라도 해를 구할 수 있다.

### Bayesian 해석: Ridge = MAP with Gaussian prior

> **교수님 연결**: "MAP가 무조건 ML보다 좋냐 이런거 아니죠. 태스크 디피컬티와 데이터에 맞춰서"

Ridge 회귀는 다음과 같은 MAP 추정에 해당:
- Likelihood: $y|X, w \sim \mathcal{N}(Xw, \sigma^2_{\text{noise}}I)$
- Prior: $w \sim \mathcal{N}(0, \sigma^2_{\text{prior}}I)$
- MAP: $\hat{w}_{MAP} = \arg\max_w [\log P(y|X,w) + \log P(w)]$

$$\boxed{\lambda = \frac{\sigma^2_{\text{noise}}}{\sigma^2_{\text{prior}}}}$$

| lambda | 의미 | Bayesian 해석 |
|--------|------|--------------|
| lambda -> 0 | 정규화 없음 = 일반 최소제곱 | 매우 넓은 prior (= MLE와 동일) |
| lambda 적당 | 적절한 정규화 | noise와 prior의 균형 |
| lambda -> inf | beta -> 0 | 매우 좁은 prior (w가 0에 가까워야 한다고 강하게 믿음) |

### SVD 관점: Shrinkage

$$\hat{\beta}_\lambda = V \text{diag}\left(\frac{\sigma_i}{\sigma_i^2 + \lambda}\right) U^T y$$

- 큰 특이값 sigma_i: $\frac{\sigma_i}{\sigma_i^2 + \lambda} \approx \frac{1}{\sigma_i}$ (거의 축소 안됨)
- 작은 특이값 sigma_i: $\frac{\sigma_i}{\sigma_i^2 + \lambda} \approx \frac{\sigma_i}{\lambda}$ → 0 (강하게 축소)

> **핵심**: Ridge는 작은 특이값 방향을 축소(shrinkage) → 과적합 방지. 교수님이 강조한 "eigenvalue가 작은 게 덜 중요하다"의 실질적 구현.

## 중급: 다항 회귀 (p.302)

### 특성 변환
$$\tilde{x}^T = [x^p, x^{p-1}, \ldots, x, 1]$$

$$f_w(x) = \tilde{x}^T w = w_0 x^p + w_1 x^{p-1} + \cdots + w_p$$

> **핵심**: 입력 x에 대해 비선형이지만, 파라미터 w에 대해서는 선형 → 표준 선형회귀로 풀 수 있음

## 중급: 커널 릿지 회귀 (p.303)

### 특성 함수 매핑
$$\phi(x) \in \mathbb{R}^p, \quad f_w(x) = \phi(x)^T w$$

### 커널 트릭
$$K = \Phi^T\Phi \quad \text{(커널 행렬, n x n)}$$

**예측**: $\hat{y} = y^T(K + \lambda I)^{-1}k(x)$

> 명시적 phi 계산 없이 커널 함수 K(x_i, x_j)만으로 계산 가능. 고차원(심지어 무한 차원) 특성 공간에서도 효율적.

## 고급: 로지스틱 회귀 — 이진 분류 (p.307-308)

### Sigmoid 함수
$$\sigma(z) = \frac{1}{1 + e^{-z}} = \frac{e^z}{1 + e^z}$$

### Sigmoid 핵심 성질
$$\boxed{\sigma'(z) = \sigma(z)(1 - \sigma(z))}$$
$$\sigma(-z) = 1 - \sigma(z)$$
$$\sigma(0) = 0.5$$

> 이 미분 성질이 로지스틱 회귀의 gradient 계산에서 핵심적으로 사용된다.

### 모델
$$P(y=1|x) = \sigma(x^T w)$$

### Log-Odds (로짓)
$$\log\frac{P(y=1|x)}{P(y=0|x)} = x^T w$$

> 로지스틱 회귀는 log-odds가 입력의 선형함수라고 가정하는 모델.

### 결정 경계
$$x^T w = 0 \quad \text{(초평면)}$$

### 손실 함수: Binary Cross-Entropy = NLL (p.308)

**우도**:
$$P(y|X; w) = \prod_{i=1}^{n} \sigma(x_i^T w)^{y_i}(1-\sigma(x_i^T w))^{1-y_i}$$

**NLL = BCE**:
$$\boxed{L_S(w) = -\sum_{i=1}^{n}\left[y_i \log\sigma(x_i^T w) + (1-y_i)\log(1-\sigma(x_i^T w))\right]}$$

> BCE = NLL. MLE로 우도를 최대화하는 것 = NLL(= BCE)을 최소화하는 것.

### Gradient
$$\boxed{\frac{\partial L}{\partial w} = \sum_{i=1}^{n}(\sigma(x_i^T w) - y_i)x_i}$$

> 구조: **(예측 - 정답) x 입력 = 오차 신호 x 특성**. 선형회귀의 gradient $(X^T(Xw-y))$와 구조적으로 동일!

### Closed Form 없음!
- Sigmoid의 비선형성 때문에 $\partial L/\partial w = 0$이 비선형 방정식
- 반드시 **수치 최적화** (GD, Newton-Raphson, L-BFGS 등) 필요
- 하지만 **손실 함수는 볼록(convex)** → 전역 최솟값 보장 (어디서 시작해도 수렴)

## 고급: 다중 클래스 — Softmax (p.309)

### Softmax 함수
$$\text{softmax}(z)_i = \frac{\exp(z_i)}{\sum_{j=1}^{C}\exp(z_j)}$$

### 성질
- 출력: 확률 심플렉스 $\Delta^{C-1} = \{p : \sum p_i = 1, p_i \geq 0\}$
- Sigmoid = 2-class softmax: $\sigma(z) = \text{softmax}([z, 0])_1$

### 모델
$$f_W(x) = \text{softmax}(Wx), \quad W \in \mathbb{R}^{C \times p}$$

### 손실 함수 (Categorical Cross-Entropy)
$$\boxed{L_S(W) = -\sum_{i=1}^{n} \log [f_W(x_i)]_{y_i}}$$

### Temperature Scaling
$$\text{softmax}(z/T)$$

| T | 효과 | 용도 |
|---|------|------|
| T >> 1 | 균일분포 (soft) | Knowledge Distillation |
| T = 1 | 표준 softmax | 일반 학습 |
| T -> 0 | argmax (hard, one-hot) | 추론 시 sharp decision |

### 수치 안정성
$$\text{softmax}(z) = \text{softmax}(z - \max(z))$$

> overflow 방지를 위해 최댓값을 빼줌. exp(매우 큰 수) = inf가 되는 것을 방지.

## 고급: 아키텍처 진화 — 교수님의 Knowledge vs Data 관점

> **교수님**: "MAP가 무조건 ML보다 좋냐 이런거 아니죠. 태스크 디피컬티와 데이터에 맞춰서"

| 아키텍처 | 시기 | Prior 강도 | 데이터 필요량 | 특징 |
|---------|------|-----------|-------------|------|
| **Linear Model** | - | 강한 prior | 적은 데이터로 충분 | "출력이 입력의 선형함수"라는 강한 가정 |
| **CNN (AlexNet)** | 2012 | 중간 prior (이미지) | 중간 데이터 | 지역성, 평행이동 불변성 = 이미지 prior |
| **Transformer** | 2017~ | 약한 prior | 대량 데이터 필요 | Attention만으로, 구조적 가정 최소화 |

```
Prior 강도:  강 ────────────────────── 약
             Linear    CNN     Transformer
데이터 필요:  적음 ────────────────────── 대량
일반화 능력:  제한적 ──────────────────── 범용적
```

> **핵심 통찰**: 모델의 prior가 강할수록 적은 데이터로 학습 가능하지만 유연성이 떨어지고, prior가 약할수록 더 많은 데이터가 필요하지만 더 범용적이다.

## 고급: 비선형 로지스틱 회귀 (p.310)

### 특성 함수 도입
$$P(y=1|x) = \sigma(\phi(x)^T w)$$

| phi 선택 | 접근 |
|---------|------|
| phi 수동 설계 | 전통적 특성 공학 |
| phi 학습 | **신경망 (딥러닝)** |

> 신경망 = 자동 특성 학습 + 선형 분류기. 마지막 레이어의 sigmoid/softmax 앞까지가 phi, 마지막 linear layer가 w.

### 볼록성
- phi 고정: w에 대해 **볼록** → 전역 최솟값
- phi 학습: w와 phi에 대해 **비볼록** → 지역 최솟값들 (딥러닝의 최적화가 어려운 이유)

## 전체 비교 요약

| 모델 | 해 | 분포 가정 | Loss | Closed Form |
|------|---|---------|------|------------|
| 선형 회귀 | $(X^TX)^{-1}X^Ty$ | Gaussian noise | MSE | O |
| 릿지 회귀 | $(X^TX+\lambda I)^{-1}X^Ty$ | Gaussian + N(0,tau^2I) prior | MSE + L2 | O |
| 로지스틱 회귀 | **없음** | Bernoulli | BCE (= NLL) | X |
| Softmax 회귀 | **없음** | Categorical | CE | X |

## 다중 출력 최소제곱 (p.304-305)

$$L_S(W) = \frac{1}{2}\|XW - Y\|_F^2$$

**해**: $\hat{B} = (X^TX)^{-1}X^TY$

> 각 출력 차원이 독립적으로 풀림 — 병렬 처리 가능.

### 일반 행렬 최소제곱 (p.305)

$$f(X) = \frac{1}{2}\|AX - B\|_F^2 \implies X^* = A^+B$$
