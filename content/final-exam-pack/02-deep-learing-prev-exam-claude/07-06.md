# Part 6: 학습률 수렴 조건 — 증명 문제 (5%)

> **교재**: p.108~127 | **출제 비중**: ~5% | **핵심**: η < 2/λ_max(A) 증명

---

## 한 줄 결론
> Gradient Descent가 수렴하려면 학습률이 Hessian의 최대 고유값의 역수의 2배보다 작아야 한다.

> **교수님**: "복잡한 함수는 다루기가 어렵고 무조건 선형으로 근사"

---

## 입문: 왜 학습률 조건이 필요한가?

### Goal
- 학습률(η)이 너무 크면 발산, 너무 작으면 수렴이 느림
- 정확한 수렴 조건을 수학적으로 보장

### 백엔드 관점
- **학습률 = Rate Limiter**: API 호출 빈도가 너무 높으면 시스템 과부하(발산), 너무 낮으면 처리량 부족(느린 수렴)
- **λ_max = 시스템의 최대 부하 한계**: 가장 민감한 방향의 곡률

### 직관
- 경사하강법은 loss surface 위에서 공을 굴리는 것
- 학습률 = 한 걸음의 크기
- 너무 크면 골짜기를 넘어서 발산, 너무 작으면 도착이 느림
- **어떤 조건을 만족하면 반드시 수렴하는가?** 이것이 이 파트의 핵심 질문

---

## 중급: Quadratic 함수에서의 GD

### Setup: Quadratic Objective

$$f(\theta) = \frac{1}{2}\theta^T A\theta + b^T\theta + c$$

여기서 A는 대칭 양정치 행렬 (A = A^T ≻ 0)

> 왜 quadratic인가? 교수님 말씀대로 "복잡한 함수는 다루기가 어렵고 무조건 선형으로 근사"하는데, GD의 수렴 분석은 loss의 2차 근사(quadratic)에서 가장 정확하게 이루어진다.

### Gradient

$$\nabla f(\theta) = A\theta + b$$

### 최적해

$$\theta^* = -A^{-1}b$$

### GD Update

$$\theta_{t+1} = \theta_t - \eta \nabla f(\theta_t) = \theta_t - \eta(A\theta_t + b)$$

---

## 고급: 수렴 조건 증명

### 오차 벡터 정의

$$e_t = \theta_t - \theta^*$$

### 오차 업데이트

$$e_{t+1} = \theta_{t+1} - \theta^* = (\theta_t - \eta A\theta_t - \eta b) - \theta^*$$

$\theta^* = -A^{-1}b$이므로 $b = -A\theta^*$:

$$e_{t+1} = \theta_t - \eta A\theta_t + \eta A\theta^* - \theta^*$$
$$= (\theta_t - \theta^*) - \eta A(\theta_t - \theta^*)$$
$$= (I - \eta A)e_t$$

### 반복 적용

$$\boxed{e_t = (I - \eta A)^t e_0}$$

### 수렴 조건

수렴 ⟺ $\|e_t\| \to 0$ ⟺ $(I - \eta A)^t \to 0$

이는 $I - \eta A$의 **모든 고유값의 절댓값이 1보다 작을 때** 성립.

### 고유값 분석

A의 고유값: $\lambda_1 \leq \lambda_2 \leq \cdots \leq \lambda_n$ (모두 양수, A ≻ 0)

$I - \eta A$의 고유값: $1 - \eta\lambda_i$

**수렴 조건**: 모든 i에 대해 $|1 - \eta\lambda_i| < 1$

$$-1 < 1 - \eta\lambda_i < 1$$
$$0 < \eta\lambda_i < 2$$
$$0 < \eta < \frac{2}{\lambda_i}$$

모든 i에 대해 성립해야 하므로 가장 restrictive한 조건:

$$\boxed{\eta < \frac{2}{\lambda_{\max}(A)}}$$

> **교수님 강조**: η < 2/λ_max 조건. GD는 1차 근사, Newton은 2차 근사.

### 최적 학습률

수렴 속도는 $\max_i |1 - \eta\lambda_i|$에 의해 결정.

최적: 가장 큰 고유값 방향과 가장 작은 고유값 방향의 수렴 속도를 균형:

$$\boxed{\eta^* = \frac{2}{\lambda_{\max} + \lambda_{\min}}}$$

이때 수렴 속도:
$$r = \frac{\lambda_{\max} - \lambda_{\min}}{\lambda_{\max} + \lambda_{\min}} = \frac{\kappa - 1}{\kappa + 1}$$

### Condition Number

$$\kappa = \frac{\lambda_{\max}}{\lambda_{\min}}$$

- κ ≈ 1: 등방적(isotropic), 빠른 수렴
- κ >> 1: ill-conditioned, 느린 수렴 (길쭉한 등고선)

> **핵심**: condition number가 크면 → 수렴이 느림. Adam, AdaGrad 등은 방향별로 다른 학습률을 적용해서 이 문제를 완화한다.

## Taylor 전개 기반 이해 (p.127)

### 1차 근사 (GD)
$$f(\theta - \eta\nabla f) \approx f(\theta) - \eta\|\nabla f\|^2 + O(\eta^2)$$

η가 충분히 작으면 $-\eta\|\nabla f\|^2 < 0$ → loss 감소 보장

### 2차 근사 (Newton)
$$f(\theta + \Delta) \approx f(\theta) + (\nabla f)^T\Delta + \frac{1}{2}\Delta^T H \Delta$$

**Newton update**: $\Delta = -H^{-1}\nabla f$

| 방법 | 근사 차수 | 학습률 | Hessian | 수렴 속도 |
|------|----------|--------|---------|----------|
| GD | 1차 | 필요 (η) | 불필요 | 선형 수렴 |
| Newton | 2차 | 불필요 | H^{-1} 계산 O(n^3) | 2차 수렴 |

> **교수님**: "역행렬로 문제를 풀어야 된다면 굉장히 느린 알고리즘" O(N^3). Newton법은 정확하지만 비싸다.

## Newton's Method: 영점 찾기와 최적화

### 영점 찾기 (Root Finding)

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

접선의 x절편으로 이동하는 것을 반복.

### 교수님의 sqrt(7) 예제

$f(x) = x^2 - 7$을 풀자. $f'(x) = 2x$.

$$x_{n+1} = x_n - \frac{x_n^2 - 7}{2x_n} = \frac{x_n + 7/x_n}{2}$$

$x_0 = 3$에서 시작:

$$x_1 = \frac{3 + 7/3}{2} = \frac{3 + 2.333...}{2} = \frac{16/3}{2} = \frac{16}{6} \approx 2.666...$$

$$x_2 = \frac{2.666 + 7/2.666}{2} \approx \frac{2.666 + 2.625}{2} \approx 2.6458$$

$\sqrt{7} \approx 2.6457513...$ → **단 2번의 반복으로 소수점 3자리까지 정확!**

> **교수님이 직접 시연**: 이것이 2차 수렴의 위력. 정확한 자릿수가 매 반복마다 2배로 늘어난다.

### 최적화로 확장

$$\theta_{n+1} = \theta_n - [H(\theta_n)]^{-1}\nabla f(\theta_n)$$

## Critical Point 분류 (p.108-109)

### Fermat 정리 (필요조건)
x가 내부 극값이고 f가 미분가능 → f'(x) = 0

### 역은 성립하지 않음!
f'(x) = 0 ⟹ 극값? **아님!** (예: f(x) = x^3의 x=0)

### 2차 미분 판별

| 조건 | 결론 |
|------|------|
| f'(x)=0, f''(x)>0 | 극소 (local min) |
| f'(x)=0, f''(x)<0 | 극대 (local max) |
| f'(x)=0, f''(x)=0 | 판별 불능 |

### 고차원에서: Hessian 판별

| Hessian 조건 | 결론 |
|-------------|------|
| H ≻ 0 (양정치) | 극소 |
| H ≺ 0 (음정치) | 극대 |
| H 부정치 (양/음 고유값 혼재) | Saddle point |

### 고차원에서 대부분 saddle point
- n차원에서 극값일 확률 ≈ (1/2)^n
- n이 크면 (딥러닝의 파라미터 수: 수백만~수십억) 거의 모든 critical point가 saddle point
- 따라서 GD가 극값에 갇히는 것보다 saddle point에서 느려지는 것이 실제 문제

## Subgradient (비미분점 처리) — p.107

### 정의

$$\partial f(x) = \{g \in \mathbb{R}^n : f(z) \geq f(x) + g^T(z-x), \forall z\}$$

볼록 함수에서 미분 불가능한 점에서도 gradient의 역할을 하는 벡터 집합.

### 예시 1: |x|의 subgradient
- x > 0: ∂|x| = {1}
- x = 0: ∂|x| = [-1, 1] (기울기 -1과 1 사이의 모든 값)
- x < 0: ∂|x| = {-1}

### 예시 2: ReLU의 subgradient
- x > 0: ∂ReLU = {1}
- x = 0: ∂ReLU = [0, 1] (실무에서는 보통 0 또는 1로 선택)
- x < 0: ∂ReLU = {0}

> **실무 연결**: PyTorch에서 ReLU의 x=0에서의 미분값은 0으로 처리. 이것은 subgradient 집합 [0,1]에서 하나를 선택한 것.

## 전체 흐름 정리

```
Loss function f(θ)
    │
    ├─ Gradient: ∇f = Aθ + b
    │     │
    │     ├─ GD Update: θ_{t+1} = θ_t - η∇f
    │     │     │
    │     │     └─ 수렴 조건: η < 2/λ_max
    │     │
    │     └─ Newton Update: θ_{t+1} = θ_t - H^{-1}∇f
    │           │
    │           └─ 학습률 불필요, 2차 수렴, but O(n³)
    │
    ├─ Critical Points: ∇f = 0
    │     ├─ Fermat 정리 (필요조건)
    │     ├─ 2차 미분/Hessian 판별
    │     └─ 고차원: 거의 모든 것이 saddle point
    │
    └─ 비미분점: Subgradient
          └─ |x|, ReLU
```

## 핵심 정리
**핵심**: η < 2/λ_max, e_t = (I - ηA)^t e_0, 최적 η* = 2/(λ_max + λ_min)
**주의**: A가 양정치일 때만 성립, condition number κ가 수렴 속도 결정
**Newton**: 2차 수렴이지만 H^{-1} 계산 O(n^3) — 교수님 "역행렬로 문제를 풀어야 된다면 굉장히 느린 알고리즘"
