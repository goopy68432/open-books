> **"무조건 MAP입니다. ML도 사실 MAP의 일종"**

| 관점 | 설명 |
|------|------|
| MLE | Prior가 Uniform인 MAP의 특수 케이스 |
| MAP | Prior를 명시적으로 반영 |
| Full Bayesian | 점 추정이 아닌 분포 자체를 추정 |

**핵심**: MLE를 쓴다고 말해도 실제로는 "Uniform prior를 선택한 MAP"를 하고 있는 것이다. Prior 선택을 피할 수 없다.

## 핵심 연결 구조: 확률 → 모델 → Loss → Gradient

```
[확률분포]                    [모델]                     [학습]
Gaussian/Bernoulli    →    P(data|θ)             →    Likelihood
     +                         +                         +
Prior P(θ)            →    P(θ|data) ∝           →    Posterior
                           P(data|θ)·P(θ)
     ↓                         ↓                         ↓
[Loss 유도]                                        [Gradient 계산]
-log P(data|θ)        →    NLL                   →    ∂NLL/∂θ = 0
     ↓                         ↓                         ↓
Gaussian noise 가정   →    NLL = MSE + const     →    ∂MSE/∂w
Bernoulli 가정        →    NLL = Cross-Entropy   →    ∂CE/∂w
     ↓                         ↓                         ↓
Prior = Gaussian      →    + λ||w||²  (L2/Ridge) →    Gradient Descent
Prior = Laplace       →    + λ||w||₁  (L1/LASSO) →   Gradient Descent
```

### 백엔드 개발자를 위한 비유

```
확률분포     = 데이터의 스키마 (어떤 형태의 데이터가 들어올 수 있는가)
Likelihood   = 쿼리 결과의 적합도 (이 파라미터로 데이터를 얼마나 잘 설명하는가)
Prior        = 설정 파일의 기본값 (데이터 보기 전의 믿음)
Posterior    = 런타임에 업데이트된 설정 (데이터를 본 후의 믿음)
NLL → MSE    = ORM이 SQL로 변환되는 것 (추상 → 구체)
Gradient     = 프로파일링 결과 (어디를 고쳐야 성능이 오르는가)
```

## Knowledge vs Data Trade-off 표 (교수님 원본)

> **"아키텍처 자체가 prior다"**

| | ML (Uniform Prior) | Weak MAP | Strong MAP |
|---|---|---|---|
| **가설공간** | 넓음 (제약 없음) | 중간 | 좁음 (강한 제약) |
| **표현력** | 높음 | 중간 | 낮음 |
| **Inductive Bias** | 약함 | 중간 | 강함 |
| **필요한 Knowledge** | 적음 | 중간 | 많음 |
| **필요한 Data** | 많음 | 중간 | 적음 |
| **과적합 위험** | 높음 | 중간 | 낮음 |

### 아키텍처 진화에 대입

| 아키텍처 | Prior 강도 | 필요 데이터 | 특징 |
|----------|-----------|------------|------|
| **Linear Regression** | 강한 Prior | 적음 | "세상은 선형이다"라는 강한 가정 |
| **CNN** | 중간 Prior | 중간 | "공간적 지역성"이라는 적절한 가정 (translation equivariance) |
| **Transformer** | 약한 Prior | 매우 많음 | 가정 최소화, 데이터가 구조를 결정 |

> 교수님 비유: 증기기관처럼 **먼저 만들고 나서 이론을 이해한다** — Transformer도 먼저 잘 되고 나서 왜 되는지 이해하는 중

## 시험 직전 5분 킬러 요약

### 1. Bayes 정리 (모든 것의 시작)

$$P(\theta|D) \propto P(D|\theta) \cdot P(\theta)$$

**Posterior ∝ Likelihood x Prior**

### 2. MLE = MAP with Uniform Prior

$$\theta_{MLE}^* = \arg\max_\theta P(D|\theta)$$

- Bernoulli: θ* = k/n (위험: 데이터에만 의존)

### 3. MAP = MLE + Prior

$$\theta_{MAP}^* = \arg\max_\theta P(D|\theta) \cdot P(\theta)$$

- p(θ) ∝ θ(1-θ): θ* = (k+1)/(n+2) → **Laplace Smoothing**
- p(θ) ∝ θ^m(1-θ)^m: θ* = (k+m)/(n+2m) → m→∞이면 θ→0.5

### 4. NLL → MSE 연결

Gaussian noise 가정 → -log P(D|θ) 최소화 = MSE 최소화

> **"nll 줄이는게 likelihood를 키우는거죠 이렇게 다 연결"**

### 5. 정규화 = Prior

- Gaussian prior on w → L2 정규화 (Ridge)
- Laplace prior on w → L1 정규화 (LASSO)

### 6. 미분 = 행렬

> **"미분을 한다는 것은 매트릭스를 얻는다는 거예요"**

- Jacobian: 벡터→벡터 미분 → 행렬
- Softmax 미분: i=j → p_i(1-p_i), i≠j → -p_i·p_j

### 7. KL Divergence

- KL(P||Q) >= 0 (항상)
- KL(P||Q) = 0 iff P = Q
- 비대칭: KL(P||Q) ≠ KL(Q||P)

### 8. 3단계 풀이 워크플로우

1. **Likelihood 쓰기** — P(D|θ) = ∏ P(x_i|θ)
2. **Prior 정하기** — P(θ) 선택
3. **합쳐서 미분=0** — log posterior 미분하여 θ* 구하기

## 핵심 공식 Quick Reference

| 이름 | 공식 |
|------|------|
| Bayes | P(θ\|D) ∝ P(D\|θ)P(θ) |
| Bernoulli MLE | θ* = k/n |
| Laplace Smoothing | θ* = (k+1)/(n+2) |
| General MAP | θ* = (k+m)/(n+2m) |
| NLL (Gaussian) | (1/2σ²)Σ(y_i - f(x_i))² + const |
| L2 정규화 | NLL + λ\|\|w\|\|² |
| Rank-Nullity | rank(A) + null(A) = n |
| KL Divergence | Σ P(x) log(P(x)/Q(x)) |
