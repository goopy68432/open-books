# Part 4: KL Divergence -- 증명 + 계산 (15%)

> **교재**: p.251~263 | **출제 비중**: ~15% | **핵심**: 계산 + Jensen 기반 증명 둘 다 나옴

> **교수님**: "p가 q랑 같으면 로그가 0이 되죠. k-다운스가 0이 됩니다"

> **시험 전략**: KL >= 0 증명은 Jensen 사용 or log t <= t-1 사용, 두 가지 모두 준비할 것

---

## 한 줄 결론
> KL Divergence는 "두 분포가 얼마나 다른가"를 측정하며, 항상 >= 0이고 비대칭이다.
> 교수님: "p가 q랑 같으면 로그가 0이 되죠" -- 같을 때 KL=0, 다를수록 커짐

---

## 입문: KL이 뭔가?

### Goal
- 두 확률분포 p와 q의 "거리" (단, 진짜 거리는 아님 -- 비대칭)
- 모델 q가 실제 분포 p를 얼마나 잘 근사하는지 측정

### 직관
- KL(p||q): p의 관점에서 바라본 q와의 차이
- p(x)가 큰 곳에서 q(x)가 작으면 큰 페널티
- p(x)가 작은 곳은 별로 신경 안 씀 (p(x)가 가중치 역할)

### 백엔드 관점
- **KL = 시스템 성능 갭**: 이상적인 시스템(p)과 실제 시스템(q)의 성능 차이
- KL(p||q) = p로 코딩할 때 최적 비트 수 대비, q로 코딩했을 때 추가로 필요한 비트 수

---

## 중급: 정의와 성질

### 정의 (p.251)

**이산**:
$$\text{KL}(p\|q) = \sum_x p(x) \log\frac{p(x)}{q(x)}$$

**연속**:
$$\text{KL}(p\|q) = \int p(x) \log\frac{p(x)}{q(x)} dx$$

> 교수님: "p가 q랑 같으면 로그가 0이 되죠" -- log(p/q) = log(1) = 0

### 핵심 성질

1. **비음수성**: KL(p||q) >= 0, 등호 <=> p = q a.e.
2. **비대칭**: KL(p||q) != KL(q||p) -> "거리"가 아님! (metric 아님)
3. **분해**: KL(p||q) = CE(p,q) - H(p)

### Forward KL vs Reverse KL (p.253)

| | Forward KL(p\|\|q) | Reverse KL(q\|\|p) |
|---|---|---|
| 최적화 대상 | q를 최적화 | q를 최적화 |
| 행동 | **mode-covering** (zero-avoiding) | **mode-seeking** (zero-forcing) |
| p(x)>0인데 q(x)~0이면 | 페널티 큼! -> q가 모든 mode 커버 | 페널티 작음 -> q가 하나의 mode에 집중 |
| q(x)>0인데 p(x)~0이면 | 페널티 작음 | 페널티 큼! |
| 응용 | MLE, VAE decoder | VI, GAN |

**직관**:
- Forward KL: "p가 있는 곳을 q가 놓치면 안 된다" -> 넓게 퍼짐
- Reverse KL: "q가 있는 곳에 p가 없으면 안 된다" -> 한 곳에 집중

## 고급: KL >= 0 증명 (Gibbs' Inequality) -- 시험 필수

### 증명 1: Jensen 부등식 사용 (정석)

**Jensen 부등식**: f가 볼록(convex)이면 $E[f(X)] \geq f(E[X])$

$$\text{KL}(p\|q) = \sum_x p(x) \log\frac{p(x)}{q(x)}$$

$$= -\sum_x p(x) \log\frac{q(x)}{p(x)}$$

$$= E_p\left[-\log\frac{q(X)}{p(X)}\right]$$

$-\log$는 **볼록함수**(strictly convex)이므로 Jensen 적용:

$$\geq -\log E_p\left[\frac{q(X)}{p(X)}\right]$$

$$= -\log \sum_x p(x) \cdot \frac{q(x)}{p(x)}$$

$$= -\log \sum_x q(x)$$

$$= -\log 1 = 0$$

$$\boxed{\text{KL}(p\|q) \geq 0}$$

**등호 조건**: Jensen 부등식에서 등호가 성립하려면 $\frac{q(x)}{p(x)} = c$ (상수)여야 한다. $\sum p(x) = \sum q(x) = 1$이므로 $c = 1$, 즉 **p = q**일 때만 등호 성립. $\square$

### 증명 2: log t <= t - 1 사용 (대안)

**보조 정리**: $\log t \leq t - 1$ (모든 $t > 0$에서 성립, 등호: $t = 1$)

이를 $t = q(x)/p(x)$에 적용:

$$-\text{KL}(p\|q) = \sum_x p(x)\log\frac{q(x)}{p(x)} \leq \sum_x p(x)\left(\frac{q(x)}{p(x)} - 1\right)$$

$$= \sum_x q(x) - \sum_x p(x) = 1 - 1 = 0$$

따라서 $-\text{KL}(p\|q) \leq 0$, 즉:

$$\boxed{\text{KL}(p\|q) \geq 0}$$

**등호 조건**: $\log t = t - 1$이 성립하려면 $t = 1$, 즉 $q(x)/p(x) = 1$ 모든 x에서. 따라서 **p = q**. $\square$

## Gaussian KL 계산 -- 시험 단골

### 일변량 Gaussian KL (p.252)

$$\boxed{\text{KL}(\mathcal{N}(\mu_1, \sigma_1^2) \| \mathcal{N}(\mu_2, \sigma_2^2)) = \frac{1}{2}\left[2\log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2}{\sigma_2^2} + \frac{(\mu_1 - \mu_2)^2}{\sigma_2^2} - 1\right]}$$

정리하면:

$$= \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

### 특수 경우 1: 분산 동일 (sigma_1 = sigma_2 = sigma)

$$\text{KL} = \frac{1}{2}\left[0 + 1 + \frac{(\mu_1 - \mu_2)^2}{\sigma^2} - 1\right] = \frac{(\mu_1 - \mu_2)^2}{2\sigma^2}$$

> **핵심**: 분산이 같으면 **KL $\propto$ MSE**! 이것이 Gaussian 가정 -> MSE 유도의 또 다른 관점

### 특수 경우 2: 표준정규분포 (sigma_1 = sigma_2 = 1)

$$\text{KL} = \frac{(\mu_1 - \mu_2)^2}{2}$$

### 다변량 Gaussian KL (p.252)

$$\boxed{\text{KL}(\mathcal{N}(\mu_1, \Sigma_1) \| \mathcal{N}(\mu_2, \Sigma_2)) = \frac{1}{2}\left[\log\frac{|\Sigma_2|}{|\Sigma_1|} + \text{tr}(\Sigma_2^{-1}\Sigma_1) + (\mu_1-\mu_2)^T\Sigma_2^{-1}(\mu_1-\mu_2) - D\right]}$$

각 항의 의미:
- $\log\frac{|\Sigma_2|}{|\Sigma_1|}$: 분산 비율 (log det 비)
- $\text{tr}(\Sigma_2^{-1}\Sigma_1)$: 공분산 형태 차이
- $(\mu_1-\mu_2)^T\Sigma_2^{-1}(\mu_1-\mu_2)$: Mahalanobis 거리 (평균 차이)
- $D$: 차원 수 (정규화 항)

### VAE에서의 KL (p.252)

$p(z) = \mathcal{N}(0, I)$, $q(z|x) = \mathcal{N}(\mu, \text{diag}(\sigma^2))$일 때:

다변량 공식에서 $\mu_2 = 0$, $\Sigma_2 = I$를 대입하면:

$$\boxed{\text{KL}(q\|p) = \frac{1}{2}\sum_{i=1}^{D}\left[\sigma_i^2 + \mu_i^2 - 1 - \log\sigma_i^2\right]}$$

> 각 차원이 독립이므로 D개의 1차원 KL의 합으로 분해됨

## 엔트로피 관련 공식 (p.255-256)

### Shannon 엔트로피

**정의** -- "분포의 불확실성(정보량) 측정"

**이산**: $H(p) = -\sum_x p(x)\log p(x)$

**연속** (differential entropy): $h(p) = -\int p(x)\log p(x) dx$

**성질**:
- $H(p) \geq 0$ (이산), 연속은 음수 가능
- 확정적 분포 (one-hot): H = 0
- 균등 분포일 때 최대

### 교차 엔트로피 (Cross-Entropy)

$$\text{CE}(p, q) = -\sum_x p(x)\log q(x) = H(p) + \text{KL}(p\|q) \geq H(p)$$

> 등호: q = p일 때 (Shannon의 Source Coding Theorem)

### 최대 엔트로피 분포 (p.256)

> "제약조건 하에서 가장 불확실한(정보가 적은) 분포"

| 제약조건 | 최대 엔트로피 분포 | 엔트로피 값 |
|---------|-----------------|-----------|
| 유한 집합 S | **Uniform(S)** | log|S| |
| 구간 [a,b] | **Uniform([a,b])** | log(b-a) |
| 평균 mu, 분산 sigma^2 고정 | **$\mathcal{N}(\mu, \sigma^2)$** | $\frac{1}{2}\log(2\pi e\sigma^2)$ |

> **핵심**: Gaussian이 "평균과 분산이 고정됐을 때 가장 불확실한 분포"라는 사실. 이것이 Gaussian 가정의 이론적 정당화.

### Gaussian 엔트로피

$$H(\mathcal{N}(\mu, \sigma^2)) = \frac{1}{2}\log(2\pi e\sigma^2)$$

**다변량**:
$$H(\mathcal{N}(\mu, \Sigma)) = \frac{D}{2}\log(2\pi e) + \frac{1}{2}\log|\Sigma|$$

## 상호정보량 (Mutual Information) -- p.258-261

### 정의

$$I(X;Y) = \text{KL}(p(x,y) \| p(x)p(y))$$

> "결합분포가 주변분포의 곱과 얼마나 다른가" = "X와 Y가 얼마나 의존적인가"

### 동치 표현

$$I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)$$

### 성질
- $I(X;Y) \geq 0$ ($\because$ KL >= 0)
- $I(X;Y) = 0$ <=> X, Y 독립 ($\because$ 독립이면 p(x,y) = p(x)p(y))
- $I(X;Y) = I(Y;X)$ (대칭! KL과 달리)
- $I(X;X) = H(X)$ (자기 자신과의 MI = 엔트로피)

## Fisher Information (p.262-263)

### Score Function

$$s(\theta; x) = \nabla_\theta \log p(x|\theta)$$

**성질**: $E[s(\theta; x)] = 0$ (정규조건 하에서)

### Fisher Information Matrix

**3가지 동치 형태**:

$$F(\theta) = E[s \cdot s^T] \quad \text{(score의 외적의 기대값)}$$

$$= -E[\nabla^2_\theta \log p(x|\theta)] \quad \text{(Hessian의 음의 기대값)}$$

$$= \text{Var}[s(\theta; x)] \quad \text{(score의 분산, } \because E[s]=0\text{)}$$

### MLE의 점근 정규성

$$\hat{\theta}_{\text{ML}} \xrightarrow{d} \mathcal{N}\left(\theta^*, \frac{1}{n}F(\theta^*)^{-1}\right) \quad (n \to \infty)$$

> Fisher Information이 클수록 MLE의 분산이 작음 = 추정이 더 정확

## KL 계산 연습

### 예제: 이산분포

p = (1/2, 1/4, 1/4), q = (1/3, 1/3, 1/3)

$$\text{KL}(p\|q) = \frac{1}{2}\log\frac{1/2}{1/3} + \frac{1}{4}\log\frac{1/4}{1/3} + \frac{1}{4}\log\frac{1/4}{1/3}$$

$$= \frac{1}{2}\log\frac{3}{2} + \frac{1}{4}\log\frac{3}{4} + \frac{1}{4}\log\frac{3}{4}$$

$$= \frac{1}{2}\log\frac{3}{2} + \frac{1}{2}\log\frac{3}{4}$$

$$= \frac{1}{2}\left(\log\frac{3}{2} + \log\frac{3}{4}\right) = \frac{1}{2}\log\frac{9}{8}$$

**검증**: log(9/8) > 0 이므로 KL > 0. (p != q이므로 당연)

**역방향도 계산해보면**:

$$\text{KL}(q\|p) = \frac{1}{3}\log\frac{1/3}{1/2} + \frac{1}{3}\log\frac{1/3}{1/4} + \frac{1}{3}\log\frac{1/3}{1/4}$$

$$= \frac{1}{3}\log\frac{2}{3} + \frac{2}{3}\log\frac{4}{3}$$

> 비대칭임을 확인: KL(p||q) != KL(q||p)

## 쉽게 설명하면
> KL은 "q 대신 p를 사용했을 때 얼마나 비효율적인가"를 숫자로 표현한 것이다.
> 교수님: "p가 q랑 같으면 로그가 0이 되죠" -- 같으면 비효율 없음, 다르면 비효율 발생

## 남에게 설명한다면
> "두 확률분포의 차이를 측정하는 도구인데, 방향에 따라 값이 달라지는 비대칭 척도다. CE = H + KL 관계를 통해 cross-entropy loss와 직접 연결된다."

## 핵심 정리
- **핵심**: KL >= 0 (Jensen), CE = H + KL, Gaussian KL 공식 암기
- **증명 2가지**: Jensen 부등식 경로, log t <= t-1 경로 -- 둘 다 등호 조건(p=q) 명시 필수
- **주의**: KL은 대칭이 아님! KL(p||q) != KL(q||p)
- **연결**: Forward KL -> MLE, Reverse KL -> VI, 분산 동일 Gaussian KL -> MSE
