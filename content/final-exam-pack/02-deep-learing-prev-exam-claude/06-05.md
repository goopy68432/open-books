## 한 줄 결론
> 행렬 미분은 "각 파라미터가 loss에 얼마나 기여하는가"를 체계적으로 계산하는 도구이다.
> 교수님의 핵심 관점: 미분 = 복잡한 함수의 **선형 근사** = **행렬**을 얻는 것

---

## 입문: 왜 행렬 미분이 필요한가?

### Goal
- 신경망의 가중치 W를 업데이트하려면 dL/dW를 계산해야 함
- 입력, 출력, 가중치가 모두 행렬/벡터이므로 행렬 미분이 필수

### 미분 = 선형 근사 = 행렬

> 교수님: "복잡한 함수를 선형으로 근사한다 이거에 있습니다"

$$f(x + \Delta x) \approx f(x) + J \cdot \Delta x$$

여기서 J가 바로 Jacobian (미분). **복잡한 비선형 함수를 1차 Taylor로 근사하면 행렬(Jacobian)이 나온다.**

이것이 Newton's Method의 기본 원리이기도 함:
> 교수님: "복잡한 함수는 다루기가 어렵고 무조건 선형으로 근사"

### 백엔드 관점
- **행렬 미분 = API 의존성 분석**: 한 서비스(파라미터) 변경이 전체 시스템(loss)에 미치는 영향을 정량화
- **Chain Rule = 마이크로서비스 호출 체인**: A->B->C에서 C의 변화가 A에 미치는 영향 = dC/dB * dB/dA

## 중급: Numerator Layout Convention과 미분 규칙

### Numerator Layout Convention (교재 기준)

> "미분을 한다는 것은 매트릭스를 얻는다는 거예요" -- 차원 규칙을 정확히 알아야 함

| 미분 | 표기 | 차원 |
|------|------|------|
| 스칼라/벡터 | ds/dv | 1 x n (행벡터) |
| 벡터/벡터 | du/dv (Jacobian) | m x n |
| 스칼라/행렬 | ds/dX | n x m (X가 m x n일 때, **전치!**) |
| Gradient | $\nabla_v s = (ds/dv)^T$ | n x 1 (열벡터) |

> **주의**: Numerator layout에서 ds/dx는 행벡터, gradient $\nabla s$는 열벡터. 혼동 주의!

### 기본 벡터 미분 공식

$$\frac{d(a^T x)}{dx} = a^T$$

$$\frac{d(x^T Ax)}{dx} = x^T(A + A^T)$$

$$\frac{d(x^T Sx)}{dx} = 2x^T S \quad \text{(S 대칭일 때, } A+A^T = 2S\text{)}$$

$$\frac{d(\|x\|^2)}{dx} = \frac{d(x^T x)}{dx} = 2x^T$$

$$\frac{d(Ax)}{dx} = A$$

### Gradient 형태 (열벡터)

$$\nabla_\theta \left(\frac{1}{2}\theta^T S\theta + a^T\theta\right) = S\theta + a \quad \text{(S 대칭)}$$

## 고급: 핵심 미분 전개

### 1. Chain Rule (연쇄법칙)

$$\frac{d(f \circ g(x))}{dx} = \frac{df(y)}{dy}\bigg|_{y=g(x)} \cdot \frac{dg(x)}{dx}$$

**차원 일관성** (반드시 확인!):

$$\underbrace{\frac{df}{dx}}_{d(f) \times d(x)} = \underbrace{\frac{df}{dy}}_{d(f) \times d(y)} \cdot \underbrace{\frac{dy}{dx}}_{d(y) \times d(x)}$$

> 행렬 곱의 내부 차원 d(y)가 일치해야 한다. 일치하지 않으면 전치(transpose)가 필요.

### 2. Product Rule

**스칼라 출력**: $\frac{d(f(x)^T g(x))}{dx} = g(x)^T \cdot \frac{df}{dx} + f(x)^T \cdot \frac{dg}{dx}$

**노름 제곱**: $\frac{d(\|f(x)\|^2)}{dx} = 2f(x)^T \cdot \frac{df(x)}{dx}$

### 3. Trace 미분 (행렬 미분의 핵심 도구)

> 행렬->스칼라 미분에서 Trace trick이 핵심

$$\frac{d\,\text{Tr}(AX)}{dX} = A$$

$$\frac{d\,\text{Tr}(XA)}{dX} = A^T$$

$$\frac{d\,\text{Tr}(X^T SX)}{dX} = 2X^T S \quad \text{(S 대칭)}$$

$$\frac{d\,\text{Tr}(XSX^T)}{dX} = 2SX^T \quad \text{(S 대칭)}$$

$$\frac{d(\|X\|_F^2)}{dX} = 2X^T$$

### 4. 행렬 미분: a^T Xb

$$\frac{d(a^T Xb)}{dX} = ba^T$$

$$\nabla_X(a^T Xb) = ab^T$$

## Softmax 미분 -- 시험 핵심 (교수님 2주차 직접 유도)

### Softmax 정의 (p.096)

$$p_i = \text{softmax}(z)_i = \frac{\exp(z_i)}{\sum_k \exp(z_k)} = \frac{e^{z_i}}{S}, \quad S = \sum_k e^{z_k}$$

### Jacobian 유도 (Quotient Rule)

> 교수님이 2주차에서 quotient rule로 직접 유도한 것

**Quotient Rule**: $\frac{d}{dx}\frac{f}{g} = \frac{f'g - fg'}{g^2}$

**Case i = j** (같은 인덱스):

$$\frac{\partial p_i}{\partial z_i} = \frac{e^{z_i} \cdot S - e^{z_i} \cdot e^{z_i}}{S^2}$$

분자: $e^{z_i}(S - e^{z_i})$

$$= \frac{e^{z_i}}{S} \cdot \frac{S - e^{z_i}}{S} = p_i\left(1 - \frac{e^{z_i}}{S}\right) = p_i(1 - p_i)$$

$$\boxed{\frac{\partial p_i}{\partial z_i} = p_i(1 - p_i)}$$

**Case i != j** (다른 인덱스):

$p_i = e^{z_i}/S$에서 $z_j$로 미분. 분자 $e^{z_i}$는 $z_j$에 무관 -> $f' = 0$:

$$\frac{\partial p_i}{\partial z_j} = \frac{0 \cdot S - e^{z_i} \cdot e^{z_j}}{S^2} = -\frac{e^{z_i}}{S} \cdot \frac{e^{z_j}}{S} = -p_i p_j$$

$$\boxed{\frac{\partial p_i}{\partial z_j} = -p_i \cdot p_j \quad (i \neq j)}$$

### 행렬 형태 (Jacobian)

두 case를 통합하면:

$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j) \quad \text{(Kronecker delta 사용)}$$

$$\boxed{\frac{\partial \mathbf{p}}{\partial \mathbf{z}} = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T}$$

**성질**:
- $\text{diag}(\mathbf{p})$: 대각행렬, 대각 성분이 $p_1, ..., p_K$
- $\mathbf{p}\mathbf{p}^T$: rank-1 행렬 (외적)
- 각 행의 합 = 0 ($\because \sum_i p_i = 1$ 제약 반영)
- 결과 행렬의 rank = K-1

## Softmax + Cross-Entropy 결합 미분 -- 놀랍도록 간단

$$L = -\log p_y = -\log[\text{softmax}(z)]_y$$

Chain rule:

$$\frac{\partial L}{\partial z_j} = -\frac{1}{p_y} \cdot \frac{\partial p_y}{\partial z_j}$$

**j = y일 때**:
$$= -\frac{1}{p_y} \cdot p_y(1-p_y) = -(1-p_y) = p_y - 1$$

**j != y일 때**:
$$= -\frac{1}{p_y} \cdot (-p_y \cdot p_j) = p_j$$

통합하면:

$$\boxed{\frac{\partial(-\log p_y)}{\partial \mathbf{z}} = \mathbf{p} - \mathbf{e}_y}$$

> **이것이 놀랍도록 간단!** 예측 확률 벡터 p에서 one-hot 정답 벡터 $\mathbf{e}_y$를 빼면 끝.
> 완벽히 맞추면($p_y = 1$) gradient = 0, 틀릴수록 gradient 커짐.

## -log sigma(Ax + b) 미분

### Sigmoid 함수 성질

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**미분** (이것도 quotient rule로 유도 가능):

$$\sigma'(z) = \sigma(z)(1 - \sigma(z))$$

> 증명: $\sigma' = \frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}} \cdot \frac{e^{-z}}{1+e^{-z}} = \sigma(z)(1-\sigma(z))$

### 전체 미분 (Chain Rule)

$f(x) = -\log\sigma(a^T x + b)$, $z = a^T x + b$로 놓으면:

$$\frac{df}{dx} = \underbrace{\frac{df}{d\sigma}}_{-1/\sigma} \cdot \underbrace{\frac{d\sigma}{dz}}_{\sigma(1-\sigma)} \cdot \underbrace{\frac{dz}{dx}}_{a^T}$$

$$= -\frac{1}{\sigma(z)} \cdot \sigma(z)(1-\sigma(z)) \cdot a^T = -(1-\sigma(z)) \cdot a^T$$

$$\boxed{\nabla_x f = -(1-\sigma(a^T x + b)) \cdot a = (\sigma(a^T x + b) - 1) \cdot a}$$

### A가 행렬일 때: $f(x) = -\log\sigma(Ax + b)$ (벡터 함수)

$$\frac{\partial f}{\partial x} = -(\mathbf{1} - \sigma(Ax+b))^T \cdot A$$

## 선형회귀 Gradient (p.094)

$$L = \|Wx - y\|^2 = (Wx - y)^T(Wx - y)$$

Chain rule 또는 직접 전개:

$$\frac{dL}{dW} = \frac{d}{dW}\text{tr}[(Wx-y)(Wx-y)^T]$$

Product rule 적용:

$$\boxed{\nabla_W L = 2(Wx - y)x^T}$$

> **외적(outer product) 구조**: 오차 벡터 $(Wx-y)$와 입력 벡터 $x^T$의 외적.
> 이것이 Hebbian Learning의 수학적 기초: "함께 활성화되는 뉴런의 연결이 강화된다"

## VJP vs JVP (p.098-104)

> **교수님**: "loss가 스칼라이므로 VJP가 효율적" -- 이것이 backprop의 핵심 이유

### JVP (Jacobian-Vector Product, Forward Mode AD)

$$\text{JVP}: \quad J \cdot v = \frac{du}{dv} \cdot v \in \mathbb{R}^m$$

- 입력 방향으로 **하나의 방향벡터 v**에 대한 미분을 계산
- 비용: 입력 차원 n개 방향 각각에 대해 반복 -> O(n) 회 forward pass

### VJP (Vector-Jacobian Product, Reverse Mode AD = Backpropagation)

$$\text{VJP}: \quad u^T \cdot J = u^T \cdot \frac{du}{dv} \in \mathbb{R}^{1 \times n}$$

- 출력 방향으로 **하나의 벡터 u**에 대한 미분을 계산
- 비용: 출력 차원 m개 방향 각각에 대해 반복 -> O(m) 회 backward pass

### 왜 Backprop(VJP)을 쓰는가?

**Loss가 스칼라이면 m = 1** -> 단 **1번의 backward pass**로 모든 파라미터의 gradient를 동시에 계산!

| | JVP (Forward) | VJP (Backward) |
|---|---|---|
| 비용 | O(n) = 입력 차원 | O(m) = 출력 차원 |
| DL에서 | n = 수백만 파라미터 | **m = 1 (loss는 스칼라)** |
| 효율성 | 매우 비효율적 | **1회로 끝!** |

> **핵심**: 딥러닝에서 loss는 항상 스칼라 -> VJP(역전파)가 n/m = n배 효율적

## Backpropagation 전체 흐름

### Forward Pass

```
x -> [W_1] -> z_1 -> [sigma] -> a_1 -> [W_2] -> z_2 -> [softmax] -> y_hat -> [CE] -> L
```

각 단계에서 중간값 저장 (backward에서 사용)

### Backward Pass (Chain Rule, VJP 방식)

```
dL/dy_hat = y_hat - y                         (softmax+CE 결합: p - e_y)
dL/dW_2 = (dL/dz_2) * a_1^T                   (외적 구조)
dL/da_1 = W_2^T * (dL/dz_2)                   (역방향 전파)
dL/dz_1 = (dL/da_1) . sigma'(z_1)             (원소별 곱, Hadamard product)
dL/dW_1 = (dL/dz_1) * x^T                     (외적 구조)
```

### 핵심 패턴: 외적 구조

$$\boxed{\frac{\partial L}{\partial W} = \delta \cdot \text{input}^T}$$

여기서 $\delta$는 해당 레이어의 **error signal** (상위 레이어에서 역전파된 gradient)

$$\Delta W_\ell = \delta_\ell \cdot a_{\ell-1}^T$$

> 가중치 업데이트 = (그 레이어의 오차) * (그 레이어의 입력)의 **외적(outer product)**
> 이것이 모든 레이어에서 반복되는 패턴

## 행렬 미분 주의사항

1. **AB != BA**: 행렬 곱은 교환법칙 불성립! 차원 맞추기에서 항상 주의
2. **차원 확인 필수**: Jacobian 차원 = (출력 차원) x (입력 차원)
3. **Transpose 관계**: Gradient $\nabla f = (df/dx)^T$ -- numerator layout vs gradient 혼동 금지
4. **i=j vs i!=j**: Softmax Jacobian에서 반드시 case 분리하여 유도
5. **Chain Rule 차원**: 중간 차원이 일치하는지 반드시 확인

## 남에게 설명한다면
> "역전파는 출력에서 입력 방향으로 chain rule을 적용해서, 모든 가중치의 gradient를 한 번에 구하는 알고리즘이다. Loss가 스칼라이기 때문에 VJP(역방향) 1회면 모든 gradient를 얻는다."

## 핵심 정리
- **핵심**: Softmax Jacobian = diag(p) - pp^T, Softmax+CE 결합 = p - e_y, 외적 구조 Delta_W = delta * x^T
- **교수님 강조**: 미분 = 행렬(선형 근사), VJP가 backprop의 핵심 (loss가 스칼라이므로)
- **시험 유도**: Softmax Jacobian은 quotient rule로 i=j/i!=j 분리하여 유도, sigma'(z) = sigma(z)(1-sigma(z))
- **주의**: numerator layout에서 차원 맞추기, chain rule 중간 차원 확인
