## 1. MLE vs MAP

| 항목 | MLE (Maximum Likelihood Estimation) | MAP (Maximum A Posteriori) |
|------|------|------|
| **목적** | $\hat{\theta}_{MLE} = \arg\max_\theta P(D \mid \theta)$ | $\hat{\theta}_{MAP} = \arg\max_\theta P(\theta \mid D)$ |
| **확률적 근거** | 가능도(likelihood)만 최대화 | **사후확률(posterior)** 최대화 |
| **Prior 사용** | 사용하지 않음 (또는 uniform prior) | $P(\theta)$를 명시적으로 사용 |
| **유도** | $\arg\max_\theta \prod_i P(x_i \mid \theta)$ | $\arg\max_\theta P(D\mid\theta)P(\theta)$ (Bayes 정리) |
| **가설 공간** | 제한 없음 | Prior가 가설 공간에 제약을 부여 |
| **과적합** | 데이터가 적으면 과적합 경향 | **Prior가 정규화 역할** → 과적합 완화 |
| **DL 아키텍처 대응** | 일반 손실 최소화 | **Weight decay = Gaussian prior의 MAP** |
| **핵심 관계** | MAP에서 $P(\theta) = \text{const}$이면 MLE와 동치 | $\log P(\theta\mid D) = \log P(D\mid\theta) + \log P(\theta) + \text{const}$ |

**핵심 차이**: MAP = MLE + Prior. Gaussian prior $P(\theta) \sim \mathcal{N}(0, \sigma^2I)$를 쓰면 MAP 목적함수에 $\frac{\lambda}{2}\|\theta\|^2$ 항이 추가되어 L2 정규화와 동치.

### 시험에서 물어볼 수 있는 질문
- "L2 regularization이 MAP 관점에서 어떤 prior에 대응하는지 유도하시오."
- "데이터가 무한히 많아지면 MAP와 MLE의 관계는?"
- "$P(\theta) \propto \exp(-\lambda\|\theta\|_1)$일 때 MAP 추정은 어떤 정규화에 대응하는가?"

## 2. CE Loss vs MSE Loss

| 항목 | Cross-Entropy Loss | MSE Loss |
|------|------|------|
| **확률 가정** | $y \sim \text{Bernoulli}(p)$ 또는 Categorical | $y \sim \mathcal{N}(\mu, \sigma^2)$ |
| **수식** | $-\sum_k y_k \log \hat{y}_k$ | $\frac{1}{n}\sum_i (y_i - \hat{y}_i)^2$ |
| **MLE 유도 경로** | Bernoulli NLL → $-[y\log p + (1-y)\log(1-p)]$ | Gaussian NLL → $\frac{1}{2\sigma^2}(y-\mu)^2 + \text{const}$ |
| **그래디언트 특성** | Sigmoid 출력 시: $\hat{y} - y$ (**포화 없음**) | Sigmoid 출력 시: $(\hat{y}-y)\hat{y}(1-\hat{y})$ (**포화 발생**) |
| **적용 태스크** | 분류 (이진/다중) | 회귀 |
| **출력 활성화** | Sigmoid / Softmax | 항등함수 (identity) |
| **값 범위** | $[0, \infty)$ | $[0, \infty)$ |

**핵심 차이**: CE는 Bernoulli 분포의 NLL, MSE는 Gaussian 분포의 NLL에서 유도. 분류에 MSE를 쓰면 sigmoid 포화 구간에서 gradient vanishing 발생.

### 시험에서 물어볼 수 있는 질문
- "이진 분류에서 CE Loss를 Bernoulli 분포의 NLL로부터 유도하시오."
- "MSE를 Gaussian 분포의 MLE로부터 유도하시오. $\sigma^2$의 MLE도 구하시오."
- "분류 문제에서 MSE 대신 CE를 쓰는 이유를 gradient 관점에서 설명하시오."

## 3. 베이지안 vs 빈도주의

| 항목 | 베이지안 (Bayesian) | 빈도주의 (Frequentist) |
|------|------|------|
| **확률의 의미** | **믿음의 정도** (degree of belief) | **장기 빈도** (long-run frequency) |
| **파라미터 $\theta$** | 확률변수 → 분포를 가짐 | 고정된 미지수 (상수) |
| **대상** | $P(\theta \mid D)$ 사후분포 전체 | $\hat{\theta}$ 점추정값 |
| **학습 방법** | $P(\theta\mid D) \propto P(D\mid\theta)P(\theta)$ | $\hat{\theta} = \arg\max_\theta P(D\mid\theta)$ |
| **불확실성 표현** | 사후분포의 분산으로 자연스럽게 표현 | 신뢰구간 (confidence interval) |
| **예측** | $P(y^*\mid x^*, D) = \int P(y^*\mid x^*,\theta)P(\theta\mid D)d\theta$ | $P(y^*\mid x^*, \hat{\theta})$ |
| **DL 대응** | Bayesian Neural Network, MC Dropout | 일반 SGD 학습 |
| **장점** | 불확실성 정량화, 과적합 방지 | 계산 효율적, 대규모 모델 가능 |

**핵심 차이**: 빈도주의는 $\theta$를 상수로 보고 점추정, 베이지안은 $\theta$를 확률변수로 보고 분포 추정.

### 시험에서 물어볼 수 있는 질문
- "Bayesian predictive distribution $P(y^*\mid x^*, D) = \int P(y^*\mid x^*,\theta)P(\theta\mid D)d\theta$의 의미를 설명하시오."
- "빈도주의의 MLE 추정이 베이지안 관점에서 어떤 특수 케이스인지 설명하시오."
- "Bayesian 접근에서 과적합이 완화되는 이유를 수학적으로 설명하시오."

## 4. Prior vs Likelihood vs Posterior

| 항목 | Prior $P(\theta)$ | Likelihood $P(D\mid\theta)$ | Posterior $P(\theta\mid D)$ |
|------|------|------|------|
| **정의** | 데이터 관측 전 $\theta$에 대한 사전 믿음 | 주어진 $\theta$에서 데이터가 나올 확률 | 데이터 관측 후 $\theta$에 대한 사후 믿음 |
| **역할** | 정규화 / 사전 지식 반영 | 데이터 적합도 측정 | 학습 결과 |
| **수식 관계** | — | — | $P(\theta\mid D) = \frac{P(D\mid\theta)P(\theta)}{P(D)}$ |
| **DL 대응** | 정규화 항 (weight decay 등) | 손실 함수 (NLL) | 학습된 파라미터 분포 |
| **$\theta$의 함수?** | Yes | Yes ($D$ 고정 시) | Yes |
| **$D$의 함수?** | No | Yes | Yes |

**핵심 차이**: Posterior $\propto$ Likelihood $\times$ Prior. 로그 취하면 $\log P(\theta\mid D) = \log P(D\mid\theta) + \log P(\theta) - \log P(D)$로 **손실 = NLL + 정규화 + 상수**.

### 시험에서 물어볼 수 있는 질문
- "Bayes 정리를 이용하여 posterior를 유도하고, 각 항의 DL에서의 의미를 쓰시오."
- "Evidence $P(D) = \int P(D\mid\theta)P(\theta)d\theta$가 MAP에서 무시 가능한 이유를 설명하시오."
- "Conjugate prior의 의미와 예시를 들시오."

## 5. Range vs Null Space

| 항목 | Range (열공간, $\text{Col}(A)$) | Null Space (영공간, $\text{Null}(A)$) |
|------|------|------|
| **정의** | $\text{Col}(A) = \{Ax : x \in \mathbb{R}^n\}$ | $\text{Null}(A) = \{x : Ax = 0\}$ |
| **의미** | $A$로 도달 가능한 출력의 집합 | $A$에 의해 영벡터로 보내지는 입력의 집합 |
| **차원** | $\text{rank}(A)$ | $\text{nullity}(A) = n - \text{rank}(A)$ |
| **직교 관계** | $\text{Col}(A) \perp \text{Null}(A^T)$ | $\text{Null}(A) \perp \text{Col}(A^T)$ |
| **Rank-Nullity** | $\dim(\text{Col}(A)) + \dim(\text{Null}(A)) = n$ | (동일 정리) |
| **DL 관련** | 표현 가능한 출력 공간 | 정보 손실 방향 |

**핵심 차이**: Range는 "갈 수 있는 곳", Null Space는 "사라지는 곳". $A \in \mathbb{R}^{m \times n}$이면 4개의 기본 부분공간이 두 쌍의 직교보공간을 형성.

### 시험에서 물어볼 수 있는 질문
- "Rank-Nullity Theorem을 증명하시오."
- "$A \in \mathbb{R}^{m \times n}$의 4개 기본 부분공간과 그 직교 관계를 도시하시오."
- "Null space가 trivial ($\{0\}$)일 조건을 rank와 연결하여 설명하시오."

## 6. 고유값 분해 (EVD) vs 특이값 분해 (SVD)

| 항목 | 고유값 분해 (Eigendecomposition) | 특이값 분해 (SVD) |
|------|------|------|
| **적용 행렬** | **정방행렬** ($n \times n$), 대각화 가능 | **모든 행렬** ($m \times n$) |
| **분해 형태** | $A = Q\Lambda Q^{-1}$ | $A = U\Sigma V^T$ |
| **대칭행렬** | $A = Q\Lambda Q^T$ (직교 대각화) | SVD와 일치: $U=Q, \Sigma=\Lambda, V=Q$ |
| **사용 조건** | 대각화 가능 (고유벡터 $n$개 독립) | **항상 존재** |
| **구성 요소** | $Q$: 고유벡터, $\Lambda$: 고유값 | $U$: 좌특이벡터, $\Sigma$: 특이값, $V$: 우특이벡터 |
| **고유값 vs 특이값** | $\lambda_i$ (음수 가능) | $\sigma_i \geq 0$ 항상 비음수 |
| **관계** | — | $\sigma_i = \sqrt{\lambda_i(A^TA)}$ |
| **DL 사용** | Hessian 분석, PCA (공분산) | 차원축소, 행렬 근사, 초기화 |

**핵심 차이**: EVD는 정방행렬 전용이고 고유값이 음수일 수 있음. SVD는 모든 행렬에 적용 가능하고 특이값은 항상 비음수. 대칭 PSD 행렬에서는 $\sigma_i = \lambda_i$.

### 시험에서 물어볼 수 있는 질문
- "$A^TA$의 고유값 분해와 $A$의 SVD의 관계를 유도하시오."
- "SVD를 이용한 최적 rank-$k$ 근사 (Eckart-Young 정리)를 설명하시오."
- "PCA가 공분산 행렬의 고유값 분해 또는 데이터 행렬의 SVD로 수행될 수 있음을 보이시오."

## 7. PSD vs PD 행렬

| 항목 | Positive Semi-Definite (PSD) | Positive Definite (PD) |
|------|------|------|
| **정의** | $x^TAx \geq 0, \;\forall x$ | $x^TAx > 0, \;\forall x \neq 0$ |
| **고유값** | $\lambda_i \geq 0$ | $\lambda_i > 0$ |
| **가역성** | 가역이 아닐 수 있음 ($\det = 0$ 가능) | **항상 가역** ($\det > 0$) |
| **Null space** | $\text{Null}(A) \neq \{0\}$ 가능 | $\text{Null}(A) = \{0\}$ |
| **Cholesky 분해** | $A = LL^T$ (pseudo) | $A = LL^T$ (유일) |
| **DL 대응** | Hessian이 PSD → 극소점 **후보** | Hessian이 PD → **강한 극소점** |
| **예시** | $A^TA$ (항상 PSD) | $A^TA$ ($A$가 full column rank이면 PD) |

**핵심 차이**: PD ⊂ PSD. PD는 모든 고유값이 **순양수**로 가역성이 보장되며, 볼록 최적화에서 강볼록 함수의 Hessian에 해당.

### 시험에서 물어볼 수 있는 질문
- "$A^TA$가 항상 PSD임을 증명하시오."
- "Hessian이 PSD일 때와 PD일 때의 최적화 관점 차이를 설명하시오."
- "$A^TA$가 PD가 되기 위한 필요충분조건을 $A$의 rank로 표현하시오."

## 8. 내적 vs 외적

| 항목 | 내적 (Inner Product) | 외적 (Outer Product) |
|------|------|------|
| **수식** | $\langle u, v \rangle = u^Tv = \sum_i u_iv_i$ | $uv^T$ |
| **결과 차원** | 스칼라 ($\mathbb{R}$) | **행렬** ($\mathbb{R}^{m \times n}$) |
| **기하학적 의미** | 유사도, 투영 길이 | Rank-1 행렬 생성 |
| **DL 사용 (내적)** | Attention score: $q^Tk$, 뉴런 연산: $w^Tx + b$ | — |
| **DL 사용 (외적)** | — | Gradient 외적: $\delta \cdot x^T$, rank-1 update |
| **교환법칙** | $u^Tv = v^Tu$ | $uv^T \neq vu^T$ (일반적으로) |
| **관련 정리** | Cauchy-Schwarz: $|u^Tv| \leq \|u\|\|v\|$ | $\text{rank}(uv^T) = 1$ ($u,v \neq 0$) |

**핵심 차이**: 내적은 스칼라(유사도), 외적은 행렬(rank-1 구조). 역전파에서 weight gradient $\nabla_W L = \delta \cdot x^T$는 외적 형태.

### 시험에서 물어볼 수 있는 질문
- "역전파에서 weight gradient가 외적 형태로 나타남을 유도하시오."
- "Attention mechanism에서 내적이 어떻게 유사도를 측정하는지 수학적으로 설명하시오."
- "$uv^T$의 rank가 1임을 증명하시오."

## 9. Gradient vs Jacobian vs Hessian

| 항목 | Gradient $\nabla f$ | Jacobian $J$ | Hessian $H$ |
|------|------|------|------|
| **함수** | $f: \mathbb{R}^n \to \mathbb{R}$ | $f: \mathbb{R}^n \to \mathbb{R}^m$ | $f: \mathbb{R}^n \to \mathbb{R}$ |
| **크기** | 벡터 $\in \mathbb{R}^n$ | 행렬 $\in \mathbb{R}^{m \times n}$ | 행렬 $\in \mathbb{R}^{n \times n}$ |
| **정의** | $(\nabla f)_i = \frac{\partial f}{\partial x_i}$ | $J_{ij} = \frac{\partial f_i}{\partial x_j}$ | $H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$ |
| **DL에서의 역할** | 파라미터 업데이트 방향 | Chain rule의 핵심: $\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}J$ | 곡률 정보, 2차 최적화 |
| **계산 비용** | $O(n)$ | $O(mn)$ | $O(n^2)$ 저장, $O(n^3)$ 역행렬 |
| **대칭성** | — | 일반적으로 비대칭 | **대칭** ($H_{ij} = H_{ji}$, Schwarz 정리) |

**핵심 차이**: Gradient는 1차 미분(벡터), Jacobian은 벡터 함수의 1차 미분(행렬), Hessian은 스칼라 함수의 2차 미분(대칭 행렬). 역전파의 chain rule은 Jacobian의 곱.

### 시험에서 물어볼 수 있는 질문
- "다층 네트워크에서 chain rule을 Jacobian 곱으로 표현하시오."
- "Hessian이 대칭행렬임을 보이시오 (Schwarz/Clairaut 정리)."
- "Hessian의 고유값이 수렴 속도에 미치는 영향을 condition number로 설명하시오."

## 10. JVP vs VJP

| 항목 | JVP (Jacobian-Vector Product) | VJP (Vector-Jacobian Product) |
|------|------|------|
| **수식** | $Jv$ ($J \in \mathbb{R}^{m \times n}$, $v \in \mathbb{R}^n$) | $v^TJ$ ($v \in \mathbb{R}^m$, $J \in \mathbb{R}^{m \times n}$) |
| **방향** | **순방향** (Forward mode AD) | **역방향** (Reverse mode AD = Backprop) |
| **계산** | 입력 방향으로 perturbation 전파 | 출력에서 입력으로 gradient 전파 |
| **효율적인 경우** | $n \ll m$ (입력 적고 출력 많을 때) | $m \ll n$ (**출력 적고 입력 많을 때**) |
| **DL에서** | 거의 사용하지 않음 | **역전파의 핵심** (Loss는 스칼라 → $m=1$) |
| **비용** | 1회 JVP = 1회 forward pass 비용 | 1회 VJP = 1회 forward + backward pass 비용 |
| **Jacobian 전체 계산** | $n$번 JVP 필요 | $m$번 VJP 필요 |

**핵심 차이**: DL에서 Loss는 스칼라($m=1$)이므로 VJP 1회로 모든 파라미터의 gradient를 구할 수 있어 역전파가 효율적. JVP는 $n$번 필요.

## 11. 볼록 vs 강볼록 vs β-smooth

| 항목 | 볼록 (Convex) | 강볼록 (μ-Strongly Convex) | β-Smooth |
|------|------|------|------|
| **정의** | $f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$ | $f(y) \geq f(x) + \nabla f(x)^T(y-x) + \frac{\mu}{2}\|y-x\|^2$ | $\|\nabla f(x) - \nabla f(y)\| \leq \beta\|x-y\|$ |
| **Hessian 조건** | $H \succeq 0$ (PSD) | $H \succeq \mu I$ ($\mu > 0$) | $H \preceq \beta I$ |
| **극소점** | 전역 극소 존재 (유일하지 않을 수 있음) | **유일한 전역 극소** | — (단독으로는 극소 보장 안 됨) |
| **GD 수렴률** | $O(1/T)$ (sublinear) | $O((1-\mu/\beta)^T)$ (**선형 수렴**) | $O(1/T)$ (β-smooth + convex) |
| **최적 학습률** | — | $\eta = 1/\beta$ | $\eta \leq 1/\beta$ |
| **직관** | 아래로 볼록한 그릇 | 날카로운 그릇 (최소점이 뾰족) | 기울기가 급변하지 않음 |

**핵심 차이**: 강볼록은 "최소점으로 끌어당기는 힘" ($\mu$), β-smooth는 "gradient의 최대 변화율" ($\beta$). Condition number $\kappa = \beta/\mu$가 수렴 속도를 결정.

### 시험에서 물어볼 수 있는 질문

- "Condition number $\kappa = \beta/\mu$가 수렴에 미치는 영향을 설명하시오."
- "β-smooth 조건 하에서 최적 학습률 $\eta = 1/\beta$를 유도하시오."

## 12. Entropy vs Cross-Entropy vs KL Divergence

| 항목 | Entropy $H(p)$ | Cross-Entropy $H(p,q)$ | KL Divergence $D_{KL}(p\|q)$ |
|------|------|------|------|
| **정의** | $-\sum_x p(x)\log p(x)$ | $-\sum_x p(x)\log q(x)$ | $\sum_x p(x)\log\frac{p(x)}{q(x)}$ |
| **의미** | $p$의 불확실성 (정보량) | $q$로 $p$를 인코딩하는 평균 비트 수 | $q$가 $p$와 얼마나 다른지 (정보 손실) |
| **관계** | — | $H(p,q) = H(p) + D_{KL}(p\|q)$ | $D_{KL}(p\|q) = H(p,q) - H(p)$ |
| **최솟값** | $H(p) \geq 0$ (등호: $p$ 결정적) | $H(p,q) \geq H(p)$ | $D_{KL} \geq 0$ (Gibbs 부등식) |
| **대칭성** | — | 비대칭 | **비대칭**: $D_{KL}(p\|q) \neq D_{KL}(q\|p)$ |
| **최소화 의미** | — | $q$를 $p$에 맞추기 (**분류 손실**) | $q$를 $p$에 맞추기 |
| **DL에서** | 정보론적 해석 | **분류 손실 함수** | VAE 손실, 지식 증류 |

**핵심 차이**: $p$ 고정 시 CE 최소화 = KL 최소화 (H(p)는 상수이므로). CE Loss는 KL Divergence + 상수.

- "CE Loss 최소화가 KL Divergence 최소화와 동치임을 보이시오."
- "Entropy가 최대가 되는 분포는 무엇인가? (이산: 균등분포, 연속: Gaussian)"

## 13. Forward KL vs Reverse KL

| 항목 | Forward KL: $D_{KL}(p\|q)$ | Reverse KL: $D_{KL}(q\|p)$ |
|------|------|------|
| **수식** | $\sum_x p(x)\log\frac{p(x)}{q(x)}$ | $\sum_x q(x)\log\frac{q(x)}{p(x)}$ |
| **기대값 기준** | $p$ (진짜 분포) 하에서 기대값 | $q$ (근사 분포) 하에서 기대값 |
| **행동 패턴** | **Mode-covering** (zero-avoiding) | **Mode-seeking** (zero-forcing) |
| **$p(x) > 0$인 곳** | $q(x) > 0$이어야 함 (빠뜨리지 않음) | $q(x) = 0$이면 무시 |
| **$p(x) = 0$인 곳** | $q(x) > 0$이어도 괜찮음 | $q(x) > 0$이면 $\infty$ 벌점 |
| **다봉 분포 근사** | 모든 mode를 커버 → 퍼진 분포 | 하나의 mode에 집중 → 뾰족한 분포 |
| **DL 사용** | 지식 증류, 변분 추론의 대안 | **VAE (ELBO)**, 변분 추론 |

**핵심 차이**: Forward KL은 $p$가 있는 곳을 $q$가 반드시 커버 (mode-covering), Reverse KL은 $q$가 있는 곳에 $p$가 반드시 있어야 함 (mode-seeking).

- "VAE에서 Reverse KL을 사용하는 이유와 그 결과를 설명하시오."
- "다봉 분포 $p$를 단봉 $q$로 근사할 때 Forward KL과 Reverse KL의 결과를 그림으로 비교하시오."

## 14. L1 vs L2 Regularization

| 항목 | L1 (Lasso) | L2 (Ridge / Weight Decay) |
|------|------|------|
| **페널티 항** | $\lambda\sum_i \|\theta_i\|$ | $\frac{\lambda}{2}\sum_i \theta_i^2$ |
| **MAP prior** | $\theta_i \sim \text{Laplace}(0, b)$ | $\theta_i \sim \mathcal{N}(0, \sigma^2)$ |
| **Gradient** | $\lambda \cdot \text{sign}(\theta_i)$ (불연속) | $\lambda \theta_i$ (연속) |
| **Sparsity** | **유도함** (많은 $\theta_i = 0$) | 유도하지 않음 (작지만 0은 아님) |
| **기하학적 해석** | L1 ball은 꼭짓점에서 축과 만남 | L2 ball은 원 → 축 위 해 아님 |
| **Feature selection** | 자동으로 수행 | 수행하지 않음 |
| **미분 가능성** | $\theta_i = 0$에서 미분 불가 | 모든 곳에서 미분 가능 |
| **최적화** | Proximal gradient, ISTA | 일반 GD |

**핵심 차이**: L1은 Laplace prior → sparsity 유도 (feature selection). L2는 Gaussian prior → 가중치 축소 (shrinkage). 기하학적으로 L1 ball의 꼭짓점이 sparse 해를 만듦.

- "Elastic Net ($\alpha L1 + (1-\alpha)L2$)의 장점을 설명하시오."

## 15. Bernoulli vs Gaussian 분포

| 항목 | Bernoulli | Gaussian |
|------|------|------|
| **확률변수** | 이산: $x \in \{0, 1\}$ | 연속: $x \in \mathbb{R}$ |
| **파라미터** | $p$ (성공 확률) | $\mu$ (평균), $\sigma^2$ (분산) |
| **PMF/PDF** | $P(x) = p^x(1-p)^{1-x}$ | $p(x) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$ |
| **MLE** | $\hat{p} = \frac{1}{n}\sum x_i$ (표본 평균) | $\hat{\mu} = \bar{x}$, $\hat{\sigma}^2 = \frac{1}{n}\sum(x_i - \bar{x})^2$ |
| **NLL → Loss** | **Cross-Entropy Loss** | **MSE Loss** (+ const) |
| **출력 활성화** | Sigmoid: $\sigma(z) = \frac{1}{1+e^{-z}}$ | Identity (항등함수) |
| **적용** | 이진 분류 | 회귀 |
| **충분통계량** | $\sum x_i$ | $\sum x_i$, $\sum x_i^2$ |

**핵심 차이**: 분류 = Bernoulli 가정 → CE Loss. 회귀 = Gaussian 가정 → MSE Loss. 손실 함수 선택의 확률론적 근거.

## 16. 선형변환 vs 아핀변환

| 항목 | 선형변환 (Linear Transformation) | 아핀변환 (Affine Transformation) |
|------|------|------|
| **정의** | $T(x) = Wx$ | $T(x) = Wx + b$ |
| **원점 보존** | $T(0) = 0$ (**항상 원점 통과**) | $T(0) = b$ (일반적으로 원점 비통과) |
| **가법성** | $T(x+y) = T(x) + T(y)$ | 성립하지 않음 |
| **동차성** | $T(\alpha x) = \alpha T(x)$ | 성립하지 않음 |
| **DL에서** | bias 없는 layer | **일반 Dense layer**: $y = Wx + b$ |
| **기하학적 해석** | 회전, 스케일링, 반사 (원점 고정) | 선형변환 + **평행이동** |
| **표현력** | 원점을 지나는 초평면만 표현 | 임의의 초평면 표현 가능 |

**핵심 차이**: 아핀변환 = 선형변환 + 평행이동(bias). DL의 Dense layer $y = Wx + b$는 아핀변환이지만 관습적으로 "선형 층"이라 부름. 엄밀하게는 선형이 아님.

## 17. Rank vs Nullity

| 항목 | Rank | Nullity |
|------|------|------|
| **정의** | $\text{rank}(A) = \dim(\text{Col}(A))$ | $\text{nullity}(A) = \dim(\text{Null}(A))$ |
| **의미** | 독립인 열(또는 행)의 수 | $Ax=0$의 해공간 차원 |
| **최대값** | $\min(m, n)$ | $n$ ($A \in \mathbb{R}^{m \times n}$) |
| **Full rank 조건** | $\text{rank}(A) = \min(m, n)$ | $\text{nullity}(A) = n - \min(m,n)$ 또는 0 |
| **Rank-Nullity 정리** | $\text{rank}(A) + \text{nullity}(A) = n$ | (동일) |
| **가역성 ($n=n$)** | $\text{rank} = n$ → 가역 | $\text{nullity} = 0$ → 가역 |
| **DL 관련** | 레이어의 표현력 (rank deficient → 정보 손실) | 중복 파라미터, weight space의 대칭 |

**핵심 차이**: Rank + Nullity = 입력 차원 $n$. Rank는 "유효 정보 차원", Nullity는 "손실/중복 차원".

## 18. 마르코프 vs 체비셰프 vs 호에프딩 부등식

| 항목 | 마르코프 (Markov) | 체비셰프 (Chebyshev) | 호에프딩 (Hoeffding) |
|------|------|------|------|
| **조건** | $X \geq 0$ | 평균, 분산 존재 | 독립, $a_i \leq X_i \leq b_i$ (유계) |
| **부등식** | $P(X \geq t) \leq \frac{E[X]}{t}$ | $P(\|X - \mu\| \geq t) \leq \frac{\sigma^2}{t^2}$ | $P(\|\bar{X} - \mu\| \geq t) \leq 2\exp\left(-\frac{2n^2t^2}{\sum(b_i-a_i)^2}\right)$ |
| **감소율** | $O(1/t)$ | $O(1/t^2)$ | $O(e^{-nt^2})$ (**지수적 감소**) |
| **필요 정보** | 기대값만 | 기대값 + 분산 | 독립성 + 범위 |
| **타이트함** | 매우 느슨 | 느슨 | 상대적으로 타이트 |
| **관계** | 가장 일반적 | 마르코프의 특수 케이스 ($X = (Y-\mu)^2$) | 독립 가정 추가 |
| **DL 관련** | 일반 확률 바운드 | 분산으로 바운드 | **일반화 바운드**, PAC 학습 |

**핵심 차이**: 가정이 강해질수록 (마르코프 → 체비셰프 → 호에프딩) 바운드가 타이트해짐. 호에프딩은 지수적 감소로 일반화 이론의 핵심.

## 19. Newton's Method vs Gradient Descent

| 항목 | Newton's Method | Gradient Descent |
|------|------|------|
| **업데이트** | $\theta_{t+1} = \theta_t - H^{-1}\nabla f$ | $\theta_{t+1} = \theta_t - \eta\nabla f$ |
| **사용 정보** | 1차 + **2차 미분** (Hessian) | 1차 미분만 (Gradient) |
| **수렴 속도** | **이차 수렴** (quadratic) | 선형 수렴 (linear) |
| **학습률** | 불필요 (Hessian이 자동 조절) | $\eta$ 수동 설정 필요 |
| **계산 비용** | $O(n^3)$ (Hessian 역행렬) | $O(n)$ |
| **메모리** | $O(n^2)$ (Hessian 저장) | $O(n)$ |
| **비볼록 함수** | 안장점으로 수렴 가능 (Hessian 부정치) | 안장점에서 느리지만 빠져나감 |
| **DL 실용성** | 파라미터 수 $n \sim 10^9$이면 불가능 | **DL의 표준 방법** |
| **근사 방법** | L-BFGS, Natural gradient | Adam, RMSprop 등 |

**핵심 차이**: Newton은 2차 정보로 빠르게 수렴하나 $O(n^3)$ 비용. DL에서 $n$이 거대하여 GD(및 변형)가 표준. Newton의 아이디어는 Adam 등에 부분 반영.

- "Newton's method의 이차 수렴(quadratic convergence)을 정의하고, GD의 선형 수렴과 비교하시오."
- "Newton's method가 안장점에서 실패할 수 있는 이유를 Hessian의 고유값으로 설명하시오."

## 20. Bias vs Variance

| 항목 | Bias (편향) | Variance (분산) |
|------|------|------|
| **정의** | $\text{Bias}[\hat{f}] = E[\hat{f}(x)] - f(x)$ | $\text{Var}[\hat{f}] = E[(\hat{f}(x) - E[\hat{f}(x)])^2]$ |
| **의미** | 모델이 진짜 함수에서 **체계적으로** 벗어난 정도 | 데이터셋에 따라 모델이 **흔들리는** 정도 |
| **모델 복잡도↑** | Bias ↓ | Variance ↑ |
| **모델 복잡도↓** | Bias ↑ | Variance ↓ |
| **과적합** | 낮은 bias | **높은 variance** |
| **과소적합** | **높은 bias** | 낮은 variance |
| **Bias-Variance 분해** | $E[(y - \hat{f})^2] = \text{Bias}^2 + \text{Var} + \sigma^2_\text{noise}$ | (동일 분해) |
| **해결** | 모델 복잡도 증가, feature 추가 | 정규화, 앙상블, 데이터 증강 |

**핵심 차이**: MSE = Bias² + Variance + 불가약 노이즈. 모델 복잡도가 증가하면 bias↓, variance↑로 trade-off 존재. 최적 모델은 총 오차를 최소화하는 지점.

### 시험에서 물어볼 수 있는 질문

- "앙상블(배깅)이 variance를 줄이는 이유를 수학적으로 설명하시오."
- "정규화 강도 $\lambda$가 bias와 variance에 미치는 영향을 분석하시오."

## 21. Softmax vs Sigmoid

| 항목 | Sigmoid | Softmax |
|------|------|------|
| **수식** | $\sigma(z) = \frac{1}{1+e^{-z}}$ | $\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$ |
| **입력** | 스칼라 $z \in \mathbb{R}$ | 벡터 $z \in \mathbb{R}^K$ |
| **출력 범위** | $(0, 1)$ | 각 원소 $(0,1)$, 합 $= 1$ |
| **확률 해석** | $P(y=1\mid x)$ (이진) | $P(y=k\mid x)$ (다중 클래스) |
| **관계** | $K=2$일 때 Softmax = Sigmoid | Sigmoid의 다중 클래스 일반화 |
| **미분** | $\sigma'(z) = \sigma(z)(1-\sigma(z))$ | $\frac{\partial \text{softmax}_i}{\partial z_j} = \text{softmax}_i(\delta_{ij} - \text{softmax}_j)$ |
| **사용** | 이진 분류, 멀티레이블 | 다중 클래스 분류 (상호 배타적) |

**핵심 차이**: Sigmoid는 독립적 이진 확률, Softmax는 상호 배타적 다중 클래스 확률 (합=1). $K=2$에서 Softmax가 Sigmoid로 환원됨을 보일 수 있음.

### 시험에서 물어볼 수 있는 질문
- "$K=2$일 때 Softmax가 Sigmoid로 환원됨을 유도하시오."
- "Softmax의 Jacobian을 계산하시오."
- "Softmax + CE Loss의 결합 gradient가 $\hat{y} - y$로 깔끔해짐을 보이시오."

## 22. Batch GD vs SGD vs Mini-batch GD

| 항목 | Batch GD | SGD | Mini-batch GD |
|------|------|------|------|
| **배치 크기** | $n$ (전체 데이터) | $1$ (단일 샘플) | $B$ ($1 < B < n$) |
| **업데이트** | $\theta \leftarrow \theta - \eta\frac{1}{n}\sum_{i=1}^n \nabla L_i$ | $\theta \leftarrow \theta - \eta\nabla L_i$ | $\theta \leftarrow \theta - \eta\frac{1}{B}\sum_{b=1}^B \nabla L_b$ |
| **Gradient 분산** | $0$ (정확한 gradient) | 높음 | 중간: $\text{Var} \propto 1/B$ |
| **수렴 경로** | 매끄러움 | 진동이 심함 | 적당한 진동 |
| **1 epoch 업데이트 수** | $1$ | $n$ | $n/B$ |
| **메모리** | $O(n)$ | $O(1)$ | $O(B)$ |
| **일반화** | 좋지 않을 수 있음 (sharp minima) | **좋음** (noise가 flat minima로 유도) | 실용적 최선 |
| **DL 표준** | 사용하지 않음 | 이론 분석 | **실제 사용** ($B=32\sim512$) |

**핵심 차이**: SGD의 gradient noise가 flat minima 탐색에 도움 (일반화 향상). Mini-batch는 noise와 계산 효율의 절충. Gradient 분산은 $O(\sigma^2/B)$.

### 시험에서 물어볼 수 있는 질문
- "SGD gradient의 unbiased estimator 성질을 증명하시오: $E[\nabla L_i] = \nabla L$."
- "Mini-batch gradient의 분산이 $O(\sigma^2/B)$임을 보이시오."
- "SGD의 noise가 일반화에 도움이 되는 이유를 flat/sharp minima 관점에서 설명하시오."
