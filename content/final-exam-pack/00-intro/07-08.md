## [1] Bayes 정리

**수식**:
$$P(H|E) = \frac{P(E|H) \, P(H)}{P(E)}$$

**한국어로 읽기**: "가설 H가 증거 E를 본 뒤에 맞을 확률은, H가 E를 만들어낼 확률 × H의 사전 믿음을, 전체 증거 확률로 나눈 것이다."

**직관적 의미**: 탐정이 용의자(H)를 추려내는 과정. 증거(E)가 나왔을 때:
- 이 용의자가 그 증거를 남겼을 가능성(가능도) × 처음부터 이 사람이 범인일 가능성(사전확률)
- 그걸 "아무나 이 증거를 남겼을 확률"로 정규화

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $P(E\|H)$ | **가능도(Likelihood)**: 가설이 참일 때 데이터가 관측될 확률 |
| $P(H)$ | **사전확률(Prior)**: 데이터 보기 전의 믿음 |
| $P(E)$ | **증거(Evidence)**: 정규화 상수, 모든 가설에 대해 합=1 되도록 |
| $P(H\|E)$ | **사후확률(Posterior)**: 데이터 본 후 업데이트된 믿음 |

**코드로 번역**:
```python
posterior = (likelihood * prior) / evidence
```

**관련 수식**: [2] MAP, [3] ML, [4] Posterior ∝ Likelihood × Prior, [54] Evidence

## [2] MAP 추정 (로그 형태)

**수식**:
$$\hat{\theta}_{\text{MAP}} = \arg\max_\theta \left[ \log P(E|\theta) + \log P(\theta) \right]$$

동등 표현:
$$\log P(\theta|E) = \log P(E|\theta) + \log P(\theta) + C$$

**한국어로 읽기**: "MAP 추정량은 로그 가능도와 로그 사전확률의 합을 최대화하는 θ이다."

**직관적 의미**: ML 추정에 "브레이크"를 건 것. 데이터가 아무리 극단적 값을 가리켜도, 사전확률이 "그건 너무 이상하다"고 잡아준다.
- 비유: 시험 점수(가능도)만으로 학생을 평가하지 않고, 평소 수행(사전확률)도 반영하는 것

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\log P(E\|\theta)$ | 데이터에 대한 적합도 (= ML 항) |
| $\log P(\theta)$ | 파라미터의 사전 제약 (= 정규화 역할) |
| $C$ | $-\log P(E)$, θ에 무관한 상수 → 최적화 시 무시 |

**코드로 번역**:
```python
loss = -log_likelihood(data, theta) - log_prior(theta)  # 최소화
```

**관련 수식**: [1] Bayes, [3] ML, [45] L2 정규화 (가우시안 사전 → MAP = Ridge)

<a id="3"></a>
## [3] ML 추정 (Maximum Likelihood)

**수식**:
$$\hat{\theta}_{\text{ML}} = \arg\max_\theta \; P(D|\theta) = \arg\max_\theta \sum_{i=1}^{N} \log P(x_i|\theta)$$

**한국어로 읽기**: "관측된 데이터를 가장 그럴듯하게 만드는 파라미터 θ를 찾아라."

**직관적 의미**: "이 주사위가 공정한지 아닌지"를 판단할 때, "관측된 결과가 가장 자연스러운 주사위"를 고르는 것.
- 데이터 100개 중 70개가 앞면 → θ=0.7이 ML 추정량
- MAP과 달리 사전확률 없음 → 데이터만 믿음 → 데이터 적으면 과적합 위험

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $P(D\|\theta)$ | 가능도 함수 (= 데이터 전체의 동시 확률) |
| i.i.d. 가정 | 곱 → 합: $\prod P(x_i\|\theta) \to \sum \log P(x_i\|\theta)$ |
| $\arg\max$ | 미분=0 풀어서 최적 θ 도출 |

**코드로 번역**:
```python
theta_ml = torch.mean(data)  # 가우시안 μ의 MLE
```

**관련 수식**: [2] MAP, [32] Log-Likelihood, [33] MLE for Gaussian

<a id="4"></a>
## [4] Posterior ∝ Likelihood × Prior

**수식**:
$$P(\theta|D) \propto P(D|\theta) \, P(\theta)$$

**한국어로 읽기**: "사후확률은 가능도 곱하기 사전확률에 비례한다."

**직관적 의미**: Bayes 정리에서 분모 $P(D)$는 θ에 무관한 상수이므로, 최적화 시 분자만 보면 된다.
- 이 한 줄이 MAP 추정의 출발점

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\propto$ | 비례 관계 — 정규화 상수를 무시 |
| $P(D\|\theta)$ | "이 θ가 데이터를 얼마나 잘 설명하는가" |
| $P(\theta)$ | "이 θ가 얼마나 그럴듯한가" (사전 지식) |

**코드로 번역**:
```python
log_posterior = log_likelihood + log_prior  # 상수 무시
```

**관련 수식**: [1] Bayes, [2] MAP, [3] ML

## [5] 가우시안 PDF (정규분포)

**수식**:
$$\mathcal{N}(x|\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

**한국어로 읽기**: "x가 평균 μ에서 떨어진 거리의 제곱을, 분산 2σ²으로 나눠서 지수적으로 감소시킨 값이다."

**직관적 의미**: 종 모양 곡선. μ = 종의 꼭대기, σ = 종의 폭.
- σ가 작으면 뾰족한 종 → "확신이 강하다"
- σ가 크면 납작한 종 → "불확실하다"
- $(x-\mu)^2$: 중심에서 멀수록 급격히 확률 감소

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $(2\pi\sigma^2)^{-1/2}$ | 전체 면적=1이 되게 하는 정규화 상수 |
| $\exp(-)$ | 거리에 따른 감소를 부드럽게 (제곱 → 미분 가능) |
| $(x-\mu)^2 / 2\sigma^2$ | 마할라노비스 거리의 제곱 (1D) |

**코드로 번역**:
```python
p = torch.distributions.Normal(mu, sigma).log_prob(x).exp()
```

**관련 수식**: [33] MLE for Gaussian (μ), [34] MLE for Gaussian (σ²), [19] 가우시안 간 KL

## [6] 베르누이 PDF

**수식**:
$$P(x|\theta) = \theta^x (1-\theta)^{1-x}, \quad x \in \{0, 1\}$$

**한국어로 읽기**: "x=1이면 θ, x=0이면 1-θ의 확률을 가진다."

**직관적 의미**: 동전 던지기의 수학적 표현.
- θ = 앞면 나올 확률
- x=1(앞면): $\theta^1(1-\theta)^0 = \theta$
- x=0(뒷면): $\theta^0(1-\theta)^1 = 1-\theta$
- 하나의 식으로 두 경우를 우아하게 통합

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\theta^x$ | x=1일 때만 θ 기여 |
| $(1-\theta)^{1-x}$ | x=0일 때만 (1-θ) 기여 |
| 지수 트릭 | if-else 없이 하나의 수식 → 미분 가능 |

**코드로 번역**:
```python
p = theta**x * (1 - theta)**(1 - x)
# 또는
p = torch.distributions.Bernoulli(theta).log_prob(x).exp()
```

**관련 수식**: [35] MLE for Bernoulli, [36] MAP for Bernoulli, [14] BCE Loss

## [7] 카테고리 분포 (Categorical Distribution)

**수식**:
$$P(x|\boldsymbol{\theta}) = \prod_{k=1}^{K} \theta_k^{[x=k]} = \theta_x$$

또는 원핫 벡터 표현:
$$P(\mathbf{e}_y | \boldsymbol{\theta}) = \prod_{k=1}^{K} \theta_k^{e_{y,k}}$$

**한국어로 읽기**: "K개 카테고리 중 x번째가 선택될 확률은 θ_x이다."

**직관적 의미**: K면 주사위. 베르누이의 일반화.
- 6면 주사위: θ = (1/6, 1/6, ..., 1/6)
- 원핫 벡터 $\mathbf{e}_y$: 정답 위치만 1, 나머지 0 → 곱셈하면 정답 확률만 살아남음

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $[x=k]$ | 이바노프 브래킷: 정답이면 1, 아니면 0 |
| $\prod$ | 원핫 지수 트릭으로 해당 클래스만 선택 |

**코드로 번역**:
```python
p = torch.distributions.Categorical(probs=theta).log_prob(x).exp()
```

**관련 수식**: [6] 베르누이, [8] Softmax, [12] CE Loss

## [8] 소프트맥스 (Softmax)

**수식**:
$$\text{softmax}(z_i) = \frac{\exp(z_i)}{\sum_{k=1}^{K} \exp(z_k)}$$

**한국어로 읽기**: "z_i의 지수를 전체 지수의 합으로 나누어 확률로 바꾼다."

**직관적 의미**: 투표 결과를 확률로 변환하는 기계.
- 입력: 각 클래스의 점수(logit) $z = [2.0, 1.0, 0.1]$
- 출력: 확률 $[0.66, 0.24, 0.10]$ (합=1)
- exp가 양수 보장 + 큰 값 강조 ("승자독식" 경향)
- 온도 파라미터 T로 소프트함 조절: $\text{softmax}(z_i/T)$

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\exp(z_i)$ | 실수 → 양수 변환 + 큰 차이 증폭 |
| $\sum \exp(z_k)$ | 정규화 → 전체 합 = 1 |
| 미분 가능 | argmax의 미분 가능한 근사 |

**코드로 번역**:
```python
probs = torch.softmax(logits, dim=-1)
```

**관련 수식**: [9] Softmax 자코비안, [12] CE Loss, [50] Log-Sum-Exp Trick

<a id="9"></a>
## [9] 소프트맥스 자코비안

**수식**:
$$\frac{\partial \text{softmax}(\mathbf{z})}{\partial \mathbf{z}} = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top$$

성분별:
$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$$

**한국어로 읽기**: "소프트맥스 출력 p_i를 입력 z_j로 미분하면, i=j일 때 p_i(1-p_i), i≠j일 때 -p_i·p_j이다."

**직관적 의미**: 풍선 비유 — 하나를 누르면(z_j 증가) 그 풍선은 커지고(p_j 증가), 나머지 풍선들은 모두 줄어든다.
- 대각항 $p_i(1-p_i)$: 자기 자신에 대한 감도 (시그모이드 미분과 같은 형태!)
- 비대각항 $-p_ip_j$: 다른 클래스와의 경쟁 관계

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\text{diag}(\mathbf{p})$ | 각 출력이 자기 입력에 반응하는 양 |
| $-\mathbf{p}\mathbf{p}^\top$ | 출력 간 제로섬 경쟁 (확률 합=1 제약) |

**코드로 번역**:
```python
J = torch.diag(p) - p.unsqueeze(1) * p.unsqueeze(0)
```

**관련 수식**: [8] Softmax, [11] 시그모이드 미분, [29] Chain Rule

<a id="10"></a>
## [10] 시그모이드 (Sigmoid)

**수식**:
$$\sigma(z) = \frac{1}{1 + \exp(-z)} = \frac{\exp(z)}{1 + \exp(z)}$$

**한국어로 읽기**: "실수 z를 0~1 사이 값으로 눌러 넣는다."

**직관적 의미**: S자 곡선. 수도꼭지 비유:
- z가 매우 음수 → 거의 0 (꼭지 잠김)
- z = 0 → 정확히 0.5 (반쯤 열림)
- z가 매우 양수 → 거의 1 (꼭지 완전 열림)
- K=2일 때 소프트맥스의 특수 케이스

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\exp(-z)$ | z가 클수록 이 항이 0에 수렴 → 출력 → 1 |
| $1/(1+\cdot)$ | 0~1 범위로 압축 |

**코드로 번역**:
```python
p = torch.sigmoid(z)
```

**관련 수식**: [8] Softmax (K=2 특수 케이스), [11] 시그모이드 미분, [6] 베르누이

<a id="11"></a>
## [11] 시그모이드 미분

**수식**:
$$\sigma'(z) = \sigma(z)(1 - \sigma(z))$$

**한국어로 읽기**: "시그모이드의 미분은 출력값 × (1 - 출력값)이다."

**직관적 의미**: z=0 근처에서 기울기가 최대(=0.25), 양 끝으로 갈수록 기울기 → 0.
- 이것이 **Vanishing Gradient** 문제의 원인: 깊은 네트워크에서 시그모이드를 쓰면 기울기가 연쇄적으로 0.25 이하를 곱하게 되어 소멸
- 해결: ReLU 사용 ([51])

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\sigma(z)$ | 현재 출력값 |
| $1-\sigma(z)$ | "아직 변할 여지" — 포화 상태면 변화 없음 |

**코드로 번역**:
```python
grad = torch.sigmoid(z) * (1 - torch.sigmoid(z))
```

**관련 수식**: [10] 시그모이드, [9] Softmax 자코비안 (대각 원소와 동일 형태)

<a id="12"></a>
## [12] Cross-Entropy Loss

**수식**:
$$\mathcal{L}_{\text{CE}} = -\frac{1}{|S|} \sum_{i=1}^{|S|} \mathbf{e}_{y_i}^\top \log h(x_i)$$

풀어 쓰면:
$$= -\frac{1}{|S|} \sum_{i=1}^{|S|} \log h_{y_i}(x_i)$$

**한국어로 읽기**: "각 샘플에서 정답 클래스에 배정된 확률의 로그를 뽑아서, 평균 내고 부호를 뒤집는다."

**직관적 의미**: 모델의 "자신감 점수". 정답에 높은 확률을 주면 낮은 손실, 낮은 확률을 주면 높은 손실.
- h(x) = [0.9, 0.05, 0.05], 정답=0 → loss = -log(0.9) ≈ 0.105 (낮음, 좋음)
- h(x) = [0.1, 0.8, 0.1], 정답=0 → loss = -log(0.1) ≈ 2.303 (높음, 나쁨)
- 원핫 벡터 $\mathbf{e}_{y_i}$의 역할: 내적으로 정답 인덱스만 선택하는 "마스크"

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\mathbf{e}_{y_i}^\top$ | 원핫 벡터로 정답 위치 선택 (= 인덱싱) |
| $\log h(x_i)$ | 확률 → 로그 확률 (곱 → 합 변환, 수치 안정) |
| $-$ | 로그확률은 음수 → 부호 뒤집어 양의 손실로 |
| $1/\|S\|$ | 배치 크기로 정규화 |

**코드로 번역**:
```python
loss = F.cross_entropy(logits, targets)  # 내부적으로 softmax + NLL
```

**관련 수식**: [8] Softmax, [16] Cross-Entropy (정보이론), [7] 카테고리 분포

<a id="13"></a>
## [13] MSE Loss

**수식**:
$$\mathcal{L}_{\text{MSE}} = \frac{1}{|S|} \sum_{i=1}^{|S|} (y_i - h(x_i))^2$$

**한국어로 읽기**: "예측값과 실제값의 차이를 제곱해서 평균 낸 것이다."

**직관적 의미**: 과녁 비유 — 화살(예측)이 과녁(정답)에서 얼마나 떨어졌는지의 제곱 평균.
- 제곱하는 이유: (1) 양수 보장 (2) 큰 오차에 더 큰 벌점 (3) 미분이 깔끔
- **가우시안 가정과의 연결**: $y_i \sim \mathcal{N}(h(x_i), \sigma^2)$이면 MLE → MSE 최소화

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $(y_i - h(x_i))$ | 잔차(residual) |
| $(\cdot)^2$ | 양수화 + 큰 오차 강조 + 미분 용이 |
| $1/\|S\|$ | 배치 크기 정규화 |

**코드로 번역**:
```python
loss = F.mse_loss(predictions, targets)
```

**관련 수식**: [5] 가우시안 PDF (MSE ↔ 가우시안 MLE), [28] 정규방정식

<a id="14"></a>
## [14] Binary Cross-Entropy Loss

**수식**:
$$\mathcal{L}_{\text{BCE}} = -\frac{1}{|S|}\sum_{i=1}^{|S|} \left[ y_i \log h(x_i) + (1-y_i) \log(1-h(x_i)) \right]$$

**한국어로 읽기**: "정답이 1이면 log h를, 정답이 0이면 log(1-h)를 보고, 평균 내서 부호를 뒤집는다."

**직관적 의미**: CE Loss의 이진 버전. 베르누이 분포의 음의 로그 가능도와 동일.
- y=1: 모델이 1에 가까운 확률을 주면 좋음
- y=0: 모델이 0에 가까운 확률을 주면 좋음

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $y_i \log h$ | 양성(1) 케이스의 로그 가능도 |
| $(1-y_i)\log(1-h)$ | 음성(0) 케이스의 로그 가능도 |
| 합쳐서 | = $\log[\theta^y(1-\theta)^{1-y}]$ = 베르누이 로그 가능도 |

**코드로 번역**:
```python
loss = F.binary_cross_entropy(torch.sigmoid(logits), targets)
```

**관련 수식**: [6] 베르누이 PDF, [12] CE Loss (다중 클래스), [10] 시그모이드

<a id="15"></a>
## [15] 엔트로피 (Entropy)

**수식**:
$$H(p) = -\mathbb{E}_p[\log p] = -\sum_x p(x) \log p(x)$$

**한국어로 읽기**: "분포 p의 불확실성 = 각 사건의 놀라움을 그 사건의 확률로 가중 평균한 것."

**직관적 의미**: "평균적 놀라움"의 측정.
- 공정한 동전: H = 1 bit (최대 불확실)
- 앞면 100% 동전: H = 0 bit (불확실성 없음)
- 6면 공정 주사위: H = log₂6 ≈ 2.58 bit
- **자기 자신의 분포로 인코딩할 때 필요한 최소 평균 비트 수**

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $-\log p(x)$ | 사건 x의 **놀라움(surprisal)** — 확률 낮을수록 놀라움 큼 |
| $p(x) \cdot$ | 확률로 가중 → 자주 일어나는 사건에 더 많은 가중치 |
| $\sum$ 또는 $\mathbb{E}$ | 모든 사건에 대한 평균 |

**코드로 번역**:
```python
H = -torch.sum(p * torch.log(p + 1e-9))
```

**관련 수식**: [16] Cross-Entropy, [17] KL Divergence, [18] KL=CE-H, [43] Self-Information

<a id="16"></a>
## [16] Cross-Entropy (정보이론)

**수식**:
$$H(p, q) = -\mathbb{E}_p[\log q] = -\sum_x p(x) \log q(x)$$

**한국어로 읽기**: "실제 분포 p를 따르는 데이터를 모델 q로 인코딩할 때 필요한 평균 비트 수."

**직관적 의미**: p가 진짜 세상, q가 모델이라면:
- q가 p와 같으면: $H(p,q) = H(p)$ (최소 = 엔트로피)
- q가 p와 다르면: $H(p,q) > H(p)$ (추가 비트 낭비 = KL)
- CE 최소화 = "모델 q를 진짜 p에 가깝게 만들어라"

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $p(x)$ | 실제 분포 (= 데이터에서 옴) |
| $\log q(x)$ | 모델의 인코딩 비용 |
| $-\mathbb{E}_p$ | 실제 데이터 기준 평균 비용 |

**코드로 번역**:
```python
CE = -torch.sum(p * torch.log(q + 1e-9))
```

**관련 수식**: [15] Entropy, [17] KL, [12] CE Loss (CE Loss = 경험적 CE)

<a id="17"></a>
## [17] KL Divergence

**수식**:
$$D_{\text{KL}}(p \| q) = \mathbb{E}_p\!\left[\log \frac{p(x)}{q(x)}\right] = \sum_x p(x) \log \frac{p(x)}{q(x)}$$

**한국어로 읽기**: "p를 q로 근사할 때 낭비되는 추가 비트 수의 기대값."

**직관적 의미**: 두 분포 사이의 "비대칭 거리".
- KL=0 ↔ p=q (완벽히 동일)
- KL>0 항상 (Gibbs 부등식)
- 비대칭: KL(p||q) ≠ KL(q||p) → "거리"가 아니라 "발산"
- 비유: p는 실제 날씨, q는 일기예보. KL = 일기예보를 믿고 옷을 입었을 때의 "평균 후회량"

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\log(p/q)$ | 각 사건에서 q가 p 대비 얼마나 "놀라는지"의 차이 |
| $\mathbb{E}_p$ | p 기준(실제 세상) 평균 |
| = $H(p,q) - H(p)$ | CE에서 엔트로피를 빼면 순수 "낭비분"만 남음 |

**코드로 번역**:
```python
kl = F.kl_div(q.log(), p, reduction='sum')  # 주의: PyTorch는 q가 log 형태
```

**관련 수식**: [15] Entropy, [16] Cross-Entropy, [18] KL=CE-H, [19] 가우시안 KL

---

<a id="18"></a>
## [18] KL = CE - H 관계

**수식**:
$$D_{\text{KL}}(p \| q) = H(p, q) - H(p)$$

동등하게:
$$H(p, q) = H(p) + D_{\text{KL}}(p \| q)$$

**한국어로 읽기**: "크로스엔트로피 = 엔트로피 + KL 발산. 즉, CE를 최소화하면 KL도 최소화된다."

**직관적 의미**: 이것이 CE Loss를 쓰는 정당성의 핵심!
- H(p)는 데이터 분포에 의해 고정 → 학습으로 못 바꿈
- CE를 줄이면 → KL이 줄어듦 → q가 p에 가까워짐
- 따라서 CE 최소화 = KL 최소화 = "모델을 데이터에 맞추는 것"

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $H(p)$ | 데이터의 본질적 불확실성 (상수) |
| $D_{\text{KL}}$ | 모델의 "추가 실수" (줄여야 할 대상) |
| $H(p,q)$ | 둘의 합 = 우리가 실제로 최소화하는 것 |

**코드로 번역**:
```python
# CE 최소화 = KL 최소화 (H(p)는 상수이므로)
loss = F.cross_entropy(logits, targets)  # 이것만 해도 KL이 줄어듦
```

**관련 수식**: [15] Entropy, [16] Cross-Entropy, [17] KL

<a id="19"></a>
## [19] 가우시안 간 KL Divergence

**수식**:
$$D_{\text{KL}}(\mathcal{N}_1 \| \mathcal{N}_2) = \frac{1}{2}\left[\log\frac{\sigma_2^2}{\sigma_1^2} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{\sigma_2^2} - 1\right]$$

다변량 (d차원):
$$D_{\text{KL}} = \frac{1}{2}\left[\log\frac{|\Sigma_2|}{|\Sigma_1|} + \text{tr}(\Sigma_2^{-1}\Sigma_1) + (\mu_2-\mu_1)^\top \Sigma_2^{-1}(\mu_1-\mu_2) - d\right]$$

**한국어로 읽기**: "두 가우시안 사이의 KL은 평균 차이와 분산 비율로 닫힌 형태로 계산된다."

**직관적 의미**: VAE(Variational Autoencoder)에서 핵심 등장.
- 첫째 항: 분산 비율 → 폭이 다른 정도
- 둘째 항: 평균 차이 → 중심이 떨어진 정도
- μ₁=μ₂, σ₁=σ₂이면 KL=0

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\log(\sigma_2^2/\sigma_1^2)$ | 분산 비율의 로그 (폭 차이) |
| $\sigma_1^2/\sigma_2^2$ | N₁의 퍼짐을 N₂ 기준으로 측정 |
| $(\mu_1-\mu_2)^2/\sigma_2^2$ | 평균 차이를 N₂의 분산으로 정규화 |
| $-1$ | N₁=N₂일 때 정확히 0이 되게 하는 보정 |

**코드로 번역**:
```python
kl = 0.5 * (torch.log(s2/s1) + s1/s2 + (m1-m2)**2/s2 - 1)
# 다변량: torch.distributions.kl_divergence(N1, N2)
```

**관련 수식**: [5] 가우시안 PDF, [17] KL Divergence

<a id="20"></a>
## [20] Jensen 부등식

**수식**:
$$f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)] \quad \text{(f가 볼록함수일 때)}$$
$$f(\mathbb{E}[X]) \geq \mathbb{E}[f(X)] \quad \text{(f가 오목함수일 때)}$$

**한국어로 읽기**: "볼록 함수에서는 '평균의 함수값'이 '함수값의 평균'보다 작거나 같다."

**직관적 의미**: 볼록 함수 = 아래로 활처럼 휜 곡선.
- 수치 예시: $f(x) = x^2$, X ∈ {1, 3} 각각 확률 1/2
  - 좌변: $f(E[X]) = f(2) = 4$
  - 우변: $E[f(X)] = (1+9)/2 = 5$
  - 4 ≤ 5 ✓
- **왜 중요한가**: KL ≥ 0 증명, EM 알고리즘의 ELBO 유도, 정보이론 부등식의 근간

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $f$ 볼록 | 곡선이 "아래로 볼록" → 할선이 곡선 위에 위치 |
| $\mathbb{E}[X]$ | 확률 가중 평균점 |
| 부등호 방향 | 볼록 → ≤, 오목 → ≥ (log는 오목 → KL ≥ 0 증명에 사용) |

**코드로 번역**:
```python
# Jensen 부등식 검증
f = lambda x: x**2
assert f(torch.mean(X)) <= torch.mean(f(X))
```

**관련 수식**: [17] KL ≥ 0 증명, [15] 엔트로피 최대값 유도

<a id="21"></a>
## [21] 내적 (Inner Product)

**수식**:
$$\langle \mathbf{v}, \mathbf{w} \rangle = \mathbf{v}^\top \mathbf{w} = \sum_{i=1}^{n} v_i w_i$$

기하학적:
$$\mathbf{v}^\top \mathbf{w} = \|\mathbf{v}\| \|\mathbf{w}\| \cos\theta$$

**한국어로 읽기**: "두 벡터의 대응 원소를 곱해서 더한 것. 기하학적으로는 한 벡터를 다른 벡터에 투영한 길이의 곱."

**직관적 의미**: "두 벡터가 얼마나 같은 방향을 가리키는가"의 측정.
- 양수: 같은 방향
- 0: 직교 (무관)
- 음수: 반대 방향
- CE Loss에서 $\mathbf{e}_y^\top \log h$: 원핫 벡터로 정답 위치만 선택하는 "마스크 연산"

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $v_i w_i$ | 각 차원별 "일치도" |
| $\sum$ | 모든 차원의 일치도 합산 |
| $\cos\theta$ | 방향 유사도 (코사인 유사도의 원천) |

**코드로 번역**:
```python
dot = torch.dot(v, w)  # 또는 (v * w).sum()
```

**관련 수식**: [12] CE Loss ($e_y^\top \log h$), [22] 외적, [52] Frobenius Norm

<a id="22"></a>
## [22] 외적 (Outer Product)

**수식**:
$$\mathbf{v}\mathbf{w}^\top \in \mathbb{R}^{m \times n}, \quad (\mathbf{v}\mathbf{w}^\top)_{ij} = v_i w_j$$

**한국어로 읽기**: "두 벡터의 외적은 모든 원소 쌍의 곱을 담은 행렬이다."

**직관적 의미**: 구구단표와 같은 구조. 벡터 v=[1,2,3], w=[4,5]이면:
```
    4  5
1 [ 4  5]
2 [ 8 10]
3 [12 15]
```
- 결과는 항상 **랭크-1 행렬** (행이 모두 w의 스칼라 배)
- SVD에서 $A = \sum \sigma_i u_i v_i^\top$: 랭크-1 행렬의 가중합으로 분해

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $v_i w_j$ | v의 i성분과 w의 j성분의 상호작용 |
| 랭크-1 | 행렬의 최소 단위 "원자" |

**코드로 번역**:
```python
outer = torch.outer(v, w)  # 또는 v.unsqueeze(1) @ w.unsqueeze(0)
```

**관련 수식**: [21] 내적, [26] SVD (랭크-1 합), [9] Softmax 자코비안 ($pp^\top$)

<a id="23"></a>
## [23] 행렬-벡터 곱

**수식**:
$$A\mathbf{v} = v_1 \mathbf{a}_1 + v_2 \mathbf{a}_2 + \cdots + v_n \mathbf{a}_n$$

여기서 $\mathbf{a}_i$는 A의 i번째 열벡터.

**한국어로 읽기**: "행렬에 벡터를 곱하는 것은 행렬의 열벡터들을 벡터의 원소로 가중합하는 것이다."

**직관적 의미**: DJ 믹싱. 각 열벡터가 하나의 음악 트랙이고, v의 원소가 각 트랙의 볼륨.
- 선형 레이어 $Wx + b$: W의 열벡터들을 입력 x로 "믹싱"하여 출력 생성
- 이것이 신경망의 가장 기본 연산

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $v_i$ | i번째 기저 방향의 가중치(좌표) |
| $\mathbf{a}_i$ | i번째 기저가 변환된 결과 |
| $\sum$ | 선형성: 중첩의 원리 |

**코드로 번역**:
```python
output = A @ v  # torch.matmul(A, v)
```

**관련 수식**: [21] 내적 (행 관점), [26] SVD, [48] Backprop

<a id="24"></a>
## [24] Trace 순환 성질

**수식**:
$$\text{tr}(AB) = \text{tr}(BA)$$

일반화:
$$\text{tr}(ABC) = \text{tr}(CAB) = \text{tr}(BCA)$$

정의:
$$\text{tr}(A) = \sum_{i=1}^{n} a_{ii}$$

**한국어로 읽기**: "트레이스는 대각 원소의 합이며, 행렬 곱의 순서를 순환적으로 바꿔도 값이 같다."

**직관적 의미**: 행렬의 "총 크기" 또는 "총 고유값"의 측정.
- $\text{tr}(A) = \sum \lambda_i$ (고유값의 합)
- 프로베니우스 노름: $\|A\|_F^2 = \text{tr}(A^\top A)$
- 기울기 계산에서 자주 등장: $\frac{\partial}{\partial A}\text{tr}(BA) = B^\top$

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| 대각합 | 행렬의 "스칼라 요약" → 최적화에서 목적함수로 사용 가능 |
| 순환 불변 | 증명이나 유도에서 행렬 순서를 편리하게 재배치 |

**코드로 번역**:
```python
tr = torch.trace(A @ B)  # == torch.trace(B @ A)
```

**관련 수식**: [27] 고유값 분해 ($\text{tr}=\sum\lambda_i$), [52] Frobenius Norm, [19] 가우시안 KL

## [25] Rank-Nullity 정리

**수식**:
$$n = \text{rank}(A) + \text{nullity}(A)$$

여기서 $A \in \mathbb{R}^{m \times n}$.

**한국어로 읽기**: "입력 차원 = 살아남는 차원(랭크) + 사라지는 차원(널리티)."

**직관적 의미**: 터널 비유. n차선 도로가 터널(행렬 A)을 지나면:
- rank(A)개 차선은 반대편으로 통과 (정보 보존)
- nullity(A)개 차선은 막다른 벽 (정보 소멸, $Av=0$)
- 두 수의 합은 항상 원래 차선 수 n
- **DL 의미**: 가중치 행렬의 랭크가 낮으면 → 표현력 부족, 높으면 → 정보 보존 좋음

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $n$ | 입력 공간의 총 자유도 |
| rank | $\mathscr{R}(A)$의 차원 = 출력으로 전달되는 독립 방향 수 |
| nullity | $\mathscr{N}(A)$의 차원 = A가 무시하는 입력 방향 수 |

**코드로 번역**:
```python
rank = torch.linalg.matrix_rank(A)
nullity = A.shape[1] - rank
```

**관련 수식**: [26] SVD (비영 특이값 수 = rank), [27] 고유값 분해

## [26] SVD (특이값 분해)

**수식**:
$$A = U \Sigma V^\top = \sum_{i=1}^{r} \sigma_i \mathbf{u}_i \mathbf{v}_i^\top$$

- $U \in \mathbb{R}^{m \times m}$: 좌특이벡터 (직교), $V \in \mathbb{R}^{n \times n}$: 우특이벡터 (직교)
- $\Sigma$: 대각 특이값 $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$

**한국어로 읽기**: "어떤 행렬이든 '회전 → 축 스케일링 → 회전'의 3단계로 분해할 수 있다."

**직관적 의미**: 행렬 = 세 가지 기본 동작의 합성
1. $V^\top$: 입력 공간에서 회전 (좌표 정렬)
2. $\Sigma$: 각 축을 늘이거나 줄이기 (중요도 반영)
3. $U$: 출력 공간에서 회전

**실용적 의미**:
- $\sigma_i$가 크면 → 그 방향이 중요
- 작은 $\sigma_i$를 잘라내면 → 저랭크 근사 (차원 축소, 데이터 압축)
- PCA = SVD의 특수 케이스

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $U$ | 출력 공간의 직교 기저 |
| $\Sigma$ | 각 기저 방향의 "중요도" (특이값) |
| $V^\top$ | 입력 공간의 직교 기저 |
| $\sigma_i u_i v_i^\top$ | 랭크-1 행렬의 가중합 → 중요한 것부터 근사 |

**코드로 번역**:
```python
U, S, Vt = torch.linalg.svd(A)
A_approx = U[:, :k] @ torch.diag(S[:k]) @ Vt[:k, :]  # 랭크-k 근사
```

**관련 수식**: [27] 고유값 분해 (대칭행렬의 SVD), [25] Rank-Nullity, [22] 외적

## [27] 고유값 분해 (Eigendecomposition)

**수식**:
$$A = U \Lambda U^\top \quad \text{(대칭 행렬)}$$

기본 정의:
$$A\mathbf{v} = \lambda \mathbf{v}$$

**한국어로 읽기**: "대칭 행렬 A는 고유벡터로 회전 → 고유값으로 스케일 → 역회전하는 것과 같다."

**직관적 의미**: 행렬의 DNA 분석. 고유벡터 = 변환해도 방향이 안 변하는 "축", 고유값 = 그 축에서의 배율.
- $\lambda > 1$: 해당 방향으로 늘어남
- $0 < \lambda < 1$: 해당 방향으로 줄어듦
- $\lambda < 0$: 해당 방향으로 뒤집힘
- **DL에서**: 헤시안의 고유값 → 손실 곡면의 곡률 → 학습 난이도

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $U$ | 고유벡터들을 열로 나열 (직교 행렬) |
| $\Lambda$ | 대각선에 고유값 $\lambda_1, ..., \lambda_n$ |
| $U^\top$ | 역변환 ($U$가 직교이므로 $U^{-1} = U^\top$) |

**코드로 번역**:
```python
eigenvalues, eigenvectors = torch.linalg.eigh(A)  # 대칭 행렬용
```

**관련 수식**: [26] SVD, [53] Positive Definite (모든 고유값 > 0), [24] Trace ($= \sum\lambda_i$)

## [28] 정규방정식 (Normal Equation)

**수식**:
$$X^\top X \boldsymbol{\beta} = X^\top \mathbf{y}$$

해:
$$\hat{\boldsymbol{\beta}} = (X^\top X)^{-1} X^\top \mathbf{y}$$

**한국어로 읽기**: "MSE를 최소화하는 β는 (X^TX)의 역행렬에 X^Ty를 곱한 것이다."

**직관적 의미**: "데이터에 가장 잘 맞는 직선(초평면)의 기울기를 한 방에 구하는 공식."
- MSE를 β로 미분하고 =0으로 놓으면 이 식이 나옴
- $X^\top X$: 입력의 "상관관계 행렬" (Gram matrix)
- $X^\top y$: 입력과 출력의 "교차 상관"
- **한계**: $O(n^3)$ 역행렬 계산 → 데이터 크면 GD 사용

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $X^\top X$ | 피처 간 상관 구조 (대칭, PSD) |
| $(X^\top X)^{-1}$ | 상관 구조를 "풀어헤치는" 연산 |
| $X^\top y$ | 피처-타겟 간 관계 |

**코드로 번역**:
```python
beta = torch.linalg.solve(X.T @ X, X.T @ y)
```

**관련 수식**: [13] MSE Loss (이것을 최소화), [26] SVD (수치적으로 안정적인 대안)

## [29] Chain Rule (연쇄법칙)

**수식**:
$$\frac{\partial (f \circ g)}{\partial x} = \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial x}$$

**한국어로 읽기**: "합성함수의 미분은 바깥 함수의 미분 × 안쪽 함수의 미분."

**직관적 의미**: 도미노 비유. x가 1mm 움직이면:
- g가 3mm 움직이고 ($\partial g/\partial x = 3$)
- g가 1mm 움직일 때 f가 2mm 움직이면 ($\partial f/\partial g = 2$)
- x → f의 총 영향 = 3 × 2 = 6mm

**이것이 딥러닝의 전부**: Backpropagation = Chain Rule의 반복 적용
$$\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial h_n} \cdot \frac{\partial h_n}{\partial h_{n-1}} \cdots \frac{\partial h_2}{\partial h_1} \cdot \frac{\partial h_1}{\partial w_1}$$

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\partial f / \partial g$ | 상위 레이어의 감도 |
| $\partial g / \partial x$ | 하위 레이어의 감도 |
| 곱 | 감도의 전파 (연쇄) |

**코드로 번역**:
```python
loss.backward()  # PyTorch가 Chain Rule을 자동 적용
grad_x = x.grad   # df/dx = (df/dg)(dg/dx) 자동 계산
```

**관련 수식**: [30] 다변수 Chain Rule, [48] Backpropagation, [11] 시그모이드 미분

<a id="30"></a>
## [30] 다변수 Chain Rule (자코비안)

**수식**:
$$\frac{\partial \mathbf{f}}{\partial \mathbf{x}} = \frac{\partial \mathbf{f}}{\partial \mathbf{g}} \cdot \frac{\partial \mathbf{g}}{\partial \mathbf{x}}$$

자코비안:
$$J_f = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}$$

**한국어로 읽기**: "벡터 함수의 미분은 자코비안 행렬이며, 합성 시 자코비안을 곱한다."

**직관적 의미**: 스칼라 chain rule의 행렬 버전.
- 각 출력이 각 입력에 얼마나 반응하는지를 행렬로 정리
- 딥러닝의 각 레이어는 자코비안을 가지며, 역전파 = 자코비안의 연쇄 곱

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $J_{ij}$ | i번째 출력의 j번째 입력에 대한 편미분 |
| 행렬곱 | 다차원 감도의 연쇄 전파 |

**코드로 번역**:
```python
J = torch.autograd.functional.jacobian(f, x)
```

**관련 수식**: [29] Chain Rule, [9] Softmax 자코비안, [31] 벡터 미분

## [31] Gradient of Scalar w.r.t. Vector

**수식**:
$$\nabla_{\mathbf{x}} f = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix}$$

주요 공식들:
$$\nabla_{\mathbf{x}} (\mathbf{a}^\top \mathbf{x}) = \mathbf{a}, \quad \nabla_{\mathbf{x}} (\mathbf{x}^\top A \mathbf{x}) = (A + A^\top)\mathbf{x}$$

**한국어로 읽기**: "그래디언트는 함수가 가장 빠르게 증가하는 방향을 가리키는 벡터다."

**직관적 의미**: 산에서 가장 가파른 오르막 방향.
- Gradient Descent: 이 방향의 반대로 가면 가장 빠르게 내려감
- 크기 = 기울기의 가파름 정도

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\partial f / \partial x_i$ | i번째 좌표 방향으로의 변화율 |
| 벡터 형태 | 모든 방향의 변화율을 하나로 종합 |

**코드로 번역**:
```python
x.requires_grad_(True)
f(x).backward()
gradient = x.grad  # ∇f
```

**관련 수식**: [47] Gradient Descent, [28] 정규방정식 (∇MSE=0)

## [32] Log-Likelihood of i.i.d. Data

**수식**:
$$\log P(D|\theta) = \log \prod_{i=1}^{N} P(x_i|\theta) = \sum_{i=1}^{N} \log P(x_i|\theta)$$

**한국어로 읽기**: "독립 데이터의 결합 확률의 로그 = 개별 로그 확률의 합."

**직관적 의미**: i.i.d. 가정이 핵심 마법.
1. 독립 → 곱: $P(x_1, x_2, ...) = P(x_1) \cdot P(x_2) \cdots$
2. 로그 → 합: $\log(ab) = \log a + \log b$
- 곱셈은 수치적으로 언더플로 위험 → 로그로 합으로 바꾸면 안정
- 이것이 "MLE 유도의 첫 단계" (출제 ~35%)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| i.i.d. | 독립동일분포 → 결합확률 = 개별확률의 곱 |
| $\log$ | 곱 → 합 변환 + 수치 안정 + 미분 용이 |
| $\sum$ | N개 데이터의 기여를 합산 |

**코드로 번역**:
```python
log_lik = torch.sum(dist.log_prob(data))
```

**관련 수식**: [3] ML 추정, [2] MAP, [33]-[36] 구체적 MLE/MAP

## [33] MLE for Gaussian (μ)

**수식**:
$$\hat{\mu}_{\text{ML}} = \frac{1}{N}\sum_{i=1}^{N} x_i = \bar{x}$$

유도: $\frac{\partial}{\partial \mu}\sum \log \mathcal{N}(x_i|\mu,\sigma^2) = 0$
→ $\sum(x_i - \mu) = 0$ → $\mu = \bar{x}$

**한국어로 읽기**: "가우시안의 평균에 대한 MLE는 표본 평균이다."

**직관적 의미**: "가장 그럴듯한 종 모양의 중심 = 데이터의 평균 위치." 직관과 완벽하게 일치하는 결과.

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\sum x_i$ | 모든 데이터의 위치 합산 |
| $1/N$ | 평균화 → 중심 위치 추정 |

**코드로 번역**:
```python
mu_ml = torch.mean(data)
```

**관련 수식**: [5] 가우시안 PDF, [32] Log-Likelihood, [34] MLE for σ²

## [34] MLE for Gaussian (σ²)

**수식**:
$$\hat{\sigma}^2_{\text{ML}} = \frac{1}{N}\sum_{i=1}^{N}(x_i - \hat{\mu})^2$$

**한국어로 읽기**: "가우시안의 분산에 대한 MLE는 평균과의 편차 제곱의 평균이다."

**직관적 의미**: "종의 폭 = 데이터가 평균에서 얼마나 퍼져있는지."
- 주의: $1/N$이므로 **편향 추정량** (불편 추정은 $1/(N-1)$)
- 데이터 적으면 분산을 과소추정하는 경향

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $(x_i - \hat{\mu})^2$ | 각 데이터의 중심 이탈도 |
| $1/N$ | MLE에서는 N으로 나눔 (편향됨) |

**코드로 번역**:
```python
sigma2_ml = torch.mean((data - mu_ml)**2)  # 편향 추정량
sigma2_unbiased = torch.var(data, correction=1)  # 불편 추정량
```

**관련 수식**: [5] 가우시안 PDF, [33] MLE for μ, [38] 분산

## [35] MLE for Bernoulli

**수식**:
$$\hat{\theta}_{\text{ML}} = \frac{1}{N}\sum_{i=1}^{N} x_i = \frac{\text{앞면 수}}{N}$$

유도: $\frac{\partial}{\partial \theta}\sum [x_i \log\theta + (1-x_i)\log(1-\theta)] = 0$
→ $\frac{\sum x_i}{\theta} - \frac{N - \sum x_i}{1-\theta} = 0$

**한국어로 읽기**: "베르누이 MLE는 성공 비율(표본 비율)이다."

**직관적 의미**: 동전 100번 던져서 70번 앞면 → θ=0.7.
- 직관과 일치하지만 문제점: 3번 던져서 3번 앞면 → θ=1.0 (과적합!)
- 이것이 MAP/사전확률이 필요한 이유

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\sum x_i$ | 성공(1) 횟수 |
| $1/N$ | 전체 대비 비율 |

**코드로 번역**:
```python
theta_ml = torch.mean(data.float())
```

**관련 수식**: [6] 베르누이 PDF, [36] MAP for Bernoulli, [32] Log-Likelihood

## [36] MAP for Bernoulli with Beta Prior

**수식**:
$$\hat{\theta}_{\text{MAP}} = \frac{\sum x_i + \alpha - 1}{N + \alpha + \beta - 2}$$

사전확률: $P(\theta) = \text{Beta}(\theta|\alpha,\beta) \propto \theta^{\alpha-1}(1-\theta)^{\beta-1}$

**한국어로 읽기**: "베타 사전확률을 쓴 MAP은 가상 데이터(α-1개 성공, β-1개 실패)를 추가한 것과 같다."

**직관적 의미**:
- MLE: 3번 던져 3번 앞면 → θ=1.0 (극단적)
- MAP(α=β=2): (3+1)/(3+2) = 0.8 → 사전확률이 "0.5 쪽으로 끌어당김"
- α, β = "가상 관측 수". α가 크면 → 1 쪽으로, β가 크면 → 0 쪽으로 편향
- 데이터가 많아지면 (N→∞) MAP → MLE (사전확률 영향 소멸)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\sum x_i + \alpha - 1$ | 실제 성공 + 가상 성공 |
| $N + \alpha + \beta - 2$ | 실제 시행 + 가상 시행 |
| Beta prior | 베르누이의 **켤레 사전확률** → 사후도 Beta |

**코드로 번역**:
```python
theta_map = (data.sum() + alpha - 1) / (len(data) + alpha + beta - 2)
```

**관련 수식**: [35] MLE for Bernoulli, [55] Beta 분포, [2] MAP

## [37] 기대값 (Expectation)

**수식**:
$$\mathbb{E}[X] = \sum_x x \, P(x) \quad \text{(이산)}, \quad \mathbb{E}[X] = \int x \, f(x) \, dx \quad \text{(연속)}$$

$$\mathbb{E}[g(X)] = \sum_x g(x) P(x)$$

**한국어로 읽기**: "기대값은 각 값에 그 확률을 가중치로 곱해서 합한 것 = 확률 가중 평균."

**직관적 의미**: 주사위 기대값 = (1×1/6 + 2×1/6 + ... + 6×1/6) = 3.5.
- 물리학의 "무게중심": 확률이 높은 곳에 무게가 더 실림
- 무한히 반복했을 때의 평균값 (대수의 법칙)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $x$ | 확률변수의 값 |
| $P(x)$ | 가중치 (확률) |
| $\sum / \int$ | 모든 가능한 값에 대한 종합 |

**코드로 번역**:
```python
E = torch.sum(values * probs)  # 이산
E = torch.mean(samples)         # 몬테카를로 근사
```

**관련 수식**: [38] 분산, [15] 엔트로피 ($E[-\log p]$), [17] KL ($E[\log(p/q)]$)

## [38] 분산 (Variance)

**수식**:
$$\text{Var}(X) = \mathbb{E}[(X - \mu)^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$$

**한국어로 읽기**: "분산은 평균으로부터의 편차 제곱의 기대값이다."

**직관적 의미**: 데이터가 평균 주위로 얼마나 퍼져있는지.
- Var=0: 모든 값이 동일 (불확실성 없음)
- Var 큼: 값이 넓게 퍼짐 (불확실성 큼)
- 두 번째 형태가 계산에 유용: "제곱의 평균 - 평균의 제곱"

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $(X-\mu)^2$ | 편차의 제곱 (양수화 + 큰 편차 강조) |
| $\mathbb{E}[\cdot]$ | 확률 가중 평균 |

**코드로 번역**:
```python
var = torch.var(data, correction=0)  # 모분산
```

**관련 수식**: [37] 기대값, [39] 공분산, [5] 가우시안 (σ² = 분산)

<a id="39"></a>
## [39] 공분산 (Covariance)

**수식**:
$$\text{Cov}(X, Y) = \mathbb{E}[(X-\mu_X)(Y-\mu_Y)] = \mathbb{E}[XY] - \mathbb{E}[X]\mathbb{E}[Y]$$

공분산 행렬:
$$\Sigma = \mathbb{E}[(\mathbf{x}-\boldsymbol{\mu})(\mathbf{x}-\boldsymbol{\mu})^\top]$$

**한국어로 읽기**: "공분산은 두 변수가 함께 움직이는 정도이다."

**직관적 의미**:
- Cov > 0: X 크면 Y도 큰 경향 (키와 몸무게)
- Cov < 0: X 크면 Y 작은 경향 (운동량과 체지방)
- Cov = 0: 선형 관계 없음 (독립이면 Cov=0이지만, Cov=0이라고 독립은 아님)
- 공분산 행렬 Σ: 다변량 가우시안의 "모양"을 결정

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $(X-\mu_X)(Y-\mu_Y)$ | 두 편차의 곱 → 같은 방향이면 양수 |
| $\mathbb{E}[\cdot]$ | 평균적 동반 이동량 |

**코드로 번역**:
```python
cov_matrix = torch.cov(data_matrix)  # (d, N) 입력
```

**관련 수식**: [38] 분산 (자기 자신의 공분산), [5] 가우시안 (Σ), [42] 독립

<a id="40"></a>
## [40] 조건부 확률

**수식**:
$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

**한국어로 읽기**: "B가 일어났다는 조건 하에서 A도 일어날 확률 = 둘 다 일어날 확률 / B가 일어날 확률."

**직관적 의미**: 전체 공간을 B로 "줌인"한 후, 그 안에서 A의 비율.
- 비유: 교실(전체) → 안경 쓴 학생(B) → 그 중 왼손잡이(A)
- Bayes 정리의 출발점: $P(A|B) = P(B|A)P(A)/P(B)$

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $P(A \cap B)$ | A와 B가 동시에 일어날 확률 |
| $/ P(B)$ | B 공간으로 정규화 (B가 전체가 됨) |

**코드로 번역**:
```python
p_a_given_b = p_a_and_b / p_b
```

**관련 수식**: [1] Bayes 정리, [41] 전체 확률의 법칙, [42] 독립

<a id="41"></a>
## [41] 전체 확률의 법칙 (Law of Total Probability)

**수식**:
$$P(B) = \sum_{i=1}^{n} P(B|A_i) P(A_i)$$

여기서 $\{A_i\}$는 표본 공간의 분할.

**한국어로 읽기**: "B의 전체 확률은 각 경우(A_i)에서 B가 일어날 확률을 그 경우의 확률로 가중합한 것이다."

**직관적 의미**: 경우의 수 나누기. "비 올 확률"을 구하려면:
- 여름일 때 비 올 확률 × 여름일 확률
- 겨울일 때 비 올 확률 × 겨울일 확률
- ... 모든 계절에 대해 합산
- Bayes 정리의 분모 P(E) 계산에 사용

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $P(B\|A_i)$ | 조건 i에서의 B 확률 |
| $P(A_i)$ | 조건 i가 성립할 확률 |
| $\sum$ | 모든 가능한 조건에 대한 종합 |

**코드로 번역**:
```python
p_b = torch.sum(p_b_given_a * p_a)  # 각 조건별 가중합
```

**관련 수식**: [1] Bayes (분모), [40] 조건부 확률, [54] Evidence

<a id="42"></a>
## [42] 결합 확률과 독립

**수식**:
$$P(A \cap B) = P(A|B) P(B) = P(B|A) P(A)$$

독립인 경우:
$$P(A \cap B) = P(A) P(B)$$

**한국어로 읽기**: "A와 B가 독립이면 결합 확률은 각 확률의 곱이다."

**직관적 의미**: "한쪽을 안다고 다른 쪽에 대한 정보가 바뀌지 않음."
- 독립: 주사위 두 번 던지기 — 첫 번째 결과가 두 번째에 영향 없음
- 비독립: 비 오는 날의 우산 가져오기 — 비와 우산은 관련
- **i.i.d. 가정의 핵심**: 독립 → 결합확률 = 곱 → 로그 가능도 = 합

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $P(A\|B)P(B)$ | 곱셈 법칙 (조건부 확률의 정의에서 유도) |
| 독립 시 $P(A)P(B)$ | 조건 무관 → 단순 곱 |

**코드로 번역**:
```python
p_joint = p_a * p_b  # 독립 가정 시
```

**관련 수식**: [40] 조건부 확률, [32] Log-Likelihood (i.i.d. → 곱 → 합)

## [43] 정보량 (Self-Information)

**수식**:
$$I(x) = -\log P(x) = \log \frac{1}{P(x)}$$

**한국어로 읽기**: "사건 x의 정보량은 그 확률의 음의 로그이다. 희귀할수록 정보가 크다."

**직관적 의미**: "놀라움"의 정량화.
- 확실한 사건(P=1): 정보량 = 0 ("해가 동쪽에서 뜬다" → 놀랍지 않음)
- 희귀한 사건(P=0.01): 정보량 = 6.64 bits ("복권 당첨" → 매우 놀라움)
- 로그를 쓰는 이유: 독립 사건의 정보량이 **더해져야** 하므로 (곱→합)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $-\log$ | 확률 → 정보량 (단조 감소 변환) |
| $P(x)$ | 사건의 확률 |
| 로그의 밑 | 2 → bits, e → nats, 10 → hartleys |

**코드로 번역**:
```python
info = -torch.log2(p)  # bits 단위
```

**관련 수식**: [15] 엔트로피 ($E[I(x)]$), [16] Cross-Entropy, [17] KL

<a id="44"></a>
## [44] Mutual Information

**수식**:
$$I(X;Y) = D_{\text{KL}}(P(X,Y) \| P(X)P(Y)) = H(X) - H(X|Y)$$

**한국어로 읽기**: "상호정보량은 Y를 알았을 때 X에 대한 불확실성이 얼마나 줄어드는가."

**직관적 의미**: "X와 Y가 공유하는 정보의 양."
- I(X;Y) = 0: X와 Y가 독립 (서로에 대해 아무것도 모름)
- I(X;Y) = H(X): Y만 알면 X를 완벽히 알 수 있음
- KL(결합분포 || 주변분포의 곱) = 독립에서 얼마나 벗어나는가
- 대칭: I(X;Y) = I(Y;X)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $H(X)$ | X의 총 불확실성 |
| $H(X\|Y)$ | Y를 안 후 남은 X의 불확실성 |
| 차이 | Y가 제거해준 불확실성 = 공유 정보 |

**코드로 번역**:
```python
mi = entropy_x + entropy_y - joint_entropy  # I(X;Y) = H(X) + H(Y) - H(X,Y)
```

**관련 수식**: [15] 엔트로피, [17] KL Divergence, [42] 독립

## [45] L2 정규화 (Ridge / Weight Decay)

**수식**:
$$\mathcal{L}_{\text{Ridge}} = \mathcal{L}_{\text{data}} + \frac{\lambda}{2}\|\mathbf{w}\|_2^2 = \mathcal{L}_{\text{data}} + \frac{\lambda}{2}\sum_j w_j^2$$

**한국어로 읽기**: "기존 손실에 가중치 크기의 제곱합 벌점을 추가한다."

**직관적 의미**: "가중치가 너무 커지지 마라"는 제약.
- 비유: 시험 답안에 "간결하게 쓰세요"라는 조건 → 불필요하게 복잡한 답 방지
- **베이지안 해석**: 가우시안 사전확률 $w \sim \mathcal{N}(0, 1/\lambda)$을 쓴 MAP 추정과 동일!
  - $\log P(w) = -\frac{\lambda}{2}\|w\|^2 + \text{const}$
- 큰 λ: 강한 정규화 → 단순한 모델 (underfitting 위험)
- 작은 λ: 약한 정규화 → 복잡한 모델 (overfitting 위험)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\mathcal{L}_{\text{data}}$ | 데이터 적합도 (= 가능도) |
| $\lambda/2$ | 정규화 강도 ($1/2$은 미분 시 깔끔함 위해) |
| $\\\|w\\\|_2^2$ | 가중치 크기 벌점 → 0으로 끌어당김 |

**코드로 번역**:
```python
optimizer = torch.optim.SGD(model.parameters(), lr=lr, weight_decay=lam)
```

**관련 수식**: [2] MAP (가우시안 사전 → Ridge), [46] L1, [28] 정규방정식 → $(X^\top X + \lambda I)^{-1}X^\top y$

## [46] L1 정규화 (Lasso)

**수식**:
$$\mathcal{L}_{\text{Lasso}} = \mathcal{L}_{\text{data}} + \lambda \|\mathbf{w}\|_1 = \mathcal{L}_{\text{data}} + \lambda \sum_j |w_j|$$

**한국어로 읽기**: "기존 손실에 가중치 절대값의 합 벌점을 추가한다."

**직관적 의미**: L2와 달리 가중치를 정확히 0으로 만들 수 있음 → **특성 선택(feature selection)** 효과.
- 비유: "필요 없는 재료는 아예 빼라" (L2는 "조금만 써라")
- **베이지안 해석**: 라플라스 사전확률 $P(w) \propto \exp(-\lambda|w|)$을 쓴 MAP
- 다이아몬드 모양 제약 영역 → 꼭짓점(축 위)에서 만날 확률 높음 → 희소 해

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\|w_j\|$ | 절대값 → 0 근처에서 미분 불연속 → 0으로 수렴 유도 |
| $\lambda$ | 정규화 강도 |

**코드로 번역**:
```python
l1_loss = lam * sum(p.abs().sum() for p in model.parameters())
loss = data_loss + l1_loss
```

**관련 수식**: [45] L2 정규화, [2] MAP

## [47] Gradient Descent Update

**수식**:
$$\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t)$$

**한국어로 읽기**: "현재 위치에서 손실의 기울기 반대 방향으로 학습률 η만큼 이동한다."

**직관적 의미**: 안개 낀 산에서 하산하기.
- 발 밑의 경사(기울기)를 느낌 → 가장 가파른 내리막 방향으로 한 걸음
- η(학습률) = 걸음 크기
  - η 너무 크면: 골짜기를 건너뛰어 발산
  - η 너무 작으면: 수렴이 너무 느림
- 변형: SGD(미니배치), Momentum, Adam 등

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\theta_t$ | 현재 파라미터 |
| $-$ | 기울기 반대 방향 (하강) |
| $\eta$ | 학습률 (스텝 크기) |
| $\nabla \mathcal{L}$ | 손실 증가 방향 → 반대로 가면 감소 |

**코드로 번역**:
```python
optimizer = torch.optim.SGD(model.parameters(), lr=eta)
optimizer.step()  # θ ← θ - η∇L
```

**관련 수식**: [31] Gradient, [29] Chain Rule, [48] Backprop

## [48] Backpropagation (단일 레이어)

**수식**:

순전파: $\mathbf{z} = W\mathbf{x} + \mathbf{b}$, $\mathbf{a} = \sigma(\mathbf{z})$

역전파:
$$\frac{\partial \mathcal{L}}{\partial W} = \frac{\partial \mathcal{L}}{\partial \mathbf{a}} \cdot \frac{\partial \mathbf{a}}{\partial \mathbf{z}} \cdot \mathbf{x}^\top$$

$$\frac{\partial \mathcal{L}}{\partial \mathbf{x}} = W^\top \cdot \frac{\partial \mathcal{L}}{\partial \mathbf{z}}$$

**한국어로 읽기**: "손실의 가중치 미분 = (출력에서 온 기울기) × (활성화 미분) × (입력의 전치). 입력 방향 기울기 = 가중치 전치 × 현재 기울기."

**직관적 의미**: 공장 라인 비유.
- 순전파: 원료(x) → 가공(Wx+b) → 포장(σ) → 출하
- 역전파: 불량품(loss) 발견 → 각 공정이 "내 탓이 얼마인지" 역추적
- $W^\top$: 순전파의 "역방향" 정보 흐름 (가중치를 뒤집어서)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\partial L / \partial a$ | 상위 레이어에서 내려온 기울기 |
| $\partial a / \partial z$ | 활성화 함수의 기울기 (= σ'(z)) |
| $x^\top$ | 외적으로 W의 각 원소별 기울기 계산 |
| $W^\top$ | 기울기를 이전 레이어로 전파 |

**코드로 번역**:
```python
# PyTorch가 자동 수행
loss.backward()
print(layer.weight.grad)  # ∂L/∂W
```

**관련 수식**: [29] Chain Rule, [47] GD Update, [9] Softmax 자코비안, [11] 시그모이드 미분

## [49] 행렬식 (Determinant) 성질

**수식**:
$$\det(AB) = \det(A)\det(B)$$
$$\det(A^{-1}) = \frac{1}{\det(A)}$$
$$\det(A) = \prod_{i=1}^{n} \lambda_i$$

**한국어로 읽기**: "행렬식은 선형변환이 공간을 몇 배 늘이거나 줄이는지(부피 변화율)를 나타낸다."

**직관적 의미**: 단위 정사각형에 변환 A를 적용했을 때 면적이 |det(A)|배가 됨.
- det=0: 차원 축소 (찌부러짐) → 역행렬 없음
- det=1: 부피 보존 (회전)
- det<0: 방향 뒤집힘 (거울 반사)
- **확률에서**: 변수 변환 시 확률밀도에 $|det(J)|^{-1}$을 곱해야 함

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\prod \lambda_i$ | 각 고유 방향에서의 스케일링을 모두 곱함 |
| $\det(AB)$ | 연속 변환의 부피 변화 = 각 변환의 곱 |

**코드로 번역**:
```python
det = torch.linalg.det(A)
```

**관련 수식**: [27] 고유값 분해, [5] 가우시안 (다변량에서 $|\Sigma|$ 등장), [19] 가우시안 KL

## [50] Log-Sum-Exp Trick

**수식**:
$$\log \sum_k \exp(z_k) = M + \log \sum_k \exp(z_k - M), \quad M = \max_k z_k$$

**한국어로 읽기**: "최대값을 빼고 exp를 취한 뒤 다시 더하면, 수치적 오버플로 없이 log-sum-exp를 계산할 수 있다."

**직관적 의미**: 소프트맥스 계산 시 $\exp(1000)$은 무한대(오버플로), $\exp(-1000)$은 0(언더플로).
- 최대값 M을 빼면: 가장 큰 항이 $\exp(0)=1$이 되고, 나머지는 $\exp(\text{음수})$
- 수학적으로 동일하지만 수치적으로 안정

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $M = \max z_k$ | exp의 최대 인자를 제거하여 오버플로 방지 |
| $z_k - M$ | 모든 인자가 ≤ 0 → exp 값이 (0, 1] |
| $+ M$ 바깥 | 빼낸 만큼 다시 보상 |

**코드로 번역**:
```python
lse = torch.logsumexp(logits, dim=-1)  # 내부적으로 trick 적용
```

**관련 수식**: [8] Softmax (log-softmax = z - logsumexp(z)), [12] CE Loss

<a id="51"></a>
## [51] ReLU 및 미분

**수식**:
$$\text{ReLU}(z) = \max(0, z)$$

$$\text{ReLU}'(z) = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$$

**한국어로 읽기**: "양수는 그대로 통과, 음수는 0으로 차단."

**직관적 의미**: 밸브/게이트. 양수 신호만 통과시키는 가장 단순한 비선형 함수.
- 시그모이드의 vanishing gradient 문제 해결: z>0이면 기울기=1 (그대로 전파)
- 음수 영역에서 기울기=0 → "Dead ReLU" 문제
- 해결: Leaky ReLU ($\max(\alpha z, z)$, $\alpha = 0.01$)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\max(0, z)$ | 음수 제거 → 희소 활성화 (대부분의 뉴런이 0) |
| 미분=1 | 양수에서 기울기 소멸 없음 → 깊은 네트워크 학습 가능 |

**코드로 번역**:
```python
output = F.relu(z)
```

**관련 수식**: [10] 시그모이드, [11] 시그모이드 미분 (vanishing gradient), [48] Backprop

<a id="52"></a>
## [52] Frobenius Norm

**수식**:
$$\|A\|_F = \sqrt{\sum_{i,j} a_{ij}^2} = \sqrt{\text{tr}(A^\top A)} = \sqrt{\sum_i \sigma_i^2}$$

**한국어로 읽기**: "프로베니우스 노름은 행렬의 모든 원소 제곱합의 제곱근이다."

**직관적 의미**: 행렬을 하나의 긴 벡터로 펼쳤을 때의 유클리드 노름.
- "행렬의 전체 크기"를 하나의 숫자로 요약
- L2 정규화에서 $\|W\|_F^2 = \sum w_{ij}^2$

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\sum a_{ij}^2$ | 모든 원소의 크기 합산 |
| $= \text{tr}(A^\top A)$ | trace와의 연결 → 행렬 미분에 유용 |
| $= \sum \sigma_i^2$ | 특이값과의 연결 → SVD 분석에 유용 |

**코드로 번역**:
```python
norm = torch.linalg.norm(A, 'fro')
```

**관련 수식**: [24] Trace, [26] SVD, [45] L2 정규화

<a id="53"></a>
## [53] Positive Definite 조건

**수식**:
$$A \succ 0 \quad \Longleftrightarrow \quad \mathbf{x}^\top A \mathbf{x} > 0 \quad \forall \mathbf{x} \neq \mathbf{0}$$

동치 조건:
$$A \succ 0 \quad \Longleftrightarrow \quad \text{모든 고유값 } \lambda_i > 0$$

**한국어로 읽기**: "양정치 행렬은 어떤 영이 아닌 벡터로 이차형식을 만들어도 항상 양수인 행렬이다."

**직관적 의미**: "모든 방향으로 위를 향하는 그릇(bowl)" 모양.
- MSE의 손실 곡면이 이 모양 → 유일한 최소점 존재
- 공분산 행렬 Σ는 항상 PSD (positive semi-definite)
- $X^\top X$도 항상 PSD → 정규방정식의 해 존재 보장

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $x^\top A x > 0$ | 이차형식이 항상 양수 → "아래로 볼록" |
| 모든 $\lambda_i > 0$ | 모든 고유 방향에서 양의 곡률 |

**코드로 번역**:
```python
eigenvalues = torch.linalg.eigvalsh(A)
is_pd = torch.all(eigenvalues > 0)
```

**관련 수식**: [27] 고유값 분해, [28] 정규방정식 ($X^\top X$), [5] 가우시안 (Σ PD)

<a id="54"></a>
## [54] Evidence (Marginal Likelihood)

**수식**:
$$P(E) = \sum_{\theta} P(E|\theta) P(\theta) \quad \text{(이산)}$$
$$P(E) = \int P(E|\theta) P(\theta) \, d\theta \quad \text{(연속)}$$

**한국어로 읽기**: "증거(데이터)의 확률은 모든 가능한 파라미터에 대해 가능도 × 사전확률을 적분/합산한 것이다."

**직관적 의미**: "이 모델 구조 자체가 데이터를 얼마나 잘 설명하는가"의 측정.
- 특정 θ 하나가 아니라, 모든 θ를 고려한 데이터의 평균 가능도
- **모델 비교(Model Selection)**에 사용: Evidence가 높은 모델 = 더 좋은 모델
- Bayes 정리의 분모 → 사후확률을 정규화하는 상수
- 보통 계산 불가능(적분이 어려움) → 근사 기법 필요 (변분추론 등)

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $P(E\|\theta)$ | 각 θ에서의 데이터 적합도 |
| $P(\theta)$ | 사전 가중치 |
| $\int / \sum$ | 모든 θ에 대한 종합 → θ를 "적분해서 없앰" |

**코드로 번역**:
```python
# 몬테카를로 근사
thetas = prior.sample((10000,))
evidence = torch.mean(likelihood(data, thetas))
```

**관련 수식**: [1] Bayes 정리 (분모), [41] 전체 확률의 법칙, [2] MAP (Evidence 무시)

## [55] Beta 분포 PDF

**수식**:
$$\text{Beta}(\theta|\alpha,\beta) = \frac{\theta^{\alpha-1}(1-\theta)^{\beta-1}}{B(\alpha,\beta)}$$

여기서 $B(\alpha,\beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$

**한국어로 읽기**: "베타 분포는 [0,1] 구간에서 정의되며, α와 β로 모양이 결정되는 분포이다."

**직관적 의미**: "확률의 확률"을 모델링. 베르누이의 θ에 대한 사전확률로 이상적.
- α=β=1: 균등분포 (아무것도 모르겠다)
- α=β=5: 0.5 근처에 집중 (공정한 동전일 것 같다)
- α=10, β=2: 1 근처에 집중 (높은 확률일 것 같다)
- **켤레 사전확률**: 베르누이 + 베타 → 사후확률도 베타 → 계산 용이

**왜 이 형태인가**:
| 항 | 역할 |
|---|------|
| $\theta^{\alpha-1}$ | α가 클수록 1에 가까운 θ 선호 |
| $(1-\theta)^{\beta-1}$ | β가 클수록 0에 가까운 θ 선호 |
| $B(\alpha,\beta)$ | 정규화 상수 (적분=1) |
| 베르누이와 곱 | $\theta^x(1-\theta)^{1-x} \cdot \theta^{\alpha-1}(1-\theta)^{\beta-1} = \theta^{x+\alpha-1}(1-\theta)^{1-x+\beta-1}$ → 여전히 Beta! |

**코드로 번역**:
```python
dist = torch.distributions.Beta(alpha, beta)
p = dist.log_prob(theta).exp()
```

**관련 수식**: [6] 베르누이, [36] MAP for Bernoulli with Beta Prior

## 유도 체인 참조 (시험 빈출)

### 체인 1: i.i.d. → 로그 → MLE
$$\prod P(x_i|\theta) \xrightarrow{\log} \sum \log P(x_i|\theta) \xrightarrow{\frac{d}{d\theta}=0} \hat{\theta}_{\text{ML}}$$
관련: [32] → [3] → [33]/[34]/[35]

### 체인 2: MLE + Prior → MAP
$$\sum \log P(x_i|\theta) + \log P(\theta) \xrightarrow{\frac{d}{d\theta}=0} \hat{\theta}_{\text{MAP}}$$
관련: [32] + [4] → [2] → [36]

### 체인 3: 가우시안 MLE → MSE
$$\sum \log \mathcal{N}(y_i|h(x_i),\sigma^2) \propto -\sum(y_i - h(x_i))^2$$
관련: [5] → [32] → [13]

### 체인 4: CE 최소화 → KL 최소화
$$\min H(p,q) = \min[H(p) + D_{\text{KL}}(p\|q)] = \min D_{\text{KL}}(p\|q)$$
관련: [18] → [16] → [17] → [12]

### 체인 5: 가우시안 Prior → L2 정규화
$$\log P(\theta) = \log \mathcal{N}(\theta|0, 1/\lambda) \propto -\frac{\lambda}{2}\|\theta\|^2$$
관련: [5] → [2] → [45]

### 체인 6: Softmax + CE → 깔끔한 기울기
$$\frac{\partial \mathcal{L}_{\text{CE}}}{\partial z_k} = p_k - y_k \quad \text{(예측 - 정답)}$$
관련: [8] + [12] → [9] + [29]
