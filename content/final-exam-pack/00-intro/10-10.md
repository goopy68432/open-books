# 딥러닝 이론 개념 연결 지도 — 완전 딥다이브

이 문서의 핵심 메시지는 단 하나입니다:

$$\boxed{\theta^* = \arg\max_\theta \log p(\mathcal{D}\mid\theta) + \log p(\theta)}$$

이 한 줄에서 **MSE, Cross-Entropy, L1/L2 정규화, Softmax, KL Divergence, ELBO** 등 우리가 아는 거의 모든 손실함수와 정규화가 파생됩니다. 이를 따라 한 단계씩 풀어보겠습니다.

---

## Part 1. 3대 기둥 — 선형대수, 미적분/최적화, 확률론

딥러닝의 모든 수학은 이 세 기둥의 교차점에서 발생합니다.

| 기둥 | 핵심 객체 | 딥러닝에서의 역할 |
|------|----------|-----------------|
| 선형대수 | 벡터, 행렬, 고유값 | 층(layer)의 변환, 표현(representation) |
| 미적분/최적화 | 그래디언트, 헤시안 | 학습 알고리즘 (역전파, SGD) |
| 확률론 | 분포, 조건부확률, 베이즈 | 손실함수, 정규화, 일반화 |

세 기둥은 독립이 아니며, **MAP 추정**이라는 한 점에서 만납니다.

## Part 2. 30개 개념의 수학적 딥다이브

### 개념 1. 행렬 = 선형변환

벡터공간 $V, W$ 사이의 선형변환 $T: V \to W$는 두 조건을 만족합니다:

$$T(\alpha x + \beta y) = \alpha T(x) + \beta T(y)$$

기저 $\{e_1, \ldots, e_n\}$를 잡으면 $T$는 행렬 $A \in \mathbb{R}^{m\times n}$로 표현됩니다. 신경망 한 층은 다음과 같습니다:

$$f(x) = \sigma(Wx + b)$$

여기서 $Wx$가 선형변환이고 $\sigma$가 비선형성입니다. **만약 $\sigma$가 없다면** $L$개 층의 합성도 $W_L W_{L-1} \cdots W_1 x = W_{\text{eff}} x$로 단일 선형변환에 불과합니다. 비선형성이 표현력의 원천인 이유입니다.

---

### 개념 2. 고유값/고유벡터

$Av = \lambda v$를 만족하는 $(\lambda, v)$ 쌍입니다. 특성다항식 $\det(A - \lambda I) = 0$의 해입니다.

**대칭행렬의 스펙트럼 정리**: $A = A^\top$이면 $A = Q\Lambda Q^\top$, 여기서 $Q$는 직교행렬, $\Lambda$는 대각행렬.

**조건수와 학습률**: Hessian $H$의 최대 고유값을 $\lambda_{\max}$라 할 때, 경사하강법이 수렴하려면

$$\eta < \frac{2}{\lambda_{\max}(H)}$$

증명 스케치: 이차 근사 $L(\theta) \approx \frac{1}{2}\theta^\top H \theta$에서 업데이트는 $\theta_{t+1} = (I - \eta H)\theta_t$. 수렴 조건은 $\|I - \eta H\|_{\text{op}} < 1$, 즉 모든 고유값 $\mu$에 대해 $|1 - \eta\mu| < 1$이어야 하므로 $\eta < 2/\lambda_{\max}$.

조건수 $\kappa = \lambda_{\max}/\lambda_{\min}$가 크면 좁고 긴 골짜기 형태가 되어 수렴이 느려집니다.

---

### 개념 3. SVD (특이값 분해)

임의의 $A \in \mathbb{R}^{m\times n}$에 대해

$$A = U\Sigma V^\top, \quad U \in \mathbb{R}^{m\times m},\ V \in \mathbb{R}^{n\times n},\ \Sigma = \text{diag}(\sigma_1, \ldots, \sigma_r)$$

여기서 $\sigma_1 \ge \cdots \ge \sigma_r > 0$.

**Eckart–Young 정리**: rank $\le k$ 행렬 중 $\|A - B\|_F$를 최소화하는 것은

$$A_k = \sum_{i=1}^k \sigma_i u_i v_i^\top$$

이고, 그 오차는

$$\|A - A_k\|_F^2 = \sum_{i=k+1}^r \sigma_i^2$$

**증명 스케치**: $\|A\|_F^2 = \text{tr}(A^\top A) = \sum \sigma_i^2$ (Frobenius norm은 직교 변환에 불변). rank $k$ 근사 중 가장 큰 $k$개 특이값을 보존하는 것이 손실을 최소화함은 변분법(Courant–Fischer)으로 보일 수 있습니다.

이것이 LoRA의 이론적 정당성입니다: $\Delta W \approx BA$ ($B \in \mathbb{R}^{d\times r}, A \in \mathbb{R}^{r\times d}$)로 rank $r$ 근사.

---

### 개념 4. Rank-Nullity 정리

선형변환 $T: V \to W$에 대해

$$\dim(\ker T) + \dim(\text{im}\, T) = \dim V$$

ReLU를 통과하면 음수 뉴런이 0이 되어 사실상 일부 차원이 죽습니다 → kernel(null space)이 커지고 rank가 줄어듭니다. 깊은 신경망에서 rank가 단조감소하면 정보가 잃습니다.

**Skip Connection**: $h_{l+1} = h_l + f(h_l)$. 야코비안은 $I + \partial f/\partial h_l$이므로 항상 항등성분이 보존되어 rank 손실을 막아줍니다.

---

### 개념 5. 내적 = 유사도

$\langle x, y\rangle = \|x\|\|y\|\cos\theta$. **코시-슈바르츠 부등식**:

$$|\langle x, y\rangle| \le \|x\|\cdot \|y\|$$

**Attention의 √d 스케일링 유도**: $q_i, k_i \overset{iid}{\sim} \mathcal{N}(0,1)$이라 가정하면

$$\text{Var}(q^\top k) = \text{Var}\left(\sum_{i=1}^d q_i k_i\right) = \sum_{i=1}^d \text{Var}(q_i k_i) = \sum_{i=1}^d \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] = d$$

분산이 $d$로 커지면 Softmax 입력의 스케일이 커져 출력이 거의 one-hot이 되고, 그래디언트가 소실됩니다. 따라서 $\sqrt{d}$로 나누어 분산을 1로 정규화:

$$\text{Attention}(Q,K,V) = \text{Softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right) V$$

### 개념 6. 그래디언트

$\nabla f(x) = \left(\frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_n}\right)^\top$.

**기하학적 의미**: $\nabla f$는 등고선 $\{x : f(x) = c\}$에 수직이며 가장 가파른 상승 방향. 증명: 단위벡터 $u$ 방향의 방향도함수는 $D_u f = u^\top \nabla f \le \|u\|\|\nabla f\| = \|\nabla f\|$ (Cauchy-Schwarz), 등호는 $u = \nabla f / \|\nabla f\|$일 때.

**Score function** $\nabla_x \log p(x)$는 확률밀도의 그래디언트로 Diffusion 모델의 핵심 (score matching).

---

### 개념 7. 야코비안

$f: \mathbb{R}^n \to \mathbb{R}^m$의 야코비안 $J_f \in \mathbb{R}^{m\times n}$:

$$(J_f)_{ij} = \frac{\partial f_i}{\partial x_j}$$

**합성함수의 체인룰**: $g \circ f$의 야코비안은 $J_{g\circ f}(x) = J_g(f(x)) \cdot J_f(x)$ (행렬곱).

**변수변환 공식**: $y = f(x)$가 가역이면

$$p_Y(y) = p_X(f^{-1}(y))\cdot |\det J_{f^{-1}}(y)|$$

이것이 **Normalizing Flow**의 핵심: 가역 변환들의 합성으로 단순 분포를 복잡한 분포로 변환하면서 likelihood를 야코비안 행렬식으로 정확히 계산할 수 있습니다.

---

### 개념 8. 헤시안

$H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$. 대칭행렬 (Schwarz 정리, $f \in C^2$일 때).

**테일러 전개**:

$$f(x + \Delta) \approx f(x) + \nabla f(x)^\top \Delta + \frac{1}{2}\Delta^\top H \Delta$$

**볼록성 판정**: $f$가 볼록 $\iff H \succeq 0$ (양반정치).

**Newton's method**: 이차 근사를 직접 풀면

$$\Delta^* = -H^{-1}\nabla f$$

이차 수렴(quadratic convergence)을 가지나 $H^{-1}$ 계산 비용이 큼. **Adam**은 대각 근사 $H \approx \text{diag}(v)$로 이를 흉내냅니다.

**예시**: $f(x) = \frac{1}{2}x^\top A x + b^\top x + c$의 그래디언트는 $\nabla f = Ax + b$ (단, $A = A^\top$일 때), 헤시안은 $H = A$. $A \succ 0$이면 $\nabla f = 0 \Rightarrow x^* = -A^{-1}b$가 유일한 전역 최솟값.

---

### 개념 9. 체인룰 = 역전파

$L$층 신경망 $h_l = \sigma(W_l h_{l-1})$에 대해

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial h_L}\cdot \prod_{l=2}^{L}\frac{\partial h_l}{\partial h_{l-1}}\cdot \frac{\partial h_1}{\partial W_1}$$

각 $\partial h_l/\partial h_{l-1}$는 야코비안 행렬. 만약 모든 야코비안의 spectral norm이 $s$라면 곱은 $s^L$로 지수적으로 변합니다.

**Sigmoid의 vanishing**: $\sigma'(x) = \sigma(x)(1-\sigma(x)) \le 1/4$. 4층만 거치면 $0.25^4 \approx 0.004$로 그래디언트 소실.

**ResNet 해결책**: $h_{l+1} = h_l + f(h_l) \Rightarrow \frac{\partial h_{l+1}}{\partial h_l} = I + \frac{\partial f}{\partial h_l}$. 항등성분 $I$가 그래디언트의 최소 흐름을 보장합니다.

### 개념 10. Softmax — 라그랑주로부터의 유도

**최대 엔트로피 원리**: 제약을 만족하는 분포 중 엔트로피가 최대인 것을 선택 (가장 "겸손한" 분포).

**문제**:

$$\max_p H(p) = -\sum_k p_k \log p_k \quad \text{s.t.}\quad \sum_k p_k = 1,\quad \sum_k p_k f_k = \mu$$

**라그랑주 함수**:

$$\mathcal{L}(p, \lambda, \beta) = -\sum_k p_k \log p_k - \lambda\!\left(\sum_k p_k - 1\right) - \beta\!\left(\sum_k p_k f_k - \mu\right)$$

각 $p_k$로 미분:

$$\frac{\partial \mathcal{L}}{\partial p_k} = -\log p_k - 1 - \lambda - \beta f_k = 0$$

$$\Rightarrow p_k = \exp(-1 - \lambda - \beta f_k) = \frac{\exp(-\beta f_k)}{Z},\quad Z = \sum_j \exp(-\beta f_j)$$

이것이 바로 **Softmax**(=Boltzmann 분포)입니다. $z_k = -\beta f_k$로 놓으면 친숙한 형태:

$$p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$$

**log-sum-exp**는 max의 smooth 근사:

$$\text{LSE}(z) = \log \sum_k e^{z_k},\quad \max_k z_k \le \text{LSE}(z) \le \max_k z_k + \log K$$

### 개념 11. 볼록함수

**정의**: $\forall \lambda \in [0,1]:\ f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda) f(y)$.

**1차/2차 조건** ($f \in C^2$):
- $f(y) \ge f(x) + \nabla f(x)^\top (y - x)$ (1차)
- $\nabla^2 f \succeq 0$ (2차)

**전역 최소성 정리**: $f$ 볼록, $\nabla f(x^*) = 0$이면 $x^*$는 전역 최솟값.

**증명**: 1차 조건에서 $f(y) \ge f(x^*) + 0 = f(x^*)$ ($\forall y$). □

신경망 손실은 일반적으로 비볼록이지만, **overparameterized regime** (Neural Tangent Kernel)에서는 거의 볼록한 landscape에 가깝다고 알려져 있습니다.

---

### 개념 12. Jensen 부등식

$f$가 볼록, $X$ 확률변수일 때:

$$f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$$

오목함수면 부호 반대.

**증명 스케치**: $\mu = \mathbb{E}[X]$에서의 1차 조건 $f(x) \ge f(\mu) + f'(\mu)(x - \mu)$의 양변에 기대값:V

$$\mathbb{E}[f(X)] \ge f(\mu) + f'(\mu)\mathbb{E}[X - \mu] = f(\mu) \quad \square$$

**KL ≥ 0 증명**: $-\log$가 볼록이므로

$$\text{KL}(p\|q) = \sum p(x)\log\frac{p(x)}{q(x)} = -\sum p(x)\log\frac{q(x)}{p(x)} = \mathbb{E}_p\!\left[-\log\frac{q}{p}\right]$$

$$\ge -\log \mathbb{E}_p\!\left[\frac{q}{p}\right] = -\log\sum_x q(x) = -\log 1 = 0$$

등호는 $p = q$ a.e.에서 성립.

**ELBO 유도** (VAE):

$$\log p(x) = \log\int p(x,z)dz = \log\int q(z|x)\frac{p(x,z)}{q(z|x)}dz \ge \mathbb{E}_q\!\left[\log\frac{p(x,z)}{q(z|x)}\right]$$

$$= \mathbb{E}_q[\log p(x|z)] - \text{KL}(q(z|x)\|p(z))$$

이 하한(ELBO)을 $q$와 $\theta$에 대해 동시에 최대화합니다.

### 개념 13. 라그랑주 승수법

**문제**: $\max f(x)$ s.t. $g(x) = 0$.

**필요조건**: $\nabla f(x^*) = \lambda \nabla g(x^*)$, $g(x^*) = 0$.

**기하학적 의미**: 목적함수 등고선과 제약 곡면이 접한다. 그렇지 않으면 제약을 따라 이동하며 $f$를 더 키울 수 있음.

**KKT 조건 확장** (부등식 제약 $g_i(x) \le 0$ 추가):
1. Stationarity: $\nabla f + \sum \lambda_i \nabla g_i + \sum \mu_j \nabla h_j = 0$
2. Primal feasibility: $g_i \le 0$, $h_j = 0$
3. Dual feasibility: $\lambda_i \ge 0$
4. Complementary slackness: $\lambda_i g_i = 0$

라그랑주 승수의 의미는 **shadow price** — 제약을 1단위 완화할 때 목적함수 증가량.

### 개념 14. 조건부확률

$$p(A|B) = \frac{p(A, B)}{p(B)}$$

**신경망 출력의 확률적 해석**:
- 분류: $p(y=k|x;\theta) = \text{Softmax}(f_\theta(x))_k$
- 회귀: $p(y|x;\theta) = \mathcal{N}(y; f_\theta(x), \sigma^2)$

**Autoregressive 분해**:

$$p(x_1, \ldots, x_T) = \prod_{t=1}^T p(x_t | x_{<t})$$

GPT가 정확히 이 분해를 학습합니다.

---

### 개념 15. i.i.d. 가정

$\mathcal{D} = \{x_i\}_{i=1}^n$가 i.i.d.면

$$p(\mathcal{D}|\theta) = \prod_{i=1}^n p(x_i|\theta) \Rightarrow \log p(\mathcal{D}|\theta) = \sum_{i=1}^n \log p(x_i|\theta)$$

이 분해 덕분에 **미니배치 SGD가 정당화**됩니다: 미니배치의 그래디언트 평균은 전체 그래디언트의 unbiased estimator.

$$\mathbb{E}\!\left[\frac{1}{B}\sum_{i \in \mathcal{B}} \nabla \ell_i\right] = \nabla L$$

---

### 개념 16. 베르누이 분포

$$p(y; p) = p^y(1-p)^{1-y},\quad y \in \{0,1\}$$

**시그모이드의 자연스러움**: 자연모수 $\eta = \log\frac{p}{1-p}$ (logit)로 매개화하면 $p = \sigma(\eta) = \frac{1}{1+e^{-\eta}}$. 신경망 출력 $z = w^\top x$를 자연모수로 해석하면 $p = \sigma(z)$가 자동으로 나옵니다.

**BCE 유도**:

$$-\log p(y|x) = -y\log\sigma(z) - (1-y)\log(1-\sigma(z))$$

이것이 Binary Cross-Entropy.

**그래디언트의 단순성**: $\partial(-\log p)/\partial z = \sigma(z) - y$ (지수족의 일반적 성질).

---

### 개념 17. 가우시안 분포

$$p(y; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi}\sigma}\exp\!\left(-\frac{(y-\mu)^2}{2\sigma^2}\right)$$

$y|x \sim \mathcal{N}(f_\theta(x), \sigma^2)$ 가정 시 NLL:

$$-\log p(y|x) = \frac{(y - f_\theta(x))^2}{2\sigma^2} + \frac{1}{2}\log(2\pi\sigma^2)$$

$\theta$에 무관한 항을 버리면

$$\text{NLL} \propto \sum_i (y_i - f_\theta(x_i))^2 = \text{MSE}\cdot n$$

→ **MSE는 가우시안 가정의 직접적 결과**.

**가우시안 Prior $p(\theta) = \mathcal{N}(0, \tau^2 I)$**:

$$-\log p(\theta) = \frac{\|\theta\|^2}{2\tau^2} + \text{const}$$

이것이 **L2 정규화** = $\lambda \|\theta\|^2$ 형태 (단, $\lambda = 1/(2\tau^2)$).

---

### 개념 18. 중심극한정리 (CLT)

$X_1, \ldots, X_n \overset{iid}{\sim}$ 평균 $\mu$, 분산 $\sigma^2$이면

$$\sqrt{n}(\bar X_n - \mu) \xrightarrow{d} \mathcal{N}(0, \sigma^2)$$

**SGD 그래디언트 분포**: 배치 크기 $B$가 크면

$$\nabla L_{\text{batch}} \approx \mathcal{N}(\nabla L_{\text{true}}, \Sigma/B)$$

배치 크기를 4배 늘리면 노이즈 표준편차는 절반.

**Xavier/He Initialization**: $h_{l+1} = W_{l+1} h_l$의 각 성분은 많은 항의 합 → CLT 적용 → 가우시안 유지. 이 분산이 층마다 보존되도록 $W$의 분산을 설정한 것이 Xavier ($\text{Var}(W) = 2/(n_{in}+n_{out})$), He ($2/n_{in}$).

### 개념 19. 베이즈 정리

$$p(\theta|\mathcal{D}) = \frac{p(\mathcal{D}|\theta)\, p(\theta)}{p(\mathcal{D})}$$

로그를 취해 $\theta$로 최대화하면 $\log p(\mathcal{D})$는 상수이므로

$$\arg\max_\theta \log p(\theta|\mathcal{D}) = \arg\max_\theta\!\left[\log p(\mathcal{D}|\theta) + \log p(\theta)\right]$$

→ **MAP = MLE + 정규화**.

**모든 정규화는 사전분포다**. 이것이 본 문서의 가장 중요한 통찰입니다.

---

### 개념 20. MLE = KL 최소화 (증명)

$$\arg\min_\theta \text{KL}(p_{\text{data}} \| p_\theta) = \arg\min_\theta \mathbb{E}_{x\sim p_{\text{data}}}\!\left[\log\frac{p_{\text{data}}(x)}{p_\theta(x)}\right]$$

$$= \arg\min_\theta\!\left[\mathbb{E}[\log p_{\text{data}}] - \mathbb{E}[\log p_\theta]\right] = \arg\min_\theta -\mathbb{E}[\log p_\theta]$$

(첫 항은 $\theta$ 무관). 경험분포 $\hat p_{\text{data}} = \frac{1}{n}\sum_i \delta_{x_i}$로 근사하면

$$= \arg\min_\theta -\frac{1}{n}\sum_i \log p_\theta(x_i) = \arg\max_\theta \prod_i p_\theta(x_i) = \text{MLE} \quad \square$$

---

### 개념 21. MAP — L2 정규화 유도

$p(\theta) = \mathcal{N}(0, \tau^2 I)$, $p(y|x;\theta) = \mathcal{N}(f_\theta(x), \sigma^2)$로 가정:

$$-\log p(\theta|\mathcal{D}) = \underbrace{\frac{1}{2\sigma^2}\sum_i (y_i - f_\theta(x_i))^2}_{\text{데이터 항}} + \underbrace{\frac{1}{2\tau^2}\|\theta\|^2}_{\text{정규화}} + \text{const}$$

$\sigma^2$로 양변을 나누면

$$\arg\min_\theta\!\left[\sum_i (y_i - f_\theta(x_i))^2 + \frac{\sigma^2}{\tau^2}\|\theta\|^2\right]$$

따라서 $\boxed{\lambda = \sigma^2/\tau^2}$. Prior 분산 $\tau^2$가 작을수록 (Prior를 강하게 믿을수록) $\lambda$ 큼.

**Prior–정규화 대응표**:

| Prior | $-\log p(\theta)$ | 정규화 |
|-------|-------------------|--------|
| $\mathcal{N}(0, \tau^2 I)$ | $\|\theta\|^2/(2\tau^2)$ | L2 (Ridge) |
| Laplace$(0, b)$ | $\|\theta\|_1/b$ | L1 (Lasso) |
| Uniform | const | 없음 (=MLE) |
| Spike-and-Slab | 혼합 | L0 근사 (Dropout) |

---

### 개념 22. Prior/Posterior

순차 학습에서 **오늘의 Posterior = 내일의 Prior**:

$$p(\theta|\mathcal{D}_1, \mathcal{D}_2) \propto p(\mathcal{D}_2|\theta)\, p(\theta|\mathcal{D}_1)$$

CNN의 weight sharing은 "공간 불변성" Prior를 강하게 인코딩합니다 — 이것은 데이터 효율성을 극적으로 높이는 inductive bias입니다.

---

### 개념 23. Likelihood

$L(\theta; \mathcal{D}) = p(\mathcal{D}|\theta)$ — 같은 함수를 $\theta$의 함수로 보는 것. **확률이 아닙니다**: $\int L(\theta) d\theta \ne 1$ 일반적으로.

GAN의 discriminator는 likelihood ratio $p_{\text{data}}/p_{\text{model}}$을 추정합니다.

---

### 개념 24. NLL — 손실함수의 통합

$\text{NLL}(\theta) = -\sum_i \log p(y_i|x_i;\theta)$.

| 분포 | NLL (상수 무시) | 손실함수 이름 |
|------|----------------|--------------|
| Gaussian | $\sum (y_i - f_i)^2$ | MSE |
| Bernoulli | $-\sum [y_i\log p_i + (1-y_i)\log(1-p_i)]$ | BCE |
| Categorical | $-\sum_i \sum_k y_{ik}\log p_{ik}$ | CE |
| Poisson | $\sum [f_i - y_i \log f_i]$ | Poisson Loss |

**NLL과 CE의 동치**:

$$\text{NLL} = -\mathbb{E}_{\hat p_{\text{data}}}[\log p_\theta] = H(\hat p_{\text{data}}, p_\theta) = H(\hat p_{\text{data}}) + \text{KL}(\hat p_{\text{data}}\|p_\theta)$$

첫 항이 상수이므로 NLL 최소화 = KL 최소화 = MLE.

---

### 개념 25. Cross-Entropy

$H(p, q) = -\sum p(x)\log q(x) = H(p) + \text{KL}(p\|q)$.

**원-핫 라벨 $y_k = \mathbb{1}[k = k^*]$에서**:

$$H(y, p) = -\log p_{k^*}$$

→ CE = NLL of correct class.

**Softmax + CE의 그래디언트 = $p - y$ 유도**:

logits $z_k$, $p_k = e^{z_k}/Z$ ($Z = \sum_j e^{z_j}$), $L = -\sum_k y_k \log p_k$.

$$\frac{\partial p_k}{\partial z_j} = \frac{\delta_{kj} e^{z_k} Z - e^{z_k} e^{z_j}}{Z^2} = p_k(\delta_{kj} - p_j)$$

$$\frac{\partial L}{\partial z_j} = -\sum_k \frac{y_k}{p_k}\cdot p_k(\delta_{kj} - p_j) = -\sum_k y_k(\delta_{kj} - p_j) = -y_j + p_j\sum_k y_k = p_j - y_j$$

(마지막에 $\sum_k y_k = 1$ 사용). □

이 깔끔함은 **지수족(exponential family)**의 일반적 성질입니다: 자연모수 $\eta$에 대한 NLL의 그래디언트는 $\mathbb{E}[T(X)] - T(y)$ (충분통계량의 기대값과 관측값의 차).

---

### 개념 26. MSE — 편향-분산 분해

$\hat f(x; \mathcal{D})$를 데이터셋 $\mathcal{D}$로 학습한 추정자, $y = f^*(x) + \varepsilon$, $\varepsilon \sim \mathcal{N}(0,\sigma^2)$:

$$\mathbb{E}_{\mathcal{D}, \varepsilon}[(y - \hat f(x))^2] = \underbrace{(\mathbb{E}_\mathcal{D}[\hat f] - f^*)^2}_{\text{Bias}^2} + \underbrace{\text{Var}_\mathcal{D}[\hat f]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Noise}}$$

**증명 스케치**: $\bar f = \mathbb{E}_\mathcal{D}[\hat f]$로 놓고

$$(y - \hat f)^2 = ((y - f^*) + (f^* - \bar f) + (\bar f - \hat f))^2$$

기대값을 취하면 교차항이 모두 0 (독립성 또는 평균 조건).

이 분해는 **정규화의 필요성**을 정당화합니다: 모델 복잡도↑ → Bias↓, Variance↑ → 적절한 균형(=정규화)이 필요.

**최적해**:
- MSE: $f^*(x) = \mathbb{E}[Y|X=x]$ (조건부 기대값)
- CE: $f^*(x) = p(Y|X=x)$ (조건부 확률)

둘 다 "조건부 무언가"의 추정.

---

### 개념 27. KL Divergence — 비대칭성

$$\text{KL}(p\|q) = \sum p(x)\log\frac{p(x)}{q(x)}$$

**비대칭성의 의미**:
- $\text{KL}(p\|q)$: $p > 0$인 곳에서 $q$도 양수여야 함 → $q$가 $p$의 모든 mode를 덮어야 함 → **mode-covering**
- $\text{KL}(q\|p)$: $q > 0$인 곳에서 $p$도 양수여야 함 → $q$는 $p$의 일부 mode만 잡아도 됨 → **mode-seeking**

| 모델 | 최소화 대상 | 결과 |
|------|------------|------|
| MLE / VAE encoder | $\text{KL}(p_{\text{data}}\|p_\theta)$ | mode-covering, blurry |
| GAN (이론적으로) | $\text{KL}(p_\theta\|p_{\text{data}})$ | mode-seeking, sharp but mode collapse |

**Mutual Information**: $I(X;Y) = \text{KL}(p(x,y)\|p(x)p(y)) \ge 0$, 등호는 독립.

---

### 개념 28. Entropy

$H(p) = -\sum p(x)\log p(x) \ge 0$.

**최댓값**: $K$개 결과 중 균등분포일 때 $H = \log K$ (Jensen으로 증명).

**최대 엔트로피 분포**:
- 합=1만 → Uniform
- 합=1 + 평균 고정 → Exponential
- 합=1 + 평균+분산 고정 → **Gaussian**

**Gaussian이 최대 엔트로피임의 증명 (라그랑주)**:

$$\max -\int p\log p\, dx \quad \text{s.t.}\quad \int p\, dx = 1,\ \int xp\, dx = \mu,\ \int x^2 p\, dx = \mu^2 + \sigma^2$$

$$\mathcal{L} = -\int p\log p - \lambda_0\!\int p - \lambda_1\!\int xp - \lambda_2\!\int x^2 p$$

$\partial \mathcal{L}/\partial p = 0 \Rightarrow -\log p - 1 - \lambda_0 - \lambda_1 x - \lambda_2 x^2 = 0$

$$\Rightarrow p(x) \propto \exp(-\lambda_2 x^2 - \lambda_1 x - (\lambda_0+1))$$

이차함수의 지수 → Gaussian. 제약을 만족하도록 모수를 풀면 $\mathcal{N}(\mu, \sigma^2)$. □

이것이 **CLT와 상통하는 정보이론적 이유**: 가우시안은 평균과 분산만 알 때 가장 "겸손한" 가정입니다.

---

### 개념 29. Regularization — 기하학적 해석

$$\theta^*_{\text{reg}} = \arg\min_\theta L(\theta) + \lambda R(\theta)$$

**라그랑주 쌍대성**: $\min L$ s.t. $R(\theta) \le C$의 라그랑주 함수 $L + \lambda(R - C)$. 이는 위 정규화 문제와 동치 (KKT).

- **L2**: $\|\theta\|^2 \le C$ → 원(공) 제약
- **L1**: $\|\theta\|_1 \le C$ → 마름모 제약

L1의 해가 sparse해지는 이유: 마름모의 꼭짓점에서 등고선과 만날 확률이 높기 때문 (꼭짓점에서는 일부 좌표가 정확히 0).

**Early Stopping ≈ L2** (직관): 최적해 $\theta^*$에서 이차 근사 $L \approx \frac{1}{2}(\theta-\theta^*)^\top H(\theta-\theta^*)$. 학습률 $\eta$로 $T$ step 학습하면 $\theta_T = (I - (I-\eta H)^T)\theta^*$. 한편 L2 ridge 해는 $\theta_{\text{ridge}} = (I + \lambda H^{-1})^{-1}\theta^*$. 고유분해 $H = Q\Lambda Q^\top$ 기준으로 두 식이 유사한 수축(shrinkage) 형태가 됨을 보일 수 있습니다 (Goodfellow et al., 7.8장).

---

### 개념 30. Inductive Bias

모든 설계 결정 = Prior:

| 결정 | Inductive Bias |
|------|---------------|
| CNN (weight sharing) | "유용한 패턴은 공간적으로 국소적·위치 불변" |
| RNN | "패턴은 순차적·시간 불변" |
| Transformer | "모든 위치 간 관계가 잠재적으로 중요" |
| GNN | "패턴은 그래프 구조를 따른다" |
| L2 정규화 | "가중치는 작다" |
| Dropout | "부분 네트워크만으로도 작동해야 한다" |
| Data Augmentation | "변환에 불변해야 한다" |
| Skip Connection | "얕은 표현도 유용하다" |

**No Free Lunch 정리** (Wolpert, 1996): 가능한 모든 함수에 대해 평균을 내면 모든 알고리즘의 성능은 동일하다. → **문제에 맞는 inductive bias가 핵심**.

## Part 3. 핵심 인과 체인 7개 — 한 흐름 정리

### 체인 1: Gaussian → MSE → NLL → KL → Jensen
$p(y|x) = \mathcal{N}(f, \sigma^2)$ 가정 → $-\log p \propto (y-f)^2$ → MSE = NLL → $\text{NLL} = H(p_{\text{data}}, p_\theta) = H + \text{KL}$ → KL ≥ 0 (Jensen).

### 체인 2: Bayes → MAP → L2 → Weight Decay → Generalization
$p(\theta|\mathcal{D}) \propto p(\mathcal{D}|\theta)p(\theta)$ → log Prior = 페널티 → 가우시안 Prior → $\|\theta\|^2$ → SGD에서 $\theta \leftarrow (1-\eta\lambda)\theta - \eta\nabla L$ (weight decay).

### 체인 3: 라그랑주 → 최대엔트로피 → Softmax → CE → ∂L/∂z = p − y
제약 최적화 → Boltzmann 분포 → 분류기 출력 → CE 결합 → 지수족 그래디언트.

### 체인 4: 체인룰 → 야코비안 곱 → Vanishing → ResNet
$\partial L/\partial W_1 = \prod J_l$ → $\sigma' \le 0.25$ → 지수 감쇠 → $h+f(h)$로 $I + \partial f$ 보장.

### 체인 5: 내적 → Attention → √d 스케일링 → Transformer
$\langle q, k\rangle$ 유사도 → $QK^\top$ → $\text{Var} = d$ → $/\sqrt{d}$로 정규화.

### 체인 6: 고유분해 → Hessian → 조건수 → Adam → Flat Minima
$H = Q\Lambda Q^\top$ → $\eta < 2/\lambda_{\max}$ → 큰 $\kappa$ → 적응적 학습률 → flat minima가 일반화 좋음.

### 체인 7: Entropy → CE → NLL → KL → Mutual Info → Information Bottleneck
$H(p)$ → $H(p,q)$ → MLE → $\text{KL} \ge 0$ → $I(X;Y)$ → $\min I(X;T) - \beta I(T;Y)$.

## Part 4. 모든 것을 지배하는 한 줄

$$\theta^* = \arg\max_\theta \underbrace{\log p(\mathcal{D}|\theta)}_{\text{Likelihood (분포 가정)}} + \underbrace{\log p(\theta)}_{\text{Prior (정규화)}}$$

| 분포 가정 | NLL = Loss |
|----------|-----------|
| Gaussian | MSE |
| Bernoulli | BCE |
| Categorical | CE |

| Prior 가정 | $-\log$ Prior = Penalty |
|-----------|------------------------|
| Gaussian | L2 |
| Laplace | L1 |
| Uniform | 없음 |

전체 학습은

$$\arg\min_\theta \underbrace{L(\theta; \mathcal{D})}_{=-\log p(\mathcal{D}|\theta)} + \lambda\underbrace{R(\theta)}_{=-\log p(\theta)}$$

이 한 줄에 30개 개념이 모두 들어 있습니다.
