# 딥러닝 이론 — 15대 유도 체인 플로우차트

> **사용법**: 각 유도는 `[출발점] --("왜")--> [다음 단계]` 형태의 플로우차트로 구성.
> **시험 전략**: "답만 적으면 0점" — 모든 화살표의 **"왜"를 글로 서술**해야 점수.
> 각 단계에서 "왜 이 변환이 정당한가?"를 반드시 적어라.

## 1. i.i.d → 로그 → 미분=0 일반 패턴 (모든 MLE의 기본 골격)

> **이 패턴을 마스터하면 Chain 2~5가 전부 자동으로 풀린다.**

```
[데이터 D = {x₁, ..., xₙ}이 i.i.d]
    │
    │ "왜": 관측값이 서로 독립이고 동일한 분포 p(x|θ)에서 추출됐다고 가정
    │       (통계적 모델링의 기본 가정 — 하나의 관측이 다른 관측에 영향 안 줌)
    ▼
[우도 함수: L(θ) = ∏ᵢ₌₁ⁿ p(xᵢ|θ)]
    │
    │ "왜": i.i.d이면 결합확률 = 개별확률의 곱
    │       P(x₁, x₂, ..., xₙ|θ) = P(x₁|θ)·P(x₂|θ)·...·P(xₙ|θ)
    │       (독립 → 곱, 동일분포 → 같은 p 사용)
    ▼
[로그우도: ℓ(θ) = log L(θ) = Σᵢ₌₁ⁿ log p(xᵢ|θ)]
    │
    │ "왜": log는 단조증가 함수이므로 argmax 보존
    │       log(∏) = Σlog로 변환 → 곱셈이 덧셈으로
    │       (곱셈은 수치적으로 underflow 위험 + 미분이 복잡)
    │       (덧셈은 안정적 + 미분이 개별 항의 합)
    ▼
[MLE: θ* = argmax_θ Σᵢ log p(xᵢ|θ)]
    │
    │ "왜": 최대화 ↔ 미분해서 0인 점 찾기 (필요조건)
    │       볼록/오목 조건 확인 후 충분조건도 체크
    ▼
[∂ℓ/∂θ = Σᵢ ∂/∂θ log p(xᵢ|θ) = 0]
    │
    │ "왜": 미분의 선형성 → Σ 안으로 미분 가능
    │       극값의 필요조건: 기울기 = 0
    ▼
[θ에 대해 풀기 → θ_MLE]
```

**숫자 예시 (Gaussian 평균 추정)**:
- $p(x|\mu) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$
- $\log p = -\frac{(x-\mu)^2}{2\sigma^2} + \text{const}$
- $\sum_i \frac{\partial}{\partial \mu}\left[-\frac{(x_i-\mu)^2}{2\sigma^2}\right] = \sum_i \frac{x_i - \mu}{\sigma^2} = 0$
- $\Rightarrow \mu_{MLE} = \frac{1}{n}\sum_i x_i$ (표본평균!)

## 2. Gaussian → MSE: y ~ N(h(x), σ²) → NLL → MSE

> **"왜 회귀에서 MSE를 쓰는가?" = "노이즈가 Gaussian이라고 가정했기 때문"**

```
[가정: y | x ~ N(h_θ(x), σ²)]
    │
    │ "왜": 관측값 y는 모델 예측 h_θ(x) 주변에서
    │       Gaussian 노이즈로 흩어진다고 가정
    │       (CLT에 의해 많은 작은 독립 노이즈의 합 → 정규분포, Chain 14 참조)
    ▼
[하나의 데이터 확률: p(yᵢ|xᵢ,θ) = (1/√(2πσ²)) exp(-(yᵢ - h_θ(xᵢ))²/(2σ²))]
    │
    │ "왜": Gaussian PDF에 평균=h_θ(xᵢ), 분산=σ² 대입
    ▼
[i.i.d 가정 → 로그우도 (Chain 1 패턴 적용)]
    │
    ▼
[ℓ(θ) = Σᵢ log p(yᵢ|xᵢ,θ)]
    │
    │ "왜": log(곱) = 합(log)
    ▼
[ℓ(θ) = Σᵢ [-½ log(2πσ²) - (yᵢ - h_θ(xᵢ))²/(2σ²)]]
    │
    │ "왜": log(exp(a)) = a, log(1/√(2πσ²)) = -½ log(2πσ²)
    ▼
[ℓ(θ) = -n/2 · log(2πσ²) - 1/(2σ²) · Σᵢ (yᵢ - h_θ(xᵢ))²]
    │
    │ "왜": 첫째 항은 θ와 무관한 상수 → argmax에서 무시 가능
    │       σ²도 상수로 취급 (σ를 모를 때는 별도 추정)
    ▼
[argmax_θ ℓ(θ) = argmax_θ { -1/(2σ²) · Σᵢ (yᵢ - h_θ(xᵢ))² }]
    │
    │ "왜": 음수 부호가 있으므로
    │       argmax(-f) = argmin(f)
    │       1/(2σ²)는 양의 상수 스케일 → argmin에 영향 없음
    ▼
[θ_MLE = argmin_θ Σᵢ (yᵢ - h_θ(xᵢ))²]
    │
    │ "왜": 이것이 바로 MSE 손실 (상수 1/n은 argmin에 영향 없음)
    ▼
[★ 결론: MLE under Gaussian noise ⟺ MSE 최소화]
```

**인과관계 핵심**: Gaussian 가정 → exp 안에 $(y-\hat{y})^2$ → log로 exp 벗기면 제곱 항만 남음 → MSE

## 3. Bernoulli/Categorical → Cross-Entropy: y ~ Cat(h(x)) → NLL → CE

> **"왜 분류에서 Cross-Entropy를 쓰는가?" = "출력이 카테고리 분포라고 가정했기 때문"**

### 3-A. 이진 분류 (Bernoulli)

```
[가정: y ∈ {0,1}, y | x ~ Bernoulli(p), p = h_θ(x) = σ(θᵀx)]
    │
    │ "왜": 이진 분류에서 출력은 0 또는 1
    │       모델이 P(y=1|x) = p를 예측
    ▼
[p(y|x,θ) = p^y · (1-p)^(1-y)]
    │
    │ "왜": Bernoulli 분포의 PMF
    │       y=1이면 p^1·(1-p)^0 = p ✓
    │       y=0이면 p^0·(1-p)^1 = 1-p ✓
    │       (두 케이스를 하나의 식으로 통합하는 트릭)
    ▼
[i.i.d → 로그우도 (Chain 1)]
    ▼
[ℓ(θ) = Σᵢ [yᵢ log p_i + (1-yᵢ) log(1-p_i)]]
    │
    │ "왜": log(p^y · (1-p)^(1-y)) = y·log(p) + (1-y)·log(1-p)
    │       (로그가 곱을 합으로 변환)
    ▼
[NLL = -ℓ(θ) = -Σᵢ [yᵢ log p_i + (1-yᵢ) log(1-p_i)]]
    │
    │ "왜": MLE는 max ℓ → min(-ℓ) = min NLL
    ▼
[★ 이것이 Binary Cross-Entropy (BCE)]
```

### 3-B. 다중 분류 (Categorical)

```
[가정: y ∈ {1,...,K}, one-hot 벡터 y, P(y=k|x) = p_k = softmax(z_θ(x))_k]
    │
    │ "왜": K개 클래스 → 카테고리 분포
    │       softmax는 실수 벡터를 확률 벡터로 변환 (Chain 6 참조)
    ▼
[p(y|x,θ) = ∏ₖ p_k^{y_k}]
    │
    │ "왜": Categorical PMF의 one-hot 표현
    │       정답 클래스 k*에서만 y_{k*}=1, 나머지 0
    │       → p(y|x,θ) = p_{k*}
    ▼
[i.i.d → 로그우도 (Chain 1)]
    ▼
[ℓ(θ) = Σᵢ Σₖ y_k^(i) log p_k^(i)]
    │
    │ "왜": log(∏ₖ p_k^{y_k}) = Σₖ y_k log p_k
    ▼
[NLL = -Σᵢ Σₖ y_k^(i) log p_k^(i)]
    │
    │ "왜": max → min 변환
    ▼
[★ 이것이 Categorical Cross-Entropy]
    │
    │ "왜": H(q, p) = -Σ q(k) log p(k)에서
    │       q = one-hot (경험적 분포), p = 모델 분포
    │       → 정확히 Cross-Entropy의 정의
    ▼
[CE = -Σₖ y_k log p_k  (한 샘플에 대해)]
```

**인과관계 핵심**: Categorical 가정 → PMF에 곱 구조 → log로 합 변환 → $-\sum y_k \log p_k$ = Cross-Entropy

## 4. MAP → L2 Regularization: Gaussian prior → log → Weight Decay

> **"왜 L2 정규화를 쓰는가?" = "가중치에 Gaussian prior를 놓았기 때문"**

```
[MAP 프레임워크: θ_MAP = argmax_θ p(θ|D)]
    │
    │ "왜": MLE는 데이터만 보지만, MAP는 사전지식도 반영
    │       (과적합 방지: "극단적 파라미터는 unlikely하다"는 믿음)
    ▼
[베이즈 정리 적용: p(θ|D) = p(D|θ)·p(θ) / p(D)]
    │
    │ "왜": Chain 8 (베이즈 정리)
    ▼
[argmax_θ p(θ|D) = argmax_θ p(D|θ)·p(θ)]
    │
    │ "왜": p(D)는 θ에 무관한 상수 → argmax에서 제거
    ▼
[로그 취하기: argmax_θ [log p(D|θ) + log p(θ)]]
    │
    │ "왜": log 단조증가 + log(곱)=합
    │       이제 두 항으로 분리됨:
    │       (1) log p(D|θ) = 로그우도 (MLE 항)
    │       (2) log p(θ) = 사전분포 항 (정규화 항)
    ▼
[사전분포 선택: θⱼ ~ N(0, τ²) (각 가중치가 독립 Gaussian)]
    │
    │ "왜": "가중치가 0 근처에 있을 것"이라는 사전 믿음
    │       τ² = 사전분포의 분산 = "얼마나 자유롭게 움직일 수 있는가"
    ▼
[log p(θ) = Σⱼ log p(θⱼ) = Σⱼ [-θⱼ²/(2τ²) - ½log(2πτ²)]]
    │
    │ "왜": 독립가정 → log(곱)=합
    │       Gaussian PDF의 log = 지수 부분만 남음
    ▼
[log p(θ) = -1/(2τ²) · Σⱼ θⱼ² + const]
    │
    │ "왜": 상수 항 모아서 정리
    │       Σⱼ θⱼ² = ||θ||₂² = L2 norm의 제곱
    ▼
[θ_MAP = argmax_θ [ℓ(θ) - 1/(2τ²) · ||θ||₂²]]
    │
    │ "왜": 로그우도 + 사전분포 항 결합
    ▼
[= argmin_θ [-ℓ(θ) + 1/(2τ²) · ||θ||₂²]]
    │
    │ "왜": max → min, 부호 반전
    ▼
[= argmin_θ [NLL + λ||θ||₂²]  여기서 λ = 1/(2τ²)]
    │
    │ "왜": λ는 정규화 강도
    │       τ² 작을수록(사전분포가 좁을수록) → λ 커짐 → 정규화 강함
    │       τ² 클수록(사전분포가 넓을수록) → λ 작음 → MLE에 가까워짐
    ▼
[★ 결론: MAP with Gaussian prior ⟺ L2 Regularization (= Weight Decay)]
```

**인과관계 핵심**: Gaussian prior → log에서 $\theta^2$ 항 등장 → L2 norm

## 5. MAP → L1 Regularization: Laplace prior → log → LASSO

> **"왜 L1은 sparse한 해를 만드는가?" = "Laplace 분포가 0에서 뾰족하기 때문"**

```
[MAP 프레임워크 (Chain 4와 동일한 시작)]
    │
    ▼
[argmax_θ [log p(D|θ) + log p(θ)]]
    │
    │ "왜": 베이즈 정리 + 로그 변환 (Chain 4 참조)
    ▼
[사전분포 선택: θⱼ ~ Laplace(0, b)]
    │
    │ "왜": Laplace는 0에서 뾰족 → "가중치가 정확히 0일 가능성 높다"는 믿음
    │       p(θⱼ) = 1/(2b) · exp(-|θⱼ|/b)
    │       Gaussian과 달리 |θⱼ|이므로 꼭짓점이 생김
    ▼
[log p(θ) = Σⱼ log p(θⱼ) = Σⱼ [-|θⱼ|/b - log(2b)]]
    │
    │ "왜": log(exp(-|θⱼ|/b)) = -|θⱼ|/b
    │       log(1/(2b)) = -log(2b) = 상수
    ▼
[log p(θ) = -1/b · Σⱼ |θⱼ| + const]
    │
    │ "왜": Σⱼ |θⱼ| = ||θ||₁ = L1 norm
    ▼
[θ_MAP = argmin_θ [NLL + λ||θ||₁]  여기서 λ = 1/b]
    │
    │ "왜": Chain 4와 동일한 max→min 변환
    ▼
[★ 결론: MAP with Laplace prior ⟺ L1 Regularization (= LASSO)]
```

**L1 vs L2 기하학적 비교**:
```
L2 (원형 등고선):          L1 (마름모 등고선):
    ╭───╮                      /\
   │  ●  │                   /  ● \
   │     │                  /      \
    ╰───╯                  \      /
                            \  /
                             \/

→ 해가 축 위에 놓일 확률 낮음    → 꼭짓점이 축 위에 있어
  (모든 가중치가 작지만 ≠ 0)       해가 축과 만나기 쉬움 (sparse!)
```

## 6. Lagrangian → Softmax: 엔트로피 정규화 + 제약 → softmax(z/τ)

> **"softmax가 왜 이런 형태인가?" = "제약 최적화의 해가 정확히 softmax이기 때문"**

```
[문제: 로짓 벡터 z가 주어졌을 때, 확률분포 p를 구하고 싶다]
    │
    │ "왜": 신경망 출력 z = (z₁, ..., zₖ)는 실수 → 확률로 변환 필요
    │       조건: (1) pₖ ≥ 0, (2) Σₖ pₖ = 1
    ▼
[최적화 문제: max_p Σₖ pₖ zₖ + τ·H(p)]
    │
    │ 첫째 항: Σₖ pₖ zₖ = 로짓과 확률의 내적 (기대 로짓 최대화)
    │ 둘째 항: τ·H(p) = -τ Σₖ pₖ log pₖ (엔트로피 정규화)
    │ "왜": 엔트로피 항이 없으면 argmax에 모든 확률 몰림 (one-hot)
    │       τ가 클수록 uniform에 가까워짐 (불확실성 선호)
    │       τ가 작을수록 argmax에 가까워짐 (확신)
    │
    │ 제약조건: Σₖ pₖ = 1
    ▼
[라그랑주 함수 구성]
[L(p, λ) = Σₖ pₖ zₖ - τ Σₖ pₖ log pₖ - λ(Σₖ pₖ - 1)]
    │
    │ "왜": 제약 최적화 → 라그랑주 승수법
    │       등식 제약 g(p) = Σpₖ - 1 = 0에 대해 λ 도입
    │       (부등식 pₖ ≥ 0은 해가 자동으로 만족)
    ▼
[∂L/∂pₖ = 0으로 각 pₖ에 대해 미분]
    │
    ▼
[zₖ - τ(log pₖ + 1) - λ = 0]
    │
    │ "왜": ∂/∂pₖ [pₖ zₖ] = zₖ
    │       ∂/∂pₖ [-τ pₖ log pₖ] = -τ(log pₖ + 1)  (곱의 미분)
    │       ∂/∂pₖ [-λ pₖ] = -λ
    ▼
[pₖ에 대해 정리: log pₖ = (zₖ - λ - τ) / τ]
    │
    ▼
[pₖ = exp((zₖ - λ - τ) / τ) = exp(zₖ/τ) · exp(-(λ+τ)/τ)]
    │
    │ "왜": 양변에 exp 씌움
    │       exp(a+b) = exp(a)·exp(b)로 분리
    │       exp(-(λ+τ)/τ)는 k에 무관한 상수
    ▼
[제약조건 Σₖ pₖ = 1 적용]
    │
    │ "왜": Σₖ pₖ = exp(-(λ+τ)/τ) · Σₖ exp(zₖ/τ) = 1
    │       → exp(-(λ+τ)/τ) = 1 / Σⱼ exp(zⱼ/τ)
    ▼
[pₖ = exp(zₖ/τ) / Σⱼ exp(zⱼ/τ)]
    │
    ▼
[★ 결론: pₖ = softmax(z/τ)ₖ]
```

**온도 τ의 효과** (z = [2, 1, 0] 예시):
```
τ = 1.0  → p = [0.665, 0.245, 0.090]  (보통)
τ = 0.5  → p = [0.844, 0.114, 0.042]  (날카로움)
τ = 2.0  → p = [0.506, 0.307, 0.186]  (평탄)
τ → 0    → p = [1, 0, 0]              (argmax)
τ → ∞    → p = [1/3, 1/3, 1/3]        (uniform)
```

## 7. Softmax Jacobian: ∂pᵢ/∂zⱼ = diag(p) - ppᵀ

> **역전파에서 softmax 그래디언트 계산에 필수**

```
[정의: pᵢ = exp(zᵢ) / Σₖ exp(zₖ),  S = Σₖ exp(zₖ)]
    │
    │ "왜": softmax 함수의 정의
    │       pᵢ = exp(zᵢ) / S로 축약
    ▼
[두 케이스로 분리: i = j  vs  i ≠ j]
    │
    │ "왜": 분자 exp(zᵢ)가 zⱼ에 의존하는가?
    │       i=j면 분자에도 zⱼ가 있음 → 곱의 미분 (quotient rule)
    │       i≠j면 분자는 zⱼ에 무관 → 분모만 미분
    ▼
┌───────────────────────────────┬──────────────────────────────────┐
│ Case 1: i = j                 │ Case 2: i ≠ j                    │
│                               │                                  │
│ ∂pᵢ/∂zᵢ = ?                  │ ∂pᵢ/∂zⱼ = ?                     │
│                               │                                  │
│ pᵢ = exp(zᵢ)/S               │ pᵢ = exp(zᵢ)/S                  │
│                               │                                  │
│ 몫의 미분:                     │ 분자는 zⱼ와 무관:                  │
│ (f/g)' = (f'g - fg')/g²      │ ∂exp(zᵢ)/∂zⱼ = 0               │
│                               │                                  │
│ f = exp(zᵢ), f' = exp(zᵢ)   │ ∂S/∂zⱼ = exp(zⱼ)               │
│ g = S,       g' = exp(zᵢ)    │                                  │
│                               │ = -exp(zᵢ)·exp(zⱼ)/S²          │
│ = [exp(zᵢ)·S - exp(zᵢ)²]/S² │ = -(exp(zᵢ)/S)·(exp(zⱼ)/S)    │
│ = exp(zᵢ)/S - (exp(zᵢ)/S)²  │ = -pᵢ · pⱼ                      │
│ = pᵢ - pᵢ²                   │                                  │
│ = pᵢ(1 - pᵢ)                 │                                  │
└───────────────────────────────┴──────────────────────────────────┘
    │                                       │
    ▼                                       ▼
[∂pᵢ/∂zᵢ = pᵢ(1-pᵢ) = pᵢδᵢⱼ - pᵢpⱼ]   [∂pᵢ/∂zⱼ = -pᵢpⱼ = pᵢδᵢⱼ - pᵢpⱼ]
    │                                       │
    │  (δᵢᵢ=1이므로 pᵢ·1 - pᵢpᵢ)           │  (δᵢⱼ=0이므로 0 - pᵢpⱼ)
    ▼                                       ▼
[두 케이스 통합: ∂pᵢ/∂zⱼ = pᵢδᵢⱼ - pᵢpⱼ]
    │
    │ "왜": 크로네커 델타 δᵢⱼ로 두 케이스를 하나의 식으로
    ▼
[행렬 형태: J = ∂p/∂z = diag(p) - ppᵀ]
    │
    │ "왜": (i,j) 성분이 pᵢδᵢⱼ - pᵢpⱼ
    │       pᵢδᵢⱼ → diag(p) (대각행렬)
    │       pᵢpⱼ → ppᵀ (외적, rank-1 행렬)
    ▼
[★ 결론: ∂p/∂z = diag(p) - ppᵀ]
```

**검증**: $J$의 각 행의 합 = $p_i \cdot 1 - p_i \sum_j p_j = p_i - p_i = 0$ (확률의 합이 1로 보존되므로 자코비안의 행 합 = 0)

## 8. 베이즈 정리 유도: P(A∩B) 대칭성에서 출발

> **"베이즈 정리는 암기가 아니라, 교집합의 대칭성에서 3줄 만에 유도된다"**

```
[출발: 조건부 확률의 정의]
    │
    │ P(A|B) = P(A∩B) / P(B)  ... (정의 1)
    │ P(B|A) = P(A∩B) / P(A)  ... (정의 2)
    │
    │ "왜": 조건부 확률 = "B가 일어난 세계에서 A도 일어날 비율"
    │       = (둘 다 일어난 경우) / (B가 일어난 전체 경우)
    ▼
[핵심 관찰: P(A∩B) = P(B∩A)]
    │
    │ "왜": 교집합은 대칭 연산 — A∩B = B∩A
    │       "A이면서 B" = "B이면서 A"
    ▼
[정의 1에서: P(A∩B) = P(A|B) · P(B)]
[정의 2에서: P(A∩B) = P(B|A) · P(A)]
    │
    │ "왜": 각 정의를 P(A∩B)에 대해 정리
    ▼
[두 식의 좌변이 같으므로 우변도 같다:]
[P(A|B) · P(B) = P(B|A) · P(A)]
    │
    │ "왜": 등호의 이행성
    ▼
[P(B)로 양변 나누기:]
[P(A|B) = P(B|A) · P(A) / P(B)]
    │
    ▼
[★ 베이즈 정리]
```

**용어 매핑 (딥러닝 맥락)**:
```
P(θ|D) = P(D|θ) · P(θ) / P(D)
  │         │        │       │
사후확률  우도함수  사전확률  증거(정규화 상수)
posterior likelihood  prior   evidence
```

**전체 확률 법칙으로 P(B) 분해**:
```
P(B) = Σₐ P(B|A=a) · P(A=a)
    │
    │ "왜": 사건 A의 모든 가능한 값에 대해 주변화(marginalize)
    │       B가 일어나는 모든 경로를 합산
```

## 9. Rank-Nullity 정리: dim(V) = rank(T) + nullity(T)

> **"행렬의 열 수 = 정보가 보존되는 차원 + 정보가 사라지는 차원"**

```
[설정: T: V → W 선형변환, dim(V) = n]
    │
    │ 정의:
    │ - Ker(T) = {v ∈ V : T(v) = 0} (영공간, null space)
    │ - Im(T) = {T(v) : v ∈ V} (상, image/range)
    │ - nullity(T) = dim(Ker(T)) = k
    │ - rank(T) = dim(Im(T))
    ▼
[Step 1: Ker(T)의 기저를 잡는다]
[{v₁, v₂, ..., vₖ}가 Ker(T)의 기저 (k = nullity)]
    │
    │ "왜": 모든 부분공간은 기저를 가짐 (기저 존재 정리)
    ▼
[Step 2: 이 기저를 V 전체의 기저로 확장]
[{v₁, ..., vₖ, u₁, u₂, ..., uₘ}이 V의 기저]
    │
    │ "왜": 기저 확장 정리 — 부분공간의 기저를
    │       전체 공간의 기저로 항상 확장 가능
    │       따라서 k + m = n (V의 차원)
    ▼
[Step 3: {T(u₁), T(u₂), ..., T(uₘ)}이 Im(T)의 기저임을 보인다]
    │
    ├── (a) 생성(span) 증명:
    │   │  임의의 T(v) ∈ Im(T)에 대해
    │   │  v = a₁v₁ + ... + aₖvₖ + b₁u₁ + ... + bₘuₘ  (V의 기저로 표현)
    │   │  T(v) = a₁T(v₁) + ... + aₖT(vₖ) + b₁T(u₁) + ... + bₘT(uₘ)
    │   │       = a₁·0 + ... + aₖ·0 + b₁T(u₁) + ... + bₘT(uₘ)
    │   │  "왜": T는 선형이므로 T(합) = 합(T)
    │   │       v₁,...,vₖ ∈ Ker(T)이므로 T(vᵢ) = 0
    │   │  → T(v) = Σⱼ bⱼ T(uⱼ) → {T(uⱼ)}가 Im(T)를 생성
    │   │
    ├── (b) 일차독립 증명:
    │   │  Σⱼ cⱼ T(uⱼ) = 0이라 가정
    │   │  → T(Σⱼ cⱼ uⱼ) = 0  (선형성)
    │   │  → Σⱼ cⱼ uⱼ ∈ Ker(T)
    │   │  → Σⱼ cⱼ uⱼ = Σᵢ dᵢ vᵢ  (Ker(T)의 원소이므로 기저로 표현)
    │   │  → Σⱼ cⱼ uⱼ - Σᵢ dᵢ vᵢ = 0
    │   │  "왜": {v₁,...,vₖ,u₁,...,uₘ}은 V의 기저이므로 일차독립
    │   │       → 모든 계수 = 0 → 특히 c₁ = ... = cₘ = 0
    │   │  → {T(uⱼ)}는 일차독립
    │
    ▼
[rank(T) = dim(Im(T)) = m]
    │
    │ "왜": 기저의 원소 수 = 차원
    ▼
[n = k + m = nullity(T) + rank(T)]
    │
    │ "왜": Step 2에서 k + m = dim(V) = n
    ▼
[★ Rank-Nullity 정리: dim(V) = rank(T) + nullity(T)]
```

**행렬 해석**: $A \in \mathbb{R}^{m \times n}$일 때, $n = \text{rank}(A) + \dim(\text{Null}(A))$
- rank(A) = 독립인 열의 수 = 정보가 보존되는 방향의 수
- nullity(A) = $Ax = 0$의 해공간 차원 = 정보가 소멸되는 방향의 수

## 10. KL ≥ 0 증명: Jensen 부등식 적용

> **"KL divergence가 항상 0 이상인 이유 = -log가 볼록함수이기 때문"**

```
[정의: KL(p || q) = Σₓ p(x) log(p(x)/q(x)) = E_p[log(p/q)]]
    │
    │ "왜": KL은 분포 p와 q의 "거리" (정확히는 비대칭 divergence)
    │       p=q이면 log(p/q)=log(1)=0 → KL=0
    ▼
[부호 변환: KL(p||q) = -Σₓ p(x) log(q(x)/p(x)) = -E_p[log(q/p)]]
    │
    │ "왜": log(a/b) = -log(b/a)
    │       부호를 바꿔서 Jensen 부등식 적용 준비
    ▼
[Jensen 부등식 확인: f(t) = -log(t)는 볼록(convex)]
    │
    │ "왜": f''(t) = 1/t² > 0 for t > 0
    │       이계도함수가 양수 → 볼록함수
    │
    │ Jensen 부등식: f가 볼록이면
    │   E[f(X)] ≥ f(E[X])
    ▼
[적용: E_p[-log(q/p)] ≥ -log(E_p[q/p])]
    │
    │ "왜": X = q(x)/p(x), f = -log
    │       Jensen: E_p[f(q/p)] ≥ f(E_p[q/p])
    ▼
[E_p[q(x)/p(x)] 계산:]
[= Σₓ p(x) · q(x)/p(x) = Σₓ q(x) = 1]
    │
    │ "왜": p(x)가 약분됨
    │       q는 확률분포이므로 합 = 1
    ▼
[KL(p||q) ≥ -log(1) = 0]
    │
    ▼
[★ KL(p||q) ≥ 0, 등호 ⟺ p = q (a.e.)]
    │
    │ "왜": Jensen 등호조건 = X가 상수 a.s.
    │       q(x)/p(x) = c (상수) for all x where p(x) > 0
    │       Σ q(x) = c · Σ p(x) = c → c = 1 → q = p
```

**수치 예시**: p = [0.7, 0.3], q = [0.5, 0.5]
- $KL = 0.7 \ln(0.7/0.5) + 0.3 \ln(0.3/0.5) = 0.7 \cdot 0.336 + 0.3 \cdot (-0.511) = 0.082 \geq 0$ ✓

## 11. 정규방정식 유도: ∇_w ||Xw - y||² = 0

> **"선형 회귀의 닫힌 해는 미분=0에서 나온다"**

```
[목적: argmin_w L(w) = ||Xw - y||₂²]
    │
    │ "왜": 선형 모델 ŷ = Xw에서 예측과 실제의 오차 제곱합 최소화
    │       X ∈ ℝⁿˣᵈ (데이터), w ∈ ℝᵈ (가중치), y ∈ ℝⁿ (타겟)
    ▼
[L(w) = (Xw - y)ᵀ(Xw - y)  (벡터 노름의 정의)]
    │
    │ "왜": ||v||₂² = vᵀv
    ▼
[전개: L(w) = wᵀXᵀXw - 2wᵀXᵀy + yᵀy]
    │
    │ "왜": (Xw-y)ᵀ(Xw-y) = (Xw)ᵀ(Xw) - (Xw)ᵀy - yᵀ(Xw) + yᵀy
    │       = wᵀXᵀXw - 2yᵀXw + yᵀy
    │       (yᵀXw는 스칼라이므로 전치해도 같음: (Xw)ᵀy = yᵀXw = wᵀXᵀy)
    ▼
[∇_w L = 0 으로 미분]
    │
    │ 행렬 미분 공식 적용:
    │ ∂/∂w (wᵀAw) = 2Aw  (A가 대칭일 때, XᵀX는 항상 대칭)
    │ ∂/∂w (bᵀw) = b
    │ ∂/∂w (상수) = 0
    ▼
[∇_w L = 2XᵀXw - 2Xᵀy = 0]
    │
    │ "왜": 첫째 항: ∂/∂w (wᵀXᵀXw) = 2XᵀXw
    │       둘째 항: ∂/∂w (-2wᵀXᵀy) = -2Xᵀy
    │       셋째 항: ∂/∂w (yᵀy) = 0
    ▼
[2XᵀXw = 2Xᵀy]
    │
    │ "왜": 0으로 옮기고 양변을 2로 나눔
    ▼
[XᵀXw = Xᵀy]
    │
    │ "왜": 이것이 정규방정식 (Normal Equation)
    │       이름 유래: 잔차 (Xw-y)가 X의 열공간에 "수직(normal)"
    ▼
[w* = (XᵀX)⁻¹Xᵀy   (XᵀX가 가역일 때)]
    │
    │ "왜": XᵀX가 가역 ⟺ X의 열들이 일차독립
    │       ⟺ rank(X) = d (full column rank)
    │       비가역이면 pseudo-inverse 또는 정규화 사용
    ▼
[★ 정규방정식: w* = (XᵀX)⁻¹Xᵀy]
```

**기하학적 해석**:
```
  y (실제값)
  │\
  │ \  e = y - Xw* (잔차)
  │  \
  │   \
  └────● Xw* (X의 열공간 위 사영)
  Col(X)

정규방정식의 의미: Xᵀ(Xw* - y) = 0
→ 잔차 벡터가 X의 모든 열과 직교
→ Xw*는 y를 Col(X) 위에 정사영한 것
```

## 12. 스펙트럼 분해: 대칭행렬 → 직교 고유벡터 → A = UΛUᵀ

> **"대칭행렬은 직교하는 축들로 완전히 분해된다"**

```
[출발: A ∈ ℝⁿˣⁿ이 대칭 (A = Aᵀ)]
    │
    ▼
[Step 1: 대칭행렬의 고유값은 모두 실수]
    │
    │ "왜": Av = λv라 하자.  양변에 v̄ᴴ(복소 전치) 곱하면
    │       v̄ᴴAv = λ v̄ᴴv = λ||v||²
    │       왼변은 실수 (A가 대칭, 즉 Hermitian이므로)
    │       ||v||² > 0이므로 λ = (v̄ᴴAv) / ||v||² ∈ ℝ
    ▼
[Step 2: 서로 다른 고유값의 고유벡터는 직교]
    │
    │ "왜": Av₁ = λ₁v₁, Av₂ = λ₂v₂ (λ₁ ≠ λ₂)
    │       v₂ᵀ(Av₁) = λ₁(v₂ᵀv₁)
    │       v₁ᵀ(Av₂) = λ₂(v₁ᵀv₂)
    │       A=Aᵀ이므로 v₂ᵀAv₁ = (Av₂)ᵀv₁ = v₁ᵀAv₂
    │       → λ₁(v₂ᵀv₁) = λ₂(v₁ᵀv₂)
    │       → (λ₁ - λ₂)(v₁ᵀv₂) = 0
    │       → λ₁ ≠ λ₂이므로 v₁ᵀv₂ = 0 (직교!)
    ▼
[Step 3: 같은 고유값의 고유공간 내에서도 직교기저를 잡을 수 있다]
    │
    │ "왜": 고유공간은 부분공간 → Gram-Schmidt 직교화 적용 가능
    │       중복도가 k인 고유값에 대해 k개의 직교 고유벡터 획득
    ▼
[Step 4: n개의 정규직교 고유벡터 {u₁, ..., uₙ} 확보]
    │
    │ "왜": 대칭행렬의 고유벡터들이 ℝⁿ의 정규직교기저를 형성
    │       (실수 스펙트럼 정리)
    ▼
[행렬로 조립: U = [u₁ | u₂ | ... | uₙ], Λ = diag(λ₁, ..., λₙ)]
    │
    │ "왜": AU = UΛ (고유값 방정식을 열별로 쓴 것)
    │       Auᵢ = λᵢuᵢ → A[u₁...uₙ] = [λ₁u₁...λₙuₙ] = [u₁...uₙ]Λ
    ▼
[U는 직교행렬: UᵀU = UUᵀ = I → U⁻¹ = Uᵀ]
    │
    │ "왜": 열벡터들이 정규직교 → 정의에 의해 직교행렬
    ▼
[AU = UΛ → A = UΛUᵀ]
    │
    │ "왜": 양변에 오른쪽에서 U⁻¹ = Uᵀ 곱하기
    ▼
[★ 스펙트럼 분해: A = UΛUᵀ = Σᵢ λᵢ uᵢuᵢᵀ]
    │
    │ "왜": UΛUᵀ를 열별로 전개하면
    │       = Σᵢ λᵢ uᵢuᵢᵀ (rank-1 행렬들의 가중합)
    │       각 uᵢuᵢᵀ는 uᵢ 방향으로의 사영 행렬
```

**해석**: 대칭행렬 A의 작용 = (1) Uᵀ로 고유벡터 좌표로 변환 → (2) Λ로 각 축 스케일링 → (3) U로 원래 좌표로 복원

## 13. SVD → 저랭크 근사: A = UΣVᵀ → Aᵣ

> **"데이터를 가장 잘 요약하는 r차원 근사"**

```
[출발: 임의의 행렬 A ∈ ℝᵐˣⁿ]
    │
    │ "왜": A는 대칭이 아닐 수 있음 → 스펙트럼 분해 불가
    │       SVD는 모든 행렬에 적용 가능한 분해
    ▼
[AᵀA와 AAᵀ 분석]
    │
    │ "왜": AᵀA ∈ ℝⁿˣⁿ, AAᵀ ∈ ℝᵐˣᵐ 모두 대칭, 양반정치
    │       → 스펙트럼 분해 가능 (Chain 12)
    │       → 고유값 ≥ 0
    ▼
[AᵀA = VΛVᵀ (V: 우특이벡터, 고유벡터들)]
[AAᵀ = UΛ'Uᵀ (U: 좌특이벡터)]
    │
    │ "왜": 대칭행렬의 스펙트럼 분해
    │       AᵀA와 AAᵀ의 0이 아닌 고유값은 동일 (증명: Av=σu이면 AᵀAv=σ²v)
    │       σᵢ = √λᵢ (특이값)
    ▼
[Σ = diag(σ₁, σ₂, ..., σᵣ, 0, ..., 0)  (σ₁ ≥ σ₂ ≥ ... ≥ σᵣ > 0)]
    │
    │ "왜": r = rank(A), 특이값은 내림차순 정렬이 관례
    ▼
[★ SVD: A = UΣVᵀ = Σᵢ₌₁ʳ σᵢ uᵢ vᵢᵀ]
    │
    │ "왜": 각 항 σᵢuᵢvᵢᵀ는 rank-1 행렬
    │       σᵢ가 큰 항이 더 중요한 성분
    ▼
[저랭크 근사 문제: min_{rank(B)=k} ||A - B||_F]
    │
    │ "왜": 데이터 압축/차원 축소 — 가장 정보를 보존하는 k차원 근사
    ▼
[Eckart-Young 정리: 최적해는 Aₖ = Σᵢ₌₁ᵏ σᵢ uᵢ vᵢᵀ]
    │
    │ "왜": ||A - B||_F² = Σᵢ σᵢ² - Σᵢ₌₁ᵏ σ̃ᵢ²
    │       에서 σ̃ᵢ를 최대화하려면 가장 큰 σᵢ를 선택
    │       → 상위 k개 특이값만 유지
    │
    │ 근사 오차: ||A - Aₖ||_F² = Σᵢ₌ₖ₊₁ʳ σᵢ²
    │ (버린 특이값들의 제곱합)
    ▼
[★ 저랭크 근사: Aₖ = UₖΣₖVₖᵀ]
```

**수치 예시**:
```
특이값: σ = [10, 5, 1, 0.1]
전체 에너지: 10² + 5² + 1² + 0.1² = 126.01

k=2 근사:
보존 에너지: 10² + 5² = 125 → 125/126.01 = 99.2% 보존!
필요 파라미터: 원본 m×n → 근사 (m+n)×k  (대폭 압축)
```

## 14. CLT 의미와 Gaussian 노이즈 정당화

> **"왜 딥러닝에서 Gaussian 노이즈를 가정하는가?" = "CLT 때문"**

```
[출발: X₁, X₂, ..., Xₙ이 i.i.d, E[Xᵢ] = μ, Var(Xᵢ) = σ² < ∞]
    │
    │ "왜": n개의 독립적인 확률변수
    │       각각 같은 분포, 같은 평균과 분산
    │       (어떤 분포든 상관없음! — 균등, 지수, 이산 등 모두 OK)
    ▼
[표본 평균: X̄ₙ = (1/n) Σᵢ Xᵢ]
    │
    │ E[X̄ₙ] = μ
    │ Var(X̄ₙ) = σ²/n
    │ "왜": 기댓값의 선형성, 독립이면 분산이 합산
    ▼
[표준화: Zₙ = (X̄ₙ - μ) / (σ/√n) = √n(X̄ₙ - μ)/σ]
    │
    │ "왜": 평균 빼고 표준편차로 나눔 → E[Zₙ]=0, Var(Zₙ)=1
    ▼
[★ CLT (중심극한정리):]
[Zₙ →(d) N(0, 1) as n → ∞]
    │
    │ "왜": (특성함수 증명 스케치)
    │       φ_Zₙ(t) = [φ_{(X-μ)/σ}(t/√n)]ⁿ
    │       Taylor 전개: φ_{(X-μ)/σ}(t/√n) ≈ 1 - t²/(2n) + o(1/n)
    │       → [1 - t²/(2n)]ⁿ → e^{-t²/2} (n→∞)
    │       e^{-t²/2}는 N(0,1)의 특성함수!
    ▼
[등가 표현: X̄ₙ ≈ N(μ, σ²/n) for large n]
    │
    │ "왜": Zₙ ~ N(0,1) → X̄ₙ = μ + (σ/√n)Zₙ ~ N(μ, σ²/n)
    ▼
[딥러닝에서의 적용]
    │
    ├── (1) 관측 노이즈 정당화:
    │   │   관측값 y = 참값 + ε, ε = (많은 작은 독립 원인의 합)
    │   │   센서 노이즈, 측정 오차, 양자화 오류, ...
    │   │   → CLT에 의해 ε ≈ N(0, σ²)
    │   │   → y | x ~ N(h(x), σ²)  (Chain 2의 가정이 정당화됨!)
    │   │
    ├── (2) 가중치 초기화:
    │   │   많은 입력의 가중합 z = Σᵢ wᵢxᵢ
    │   │   → CLT에 의해 z ≈ N(0, n·Var(wᵢxᵢ))
    │   │   → Xavier/He 초기화의 이론적 근거
    │   │
    └── (3) 배치 통계:
        │   미니배치의 평균/분산 → CLT에 의해 정규 근사
        │   → Batch Normalization의 이론적 근거
    ▼
[★ 결론: 독립적 원인들의 합 → Gaussian → MSE 손실 정당화]
```

**핵심 흐름 요약**:
```
많은 독립적 원인의 합 --("왜": CLT)--> Gaussian 분포
                                          │
                           --("왜": Chain 2)--> MSE 손실
```

## 15. NLL = KL divergence: 경험적 분포와 모델 분포의 KL

> **"NLL 최소화 = 모델을 데이터에 가깝게 만드는 것 = KL 최소화"**

```
[경험적 분포 정의: p̂(x) = (1/n) Σᵢ δ(x - xᵢ)]
    │
    │ "왜": 데이터 D = {x₁, ..., xₙ}을 분포로 표현
    │       각 관측점에 1/n의 확률 질량을 부여
    │       δ는 디랙 델타 (이산이면 지시함수)
    ▼
[KL(p̂ || q_θ) 전개]
    │
    ▼
[KL(p̂ || q_θ) = Σₓ p̂(x) log(p̂(x)/q_θ(x))]
    │
    │ "왜": KL divergence의 정의
    ▼
[= Σₓ p̂(x) log p̂(x) - Σₓ p̂(x) log q_θ(x)]
    │
    │ "왜": log(a/b) = log a - log b
    │       첫째 항 = -H(p̂) = 경험적 분포의 (음의) 엔트로피
    │       둘째 항 = -E_{p̂}[log q_θ]
    ▼
[= -H(p̂) - E_{p̂}[log q_θ(x)]]
    │
    │ "왜": 첫째 항 -H(p̂)는 θ와 무관한 상수!
    │       (데이터가 고정이면 경험적 분포는 고정)
    ▼
[argmin_θ KL(p̂ || q_θ) = argmin_θ { -E_{p̂}[log q_θ(x)] }]
    │
    │ "왜": 상수 항은 argmin에 영향 없음
    ▼
[E_{p̂}[log q_θ(x)] = (1/n) Σᵢ log q_θ(xᵢ)]
    │
    │ "왜": 경험적 분포에 대한 기댓값
    │       = 데이터 포인트에서의 평균
    ▼
[argmin_θ { -(1/n) Σᵢ log q_θ(xᵢ) }]
    │
    │ "왜": 음의 부호 → argmin(-f) = argmax(f)
    │       1/n은 스케일 상수 → argmin에 영향 없음
    ▼
[= argmax_θ Σᵢ log q_θ(xᵢ)]
    │
    │ "왜": 이것은 정확히 MLE!
    ▼
[★ 결론: argmin_θ KL(p̂ || q_θ) = argmax_θ ℓ(θ) = argmin_θ NLL]
```

**등가 관계 정리**:
```
KL(p̂ || q_θ) = H(p̂, q_θ) - H(p̂)
                    │           │
              Cross-Entropy   상수(θ무관)

따라서:
min_θ KL(p̂||q_θ) ⟺ min_θ H(p̂, q_θ) ⟺ min_θ NLL ⟺ max_θ ℓ(θ)

네 가지가 전부 같은 것!
```

**Cross-Entropy 분해**:
```
H(p̂, q_θ) = H(p̂) + KL(p̂ || q_θ)
              ≥ H(p̂)   ("왜": KL ≥ 0, Chain 10)
              등호 ⟺ q_θ = p̂  (모델이 데이터를 완벽 복원)
```
