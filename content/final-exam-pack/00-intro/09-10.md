# 딥러닝 이론 개념 연결 지도 — 모든 개념이 어떻게 연결되는가

> SNU 수학과 대학원 딥러닝 이론 과목 기말 정리
>
> **핵심 통찰**: 이 과목의 모든 개념은 서로 연결되어 있다. 하나를 깊이 이해하면 나머지가 따라온다.

### 1.2 핵심 연결 축 3개

```
축 1: 분포 → 손실함수 축
─────────────────────────
Gaussian ──→ MSE ──→ NLL ──→ KL Divergence
    │                            │
    └── CLT가 정당성 부여        └── Entropy와 CE로 분해

축 2: 베이즈 → 정규화 축
─────────────────────────
Bayes Rule ──→ MAP ──→ Regularization ──→ 일반화
    │              │          │
  Prior       log Prior    L1/L2 penalty
  = 사전지식   = 페널티항    = Inductive Bias

축 3: 선형대수 → 신경망 축
─────────────────────────
행렬=변환 ──→ 층=변환합성 ──→ 체인룰=역전파
    │              │              │
  고유분해      Jacobian       Hessian
  = 스펙트럼     = 국소변환      = 곡률
```

### 1.3 "하나의 수식이 모든 것을 지배한다"

**MAP 추정의 목적함수가 딥러닝의 거의 모든 것을 포함한다:**

```
θ* = argmax_θ  log p(D|θ)  +  log p(θ)
     ─────────  ──────────     ─────────
     최적화      Likelihood     Prior
                    │              │
              분포가정에 따라    Prior에 따라
              Loss가 결정됨     정규화가 결정됨
                    │              │
              ┌─────┴─────┐    ┌──┴──┐
              │           │    │     │
           Gaussian    Categorical   Gaussian  Laplace
              │           │    │     │
            MSE         CE    L2    L1

전체 학습 = argmin_θ  L(θ; D)  +  λR(θ)
                      ───────     ──────
                      = -log p(D|θ)    = -log p(θ)
```

## Part 2: 개념별 연결 상세

### 개념 1: 행렬 = 선형변환

**선수 개념**: 벡터공간, 기저(basis), 선형성(superposition principle)

**파생 개념**:
- 고유값 분해 → 행렬이 어떤 방향으로 얼마나 늘리는가
- SVD → 임의의 행렬을 회전-스케일-회전으로 분해
- 신경망의 각 층 = 선형변환 + 비선형 활성화

**예상치 못한 연결**:
- Softmax의 분자 exp(wᵀx)에서 wᵀx 자체가 선형변환의 한 행
- Attention에서 QKᵀ는 두 선형변환의 합성 → 유사도 행렬이 됨
- Convolution도 Toeplitz 행렬과의 행렬곱으로 표현 가능

**시험 연결 질문 예시**:
> "신경망의 한 층 f(x) = σ(Wx + b)에서 W를 고유분해했을 때, 고유값의 크기가 학습 dynamics에 어떤 영향을 미치는가?"

---

### 개념 2: 고유값/고유벡터

**선수 개념**: 행렬 = 선형변환, 행렬식(determinant), 특성다항식

**파생 개념**:
- PCA = 공분산 행렬의 고유벡터 방향으로 투영
- Hessian의 고유값 = Loss landscape의 곡률
- 양정치행렬(PD) 판정 = 모든 고유값 > 0 = 볼록함수

**예상치 못한 연결**:
- 학습률 선택: η < 2/λ_max(H)이어야 수렴 (Hessian의 최대 고유값)
- Batch Normalization의 효과를 Hessian 고유값 스펙트럼 균일화로 설명 가능
- Graph Neural Network의 spectral method = 그래프 라플라시안의 고유분해

**시험 연결 질문 예시**:
> "Hessian의 고유값이 [0.01, 0.01, ..., 100]과 같이 분포할 때, 경사하강법의 수렴 속도가 왜 느려지는지 조건수(condition number)와 연결하여 설명하라."

---

### 개념 3: SVD (특이값 분해)

**선수 개념**: 고유값/고유벡터, 직교행렬, rank

**파생 개념**:
- 저랭크 근사 (Eckart-Young 정리) → 모델 압축
- Pseudoinverse (Moore-Penrose) → 최소제곱 해
- PCA와의 관계: X = UΣVᵀ이면 공분산 XXᵀ의 고유분해 = UΣ²Uᵀ

**예상치 못한 연결**:
- LoRA(Low-Rank Adaptation)의 이론적 정당성 = SVD 저랭크 근사
- Attention 행렬의 effective rank → 모델의 표현력 분석
- Weight matrix의 singular value 분포 → 학습 상태 진단

**시험 연결 질문 예시**:
> "A = UΣVᵀ일 때, rank-k 근사 A_k가 ||A - A_k||_F를 최소화함을 증명하고, 이것이 신경망 가중치 압축에 어떻게 적용되는지 설명하라."

---

### 개념 4: Rank-Nullity 정리

**선수 개념**: 선형변환, 핵(kernel/null space), 상(image/range)

**파생 개념**:
- rank(A) + nullity(A) = n → 정보가 사라지는 차원과 보존되는 차원
- 과결정/미결정 시스템의 해 존재성/유일성
- 신경망 표현력: 층의 rank가 떨어지면 정보 손실

**예상치 못한 연결**:
- ReLU 활성화 → 음수 뉴런을 0으로 → rank가 줄어듦 → 정보 병목
- Dying ReLU 문제 = null space가 커지는 현상
- Skip connection이 rank 보존에 기여 → ResNet의 성공 이유 중 하나

**시험 연결 질문 예시**:
> "깊은 신경망에서 각 층의 rank가 단조감소할 수 있음을 보이고, skip connection이 이 문제를 어떻게 완화하는지 rank-nullity 관점에서 논하라."

---

### 개념 5: 내적 = 유사도

**선수 개념**: 벡터공간, 노름(norm), 코시-슈바르츠 부등식

**파생 개념**:
- 코사인 유사도 = 정규화된 내적
- 커널 함수 = 고차원 공간에서의 내적
- Attention score = Query와 Key의 내적

**예상치 못한 연결**:
- Softmax(QKᵀ/√d)에서 내적이 유사도 역할 → 유사한 토큰에 집중
- MSE Loss = ||y - f(x)||² = 내적 (y-f, y-f) → 유클리드 거리의 제곱
- Fisher Information Matrix = score function의 내적의 기대값

**시험 연결 질문 예시**:
> "내적 공간에서 정의되는 유사도가 Attention 메커니즘의 QKᵀ와 어떻게 연결되는지 설명하고, √d로 나누는 이유를 분산 관점에서 유도하라."

---

### 개념 6: 그래디언트

**선수 개념**: 편미분, 방향도함수, 다변수 함수

**파생 개념**:
- 경사하강법: θ ← θ - η∇L(θ)
- 야코비안 = 벡터함수의 그래디언트 모음
- 자연 그래디언트 = Fisher Information으로 보정한 그래디언트

**예상치 못한 연결**:
- ∇f(x)는 f의 등고선(level set)에 수직 → 가장 가파른 상승 방향
- 그래디언트의 노름 ||∇L|| → 학습 진행 상태의 지표 (vanishing/exploding)
- Score function ∇_x log p(x) = 확률 분포의 그래디언트 → Diffusion 모델의 핵심

**시험 연결 질문 예시**:
> "∇_θ L(θ) = 0이 최솟값의 필요조건임을 보이고, 충분조건을 위해 Hessian이 왜 필요한지 설명하라."

---

### 개념 7: 야코비안 (Jacobian)

**선수 개념**: 그래디언트, 다변수 함수, 행렬 미분

**파생 개념**:
- 체인룰의 행렬 형태: ∂L/∂x = (∂f/∂x)ᵀ ∂L/∂f
- 역전파 = 야코비안의 전치와의 곱의 체인
- 야코비안의 행렬식 = 변환에 의한 부피 변화율 (변수변환)

**예상치 못한 연결**:
- Normalizing Flow: p(z)|det(∂f/∂z)| = p(x) → 야코비안 행렬식으로 확률 변환
- Lipschitz 상수 ≈ ||J||_op → 모델의 안정성/강건성 지표
- GAN의 학습 안정성 분석에 생성자의 야코비안 스펙트럼 사용

**시험 연결 질문 예시**:
> "f: R^n → R^m의 야코비안 J_f를 정의하고, 합성함수 g∘f의 야코비안이 J_g · J_f임을 보여라. 이것이 역전파와 어떻게 연결되는가?"

---

### 개념 8: 헤시안 (Hessian)

**선수 개념**: 그래디언트, 이차형식(quadratic form), 고유값

**파생 개념**:
- Loss landscape의 곡률(curvature) 분석
- Newton's method: θ ← θ - H⁻¹∇L (이차 수렴)
- 볼록성 판정: H ≽ 0 ⟺ f가 볼록

**예상치 못한 연결**:
- 학습률 스케줄링의 이론적 근거 = Hessian의 스펙트럼 변화 추적
- Adam optimizer ≈ 대각 Hessian 근사 (이차형식의 대각 성분)
- Sharp minima vs Flat minima 논쟁 = Hessian 고유값의 크기
- Fisher Information Matrix ≈ Hessian의 기대값 (NLL에서)

**시험 연결 질문 예시**:
> "f(x) = xᵀAx + bᵀx + c의 Hessian을 구하고, A가 양정치일 때 유일한 최솟값이 존재함을 증명하라. 이것이 L2 정규화된 선형회귀와 어떻게 연결되는가?"

---

### 개념 9: 체인룰 (Chain Rule)

**선수 개념**: 합성함수, 그래디언트, 야코비안

**파생 개념**:
- 역전파 알고리즘 (Backpropagation)
- 자동 미분 (Automatic Differentiation)
- Vanishing/Exploding gradient 문제의 원인

**예상치 못한 연결**:
- 체인룰 반복 적용 = 야코비안의 행렬곱 체인
  ∂L/∂W₁ = (∂h₂/∂h₁)ᵀ (∂h₃/∂h₂)ᵀ ... (∂L/∂hₙ)
  → 행렬곱이 깊어질수록 고유값이 지수적으로 증폭/감쇠
- sigmoid의 미분 최대값 = 0.25 → 4층만 거치면 0.25⁴ ≈ 0.004 → vanishing
- ResNet의 skip connection: ∂h_{l+1}/∂h_l = I + ∂f/∂h_l → 항등행렬이 보장

**시험 연결 질문 예시**:
> "L층 신경망에서 ∂L/∂W₁을 체인룰로 전개하고, vanishing gradient가 발생하는 조건을 야코비안의 고유값으로 서술하라."

---

### 개념 10: Softmax

**선수 개념**: 지수함수, 라그랑주 승수법, 볼록 최적화

**파생 개념**:
- Cross-Entropy Loss와의 결합
- Temperature scaling (τ → 0이면 argmax, τ → ∞이면 uniform)
- Gumbel-Softmax (미분 가능한 이산 샘플링)

**예상치 못한 연결**:
- **라그랑주에서 유도**: "엔트로피를 최대화하되 기대값 제약을 만족하는 분포" → Softmax가 유일한 해
  ```
  max H(p) = -Σ p_k log p_k
  s.t. Σ p_k = 1,  Σ p_k · f_k = E[f]  (에너지 제약)

  라그랑주: L = -Σ p_k log p_k - λ(Σp_k - 1) - β Σ p_k f_k
  ∂L/∂p_k = 0  →  p_k = exp(-β f_k) / Σ exp(-β f_j)  ← Softmax!
  ```
- Boltzmann 분포와 동일한 형태 → 통계역학과의 연결
- log-sum-exp = Softmax의 로그 = max의 smooth 근사

**시험 연결 질문 예시**:
> "최대 엔트로피 원리와 라그랑주 승수법을 사용하여 Softmax 함수를 유도하라."

---

### 개념 11: 볼록함수 (Convex Function)

**선수 개념**: 헤시안, 이차형식, 에피그래프

**파생 개념**:
- 전역 최솟값의 유일성 보장
- Jensen 부등식
- 볼록 최적화 = 다항시간 풀 수 있는 최적화

**예상치 못한 연결**:
- NLL이 볼록 ⟺ 지수족(exponential family) 분포
- Cross-Entropy는 p에 대해 볼록 → Softmax + CE의 그래디언트가 깔끔
- 신경망의 Loss는 비볼록 → 그래서 local minima, saddle point 문제 발생
- 하지만 overparameterized 신경망에서는 "거의 볼록"에 가까운 landscape

**시험 연결 질문 예시**:
> "f가 볼록이고 미분가능할 때, ∇f(x*) = 0이면 x*가 전역 최솟값임을 증명하라. 신경망의 Loss가 일반적으로 볼록이 아닌 이유는?"

---

### 개념 12: Jensen 부등식

**선수 개념**: 볼록함수, 기대값

**파생 개념**:
- KL Divergence ≥ 0의 증명 (log의 오목성 이용)
- ELBO (Evidence Lower Bound) 유도 → VAE의 핵심
- EM 알고리즘의 수렴 증명

**예상치 못한 연결**:
- E[f(X)] ≥ f(E[X]) (f가 볼록일 때)
- log가 오목이므로: E[log X] ≤ log E[X]
  → KL(p||q) = E_p[log(p/q)] ≥ 0 증명에 직접 사용
- VAE의 ELBO: log p(x) ≥ E_q[log p(x|z)] - KL(q(z|x)||p(z))
  → Jensen 부등식으로 하한을 만들어 최적화 가능하게 만듦

**시험 연결 질문 예시**:
> "Jensen 부등식을 이용하여 KL(p||q) ≥ 0을 증명하라."

### 개념 13: 라그랑주 승수법

### 개념 17: 가우시안 분포

**선수 개념**: 연속확률분포, 지수함수, 이차형식

**파생 개념**:
- MSE Loss의 확률적 정당성
- 가우시안 혼합 모델 (GMM) → EM 알고리즘
- 다변수 가우시안 → Mahalanobis 거리

**예상치 못한 연결**:
- p(y|x) = N(f_θ(x), σ²)로 가정하면:
  ```
  NLL = -log p(y|x) = 1/(2σ²) ||y - f_θ(x)||² + const
  ```
  → MSE Loss는 가우시안 가정의 직접적 결과!
  → σ²는 학습률의 스케일에 흡수됨
- 가우시안 Prior p(θ) = N(0, τ²I)의 NLL = ||θ||²/(2τ²)
  → L2 정규화 = 가우시안 Prior의 MAP 추정
- VAE의 latent space: z ~ N(0, I) → Reparameterization trick

**시험 연결 질문 예시**:
> "y|x ~ N(f_θ(x), σ²I) 가정 하에서 MLE가 MSE 최소화와 동치임을 유도하라."

### 개념 19: 베이즈 정리

**선수 개념**: 조건부확률, 결합확률, 주변화(marginalization)

**파생 개념**:
- MAP 추정
- Posterior 분포
- Bayesian Neural Network

**예상치 못한 연결**:
- ```
  p(θ|D) = p(D|θ)p(θ) / p(D)
  ────────  ────── ────   ────
  Posterior  Like- Prior  Evidence
             lihood        (정규화 상수)
  ```
- log를 취하면: log p(θ|D) = log p(D|θ) + log p(θ) - log p(D)
  → 최적화에서 log p(D)는 θ에 무관 → 버림
  → MAP = MLE + Prior = Loss + Regularization
- **모든 정규화는 사전분포다**: 이 통찰이 가장 중요
- Evidence p(D) = ∫p(D|θ)p(θ)dθ → 모델 선택(model selection)에 사용

**시험 연결 질문 예시**:
> "베이즈 정리를 이용하여 MAP 추정이 정규화된 MLE와 동치임을 보이고, 가우시안 Prior가 L2 정규화에 대응함을 유도하라."

### 개념 20: MLE (최대우도추정)

**선수 개념**: Likelihood, i.i.d., 최적화

**파생 개념**:
- NLL 최소화 = MLE
- 각 분포별 MLE → 손실함수 유도
- 일치성(consistency), 점근적 정규성(asymptotic normality)

**예상치 못한 연결**:
- MLE = KL Divergence 최소화와 동치:
  ```
  argmin_θ KL(p_data || p_θ)
  = argmin_θ E_data[log p_data - log p_θ]
  = argmin_θ -E_data[log p_θ]        (p_data는 θ에 무관)
  = argmin_θ NLL(θ)
  = MLE
  ```
  → MLE는 모델 분포를 데이터 분포에 가깝게 만드는 것!
- MLE는 Prior가 없는 MAP (= 균등 Prior)
- Fisher Information = MLE 추정량의 분산의 역수 (Cramer-Rao)

**시험 연결 질문 예시**:
> "MLE가 KL(p_data || p_θ) 최소화와 동치임을 증명하라."

---

### 개념 21: MAP (최대사후확률추정)

**선수 개념**: 베이즈 정리, MLE, Prior

**파생 개념**:
- 정규화된 손실함수 (regularized loss)
- L1/L2 정규화의 확률적 해석
- 경험적 베이즈 (Empirical Bayes)

**예상치 못한 연결**:
- MAP = argmax_θ p(θ|D) = argmin_θ [-log p(D|θ) - log p(θ)]
  ```
  Prior             | -log p(θ)        | 정규화
  ──────────────────┼──────────────────┼────────────────
  N(0, τ²I)        | ||θ||²/(2τ²)     | L2 (Ridge)
  Laplace(0, b)    | ||θ||₁/b          | L1 (Lasso)
  Uniform          | 0 (상수)          | 없음 (= MLE)
  Spike-and-Slab   | 혼합              | L0 근사 (Dropout)
  ```
- λ = 1/(2τ²) → 정규화 강도 λ는 Prior 분산의 역수!
  → λ가 크다 = Prior를 강하게 믿는다 = 가중치를 작게 유지
- Dropout ≈ 베이즈 근사 (Gal & Ghahramani, 2016)

**시험 연결 질문 예시**:
> "p(θ) = N(0, τ²I)일 때 MAP 추정이 L2 정규화와 동치임을 유도하고, τ와 λ의 관계를 구하라."

### 개념 22: Prior/Posterior

**선수 개념**: 베이즈 정리, 확률분포

**파생 개념**:
- 순차적 업데이트: 오늘의 Posterior = 내일의 Prior
- Conjugate Prior → 계산 편의
- Posterior의 불확실성 → 예측의 신뢰도

**예상치 못한 연결**:
- Prior = Inductive Bias의 확률적 표현
  → "가중치가 작을 것이다" = Gaussian Prior = L2
  → "가중치가 sparse할 것이다" = Laplace Prior = L1
  → "특정 구조를 가질 것이다" = 아키텍처 선택 = 강한 Prior
- CNN의 weight sharing = "공간 불변성" Prior
- Transfer Learning: 사전학습 가중치 = 데이터로부터 학습된 Prior

**시험 연결 질문 예시**:
> "Prior 선택이 학습 결과에 미치는 영향을 L1/L2 정규화의 관점에서 비교하고, 각각의 해의 특성을 설명하라."

### 개념 24: NLL (Negative Log-Likelihood)

**선수 개념**: Likelihood, 로그함수의 단조성, i.i.d.

**파생 개념**:
- 모든 표준 손실함수의 통합 프레임워크
- Cross-Entropy와의 관계
- 정보이론적 해석

**예상치 못한 연결**:
- NLL = -Σ log p(yᵢ|xᵢ; θ)
- **분포별 NLL이 곧 우리가 아는 손실함수**:
  ```
  분포           | NLL (상수 무시)
  ───────────────┼──────────────────
  Gaussian       | Σ ||yᵢ - f(xᵢ)||²     = MSE
  Bernoulli      | -Σ [yᵢ log pᵢ + ...]  = BCE
  Categorical    | -Σ Σ_k yᵢₖ log pᵢₖ    = CE
  Poisson        | Σ [f(xᵢ) - yᵢ log f]  = Poisson Loss
  ```
- NLL과 Cross-Entropy의 관계:
  NLL = H(p_data, p_model) = H(p_data) + KL(p_data || p_model)
  → NLL 최소화 = KL 최소화 (H(p_data)는 상수)

**시험 연결 질문 예시**:
> "Gaussian 분포의 NLL이 MSE와 동치임을 보이고, Bernoulli 분포의 NLL이 Binary Cross-Entropy와 동치임을 보여라."

### 개념 25: Cross-Entropy

**선수 개념**: Entropy, KL Divergence, NLL

**파생 개념**:
- 분류 문제의 표준 손실함수
- Cross-Entropy + Softmax의 그래디언트가 깔끔한 이유
- Label Smoothing의 정보이론적 해석

**예상치 못한 연결**:
- H(p, q) = -Σ p(x) log q(x) = H(p) + KL(p||q)
  → CE 최소화 = KL 최소화 (p가 고정일 때)
- **원-핫 라벨에서**: H(y, p) = -log p_k (정답 클래스 k만 살아남음)
  → CE가 사실상 NLL과 동일해짐
- Softmax + CE의 그래디언트 = p - y (매우 깔끔!)
  ```
  ∂L/∂z_k = p_k - y_k
  ```
  → Sigmoid + BCE도 동일: ∂L/∂z = σ(z) - y
  → 이 깔끔함은 지수족의 일반적 성질에서 비롯됨

**시험 연결 질문 예시**:
> "Softmax + Cross-Entropy의 역전파 그래디언트가 p_k - y_k임을 유도하라."

---

### 개념 26: MSE (Mean Squared Error)

**선수 개념**: 가우시안 분포, NLL, 내적

**파생 개념**:
- 편향-분산 분해 (Bias-Variance Decomposition)
- 회귀 문제의 표준 손실
- L2 Loss와의 관계

**예상치 못한 연결**:
- MSE = E[(y - f(x))²] = Bias² + Variance + Noise
  → 모델 복잡도를 높이면 Bias↓, Variance↑ → 정규화의 필요성
- MSE는 가우시안 NLL (개념 17, 24)
- MSE의 최적해 f*(x) = E[y|x] = 조건부 기대값
  → CE의 최적해 f*(x) = p(y|x) = 조건부 확률
  → 둘 다 조건부 뭔가의 추정!
- Diffusion 모델의 noise prediction loss도 MSE 형태

**시험 연결 질문 예시**:
> "E[(Y - f(X))²]를 Bias²(f) + Var(f) + σ²으로 분해하라. 이 분해가 정규화의 필요성을 어떻게 정당화하는가?"

### 개념 27: KL Divergence

**선수 개념**: Entropy, Cross-Entropy, Jensen 부등식

**파생 개념**:
- MLE = KL 최소화 (개념 20)
- ELBO와 VAE
- Information Bottleneck

**예상치 못한 연결**:
- KL(p||q) = H(p,q) - H(p) = E_p[log(p/q)] ≥ 0 (Jensen으로 증명)
- KL은 비대칭! KL(p||q) ≠ KL(q||p)
  ```
  KL(p||q): q가 0인 곳에서 p>0이면 → ∞  (mode-covering)
  KL(q||p): p가 0인 곳에서 q>0이면 → ∞  (mode-seeking)

  → 왜 중요한가?
  MLE/VAE encoder: KL(p_data||p_model) → mode-covering → 분산 과대
  GAN:             KL(p_model||p_data) → mode-seeking → mode collapse
  ```
- Forward KL vs Reverse KL의 차이가 VAE vs GAN의 생성 품질 차이를 설명
- Mutual Information I(X;Y) = KL(p(x,y) || p(x)p(y))

**시험 연결 질문 예시**:
> "KL(p||q) ≥ 0을 Jensen 부등식으로 증명하고, 등호 조건을 구하라. KL의 비대칭성이 생성 모델(VAE vs GAN)에 미치는 영향을 논하라."

---

### 개념 28: Entropy

**선수 개념**: 확률분포, 로그함수, 기대값

**파생 개념**:
- Cross-Entropy = Entropy + KL
- 최대 엔트로피 원리 → Softmax 유도
- 정보 이득 (Information Gain)

**예상치 못한 연결**:
- H(p) = -Σ p(x) log p(x) = "불확실성의 측도"
- H(p) ≤ log K (K개 클래스) → 등호: 균등분포 (가장 불확실)
- H(p) = 0 → 확정적 분포 (불확실성 없음)
- 최대 엔트로피 + 제약 = 가장 "겸손한" 분포 선택
  → 평균 제약만 → Exponential
  → 평균+분산 제약 → Gaussian!
  → 합 = 1 제약만 → Uniform
- Label Smoothing: p_smooth = (1-ε)·one_hot + ε/K → 엔트로피를 인위적으로 높임 → 과신(overconfidence) 방지

**시험 연결 질문 예시**:
> "평균과 분산이 주어졌을 때 엔트로피를 최대화하는 연속 분포가 가우시안임을 라그랑주 승수법으로 유도하라."

### 개념 29: Regularization (L1/L2)

**선수 개념**: MAP, Prior, 과적합(overfitting)

**파생 개념**:
- L2 = Ridge = 가우시안 Prior = 가중치 감쇄(weight decay)
- L1 = Lasso = 라플라스 Prior = 희소성(sparsity)
- Elastic Net = L1 + L2

**예상치 못한 연결**:
- L2의 기하학적 해석:
  ```
  원래 해: θ* = argmin L(θ)
  L2 정규화: θ*_reg = argmin L(θ) + λ||θ||²

  → 등고선(L) ∩ 원(||θ||² ≤ C) 의 접점
  → 해가 원점 방향으로 수축 (shrinkage)
  ```
- L1의 기하학적 해석:
  ```
  → 등고선(L) ∩ 마름모(||θ||₁ ≤ C) 의 접점
  → 꼭짓점에서 만날 확률 높음 → 일부 θ_j = 0 → 자동 특성 선택
  ```
- Dropout ≈ L2 정규화의 적응적 버전 (Wager et al., 2013)
- Batch Normalization도 정규화 효과 → internal covariate shift 감소
- Early Stopping ≈ L2 정규화 (둘 다 해를 초기값 근처로 제한)

**시험 연결 질문 예시**:
> "L1과 L2 정규화의 해의 기하학적 특성을 비교하고, L1이 희소해를 유도하는 이유를 그림으로 설명하라."

### 개념 30: Inductive Bias

**선수 개념**: Prior, 정규화, 모델 선택

**파생 개념**:
- 아키텍처 선택 = 강한 Inductive Bias
- No Free Lunch 정리
- 편향-분산 트레이드오프

**예상치 못한 연결**:
- **모든 설계 결정이 Inductive Bias**:
  ```
  설계 결정               Inductive Bias
  ──────────────────────  ────────────────────────────
  CNN                     "유용한 패턴은 공간적으로 국소적이고 위치 불변"
  RNN                     "유용한 패턴은 순차적이고 시간 불변"
  Transformer             "모든 위치 간 관계가 잠재적으로 중요"
  GNN                     "유용한 패턴은 그래프 구조를 따른다"
  L2 정규화               "가중치는 작을 것이다"
  Dropout                 "부분 네트워크만으로도 작동해야 한다"
  Data Augmentation       "변환에 불변해야 한다"
  Skip Connection         "얕은 표현도 유용하다"
  ```
- 확률적 관점에서: Inductive Bias = Prior
  → 적절한 Prior는 데이터 효율성을 높인다
  → 잘못된 Prior는 성능을 해친다
- No Free Lunch: "모든 문제에 최적인 Inductive Bias는 없다"
  → 문제에 맞는 Prior/Architecture를 선택하는 것이 핵심

**시험 연결 질문 예시**:
> "CNN의 weight sharing과 local connectivity가 어떤 Inductive Bias를 인코딩하는지 설명하고, 이것을 Prior의 관점에서 해석하라."

## Part 3: "이것을 알면 저것도 안다" 체인

### 체인 1: Gaussian → MSE → NLL → KL (분포-손실 체인)

```
Gaussian 분포를 안다
  │
  │ p(y|x) = N(f(x), σ²) 가정
  ▼
NLL을 계산하면
  │
  │ -log p(y|x) = (y-f)²/(2σ²) + const
  ▼
MSE Loss가 나온다
  │
  │ NLL = H(p_data, p_model)
  ▼
Cross-Entropy = Entropy + KL 이므로
  │
  │ NLL 최소화 = KL(p_data || p_model) 최소화
  ▼
KL Divergence를 이해한다
  │
  │ KL ≥ 0 (Jensen)
  ▼
Jensen 부등식까지 연결!
```

**인과관계 요약**: Gaussian 가정 → NLL 전개 → MSE 발견 → CE로 재해석 → KL로 일반화 → Jensen으로 증명

---

### 체인 2: Bayes → MAP → Regularization → L2 (베이즈-정규화 체인)

```
베이즈 정리를 안다
  │
  │ p(θ|D) ∝ p(D|θ)·p(θ)
  ▼
MAP 추정을 안다
  │
  │ argmax log p(D|θ) + log p(θ)
  ▼
Prior = 정규화항임을 안다
  │
  │ p(θ) = N(0, τ²I) 선택
  ▼
L2 Regularization이 나온다
  │
  │ -log p(θ) = ||θ||²/(2τ²)
  ▼
Weight Decay와 같다
  │
  │ θ ← (1-ηλ)θ - η∇L
  ▼
Early Stopping과도 연결된다
  │
  │ 둘 다 해를 초기값 근처로 제한
  ▼
일반화(Generalization)를 이해한다
```

**인과관계 요약**: Bayes → MAP 유도 → log Prior = 페널티 → 가우시안 Prior = L2 → Weight Decay = Early Stopping의 유사 효과

---

### 체인 3: 라그랑주 → Softmax → CE Loss (제약최적화-분류 체인)

```
라그랑주 승수법을 안다
  │
  │ max H(p) s.t. Σp_k = 1, 에너지 제약
  ▼
최대 엔트로피 원리를 적용한다
  │
  │ ∂L/∂p_k = 0 풀기
  ▼
Softmax가 유도된다
  │
  │ p_k = exp(z_k) / Σexp(z_j)
  ▼
CE Loss와 결합한다
  │
  │ L = -Σ y_k log p_k
  ▼
그래디언트가 p - y 로 깔끔하다
  │
  │ 지수족의 일반적 성질
  ▼
지수족 분포를 이해한다
```

**인과관계 요약**: 라그랑주 → 최대 엔트로피 → Softmax 유도 → CE 결합 → 깔끔한 그래디언트 → 지수족 일반론

---

### 체인 4: 체인룰 → 역전파 → Vanishing Gradient → ResNet (미분-아키텍처 체인)

```
체인룰을 안다
  │
  │ ∂L/∂W₁ = ∏ᵢ (∂hᵢ₊₁/∂hᵢ)ᵀ · ∂L/∂hₙ
  ▼
역전파가 야코비안 곱의 체인임을 안다
  │
  │ 야코비안의 고유값 < 1 → 기하급수적 감소
  ▼
Vanishing Gradient 문제를 이해한다
  │
  │ sigmoid의 max 미분 = 0.25
  ▼
해결책들을 이해한다
  │
  ├── ReLU: 미분 = 1 (양수 영역에서)
  ├── LSTM: Cell state의 덧셈 경로
  └── ResNet: h_{l+1} = h_l + f(h_l)
  │
  │ ∂h_{l+1}/∂h_l = I + ∂f/∂h_l
  ▼
Skip Connection이 항등행렬을 보장함을 안다
  → 그래디언트가 최소 I만큼은 흐른다
```

**인과관계 요약**: 체인룰 → 야코비안 곱 체인 → 고유값 감쇠 = Vanishing → ReLU/ResNet으로 해결

---

### 체인 5: 내적 → 유사도 → Attention → Transformer (유사도-아키텍처 체인)

```
내적 = 유사도를 안다
  │
  │ <q, k> = ||q|| ||k|| cos θ
  ▼
Scaled Dot-Product Attention을 안다
  │
  │ Attention(Q,K,V) = Softmax(QKᵀ/√d)V
  ▼
√d 스케일링의 이유를 안다
  │
  │ q,k ~ N(0,1)이면 qᵀk의 분산 = d
  │ Softmax 입력의 분산이 크면 → 출력이 one-hot에 가까워짐
  │ → 그래디언트 vanishing → √d로 나눠서 분산을 1로 유지
  ▼
Multi-Head Attention을 안다
  │
  │ 여러 유사도 공간에서 동시에 관계 파악
  ▼
Transformer 전체 구조를 이해한다
```

---

### 체인 6: 고유분해 → Hessian → 곡률 → 최적화 (스펙트럼-최적화 체인)

```
고유분해를 안다
  │
  │ H = QΛQᵀ (Hessian의 고유분해)
  ▼
Loss landscape의 곡률을 안다
  │
  │ λ_max: 가장 가파른 방향
  │ λ_min: 가장 완만한 방향
  ▼
조건수 κ = λ_max/λ_min 을 안다
  │
  │ κ가 크면 → 수렴 느림 (long narrow valley)
  ▼
적응적 학습률의 필요성을 안다
  │
  │ Newton: θ ← θ - H⁻¹∇L (이차 수렴, 하지만 비현실적)
  │ Adam: 대각 근사 → 방향별 학습률 조절
  ▼
Flat Minima ↔ 일반화의 연결을 안다
  │
  │ 고유값이 작은 minima = flat = 일반화 좋음
  │ 고유값이 큰 minima = sharp = 일반화 나쁨
  ▼
큰 배치 vs 작은 배치의 차이를 이해한다
  → 작은 배치의 노이즈가 sharp minima 탈출을 도움
```

### 체인 7: 엔트로피 → 정보이론 → 손실함수 통합 (정보-손실 체인)

```
Entropy H(p)를 안다
  │
  │ "최소 평균 부호 길이" = 불확실성 측도
  ▼
Cross-Entropy H(p,q) = H(p) + KL(p||q)
  │
  │ q로 인코딩했을 때의 평균 부호 길이
  ▼
NLL = H(p_data, p_model)
  │
  │ 모든 손실함수의 통합
  ▼
KL(p||q) = H(p,q) - H(p) ≥ 0
  │
  │ MLE = KL 최소화
  ▼
Mutual Information I(X;Y) = KL(p(x,y) || p(x)p(y))
  │
  │ 독립에서의 이탈 정도
  ▼
Information Bottleneck
  min I(X;T) - β·I(T;Y)
  "입력 정보는 줄이되, 출력 예측 정보는 보존"
```
