# dl_study.md — 2단계부터 진짜 천천히 (왕초보용 풀버전)

> 이 문서는 `dl_study_쉬운설명.md`의 2단계 이후가 어렵다는 피드백을 받아, **각 줄 사이의 비약을 모두 풀어** 더 잘게 쪼갠 자료다. 분량은 길지만 한 단계도 건너뛰지 마라.

---

## 사전 약속 (이거 먼저 챙기자)

### 약속 1. θ는 그냥 "다이얼들"
모델 안에 든 숫자 다이얼 묶음을 θ라고 부른다. 다이얼이 하나일 수도 있고(`θ ∈ ℝ`), 100개일 수도 있다(`θ ∈ ℝ¹⁰⁰`). 처음에는 **다이얼 1개**라고 생각해도 좋다.

### 약속 2. P(...)는 "확률" 또는 "그럴듯함"
- `P(θ)` = "다이얼이 θ 근처일 가능성" (값이 클수록 가능성↑)
- `P(D|θ)` = "다이얼을 θ에 놓고 봤을 때 데이터 D가 나올 가능성"

### 약속 3. log는 "뻣뻣한 곱셈을 부드러운 덧셈으로 바꾸는 마법"
- `log(A · B) = log A + log B`
- `log(eˣ) = x` ← **이거 정말 중요**. exp와 log는 서로 풀어준다.

### 약속 4. argmax / argmin
- `arg max f(θ)` : "f를 가장 크게 만드는 그 θ값"
- `arg min f(θ)` : "f를 가장 작게 만드는 그 θ값"
- 값 자체가 아니라 **위치**를 묻는 것.

### 약속 5. 1단계 결과 (다시 한 번)

$$
\hat\theta_{\text{MAP}} = \arg\min_\theta\big[\,\underbrace{-\log P(D\mid\theta)}_{\text{데이터 손실}} + \underbrace{-\log P(\theta)}_{\text{정규화 R(θ)}}\,\big].
$$

→ 이 식은 **"손실 + 페널티"** 두 부분으로 이뤄진다. 데이터를 잘 맞추는 부분(첫째 항)과 너무 큰 θ에 벌금을 매기는 부분(둘째 항).

# 2단계. "세 가지 시각이 사실 하나" — 진짜 천천히

원본은 한 줄로 표 한 개 보여주고 끝났다. 하지만 그 표를 처음 보는 사람은 "왜?"가 안 풀린다. 차근차근 셋을 따로 보고 → 합치자.

## 2-1. 첫 번째 시각: "확률론자의 시각" (prior P(θ))

### 무대
당신은 통계학자다. 당신의 세계관은:
> "모든 것은 확률 분포로 설명된다."

### 어떻게 본다
다이얼 θ가 **어디 있을지 미리 알 수는 없지만**, "어디 있을 가능성이 높은지"는 안다고 가정한다. 이걸 분포 `P(θ)` 로 표현.

### 구체 예
당신이 사람의 **키 평균**을 추정한다고 하자.
- θ = 키 평균 (cm).
- 데이터 보기 전에도 우리는 안다: "사람 키 평균은 보통 150~180 어디쯤 일거야. 1000cm일 리는 없어."
- 이 믿음이 곧 **prior** `P(θ)`. 가운데(160~170 근처)는 높고, 멀어질수록 낮은 종 모양.

### 핵심
**prior = 데이터 보기 전의 믿음을 분포로 적은 것.**

---

## 2-2. 두 번째 시각: "최적화 엔지니어의 시각" (regularizer R(θ))

### 무대
당신은 최적화 코드를 짜는 엔지니어다. 당신의 세계관은:
> "어떤 함수를 가장 작게 만드는 θ를 찾는 게 일이다."

### 어떻게 본다
당신은 **손실 함수 L(θ)** 를 최소화하면 된다고 본다. 그런데 데이터에만 맞추려 하면 θ가 미친 듯이 커지는 일이 생긴다 (overfitting). 그래서 **벌금 항** R(θ)을 추가:
$$
\text{전체 손실} = L(θ) + \lambda R(θ).
$$
- L(θ): 데이터를 못 맞추면 커지는 항.
- R(θ): θ가 너무 크면 커지는 항.
- λ: 두 항의 비중을 정하는 다이얼 (얼마나 페널티 강하게 줄지).

### 구체 예
- R(θ) = θ² (다이얼이 0에서 멀수록 벌금↑).
- "데이터에 잘 맞으면서 θ도 작은" 답을 찾게 됨.

### 핵심
**regularizer = θ가 커지지 않게 잡아주는 페널티 항.**

---

## 2-3. 세 번째 시각: "학습이론가의 시각" (가설공간 H 제한)

### 무대
당신은 ML 이론을 연구하는 학자다. 당신의 세계관은:
> "학습 = 가능한 모델들의 집합 H 안에서 하나를 고르는 일."

### 어떻게 본다
**가설공간(hypothesis space) H** = 우리가 고려할 수 있는 모든 모델의 집합. 예: 모든 직선, 모든 다항식, 모든 가능한 θ들.

H가 너무 크면 데이터에 어떻게든 맞출 수 있어 과적합. H가 너무 작으면 표현력이 부족해 과소적합. 그래서 H를 적당히 **제한**한다:
$$
\theta\in H_C := \{\theta:\|\theta\|\le C\}.
$$
"θ의 길이가 C 이하"인 영역에서만 답을 찾자.

### 구체 예
직선 `y = ax + b`를 학습. 보통 H는 모든 (a, b). 제한하면 "a²+b² ≤ 1" 영역에서만 찾기.

### 핵심
**H 제한 = 처음부터 후보 모델 풀을 좁히기.**

---

## 2-4. 셋이 같다? 어떻게 같다?

세 시각의 식을 나란히 놓자:

| 시각 | 식 |
|---|---|
| ① 확률 | `argmax_θ P(D|θ)·P(θ)` |
| ② 최적화 | `argmin_θ [L(θ) + λ R(θ)]` |
| ③ 학습이론 | `argmin_θ L(θ)  s.t.  ‖θ‖ ≤ C` |

### ①과 ② 가 같은 이유 (1단계 결과 재활용)
1단계에서 우리는 ①을 변형해 다음을 얻었다:
$$
\arg\min_\theta\big[-\log P(D|\theta) - \log P(\theta)\big].
$$
- 첫 항 `-log P(D|θ)` = 데이터 손실 = **L(θ)**.
- 둘째 항 `-log P(θ)` = θ에 대한 페널티 = **λR(θ)** (구체적인 분포에 따라 모양 결정 — 3단계에서).

→ ①을 변형하면 ②와 똑같은 식. **수학적으로 동치**.

### ②와 ③이 같은 이유 (Lagrangian 쌍대)
이건 약간 더 어려운데, 직관만 잡으면 된다.

**비유**: 다이어트하는 사람.
- (페널티 형태): "치킨 1조각 = 벌점 100. 행복도에서 빼라."
- (제약 형태): "하루 칼로리 1500 이하만 먹어라."
두 방법은 **결과적으로 같은 식단**을 만들 수 있다. λ(벌점 강도)와 C(칼로리 한도)는 서로 변환 가능.

수학적으로:
- λ가 정해지면 → 그에 맞는 C가 존재 (라그랑주 승수 이론).
- 두 문제의 **최적해 θ\*는 같다.**

### 결론
세 식이 **같은 θ\*를 답으로 준다**. 그래서 "세 시각이 사실 하나"라고 말하는 것이다.

> 📌 **외울 한 줄**: prior P(θ) → -log P(θ) = R(θ) → ‖θ‖ ≤ C 영역. 셋은 같은 정보의 세 표현.

# 3단계. Prior 모양에 따라 R(θ)가 어떻게 달라지나

이제 "prior가 어떤 모양이면 어떤 R(θ)가 나오는지" 셋을 손으로 직접 유도해보자.

## 3-A. Gaussian (정규분포) Prior → L2 정규화

### 3-A-1. Gaussian이 뭐였더라
종 모양 분포. 평균 0, 분산 σ² 인 1차원 정규분포의 PDF:
$$
P(\theta) = \frac{1}{\sqrt{2\pi}\sigma}\exp\!\Big(-\frac{\theta^2}{2\sigma^2}\Big).
$$

📊 그림: x축 θ, y축 P(θ). θ=0에서 가장 높고, σ가 작으면 좁고 뾰족, σ가 크면 넓고 평평.

### 3-A-2. 왜 이게 "θ가 0 근처에 있을 거야"라는 믿음인가?
- θ=0에서 PDF가 최대 → 0이 제일 그럴듯.
- |θ|가 커질수록 PDF가 빠르게 감소 → 큰 값일수록 안 그럴듯.
- σ는 "얼마나 넓게 퍼지나" — σ 작으면 0 근처에 매우 가깝다고 강하게 믿는 것.

### 3-A-3. -log를 한 단계씩 씌우기

$$
P(\theta) = \frac{1}{\sqrt{2\pi}\sigma}\cdot \exp\!\Big(-\frac{\theta^2}{2\sigma^2}\Big).
$$

**Step 1.** log 양변에 적용. log(곱) = log + log:
$$
\log P(\theta) = \log\frac{1}{\sqrt{2\pi}\sigma} + \log\exp\!\Big(-\frac{\theta^2}{2\sigma^2}\Big).
$$

**Step 2.** `log(exp(x)) = x` 이므로:
$$
\log P(\theta) = \log\frac{1}{\sqrt{2\pi}\sigma} - \frac{\theta^2}{2\sigma^2}.
$$

**Step 3.** 첫 항은 **θ에 무관한 상수**. `c`로 부르자:
$$
\log P(\theta) = c - \frac{\theta^2}{2\sigma^2}.
$$

**Step 4.** 부호 반전:
$$
-\log P(\theta) = -c + \frac{\theta^2}{2\sigma^2}.
$$

**Step 5.** `-c`도 상수, argmin에 영향 없음 → 무시. 다이얼이 여러 개면 `θ² → ‖θ‖²`:
$$
\boxed{\,R(\theta) = -\log P(\theta) = \frac{1}{2\sigma^2}\|\theta\|_2^2.\,}
$$

### 3-A-4. 이 식의 뜻
- `‖θ‖² = θ₁² + θ₂² + ⋯` 모든 다이얼의 제곱합.
- 다이얼이 클수록 페널티 커짐 (제곱이라 빨리 커짐).
- 정규화 강도 **λ = 1/(2σ²)**:
  - σ 작다 (믿음 강함) → λ 크다 (페널티 강함). ✅ 직관과 일치.
  - σ 크다 (믿음 약함) → λ 작다 (페널티 약함).

### 3-A-5. 이게 왜 "L2"라 불리나
"L2 norm" = 유클리드 길이 = `√(θ₁²+θ₂²+⋯)`. 그 제곱이 `‖θ‖²`. L2 노름의 제곱을 페널티로 쓰니까 "L2 정규화" (= **Ridge**).

📌 **핵심 결과 (Gaussian)**: `Gaussian prior → R(θ) = (λ)·‖θ‖²` (Ridge).

---

## 3-B. Laplace Prior → L1 정규화

### 3-B-1. Laplace 분포가 뭔가
**뾰족한** 종 모양. 0에서 위로 뾰족. PDF (1차원, 평균 0, 스케일 b):
$$
P(\theta) = \frac{1}{2b}\exp\!\Big(-\frac{|\theta|}{b}\Big).
$$

📊 그림: Gaussian이랑 비슷하지만 0 근처가 더 **뾰족하고**, 꼬리가 더 두껍다.

### 3-B-2. 왜 sparse 해가 나오는가? (예고)
0에서 뾰족하다는 건 → **"θ가 정확히 0일 가능성이 매우 높아"** 라고 강하게 믿는다는 것. 결과적으로 학습이 끝났을 때 일부 θᵢ가 정확히 0이 됨.

### 3-B-3. -log 한 단계씩

$$
P(\theta) = \frac{1}{2b}\exp\!\Big(-\frac{|\theta|}{b}\Big).
$$

**Step 1.** log 적용:
$$
\log P(\theta) = \log\frac{1}{2b} + \log\exp\!\Big(-\frac{|\theta|}{b}\Big).
$$

**Step 2.** `log(exp(x)) = x`:
$$
\log P(\theta) = \log\frac{1}{2b} - \frac{|\theta|}{b}.
$$

**Step 3.** 상수 무시:
$$
-\log P(\theta) = \frac{|\theta|}{b} + \text{상수}.
$$

**Step 4.** 다이얼 여러 개면 `|θ| → ‖θ‖₁ = |θ₁|+|θ₂|+⋯`:
$$
\boxed{\,R(\theta) = \frac{1}{b}\|\theta\|_1.\,}
$$

### 3-B-4. 이게 왜 "L1"이며 왜 sparse인가
- "L1 norm" = 각 좌표 절댓값의 **합** = `|θ₁|+|θ₂|+⋯`.
- L2(`‖θ‖²`)는 0 근처에서 **부드럽게** 줄어들지만, L1(`|θ|`)는 **꺾여** 있음 (V자).
- 5단계의 기하 그림에서 보겠지만, 이 꺾임이 **꼭짓점**을 만들고, 이게 sparsity로 이어진다.

📌 **핵심 결과 (Laplace)**: `Laplace prior → R(θ) = (λ)·‖θ‖₁` (Lasso, sparse).

---

## 3-C. Uniform Prior → 정규화 없음 (= MLE)

### 3-C-1. Uniform이란
"모든 θ가 똑같이 가능하다" 는 분포. PDF가 상수.
$$
P(\theta) = \text{상수}.
$$

### 3-C-2. -log 한 줄
상수의 log도 상수 → -log도 상수:
$$
-\log P(\theta) = \text{상수}.
$$
→ R(θ)가 θ에 무관 → argmin에 아무 영향 없음.

### 3-C-3. 결과
$$
\hat\theta_{\text{MAP}} = \arg\min -\log P(D|\theta) = \hat\theta_{\text{MLE}}.
$$

→ **MLE = "Uniform prior MAP"**. 즉 MLE는 MAP의 특수한 한 경우.

### 3-C-4. 왜 위험?
페널티가 없어 데이터가 적으면 θ가 미친 값으로 튀어 **과적합**. 시험에서 "MLE의 단점은?" 하면 답: "정규화가 없어 과적합 위험."

# 4단계. λ가 결정하는 모든 것 (그림으로 이해)

## 4-1. 식을 다시 보자
$$
\hat\theta = \arg\min_\theta\big[L(\theta) + \lambda R(\theta)\big].
$$
- L(θ) = 데이터 손실.
- R(θ) = θ가 크면 커지는 페널티.
- λ = 두 항의 비중.

## 4-2. λ가 0일 때
"페널티 무시, 데이터에만 충실"
- argmin은 L(θ)만 최소화 → 그게 곧 **MLE**.
- 가설공간 H 제한 없음 (어떤 θ도 가능).
- **결과**: 데이터에 매우 잘 맞지만, 새 데이터에는 종종 망함 (과적합).

### 직관 비유
시험 직전 "지난 5년 기출문제만 외우는" 학생. 기출은 100점, 새 문제는 70점.

## 4-3. λ가 무한대일 때
"데이터 무시, 페널티만"
- argmin은 R(θ)만 최소화 → R(θ)=‖θ‖² 면 답은 θ=0.
- 가설공간 한 점으로 수축.
- **결과**: 데이터 안 봤으니 학습 효과 없음 (과소적합).

### 직관 비유
"공부하기 싫어, 그냥 모든 문제 0번 찍을래" — 안전하지만 점수 거의 0.

## 4-4. λ가 적당할 때
"데이터와 페널티의 균형"
- L과 R이 둘 다 작은 적당한 θ를 고름.
- 새 데이터에서도 잘 작동.

### 직관 비유
"기출 50%, 개념 이해 50%" — 기출도 잘 보고 새 문제도 풀 수 있음.

## 4-5. Bias-Variance Tradeoff와의 연결
| λ | bias (편향) | variance (분산) | 모델 행동 |
|---|---|---|---|
| 작음 | 낮음 (데이터 잘 따름) | 높음 (데이터셋 바뀌면 답 휙 바뀜) | 과적합 |
| 큼 | 높음 (단순한 답) | 낮음 (안정적) | 과소적합 |
| 중간 | 중간 | 중간 | sweet spot |

→ λ를 cross-validation 등으로 튜닝해서 sweet spot을 찾는 게 ML 실전.

# 5단계. 기하 그림 — L1이 왜 sparse를 만드는가 (가장 헷갈리는 부분)

이건 **그림으로** 이해하는 게 가장 빠르다. 머리에 그려가며 읽어라.

## 5-1. 무대 설정
다이얼이 2개라 하자: θ = (θ₁, θ₂). 평면(2D 좌표)에서 가로축 θ₁, 세로축 θ₂.

## 5-2. 첫 번째 그림: Likelihood 등고선

데이터 손실 `L(θ)`을 평면 위에 그리면 **그릇 모양**(아래로 볼록). 등고선은 보통 **타원 동심원**.
- 가장 안쪽 점 = MLE 답 (정규화 없을 때 최적).
- 멀어질수록 손실 ↑.

```
  θ₂↑
    |    ___
    |   / o \   ← 가운데 점 'o' 가 MLE
    |  ( ⊙ )       동심원 = 같은 손실값
    |   \___/
    |__________ θ₁→
```

## 5-3. 두 번째 그림: 제약 영역

### L2 제약: ‖θ‖² ≤ C → **원**
"θ₁² + θ₂² ≤ C" → 반지름 √C 인 원 안.

```
  θ₂↑
    |   ___
    |  /   \
    | (  •  )   ← 원점 중심의 원
    |  \___/
    |__________ θ₁→
```

### L1 제약: ‖θ‖₁ ≤ C → **마름모**
"|θ₁| + |θ₂| ≤ C" → 꼭짓점이 (±C, 0), (0, ±C) 인 마름모.

```
  θ₂↑
    |    ◇
    |   / \
    |  / • \
    | <  +  >   ← 마름모 (꼭짓점이 축 위에)
    |  \   /
    |   \ /
    |    ◇
    |__________ θ₁→
```

## 5-4. 두 그림 겹치기 — 답은 어디서 만나나?

이제 likelihood 등고선과 제약 영역을 겹친다. 답은 **두 영역의 첫 접점** (등고선이 제약 영역을 처음 만나는 곳).

### L2 (원) 의 경우
- 원과 등고선 둘 다 매끈한 곡선.
- 접점은 보통 **축 위가 아닌 임의의 위치**.
- → 답 (θ₁, θ₂) 둘 다 0이 아닌 작은 값.
- **현상**: 모든 다이얼이 0에 가까워지지만 정확히 0은 거의 없음.

```
   ___
  /   \           ← 등고선 (타원)
 ( ___ )
  /   \           ← L2 원
 (  o  )         ← o = 접점 (축 위 아님)
  \___/
  \___/
```

### L1 (마름모) 의 경우
- 등고선은 매끈한 타원, 제약은 **뾰족한** 마름모.
- 등고선이 마름모로 들어올 때 **꼭짓점에서 만나기 쉽다** (마름모의 변보다 꼭짓점이 더 "튀어나와" 있어서).
- 꼭짓점 좌표 = (C, 0) 또는 (0, C) → **한 좌표가 정확히 0**.
- → 답이 (something, 0) 형태 → 일부 다이얼이 0.
- **현상**: sparsity (희소성) — 이게 L1의 마법.

```
      ◇
     / \
    / o \         ← o = 꼭짓점에서 등고선이 만남
   <-----►        → θ₂ = 0, θ₁만 살아남
    \   /
     \ /
      ◇
```

### 왜 마름모는 "꼭짓점에서 만나기 쉽나"?
직관: 등고선이 점점 커지며 마름모로 다가올 때, 마름모의 가장 멀리 튀어나온 부분은 **꼭짓점**이다. 그래서 등고선이 가장 먼저 만나는 곳도 꼭짓점일 확률이 높다.

(엄밀히는 등고선의 모양과 방향에 따라 변에서 만날 수도 있지만, 평균적으로 꼭짓점 만남이 빈번 → 통계적으로 sparsity.)

## 5-5. C가 작을수록 H가 작다 → bias↑, variance↓

- C ↓: 제약 영역이 작아짐 → 더 좁은 H 안에서 답을 찾음 → 답이 데이터 변화에 덜 민감 (variance ↓), 대신 진짜 답을 못 맞출 수 있음 (bias ↑).
- C ↑: H가 커짐 → 데이터에 민감해지지만 (variance ↑) 진짜 답에 가까이 (bias ↓).

→ **C(또는 λ)는 bias-variance tradeoff의 다이얼.**

## 5-6. 페널티(λ)와 제약(C)이 같은 이유 — Lagrangian 직관 한 번 더

원하는 식이 두 가지로 표현된다:
- **(P)** `min L(θ) + λR(θ)`
- **(C)** `min L(θ)  s.t.  R(θ) ≤ C`

**라그랑주 정리**가 말하길:
> 어떤 λ에 대해 (P)를 풀어 답 θ*를 얻으면, **그 θ*는 어떤 C에 대한 (C)의 답**이기도 하다 (C = R(θ*)).

거꾸로도 성립. 즉 두 형식 사이를 자유롭게 오갈 수 있다 — 따라서 **사실상 같은 문제**.

**비유로 다시**:
- (P): "치킨 한 조각당 벌점 λ. 행복도 - 벌점 최대화."
- (C): "오늘 치킨 C조각만 먹기. 그 안에서 행복 최대화."
- λ를 어떻게 잡든, 그에 대응하는 적당한 C가 존재해 같은 식단이 나온다.

# 6단계. 시험 포인트 (각각 풀어서)

## 6-1. MAP = MLE + log-prior 유도 (백지 5단계)

빈 종이에 다음을 한 번에 쓸 수 있어야 한다:

```
1. θ̂ = argmax P(θ|D)                              ← MAP 정의
2.   = argmax [P(D|θ) · P(θ)]                     ← 베이즈, P(D)는 무시
3.   = argmax [log P(D|θ) + log P(θ)]              ← log 단조증가 적용
4.   = argmin [-log P(D|θ) - log P(θ)]             ← 부호 반전
5.   = argmin [data loss + R(θ)]                   ← 명명
```

각 줄의 변환 이름(베이즈/log/부호반전/명명)을 함께 쓰면 만점.

## 6-2. Gaussian → L2, Laplace → L1 (각각 5줄로)

**Gaussian** (3-A-3 그대로):
```
P(θ) = (1/√2πσ) · exp(-θ²/2σ²)
log → log(1/√2πσ) - θ²/2σ²
부호 → -log(1/√2πσ) + θ²/2σ²
상수 무시 → R(θ) = θ²/(2σ²) = (1/2σ²)‖θ‖²
∴ λ = 1/(2σ²)
```

**Laplace** (3-B-3 그대로):
```
P(θ) = (1/2b) · exp(-|θ|/b)
log → log(1/2b) - |θ|/b
부호+상수무시 → R(θ) = |θ|/b = (1/b)‖θ‖₁
∴ λ = 1/b
```

## 6-3. λ ↔ σ 관계
**Gaussian의 경우** `λ = 1/(2σ²)`. 즉:
- σ ↓ (믿음 강함, 분포 좁음) → λ ↑ (페널티 강함). ✅
- σ ↑ (믿음 약함, 분포 넓음) → λ ↓ (페널티 약함).

이 변환을 헷갈리지 마라. **σ는 분포의 폭, λ는 페널티 강도**, 둘은 반비례.

## 6-4. H 제한의 두 형태 (페널티 vs 제약) 동치
- 페널티: `min L(θ) + λR(θ)`
- 제약: `min L(θ)  s.t.  R(θ) ≤ C`
- 동치 근거: **Lagrangian 쌍대성** (모든 λ ↔ 그에 대응하는 C가 존재).

## 6-5. MAP은 mode이지 mean이 아니다
- MAP = `argmax P(θ|D)` = 사후분포의 **최빈값(mode)**, 즉 분포의 봉우리 위치.
- 사후 평균 = `E[θ|D] = ∫θ·P(θ|D)dθ` = 분포의 **평균값**.
- 분포가 **비대칭**이면 mode와 mean이 다르다.

### 예
사후가 오른쪽으로 긴 꼬리(skewed right)면:
- mode는 왼쪽 봉우리 위치 (예: 2)
- mean은 꼬리에 끌려 더 큰 값 (예: 5)
- 둘이 다르다 → MAP과 사후 평균이 다른 답.

시험: "MAP과 사후 평균은 같은가?" → "비대칭 분포에서 다르다" 가 정답.

# 7단계. 다음에 배울 거리

위 6단계까지 다 이해했으면 6주차는 통과다. 더 깊이 가고 싶다면:

- **(A) L1 sparsity 엄밀 증명**: KKT 조건 + 마름모 기하로 "왜 정확히 0이 되는가"를 수학으로 증명.
- **(B) MAP vs Full Bayesian**: MAP은 한 점만, Full Bayesian은 P(θ|D) **분포 전체**를 사용. 불확실성 정보 보존.
- **(C) Ridge / Lasso 손계산**: 작은 데이터셋(예: x=[1,2,3], y=[2,4,5])에 직접 풀어보기.
- **(D) PAC learning 연결**: VC 차원, generalization bound와 H 제한.

```
┌─────────────────────────────────────────────────────┐
│ MAP의 정수                                           │
├─────────────────────────────────────────────────────┤
│ θ̂ = argmin [-log P(D|θ) - log P(θ)]                 │
│              ↑ data loss   ↑ regularizer            │
│                                                      │
│ 세 시각이 같다:                                      │
│   prior P(θ)  ⟺  -log P(θ) = R(θ)  ⟺  ‖θ‖ ≤ C       │
│   (확률)         (최적화)              (학습이론)    │
│                                                      │
│ Prior → Regularizer:                                │
│   Gaussian N(0,σ²)   → R = (1/2σ²)‖θ‖²    (Ridge)   │
│   Laplace exp(-|θ|/b)→ R = (1/b)‖θ‖₁      (Lasso)   │
│   Uniform            → R = 0              (= MLE)   │
│                                                      │
│ λ ↔ 학습 행동:                                       │
│   λ→0 : MLE, 과적합                                 │
│   λ→∞ : prior 한 점, 과소적합                        │
│   중간 : bias-variance sweet spot                   │
│                                                      │
│ 기하: L2=원(매끈) / L1=마름모(꼭짓점→sparsity)       │
│                                                      │
│ MAP = mode (최빈값) ≠ posterior mean (평균)         │
└─────────────────────────────────────────────────────┘
```
