# 딥러닝 이론 증명 연습장 — 빈칸 채우기 형식

> **사용법**: 완성본으로 흐름을 익힌 뒤, 연습 버전을 인쇄하여 펜으로 빈칸을 채운다.
> "답만 적으면 0점" — 모든 단계에서 **왜** 그 변환이 가능한지를 반드시 서술할 것.

---

## 증명 1: Gaussian 가정 → MSE 유도

### 1-A. 완성본

**목표**: $y \mid x \sim \mathcal{N}(f_\theta(x),\;\sigma^2)$ 가정 하에서 MLE가 MSE 최소화와 동치임을 보인다.

**Step 1.** 단일 샘플의 likelihood를 쓴다.

$$p(y_i \mid x_i;\theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\Bigl(-\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2}\Bigr)$$

(왜: Gaussian pdf 정의)

**Step 2.** i.i.d. 가정에 의해 전체 likelihood는 개별 likelihood의 곱이다.

$$\mathcal{L}(\theta) = \prod_{i=1}^{N} p(y_i \mid x_i;\theta)$$

(왜: 독립 사건의 결합확률 = 각 확률의 곱)

**Step 3.** 양변에 $-\log$를 취하면 곱이 합으로 바뀐다.

$$-\log \mathcal{L}(\theta) = \sum_{i=1}^{N} \Bigl[\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2} + \frac{1}{2}\log(2\pi\sigma^2)\Bigr]$$

(왜: $\log(ab)=\log a + \log b$, $\log\exp(x)=x$, 그리고 $-\log$를 취하면 최대화 → 최소화로 전환)

**Step 4.** $\theta$에 무관한 상수항 $\frac{N}{2}\log(2\pi\sigma^2)$를 제거하면:

$$\arg\min_\theta \;-\log\mathcal{L}(\theta) = \arg\min_\theta \;\sum_{i=1}^{N}(y_i - f_\theta(x_i))^2$$

(왜: 상수를 더하거나 양의 상수를 곱해도 argmin은 변하지 않는다)

**결론**: Gaussian noise 가정 하에서 MLE ≡ MSE 최소화. $\blacksquare$

---

### 1-B. 연습 버전

**Step 1.** 단일 샘플의 likelihood를 쓴다.

$$p(y_i \mid x_i;\theta) = \text{[빈칸 A]}$$

(왜: [빈칸 B])

**Step 2.** i.i.d. 가정에 의해 전체 likelihood는:

$$\mathcal{L}(\theta) = \text{[빈칸 C]}$$

(왜: [빈칸 D])

**Step 3.** 양변에 $\text{[빈칸 E]}$를 취하면:

$$-\log \mathcal{L}(\theta) = \text{[빈칸 F]}$$

(왜: [빈칸 G])

**Step 4.** $\theta$에 무관한 항을 제거하면:

$$\arg\min_\theta\; -\log\mathcal{L}(\theta) = \arg\min_\theta\;\text{[빈칸 H]}$$

(왜: [빈칸 I])

---

### 1-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $\frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\bigl(-\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2}\bigr)$ |
| B | Gaussian pdf 정의 |
| C | $\prod_{i=1}^{N} p(y_i \mid x_i;\theta)$ |
| D | 독립 사건의 결합확률 = 각 확률의 곱 |
| E | $-\log$ |
| F | $\sum_{i=1}^{N}\bigl[\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2} + \frac{1}{2}\log(2\pi\sigma^2)\bigr]$ |
| G | $\log$의 성질로 곱→합 변환, $\log\exp(x)=x$, 부호 반전으로 max→min 전환 |
| H | $\sum_{i=1}^{N}(y_i - f_\theta(x_i))^2$ |
| I | 상수를 더하거나 양의 상수를 곱해도 argmin은 변하지 않는다 |

## 증명 2: Bernoulli 가정 → Cross-Entropy 유도

### 2-A. 완성본

**목표**: $y \mid x \sim \text{Bernoulli}(p_\theta(x))$ 가정 하에서 MLE가 Binary CE 최소화와 동치임을 보인다.

**Step 1.** Bernoulli 분포의 pmf를 하나의 식으로 쓴다.

$$p(y_i \mid x_i;\theta) = p_\theta(x_i)^{y_i}(1-p_\theta(x_i))^{1-y_i}, \quad y_i \in \{0,1\}$$

(왜: $y=1$이면 $p$, $y=0$이면 $1-p$를 하나의 식으로 통합)

**Step 2.** i.i.d. 가정으로 전체 likelihood:

$$\mathcal{L}(\theta) = \prod_{i=1}^{N} p_\theta(x_i)^{y_i}(1-p_\theta(x_i))^{1-y_i}$$

**Step 3.** Negative log-likelihood:

$$-\log\mathcal{L}(\theta) = -\sum_{i=1}^{N}\bigl[y_i \log p_\theta(x_i) + (1-y_i)\log(1-p_\theta(x_i))\bigr]$$

(왜: $\log(a^b) = b\log a$, 곱→합)

**Step 4.** 이것이 정확히 Binary Cross-Entropy의 정의이다.

$$\mathcal{L}_{\text{BCE}} = -\frac{1}{N}\sum_{i=1}^{N}\bigl[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\bigr]$$

**결론**: Bernoulli noise 가정 하에서 MLE ≡ BCE 최소화. $\blacksquare$

---

### 2-B. 연습 버전

**Step 1.** Bernoulli pmf를 하나의 통합 식으로:

$$p(y_i \mid x_i;\theta) = \text{[빈칸 A]}$$

(왜: [빈칸 B])

**Step 2.** 전체 likelihood:

$$\mathcal{L}(\theta) = \text{[빈칸 C]}$$

**Step 3.** $-\log$를 취하면:

$$-\log\mathcal{L}(\theta) = \text{[빈칸 D]}$$

(왜: [빈칸 E])

**Step 4.** 이것이 정확히 [빈칸 F]의 정의이다.

---

### 2-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $p_\theta(x_i)^{y_i}(1-p_\theta(x_i))^{1-y_i}$ |
| B | $y=1,0$ 두 경우를 지수 트릭으로 하나의 식에 통합 |
| C | $\prod_{i=1}^{N} p_\theta(x_i)^{y_i}(1-p_\theta(x_i))^{1-y_i}$ |
| D | $-\sum_{i=1}^{N}\bigl[y_i \log p_\theta(x_i) + (1-y_i)\log(1-p_\theta(x_i))\bigr]$ |
| E | $\log(a^b) = b\log a$ 적용, 곱→합 변환 |
| F | Binary Cross-Entropy (BCE) |

---

## 증명 3: MAP 추정 → L2 Regularization

### 3-A. 완성본

**목표**: 사전분포 $\theta \sim \mathcal{N}(0, \tau^2 I)$일 때, MAP 추정이 L2 정규화된 MLE와 동치임을 보인다.

**Step 1.** 베이즈 정리로 사후분포를 쓴다.

$$p(\theta \mid \mathcal{D}) \propto p(\mathcal{D} \mid \theta)\,p(\theta)$$

(왜: 베이즈 정리에서 $p(\mathcal{D})$는 $\theta$에 무관한 상수이므로 비례 관계)

**Step 2.** MAP = 사후분포 최대화 = $-\log$ 취한 것의 최소화:

$$\theta_{\text{MAP}} = \arg\min_\theta\;\bigl[-\log p(\mathcal{D}\mid\theta) - \log p(\theta)\bigr]$$

(왜: $-\log$는 단조감소이므로 최대화→최소화 전환)

**Step 3.** Gaussian prior $\theta \sim \mathcal{N}(0,\tau^2 I)$의 $-\log$:

$$-\log p(\theta) = \frac{\|\theta\|^2}{2\tau^2} + \text{const}$$

(왜: Gaussian pdf에 $-\log$를 취하면 지수부의 이차형식만 남음)

**Step 4.** 합치면:

$$\theta_{\text{MAP}} = \arg\min_\theta\;\Bigl[\underbrace{-\log p(\mathcal{D}\mid\theta)}_{\text{NLL (= loss)}} + \underbrace{\frac{1}{2\tau^2}\|\theta\|^2}_{\lambda\|\theta\|^2}\Bigr]$$

여기서 $\lambda = \frac{1}{2\tau^2}$.

(왜: 두 항을 결합하고, $\tau^2$가 작을수록 → $\lambda$가 커지고 → 정규화 강도 증가)

**결론**: Gaussian prior의 MAP ≡ L2 정규화. $\blacksquare$

---

### 3-B. 연습 버전

**Step 1.** 베이즈 정리:

$$p(\theta \mid \mathcal{D}) \propto \text{[빈칸 A]}$$

(왜: [빈칸 B])

**Step 2.** MAP의 $-\log$ 형태:

$$\theta_{\text{MAP}} = \arg\min_\theta\;\text{[빈칸 C]}$$

(왜: [빈칸 D])

**Step 3.** $\theta \sim \mathcal{N}(0,\tau^2 I)$에 $-\log$를 취하면:

$$-\log p(\theta) = \text{[빈칸 E]}$$

(왜: [빈칸 F])

**Step 4.** 결합하면:

$$\theta_{\text{MAP}} = \arg\min_\theta\;\Bigl[\text{NLL} + \text{[빈칸 G]}\Bigr]$$

여기서 $\lambda = \text{[빈칸 H]}$

---

### 3-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $p(\mathcal{D} \mid \theta)\,p(\theta)$ |
| B | $p(\mathcal{D})$는 $\theta$에 무관한 상수이므로 비례 관계 |
| C | $-\log p(\mathcal{D}\mid\theta) - \log p(\theta)$ |
| D | $-\log$는 단조감소 → 최대화를 최소화로 전환 |
| E | $\frac{\|\theta\|^2}{2\tau^2} + \text{const}$ |
| F | Gaussian pdf의 $-\log$를 취하면 지수부의 이차형식만 남음 |
| G | $\lambda\|\theta\|^2$ (= $\frac{1}{2\tau^2}\|\theta\|^2$) |
| H | $\frac{1}{2\tau^2}$ |

## 증명 4: Softmax 함수의 Lagrangian 유도

### 4-A. 완성본

**목표**: $\sum_k p_k = 1$ 제약 하에서 Cross-Entropy를 최소화하는 $p$가 softmax임을 보인다. 더 정확히는, $\max_p \sum_k q_k \log p_k$ s.t. $\sum_k p_k=1$의 해가 $p_k = q_k$임을 보이고, 지수족 모델에서 softmax가 자연스럽게 나옴을 유도한다.

**접근**: 로그-선형 모델 $\log p_k = z_k - \log Z$에서 정규화 조건으로 softmax를 유도한다.

**Step 1.** 최대 엔트로피 원리에서, 에너지 $z_k$가 주어졌을 때 확률분포를 구한다. Lagrangian 설정:

$$\mathcal{L}(p, \lambda) = \sum_{k} z_k\, p_k + H(p) - \lambda\Bigl(\sum_{k} p_k - 1\Bigr)$$

여기서 $H(p) = -\sum_k p_k \log p_k$ (엔트로피).

(왜: 에너지의 기댓값을 고정하면서 엔트로피를 최대화하는 문제. 등식 제약이므로 Lagrange 승수법 적용)

**Step 2.** $p_j$에 대해 편미분하고 0으로 놓는다:

$$\frac{\partial \mathcal{L}}{\partial p_j} = z_j - \log p_j - 1 - \lambda = 0$$

(왜: $\frac{\partial}{\partial p_j}(-p_j \log p_j) = -\log p_j - 1$)

**Step 3.** $p_j$에 대해 풀면:

$$p_j = \exp(z_j - 1 - \lambda) = \frac{\exp(z_j)}{\exp(1+\lambda)}$$

**Step 4.** $\sum_k p_k = 1$ 제약에 대입:

$$\sum_k \frac{\exp(z_k)}{\exp(1+\lambda)} = 1 \;\Longrightarrow\; \exp(1+\lambda) = \sum_k \exp(z_k)$$

**Step 5.** 대입하면:

$$p_j = \frac{\exp(z_j)}{\sum_k \exp(z_k)} = \text{softmax}(z)_j$$

**결론**: 정규화 + 최대 엔트로피 제약 하에서 softmax가 유일한 해이다. $\blacksquare$

---

### 4-B. 연습 버전

**Step 1.** Lagrangian 설정:

$$\mathcal{L}(p,\lambda) = \text{[빈칸 A]}$$

(왜: [빈칸 B])

**Step 2.** $\frac{\partial \mathcal{L}}{\partial p_j} = 0$:

$$\text{[빈칸 C]} = 0$$

(왜: [빈칸 D])

**Step 3.** $p_j$에 대해 풀면:

$$p_j = \text{[빈칸 E]}$$

**Step 4.** $\sum_k p_k = 1$ 대입 → $\exp(1+\lambda) = \text{[빈칸 F]}$

**Step 5.** 최종:

$$p_j = \text{[빈칸 G]}$$

---

### 4-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $\sum_k z_k p_k - \sum_k p_k \log p_k - \lambda(\sum_k p_k - 1)$ |
| B | 에너지 기댓값 고정 + 엔트로피 최대화. 등식 제약 → Lagrange 승수법 |
| C | $z_j - \log p_j - 1 - \lambda$ |
| D | $\frac{\partial}{\partial p_j}(-p_j\log p_j) = -\log p_j - 1$ |
| E | $\exp(z_j - 1 - \lambda)$ |
| F | $\sum_k \exp(z_k)$ |
| G | $\frac{\exp(z_j)}{\sum_k \exp(z_k)}$ (= softmax) |

## 증명 5: Softmax Jacobian ($\partial p_i / \partial z_j$)

### 5-A. 완성본

**목표**: $p_i = \frac{e^{z_i}}{\sum_k e^{z_k}}$일 때 $\frac{\partial p_i}{\partial z_j}$를 구한다.

**Step 1.** $S = \sum_k e^{z_k}$로 놓으면 $p_i = e^{z_i}/S$.

**Step 2.** **Case $i = j$**: 몫의 미분법(Quotient rule) 적용:

$$\frac{\partial p_i}{\partial z_i} = \frac{e^{z_i}\cdot S - e^{z_i}\cdot e^{z_i}}{S^2} = \frac{e^{z_i}}{S}\cdot\frac{S - e^{z_i}}{S} = p_i(1 - p_i)$$

(왜: $\frac{\partial}{\partial z_i}e^{z_i} = e^{z_i}$, $\frac{\partial S}{\partial z_i} = e^{z_i}$, 몫의 미분 $\frac{f'g - fg'}{g^2}$)

**Step 3.** **Case $i \neq j$**: 분자 $e^{z_i}$는 $z_j$에 무관:

$$\frac{\partial p_i}{\partial z_j} = \frac{0 \cdot S - e^{z_i}\cdot e^{z_j}}{S^2} = -\frac{e^{z_i}}{S}\cdot\frac{e^{z_j}}{S} = -p_i\, p_j$$

(왜: 분자 $e^{z_i}$의 $z_j$ 미분 = 0, 분모의 $z_j$ 미분 = $e^{z_j}$)

**Step 4.** 통합하면:

$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j)$$

여기서 $\delta_{ij}$는 Kronecker delta.

(왜: $i=j$면 $p_i(1-p_i) = p_i(\delta_{ii}-p_i)$, $i\neq j$면 $-p_ip_j = p_i(\delta_{ij}-p_j)$로 통합)

**결론**: Jacobian $J = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T$. $\blacksquare$

---

### 5-B. 연습 버전

$S = \sum_k e^{z_k}$, $p_i = e^{z_i}/S$로 놓자.

**Case $i=j$**: 몫의 미분법:

$$\frac{\partial p_i}{\partial z_i} = \frac{\text{[빈칸 A]}}{S^2} = \text{[빈칸 B]}$$

(왜: [빈칸 C])

**Case $i\neq j$**:

$$\frac{\partial p_i}{\partial z_j} = \frac{\text{[빈칸 D]}}{S^2} = \text{[빈칸 E]}$$

(왜: [빈칸 F])

**통합**:

$$\frac{\partial p_i}{\partial z_j} = \text{[빈칸 G]}$$

**행렬 형태**: $J = \text{[빈칸 H]}$

---

### 5-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $e^{z_i}\cdot S - e^{z_i}\cdot e^{z_i}$ |
| B | $p_i(1-p_i)$ |
| C | 몫의 미분 $\frac{f'g-fg'}{g^2}$, $f'=e^{z_i}$, $g'=e^{z_i}$ |
| D | $0\cdot S - e^{z_i}\cdot e^{z_j}$ |
| E | $-p_i\,p_j$ |
| F | 분자 $e^{z_i}$는 $z_j$에 대해 상수, 분모의 $z_j$ 미분만 $e^{z_j}$ |
| G | $p_i(\delta_{ij} - p_j)$ |
| H | $\text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T$ |

## 증명 6: Rank-Nullity 정리

### 6-A. 완성본

**목표**: 선형사상 $T: V \to W$에 대해 $\dim V = \dim(\ker T) + \dim(\text{im}\,T)$를 보인다.

**Step 1.** $\ker T$의 기저를 $\{v_1, \dots, v_r\}$이라 하자. ($r = \dim\ker T$)

**Step 2.** 이 기저를 확장하여 $V$의 기저 $\{v_1, \dots, v_r, u_1, \dots, u_s\}$를 얻는다.

(왜: 모든 부분공간의 기저는 전체 공간의 기저로 확장 가능 — 기저 확장 정리)

그러면 $n = \dim V = r + s$.

**Step 3.** $\{T(u_1), \dots, T(u_s)\}$가 $\text{im}\,T$의 기저임을 보인다.

**(3a) 생성**: 임의의 $w \in \text{im}\,T$에 대해 $w = T(v)$인 $v \in V$가 존재. $v = \sum a_i v_i + \sum b_j u_j$이므로:

$$w = T(v) = \sum a_i \underbrace{T(v_i)}_{=0} + \sum b_j T(u_j) = \sum b_j T(u_j)$$

(왜: $v_i \in \ker T$이므로 $T(v_i) = 0$)

**(3b) 일차독립**: $\sum c_j T(u_j) = 0$이면 $T(\sum c_j u_j) = 0$이므로 $\sum c_j u_j \in \ker T$.

따라서 $\sum c_j u_j = \sum d_i v_i$ (커널의 기저로 표현 가능).

이는 $\sum d_i v_i - \sum c_j u_j = 0$을 의미하고, $\{v_1,\dots,v_r,u_1,\dots,u_s\}$가 $V$의 기저(일차독립)이므로 모든 $c_j = 0$.

(왜: $V$의 기저는 일차독립 → 모든 계수가 0)

**Step 4.** 따라서 $\dim(\text{im}\,T) = s$이고:

$$\dim V = r + s = \dim(\ker T) + \dim(\text{im}\,T) \quad\blacksquare$$

---

### 6-B. 연습 버전

**Step 1.** $\ker T$의 기저: $\{v_1, \dots, v_r\}$, $r = \dim\ker T$.

**Step 2.** 기저를 확장: $\{v_1,\dots,v_r, u_1,\dots,u_s\}$는 [빈칸 A]의 기저.

(왜: [빈칸 B])

$\dim V = \text{[빈칸 C]}$

**Step 3a.** 생성 증명: $w = T(v) = \sum a_i T(v_i) + \sum b_j T(u_j) = \text{[빈칸 D]}$

(왜: [빈칸 E])

**Step 3b.** 일차독립 증명: $\sum c_j T(u_j) = 0$ ⟹ $\sum c_j u_j \in \text{[빈칸 F]}$

⟹ $\sum c_j u_j = \sum d_i v_i$ ⟹ 모든 $c_j = 0$.

(왜: [빈칸 G])

**Step 4.** $\dim V = \text{[빈칸 H]}$

---

### 6-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $V$ (전체 공간) |
| B | 기저 확장 정리: 부분공간의 기저를 전체 공간의 기저로 확장 가능 |
| C | $r + s$ |
| D | $\sum b_j T(u_j)$ |
| E | $v_i \in \ker T$이므로 $T(v_i) = 0$ |
| F | $\ker T$ |
| G | $\{v_1,\dots,v_r,u_1,\dots,u_s\}$가 $V$의 기저(일차독립)이므로 모든 계수 = 0 |
| H | $\dim(\ker T) + \dim(\text{im}\,T)$ |

## 증명 7: 베이즈 정리 유도

### 7-A. 완성본

**목표**: $P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}$를 유도한다.

**Step 1.** 조건부 확률의 정의:

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}, \qquad P(B \mid A) = \frac{P(A \cap B)}{P(A)}$$

(왜: 조건부 확률의 공리적 정의. $P(B)>0$ 가정)

**Step 2.** 두 번째 식에서 $P(A \cap B)$를 구한다:

$$P(A \cap B) = P(B \mid A)\,P(A)$$

(왜: 양변에 $P(A)$를 곱함)

**Step 3.** 첫 번째 식에 대입:

$$P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}$$

**Step 4.** (확장) 전확률 법칙으로 분모를 전개:

$$P(B) = \sum_i P(B \mid A_i)\,P(A_i)$$

(왜: $\{A_i\}$가 표본공간의 분할이면, $B = \bigcup_i (B \cap A_i)$이고 서로 배반)

**결론**: 베이즈 정리. $\blacksquare$

---

### 7-B. 연습 버전

**Step 1.** 조건부 확률의 정의:

$$P(A\mid B) = \text{[빈칸 A]}, \qquad P(B\mid A) = \text{[빈칸 B]}$$

**Step 2.** $P(A \cap B) = \text{[빈칸 C]}$

(왜: [빈칸 D])

**Step 3.** 대입하면:

$$P(A\mid B) = \text{[빈칸 E]}$$

**Step 4.** 전확률 법칙: $P(B) = \text{[빈칸 F]}$

(왜: [빈칸 G])

---

### 7-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $\frac{P(A \cap B)}{P(B)}$ |
| B | $\frac{P(A \cap B)}{P(A)}$ |
| C | $P(B \mid A)\,P(A)$ |
| D | $P(B\mid A)$의 정의식 양변에 $P(A)$를 곱함 |
| E | $\frac{P(B\mid A)\,P(A)}{P(B)}$ |
| F | $\sum_i P(B\mid A_i)\,P(A_i)$ |
| G | $\{A_i\}$가 분할이면 $B = \bigcup(B\cap A_i)$, 서로 배반이므로 확률의 합 |

## 증명 8: KL Divergence $\geq 0$ (Jensen 부등식)

### 8-A. 완성본

**목표**: 임의의 분포 $p, q$에 대해 $D_{\text{KL}}(p\|q) \geq 0$이고, 등호는 $p=q$ a.e.일 때만 성립함을 보인다.

**Step 1.** KL divergence 정의:

$$D_{\text{KL}}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)} = -\sum_x p(x)\log\frac{q(x)}{p(x)}$$

**Step 2.** $-\log$는 볼록(convex) 함수이다.

(왜: $\frac{d^2}{dx^2}(-\log x) = \frac{1}{x^2} > 0$)

**Step 3.** Jensen 부등식 적용: 볼록 함수 $f$와 확률변수 $X$에 대해 $f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$.

$$D_{\text{KL}}(p\|q) = \mathbb{E}_{p}\!\Bigl[-\log\frac{q(x)}{p(x)}\Bigr] \geq -\log\mathbb{E}_{p}\!\Bigl[\frac{q(x)}{p(x)}\Bigr]$$

(왜: Jensen 부등식에서 $f = -\log$, $X = q(x)/p(x)$)

**Step 4.** 우변을 계산:

$$\mathbb{E}_{p}\!\Bigl[\frac{q(x)}{p(x)}\Bigr] = \sum_x p(x)\cdot\frac{q(x)}{p(x)} = \sum_x q(x) = 1$$

(왜: 확률분포의 정규화 조건 $\sum q(x) = 1$)

**Step 5.** 따라서:

$$D_{\text{KL}}(p\|q) \geq -\log 1 = 0$$

**등호 조건**: Jensen 부등식의 등호는 $X$가 상수일 때, 즉 $q(x)/p(x) = c$ (상수)일 때 성립. 정규화 조건에 의해 $c = 1$, 즉 $p = q$ a.e.

**결론**: $D_{\text{KL}}(p\|q) \geq 0$, 등호 ⟺ $p = q$. $\blacksquare$

---

### 8-B. 연습 버전

**Step 1.** KL 정의를 변형:

$$D_{\text{KL}}(p\|q) = -\sum_x p(x)\log\frac{q(x)}{p(x)} = \mathbb{E}_p\!\Bigl[\text{[빈칸 A]}\Bigr]$$

**Step 2.** $-\log$는 [빈칸 B] 함수이다.

(왜: [빈칸 C])

**Step 3.** [빈칸 D] 부등식 적용:

$$D_{\text{KL}}(p\|q) \geq -\log\mathbb{E}_p\!\Bigl[\text{[빈칸 E]}\Bigr]$$

**Step 4.** $\mathbb{E}_p\!\bigl[\frac{q(x)}{p(x)}\bigr] = \text{[빈칸 F]}$

(왜: [빈칸 G])

**Step 5.** $D_{\text{KL}}(p\|q) \geq -\log\text{[빈칸 H]} = \text{[빈칸 I]}$

**등호 조건**: [빈칸 J]

---

### 8-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $-\log\frac{q(x)}{p(x)}$ |
| B | 볼록(convex) |
| C | $\frac{d^2}{dx^2}(-\log x) = 1/x^2 > 0$ |
| D | Jensen |
| E | $\frac{q(x)}{p(x)}$ |
| F | $1$ |
| G | $\sum_x p(x)\cdot\frac{q(x)}{p(x)} = \sum_x q(x) = 1$ (정규화 조건) |
| H | $1$ |
| I | $0$ |
| J | $q(x)/p(x)$가 상수, 즉 $p = q$ a.e. |

## 증명 9: 정규방정식 유도 ($\nabla_w \|Xw - y\|^2 = 0$)

### 9-A. 완성본

**목표**: $\min_w \|Xw - y\|^2$의 해가 $w^* = (X^TX)^{-1}X^Ty$임을 보인다.

**Step 1.** 목적함수를 전개한다:

$$L(w) = \|Xw - y\|^2 = (Xw-y)^T(Xw-y)$$
$$= w^TX^TXw - 2y^TXw + y^Ty$$

(왜: $\|a\|^2 = a^Ta$ 전개, $(Xw)^T = w^TX^T$, 그리고 $w^TX^Ty = y^TXw$ (스칼라이므로 전치해도 같음))

**Step 2.** $w$에 대해 미분한다:

$$\nabla_w L = 2X^TXw - 2X^Ty$$

(왜: $\nabla_w(w^TAw) = 2Aw$ ($A$ 대칭일 때), $\nabla_w(b^Tw) = b$. 여기서 $A = X^TX$는 대칭)

**Step 3.** $\nabla_w L = 0$으로 놓으면:

$$2X^TXw - 2X^Ty = 0$$
$$X^TXw = X^Ty$$

(왜: 볼록 함수의 정상점(stationary point)이 전역 최솟값)

**Step 4.** $X^TX$가 가역이면 양변에 $(X^TX)^{-1}$를 곱한다:

$$w^* = (X^TX)^{-1}X^Ty$$

(왜: $X$의 열이 일차독립이면 $X^TX$는 양정치(positive definite) → 가역)

**결론**: 정규방정식(Normal Equation). $\blacksquare$

---

### 9-B. 연습 버전

**Step 1.** 목적함수 전개:

$$L(w) = (Xw-y)^T(Xw-y) = \text{[빈칸 A]}$$

(왜: [빈칸 B])

**Step 2.** $w$에 대해 미분:

$$\nabla_w L = \text{[빈칸 C]}$$

(왜: [빈칸 D])

**Step 3.** $\nabla_w L = 0$:

$$\text{[빈칸 E]} = X^Ty$$

(왜: [빈칸 F])

**Step 4.** $(X^TX)^{-1}$를 곱하면:

$$w^* = \text{[빈칸 G]}$$

(왜: [빈칸 H])

---

### 9-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $w^TX^TXw - 2y^TXw + y^Ty$ |
| B | $\|a\|^2 = a^Ta$ 전개, 스칼라 전치 항등식 적용 |
| C | $2X^TXw - 2X^Ty$ |
| D | $\nabla_w(w^TAw) = 2Aw$ ($A$ 대칭), $\nabla_w(b^Tw) = b$ |
| E | $X^TXw$ |
| F | 볼록 함수의 정상점 = 전역 최솟값 |
| G | $(X^TX)^{-1}X^Ty$ |
| H | 열 독립 → $X^TX$ 양정치 → 가역 |

## 증명 10: 엔트로피 최대화 → 균등분포

### 10-A. 완성본

**목표**: 이산 확률변수 $X$가 $n$개의 값을 가질 때, $H(X)$를 최대화하는 분포가 균등분포 $p_i = 1/n$임을 보인다.

**Step 1.** 문제를 Lagrangian으로 설정:

$$\max_{p_1,\dots,p_n} H(p) = -\sum_{i=1}^{n} p_i \log p_i \quad \text{s.t.} \quad \sum_{i=1}^{n} p_i = 1,\; p_i \geq 0$$

**Step 2.** Lagrangian:

$$\mathcal{L}(p,\lambda) = -\sum_{i=1}^{n} p_i \log p_i - \lambda\Bigl(\sum_{i=1}^{n} p_i - 1\Bigr)$$

**Step 3.** $p_j$에 대해 편미분:

$$\frac{\partial \mathcal{L}}{\partial p_j} = -\log p_j - 1 - \lambda = 0$$

(왜: $\frac{d}{dp}(-p\log p) = -\log p - 1$)

**Step 4.** $p_j$에 대해 풀면:

$$p_j = e^{-(1+\lambda)}$$

이 값은 $j$에 무관하므로 모든 $p_j$가 동일하다.

(왜: 우변에 $j$가 나타나지 않음 → 모든 $j$에 대해 같은 값)

**Step 5.** 제약 $\sum p_j = 1$ 대입:

$$n \cdot e^{-(1+\lambda)} = 1 \;\Longrightarrow\; p_j = \frac{1}{n}$$

**Step 6.** 이것이 최대임을 확인: $H$는 오목(concave) 함수이다.

(왜: $-p\log p$의 이계도함수 $= -1/p < 0$ → 오목. 오목 함수의 합도 오목. 오목 함수의 정상점은 전역 최대)

**결론**: 엔트로피를 최대화하는 분포는 균등분포. $H_{\max} = \log n$. $\blacksquare$

---

### 10-B. 연습 버전

**Step 1.** 최적화 문제:

$$\max_p\; \text{[빈칸 A]} \quad \text{s.t.} \quad \text{[빈칸 B]}$$

**Step 2.** Lagrangian:

$$\mathcal{L}(p,\lambda) = \text{[빈칸 C]}$$

**Step 3.** $\frac{\partial \mathcal{L}}{\partial p_j} = 0$:

$$\text{[빈칸 D]} = 0$$

(왜: [빈칸 E])

**Step 4.** $p_j = \text{[빈칸 F]}$

이 값이 모든 $j$에 대해 동일한 이유: [빈칸 G]

**Step 5.** $\sum p_j = 1$ 대입 → $p_j = \text{[빈칸 H]}$

**Step 6.** 최대임의 근거: [빈칸 I]

**결론**: $H_{\max} = \text{[빈칸 J]}$

---

### 10-C. 정답표

| 빈칸 | 정답 |
|------|------|
| A | $-\sum_{i=1}^{n} p_i \log p_i$ (엔트로피) |
| B | $\sum_{i=1}^{n} p_i = 1$, $p_i \geq 0$ |
| C | $-\sum p_i \log p_i - \lambda(\sum p_i - 1)$ |
| D | $-\log p_j - 1 - \lambda$ |
| E | $\frac{d}{dp}(-p\log p) = -\log p - 1$ |
| F | $e^{-(1+\lambda)}$ |
| G | 우변에 $j$가 나타나지 않으므로 모든 $j$에 동일한 값 |
| H | $1/n$ |
| I | $H$는 오목(concave) 함수 ($-p\log p$의 이계도함수 $= -1/p < 0$), 오목 함수의 정상점 = 전역 최대 |
| J | $\log n$ |
