# 6주차 — Hypothesis Space Restriction = MAP 통합 시각 (왕초보용 단계별 설명)

> 원본: `dl_study.md`
> 이 문서는 수학·확률을 한 번도 배운 적 없는 사람이라도 끝까지 읽을 수 있도록, 각 단계가 **왜** 그런 모양이 되는지부터 풀어 쓴 자료다.

---

## 0. 가장 먼저 — 이 단원이 풀려는 문제

여러분이 컴퓨터에게 "이 사진이 고양이인지 강아지인지 맞춰봐" 라고 시킨다고 하자. 컴퓨터 안에는 **숫자 다이얼들** (이걸 θ "쎄타"라 부른다) 이 잔뜩 있고, 다이얼을 어떻게 맞추느냐에 따라 정답률이 달라진다.

질문: **다이얼을 어떻게 맞추는 게 가장 좋은가?**

답을 찾는 방식이 세 가지가 있는데, 이 6주차 자료의 결론은:
> **"세 가지 방식이 사실은 똑같은 것이다."**

이걸 5분 만에 보여주는 게 이 단원의 목적이다. 차근차근 가자.

---

## 1단계. MAP — "데이터 + 사전 믿음"으로 다이얼 맞추기

### 1-1. 등장 인물 4명

| 기호 | 읽기 | 의미 |
|---|---|---|
| `θ` | 쎄타 | **다이얼 위치** (모델의 파라미터) |
| `D` | 데이터 | **우리가 본 학습 데이터** |
| `P(D \| θ)` | "다이얼이 θ일 때 D가 나올 확률" | **우도(likelihood)**. 다이얼을 θ에 놓았을 때 이 데이터가 관측될 가능성 |
| `P(θ)` | "다이얼이 θ일 확률" | **사전(prior)**. 데이터를 보기 전 우리가 갖고 있던 다이얼에 대한 믿음 |
| `P(θ \| D)` | "데이터를 보고 난 뒤 다이얼이 θ일 확률" | **사후(posterior)** |

> 💡 핵심: 우리가 **알고 싶은 것**은 `P(θ|D)` (데이터 보고 난 뒤 어디가 정답?), 우리가 **계산할 수 있는 것**은 `P(D|θ)` 와 `P(θ)`.

### 1-2. 베이즈 정리 — 왜 곱셈인가?

$$
P(\theta\mid D) = \frac{P(D\mid\theta)\,P(\theta)}{P(D)}.
$$

직관: "데이터를 본 뒤의 믿음" = "데이터 보기 전 믿음" × "그 믿음이 데이터를 얼마나 잘 설명하나" ÷ "데이터의 전체 그럴듯함".

분모 `P(D)` 는 **θ에 대한 함수가 아니다** (이미 본 데이터의 전체 확률, 그냥 숫자 하나). 그래서:
- "어느 θ가 가장 큰 P(θ|D)를 주나?"를 찾을 때 분모는 **무시 가능**.
- 그래서 비례식으로 쓴다: `P(θ|D) ∝ P(D|θ)·P(θ)`.

### 1-3. MAP 정의

> **MAP** = Maximum A Posteriori = "사후 확률을 가장 크게 만드는 θ".

$$
\hat\theta_{\text{MAP}} = \arg\max_\theta P(\theta\mid D) = \arg\max_\theta P(D\mid\theta)\cdot P(\theta).
$$

`arg max` 는 "최댓값을 만드는 그 θ값"이라는 뜻. (값 자체가 아니라 위치를 묻는다.)

### 1-4. 왜 log를 씌우나?

곱셈은 미분·계산하기 어렵다. 그런데 `log(A·B) = log A + log B`. **곱이 합으로 변한다.**

또 `log` 함수는 단조증가 — 즉 A가 클수록 log A도 큼. 그래서 "A를 가장 크게 하는 θ"와 "log A를 가장 크게 하는 θ"는 **똑같다**. 위험 없이 log를 씌울 수 있다.

$$
\hat\theta_{\text{MAP}} = \arg\max_\theta\big[\log P(D\mid\theta) + \log P(\theta)\big].
$$

### 1-5. 왜 부호를 뒤집어 "loss"로 만드나?

기계학습은 보통 **"손실(loss)을 최소화"** 하는 형태로 이야기한다 (관습). `arg max f` 와 `arg min (-f)` 는 같다 (큰 값을 찾는 거나, 음수로 만든 뒤 작은 값을 찾는 거나).

$$
\hat\theta_{\text{MAP}} = \arg\min_\theta\big[\underbrace{-\log P(D\mid\theta)}_{\text{데이터 손실}} + \underbrace{-\log P(\theta)}_{\text{정규화}}\big].
$$

📌 **이 줄의 메시지**: **"prior(사전 믿음) = regularizer(정규화 항)"**. 이게 6주차의 가장 중요한 통찰.

## 2단계. "세 가지 시각이 사실 하나" — 같은 것을 부르는 세 가지 이름

| 시각 | 분야 | 부르는 이름 | 직관 |
|---|---|---|---|
| 확률론적 | 통계학 | **prior** `P(θ)` | "θ는 보통 0 근처에 있을 거야" 같은 사전 믿음 |
| 최적화 | 수치해석 | **regularizer** `R(θ)` | "θ가 너무 크면 페널티를 주자" |
| 학습이론 | ML 이론 | **가설공간 H 제한** | "고려할 모델의 종류 자체를 좁히자" |

세 가지가 **수학적으로 같다**는 게 핵심. 세 가지 언어로 같은 한 가지를 말하고 있을 뿐.

> 🎯 **이걸 알면 좋은 점**: 어떤 강의·논문에서 "L2 regularization 추가"라 하든, "Gaussian prior 사용"이라 하든, "weight를 작은 영역으로 제한"이라 하든 — **모두 같은 짓** 임을 즉시 알 수 있다.

## 3단계. Prior 종류별로 — 어떤 R(θ)가 나오나?

### (a) Gaussian Prior → L2 정규화 (Ridge)

**가정**: "θ는 0 주위에 종 모양으로 분포 (큰 값일 가능성 낮음)".

수식:
$$
P(\theta) = \mathcal N(0, \sigma^2 I) \propto \exp\!\Big(-\frac{\|\theta\|^2}{2\sigma^2}\Big).
$$

`-log` 를 씌우면:
$$
-\log P(\theta) = \frac{1}{2\sigma^2}\|\theta\|_2^2 + \text{상수}.
$$

상수는 θ에 무관하므로 무시. 결과:
$$
R(\theta) = \lambda \|\theta\|_2^2,\quad \lambda = \frac{1}{2\sigma^2}.
$$

`‖θ‖² = θ₁² + θ₂² + …` 모든 다이얼의 제곱합. **큰 다이얼에 더 큰 페널티.**

🔎 **σ와 λ의 관계**: 
- σ가 작다 = "θ가 0에서 크게 벗어나지 않을 거야" 라는 강한 믿음 → λ가 크다 = 강한 정규화.
- σ가 크다 = "θ는 어디든 갈 수 있어" → λ가 작다 = 약한 정규화.

### (b) Laplace Prior → L1 정규화 (Lasso)

**가정**: "θ는 정확히 0일 가능성이 매우 높고, 0이 아니면 좀 떨어져 있다" (뾰족한 분포).

수식:
$$
P(\theta) \propto \exp\!\Big(-\frac{\|\theta\|_1}{b}\Big).
$$

`-log` 를 씌우면:
$$
-\log P(\theta) = \frac{1}{b}\|\theta\|_1 + \text{상수}.
$$

`‖θ‖₁ = |θ₁| + |θ₂| + …` 다이얼의 **절댓값 합**.

🌟 **L1의 마법 — Sparsity**: L1 정규화는 종종 **일부 θᵢ를 정확히 0으로 만든다**. 즉 "이 특징(feature)은 무시해도 좋아"라고 자동 선택해준다 → **자동 변수 선택(feature selection)**.

### (c) Uniform Prior → MLE (정규화 없음)

**가정**: "θ가 어디 있을지 전혀 모르겠다, 모든 위치가 똑같이 가능하다".

`P(θ)` = 상수 → `-log P(θ)` = 상수 → **θ에 영향 없음**.

결과:
$$
\hat\theta_{\text{MAP}} = \arg\min_\theta -\log P(D\mid\theta) = \arg\max_\theta P(D\mid\theta) = \hat\theta_{\text{MLE}}.
$$

> ✅ 이걸 보면 **MLE는 "Uniform prior를 쓴 MAP"** 이라는 걸 알 수 있다. MLE는 MAP의 특수한 한 경우.

⚠️ Uniform prior는 정규화가 없어 데이터가 적을 때 **과적합(overfitting)** 위험이 큼.

## 4단계. 핵심 한 줄 + λ가 뭘 결정하나

> **MAP은** likelihood(데이터 적합도)만 최대화하지 않고, **prior로 "θ가 있을 만한 영역"을 미리 좋아하는 영역으로 정해놓고**, 그 안에서 best fit을 찾는 것이다.

`λ` (정규화 세기) 가 학습 결과를 결정한다:

| λ | 의미 | 결과 |
|---|---|---|
| λ → 0 | prior 거의 무시, 데이터가 모든 것 | MAP → MLE, 가설공간 H 전체 탐색, **과적합 위험** |
| λ → ∞ | prior가 모든 것, 데이터 거의 무시 | MAP → prior의 mode (예: 0), 항상 같은 답, **과소적합** |
| 중간 | 데이터와 prior의 균형 | **bias-variance tradeoff** 의 sweet spot |

📌 즉 **λ는 "내가 데이터를 얼마나 신뢰하나" 다이얼**. 클수록 사전 믿음 신뢰, 작을수록 데이터 신뢰.

## 5단계. 기하학적 그림 — 왜 L1은 sparse하고 L2는 안 그런가?

### 두 가지 표현은 동치다

원래 식 (페널티 형태):
$$
\min_\theta\;\big[-\log P(D\mid\theta) + \lambda R(\theta)\big].
$$

이건 다음 **제약 형태**와 같다 (Lagrangian 쌍대):
$$
\min_\theta -\log P(D\mid\theta)\quad\text{단, } \|\theta\|\le C.
$$

→ "데이터 손실을 최소화하되, θ가 크기 C인 영역을 벗어나지 마라."

### 그림으로 보면

평면(2차원 θ) 위에 두 가지가 그려진다:
1. **Likelihood 등고선**: 데이터 손실의 등고선. 가운데가 MLE 답, 동심원 모양.
2. **제약 영역**: `‖θ‖ ≤ C`.
   - **L2 (Ridge)** : 원/공 모양 (둥글둥글)
   - **L1 (Lasso)** : 마름모 모양 (꼭짓점이 축 위에 있음)

해는 **두 영역의 첫 접촉점**.

#### L2의 경우 (원)
- 등고선과 원이 매끈하게 만난다.
- 접점은 어떤 위치든 가능 → θ가 0이 될 일이 별로 없음 → **모든 다이얼이 작아질 뿐**, 0은 안 됨.

#### L1의 경우 (마름모)
- 마름모는 **축 위에 꼭짓점**이 있다. 등고선이 꼭짓점을 만날 확률이 높음.
- 꼭짓점 = 어떤 좌표가 0인 점 → **일부 θᵢ가 정확히 0** → sparsity.

### C 와 가설공간의 관계
- C ↓ (영역 작게) → 가설공간 H ↓ → variance ↓ (안정적), bias ↑ (덜 정확)
- C ↑ (영역 크게) → H ↑ → variance ↑, bias ↓
- → **bias-variance tradeoff**가 C(또는 λ)로 조절됨.

## 6단계. 시험 포인트 — 무엇을 외워야 하나

### ① MAP = MLE + log-prior 유도 (필수)
백지에서 다음을 5단계로:
1. `θ̂ = argmax P(θ|D)`
2. = `argmax P(D|θ)·P(θ)` (베이즈, 분모 무시)
3. = `argmax [log P(D|θ) + log P(θ)]` (log 단조증가)
4. = `argmin [-log P(D|θ) - log P(θ)]` (부호 반전)
5. = `argmin [data loss + R(θ)]` (명명)

### ② 두 가지 prior → 두 가지 정규화
- Gaussian prior → L2 (`λ‖θ‖²`)
- Laplace prior → L1 (`λ‖θ‖₁`)
- 유도까지 쓸 수 있어야 함 (PDF에 `-log` 씌우기).

### ③ λ ↔ σ 관계
$$
\lambda = \frac{1}{2\sigma^2}.
$$
σ 작다 ↔ λ 크다 ↔ 강한 정규화.

### ④ H 제한의 두 형태와 동치성
- **명시적 제약**: `s.t. ‖θ‖ ≤ C`
- **암묵적 페널티**: `+ λR(θ)`
- 두 형태는 **Lagrangian 쌍대성**으로 동치.

### ⑤ MAP은 mode이지 평균이 아님
사후분포의 **최빈값(mode)**이지 기댓값(mean)이 아니다:
$$
\hat\theta_{\text{MAP}} = \arg\max_\theta P(\theta\mid D) \;\neq\; \mathbb E[\theta\mid D] = \int\theta\,P(\theta\mid D)\,d\theta.
$$
(분포가 비대칭이면 둘이 다른 값. 시험에 잘 나옴.)

## 부록. 한 페이지 요약 (인쇄용)

```
[ MAP의 정수 ]

θ̂_MAP = argmax P(θ|D)
       = argmax P(D|θ)·P(θ)             (베이즈)
       = argmax [log P(D|θ) + log P(θ)] (log)
       = argmin [-log P(D|θ) - log P(θ)] (부호)
       = argmin [data loss + R(θ)]      (명명)

[ Prior → Regularizer 매핑 ]

Gaussian N(0, σ²) ─→ L2:  R(θ) = (1/2σ²)‖θ‖²    (Ridge)
Laplace exp(-|θ|/b) ─→ L1:  R(θ) = (1/b)‖θ‖₁     (Lasso, sparse)
Uniform           ─→ 없음:  R(θ) = const        (= MLE)

[ 세 시각의 동치 ]

prior P(θ)  ⟺  regularizer R(θ)  ⟺  H 제한 ‖θ‖≤C

[ λ가 결정하는 것 ]

λ → 0 :  MLE,      과적합
λ → ∞ :  prior,     과소적합
중간   :  bias-var sweet spot
```
