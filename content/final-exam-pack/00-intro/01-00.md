# 기말고사 공부 전략

> 교수님 공지 기반 역설계 학습 플랜
> 핵심 메시지: **"퀴즈 암기 ❌ → 인덕티브 바이어스(Inductive Bias) 중심의 깊은 이해 ✅"**

---

## 1. 공지 핵심 요약 (반드시 내재화)

| 항목 | 내용 | 학습 함의 |
| --- | --- | --- |
| 시험 형식 | 중간고사와 유사 | 중간 시험지 형식·문항 구조 그대로 복기 |
| 문제 수 | 중간보다 다소 적음 | 문제당 비중 ↑ → 한 문제 실수 = 큰 감점 |
| 출제 방식 ① | 중간고사 문제 동일/약간 변형 (≈33%) | **중간고사 전 문항 100% 재현 가능 수준 학습** |
| 출제 방식 ② | 최적화·신경망·선형모델 + 오늘 배운 내용을 **연결**, 인덕티브 바이어스 같은 **큰 뼈대 개념**의 깊은 이해 (≈66%) | 단원별 암기 ❌ / 개념 간 다리(bridge) 만들기 ✅ |

**비중 해석**: 1/3은 "확정 점수"(중간 복습), 2/3은 "개념 통합 서술". 즉 **중간 만점 + 통합 이해**가 최소 안전선.

---

## 2. 학습 우선순위 (Pareto)

```
[Priority 1] 중간고사 전 문항 완전 정복         ← 33% 확보
[Priority 2] 인덕티브 바이어스 종축 정리         ← 66%의 척추
[Priority 3] 최적화 ↔ 신경망 ↔ 선형모델 연결    ← 66%의 살
[Priority 4] "오늘 배운 내용"(최근 강의) 흡수     ← 연결의 한쪽 끝
[Priority 5] 변형 대비 (수식 부호·차원·가정 흔들기) ← 변별점
```

## 3. Phase별 학습 로드맵

### Phase A. 중간고사 재현 (Day 1–2, 30%)
- `midterm/` 디렉터리의 기출/모의고사 전 문항 **백지 풀이 → 답안 비교 → 오답노트**
- 핵심 산출물:
  - `midterm/05_오답노트_흔한실수.md` 갱신 (있으면 final/05_오답노트_흔한실수.md 재사용)
  - 각 문제에 대해 "왜 이 답인가?"를 **2문장 이내**로 설명 가능해야 통과
- 변형 대비 훈련:
  - 부호 바꾸기 (max ↔ min, +λ ↔ −λ)
  - 차원/축 바꾸기 (행 ↔ 열, batch axis 위치)
  - 가정 제거 (i.i.d. 빼면? convex 빼면?)
  - 활성함수/손실함수 교체

### Phase B. 인덕티브 바이어스 척추 세우기 (Day 2–4, 35%)

**정의 한 줄**: 학습자가 "보지 못한 데이터"에 일반화하기 위해 **데이터 외부에서 주입하는 가정**.

각 단원을 `(가설공간 H, 주입된 가정, 그 가정이 만드는 일반화 효과, 깨질 때 무엇이 망가지는가)` 4-tuple로 정리:

| 영역 | 인덕티브 바이어스 | 효과 | 깨지는 경우 |
| --- | --- | --- | --- |
| 선형 모델 | 입력-출력 관계가 **선형/affine** | 저분산·고편향, 외삽 안정 | 비선형 패턴에서 underfit |
| 정규화(L2/L1) | 작은 가중치 / 희소성 선호 | 일반화↑, feature selection | 진짜 큰 가중치가 필요한 문제 |
| 신경망(MLP) | 합성 함수 + 매끄러운 함수 선호 (SGD + 초기화) | 보편 근사 + implicit regularization | 구조적 사전이 강한 문제(이미지·시퀀스)에서 비효율 |
| CNN | **지역성 + 평행이동 등변성 + 가중치 공유** | 적은 데이터로 이미지 일반화 | 회전/스케일 변화 큰 데이터 |
| RNN/시퀀스 | 시간 불변성 + 마르코프성 가정 | 가변 길이 처리 | 장기 의존성 |
| Transformer | **순열 등변성 + content-based routing**, 위치 정보는 외부 주입 | 장거리 의존성 | 데이터/연산 비용↑ |
| 최적화(SGD) | flat minima 선호, 암묵적 정규화 | 일반화 격차 ↓ | 매우 sharp loss landscape |

**산출물**: `final/10_개념연결지도.md`에 본 표를 가설공간 다이어그램으로 확장.

### Phase C. 4대 축 연결 (Day 4–5, 20%)

핵심은 **"같은 현상을 4가지 언어로 말하기"**.

예시 문장 (시험 변형 대응 훈련):
1. **표현 관점**: "선형 모델은 H = {w·x+b}, MLP는 그 합성, CNN은 합성 + 가중치 공유."
2. **최적화 관점**: "선형 회귀는 convex → 전역해 보장, NN은 non-convex이지만 SGD의 flat-minima 바이어스가 일반화 보전."
3. **확률 관점**: "L2 정규화 = Gaussian prior MAP, 선형회귀 + Gaussian noise = MLE."
4. **일반화 관점**: "편향-분산 트레이드오프, 인덕티브 바이어스가 강할수록 편향↑·분산↓."

**연결 질문 자기 테스트**:
- Q1. "CNN의 평행이동 등변성이 깨지면 학습에 어떤 영향?"
- Q2. "Adam이 SGD보다 generalization이 나쁠 수 있는 이유를 인덕티브 바이어스로 설명."
- Q3. "선형모델의 ridge와 NN의 weight decay가 같은가? 무엇이 다른가?"
- Q4. "Transformer가 위치 인코딩을 외부에서 주입해야 하는 이유를 inductive bias 부재로 설명."

### Phase D. 최근 강의 흡수 (Day 5, 10%)

## 5. "변형 출제" 방어 체크리스트

문제를 풀기 전 자가 점검 5문항:
1. **가정 식별**: 이 문제에서 명시된/암묵적 가정은? (linearity, convexity, i.i.d., stationarity 등)
2. **가설공간**: 모델 H의 표현 한계는?
3. **손실/목적**: 무엇을 최소화/최대화? 정규화 항의 prior 의미는?
4. **최적화 동역학**: 누가 어떻게 최소점에 도달? flat vs sharp?
5. **일반화 다리**: 왜 train→test로 옮겨갈 수 있나? 어떤 inductive bias가 그 다리를 놓는가?

→ 5문항 모두 1문장으로 답할 수 있으면 변형되어도 흔들리지 않음.

## 6. 자주 빠지는 함정 (오답 패턴)

- "정규화 = overfitting 방지"만 외움 → **사전분포 = MAP 해석** 못 함
- "CNN은 이미지에 좋다"만 외움 → **등변성/지역성**으로 환원 못 함
- "Adam이 빠르다"만 외움 → **flat minima / 일반화 트레이드오프** 누락
- "Transformer는 attention" → **순열 등변성, 위치 인코딩 필요성** 누락
- 수식 외움 → **각 항의 의미·단위·차원** 설명 못 함
