# 딥러닝 이론 1페이지 치트시트 (시험 직전 최종 정리)

> **범위**: 1~4주차 | **채점**: 답만 적으면 0점, 유도의 **각 단계에 "왜"** 서술 필수

---

## 1. 선형대수 핵심 공식

| 공식 | 내용 |
|------|------|
| **Rank-Nullity** | $n = \text{rank}(A) + \text{nullity}(A)$ &nbsp; (입력차원 = 살아남는 차원 + 죽는 차원) |
| **Rank** | $\text{rank}(A) = \text{rank}(A^\top) = \text{rank}(A^\top A) = \text{rank}(AA^\top)$ |
| **고유분해** | $A = Q\Lambda Q^{-1}$ &nbsp; ($A$ 대칭이면 $Q$ 직교: $A = Q\Lambda Q^\top$) |
| **SVD** | $A = U\Sigma V^\top$ &nbsp; ($U$: 좌특이벡터, $\Sigma$: 특이값, $V$: 우특이벡터) |
| **유사역행렬** | $A^+ = V\Sigma^+ U^\top$ &nbsp; ($\Sigma^+$: 비제로 대각원소 역수) |
| **최소제곱해** | $x^* = A^+ b = (A^\top A)^{-1} A^\top b$ &nbsp; (full rank일 때) |
| **Trace 성질** | $\text{tr}(AB) = \text{tr}(BA)$, &nbsp; $\text{tr}(A^\top) = \text{tr}(A)$, &nbsp; $\text{tr}(A+B) = \text{tr}(A) + \text{tr}(B)$ |
| **행렬식** | $\det(AB) = \det(A)\det(B)$, &nbsp; $\det(A^{-1}) = 1/\det(A)$, &nbsp; $\det(A^\top) = \det(A)$ |

**노름 (Norm)**

| 노름 | 정의 | 용도 |
|------|------|------|
| $L_1$ | $\|\|x\|\|_1 = \sum_i \|x_i\|$ | Lasso (희소 유도) |
| $L_2$ | $\|\|x\|\|_2 = \sqrt{\sum_i x_i^2}$ | Ridge, 유클리드 거리 |
| $L_\infty$ | $\|\|x\|\|_\infty = \max_i \|x_i\|$ | 최대 원소 |
| Frobenius | $\|\|A\|\|_F = \sqrt{\text{tr}(A^\top A)}$ | 행렬 노름 |

## 2. 미적분 핵심 공식

**기본 정의**

| 개념 | 정의 |
|------|------|
| **Gradient** | $\nabla_x f = \left[\frac{\partial f}{\partial x_1}, \ldots, \frac{\partial f}{\partial x_n}\right]^\top \in \mathbb{R}^n$ |
| **Jacobian** | $J_{ij} = \frac{\partial f_i}{\partial x_j}$, &nbsp; $J \in \mathbb{R}^{m \times n}$ &nbsp; ($f: \mathbb{R}^n \to \mathbb{R}^m$) |
| **Hessian** | $H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$, &nbsp; $H \in \mathbb{R}^{n \times n}$ (대칭) |
| **Chain Rule** | $\frac{\partial f}{\partial x} = \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial x}$ &nbsp; (벡터: $J_f = J_{f \circ g} = J_f \cdot J_g$) |

**킬러 미분 공식 (반드시 암기)**

| 함수 | 미분 결과 |
|------|----------|
| $\frac{\partial}{\partial x}(a^\top x)$ | $a$ |
| $\frac{\partial}{\partial x}(x^\top A x)$ | $(A + A^\top)x$ &nbsp; ($A$ 대칭이면 $2Ax$) |
| $\frac{\partial}{\partial x}(x^\top S x)$ where $S=S^\top$ | $2Sx$ |
| $\frac{\partial}{\partial A}\text{tr}(AB)$ | $B^\top$ |
| $\frac{\partial}{\partial x}\|x - \mu\|^2$ | $2(x - \mu)$ |
| $\frac{\partial}{\partial x}\log(x)$ | $1/x$ (원소별) |

**Softmax & Jacobian**

$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

$$\frac{\partial \text{softmax}(z)_i}{\partial z_j} = \text{softmax}(z)_i(\delta_{ij} - \text{softmax}(z)_j)$$

## 3. 최적화 핵심

| 개념 | 공식/조건 |
|------|----------|
| **1차 필요조건** | $\nabla f(x^*) = 0$ |
| **2차 충분조건** | $\nabla f = 0$ 이고 $H \succ 0$ (양정치) → 극소 |
| **볼록함수** | $f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$ |
| **Jensen 부등식** | $f(\mathbb{E}[X]) \le \mathbb{E}[f(X)]$ &nbsp; ($f$ 볼록) |
| **Lagrangian** | $\mathcal{L}(x,\lambda) = f(x) + \sum_i \lambda_i g_i(x)$ |
| **KKT 조건** | ① $\nabla_x \mathcal{L} = 0$ &nbsp; ② $g_i(x) \le 0$ &nbsp; ③ $\lambda_i \ge 0$ &nbsp; ④ $\lambda_i g_i(x) = 0$ |
| **Newton's Method** | $x_{k+1} = x_k - H^{-1} \nabla f(x_k)$ |
| **Gradient Descent** | $x_{k+1} = x_k - \eta \nabla f(x_k)$ |

**볼록함수 판별 4가지** (동치):
1. 정의: $f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$
2. 1차 조건: $f(y) \ge f(x) + \nabla f(x)^\top(y-x)$ (접선이 항상 아래)
3. 2차 조건: $H = \nabla^2 f \succeq 0$ (반양정치)
4. Epigraph $\{(x,t): f(x) \le t\}$가 볼록 집합

## 4. 확률 핵심 공식

| 공식 | 내용 |
|------|------|
| **Bayes** | $P(A\|B) = \frac{P(B\|A)P(A)}{P(B)}$ &nbsp; → &nbsp; $\text{posterior} \propto \text{likelihood} \times \text{prior}$ |
| **주변화** | $P(X) = \sum_y P(X,Y=y)$ &nbsp; (연속: $\int$) |
| **조건부** | $P(X,Y) = P(X\|Y)P(Y)$ |
| **기댓값** | $\mathbb{E}[X] = \sum_x x \cdot P(x)$ &nbsp; / &nbsp; $\int x \cdot f(x)dx$ |
| **분산** | $\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ |
| **공분산** | $\text{Cov}(X,Y) = \mathbb{E}[XY] - \mathbb{E}[X]\mathbb{E}[Y]$ |
| **CLT** | $\bar{X}_n \xrightarrow{d} \mathcal{N}(\mu, \sigma^2/n)$ &nbsp; (n이 크면 평균은 정규분포) |

**주요 분포**

| 분포 | PDF/PMF | $\mathbb{E}$ | $\text{Var}$ |
|------|---------|---------------|--------------|
| $\text{Bern}(p)$ | $p^x(1-p)^{1-x}$ | $p$ | $p(1-p)$ |
| $\mathcal{N}(\mu,\sigma^2)$ | $\frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$ | $\mu$ | $\sigma^2$ |
| 다변량 정규 | $\frac{1}{(2\pi)^{d/2}\|\Sigma\|^{1/2}}\exp\left(-\frac{1}{2}(x-\mu)^\top\Sigma^{-1}(x-\mu)\right)$ | $\mu$ | $\Sigma$ |

**독립 vs 비상관**
- **독립**: $P(X,Y) = P(X)P(Y)$ → 비상관 (역은 성립 안 함!)
- **비상관**: $\text{Cov}(X,Y) = 0$ → 독립이 **아닐 수 있음** (정규분포일 때만 동치)

## 5. MLE / MAP 핵심

### MLE 유도 템플릿 (모든 문제에 적용)

$$\theta_{\text{MLE}} = \arg\max_\theta \prod_{i=1}^n P(x_i|\theta) \xrightarrow{\text{log}} \arg\max_\theta \sum_{i=1}^n \log P(x_i|\theta) \xrightarrow{\text{미분}=0} \text{풀기}$$

**핵심 체인**: i.i.d 가정 → 곱 → 로그로 합 변환 → 미분=0 → 해

| 모델 | MLE 결과 |
|------|---------|
| **Bernoulli** | $\hat{p} = k/n$ &nbsp; (표본평균) |
| **Gaussian ($\mu$)** | $\hat{\mu} = \frac{1}{n}\sum x_i$ &nbsp; (표본평균) |
| **Gaussian ($\sigma^2$)** | $\hat{\sigma}^2 = \frac{1}{n}\sum(x_i - \hat{\mu})^2$ &nbsp; (편향 추정량!) |

### MAP

$$\theta_{\text{MAP}} = \arg\max_\theta \left[\sum_i \log P(x_i|\theta) + \log P(\theta)\right]$$

| Prior | 효과 | 등가 정규화 |
|-------|------|-----------|
| $\theta \sim \mathcal{N}(0, \sigma^2)$ | $+\log P(\theta) = -\frac{\|\theta\|^2}{2\sigma^2} + C$ | **L2 (Ridge)** |
| $\theta \sim \text{Laplace}(0,b)$ | $+\log P(\theta) = -\frac{\|\theta\|_1}{b} + C$ | **L1 (Lasso)** |

> **MAP = MLE + Prior = Loss + Regularization** (이 등식이 시험 핵심!)

## 6. 정보이론 핵심

| 공식 | 정의 | 의미 |
|------|------|------|
| **엔트로피** | $H(p) = -\sum_x p(x)\log p(x)$ | 평균 불확실성 (비트) |
| **교차 엔트로피** | $H(p,q) = -\sum_x p(x)\log q(x)$ | $q$로 $p$를 코딩하는 비용 |
| **KL 발산** | $D_{KL}(p\|\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$ | 분포 차이 (비대칭!) |
| **관계식** | $H(p,q) = H(p) + D_{KL}(p\|\|q)$ | CE = 엔트로피 + KL |
| **KL 성질** | $D_{KL}(p\|\|q) \ge 0$, &nbsp; $= 0 \iff p = q$ | **Gibbs 부등식** |

**가우시안 KL** (VAE 등에서 사용):

$$D_{KL}\left(\mathcal{N}(\mu_1, \sigma_1^2) \| \mathcal{N}(\mu_2, \sigma_2^2)\right) = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

$q = \mathcal{N}(0,1)$일 때: $D_{KL} = -\frac{1}{2}\left(1 + \log\sigma^2 - \mu^2 - \sigma^2\right)$

## 7. 킬러 등식 체인 (시험 최다 출제)

```
┌─────────────────────────────────────────────────────────┐
│  Cross-Entropy Loss = NLL = -log P(data|θ)              │
│                     = H(p) + KL(p‖q)                    │
│                                                         │
│  MSE Loss ← Gaussian 가정 + MLE에서 유도됨              │
│  CE Loss  ← Bernoulli/Categorical 가정 + MLE에서 유도됨 │
│                                                         │
│  MAP = MLE + log Prior                                  │
│      = Loss + Regularization                            │
│                                                         │
│  L2 Reg = Gaussian Prior = Ridge                        │
│  L1 Reg = Laplace Prior  = Lasso                        │
└─────────────────────────────────────────────────────────┘
```

**유도 흐름 (CE Loss 예시)**:

$$\text{NLL} = -\sum_i \log P(y_i|x_i;\theta) = -\sum_i \left[y_i \log h_\theta(x_i) + (1-y_i)\log(1-h_\theta(x_i))\right] = \text{Binary CE}$$

**유도 흐름 (MSE 예시)**:

$$y_i \sim \mathcal{N}(f_\theta(x_i), \sigma^2) \Rightarrow \text{NLL} = \frac{1}{2\sigma^2}\sum_i(y_i - f_\theta(x_i))^2 + C \propto \text{MSE}$$

## 8. 동치 조건 모음

### 가역행렬 $A \in \mathbb{R}^{n \times n}$의 10가지 동치 조건

| # | 조건 |
|---|------|
| 1 | $A$는 가역 ($A^{-1}$ 존재) |
| 2 | $\det(A) \ne 0$ |
| 3 | $\text{rank}(A) = n$ |
| 4 | $\text{nullity}(A) = 0$ &nbsp; ($\mathscr{N}(A) = \{0\}$) |
| 5 | 열벡터들이 선형독립 |
| 6 | 행벡터들이 선형독립 |
| 7 | $Ax = b$가 모든 $b$에 대해 유일한 해 |
| 8 | $Ax = 0$의 해가 $x = 0$뿐 |
| 9 | 모든 고유값 $\lambda_i \ne 0$ |
| 10 | 모든 특이값 $\sigma_i > 0$ |

### 볼록함수 4가지 동치 조건

| # | 조건 |
|---|------|
| 1 | **정의**: $f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$, &nbsp; $\forall \lambda \in [0,1]$ |
| 2 | **1차**: $f(y) \ge f(x) + \nabla f(x)^\top(y - x)$, &nbsp; $\forall x, y$ (접선이 항상 아래) |
| 3 | **2차**: $\nabla^2 f(x) \succeq 0$, &nbsp; $\forall x$ (Hessian 반양정치) |
| 4 | **Epigraph**: $\text{epi}(f) = \{(x,t) : f(x) \le t\}$가 볼록 집합 |
