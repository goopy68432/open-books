**P3-1. (10점)** Derive MSE from Gaussian Likelihood
(가우시안 우도에서 MSE 유도)

Given a regression dataset $\{(x_i, y_i)\}_{i=1}^n$ and a model $h_\theta(x)$, assume the noise model:

$$y_i = h_\theta(x_i) + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2) \text{ i.i.d.}$$

(a) Write the likelihood $p(y_i | x_i, \theta)$ explicitly as a Gaussian density.
(b) Assuming i.i.d. observations, write the full joint likelihood $\mathcal{L}(\theta) = \prod_{i=1}^n p(y_i | x_i, \theta)$.
(c) Take the negative log-likelihood (NLL) and simplify.
(d) Show that minimizing NLL is equivalent to minimizing the mean squared error:

$$\text{MSE}(\theta) = \frac{1}{n} \sum_{i=1}^n (y_i - h_\theta(x_i))^2$$

(e) State clearly: at which step was the Gaussian assumption used, and what loss function would you get under a different noise model?

**P3-2. (10점)** Derive Cross-Entropy from Bernoulli Likelihood
(베르누이 우도에서 교차 엔트로피 유도)

Given a binary classification dataset $\{(x_i, y_i)\}_{i=1}^n$ with $y_i \in \{0, 1\}$, let the model output $\hat{p}_i = p(y_i = 1 | x_i, \theta) \in (0, 1)$.

(a) Write $p(y_i | x_i, \theta)$ using the Bernoulli PMF in a unified expression valid for both $y_i = 0$ and $y_i = 1$.
(b) Assuming i.i.d. observations, write the joint likelihood $\mathcal{L}(\theta)$.
(c) Take the log-likelihood and simplify.
(d) Show that maximizing log-likelihood is equivalent to minimizing binary cross-entropy:

$$\text{BCE}(\theta) = -\frac{1}{n}\sum_{i=1}^n \left[y_i \log \hat{p}_i + (1 - y_i)\log(1 - \hat{p}_i)\right]$$

(e) Explain the connection: "cross-entropy loss is not invented; it is derived."

**P3-3. (10점)** Derive L2 Regularization from MAP with Gaussian Prior
(가우시안 Prior의 MAP에서 L2 정규화 유도)

We want to estimate parameters $\theta \in \mathbb{R}^d$ from data. Instead of pure MLE, we use MAP estimation with a Gaussian prior on the parameters:

$$p(\theta) = \mathcal{N}(\theta; \mathbf{0}, \tau^2 I) = \prod_{j=1}^d \frac{1}{\sqrt{2\pi\tau^2}} \exp\!\left(-\frac{\theta_j^2}{2\tau^2}\right)$$

The data likelihood under Gaussian noise is:

$$p(\mathbf{y} | \mathbf{X}, \theta) = \prod_{i=1}^n \mathcal{N}(y_i; \theta^\top x_i, \sigma^2)$$

(a) Write the MAP objective: $\theta_{\text{MAP}} = \arg\max_\theta \left[\log p(\mathbf{y}|\mathbf{X},\theta) + \log p(\theta)\right]$.
(b) Expand and simplify the log-prior term $\log p(\theta)$.
(c) Show that the MAP objective reduces to:

$$\theta_{\text{MAP}} = \arg\min_\theta \left[\sum_{i=1}^n (y_i - \theta^\top x_i)^2 + \frac{\sigma^2}{\tau^2} \|\theta\|^2\right]$$

(d) Identify the regularization coefficient $\lambda = \sigma^2 / \tau^2$ and explain its role.
(e) Explain: "L2 regularization is not a trick; it is a prior belief." What does a small $\tau^2$ mean about our prior belief?

#### Q1 해설 — 행렬 = 선형변환, 고유벡터/고유값

**배점 분배**:
- 선형변환의 정의 (변환이 벡터를 다른 벡터로 보낸다는 설명): 1점
- 고유벡터/고유값의 정의 및 의미: 1점
- 딥러닝과의 연결 (왜 중요한지): 1점

**입문 풀이** (비유와 직관):

행렬을 "숫자 표"가 아니라 "공간을 변형하는 함수"로 생각하세요. 예를 들어 2×2 행렬은 평면 위의 모든 벡터를 새로운 위치로 이동시키는 변환입니다. 어떤 벡터들은 이 변환 후에도 방향이 바뀌지 않고 늘어나거나 줄어들기만 합니다. 그 특별한 방향이 고유벡터이고, 늘어나는 비율이 고유값입니다.

**중급 풀이** (수식과 단계별):

선형변환 $T: \mathbb{R}^n \to \mathbb{R}^n$은 행렬 $A \in \mathbb{R}^{n \times n}$에 의해 $T(\mathbf{v}) = A\mathbf{v}$로 표현됩니다. 이 변환의 "고유 방향"은 다음을 만족하는 벡터입니다:

$$A\mathbf{v} = \lambda\mathbf{v}$$

즉, 변환 후에도 방향이 유지되고 오직 크기(스케일)만 $\lambda$배 변합니다.

- 고유값 $\lambda$: 그 방향의 확대/축소 비율
- 고유벡터 $\mathbf{v}$: 변환에 불변인 방향

**고급 풀이** (엄밀한 유도 + 교안 연결):

행렬의 선형변환 해석은 딥러닝의 모든 레이어에 적용됩니다. Weight matrix $\mathbf{W}$는 입력 공간을 다른 표현 공간으로 변환하는 선형변환입니다. Attention의 key/query/value 행렬도 모두 선형변환입니다.

고유값이 중요한 이유:
- SVD 분해 시 대각 행렬의 원소가 실질적으로 "각 방향의 중요도"
- PageRank: 가장 중요한 방향이 가장 큰 고유값에 대응
- 최적화: Hessian의 고유값이 loss landscape의 곡률을 결정

**자주 하는 실수**:
- 고유벡터를 "고유한(unique) 벡터"로 오해하는 것. 고유벡터는 무수히 많을 수 있습니다(스칼라 배).
- 고유값 분해가 모든 행렬에 적용된다고 생각하는 것. 정방행렬에만 적용됩니다.

**남에게 설명하는 한 문장**: 행렬은 공간을 비틀고 늘리는 변환이며, 고유벡터는 그 변환에서 방향이 유지되는 축이고, 고유값은 그 축의 신축 비율이다.

**핵심 킬러 요약**: $A\mathbf{v} = \lambda\mathbf{v}$ → 방향 불변, 크기만 변함 → AI에서 "중요한 방향"의 수학적 표현

**결국 뭐가 중요한가 (3가지)**:
1. 행렬 = 선형변환 (숫자가 아니라 함수다)
2. 고유벡터 = 변환에 불변인 방향 (시스템의 본질적 축)
3. 고유값 = 그 방향에서의 스케일 (크면 클수록 중요한 방향)

---

#### Q2 해설 — Span, Basis, Dimension

**배점 분배**:
- span/basis/dimension의 정의: 각 0.5점 (합 1.5점)
- 세 개념의 관계 설명: 0.75점
- 선형독립이 필요한 이유: 0.75점

**입문 풀이**:

- **span**: 주어진 벡터들을 어떻게 조합해도 만들 수 있는 모든 벡터의 집합
- **basis**: 공간을 낭비 없이, 최소한의 벡터로 표현하는 집합
- **dimension**: 그 basis의 벡터 개수 = 공간의 "자유도"

선형독립이 필요한 이유: 만약 선형종속이면 어떤 벡터가 다른 벡터들의 조합으로 표현됩니다. 그러면 그 벡터는 "새로운 정보"를 제공하지 않으므로 basis에 포함될 자격이 없습니다.

**중급 풀이**:

공식 정의:
$$\text{span}(v_1, \ldots, v_k) = \{c_1 v_1 + \cdots + c_k v_k \mid c_i \in \mathbb{R}\}$$

선형독립 조건:
$$c_1 v_1 + \cdots + c_k v_k = \mathbf{0} \implies c_1 = \cdots = c_k = 0$$

Basis: span이 전체 공간 $V$이면서 선형독립인 최소 집합. 이때 basis의 크기가 dimension.

**고급 풀이**:

rank-nullity theorem과의 연결: 선형사상 $T: \mathbb{R}^n \to \mathbb{R}^m$에서 dim(image) + dim(kernel) = $n$. image의 basis는 "살아남은 방향들", kernel의 basis는 "소멸하는 방향들".

딥러닝에서: weight matrix $\mathbf{W} \in \mathbb{R}^{m \times n}$의 rank는 모델이 표현할 수 있는 독립적인 특징의 수.

**자주 하는 실수**: span과 basis를 혼동하는 것. span은 집합, basis는 최소 생성 집합. 모든 basis는 span을 생성하지만, span을 생성한다고 모두 basis는 아닙니다.

**남에게 설명하는 한 문장**: Span은 벡터들로 만들 수 있는 모든 것, basis는 그 공간을 중복 없이 표현하는 최소 집합이며, dimension은 그 집합의 크기다.

**핵심 킬러 요약**: Span → Basis (선형독립 + 전체 span) → Dimension (basis의 크기) → 이 셋은 하나의 구조를 세 각도로 본 것

**결국 뭐가 중요한가 (3가지)**:
1. Basis = 공간의 최소 기술 집합 (중복 없이, 빠짐 없이)
2. 선형독립 = 중복 없음의 수학적 표현
3. Dimension = 공간의 자유도 (AI에서 표현력과 직결)

#### Q7 해설 — Gradient와 Chain Rule

**배점 분배**:
- gradient의 정의 및 벡터적 의미: 1점
- chain rule의 역할 설명: 1점
- chain rule 없이는 무엇이 불가능한지: 1점

**입문 풀이**:

Gradient는 "함수가 가장 가파르게 증가하는 방향"을 가리키는 벡터입니다. 산 위에서 가장 급경사 방향이 gradient, 반대 방향이 gradient descent입니다.

Chain rule은 "합성함수의 미분 = 각 함수 미분의 곱"입니다. $f(g(x))$의 미분 = $f'(g(x)) \cdot g'(x)$. 신경망은 여러 레이어의 합성함수이므로, 맨 앞 레이어까지 gradient를 전달하려면 반드시 chain rule이 필요합니다.

**중급 풀이**:

Gradient 공식:
$$\nabla_\mathbf{w} L = \left(\frac{\partial L}{\partial w_1}, \frac{\partial L}{\partial w_2}, \ldots, \frac{\partial L}{\partial w_d}\right)^\top$$

Chain rule (backpropagation의 기초):
$$\frac{\partial L}{\partial w_j^{(\ell)}} = \frac{\partial L}{\partial a^{(\ell+1)}} \cdot \frac{\partial a^{(\ell+1)}}{\partial w_j^{(\ell)}}$$

Chain rule 없이는 gradient가 앞 레이어로 전달되지 않으므로, gradient descent를 실행할 수 없습니다. 즉, 딥러닝 학습 자체가 불가능합니다.

**고급 풀이**:

Jacobian과의 연결: 벡터-벡터 함수 $f: \mathbb{R}^m \to \mathbb{R}^n$의 미분은 야코비안 $J \in \mathbb{R}^{n \times m}$. Backpropagation은 이 야코비안들을 chain rule로 연결합니다:

$$\frac{\partial L}{\partial \mathbf{x}^{(1)}} = J_1^\top J_2^\top \cdots J_\ell^\top \frac{\partial L}{\partial \mathbf{a}^{(\ell+1)}}$$

**자주 하는 실수**: gradient가 "최소점 방향"이라고 오해. gradient는 최대 증가 방향, 최소화를 위해서는 gradient의 반대 방향으로 이동합니다.

**남에게 설명하는 한 문장**: Gradient는 loss가 가장 빠르게 증가하는 방향이고, chain rule은 그 gradient를 깊은 레이어까지 전달하는 수학적 메커니즘이다.

**핵심 킬러 요약**: Gradient → 방향 / Chain rule → 전달 / Gradient descent = 반대 방향으로 이동

**결국 뭐가 중요한가 (3가지)**:
1. Gradient = 다변수 함수에서 가장 가파른 증가 방향을 가리키는 벡터
2. Chain rule = 합성함수의 미분 법칙, 역전파의 수학적 근거
3. 이 둘 없이는 딥러닝 학습이 근본적으로 불가능

#### Q10 해설 — Bayes 정리

**배점 분배**:
- Bayes 정리 수식: 1점
- 각 항 정의 (prior, likelihood, posterior, evidence): 1점
- 믿음 갱신의 직관: 1점

**입문 풀이**:

베이즈 정리는 "새로운 증거를 보고 나면 기존 믿음이 얼마나 바뀌어야 하는가?"를 알려주는 공식입니다. 예를 들어, 의사가 환자를 보기 전에 갖는 판단(prior)이 검사 결과(likelihood)를 보고 나서 수정되어 최종 판단(posterior)이 됩니다.

**중급 풀이**:

$$P(H|E) = \frac{P(E|H) \cdot P(H)}{P(E)}$$

각 항 정의:
- $P(H)$: Prior — 데이터 $E$를 보기 전의 가설 $H$에 대한 믿음
- $P(E|H)$: Likelihood — 가설 $H$가 참일 때 데이터 $E$가 관측될 확률
- $P(H|E)$: Posterior — 데이터 $E$를 본 후 갱신된 가설 $H$에 대한 믿음
- $P(E)$: Marginal likelihood (Evidence) — 모든 가설을 고려한 데이터의 총 확률

$$P(E) = \int P(H) P(E|H) \, dH$$

믿음 갱신의 구조:
$$\text{Posterior} \propto \text{Likelihood} \times \text{Prior}$$

**고급 풀이**:

MLE와 MAP로의 연결:
- MLE: $P(H)$를 균등분포로 가정 → Prior term이 상수 → $\theta_{\text{MLE}} = \arg\max P(E|\theta)$
- MAP: $P(H)$를 비균등분포로 가정 → $\theta_{\text{MAP}} = \arg\max [P(E|\theta) \cdot P(\theta)]$

딥러닝에서: 각 학습 미니배치는 새로운 데이터 $E$. 모델 파라미터 $\theta$가 가설 $H$. 학습 = 베이지안 업데이트의 반복.

**자주 하는 실수**: Likelihood $P(E|H)$를 posterior $P(H|E)$로 혼동. 이 둘은 완전히 다릅니다. $P(\text{비가 오고 있을 때 구름}) \neq P(\text{구름이 있을 때 비가 옴})$.

**남에게 설명하는 한 문장**: 베이즈 정리는 새로운 증거를 본 후 믿음을 합리적으로 갱신하는 수학적 공식으로, Prior×Likelihood를 정규화하면 Posterior가 된다.

**핵심 킬러 요약**: $\text{Posterior} \propto \text{Likelihood} \times \text{Prior}$ — 이 한 줄로 MLE, MAP, 정규화, 딥러닝이 모두 연결됩니다.

**결국 뭐가 중요한가 (3가지)**:
1. Prior = 데이터 이전의 믿음 (inductive bias의 수학적 표현)
2. Likelihood = 데이터가 파라미터에 대해 주는 정보
3. Posterior = 두 정보의 합리적 결합 → 학습의 본질

#### P2-1 해설 — 고유값 계산

$$A = \begin{pmatrix} 4 & 1 \\ 2 & 3 \end{pmatrix}$$

**배점**: (a) 2점, (b) 2점, (c) 1점

**(a) 특성방정식**:

$$\det(A - \lambda I) = \det\begin{pmatrix} 4-\lambda & 1 \\ 2 & 3-\lambda \end{pmatrix} = 0$$

$$(4-\lambda)(3-\lambda) - (1)(2) = 0$$
$$\lambda^2 - 7\lambda + 12 - 2 = 0$$
$$\lambda^2 - 7\lambda + 10 = 0$$
$$(\lambda - 5)(\lambda - 2) = 0$$

$$\boxed{\lambda_1 = 5, \quad \lambda_2 = 2}$$

**(b) 고유벡터**:

$\lambda_1 = 5$:
$$(A - 5I)\mathbf{v} = \begin{pmatrix} -1 & 1 \\ 2 & -2 \end{pmatrix}\mathbf{v} = \mathbf{0}$$
$$-v_1 + v_2 = 0 \implies v_2 = v_1$$
$$\mathbf{v}_1 = \begin{pmatrix}1\\1\end{pmatrix}$$

$\lambda_2 = 2$:
$$(A - 2I)\mathbf{v} = \begin{pmatrix} 2 & 1 \\ 2 & 1 \end{pmatrix}\mathbf{v} = \mathbf{0}$$
$$2v_1 + v_2 = 0 \implies v_2 = -2v_1$$
$$\mathbf{v}_2 = \begin{pmatrix}1\\-2\end{pmatrix}$$

**(c) 검증**:

$$A\mathbf{v}_1 = \begin{pmatrix}4&1\\2&3\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}5\\5\end{pmatrix} = 5\begin{pmatrix}1\\1\end{pmatrix} = \lambda_1 \mathbf{v}_1 \checkmark$$

$$A\mathbf{v}_2 = \begin{pmatrix}4&1\\2&3\end{pmatrix}\begin{pmatrix}1\\-2\end{pmatrix} = \begin{pmatrix}2\\-4\end{pmatrix} = 2\begin{pmatrix}1\\-2\end{pmatrix} = \lambda_2 \mathbf{v}_2 \checkmark$$

**자주 하는 실수**: 특성방정식을 전개할 때 행렬식 계산 오류. 반드시 $ad - bc$로 계산.

#### P2-3 해설 — 베이즈 정리 (의료 검사)

**배점**: (a) 1.5점, (b) 1.5점, (c) 2점

**(a) 전확률 공식**:

$$P(\text{Test}^+) = P(\text{Test}^+|\text{D})P(\text{D}) + P(\text{Test}^+|\text{no D})P(\text{no D})$$
$$= 0.95 \times 0.01 + 0.05 \times 0.99$$
$$= 0.0095 + 0.0495 = \mathbf{0.059}$$

**(b) 베이즈 정리 적용**:

$$P(\text{D}|\text{Test}^+) = \frac{P(\text{Test}^+|\text{D}) \cdot P(\text{D})}{P(\text{Test}^+)} = \frac{0.95 \times 0.01}{0.059} = \frac{0.0095}{0.059} \approx \mathbf{0.161}$$

**(c) 해석**:

놀랍게도, 양성 판정을 받았어도 실제로 병이 있을 확률은 약 16.1%에 불과합니다. 왜냐하면:

1. **Prior (사전확률)이 매우 낮음**: 전체 인구의 1%만 병을 가짐
2. **Base rate fallacy**: 검사 정확도가 높아도 유병률이 낮으면 위양성이 실제 양성보다 훨씬 많음
3. 숫자로 보면: 1000명 중 10명 환자 → 9.5명 올바르게 양성. 990명 비환자 → 49.5명이 위양성. 양성 판정 총 59명 중 실제 환자는 9.5/59 ≈ 16.1%.

이것이 베이즈 정리의 핵심 통찰: Prior를 무시하면 posterior를 잘못 추론합니다.

**남에게 설명하는 한 문장**: Prior가 매우 낮으면(희귀 질병), 아무리 정확한 검사도 양성 결과 대부분이 위양성일 수 있다.

#### P2-4 해설 — Cross-Entropy 계산

#### P3-1 해설 — Gaussian → MSE 유도

**배점**: (a) 1점, (b) 1.5점, (c) 2점, (d) 4점, (e) 1.5점

**입문 이해**:

"왜 딥러닝에서 MSE를 쓰냐?"는 "오차가 가우시안 분포를 따른다고 가정했기 때문"입니다. MSE는 자연에서 만들어진 손실함수입니다.

**중급 유도**:

**(a) Likelihood**:

$$p(y_i | x_i, \theta) = \mathcal{N}(y_i; h_\theta(x_i), \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - h_\theta(x_i))^2}{2\sigma^2}\right)$$

**(b) Joint likelihood (i.i.d.)**:

$$\mathcal{L}(\theta) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(y_i - h_\theta(x_i))^2}{2\sigma^2}\right)$$

**(c) Negative Log-Likelihood**:

$$-\log \mathcal{L}(\theta) = -\sum_{i=1}^n \log\frac{1}{\sqrt{2\pi\sigma^2}} + \sum_{i=1}^n \frac{(y_i - h_\theta(x_i))^2}{2\sigma^2}$$

$$= \underbrace{\frac{n}{2}\log(2\pi\sigma^2)}_{\text{$\theta$와 무관한 상수}} + \frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - h_\theta(x_i))^2$$

**(d) MSE 등치 유도**:

$\theta$에 대해 NLL를 최소화할 때, 상수항을 버리면:

$$\arg\min_\theta \text{NLL} = \arg\min_\theta \frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - h_\theta(x_i))^2$$

$\frac{1}{2\sigma^2}$는 양의 상수이므로 최적화 결과에 영향 없음:

$$= \arg\min_\theta \sum_{i=1}^n (y_i - h_\theta(x_i))^2 = \arg\min_\theta \text{MSE}(\theta) \cdot n$$

$$\therefore \arg\min_\theta \text{NLL} = \arg\min_\theta \text{MSE}(\theta) \quad \checkmark$$

**(e) 분석**:

- 가우시안 가정이 사용된 단계: (a)에서 likelihood를 가우시안으로 작성할 때
- 다른 분포를 쓴다면: 라플라스 분포 → L1 손실(MAE), 베르누이 → Cross Entropy

**고급 관점**:

MSE는 오류 분포가 Gaussian이라는 가정을 내포합니다. 데이터에 이상치(outlier)가 많다면 라플라스 분포 가정이 더 적절하고, 이때 L1 손실이 나옵니다. 손실함수 선택은 취향이 아니라 noise model 선택입니다.

**자주 하는 실수**:
1. 상수항($\frac{n}{2}\log(2\pi\sigma^2)$)을 버리는 이유를 설명하지 못하는 것
2. i.i.d. 가정이 곱을 허용하는 이유를 명시하지 않는 것
3. 최대화 → 최소화 변환(부호 반전)을 빠뜨리는 것

**남에게 설명하는 한 문장**: MSE는 오차가 Gaussian을 따른다는 noise model 가정에서 MLE를 적용했을 때 자연스럽게 유도되는 손실함수다.

**핵심 킬러 요약**: Gaussian i.i.d. → NLL = const + $\frac{1}{2\sigma^2}$MSE → 상수 제거 → MSE 최소화

**결국 뭐가 중요한가 (3가지)**:
1. 손실함수는 임의가 아니라 noise model에서 유도됨
2. i.i.d. 가정 → 곱 → 로그 → 합 (계산 가능)
3. Gaussian → MSE, Bernoulli → CE, 다른 분포 → 다른 손실

#### P3-2 해설 — Bernoulli → Cross Entropy 유도

**배점**: (a) 1점, (b) 1.5점, (c) 2점, (d) 4점, (e) 1.5점

**입문 이해**:

"왜 분류에서 cross entropy를 쓰냐?"는 "예측값이 이진 결과의 확률이라고 가정했기 때문"입니다.

**중급 유도**:

**(a) Bernoulli PMF (통합 표현)**:

$$p(y_i | x_i, \theta) = \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1-y_i}$$

이 표현은 $y_i = 1$이면 $\hat{p}_i$, $y_i = 0$이면 $1 - \hat{p}_i$를 반환합니다.

**(b) Joint likelihood**:

$$\mathcal{L}(\theta) = \prod_{i=1}^n \hat{p}_i^{y_i} (1 - \hat{p}_i)^{1-y_i}$$

**(c) Log-likelihood**:

$$\log \mathcal{L}(\theta) = \sum_{i=1}^n \left[y_i \log \hat{p}_i + (1-y_i)\log(1 - \hat{p}_i)\right]$$

**(d) Cross-entropy와의 연결**:

$$\arg\max_\theta \log \mathcal{L} = \arg\max_\theta \sum_{i=1}^n \left[y_i \log \hat{p}_i + (1-y_i)\log(1 - \hat{p}_i)\right]$$

부호를 뒤집어 최소화 문제로:

$$= \arg\min_\theta \left[-\frac{1}{n}\sum_{i=1}^n \left(y_i \log \hat{p}_i + (1-y_i)\log(1 - \hat{p}_i)\right)\right] = \arg\min_\theta \text{BCE}(\theta) \quad \checkmark$$

**(e) 철학적 의미**:

"Cross-entropy loss is not invented; it is derived." Cross entropy는 Bernoulli 분포 아래 MLE를 적용했을 때 자동으로 등장합니다. 임의로 선택된 손실함수가 아닙니다. 이 연결 덕분에 cross entropy를 최소화하는 것이 데이터의 확률분포를 올바르게 모델링한다는 통계적 의미를 갖습니다.

**자주 하는 실수**:
1. $\hat{p}_i^{y_i}(1-\hat{p}_i)^{1-y_i}$라는 통합 표현을 쓰지 않고 case를 나눔
2. log를 취할 때 지수가 계수로 내려오는 것을 명시하지 않음

**남에게 설명하는 한 문장**: BCE는 이진 출력을 Bernoulli로 모델링했을 때 MLE에서 자동으로 유도되는 손실함수다.

**핵심 킬러 요약**: $y \in \{0,1\}$ → Bernoulli PMF → Log → Sum → 부호 반전 → BCE

**결국 뭐가 중요한가 (3가지)**:
1. 통합 표현 $\hat{p}^y(1-\hat{p})^{1-y}$가 핵심 — 두 경우를 하나로
2. MLE = 로그우도 최대화 = CE 최소화 (완전히 동치)
3. 분류 문제에서 CE를 쓰는 이유는 분류가 Bernoulli/Categorical이기 때문

#### P3-3 해설 — MAP → L2 정규화 유도

**배점**: (a) 1점, (b) 2점, (c) 4점, (d) 1.5점, (e) 1.5점

**입문 이해**:

L2 정규화($\|\theta\|^2$를 loss에 더하는 것)는 "파라미터가 0 근처에 있어야 한다"는 사전 믿음을 수학으로 표현한 것입니다.

**중급 유도**:

**(a) MAP objective**:

$$\theta_{\text{MAP}} = \arg\max_\theta [\underbrace{\log p(\mathbf{y}|\mathbf{X},\theta)}_{\text{log-likelihood}} + \underbrace{\log p(\theta)}_{\text{log-prior}}]$$

**(b) Log-prior 전개**:

$$\log p(\theta) = \log \prod_{j=1}^d \frac{1}{\sqrt{2\pi\tau^2}} \exp\!\left(-\frac{\theta_j^2}{2\tau^2}\right)$$

$$= -\frac{d}{2}\log(2\pi\tau^2) - \frac{1}{2\tau^2}\sum_{j=1}^d \theta_j^2$$

$$= \underbrace{-\frac{d}{2}\log(2\pi\tau^2)}_{\text{상수}} - \frac{1}{2\tau^2}\|\theta\|^2$$

**(c) MAP 목적함수 결합**:

$$\theta_{\text{MAP}} = \arg\max_\theta \left[-\frac{1}{2\sigma^2}\sum_i (y_i - \theta^\top x_i)^2 - \frac{1}{2\tau^2}\|\theta\|^2 + \text{const}\right]$$

부호 반전 (최대화 → 최소화):

$$= \arg\min_\theta \left[\frac{1}{2\sigma^2}\sum_i (y_i - \theta^\top x_i)^2 + \frac{1}{2\tau^2}\|\theta\|^2\right]$$

$\frac{1}{2\sigma^2}$을 상수로 묶으면:

$$= \arg\min_\theta \left[\sum_i (y_i - \theta^\top x_i)^2 + \underbrace{\frac{\sigma^2}{\tau^2}}_{\lambda}\|\theta\|^2\right] \quad \checkmark$$

**(d) 정규화 계수 해석**:

$$\lambda = \frac{\sigma^2}{\tau^2}$$

- $\sigma^2$가 크면(noise가 크면) → $\lambda$가 커짐 → 정규화가 강해짐 → 파라미터를 더 강하게 0으로 당김
- $\tau^2$가 크면(prior가 약하면, 파라미터가 퍼져있어도 된다고 믿으면) → $\lambda$가 작아짐 → 정규화 약화

**(e) 철학적 의미**:

"L2 regularization is not a trick; it is a prior belief."

작은 $\tau^2$는 "파라미터가 0 근처에 있을 것이다"라는 강한 믿음입니다. 이것은 모델의 복잡도를 제한하는 inductive bias입니다. 데이터가 많아질수록 likelihood term이 prior term을 압도하여 정규화 효과가 줄어듭니다.

**자주 하는 실수**:
1. Prior의 log를 취할 때 지수 항을 제대로 전개하지 않음
2. 상수항을 최적화 결과에 포함시키는 실수
3. $\lambda = \sigma^2/\tau^2$의 분모/분자를 뒤집는 실수

**남에게 설명하는 한 문장**: L2 정규화는 파라미터가 Gaussian prior를 따른다는 MAP 추정의 수학적 결과물로, 손실에 더하는 페널티가 아니라 확률적 믿음의 표현이다.

**핵심 킬러 요약**: Gaussian prior → $\log p(\theta) = \text{const} - \frac{1}{2\tau^2}\|\theta\|^2$ → MAP objective → L2 regularization

**결국 뭐가 중요한가 (3가지)**:
1. Gaussian prior = "파라미터가 0 근처에 있다"는 사전 믿음
2. MAP = MLE + log-prior → MSE + L2 regularization
3. $\lambda = \sigma^2/\tau^2$: noise 강도 / prior 폭의 비율

#### P4-2 해설 — MLE vs MAP vs 정규화

**배점**: (a) 2점, (b) 3점, (c) 3점, (d) 2점

**(a) MLE 유도**:

$$\log P(\text{data}|\theta) = k\log\theta + (n-k)\log(1-\theta)$$

$$\frac{d}{d\theta}[\log P] = \frac{k}{\theta} - \frac{n-k}{1-\theta} = 0$$

$$k(1-\theta) = (n-k)\theta$$
$$k - k\theta = n\theta - k\theta$$
$$k = n\theta$$

$$\boxed{\theta_{\text{MLE}} = \frac{k}{n} = \frac{4}{5} = 0.8}$$

**(b) MAP 유도**:

Prior $p(\theta) = 6\theta(1-\theta)$이므로 $\log p(\theta) = \log 6 + \log\theta + \log(1-\theta)$.

$$\log\text{post} = k\log\theta + (n-k)\log(1-\theta) + \log\theta + \log(1-\theta) + \text{const}$$
$$= (k+1)\log\theta + (n-k+1)\log(1-\theta) + \text{const}$$

미분 = 0:
$$\frac{k+1}{\theta} - \frac{n-k+1}{1-\theta} = 0$$
$$(k+1)(1-\theta) = (n-k+1)\theta$$
$$k+1 = (n+2)\theta$$

$$\boxed{\theta_{\text{MAP}} = \frac{k+1}{n+2} = \frac{5}{7} \approx 0.714}$$

**(c) 표 완성**:

| Framework | Objective | $\theta^*$ | Interpretation |
|---|---|---|---|
| MLE | $\arg\max \log P(\text{data}\|\theta)$ | 0.8 | 순수 데이터 기반 |
| MAP | $\arg\max [\log P + \log p(\theta)]$ | 0.714 | Prior가 0.5 방향으로 당김 |
| L2 Reg | $\arg\min [-\log P + \lambda\|\theta - 0.5\|^2]$ | 0.5와 0.8 사이 | Prior 강도에 따른 수축 |

**(d) 점근 분석**:

$n \to \infty$: Likelihood term이 prior를 압도 → MLE ≈ MAP → 둘의 차이 소멸. "데이터가 많으면 prior는 잊힌다."

$n \to 0$: 데이터가 없어 likelihood가 평평 → Prior가 모든 결정. MAP가 더 신뢰할만한 추정치를 줌. "데이터가 적을수록 prior의 역할이 커진다."

**남에게 설명하는 한 문장**: MLE는 데이터만, MAP는 데이터+믿음, 정규화는 MAP의 특수한 경우이며, 데이터가 많아질수록 셋의 결과는 수렴한다.

#### P2-2 해설 (SET B) — Chain Rule과 역전파

$$\sigma^2_{\text{MLE}} = \frac{1}{5}\sum_{i=1}^5 (x_i - 4)^2 = \frac{(2-4)^2 + 0 + 0 + 0 + (6-4)^2}{5} = \frac{4 + 4}{5} = \mathbf{1.6}$$

**(d) 편향성**:

$$\mathbb{E}[\sigma^2_{\text{MLE}}] = \frac{n-1}{n}\sigma^2 = \frac{4}{5}\sigma^2 \neq \sigma^2$$

$\sigma^2_{\text{MLE}}$는 편향 추정량입니다. 불편 추정량:

$$\hat{\sigma}^2_{\text{unb}} = \frac{n}{n-1}\sigma^2_{\text{MLE}} = \frac{5}{4} \times 1.6 = \mathbf{2}$$

편향이 생기는 이유: $\mu_{\text{MLE}}$로 편차를 계산하기 때문에 실제 $\mu$로 계산할 때보다 항상 작아집니다(편차의 합이 항상 0이 되도록 강제되므로 자유도가 $n-1$).

#### P2-4 해설 (SET B) — KL Divergence

$p = [0.5, 0.3, 0.2]$, $q = [0.4, 0.4, 0.2]$

**(a) $H(p)$**:

$$H(p) = -(0.5\log 0.5 + 0.3\log 0.3 + 0.2\log 0.2)$$
$$= -(0.5 \times (-0.693) + 0.3 \times (-1.204) + 0.2 \times (-1.609))$$
$$= 0.3466 + 0.3612 + 0.3218 = \mathbf{1.029 \text{ nats}}$$

**(b) $\text{CE}(p,q)$**:

$$\text{CE}(p,q) = -(0.5\log 0.4 + 0.3\log 0.4 + 0.2\log 0.2)$$
$$= -(0.5 \times (-0.916) + 0.3 \times (-0.916) + 0.2 \times (-1.609))$$
$$= 0.458 + 0.2748 + 0.3218 = \mathbf{1.055 \text{ nats}}$$

**(c) $\text{KL}(p\|q)$**:

$$\text{KL}(p\|q) = \text{CE}(p,q) - H(p) = 1.055 - 1.029 = \mathbf{0.026 \text{ nats}}$$

**(d) 비대칭성 확인**:

$$\text{KL}(q\|p) = \sum_k q_k \log\frac{q_k}{p_k}$$
$$= 0.4\log\frac{0.4}{0.5} + 0.4\log\frac{0.4}{0.3} + 0.2\log\frac{0.2}{0.2}$$
$$= 0.4(-0.223) + 0.4(0.288) + 0.2(0)$$
$$= -0.0892 + 0.1152 = \mathbf{0.026 \text{ nats}}$$

이 특수 사례에서는 거의 같지만, 일반적으로 $\text{KL}(p\|q) \neq \text{KL}(q\|p)$.

**중요 성질**: KL divergence는 항상 $\geq 0$ (Jensen's inequality). 두 분포가 같을 때만 0.

### Part 3 해설 (SET B)

---

#### P3-1 해설 (SET B) — 가우시안 MLE 완전 유도: 불편성

**배점**: (a) 1점, (b) 1.5점, (c) 2.5점, (d) 2.5점, (e) 2.5점

**(c) $\mu_{\text{MLE}}$ 유도**:

$$\ell(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_i (x_i - \mu)^2$$

$$\frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum_i (x_i - \mu) = 0 \implies n\mu = \sum_i x_i \implies \boxed{\mu_{\text{MLE}} = \bar{x}}$$

**(d) $\sigma^2_{\text{MLE}}$ 유도**:

$\ell$을 $\sigma^2 = v$에 대해 미분:

$$\frac{\partial \ell}{\partial v} = -\frac{n}{2v} + \frac{1}{2v^2}\sum_i (x_i - \mu)^2 = 0$$

$$\frac{n}{2v} = \frac{\sum_i (x_i - \mu)^2}{2v^2} \implies v = \frac{1}{n}\sum_i (x_i - \mu)^2$$

$$\boxed{\sigma^2_{\text{MLE}} = \frac{1}{n}\sum_i (x_i - \bar{x})^2}$$

**(e) 불편성 분석**:

$\mu_{\text{MLE}} = \bar{x}$의 기댓값:
$$\mathbb{E}[\bar{x}] = \mathbb{E}\left[\frac{1}{n}\sum x_i\right] = \frac{1}{n}\sum \mathbb{E}[x_i] = \frac{1}{n} \cdot n\mu = \mu \quad \checkmark \text{ 불편}$$

$\sigma^2_{\text{MLE}}$의 기댓값 (핵심 유도):
$$\mathbb{E}\left[\sum_i (x_i - \bar{x})^2\right] = \mathbb{E}\left[\sum_i x_i^2 - n\bar{x}^2\right]$$

$$= \sum_i \mathbb{E}[x_i^2] - n\mathbb{E}[\bar{x}^2]$$

$$= n(\sigma^2 + \mu^2) - n\left(\frac{\sigma^2}{n} + \mu^2\right) = n\sigma^2 - \sigma^2 = (n-1)\sigma^2$$

따라서:
$$\mathbb{E}[\sigma^2_{\text{MLE}}] = \frac{(n-1)\sigma^2}{n} \neq \sigma^2 \quad \text{편향}$$

편향의 이유: $\mu$를 모르므로 데이터에서 추정한 $\bar{x}$를 사용. $\bar{x}$는 이미 데이터에 "맞춰진" 값이므로 잔차가 실제보다 작아짐. 자유도 손실 1.

불편 추정량: $\hat{\sigma}^2_{\text{unb}} = \frac{1}{n-1}\sum_i (x_i - \bar{x})^2$ (베셀 보정).

**남에게 설명하는 한 문장**: 가우시안 MLE에서 평균은 불편 추정량이지만 분산은 $\frac{n-1}{n}$배로 과소추정되어 편향 추정량이다.

#### P3-2 해설 (SET B) — Softmax 분류기 NLL

**배점**: (a) 1.5점, (b) 2점, (c) 2점, (d) 3점, (e) 1.5점

**(a) 단일 샘플 NLL**:

$$-\log p(y_i | \mathbf{x}_i, \mathbf{W}) = -\log \frac{e^{\mathbf{w}_{y_i}^\top \mathbf{x}_i}}{\sum_j e^{\mathbf{w}_j^\top \mathbf{x}_i}}$$

**(b) 간소화**:

$$= -\mathbf{w}_{y_i}^\top \mathbf{x}_i + \log\sum_j e^{\mathbf{w}_j^\top \mathbf{x}_i}$$

첫 항은 정답 클래스의 점수를 높이는 항, 두 번째 항(log-sum-exp)은 모든 클래스 점수를 억제하는 항.

**(c) 이진 분류로의 축소 ($C=2$)**:

$C=2$이면 $p_1 = \sigma(\mathbf{w}_1^\top\mathbf{x} - \mathbf{w}_2^\top\mathbf{x}) = \sigma((\mathbf{w}_1-\mathbf{w}_2)^\top\mathbf{x})$. $\mathbf{w} = \mathbf{w}_1 - \mathbf{w}_2$로 재정의하면 logistic sigmoid. BCE가 됩니다.

**(d) Gradient 유도**:

$$\frac{\partial}{\partial \mathbf{w}_c}\left[-\mathbf{w}_{y_i}^\top \mathbf{x}_i + \log\sum_j e^{\mathbf{w}_j^\top \mathbf{x}_i}\right]$$

$c = y_i$일 때: $-\mathbf{x}_i + \frac{e^{\mathbf{w}_c^\top\mathbf{x}_i}}{\sum_j e^{\mathbf{w}_j^\top\mathbf{x}_i}}\mathbf{x}_i = (\hat{p}_c - 1)\mathbf{x}_i$

$c \neq y_i$일 때: $\frac{e^{\mathbf{w}_c^\top\mathbf{x}_i}}{\sum_j e^{\mathbf{w}_j^\top\mathbf{x}_i}}\mathbf{x}_i = \hat{p}_c \mathbf{x}_i$

통합: $\frac{\partial \text{NLL}}{\partial \mathbf{w}_c} = (\hat{p}_c - \mathbf{1}[c = y_i])\mathbf{x}_i$

기하적 해석: 예측 확률 $\hat{p}_c$와 실제 레이블의 차이(오차)만큼 weight를 조정합니다.

**(e) 핵심 이해**:

CE를 최소화하면 $-\log p(y_i|\mathbf{x}_i,\mathbf{W})$를 최소화. 즉 $\log p(y_i|\mathbf{x}_i,\mathbf{W})$를 최대화. 즉 정답 클래스의 예측 확률을 최대화. 학습의 목적과 완전히 일치합니다.

#### P3-3 해설 (SET B) — 베이지안 업데이트 (Beta 분포)

**배점**: (a) 1점, (b) 2점, (c) 3점, (d) 2점, (e) 2점

**(b) Posterior 적용**:

$$p(\theta|D) \propto P(D|\theta) \cdot p(\theta) = \theta^k(1-\theta)^{n-k} \cdot \theta^{m-1}(1-\theta)^{m-1}$$
$$= \theta^{k+m-1}(1-\theta)^{n-k+m-1}$$

이것은 Beta$(k+m, n-k+m)$ 분포의 커널입니다.

**(c) 정규화 상수**:

$$p(\theta|D) = \frac{\theta^{k+m-1}(1-\theta)^{n-k+m-1}}{B(k+m, n-k+m)}$$

여기서 $B(\alpha, \beta) = \frac{(\alpha-1)!(\beta-1)!}{(\alpha+\beta-1)!}$는 Beta 함수입니다.

**(d) MAP vs MLE**:

MAP (Beta posterior의 최빈값, mode):
$$\theta_{\text{MAP}} = \frac{(k+m-1)}{(k+m-1)+(n-k+m-1)} = \frac{k+m-1}{n+2m-2}$$

MLE: $\theta_{\text{MLE}} = k/n$

$n \to \infty$: $\theta_{\text{MAP}} \to k/n = \theta_{\text{MLE}}$. 데이터가 많으면 prior가 무관해집니다.

**(e) "Prior = 의사 데이터" 해석**:

$m-1$은 실험 전에 $m-1$번의 앞면과 $m-1$번의 뒷면을 미리 본 것과 수학적으로 동일합니다. 즉 Beta$(m, m)$ prior는 "균형 잡힌 동전을 $(m-1)$번씩 미리 관측했다"는 믿음입니다. 실제 데이터 $(k, n-k)$가 여기에 더해집니다.

**남에게 설명하는 한 문장**: Beta prior는 Bernoulli likelihood와 켤레 관계여서 posterior도 Beta이며, prior의 파라미터는 가상의 사전 데이터로 해석된다.

#### P4-1 해설 (SET B) — Softmax 미분과 Attention

**Softmax Jacobian 유도**:

$\sigma_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$라 하면:

**(i) 대각 항 ($i = j$)**:

$$\frac{\partial \sigma_i}{\partial z_i} = \frac{e^{z_i}(\sum_j e^{z_j}) - e^{z_i} \cdot e^{z_i}}{(\sum_j e^{z_j})^2} = \sigma_i - \sigma_i^2 = \sigma_i(1 - \sigma_i)$$

**(ii) 비대각 항 ($i \neq j$)**:

$$\frac{\partial \sigma_i}{\partial z_j} = \frac{0 \cdot (\sum_k e^{z_k}) - e^{z_i} \cdot e^{z_j}}{(\sum_k e^{z_k})^2} = -\sigma_i \sigma_j$$

**(iii) 컴팩트 표현**:

$$J_{ij} = \frac{\partial \sigma_i}{\partial z_j} = \sigma_i(\delta_{ij} - \sigma_j)$$

여기서 $\delta_{ij}$는 Kronecker delta. 행렬 형태: $J = \text{diag}(\boldsymbol{\sigma}) - \boldsymbol{\sigma}\boldsymbol{\sigma}^\top$.

**(iv) 비대각인 이유**:

Softmax는 모든 $\sigma_i$의 합이 항상 1이라는 제약이 있습니다. 따라서 $z_j$를 변경하면 $\sigma_j$가 변하고, 이를 보상하기 위해 모든 다른 $\sigma_i$도 같이 변합니다.

**Attention 계산**:

$$\mathbf{K}\mathbf{q} = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}1\\1\\2\end{pmatrix}$$

$$\mathbf{s} = \frac{\mathbf{K}\mathbf{q}}{\sqrt{2}} = \begin{pmatrix}1/\sqrt{2}\\1/\sqrt{2}\\2/\sqrt{2}\end{pmatrix} = \begin{pmatrix}0.707\\0.707\\1.414\end{pmatrix}$$

$$\boldsymbol{\alpha} = \text{softmax}(\mathbf{s}) = \frac{1}{e^{0.707} + e^{0.707} + e^{1.414}}\begin{pmatrix}e^{0.707}\\e^{0.707}\\e^{1.414}\end{pmatrix}$$

$e^{0.707} \approx 2.028$, $e^{1.414} \approx 4.113$

$$\boldsymbol{\alpha} = \frac{1}{8.169}\begin{pmatrix}2.028\\2.028\\4.113\end{pmatrix} \approx \begin{pmatrix}0.248\\0.248\\0.503\end{pmatrix}$$

$$o = \boldsymbol{\alpha}^\top \mathbf{V} = 0.248(10) + 0.248(20) + 0.503(30) = 2.48 + 4.96 + 15.09 \approx \mathbf{22.53}$$

해석: Query $[1, 1]^\top$은 세 번째 Key $[1, 1]^\top$과 가장 많이 정렬(aligned)되므로, 세 번째 Value(30)에 가장 큰 가중치(50.3%)를 부여합니다.

#### P4-2 해설 (SET B) — Inductive Bias, Expressivity, 모델 선택

**(a) 정의**:

- **Inductive bias**: 학습 알고리즘이 보지 않은 데이터에 대해 일반화하기 위해 만드는 가정들. 베이지안 언어로는 prior.
- **Expressivity**: 모델이 표현할 수 있는 함수의 집합의 크기. 높을수록 더 복잡한 패턴을 학습 가능.
- **긴장 관계**: inductive bias가 강하면 hypothesis space가 작아 expressivity가 낮아짐. 반대로 표현력이 높으면 prior가 약해 더 많은 데이터가 필요.

**(b) 표 완성**:

| Property | Linear Model | MLP | CNN | Transformer |
|---|---|---|---|---|
| Inductive bias | Strong (linearity) | Weak | Medium (locality, translation invariance) | Weak |
| Expressivity | Low | High | Medium-High | Very High |
| Data requirement | Small | Large | Medium | Very Large |
| Key prior assumption | Linearity | Universal approximation | Local features, translation equivariance | No structural prior (learns everything) |
| Typical application | Simple regression | General tasks | Images | Language, general |

**(c) 베이지안 대응**:

Prior가 강한 MAP ↔ Inductive bias가 강한 모델:
- CNN의 locality/weight sharing = "이미지는 local feature로 구성된다"는 prior
- RNN의 recurrence = "언어는 순차적이다"는 prior
- 선형 모델 = "관계는 선형이다"는 강한 prior

동전 예시:
- $n = 5$ (적은 데이터): MAP (강한 prior)가 더 신뢰 가능. MLE = 0.8이지만 MAP (m=1) = 0.714로 더 보수적.
- $n = 1000$ (많은 데이터): 둘이 거의 같아짐. 데이터가 prior를 압도.

**(d) Transformer vs CNN 데이터 요구량**:

CNN은 이미지의 translation equivariance와 locality라는 강한 structural prior를 내장합니다. 이 prior 덕분에 적은 데이터로도 이미지의 구조를 학습할 수 있습니다.

Transformer는 structural prior가 매우 약합니다. 모든 위치 사이의 관계를 데이터에서 학습해야 하므로, 위치 정보조차 positional encoding으로 명시해야 합니다. 따라서 동일한 이미지 분류 작업이라도 CNN보다 훨씬 많은 데이터가 필요합니다(ViT 논문에서 JFT-300M 같은 거대 데이터셋 필요).

**남에게 설명하는 한 문장**: Inductive bias는 모델에 내장된 사전 지식으로, 강할수록 적은 데이터로 잘 작동하지만 잘못된 가정이면 오히려 해가 된다.

## 종합 요약: A+ 핵심 포인트

### 반드시 외워야 할 유도 체인 (시험 킬러 공식)

```
데이터 관측 → i.i.d. 가정
    ↓
Joint likelihood = ∏ individual likelihood
    ↓
Log-likelihood = Σ log(individual likelihood)  ← 곱 → 합
    ↓
최적화: d/dθ [log-likelihood] = 0
    ↓
Gaussian noise → MSE
Bernoulli data → BCE (Cross Entropy)
Gaussian prior + Gaussian noise → MSE + L2 regularization (MAP)
```

### 자주 출제되는 "why" 질문 답변 프레임

| 질문 | 핵심 답변 |
|---|---|
| 왜 i.i.d.를 가정하는가? | 결합 확률 = 개별 확률의 곱 → 계산 가능 |
| 왜 log를 취하는가? | 곱 → 합, 수치 안정성, 미분 편의 |
| 왜 미분 = 0인가? | 극값 후보 (stationary point) |
| 왜 상수를 버리는가? | θ와 무관 → 최적화 결과에 영향 없음 |
| 왜 MLE ≠ MAP인가? | MAP에는 prior 정보가 추가됨 |
| 왜 L2 = Gaussian prior인가? | Gaussian log = 이차식 = L2 페널티 |
| 왜 CE를 쓰는가? | Bernoulli MLE에서 자연스럽게 유도 |
| 왜 MSE를 쓰는가? | Gaussian MLE에서 자연스럽게 유도 |

### 자주 틀리는 개념 쌍

| 자주 혼동 | 올바른 구분 |
|---|---|
| Likelihood vs Posterior | $P(E\|H)$ vs $P(H\|E)$: 순서가 반대 |
| MLE vs MAP | Prior 포함 여부 |
| Entropy vs Cross-entropy | $H(p,p)$ vs $H(p,q)$: 같은 분포 vs 다른 분포 |
| KL(p‖q) vs KL(q‖p) | 비대칭! Forward CE-seeking vs Reverse mode-seeking |
| 고유값 분해 vs SVD | 정방행렬 전용 vs 임의 행렬 |
| Span vs Basis | 모든 선형결합 집합 vs 최소 생성 집합 |
