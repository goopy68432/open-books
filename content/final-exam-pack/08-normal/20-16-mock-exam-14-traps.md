# 모범답안

## 답 1.
(a) **참**. 독립 → $E[XY]=E[X]E[Y]$ → $\text{Cov}=0$ → 비상관.
(b) **거짓**. 반례: $X\sim\text{Uniform}(-1,1)$, $Y=X^2$. $\text{Cov}(X,Y)=E[X^3]=0$ (비상관) but $Y$는 $X$에 완전 의존 (비독립).
(c) **거짓**. $KL(p\|q) \neq KL(q\|p)$ (대칭성 불만족) + 삼각부등식도 불만족.
(d) **거짓**. 데이터 적을 때 과적합 (예: $n=k=3$ → $\theta=1$). MAP/Bayesian이 더 나을 수 있음.
(e) **거짓**. $\exp(z_i+c)/\sum\exp(z_j+c) = \exp(z_i)/\sum\exp(z_j)$ → $e^c$가 분자분모에서 약분. **출력 불변**.

## 답 3.
### (b)
$\sigma'(x) \leq 0.25$. 10층 네트워크에서 그래디언트:
$\prod_{i=1}^{10}\sigma'(x_i) \leq 0.25^{10} = 9.5 \times 10^{-7}$
→ 초기 층의 그래디언트가 $10^{-6}$ 스케일 → 사실상 학습 불가 = gradient vanishing.

## 답 4.
(a) **거짓**. $f(x) = x^3$: $f'(0)=0$이지만 극값이 아님 (변곡점).
    $f(x) = -x^2$: $f'(0)=0$이지만 극대값 (극소 아님).
    비볼록 함수에서 안장점: $f(x,y)=x^2-y^2$, $(0,0)$에서 미분=0이지만 극값 아님.
(b) 볼록: $f(\alpha x + (1-\alpha)y) \leq \alpha f(x) + (1-\alpha)f(y)$. 임계점이 극소가 아니면 볼록 정의에 모순. (볼록 함수에 극대나 안장점 없음)

## 답 5.
(a) $KL = -\sum p(x)\log(q(x)/p(x))$에서 $q(x)=0$, $p(x)>0$이면 $\log 0 = -\infty$ → $KL = +\infty$. 따라서 q의 support가 p를 포함해야 함.
(b) $\min_q KL(p\|q)$: q가 p의 모든 mode를 커버하려 함 → **mean-seeking** (넓게 퍼짐)
   $\min_q KL(q\|p)$: q가 p의 하나의 mode에 집중 → **mode-seeking** (하나에 집중)

## 답 7.
(a) 거짓. 잘못된 Prior는 bias를 증가시킨다. 예: 실제 $\theta=0.9$인데 Prior가 $\theta \approx 0.1$이면 MAP가 데이터에 반하는 추정을 할 수 있음.
(b) $\theta_{MAP} = \frac{k+\alpha-1}{n+\alpha+\beta-2}$. $n \to \infty$: $\frac{k/n+(\alpha-1)/n}{1+(\alpha+\beta-2)/n} \to k/n = \theta_{ML}$. Prior 항이 $O(1/n)$으로 소멸.

## 답 10.
(a) **과적합**. Train-Test gap 거대. 해결: 정규화 추가, 데이터 증강, Dropout.
(b) **과소적합**. 둘 다 높고 gap 작음. 해결: 모델 복잡도 증가, 학습 에폭 증가.
(c) 데이터 증가로 일반화 개선. Gap 축소(0.1→0.05) + 두 Loss 감소 → 더 많은 데이터가 과적합 방지와 성능 향상 모두에 기여.
