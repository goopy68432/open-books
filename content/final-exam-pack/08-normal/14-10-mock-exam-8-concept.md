# 모범답안

## 답 1.
(a) $y \sim \mathcal{N}(h(x), \sigma^2)$ — 노이즈가 가우시안. NLL의 지수항 = $(y-h(x))^2$ = MSE.
(b) $y \sim \text{Cat}(h(x))$ — 출력이 카테고리 분포. $-\log$ 확률 = CE.
(c) Laplace: $p(y|x) \propto \exp(-|y-h(x)|/b)$ → NLL $\propto \sum|y_i - h(x_i)|$ = **MAE (Mean Absolute Error)**. L1 Loss.

## 답 3.
(a) MLE는 "관측된 데이터만으로 판단" (귀납: 사례→일반), MAP는 "사전 지식 + 데이터로 판단" (연역: 원리+사례→결론).
(b) CNN은 "이미지에서 인접 픽셀이 관련있다"(locality)와 "패턴이 위치에 무관하다"(equivariance)라는 Prior를 구조적으로 내장. 이것은 MAP에서 Prior를 설정하는 것과 유사. Transformer는 이런 구조적 제약이 없으므로(약한 Prior = MLE적), 대량 데이터로 학습해야 함.

## 답 6.
(a) $\frac{\partial L}{\partial x} = \frac{\partial L}{\partial f_3} \cdot \frac{\partial f_3}{\partial f_2} \cdot \frac{\partial f_2}{\partial f_1} \cdot \frac{\partial f_1}{\partial x}$
역순(L→3→2→1→x)으로 야코비안을 곱해나감 = backward pass.

(b) Forward: 입력 x에서 출력 L까지 각 층의 출력값 저장.
Backward: L에서 시작하여 각 층의 야코비안을 역순으로 곱하며 그래디언트 전파.

(c) 각 야코비안 $\frac{\partial f_i}{\partial f_{i-1}}$의 스펙트럴 노름 < 1이면 곱할수록 기하급수적 감소 → gradient vanishing. Sigmoid의 $\sigma'(x) \leq 0.25$가 대표적 원인.

## 답 8.
(a) **선형대수** → 데이터 표현(행렬), 차원 축소(SVD), 변환(가중치 행렬)
(b) **미분/최적화** → 파라미터 학습(gradient descent), 역전파(체인룰)
(c) **확률론** → 불확실성 모델링, Loss 함수 유도(MLE), 과적합 방지(MAP)
(d) **정보이론** → 분포 간 거리(KL), Loss 해석(CE=NLL=KL)
(e) 딥러닝은 "데이터(확률) 속 구조(선형대수)를 최적(미분)으로 학습하고, 학습의 목표(정보이론)는 모델 분포를 데이터 분포에 가깝게 만드는 것"이다. 확률 가정→NLL 유도→체인룰로 그래디언트 계산→행렬 연산으로 파라미터 업데이트.

## 답 10.
(a) CLT: 수많은 독립 원인의 합 → 어떤 원래 분포든 정규분포 수렴. 노이즈 = 무수한 독립 요인의 합.
(b) 최대 엔트로피: 평균/분산만 알 때 가장 보수적(정보 가정 최소) 선택 = 가우시안.
(c) 수학적 편의: log-likelihood가 닫힌 형태, 켤레 사전분포 존재, 적분 가능, MLE 해석해 존재.
(d) 한계: 실제 노이즈는 heavy-tail(이상치), 다봉(multimodal) 가능. 가우시안 가정이 깨지면 MSE가 부적절해질 수 있음 (robust loss 필요: Huber 등).
