## 문제 8. [10점] "왜" 체인: KL ≥ 0

```
KL(p‖q) = E_p[-log(q/p)] → (1) -log는 볼록
→ (2) Jensen 부등식 적용 가능
→ (3) E[f(X)] ≥ f(E[X])
→ (4) -log(E[q/p]) = -log(1) = 0
→ (5) KL ≥ 0
```

---

## 문제 9. [10점] "왜" 체인: CE = KL = NLL

```
(1) KL = CE - H → (2) H(p) 고정 → (3) min CE = min KL
(4) CE = E_p[-log q] → (5) 샘플 근사 = NLL
→ (6) min NLL = min CE = min KL
```

## 문제 10. [10점] 대통합: 모든 "왜"를 하나의 스토리로

아래의 이야기를 완성하시오 (빈칸 채우기 + 각 빈칸에 "왜" 1줄):

> 딥러닝은 데이터에서 패턴을 학습한다. 데이터를 확률 분포로 모델링하면
> __(a)__ 추정이 된다. 이때 데이터가 독립이면 __(b)__으로 분해되고,
> 로그를 취하면 __(c)__이 된다. 이것의 부호를 반전하면 __(d)__이고,
> 가우시안 가정이면 __(e)__, 카테고리 가정이면 __(f)__이 된다.
> 여기에 사전 지식(Prior)을 추가하면 __(g)__ 추정이 되고,
> Gaussian Prior이면 __(h)__가 추가된다. 이 모든 것의 근본 원리는
> "모델 분포를 데이터 분포에 가깝게 만든다" = __(i)__ 최소화이다.

# 모범답안

## 답 1.
(1) 왜 확률 모델: 데이터의 불확실성을 수학적으로 표현하기 위해
(2) 왜 i.i.d.: 결합확률을 곱으로 분해하여 다루기 쉽게 만들기 위해
(3) 왜 log: 곱→합(계산 편의), 수치안정, 단조(argmax 불변)
(4) 왜 미분=0: Fermat 정리 — 내부 극값의 필요조건
(5) 왜 해 도출: 미분=0의 방정식을 풀면 MLE 추정값

## 답 6.
(1) CLT: 독립적 요인의 합 → 정규분포 수렴. 노이즈 = 무수한 독립 원인의 합이므로 가우시안 모델링 정당화.
(2) 최대 엔트로피: 평균/분산만 알 때 추가 가정을 최소화하는 "가장 보수적" 분포 = 가우시안. 라그랑주 승수법으로 유도 가능.
(3) 켤레 사전분포: 가우시안 Likelihood + 가우시안 Prior = 가우시안 Posterior. Posterior가 닫힌 형태로 나와 계산이 편리.

## 답 10.
(a) MLE/최대우도 (왜: 데이터를 가장 잘 설명하는 파라미터)
(b) 개별 확률의 곱 (왜: i.i.d. = 독립동일분포)
(c) 로그 우도의 합 (왜: log는 곱→합, 단조증가)
(d) NLL (Negative Log-Likelihood) (왜: 최대화→최소화 변환)
(e) MSE (왜: 가우시안의 지수항 = $(y-h(x))^2$)
(f) Cross-Entropy (왜: 카테고리 분포의 -log 확률)
(g) MAP (왜: Posterior = Likelihood × Prior 최대화)
(h) L2 Regularization $\lambda\|\theta\|^2$ (왜: Gaussian의 log = $-\|\theta\|^2/(2\sigma^2)$)
(i) KL Divergence (왜: KL = CE - H, CE 최소화 = 모델→데이터 분포 접근)
