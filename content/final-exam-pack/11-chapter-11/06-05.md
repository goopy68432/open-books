# 05. 편미분과 체인룰 (다변수)

> 딥러닝 모델은 변수가 수백만 개. 한 변수씩 미분하는 게 편미분이다.

## 1. 편미분이란? — "한 놈만 본다"

`f(x, y) = x² + 3xy + y²` 에서 **x에 대해 편미분**한다는 건:
- y는 **상수처럼 취급**하고 x로만 미분.
- 결과: `∂f/∂x = 2x + 3y`.

y에 대해 편미분:
- x는 상수처럼 취급, y로만 미분.
- `∂f/∂y = 3x + 2y`.

기호 `∂` 는 "라운드 d"라 읽고, **편미분**임을 표시한다.

🧪 **직접 해보기**: `f(x,y,z) = x²y + yz + z³` 에서
- `∂f/∂x = ?` (정답: `2xy`)
- `∂f/∂y = ?` (정답: `x² + z`)
- `∂f/∂z = ?` (정답: `y + 3z²`)

## 2. 그래디언트 ∇f — 편미분 모음 벡터

$$\nabla f(x,y,z) = \begin{bmatrix}\partial f/\partial x \\ \partial f/\partial y \\ \partial f/\partial z\end{bmatrix}.$$

위 예에서 `∇f = [2xy, x²+z, y+3z²]`.

💡 **직관**: 그래디언트 벡터는 **함수가 가장 가파르게 증가하는 방향**. 손실을 줄이려면 `−∇L` 방향으로 가면 된다 → 이게 **경사하강법(GD)**.

## 3. 다변수 체인룰 (꼭 이해!)

`z = f(x, y)`이고 `x = g(t)`, `y = h(t)` 일 때:
$$\frac{dz}{dt} = \frac{\partial f}{\partial x}\cdot\frac{dx}{dt} + \frac{\partial f}{\partial y}\cdot\frac{dy}{dt}.$$

여러 길로 영향을 주면 **모두 더한다**.

### 예: 신경망의 한 층
입력 `x`, 가중치 `w`, 출력 `y = wx`, 손실 `L = (y−t)²`.
- `∂L/∂y = 2(y−t)`.
- `∂y/∂w = x`.
- `∂L/∂w = ∂L/∂y · ∂y/∂w = 2(y−t)·x`.

이게 백프롭의 한 스텝.

## 4. "여러 길" 체인룰 — softmax 증명에 직결

`L(z₁, z₂, …, z_C)` 에서, 만약 `L = g(ŷ₁, ŷ₂, …)`이고 각 `ŷ_i = ŷ_i(z₁,…,z_C)` 라면:
$$\frac{\partial L}{\partial z_j} = \sum_{i=1}^{C}\frac{\partial L}{\partial \hat y_i}\cdot \frac{\partial \hat y_i}{\partial z_j}.$$

**왜 합하는가**? `z_j`가 변하면 모든 `ŷ_i`가 영향받고, 각각이 L에 영향을 미친다. 그 모든 경로를 더한다.

📌 **외울 것**: "여러 경로가 있으면 **각 경로를 곱하고 모두 더한다**."

## 5. 합성 다변수 체인룰의 일반 형식

벡터 `x → 함수 g → 벡터 y → 함수 f → 스칼라 L` 일 때, 입력 x_j에 대한 미분:
$$\frac{\partial L}{\partial x_j} = \sum_i \frac{\partial L}{\partial y_i}\cdot \frac{\partial y_i}{\partial x_j}.$$

이게 **자코비안-그래디언트 곱**이며, 신경망 백프롭의 일반식이다.

## 6. 자주 쓰는 그래디언트 공식 (외워두면 좋다)

| 함수 | 그래디언트 |
|---|---|
| `f(x) = aᵀx` (스칼라) | `∇f = a` |
| `f(x) = xᵀx = ‖x‖²` | `∇f = 2x` |
| `f(x) = xᵀAx` (이차형식) | `∇f = (A + Aᵀ)x` |
| `f(W) = ‖Wx − y‖²` (회귀) | `∇_W f = 2(Wx-y)xᵀ` |

지금 다 외울 필요는 없지만 06번 파일(벡터/행렬) 끝나면 다시 보자.

## 7. 헤시안 (옵션, Adam 이해에 도움)

이중 편미분을 모은 행렬. `H_{ij} = ∂²f/(∂x_i ∂x_j)`. 곡률 정보. 지금은 이름만 알자.

## 8. 직접 해보기

1. `f(x,y) = e^{x+2y}` 의 `∂f/∂x`, `∂f/∂y`.
   - 정답: `e^{x+2y}`, `2e^{x+2y}`.

2. `L = (wx − y)²` 에 대해 `∂L/∂w` 와 `∂L/∂x`.
   - `∂L/∂w = 2(wx−y)·x`, `∂L/∂x = 2(wx−y)·w`.

3. `ŷ = σ(z) = 1/(1+e^{-z})`, `L = -ln ŷ` 일 때 `dL/dz`.
   - 풀이: `dL/dŷ = -1/ŷ`, `dŷ/dz = ŷ(1-ŷ)` → `dL/dz = -1/ŷ · ŷ(1-ŷ) = -(1-ŷ) = ŷ-1`.
   - 라벨이 1인 데이터의 BCE 미분이 정확히 `ŷ−1`이라는 걸 확인.

4. `f(x,y,z) = xyz` 의 그래디언트.
   - 정답: `[yz, xz, xy]`.

## 9. 손실 미분의 일반 패턴 (백프롭 핵심)

신경망 한 층:
$$z = Wx + b,\quad h = \sigma(z),\quad L = \mathcal L(h).$$

체인룰:
$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial h}\odot \sigma'(z)\cdot x^\top,\quad \frac{\partial L}{\partial x} = W^\top\Big(\frac{\partial L}{\partial h}\odot \sigma'(z)\Big).$$

지금 다 이해 못해도 OK. 11번 파일에서 다시 손계산한다.

## 10. 정리

> **편미분: 한 놈만 보고 나머지는 상수.**
> **그래디언트 ∇f: 편미분을 쌓은 벡터.**
> **체인룰(여러 변수): 경로마다 곱해서 모두 더하기.**
> **GD: `θ ← θ − η ∇L`.**
