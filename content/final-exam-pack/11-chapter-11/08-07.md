# 07. 확률 기초

## 1. 확률이란?
- "어떤 일이 일어날 가능성"을 0과 1 사이의 수로 표현.
- 동전 앞면: `P(앞) = 1/2 = 0.5`.
- 6면 주사위 1: `P(1) = 1/6`.

### 공리 (Kolmogorov)
1. `P(A) ≥ 0`.
2. `P(전체) = 1`.
3. 서로 배반이면 `P(A∪B) = P(A) + P(B)`.

## 2. 확률변수 (RV)
- 어떤 실험의 결과를 **숫자**로 매핑하는 함수.
- 동전 두 번: 앞면 수 X = 0, 1, 2 → `P(X=0)=1/4, P(X=1)=1/2, P(X=2)=1/4`.

## 3. PMF / PDF
- **PMF (확률질량함수)**: 이산 RV. `P(X=k)`.
- **PDF (확률밀도함수)**: 연속 RV. `p(x)` 자체는 확률 아님. 적분해야 확률. `P(a≤X≤b) = ∫_a^b p(x)dx`.
- 둘 다 합/적분이 1.

## 4. 결합확률, 주변확률, 조건부확률

| 표기 | 뜻 |
|---|---|
| `P(A, B)` 또는 `P(A∩B)` | A와 B가 동시에 |
| `P(A)` | (B 무시한) A의 확률 |
| `P(A\|B)` | B가 일어났을 때 A의 확률 |

### 정의
$$P(A\mid B) = \frac{P(A,B)}{P(B)},\quad P(B)>0.$$

### 곱셈공식
$$P(A,B) = P(A\mid B)\,P(B) = P(B\mid A)\,P(A).$$

## 5. 독립
A와 B가 독립 ⇔ `P(A,B) = P(A)·P(B)` ⇔ `P(A|B) = P(A)`.

🧪 **직접 해보기**: 주사위 두 개. `A: 첫번째=1`, `B: 두번째=2`. 독립인가? 확률은?
- 정답: 독립. `P(A,B) = (1/6)(1/6) = 1/36`.

## 6. 베이즈 정리 — 마스터 자료의 핵심

곱셈공식 두 식을 같다 두면:
$$P(A\mid B)P(B) = P(B\mid A)P(A).$$
양변을 `P(B)`로 나눠:
$$\boxed{P(A\mid B) = \frac{P(B\mid A)P(A)}{P(B)}.}$$

### 의미
- `A = θ`(파라미터), `B = D`(데이터)로 두면:
$$p(\theta\mid D) = \frac{p(D\mid \theta)\,p(\theta)}{p(D)}.$$
- `p(D)` 는 θ에 무관 → `p(θ|D) ∝ p(D|θ)·p(θ)`.

이게 마스터자료 §1의 출발점이다.

📌 **외울 것**: **사후 ∝ 우도 × 사전.**

## 7. i.i.d. (독립이고 동일분포)

데이터 `x₁, …, x_N` 이 i.i.d.이면:
$$p(x_1, x_2, \ldots, x_N \mid \theta) = \prod_{i=1}^N p(x_i \mid \theta).$$
**곱**으로 분해 가능. 이게 likelihood의 곱 형태.

## 8. 직접 해보기

1. `P(A) = 0.4`, `P(B|A) = 0.5`, `P(B|¬A) = 0.2` 일 때 `P(A|B)`?
   - `P(B) = 0.4·0.5 + 0.6·0.2 = 0.2 + 0.12 = 0.32`.
   - `P(A|B) = 0.4·0.5/0.32 = 0.2/0.32 = 0.625`.

2. 동전 3번 던져 앞면 수 X. `P(X=2)`?
   - 정답: 3개 케이스(앞앞뒤, 앞뒤앞, 뒤앞앞) × `(1/2)³ = 3/8`.

3. `p(D|θ) ∝ exp(-θ²)`, `p(θ) ∝ exp(-(θ-1)²/2)` 일 때 `p(θ|D)` 의 비례식.
   - 정답: `p(θ|D) ∝ exp(-θ² - (θ-1)²/2)`.

## 9. 정리

> **베이즈 정리 = 곱셈공식 두 줄을 정리한 것. `posterior ∝ likelihood × prior`.**
> **i.i.d. ⇒ likelihood = 곱.**
