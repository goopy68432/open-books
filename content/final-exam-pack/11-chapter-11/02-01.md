# 01. 수학기호 읽는 법 — 수식을 한국어처럼

> 목표: 수식을 보면 머릿속에서 **자동으로 한국어 문장으로 바뀌도록** 한다.

## 1. 수식은 "줄임말"이다
한국어로 "1부터 10까지 모두 더해라"는 길다. 수학은 이걸 짧게 쓴다:
$$\sum_{i=1}^{10} i$$
이게 다다. 의미만 외우면 무섭지 않다.

## 2. 핵심 기호 30개 (꼭 외우기)

### A. 합과 곱

| 기호 | 읽는 법 | 의미 | 예 |
|---|---|---|---|
| `Σ` | 시그마 | 합 (Sum) | `Σ_{i=1}^3 i = 1+2+3 = 6` |
| `Π` | 파이(대문자) | 곱 (Product) | `Π_{i=1}^3 i = 1·2·3 = 6` |
| `∫` | 인테그랄 | 적분(continuous한 합) | 지금은 "Σ의 연속판" 정도로만 |

> **읽는 법 전체**: `Σ_{i=1}^{N} f(i)` → "i가 1부터 N까지 갈 때, f(i)들을 모두 더한 값"

### B. 변수와 집합

| 기호 | 의미 |
|---|---|
| `∈` | "~의 원소이다" (`x ∈ ℝ` = "x는 실수") |
| `∉` | "~의 원소가 아니다" |
| `⊂` | "부분집합이다" |
| `∪` | 합집합 |
| `∩` | 교집합 |
| `∅` | 공집합 |
| `ℝ` | 실수 전체 |
| `ℕ` | 자연수 |
| `ℝ^n` | n차원 실수 벡터 (중1엔 처음일 텐데 §6에서 자세히) |

### C. 논리

| 기호 | 의미 |
|---|---|
| `∀` | "모든 ~에 대해" (for all) |
| `∃` | "어떤 ~가 존재한다" (there exists) |
| `⇒` | "~이면 ~이다" (implies) |
| `⇔` | "필요충분조건" (iff) |
| `:=` | "왼쪽을 오른쪽으로 정의한다" |
| `∝` | "비례한다" (`y ∝ x` → `y = kx` for some k) |

### D. 미적분/딥러닝에서 등장

| 기호 | 의미 |
|---|---|
| `f'(x)` 또는 `df/dx` | x에 대한 도함수(변화율) |
| `∂f/∂x` | "f를 x에 대해 편미분" (다른 변수는 상수 취급) |
| `∇f` | "그래디언트 f" — 모든 편미분을 모은 벡터 |
| `lim_{x→a}` | "x가 a로 갈 때의 극한" |
| `→` | "~로 간다" |
| `argmax_θ f(θ)` | f를 최대로 만드는 θ값 (값이 아니라 **θ 자체**) |
| `argmin_θ f(θ)` | f를 최소로 만드는 θ값 |
| `‖x‖` | 벡터 x의 길이 (norm) |
| `xᵀ` | x의 전치(행/열 뒤집기) |
| `⊙` | 원소별 곱 (Hadamard product) |
| `δ_{ij}` | 크로네커 델타: i=j면 1, 아니면 0 |
| `\|x\|` | 절댓값 또는 행렬식 (문맥) |
| `≈` | "거의 같다" |
| `≠` | "같지 않다" |
| `≤, ≥` | "이하, 이상" |

### E. 확률

| 기호 | 의미 |
|---|---|
| `P(A)` | 사건 A의 확률 |
| `P(A\|B)` | "B가 일어났을 때 A의 조건부확률" |
| `E[X]` | 확률변수 X의 기댓값 (평균) |
| `Var(X)` | 분산 |
| `~` | "이 분포를 따른다" (`X ~ N(0,1)`) |
| `i.i.d.` | "독립이고 동일분포" (independent and identically distributed) |

## 3. 첨자(아래첨자/위첨자) 읽는 법

- `x_i` : "i번째 x"  →  데이터 한 점.
- `x^{(i)}` : 이것도 "i번째 x" (괄호 위첨자, 거듭제곱과 헷갈리지 말 것).
- `x_i^2` : "i번째 x를 제곱"
- `x_{ij}` : "i행 j열의 x" (행렬의 원소)

❓ **자주 헷갈림**: `x²`(제곱) vs `x^{(2)}`(두 번째 데이터). 위첨자에 괄호가 있으면 "라벨"이지 거듭제곱이 아니다.

## 4. 자주 나오는 문장 패턴 해독

### 패턴 1: `f(x) = Σ_{i=1}^N a_i x^i`
"f(x)는 a_i 곱하기 x의 i제곱을 i가 1부터 N까지 더한 것."

### 패턴 2: `θ̂ = argmax_θ p(D|θ)`
"θ-hat이라는 추정값은, p(D|θ)를 가장 크게 만드는 θ이다."
- `̂` (hat): "추정한"
- `argmax_θ`: "θ를 움직여 최댓값을 만드는 θ"

### 패턴 3: `∀ε>0, ∃N, ∀n≥N : |a_n − a| < ε`
"임의의 양수 ε에 대해, 어떤 자연수 N이 있어, n이 N 이상이면 항상 |a_n − a| < ε."
(이건 극한의 정의. 지금 외우지 말고 *읽을 줄만* 알자.)

## 5. 시그마 다루는 기본 규칙 (자주 씀)

1. **상수 분리**: `Σ_i (c·a_i) = c·Σ_i a_i`
2. **분배**: `Σ_i (a_i + b_i) = Σ_i a_i + Σ_i b_i`
3. **인덱스 무관**: `Σ_{i=1}^{n} a_i = Σ_{j=1}^{n} a_j` (이름은 그냥 라벨)
4. **이중합**: `Σ_i Σ_j a_{ij}` 와 `Σ_j Σ_i a_{ij}` 는 같다.

📌 **외울 것**: 시그마 안에서 **i와 무관한 것은 시그마 밖으로 뺄 수 있다.**

## 6. 직접 해보기 (반드시 손으로!)

1. `Σ_{i=1}^4 i²` 의 값은? (정답: 1+4+9+16 = 30)
2. `Π_{i=1}^3 (i+1)` 의 값은? (정답: 2·3·4 = 24)
3. 다음 문장을 한국어로 읽어라:
   - `∀x ∈ ℝ, x² ≥ 0`
   - `θ̂_{MLE} = argmax_θ Σ_{i=1}^N log p(x_i|θ)`
4. `Σ_{i=1}^N (x_i + 3)` 를 시그마 규칙으로 풀어 써라.
   - 정답: `Σ x_i + Σ 3 = Σ x_i + 3N`

## 7. 정리 (외울 박스)

> **시그마 = 더하기 기계, 파이 = 곱하기 기계, ∂ = 편미분, ∇ = 그래디언트, argmax = "최댓값을 만드는 그 변수".**
> 모든 수식은 한국어 문장이다. 머뭇거리지 말고 한국어로 옮겨 읽자.
