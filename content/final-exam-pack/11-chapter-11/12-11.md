# 11. 역전파 (Backpropagation) 손계산

> 목표: 2-layer 신경망의 forward/backward를 **종이와 펜만으로** 끝까지 계산할 수 있게 된다.

## 1. 핵심 원리 (한 줄)
**Upstream gradient × Local Jacobian** 의 누적 곱.
즉 손실에서부터 거꾸로 가며, 각 노드의 **출력 미분(이미 알고 있음)** 과 **그 노드의 입력→출력 자코비안**을 곱해 입력에 대한 미분을 얻는다.

## 2. 구체 예제 — 작은 회귀 신경망

### 구조
- 입력 `x ∈ ℝ²`.
- 1번째 층 가중치 `W₁ ∈ ℝ^{2×2}`, bias `b₁ ∈ ℝ²`, 활성화 σ(시그모이드).
- 2번째 층 가중치 `W₂ ∈ ℝ^{1×2}`, bias `b₂ ∈ ℝ`. 출력 스칼라 `ŷ`.
- 손실 `L = ½(ŷ - t)²`.

### Forward
1. `z₁ = W₁x + b₁`     (∈ ℝ²)
2. `h = σ(z₁)`             (∈ ℝ²)
3. `z₂ = W₂h + b₂`     (∈ ℝ)
4. `ŷ = z₂` (선형 출력)
5. `L = ½(ŷ - t)²`

## 3. Backward 단계별

### 단계 1. 손실의 출력 미분
$$\frac{\partial L}{\partial \hat y} = \hat y - t.$$
이게 **upstream gradient의 시작점**. 이걸 `δ_y` 라 부르자.

### 단계 2. 출력층 z₂ 그래디언트
`ŷ = z₂` 이므로 `∂ŷ/∂z₂ = 1`. 따라서:
$$\frac{\partial L}{\partial z_2} = \delta_y \cdot 1 = \hat y - t.$$
`δ_{z₂} := ŷ - t`.

### 단계 3. W₂, b₂ 그래디언트
`z₂ = W₂h + b₂`. 행렬·벡터 미분 공식 (06번 §8):
$$\frac{\partial L}{\partial W_2} = \delta_{z_2}\cdot h^\top,\qquad \frac{\partial L}{\partial b_2} = \delta_{z_2}.$$

W₂는 `1×2`, h는 `2×1`. 외적이라 결과 `1×2`. ✅

### 단계 4. h 그래디언트 (입력 거꾸로)
`z₂ = W₂h + …` 에서 `∂z₂/∂h = W₂ᵀ`. 따라서:
$$\frac{\partial L}{\partial h} = W_2^\top\,\delta_{z_2}\quad(\in\mathbb R^2).$$

### 단계 5. z₁ 그래디언트 (시그모이드 통과)
`h = σ(z₁)`. element-wise 미분 → 자코비안은 대각.
$$\frac{\partial L}{\partial z_1} = \frac{\partial L}{\partial h} \odot \sigma'(z_1) = \frac{\partial L}{\partial h} \odot h\odot(1-h).$$
`δ_{z₁}` 라 부르자.

### 단계 6. W₁, b₁ 그래디언트
`z₁ = W₁x + b₁` 이므로:
$$\frac{\partial L}{\partial W_1} = \delta_{z_1}\, x^\top,\qquad \frac{\partial L}{\partial b_1} = \delta_{z_1}.$$

## 4. 일반 규칙 (외울 표)

| 연산 | Forward | Backward |
|---|---|---|
| `z = Wx + b` | — | `∂L/∂x = Wᵀ ∂L/∂z`, `∂L/∂W = ∂L/∂z · xᵀ`, `∂L/∂b = ∂L/∂z` |
| `h = φ(z)` element-wise | — | `∂L/∂z = ∂L/∂h ⊙ φ'(z)` |
| `L = ½(ŷ-t)²` | — | `∂L/∂ŷ = ŷ-t` |
| `L = -Σy log ŷ`(softmax) | — | `∂L/∂z = ŷ-y` |
| Sum (broadcast) | — | gradient를 broadcast 차원으로 sum |

📌 **외울 것**: 위 표 5줄. 어떤 신경망도 이 다섯의 조합.

## 5. 숫자 예제 (실제로 해보기)

### Setup
- `x = [1, 2]ᵀ`, `t = 1`.
- `W₁ = [[0.1, 0.2], [-0.1, 0.3]]`, `b₁ = [0, 0]ᵀ`.
- `W₂ = [0.5, -0.5]`, `b₂ = 0`.

### Forward
1. `z₁ = [0.1·1+0.2·2, -0.1·1+0.3·2]ᵀ = [0.5, 0.5]ᵀ`.
2. `h = σ([0.5, 0.5]) ≈ [0.6225, 0.6225]ᵀ`.
3. `z₂ = 0.5·0.6225 + (-0.5)·0.6225 + 0 = 0`.
4. `ŷ = 0`.
5. `L = ½(0 - 1)² = 0.5`.

### Backward
1. `δ_y = ŷ - t = -1`.
2. `δ_{z₂} = -1`.
3. `∂L/∂W₂ = -1 · [0.6225, 0.6225] = [-0.6225, -0.6225]`.
   `∂L/∂b₂ = -1`.
4. `∂L/∂h = W₂ᵀ · (-1) = [0.5, -0.5]ᵀ · (-1) = [-0.5, 0.5]ᵀ`.
5. `σ'(z₁) = h(1-h) ≈ [0.235, 0.235]`. (왜냐하면 0.6225·0.3775≈0.235)
   `δ_{z₁} = [-0.5·0.235, 0.5·0.235] = [-0.1175, 0.1175]`.
6. `∂L/∂W₁ = δ_{z₁} xᵀ = [[-0.1175, -0.235], [0.1175, 0.235]]`.
   `∂L/∂b₁ = [-0.1175, 0.1175]`.

🧪 직접 계산기로 검증해보면 좋다.

## 6. 깊은 망에서도 똑같이 — 누적 곱

층이 L개여도 매 층의 backward는 같다. **upstream을 받아 local Jacobian과 곱하고 다음 층으로 전달.** 이게 끝.

## 7. Vanishing/Exploding Gradient

층마다 `σ'` (≤ 0.25) 같은 작은 수가 곱해지면, 깊을수록 그래디언트가 **0으로 사라짐(vanishing)**. 반대로 큰 가중치가 곱해지면 **폭발(exploding)**.

대처:
- ReLU (`φ' = 0 또는 1`) — vanishing 완화.
- Residual connection — gradient 우회로.
- 적절한 초기화 (Xavier, He).
- BatchNorm/LayerNorm.

## 8. 직접 해보기

1. `x = [2]`, `W₁ = 0.5`, `b₁ = 0.1`, σ 통과, `W₂ = 1`, `b₂ = 0`, `t = 0`. forward+backward.
2. softmax+CE 출력층의 backward는 `ŷ-y`. 위 5번 표에 어떻게 들어가는지 그려보라.
3. ReLU 활성화일 때 `φ'(z) = ?` (정답: `1 if z>0 else 0`).

## 9. 정리

> **Backprop = 체인룰의 행렬판.**
> **각 층: `∂L/∂z = (Wᵀ·upstream) ⊙ φ'(z)` 식 반복.**
> **5개 규칙(affine, element-wise, MSE, CE+softmax, broadcast sum)으로 모든 망의 backward 가능.**
