# 04. 미분 입문

> 미분은 딥러닝의 심장이다. 학습 = 손실의 미분(기울기)에 따라 파라미터를 옮기는 것.

## 1. 미분 = "순간의 변화율"

자동차가 1초에 10m 갔다 → 평균 속도 10m/s.
하지만 **딱 그 순간의 속도**는? → 시간 간격을 0으로 줄이면 된다. 그게 미분.

### 정의 (꼭 외워라)
$$f'(x) = \lim_{h\to 0}\frac{f(x+h) - f(x)}{h}.$$

읽기: "h가 0으로 갈 때, x+h와 x에서의 함숫값 차이를 h로 나눈 값의 극한."

💡 **직관**: 그래프에서 (x, f(x)) 점에서 그은 **접선의 기울기**.

## 2. 정의로 직접 미분 (한 번은 손으로 해보기)

### 예: `f(x) = x²`
$$\frac{f(x+h)-f(x)}{h} = \frac{(x+h)^2 - x^2}{h} = \frac{x^2+2xh+h^2 - x^2}{h} = 2x + h.$$
`h→0` 보내면 `f'(x) = 2x`. ✓

🧪 **직접 해보기**: `f(x) = 3x` 의 도함수를 정의로 구하라. (정답: 3)

## 3. 기본 미분 공식 (8개 외우기)

| 함수 f(x) | 도함수 f'(x) |
|---|---|
| 상수 c | 0 |
| x | 1 |
| xⁿ | n·x^{n−1} |
| eˣ | eˣ |
| ln x | 1/x |
| sin x | cos x |
| cos x | −sin x |
| 시그모이드 σ(x) | σ(x)(1−σ(x)) |

📌 **외울 것**: 이 표 8줄은 자동반사. 특히 `xⁿ → nx^{n-1}`, `eˣ → eˣ`, `ln x → 1/x`.

## 4. 미분 규칙 4개

1. **상수배**: `(c·f)' = c·f'`
2. **합/차**: `(f ± g)' = f' ± g'`
3. **곱**: `(f·g)' = f'·g + f·g'` (앞 미분·뒤 + 앞·뒤 미분)
4. **나눗셈**: `(f/g)' = (f'·g − f·g')/g²`
5. **합성(체인룰)**: `(f(g(x)))' = f'(g(x)) · g'(x)` ★★★

## 5. 체인룰 — 가장 중요!

합성함수 `h(x) = f(g(x))`의 미분:
$$h'(x) = f'(g(x))\cdot g'(x).$$

읽기: "바깥 함수 미분(안은 그대로) × 안 미분."

### 예 1: `h(x) = (2x+1)³`
- 바깥 `f(u) = u³`, `f'(u) = 3u²`.
- 안 `g(x) = 2x+1`, `g'(x) = 2`.
- 합치면 `h'(x) = 3(2x+1)² · 2 = 6(2x+1)²`.

### 예 2: `h(x) = e^{−x²}`
- 바깥 `eᵘ → eᵘ`.
- 안 `−x² → −2x`.
- `h'(x) = e^{−x²}·(−2x) = −2x·e^{−x²}`.

🧪 **직접 해보기** (필수):
1. `(x²+1)⁵` 의 미분. (정답: `5(x²+1)⁴ · 2x = 10x(x²+1)⁴`)
2. `ln(3x)` 의 미분. (정답: `(1/(3x))·3 = 1/x`)
3. `e^{2x+1}` 의 미분. (정답: `2e^{2x+1}`)

## 6. 시그모이드 도함수 — 직접 유도

`σ(x) = 1/(1+e^{-x})` 의 미분을 구하자.

쓰기 편하게: `σ(x) = (1+e^{-x})^{-1}`.
체인룰:
- 바깥 `u^{-1} → -u^{-2}`.
- 안 `(1+e^{-x})' = -e^{-x}`.
- 합치면: `σ'(x) = -(1+e^{-x})^{-2} · (-e^{-x}) = e^{-x}/(1+e^{-x})²`.

여기서 트릭. `e^{-x}/(1+e^{-x}) = 1 - 1/(1+e^{-x}) = 1-σ(x)` 이므로:
$$\sigma'(x) = \sigma(x)\cdot(1-\sigma(x)).$$

📌 **외울 것**: **`σ' = σ(1-σ)`** — 백프롭에서 무지하게 자주 등장.

## 7. 로그함수 미분 — 자주 쓰는 식

`(ln x)' = 1/x`. 체인룰과 결합:
$$(\ln f(x))' = \frac{f'(x)}{f(x)}.$$

예: `(ln(1+e^x))' = e^x/(1+e^x) = σ(x)`. (시그모이드와 만난다!)

## 8. 극값을 찾는 절차 (최대/최소)

1. 도함수 계산: `f'(x)`.
2. `f'(x) = 0` 풀기 → 후보점.
3. 두 번 미분 `f''(x)` 부호로 최대(<0)/최소(>0) 판정.

예: `f(x) = x² − 4x + 5`.
- `f'(x) = 2x − 4 = 0 → x = 2`.
- `f''(x) = 2 > 0` → 최소.
- `f(2) = 4 − 8 + 5 = 1`. 최솟값 1.

💡 **딥러닝과 연결**: 학습 = 손실 L의 최솟값을 찾는 것. 그래서 `∂L/∂θ = 0` 방향으로 옮긴다.

## 9. 직접 해보기 (체크리스트)

1. `(3x²+2x−1)' = ?` (정답: `6x+2`)
2. `(x³ · ln x)' = ?` (곱 미분) (정답: `3x² ln x + x³ · 1/x = 3x² ln x + x²`)
3. `(e^{x²})' = ?` (정답: `2x·e^{x²}`)
4. `f(x) = (x−3)²+5`의 최솟값과 그때의 x. (정답: x=3, 최솟값 5)
5. `(ln(σ(x)))' = ?` (정답: `σ'(x)/σ(x) = (1-σ(x))`)

## 10. 정리

> **미분 = 변화율 = 접선 기울기.**
> **체인룰: 바깥 미분(안 그대로) × 안 미분.**
> **`σ' = σ(1-σ)`, `(eˣ)' = eˣ`, `(ln x)' = 1/x` — 자동반사.**
> **극값 찾기: f'(x)=0.**
