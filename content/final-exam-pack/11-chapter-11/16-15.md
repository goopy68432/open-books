# 15. 백지증명 체크리스트 — 자기점검과 가르치기 연습

> 이 파일의 모든 항목을 **자료를 보지 않고** 빈 종이에 쓸 수 있을 때 코스 완주.

## 1. 자기점검 표 (✓ 또는 ✗ 표시)

### A. 수학 언어 (Stage 1)
- [ ] Σ, Π, ∀, ∃, ∈, ∝, →, ∂, ∇, argmax, ⊙, δ_{ij}, ‖·‖ 의미 즉답.
- [ ] `Σ_{i=1}^n (x_i + c) = Σx_i + nc` 같은 시그마 변형 자유롭게.
- [ ] 함수 7개(linear, quadratic, abs, exp, log, sigmoid, ReLU) 그래프 그리기.
- [ ] 합성함수 `h(x) = e^{2x+1}` 분해 가능.

### B. 도구 (Stage 2)
- [ ] 지수법칙 5개, 로그법칙 5개 즉답.
- [ ] `(eˣ)' = eˣ`, `(ln x)' = 1/x` 자동.
- [ ] 체인룰 `(f(g(x)))' = f'(g(x))g'(x)` 의 예 3개 즉시 풀이.
- [ ] **`σ(x)' = σ(x)(1-σ(x))` 유도 5줄**.
- [ ] 편미분 `∂f/∂x_i` 자유, 그래디언트 ∇f 작성.
- [ ] 다변수 체인룰 `∂L/∂x_j = Σ_i (∂L/∂y_i)(∂y_i/∂x_j)`.
- [ ] 행렬곱 `(AB)_{ij} = Σ_k A_{ik}B_{kj}` 정의 + 손계산.
- [ ] **표준 행렬 정리 `A=[T(e_1),...,T(e_n)]` 5단계 증명**.
- [ ] `(AB)ᵀ = BᵀAᵀ`, `‖x‖² = xᵀx` 자동반사.

### C. 확률 (Stage 3)
- [ ] 베이즈 정리 → `posterior ∝ likelihood × prior` 유도.
- [ ] i.i.d. 가정의 의미와 likelihood 곱.
- [ ] 베르누이/정규분포 PMF/PDF 적기.
- [ ] **NLL → MSE (가우시안 noise) 유도** 4줄.
- [ ] **NLL → BCE (베르누이) 유도** 3줄.
- [ ] MLE vs MAP vs Full Bayes 차이 설명.
- [ ] log argmax 보존 이유 (단조성).

### D. 본 게임 (Stage 4)
- [ ] **MAP = NLL + R(θ) 5단계 증명**.
- [ ] Gaussian prior → L2, Laplace prior → L1.
- [ ] **Softmax 자코비안 두 case 분수미분 증명**.
- [ ] 통합식 `∂ŷ_i/∂z_j = ŷ_i(δ_{ij}-ŷ_j)`.
- [ ] **Softmax+CE 합성 미분 5단계 → `ŷ-y`**.
- [ ] **2-layer NN forward + backward 손계산** (W₁, b₁, W₂, b₂ 모두).
- [ ] backprop 일반 규칙 5개(affine, element-wise, MSE, CE+softmax, broadcast).
- [ ] **Conv = Toeplitz 행렬곱** 표현 + sparse + weight-sharing.
- [ ] **Translation equivariance 3줄 증명**.
- [ ] GD/Momentum/AdaGrad/RMSProp/Adam 5개 식 작성.
- [ ] Adam bias correction 의미 + 간단 유도.
- [ ] **Bias-Variance 분해 5단계 증명**.
- [ ] Bitter Lesson과 bias의 관계 설명.

## 2. "다른 중학생에게 가르치기" 시뮬레이션

다음 5개 주제 각각을 **10분짜리 강의 스크립트**로 작성. 자료 없이.
1. "베이즈 정리가 뭐야? 사후=우도×사전이 무슨 뜻이야?"
2. "softmax 미분이 왜 ŷ-y가 되는지 설명해줘."
3. "역전파의 핵심 한 줄로 설명해줘."
4. "convolution이 그냥 행렬곱이라는 게 무슨 뜻이야?"
5. "Adam 옵티마이저가 GD보다 좋은 이유는?"

각 강의는 다음 구조를 따른다:
- (1분) 왜 이게 중요한지.
- (2분) 정의.
- (5분) 직관 + 한 가지 손계산 예제.
- (1분) 잘못 알기 쉬운 함정.
- (1분) 한 줄 요약.

가족·친구를 앉혀놓고 **실제 말로 설명**해보면 막히는 부분이 즉시 드러난다.

## 3. 1주 반복 학습 루틴

### 매일 (10~20분)
- 핵심 공식 8개를 빈 종이에 적기:
  - σ(x)와 σ'(x)
  - log법칙 + 지수법칙
  - 베이즈 정리
  - softmax+CE 미분 결과
  - backprop 일반 규칙
  - Adam 4식
  - Conv equivariance
  - bias-var 결과식

### 격일 (30분)
- 위 체크리스트 중 ✗ 항목 하나 골라 자료 보지 않고 처음부터 끝까지 종이에 쓰기. 막히면 자료 열어 학습, 다음날 다시.

### 주1회 (1시간)
- "가르치기 강의" 1개를 녹음하거나 누군가에게 발표. 어색한 부분이 약점.

## 4. 흔한 실수 패턴 점검

- ❌ "δ_{ij} 안 쓰고 case 분리 잊음" → softmax 자코비안에서 자주.
- ❌ "Σ y_i = 1 가정 까먹음" → softmax+CE 단계 5에서 막힘.
- ❌ "전치 위치 헷갈림" → backprop의 `Wᵀ`.
- ❌ "log 단조성 잊고 argmax/argmin 부호 실수".
- ❌ "Adam의 bias correction 의미 모름" — `(1-βᵗ)`로 나누는 이유.
- ❌ "convolution의 weight-sharing이 뭔지 말로 설명 못 함" — Toeplitz 정의 외울 것.

## 5. 마지막 한마디

**손으로 써라. 입으로 설명해라. 외우려 하지 말고 유도하라.**
- 외운 식은 한 달 뒤 사라진다.
- 유도할 줄 알면 평생 간다.

이 16개 파일은 *지도*일 뿐이다. 진짜 학습은 빈 종이 위에서 일어난다.
