# 06. 벡터와 행렬 (선형대수의 시작)

## 1. 벡터 = 숫자의 줄
$$\mathbf x = \begin{bmatrix}3\\1\\-2\end{bmatrix}\in\mathbb R^3.$$

- 정의: 실수의 순서쌍 (n개면 n차원).
- 표기: 굵은 소문자 `x`, 또는 `→x`.
- `xᵀ = [3, 1, -2]` (가로, 전치).

💡 **딥러닝**: 입력 이미지·문장·임베딩 모두 벡터.

## 2. 벡터 연산

### (1) 합 / 상수배
$$\begin{bmatrix}1\\2\end{bmatrix}+\begin{bmatrix}3\\4\end{bmatrix}=\begin{bmatrix}4\\6\end{bmatrix},\quad 2\begin{bmatrix}1\\2\end{bmatrix}=\begin{bmatrix}2\\4\end{bmatrix}.$$

### (2) 내적 (dot product)
$$\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + \cdots + a_n b_n = \sum_i a_i b_i = \mathbf a^\top \mathbf b.$$
예: `[1,2]·[3,4] = 3+8 = 11`.

### (3) 길이 (norm)
$$\|\mathbf x\| = \sqrt{x_1^2 + x_2^2 + \cdots} = \sqrt{\mathbf x^\top \mathbf x}.$$

### (4) 외적 (outer product) — 백프롭에 등장
$$\mathbf a \mathbf b^\top = \begin{bmatrix}a_1\\a_2\end{bmatrix}\begin{bmatrix}b_1 & b_2\end{bmatrix} = \begin{bmatrix}a_1b_1 & a_1b_2\\a_2b_1 & a_2b_2\end{bmatrix}.$$
결과는 **행렬**.

🧪 **직접 해보기**: `a = [1,2]`, `b = [3,4]` 의 내적과 외적을 구하라.
- 내적: 11. 외적: `[[3,4],[6,8]]`.

## 3. 표준기저 e_i

$$\mathbf e_1 = \begin{bmatrix}1\\0\\0\end{bmatrix},\;\mathbf e_2 = \begin{bmatrix}0\\1\\0\end{bmatrix},\;\mathbf e_3 = \begin{bmatrix}0\\0\\1\end{bmatrix}.$$

성질: 임의 `x ∈ ℝⁿ`에 대해 `x = Σ x_i e_i`. (한 자리만 1, 나머지는 0.)

📌 **외울 것**: `e_i`는 i번째 좌표만 1인 단위벡터. 이게 §3 표준행렬 정리의 출발점.

## 4. 행렬 = 숫자의 격자

$$A = \begin{bmatrix}1 & 2 & 3\\ 4 & 5 & 6\end{bmatrix}\in\mathbb R^{2\times 3}.$$
`m×n`: m행 n열. 원소 `A_{ij}` = i행 j열.

## 5. 행렬 연산

### (1) 합 / 상수배 — 원소별.

### (2) 행렬 × 벡터
`A ∈ ℝ^{m×n}`, `x ∈ ℝⁿ` → `Ax ∈ ℝᵐ`.
$$(A\mathbf x)_i = \sum_{j=1}^n A_{ij}x_j.$$
"i번째 행과 x의 내적".

### (3) 행렬 × 행렬
`A: m×n`, `B: n×p` → `AB: m×p`.
$$(AB)_{ij} = \sum_{k=1}^n A_{ik}B_{kj}.$$
"A의 i행과 B의 j열의 내적".

### (4) 전치 `Aᵀ`
행과 열을 바꿈. `(Aᵀ)_{ij} = A_{ji}`. 성질:
- `(Aᵀ)ᵀ = A`
- `(AB)ᵀ = BᵀAᵀ` ★

🧪 **직접 해보기**:
- `A = [[1,2],[3,4]]`, `x = [5, 6]ᵀ`. `Ax = ?` (정답: `[17, 39]ᵀ`)
- 위 A의 전치는? (정답: `[[1,3],[2,4]]`)

## 6. 행렬 = 선형변환 (핵심 관점)

`T(x) = Ax` 라는 함수는 **선형사상**이다. 즉:
- `T(x+y) = T(x)+T(y)`
- `T(cx) = c·T(x)`

거꾸로, **모든 선형 T: ℝⁿ→ℝᵐ는 어떤 행렬 A로 표현된다**. 이것이 §3의 정리.

### 핵심 정리 (백지에서 증명할 줄 알아야 함)

**Theorem.** `T: ℝⁿ→ℝᵐ`이 선형이면, `A = [T(e₁), T(e₂), …, T(e_n)]` 일 때 `T(x) = Ax`.

**증명 5단계**:
1. `x = x₁e₁ + … + x_n e_n` (표준기저 분해).
2. `T(x) = T(Σ x_j e_j) = Σ x_j T(e_j)` (선형성).
3. `Ax`의 정의: A의 j열을 `T(e_j)`로 두면 `Ax = Σ x_j T(e_j)`.
4. (2) = (3). 따라서 `T(x) = Ax`.
5. 유일성: `Ae_j = T(e_j)`로 모든 열이 결정. ∎

🧪 **직접 해보기**: `T: ℝ²→ℝ², T(x,y) = (2x+y, x−y)`의 표준행렬을 구하라.
- `T(e₁) = T(1,0) = (2,1)`.
- `T(e₂) = T(0,1) = (1,-1)`.
- `A = [[2,1],[1,-1]]`. 검증: `A·[x,y]ᵀ = [2x+y, x-y]ᵀ` ✓.

## 7. 항등행렬, 역행렬

- 항등행렬 `I`: 대각이 1, 나머지 0. `Ix = x`.
- 역행렬 `A^{-1}`: `A·A^{-1} = I`. (정사각행렬에서만, 가역일 때만.)
- `(A^{-1})ᵀ = (Aᵀ)^{-1}`.

## 8. 자주 쓰는 항등식 (외울 것)

1. `(AB)ᵀ = BᵀAᵀ`
2. `(AB)C = A(BC)` (결합법칙)
3. `xᵀy = yᵀx` (스칼라끼리는 교환)
4. `xᵀAy` 는 스칼라
5. `‖x‖² = xᵀx`
6. `Iᵀ = I`, `(A+B)ᵀ = Aᵀ+Bᵀ`

## 9. 자코비안 행렬 (편미분 표 모음)

벡터함수 `f: ℝⁿ→ℝᵐ` 의 자코비안:
$$J_{ij} = \frac{\partial f_i}{\partial x_j}.$$
크기는 `m×n`. 백프롭은 자코비안의 곱셈으로 본질이 같다.

예: softmax (§10에서 유도) 자코비안 = `diag(ŷ) − ŷŷᵀ`.

## 10. 직접 해보기 (필수)

1. `A = [[1,2],[3,4]]`, `B = [[2,0],[1,1]]` 일 때 `AB`. (정답: `[[4,2],[10,4]]`)
2. `T: ℝ²→ℝ³, T(x,y) = (x, x+y, 2y)` 의 표준행렬. (정답: `[[1,0],[1,1],[0,2]]`)
3. `(Ax)ᵀy = ?` 를 다른 표현으로. (정답: `xᵀAᵀy`)
4. `‖x‖² = xᵀx` 를 풀어 `x = [1,2,3]`에서 검증. (정답: 1+4+9=14)
5. 항등행렬 `I₂`를 곱한 `I₂x`는? (정답: x)

## 11. 정리

> **벡터 = 숫자 줄, 행렬 = 격자.**
> **행렬곱 = 행과 열의 내적 모음.**
> **모든 선형변환은 행렬, 그 행렬의 j열은 `T(e_j)`.**
> **`(AB)ᵀ = BᵀAᵀ`, `‖x‖² = xᵀx`** — 자동반사.
