# 08. 기댓값과 분포

## 1. 기댓값 (평균) `E[X]`
- 이산: `E[X] = Σ_k k·P(X=k)`.
- 연속: `E[X] = ∫ x·p(x)dx`.

예: 주사위 X. `E[X] = (1+2+3+4+5+6)/6 = 3.5`.

### 성질 (꼭 외워라)
1. `E[aX + b] = a·E[X] + b`.
2. `E[X+Y] = E[X] + E[Y]` (독립이 아니어도 성립!).
3. 독립이면 `E[XY] = E[X]E[Y]`.
4. `E[c] = c` (상수).

## 2. 분산 `Var(X)`
$$\text{Var}(X) = E[(X-E[X])^2] = E[X^2] - (E[X])^2.$$
"평균에서 얼마나 떨어져 있나"의 제곱평균.

### 성질
- `Var(aX+b) = a²·Var(X)` (b는 분산에 영향 없음).
- 독립이면 `Var(X+Y) = Var(X) + Var(Y)`.

🧪 **직접 해보기**: 주사위 X의 `Var(X)`?
- `E[X²] = (1+4+9+16+25+36)/6 = 91/6`.
- `Var = 91/6 - (3.5)² = 91/6 - 12.25 = 15.166... - 12.25 = 2.917`.

## 3. 베르누이 분포 `Bern(p)`
- X ∈ {0, 1}, `P(X=1) = p`, `P(X=0) = 1−p`.
- PMF (한 줄로): `P(X=x) = p^x (1-p)^{1-x}`.
- `E[X] = p`, `Var(X) = p(1-p)`.

📌 **로지스틱 회귀의 모델**: `p = σ(wᵀx + b)`. y는 베르누이.

## 4. 정규(가우시안) 분포 `N(μ, σ²)`
$$p(x) = \frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).$$
- `μ`: 평균, `σ²`: 분산.
- 그래프: 종 모양.
- `E[X] = μ`, `Var(X) = σ²`.

📌 **선형 회귀**: 잔차가 `N(0, σ²)`이라고 가정.

## 5. 우도(likelihood)의 의미 — 가장 헷갈리는 부분

같은 식 `p(x|θ)` 을 두 가지로 본다:
- **확률(PDF)**: `θ`를 고정하고 `x`의 함수로 본다 → 데이터가 어떻게 생길지.
- **우도(likelihood)**: `x`(데이터)를 고정하고 `θ`의 함수로 본다 → "이 데이터가 관측된 게 어떤 θ에서 더 그럴듯한가".

기호:
$$L(\theta) = p(D\mid \theta) = \prod_{i=1}^N p(x_i\mid\theta) \quad(\text{i.i.d.}).$$

⚠️ 우도는 확률이 아니다 (θ에 대한 적분이 1이 아닐 수 있음).

## 6. 로그 우도 `ℓ(θ) = log L(θ)`
$$\ell(\theta) = \sum_{i=1}^N \log p(x_i\mid\theta).$$
곱이 합으로 → 미분이 쉬워짐.

## 7. NLL (Negative Log Likelihood)
$$\text{NLL}(\theta) = -\ell(\theta) = -\sum_{i=1}^N \log p(x_i\mid\theta).$$
"우도 최대화 = NLL 최소화". 손실로 쓰는 이유.

## 8. 정규분포 NLL → MSE 유도 (한 번 손으로 해보기)

`y_i = wᵀx_i + b + ε_i`, `ε_i ~ N(0, σ²)`. ⇒ `p(y_i|x_i; w, b) = N(wᵀx_i+b, σ²)`.

NLL:
$$\text{NLL} = -\sum_{i=1}^N \log\!\left[\frac{1}{\sqrt{2\pi}\sigma}\exp\!\left(-\frac{(y_i-wᵀx_i-b)^2}{2\sigma^2}\right)\right].$$

전개:
$$= \sum_{i=1}^N\!\left[\tfrac{1}{2}\log(2\pi\sigma^2) + \frac{(y_i-wᵀx_i-b)^2}{2\sigma^2}\right].$$

`w, b`에 무관한 항 제거하고 `1/(2σ²)`은 양의 상수:
$$\arg\min_{w,b}\;\text{NLL} = \arg\min_{w,b}\;\sum_i (y_i - wᵀx_i - b)^2.$$

→ **MSE 손실**. ✅

## 9. 베르누이 NLL → BCE (Binary Cross-Entropy)

라벨 `y_i ∈ {0,1}`, 모델 `p_i = σ(wᵀx_i+b)`. 베르누이:
$$p(y_i|x_i) = p_i^{y_i}(1-p_i)^{1-y_i}.$$

NLL:
$$-\sum_i [y_i \log p_i + (1-y_i)\log(1-p_i)].$$

→ **BCE 손실**. ✅

📌 **외울 것**: **회귀 = Gaussian → MSE, 이진 분류 = Bernoulli → BCE, 다중 분류 = Categorical → CE.**

## 10. 직접 해보기

1. 동전 5번 던져 앞면 3번. 베르누이 i.i.d. 모델 `p` 의 NLL.
   - `NLL(p) = -[3 log p + 2 log(1-p)]`.
   - 미분 0: `-3/p + 2/(1-p) = 0 → p = 3/5 = 0.6`. (직관과 일치.)

2. `X ~ N(0,1)` 일 때 `E[X²]`?
   - 정답: `Var + E[X]² = 1 + 0 = 1`.

3. 정규분포 PDF에서 지수부분만 따로 미분 가능한 모양으로 정리.

## 11. 정리

> **PMF/PDF, 기댓값, 분산.**
> **베르누이/정규분포 PMF/PDF 외울 것.**
> **likelihood = θ의 함수, NLL = -log L. 회귀→MSE, 분류→BCE/CE 모두 NLL에서 나온다.**
