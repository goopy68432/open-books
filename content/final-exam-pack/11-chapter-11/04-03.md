# 03. 지수와 로그

> 딥러닝에서 **모든** 확률 계산은 지수/로그를 거친다. 여기서 막히면 끝까지 막힌다.

## 1. 지수의 정의 (복습)
- `2³ = 2·2·2 = 8`
- `aⁿ`: a를 n번 곱함.

### 지수법칙 5개 (반드시 외우기)
1. `aᵐ · aⁿ = a^{m+n}` (밑이 같으면 지수끼리 더함)
2. `aᵐ / aⁿ = a^{m−n}`
3. `(aᵐ)ⁿ = a^{mn}`
4. `(ab)ⁿ = aⁿbⁿ`
5. `a⁰ = 1` (a≠0), `a^{-n} = 1/aⁿ`

🧪 **직접 해보기**: 다음을 간단히 하라.
- `2³ · 2⁴ = ?` (정답: `2⁷ = 128`)
- `(3²)⁵ = ?` (정답: `3¹⁰`)
- `2^{-3} = ?` (정답: `1/8`)

## 2. 자연상수 e
`e ≈ 2.71828…` 인 특별한 상수. 왜 특별?
- `f(x) = eˣ`의 미분이 자기 자신: `(eˣ)' = eˣ`.
- 이 성질 덕분에 모든 확률·미분 계산이 깔끔.

📌 **외울 것**: `e^0 = 1`, `e^1 ≈ 2.718`, `eˣ` 는 항상 양수.

## 3. 로그의 정의 — 지수의 반대
$$\log_a b = c \;\Leftrightarrow\; a^c = b.$$
"a를 몇 번 곱해야 b가 되나?"의 답이 `log_a b`.

예:
- `log₂ 8 = 3` (왜냐하면 2³=8)
- `log₁₀ 100 = 2`
- `log_e x` 는 **자연로그**라 부르고 `ln x` 로 쓴다.

### 로그법칙 5개 (반드시 외우기)
1. `log(ab) = log a + log b` (곱 → 합)
2. `log(a/b) = log a − log b`
3. `log(aⁿ) = n·log a`
4. `log 1 = 0`, `log a 1 = 0`
5. `log_a a = 1`

> 💡 **이게 왜 중요?** 곱셈을 덧셈으로 바꿔주기 때문이다. 딥러닝에서 우도 `Π p_i`가 곱이라 다루기 힘든데, 로그를 씌우면 `Σ log p_i` 합으로 바뀌어 미분/계산이 쉬워진다.

## 4. 자연로그 ln 의 핵심 성질
- `ln(eˣ) = x`, `e^{ln x} = x` (서로 역함수)
- `(ln x)' = 1/x`
- `ln 1 = 0`
- `ln(ab) = ln a + ln b`

🧪 **직접 해보기**:
- `ln(e³) = ?` (정답: 3)
- `e^{ln 5} = ?` (정답: 5)
- `ln(eˣ · e²) = ?` (정답: x+2)

## 5. 로그의 단조성 (증명에 자주 쓰임)

`log` 함수는 **단조증가**한다. 즉:
$$a > b > 0 \;\Longleftrightarrow\; \log a > \log b.$$

**왜 중요?** "f(θ)를 최대화하는 θ"와 "log f(θ)를 최대화하는 θ"는 **같다.** 그래서 likelihood 대신 log-likelihood를 쓴다.
$$\arg\max_\theta f(\theta) = \arg\max_\theta \log f(\theta) \quad (f>0).$$

📌 **외울 것**: `log`는 단조증가 → arg max/arg min을 보존.

## 6. 음수 로그(NLL의 등장)
딥러닝에서는 보통 손실을 **최소화**한다. 그래서 `log` 대신 `−log`를 자주 쓴다:
- `f` 최대화 ⇔ `−log f` 최소화.

이게 바로 NLL = Negative Log Likelihood.

## 7. 지수·로그가 등장하는 딥러닝 식들

### (1) 시그모이드
$$\sigma(z) = \frac{1}{1+e^{-z}}.$$
분모에 `e^{-z}` 등장.

### (2) 소프트맥스
$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_k e^{z_k}}.$$
지수의 비율.

### (3) 정규분포 PDF
$$p(x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).$$

### (4) Cross-Entropy 손실
$$L = -\sum_i y_i \log \hat y_i.$$

이 4개가 거의 전부다. **지수·로그를 자유자재로 쓰면 절반 끝.**

## 8. 자주 쓰는 변형 트릭

### 트릭 1. `log(곱) = 합`
$$\log\prod_i p_i = \sum_i \log p_i.$$
→ likelihood를 log-likelihood로.

### 트릭 2. `log(eˣ) = x`
$$\exp(-L) \text{ 의 } \log = -L.$$
→ exp와 log는 서로 풀어준다.

### 트릭 3. `−log` 부호 뒤집기
"확률이 클수록 좋다(최대화)" ↔ "−log 확률이 작을수록 좋다(최소화)".

🧪 **직접 해보기**: `f(θ) = exp(-θ²)`을 최대화하는 θ를 구하라.
- 풀이: `log f(θ) = -θ²` → 최대화는 `θ²` 최소화 → `θ = 0`.

## 9. 직접 해보기 (완성형)

1. `log₂ 32 + log₂ 8 = ?` (힌트: 합 → 곱) (정답: 5+3 = 8, 또는 log₂(32·8)=log₂256=8)
2. `ln(e^5 / e²) = ?` (정답: 3)
3. `−log(0.1) > −log(0.5)` 인가? (정답: 0.1<0.5이고 log는 단조증가이므로 log(0.1)<log(0.5), 부호반전하면 −log(0.1)>−log(0.5). 즉 확률이 작을수록 NLL이 크다.)
4. `Π_{i=1}^3 e^{x_i}` 를 간단히 하라. (정답: `e^{x₁+x₂+x₃}`)
5. `log(1/p)` 와 `−log p`는 같은가? (정답: 같다. 로그법칙 2번 사용.)

## 10. 정리

> **지수·로그는 서로 역. 곱은 로그 안에서 합으로. argmax는 log를 통과한다. NLL은 −log likelihood.**
