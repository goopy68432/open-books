# 02. 함수와 그래프

## 1. 함수란? — "입력→출력" 기계
함수 `f`는 **숫자를 넣으면 숫자가 나오는 상자**다. `f(x) = 2x+1` 이라면:
- 입력 1 → 출력 3
- 입력 5 → 출력 11

수학적으로 쓸 때:
$$f: \mathbb R \to \mathbb R,\quad f(x) = 2x+1.$$
- `ℝ→ℝ`: "실수를 받아 실수를 뱉는다"

💡 **직관**: 딥러닝 모델 전체가 거대한 함수다. `f(이미지) = 라벨확률`. 함수 개념이 모든 것의 출발이다.

## 2. 정의역, 치역
- **정의역(domain)**: 입력 가능한 값들의 집합.
- **치역(range)**: 출력으로 나올 수 있는 값들의 집합.
- 예: `f(x) = √x` → 정의역 `x ≥ 0`, 치역 `≥ 0`.

## 3. 그래프 그리는 5단계
1. 정의역에서 x값 5~10개 선택.
2. 각 x에 대해 f(x) 계산.
3. (x, f(x)) 점들을 좌표평면에 찍는다.
4. 점들을 부드럽게 잇는다.
5. 어디서 증가/감소/꺾이는지 확인.

🧪 **직접 해보기**: `f(x) = x²` 를 x = -3, -2, -1, 0, 1, 2, 3에서 계산하고 그래프 그려라.
정답표:
```
x    | -3  -2  -1  0  1  2  3
f(x) |  9   4   1  0  1  4  9
```
포물선이 보이는가? 좋다.

## 4. 딥러닝에 자주 나오는 함수들

### (1) 선형(일차)함수 `f(x) = ax + b`
- 그래프: 직선
- a: 기울기, b: y절편
- **선형회귀**의 기본 모델.

### (2) 이차함수 `f(x) = x²`
- 그래프: 포물선 (U자 모양)
- 항상 `≥ 0`.
- **MSE 손실** = 잔차의 제곱.

### (3) 절댓값 `f(x) = |x|`
- 그래프: V자.
- **L1 정규화**의 기반.

### (4) 지수함수 `f(x) = e^x`
- 항상 양수, 가파르게 증가.
- 자세한 건 03번 파일.

### (5) 로그함수 `f(x) = log x`
- x>0에서만 정의, 천천히 증가.
- 03번 파일에서.

### (6) 시그모이드 `σ(x) = 1/(1+e^{-x})`
- 출력 범위 (0, 1).
- S자 곡선.
- **로지스틱 회귀**의 핵심.

### (7) ReLU `f(x) = max(0, x)`
- x<0이면 0, x≥0이면 x.
- 꺾인 직선. 딥러닝 활성화함수의 표준.

📌 **외울 것**: 위 7개 함수의 모양을 머릿속에 그릴 수 있을 것.

## 5. 합성함수 — 함수의 함수
`f(x) = x²`, `g(x) = x+1` 일 때:
- `f(g(x))` = `f(x+1)` = `(x+1)²`
- `g(f(x))` = `g(x²)` = `x²+1`

순서가 중요하다! "안에서부터 바깥으로" 계산.

🧪 **직접 해보기**: `h(x) = e^{2x+3}` 를 합성으로 분해하라.
- 정답: `f(u) = eᵘ`, `g(x) = 2x+3`이라 두면 `h = f(g(x))`.

이걸 잘 분해하는 능력이 **체인룰의 핵심**이다 (04번 파일).

## 6. 다변수 함수
입력이 여러 개:
$$f(x,y) = x² + y².$$
- 정의역: 평면 (ℝ²)
- 치역: 실수
- 그래프: 3D (밥그릇 모양)

딥러닝의 손실함수 `L(w₁, w₂, …, w_n)` 는 변수가 수백만 개인 다변수 함수다.

## 7. 함수의 표기들 (헷갈리지 마라)

| 표기 | 의미 |
|---|---|
| `f(x)` | f라는 함수에 x를 넣은 결과(값) |
| `f` | 함수 자체 |
| `f: ℝ → ℝ` | f는 실수 → 실수 함수 |
| `y = f(x)` | y는 x의 함수 |
| `f ∘ g` | f와 g의 합성, `(f∘g)(x) = f(g(x))` |

## 8. 직접 해보기

1. `f(x) = 3x − 2` 의 그래프를 그려라.
2. `g(x) = x²+1`, `h(x) = 2x` 일 때 `g(h(x))` 와 `h(g(x))`를 각각 구해라.
   - 정답: `g(h(x)) = (2x)²+1 = 4x²+1`, `h(g(x)) = 2(x²+1) = 2x²+2`.
3. 시그모이드 `σ(0)`의 값은? (정답: 1/(1+1) = 0.5)
4. `σ(x)`는 어떤 두 함수의 합성인가? (정답: `f(u) = 1/(1+u)`, `g(x) = e^{-x}`)

## 9. 정리

> **함수 = 입력 → 출력. 합성 = 함수의 줄세우기. 그래프 = 함수의 사진.**
> 딥러닝의 모델, 손실, 활성화 모두 함수다. 함수를 그릴 수 있으면 절반은 끝났다.
