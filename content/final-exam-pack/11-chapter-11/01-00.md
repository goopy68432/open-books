# 중1부터 시작하는 딥러닝 수학 마스터 커리큘럼

## 누구를 위한 자료인가
- 현재 수학 실력: **중1 수준** (사칙연산, 일차방정식, 음수, 분수까지는 능숙)
- 익숙하지 않은 것: 수학기호(Σ, ∂, ∇), 추상적 사고, 증명, 미적분, 벡터, 확률
- 목표: `마스터_학습자료.md`에 나오는 **10개 주제의 모든 수식과 증명을 백지에서 재현**하고, **다른 중학생에게도 설명 가능한 수준** 도달.

## 학습 원칙 (꼭 지켜라)
1. **한 파일을 끝낼 때까지 다음으로 안 넘어간다.** 순서대로 학습한다.
2. 각 파일 끝의 **연습문제는 손으로 직접 푼다.** 눈으로만 풀면 절대 안 남는다.
3. 모르는 기호가 나오면 즉시 `01_수학기호_읽는법.md`로 돌아가 확인한다.
4. **하루 1~2개 파일 페이스**로 약 2~3주면 끝난다. 무리해서 몰아치지 말 것.
5. 매 파일이 끝날 때마다 **그 파일의 핵심 정리(요약 박스)를 노트에 손으로 베껴 쓴다**. 이게 외워지는 비결이다.
6. 파일을 다 끝낸 뒤 `15_백지증명_체크리스트.md`로 자기점검 → 통과 못 한 항목은 해당 파일로 돌아간다.

## 전체 로드맵 (총 16개 파일)

### Stage 1. 언어 익히기 (수학을 한국어처럼 읽기)
- **01_수학기호_읽는법.md** — Σ, ∏, ∀, ∃, ∈, ∝, →, ∇, ∂ 등 모든 기호의 읽는 법과 의미.
- **02_함수와_그래프.md** — 함수 = 입력→출력 기계. 그래프 그리기, 합성함수.

### Stage 2. 도구 익히기 (계산할 줄 알기)
- **03_지수와_로그.md** — 지수법칙, 로그의 정의/성질, 자연로그 e와 ln.
- **04_미분_입문.md** — 변화율, 도함수, 기본 미분 공식, 합성함수 미분(체인룰).
- **05_편미분과_체인룰.md** — 변수가 여러 개일 때, 그래디언트 ∇, 다변수 체인룰.
- **06_벡터와_행렬.md** — 벡터의 정의, 내적, 행렬, 행렬곱, 전치, 표준기저, 항등식.

### Stage 3. 확률의 언어
- **07_확률_기초.md** — 확률의 정의, 조건부확률, 독립, 베이즈 정리.
- **08_기댓값과_분포.md** — 평균/분산, 베르누이/정규분포, PDF/PMF.
- **09_likelihood와_MLE.md** — 우도(likelihood)의 의미, 로그우도, MLE 절차.

### Stage 4. 본 게임 (마스터 자료의 증명들 직접 재현)
- **10_softmax와_크로스엔트로피_증명.md** — 자코비안 두 case, ∂L/∂z = ŷ−y 백지 증명.
- **11_역전파_손계산.md** — 2-layer NN forward + backward를 손으로 끝까지.
- **12_컨볼루션_행렬_증명.md** — Toeplitz 행렬, sparse+공유, translation equivariance 증명.
- **13_옵티마이저_수식.md** — GD→Momentum→AdaGrad→RMSProp→Adam 식 직접 유도/암기.
- **14_bias_variance_증명.md** — 분해식 5단계 증명 백지 재현.

### Stage 5. 마무리
- **15_백지증명_체크리스트.md** — 모든 증명을 빈 종이에 재현할 수 있는지 자기점검 표.

## 자료 사용 팁
- 파일 안의 **"💡 직관"** 박스는 *왜 이게 자연스러운가*를 설명한다. 외우지 말고 이해하라.
- **"🧪 직접 해보기"** 는 반드시 손으로 풀어라. 답이 틀려도 괜찮다, 시도가 중요.
- **"📌 외울 것"** 은 진짜 외우는 것. 이건 자동반사 수준으로.
- **"❓ 자주 헷갈림"** 은 한국 학생들이 반복적으로 실수하는 포인트.

자, 이제 `01_수학기호_읽는법.md`로 가자.
