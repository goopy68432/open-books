# Part E: 베이지안 추론과 파라미터 추정 — 중학생부터 대학원까지

> **핵심 킬러 요약**: 베이지안 추론은 "믿음을 증거로 업데이트하는 수학"이다.
> MLE/MAP/정규화는 모두 하나의 유도 체인(i.i.d. → product → log → gradient = 0)에서 나온다.

---

## 1. Bayes Theorem ★★★

**한 줄 결론**: 새 증거가 오면, 이전 믿음을 비례적으로 업데이트한다.

$$P(\theta | D) = \frac{P(D | \theta) \cdot P(\theta)}{P(D)}$$

$$\text{posterior} = \frac{\text{likelihood} \times \text{prior}}{\text{evidence}}$$

### 입문 (중학생 수준)

**쉽게 말하면**: 탐정이 사건을 수사하는 것과 같다. 처음엔 "용의자가 범인일 확률"을 직감으로 잡고, 새 증거(지문, 알리바이)가 나올 때마다 그 확률을 수정해 나간다.

예시:
- 병원에서 드문 병(유병률 1%)을 검사하는 키트가 있다. 검사 양성이면 실제 병일 확률이 얼마일까?
- 키트 정확도 99%여도, 실제 양성자의 확률은 직관보다 훨씬 낮다 → 베이즈 정리로 계산해야 정확히 나온다.

**남에게 설명하는 한 문장**: "사전 믿음(prior)에 새 데이터의 가능성(likelihood)을 곱하고, 전체 확률(evidence)로 나누면 업데이트된 믿음(posterior)이 나온다."

### 중급 (학부 수준)

업데이트 순서:

```
사전 믿음 P(θ)
    ↓  관측 데이터 D를 봄
P(D|θ)를 계산  ← θ가 참일 때 D가 나올 가능성
    ↓  베이즈 정리 적용
사후 믿음 P(θ|D)  ← 데이터를 본 후의 업데이트된 믿음
```

- P(D) = ∫ P(D|θ)P(θ) dθ  (marginalization, 모든 가능한 θ에 대해 적분)
- P(D)는 θ에 무관한 상수 → 정규화 상수(normalizing constant) 역할

### 고급 (대학원 수준)

**켤레 사전분포 (Conjugate Prior)**: prior와 posterior가 같은 분포족(family)에 속하도록 prior를 선택하는 기법.

| Likelihood | Conjugate Prior | Posterior |
|-----------|----------------|-----------|
| Bernoulli/Binomial | Beta | Beta |
| Gaussian (σ 알려짐) | Gaussian | Gaussian |
| Poisson | Gamma | Gamma |
| Multinomial | Dirichlet | Dirichlet |

**Gaussian-Gaussian 켤레 유도**:
- Prior: $P(\mu) = \mathcal{N}(\mu_0, \sigma_0^2)$
- Likelihood: $P(x_i | \mu) = \mathcal{N}(\mu, \sigma^2)$, n개 관측
- Posterior: $P(\mu | \mathbf{x}) = \mathcal{N}(\mu_n, \sigma_n^2)$

$$\mu_n = \frac{\frac{\mu_0}{\sigma_0^2} + \frac{n\bar{x}}{\sigma^2}}{\frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}}, \quad \frac{1}{\sigma_n^2} = \frac{1}{\sigma_0^2} + \frac{n}{\sigma^2}$$

**주의**: P(D)의 계산(적분)이 어려울 때 → MCMC, Variational Inference로 근사.

## 2. Prior, Likelihood, Posterior

**한 줄 결론**: Prior는 "내 기존 믿음", Likelihood는 "데이터가 파라미터를 얼마나 지지하는가", Posterior는 "데이터를 본 후의 업데이트된 믿음"이다.

### 입문

| 이름 | 기호 | 쉬운 표현 |
|------|------|----------|
| Prior | P(θ) | 데이터 보기 전 내 믿음 |
| Likelihood | P(D\|θ) | θ가 맞다면 이 데이터가 나올 가능성 |
| Posterior | P(θ\|D) | 데이터를 본 후 업데이트된 믿음 |
| Evidence | P(D) | 데이터가 관측될 전체 확률 (정규화) |

**쉽게 말하면**: 날씨 예보를 생각해보자.
- Prior: "이 계절엔 비 올 확률 30%"
- Likelihood: "이 구름 모양이 비가 올 때 자주 보인다"
- Posterior: "구름을 보고 나서 비 올 확률이 70%로 업데이트됨"

### 중급

Belief Update 과정:

```
[이전 posterior] → 새 데이터 D_new →  [새 prior] → 새 posterior
```

- 베이지안 추론은 순차 업데이트(sequential update)가 자연스럽다.
- 같은 데이터를 한번에 보거나, 나눠서 보거나 최종 결과는 같다 (일관성).

### 고급

**연구 포인트**: Prior 선택이 결과에 미치는 영향 분석.
- Jeffreys prior: 파라미터 변환에 불변한 무정보(non-informative) prior
  - $P(\theta) \propto \sqrt{I(\theta)}$ (I: Fisher Information)
- 데이터가 무한히 많아지면: posterior는 prior에 무관하게 MLE와 일치 (Bernstein-von Mises theorem)

## 3. MLE (Maximum Likelihood Estimation) ★★★

**한 줄 결론**: 관측된 데이터를 가장 잘 설명하는 파라미터를 찾는다 — prior 없이, 데이터만으로.

$$\hat{\theta}_{MLE} = \arg\max_\theta P(D | \theta) = \arg\max_\theta \mathcal{L}(\theta)$$

### 입문

**쉽게 말하면**: 동전을 10번 던져서 7번 앞면이 나왔다. 이 동전의 앞면 확률 θ가 얼마일 때, "10번 중 7번 앞면"이라는 결과가 가장 그럴듯할까? → 답: θ = 0.7

**남에게 설명하는 한 문장**: "데이터가 관측될 가능성(likelihood)을 최대로 만드는 파라미터가 MLE 추정값이다."

### 중급 — 핵심 유도 체인 (각 단계의 "왜" 포함)

**Step 1: i.i.d. 가정**

$$P(D|\theta) = P(x_1, x_2, \ldots, x_n | \theta)$$

**왜?** 데이터 포인트들이 서로 독립적으로, 같은 분포에서 추출됐다고 가정.
독립이므로 결합확률을 곱으로 분해할 수 있다.

$$= \prod_{i=1}^n P(x_i | \theta)$$

**Step 2: Log-Likelihood**

$$\ell(\theta) = \log P(D|\theta) = \sum_{i=1}^n \log P(x_i | \theta)$$

**왜?**
1. 곱(product)이 합(sum)으로 바뀐다 → 수치 계산이 쉬워진다.
2. 확률값은 0~1 사이 → 수백 개를 곱하면 0에 수렴 (underflow 방지).
3. log는 단조증가 함수 → argmax가 보존된다. $\arg\max \ell(\theta) = \arg\max P(D|\theta)$

**Step 3: Gradient = 0**

$$\frac{\partial \ell(\theta)}{\partial \theta} = 0$$

**왜?** 최댓값에서 기울기(gradient)는 0이다. 이것이 극값의 필요조건.

**Step 4: 해를 구함**

방정식을 풀어 $\hat{\theta}_{MLE}$ 를 구한다.

### 고급

**Fisher Information과 MLE의 점근적 성질**:

$$\sqrt{n}(\hat{\theta}_{MLE} - \theta^*) \xrightarrow{d} \mathcal{N}(0, I(\theta^*)^{-1})$$

- $I(\theta) = -\mathbb{E}\left[\frac{\partial^2 \log P(x|\theta)}{\partial \theta^2}\right]$ (Fisher Information)
- MLE는 점근적으로 **효율적** (Cramér-Rao 하한 달성)
- 단점: 데이터가 적을 때 overfitting 위험

**연구 포인트**: MLE는 prior를 쓰지 않으므로 데이터가 적을 때 불안정. MAP가 regularization 역할.

## 4. MAP (Maximum A Posteriori)

**한 줄 결론**: MLE에 prior 믿음을 더해, 데이터가 적을 때도 합리적인 추정을 한다.

$$\hat{\theta}_{MAP} = \arg\max_\theta P(\theta|D) = \arg\max_\theta P(D|\theta) \cdot P(\theta)$$

### 입문

**쉽게 말하면**: 동전을 3번 던져 3번 앞면이 나왔다. MLE라면 θ=1.0 (100% 앞면) 이라고 추정하지만, 실제론 말이 안 된다. MAP는 "공정한 동전일 가능성이 높다"는 prior 믿음을 반영해 θ를 0.5쪽으로 당긴다.

### 중급 — MLE vs MAP 비교

| | MLE | MAP |
|--|-----|-----|
| 목표 | P(D\|θ) 최대화 | P(D\|θ)·P(θ) 최대화 |
| Prior | 사용 안 함 | 사용함 |
| 데이터 적을 때 | 불안정, overfitting | Prior가 regularization |
| 데이터 많을 때 | MAP와 수렴 | MLE와 수렴 |

**Log-MAP**:

$$\hat{\theta}_{MAP} = \arg\max_\theta \left[\sum_{i=1}^n \log P(x_i|\theta) + \log P(\theta)\right]$$

$$= \arg\max_\theta \underbrace{\ell(\theta)}_\text{log-likelihood} + \underbrace{\log P(\theta)}_\text{log-prior (정규화 항)}$$

**핵심**: log P(θ) 항이 정규화(regularization)로 작용한다!

### 고급

**데이터가 적을수록 prior 영향이 커지는 이유**:

Gaussian-Gaussian 경우, posterior mean은:

$$\mu_{MAP} = \frac{\frac{n}{\sigma^2}}{\frac{n}{\sigma^2} + \frac{1}{\sigma_0^2}} \bar{x} + \frac{\frac{1}{\sigma_0^2}}{\frac{n}{\sigma^2} + \frac{1}{\sigma_0^2}} \mu_0$$

- n → 0: $\mu_{MAP} \to \mu_0$ (prior 지배)
- n → ∞: $\mu_{MAP} \to \bar{x}$ (MLE 지배)

**주의**: MAP는 점 추정(point estimate)이다. Full Bayesian은 posterior 전체 분포를 유지한다.

## 5. 킬러 유도 1: Gaussian → MSE ★★★

**한 줄 결론**: 노이즈가 Gaussian이라고 가정하면, MLE를 최대화하는 것이 MSE를 최소화하는 것과 동치다.

**남에게 설명하는 한 문장**: "MLE에서 Gaussian noise 가정을 넣으면 수식이 자동으로 MSE 형태로 나온다."

### 완전 유도 (단계별)

**설정**: 회귀 문제에서 각 데이터 포인트는

$$y_i = f_\theta(x_i) + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2)$$

**Step 1: Likelihood 설정**

$$P(y_i | x_i, \theta) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2}\right)$$

**Step 2: i.i.d. → Product**

$$P(D|\theta) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i - f_\theta(x_i))^2}{2\sigma^2}\right)$$

**Step 3: Log-Likelihood**

$$\ell(\theta) = \log P(D|\theta) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (y_i - f_\theta(x_i))^2$$

**Step 4: MLE = NLL 최소화**

상수항 제거, maximize ↔ minimize negative:

$$\hat{\theta}_{MLE} = \arg\max_\theta \ell(\theta) = \arg\min_\theta \sum_{i=1}^n (y_i - f_\theta(x_i))^2$$

$$= \arg\min_\theta \underbrace{\frac{1}{n}\sum_{i=1}^n (y_i - f_\theta(x_i))^2}_{\text{MSE}}$$

**결론**:

```
Gaussian noise 가정
    ↓ i.i.d.
Product of Gaussians
    ↓ log
Sum of squared terms - constant
    ↓ -1 곱하고 최소화
MSE Loss
```

**핵심**: MSE는 "Gaussian noise 하에서의 MLE"라는 확률적 근거를 가진다. 임의로 선택한 손실함수가 아니다.

## 6. 킬러 유도 2: Bernoulli → Cross Entropy ★★★

**한 줄 결론**: 이진 분류에서 각 레이블이 Bernoulli 분포를 따른다고 가정하면, NLL이 Cross Entropy Loss와 동치다.

**남에게 설명하는 한 문장**: "Bernoulli 모델의 MLE를 최대화하면, 식이 정확히 Binary Cross Entropy가 된다."

### 완전 유도 (단계별)

**설정**: 이진 분류. 모델이 $\hat{y}_i = P(y_i=1|x_i,\theta) \in [0,1]$ 을 출력.

**Step 1: Bernoulli Likelihood**

$$P(y_i|x_i,\theta) = \hat{y}_i^{y_i}(1-\hat{y}_i)^{1-y_i}$$

- $y_i=1$ 이면: $P = \hat{y}_i$
- $y_i=0$ 이면: $P = 1-\hat{y}_i$
- 이 한 줄로 두 경우를 동시에 표현한다.

**Step 2: i.i.d. → Product**

$$P(D|\theta) = \prod_{i=1}^n \hat{y}_i^{y_i}(1-\hat{y}_i)^{1-y_i}$$

**Step 3: Log-Likelihood**

$$\ell(\theta) = \sum_{i=1}^n \left[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\right]$$

**Step 4: NLL = Cross Entropy**

$$\mathcal{L}_{CE} = -\ell(\theta) = -\frac{1}{n}\sum_{i=1}^n \left[y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\right]$$

**결론**:

```
Bernoulli 분포 가정 (이진 레이블)
    ↓ i.i.d.
Product of Bernoullis
    ↓ log
Sum of log-probabilities
    ↓ -1 곱하고 최소화
Binary Cross Entropy Loss
```

**다중 클래스 (Categorical)로 확장**:

$$P(y_i = k | x_i, \theta) = \hat{p}_{ik}, \quad \sum_k \hat{p}_{ik} = 1$$

$$\mathcal{L}_{CE} = -\frac{1}{n}\sum_{i=1}^n \sum_k \mathbf{1}[y_i=k]\log \hat{p}_{ik} = -\frac{1}{n}\sum_{i=1}^n \log \hat{p}_{i, y_i}$$

**주의**: Softmax 출력 + Cross Entropy는 Categorical MLE다.

## 7. MAP와 Regularization의 관계 ★★

**한 줄 결론**: Regularization은 특정 prior 분포 가정 하의 MAP 추정이다.

### Gaussian Prior → L2 Regularization

Prior: $P(\theta) = \mathcal{N}(0, \frac{1}{2\lambda}I)$

$$\log P(\theta) = -\lambda \|\theta\|_2^2 + \text{const}$$

MAP 목적함수:

$$\hat{\theta}_{MAP} = \arg\min_\theta \underbrace{\mathcal{L}(\theta)}_\text{NLL} + \underbrace{\lambda\|\theta\|_2^2}_\text{L2 reg}$$

**결론**: **Gaussian prior = L2 (Ridge) regularization**

### Laplace Prior → L1 Regularization

Prior: $P(\theta) = \text{Laplace}(0, \frac{1}{\lambda}) \propto \exp(-\lambda|\theta|)$

$$\log P(\theta) = -\lambda\|\theta\|_1 + \text{const}$$

MAP 목적함수:

$$\hat{\theta}_{MAP} = \arg\min_\theta \mathcal{L}(\theta) + \lambda\|\theta\|_1$$

**결론**: **Laplace prior = L1 (Lasso) regularization → 희소(sparse) 해**

### 비교 요약

| Prior | Regularization | 효과 |
|-------|---------------|------|
| Gaussian | L2 | 파라미터를 작은 값으로 수축 |
| Laplace | L1 | 일부 파라미터를 정확히 0으로 |
| 없음 | 없음 | MLE (overfitting 위험) |

**핵심**: "Regularization은 prior 믿음의 수학적 표현이다."

## 8. 핵심 유도 체인 총정리 (1순위 시험 대비) ★★★

**한 줄 결론**: i.i.d. → product → log → gradient=0 → solve. 이 체인 하나로 딥러닝의 모든 손실함수를 유도할 수 있다.

```
[데이터 D = {x_1,...,x_n} i.i.d. 가정]
           ↓
[결합 가능도: L(θ) = ∏ P(x_i|θ)]
           ↓ log 취하기 (underflow 방지, 미분 용이)
[로그 가능도: ℓ(θ) = Σ log P(x_i|θ)]
           ↓ 최대화 ↔ -ℓ(θ) 최소화
[NLL: -ℓ(θ) = -Σ log P(x_i|θ)]
           ↓ 확률 모형 선택
     ┌─────┴─────┐
     │           │
 Gaussian      Bernoulli
     ↓              ↓
   MSE          Cross Entropy
           ↓ MAP = log-likelihood + log-prior
     ┌─────┴─────┐
     │           │
Gaussian prior  Laplace prior
     ↓               ↓
   L2 reg         L1 reg
```

### 각 케이스 한눈에 정리

| 가정 | 손실함수 | 수식 |
|------|---------|------|
| Gaussian noise (회귀) | MSE | $\frac{1}{n}\sum(y_i - \hat{y}_i)^2$ |
| Bernoulli (이진 분류) | BCE | $-\frac{1}{n}\sum[y_i\log\hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]$ |
| Categorical (다중 분류) | CE | $-\frac{1}{n}\sum\log\hat{p}_{i,y_i}$ |
| Gaussian prior (MAP) | MSE + L2 | $\text{MSE} + \lambda\|\theta\|_2^2$ |
| Laplace prior (MAP) | MSE + L1 | $\text{MSE} + \lambda\|\theta\|_1$ |

## 9. 시험 대비 질문 + 모범 답안 5개

---

### Q1. MLE의 유도 체인을 설명하고, Gaussian noise 가정에서 MSE가 나오는 과정을 쓰시오.

**모범 답안**:

MLE는 데이터를 가장 잘 설명하는 파라미터를 찾는 방법이다.

유도 체인: i.i.d. 가정으로 결합 가능도를 $L(\theta) = \prod P(x_i|\theta)$ 로 쓴다. 수치 안정성과 미분 편의를 위해 log를 취하면 $\ell(\theta) = \sum \log P(x_i|\theta)$. 최댓값에서 $\nabla_\theta \ell = 0$을 풀어 MLE를 구한다.

Gaussian → MSE 유도: 각 $y_i = f_\theta(x_i) + \epsilon_i$, $\epsilon_i \sim \mathcal{N}(0,\sigma^2)$ 가정 시 $P(y_i|x_i,\theta) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y_i-f_\theta(x_i))^2}{2\sigma^2}\right)$. 로그 가능도는 $\ell(\theta) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum(y_i - f_\theta(x_i))^2$. 최대화하면 $\arg\min \sum(y_i-f_\theta(x_i))^2 = \arg\min \text{MSE}$.

**핵심**: MSE는 Gaussian noise 가정 하의 MLE이다. 임의의 선택이 아니라 확률적 근거를 가진다.

---

### Q2. MAP와 MLE의 차이를 설명하고, MAP가 L2 regularization과 동치임을 보이시오.

**모범 답안**:

MLE: $\hat{\theta}_{MLE} = \arg\max P(D|\theta)$ — prior 없이 데이터만 사용.
MAP: $\hat{\theta}_{MAP} = \arg\max P(D|\theta)P(\theta)$ — prior를 포함.

차이: 데이터가 적을 때 MLE는 overfitting되지만, MAP는 prior가 regularization 역할을 한다. 데이터가 많아지면 두 추정값이 수렴한다.

L2 연결: Gaussian prior $P(\theta) = \mathcal{N}(0, \frac{1}{2\lambda}I)$ 가정 시, $\log P(\theta) = -\lambda\|\theta\|_2^2 + \text{const}$. MAP 목적함수: $\arg\max[\ell(\theta) + \log P(\theta)] = \arg\min[\text{NLL}(\theta) + \lambda\|\theta\|_2^2]$. 이것이 L2 (Ridge) regularization이다.

### Q3. 베이즈 정리를 이용해 Bernoulli likelihood에서 Cross Entropy가 유도됨을 보이시오.

**모범 답안**:

이진 분류에서 $y_i \in \{0,1\}$. 모델 출력 $\hat{y}_i = P(y_i=1|x_i,\theta)$.

Bernoulli likelihood: $P(y_i|x_i,\theta) = \hat{y}_i^{y_i}(1-\hat{y}_i)^{1-y_i}$

i.i.d. 가정: $P(D|\theta) = \prod_{i=1}^n \hat{y}_i^{y_i}(1-\hat{y}_i)^{1-y_i}$

로그 가능도: $\ell(\theta) = \sum_{i=1}^n[y_i\log\hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]$

NLL = Cross Entropy: $\mathcal{L}_{BCE} = -\frac{1}{n}\sum_{i=1}^n[y_i\log\hat{y}_i + (1-y_i)\log(1-\hat{y}_i)]$

**결론**: Binary Cross Entropy는 Bernoulli 모델의 NLL(Negative Log-Likelihood)이다.

### Q4. "데이터가 적을수록 prior의 영향이 커진다"는 것을 수식으로 설명하시오.

**모범 답안**:

Gaussian-Gaussian 켤레 사전분포에서 posterior mean은:

$$\mu_{MAP} = \underbrace{\frac{\frac{n}{\sigma^2}}{\frac{n}{\sigma^2} + \frac{1}{\sigma_0^2}}}_{\text{데이터 가중치}} \bar{x} + \underbrace{\frac{\frac{1}{\sigma_0^2}}{\frac{n}{\sigma^2} + \frac{1}{\sigma_0^2}}}_{\text{prior 가중치}} \mu_0$$

- n이 작을 때: prior 가중치 $\frac{1/\sigma_0^2}{n/\sigma^2 + 1/\sigma_0^2} \approx 1$, 즉 prior($\mu_0$) 지배.
- n → ∞일 때: 데이터 가중치 $\frac{n/\sigma^2}{n/\sigma^2 + 1/\sigma_0^2} \to 1$, 즉 MLE($\bar{x}$)에 수렴.

**직관**: 데이터가 없으면 prior만 남고, 데이터가 무한하면 prior의 영향이 무시된다.

### Q5. Laplace prior가 L1 regularization으로 이어지는 이유를 설명하고, L1과 L2 regularization의 효과 차이를 논하시오.

**모범 답안**:

Laplace prior: $P(\theta) \propto \exp(-\lambda|\theta|)$

$$\log P(\theta) = -\lambda\|\theta\|_1 + \text{const}$$

MAP 목적함수: $\arg\min[\text{NLL}(\theta) + \lambda\|\theta\|_1]$ → L1 regularization.

**차이**:
- L2 (Gaussian prior): 2차함수 형태의 페널티 → 파라미터를 0 근처로 **수축**시키지만 정확히 0이 되지 않음.
- L1 (Laplace prior): 절댓값 형태 → 0에서 기울기 불연속 → 최적해에서 일부 파라미터가 **정확히 0**이 됨 → 희소(sparse) 해.

**연구 포인트**: L1이 sparsity를 유도하는 이유는 Laplace 분포가 0 근처에서 Gaussian보다 뾰족하게 모여 있기 때문이다. 기하학적으로는 L1 제약이 다이아몬드 형태여서 코너에서 최적해를 가지기 쉽다.
