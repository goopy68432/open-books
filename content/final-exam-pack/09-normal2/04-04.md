# Part D: 확률과 확률분포 — 중학생부터 대학원까지

> **한 줄 결론**: 딥러닝 모델은 "데이터가 어떤 확률 분포에서 생성됐는가"를 가정하며, 그 가정에 맞는 loss 함수와 학습 방법이 결정된다.

---

## 1. 확률의 기본

### 쉽게 말하면
주사위를 던질 때 가능한 결과들의 목록이 표본공간이고, 그 중 우리가 관심 있는 결과의 집합이 사건이다. 확률은 그 사건이 얼마나 자주 일어나는지의 장기 평균이다.

### 3단계 설명

**입문**

- **표본공간 (Sample Space) Ω**: 실험에서 나올 수 있는 모든 결과의 집합
  - 동전: Ω = {앞, 뒤}
  - 주사위: Ω = {1, 2, 3, 4, 5, 6}
  - 이미지 분류: Ω = {cat, dog, bird, ...}

- **사건 (Event) A**: 표본공간의 부분집합
  - "짝수가 나온다" = {2, 4, 6} ⊂ {1, 2, 3, 4, 5, 6}

- **확률 P(A)**: 사건 A가 일어날 가능성 (0~1 사이 숫자)

**중급**

**확률의 3가지 공리 (Kolmogorov axioms)**:

1. 비음수성: 모든 사건 A에 대해 P(A) ≥ 0
2. 정규화: P(Ω) = 1 (반드시 어떤 결과가 나온다)
3. 가산 가법성: 서로소인 사건 A₁, A₂, ...에 대해
   $$P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)$$

이 3가지에서 모든 확률 이론이 파생된다.

중요 결과:
- P(Aᶜ) = 1 - P(A) (여사건)
- P(A ∪ B) = P(A) + P(B) - P(A ∩ B) (포함-배제 원리)
- P(∅) = 0

**고급**

확률의 해석:
- **빈도론 (Frequentist)**: P(A) = 무한히 반복했을 때 A가 나오는 비율. 객관적, 반복 가능한 실험에 적합.
- **베이지안 (Bayesian)**: P(A) = 사건 A에 대한 주관적 믿음의 강도(degree of belief). 일회성 사건에도 적용 가능.

딥러닝과의 연결:
- 베이지안 딥러닝: 가중치 W를 확률변수로 보고 사후 분포 P(W|data)를 추론
- 빈도론적 딥러닝: 고정된 W를 MLE로 추정

### 핵심:
표본공간 = 가능한 모든 결과, 사건 = 표본공간의 부분집합, 확률 = 3개의 공리를 만족하는 [0,1] 값.

### 남에게 설명하는 한 문장:
"확률은 Kolmogorov의 3가지 공리를 만족하는 사건의 크기 측정이며, 딥러닝에서는 데이터 생성 과정을 모델링하는 기본 언어다."

## 2. 조건부확률 (Conditional Probability)

### 쉽게 말하면
"비가 왔다는 사실을 알고 있을 때, 내일도 비가 올 확률"처럼 어떤 정보가 주어진 상황에서의 확률이다. 정보가 추가되면 확률이 업데이트된다.

### 3단계 설명

**입문**

$$P(A|B) = \frac{P(A \cap B)}{P(B)} \quad \text{(단, P(B) > 0)}$$

직관: B라는 좁은 세계 안에서 A가 차지하는 비율

수치 예시: 학생 100명 중 수학 잘하는 학생 40명, 물리도 잘하는 학생 20명, 둘 다 잘하는 학생 15명.
- P(물리|수학) = P(물리 ∩ 수학) / P(수학) = 15/100 ÷ 40/100 = 15/40 = 0.375

**중급**

**전체 확률 법칙 (Law of Total Probability)**:

B₁, B₂, ..., Bₙ이 Ω의 분할이면:
$$P(A) = \sum_{i=1}^n P(A|B_i) P(B_i)$$

**Bayes' Theorem (베이즈 정리)**:
$$P(B|A) = \frac{P(A|B) P(B)}{P(A)} = \frac{P(A|B) P(B)}{\sum_i P(A|B_i) P(B_i)}$$

용어:
- P(B): 사전 확률 (prior) — 관측 전 믿음
- P(A|B): 우도 (likelihood) — 모델이 데이터를 설명하는 능력
- P(B|A): 사후 확률 (posterior) — 데이터 관측 후 업데이트된 믿음

**고급**

딥러닝에서 조건부확률의 역할:

분류 문제에서 모델이 학습하는 것:
$$P(Y = k | X = x; \theta) = \text{softmax}(f_\theta(x))_k$$

이것은 입력 x가 주어졌을 때 클래스 k일 조건부 확률이다.

생성 모델에서:
- VAE: P(x|z) 모델링 (디코더)
- Diffusion: P(x_t-1|x_t) 모델링 (역방향 과정)
- GPT: P(x_t|x_1,...,x_{t-1}) 모델링 (자기회귀)

Bayes 정리의 머신러닝 적용:
$$P(\theta | \mathcal{D}) = \frac{P(\mathcal{D} | \theta) P(\theta)}{P(\mathcal{D})}$$
- P(D|θ): likelihood (데이터가 파라미터를 얼마나 잘 설명하는가)
- P(θ): prior (파라미터의 사전 믿음 = regularization)
- P(θ|D): posterior (학습 후 파라미터의 분포)

### 핵심:
조건부확률 = 어떤 사건이 발생했다는 정보가 주어진 상황에서의 업데이트된 확률. 딥러닝 모델은 본질적으로 조건부 분포를 모델링한다.

### 주의:
P(A|B) ≠ P(B|A). 이 혼동이 많은 오류를 낳는다 (예: "진단이 양성이면 실제 병에 걸렸을 확률" vs "병에 걸렸을 때 양성이 나올 확률"). Bayes 정리로 변환해야 한다.

### 남에게 설명하는 한 문장:
"조건부확률은 특정 정보가 주어진 상태에서의 업데이트된 확률이며, Bayes 정리를 통해 학습 전후의 믿음 변화를 수학적으로 표현한다."

## 3. 독립 (Independence)

### 쉽게 말하면
첫 번째 동전을 던진 결과가 두 번째 동전 결과에 전혀 영향을 미치지 않는다. 이처럼 두 사건이 서로 전혀 상관없을 때 독립이라고 한다.

### 3단계 설명

**입문**

두 사건 A, B가 독립이면:
$$P(A \cap B) = P(A) \cdot P(B)$$

동치 조건:
$$P(A|B) = P(A) \quad \text{(B를 알아도 A의 확률이 변하지 않음)}$$

예시:
- 동전 두 번 던지기: "1번이 앞"과 "2번이 앞"은 독립
- 주사위: "짝수"와 "3 이상"은 독립이 아님 (P(짝수|3이상) = 2/4 ≠ P(짝수) = 3/6)

**중급**

**조건부 독립 (Conditional Independence)**:
$$P(A \cap B | C) = P(A|C) \cdot P(B|C)$$

"C를 알고 있을 때 A와 B는 독립"

예시: X → Y → Z에서 Y를 안다면 X와 Z는 조건부 독립
- "날씨 → 우산 사용 → 젖음": 우산을 알면 날씨와 젖음이 조건부 독립

**왜 i.i.d. 가정이 likelihood를 단순화하는가:**

데이터 D = {x₁, x₂, ..., xₙ}이 i.i.d. (independently and identically distributed)이면:
$$P(\mathcal{D}|\theta) = \prod_{i=1}^n P(x_i|\theta)$$

곱셈 = 덧셈 (log 적용 후):
$$\log P(\mathcal{D}|\theta) = \sum_{i=1}^n \log P(x_i|\theta)$$

이 단순화가 없다면 n개 데이터의 결합분포를 직접 모델링해야 함 → 불가능

**고급**

i.i.d. 가정의 한계와 이를 다루는 연구:

실제 데이터는 i.i.d.가 아닌 경우가 많다:
1. **시계열 데이터**: x_t는 x_{t-1}에 의존 → RNN, Transformer로 처리
2. **도메인 시프트**: 훈련/테스트 데이터의 분포가 다름 → Domain Adaptation
3. **소규모 배치**: 미니배치 내 샘플들이 완전히 독립이 아님 → Batch Normalization이 이를 이용

Naive Bayes 분류기: 특징들이 클래스가 주어졌을 때 조건부 독립이라 가정
$$P(x_1,...,x_n|y) = \prod_{i=1}^n P(x_i|y)$$
단순한 가정이지만 텍스트 분류에서 놀랍도록 잘 작동.

### 핵심:
독립 = 한 사건의 발생이 다른 사건의 확률을 변경하지 않음. i.i.d. 가정 덕분에 결합 확률을 개별 확률의 곱으로 분해할 수 있다.

### 주의:
상관관계 없음(uncorrelated) ≠ 독립. 독립이면 상관관계가 없지만, 상관관계가 없다고 반드시 독립인 것은 아니다. (예: X~Uniform(-1,1), Y=X²는 E[XY]=0이지만 독립이 아님)

### 남에게 설명하는 한 문장:
"독립은 두 사건이 서로에게 전혀 정보를 주지 않는 관계이며, i.i.d. 가정은 데이터의 결합 확률을 개별 확률의 단순한 곱으로 분해해 학습을 가능하게 한다."

## 4. 확률변수 (Random Variable)

### 쉽게 말하면
주사위 던지기의 결과(1,2,3,4,5,6)처럼 "무작위 실험의 결과를 숫자로 변환하는 함수"다. 결과를 숫자로 만들어야 수학 계산이 가능하기 때문이다.

### 3단계 설명

**입문**

확률변수 X: Ω → R (표본공간에서 실수로의 함수)

예시:
- 동전: X(앞) = 1, X(뒤) = 0
- 주사위: X = 나온 숫자 (이미 숫자)
- 이미지: X = "고양이면 1, 아니면 0"

**이산 확률변수 vs 연속 확률변수**:

| 구분 | 이산 (Discrete) | 연속 (Continuous) |
|---|---|---|
| 값 | 셀 수 있음 (정수, 유한) | 셀 수 없음 (실수 구간) |
| 분포 함수 | PMF (확률 질량 함수) | PDF (확률 밀도 함수) |
| 합/적분 | Σ P(X=x) = 1 | ∫ f(x) dx = 1 |
| 예시 | 동전 앞면 수, 단어 개수 | 키, 온도, 픽셀 값 |

**중급**

**PMF (Probability Mass Function)**:
$$P(X = x_i) = p_i, \quad \sum_i p_i = 1, \quad p_i \geq 0$$

**PDF (Probability Density Function)**:
$$f(x) \geq 0, \quad \int_{-\infty}^{\infty} f(x) dx = 1$$
$$P(a \leq X \leq b) = \int_a^b f(x) dx$$

주의: PDF에서 P(X = x) = 0 (연속 확률변수에서 특정 값의 확률은 0)

**CDF (Cumulative Distribution Function)**:
$$F(x) = P(X \leq x) = \int_{-\infty}^x f(t) dt$$

**고급**

딥러닝에서 확률변수의 역할:

1. **입력 데이터 x**: 확률분포 P_data(x)에서 샘플링된 확률변수
2. **레이블 y|x**: 조건부 확률변수 (클래스 예측)
3. **가중치 W**: 베이지안 딥러닝에서 확률변수 취급
4. **잠재 변수 z**: VAE에서 z ~ N(0, I), 디코더가 P(x|z) 모델링
5. **노이즈 ε**: Diffusion에서 ε ~ N(0, I), 역방향 과정으로 데이터 복원

확률변수의 변환:
X ~ P이고 Y = g(X)일 때 Y의 분포? (Change of Variables)
$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{dg^{-1}}{dy}\right|$$
→ 정규화 흐름(Normalizing Flow)의 수학적 기반

### 핵심:
확률변수 = 표본공간을 실수로 매핑하는 함수. 이산/연속에 따라 PMF/PDF로 분포를 기술하며, 딥러닝의 데이터, 레이블, 잠재변수 모두 확률변수다.

### 남에게 설명하는 한 문장:
"확률변수는 무작위 실험 결과를 수학적으로 다룰 수 있게 숫자로 변환하는 함수이며, 딥러닝의 입력·출력·잠재변수 모두 확률변수로 모델링된다."

## 5. Bernoulli 분포

### 쉽게 말하면
동전 던지기처럼 두 가지 결과만 있는 확률 모델이다. 딥러닝의 이진 분류(positive/negative)와 정확히 대응한다.

### 3단계 설명

**입문**

$$P(X = 1) = p, \quad P(X = 0) = 1 - p, \quad 0 \leq p \leq 1$$

통합 표기:
$$P(X = x) = p^x (1-p)^{1-x}, \quad x \in \{0, 1\}$$

예시:
- 불량품 검사: 불량이면 X=1 (p=0.03)
- 이메일 스팸 여부: 스팸이면 X=1
- 의학 진단: 양성이면 X=1

**중급**

통계량:
- 기대값: E[X] = p
- 분산: Var(X) = p(1-p) — p=0.5에서 최대 (불확실성 최대)

**왜 이진 분류에서 자연스러운가:**

모델 출력 f_θ(x) ∈ (0, 1)를 P(Y=1|X=x)로 해석.
Sigmoid 함수가 이 역할을 함:
$$\sigma(z) = \frac{1}{1+e^{-z}} \in (0,1)$$

손실 함수 유도:
$$-\log P(y|x;\theta) = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$$
→ Binary Cross-Entropy Loss!

즉, BCE loss = Bernoulli 분포 가정 하의 negative log-likelihood.

**고급**

Bernoulli 분포와 정보 이론:
- Entropy: H(Bernoulli(p)) = -p log p - (1-p) log(1-p) (bits)
- p=0 또는 p=1: H=0 (완전한 확실성)
- p=0.5: H=1 bit (최대 불확실성)

Cross-Entropy Loss의 의미:
$$\text{BCE} = \mathbb{E}_{y \sim P_{data}}[-\log P_{model}(y|x)]$$

= H(P_data, P_model) (교차 엔트로피)
= H(P_data) + KL(P_data || P_model)

KL divergence를 최소화 = BCE loss 최소화.

다중 레이블 분류: 각 레이블에 독립 Bernoulli를 적용 → sigmoid + BCE per label

### 핵심:
Bernoulli 분포 = 이진 결과의 확률 모델. BCE loss는 Bernoulli 분포 가정 하의 negative log-likelihood다.

### 주의:
Bernoulli의 확장이 Binomial(이항) 분포: n번 독립 시행 중 성공 횟수. Bernoulli는 n=1인 특수 경우.

### 남에게 설명하는 한 문장:
"Bernoulli 분포는 이진 결과를 모델링하며, 딥러닝의 이진 분류 손실함수(BCE)는 이 분포에서의 최대우도추정에서 자연스럽게 유도된다."

## 6. Gaussian (정규) 분포 ★★★

### 쉽게 말하면
자연계에서 가장 흔하게 나타나는 종 모양의 대칭 분포다. 평균 주변에 많이 몰려있고 멀어질수록 급격히 줄어든다. 딥러닝에서 잡음(noise) 모델의 기본값이다.

### 3단계 설명

**입문**

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

핵심 파라미터:
- μ (mu): 평균 — 분포의 중심
- σ² (sigma squared): 분산 — 분포의 퍼짐 정도
- σ: 표준편차

표기: X ~ N(μ, σ²)

직관:
- μ=0, σ²=1: 표준 정규분포 N(0,1)
- σ가 클수록 종 모양이 납작해짐 (넓게 퍼짐)
- μ가 바뀌면 종 모양이 좌우로 이동

경험 법칙 (68-95-99.7 rule):
- P(μ-σ ≤ X ≤ μ+σ) ≈ 68%
- P(μ-2σ ≤ X ≤ μ+2σ) ≈ 95%
- P(μ-3σ ≤ X ≤ μ+3σ) ≈ 99.7%

**중급**

통계량:
- E[X] = μ
- Var(X) = σ²
- Mode (최빈값) = Median (중앙값) = μ (대칭)
- Moment generating function: M(t) = exp(μt + σ²t²/2)

다변수 Gaussian: X ~ N(μ, Σ)
$$f(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top \Sigma^{-1} (\mathbf{x}-\boldsymbol{\mu})\right)$$

- μ: 평균 벡터 (d차원)
- Σ: 공분산 행렬 (d×d, 양정치 대칭)

**왜 잡음 모델로 자주 쓰이는가:**
1. 수학적으로 다루기 쉬움 (지수 함수, 미분 closed-form)
2. 중심극한정리: 많은 독립 요인의 합 → 정규분포
3. Maximum Entropy: 평균·분산이 고정될 때 가장 "편향 없는" 분포
4. Gaussian끼리 더하면 Gaussian (폐쇄성)

**고급**

MSE Loss와 Gaussian의 관계:

y = f_θ(x) + ε, ε ~ N(0, σ²) 가정 시:
$$-\log P(y|x;\theta) = \frac{(y - f_\theta(x))^2}{2\sigma^2} + \text{const}$$

σ²을 상수로 보면, **MSE Loss 최소화 = Gaussian noise 가정 하의 MLE**.

KL Divergence between Gaussians:
$$KL(N(\mu_1, \sigma_1^2) \| N(\mu_2, \sigma_2^2)) = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1-\mu_2)^2}{2\sigma_2^2} - \frac{1}{2}$$

VAE에서 핵심: KL(q(z|x) || p(z)) = KL(N(μ, σ²) || N(0, I))의 closed-form 계산 가능:
$$KL = \frac{1}{2}\sum_j \left(\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1\right)$$

딥러닝에서 Gaussian이 등장하는 곳:
1. **가중치 초기화**:
   - Xavier: W ~ N(0, 1/fan_in)
   - He: W ~ N(0, 2/fan_in) (ReLU 전용)
2. **Dropout**: Gaussian Dropout은 multiplicative 버전
3. **VAE**: 잠재공간 z ~ N(μ, σ²), 사전분포 N(0,I)
4. **Diffusion**: 각 단계에서 Gaussian 노이즈 추가
5. **Data Augmentation**: 가우시안 잡음 추가

### 핵심:
Gaussian 분포 = 종 모양, 평균+분산으로 완전히 결정. MSE loss는 이 분포 가정에서 나오며, 딥러닝의 초기화·잠재변수·잡음 모델의 표준이다.

### 주의:
Gaussian은 꼬리가 얇다 (thin tail). 실세계에서 극단값이 Gaussian보다 자주 발생하는 경우 (fat-tail 분포), Gaussian 가정이 틀릴 수 있다. 금융 데이터, 자연어의 단어 빈도 등이 이 경우에 해당.

### 연구 포인트:
**Score Matching과 Diffusion Models**: Diffusion은 각 노이즈 수준에서 ∇_x log p(x) (score function)를 학습한다. Gaussian 노이즈를 단계적으로 추가하면 score function이 tractable해지는 것이 핵심 아이디어다.

### 남에게 설명하는 한 문장:
"Gaussian 분포는 중심극한정리로 자연에서 가장 흔히 나타나며, MSE loss는 이 분포의 negative log-likelihood로 유도되고 딥러닝의 잡음 모델·잠재공간의 표준이다."

## 7. CLT (중심극한정리)

### 쉽게 말하면
"각자 다른 방식으로 기여하는 1000명의 학생 성적을 합치면 어떤 분포가 됐든 결국 종 모양(정규분포)이 된다." 독립적인 랜덤 요소를 많이 더하면 항상 Gaussian으로 수렴한다.

### 3단계 설명

**입문**

**CLT**: X₁, X₂, ..., Xₙ이 평균 μ, 분산 σ²인 i.i.d. 확률변수이면:

$$\bar{X}_n = \frac{X_1 + X_2 + \cdots + X_n}{n}$$

n → ∞일 때:
$$\sqrt{n}(\bar{X}_n - \mu) \xrightarrow{d} N(0, \sigma^2)$$

쉬운 표현: 표본 평균은 n이 충분히 크면 N(μ, σ²/n)에 가깝다.

수치 예시: 주사위(μ=3.5, σ²=2.92) 100번의 평균
- 이론: ~ N(3.5, 0.0292)
- 표준오차 = σ/√n = 1.71/10 = 0.171
- 95% 범위: 3.5 ± 2×0.171 = [3.158, 3.842]

**중급**

CLT가 성립하기 위한 조건:
- i.i.d. (독립 동일 분포) — 실제로는 약화 가능
- 유한한 평균과 분산
- n이 충분히 커야 함 (경험적으로 n ≥ 30이면 대체로 OK)

**왜 정규분포가 보편적인가 (CLT 관점)**:
실제 현상들은 많은 작고 독립적인 요인의 합으로 결정됨:
- 키 = 유전 수백 개 + 영양 + 환경 + ... → 정규분포
- 측정 오차 = 수많은 소음원의 합 → 정규분포
- 가격 변동 = 수많은 독립 거래의 합 → (대략) 정규분포

**고급**

CLT의 일반화:

1. **Lindeberg-Lévy CLT**: 기본 형태 (i.i.d. 가정)
2. **Lyapunov CLT**: 독립이지만 동일 분포가 아닌 경우로 확장
3. **Functional CLT (Donsker's theorem)**: 확률 과정으로 확장 → Brownian motion 이론
4. **CLT for dependent data**: 시계열 데이터에서의 확장 (Mixing conditions)

딥러닝에서 CLT의 활용:

1. **무한 폭 신경망 = Gaussian Process**: 1층 신경망에서 뉴런 수 → ∞이면 CLT에 의해 출력이 Gaussian Process로 수렴 (Neal, 1996)
2. **미니배치 그래디언트의 근사**: 미니배치 그래디언트 = 전체 그래디언트의 추정치. 배치 크기 B가 크면 CLT에 의해 분산 ∝ 1/B
3. **BatchNorm의 정당화**: 배치 내 정규화 = 중간 특징의 분포를 Gaussian 근사로 정규화

### 핵심:
CLT = 독립 확률변수의 합은 n이 크면 정규분포로 수렴. 자연과 딥러닝 모두에서 Gaussian이 편재하는 근본 이유.

### 주의:
CLT는 "수렴"이지 정확히 정규분포라는 뜻이 아니다. 꼬리 부분에서는 오차가 클 수 있다 (Berry-Esseen 정리: 오차 ≤ C·ρ/(σ³·√n)).

### 남에게 설명하는 한 문장:
"CLT는 독립적인 많은 요인의 합이 원래 분포와 무관하게 정규분포로 수렴함을 보장하며, 이것이 Gaussian이 자연과 딥러닝에서 보편적인 이유다."

## 8. 기대값, 분산

### 쉽게 말하면
기대값은 "평균적으로 얼마가 나오는가", 분산은 "평균에서 얼마나 멀리 흩어져 있는가"다. 복잡한 분포를 두 숫자로 요약하는 것.

### 3단계 설명

**입문**

**기대값 (Expected Value, Mean)**:
- 이산: $E[X] = \sum_x x \cdot P(X=x)$
- 연속: $E[X] = \int_{-\infty}^{\infty} x f(x) dx$

예시: 주사위 E[X] = 1·(1/6) + 2·(1/6) + ... + 6·(1/6) = 21/6 = 3.5

**분산 (Variance)**:
$$\text{Var}(X) = E[(X-\mu)^2] = E[X^2] - (E[X])^2$$

표준편차: $\sigma = \sqrt{\text{Var}(X)}$ (기대값과 같은 단위)

예시: 주사위 E[X²] = (1+4+9+16+25+36)/6 = 91/6 ≈ 15.17
- Var(X) = 15.17 - 3.5² = 15.17 - 12.25 = 2.92

**중급**

**기대값의 선형성** (가장 중요한 성질):
$$E[aX + bY] = aE[X] + bE[Y]$$
(X, Y가 독립이 아니어도 성립!)

**분산의 성질**:
$$\text{Var}(aX + b) = a^2 \text{Var}(X)$$

독립일 때:
$$\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y)$$

**공분산 (Covariance)**:
$$\text{Cov}(X, Y) = E[(X-E[X])(Y-E[Y])] = E[XY] - E[X]E[Y]$$

**상관계수 (Correlation)**:
$$\rho(X,Y) = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y} \in [-1, 1]$$

**고급**

딥러닝에서 기대값과 분산의 역할:

**1. Loss의 기대값 = 일반화 목표**:
$$\mathcal{L}(\theta) = \mathbb{E}_{(x,y)\sim P_{data}}[\ell(f_\theta(x), y)]$$
실제로는 유한 샘플로 근사: $\hat{\mathcal{L}} = \frac{1}{n}\sum_i \ell(f_\theta(x_i), y_i)$

**2. Bias-Variance Tradeoff**:
임의의 점 x에서 예측 오차 분해:
$$E[(y - \hat{f}(x))^2] = \underbrace{(E[\hat{f}(x)] - f(x))^2}_{\text{Bias}^2} + \underbrace{E[(\hat{f}(x) - E[\hat{f}(x)])^2]}_{\text{Variance}} + \underbrace{\sigma^2_\epsilon}_{\text{Irreducible Noise}}$$

- Bias: 모델의 평균 예측이 실제에서 얼마나 벗어나는가
- Variance: 다른 훈련 데이터에서 모델이 얼마나 달라지는가
- 딥러닝에서는 과잉파라미터화로 bias와 variance를 동시에 낮출 수 있다는 "Double Descent" 현상 발견

**3. Batch Normalization의 수학**:
각 레이어 출력을 배치 내에서 정규화:
$$\hat{x}_i = \frac{x_i - E_{\text{batch}}[x]}{\sqrt{\text{Var}_{\text{batch}}[x] + \epsilon}}$$
기대값 0, 분산 1로 만들어 학습 안정화.

**4. 몬테카를로 추정**:
$$E[f(X)] \approx \frac{1}{N}\sum_{i=1}^N f(x_i), \quad x_i \sim P(X)$$
분산 감소 기법: Importance Sampling, Control Variates

### 핵심:
기대값 = 분포의 중심, 분산 = 분포의 퍼짐. 딥러닝에서 loss는 기대값으로 정의되고, 분산 감소가 학습 안정화의 핵심이다.

### 주의:
E[f(X)] ≠ f(E[X]) (Jensen's 부등식: f가 볼록이면 E[f(X)] ≥ f(E[X])). log는 오목 함수이므로 E[log X] ≤ log E[X]. 이 성질이 ELBO(변분 하한)의 근거.

### 연구 포인트:
**Double Descent 현상**: 모델 복잡도가 증가하면 bias-variance tradeoff 이론상 일정 구간에서 test error가 증가해야 하지만, 과잉파라미터화 모델에서는 다시 감소한다. 이는 전통적인 통계학의 예측과 다른 딥러닝의 미스터리 중 하나다.

### 남에게 설명하는 한 문장:
"기대값과 분산은 확률분포의 중심과 퍼짐을 요약하는 두 핵심 통계량이며, 딥러닝의 loss 정의·Batch Normalization·Bias-Variance Tradeoff 모두 이 개념에 기반한다."

### Q1. Bayes' Theorem을 이용하여 딥러닝의 MAP (Maximum A Posteriori) 추정이 왜 L2 정규화와 동치인지 설명하라.

**모범 답안**:

**Bayes' Theorem 적용**:
$$P(\theta|\mathcal{D}) \propto P(\mathcal{D}|\theta) \cdot P(\theta)$$

**MAP 추정**: 사후확률을 최대화하는 θ:
$$\hat{\theta}_{MAP} = \arg\max_\theta \log P(\mathcal{D}|\theta) + \log P(\theta)$$

**가우시안 Prior 가정**: θ ~ N(0, τ²I)
$$\log P(\theta) = -\frac{1}{2\tau^2}\|\theta\|^2 + \text{const}$$

**Gaussian Likelihood 가정**: y|x,θ ~ N(f_θ(x), σ²)
$$\log P(\mathcal{D}|\theta) = -\frac{1}{2\sigma^2}\sum_i(y_i - f_\theta(x_i))^2 + \text{const}$$

**합산**:
$$\hat{\theta}_{MAP} = \arg\min_\theta \sum_i(y_i - f_\theta(x_i))^2 + \underbrace{\frac{\sigma^2}{\tau^2}}_{\lambda}\|\theta\|^2$$

→ **L2 정규화(Weight Decay)와 완전히 동치!**

해석: L2 정규화의 강도 λ = σ²/τ² = (노이즈 분산)/(Prior 분산)
- τ가 작을수록 (강한 Prior): λ가 크고 가중치가 0에 가깝게 강제됨
- σ가 클수록 (큰 노이즈): λ가 크고 더 강하게 정규화

### Q2. 왜 분류 문제에서 Cross-Entropy Loss를 사용하고 MSE Loss를 사용하지 않는가? 확률론적 관점에서 설명하라.

**모범 답안**:

**MSE Loss의 문제 (분류에서)**:

MSE는 Gaussian 노이즈 가정에서 나온다: y ~ N(f_θ(x), σ²)
분류에서 실제 레이블은 0 또는 1 (이진) 또는 one-hot (다중)이므로 Gaussian 가정 부적합.

MSE with sigmoid의 실제 문제:
- f_θ(x)가 크게 틀렸을 때 (예: sigmoid 출력 0.001, 실제 1), 그래디언트 계산:
  $$\frac{\partial \text{MSE}}{\partial z} = (ŷ - y) \cdot ŷ(1-ŷ) \approx (-1)(0.001)(0.999) \approx -0.001$$
- 그래디언트 소실! 틀렸는데도 업데이트가 거의 안 됨

**Cross-Entropy의 장점 (Bernoulli 가정)**:
$$\frac{\partial \text{BCE}}{\partial z} = -(y - ŷ) = -(1 - 0.001) = -0.999$$
틀린 정도에 비례하는 그래디언트 → 빠른 학습

**수학적 정당화**:
분류에서 y ~ Bernoulli(f_θ(x)) 가정이 적절:
$$-\log P(y|x;\theta) = -[y\log\hat{y} + (1-y)\log(1-\hat{y})] = \text{BCE}$$

→ 분류 문제에서 올바른 확률 모델 가정 = BCE loss.

### Q3. i.i.d. 가정이 MLE에서 어떻게 log-likelihood의 합산으로 이어지는지 수식으로 보여라.

**모범 답안**:

**결합 likelihood (i.i.d. 가정 적용)**:

D = {x₁, x₂, ..., xₙ} 독립 관측치이면:
$$P(\mathcal{D}|\theta) = \prod_{i=1}^n P(x_i|\theta)$$
(독립이므로 결합 확률 = 개별 확률의 곱)

**MLE 목적함수**: 이 확률을 최대화
$$\hat{\theta}_{MLE} = \arg\max_\theta \prod_{i=1}^n P(x_i|\theta)$$

**문제**: 곱셈 → 수치적으로 매우 작은 값 (언더플로우)

**해결**: log를 취하면 (log는 단조증가이므로 argmax 불변):
$$\hat{\theta}_{MLE} = \arg\max_\theta \sum_{i=1}^n \log P(x_i|\theta)$$

**이점**:
1. 수치 안정성 (언더플로우 방지)
2. 곱셈 → 덧셈 (계산 효율)
3. 경험적 분포와의 KL divergence 최소화와 동치

i.i.d. 가정이 없다면 P(D|θ)를 직접 모델링해야 하는데, 이는 일반적으로 불가능하다. 예를 들어 시계열에서는 자기회귀 분해를 사용: P(x₁,...,xₙ) = ∏ P(xₜ|x₁,...,x_{t-1}) — 각 조건부가 다른 복잡한 형태.

### Q4. 가우시안 분포의 Maximum Entropy 성질이란 무엇이며, 딥러닝에서 왜 중요한가?

**모범 답안**:

**Maximum Entropy 원리**:

평균 μ와 분산 σ²이 고정되어 있을 때, 이 제약조건을 만족하는 분포 중 엔트로피가 최대인 분포는 N(μ, σ²)이다.

엔트로피: $H[p] = -\int p(x) \log p(x) dx$

N(μ, σ²)의 엔트로피: $H = \frac{1}{2}\log(2\pi e \sigma^2)$ (nats)

**증명 스케치 (Lagrange Multiplier)**:
$$\max_p H[p] \quad \text{s.t.} \quad \int p\,dx = 1, \quad \int xp\,dx = \mu, \quad \int x^2 p\,dx = \mu^2 + \sigma^2$$
Lagrange 조건에서 최적해: $p(x) \propto \exp(-ax^2 - bx) = \text{Gaussian}$

**딥러닝에서의 중요성**:

1. **잠재공간 설계 (VAE)**: 잠재 변수 z의 prior를 N(0,I)로 설정하는 이유 — 평균 0, 분산 1이라는 제약 하에서 "가장 정보가 없는" (most uninformative) 분포

2. **가중치 초기화**: 출력 분산을 제어하는 제약 하에서 가장 중립적인 초기화 → Xavier/He initialization의 이론적 근거

3. **Regularization 해석**: 가우시안 Prior (L2 정규화)는 "파라미터에 대한 정보가 없을 때" 가장 편향 없는 사전 분포

4. **노이즈 모델**: 실제 노이즈 분포를 모를 때, 분산이 고정되면 Gaussian 가정이 가장 보수적(conservative) 선택

**결론**: Gaussian은 수학적 편의성뿐 아니라 "제한된 정보 하에서 가장 적은 가정을 하는 분포"라는 정보-이론적 정당화가 있다.

### Q5. Bernoulli 분포와 Categorical 분포의 관계를 설명하고, 딥러닝 분류에서 sigmoid와 softmax가 각각 언제 사용되는지 수식과 함께 설명하라.

**모범 답안**:

**Bernoulli vs Categorical**:

| 분포 | 클래스 수 | 출력 | 활성화 | Loss |
|---|---|---|---|---|
| Bernoulli | 2 (이진) | P(Y=1) 하나 | sigmoid | BCE |
| Categorical | K (다중) | P(Y=k), k=1,...,K | softmax | CE |

Categorical은 Bernoulli의 일반화: K=2이면 동치

**Sigmoid (이진 분류)**:
$$\hat{y} = P(Y=1|x) = \sigma(z) = \frac{1}{1+e^{-z}} \in (0,1)$$

y ~ Bernoulli(ŷ)이면:
$$L_{BCE} = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$$

**Softmax (다중 분류)**:
$$\hat{y}_k = P(Y=k|x) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}, \quad \sum_k \hat{y}_k = 1$$

y ~ Categorical(ŷ)이면 (one-hot y):
$$L_{CE} = -\sum_{k=1}^K y_k \log\hat{y}_k = -\log\hat{y}_{y^*}$$

(y*: 정답 클래스)

**중요한 차이**: sigmoid는 각 클래스가 독립적(합 ≠ 1 가능), softmax는 합 = 1 강제.

**다중 레이블 분류** (한 샘플에 여러 레이블 가능): sigmoid를 각 레이블에 독립적으로 사용 (softmax 불적합 — 레이블들이 상호배타적이지 않으므로)

**수치 안정성**: softmax 계산 시 오버플로우 방지:
$$\text{softmax}(z_k) = \frac{e^{z_k - \max z}}{\sum_j e^{z_j - \max z}}$$

## 핵심 킬러 요약

| 개념 | 한 줄 핵심 |
|---|---|
| 확률의 기본 | 표본공간·사건·Kolmogorov 공리 3개로 모든 확률 이론이 유도됨 |
| 조건부확률 | P(A|B) = P(A∩B)/P(B). 딥러닝 모델은 P(y|x)를 모델링 |
| 독립 | P(A∩B)=P(A)P(B). i.i.d. 덕분에 결합 likelihood = 개별 likelihood의 곱 |
| 확률변수 | 표본공간 → 실수. 이산(PMF)과 연속(PDF)으로 구분 |
| Bernoulli | 이진 결과. BCE loss = Bernoulli 가정 하의 negative log-likelihood |
| Gaussian | 평균+분산으로 완전히 결정. MSE loss의 확률론적 근거. CLT의 수렴점 |
| CLT | 많은 i.i.d. 합 → Gaussian으로 수렴. Gaussian이 보편적인 근본 이유 |
| 기대값·분산 | 분포의 중심과 퍼짐. Bias-Variance Tradeoff의 수학적 기반 |
