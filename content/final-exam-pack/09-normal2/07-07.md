## 서술형 모범답안 (핵심만)

**24.** Span은 주어진 벡터들의 모든 선형결합의 집합으로, "이 벡터들로 도달할 수 있는 모든 점". Basis는 span하면서 선형독립인 벡터 집합으로, 공간을 표현하는 **최소 충분 세트**. Dimension은 basis 벡터의 수로, 공간의 **자유도**를 나타냄. 관계: basis가 space를 span → basis 수 = dimension. Basis가 필요한 이유: 중복 없이(선형독립) 공간 전체를 표현(span)하는 가장 효율적인 좌표계를 제공.

**25.** 고유값 분해(A=PDP⁻¹)는 **정방행렬**에만 적용 가능하고, n개 선형독립 고유벡터가 필요. SVD(A=UΣVᵀ)는 **모든 행렬**(비정방 포함)에 적용 가능. SVD의 U, V는 직교행렬이므로 수치적으로 안정. 특이값은 항상 실수이고 비음수. 따라서 SVD가 차원축소, 압축, 추천시스템, 자연어처리 등에 범용적으로 활용.

**26.** Gradient ∇f는 각 변수에 대한 편미분을 원소로 갖는 벡터. 이 벡터의 방향은 함수가 가장 빠르게 증가하는 방향이고, 크기는 그 증가율. 따라서 loss를 줄이려면 gradient의 **반대 방향**으로 파라미터를 이동: θ ← θ - η∇L. 이것이 Gradient Descent의 핵심 원리.

**27.** i.i.d.(독립 동일 분포) 가정이 있어야 결합확률 P(x₁,...,xₙ|θ)를 P(x₁|θ)·P(x₂|θ)·...·P(xₙ|θ)으로 분해 가능. 이 가정 없으면 모든 데이터 간 의존관계를 모델링해야 하므로 계산이 기하급수적으로 복잡해짐. 독립 가정이 likelihood를 곱으로 만들고, 로그를 취하면 합이 되어 미분이 용이.

**28.**
1. 데이터 모델: y_i = f(x_i; θ) + ε, ε ~ N(0, σ²)
2. 단일 데이터 likelihood: P(y_i|x_i, θ) = (1/√(2πσ²)) exp(-(y_i - f(x_i;θ))²/2σ²)
3. i.i.d. 가정으로 전체 likelihood: L(θ) = Π P(y_i|x_i, θ)
4. Log-likelihood: log L = Σ[-1/2 log(2πσ²) - (y_i - f(x_i;θ))²/2σ²]
5. Negative log-likelihood 최소화 = -log L 최소화. 상수항(-N/2 log(2πσ²))은 θ와 무관 → 제거
6. 남은 항: (1/2σ²) Σ(y_i - f(x_i;θ))² = **MSE(에 상수배)**

따라서 Gaussian noise 가정 아래 MLE = MSE 최소화.

**29.**
- **Entropy** H(p) = -Σp(x)log p(x): 분포 p 자체의 불확실성/정보량
- **Cross Entropy** H(p,q) = -Σp(x)log q(x): 실제 분포 p를 모델 q로 인코딩할 때의 평균 비용
- **KL Divergence** D_KL(p‖q) = Σp(x)log(p(x)/q(x)): 두 분포의 차이 (비대칭)
- 관계: **H(p,q) = H(p) + D_KL(p‖q)**
- H(p)는 정답 분포의 entropy → 학습 중 상수 → Cross Entropy 최소화 = KL 최소화
- 즉, Cross Entropy를 loss로 쓰면 모델 q가 실제 p에 가까워지도록 학습하는 것과 동치.

**30.**
- **CNN**: locality(지역성) + translation invariance(이동 불변성)이라는 강한 구조적 prior. 이미지에서 인접 픽셀이 관련성이 높다는 사전 지식을 건축적으로 내장. 장점: 적은 데이터로도 학습 가능. 단점: 전역적 관계 포착에 한계.
- **Transformer**: 구조적 prior가 약함 (self-attention은 모든 위치를 동등하게 참조). 장점: 높은 표현력(expressivity), 전역 패턴 학습 가능. 단점: 대규모 데이터가 필요.
- Trade-off: Inductive bias ↑ → 데이터 효율 ↑, 표현력 ↓ / Inductive bias ↓ → 표현력 ↑, 데이터 요구 ↑
- ViT는 대규모 데이터(JFT-300M)에서 CNN을 능가, 소규모에서는 CNN이 유리.
