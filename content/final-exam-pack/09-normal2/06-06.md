# Part F: 딥러닝 연결 주제 + 정보이론 — 중학생부터 대학원까지

> **핵심 킬러 요약**: 손실함수는 임의가 아니라 확률 모형에서 유도되고, 정보이론은 그 손실함수의 의미를 설명한다.
> Softmax, Cross Entropy, KL Divergence, Attention은 하나의 거대한 확률적 관점으로 연결된다.

---

## 1. Softmax ★★★

**한 줄 결론**: 임의의 실수 점수 벡터를 합이 1인 확률 분포로 바꾸는 함수다.

$$\text{softmax}(z_i) = \frac{\exp(z_i)}{\sum_{j=1}^K \exp(z_j)}$$

### 입문 (중학생 수준)

**쉽게 말하면**: 시험에서 국어 90점, 영어 70점, 수학 85점을 받았다. 이 점수들을 "국어를 제일 잘한다고 얼마나 확신하는가?"처럼 확률로 바꾸고 싶다. softmax가 바로 그 변환이다.

- 점수가 높을수록 확률이 크게 올라간다 (exp 때문에 지수적으로).
- 모든 확률의 합은 정확히 1이 된다.

**왜 확률분포가 되는가**:
1. $\exp(z_i) > 0$ → 모든 원소가 양수 (양수 조건 충족)
2. $\frac{\exp(z_i)}{\sum_j \exp(z_j)}$의 합 = $\frac{\sum_i \exp(z_i)}{\sum_j \exp(z_j)} = 1$ (합=1 조건 충족)

**남에게 설명하는 한 문장**: "Softmax는 실수 점수를 지수함수로 변환하여 양수로 만든 뒤, 전체 합으로 나눠서 확률 분포를 만드는 함수다."

### 중급

**Overflow 방지 트릭 (max 빼기)**:

$\exp(z_i)$에서 $z_i$가 크면 수치 overflow 발생. 해결책:

$$\text{softmax}(z_i) = \frac{\exp(z_i - \max_j z_j)}{\sum_j \exp(z_j - \max_j z_j)}$$

**왜 동일한가**: 분자 분모에 같은 상수 $\exp(-c)$를 곱한 것. 비율이 유지되므로 결과값 불변.

```python
def softmax_stable(z):
    z = z - z.max()  # overflow 방지
    exp_z = np.exp(z)
    return exp_z / exp_z.sum()
```

### 고급 — Temperature Scaling

$$\text{softmax}_\tau(z_i) = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}$$

| 온도 τ | 효과 |
|--------|------|
| τ → 0 | argmax와 동일 (확실한 분포, 가장 큰 값에 집중) |
| τ = 1 | 표준 softmax |
| τ → ∞ | 균일 분포 (uniform) |

**활용**: Language model의 temperature sampling (창의성 조절), Knowledge Distillation (soft label 생성).

**연구 포인트**: Gumbel-Softmax trick으로 이산 변수를 미분 가능하게 근사.

## 2. Softmax 미분 ★★

**한 줄 결론**: Softmax의 편미분은 대각 항과 비대각 항이 다른 형태를 가지며, Jacobian 행렬로 표현된다.

$$\frac{\partial \text{softmax}(z)_i}{\partial z_j} = \text{softmax}(z)_i (\delta_{ij} - \text{softmax}(z)_j)$$

여기서 $\delta_{ij}$는 Kronecker delta: $i=j$이면 1, $i \neq j$이면 0.

### 입문

$s_i = \text{softmax}(z_i)$라 하자.

### 중급 — 두 경우로 나누어 유도

**경우 1: $i = j$ (대각 항)**

$$\frac{\partial s_i}{\partial z_i} = \frac{\exp(z_i)\sum_k \exp(z_k) - \exp(z_i)\exp(z_i)}{(\sum_k \exp(z_k))^2}$$

$$= \frac{\exp(z_i)}{\sum_k \exp(z_k)} \cdot \left(1 - \frac{\exp(z_i)}{\sum_k \exp(z_k)}\right) = s_i(1 - s_i)$$

**경우 2: $i \neq j$ (비대각 항)**

$$\frac{\partial s_i}{\partial z_j} = \frac{0 \cdot \sum_k \exp(z_k) - \exp(z_i)\exp(z_j)}{(\sum_k \exp(z_k))^2} = -s_i s_j$$

**통합 표현**: $\frac{\partial s_i}{\partial z_j} = s_i(\delta_{ij} - s_j)$

**Jacobian 행렬 (K×K)**:

$$J = \text{diag}(\mathbf{s}) - \mathbf{s}\mathbf{s}^T$$

### 고급

**왜 대각·비대각이 나뉘는가**: $s_i$가 $z_j$에 의존하는 경로가 두 개이기 때문.
1. $z_j$가 직접 분자에 영향 (i=j일 때만)
2. $z_j$가 분모(합) 전체에 영향 (항상)

**Cross Entropy와 결합 시 편리함**: Loss $L = -\log s_{y}$ 에서

$$\frac{\partial L}{\partial z_j} = s_j - \mathbf{1}[j = y]$$

즉, softmax 출력에서 정답 레이블을 뺀 것. 역전파가 매우 간단해진다.

**연구 포인트**: Jacobian이 rank-1 update 형태 ($\text{diag}(\mathbf{s}) - \mathbf{s}\mathbf{s}^T$)이므로, 역전파를 행렬 곱 없이 $O(K)$에 계산 가능.

## 3. Entropy (엔트로피) ★★

**한 줄 결론**: 확률 분포의 불확실성(놀라움의 평균)을 측정하는 값이다.

$$H(p) = -\sum_x p(x) \log p(x) = \mathbb{E}_p[-\log p(x)]$$

### 입문

**쉽게 말하면**: 동전을 던진다.
- 공정한 동전 (앞:50%, 뒤:50%) → 결과를 예측하기 어렵다 → **엔트로피 최대**
- 무게중심이 한쪽으로 치우친 동전 (앞:99%, 뒤:1%) → 거의 확실하게 예측 가능 → **엔트로피 작음**
- 앞면만 나오는 동전 (앞:100%) → 완전히 확실 → **엔트로피 = 0**

**정보량 (self-information)**: 사건 $x$의 정보량 = $-\log p(x)$
- 드문 사건이 일어나면 → 정보량이 크다 (놀랍다).
- 흔한 사건이 일어나면 → 정보량이 작다 (당연하다).

엔트로피 = **정보량의 기대값**

**남에게 설명하는 한 문장**: "엔트로피는 확률 분포가 얼마나 불확실한지를 나타내며, 균일할수록 최대이고 하나의 값에 집중될수록 0에 가깝다."

### 중급

**최대 엔트로피**: K개 클래스에서 균일 분포일 때 $H = \log K$.

**최소 엔트로피**: 하나의 결과가 확실할 때 $H = 0$.

이진 엔트로피 함수 ($K=2$, $p$: 앞면 확률):

$$H(p) = -p\log p - (1-p)\log(1-p)$$

- $p=0.5$일 때 최대값 $\log 2 \approx 0.693$ (nat 단위) 또는 1 (bit 단위).

### 고급

**연속 분포의 미분 엔트로피 (Differential Entropy)**:

$$h(p) = -\int p(x)\log p(x) dx$$

**주의**: 미분 엔트로피는 음수가 될 수 있다. (이산 엔트로피는 항상 ≥ 0)

**Gaussian의 미분 엔트로피**: $h(\mathcal{N}(\mu,\sigma^2)) = \frac{1}{2}\log(2\pi e \sigma^2)$

**연구 포인트**: Maximum Entropy Principle — 제약 조건을 만족하는 분포 중 가장 불확실한 (엔트로피가 최대인) 분포를 선택하는 원리. Softmax의 이론적 근거.

## 4. Cross Entropy ★★★

**한 줄 결론**: 실제 분포 p를 예측 분포 q로 인코딩(표현)할 때 필요한 평균 비트 수다.

$$H(p, q) = -\sum_x p(x) \log q(x)$$

### 입문

**쉽게 말하면**: 실제 정답 분포가 $p$이고, 모델이 예측한 분포가 $q$일 때,
- 모델이 완벽하면 ($q = p$): Cross Entropy = Entropy (최소)
- 모델이 틀리면: Cross Entropy > Entropy (더 많은 비트 필요)

**왜 분류 loss로 쓰이는가**: $p$를 정답 레이블 (one-hot), $q$를 모델 출력 (softmax)으로 놓으면:

$$H(p, q) = -\sum_k p_k \log q_k = -\log q_{y}$$

($y$: 정답 클래스 인덱스) → 정답 클래스의 예측 확률의 negative log.

**남에게 설명하는 한 문장**: "Cross Entropy는 실제 분포 p를 잘못된 분포 q로 표현할 때의 비효율성을 측정하며, q를 p에 가깝게 만들수록 줄어든다."

### 중급

**One-hot label 경우**:

$$\mathcal{L}_{CE} = -\log \hat{p}_{y} = -\log \text{softmax}(z_y)$$

모델이 정답에 높은 확률을 부여할수록 loss가 줄어든다.

**부드러운 레이블 (Label Smoothing)**:

one-hot 대신 $p_k = (1-\epsilon)\mathbf{1}[k=y] + \frac{\epsilon}{K}$ 사용.

→ 과신뢰(over-confidence) 방지, 일반화 성능 향상.

### 고급

**Cross Entropy = Entropy + KL Divergence** (다음 섹션 6에서 자세히):

$$H(p, q) = H(p) + D_{KL}(p \| q)$$

- $H(p)$: 실제 분포의 엔트로피 (상수, q와 무관)
- $D_{KL}(p\|q)$: p와 q의 차이

**결론**: Cross Entropy 최소화 = KL Divergence 최소화 (H(p) 상수이므로).

**연구 포인트**: Label Smoothing의 정보이론적 해석 — Cross Entropy target을 soft label로 바꾸는 것은 teacher distribution을 사용하는 것과 같다.

## 5. KL Divergence ★★

**한 줄 결론**: 두 확률 분포 p와 q의 차이를 측정하며, p 관점에서 q를 사용할 때의 정보 손실이다.

$$D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = \mathbb{E}_p\left[\log \frac{p(x)}{q(x)}\right]$$

### 입문

**쉽게 말하면**: p가 진짜 분포, q가 우리가 근사한 분포일 때,
- p로 인코딩 → H(p) 비트 필요
- q로 인코딩 → H(p,q) 비트 필요
- KL = 추가로 낭비된 비트 수

**남에게 설명하는 한 문장**: "KL Divergence는 분포 p를 분포 q로 근사할 때 얼마나 정보를 잃는지 측정하며, 두 분포가 같으면 0이다."

### 중급

**왜 비대칭인가 ($D_{KL}(p\|q) \neq D_{KL}(q\|p)$)**:

$$D_{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$
$$D_{KL}(q\|p) = \sum_x q(x)\log\frac{q(x)}{p(x)}$$

- p의 관점에서 q를 평가 vs q의 관점에서 p를 평가 → 가중치가 다름.
- $D_{KL}(p\|q)$: p가 높은 곳에서 q가 낮으면 크게 페널티 → "forward KL"
- $D_{KL}(q\|p)$: q가 높은 곳에서 p가 낮으면 크게 페널티 → "reverse KL"

**왜 거리(metric)가 아닌가**:
1. 비대칭: $D_{KL}(p\|q) \neq D_{KL}(q\|p)$ → 거리의 대칭성 위반
2. 삼각 부등식 성립 보장 안 됨

**KL ≥ 0 (Gibbs' inequality)**:

Jensen's inequality로 증명: $\log$는 오목함수이므로

$$-D_{KL}(p\|q) = \sum_x p(x)\log\frac{q(x)}{p(x)} \leq \log\sum_x p(x)\frac{q(x)}{p(x)} = \log 1 = 0$$

따라서 $D_{KL}(p\|q) \geq 0$, 등호는 $p = q$일 때.

### 고급

**Forward KL vs Reverse KL의 실제 차이**:

| | Forward KL (MLE) | Reverse KL (VI) |
|--|-----------------|-----------------|
| 최소화 | $D_{KL}(p\|q)$ | $D_{KL}(q\|p)$ |
| 특성 | mean-seeking, zero-avoiding | mode-seeking |
| 활용 | MLE 학습 | Variational Inference |

**연구 포인트**: Jensen-Shannon divergence는 대칭화된 KL: $JSD(p\|q) = \frac{1}{2}D_{KL}(p\|m) + \frac{1}{2}D_{KL}(q\|m)$, $m = \frac{p+q}{2}$. GAN의 이론적 분석에 사용.

## 6. Entropy, Cross Entropy, KL의 관계

**한 줄 결론**: Cross Entropy = 자체 엔트로피 + KL Divergence. 이 분해가 학습 손실함수의 이론적 근거다.

$$H(p, q) = H(p) + D_{KL}(p \| q)$$

### 증명

$$H(p, q) = -\sum_x p(x)\log q(x)$$

$$= -\sum_x p(x)\log p(x) + \sum_x p(x)\log \frac{p(x)}{q(x)}$$

$$= H(p) + D_{KL}(p \| q) \quad \blacksquare$$

### 왜 중요한가

**학습에서의 의미**:
- $p$: 실제(정답) 분포 → 학습 중 변하지 않음
- $q$: 모델 예측 분포 → 학습으로 업데이트
- $H(p)$는 상수 → $H(p,q)$를 최소화 = $D_{KL}(p\|q)$를 최소화

```
Cross Entropy 최소화
        ↕ 동치 (H(p) 상수이므로)
KL Divergence 최소화
        ↕ 동치 (KL ≥ 0, 등호는 p=q)
모델 분포 q → 실제 분포 p
```

**쉽게 말하면**: "딥러닝 학습 = 예측 분포를 정답 분포에 가깝게 만드는 과정 = Cross Entropy 최소화 = KL 최소화."

**연구 포인트**: VAE에서 ELBO = 재구성 손실 (Cross Entropy) + KL 정규화 항. 이 두 항의 균형이 latent space의 구조를 결정한다.

## 7. Attention ★★

**한 줄 결론**: 쿼리(Q)와 키(K)의 유사도로 중요도를 계산하고, 그 가중치로 값(V)을 합산하는 메커니즘이다.

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

### 입문

**쉽게 말하면**: 도서관에서 책을 찾는다.
- Q (Query): "딥러닝 관련 책을 찾고 싶다"
- K (Key): 각 책의 "제목, 태그, 분류"
- V (Value): 실제 책의 내용

Q와 K를 비교해서 관련성이 높은 책에 높은 가중치를 주고, 그 책의 내용(V)을 가중 합산한다.

**남에게 설명하는 한 문장**: "Attention은 쿼리와 키의 내적으로 유사도를 계산하고, softmax로 정규화한 뒤, 값의 가중합을 구해 관련 정보를 선택적으로 수집한다."

### 중급 — 각 연산의 의미

| 연산 | 수식 | 의미 |
|------|------|------|
| 유사도 계산 | $QK^T$ | 모든 쿼리-키 쌍의 내적 (유사도) |
| 스케일링 | $/ \sqrt{d_k}$ | 차원이 커지면 내적값 커짐 → 기울기 안정화 |
| 정규화 | softmax(·) | 유사도를 확률(가중치)로 변환, 합=1 |
| 정보 수집 | ·V | 가중치로 값(Value)을 가중합산 |

**왜 $\sqrt{d_k}$로 나누는가**:
- Q, K가 각 원소 분산 1인 경우, $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$의 분산은 $d_k$.
- 분산이 크면 softmax 입력이 커져서 gradient vanishing 발생.
- $\sqrt{d_k}$로 나눠서 분산을 1로 맞춤.

**Multi-Head Attention**:

$$\text{MHA}(Q,K,V) = \text{Concat}(\text{head}_1,\ldots,\text{head}_h)W^O$$
$$\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

각 head가 서로 다른 유사도 공간을 학습한다.

### 고급

**Self-Attention**: Q=K=V=X (동일한 시퀀스에서 추출). 시퀀스 내 모든 위치 간의 관계를 한 번에 계산.

**Complexity**: 시퀀스 길이 n에 대해 $O(n^2 d)$ → 긴 시퀀스에서 병목. 해결책: Sparse Attention, Linear Attention.

**연구 포인트**: Attention의 정보이론적 해석 — softmax 가중치가 분포 $\alpha$를 형성하며, $V$의 가중합은 $\mathbb{E}_\alpha[V]$. Attention heads의 엔트로피가 집중도를 측정한다.

## 8. CNN vs Transformer — Inductive Bias ★★

**한 줄 결론**: CNN은 강한 구조적 prior(지역성, 이동 불변성)로 효율적이지만 제한적이고, Transformer는 약한 prior로 유연하지만 데이터를 더 많이 요구한다.

**남에게 설명하는 한 문장**: "CNN과 Transformer의 핵심 차이는 데이터에 대해 어떤 구조적 가정(inductive bias)을 갖느냐이다."

### 입문

**Inductive Bias란**: 학습 데이터 외에 모델이 미리 갖고 있는 구조적 가정.

마치 "도로 표지판은 일반적으로 사각형이다"는 사전 지식이 있으면 표지판을 더 빨리 찾을 수 있는 것처럼.

### 중급

| | CNN | Transformer |
|--|-----|-------------|
| **Locality** | 강함: 3×3 커널 → 주변 픽셀만 봄 | 약함: 모든 위치를 봄 |
| **Translation Invariance** | 있음: 같은 커널이 모든 위치에 공유 | 없음 (Position Embedding으로 보완) |
| **장거리 의존성** | 약함: 여러 층을 쌓아야 | 강함: Self-Attention이 한 번에 처리 |
| **데이터 요구량** | 적음 (강한 prior) | 많음 (약한 prior) |
| **표현력** | 낮음 | 높음 |

**Inductive Bias vs Expressivity Trade-off**:

- 강한 prior → 데이터 효율 좋음, 표현력 제한
- 약한 prior → 더 많은 데이터 필요, 더 유연하게 학습

### 고급

**CNN의 Inductive Bias 수식적 표현**:
- Weight sharing: $f_l(x)_{i,j} = \sum_{u,v} w_{u,v} \cdot x_{i+u, j+v}$ (같은 $w$가 모든 위치에 적용)
- Translation equivariance: $f(T(x)) = T(f(x))$ (T: 이동 변환)

**Transformer의 Expressivity**:
- Universal approximation (충분한 head, layer): 임의의 시퀀스-투-시퀀스 함수를 근사 가능
- 데이터가 충분하면 CNN보다 우수한 성능 (ViT vs ResNet)

**연구 포인트**: Convolution은 Attention의 특수한 경우다 — 고정된 지역 mask를 가진 attention으로 해석 가능. ConvNeXt는 Transformer의 설계 원칙을 CNN에 적용한 시도.

**주의**: "CNN이 나쁘다"가 아니다. 데이터가 적고 공간적 구조가 명확한 문제에서는 CNN이 여전히 강력하다.

## 9. 선형모델 → 신경망 → CNN → Transformer

**한 줄 결론**: 표현력(expressivity)은 증가하지만 데이터 요구량과 계산 비용도 함께 증가한다.

### 발전 단계

```
선형 모델 → 신경망(MLP) → CNN → Transformer
    ↑              ↑          ↑          ↑
가장 단순    비선형성 추가  공간 prior  관계 prior 없음
Inductive    활성화 함수   추가         (최대 표현력)
Bias 강함                              데이터 많이 필요
```

### 각 단계에서 추가된 것

| 모델 | 추가 요소 | 표현 가능한 것 |
|------|----------|--------------|
| **선형 모델** | - | 선형 결정 경계 |
| **MLP** | 비선형 활성화(ReLU 등) | 임의의 연속 함수 (UAT) |
| **CNN** | 국소 연결, 가중치 공유 | 공간적 계층 패턴 (엣지→텍스처→물체) |
| **Transformer** | Self-Attention | 임의의 쌍방향 관계 (전역 의존성) |

**Universal Approximation Theorem (UAT)**: 하나의 은닉층 MLP는 충분한 뉴런이 있으면 임의의 연속함수를 근사할 수 있다.

**쉽게 말하면**:
- 선형 모델: 직선으로만 분류
- MLP: 어떤 모양이든 분류 가능 (이론상)
- CNN: 이미지처럼 공간적 구조가 있는 데이터에 특화
- Transformer: 문장, 이미지, 단백질 등 관계가 복잡한 데이터에 특화

### 데이터 요구량과의 관계

- 표현력이 높을수록 더 많은 데이터 없이는 overfitting
- CNN: 수천 ~ 수만 장으로도 좋은 성능
- Transformer (ViT): 수백만 장 이상이 필요한 경우가 많음

**연구 포인트**: 적은 데이터에서 Transformer를 쓰려면 → Pre-training + Fine-tuning (전이학습). Inductive bias의 부족을 데이터 효율로 보완.

## 10. 손실함수는 확률모형에서 유도된다 (총정리)

**한 줄 결론**: 손실함수는 임의로 선택된 것이 아니라, 데이터에 대한 확률적 가정(noise model)에서 수학적으로 유도된다.

**남에게 설명하는 한 문장**: "Gaussian noise를 가정하면 MSE가, Bernoulli 모델을 가정하면 Cross Entropy가 자연스럽게 나온다."

### 통합 유도 체인

```
문제 정의
    ↓
확률 모형 선택 (noise/likelihood 가정)
    ↓
i.i.d. 가정 → 결합 가능도: L(θ) = ∏ P(x_i|θ)
    ↓
로그 취하기: ℓ(θ) = Σ log P(x_i|θ)
    ↓
NLL 최소화: -ℓ(θ)
    ↓
┌─────────────────┬────────────────────┐
│ Gaussian noise  │ Bernoulli/Softmax  │
│ y = fθ(x) + ε  │ P(y|x) = σ(fθ(x)) │
│ ε ~ N(0, σ²)   │                    │
└────────┬────────┴──────────┬─────────┘
         ↓                   ↓
       MSE Loss         Cross Entropy
 Σ(yi - ŷi)²/n    -Σ[yi log ŷi + (1-yi)log(1-ŷi)]
         ↓                   ↓
    + Gaussian prior    + Bernoulli prior
         ↓                   ↓
  MSE + L2 (Ridge)    CE + regularization
```

### 정보이론과의 연결

| 손실함수 | 확률 해석 | 정보이론 해석 |
|---------|----------|--------------|
| MSE | Gaussian NLL | 제곱 거리 최소화 |
| Cross Entropy | Categorical NLL | 분포 q를 분포 p에 근사 |
| KL Divergence | NLL - Entropy | 정보 손실 |
| L2 Regularization | MAP (Gaussian prior) | 파라미터 복잡도 제한 |
| L1 Regularization | MAP (Laplace prior) | 희소 파라미터 선호 |

**핵심**: 딥러닝의 손실함수 설계 = 데이터 생성 과정(generative process)에 대한 확률적 가정.

### Q1. Softmax 함수가 확률 분포를 형성하는 이유를 설명하고, overflow 방지 트릭을 서술하시오.

**모범 답안**:

Softmax: $\text{softmax}(z_i) = \frac{\exp(z_i)}{\sum_j \exp(z_j)}$

**확률 분포인 이유**:
1. 양수성: $\exp(z_i) > 0$ → 모든 원소 양수
2. 합이 1: $\sum_i \text{softmax}(z_i) = \frac{\sum_i \exp(z_i)}{\sum_j \exp(z_j)} = 1$

**Overflow 방지**: $z_i$가 크면 $\exp(z_i)$ → ∞. 해결: 상수 $c = \max_j z_j$를 빼면

$$\text{softmax}(z_i) = \frac{\exp(z_i - c)}{\sum_j \exp(z_j - c)}$$

분자·분모에 $e^{-c}$를 곱한 것이므로 값 불변. $z_i - c \leq 0$ 이므로 overflow 없음.

**핵심**: temperature parameter τ를 추가하면 분포의 날카로움(peakiness)을 조절할 수 있다.

### Q2. KL Divergence가 비대칭인 이유와 왜 거리 함수(metric)가 아닌지 설명하시오. 또한 KL ≥ 0을 증명하시오.

**모범 답안**:

**비대칭 이유**: $D_{KL}(p\|q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$와 $D_{KL}(q\|p) = \sum_x q(x)\log\frac{q(x)}{p(x)}$는 기대값의 가중 분포가 다르다 (p 기대값 vs q 기대값).

예: p = (0.9, 0.1), q = (0.5, 0.5)이면
- $D_{KL}(p\|q)$: p가 높은 곳(x=1)에서 q가 낮으면 크게 페널티
- $D_{KL}(q\|p)$: q가 높은 곳(x=2)에서 p가 낮으면 크게 페널티

**거리가 아닌 이유**: 대칭성 미충족 ($D_{KL}(p\|q) \neq D_{KL}(q\|p)$), 삼각 부등식 보장 안 됨.

**KL ≥ 0 증명** (Jensen's inequality 이용):

$\log$는 strictly concave이므로: $\mathbb{E}[\log X] \leq \log \mathbb{E}[X]$

$$-D_{KL}(p\|q) = \mathbb{E}_p\left[\log\frac{q}{p}\right] \leq \log\mathbb{E}_p\left[\frac{q}{p}\right] = \log\sum_x q(x) = \log 1 = 0$$

따라서 $D_{KL}(p\|q) \geq 0$, 등호: $p=q$.

### Q3. Cross Entropy, Entropy, KL Divergence의 관계를 수식으로 보이고, 딥러닝 학습에서의 의미를 설명하시오.

**모범 답안**:

$$H(p, q) = -\sum_x p(x)\log q(x)$$

$$= -\sum_x p(x)\log p(x) + \sum_x p(x)\log\frac{p(x)}{q(x)} = H(p) + D_{KL}(p\|q)$$

**딥러닝에서의 의미**:
- $p$: 정답 레이블 분포 (one-hot 또는 soft) → 학습 중 불변
- $q = q_\theta$: 모델 예측 분포 → 파라미터 θ로 학습
- $H(p)$: θ에 무관한 상수

따라서 $\arg\min_\theta H(p, q_\theta) = \arg\min_\theta D_{KL}(p\|q_\theta)$

**결론**: Cross Entropy 학습 = 모델 분포를 데이터 분포에 가깝게 만드는 것 (KL 최소화).

### Q4. Attention 메커니즘을 수식으로 쓰고, QK^T의 의미와 √dk로 나누는 이유를 설명하시오.

**모범 답안**:

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

**$QK^T$의 의미**: Q의 각 행(쿼리 벡터)과 K의 각 행(키 벡터)의 내적. 내적이 클수록 두 벡터가 유사(cosine similarity와 연관). 결과: $(n_q \times n_k)$ 유사도 행렬.

**$\sqrt{d_k}$로 나누는 이유**: Q, K의 각 원소가 평균 0, 분산 1일 때, $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$의 분산은 $d_k$. 분산이 크면 softmax 입력의 일부가 매우 커져 softmax가 one-hot에 가까워짐 → gradient vanishing. $\sqrt{d_k}$로 나눠 분산을 1로 정규화하여 학습을 안정화.

**전체 흐름**: 유사도 계산($QK^T$) → 스케일링($\sqrt{d_k}$ 나누기) → 가중치 정규화(softmax) → 정보 수집(V 가중합).

### Q5. CNN과 Transformer의 inductive bias 차이를 비교하고, 각각 어떤 상황에서 유리한지 설명하시오.

**모범 답안**:

| | CNN | Transformer |
|--|-----|-------------|
| Locality | 강함 (커널 크기 내 지역 연결) | 없음 (Self-Attention은 전역) |
| Weight Sharing | 있음 (같은 커널이 전체 적용) | 없음 |
| Translation Inv. | 있음 | 없음 (Position Embedding 필요) |
| 장거리 의존성 | 약함 (깊게 쌓아야) | 강함 (O(1) 경로) |

**CNN이 유리한 상황**:
- 데이터가 적을 때 (강한 inductive bias = 데이터 효율)
- 이미지처럼 공간적 지역성이 명확한 데이터
- 계산 자원이 제한적인 엣지 디바이스

**Transformer가 유리한 상황**:
- 데이터가 충분할 때 (weak prior의 단점을 데이터로 극복)
- 텍스트, 음성처럼 장거리 의존성이 중요한 데이터
- 다양한 modality를 통합할 때 (Vision-Language 등)

**핵심**: Inductive bias는 expressivity와 trade-off 관계. 강한 prior = 데이터 효율적, 약한 prior = 더 유연하지만 데이터 많이 필요.
