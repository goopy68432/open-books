# 입문 1: 수학 기호를 한국어로 번역하기

입문 단계의 목표는 계산이 아닙니다. 식을 보고 "무슨 행동을 하라는 말인지" 읽는 것입니다.

## 1. 식은 명령문이다

| 기호 | 읽는 법 | 행동 |
|---|---|---|
| $\sum$ | 시그마 | 여러 항을 더한다 |
| $\prod$ | 파이 | 여러 항을 곱한다 |
| $\int$ | 적분 | 연속적인 넓이/가중합을 구한다 |
| $\partial$ | 편미분 | 여러 변수 중 하나만 움직인다 |
| $\propto$ | 비례 | 정규화 상수는 생략하고 모양만 본다 |
| $\sim$ | 따른다 | 확률변수의 분포를 선언한다 |
| $\hat{\theta}$ | theta hat | 데이터로 추정한 값 |
| $\delta_{ij}$ | 크로네커 델타 | 인덱스가 같으면 1, 다르면 0 |
| $\arg\max$ | 아그맥스 | 최댓값을 만드는 입력을 찾는다 |
| $\|\cdot\|$ | 노름 | 벡터의 길이 |

## 2. 핵심 식 번역 훈련

### $\sum_{i=1}^n y_i=k$

번역:

> $y_1$부터 $y_n$까지 모두 더했더니 $k$가 나왔다.

Bernoulli 자료에서는 $y_i$가 0 또는 1이므로, $k$는 성공 횟수입니다.

### $L(\theta)=\prod_{i=1}^n p(y_i|\theta)$

번역:

> 각 관측값이 나올 가능성을 모두 곱해서, $\theta$가 얼마나 그럴듯한지 보는 함수다.

여기서 데이터 $y_i$는 이미 관측되어 고정이고, $\theta$가 변수입니다.

### $\ell(\theta)=\log L(\theta)$

번역:

> 우도에 로그를 씌워 계산하기 쉬운 형태로 바꾼다.

로그는 단조증가이므로 최댓값을 만드는 $\theta$는 바뀌지 않습니다.

### $\frac{\partial p_i}{\partial z_j}$

번역:

> 점수 $z_j$를 조금 움직이면 softmax 확률 $p_i$가 얼마나 변하는가?

$i=j$이면 자기 점수를 올렸을 때 자기 확률이 변하는 양이고, $i\ne j$이면 남의 점수를 올렸을 때 내 확률이 변하는 양입니다.

### $p(\theta|D)\propto p(D|\theta)p(\theta)$

번역:

> 데이터를 본 뒤의 믿음은, 데이터가 주는 증거와 기존 믿음을 곱한 모양과 같다.

MAP 문제의 출발점입니다.

## 3. 시험 답안에서 쓰는 번역 문장

다음 문장들은 외우는 것이 좋습니다.

| 상황 | 문장 |
|---|---|
| i.i.d | 관측치들이 독립이고 동일분포이므로 결합확률은 단일 확률들의 곱으로 쓸 수 있다. |
| 로그 | 로그는 단조증가함수라 최대점 위치를 보존하고, 곱을 합으로 바꿔 미분을 쉽게 한다. |
| 미분=0 | 내부에서 미분 가능한 함수의 극값 후보는 페르마 정리에 의해 1차 도함수가 0인 점이다. |
| 경계 | 페르마 정리는 내부점에 대한 정리이므로 경계와 미분 불가능점은 별도로 비교한다. |
| MAP | posterior는 likelihood와 prior의 곱에 비례하므로, MAP은 log posterior를 최대화하는 점이다. |

## 4. 입문 연습

아래 식을 계산하지 말고 말로 번역하세요.

1. $X\sim Uniform[a,b]$
2. $E[X^2]=\int_a^b x^2p(x)\,dx$
3. $\operatorname{Var}(X)=E[X^2]-E[X]^2$
4. $\det(A-\lambda I)=0$
5. $J=\operatorname{diag}(p)-pp^T$
6. $-\log p(w)=\frac{\|w\|^2}{2\tau^2}+C$

답은 하나가 아닙니다. 중요한 것은 기호를 행동으로 바꾸는 능력입니다.
