# 딥러닝 최적화 - 수학적 개념 완전 정복

## 1. 주제 개요 및 중요성

**한 문장 정의**: 딥러닝 최적화는 수백만~수십억 개 파라미터를 가진 신경망의 손실 함수를 최소화하는 파라미터를 경사 기반 방법으로 효율적으로 찾아가는 수학적 체계이다.

**왜 배워야 하는가**:
- **실용적 가치**: 최적화 알고리즘의 선택과 하이퍼파라미터 튜닝이 모델 성능을 직접 좌우한다. 같은 아키텍처라도 Adam vs SGD, 학습률 스케줄에 따라 성능이 크게 달라진다.
- **이론적 중요성**: 볼록/비볼록 최적화 이론, 수렴 보장, 역전파 알고리즘의 수학적 기반을 이해해야 최적화 실패 원인을 진단하고 해결할 수 있다.

**어떤 문제를 해결하는가**: 선형 회귀처럼 닫힌 해가 존재하는 볼록 문제와 달리, DNN의 비볼록 손실 함수에서 좋은 해를 효율적으로 찾는 문제를 해결한다.

## 2. 입문자용 설명 (Level 1)

### 경사 하강법 -- 안개 낀 산에서 골짜기 찾기
눈을 감고 산 꼭대기에 서 있다고 상상하자. 가장 낮은 곳(골짜기)으로 가고 싶은데 볼 수가 없다. 발밑의 경사를 느끼면서, 가장 가파르게 내려가는 방향으로 한 걸음씩 내려간다. "발로 더듬기"가 미분(gradient)이고, "한 걸음"이 학습률(learning rate)이다.

### 볼록 함수 -- 그릇 모양
그릇(U자) 모양의 함수라면 어디서 구슬을 놓아도 가장 낮은 곳으로 굴러간다. 계란판 같은 울퉁불퉁한 함수에서는 구슬이 여기저기 구멍에 빠질 수 있다. 볼록 함수는 최적해를 반드시 찾을 수 있어서 수학적으로 다루기 좋다.

### SGD -- 대충 보고 빠르게 내려가기
산 전체의 기울기를 재려면 산 구석구석을 다 돌아봐야 해서 너무 오래 걸린다. 발밑의 작은 영역(미니배치)만 보고 대충 방향을 잡아서 내려간다. 정확하진 않지만 훨씬 빠르고, 놀랍게도 이 "부정확함"이 오히려 좋은 해를 찾는 데 도움이 된다.

### 모멘텀 -- 관성을 이용한 가속
공을 산에서 굴려 보면, 내리막에서 속도가 점점 빨라지고, 오르막에서도 관성 때문에 조금 더 굴러간다. 이 "관성"을 이용하면 작은 언덕은 넘어가고 깊은 골짜기에 더 빨리 도달할 수 있다.

### Adam -- 방향마다 다른 걸음 크기
산에서 내려갈 때, 어떤 방향은 가파르고 어떤 방향은 완만하다. 가파른 곳에서는 조심스럽게, 완만한 곳에서는 과감하게 걸어야 한다. Adam은 방향마다 걸음 크기를 자동으로 조절해 준다.

### 역전파 -- 도미노를 거꾸로 추적하기
도미노를 세워 놓고 첫 번째를 밀면 차례대로 넘어진다. 역전파는 마지막 도미노부터 "얼마나 세게 밀었는지"를 거꾸로 추적하여, 각 도미노(파라미터)가 결과에 얼마나 영향을 주었는지 계산한다.

## 3. 기술적 상세 설명 (Level 2)

### 3.1 볼록 집합과 볼록 함수

**볼록 집합**: 집합 안의 임의의 두 점을 잇는 선분이 모두 집합 안에 있는 것.

$$x, y \in X \Rightarrow \lambda x + (1-\lambda)y \in X, \quad \forall \lambda \in [0, 1]$$

**볼록 함수**:

$$f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$$

| 기호 | 의미 |
|------|------|
| $\lambda \in [0,1]$ | 두 점 사이의 내분 비율 |
| $f(x), f(y)$ | 양 끝점에서의 함수값 |

**수치 예시**: $f(x) = x^2$이 볼록인지 확인. $x=1, y=3, \lambda=0.5$:
- 좌변: $f(0.5 \times 1 + 0.5 \times 3) = f(2) = 4$
- 우변: $0.5 \times 1 + 0.5 \times 9 = 5$
- $4 \leq 5$ 성립!

**미분 가능한 함수의 볼록성 동치 조건**:
1. **접선 조건**: $f(x) \geq f(y) + \nabla f(y)^\top(x - y)$ -- 접선이 항상 함수 아래에 위치
2. **헤시안 조건**: $\nabla^2 f(x) \succeq 0$ -- 2차 도함수 행렬이 양의 준정부호

**Jensen 부등식**: 볼록 함수 $f$에 대해 $f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$

**응용**: KL-divergence가 항상 0 이상임을 증명하는 데 사용된다.

### 3.2 강볼록성과 매끄러움

**$m$-강볼록(Strongly Convex)**:

$$f(x) - \left(f(y) + \nabla f(y)^\top(x-y)\right) \geq \frac{m}{2}\|x - y\|^2$$

| 기호 | 의미 |
|------|------|
| $m > 0$ | 강볼록 상수 -- 함수가 "최소한 이 정도는 휘어있다"는 하한 |

**$\beta$-매끄러움(Smooth)**:

$$\left|f(x) - \left(f(y) + \nabla f(y)^\top(x-y)\right)\right| \leq \frac{\beta}{2}\|x - y\|^2$$

| 기호 | 의미 |
|------|------|
| $\beta$ | 매끄러움 상수 -- 함수가 "최대한 이 정도만 휘어있다"는 상한 |

**직관**: 강볼록은 "너무 평평하지 않다" (최솟값을 빨리 찾을 수 있음), 매끄러움은 "너무 뾰족하지 않다" (경사 하강법이 안정적).

**Polyak-Lojasiewicz (PL) 조건**:

$$\frac{1}{2}\|\nabla f(x)\|^2 \geq c(f(x) - f(x^*))$$

강볼록성보다 약한 조건이지만, 비볼록 함수에도 적용 가능하여 DNN 분석에 유용하다.

**조건수**: $\kappa = \beta/m$. 조건수가 클수록 최적화가 어렵다 (타원형 등고선이 극도로 길쭉해짐).

### 3.3 경사 하강법 (Gradient Descent)

$$\theta \leftarrow \theta - \eta \nabla_\theta L(\theta)$$

| 기호 | 의미 |
|------|------|
| $\theta$ | 모델 파라미터 벡터 |
| $\eta > 0$ | 학습률 -- 한 걸음의 크기 |
| $\nabla_\theta L$ | 손실 함수의 기울기 벡터 -- 가장 가파른 상승 방향 |

**수렴 조건**: 2차 손실 함수에서 $\eta < \frac{2}{\lambda_{\max}(A)}$이면 매 스텝 손실이 감소한다.

**수치 예시**: $L(\theta) = \theta^2$, $\eta = 0.3$, $\theta_0 = 5$:
- $\theta_1 = 5 - 0.3 \times 10 = 2$
- $\theta_2 = 2 - 0.3 \times 4 = 0.8$
- $\theta_3 = 0.8 - 0.3 \times 1.6 = 0.32$
- 0을 향해 빠르게 수렴!

**선형 수렴 증명** ($\beta$-smooth + $c$-PL 조건, $\eta = 1/\beta$):

$$L_t - L^* \leq \left(1 - \frac{c}{\beta}\right)^t (L_0 - L^*)$$

이는 오차가 매 스텝 $(1 - c/\beta)$배로 줄어든다는 의미이다. $c/\beta$가 클수록 빠르게 수렴한다.

### 3.4 확률적 경사 하강법 (SGD)

$$\theta \leftarrow \theta - \eta \nabla_\theta L_B(\theta)$$

| 기호 | 의미 |
|------|------|
| $L_B$ | 미니배치 $B$에 대한 손실 |
| $B \subset S$ | 전체 데이터에서 무작위 추출한 부분집합 |

**핵심 성질**: $\mathbb{E}_B[\nabla L_B(\theta)] = \nabla L_S(\theta)$ -- 미니배치 기울기는 전체 기울기의 **불편 추정량(unbiased estimator)**이다.

**수치 예시**: 데이터 100만 개, 배치 크기 256이면 한 스텝에 256개만 사용. 전체 GD 대비 ~4000배 빠른 업데이트.

**SGD의 잡음이 주는 이점**:
- **암묵적 정규화**: 잡음이 날카로운 극솟값에서 벗어나게 하여 평평한 극솟값으로 유도
- **안장점 탈출**: 잡음이 안장점에서 벗어나는 데 도움

### 3.5 모멘텀 방법

**Heavy Ball (Polyak Momentum)**:

$$m \leftarrow \beta m + g(\theta), \qquad \theta \leftarrow \theta - \eta m$$

| 기호 | 의미 |
|------|------|
| $m$ | 모멘텀 벡터 -- 이전 이동 방향의 누적 |
| $\beta \in [0, 1)$ | 모멘텀 계수 -- 관성의 크기 (보통 0.9) |
| $g(\theta)$ | 현재 기울기 |

**수학적 의미**: $m_t = \sum_{i=0}^{t} \beta^{t-i} g_i$ -- 기울기의 **지수 이동 평균(EMA)**으로, 최근 기울기에 더 큰 가중치를 부여한다.

**Nesterov Accelerated Gradient (NAG)**:

$$m \leftarrow \beta m + g(\theta - \eta \beta m)$$

NAG는 "앞을 내다보고(look ahead)" 기울기를 계산하여 오버슈팅을 사전에 보정한다.

**수렴 속도 비교** (2차 볼록 문제, 조건수 $\kappa$):
- GD: $O\left(\left(\frac{\kappa-1}{\kappa+1}\right)^{2t}\right)$
- Heavy Ball: $O\left(\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^{2t}\right)$ -- 조건수의 제곱근에만 의존!

### 3.6 Adam (Adaptive Moment Estimation)

$$m \leftarrow \beta_1 m + (1-\beta_1)g \quad \text{(1차 모멘트)}$$
$$s \leftarrow \beta_2 s + (1-\beta_2)g^2 \quad \text{(2차 모멘트)}$$
$$\hat{m} = m/(1-\beta_1^t), \quad \hat{s} = s/(1-\beta_2^t) \quad \text{(편향 보정)}$$
$$\theta \leftarrow \theta - \eta \frac{\hat{m}}{\sqrt{\hat{s}} + \varepsilon}$$

| 기호 | 의미 |
|------|------|
| $m$ | 1차 모멘트 -- 기울기의 방향 (모멘텀) |
| $s$ | 2차 모멘트 -- 기울기 크기의 기록 (적응적 학습률) |
| $\beta_1 = 0.9$ | 1차 모멘트 감쇠율 |
| $\beta_2 = 0.999$ | 2차 모멘트 감쇠율 |
| $\varepsilon = 10^{-8}$ | 0으로 나누기 방지 |
| $1/(1-\beta^t)$ | 편향 보정 -- 초기에 $s=0$에서 시작하므로 필요 |

**편향 보정이 필요한 이유**: $s_0 = 0$으로 시작하면 $\mathbb{E}[s_t] = \mathbb{E}[g^2](1-\beta_2^t)$로 편향된다. $(1-\beta_2^t)$로 나누면 $\mathbb{E}[\hat{s}_t] = \mathbb{E}[g^2]$으로 보정된다.

**수치 예시**: $t=1$, $\beta_2 = 0.999$이면 편향 보정 계수 $1/(1-0.999^1) = 1000$. 즉 초기에는 $s$를 1000배 키워서 보정한다. $t=100$이면 $1/(1-0.999^{100}) \approx 10.5$로 보정 효과가 줄어든다.

### 3.7 역전파와 자동 미분

연쇄 법칙(chain rule)을 계산 그래프(DAG)를 따라 역방향으로 적용:

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial x_1} \cdot \frac{\partial x_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial W_1}$$

**주요 미분 공식**:

| 연산 | 미분 |
|------|------|
| Cross-Entropy: $L = -\log p_y$ | $\frac{\partial L}{\partial z} = (p - e_y)^\top$ |
| MSE: $L = \frac{1}{2}\|z - z_0\|^2$ | $\frac{\partial L}{\partial z} = (z - z_0)^\top$ |
| ReLU$(z)$ | $\text{diag}(\mathbf{1}(z > 0))$ |
| $Wx$ | $\frac{\partial Wx}{\partial x} = W$ |

**시간 복잡도**: backward pass는 forward pass와 같은 차수 $O(Ln^2)$이다. 야코비안 행렬을 명시적으로 구성하지 않고, VJP(vector-Jacobian product)만 순차 계산하기 때문이다.

**수치 예시** (PyTorch):
```python
x1 = torch.tensor([1.], requires_grad=True)
x2 = torch.tensor([2.], requires_grad=True)
y = x1 * x2  # y = 2
y.backward()
print(x1.grad)  # tensor([2.]) = x2의 값
print(x2.grad)  # tensor([1.]) = x1의 값
```

### 3.8 학습률 스케줄

| 스케줄 | 수식 | 특성 |
|--------|------|------|
| Step decay | $\eta_t = \eta_0 \gamma^i$ | 일정 에폭마다 감소 |
| Square-root | $\eta_t = \eta_0 / \sqrt{t+1}$ | 이론적 수렴 보장 |
| Cosine annealing | $\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\pi t/T))$ | 실전 인기 |
| Warmup | 초기에 $\eta$를 선형으로 증가 후 감소 | Adam 초기 불안정 방지 |

**Robbins-Monro 조건** (이론적 요건):

$$\sum_{t=1}^{\infty} \eta_t = \infty, \qquad \sum_{t=1}^{\infty} \eta_t^2 < \infty$$

첫 조건은 어디든 도달 가능, 두 번째 조건은 잡음 소멸을 보장한다.

### 3.9 기울기 폭발/소실 문제와 해결책

**Residual Connection**: $y = F(x) + x$이면

$$\frac{\partial y}{\partial x} = \frac{\partial F(x)}{\partial x} + I$$

항등 행렬 $I$가 더해져서 기울기가 최소한 1 이상 유지 -- 소실 방지!

**Gradient Clipping**: $g' = \min\!\left(1, \frac{c}{\|g\|}\right) g$ -- 기울기의 노름이 $c$를 초과하면 잘라냄.

**Batch Normalization**:

$$\hat{x}_k = \frac{x_k - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}, \qquad y = \gamma \odot \hat{x} + \beta$$

| 기호 | 의미 |
|------|------|
| $\mu_B, \sigma_B^2$ | 미니배치의 평균과 분산 |
| $\gamma, \beta$ | 학습 가능한 스케일/시프트 파라미터 |
| $\epsilon$ | 0으로 나누기 방지 |

**BN vs LN**:
- **BN**: batch + spatial 축 정규화 -- CV 표준
- **LN**: channel + spatial 축 정규화 -- NLP/Transformer 표준

### 3.10 수렴 이론

**수렴 속도 분류**:
- **Sublinear**: $O(1/t)$ -- 일반 볼록 + smooth
- **Linear**: $O(\rho^t)$, $\rho < 1$ -- 강볼록 + smooth
- **Quadratic**: Newton's method -- $\|x_{t+1} - x^*\| \leq c\|x_t - x^*\|^2$

**비볼록 문제의 도전**: DNN 손실은 비볼록이지만 SGD가 놀랍게 좋은 해를 찾는다. 과매개변수화된 DNN에서 대부분의 극솟값은 전역 최솟값과 비슷한 손실을 가지기 때문이다.

## 4. 전문가 수준 핵심 요약 (Level 3)

DNN 최적화의 핵심 역설은 비볼록 손실 함수에서 SGD가 놀랍도록 좋은 해를 찾는다는 점이다. 이는 과매개변수화된 네트워크의 손실 경관에서 대부분의 극솟값이 전역 최솟값과 비슷한 성능을 가지며, SGD의 잡음이 안장점 탈출과 flat minima 선호에 기여하기 때문으로 부분적으로 설명된다. Adam = Momentum + RMSProp + Bias Correction으로, 1차/2차 모멘트의 지수 이동 평균으로 파라미터별 적응적 학습률을 제공한다. 역전파는 reverse-mode autodiff의 특수 사례로, VJP 체인을 통해 forward pass와 같은 차수의 비용으로 모든 파라미터의 기울기를 계산한다. BN/LN은 internal covariate shift 해결보다는 **손실 landscape의 매끈화(smoothing)** 효과가 핵심이며, Residual Connection은 기울기 경로에 항등 매핑을 삽입하여 깊은 네트워크의 학습을 가능하게 한다.

## 6. 흔한 오개념 및 주의사항

**"학습률이 작을수록 항상 좋다"**
너무 작은 학습률은 수렴이 극도로 느려지고, SGD에서 잡음에 의한 탐색 능력이 줄어 날카로운 극솟값에 갇힐 수 있다.

**"Adam은 항상 SGD보다 낫다"**
Adam은 빠르게 수렴하지만, CV에서 SGD + momentum이 더 나은 일반화 성능을 보이는 경우가 많다. NLP에서는 Adam이 표준이다.

**"비볼록이면 GD는 무용지물이다"**
과매개변수화된 DNN에서 대부분의 극솟값은 전역 최솟값과 비슷한 성능을 가진다. SGD의 잡음이 안장점 탈출에 도움을 준다.

**"역전파는 forward pass보다 훨씬 비싸다"**
VJP 체인으로 계산하므로 backward pass는 forward pass의 상수배(약 2-3배)이다.

**"Batch Normalization은 internal covariate shift를 해결하기 위한 것이다"**
후속 연구에 따르면, BN의 실제 효과는 손실 landscape을 매끄럽게 만드는 것이다.

**"모멘텀의 $\beta$가 크면 항상 빠르게 수렴한다"**
$\beta$가 너무 크면 과거 기울기에 과도하게 의존하여 방향 전환이 느려지고, 최솟값 주변에서 진동이 심해질 수 있다.

## 8. 실전 활용 사례

### 사례 1: CIFAR-10 이미지 분류
- **상황**: ResNet-18으로 10개 클래스 이미지 분류
- **적용**: SGD + momentum(0.9) + cosine annealing (초기 lr=0.1, 200 에폭)
- **결과**: SGD가 Adam보다 약 0.5% 높은 테스트 정확도

### 사례 2: GPT 스타일 언어 모델 학습
- **상황**: Transformer 기반 대규모 언어 모델 사전학습
- **적용**: AdamW ($\beta_1=0.9$, $\beta_2=0.95$) + linear warmup (2000 스텝) + cosine decay
- **결과**: warmup 없이는 초기 발산, AdamW의 weight decay가 일반화에 기여

### 사례 3: 기울기 폭발 디버깅
- **상황**: 10층 RNN에서 loss가 NaN으로 발산
- **적용**: gradient clipping (max_norm=1.0) + LSTM으로 구조 변경
- **결과**: 안정적 학습 달성, LSTM의 가산적 셀 업데이트가 기울기 소실도 완화

> **핵심을 날카롭게 정리하면:**
>
> 딥러닝 최적화의 전체 진화는 GD -> SGD -> SGD+Momentum -> Adam으로 요약되며, 각 단계는 계산 효율성(미니배치), 방향 기억(모멘텀), 파라미터별 적응(적응적 학습률)을 추가한 것이다. 역전파는 이 모든 것의 기반으로, VJP 체인을 통해 forward pass와 같은 비용으로 모든 기울기를 계산한다.
>
> 이것이 중요한 이유는 최적화 알고리즘과 하이퍼파라미터의 선택이 같은 아키텍처에서도 성능을 크게 좌우하기 때문이다.
>
> 진정한 마스터와 피상적 이해의 차이는 "왜 비볼록인데 SGD가 잘 작동하는지", "Adam의 편향 보정이 왜 필요한지", "BN이 실제로 왜 도움이 되는지"를 수학적으로 설명할 수 있느냐에 달려 있다.
