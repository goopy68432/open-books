# 14. CNN -- 이미지 이해

## 왜 배우는가?

이미지는 가로 x 세로 x 색상 채널로 이루어진 고차원 데이터다. 예를 들어 $224 \times 224 \times 3$ 이미지를 일반 MLP로 처리하면 첫 번째 층의 가중치만 $224 \times 224 \times 3 = 150,528$개의 입력을 받아야 한다. 파라미터가 폭발적으로 늘어난다.

CNN(합성곱 신경망)은 이미지의 두 가지 특성을 활용하여 이 문제를 해결한다:
1. **지역성**: 가까운 픽셀끼리 관련이 깊다
2. **이동 불변성**: 같은 패턴(고양이 귀 등)이 이미지 어디에나 나타날 수 있다

2012년 AlexNet이 ImageNet 대회에서 압승한 이후, CNN은 컴퓨터 비전의 표준이 되었다.

## 핵심 개념 1: 합성곱 연산

### 직관적 설명

큰 그림 위에 작은 돋보기(필터)를 올려놓고, 돋보기가 보는 부분과 필터를 짝지어 곱한 뒤 모두 더한다. 돋보기를 한 칸씩 옮기면서 반복하면, "이 부분에 이런 패턴이 있는가?"를 알려주는 새로운 지도가 만들어진다.

### 수식

1D 합성곱:
$$[w * x](i) = \sum_{u=0}^{k-1} w_u \cdot x_{i+u}$$

- $w$: 필터(커널), 크기 $k$
- $x$: 입력 신호
- 결과: 필터와 입력의 국소 영역 사이의 **내적** (유사도)

### 합성곱 = 특수한 행렬곱

합성곱은 사실 **희소(sparse) + 가중치 공유(weight sharing)** 행렬곱이다:

```
일반 행렬곱 (MLP):       합성곱 행렬:
[a b c d e]              [a b c 0 0]
[f g h i j]    vs        [0 a b c 0]
[k l m n o]              [0 0 a b c]
(모든 원소가 다름)         (같은 값이 대각선으로 반복)
```

- **희소**: 각 출력이 입력의 국소 영역만 참조 (지역성)
- **가중치 공유**: 같은 필터가 모든 위치에서 사용됨 (이동 불변성)

### 출력 크기 공식

$$H_{out} = \frac{H_{in} + 2p - k}{s} + 1$$

- $H_{in}$: 입력 크기, $k$: 커널 크기, $s$: 스트라이드(이동 칸수), $p$: 패딩

예: 입력 $7 \times 7$, 커널 $3 \times 3$, 스트라이드 1, 패딩 0 --> $\frac{7 + 0 - 3}{1} + 1 = 5$ --> 출력 $5 \times 5$

## 핵심 개념 2: 특징 맵과 계층적 특징 학습

### 직관적 설명

하나의 필터는 하나의 패턴(예: 대각선)을 감지한다. 이 필터를 이미지 전체에 적용하면 "이 패턴이 어디에 강하게 나타나는가"를 보여주는 **특징 맵(feature map)**이 만들어진다. 필터를 여러 개 쓰면 여러 종류의 특징 맵이 생긴다.

### CNN이 학습하는 계층적 특징

| 층 | 학습하는 것 | 예시 |
|----|-----------|------|
| Layer 1 | 에지, 색상 블롭 | / \\ - \| |
| Layer 2 | 코너, 텍스처 | L 모양, 격자 |
| Layer 3 | 부분 패턴 | 바퀴, 눈 |
| Layer 4~5 | 의미 있는 물체 | 강아지 얼굴, 꽃 |

얕은 층은 단순한 특징, 깊은 층은 추상적이고 의미 있는 특징을 학습한다. 이것이 **표현 학습(Representation Learning)**의 핵심이다.

### 다채널 합성곱

$c_{in}$ 채널 입력에 $c_{out}$개의 필터를 적용하면:
- 각 필터 크기: $k \times k \times c_{in}$ (3D 텐서)
- 전체 커널: $c_{out} \times c_{in} \times k \times k$
- 출력: $H_{out} \times W_{out} \times c_{out}$

**$1 \times 1$ 합성곱**: 공간 해상도를 유지하면서 채널 간 선형 결합만 수행. 채널 수를 줄이거나 늘리는 데 사용.

## 핵심 개념 3: 이동 등변성 vs 이동 불변성

### 직관적 설명

- **등변성(Equivariance)**: 입력이 오른쪽으로 이동하면 출력도 오른쪽으로 같이 이동. "고양이 위치가 바뀌면 특징 맵에서의 위치도 바뀜"
- **불변성(Invariance)**: 입력이 이동해도 출력이 변하지 않음. "고양이가 어디에 있든 '고양이다'라고 판단"

### 수식

- 이동 등변: $f(S(x)) = S(f(x))$ -- 합성곱 자체가 이 성질을 가짐
- 이동 불변: $f(S(x)) = f(x)$ -- 풀링을 통해 얻음

### 적용

- **이미지 분류**: 불변성 필요 (위치에 무관하게 분류) --> 풀링 사용
- **객체 검출**: 등변성 필요 (위치를 정확히 알아야 함) --> 합성곱 활용

주의: 표준 CNN은 이동에만 등변적이고, **회전이나 크기 변화**에는 등변적이지 않다.

## 핵심 개념 4: 풀링(Pooling)

### 직관적 설명

특징 맵이 너무 크면 계산이 힘들다. 그래서 $2 \times 2$ 칸씩 묶어서 대표값만 남긴다. 축소 복사처럼 작아지지만 중요한 정보는 살아있다.

### 종류

| 풀링 | 방법 | 용도 |
|------|------|------|
| Max Pooling | 영역 내 최대값 | "이 특징이 존재하는가?" |
| Average Pooling | 영역 내 평균 | "전반적 특징 강도는?" |
| Global Average Pooling (GAP) | 전체 공간을 하나의 값으로 | 마지막에 FC 층 대체 |

### 효과

1. **계산량 감소**: 해상도를 절반으로 줄임
2. **수용 영역 확대**: 다음 층이 더 넓은 영역을 볼 수 있게 됨
3. **이동 불변성 부여**: 약간의 위치 변화에 강건해짐

재미있는 성질: $\text{ReLU}(\text{MaxPool}(x)) = \text{MaxPool}(\text{ReLU}(x))$ (순서를 바꿔도 같다!)

## 핵심 개념 5: CNN 아키텍처의 진화

### AlexNet (2012) -- 딥러닝 붐의 시작

```
입력(227x227x3) --> Conv(11x11, s=4) --> MaxPool --> Conv(5x5)
  --> MaxPool --> Conv(3x3) x3 --> MaxPool
  --> Flatten(9216) --> FC(4096) --> FC(4096) --> Softmax(1000)
```

혁신 요소: ReLU, GPU 학습, Dropout, Data Augmentation

### 이후의 진화

| 모델 | 연도 | 핵심 아이디어 |
|------|------|-------------|
| VGG | 2014 | 3x3 필터로 통일, 더 깊게 |
| GoogLeNet | 2014 | 1x1 합성곱으로 차원 축소 (Inception) |
| ResNet | 2015 | Skip connection으로 152층 학습 가능 |
| EfficientNet | 2019 | 폭/깊이/해상도 복합 스케일링 |

### VGG의 핵심 통찰

$3 \times 3$ 필터 2개를 쌓으면 $5 \times 5$ 필터 1개와 같은 수용 영역을 가진다:
- $5 \times 5$ 필터: $25$개 파라미터
- $3 \times 3$ 필터 $\times$ 2: $9 + 9 = 18$개 파라미터 + 비선형성 1개 추가

파라미터는 적으면서 비선형성은 더 많아 효율적!

## 핵심 개념 6: 비전 태스크의 스펙트럼

### 직관적 설명

이미지를 보고 할 수 있는 일들:

```
단순 --------- 이미지 --> "고양이" (분류)
       |------- 이미지 --> "고양이, 개, 사람" (태깅)
       |------- 이미지 --> [박스] + "고양이" (객체 검출)
       |------- 이미지 --> 모든 픽셀에 클래스 (시맨틱 분할)
복잡 --------- 이미지 --> 물체별 분리 + 클래스 (인스턴스 분할)
```

### 수학적 정의

| 태스크 | 입출력 | 손실 함수 |
|--------|--------|----------|
| 분류 | 이미지 --> 클래스 1개 | Cross-entropy |
| 태깅 | 이미지 --> 클래스 여러 개 | Binary cross-entropy (각 클래스 독립) |
| 검출 | 이미지 --> 박스 좌표 + 클래스 | 좌표 회귀 + 분류 |
| 시맨틱 분할 | 이미지 --> 픽셀별 클래스 | 픽셀별 cross-entropy |

### 객체 검출: YOLO

YOLO(You Only Look Once)는 이미지를 한 번만 통과시켜 모든 객체를 동시에 검출한다. 미리 정의된 **앵커 박스**에 대해 (1) 클래스 확률, (2) 바운딩 박스 오프셋을 예측.

---

## 핵심 개념 7: 시맨틱/인스턴스/파놉틱 분할

### 직관적 설명

- **시맨틱 분할**: 사진의 모든 픽셀에 "도로, 사람, 하늘" 색칠하기. 같은 클래스 물체는 구분 안 함
- **인스턴스 분할**: 사람이 여러 명이면 "사람1, 사람2, 사람3" 다르게 색칠하기
- **파놉틱 분할**: 위 둘을 합쳐서 모든 것을 빈틈없이 색칠하기

### 수식

시맨틱 분할: $f: \mathbb{R}^{H \times W \times C} \to \{1, \ldots, K\}^{H \times W}$ (각 픽셀에 클래스 배정)

인스턴스 분할 대표 모델: **Mask R-CNN** = 객체 검출(박스 찾기) + 각 박스 안에서 전경/배경 분류

## 핵심 개념 8: 인코더-디코더 구조

### 직관적 설명

인코더는 사진을 점점 작게 줄이면서 "이 사진에 뭐가 있는지" 요약하는 역할이다. 디코더는 그 요약을 다시 크게 펼쳐서 원래 크기의 답을 만든다.

### 구조

```
인코더 (다운샘플링)             디코더 (업샘플링)
[224x224] --Conv+Pool--> [112x112] --Conv+Pool--> [56x56]
                                                     |
[224x224] <--UpConv--- [112x112] <--UpConv----- [56x56]
```

### 전치 합성곱 (Transposed Convolution)

합성곱 행렬 $W$의 **전치** $W^\top$를 곱하는 연산. 작은 입력으로 큰 출력을 생성한다.

주의: **역행렬이 아니라 전치 행렬**이다! 원래 입력을 복원하는 것이 아니라, 해상도를 키우는 연산이다.

### 핵심 아키텍처

- **SegNet**: 풀링 시 기록한 최대값 위치(switch)를 업샘플링에 활용
- **U-Net**: **Skip connection**으로 인코더의 고해상도 특징을 디코더에 직접 전달 --> 디테일 보존

### Dilated Convolution

커널 원소 사이에 간격(dilation rate $r$)을 두어 파라미터 증가 없이 수용 영역을 확대한다.

```
일반 3x3 (수용영역 3x3):     Dilated 3x3, r=2 (수용영역 5x5):
[x x x]                     [x . x . x]
[x x x]                     [. . . . .]
[x x x]                     [x . x . x]
                             [. . . . .]
                             [x . x . x]
```

## 핵심 개념 9: 밀집 예측

### 직관적 설명

사진 한 장만 보고 "이 부분은 가까이 있고, 저 부분은 멀리 있어"를 맞추는 것이 **깊이 예측**이다. "이 벽은 이쪽을 향하고 있어"를 알아내는 것이 **표면법선 예측**이다.

### 공통 구조

모든 밀집 예측(dense prediction) 과제는 인코더-디코더 구조로 해결 가능:

| 태스크 | 출력 채널 수 | 손실 함수 |
|--------|------------|----------|
| 깊이 예측 | 1 (거리값) | MSE ($L_2$) |
| 표면법선 | 3 (방향 벡터) | Cosine loss |
| 시맨틱 분할 | $K$ (클래스 수) | Cross-entropy |
| 자세 추정 | 키포인트 수 (히트맵) | MSE |

**Multi-task learning**: 하나의 인코더를 공유하고 여러 디코더를 붙여 동시에 학습할 수 있다.

## 핵심 개념 10: CNN 시각화와 적대적 예제

### CNN 시각화

ZFNet의 Deconvnet 방법으로 각 층의 뉴런이 "무엇을 보는지" 역투영할 수 있다:

1. 특정 뉴런만 활성화 유지, 나머지는 0으로
2. Max Unpooling (최대값 위치로 복원)
3. ReLU 역적용
4. Transposed Convolution (전치 합성곱으로 역투영)

### 적대적 예제(Adversarial Examples)

사람 눈에는 **똑같아 보이는** 사진에 아주 작은 노이즈를 넣으면 CNN이 완전히 다른 답을 한다!

```
판다 사진 (57.7% "판다") + 미세한 노이즈 = 판다 사진 (99.3% "긴팔원숭이"!)
```

FGSM 공격: $x_{adv} = x + \epsilon \cdot \text{sign}(\nabla_x L(x, y))$

이것은 CNN이 인간과 **근본적으로 다른 특징**에 의존할 수 있음을 시사한다.

## 오해하기 쉬운 포인트

### 1. "합성곱은 비선형 연산이다?"
틀렸다. 합성곱 자체는 **선형** 연산(특수 구조의 행렬곱)이다. 비선형성은 ReLU 등 활성화 함수가 담당한다.

### 2. "합성곱은 이동 불변적이다?"
틀렸다. 합성곱은 이동 **등변적(equivariant)**이다. 입력이 이동하면 출력도 같이 이동한다. 불변성은 풀링 등 추가 연산으로 얻는다.

### 3. "전치 합성곱은 합성곱의 역연산이다?"
틀렸다. 전치 합성곱은 합성곱 행렬의 **전치(transpose)**를 사용하는 것이지, **역행렬(inverse)**이 아니다. 원래 입력을 복원하지 않는다.

### 4. "Max Pooling이 항상 Average Pooling보다 좋다?"
용도에 따라 다르다. 특징 존재 여부 감지에는 Max, 전반적 특징 강도에는 Average가 적합하다. 최종 출력에는 GAP이 자주 사용된다.

### 5. "CNN은 깊을수록 항상 좋다?"
단순히 깊게만 쌓으면 기울기 소실 문제로 성능이 오히려 하락한다. ResNet의 skip connection이 이를 해결했다. 폭, 해상도와의 균형도 중요하다.

### 6. "시맨틱 분할과 인스턴스 분할은 같은 문제다?"
시맨틱 분할은 같은 클래스 물체를 구분하지 않고(모든 자동차 = "자동차"), 인스턴스 분할은 개별 물체를 구분한다(자동차1, 자동차2). 파놉틱 분할이 이 둘을 통합한다.

### 7. "CNN은 처음부터 이미지 전체를 본다?"
초기 층의 수용 영역은 매우 작아 국소 정보만 사용한다. 깊은 층으로 갈수록 수용 영역이 커져 점진적으로 전역 정보를 통합한다.

## 정리 및 요약

```
이미지 = 고차원 격자 데이터 (H x W x C)
MLP로 처리하면? 파라미터 폭발!

핵심 귀납적 편향 2가지:
  1. 지역성 --> 희소 행렬 (각 뉴런이 국소 영역만 봄)
  2. 이동 불변성 --> 가중치 공유 (같은 필터가 모든 위치에서 작동)

CNN 구조: [Conv -> ReLU -> Pool] x N -> Flatten -> FC -> Softmax

등변성 vs 불변성:
  - 합성곱 --> 이동 등변 (출력도 같이 이동)
  - 풀링 --> 이동 불변 (위치 무관한 판단)

비전 태스크:
  분류 -> 태깅 -> 검출 -> 시맨틱 분할 -> 인스턴스 분할 -> 밀집 예측
```

| 개념 | 핵심 수식/아이디어 | 한 줄 요약 |
|------|-------------------|-----------|
| 합성곱 | $[w*x](i) = \sum w_u x_{i+u}$ | 필터 슬라이딩으로 특징 추출 |
| 출력 크기 | $(H_{in} + 2p - k)/s + 1$ | 합성곱/풀링 후 크기 계산 |
| 등변성 | $f(S(x)) = S(f(x))$ | 합성곱의 핵심 성질 |
| 풀링 | Max 또는 Average 다운샘플링 | 해상도 축소 + 불변성 부여 |
| 전치 합성곱 | $W^\top$ (전치이지 역행렬 아님!) | 업샘플링에 사용 |
| U-Net | 인코더-디코더 + skip connection | 시맨틱 분할의 표준 구조 |
| 적대적 예제 | $x + \epsilon \cdot \text{sign}(\nabla_x L)$ | CNN의 취약점 경고 |
