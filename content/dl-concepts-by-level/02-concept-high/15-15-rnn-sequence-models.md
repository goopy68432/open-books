# 15. RNN과 시퀀스 모델

## 왜 배우는가?

언어, 음성, 시계열, 음악 등 우리가 접하는 데이터의 상당수는 **순서(sequence)**가 핵심이다. "나는 사과를 먹었다"와 "사과를 나는 먹었다"는 같은 단어지만 느낌이 다르고, "먹었다 사과를 나는"은 아예 어색하다. 고정 크기 입력만 다루는 MLP나 CNN으로는 이런 **가변 길이 시퀀스**의 **시간적 의존성**을 자연스럽게 처리할 수 없다.

RNN(순환 신경망)은 **은닉 상태(hidden state)**라는 "메모"를 통해 과거 정보를 축적하며 시퀀스를 처리하는 가장 기본적인 구조다.

---

## 핵심 개념 1: 텍스트를 숫자로 -- 워드 임베딩

### 직관적 설명

컴퓨터는 글자를 모른다. 그래서 단어마다 번호를 매기는데, 단순한 번호만으로는 "강아지"와 "개"가 비슷하다는 걸 알 수 없다. 워드 임베딩은 각 단어를 **의미를 담은 벡터**로 바꿔서, 비슷한 단어가 벡터 공간에서 가까이 위치하도록 한다.

### 원-핫 인코딩의 한계

사전에 10,000개 단어가 있으면, 각 단어를 길이 10,000짜리 벡터로 표현한다:
- "고양이" = [0, 0, ..., 1, ..., 0, 0] (자기 위치만 1)
- "강아지" = [0, 0, ..., 0, ..., 1, 0]

문제: 어떤 두 단어든 거리가 $\sqrt{2}$로 동일하다. 유사도 정보가 전혀 없다!

### 워드 임베딩

원-핫 벡터 $x \in \{0,1\}^V$에 임베딩 행렬 $E \in \mathbb{R}^{K \times V}$를 곱한다:

$$e = Ex \in \mathbb{R}^K \quad (K \ll V)$$

- $V$: 어휘 크기 (예: 50,000)
- $K$: 임베딩 차원 (예: 300)
- 결과: 50,000차원 --> 300차원으로 압축하면서 의미를 보존

### Word2Vec의 유명한 예시

$$\text{King} - \text{Man} + \text{Woman} \approx \text{Queen}$$

벡터 연산으로 단어 간의 의미적 관계를 포착할 수 있다!

### 학습 방법 (Word2Vec)

- **CBOW**: 주변 단어들로 중심 단어를 예측
- **Skip-gram**: 중심 단어로 주변 단어들을 예측

핵심 가설(**분포 가설**): 비슷한 문맥에 등장하는 단어는 의미가 비슷하다.

## 핵심 개념 2: 확률 그래프 모델과 시퀀스

### 직관적 설명

여러 사건이 서로 영향을 줄 때, 그 관계를 화살표로 연결한 그림이 확률 그래프 모델(PGM)이다. 시퀀스에서는 앞 단어가 뒷 단어에 영향을 주므로 체인(사슬) 형태가 된다:

$$y_1 \to y_2 \to y_3 \to \cdots \to y_T$$

### 결합 확률의 분해

PGM에서 결합 확률을 조건부 확률의 곱으로 분해할 수 있다:

$$p(y_1, y_2, \ldots, y_T) = \prod_{t=1}^{T} p(y_t \mid y_{\text{부모}(t)})$$

### 마르코프 성질

**1차 마르코프 가정**: "미래는 현재만 알면 과거와 독립이다"

$$p(y_t \mid y_1, y_2, \ldots, y_{t-1}) = p(y_t \mid y_{t-1})$$

이러면 결합 확률이 깔끔해진다: $p(y_{1:T}) = \prod_{t=1}^{T} p(y_t \mid y_{t-1})$

### 마르코프 가정의 한계

"ate an ___"와 "built an ___"에서 빈칸에 올 단어가 달라야 하는데, 1차 마르코프에서는 둘 다 "an" 다음이라 같은 확률을 준다. 먼 과거의 정보("ate" vs "built")가 중요한데 잃어버린다!

이것이 RNN의 동기다: **은닉 상태에 과거 정보를 압축해서 저장**한다.

## 핵심 개념 3: RNN 기본 구조

### 직관적 설명

RNN은 "기억력 있는 신경망"이다. 글을 읽을 때 앞에서 읽은 내용을 기억하고 다음을 이해하는 것처럼, RNN도 이전 단계에서 배운 것을 다음 단계로 넘겨준다.

### 수식

$$h_t = \phi(W_{hx} x_t + W_{hh} h_{t-1} + b)$$
$$\hat{y}_t = \text{softmax}(W' h_t)$$

- $x_t$: 시간 $t$에서의 입력 (예: 단어 임베딩)
- $h_t$: 시간 $t$에서의 은닉 상태 (메모리)
- $h_{t-1}$: 이전 시간의 은닉 상태
- $\phi$: 활성화 함수 (보통 tanh)
- $W_{hx}, W_{hh}, W'$: **모든 시간 단계에서 공유**되는 가중치

### 시각적 구조

```
    [y1]       [y2]       [y3]
     |          |          |
    [h1] ----> [h2] ----> [h3] ---->
     |          |          |
    [x1]       [x2]       [x3]
```

### 핵심 특성: 파라미터 공유

모든 시간 단계에서 **같은** $W_{hx}, W_{hh}, W'$를 사용한다. 따라서:
- 시퀀스 길이가 달라도 같은 모델을 적용 가능
- 파라미터 수가 시퀀스 길이에 무관

## 핵심 개념 4: RNN의 구조적 변형

### Seq2Vec (시퀀스 --> 벡터)

시퀀스를 쭉 읽고 **마지막 은닉 상태** $h_T$로 분류:

$$p(y \mid x_{1:T}) = \text{softmax}(W' h_T)$$

응용: 감성 분석 ("이 영화 리뷰는 긍정? 부정?")

### Vec2Seq (벡터 --> 시퀀스)

벡터 입력 $x$에서 시퀀스를 생성:
- 은닉 상태의 초기값이 $x$에 의존
- 이후 자기회귀적으로 한 토큰씩 생성

응용: 이미지 캡셔닝 (CNN의 출력 벡터 --> 문장 생성)

### Seq2Seq (시퀀스 --> 시퀀스)

**인코더-디코더** 구조:

```
인코더: x1 --> [h1] --> x2 --> [h2] --> x3 --> [h3] = c (컨텍스트 벡터)
                                                        |
디코더:                         [y1] <-- [h1'] <------ c
                                [y2] <-- [h2'] <-- y1
                                [y3] <-- [h3'] <-- y2
```

- 인코더: 입력 시퀀스 전체를 컨텍스트 벡터 $c = h_T^e$로 압축
- 디코더: $c$를 기반으로 출력 시퀀스 생성

응용: 기계 번역 ("안녕하세요" --> "Hello")

**핵심 한계 -- 정보 병목**: 입력 시퀀스의 모든 정보를 고정 크기 벡터 $c$에 압축해야 한다. 입력이 길어질수록 정보 손실이 커진다. --> 이것이 **Attention 메커니즘**의 동기!

### 양방향 RNN (Bidirectional RNN)

정방향과 역방향을 각각 계산하여 결합:

$$h_t = [\vec{h}_t ; \overleftarrow{h}_t]$$

앞뒤 문맥을 모두 활용하여 각 위치의 표현이 더 풍부해진다.

주의: **전체 시퀀스가 주어진 경우에만** 사용 가능. 자기회귀 생성(다음 단어 예측)에는 사용 불가!

## 핵심 개념 5: 시간 역전파 (BPTT)

### 직관적 설명

신경망이 실수하면 "어디서 틀렸나" 거꾸로 추적한다. RNN에서는 시간을 거꾸로 따라가면서 추적하는데, 이것이 "시간 역전파(Backpropagation Through Time)"다. RNN을 시간축으로 **펼쳐서** 보통 신경망처럼 역전파를 적용하는 것이다.

### 수식

RNN을 $T$개 시간 단계로 펼치면 각 단계가 하나의 층이 된다. 파라미터 $W$에 대한 총 기울기:

$$\frac{\partial L}{\partial W} = \sum_{t=1}^{T} \frac{\partial L_t}{\partial W}$$

각 시간 단계의 기울기를 모두 더한 것이다 (파라미터 공유 때문).

### 핵심 문제: 기울기 곱셈

$h_t$가 $h_{t-1}$에 의존하고, $h_{t-1}$이 $h_{t-2}$에 의존하므로:

$$\frac{\partial h_t}{\partial h_k} = \prod_{i=k+1}^{t} \frac{\partial h_i}{\partial h_{i-1}}$$

이 **곱셈의 반복**이 기울기 소실/폭발 문제의 근원이다.

---

## 핵심 개념 6: 기울기 소실과 폭발

### 직관적 설명

전화기 게임에서 첫 번째 사람이 한 말을 여러 사람이 차례로 전달하면, 마지막 사람에게는 원래 말이 완전히 달라져 있다. RNN에서도 비슷한 일이 일어난다: 아주 긴 시퀀스에서 처음 부분의 정보가 전달되다 점점 흐려진다.

### 수학적 원인

$$\frac{\partial h_t}{\partial h_k} = \prod_{i=k+1}^{t} W_{hh}^\top \cdot \text{diag}(\phi'(\cdot))$$

$W_{hh}$의 **최대 특이값** $\sigma_{\max}$에 따라:
- $\sigma_{\max} < 1$: 기울기가 **지수적으로 감소** --> 소실 ($0.9^{100} \approx 0.00003$)
- $\sigma_{\max} > 1$: 기울기가 **지수적으로 증가** --> 폭발 ($1.1^{100} \approx 13,781$)

### 해결 방법

| 문제 | 해결책 |
|------|--------|
| 기울기 폭발 | **Gradient Clipping**: $\|g\| > c$이면 $g \leftarrow c \cdot g / \|g\|$ |
| 기울기 소실 | **LSTM/GRU**: 게이트 메커니즘으로 가산적 업데이트 |
| 근본적 해결 | **Transformer**: 어텐션으로 임의 거리를 직접 참조 |

## 핵심 개념 7: LSTM (Long Short-Term Memory)

### 직관적 설명

LSTM은 "똑똑한 기억 장치"가 달린 RNN이다. 세 개의 문(게이트)이 있다:
- **잊기 문(Forget gate)**: 필요 없는 기억을 지운다 (지우개)
- **입력 문(Input gate)**: 새 정보를 기억에 추가한다 (연필)
- **출력 문(Output gate)**: 기억에서 필요한 것만 꺼내 쓴다 (책갈피)

### 수식

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad \text{(Forget gate: 무엇을 잊을까?)}$$
$$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \quad \text{(Input gate: 무엇을 기억할까?)}$$
$$\tilde{c}_t = \tanh(W_c [h_{t-1}, x_t] + b_c) \quad \text{(후보 기억)}$$
$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t \quad \text{(셀 상태 업데이트)}$$
$$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad \text{(Output gate: 무엇을 출력할까?)}$$
$$h_t = o_t \odot \tanh(c_t) \quad \text{(은닉 상태)}$$

- $\sigma$: 시그모이드 (0~1 사이 값으로 "얼마나 열까"를 결정)
- $\odot$: 원소별 곱 (벡터의 각 원소를 독립적으로 조절)
- $c_t$: **셀 상태** -- 장기 기억을 저장하는 별도 통로

### 왜 기울기 소실을 해결하는가?

셀 상태 업데이트를 보면:
$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

기울기: $\frac{\partial c_t}{\partial c_{t-1}} = \text{diag}(f_t)$

$f_t \approx 1$이면 기울기가 거의 그대로 전파된다! 이것은 ResNet의 skip connection ($y = F(x) + x$)과 **정확히 같은 원리**다. 셀 상태가 기울기의 고속도로(gradient highway) 역할을 한다.

## 핵심 개념 8: GRU (Gated Recurrent Unit)

### 직관적 설명

GRU는 LSTM의 간소화 버전이다. 문이 두 개뿐이다:
- **리셋 문(Reset gate)**: 이전 기억을 얼마나 무시할지
- **업데이트 문(Update gate)**: 이전 기억과 새 정보를 얼마나 섞을지

### 수식

$$r_t = \sigma(W_r [h_{t-1}, x_t]) \quad \text{(Reset gate)}$$
$$z_t = \sigma(W_z [h_{t-1}, x_t]) \quad \text{(Update gate)}$$
$$\tilde{h}_t = \tanh(W[r_t \odot h_{t-1}, x_t]) \quad \text{(후보 상태)}$$
$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t \quad \text{(상태 업데이트)}$$

- $z_t \approx 0$: 이전 상태 유지 (기억 보존)
- $z_t \approx 1$: 새로운 상태로 교체 (기억 갱신)

### LSTM vs GRU

| | LSTM | GRU |
|---|------|-----|
| 게이트 수 | 3개 | 2개 |
| 상태 | 셀 상태 $c_t$ + 은닉 상태 $h_t$ | 은닉 상태 $h_t$만 |
| 파라미터 | 더 많음 | 더 적음 |
| 성능 | 복잡한 장기 의존성에 유리 | 대부분의 과제에서 비슷 |

GRU의 업데이트 게이트는 LSTM의 forget gate와 input gate를 하나로 합친 것이다: $(1-z_t)$가 forget, $z_t$가 input 역할.

## 핵심 개념 9: RNN vs Transformer

### 직관적 설명

RNN은 책을 처음부터 끝까지 **순서대로** 읽는다. Transformer는 책의 모든 페이지를 **한 번에 펼쳐놓고** 필요한 부분끼리 연결한다.

### 비교

| | RNN | Transformer |
|---|------|-------------|
| 처리 방식 | 순차적 (한 토큰씩) | 병렬 (모든 토큰 동시) |
| 장기 의존성 | 어려움 (기울기 소실) | 쉬움 (직접 참조) |
| 계산 복잡도 | $O(T)$ (시퀀스 길이에 선형) | $O(T^2)$ (모든 쌍 비교) |
| 귀납적 편향 | 강한 순차적 편향 | 약한 순차적 편향 (위치 인코딩으로 보완) |

### Transformer의 핵심: Self-Attention

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right) V$$

모든 위치 쌍의 유사도를 계산하여 가중합으로 표현을 만든다. 임의 거리의 토큰을 직접 참조할 수 있어 장기 의존성 문제를 우회한다.

### 발전 계보

$$\text{마르코프 모델} \to \text{RNN} \to \text{LSTM/GRU} \to \text{Transformer}$$

Transformer가 GPT, BERT 등 대규모 언어 모델의 기반이 되었다.

## 오해하기 쉬운 포인트

### 1. "RNN의 핵심은 가변 길이 처리다?"
가변 길이는 부수적 특징이다. 핵심은 **파라미터 공유 + 은닉 상태를 통한 시간적 정보 축적**이다. 이 구조가 자연스럽게 가변 길이를 처리하는 것이다.

### 2. "LSTM의 셀 상태는 장기 기억, 은닉 상태는 단기 기억이다?"
이 비유는 부분적으로만 맞다. 셀 상태의 진짜 역할은 **기울기 고속도로**다. Forget gate에 의해 매 시점 수정되므로 "영구 기억"이 아니다. 은닉 상태는 셀 상태의 **필터링된 출력**이다.

### 3. "기울기 소실 = 기울기가 0이 된다?"
정확히 0이 되는 것이 아니라 **지수적으로 작아져서** 학습 신호가 실질적으로 무의미해지는 것이다. 먼 과거 입력에 대한 기울기가 최근 입력의 기울기에 비해 무시할 만큼 작아진다.

### 4. "양방향 RNN은 항상 단방향보다 좋다?"
양방향 RNN은 **전체 시퀀스가 주어진 경우에만** 사용 가능하다. 다음 단어를 예측하거나 실시간 스트리밍에서는 미래 정보를 볼 수 없으므로 단방향만 가능하다.

### 5. "GRU는 LSTM의 열등한 버전이다?"
GRU는 파라미터가 적어 학습이 빠르고 과적합 위험이 낮다. 많은 벤치마크에서 LSTM과 유사한 성능을 보인다. 선택은 과제와 데이터에 따라 달라진다.

### 6. "BPTT는 일반 역전파와 다른 알고리즘이다?"
BPTT는 별도의 알고리즘이 아니다. RNN을 시간축으로 **펼친** 후 일반 역전파를 그대로 적용하는 것이다. 펼친 네트워크는 가중치를 공유하는 매우 깊은 피드포워드 네트워크와 동일하다.

## 정리 및 요약

```
시퀀스 데이터의 핵심 과제: 가변 길이 + 시간적 의존성

해결 방법의 진화:
  마르코프 모델 (기억 1칸) --> RNN (은닉 상태로 기억)
  --> LSTM/GRU (게이트로 장기 기억) --> Transformer (어텐션으로 직접 참조)

RNN의 본질:
  1. 파라미터 공유 (모든 시간 단계에서 같은 W)
  2. 은닉 상태를 통한 시간 재귀 (h_t = f(h_{t-1}, x_t))

LSTM/GRU의 핵심:
  가산적 상태 업데이트로 기울기 소실 완화
  (ResNet의 skip connection과 같은 원리!)

Transformer가 대체한 이유:
  RNN의 순차적 병목 + 장기 의존성 문제를 어텐션으로 근본 해결
```

| 개념 | 핵심 수식 | 한 줄 요약 |
|------|----------|-----------|
| 워드 임베딩 | $e = Ex$, $E \in \mathbb{R}^{K \times V}$ | 단어를 의미 있는 벡터로 변환 |
| RNN | $h_t = \phi(W_{hx} x_t + W_{hh} h_{t-1})$ | 은닉 상태로 시퀀스 정보 축적 |
| BPTT | $\frac{\partial L}{\partial W} = \sum_t \frac{\partial L_t}{\partial W}$ | 시간축으로 펼쳐서 역전파 |
| 기울기 소실 | $\prod W_{hh} \cdot \phi'$가 지수적 감소 | 장기 의존성 학습 실패의 원인 |
| LSTM | $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$ | 3개 게이트 + 셀 상태로 장기 기억 |
| GRU | $h_t = (1-z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$ | 2개 게이트, LSTM의 경량화 |
| Seq2Seq | 인코더 --> 컨텍스트 벡터 $c$ --> 디코더 | 시퀀스 간 변환 (번역 등) |
| Attention | $\text{softmax}(QK^\top / \sqrt{d_k}) V$ | 모든 위치를 직접 참조 |
