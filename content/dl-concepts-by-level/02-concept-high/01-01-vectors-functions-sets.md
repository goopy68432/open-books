# 01. 벡터, 함수, 집합 -- 딥러닝의 첫 번째 언어

> 이 문서는 고등학생 수준에서 딥러닝의 수학적 기초를 설명합니다.

---

## 왜 이걸 배워야 할까?

딥러닝(인공지능)은 결국 **숫자를 다루는 기술**이다. 이미지, 텍스트, 음성 등 모든 데이터를 숫자로 바꾸고, 그 숫자를 변환해서 원하는 결과를 얻는다. 이 과정을 이해하려면 집합, 함수, 벡터 같은 기본 도구가 필요하다.

```
[데이터: 이미지/텍스트/음성]
        |
        v
[숫자로 변환 (벡터)]
        |
        v
[변환 규칙 적용 (함수/행렬)]
        |
        v
[결과: 분류/생성/번역]
```

---

## 1. 집합 (Set)

### 핵심 개념

집합은 **중복 없이 모아놓은 것들의 모임**이다. 순서는 상관없다.

$$A = \{1, 2, 3\}, \quad B = \{x, y\}$$

- $\{1, 2, 3\} = \{3, 1, 2\}$ (순서 무관)
- $\{1, 1, 2\} = \{1, 2\}$ (중복 제거)

### 카테시안 곱 (Cartesian Product)

두 집합에서 하나씩 골라 짝짓는 **모든 경우**:

$$A \times B = \{(1,x), (1,y), (2,x), (2,y), (3,x), (3,y)\}$$

원소 개수: $|A \times B| = |A| \cdot |B| = 3 \times 2 = 6$

### 딥러닝에서 왜 중요한가?

- **데이터셋**: 입력-정답 쌍 $(x, y)$의 모음 = 카테시안 곱의 부분집합
- **입력 공간**: 딥러닝의 입력은 실수의 카테시안 곱 $\mathbb{R}^n = \mathbb{R} \times \mathbb{R} \times \cdots \times \mathbb{R}$
- **단어 사전(vocabulary)**: 모델이 아는 단어의 집합

### 오해하기 쉬운 포인트

| 오해 | 실제 |
|------|------|
| 집합에 순서가 있다 | 집합 자체는 순서가 없다. 순서가 필요하면 **순서쌍(tuple)**이나 **벡터**를 써야 한다 |
| $A \times B = B \times A$ | $(1, x) \neq (x, 1)$이므로 순서쌍의 순서가 달라 일반적으로 다르다 |

## 2. 함수 (Function)

### 핵심 개념

함수는 **입력 하나에 출력 하나를 대응시키는 규칙**이다.

$$f : A \to B, \quad a \mapsto f(a)$$

자판기를 떠올려 보자: 버튼(입력)을 누르면 반드시 음료(출력) **하나**가 나온다.

### 단사 함수 (One-to-One, Injective)

서로 다른 입력은 반드시 서로 다른 출력을 만드는 함수:

$$a \neq a' \implies f(a) \neq f(a')$$

대우(contrapositive)로 쓰면: $f(a) = f(a') \implies a = a'$

### 지시 함수 (Indicator Function)

조건이 참이면 1, 거짓이면 0을 반환하는 함수:

$$\mathbf{1}(p) = \begin{cases} 1 & \text{참일 때} \\ 0 & \text{거짓일 때} \end{cases}$$

예: "오늘 비가 온다"가 참이면 $\mathbf{1}(\text{비}) = 1$

### 딥러닝에서 왜 중요한가?

| 함수 개념 | 딥러닝 대응 |
|-----------|------------|
| 함수 $f$ | 신경망의 각 레이어 |
| 함수 합성 $f \circ g$ | 레이어를 쌓는 것: $f_3(f_2(f_1(x)))$ |
| 단사 함수 | 역변환이 가능한 생성 모델 (Normalizing Flows) |
| 지시 함수 | 마스킹, one-hot 인코딩 |

딥러닝 전체 네트워크는 함수의 합성이다:

$$\text{네트워크} = f_L \circ f_{L-1} \circ \cdots \circ f_1$$

### 오해하기 쉬운 포인트

| 오해 | 실제 |
|------|------|
| 함수는 반드시 수식이다 | 함수는 **매핑 규칙**이다. 표, 그래프, 학습된 가중치도 함수를 정의한다 |
| 모든 함수는 역함수가 있다 | 단사(one-to-one)이면서 전사(onto)인 함수만 역함수가 존재한다 |

## 3. 스칼라 (Scalar)

### 핵심 개념

스칼라는 **크기만 있는 숫자 하나**이다. 실수 $s \in \mathbb{R}$.

- 온도 25도, 시험 점수 90점, 키 175cm -- 이런 것들이 스칼라

### 체(Field)의 성질

실수 $(\mathbb{R}, +, \times)$는 사칙연산이 자유롭다:
- 덧셈 항등원: $0$ ($a + 0 = a$)
- 곱셈 항등원: $1$ ($a \times 1 = a$)
- 0이 아닌 수는 곱셈 역원이 존재: $s \neq 0$이면 $s \times \frac{1}{s} = 1$

### 딥러닝에서 왜 중요한가?

- **학습률(learning rate)**: 가중치를 얼마나 조절할지 결정하는 스칼라 $\alpha = 0.01$
- **손실값(loss)**: 모델이 얼마나 틀렸는지를 나타내는 스칼라
- **가중치 업데이트**: $w_{\text{새}} = w_{\text{이전}} - \alpha \times \text{기울기}$ (스칼라 $\times$ 벡터)

## 4. 벡터 (Vector)

### 핵심 개념

벡터는 **순서 있는 숫자의 나열**이다.

$$v = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix} \in \mathbb{R}^n$$

집합과 달리 **순서가 중요**하다: $[1, 2, 3] \neq [3, 1, 2]$

### 벡터 연산

$v = [1, 2, 3]^{\top}$, $w = [4, 5, 6]^{\top}$일 때:

**덧셈**: $v + w = [5, 7, 9]^{\top}$ (같은 위치끼리 더하기)

**스칼라곱**: $2v = [2, 4, 6]^{\top}$ (모든 원소에 곱하기)

### 내적 (Inner Product / Dot Product)

$$\langle v, w \rangle = v_1 w_1 + v_2 w_2 + \cdots + v_n w_n$$

예시:
$$\langle v, w \rangle = 1 \times 4 + 2 \times 5 + 3 \times 6 = 32$$

**직관**: 내적은 두 벡터가 **얼마나 같은 방향을 가리키는지** 측정한다.
- 내적이 크다 = 비슷한 방향
- 내적이 0 = 수직 ($v \perp w$)
- 내적이 음수 = 반대 방향

### 노름 (Norm) -- 벡터의 "길이"

$$\|v\| = \sqrt{v_1^2 + v_2^2 + \cdots + v_n^2} = \sqrt{\langle v, v \rangle}$$

예시: $\|v\| = \sqrt{1^2 + 2^2 + 3^2} = \sqrt{14} \approx 3.74$

이것은 피타고라스 정리의 $n$차원 확장이다!

### 거리 (Distance)

$$d(v, w) = \|v - w\| = \sqrt{(v_1 - w_1)^2 + \cdots + (v_n - w_n)^2}$$

유용한 공식:
$$\|v - w\|^2 = \|v\|^2 + \|w\|^2 - 2\langle v, w \rangle$$

**핵심**: 내적이 클수록(유사할수록) 거리가 줄어든다.

### 내적의 수학적 성질

| 성질 | 수식 |
|------|------|
| 대칭 | $\langle v, w \rangle = \langle w, v \rangle$ |
| 선형 | $\langle av + bu, w \rangle = a\langle v, w \rangle + b\langle u, w \rangle$ |
| 양정치 | $\langle v, v \rangle \geq 0$, 등호는 $v = \mathbf{0}$일 때만 |

### 딥러닝에서 왜 중요한가?

| 벡터 개념 | 딥러닝 대응 |
|-----------|------------|
| 벡터 | 단어 임베딩 (Word2Vec: 768차원 벡터), 이미지 특징 |
| 내적 | Attention 점수: 질문과 답이 얼마나 관련 있는지 |
| 코사인 유사도 | 두 문장이 얼마나 비슷한지 비교 |
| 노름 | 가중치 크기 제한 (weight decay) |
| 거리 | 예측값과 정답 사이의 오차 (L2 loss) |

**코사인 유사도**: $\cos\theta = \frac{\langle v, w \rangle}{\|v\| \cdot \|w\|}$

### 오해하기 쉬운 포인트

| 오해 | 실제 |
|------|------|
| 벡터는 화살표이다 | 화살표는 2D, 3D에서의 시각화일 뿐. 768차원 단어 임베딩도 벡터이다 |
| 내적은 단순 곱셈이다 | 내적은 대응 원소 곱의 **합**이며, 결과는 벡터가 아니라 **스칼라**이다 |
| 벡터와 집합은 비슷하다 | 벡터는 순서가 있고 중복이 가능. 집합은 순서가 없고 중복 불가 |

## 5. 선형 변환 (Linear Transformation)

### 핵심 개념

선형 변환은 다음 두 조건을 만족하는 함수 $L$이다:

1. **가법성**: $L(v + u) = L(v) + L(u)$
2. **동차성**: $L(av) = aL(v)$

합쳐서 (중첩 원리):
$$L(\alpha v + \beta u) = \alpha L(v) + \beta L(u)$$

**직관**: "더한 다음 변환하나, 변환한 다음 더하나 결과가 같다"

### 예시

$L$이 "모든 원소를 2배로 만드는 변환"이라 하면:
- $L([1, 3]^{\top}) = [2, 6]^{\top}$
- $L([1, 3]^{\top} + [2, 1]^{\top}) = L([3, 4]^{\top}) = [6, 8]^{\top}$
- $L([1, 3]^{\top}) + L([2, 1]^{\top}) = [2, 6]^{\top} + [4, 2]^{\top} = [6, 8]^{\top}$
- 결과가 같다!

### Linear vs Affine -- 중요한 구분

- **선형 변환**: $L(v) = Wv$ ($L(\mathbf{0}) = \mathbf{0}$ 반드시 성립)
- **아핀(Affine) 변환**: $L(v) = Wv + b$ (상수 $b$가 추가)

$y = 2x + 3$은 선형이 **아니라** 아핀이다! ($L(0) = 3 \neq 0$)

### 딥러닝에서 왜 중요한가?

- 딥러닝의 `Linear` 레이어: $y = Wx + b$ -- 수학적으로는 **아핀** 변환
- 선형 변환만으로는 XOR 문제도 풀 수 없다 -- 그래서 비선형 활성화 함수(ReLU 등)가 필수
- Transformer의 Q, K, V 사영(projection)은 선형 변환이다

### 오해하기 쉬운 포인트

| 오해 | 실제 |
|------|------|
| $y = ax + b$가 "선형 함수"이다 | 수학에서 선형 변환은 $L(\mathbf{0}) = \mathbf{0}$을 만족해야 한다. $b \neq 0$이면 아핀 |
| 선형 변환으로 모든 문제를 풀 수 있다 | 불가능. 비선형 활성화 함수가 반드시 필요하다 |

## 6. 행렬 (Matrix)

### 핵심 개념

행렬은 **선형 변환을 숫자 표로 나타낸 것**이다.

$A = \begin{bmatrix} 1 & 1 & 1 \\ 1 & 2 & 3 \end{bmatrix}$는 $\mathbb{R}^3 \to \mathbb{R}^2$인 선형 변환을 나타낸다.

### 행렬의 열 = 기저 벡터의 변환 결과

표준 기저 벡터 $e_1 = [1, 0, 0]^{\top}$, $e_2 = [0, 1, 0]^{\top}$, $e_3 = [0, 0, 1]^{\top}$에 대해:

$$Ae_1 = \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \quad Ae_2 = \begin{bmatrix} 1 \\ 2 \end{bmatrix}, \quad Ae_3 = \begin{bmatrix} 1 \\ 3 \end{bmatrix}$$

**핵심**: 행렬의 $j$번째 열 = $e_j$가 변환된 결과

역으로, 각 기저 벡터가 어디로 가는지 알면 행렬을 만들 수 있다!

### 행렬과 선형 변환은 일대일 대응

임의의 벡터 $v = v_1 e_1 + v_2 e_2 + \cdots + v_n e_n$에 대해:

$$L(v) = v_1 L(e_1) + v_2 L(e_2) + \cdots + v_n L(e_n) = Av$$

따라서 선형 변환은 기저 벡터의 변환 결과만으로 완전히 결정된다.

### 딥러닝에서 왜 중요한가?

- `nn.Linear(3, 2)`의 가중치 = $2 \times 3$ 행렬
- 행렬 곱 $Ax$ = 입력을 새로운 공간으로 변환
- Attention 행렬 = 단어들 사이의 관계를 나타내는 표

## 7. 텐서 (Tensor)

### 핵심 개념

텐서는 행렬의 일반화로, **차원을 계속 늘려간 것**이다.

| 차수 | 이름 | 예시 | 딥러닝 예시 |
|------|------|------|------------|
| 0 | 스칼라 | $5$ | loss 값 |
| 1 | 벡터 | $[1, 2, 3]$ | 단어 임베딩 |
| 2 | 행렬 | 2x3 표 | 가중치 $W$ |
| 3 | 3차 텐서 | 표 여러 장 | 컬러 이미지(RGB) |
| 4 | 4차 텐서 | 상자 여러 개 | 이미지 배치 (배치 x 채널 x 높이 x 너비) |

### 딥러닝에서 왜 중요한가?

PyTorch, TensorFlow의 이름 자체가 "Tensor"인 이유: 모든 데이터와 파라미터가 텐서로 표현된다.

- 컬러 이미지 = 높이 x 너비 x 3(RGB) = 3차 텐서
- 이미지 배치 = 배치수 x 높이 x 너비 x 3 = 4차 텐서

## 8. 딥러닝에서 자주 보는 그리스 문자

| 기호 | 이름 | 딥러닝에서의 의미 |
|------|------|------------------|
| $\alpha$ | 알파 | 학습률 (learning rate) |
| $\beta$ | 베타 | 모멘텀 계수 (Adam의 $\beta_1, \beta_2$) |
| $\theta$ | 세타 | 모델의 전체 파라미터 |
| $\lambda$ | 람다 | 정규화 계수 |
| $\sigma$ | 시그마 | 표준편차, 시그모이드 함수 |
| $\epsilon$ | 엡실론 | 아주 작은 수 (수치 안정성용) |
| $\mu$ | 뮤 | 평균 |
| $\Sigma$ | 대문자 시그마 | 합 연산 $\sum$ |

## 정리 / 요약

### 한 줄 요약

> 딥러닝은 벡터(숫자 나열)를 입력받아 행렬(선형 변환)과 비선형 함수를 반복 적용하여 원하는 출력 벡터를 만드는 과정이다.

### 개념 흐름도

```
집합 (데이터의 정의역/공역)
  |
  v
함수 (입출력 매핑 규칙)
  |
  v
벡터 (데이터를 숫자로 표현)
  |
  v
선형 변환 (가법성 + 동차성)
  |
  v
행렬 (선형 변환의 숫자 표현)
  |
  v
텐서 (모든 것을 일반화한 다차원 배열)
```

### 핵심 공식 정리

| 개념 | 공식 | 한 줄 설명 |
|------|------|-----------|
| 카테시안 곱 | $\|A \times B\| = \|A\| \cdot \|B\|$ | 모든 조합의 수 |
| 내적 | $\langle v, w \rangle = \sum v_i w_i$ | 유사도 측정 |
| 노름 | $\|v\| = \sqrt{\langle v, v \rangle}$ | 벡터의 길이 |
| 거리 | $d(v,w) = \|v - w\|$ | 두 벡터 사이 거리 |
| 선형 변환 | $L(\alpha v + \beta u) = \alpha L(v) + \beta L(u)$ | 중첩 원리 |
| 행렬-벡터 곱 | $Av = \sum v_i \cdot (\text{A의 i번째 열})$ | 열벡터의 가중합 |

### 다음 장에서는...

행렬의 곱셈, 행렬이 만드는 공간(열공간, 영공간), 그리고 차원과 랭크를 배운다. 이것이 딥러닝에서 "가중치 행렬이 실제로 무엇을 하는지"를 이해하는 열쇠가 된다.
