# 09. 베이지안 확률과 정보이론

## 왜 배우는가?

딥러닝의 학습은 본질적으로 **데이터를 보고 모델의 믿음을 업데이트하는 과정**이다.

- **베이지안 사고**: 사전 지식(prior)을 활용하여 적은 데이터에서도 과적합을 방지한다
- **정보이론**: 불확실성을 측정하고, 분포 간 차이를 정량화한다

딥러닝의 손실 함수(cross-entropy), 생성 모델(VAE)의 ELBO, 지식 증류의 KL divergence 등 **현대 딥러닝의 거의 모든 학습 목표가 이 두 이론 위에 있다.**

---

## 1. 베이즈 정리

### 핵심 아이디어

**"새로운 증거를 보고 내 믿음을 업데이트한다."**

**비유**: 아침에 "오늘 비 올 확률 30%"라고 생각했다(사전 확률). 창밖을 보니 하늘이 새까맣다. 이제 "비 올 확률 80%"로 생각이 바뀌었다(사후 확률). 이렇게 새로운 정보를 보고 생각을 바꾸는 수학적 방법이 베이즈 정리이다.

### 수식

$$P(H | E) = \frac{P(E | H) \cdot P(H)}{P(E)}$$

| 기호 | 이름 | 의미 |
|------|------|------|
| $P(H)$ | **사전 확률 (Prior)** | 데이터를 보기 전의 믿음 |
| $P(E \| H)$ | **우도 (Likelihood)** | 가설이 맞다면 이런 데이터가 나올 확률 |
| $P(E)$ | **주변 우도 (Evidence)** | 정규화 상수 |
| $P(H \| E)$ | **사후 확률 (Posterior)** | 데이터를 본 뒤의 업데이트된 믿음 |

간단히 쓰면: **사후 $\propto$ 우도 $\times$ 사전**

### 빈도주의 vs 베이지안

| 관점 | 확률의 의미 | 핵심 질문 |
|------|-----------|----------|
| 빈도주의 | 반복 실험에서의 빈도 | "이 데이터가 나올 확률은?" |
| 베이지안 | 믿음의 정도 | "이 가설이 맞을 확률은?" |

### 딥러닝 연결

- **온라인 학습**: 이전 학습 결과(사후)가 다음 학습의 사전이 된다
- **Bayesian Neural Network**: 가중치 자체에 확률분포를 부여
- **Weight decay = 가우시안 사전분포**: $P(w) \sim \mathcal{N}(0, \sigma^2 I)$

## 2. 최대우도추정 (MLE)

### 핵심 아이디어

**"관찰한 데이터를 가장 잘 설명하는 파라미터를 고른다."**

**비유**: 동전을 5번 던져서 3번 앞면이 나왔다. 앞면 확률이 0.5인 동전? 0.6인 동전? 0.9인 동전? "이 결과가 가장 그럴듯한" 동전을 고르는 것이 MLE이다.

### 수식

데이터 $\{x_1, \ldots, x_n\}$이 i.i.d.일 때:

$$\theta_{\text{ML}} = \arg\max_\theta \sum_{i=1}^{n} \log P(x_i | \theta)$$

(곱의 최대화보다 합의 최대화가 계산에 편리하므로 로그를 취한다)

### 베르누이 MLE 예제

$n$번 동전 던지기에서 $k$번 앞면:

$$\text{log-lik} = k \log \theta + (n-k) \log(1-\theta)$$

미분해서 0으로 놓으면: $\theta_{\text{ML}} = \frac{k}{n}$ (직관과 일치!)

### 정규분포 MLE

$x_i \sim \mathcal{N}(\mu, \sigma^2)$일 때:

$$\mu_{\text{ML}} = \frac{1}{n}\sum x_i \quad \text{(표본 평균)}, \quad \sigma^2_{\text{ML}} = \frac{1}{n}\sum (x_i - \bar{x})^2$$

**주의**: 분산의 MLE는 **편향 추정량**이다! 비편향 추정량은 $n$ 대신 $n-1$로 나눈다.

### MLE의 과적합 문제

동전 3번 던져서 3번 다 앞면: $\theta_{\text{ML}} = 1.0$

이 모델은 "앞으로도 무조건 앞면만 나온다"고 예측하는데, 이는 명백히 비합리적!

**데이터가 적을 때 MLE는 극단적인 값을 줄 수 있다** -- 이것이 MAP가 필요한 이유.

## 3. MAP 추정 (Maximum A Posteriori)

### 핵심 아이디어

**MLE + 상식 = MAP**

"데이터만 보는 것"(MLE)이 아니라 "이미 알고 있는 것(사전 지식)도 함께 고려"한다.

### 수식

$$\theta_{\text{MAP}} = \arg\max_\theta \underbrace{\log P(E|\theta)}_{\text{log-likelihood}} + \underbrace{\log P(\theta)}_{\text{log-prior}}$$

### MLE vs MAP 비교

동전 3번 던져서 3번 앞면인 경우:

| 방법 | 결과 | 설명 |
|------|------|------|
| MLE | $\theta = 1.0$ | 데이터만 본다 -- 극단적 |
| MAP (약한 prior) | $\theta = 0.8$ | 상식도 반영 -- 합리적 |
| MAP (강한 prior) | $\theta \approx 0.5$ | 상식을 강하게 반영 |

### Uniform Prior일 때 MAP = MLE

$P(\theta) = \text{상수}$이면 $\log P(\theta)$도 상수이므로:

$$\theta_{\text{MAP}} = \arg\max_\theta [\log P(E|\theta) + \text{상수}] = \theta_{\text{ML}}$$

**MLE는 "모든 파라미터가 동등하게 가능하다"는 사전 가정을 가진 MAP의 특수 경우이다!**

### MAP와 정규화의 관계

이것이 딥러닝에서 아주 중요한 연결이다:

| 사전 분포 | MAP의 추가 항 | 딥러닝에서의 이름 |
|-----------|-------------|----------------|
| 가우시안 $\mathcal{N}(0, \sigma^2)$ | $-\frac{\lambda}{2}\|\theta\|^2$ | **L2 정규화 (Weight Decay)** |
| 라플라스 $\exp(-\lambda|\theta|)$ | $-\lambda\|\theta\|_1$ | **L1 정규화 (Sparsity)** |

> Weight decay를 쓴다는 것은 "가중치가 0 근처에 있을 것"이라는 사전 믿음을 반영하는 것이다!

### ML vs MAP 정리 표

| 속성 | ML | MAP (강한 prior) |
|------|-----|-----------------|
| 의존 대상 | 데이터(패턴) | 사전 지식(규칙) |
| 가설 공간 | 크다 (자유) | 작다 (제한적) |
| 과적합 | 쉽다 | 어렵다 |
| 데이터 많을 때 | 우수 | 비슷 |
| 데이터 적을 때 | 위험 | 안전 |

## 4. 엔트로피

### 핵심 아이디어

**"다음에 무엇이 나올지 얼마나 놀라울까?"를 숫자로 나타낸 것.**

**비유**: 생일 선물 상자를 열 때, 엄마가 "레고야"라고 미리 말해줬으면 안 놀랍다(엔트로피 낮음). 힌트 없이 열면 두근두근한다(엔트로피 높음).

### 수식

$$H(p) = -\sum_x p(x) \log p(x)$$

### 주요 성질

| 분포 | 엔트로피 | 의미 |
|------|---------|------|
| 결정론적 (one-hot) | $H = 0$ (최소) | 결과를 완전히 안다 |
| 균등분포 ($p_i = 1/n$) | $H = \log n$ (최대) | 전혀 예측 못 한다 |

### 최대 엔트로피 원리

- 유한 집합 위: **균등분포**가 최대 엔트로피
- 평균과 분산이 주어질 때: **정규분포**가 최대 엔트로피

### 딥러닝 연결

- **Label Smoothing**: one-hot 레이블의 엔트로피를 약간 높여 과적합 방지
- **강화학습**: 정책의 엔트로피에 보너스를 부여하여 탐색(exploration) 촉진

## 5. 교차 엔트로피 (Cross-Entropy)

### 핵심 아이디어

**"진짜 정답과 내 예측이 얼마나 다른지 재는 점수."**

**비유**: 시험의 정답지(진짜 분포 $p$)와 내 답안(예측 분포 $q$)이 있다. 교차 엔트로피는 "내 답안을 쓸 때 평균적으로 얼마나 틀리는지"를 숫자로 나타낸다.

### 수식

$$CE(p, q) = -\sum_x p(x) \log q(x)$$

### 핵심 관계

$$\boxed{CE(p, q) = H(p) + KL(p \| q)}$$

- $H(p)$: 진짜 분포의 본질적 불확실성 (바꿀 수 없음, 상수)
- $KL(p \| q) \geq 0$: 예측의 추가적 비효율성

**따라서 CE를 최소화하는 것은 KL divergence를 최소화하는 것과 동치!**

### 딥러닝에서의 교차 엔트로피 손실

분류 문제에서:
- 정답: one-hot $p = (0, \ldots, 1, \ldots, 0)$
- 모델 출력: $q = \text{softmax}(z)$

$$CE = -\log q(y_{\text{true}}) = -\log \frac{e^{z_{y_{\text{true}}}}}{\sum_c e^{z_c}}$$

이것이 **Negative Log-Likelihood (NLL)**이며, 딥러닝 분류의 표준 손실 함수이다.

### 정규분포에서의 놀라운 연결

가우시안 가정 + 같은 분산일 때:

$$KL(\mathcal{N}(\mu_1, \sigma^2) \| \mathcal{N}(\mu_2, \sigma^2)) = \frac{(\mu_1 - \mu_2)^2}{2\sigma^2}$$

**CE 최소화 = MSE 최소화!** 회귀에서 MSE를 쓰는 것은 가우시안 가정 하의 CE 최소화이다.

## 6. KL 다이버전스

### 핵심 아이디어

**두 확률분포가 "얼마나 다른지"를 측정하는 도구.**

**비유**: 두 주사위가 있다. 하나는 공정, 하나는 조작. KL divergence는 "조작 주사위가 공정 주사위와 얼마나 다른지"를 재는 자이다.

### 수식

$$KL(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)}$$

### 핵심 성질

| 성질 | 설명 |
|------|------|
| $KL(p \| q) \geq 0$ | 항상 0 이상 |
| $KL(p \| q) = 0 \iff p = q$ | 같을 때만 0 |
| $KL(p \| q) \neq KL(q \| p)$ | **비대칭! "거리"가 아니다** |

### Forward KL vs Reverse KL

이 차이가 딥러닝에서 매우 중요하다:

```
[진짜 분포 p]          [진짜 분포 p]
  ∧   ∧                  ∧   ∧
 / \ / \                / \ / \
/   X   \              /   X   \
────────────          ────────────
Forward KL:           Reverse KL:
min_q KL(p||q)        min_q KL(q||p)

→ q가 p의 모든 봉우리를   → q가 p의 하나의 봉우리에
  커버하려 함 (mode-covering)  집중 (mode-seeking)
```

| 유형 | 행동 | 사용처 |
|------|------|--------|
| Forward KL: $\min_q KL(p\|q)$ | mode-covering (모든 봉우리 커버) | **MLE/CE 최소화 (일반 학습)** |
| Reverse KL: $\min_q KL(q\|p)$ | mode-seeking (하나에 집중) | **변분 추론 (VAE)** |

### 가우시안 KL (자주 나오는 공식)

1차원, 같은 분산일 때: $KL = \frac{(\mu_1 - \mu_2)^2}{2\sigma^2}$

$D$차원:
$$KL(\mathcal{N}(\mu_1,\Sigma_1)\|\mathcal{N}(\mu_2,\Sigma_2)) = \frac{1}{2}\left[\log\frac{|\Sigma_2|}{|\Sigma_1|} + \text{tr}(\Sigma_1\Sigma_2^{-1}) + (\mu_1-\mu_2)^\top\Sigma_2^{-1}(\mu_1-\mu_2) - D\right]$$

### 딥러닝 연결

- **VAE의 ELBO**: $\log p(x) \geq \mathbb{E}_{q}[\log p(x|z)] - KL(q(z|x) \| p(z))$
- **Knowledge Distillation**: 학생 모델이 선생님의 soft label을 따라가도록 KL 최소화
- **PPO (강화학습)**: 정책 업데이트를 KL divergence로 제한

## 7. 상호정보량 (Mutual Information)

### 핵심 아이디어

**"하나를 알면 다른 하나를 맞추기 더 쉬워지나?"의 정도.**

**비유**: 비가 오는지 알면 우산 든 사람 수를 더 잘 예측할 수 있다. 이런 "도움의 정도"가 상호정보량이다.

### 수식

$$I(X; Y) = KL(p(x,y) \| p(x)p(y)) = H(X) - H(X|Y)$$

해석: $Y$를 알았을 때 $X$에 대한 **불확실성이 얼마나 줄어드는가**.

| 조건 | 의미 |
|------|------|
| $I(X;Y) = 0$ | $X$와 $Y$가 독립 (서로 정보 공유 없음) |
| $I(X;Y) > 0$ | 서로에 대한 정보를 공유함 |

### 딥러닝 연결

- **Contrastive Learning (SimCLR 등)**: 상호정보량의 하한을 최대화
- **Information Bottleneck**: 표현 $Z$가 입력의 정보는 적게, 출력의 정보는 많이 가지도록 학습
- **Data Processing Inequality**: 레이어가 깊어질수록 입력 정보가 줄어든다는 이론적 한계

## 8. 확률분포 적합과 베이지안 추론 사이클

### 핵심 아이디어

데이터가 주어졌을 때, "이 데이터를 가장 잘 설명하는 확률분포의 파라미터"를 찾는 과정.

### 방법론 순서

```
MLE (데이터만)  →  MAP (데이터 + 사전지식)  →  Full Bayesian (사후분포 전체)
   단순하지만         과적합 방지                불확실성 정량화
   과적합 위험          실용적                     계산 비용 높음
```

### 데이터 양에 따른 전략

| 데이터 양 | 추천 방법 | 이유 |
|----------|----------|------|
| 매우 적음 | MAP (강한 prior) | 데이터만으로는 불안정 |
| 보통 | MAP (약한 prior) | 균형 잡힌 추정 |
| 매우 많음 | MLE | 데이터가 충분하면 prior 불필요 |

LLM 시대에는 데이터가 매우 많으므로, 강한 사전지식 없이 MLE로도 뛰어난 성능을 낸다 -- 이것이 "Scaling Law"의 이론적 근거이다.

## 오해하기 쉬운 포인트

| # | 흔한 오해 | 실제 |
|---|----------|------|
| 1 | KL divergence는 "거리"이다 | **비대칭**이므로 거리가 아니다. $KL(p\|q) \neq KL(q\|p)$ |
| 2 | MLE는 항상 좋은 추정이다 | 데이터가 적으면 극단적 값을 준다 (동전 3/3 → $\theta = 1$) |
| 3 | 엔트로피가 높으면 나쁘다 | 맥락에 따라 다르다. 강화학습에서는 높은 엔트로피가 탐색에 유리 |
| 4 | CE와 KL divergence는 별개 | $CE = H + KL$이므로, $p$ 고정 시 CE 최소화 = KL 최소화 |
| 5 | 사전분포가 강할수록 좋다 | 너무 강하면 데이터를 무시하게 된다. 데이터 양과의 균형이 중요 |
| 6 | Forward KL과 Reverse KL은 비슷하다 | 다봉 분포를 근사할 때 결과가 극적으로 다르다 (mode-covering vs mode-seeking) |

## 정리/요약

### 한 줄 요약 표

| 개념 | 핵심 수식 | 한 줄 의미 |
|------|----------|-----------|
| 베이즈 정리 | $P(H\|E) \propto P(E\|H)P(H)$ | 데이터를 보고 믿음 업데이트 |
| MLE | $\arg\max_\theta \log P(E\|\theta)$ | 데이터를 가장 잘 설명하는 파라미터 |
| MAP | $\arg\max_\theta [\text{loglik} + \text{logprior}]$ | MLE + 사전지식 = 정규화 |
| 엔트로피 | $H(p) = -\mathbb{E}_p[\log p]$ | 불확실성(놀라움)의 평균 |
| 교차 엔트로피 | $CE(p,q) = H(p) + KL(p\|q)$ | 분류의 표준 손실함수 |
| KL divergence | $KL(p\|q) = \mathbb{E}_p[\log\frac{p}{q}]$ | 분포 차이의 비대칭 측정 |
| 상호정보량 | $I(X;Y) = H(X) - H(X\|Y)$ | 두 변수가 공유하는 정보 |

### 핵심 등가 관계

```
CE 최소화  =  KL 최소화  (H(p)가 상수이므로)
가우시안 KL  =  MSE  (같은 분산일 때)
MAP + 가우시안 prior  =  L2 정규화 (Weight Decay)
MAP + 라플라스 prior  =  L1 정규화 (Sparsity)
Uniform prior MAP  =  MLE
```

| 수학 개념 | 딥러닝 대응 |
|-----------|-----------|
| 베이즈 정리 | 가중치 업데이트, Bayesian NN |
| MLE | 정규화 없는 학습 (SGD only) |
| MAP | Weight decay, Dropout |
| 엔트로피 | Label smoothing, RL 탐색 보너스 |
| CE | **분류 손실함수 (softmax + CE)** |
| KL divergence | VAE의 ELBO, Knowledge Distillation |
| 상호정보량 | Contrastive Learning, InfoNCE |
