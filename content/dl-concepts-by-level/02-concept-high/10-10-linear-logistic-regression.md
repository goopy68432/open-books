# 10. 선형회귀와 로지스틱 회귀

## 왜 배우는가?

선형회귀와 로지스틱 회귀는 **딥러닝의 가장 단순한 형태**이다:
- 뉴런 1개짜리 네트워크 = 선형회귀 (연속 출력)
- 거기에 시그모이드를 씌우면 = 로지스틱 회귀 (이진 분류)

손실 함수 설계, 경사 하강법, MLE/MAP 추정 등 딥러닝의 모든 핵심 원리가 이 두 모델에서 시작된다. 이 기초를 완벽히 이해하면 복잡한 심층 신경망도 "선형 변환 + 비선형 활성화의 반복"으로 자연스럽게 확장할 수 있다.

---

## 1. 지도학습 프레임워크

### 핵심 개념

**비유**: 선생님이 문제와 정답을 같이 보여주면서 가르쳐준다. 나중에 새 문제를 보면 스스로 정답을 맞출 수 있게 되는 것이 지도학습이다.

### 두 가지 유형

| 유형 | 출력 $y$ | 예시 |
|------|---------|------|
| **분류** | 이산값 (카테고리) | 강아지/고양이 구분, 스팸 여부 |
| **회귀** | 연속값 (숫자) | 집값 예측, 기온 예측 |

### 수학적 표현

- 데이터: $S = \{(x_i, y_i)\}_{i=1}^n$ ($x$: 입력, $y$: 정답)
- 목표: 새로운 $x$가 들어왔을 때 $y$를 잘 예측하는 함수 $h$를 찾는다
- 목적 함수 (모집단 위험):
  - 분류: $L(h) = \mathbb{E}[\mathbf{1}(h(x) \neq y)]$ (오분류 확률)
  - 회귀: $L(h) = \mathbb{E}[(h(x) - y)^2]$ (평균 제곱 오차)

### 지도학습 vs 비지도학습 (확률적 관점)

```
비지도학습: p(x)를 모델링         → "데이터의 분포를 이해"
지도학습:   p(y|x)를 모델링       → "입력이 주어졌을 때 출력을 예측"
```

## 2. MLE와 NLL

### 핵심 아이디어

**"데이터를 가장 잘 설명하는 모델 파라미터를 찾는다"** = MLE (최대우도추정)

확률을 최대화하는 것 = 확률의 음의 로그(NLL)를 최소화하는 것:

$$\text{NLL}(h) = -\sum_{i=1}^{n} \log p(y_i | x_i, h)$$

### 가장 중요한 통찰

**분류와 회귀의 손실 함수는 모두 NLL의 특수한 경우이다!**

| 분포 가정 | NLL이 되는 것 | 사용처 |
|-----------|-------------|--------|
| 가우시안 ($y \sim \mathcal{N}(h(x), \sigma^2)$) | **MSE** (평균 제곱 오차) | 회귀 |
| 베르누이 ($y \sim \text{Bern}(h(x))$) | **BCE** (이진 교차 엔트로피) | 이진 분류 |
| 범주형 ($y \sim \text{Cat}(h(x))$) | **CE** (교차 엔트로피) | 다중 분류 |

> MSE를 쓰는 건 "관례"가 아니라, "오차가 정규분포"라는 가정에서 자연스럽게 유도되는 것이다!

### NLL과 KL divergence의 관계

$$KL(p_S \| q) = \underbrace{-H(p_S)}_{\text{상수}} + \underbrace{\frac{1}{n}\text{NLL}}_{\text{최소화 대상}}$$

**NLL 최소화 = KL 최소화 = 모델 분포를 데이터 분포에 가깝게 만드는 것**

## 3. 경험적 위험 최소화 (ERM)

### 핵심 아이디어

진짜 목표는 모든 데이터(모집단)에 대해 잘 맞추는 건데, 모집단 전체를 알 수 없으니 **가지고 있는 훈련 데이터에서의 평균 오차를 최소화**한다.

$$L_S(h) = \frac{1}{n}\sum_{i=1}^{n} \ell(y_i, h(x_i))$$

**비유**: 전교생 시험 성적을 예측하고 싶지만, 우리 반 성적으로 연습한다. "연습 데이터에서 틀린 횟수를 줄이자!"

### MLE와 ERM의 관계

MLE는 ERM의 **특수한 경우**: 손실 $\ell$로 $-\log p(y|x; h)$를 사용하면 MLE가 곧 ERM이 된다.

```
          ERM (일반적 손실 함수)
           ↓
   NLL을 손실로 사용하면
           ↓
    MLE (최대우도추정)
       ↓            ↓
가우시안 가정     베르누이 가정
       ↓            ↓
    MSE 손실      CE 손실
```

## 4. 선형회귀 모델

### 핵심 개념

**데이터에 가장 잘 맞는 직선(또는 초평면)을 찾는 것.**

**비유**: 키와 몸무게 데이터에 자를 대고 직선을 긋는다. "키가 170cm이면 몸무게는 약 65kg"처럼 예측한다.

### 모델

$$f_w(x) = w_1 x_1 + w_2 x_2 + \cdots + w_d x_d + b = x^\top w$$

- $w$: 가중치 벡터 (각 특징의 중요도)
- $b$: 편향 (y절편), 보통 $x$에 1을 추가하여 $w$에 통합

행렬 표현: $f_w(X) = Xw$, $X \in \mathbb{R}^{n \times p}$

### 확률적 해석

$$y_i = h(x_i) + \varepsilon_i, \quad \varepsilon_i \sim \mathcal{N}(0, \sigma^2)$$

"예측값 + 종 모양 오차". 대부분 예측값 근처에 있고, 아주 크게 틀리는 건 드물다.

## 5. 최소제곱법과 정규방정식

### 손실 함수

$$L_S(w) = \frac{1}{2}\|Xw - y\|^2 = \frac{1}{2}\sum_{i=1}^{n}(x_i^\top w - y_i)^2$$

**왜 제곱하는가?** 위로 빗나간 것(+3)과 아래로 빗나간 것(-3)을 그냥 더하면 상쇄되어 0이 된다. 제곱하면 둘 다 9가 되어 공평하게 벌점을 준다.

### 정규방정식 유도

$w$에 대해 미분하고 0으로 놓으면:

$$\nabla_w L_S = X^\top X w - X^\top y = 0$$

$$\boxed{\hat{\beta} = (X^\top X)^{-1} X^\top y} \quad \text{(정규방정식의 해)}$$

이것은 미분을 한 번만 하면 **닫힌 형태(closed-form)**로 답이 나오는 경우이다! 경사 하강법 없이도 직접 계산 가능하다.

### 해의 존재와 유일성

| 조건 | 해의 수 | 대처법 |
|------|---------|--------|
| $\text{rank}(X) = p$ (특징 수 이하의 데이터) | **유일** | $(X^\top X)^{-1}$ 존재 |
| $\text{rank}(X) < p$ (특징이 데이터보다 많음) | **무한히 많음** | 최소 노름 해 또는 정규화 |

### 기하학적 해석

$\hat{y} = X\hat{\beta}$는 $y$를 $X$의 열공간에 **직교 사영(orthogonal projection)**한 것이다. 잔차 $y - \hat{y}$는 $X$의 열공간에 수직이다.

## 6. 릿지 회귀 (Ridge Regression)

### 동기

$n < p$ (데이터보다 특징이 많을 때)이면 해가 무한히 많다. 또한 과적합 위험이 크다. 이를 해결하기 위해 **정규화 항을 추가**한다.

### 수식

$$L_S(w; \lambda) = \frac{1}{2}\|Xw - y\|^2 + \frac{\lambda}{2}\|w\|^2$$

두 번째 항이 가중치의 크기에 벌점을 준다. $\lambda > 0$이 클수록 가중치를 작게 유지하려 한다.

### 해

$$\boxed{\hat{\beta}_\lambda = (X^\top X + \lambda I)^{-1} X^\top y}$$

$X^\top X + \lambda I$는 항상 양정치(positive definite)이므로 **항상 역행렬이 존재**한다! 유일한 해가 보장된다.

### 확률적 해석

릿지 회귀 = 가우시안 사전분포 $p(w) \propto e^{-\frac{\lambda}{2}\|w\|^2}$를 가정한 **MAP 추정**.

> "가중치가 0 근처에 있을 것"이라는 상식을 수학적으로 반영한 것이 릿지 회귀이다!

## 7. 로지스틱 회귀

### 핵심 개념

**"예/아니오" 문제를 확률로 푸는 모델.**

**비유**: 스팸 여부를 판단할 때, 점수를 매긴 다음 S자 커브(시그모이드)를 통과시켜 "스팸일 확률 85%"처럼 대답한다.

### 모델

1단계: 선형 점수 계산: $z = x^\top w$

2단계: 시그모이드로 확률 변환:

$$f_w(x) = \sigma(x^\top w) = \frac{1}{1 + e^{-x^\top w}} \in (0, 1)$$

- $\sigma(z) > 0.5$이면 클래스 1 (양성)
- $\sigma(z) < 0.5$이면 클래스 0 (음성)

### 이름에 주의!

"Logistic **Regression**"이지만 실제로는 **분류** 모델이다! 확률값(0~1)을 출력하기 때문에 "회귀"라는 이름이 붙었을 뿐이다.

### 손실 함수: BCE (Binary Cross-Entropy)

$$L_S(w) = -\sum_i \left[ y_i \log \sigma(x_i^\top w) + (1-y_i) \log(1 - \sigma(x_i^\top w)) \right]$$

이것은 **닫힌 해가 없다!** 정규방정식 같은 공식이 없으므로 경사 하강법 등 **수치적 최적화**가 필요하다.

### 선형회귀 vs 로지스틱 회귀 비교

| 항목 | 선형회귀 | 로지스틱 회귀 |
|------|---------|-------------|
| 목적 | 연속값 예측 (회귀) | 이진 분류 |
| 모델 | $f_w(x) = x^\top w$ | $f_w(x) = \sigma(x^\top w)$ |
| 분포 가정 | 가우시안 | 베르누이 |
| 손실 함수 | MSE | BCE (Cross-Entropy) |
| 닫힌 해 | **있음** (정규방정식) | **없음** (수치 최적화 필요) |
| 출력 범위 | $(-\infty, +\infty)$ | $(0, 1)$ |

## 8. 소프트맥스와 다중 분류

### 핵심 아이디어

시그모이드가 **이진**(2개 클래스) 분류라면, 소프트맥스는 **다중**(C개 클래스) 분류의 일반화이다.

### 수식

$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}, \quad i = 1, \ldots, C$$

성질:
- 각 출력은 $0 < \text{softmax}(z)_i < 1$
- 전체 합 = 1 (확률 분포)
- 큰 $z_i$일수록 높은 확률

### 시그모이드는 소프트맥스의 특수 경우

$C = 2$일 때 소프트맥스:

$$\frac{e^{z_1}}{e^{z_1} + e^{z_0}} = \frac{1}{1 + e^{-(z_1 - z_0)}} = \sigma(z_1 - z_0)$$

### 다중 분류 손실: Categorical Cross-Entropy

$$L_S(W) = -\sum_i \log[\text{softmax}(Wx_i)]_{y_i}$$

## 9. KL 발산과 손실 함수의 통합

### 핵심 등가 관계

$$\arg\max_h \text{Likelihood} = \arg\min_h \text{NLL} = \arg\min_h \text{KL divergence}$$

모두 같은 것을 다른 각도에서 본 것이다:
- 우도 최대화 = 데이터를 잘 설명하는 모델
- NLL 최소화 = 계산에 편리한 형태
- KL 최소화 = 모델 분포를 데이터 분포에 가깝게

### 가우시안일 때

$$\text{NLL} = \frac{n}{2\sigma^2}\text{MSE} + \text{상수} \quad \Rightarrow \quad \text{NLL 최소화} = \text{MSE 최소화}$$

### 베르누이일 때

$$\text{NLL} = \text{BCE} + \text{상수} \quad \Rightarrow \quad \text{NLL 최소화} = \text{BCE 최소화}$$

## 10. 베이즈 최적 분류기와 나이브 베이즈

### 베이즈 최적 분류기

**이론적으로 가장 좋은** 분류기: 각 클래스의 사후 확률을 계산하여 가장 높은 것을 고른다.

$$f(x) = \arg\max_{k} p(y=k | x) = \arg\max_{k} p(x|y=k) \cdot p(y=k)$$

### 나이브 베이즈

특징들이 **독립**이라는 (순진한) 가정을 추가:

$$f(x) = \arg\max_{k} \prod_{i=1}^{d} p(x_i | y=k) \cdot p(y=k)$$

**비유**: 스팸 필터에서 "Congratulations"라는 단어가 나왔을 확률, "Free"라는 단어가 나왔을 확률 등을 독립적으로 계산하여 스팸 여부를 판단한다.

가정이 비현실적이지만, 실제로는 놀라울 정도로 잘 작동한다!

### LDA와 QDA

각 클래스의 데이터가 가우시안이라고 가정할 때:

| 방법 | 가정 | 결정 경계 |
|------|------|----------|
| **QDA** (이차 판별분석) | 각 클래스마다 다른 공분산 | 곡선 (이차) |
| **LDA** (선형 판별분석) | 모든 클래스가 같은 공분산 | **직선** (선형) |

LDA의 결정 경계: $f(x) = \text{sign}[a^\top x - b]$, 여기서 $a = \Sigma^{-1}(m_1 - m_2)$

## 11. 역사 이야기: 가우스와 케레스

1801년, 천문학자 피아치가 소행성 케레스를 40일간 관측했지만 태양 뒤로 사라졌다. 24살의 가우스는 단 19개의 관측값으로 케레스의 궤도를 예측했고, 12월 31일에 예측한 위치에서 정확히 발견되었다.

가우스가 사용한 방법이 바로 **최소제곱법** -- 관측 오차의 제곱합을 최소화하는 것이다. 이 200년 된 방법이 오늘날 딥러닝의 MSE 손실 함수로 매일 사용되고 있다.

## 오해하기 쉬운 포인트

| # | 흔한 오해 | 실제 |
|---|----------|------|
| 1 | MSE는 그냥 관례적으로 쓴다 | **가우시안 노이즈 + MLE**에서 자연스럽게 유도된다 |
| 2 | 로지스틱 회귀는 회귀 모델이다 | 이름과 달리 **이진 분류** 모델이다 |
| 3 | 정규방정식의 해는 항상 유일하다 | $n < p$이면 무한히 많은 해가 존재한다 |
| 4 | KL divergence는 거리이다 | **비대칭**이므로 수학적으로 거리가 아니다 |
| 5 | MLE와 ERM은 완전히 다르다 | MLE는 NLL을 손실로 사용한 **ERM의 특수 경우** |
| 6 | CE와 MSE는 근본적으로 다른 손실이다 | 둘 다 **NLL**이라는 같은 목적함수의 특수 경우 |
| 7 | 나이브 베이즈의 독립 가정은 비실용적이다 | 가정이 위반되어도 실제로 놀라울 정도로 잘 작동한다 |

## 정리/요약

### 한 문장 요약

> 선형회귀와 로지스틱 회귀는 각각 **"가우시안 + MLE = MSE"**와 **"베르누이 + MLE = CE"**로, 둘 다 NLL 최소화라는 **같은 원리의 두 가지 얼굴**이다.

### 핵심 공식 체크리스트

| # | 공식 | 의미 |
|---|------|------|
| 1 | $f_w(x) = x^\top w$ | 선형회귀 모델 |
| 2 | $\hat{\beta} = (X^\top X)^{-1}X^\top y$ | 정규방정식 (닫힌 해) |
| 3 | $\hat{\beta}_\lambda = (X^\top X + \lambda I)^{-1}X^\top y$ | 릿지 회귀 해 |
| 4 | $\sigma(z) = \frac{1}{1+e^{-z}}$ | 시그모이드 함수 |
| 5 | $\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$ | 소프트맥스 함수 |
| 6 | $\text{NLL}(\text{가우시안}) = \frac{n}{2\sigma^2}\text{MSE} + C$ | 가우시안 NLL = MSE |

### 논리 흐름도

```
가우시안 가정 ──→ NLL = MSE ──→ 정규방정식 (닫힌 해)
                                    ↓
                              릿지 정규화 (MAP)

베르누이 가정 ──→ NLL = BCE ──→ 경사 하강법 (수치 해)
                                    ↓
                              소프트맥스 (다중 클래스)
```
