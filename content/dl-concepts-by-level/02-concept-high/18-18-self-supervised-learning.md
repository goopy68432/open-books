# 18. 자기지도학습 (Self-Supervised Learning)

## 왜 배우는가?

현실 세계의 데이터 대부분은 라벨(정답)이 없다. 인터넷에 하루에 올라오는 이미지만 수십억 장인데, 일일이 "이건 고양이", "이건 자동차"라고 적어줄 수 있을까? 불가능하다.

자기지도학습(Self-Supervised Learning, SSL)은 **라벨 없이 데이터 자체의 구조를 이용해 학습**하는 방법이다. Yann LeCun(딥러닝의 거장)의 "케이크 비유"에 따르면:
- **자기지도학습** = 케이크 본체 (정보의 대부분)
- **지도학습** = 아이싱 (소량의 정보)
- **강화학습** = 체리 (극소량의 정보)

SSL은 BERT, GPT, CLIP, DINOv2 등 현대 AI의 핵심 기반 기술이다.

---

## 1. 자기지도학습의 세 가지 접근법

### 개요

SSL은 데이터에서 "가짜 과제"를 스스로 만들어서 풀면서 학습한다. 크게 세 가지 방법이 있다:

| 접근법 | 아이디어 | 대표 방법 |
|--------|---------|----------|
| **대입 과제 (Imputation)** | 입력의 일부를 가리고 복원 | MAE, BERT |
| **프록시 과제 (Pretext)** | 변환 관계를 예측 | 회전 예측, 상대 위치 예측 |
| **대조학습 (Contrastive)** | 같은 것은 가깝게, 다른 것은 멀게 | SimCLR, CLIP |

목표는 모두 같다: **다양한 과제에 활용할 수 있는 범용 표현(representation)을 학습하는 것**.

## 2. 대입 과제와 MAE

### 핵심 아이디어

시험의 "빈칸 채우기" 문제와 같다. 빈칸을 맞추려면 문맥을 이해해야 하듯, 이미지의 가려진 부분을 복원하려면 이미지의 전체 구조를 이해해야 한다.

### 수학적 구조

입력을 보이는 부분($x_v$)과 숨겨진 부분($x_h$)으로 나눈다:

$$\hat{x}_h = f(x_v, x_h = 0)$$

보이는 부분만으로 숨겨진 부분을 예측하는 함수 $f$를 학습한다.

### MAE (Masked Autoencoder)

이미지 분야의 대표적 대입 과제 방법이다:

```
원본 이미지
    │
    ↓ 패치로 분할
    │
    ↓ 75%를 무작위로 가림 (마스킹)
    │
    ↓ 보이는 25%만 인코더(ViT)에 입력
    │
    ↓ 마스크 토큰 추가 + 디코더로 원본 복원
    │
    ↓ 사전학습 후 디코더 제거, 인코더만 활용
```

**왜 75%나 가리는가?** 텍스트는 단어 하나가 의미 단위이므로 15%만 가려도 어렵다. 하지만 이미지 패치는 주변과 비슷한 경우가 많아(공간적 중복), 75%를 가려야 "쉽게 때우기"를 방지하고 의미 있는 학습이 된다.

## 3. 프록시 과제 (Pretext Tasks)

### 핵심 아이디어

"진짜 목표 대신 우회 문제를 풀어서 능력을 키우는 것". 수학 실력을 기르기 위해 퍼즐을 푸는 것과 같다.

### 대표적 방법들

**회전 예측**: 이미지를 {0도, 90도, 180도, 270도} 중 하나로 회전시키고, 몇 도 돌렸는지 맞추기

$$p(y \mid x_{\text{회전}}) \quad \text{(4-class 분류 문제)}$$

회전 각도를 맞추려면 물체의 "위/아래", "중력 방향" 같은 의미적 특징을 이해해야 한다.

**상대 위치 예측**: 이미지를 3x3 그리드로 나누고, 두 패치의 상대 위치(8가지 방향)를 맞추기

### 수학적 구조

원본 $x_1$에 변환 $t$를 적용하여 $x_2 = t(x_1)$을 생성하고, 표현 함수 $f$로 특징을 추출한 뒤, 변환 관계를 예측한다:

$$p(y \mid x_1, x_2) = p(y \mid r[f(x_1), f(x_2)])$$

$f$가 좋은 표현을 학습해야만 관계 $y$를 정확히 예측할 수 있다.

### 한계

모델이 의미적 특징 대신 저수준 단서(JPEG 아티팩트, 색수차 등)를 이용하는 **shortcut learning** 문제가 있다. 이 한계가 대조학습으로의 발전을 촉진했다.

## 4. 거리 메트릭 학습

### 핵심 아이디어

비슷한 것은 가까이, 다른 것은 멀리 배치하는 임베딩 공간을 학습한다.

### 세 가지 손실 함수의 발전

**1단계 - Contrastive Loss** (쌍 비교)
- 같은 쌍: 거리를 줄인다
- 다른 쌍: 거리가 마진($\epsilon$) 이상이 되도록 한다

**2단계 - Triplet Loss** (세 개 비교)
- Anchor(기준), Positive(같은 것), Negative(다른 것)
- $\text{ReLU}(\|e - e^+\|^2 - \|e - e^-\|^2 + \epsilon)$
- "Positive와의 거리가 Negative와의 거리보다 마진만큼 작아야 한다"

**3단계 - N-pair Loss (InfoNCE)**
- 여러 Negative를 동시에 비교

$$\ell = -\log \frac{\exp(e^\top e^+)}{\exp(e^\top e^+) + \sum_n \exp(e^\top e_n^-)}$$

softmax와 같은 구조로, 분모에 모든 Negative의 유사도가 들어간다. SimCLR과 CLIP이 이 손실을 사용한다.

### 유사도 측정

정규화된 임베딩의 코사인 유사도를 사용한다:

$$\text{sim}(e, e') = \frac{e^\top e'}{\|e\| \cdot \|e'\|}$$

## 5. SimCLR

### 4단계 구조

```
원본 이미지 x₀
    │
    ├── 변환 t  → x  (자르기 + 색상 변경)
    └── 변환 t' → x' (다른 자르기 + 색상 변경)
    │
    ↓ 인코더 r (예: ResNet)
    │
    (h, h') = (r(x), r(x'))  ← "표현" (나중에 사용할 것)
    │
    ↓ 프로젝션 헤드 g (MLP)
    │
    (z, z') = (g(h), g(h'))  ← 대조 손실 계산용
    │
    ↓ 대조 손실: 같은 이미지의 (z, z')는 가깝게, 다른 이미지는 멀게
```

### 손실 함수 (NT-Xent)

배치 안에서 $N$개의 이미지에서 각각 2개의 변형을 만들어 총 $2N$개의 벡터를 얻는다.

$$\ell_{i,j} = -\log \frac{\exp(\text{sim}(z_i, z_j) / \tau)}{\sum_{k \neq i} \exp(\text{sim}(z_i, z_k) / \tau)}$$

여기서 $\tau$는 temperature 파라미터이다.

### 핵심 포인트

- **프로젝션 헤드가 중요하다**: 대조 손실은 $z$에서 계산하지만, 실제 사용할 때는 인코더 출력 $h$를 쓴다. $z$는 augmentation 불변 정보만 남기고, $h$에는 더 풍부한 정보가 보존되기 때문이다.
- **큰 배치가 좋다**: Negative가 많을수록 학습이 좋아진다.
- **Augmentation 전략이 핵심**: random crop + color distortion 조합이 가장 효과적이다.

## 6. Barlow Twins

### SimCLR과 다른 접근

SimCLR은 "Negative 샘플"이 필수적이라 큰 배치에 의존한다. Barlow Twins는 **Negative 없이** 학습하는 방법이다.

### 핵심 아이디어: 교차상관행렬을 단위행렬로!

같은 이미지의 두 변형에서 나온 표현 $r, r'$의 **교차상관행렬** $C$를 단위행렬 $I$에 가깝게 만든다.

$$C = \frac{\bar{r}^\top \bar{r}'}{N} \in \mathbb{R}^{D \times D}$$

$$\mathcal{L} = \underbrace{\sum_i (1 - C_{ii})^2}_{\text{불변성: 같은 차원은 일치}} + \lambda \underbrace{\sum_{i \neq j} C_{ij}^2}_{\text{중복 제거: 다른 차원은 독립}}$$

- **대각 원소 $C_{ii} = 1$**: 같은 차원의 표현이 일치해야 한다 (불변성)
- **비대각 원소 $C_{ij} = 0$**: 서로 다른 차원이 독립적이어야 한다 (중복 제거)

$\lambda = 1$이면 간단히 $\mathcal{L} = \|C - I\|_F^2$ (프로베니우스 노름)이 된다.

### 왜 표현이 무너지지 않는가?

불변성 항만 있으면 모든 표현이 같은 상수로 무너질 수 있다(collapse). 중복 제거 항이 각 차원의 정보 분산을 강제하여 이를 방지한다.

## 7. CLIP (Contrastive Language-Image Pre-training)

### 이미지와 텍스트를 연결하다

인터넷에서 4억 개의 (이미지, 텍스트) 쌍을 수집하여, 이미지 인코더와 텍스트 인코더를 동시에 학습한다.

```
이미지 인코더 f_I         텍스트 인코더 f_T
     │                        │
   이미지 벡터 I_i          텍스트 벡터 T_j
     │                        │
     └────── 유사도 행렬 ──────┘
              L_ij = cos(I_i, T_j)
              대각선(올바른 쌍) 최대화
```

### 손실 함수

이미지 → 텍스트 방향과 텍스트 → 이미지 방향의 대칭 cross-entropy:

$$\mathcal{L} = \sum_i -\log[\text{softmax}(L_{i,:})]_i + \sum_j -\log[\text{softmax}(L_{:,j})]_j$$

### Zero-shot 분류가 가능하다!

학습 후, 새로운 카테고리의 이름만 알면 분류가 가능하다:

1. 각 클래스 이름을 "a photo of a {class}"로 텍스트 인코딩
2. 테스트 이미지를 이미지 인코딩
3. 코사인 유사도가 가장 높은 클래스 선택

$$p(y_k \mid x) = \text{softmax}(\cos(I, T_{1:K}))_k$$

CLIP은 DALL-E, Stable Diffusion 등 이미지 생성 모델의 핵심 구성 요소로도 활용된다.

## 8. 준지도학습과 메타학습 (관련 개념)

### 준지도학습 (Semi-Supervised Learning)

**소량의 라벨 데이터 + 대량의 라벨 없는 데이터**를 함께 사용한다.

대표적 방법 - **Self-training (Pseudo-labeling)**:
1. 라벨 데이터로 초기 모델 학습
2. 라벨 없는 데이터에 모델이 예측(pseudo-label 생성)
3. 높은 확신의 pseudo-label을 학습 데이터에 추가
4. 반복

### 메타학습 (Meta-Learning) - "학습하는 법을 학습"

**MAML** (Model-Agnostic Meta-Learning): 어떤 과제든 빠르게 적응할 수 있는 초기 파라미터 $\theta$를 찾는다.

- **내부 루프**: 특정 과제에 맞게 $\theta$를 빠르게 적응
  $$\theta_j' = \theta - \alpha \nabla_\theta L_j(\theta)$$

- **외부 루프**: 여러 과제에서의 적응 결과를 모아서 $\theta$를 업데이트
  $$\theta \leftarrow \theta - \beta \nabla_\theta \sum_j L_j(\theta_j')$$

특징: 외부 루프에서 내부 루프의 gradient를 한 번 더 미분하는 **이중 미분**이 필요하다.

## 9. SSL 방법론 발전사

```
2019  MoCo          큰 딕셔너리로 negative 관리
  │
2020  SimCLR        간단한 프레임워크, 큰 배치 필요
  │   BYOL          negative 없이 teacher-student 구조
  │
2021  Barlow Twins  교차상관 행렬로 negative 불필요
  │   CLIP          이미지-텍스트 대조학습, zero-shot
  │
2023  DINOv2        자기증류, ImageNet supervised를 능가
```

### Collapse 방지: SSL의 핵심 설계 과제

| 방법 | Collapse 방지 전략 |
|------|-------------------|
| SimCLR | Negative가 표현을 밀어내서 방지 |
| BYOL/SimSiam | Predictor + Stop gradient |
| Barlow Twins | 차원 간 독립성 강제 |
| SwAV | 프로토타입 할당의 균등화 |

## 오해하기 쉬운 포인트

### 1. "자기지도학습은 라벨이 전혀 없다"

라벨이 있다! 다만 사람이 아니라 **알고리즘이 자동 생성**한다. 마스킹, 회전 각도, augmentation 쌍 등이 모두 자동 생성 라벨이다.

### 2. "SimCLR의 최종 표현은 프로젝션 헤드 출력이다"

프로젝션 헤드 출력 $z$는 학습 시에만 쓰고, 실제 활용할 때는 **인코더 출력 $h$**를 사용한다. $h$에 더 풍부한 정보가 보존되어 있기 때문이다.

### 3. "Barlow Twins는 대조학습이다"

Barlow Twins는 **non-contrastive** 방법이다. Negative 쌍을 사용하지 않는다.

### 4. "CLIP은 이미지 분류 전용이다"

CLIP은 이미지-텍스트 **공동 임베딩 공간**을 학습하는 범용 모델이다. 분류, 검색, 이미지 생성 등 다양하게 활용된다.

### 5. "Triplet loss와 N-pair loss는 완전히 다르다"

N-pair loss에서 Negative가 1개면 Triplet loss와 거의 같다. N-pair는 Triplet의 일반화이다.

## 정리/요약

| 개념 | 핵심 한 줄 |
|------|-----------|
| 자기지도학습 | 라벨 없이 데이터 자체의 구조로 범용 표현을 학습. 현대 AI의 기반 |
| 대입 과제 / MAE | 입력의 숨겨진 부분을 복원하여 학습. MAE는 75% 마스킹으로 ViT 사전학습 |
| 프록시 과제 | 회전/위치 같은 우회 과제로 표현 학습. Shortcut learning 한계 존재 |
| 거리 메트릭 학습 | Contrastive → Triplet → N-pair로 발전. 유사한 것은 가깝게, 다른 것은 멀게 |
| SimCLR | 같은 이미지 변형은 당기고, 다른 이미지는 밀어냄. 큰 배치 + 프로젝션 헤드가 핵심 |
| Barlow Twins | 교차상관행렬 $\to$ 단위행렬. Negative 불필요, 중복 제거 원리 |
| CLIP | 이미지-텍스트 쌍의 대조학습. Zero-shot 분류 가능. 4억 쌍으로 학습 |
| 메타학습/MAML | "학습하는 법을 학습". 빠른 적응이 가능한 초기화를 찾는다 |
