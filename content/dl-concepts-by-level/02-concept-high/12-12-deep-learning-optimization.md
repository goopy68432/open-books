# 12. 딥러닝 최적화

## 왜 배우는가?

딥러닝 모델은 수백만~수십억 개의 파라미터를 가진다. 이 파라미터들의 최적값을 찾는 것이 곧 "학습"이다. 아무리 멋진 신경망 구조를 설계해도, 최적화가 제대로 되지 않으면 쓸모가 없다. 이 장에서는 "어떻게 파라미터를 효율적으로 찾는가"라는 핵심 질문에 답한다.

---

## 핵심 개념 1: 볼록 함수와 볼록 집합

### 직관적 설명

그릇(U자) 모양의 함수가 볼록 함수다. 구슬을 놓으면 어디에서 놓든 가장 낮은 곳으로 굴러간다. 반면, 계란판처럼 울퉁불퉁한 함수에서는 구슬이 여기저기 웅덩이에 빠질 수 있다.

### 수식과 의미

**볼록 집합**: 집합 안의 아무 두 점을 잇는 선분이 완전히 집합 안에 있다.

$$x, y \in X \;\Rightarrow\; \lambda x + (1 - \lambda)y \in X, \quad \forall \lambda \in [0, 1]$$

**볼록 함수**: 함수 위의 두 점을 잇는 직선이 항상 함수 그래프 위에 있다.

$$f(\lambda x + (1-\lambda)y) \leq \lambda f(x) + (1-\lambda)f(y)$$

예: $f(x) = x^2$는 볼록이다. 확인하면 $(\lambda x + (1-\lambda)y)^2 \leq \lambda x^2 + (1-\lambda)y^2$는 $\lambda(1-\lambda)(x-y)^2 \geq 0$으로 항상 성립.

### 왜 중요한가?

- **볼록 문제**: 전역 최솟값이 유일하고, 경사 하강법으로 반드시 찾을 수 있다
- **비볼록 문제**: 전역 최솟값 보장 없음. DNN의 손실은 일반적으로 비볼록
- 그런데도 SGD가 놀랍게 잘 작동한다는 것이 현대 딥러닝의 미스터리!

### 볼록 함수의 유용한 성질

| 성질 | 설명 |
|------|------|
| 접선 조건 | $f(x) \geq f(y) + \nabla f(y)^\top (x - y)$ (접선이 항상 함수 아래) |
| Hessian 조건 | $\nabla^2 f(x) \succeq 0$ (이계도함수가 양수/양의 준정치) |
| Jensen 부등식 | $f(\mathbb{E}[X]) \leq \mathbb{E}[f(X)]$ (평균의 함수값 $\leq$ 함수값의 평균) |

## 핵심 개념 2: 강볼록성과 매끄러움

### 직관적 설명

그릇이 너무 평평하면 구슬이 어디로 가야 할지 모르고(수렴 느림), 너무 뾰족하면 구슬이 너무 빨리 굴러가 넘어진다(불안정). **적당히 둥근 그릇**이 최적이다.

### 수식과 의미

**강볼록(Strong Convexity)**: "최소한 이 정도는 휘어있다"는 보장

$$f(x) \geq f(y) + \nabla f(y)^\top(x - y) + \frac{m}{2}\|x - y\|^2$$

$m > 0$이 클수록 함수가 더 가파르게 휘어있다.

**$\beta$-매끄러움(Smoothness)**: "최대한 이 정도만 휘어있다"는 보장

$$\left|f(x) - f(y) - \nabla f(y)^\top(x-y)\right| \leq \frac{\beta}{2}\|x - y\|^2$$

### 수렴 속도와의 관계

**조건수** $\kappa = \beta / m$ (매끄러움/강볼록성의 비율):
- $\kappa$가 작을수록 수렴이 빠르다
- 수렴 속도: $L_t - L^* \leq (1 - 1/\kappa)^t (L_0 - L^*)$

직관: $\kappa$가 크다 = 어떤 방향은 가파르고 어떤 방향은 평평하다 = 최적화가 어렵다

## 핵심 개념 3: 경사 하강법(Gradient Descent)

### 직관적 설명

안개 낀 산에서 가장 낮은 곳을 찾고 싶다. 눈을 감고 발밑의 경사를 느끼면서, 가장 가파르게 내려가는 방향으로 한 걸음씩 내려간다. "발로 경사 느끼기"가 미분(gradient)이고, "한 걸음 크기"가 학습률이다.

### 수식

$$\theta \leftarrow \theta - \eta \nabla_\theta L(\theta)$$

- $\theta$: 파라미터 (현재 위치)
- $\eta > 0$: **학습률** (걸음 크기)
- $\nabla_\theta L(\theta)$: 기울기 (가장 가파른 오르막 방향)
- 마이너스: 오르막의 반대 = 내리막으로 이동

### 학습률의 중요성

```
학습률이 너무 크면:  ---\/\/\/---  (발산하거나 진동)
학습률이 적당하면:  --\____/----  (안정적으로 수렴)
학습률이 너무 작으면: --------\..  (수렴이 매우 느림)
```

**수렴 조건**: 2차 함수 $L(\theta) = \frac{1}{2}\theta^\top A \theta$에서 $\eta < \frac{2}{\lambda_{\max}(A)}$이면 매 스텝 손실이 감소한다. $\lambda_{\max}$는 함수의 최대 곡률이다.

---

## 핵심 개념 4: 확률적 경사 하강법(SGD)

### 직관적 설명

산 전체의 기울기를 재려면 산 구석구석을 다 돌아봐야 해서 너무 오래 걸린다. 그래서 발밑의 **작은 영역만 보고** 대충 방향을 잡아서 내려간다. 정확하진 않지만 훨씬 빠르다!

### 수식

데이터 전체가 아닌 **미니배치** $B$ (무작위 부분집합)만으로 기울기를 추정:

$$\theta \leftarrow \theta - \eta \nabla_\theta L_B(\theta)$$

핵심 성질: $\mathbb{E}_B[\nabla L_B(\theta)] = \nabla L_S(\theta)$ (기댓값이 정확한 기울기와 같다 = **불편 추정량**)

### SGD의 장점

| 특성 | 전체 GD | SGD |
|------|---------|-----|
| 한 스텝 비용 | $O(n)$ (전체 데이터) | $O(b)$ (배치 크기) |
| 기울기 정확도 | 정확 | 노이즈 있음 |
| 국소 최솟값 | 빠지기 쉬움 | 노이즈 덕에 탈출 가능 |
| 일반화 | 보통 | 좋음 (암묵적 정규화) |

배치 크기와 학습률의 관계: 배치를 $k$배 키우면 학습률도 $k$배 키울 수 있다 (선형 스케일링 규칙).

## 핵심 개념 5: 모멘텀

### 직관적 설명

공을 산에서 굴리면 내리막에서 속도가 점점 빨라지고, 오르막에서도 관성 때문에 조금 더 나아간다. 이 "관성"을 이용하면 작은 언덕은 넘어가고 깊은 골짜기에 더 빨리 도달한다.

### 수식

**Heavy Ball (Polyak Momentum)**:
$$m \leftarrow \beta m + g(\theta)$$
$$\theta \leftarrow \theta - \eta m$$

- $\beta \in [0, 1)$: 모멘텀 계수 (보통 0.9)
- $\beta = 0$이면 일반 경사 하강법
- $m$을 풀어쓰면: $m_t = g_t + \beta g_{t-1} + \beta^2 g_{t-2} + \cdots$ (과거 기울기의 지수 이동 평균)

**Nesterov Accelerated Gradient (NAG)**: "앞을 내다보고" 기울기를 계산

$$m \leftarrow \beta m + g(\theta - \eta \beta m)$$

이론적으로 1차 방법 중 최적의 수렴 속도를 달성한다.

## 핵심 개념 6: 적응적 학습률 -- Adam

### 직관적 설명

산에서 내려갈 때, 어떤 방향은 가파르고 어떤 방향은 완만하다. 가파른 곳에서는 조심스럽게, 완만한 곳에서는 과감하게 걷는다. Adam은 **방향마다 걸음 크기를 자동으로 조절**한다.

### Adam = 모멘텀 + 적응적 학습률

1. **1차 모멘트** (모멘텀): $m \leftarrow \beta_1 m + (1 - \beta_1) g$
2. **2차 모멘트** (기울기 크기 추적): $s \leftarrow \beta_2 s + (1 - \beta_2) g^2$
3. **편향 보정**: $\hat{m} = m / (1 - \beta_1^t)$, $\hat{s} = s / (1 - \beta_2^t)$
4. **업데이트**: $\theta \leftarrow \theta - \eta \cdot \hat{m} / (\sqrt{\hat{s}} + \varepsilon)$

기본 하이퍼파라미터: $\beta_1 = 0.9$, $\beta_2 = 0.999$, $\varepsilon = 10^{-8}$

### 편향 보정이 필요한 이유

$s$를 0으로 초기화하면 초기 추정치가 0쪽으로 편향된다. $t$가 작을 때 $(1 - \beta^t)$으로 나눠주면 이 편향이 교정된다. $t$가 커지면 $\beta^t \to 0$이므로 보정 효과가 사라진다.

### 옵티마이저 진화 트리

```
GD --> SGD --> SGD + Momentum --> Adam (= Momentum + RMSProp)
                                  |
              AdaGrad(누적) --> RMSProp(지수이동평균) -+
```

## 핵심 개념 7: 역전파(Backpropagation)

### 직관적 설명

도미노를 세워놨다고 생각하자. 첫 번째 도미노(입력)를 밀면 차례대로 넘어져서 마지막 도미노(출력/손실)가 넘어진다. 역전파는 반대로, 마지막 도미노부터 **"얼마나 세게 밀었는지"를 거꾸로 추적**하는 것이다.

### 핵심 원리: 연쇄 법칙(Chain Rule)

2층 신경망의 경우:
$$x \to z_1 = W_1 x \to h = \sigma(z_1) \to z_2 = W_2 h \to L$$

$W_1$에 대한 기울기:
$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial z_2} \cdot \frac{\partial z_2}{\partial h} \cdot \frac{\partial h}{\partial z_1} \cdot \frac{\partial z_1}{\partial W_1}$$

각 단계의 미분을 뒤에서 앞으로 순서대로 곱한다.

### 주요 미분 공식

| 연산 | 미분 |
|------|------|
| Cross-Entropy: $L = -\log p_y$ | $\frac{\partial L}{\partial z} = p - e_y$ (예측 - 정답) |
| MSE: $L = \frac{1}{2}\|z - z_0\|^2$ | $\frac{\partial L}{\partial z} = z - z_0$ |
| ReLU | $\frac{\partial}{\partial z} = \begin{cases} 1 & z > 0 \\ 0 & z \leq 0 \end{cases}$ |
| 행렬곱 $y = Wx$ | $\frac{\partial y}{\partial x} = W$ |

### 시간 복잡도

역전파(backward pass)의 시간 복잡도는 순전파(forward pass)의 약 2~3배. 야코비안 행렬을 직접 만들지 않고, **벡터-야코비안 곱(VJP)**만 순차적으로 계산하기 때문이다.

## 핵심 개념 8: 학습률 스케줄

### 직관적 설명

처음에는 큰 걸음으로 빨리 가다가, 목적지에 가까워지면 작은 걸음으로 조심스럽게 간다.

### 주요 스케줄

| 스케줄 | 방법 | 특징 |
|--------|------|------|
| Step Decay | 일정 에폭마다 $\eta \times 0.9$ | 가장 단순 |
| Cosine Annealing | $\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\pi t/T))$ | 가장 인기 |
| Warmup | 초기에 $\eta$를 천천히 올림 | Adam 초기 불안정 해소 |
| Reduce-on-Plateau | 검증 손실이 정체되면 $\eta$ 감소 | 적응적 |

**Warmup이 필요한 이유**: Adam의 2차 모멘트 $s$가 초기에 부정확하므로, 학습률을 처음부터 크게 하면 불안정하다. Warmup으로 $s$가 안정화될 시간을 확보한다.

## 핵심 개념 9: 기울기 폭발/소실과 해결책

### 직관적 설명

전화기 게임에서 속삭이며 전달하면 메시지가 사라지고(소실), 소리 지르며 전달하면 알아들을 수 없어진다(폭발). 깊은 신경망에서도 기울기가 층을 지날수록 같은 문제가 생긴다.

### 해결책 모음

| 문제 | 해결책 | 핵심 아이디어 |
|------|--------|-------------|
| 기울기 폭발 | Gradient Clipping | 기울기 크기를 $c$ 이하로 잘라냄 |
| 기울기 소실 | ReLU 활성화 | 포화되지 않는 활성화 함수 |
| 기울기 소실 | **Residual Connection** | $y = F(x) + x$ (항등 경로 추가) |
| 양쪽 모두 | Batch Normalization | 각 층의 입력을 정규화 |
| 양쪽 모두 | 적절한 초기화 (Xavier, He) | 분산을 유지하는 초기화 |

### Residual Connection의 수학

$$y = F(x) + x \quad \Rightarrow \quad \frac{\partial y}{\partial x} = \frac{\partial F(x)}{\partial x} + I$$

항등 행렬 $I$가 더해져서 기울기가 최소한 1 이상 유지된다. 이것이 ResNet이 152층까지 학습 가능한 비결이다.

### Batch Normalization

각 미니배치에서 채널별로 평균을 빼고 표준편차로 나눈다:

$$\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \varepsilon}}, \quad y = \gamma \hat{x} + \beta$$

$\gamma, \beta$는 학습 가능한 파라미터. 효과: 손실 지형을 매끄럽게 만들어 큰 학습률 사용 가능.

## 핵심 개념 10: 수렴 이론과 비볼록 최적화

### 수렴 속도 분류

| 종류 | 속도 | 조건 |
|------|------|------|
| Sublinear | $O(1/t)$ | 볼록 + 매끄러움 |
| Linear | $O(\rho^t)$, $\rho < 1$ | 강볼록 + 매끄러움 |
| Quadratic | $\|x_{t+1} - x^*\| \leq c\|x_t - x^*\|^2$ | Newton's method |

### 비볼록 문제에서 왜 SGD가 잘 작동하는가?

DNN의 손실은 비볼록이지만, 놀랍게도 SGD가 좋은 해를 찾는다. 이유:

1. 과매개변수화된 DNN에서 대부분의 극솟값은 전역 최솟값과 비슷한 성능을 가진다
2. SGD의 노이즈가 **안장점(saddle point)**에서 탈출하는 데 도움을 준다
3. SGD는 **평평한 극솟값(flat minima)**으로 수렴하는 경향이 있어 일반화 성능이 좋다

---

## 오해하기 쉬운 포인트

### 1. "학습률이 작을수록 항상 좋다?"
틀렸다. 너무 작은 학습률은 수렴이 극도로 느리고, SGD의 탐색 능력도 줄어 나쁜 극솟값에 갇힐 수 있다.

### 2. "Adam은 항상 SGD보다 낫다?"
틀렸다. Adam은 빠르게 수렴하지만, 일부 문제(특히 컴퓨터 비전)에서 SGD + Momentum이 더 나은 일반화 성능을 보인다. NLP에서는 Adam이 표준.

### 3. "비볼록이면 경사 하강법은 무용지물이다?"
틀렸다. 실전에서 overparameterized DNN의 대부분 극솟값은 좋은 성능을 가지며, SGD의 노이즈가 안장점 탈출에 도움을 준다.

### 4. "역전파는 순전파보다 훨씬 비싸다?"
틀렸다. VJP 체인 방식 덕분에 역전파는 순전파의 약 2~3배 비용일 뿐이다. 야코비안 행렬을 명시적으로 만들지 않기 때문이다.

### 5. "Batch Normalization은 내부 공변량 이동을 해결하기 위한 것이다?"
원래 논문의 주장이었지만, 후속 연구에 따르면 BN의 실제 효과는 **손실 지형을 매끄럽게 만드는 것**이다.

### 6. "모멘텀 $\beta$가 크면 항상 빠르게 수렴한다?"
틀렸다. $\beta$가 너무 크면 과거 기울기에 과도하게 의존하여 방향 전환이 느려지고, 최솟값 주변에서 진동이 심해진다.

## 정리 및 요약

```
목표: min L(theta)  [손실 함수 최소화 = 학습]

최적화 알고리즘 진화:
  GD --> SGD --> SGD+Momentum --> Adam (= Momentum + RMSProp)

핵심 수렴 조건:
  - 2차 함수: eta < 2/lambda_max
  - beta-smooth + 강볼록: 선형 수렴 보장

실전 체크리스트:
  [1] 역전파 (VJP 체인)로 기울기 계산
  [2] 학습률 스케줄: warmup + cosine annealing
  [3] Gradient clipping (폭발 방지)
  [4] Residual connection + BN/LN (소실 방지)
  [5] 하이퍼파라미터: eta, batch size, beta1, beta2
```

| 개념 | 핵심 수식 | 한 줄 요약 |
|------|----------|-----------|
| 경사 하강법 | $\theta \leftarrow \theta - \eta \nabla L$ | 기울기 반대 방향으로 이동 |
| SGD | $\theta \leftarrow \theta - \eta \nabla L_B$ | 미니배치로 빠르게 근사 |
| 모멘텀 | $m \leftarrow \beta m + g$ | 관성으로 가속 |
| Adam | 1차 모멘트 + 2차 모멘트 + 편향 보정 | 방향별 적응적 학습률 |
| 역전파 | 연쇄 법칙으로 기울기 역방향 계산 | 순전파의 2~3배 비용 |
| Residual | $y = F(x) + x$ | 기울기 소실 방지 |
| Batch Norm | 정규화 후 스케일/시프트 | 손실 지형 매끈하게 |
