# 07. 미분방정식

## 왜 배우는가?

미분방정식은 **"변화의 법칙"**을 수학으로 표현하는 도구이다. 딥러닝에서 중요한 이유:

- **시그모이드 함수**가 사실은 로지스틱 미분방정식의 해이다
- **ResNet**의 잔차 연결은 미분방정식의 수치 풀이(오일러 방법)와 같은 구조이다
- **Neural ODE**는 이산적 레이어 대신 연속 동역학을 직접 학습한다
- **Gradient explosion/vanishing** 현상을 미분방정식으로 이해할 수 있다

---

## 1. 미분방정식이란?

### 핵심 개념

미분방정식(ODE: Ordinary Differential Equation)은 **미지 함수 $x(t)$와 그 도함수 $x' = \frac{dx}{dt}$의 관계식**이다.

**비유**: 물병에 구멍이 뚫려서 물이 빠지고 있다. 물이 많으면 수압이 세서 빨리 빠지고, 물이 적으면 천천히 빠진다. "물이 빠지는 속도 = 남은 물의 양에 비례"라는 규칙을 수식으로 쓴 것이 미분방정식이다.

$$x' = f(x) \quad \leftarrow \text{"변화 속도가 현재 상태에 의해 결정된다"}$$

### ODE 유형 분류표

우변 $f(x)$의 모양에 따라 해의 행동이 완전히 달라진다:

| ODE | 해의 유형 | 직관 |
|-----|----------|------|
| $x' = a$ (상수) | 직선: $x(t) = x_0 + at$ | 일정한 속도로 이동 |
| $x' = ax$ (1차) | 지수: $x(t) = x_0 e^{at}$ | 복리와 같은 성장/감쇠 |
| $x' = x^2$ (2차, 근 1개) | 쌍곡: $x(t) = \frac{1}{1/x_0 - t}$ | 유한 시간에 폭발! |
| $x' = ax(1-x)$ (2차, 근 2개) | **시그모이드** | S자 곡선 (포화 성장) |

**핵심 관찰**: 우변의 **근(영점)의 개수**가 해의 질적 행동을 결정한다.

---

## 2. 변수분리법

### 핵심 개념

미분방정식을 풀 때 **$x$ 관련 항과 $t$ 관련 항을 양쪽으로 분리**한 후 각각 적분하는 방법이다.

**비유**: 밀가루와 설탕을 따로 계량한 후 합치듯이, $x$와 $t$를 분리해서 각각 계산한다.

### 풀이 패턴

$$x' = f(x) \quad \Rightarrow \quad \frac{dx}{f(x)} = dt \quad \Rightarrow \quad \int \frac{dx}{f(x)} = t + C$$

이 패턴이 아래 모든 ODE 풀이에 반복적으로 등장한다.

---

## 3. 선형 ODE와 지수 해

### $x' = ax$의 풀이

**비유**: 은행에 돈을 맡기면 이자가 붙고, 이자에 또 이자가 붙는 "복리"와 같다.

변수분리법 적용:

$$\frac{dx}{x} = a \, dt \quad \Rightarrow \quad \ln|x| = at + C \quad \Rightarrow \quad \boxed{x(t) = x_0 e^{at}}$$

| $a$의 부호 | 해의 행동 | 딥러닝 연결 |
|-----------|----------|------------|
| $a > 0$ | 폭발적 증가 (지수 성장) | Gradient explosion |
| $a < 0$ | 0으로 감소 (지수 감쇠) | Gradient descent의 수렴 |
| $a = 0$ | 변화 없음 | 학습 정체 |

### $x' = ax + b$의 풀이

평형점 $x^* = -b/a$를 중심으로 지수적으로 수렴하거나 발산한다:

$$x(t) = \left(x_0 + \frac{b}{a}\right)e^{at} - \frac{b}{a}$$

### 딥러닝 연결: Gradient Flow

경사하강법의 연속 버전이 바로 이 선형 ODE이다. 이차 손실함수 $L(\theta) = \frac{a}{2}\theta^2$에서:

$$\dot{\theta} = -\nabla L = -a\theta \quad \Rightarrow \quad \theta(t) = \theta_0 \, e^{-at}$$

$a > 0$이면 파라미터가 지수적으로 0에 수렴한다 -- 이것이 gradient descent가 작동하는 원리이다.

---

## 4. 쌍곡 성장과 유한시간 폭발

### $x' = x^2$의 풀이

**비유**: 소문이 퍼지는 속도가 "이미 아는 사람 수의 제곱"에 비례한다면, 처음엔 느리다가 어느 순간 폭발적으로 퍼져서 유한한 시간 안에 "무한대"에 도달한다.

$$\frac{dx}{x^2} = dt \quad \Rightarrow \quad -\frac{1}{x} = t + C \quad \Rightarrow \quad \boxed{x(t) = \frac{1}{1/x_0 - t}}$$

### 유한시간 폭발 (Finite-time Blow-up)

$t \to 1/x_0$일 때 $x(t) \to \infty$. 초기값 $x_0 = 0.1$이면 $t = 10$에서 폭발!

```
지수 성장 vs 쌍곡 성장 비교:

지수 (x' = ax):     천천히 올라가다... 점점 빨라짐... (무한 시간 후 무한대)
쌍곡 (x' = x^2):    천천히 올라가다... 갑자기 수직 상승! (유한 시간에 무한대)
                                                    |
                                                    ← 이 순간이 blow-up
```

### 딥러닝 연결

- **Gradient explosion**: RNN에서 비선형 항이 있으면 쌍곡적 폭발이 가능하다
- **Neural ODE**: 벡터장에 Lipschitz 조건을 부과하여 blow-up을 방지한다
- **Gradient clipping**: 폭발을 막기 위해 기울기 크기를 제한하는 기법

## 5. 로지스틱 방정식과 시그모이드 유도

### 핵심: 시그모이드는 미분방정식의 해이다!

$$x' = ax(1-x)$$

**비유**: 호수에 물고기가 늘어난다. 처음엔 먹이가 충분해서 빠르게 늘지만, 물고기가 많아지면 먹이가 부족해져서 성장이 느려진다. 결국 호수가 수용할 수 있는 최대 수에서 멈춘다.

### 해의 구조 분석

- $x$가 작을 때: $(1-x) \approx 1$이므로 $x' \approx ax$ -- **지수적 성장**
- $x$가 1에 가까울 때: $(1-x) \approx 0$이므로 $x' \approx 0$ -- **성장 멈춤**
- 결과: 0에서 시작하면 **S자 곡선**을 그리며 1에 수렴

### 부분분수 분해를 이용한 풀이

$$\frac{1}{x(x-1)}dx = -a \, dt$$

부분분수: $\frac{1}{x(x-1)} = \frac{1}{x-1} - \frac{1}{x}$

적분 후 정리하면:

$$\boxed{x(t) = \frac{1}{1 + Ce^{-at}}}$$

여기서 $C = \frac{1-x_0}{x_0}$.

### 시그모이드와의 연결

$x_0$가 매우 작을 때:

$$x(t) \approx \frac{1}{1 + \frac{1}{x_0}e^{-at}} = \sigma\left(at - \ln\frac{1}{x_0}\right)$$

여기서 $\sigma(z) = \frac{1}{1+e^{-z}}$은 바로 딥러닝의 **시그모이드 활성화 함수**이다!

### 딥러닝 연결

1. **시그모이드의 도함수**: $\sigma'(z) = \sigma(z)(1-\sigma(z))$는 정확히 $x' = x(1-x)$ ($a=1$)이다

2. **Vanishing Gradient 설명**: 포화 영역($x \approx 0$ 또는 $x \approx 1$)에서 $x' \approx 0$이므로 기울기가 사라진다. 이것이 시그모이드를 쓸 때 gradient vanishing이 생기는 근본 원인이다.

3. **ReLU의 등장 이유**: 시그모이드의 포화 문제를 해결하기 위해 ReLU 등 대안 활성화 함수가 개발되었다.

## 6. 일반 이중근 이차 ODE

### $x' = ax(\beta - x)$의 풀이

이것은 **수용량(carrying capacity)이 $\beta$인 로지스틱 성장**이다.

$$x(t) = \frac{\beta}{1 + C'e^{-a\beta t}}$$

| 파라미터 | 역할 |
|---------|------|
| $\alpha, \beta$ | 하한과 상한 (평형점) |
| $a$ | 전이(transition) 속도 |
| $x_0$ | 초기 위치 -- 전이 시점 결정 |

### 반감기 분석

$x = \beta/2$에 도달하는 시간: $t \propto \frac{1}{\beta}$

$\beta$가 클수록 절대적 목표는 높지만, 초기 가속도($a\beta$)도 높아져 상대적 도달 시간은 줄어든다.

### 딥러닝 연결: 학습 곡선

딥러닝의 학습 곡선이 종종 시그모이드를 따르는 이유: 학습 초기에는 쉬운 패턴을 빠르게 학습(지수적 성장)하고, 후기에는 한계에 도달(포화)하기 때문이다.

## 7. 안정성 이론과 위상 평면

### 평형점의 안정성

**비유**:
- **안정**: 그릇 안에 구슬을 놓으면 바닥으로 굴러감 -- 건드려도 돌아온다
- **불안정**: 뒤집힌 그릇 위에 구슬을 놓으면 굴러 떨어짐 -- 조금만 건드려도 멀어진다

### 1차원 안정성 판별

고정점 $x^*$에서 $f(x^*) = 0$일 때:
- $f'(x^*) < 0$: **안정** (attracting) -- 주변 해가 고정점으로 수렴
- $f'(x^*) > 0$: **불안정** (repelling) -- 주변 해가 고정점에서 발산

### 2차원 선형 시스템: $\dot{X} = AX$

행렬 $A$의 행렬식(det)과 대각합(tr)으로 위상 초상(phase portrait)을 분류한다:

| 조건 | 유형 |
|------|------|
| $\det(A) < 0$ | **안장점** (saddle) -- 한 방향으로 끌리고, 다른 방향으로 밀림 |
| $\det(A) > 0$, $\text{tr}(A) < 0$ | **안정** (sink) -- 모든 방향에서 수렴 |
| $\det(A) > 0$, $\text{tr}(A) > 0$ | **불안정** (source) -- 모든 방향에서 발산 |
| $\det(A) > 0$, $\text{tr}(A) = 0$ | **중심** (center) -- 영원히 회전 |

판별식 $\Delta = (\text{tr}A)^2 - 4\det A$에 따라:
- $\Delta > 0$: 노드 (실수 고유값)
- $\Delta < 0$: 나선 (복소 고유값)

### 딥러닝 연결

- **손실 함수의 극소점**: 안정 고정점에 대응
- **안장점 문제**: 고차원에서 안장점이 극소보다 훨씬 많음
- **ResNet = 오일러 방법**: $x_{l+1} = x_l + f_\theta(x_l)$은 $\dot{x} = f_\theta(x)$의 오일러 이산화
- **Batch Normalization**: 학습 동역학의 불안정한 spiral을 안정한 node로 변환하는 효과

## 오해하기 쉬운 포인트

| # | 흔한 오해 | 실제 |
|---|----------|------|
| 1 | "$x' = x^2$도 지수 성장과 비슷하다" | 지수 성장은 무한 시간 후 무한대이지만, 쌍곡 성장은 **유한 시간**에 무한대가 된다 |
| 2 | "시그모이드는 누군가 임의로 설계한 것이다" | 로지스틱 ODE $x' = ax(1-x)$의 **자연스러운 해**이다 |
| 3 | "평형점은 항상 안정하다" | 안정, 불안정, 반안정 중 하나이다. $f'(x^*)$의 부호로 판별 |
| 4 | "ODE를 풀면 항상 공식이 나온다" | 대부분의 ODE는 닫힌 형태의 해가 없다. 변수분리로 풀리는 건 특수한 경우 |
| 5 | "선형 ODE $x' = ax + b$의 해는 직선이다" | "선형"은 $x$에 대한 것이지, 해가 직선이라는 뜻이 아니다. 해는 **지수함수** |
| 6 | "$x' = ax(1-x)$에서 $a$가 크면 최종값도 크다" | $a$는 전이 **속도**만 결정하며, 최종값(상한)은 항상 1이다 |
| 7 | "Center(중심)는 안정이다" | 중립 안정일 뿐, 점근 안정은 아니다. 해가 원점에 수렴하지 않고 영원히 회전한다 |

## 정리/요약

### 핵심 공식 3개

$$\boxed{x' = ax \;\Rightarrow\; x(t) = x_0 e^{at}} \quad \text{(지수 성장/감쇠)}$$

$$\boxed{x' = x^2 \;\Rightarrow\; x(t) = \frac{1}{1/x_0 - t}} \quad \text{(쌍곡 성장, blow-up)}$$

$$\boxed{x' = ax(1-x) \;\Rightarrow\; x(t) = \sigma(at + C)} \quad \text{(시그모이드)}$$

### 기억 흐름

```
상수   →  선형   →  지수   →  쌍곡   →  시그모이드  →  안정성
x'=a     x'=ax    e^(at)   1/(1/x₀-t)   sigma(z)     Poincare
직선     곡선     발산      폭발         포화          분류
```

### 수학과 딥러닝 연결

| 수학 개념 | 딥러닝에서의 역할 |
|-----------|-----------------|
| $x' = ax$ (지수 해) | Gradient flow, 학습률과 수렴 속도 |
| $x' = ax(1-x)$ (시그모이드 해) | 시그모이드 활성화 함수의 수학적 기원 |
| $\sigma'(z) = \sigma(z)(1-\sigma(z))$ | Vanishing gradient의 근본 원인 |
| $x' = x^2$ (유한시간 폭발) | Gradient explosion, 수치적 불안정 |
| 오일러 방법: $x_{n+1} = x_n + hf(x_n)$ | ResNet의 잔차 연결 $x_{l+1} = x_l + f_\theta(x_l)$ |
| 고정점 안정성 | 손실 함수의 극소점/안장점 분류 |
