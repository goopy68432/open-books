# 04. 노름, 대각합, 연립방정식 -- 크기 측정과 방정식 풀기

> 이 문서는 고등학생 수준에서 노름, 대각합, 유사역행렬 등을 설명합니다.

---

## 왜 이걸 배워야 할까?

딥러닝에서는 끊임없이 "크기"를 재야 한다:
- 예측이 정답에서 **얼마나 벗어났는지** (손실 함수)
- 가중치가 **얼마나 큰지** (정규화)
- 모델이 데이터를 **얼마나 잘 맞추는지** (최소제곱법)

노름은 이 "크기를 재는 도구"이고, 유사역행렬은 "정확한 답이 없을 때 최선의 답을 찾는 도구"이다.

---

## 1. 벡터 노름 (Vector Norm)

### 핵심 개념

노름은 벡터의 **"길이"를 일반화한 개념**이다.

### Lp 노름 패밀리

$$\|v\|_p = \left(|v_1|^p + |v_2|^p + \cdots + |v_n|^p\right)^{1/p}$$

| 노름 | 정의 | 직관 | 예시 ($v = [3, 4]$) |
|------|------|------|---------------------|
| $\|v\|_1$ (L1) | $|v_1| + |v_2| + \cdots$ | 맨해튼 거리 (블록 수) | $3 + 4 = 7$ |
| $\|v\|_2$ (L2) | $\sqrt{v_1^2 + v_2^2 + \cdots}$ | 직선 거리 (유클리드) | $\sqrt{9 + 16} = 5$ |
| $\|v\|_\infty$ (Linf) | $\max_i |v_i|$ | 가장 큰 성분 | $\max(3, 4) = 4$ |
| $\|v\|_0$ ("L0") | 0 아닌 원소 개수 | 비영 원소 수 | $2$ |

**주의**: L0 "노름"은 진정한 노름이 아니다 (삼각부등식 불만족). 관례적 명칭일 뿐.

### 직관: 같은 벡터, 다른 자

```
p에 따른 단위원 (||v||_p = 1인 점들의 모양):

L1:  마름모     L2:  원         Linf: 정사각형
  /\             ___
 /  \           /   \            ___
 \  /           \___/           |   |
  \/                            |___|
```

### 딥러닝에서 왜 중요한가?

| 노름 | 딥러닝 활용 |
|------|------------|
| L2 | MSE 손실함수: $\|y - \hat{y}\|_2^2$, Weight decay: $\lambda\|W\|_2^2$ |
| L1 | MAE 손실, 희소성(sparsity) 유도 정규화 (Lasso) |
| Linf | Adversarial attack에서 허용 범위 |
| L0 | 프루닝(pruning): 0인 가중치 수 |

## 2. 행렬 노름 (Matrix Norm)

### 핵심: 특이값으로 통일된다

행렬 $A$의 특이값을 $\sigma_1 \geq \sigma_2 \geq \cdots \geq 0$이라 할 때:

| 행렬 노름 | 정의 | 특이값 해석 |
|-----------|------|-----------|
| **Nuclear 노름** $\|A\|_*$ | $\sum_i \sigma_i$ | 특이값의 L1 노름 |
| **Frobenius 노름** $\|A\|_F$ | $\sqrt{\sum_{i,j} a_{ij}^2}$ | 특이값의 L2 노름 |
| **Spectral 노름** $\|A\|_\sigma$ | $\sigma_{\max}$ | 특이값의 Linf 노름 |

항상 성립: $\|A\|_\sigma \leq \|A\|_F \leq \|A\|_*$

### 각 행렬 노름의 의미

- **Frobenius 노름**: 행렬의 모든 원소를 하나의 긴 벡터로 펼쳤을 때의 L2 노름
  - $\|A\|_F = \sqrt{\text{Tr}(A^{\top}A)}$ (대각합과 연결!)
- **Spectral 노름**: 행렬이 벡터를 최대 얼마나 늘리는가
  - $\|A\|_\sigma = \max_{x \neq 0} \frac{\|Ax\|}{\|x\|}$
- **Nuclear 노름**: 저랭크 구조를 촉진하는 정규화에 사용

### 숫자 예시

$A = \text{diag}(3, 1, 0)$ (특이값 = 3, 1, 0)

- $\|A\|_* = 3 + 1 + 0 = 4$
- $\|A\|_F = \sqrt{3^2 + 1^2 + 0^2} = \sqrt{10} \approx 3.16$
- $\|A\|_\sigma = 3$

### 딥러닝에서 왜 중요한가?

- **L2 정규화**: $\lambda\|W\|_F^2$ -- 가중치를 골고루 작게 유지
- **Spectral Normalization**: GAN 판별자의 가중치를 $W / \|W\|_\sigma$로 정규화 -- 학습 안정화
- **Nuclear 노름 정규화**: 저랭크 구조 유도 (추천 시스템의 행렬 완성 문제)

### 오해하기 쉬운 포인트

| 오해 | 실제 |
|------|------|
| Frobenius 노름 = 벡터 L2 노름 | Frobenius는 **행렬**의 노름. 벡터 L2와 적용 대상이 다르다 |
| Spectral 노름 = 최대 고유값 | Spectral 노름 = 최대 **특이값**. 고유값과 특이값은 다르다! |

## 3. 대각합 (Trace)

### 핵심 정의

정사각 행렬의 **대각선 원소를 모두 더한 값**:

$$\text{Tr}(A) = \sum_{i} a_{ii} = a_{11} + a_{22} + \cdots + a_{nn}$$

### 놀라운 사실

$$\boxed{\text{Tr}(A) = \text{고유값의 합} = \lambda_1 + \lambda_2 + \cdots + \lambda_n}$$

### Trace의 핵심 성질

| 성질 | 수식 | 의미 |
|------|------|------|
| 전치 불변 | $\text{Tr}(A^{\top}) = \text{Tr}(A)$ | 전치해도 대각합 같음 |
| 선형성 | $\text{Tr}(A + B) = \text{Tr}(A) + \text{Tr}(B)$ | 합의 trace = trace의 합 |
| **순환 성질** | $\text{Tr}(AB) = \text{Tr}(BA)$ | 곱 순서를 순환적으로 바꿔도 됨 |
| Frobenius 연결 | $\|A\|_F^2 = \text{Tr}(A^{\top}A)$ | Frobenius 노름의 제곱 |

**순환 성질 주의**: $\text{Tr}(ABC) = \text{Tr}(BCA) = \text{Tr}(CAB)$는 되지만, $\text{Tr}(ABC) \neq \text{Tr}(ACB)$ (순서 **뒤집기**는 안 됨, **순환 이동**만 됨)

### 이차형식과 Trace의 관계

$$x^{\top}Ax = \text{Tr}(x^{\top}Ax) = \text{Tr}(Axx^{\top})$$

이 변환이 왜 유용한가? 기대값 계산에서:

$$\mathbb{E}[x^{\top}Ax] = \text{Tr}(A \cdot \mathbb{E}[xx^{\top}])$$

### Hutchinson Trace 추정

큰 행렬의 trace를 **직접 계산하지 않고** 추정하는 방법:

$$\text{Tr}(A) \approx \frac{1}{s}\sum_{i=1}^{s} x_i^{\top} A x_i \quad (x_i \sim \mathcal{N}(0, I))$$

**핵심**: 행렬의 원소에 직접 접근하지 않고, **행렬-벡터 곱만으로** trace를 추정한다. 대규모 행렬에서 위력적.

### 딥러닝에서 왜 중요한가?

- Hessian의 trace 추정: 손실 함수의 곡률(curvature) 파악
- Frobenius 노름 계산: 정규화 항 $\|W\|_F^2 = \text{Tr}(W^{\top}W)$

## 4. 연립방정식 풀이 ($Ax = b$)

### 세 가지 경우

$A \in \mathbb{R}^{m \times n}$, $x \in \mathbb{R}^n$, $b \in \mathbb{R}^m$일 때:

| 경우 | 조건 | 해의 수 |
|------|------|--------|
| **유일한 해** | $A$가 정사각 가역 ($\text{rank}(A) = n = m$) | 1개: $x = A^{-1}b$ |
| **무한히 많은 해** | $b$가 열공간에 있지만 rank < $n$ | 무한개 |
| **해가 없음** | $b$가 열공간 밖 | 0개 |

### 일상 비유

사과 1개와 배 2개를 사면 1000원, 사과 2개와 배 1개를 사면 800원이다.
- 방정식 2개, 미지수 2개 -> 유일한 해 (사과, 배 가격을 정확히 알 수 있다)

방정식이 1개뿐이면? -> 무한히 많은 답
방정식끼리 모순이면? -> 답 없음

## 5. Moore-Penrose 유사역행렬 ($A^+$)

### 핵심 아이디어

역행렬이 없어도 **"가능한 한 가까운 답"**을 구하는 도구.

### 세 가지 경우를 모두 처리

| 상황 | $A^+b$가 하는 일 |
|------|-----------------|
| 유일한 해 존재 | 그 해를 반환 ($A^+b = A^{-1}b$) |
| 해가 무한히 많음 | **노름이 가장 작은** 해를 반환 (최소노름해) |
| 해가 없음 | **오차가 가장 작은** 해를 반환 (최소제곱해) |

### SVD를 이용한 계산

$A = U\Sigma V^{\top}$ (SVD)이면:

$$A^+ = V\Sigma^+ U^{\top}$$

여기서 $\Sigma^+$는 0이 아닌 특이값의 역수를 취한 것.

### Moore-Penrose 4가지 조건

$A^+$는 다음을 **동시에** 만족하는 유일한 행렬:

1. $AA^+A = A$
2. $A^+AA^+ = A^+$
3. $(AA^+)^{\top} = AA^+$
4. $(A^+A)^{\top} = A^+A$

### 딥러닝에서 왜 중요한가?

- **선형 회귀**: $\theta = (X^{\top}X)^{-1}X^{\top}y = X^+y$
- **과매개변수 모델**: 딥러닝에서 파라미터가 데이터보다 많으면 해가 무한히 많다. SGD가 찾는 해가 최소노름해에 가까운지가 현대 연구의 핵심 질문

### 오해하기 쉬운 포인트

| 오해 | 실제 |
|------|------|
| $A^+A = I$ | 일반적으로 성립하지 않는다. $A$의 열이 선형독립일 때만 |
| 역행렬이 없으면 방정식을 못 푼다 | 유사역행렬로 "최선의 해"를 항상 구할 수 있다 |
| 최소제곱 해는 유일하다 | 영공간이 있으면 무한히 많다. $A^+b$는 그 중 노름이 가장 작은 것 |

## 6. 선형 사영 (Projection)과 최소제곱법

### 직관: 수선의 발

직선 위에서 점 P에 **가장 가까운 점** = 수선의 발 (직교 사영)

### 열공간으로의 사영

$b$를 $A$의 열공간으로 사영:

$$\text{Proj}(b; A) = AA^+b$$

### 최소제곱법과의 연결

$$x^* = \arg\min_x \|b - Ax\|^2$$

이 최소화 문제의 해: $x^* = A^+b$

**기하학적 의미**: $Ax^*$는 $A$의 열공간에서 $b$에 가장 가까운 점이다.

```
         b
        /|
       / |
      /  |  <-- 잔차 (b - Ax*), 열공간에 수직
     /   |
    /    |
   *-----+------> 열공간 im(A)
  Ax*
```

### 벡터 사영 공식

벡터 $a$로의 사영:

$$\text{Proj}(b; a) = a \cdot \frac{a^{\top}b}{\|a\|^2}$$

### 딥러닝에서 왜 중요한가?

- 선형 회귀의 해 = 열공간 사영의 직접적 결과
- Attention mechanism도 일종의 사영 연산
- Layer Normalization에서 평균을 빼는 것 = 상수 벡터 방향의 성분을 제거 (사영의 보수)

## 7. Power Method (거듭제곱법) 보충

### 핵심 알고리즘

```
입력: 행렬 A, 반복 횟수 T
u = 랜덤 단위 벡터

반복 T번:
    u = A * u
    u = u / ||u||  (정규화)

출력: 최대 고유값 ~ u^T * A * u, 최대 고유벡터 ~ u
```

### 수렴 속도

오차는 $\left(\frac{\lambda_2}{\lambda_1}\right)^t$에 비례하여 지수적으로 감소.

- $\lambda_1$과 $\lambda_2$의 차이(spectral gap)가 클수록 빠르게 수렴
- $\lambda_1 = \lambda_2$이면 수렴이 보장되지 않음

### PageRank 계산

PageRank 벡터 = 전이 행렬의 최대 고유값(=1)에 대응하는 고유벡터

Power Method로 구한다: $u_{t+1} = G \cdot u_t$ 반복

- Damping factor $\alpha = 0.85$: 모든 페이지에 약간의 기본 확률을 부여하여 수렴 보장

## 정리 / 요약

### 한 줄 요약

> 노름은 크기를 재는 자이고, trace는 대각합(=고유값의 합)이며, 유사역행렬은 정확한 답이 없을 때 최선의 답을 찾는 도구이다. 이 세 가지가 딥러닝의 손실 함수, 정규화, 최적화의 수학적 기초이다.

### 핵심 공식 정리

| 개념 | 공식 | 한 줄 설명 |
|------|------|-----------|
| Lp 노름 | $\|v\|_p = (\sum |v_i|^p)^{1/p}$ | 벡터의 크기 (p에 따라 다른 기준) |
| Frobenius 노름 | $\|A\|_F = \sqrt{\text{Tr}(A^{\top}A)}$ | 행렬 원소의 제곱합의 제곱근 |
| Spectral 노름 | $\|A\|_\sigma = \sigma_{\max}$ | 최대 특이값 |
| Trace | $\text{Tr}(A) = \sum \lambda_i$ | 대각합 = 고유값의 합 |
| 순환 성질 | $\text{Tr}(AB) = \text{Tr}(BA)$ | 곱 순서를 순환적으로 바꿀 수 있음 |
| 유사역행렬 | $A^+ = V\Sigma^+ U^{\top}$ | 최소노름 최소제곱 해 |
| 최소제곱 | $x^* = A^+b$ | 열공간으로의 직교 사영 |
| Rank-Nullity | $n = \text{rank}(A) + \text{nullity}(A)$ | 입력 차원 보존 |

### 오해하기 쉬운 포인트 모음

| 오해 | 실제 |
|------|------|
| L0 노름은 노름이다 | 삼각부등식을 만족하지 않아 수학적으로 노름이 아니다 |
| Spectral 노름 = 최대 고유값 | 최대 **특이값**이다. 일반 행렬에서 고유값과 특이값은 다르다 |
| $A^+A = I$ | 일반적으로 성립하지 않는다 |
| Power Method는 항상 수렴 | 초기 벡터가 최대 고유벡터와 직교하면 수렴 안 함 (확률 0이지만 이론적으로 가능) |
| $\text{Tr}(ABC) = \text{Tr}(CBA)$ | 순환 이동만 가능: $\text{Tr}(ABC) = \text{Tr}(BCA) = \text{Tr}(CAB)$ |
| 역행렬 없으면 못 푼다 | 유사역행렬 $A^+$로 항상 최선의 해를 구할 수 있다 |
