# 📏 크기 재기, 그림자 만들기, 연립방정식 풀기

## 간단한 소개

이번에는 세 가지를 배울 거예요:
1. 벡터나 행렬의 **크기(길이)**를 재는 방법
2. 여러 조건을 동시에 만족하는 답을 찾는 **연립방정식**
3. 높은 차원의 데이터를 낮은 차원으로 내리는 **사영(투영)**

모두 AI에서 매일 쓰이는 핵심 도구들이에요!

---

## 1. 노름 (Norm) — 벡터의 크기를 재는 방법

### 쉽게 말하면?

**노름**은 벡터가 "얼마나 큰지"를 숫자 하나로 표현하는 거예요.
쉽게 말해 **길이를 재는 자**예요!

### 일상 비유: 집에서 학교까지 거리 🏠→🏫

집에서 학교까지 가는데, "거리"를 재는 방법이 여러 가지 있어요.

```
집 위치: [0, 0]
학교 위치: [3, 4]
```

**방법 1: L2 노름 (직선 거리)**
```
새가 날아가는 직선 거리
= √(3² + 4²) = √(9+16) = √25 = 5

→ 가장 일반적인 "거리"
```

**방법 2: L1 노름 (맨해튼 거리)**
```
길을 따라 걸어가는 거리 (가로 + 세로)
= |3| + |4| = 7

→ 뉴욕 맨해튼의 바둑판 길처럼!
```

**방법 3: L∞ 노름 (가장 큰 값)**
```
가장 먼 방향의 거리만
= max(|3|, |4|) = 4
```

### 표로 비교

| 노름 | 계산 방법 | 비유 | 값 |
|------|----------|------|-----|
| L1 | 모든 값의 절대값 합 | 택시 거리 | 7 |
| L2 | 제곱합의 제곱근 | 직선 거리 | 5 |
| L∞ | 가장 큰 절대값 | 가장 먼 방향 | 4 |

### 왜 중요해?

AI에서 노름은 정말 많이 써요:

- **오차 측정**: AI의 예측이 정답에서 얼마나 벗어났는지
- **규제(정규화)**: AI가 너무 복잡해지지 않게 크기를 제한
- **유사도 계산**: 두 데이터가 얼마나 비슷한지

```
AI 예측: [2.1, 3.8, 5.2]
실제 정답: [2.0, 4.0, 5.0]
오차 벡터: [0.1, -0.2, 0.2]

오차의 L2 노름 = √(0.01 + 0.04 + 0.04) = √0.09 = 0.3
→ "이 AI의 오차는 0.3이다!"
```

## 2. 행렬 노름 — 행렬의 크기를 재는 방법

### 쉽게 말하면?

벡터에 길이가 있듯이, 행렬에도 "크기"가 있어요.

### 프로베니우스 노름 (가장 많이 쓰는 방법)

행렬의 모든 숫자를 제곱해서 더한 후 제곱근을 구해요.

```
A = [ 1  2 ]
    [ 3  4 ]

||A|| = √(1² + 2² + 3² + 4²) = √(1+4+9+16) = √30 ≈ 5.48
```

### 일상 비유

시험 성적표가 행렬이라면:

```
         국어  영어
철수  [  85    90 ]
영희  [  92    88 ]
```

행렬 노름 = 전체 성적의 "총 규모"를 하나의 숫자로 표현한 것

### 왜 중요해?

AI 학습 중에 행렬(가중치)이 너무 커지면 문제가 생겨요.
노름으로 크기를 감시하면서 적절한 범위를 유지하게 해요!

## 3. 대각합 (Trace) — 대각선 숫자를 더하기

### 쉽게 말하면?

정사각형 행렬에서 **대각선에 있는 숫자들을 다 더한 것**이에요.

```
A = [ 1  2  3 ]
    [ 4  5  6 ]
    [ 7  8  9 ]

대각합 = 1 + 5 + 9 = 15
(왼쪽 위에서 오른쪽 아래로 가는 대각선!)
```

### 일상 비유

성적표에서 **자기 자신의 점수**만 보는 거예요:

```
         1교시  2교시  3교시
1교시 [ *90*   75    80 ]
2교시 [  85  *88*   70 ]
3교시 [  92   78   *95* ]

대각합 = 90 + 88 + 95 = 273
```

### 왜 중요해?

대각합은 행렬의 **고유값의 합**과 같아요!
행렬의 전체적인 특성을 빠르게 파악할 수 있는 방법이에요.

## 4. 연립방정식 — 여러 조건을 동시에 만족하는 답 찾기

### 쉽게 말하면?

**여러 개의 조건**이 있을 때, **모든 조건을 동시에 만족하는 답**을 찾는 거예요.

### 일상 비유: 범인 찾기 🔍

목격자 증언:
- 목격자 1: "범인의 키 + 몸무게 = 230이었어요"
- 목격자 2: "범인의 키 - 몸무게 = 110이었어요"

```
키 + 몸무게 = 230  ... 조건 1
키 - 몸무게 = 110  ... 조건 2

두 식을 더하면: 2 × 키 = 340
키 = 170cm

키를 조건 1에 넣으면: 170 + 몸무게 = 230
몸무게 = 60kg

답: 키 170cm, 몸무게 60kg
```

### 행렬로 표현하면?

위의 문제를 행렬로 깔끔하게 쓸 수 있어요:

```
[ 1   1 ] [ 키     ]   [ 230 ]
[ 1  -1 ] [ 몸무게 ] = [ 110 ]

  행렬 A  ×  벡터 x   =  벡터 b

Ax = b 형태!
```

### 세 가지 경우

| 상황 | 결과 | 비유 |
|------|------|------|
| 딱 하나의 답 | 유일한 해 | 두 직선이 한 점에서 만남 |
| 답이 없음 | 해 없음 | 두 직선이 평행 (영원히 안 만남) |
| 답이 무한히 많음 | 무수히 많은 해 | 두 직선이 겹침 |

```
딱 하나의 답:          답 없음:           답이 무한:
    ╲╱                  ─────              ═════
    ╱╲                  ─────              (겹침!)
  한 점에서 만남        평행선
```

### 왜 중요해?

AI 학습은 사실 거대한 연립방정식을 푸는 거예요!
수천, 수만 개의 조건(데이터)을 동시에 만족하는 답(가중치)을 찾는 거죠.

## 5. 유사역행렬 (Pseudo-inverse) — 완벽한 답이 없을 때

### 쉽게 말하면?

연립방정식의 정확한 답이 없을 때, **가장 가까운 답**을 찾아주는 도구예요.

### 일상 비유: 모든 친구를 만족시킬 수 없을 때

```
철수: "치킨 먹자!"
영희: "피자 먹자!"
지민: "초밥 먹자!"

완벽한 답은 없지만...
→ 치킨+피자+초밥을 파는 뷔페! (가장 모두를 만족시키는 답)
```

수학적으로는 **오차를 최소화하는 답**을 찾아요.

```
모든 조건을 100% 만족 못 하더라도,
전체적으로 가장 적게 틀리는 답을 구해요!
```

### 왜 중요해?

현실 데이터는 완벽하지 않아요. 노이즈(잡음)도 있고, 모순되는 데이터도 있어요.
유사역행렬은 이런 **불완전한 상황에서 최선의 답**을 찾아줘요.
AI의 학습이 바로 이 원리예요!

## 6. 사영/투영 (Projection) — 그림자처럼 낮은 차원에 떨어뜨리기

### 쉽게 말하면?

높은 차원의 데이터를 **낮은 차원으로 떨어뜨리는 것**이에요.
마치 3D 물체의 **그림자**를 만드는 것처럼요!

### 일상 비유: 그림자 놀이 🌞

```
3D 입체 물체 (공)
      ↓ 빛을 비추면
2D 그림자 (원)

→ 3차원을 2차원으로 사영!
```

또 다른 예시:

```
지구 (3D 구) → 세계지도 (2D 평면)
→ 완벽하지는 않지만, 중요한 정보는 보존!
```

### 수학적 사영

벡터를 어떤 방향으로 "떨어뜨리는" 것:

```
원래 벡터: ↗ (대각선 방향)

가로 축에 사영하면: → (가로 성분만!)
세로 축에 사영하면: ↑ (세로 성분만!)
```

### 직교 사영 (가장 가까운 점 찾기)

```
          * ← 원래 점
          |
          | (수직으로 떨어뜨림)
          |
─────────●────────── 직선
          ↑
     사영된 점 (직선 위에서 가장 가까운 점!)
```

### 왜 중요해?

AI에서 사영은 엄청 중요해요:

| 활용 | 설명 |
|------|------|
| 차원 축소 | 1000차원 데이터 → 50차원으로 압축 |
| 노이즈 제거 | 중요한 방향에만 사영 → 잡음 사라짐 |
| 시각화 | 고차원 데이터를 2D/3D로 보여주기 |
| 최소제곱법 | 데이터에 가장 잘 맞는 직선 찾기 |

### 실생활 예시

```
학생 데이터 (10차원):
[키, 몸무게, 시력, 수학점수, 영어점수,
 국어점수, 운동능력, 음악점수, 미술점수, 출석률]

사영해서 2차원으로 줄이면:
[학업 능력, 신체 능력]

→ 10가지 정보를 2가지 핵심 정보로 요약!
```
