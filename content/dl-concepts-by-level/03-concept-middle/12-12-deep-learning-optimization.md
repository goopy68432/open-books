# 12. 딥러닝 최적화: AI를 훈련시키는 방법 🏋️

## 간단한 소개

신경망의 구조를 만들었다고 끝이 아니에요. 신경망이 문제를 잘 풀려면 **훈련(학습)**을 해야 해요. 마치 운동선수가 매일 훈련하면서 실력을 키우는 것처럼요.

이번 글에서는 AI가 어떻게 스스로 "아, 내가 틀렸구나. 이렇게 고쳐야겠다"를 반복하면서 점점 똑똑해지는지 알아볼 거예요.

---

## 1. 손실 함수: 얼마나 틀렸는지 점수 매기기

### 쉬운 설명

**손실 함수(Loss Function)**는 AI가 내놓은 답이 정답과 **얼마나 다른지** 숫자로 알려주는 채점표예요.

- 손실 값이 **크면** → 많이 틀림 😰
- 손실 값이 **작으면** → 거의 맞음 😊
- 손실 값이 **0이면** → 완벽! 🎉

### 일상 비유 🎯

양궁에서 과녁 맞추기를 생각해 봐요.

```
        ┌───────────┐
        │           │
        │  ┌─────┐  │
        │  │  ●  │  │  ← 정답 (과녁 중심)
        │  └─────┘  │
        │     ✖     │  ← AI의 예측
        └───────────┘
```

- **정답(과녁 중심)**과 **AI의 예측(화살이 꽂힌 곳)** 사이의 거리 = 손실
- 화살이 과녁 중심에서 멀수록 손실이 크고, 가까울수록 손실이 작아요

### 왜 중요한가요?

손실 함수가 없으면 AI는 자기가 잘하고 있는지 못하고 있는지 알 수 없어요. 시험 점수가 없으면 공부를 어떻게 고쳐야 할지 모르는 것과 같아요!

---

## 2. 경사 하강법: 안개 낀 산에서 내려오기

### 쉬운 설명

손실을 줄이는 것이 목표라면, **어떻게** 줄일까요? 바로 **경사 하강법(Gradient Descent)**을 써요!

### 일상 비유 🌫️

여러분이 안개가 자욱한 산꼭대기에 있다고 상상해 봐요. 아무것도 안 보이는데, 가장 낮은 곳(골짜기)으로 내려가야 해요.

**방법**: 발밑을 더듬어서, **가장 가파르게 내려가는 방향**으로 한 발짝씩 이동!

```
산꼭대기 (손실 큼)
   ↘
     ↘
       ↘  ← 기울기(경사)를 따라 내려감
         ↘
           ⭐ 골짜기 (손실 작음)
```

- **산의 높이** = 손실 값
- **경사(기울기)** = 손실이 줄어드는 방향
- **한 발짝** = 가중치를 조금씩 수정

매 발짝마다 경사를 확인하고, 내리막 방향으로 이동하면 결국 가장 낮은 곳에 도착해요!

### 왜 중요한가요?

경사 하강법은 거의 모든 AI 학습의 기본이에요. 이 방법이 없으면 AI는 어떤 방향으로 자신을 고쳐야 할지 알 수 없어요.

---

## 3. SGD: 전체 대신 일부만 보고 빨리 내려가기

### 쉬운 설명

**SGD(확률적 경사 하강법)**는 데이터 전체를 다 보지 않고, **일부만 랜덤으로 골라서** 방향을 정하는 방법이에요.

### 일상 비유 🍱

학교 급식이 맛있는지 알고 싶어요.

- **일반 경사 하강법**: 전교생 1,000명 전부에게 물어봄 → 정확하지만 시간 오래 걸림
- **SGD**: 복도에서 만난 30명에게만 물어봄 → 대략 맞고, 엄청 빠름!

```
일반 방법: 🧑🧑🧑🧑🧑🧑🧑🧑🧑🧑... (1000명 다 물어봄)
           → 정확한 방향, 하지만 느림

SGD:       🧑🧑🧑 (30명만 물어봄)
           → 대략적 방향, 하지만 빠름!
```

30명의 의견이 항상 정확하진 않지만, 여러 번 반복하면 결국 맞는 방향으로 가게 돼요.

### 왜 중요한가요?

실제 AI 학습에서는 데이터가 수백만 개예요. 매번 전부 보면 너무 느리니까, SGD로 빠르게 학습하는 것이 현실적이에요.

---

## 4. 모멘텀: 관성을 이용해 더 빨리!

### 쉬운 설명

**모멘텀(Momentum)**은 경사 하강법에 **관성**을 추가한 거예요. 이전에 움직인 방향의 힘을 기억해서, 같은 방향이면 더 빠르게 가요.

### 일상 비유 ⛷️

스키를 타고 내려온다고 생각해 봐요.

- **모멘텀 없이**: 매 순간 멈추고, 주위를 살피고, 다시 출발 → 느림
- **모멘텀 있게**: 쭉 미끄러지면서 방향만 살짝 조절 → 빠름!

```
모멘텀 없이:  →  멈춤  →  멈춤  →  멈춤  → ⭐
모멘텀 있게:  →→→→→→→→→→→→→→→→→ ⭐ (훨씬 빠름!)
```

특히 평평한 구간에서 큰 차이가 나요. 관성이 없으면 평평한 곳에서 멈춰버리지만, 관성이 있으면 이전 속도로 계속 진행할 수 있거든요.

### 왜 중요한가요?

모멘텀 덕분에 학습이 훨씬 빨라지고, 작은 울퉁불퉁한 곳에서 멈추는 것도 방지해요.

---

## 5. Adam: 자동으로 걸음 크기 조절

### 쉬운 설명

**Adam**은 현재 가장 많이 쓰이는 최적화 방법이에요. 모멘텀도 쓰고, 추가로 **방향마다 걸음 크기를 자동으로 조절**해요.

### 일상 비유 🚗

네비게이션이 달린 자동차를 생각해 봐요.

| 상황 | Adam의 대응 |
|------|------------|
| 넓고 쭉 뻗은 고속도로 | 속도 올리기! (큰 걸음) |
| 좁고 구불구불한 골목 | 속도 줄이기! (작은 걸음) |
| 오르막 → 내리막 반복 | 관성으로 넘어가기! |
| 처음 보는 길 | 조심스럽게 시작 |

일반 SGD가 자전거라면, Adam은 똑똑한 네비가 달린 자동차예요.

### 왜 중요한가요?

Adam은 대부분의 경우 "그냥 쓰면 잘 동작하는" 방법이에요. 딥러닝 초보자도 Adam을 쓰면 꽤 좋은 결과를 얻을 수 있어요.

---

## 6. 역전파: 오류를 거꾸로 추적하기

### 쉬운 설명

**역전파(Backpropagation)**는 신경망이 틀렸을 때, **어디서 얼마나 틀렸는지** 뒤에서 앞으로 거슬러 올라가며 추적하는 방법이에요.

### 일상 비유 🏭

쿠키 공장에서 맛없는 쿠키가 나왔어요. 원인을 찾으려면?

```
[재료 준비] → [반죽 만들기] → [오븐 굽기] → [포장] → 맛없는 쿠키 😫
     ↑              ↑             ↑           ↑
     ④              ③             ②           ①

순서: 결과(맛없음)부터 거꾸로 추적!
① 포장이 잘못됐나? → 아니네
② 오븐 온도가 잘못됐나? → 좀 높았음! (여기 수정!)
③ 반죽이 잘못됐나? → 설탕이 적었음! (여기도 수정!)
④ 재료가 잘못됐나? → 괜찮았음
```

이렇게 결과에서부터 거꾸로 각 단계의 책임을 따져서, 잘못된 부분을 고치는 거예요.

### 신경망에서의 역전파

```
입력층 → 은닉층1 → 은닉층2 → 출력층 → 오차 발생!
  ④        ③         ②        ①
  ←────── 거꾸로 오차 전파 ──────←

각 층의 가중치를 "오차에 대한 책임"만큼 수정
```

### 왜 중요한가요?

역전파가 없으면 신경망의 수천~수억 개의 가중치를 어떻게 수정해야 할지 알 수 없어요. 역전파 덕분에 딥러닝이 실용적으로 가능해진 거예요!

---

## 7. 학습률: 한 걸음의 크기

### 쉬운 설명

**학습률(Learning Rate)**은 경사 하강법에서 **한 번에 얼마나 움직일지** 정하는 값이에요.

### 일상 비유 👟

산에서 내려올 때 걸음 크기를 생각해 봐요.

| 학습률 | 비유 | 결과 |
|--------|------|------|
| 너무 큼 | 10미터씩 점프 | 골짜기를 지나쳐서 반대편 산으로! |
| 적당함 | 1미터씩 걷기 | 안정적으로 골짜기 도착! |
| 너무 작음 | 1cm씩 기어감 | 도착은 하겠지만 100년 걸림... |

```
너무 큰 학습률:      적당한 학습률:        너무 작은 학습률:
  ↗️        ↖️           ↘                    ↘
↗️   골짜기   ↖️          ↘                   ↘ (너무 느림)
  (지나침!)              ⭐ (도착!)            ↘
                                               ↘...
```

### 학습률 스케줄링

똑똑한 방법: 처음에는 크게, 나중에는 작게!

- 처음: 큰 걸음으로 대략적인 방향 잡기
- 중간: 보통 걸음으로 접근
- 마지막: 작은 걸음으로 정확히 도착

이것을 **학습률 스케줄링**이라고 해요.

### 왜 중요한가요?

학습률은 AI 훈련에서 가장 중요한 설정값 중 하나예요. 이 값 하나만 잘못 정해도 AI가 전혀 학습을 못 할 수 있어요!

---

## 전체 학습 과정 정리

AI가 배우는 전체 과정을 한눈에 볼게요.

```
1. 데이터를 입력
       ↓
2. 신경망이 예측 (처음에는 엉터리)
       ↓
3. 손실 함수로 "얼마나 틀렸는지" 계산
       ↓
4. 역전파로 "각 가중치의 책임" 계산
       ↓
5. 경사 하강법(SGD/모멘텀/Adam)으로 가중치 수정
       ↓
6. 1번으로 돌아가서 반복!
       ↓
   ... 수천~수만 번 반복 ...
       ↓
7. 드디어 손실이 충분히 작아짐 = 학습 완료! 🎉
```

---

## 정리/요약 📝

| 개념 | 한 줄 요약 |
|------|-----------|
| 손실 함수 | AI가 얼마나 틀렸는지 점수 매기는 채점표 |
| 경사 하강법 | 안개 낀 산에서 기울기를 따라 내려가기 |
| SGD | 데이터 일부만 보고 빠르게 방향 정하기 |
| 모멘텀 | 관성을 이용해 빠르고 안정적으로 이동 |
| Adam | 방향마다 걸음 크기를 자동 조절하는 똑똑한 방법 |
| 역전파 | 오류를 거꾸로 추적해서 각 부분의 책임 찾기 |
| 학습률 | 한 걸음의 크기 (너무 크면 지나침, 너무 작으면 느림) |

### 핵심 한 마디

> AI 학습 = "틀린 정도를 계산하고, 덜 틀리는 방향으로 조금씩 고치기"를 수만 번 반복하는 것!

다음 글에서는 AI가 연습문제만 잘 푸는 게 아니라, **처음 보는 문제도 잘 푸는 방법**(일반화)에 대해 알아볼 거예요! 📚
