# 14. CNN: AI가 이미지를 이해하는 방법 📷

## 간단한 소개

우리는 사진을 보면 "이건 고양이다", "저건 자동차다"를 바로 알 수 있어요. 하지만 컴퓨터에게 사진은 그냥 **숫자의 나열**일 뿐이에요. 그렇다면 AI는 어떻게 사진 속 내용을 이해할 수 있을까요?

그 비밀은 바로 **CNN(합성곱 신경망, Convolutional Neural Network)**에 있어요. CNN은 마치 돋보기로 그림의 부분부분을 살펴보면서 패턴을 찾아내는 신경망이에요.

---

## 1. 컴퓨터가 보는 이미지

### 이미지 = 숫자표

우리 눈에는 예쁜 사진이지만, 컴퓨터에게는 이렇게 보여요.

```
고양이 사진 (아주 작게 축소하면):

  120  130  140  150
  110  200  210  160
  100  190  220  170
  105  125  145  155

각 숫자 = 그 칸의 밝기 (0=검정, 255=흰색)
```

컬러 사진이면 빨강, 초록, 파랑 세 장의 숫자표가 겹쳐져 있어요.

만약 이 숫자표를 그냥 일반 신경망(MLP)에 넣으면 어떨까요? 픽셀 하나하나를 따로따로 보기 때문에 **"이 근처에 이런 무늬가 있다"**는 정보를 놓치게 돼요. 그래서 CNN이 필요해요!

---

## 2. 합성곱: 작은 돋보기로 무늬 찾기

### 쉬운 설명

**합성곱(Convolution)**은 작은 **필터(돋보기)**를 이미지 위에서 이리저리 움직이면서, **특정 무늬가 있는지** 확인하는 과정이에요.

### 일상 비유 🔍

퍼즐을 맞출 때를 생각해 봐요. 큰 그림을 한 번에 보는 게 아니라, 작은 부분씩 살펴보잖아요?

```
원본 이미지 (6×6):              필터 (3×3):
┌─┬─┬─┬─┬─┬─┐               ┌─┬─┬─┐
│ │ │ │ │ │ │               │ │█│ │ ← "세로선"을
├─┼─┼─┼─┼─┼─┤               ├─┼─┼─┤    찾는 필터
│ │ │ │ │ │ │               │ │█│ │
├─┼─┼─┼─┼─┼─┤               ├─┼─┼─┤
│ │ │ │ │ │ │               │ │█│ │
├─┼─┼─┼─┼─┼─┤               └─┴─┴─┘
│ │ │ │ │ │ │
├─┼─┼─┼─┼─┼─┤     이 필터를 이미지 위에서
│ │ │ │ │ │ │     슬라이드하면서 확인!
├─┼─┼─┼─┼─┼─┤
│ │ │ │ │ │ │
└─┴─┴─┴─┴─┴─┘
```

필터가 이미지 위를 움직이면서 "여기에 세로선이 있나?", "저기에 세로선이 있나?" 확인해요. 세로선이 있는 곳에서는 높은 값이, 없는 곳에서는 낮은 값이 나와요.

### 여러 종류의 필터

```
가로선 필터:     세로선 필터:     대각선 필터:
┌─┬─┬─┐        ┌─┬─┬─┐        ┌─┬─┬─┐
│ │ │ │        │ │█│ │        │█│ │ │
├─┼─┼─┤        ├─┼─┼─┤        ├─┼─┼─┤
│█│█│█│        │ │█│ │        │ │█│ │
├─┼─┼─┤        ├─┼─┼─┤        ├─┼─┼─┤
│ │ │ │        │ │█│ │        │ │ │█│
└─┴─┴─┘        └─┴─┴─┘        └─┴─┴─┘
```

CNN은 이런 필터를 **수십~수백 개** 가지고 있어요. 그리고 학습하면서 **어떤 무늬를 찾을지 스스로 배워요!**

### 왜 중요한가요?

합성곱 덕분에 CNN은 이미지의 **지역적 패턴**(선, 모서리, 질감 등)을 효과적으로 찾을 수 있어요. 이것이 CNN이 이미지를 잘 이해하는 핵심 비결이에요.

---

## 3. 풀링: 중요한 것만 남기고 줄이기

### 쉬운 설명

**풀링(Pooling)**은 합성곱으로 찾은 정보를 **압축**하는 과정이에요. 중요한 정보는 유지하면서 크기를 줄여요.

### 일상 비유 📝

긴 책을 읽고 요약문을 쓰는 것과 비슷해요.

- 원본 책: 300페이지
- 요약문: 30페이지
- 핵심 내용은 다 들어있지만, 크기는 1/10!

### 맥스 풀링 예시

가장 많이 쓰는 **맥스 풀링(Max Pooling)**은 작은 영역에서 **가장 큰 값만** 남겨요.

```
합성곱 결과 (4×4):           맥스 풀링 후 (2×2):
┌───┬───┬───┬───┐          ┌───┬───┐
│ 1 │ 3 │ 2 │ 1 │          │   │   │
├───┼───┤───┼───┤    →     │ 5 │ 7 │
│ 5 │ 2 │ 7 │ 4 │          │   │   │
├───┼───┼───┼───┤          ├───┼───┤
│ 3 │ 8 │ 1 │ 0 │          │   │   │
├───┼───┤───┼───┤    →     │ 8 │ 6 │
│ 2 │ 1 │ 6 │ 3 │          │   │   │
└───┴───┴───┴───┘          └───┴───┘

2×2 영역에서 가장 큰 값만 뽑아!
```

### 왜 중요한가요?

풀링의 장점:
1. **크기를 줄여서** 계산을 빠르게!
2. **위치가 조금 바뀌어도 괜찮음** — 고양이 귀가 왼쪽이든 오른쪽이든 찾을 수 있어요

---

## 4. 특징 맵: 무늬 위치 지도

### 쉬운 설명

**특징 맵(Feature Map)**은 필터가 이미지를 스캔한 결과예요. "이미지의 어디에 어떤 무늬가 있는지" 표시한 지도라고 생각하면 돼요.

### 일상 비유 🗺️

보물찾기 지도를 생각해 봐요.

```
"세로선 지도":          "동그라미 지도":        "대각선 지도":
┌─────────┐           ┌─────────┐           ┌─────────┐
│    ★    │           │         │           │★        │
│    ★    │           │  ★  ★   │           │  ★      │
│    ★    │           │  ★  ★   │           │    ★    │
│         │           │         │           │      ★  │
└─────────┘           └─────────┘           └─────────┘
"여기에 세로선!"       "여기에 동그라미!"      "여기에 대각선!"
```

CNN에는 필터가 여러 개 있으니까, 특징 맵도 여러 장이 나와요. 각 특징 맵은 서로 다른 무늬를 보여줘요.

---

## 5. CNN의 전체 구조

### 기본 흐름

CNN은 **합성곱 → 활성화 → 풀링**을 여러 번 반복하는 구조예요.

```
이미지 입력
    ↓
[합성곱 + ReLU]  → 특징 맵 (선, 모서리 등 단순한 무늬)
    ↓
[풀링]           → 크기 줄이기
    ↓
[합성곱 + ReLU]  → 특징 맵 (눈, 코 등 복잡한 무늬)
    ↓
[풀링]           → 크기 더 줄이기
    ↓
[합성곱 + ReLU]  → 특징 맵 (얼굴 전체 등 더 복잡한 무늬)
    ↓
[풀링]           → 크기 더 줄이기
    ↓
[완전 연결층]     → 최종 판단
    ↓
결과: "고양이!" 🐱
```

### 층이 깊어질수록 복잡한 것을 봄

이것이 CNN의 아주 신기한 점이에요!

```
1번째 층: 선, 모서리 (단순)
    ↓
2번째 층: 눈, 코, 귀 (중간)
    ↓
3번째 층: 얼굴 전체 (복잡)
    ↓
최종: "이건 고양이다!"
```

마치 우리 뇌가 사물을 인식하는 과정과 비슷해요!

## 6. 유명한 CNN 모델들

### AlexNet (2012) 🏆

**AI 역사를 바꾼 모델!**

2012년, 이미지 인식 대회에서 AlexNet이 다른 방법들을 압도적으로 이겼어요. 이때부터 딥러닝이 본격적으로 유명해졌어요.

| 특징 | 설명 |
|------|------|
| 층 수 | 8개 (당시로서는 깊음) |
| 활성화 함수 | ReLU 사용 (빠른 학습) |
| 기법 | 드롭아웃으로 과적합 방지 |
| 의미 | "딥러닝이 진짜 된다!"는 것을 증명 |

### ResNet (2015) 🏗️

**잔차 연결(Residual Connection)의 발명!**

층을 더 쌓으면 좋을 줄 알았는데, 어느 순간부터 성능이 오히려 떨어졌어요. ResNet은 이 문제를 **지름길(Skip Connection)**로 해결했어요.

```
일반 신경망:
입력 → [층1] → [층2] → [층3] → 출력

ResNet:
입력 → [층1] → [층2] → [층3] → (+) → 출력
  │                               ↑
  └──── 지름길 (입력을 바로 전달) ──┘
```

**비유**: 전화 돌리기 게임에서, 첫 번째 사람의 말이 중간에 왜곡될 수 있잖아요? 그래서 첫 번째 사람이 **마지막 사람에게 직접** 귓속말도 해주는 거예요!

| 모델 | 층 수 | 핵심 아이디어 |
|------|-------|-------------|
| AlexNet | 8 | 딥러닝이 된다! |
| VGGNet | 19 | 작은 필터를 많이 쌓기 |
| ResNet | 152 | 지름길로 깊게 쌓기 |

## 7. 이미지 AI의 세 가지 과제

CNN으로 할 수 있는 일은 크게 세 가지예요.

### 이미지 분류 (Classification) 🏷️

"이 사진에 뭐가 있어?"

```
┌──────────┐
│  🐱      │  → "고양이!"
│          │
└──────────┘
```
사진 전체를 보고 **하나의 라벨**을 붙여요.

### 물체 검출 (Object Detection) 📦

"어디에 뭐가 있어?"

```
┌──────────┐
│ ┌──┐     │  → "고양이: 왼쪽 위"
│ │🐱│ ┌─┐ │  → "강아지: 오른쪽"
│ └──┘ │🐕│ │
│      └─┘ │
└──────────┘
```
사진에서 물체의 **위치(네모 상자)**와 **종류**를 알려줘요.

### 이미지 분할 (Segmentation) ✂️

"어디까지가 뭐야?"

```
┌──────────┐
│▓▓▓░░░░░░│  ▓ = 고양이 영역
│▓▓▓▓░░▒▒░│  ▒ = 강아지 영역
│▓▓▓░░▒▒▒░│  ░ = 배경
│░░░░░▒▒░░│
└──────────┘
```
사진의 **모든 픽셀**이 어떤 물체에 속하는지 색칠해요.

### 난이도 비교

```
분류 (쉬움) → 검출 (중간) → 분할 (어려움)
"뭐가 있어?"  "어디에 있어?"  "정확히 어디까지?"
```

---

## 왜 CNN이 이미지에 강한가요?

일반 신경망(MLP)과 비교해 볼게요.

| | MLP | CNN |
|---|-----|-----|
| 보는 방식 | 픽셀 하나하나 따로 | 근처 픽셀들을 함께 |
| 비유 | 글자 하나하나 따로 읽기 | 문장 단위로 읽기 |
| 위치 변화 | 고양이가 이동하면 다시 배워야 함 | 어디에 있든 같은 필터로 찾음 |
| 효율성 | 연결이 너무 많음 | 필터를 공유해서 효율적 |

CNN의 핵심 장점:
1. **지역적 패턴**을 잘 찾음 (합성곱)
2. **위치가 바뀌어도** 인식 가능 (필터 공유)
3. **점점 복잡한 패턴**을 쌓아감 (깊은 구조)

## 정리/요약 📝

| 개념 | 한 줄 요약 |
|------|-----------|
| 합성곱 | 작은 필터(돋보기)로 이미지에서 무늬 찾기 |
| 풀링 | 중요한 정보만 남기고 크기 줄이기 |
| 특징 맵 | 어디에 어떤 무늬가 있는지 표시한 지도 |
| CNN 구조 | 합성곱 → 활성화 → 풀링 반복 |
| AlexNet | 딥러닝 시대를 연 역사적 모델 (2012) |
| ResNet | 지름길로 아주 깊은 신경망 가능 (2015) |
| 분류/검출/분할 | 뭐가 있어? / 어디에 있어? / 어디까지가 뭐야? |

### 핵심 한 마디

> CNN은 작은 돋보기(필터)로 그림의 부분부분을 살피고, 단순한 무늬에서 점점 복잡한 무늬를 쌓아가면서 이미지를 이해해요!
