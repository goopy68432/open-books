# 🎒 수학의 기본 도구들: 집합, 함수, 벡터, 행렬

## 간단한 소개

수학에는 여러 가지 "도구"가 있어요. 마치 공구함에 망치, 드라이버, 렌치가 있는 것처럼요.
딥러닝(인공지능)을 이해하려면 먼저 이 도구들이 뭔지 알아야 해요.

걱정 마세요! 하나하나 쉽게 설명해 드릴게요. 😊

---

## 1. 집합 (Set) — 같은 종류끼리 모아놓은 것

### 쉽게 말하면?

**집합**은 그냥 "모음"이에요.

- 우리 반 학생들의 모임 → 집합
- 1부터 10까지의 숫자 모임 → 집합
- 내가 좋아하는 과일 모임 → 집합

### 일상 비유

학교 사물함을 생각해 보세요.

| 사물함 이름 | 안에 들어있는 것 |
|-------------|------------------|
| 1반 학생 사물함 | 김철수, 이영희, 박지민... |
| 과일 바구니 | 사과, 바나나, 딸기 |
| 짝수 모음 | 2, 4, 6, 8, 10... |

사물함 = 집합, 안에 들어있는 것 = **원소(element)**라고 불러요.

### 왜 중요해?

AI가 데이터를 다룰 때, "이 데이터가 어떤 그룹에 속하는지"를 구분해야 해요.
예를 들어 사진을 보고 "이건 고양이 그룹", "이건 강아지 그룹"으로 나누는 거죠.
이때 **집합**의 개념이 기본이 됩니다.

---

## 2. 함수 (Function) — 입력을 넣으면 출력이 나오는 기계

### 쉽게 말하면?

자판기를 생각해 보세요!

```
[500원 동전] → 🎰 자판기 → [콜라]
[1000원 지폐] → 🎰 자판기 → [주스]
```

**입력**을 넣으면 정해진 **출력**이 나와요. 이게 바로 함수예요!

### 수학에서는?

```
입력 3 → f(x) = x + 2 → 출력 5
입력 7 → f(x) = x + 2 → 출력 9
```

f(x) = x + 2 라는 함수는 "넣은 숫자에 2를 더해주는 기계"예요.

### 일상 비유

| 기계(함수) | 입력 | 출력 |
|-----------|------|------|
| 토스터기 | 식빵 | 토스트 |
| 계산기(×2) | 5 | 10 |
| 번역기 | "안녕" | "Hello" |

### 왜 중요해?

AI도 하나의 거대한 함수예요!
- 입력: 고양이 사진
- AI 함수 작동 중...
- 출력: "이것은 고양이입니다!"

---

## 3. 스칼라 (Scalar) — 그냥 숫자 하나

### 쉽게 말하면?

**스칼라**는 그냥 숫자 하나예요. 끝!

- 키: 165cm → 스칼라
- 시험 점수: 85점 → 스칼라
- 온도: 25도 → 스칼라

크기만 있고, 방향은 없어요.

---

## 4. 벡터 (Vector) — 숫자 여러 개의 묶음

### 쉽게 말하면?

**벡터**는 숫자를 여러 개 묶어놓은 거예요. 방향과 크기를 동시에 나타낼 수 있어요.

### 일상 비유

내비게이션을 생각해 보세요.

- "100m" → 이건 스칼라 (거리만 알려줌)
- "동쪽으로 100m" → 이건 벡터 (방향 + 거리)

더 쉬운 예시:

```
내 정보 벡터 = [키, 몸무게, 나이]
              = [165, 55, 14]
```

이렇게 여러 숫자를 하나로 묶은 것이 벡터예요!

### 왜 중요해?

AI는 모든 것을 숫자 묶음(벡터)으로 바꿔서 이해해요.

| 원래 데이터 | 벡터로 변환 |
|------------|------------|
| 사진 한 장 | 수만 개의 숫자 묶음 (픽셀값) |
| "나는 학생이다" | 수백 개의 숫자 묶음 |
| 음악 1초 | 수천 개의 숫자 묶음 |

---

## 5. 행렬 (Matrix) — 숫자를 표로 정리한 것

### 쉽게 말하면?

**행렬**은 숫자를 직사각형 모양의 표로 정리한 거예요.
엑셀 표를 떠올리면 됩니다!

### 예시

중간고사 성적표:

```
         국어  영어  수학
철수  [  85    90    78  ]
영희  [  92    88    95  ]
지민  [  76    82    89  ]
```

이게 바로 3×3 행렬이에요! (3행 × 3열)

### 일상 비유

- 행(row) = 가로줄 (한 사람의 전과목 성적)
- 열(column) = 세로줄 (한 과목의 모든 학생 성적)

### 왜 중요해?

AI가 처리하는 데이터 대부분이 행렬로 표현돼요.
흑백 사진 한 장도 사실은 숫자로 된 행렬이에요!

```
사진의 밝기값:
[ 200  150  100 ]
[ 180  120   80 ]    ← 각 숫자는 그 위치의 밝기
[ 160  100   60 ]
```

## 6. 텐서 (Tensor) — 행렬을 더 확장한 것

### 쉽게 말하면?

| 이름 | 차원 | 비유 |
|------|------|------|
| 스칼라 | 0차원 | 점 하나 |
| 벡터 | 1차원 | 줄(선) |
| 행렬 | 2차원 | 표(면) |
| **텐서** | **3차원 이상** | **상자(입체)** |

### 일상 비유

- **스칼라**: 사물함 하나에 숫자 하나
- **벡터**: 사물함 한 줄
- **행렬**: 사물함 한 면 (벽 하나)
- **텐서**: 사물함 여러 면이 겹쳐진 것 (건물 전체!)

### 실제 예시

컬러 사진은 3차원 텐서예요:

```
가로 × 세로 × 색상(빨강, 초록, 파랑)
 100  ×  100  ×  3

→ 총 30,000개의 숫자!
```

### 왜 중요해?

딥러닝 프레임워크(PyTorch, TensorFlow)는 이름에 "Tensor"가 들어가요.
AI의 모든 계산이 텐서 단위로 이루어지기 때문이에요!

## 7. 선형변환 (Linear Transformation) — 직선을 직선으로 바꾸는 변환

### 쉽게 말하면?

모눈종이 위에 그림을 그렸다고 생각해 보세요.
**선형변환**은 그 모눈종이를 늘이거나, 회전하거나, 뒤집는 것이에요.

중요한 규칙:
- 직선은 변환 후에도 여전히 직선 ✅
- 원점(0,0)은 그대로 ✅
- 곡선으로 변하면 안 됨 ❌

### 일상 비유

```
원래 모눈종이        →      늘린 후
┌──┬──┐                ┌────┬────┐
│  │  │                │    │    │
├──┼──┤        →       │    │    │
│  │  │                ├────┼────┤
└──┴──┘                │    │    │
                       └────┴────┘
```

가로로 2배 늘렸지만, 직선은 여전히 직선이죠? 이게 선형변환!

### 왜 중요해?

AI의 핵심인 **신경망(Neural Network)**의 각 층이 하는 일이 바로 선형변환이에요.
데이터를 변환하고 또 변환해서 원하는 답을 찾아가는 거죠.

## 8. 그리스 문자 — 수학의 약속된 기호들

수학이나 과학 글을 보면 이상한 기호가 나오죠? 대부분 **그리스 문자**예요.
외울 필요는 없고, 자주 나오는 것만 알아두면 돼요!

| 기호 | 이름 | 어디서 쓰이나 |
|------|------|--------------|
| α (알파) | alpha | 학습률 (AI가 배우는 속도) |
| β (베타) | beta | 가중치 조절 |
| γ (감마) | gamma | 감쇠율 |
| δ (델타) | delta | 작은 변화량 |
| ε (엡실론) | epsilon | 아주 작은 수 |
| θ (세타) | theta | AI의 파라미터 (설정값) |
| λ (람다) | lambda | 조절 계수 |
| σ (시그마) | sigma | 표준편차, 시그모이드 함수 |
| Σ (대문자 시그마) | Sigma | 합계 (다 더하기!) |
| π (파이) | pi | 원주율 3.14... |

### 왜 중요해?

AI 논문이나 설명을 읽을 때, 이 기호들이 뭔지 알면
"아, 이건 학습 속도를 말하는 거구나!" 하고 이해할 수 있어요.

> 함수(변환)를 반복 적용해서 원하는 답을 찾아가는 거예요!
