# 🔍 고유값, SVD, 그리고 구글의 비밀

## 간단한 소개

이번에는 조금 신기한 이야기를 할 거예요.
행렬(변환)을 했는데 **방향이 안 바뀌는 특별한 벡터**가 있대요!
그리고 이 개념이 **구글 검색 엔진**의 핵심 원리라니, 흥미롭지 않나요?

어렵게 느껴질 수 있지만, 비유를 통해 쉽게 이해해 봐요! 😊

---

## 1. 역행렬 (Inverse Matrix) — 변환을 되돌리는 것

### 쉽게 말하면?

**역행렬**은 "되돌리기(Ctrl+Z)"예요!

```
원래 데이터  →  [변환 A]  →  변환된 데이터
변환된 데이터  →  [역행렬 A⁻¹]  →  원래 데이터!
```

### 일상 비유

| 행동 | 되돌리기 |
|------|---------|
| 암호화 | 복호화 |
| 한→영 번역 | 영→한 번역 |
| 사진 확대 2배 | 사진 축소 1/2배 |
| 오른쪽으로 90° 회전 | 왼쪽으로 90° 회전 |

### 되돌릴 수 없는 경우도 있어요!

```
원래 데이터: [1, 2, 3, 4, 5]
    ↓ 평균 구하기 변환
결과: [3]

역변환: [3] → [?, ?, ?, ?, ?]  ← 원래 뭐였는지 모름!
```

평균만 알면 원래 숫자들을 복원할 수 없죠?
이런 경우를 "역행렬이 존재하지 않는다"고 해요.

### 왜 중요해?

AI에서 어떤 변환이 되돌릴 수 있는지 아는 것이 중요해요.
되돌릴 수 없다면 정보가 손실된 거니까요!

---

## 2. 고유값과 고유벡터 — 변환해도 방향이 안 바뀌는 특별한 벡터

### 쉽게 말하면?

어떤 변환(행렬)을 적용했을 때,
**방향은 그대로이고 크기만 변하는 벡터**를 **고유벡터**라고 해요.
그때 크기가 변하는 비율을 **고유값**이라고 해요.

```
변환(고유벡터) = 고유값 × 고유벡터
```

### 일상 비유: 태풍과 나무 🌳

태풍이 불 때를 상상해 보세요:
- 대부분의 나뭇잎: 이리저리 날아감 (방향 바뀜)
- **특별한 나뭇잎**: 바람 방향으로만 날아감 (방향 안 바뀜!)

이 "특별한 나뭇잎"이 고유벡터예요.
바람의 세기(얼마나 멀리 날아가는지)가 고유값이에요.

### 또 다른 비유: 고무판 늘이기

정사각형 고무판을 잡아당긴다고 생각해 봐요.

```
원래 정사각형:        늘인 후:
  ↑ ↗                ↑    ↗
  │╱                 │  ╱
  └───→              └──────→

- 가로 방향(→): 방향 안 바뀜! 길이만 2배 → 고유벡터, 고유값 = 2
- 세로 방향(↑): 방향 안 바뀜! 길이 그대로 → 고유벡터, 고유값 = 1
- 대각선(↗): 방향이 바뀜 → 고유벡터 아님!
```

### 왜 중요해?

고유벡터는 변환의 **핵심 방향**을 알려줘요.
AI에서 데이터의 가장 중요한 패턴을 찾을 때 사용해요!

## 3. 고유값 분해 (Eigendecomposition) — 변환을 쪼개기

### 쉽게 말하면?

복잡한 변환을 **단순한 늘이기/줄이기의 조합**으로 분해하는 거예요.

### 일상 비유: 음식 레시피 분석

복잡한 요리를 먹고 맛을 분석한다고 해봐요:

```
불고기 맛 = 달콤한 맛(강도 5) + 짠 맛(강도 3) + 감칠맛(강도 4)

여기서:
- 달콤함, 짠맛, 감칠맛 = 고유벡터 (기본 맛의 방향)
- 5, 3, 4 = 고유값 (각 맛의 강도)
```

복잡한 맛을 기본 맛으로 분해한 거예요!
마찬가지로 복잡한 변환도 기본 변환으로 분해할 수 있어요.

### 왜 중요해?

복잡한 것을 단순한 것들의 조합으로 이해하면,
어떤 부분이 중요하고 어떤 부분을 무시해도 되는지 알 수 있어요!

---

## 4. SVD (특이값 분해) — 어떤 변환이든 분해하는 만능 도구

### 쉽게 말하면?

**어떤 행렬이든** 세 단계로 분해할 수 있어요:

```
원래 변환 = 회전 → 늘이기 → 다시 회전
```

고유값 분해는 정사각형 행렬에만 쓸 수 있지만,
SVD는 **모든 행렬**에 사용할 수 있는 만능 도구예요!

### 일상 비유: 포토샵 변환

사진을 편집한다고 생각해 보세요:

```
복잡한 변환 한 번에?    →    3단계로 나누면 이해하기 쉬워요!

원본 사진 → [복잡한 변형] → 결과

이것을 분해하면:

원본 사진 → [회전] → [가로세로 늘이기] → [다시 회전] → 결과
            (U)        (Σ/시그마)          (Vᵀ)
```

| 단계 | 이름 | 하는 일 |
|------|------|--------|
| 1단계 | U (회전) | 방향 돌리기 |
| 2단계 | Σ (늘이기) | 크기 조절 |
| 3단계 | Vᵀ (회전) | 방향 돌리기 |

### 왜 중요해?

SVD는 AI에서 정말 많이 쓰여요:
- 추천 시스템 (넷플릭스가 영화 추천할 때!)
- 이미지 압축
- 자연어 처리 (단어의 의미 분석)

## 5. 저랭크 근사 — 중요한 정보만 남기고 압축하기

### 쉽게 말하면?

SVD로 분해한 후, **중요한 부분만 남기고 나머지는 버리는 것**이에요.

### 일상 비유: 캐리커처 그리기 ✏️

친구 얼굴을 그릴 때:
- 사진 그대로 그리기 → 완벽하지만 시간 오래 걸림
- 캐리커처 → **특징만 살려서** 빠르게 그리기

```
원본 사진 (1000가지 정보)
    ↓ 저랭크 근사
압축된 정보 (50가지 핵심 정보만)
    ↓
거의 원본처럼 보이지만 용량은 1/20!
```

### 실제 예시: 이미지 압축

```
원본 이미지 (Rank 100)
├── 1~10번째 성분: 전체 윤곽 (가장 중요!)
├── 11~30번째 성분: 세부 모양
├── 31~60번째 성분: 미세한 질감
└── 61~100번째 성분: 노이즈에 가까운 것들

Rank 10으로 압축 → 윤곽은 보존, 용량 1/10
Rank 30으로 압축 → 꽤 선명, 용량 3/10
```

### 왜 중요해?

AI에서 데이터가 너무 크면 처리가 느려요.
저랭크 근사로 **중요한 정보만 남기면** 빠르면서도 정확한 AI를 만들 수 있어요!

## 6. PageRank — 구글이 웹페이지 순위를 매기는 방법 🌐

### 쉽게 말하면?

구글 검색을 하면 결과가 순서대로 나오잖아요?
그 순서를 정하는 알고리즘이 **PageRank**예요.
그리고 이 알고리즘의 핵심이 바로 **고유벡터**!

### 일상 비유: 인기 투표

학교에서 "가장 영향력 있는 학생" 투표를 한다고 해봐요.

**규칙:**
- 투표할 때 **내가 영향력이 있으면** 내 표도 더 세진다!
- 인기 많은 애가 추천하는 사람 → 더 영향력 높아짐

```
반장 철수가 영희를 추천 → 영희 점수 크게 올라감 (철수가 유명하니까!)
평범한 지민이 민수를 추천 → 민수 점수 조금 올라감
```

### 웹페이지로 바꾸면?

```
유명한 사이트(네이버)가 내 블로그를 링크함 → 내 순위 크게 올라감!
아무도 모르는 사이트가 내 블로그를 링크함 → 내 순위 조금 올라감

이걸 반복하고 반복하면...
최종적으로 안정된 순위가 나옴!
```

### 행렬과의 연결

```
     A  B  C  (어디로 링크하는지)
A [  0  1  1 ]    A는 B, C로 링크
B [  1  0  0 ]    B는 A로 링크
C [  1  1  0 ]    C는 A, B로 링크
```

이 행렬의 **고유벡터**가 바로 각 페이지의 순위가 돼요!

### 왜 중요해?

- 이 알고리즘 하나로 구글은 세계 최대 기업이 됐어요
- 고유벡터라는 수학 개념이 실제 세상을 바꾼 대표적인 예시!
- 비슷한 원리가 SNS 추천, 유튜브 알고리즘에도 사용돼요

## 📝 정리 / 요약

| 개념 | 한 줄 설명 | 비유 |
|------|-----------|------|
| 역행렬 | 변환 되돌리기 | Ctrl+Z |
| 고유벡터 | 방향 안 바뀌는 특별한 벡터 | 태풍에서 바람 방향으로만 날아가는 잎 |
| 고유값 | 고유벡터의 크기 변화 비율 | 바람의 세기 |
| 고유값 분해 | 변환을 기본 요소로 쪼개기 | 맛을 기본 맛으로 분석 |
| SVD | 모든 변환을 회전+늘이기+회전으로 분해 | 포토샵 변환 3단계 |
| 저랭크 근사 | 중요한 것만 남기고 압축 | 캐리커처 |
| PageRank | 링크 구조로 중요도 계산 | 인기 투표 |

> 💡 **핵심 포인트**: 복잡한 변환도 분해하면 단순해져요.
> 그리고 이 "분해"가 구글 검색부터 넷플릭스 추천까지, 우리 일상을 바꾸고 있어요!
