# 15. RNN: AI가 말과 순서를 이해하는 방법 💬

## 간단한 소개

우리가 문장을 읽을 때, 앞에서 읽은 내용을 **기억하면서** 뒤의 내용을 이해해요. "나는 학교에 가서 ___를 만났다"라는 문장에서, 앞부분("학교에 가서")을 기억하고 있어야 "선생님" 같은 적절한 단어를 떠올릴 수 있잖아요?

CNN은 이미지를 잘 이해하지만, **순서가 있는 데이터**(문장, 음악, 주가 등)는 잘 처리하지 못해요. 이런 데이터에는 **RNN(순환 신경망)**이 필요해요!

---

## 1. 워드 임베딩: 단어를 숫자로 바꾸기

### 쉬운 설명

컴퓨터는 글자를 이해하지 못해요. 그래서 단어를 **숫자 화살표(벡터)**로 바꿔야 해요. 이것을 **워드 임베딩(Word Embedding)**이라고 해요.

### 일상 비유 📊

모든 단어를 **능력치표**로 바꾼다고 생각해 봐요. 게임 캐릭터처럼요!

| 단어 | 동물 점수 | 크기 점수 | 귀여움 점수 |
|------|----------|----------|------------|
| 강아지 | 0.9 | 0.3 | 0.9 |
| 고양이 | 0.9 | 0.2 | 0.8 |
| 코끼리 | 0.9 | 0.95 | 0.3 |
| 자동차 | 0.0 | 0.7 | 0.1 |

이렇게 하면 **비슷한 단어는 비슷한 숫자**를 가지게 돼요!

```
           귀여움 ↑
                │  ● 강아지
                │  ● 고양이
                │
                │         ● 코끼리
                │
                │                    ● 자동차
                └──────────────────→ 크기
```

강아지와 고양이는 가까이, 자동차는 멀리 있어요! 이렇게 **의미가 비슷한 단어는 가까운 위치**에 놓이도록 하는 것이 워드 임베딩이에요.

### 신기한 성질

워드 임베딩에는 이런 신기한 관계도 생겨요:

```
왕 - 남자 + 여자 ≈ 여왕
한국 - 서울 + 도쿄 ≈ 일본
```

단어 사이의 **관계까지** 숫자로 표현할 수 있어요!

### 왜 중요한가요?

워드 임베딩 덕분에 AI가 단어의 **의미를 이해**할 수 있게 돼요. "강아지"와 "고양이"가 비슷하다는 것도, "강아지"와 "자동차"가 다르다는 것도 알 수 있어요.

---

## 2. 마르코프 모델: 바로 앞만 기억하기

### 쉬운 설명

RNN을 배우기 전에, 더 단순한 방법을 먼저 볼게요. **마르코프 모델**은 **바로 직전 단어만** 보고 다음 단어를 예측하는 방법이에요.

### 일상 비유 🔗

끝말잇기를 생각해 봐요!

- "사과" → 다음은 "과"로 시작하는 단어 → "과일"
- 바로 앞 단어("사과")만 보고 판단!

```
"오늘" → "날씨가" → "좋다"
  ↓          ↓
앞 단어만    앞 단어만
  보고        보고
다음 예측    다음 예측
```

### 한계

"나는 프랑스에서 태어나서 프랑스어를 유창하게 할 수 있다. 나의 모국어는 ___"

마르코프 모델은 "모국어는" 바로 뒤에 올 단어만 추측해요. 문장 앞부분의 "프랑스"를 기억하지 못하기 때문에 정확한 답("프랑스어")을 맞추기 어려워요.

**이래서 RNN이 필요한 거예요!**

---

## 3. RNN: 기억력이 있는 신경망

### 쉬운 설명

**RNN(Recurrent Neural Network, 순환 신경망)**은 이전 정보를 **기억**하면서 순서대로 처리하는 신경망이에요.

### 일상 비유 📓

수업 시간에 필기하는 것과 비슷해요.

- 선생님이 말할 때마다 **메모장에 정리**
- 새로운 내용이 나오면 **이전 메모를 참고하면서** 추가
- 결국 메모장에 수업 전체 내용이 축적!

```
시간 →  단어1    단어2    단어3    단어4
         ↓        ↓        ↓        ↓
메모:  [메모1] → [메모2] → [메모3] → [메모4]
       "나는"    "나는     "나는     "나는
                  학교에"   학교에    학교에
                            가서"    가서
                                    공부를"
```

각 시점에서 RNN은:
1. **새로운 입력**(현재 단어)을 받고
2. **이전 메모**(기억)를 참고해서
3. **새로운 메모**(업데이트된 기억)를 만들어요

### 왜 중요한가요?

RNN 덕분에 AI가 **문맥을 이해**할 수 있게 돼요. "bank"가 "은행"인지 "강둑"인지는 앞뒤 문맥을 봐야 알 수 있잖아요!

---

## 4. 기울기 소실: 긴 문장의 기억을 잃다

### 쉬운 설명

RNN에는 큰 문제가 있어요. 문장이 길어지면 **앞부분의 기억이 점점 사라지는** 거예요. 이것을 **기울기 소실(Vanishing Gradient)** 문제라고 해요.

### 일상 비유 📢

전화 돌리기 게임을 생각해 봐요.

```
1번 학생: "프랑스에서 태어났대"
    ↓ (전달)
2번 학생: "프랑스에서 태어났대"
    ↓
3번 학생: "어디선가 태어났대"
    ↓
 ... (50명 지남) ...
    ↓
50번 학생: "뭐라고 했더라...?" 😵
```

정보가 전달될수록 점점 희미해져요. RNN에서도 마찬가지로, 단어가 많이 지나면 처음에 나온 정보를 거의 기억하지 못해요.

### 왜 문제인가요?

"나는 **한국**에서 태어나고 자라서, 초등학교부터 고등학교까지 쭉 한국에서 교육을 받았고, 대학교도 서울에 있는 학교에 다녔기 때문에, 나의 모국어는 ___이다."

이런 긴 문장에서 "한국"이라는 정보가 끝까지 전달되어야 "한국어"를 맞출 수 있는데, RNN은 이걸 잊어버려요.

---

## 5. LSTM: 똑똑한 기억장치

### 쉬운 설명

**LSTM(Long Short-Term Memory)**은 RNN의 기억력 문제를 해결하기 위해 만든 **업그레이드된 RNN**이에요. 세 개의 "문(gate)"이 있어서 기억을 똑똑하게 관리해요.

### 일상 비유 🚪

LSTM을 **똑똑한 필통**이라고 생각해 봐요.

```
┌─────────────────────────────────────┐
│           LSTM 필통                   │
│                                       │
│  🚪 잊기 문          → 필요 없는 펜 버리기     │
│  (Forget Gate)       "이 정보는 이제 필요 없어" │
│                                       │
│  🚪 입력 문          → 새 펜 넣기            │
│  (Input Gate)        "이 정보는 기억해야 해"   │
│                                       │
│  🚪 출력 문          → 지금 쓸 펜 꺼내기      │
│  (Output Gate)       "지금 이 정보가 필요해"   │
│                                       │
└─────────────────────────────────────┘
```

**각 문의 역할**:

| 문 | 역할 | 예시 |
|---|------|------|
| 잊기 문 | 더 이상 필요 없는 기억 삭제 | 주제가 바뀌면 이전 주제 잊기 |
| 입력 문 | 새로 기억할 정보 선택 | 중요한 키워드 기억하기 |
| 출력 문 | 지금 사용할 기억 선택 | 답을 쓸 때 관련 기억 꺼내기 |

### 전화 돌리기와의 차이

```
일반 RNN (전화 돌리기):
1번 → 2번 → ... → 50번 → "뭐라고?" 😵

LSTM (핵심만 메모해서 전달):
1번 → [메모: "한국 태어남"] → 2번 → [메모 유지] → ... → 50번 → "한국어!" 🎉
```

### 왜 중요한가요?

LSTM 덕분에 AI가 **긴 문장도** 이해할 수 있게 돼요. 번역, 요약, 대화 등 많은 자연어 처리에 혁신을 가져왔어요.

---

## 6. GRU: LSTM의 간단한 버전

### 쉬운 설명

**GRU(Gated Recurrent Unit)**는 LSTM을 **더 간단하게** 만든 것이에요. LSTM의 3개 문 대신 **2개 문**만 사용해요.

### LSTM vs GRU 비교

```
LSTM:                     GRU:
┌──────────────┐         ┌──────────────┐
│ 잊기 문 🚪    │         │ 리셋 문 🚪    │
│ 입력 문 🚪    │         │ 업데이트 문 🚪 │
│ 출력 문 🚪    │         │               │
│ (문 3개)      │         │ (문 2개)       │
└──────────────┘         └──────────────┘
복잡하지만 강력           간단하고 빠름
```

| | LSTM | GRU |
|---|------|-----|
| 문 개수 | 3개 | 2개 |
| 속도 | 상대적으로 느림 | 상대적으로 빠름 |
| 성능 | 매우 좋음 | 비슷하게 좋음 |
| 비유 | 고급 필통 (칸이 많음) | 실용적 필통 (칸이 적지만 충분) |

### 왜 중요한가요?

GRU는 LSTM과 비슷한 성능을 내면서 더 가볍고 빨라요. 상황에 따라 LSTM과 GRU 중 적합한 것을 골라 쓸 수 있어요.

---

## 7. Seq2Seq: 문장을 다른 문장으로 바꾸기

### 쉬운 설명

**Seq2Seq(Sequence to Sequence)**는 **하나의 문장(순서)을 다른 문장(순서)으로** 변환하는 구조예요. 번역이 대표적인 예시!

### 일상 비유 🌍

통역사를 생각해 봐요.

```
한국어 문장:    "오늘 날씨가 좋아요"
                    ↓
             [통역사의 뇌] 🧠
             (내용 이해 중...)
                    ↓
영어 문장:    "The weather is nice today"
```

Seq2Seq도 이와 같아요. 두 부분으로 나뉘어져 있어요.

### 구조: 인코더와 디코더

```
인코더 (듣는 사람):              디코더 (말하는 사람):
한국어를 듣고 이해                이해한 내용을 영어로 표현

"오늘" → [RNN] ─┐
"날씨가"→ [RNN] ─┤
"좋아요"→ [RNN] ─┘
                 ↓
            [요약 정보] ←── "이 사람이 날씨가 좋다고 한 거구나!"
                 ↓
            [RNN] → "The"
            [RNN] → "weather"
            [RNN] → "is"
            [RNN] → "nice"
            [RNN] → "today"
```

- **인코더**: 입력 문장을 읽고 의미를 압축
- **디코더**: 압축된 의미를 풀어서 새로운 문장 생성

### Seq2Seq로 할 수 있는 것들

| 응용 | 입력 | 출력 |
|------|------|------|
| 번역 | 한국어 문장 | 영어 문장 |
| 요약 | 긴 글 | 짧은 요약 |
| 챗봇 | 질문 | 대답 |
| 문법 교정 | 틀린 문장 | 바른 문장 |

### 왜 중요한가요?

Seq2Seq는 **입력과 출력의 길이가 달라도** 처리할 수 있어요. "나는 학생입니다"(4글자)를 "I am a student"(4단어)로 바꾸는 것처럼요. 이 구조가 나중에 **Transformer(트랜스포머)**로 발전하면서 ChatGPT 같은 AI가 탄생하게 돼요!

---

## 순서 모델의 발전 과정

```
마르코프 모델 (바로 앞만 기억)
      ↓
RNN (기억 있지만 짧은 기억)
      ↓
LSTM/GRU (긴 기억 가능!)
      ↓
Seq2Seq (문장 → 문장 변환)
      ↓
Transformer (다음 시간에!)
```

---

## 정리/요약 📝

| 개념 | 한 줄 요약 |
|------|-----------|
| 워드 임베딩 | 단어를 의미가 담긴 숫자 화살표로 변환 |
| 마르코프 모델 | 바로 앞만 보고 다음 예측 (기억 없음) |
| RNN | 기억을 가진 신경망 (메모장처럼 정보 축적) |
| 기울기 소실 | 긴 문장에서 앞부분 기억을 잃는 문제 |
| LSTM | 3개의 문으로 기억을 똑똑하게 관리 |
| GRU | LSTM의 간단 버전 (2개의 문) |
| Seq2Seq | 한 문장을 다른 문장으로 바꾸기 (번역 등) |

### 핵심 한 마디

> RNN 계열은 **순서와 문맥을 기억**하면서 데이터를 처리해요. 문장, 음악, 주가처럼 **앞뒤 순서가 중요한 데이터**에 딱!

이 시리즈를 통해 AI의 기본부터 이미지(CNN), 순서 데이터(RNN)까지 알아봤어요. 이제 여러분은 AI의 핵심 원리를 이해하는 중학생 AI 전문가예요! 🎓
