# 🔍 베이즈 정리와 정보 이론: AI가 배우고 판단하는 방법

## 간단한 소개

여러분은 새로운 정보가 들어오면 **생각을 바꾸죠?**

"오늘 비 올까?"
→ 하늘이 흐리면 "비 올 것 같다"로 바뀌고,
→ 우산 챙긴 친구를 보면 "거의 확실하다"로 바뀌어요.

이렇게 **새로운 증거로 믿음을 업데이트**하는 걸
수학적으로 정리한 게 **베이즈 정리**예요.

그리고 "정보가 얼마나 가치 있는지"를 측정하는 방법이
**정보 이론**이에요.

이 두 가지가 합쳐져서 AI가 학습하고 판단하는 핵심 도구가 됩니다!

---

## 1. 베이즈 정리: 증거로 믿음 업데이트하기 🔄

### 쉬운 설명

**베이즈 정리**의 핵심 아이디어는 간단해요:

> **이전 믿음 + 새로운 증거 = 업데이트된 믿음**

### 일상 비유: 아침에 날씨 예측하기

아침에 일어났을 때 "오늘 비가 올까?" 생각해 봐요.

**1단계: 이전 믿음 (사전 확률)**
> 요즘 비 오는 날이 10일 중 3일이니까...
> 비 올 확률 = 30%

**2단계: 새로운 증거 발견!**
> 창밖을 보니 하늘이 잔뜩 흐려요!

**3단계: 업데이트된 믿음 (사후 확률)**
> 흐린 날에 비가 올 확률은 높으니까...
> 비 올 확률 = 70%로 업데이트!

**4단계: 또 다른 증거!**
> 일기예보에서 "비 온다"고 했어요!

**5단계: 다시 업데이트!**
> 비 올 확률 = 90%!

```
30% ──[하늘 흐림]──→ 70% ──[일기예보]──→ 90%
 │                    │                    │
이전 믿음          1차 업데이트        2차 업데이트
```

### 왜 대단할까?

- 완벽한 정보가 없어도 판단할 수 있어요
- 정보가 추가될수록 점점 정확해져요
- 우리 뇌가 실제로 이렇게 작동한다고 해요!

## 2. MLE와 MAP: AI가 답을 추측하는 두 가지 방법 🎯

### MLE: 가장 그럴듯한 답 찾기

**MLE(최대 가능도 추정)**는 이런 방식이에요:

> "이 데이터가 나올 확률이 **가장 높은** 답이 뭐야?"

#### 일상 비유: 동전의 공정성 추측

동전을 10번 던졌더니 앞면 7번, 뒷면 3번이 나왔어요.

MLE의 답: "이 동전은 앞면이 70% 나오는 동전이야!"
→ 데이터를 그대로 믿어요.

### MAP: 상식도 함께 고려하기

**MAP(최대 사후 확률 추정)**는 여기에 **상식(사전 지식)**을 더해요:

> "데이터도 보고, 상식도 고려해서 **가장 합리적인** 답을 찾자!"

#### 일상 비유: 같은 동전 상황

동전을 10번 던져서 앞면 7번, 뒷면 3번.

MAP의 답: "보통 동전은 50:50이니까... 데이터를 고려해도 한 60% 정도가 맞을 거야"
→ 상식과 데이터를 **절충**해요.

### 비교 표

| | MLE | MAP |
|---|-----|-----|
| 방식 | 데이터만 봄 | 데이터 + 상식 |
| 장점 | 데이터에 충실 | 더 안정적 |
| 단점 | 데이터가 적으면 위험 | 상식이 틀릴 수 있음 |
| 비유 | "본 대로 믿자!" | "상식도 생각하자!" |

### AI에서는?

- 데이터가 **많을 때**: MLE도 MAP도 비슷한 결과
- 데이터가 **적을 때**: MAP가 더 안정적 (상식이 도와주니까!)

## 3. 엔트로피: 불확실함을 숫자로 📏

### 쉬운 설명

**엔트로피**는 **"얼마나 예측하기 어려운지"**를 숫자로 나타낸 거예요.

- 엔트로피가 **높음** = 결과를 예측하기 어려움 (불확실)
- 엔트로피가 **낮음** = 결과를 예측하기 쉬움 (확실)

### 일상 비유: 내일 급식 메뉴

**상황 A: 엔트로피 낮음** ⬇️
> 월요일은 항상 카레!
> 내일 메뉴를 맞추기 → 아주 쉬움 (불확실성 낮음)

**상황 B: 엔트로피 높음** ⬆️
> 매일 다른 메뉴가 랜덤으로 나옴!
> 카레, 불고기, 스파게티, 비빔밥, 돈까스 중 뭐가 나올지 전혀 모름
> 내일 메뉴를 맞추기 → 아주 어려움 (불확실성 높음)

### 또 다른 비유: 스무고개

| 상황 | 엔트로피 | 스무고개 필요 질문 수 |
|------|---------|------------------|
| 2개 중 하나 (동전) | 낮음 | 1번이면 충분 |
| 6개 중 하나 (주사위) | 중간 | 2~3번 필요 |
| 100개 중 하나 | 높음 | 6~7번 필요 |

엔트로피가 높을수록 정보가 더 많이 필요해요!

## 4. 크로스엔트로피: AI의 성적표 📝

### 쉬운 설명

**크로스엔트로피**는 AI가 정답을 **얼마나 잘 맞추는지** 측정하는 점수예요.

- 크로스엔트로피가 **낮으면** → AI가 잘하고 있음! 👏
- 크로스엔트로피가 **높으면** → AI가 못하고 있음... 😥

### 일상 비유: 날씨 예보관 평가

두 명의 예보관이 있다고 해봐요.
실제 결과: **비가 왔다!**

**예보관 A:**
> "비 올 확률 90%!"라고 했음
> → 거의 맞췄으니 좋은 점수! (크로스엔트로피 낮음)

**예보관 B:**
> "비 올 확률 10%!"라고 했음
> → 완전 틀렸으니 나쁜 점수! (크로스엔트로피 높음)

### AI 학습에서의 크로스엔트로피

```
정답: 고양이

AI의 예측 (좋은 경우):         AI의 예측 (나쁜 경우):
  고양이: 0.9  ✅ 높음!          고양이: 0.2  ❌ 낮음...
  강아지: 0.05                   강아지: 0.5
  토끼:   0.05                   토끼:   0.3

  크로스엔트로피: 낮음 👍         크로스엔트로피: 높음 👎
```

### 왜 중요할까?

AI는 학습할 때 **크로스엔트로피를 줄이는 방향**으로 배워요.

```
학습 과정:
크로스엔트로피
  높음 |*
       | *
       |  *
       |   *
       |    *
       |     *  *
       |        *  *
  낮음 |           *  *  *  *
       +──────────────────────→ 학습 횟수
       AI가 점점 정답을 잘 맞추게 됨!
```

## 5. KL 발산: 두 예측이 얼마나 다른지 📐

### 쉬운 설명

**KL 발산**은 두 확률분포가 **얼마나 다른지** 측정하는 거예요.

### 일상 비유: 두 친구의 취향 비교

**철수의 좋아하는 과목 분포:**
수학 40%, 과학 30%, 영어 20%, 국어 10%

**영희의 좋아하는 과목 분포:**
수학 35%, 과학 35%, 영어 15%, 국어 15%

→ KL 발산이 **작음** (취향이 비슷해!)

**민수의 좋아하는 과목 분포:**
수학 5%, 과학 5%, 영어 10%, 국어 80%

→ 철수와 민수의 KL 발산은 **큼** (취향이 매우 다르다!)

### AI에서의 KL 발산

AI에서 KL 발산은 이렇게 쓰여요:

> "AI의 예측 분포"와 "실제 정답 분포"가 **얼마나 다른지** 측정

- KL 발산이 크면 → AI의 예측이 현실과 동떨어짐
- KL 발산이 작으면 → AI의 예측이 현실과 비슷함

사실 크로스엔트로피와 KL 발산은 **밀접하게 연결**되어 있어요.
크로스엔트로피를 줄이는 것이 곧 KL 발산을 줄이는 것과 같거든요!

┌─────────────┐     ┌──────────────┐     ┌──────────────┐

│ 새 정보로    │     │ 불확실성을    │     │ AI 예측의     │

└──────┬──────┘     └──────┬───────┘     └──────┬───────┘
       │                   │                     │
       └───────────┬───────┘                     │
                   │                             │
                   ▼                             ▼
          AI가 데이터에서 배움          AI가 얼마나 잘하는지 평가
                   │                             │
                   └──────────┬──────────────────┘
                              │
                              ▼
                     AI가 점점 똑똑해짐! 🎉

### 실제 AI 학습 사이클

1. **데이터를 본다** (새로운 증거)
2. **베이즈 정리**처럼 AI의 판단을 업데이트
3. **크로스엔트로피**로 얼마나 잘했는지 점수 매기기
4. 점수를 **낮추는 방향**으로 AI를 조정
5. 1~4를 수천, 수만 번 반복!
