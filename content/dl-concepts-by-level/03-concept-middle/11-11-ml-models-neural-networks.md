# 11. 머신러닝 모델과 신경망 🧠

## 간단한 소개

우리 뇌에는 약 860억 개의 뉴런(신경세포)이 있어요. 이 뉴런들이 서로 연결되어 생각하고, 판단하고, 기억하죠. 과학자들은 이 뇌의 구조를 흉내 내서 **인공 신경망**이라는 것을 만들었어요.

이번 글에서는 가장 단순한 인공 뉴런인 **퍼셉트론**부터 시작해서, 왜 신경망이 필요한지, 그리고 신경망이 어떻게 거의 모든 문제를 풀 수 있는지 알아볼 거예요.

---

## 1. 퍼셉트론: 가장 단순한 AI 뉴런

### 쉬운 설명

퍼셉트론은 **"예" 또는 "아니오"를 판별하는 기계**예요.

여러 가지 정보를 받아서, 각 정보에 중요도(가중치)를 곱하고, 다 더한 다음, 기준보다 크면 "예!", 작으면 "아니오!"라고 대답해요.

### 일상 비유 🍕

피자를 주문할지 말지 결정한다고 생각해 봐요.

| 조건 | 점수 | 중요도 |
|------|------|--------|
| 배가 고프다 | 있으면 1, 없으면 0 | ×3 |
| 돈이 있다 | 있으면 1, 없으면 0 | ×2 |
| 피자집이 가깝다 | 가까우면 1, 멀면 0 | ×1 |

**총점 = (배고픔 × 3) + (돈 × 2) + (거리 × 1)**

만약 총점이 4점 이상이면 → "피자 주문!" 🍕
4점 미만이면 → "참는다..." 😢

이게 바로 퍼셉트론이 하는 일이에요. 정보를 받고, 중요도를 고려해서, 최종 판단을 내리는 거죠.

### 왜 중요한가요?

퍼셉트론은 모든 신경망의 **기본 부품**이에요. 레고 블록 하나하나처럼, 이 간단한 부품들을 많이 연결하면 엄청나게 복잡한 것도 만들 수 있어요.

---

## 2. XOR 문제: 퍼셉트론의 한계

### 쉬운 설명

퍼셉트론은 **직선 하나**를 그어서 두 그룹을 나눠요. 그런데 세상에는 직선 하나로 나눌 수 없는 문제가 있어요. 그게 바로 **XOR 문제**예요.

### 일상 비유 ✂️

운동장에 빨간 팀과 파란 팀이 있어요.

```
   파란⭕         빨간🔴

   빨간🔴         파란⭕
```

이렇게 대각선으로 섞여 있으면, 줄 하나로는 절대 빨간 팀과 파란 팀을 나눌 수 없어요!

이건 마치 "둘 중 하나만 맞으면 O, 둘 다 맞거나 둘 다 틀리면 X"인 상황이에요.

- 비 오고 + 우산 없으면 → 젖는다 ⭕
- 비 안 오고 + 우산 있으면 → 안 젖는다 (하지만 민망하다 ⭕)
- 비 오고 + 우산 있으면 → 안 젖는다 ❌
- 비 안 오고 + 우산 없으면 → 안 젖는다 ❌

이런 패턴은 직선 하나로 나눌 수 없어요.

### 왜 중요한가요?

XOR 문제 때문에 1960~70년대에 AI 연구가 한동안 멈췄어요. 하지만 나중에 **여러 층의 퍼셉트론(신경망)**을 쌓으면 해결된다는 걸 발견했고, 이것이 딥러닝의 시작이 되었어요!

---

## 3. SVM: 가장 넓은 도로 긋기

### 쉬운 설명

SVM(서포트 벡터 머신)은 두 그룹을 나눌 때 **가장 넓은 도로**를 만드는 방법이에요.

### 일상 비유 🛤️

학교 운동장에서 축구팀과 야구팀의 영역을 나눈다고 해 봐요.

- 방법 1: 아슬아슬하게 경계선만 긋기 → 선수들이 자꾸 넘어옴
- 방법 2: **넓은 도로**를 만들어서 나누기 → 여유 있어서 안전!

```
축구팀 ⚽⚽⚽  |  넓은 도로  |  ⚾⚾⚾ 야구팀
                ←  여백  →
```

SVM은 이 도로의 **폭이 최대한 넓어지도록** 경계선을 찾아요. 도로 가장자리에 있는 선수들을 **서포트 벡터**라고 부르고, 이 선수들이 도로의 위치를 결정해요.

### 왜 중요한가요?

도로가 넓을수록, 새로운 선수가 와도 어느 팀인지 정확하게 판별할 수 있어요. 이것을 **일반화 능력이 좋다**고 해요.

---

## 4. 커널 트릭: 차원을 높여서 나누기

### 쉬운 설명

아까 XOR처럼 직선으로 못 나누는 경우, **차원을 하나 더 추가**하면 나눌 수 있게 돼요. 이것이 **커널 트릭**이에요.

### 일상 비유 🎪

책상 위에 동전들이 놓여 있어요. 1원짜리와 500원짜리가 섞여 있는데, 직선 하나로 나눌 수 없는 상황이에요.

그런데! 동전을 **공중으로 튀겨 올리면?** 가벼운 1원짜리는 높이 올라가고, 무거운 500원짜리는 낮게 올라가요.

```
높이 ↑
      |  1원 1원
      |       1원
      |  ─────────── ← 이제 평면으로 나눌 수 있다!
      |  500원
      |     500원 500원
      └─────────────── 위치 →
```

2차원(책상 위)에서 못 나눈 것을 3차원(공중)으로 올리니까 나눌 수 있게 된 거예요!

커널 트릭은 실제로 차원을 높이지 않고도 **높인 것 같은 효과**를 내는 수학적 방법이에요.

### 왜 중요한가요?

덕분에 SVM이 복잡한 패턴도 분류할 수 있게 되었어요. 단순한 직선 분류기가 곡선 경계도 만들 수 있게 된 거죠!

---

## 5. 신경망: 여러 층의 뉴런 연결

### 쉬운 설명

퍼셉트론 하나만으로는 XOR도 못 풀었잖아요? 그래서 퍼셉트론을 **여러 층으로 쌓아서** 연결한 것이 **신경망**이에요.

### 구조 📊

```
입력층          은닉층          출력층
 ⭕ ─────────→ ⭕ ──┐
     ╲       ╱       ├──→ ⭕ (결과)
      ╲     ╱       ┘
 ⭕ ─────────→ ⭕
```

- **입력층**: 정보를 받는 곳 (눈, 귀 역할)
- **은닉층**: 정보를 처리하는 곳 (뇌 역할) — 여러 개 가능!
- **출력층**: 결과를 내보내는 곳 (입 역할)

### 일상 비유 🏫

학교에서 문제를 푸는 과정과 비슷해요.

1. **입력층** = 선생님이 문제를 읽어줌
2. **은닉층 1** = 문제에서 핵심 키워드 찾기
3. **은닉층 2** = 어떤 공식을 쓸지 판단하기
4. **출력층** = 답 쓰기

층이 많아질수록 더 복잡한 문제를 풀 수 있어요!

### 왜 중요한가요?

신경망은 현대 AI의 핵심이에요. ChatGPT, 이미지 인식, 자율주행 등 거의 모든 AI가 신경망을 기반으로 해요.

---

## 6. 활성화 함수: 곡선 능력 부여

### 쉬운 설명

만약 신경망의 각 뉴런이 단순히 덧셈과 곱셈만 한다면, 층을 아무리 쌓아도 결국 **직선**밖에 못 그려요. **활성화 함수**는 신경망에 **곡선을 그리는 능력**을 줘요.

### 주요 활성화 함수

| 이름 | 하는 일 | 비유 |
|------|---------|------|
| **ReLU** | 0보다 작으면 0, 크면 그대로 통과 | 음수는 문 앞에서 차단! 양수만 통과! |
| **Sigmoid** | 어떤 숫자든 0~1 사이로 바꿈 | 확률로 변환! "50%로 고양이다" |

### 일상 비유 🚦

**ReLU는 신호등** 같아요.
- 빨간불(음수) → 멈춤! (0으로 바꿈)
- 초록불(양수) → 그대로 통과!

**Sigmoid는 온도계** 같아요.
- 아무리 추워도 0도 이하로 안 내려감
- 아무리 더워도 1도 이상으로 안 올라감
- 대부분의 값은 0과 1 사이 어딘가

### 왜 중요한가요?

활성화 함수가 없으면 신경망은 그냥 큰 계산기에 불과해요. 활성화 함수 덕분에 복잡한 패턴을 학습할 수 있게 돼요!

---

## 7. MLP: 다층 퍼셉트론

### 쉬운 설명

MLP는 **Multi-Layer Perceptron**, 즉 **여러 층의 퍼셉트론**이에요. 앞에서 배운 신경망의 가장 기본적인 형태죠.

### 구조

```
입력 → [뉴런뉴런뉴런] → [뉴런뉴런뉴런] → [뉴런] → 출력
        1번째 은닉층      2번째 은닉층     출력층
```

각 층의 모든 뉴런이 다음 층의 모든 뉴런과 연결되어 있어요. 그래서 **완전 연결 신경망**이라고도 불러요.

### 일상 비유 📱

스마트폰 공장의 조립 라인과 비슷해요.

- **1단계 (은닉층 1)**: 부품 검사 담당자들
- **2단계 (은닉층 2)**: 조립 담당자들
- **3단계 (출력층)**: 최종 검수 담당자

각 단계의 모든 담당자가 다음 단계의 모든 담당자에게 결과를 전달하는 거예요.

---

## 8. 보편 근사 정리: 뉴런이 충분하면 뭐든 가능!

### 쉬운 설명

**"은닉층에 뉴런이 충분히 많으면, 어떤 복잡한 패턴이든 학습할 수 있다"**는 것이 보편 근사 정리예요.

### 일상 비유 🎨

레고 블록을 생각해 봐요.

- 블록 10개 → 간단한 집만 만들 수 있음
- 블록 100개 → 멋진 성을 만들 수 있음
- 블록 10,000개 → 거의 뭐든지 만들 수 있음!

뉴런도 마찬가지예요. 뉴런(블록)이 충분히 많으면, 어떤 복잡한 관계도 표현할 수 있어요.

### 주의할 점 ⚠️

"가능하다"와 "쉽다"는 달라요!
- 이론적으로 블록 10,000개면 뭐든 만들 수 있지만...
- 실제로 만드는 건 엄청 어려울 수 있어요!
- 마찬가지로, 뉴런이 많다고 자동으로 잘 학습하는 건 아니에요.

## 9. 귀납적 편향 (Inductive Bias)

### 쉬운 설명

AI가 세상을 바라볼 때 가지고 있는 **"미리 정해진 관점"**이에요. 어떤 종류의 패턴을 더 잘 찾을지 미리 정해주는 것이죠.

### 일상 비유 🔍

수학 문제를 풀 때를 생각해 봐요.

- **선생님 A**: "이 문제는 일차방정식으로 풀어봐" → 직선 패턴을 찾게 됨
- **선생님 B**: "이 문제는 그래프로 그려봐" → 시각적 패턴을 찾게 됨
- **선생님 C**: "이 문제는 규칙을 찾아봐" → 반복 패턴을 찾게 됨

AI 모델마다 다른 귀납적 편향을 가져요.

| 모델 | 편향 (잘하는 것) |
|------|-----------------|
| MLP | 일반적인 패턴 |
| CNN (나중에 배움) | 이미지 속 무늬 |
| RNN (나중에 배움) | 순서가 있는 데이터 |

### 왜 중요한가요?

문제에 맞는 편향을 가진 모델을 골라야 해요. 이미지 문제에 RNN을 쓰면 비효율적이고, 순서 데이터에 CNN을 쓰면 마찬가지예요. **적재적소!**

## 정리/요약 📝

| 개념 | 한 줄 요약 |
|------|-----------|
| 퍼셉트론 | 예/아니오를 판별하는 가장 단순한 AI 뉴런 |
| XOR 문제 | 직선 하나로 못 나누는 문제 → 신경망의 필요성 |
| SVM | 두 그룹 사이에 가장 넓은 도로를 만드는 분류법 |
| 커널 트릭 | 차원을 높여서 직선으로 나눌 수 있게 만들기 |
| 신경망 | 여러 층의 뉴런을 연결한 네트워크 |
| 활성화 함수 | 신경망에 곡선 능력을 주는 장치 |
| MLP | 가장 기본적인 형태의 다층 신경망 |
| 보편 근사 정리 | 뉴런이 충분하면 어떤 패턴도 학습 가능 |
| 귀납적 편향 | 모델이 미리 가진 관점 (어떤 패턴을 잘 찾는지) |

### 핵심 흐름

```
퍼셉트론 (너무 단순)
   ↓
XOR 문제 발견 (한계!)
   ↓
여러 층 쌓기 = 신경망 (해결!)
   ↓
활성화 함수 추가 (곡선 가능!)
   ↓
보편 근사 정리 (이론적으로 뭐든 가능!)
```

다음 글에서는 이 신경망을 어떻게 **훈련**시키는지, 즉 학습 방법에 대해 알아볼 거예요! 🚀
